## 二、教育背景与职业履历

- **1998—2002年，中国矿业大学理学院数学系**：完成数学本科学习，奠定数理与计算基础。
- **2002年9月—2009年6月，浙江大学理学院数学系**：获应用数学博士学位。山东大学教师主页明确列示其博士导师为**王国瑾教授**，而非鲍虎军或彭群生。王国瑾教授为国内 CAD/CG 领域资深学者；这一师承关系解释了辛士庆教授从应用数学进入计算几何、几何处理与 CAD/CG 的学术路径。
- **2007年4月—2009年8月，上海 Autodesk（欧特克软件公司）**：任软件工程师。该段产业经历与博士后期交叠，是其将几何理论置于 CAD 软件工程约束、效率与鲁棒性要求下审视的重要职业节点。
- **2009年10月—2012年6月，新加坡南洋理工大学**：从事博士后研究。公开论文信息显示，他与陈双敏、何颖、王国瑾等人曾以南洋理工大学和浙江大学为署名机构合作，表明这一时期形成了跨新加坡—浙江的几何计算合作纽带。
- **2012年9月—2017年8月，宁波大学信息学院**：任职并于2014年12月获评副教授；这一阶段持续发展几何计算与几何处理方向，也形成了与陈双敏等合作者的长期联系。
- **2017年9月至今，山东大学计算机科学与技术学院 / IRC**：以预聘制副教授身份调入，现为教授、博士生导师。此后与屠长河教授共同构成 IRC 几何处理与三维计算方向的重要指导组合，并持续将成果拓展至三维重建、机器人及智能制造。

这一履历串联了浙江大学 CAD/CG 学术谱系、Autodesk 的工业软件经验、新加坡南洋理工大学的国际研究经历、宁波大学的独立发展阶段，以及山东大学 IRC 的团队化科研平台。其网络并非单一学校内生型，而是由导师谱系、海外科研经历、产业工程经验和现单位协同指导共同构成。

## 四、学术合作网络

### 4.1 与屠长河搭档关系

屠长河教授是辛士庆教授在山东大学 IRC 最紧密、最具组织性的核心合作伙伴。二人同属计算机科学与技术学院 / IRC，研究交集集中在计算机图形学、数字几何处理、三维重建和智能机器人；其合作并非偶发共同署名，而是以共同指导学生、共同通讯作者和共享团队项目为特征的稳定关系。

- **共同指导与成果共担**：SIGGRAPH 2023 获奖论文以徐瑞为第一作者，屠长河、辛士庆为通讯作者。该奖在当届213篇录用论文中仅选出5篇最佳论文，山东大学为国内科研单位首次获此荣誉。论文聚焦点云全局一致法线定向，通过规范化卷绕数场构造优化方法，并在低质量点云上获得高质量重建结果。
- **多导师协同机制**：SPM 2023 最佳论文由宗辰完成，指导教师包括王文平、屠长河、周元峰、辛士庆和陈双敏。这一组合说明屠—辛搭档既是直接的双导师单元，也是连接校内外资深学者与青年合作者的枢纽。
- **长期共同作者结构**：辛士庆个人主页的近年论文中，屠长河与辛士庆反复共同出现，并与陈双敏、王文平、王鹏飞等形成围绕网格、骨架、包络与重建的稳定合作群。

因此，屠长河可视为辛士庆在现单位的**第一圈层搭档**：屠长河更强的团队组织、国家级项目与三维建模平台资源，与辛士庆在几何计算、度量、优化及算法理论上的专长互补。二人联合指导使 IRC 能把几何理论问题转化为点云重建、制造、机器人等持续性课题。

### 4.2 跨机构合作

辛士庆教授的跨机构网络可按“历史纽带—现有共同体—课题协同”分为三类。

1. **浙江大学 / 宁波大学—山东大学延续链**：博士导师王国瑾教授所代表的浙江大学 CAD/CG 谱系，是其早期研究的学术源头。陈双敏与辛士庆在南洋理工大学、宁波大学阶段均存在经历与研究主题交集，后者现任青岛科技大学副教授；二人及屠长河、周元峰等在测地距离、几何处理和网格方向存在多篇公开合作记录。该链条体现出从浙江大学数学与 CAD/CG、经新加坡与宁波、延展至山东青岛区域高校的持续合作。
2. **青岛科技大学**：陈双敏作为共同作者和共同指导网络的重要节点，参与了 SIGGRAPH 2023 与 SPM 2023 相关成果。她的研究方向包括计算机图形学、深度几何处理和计算辅助几何设计，与辛士庆教授的几何计算主线高度互补。
3. **山东大学内部跨团队协同**：周元峰、江铭炎、贾晓红、王鹏飞等以共同论文、共同指导或学术报告邀请等方式进入网络。以 SPM 2023、SIGGRAPH 2023 及后续 CAD/几何重建论文为例，体现出计算机学院、软件学院以及相关研究方向之间的协作。

从方法论看，跨机构合作围绕可共享的数据对象和方法组件展开：点云、隐式曲面、网格、SDF、测地距离场和 CAD 表面。它们具有明确的理论接口与工程接口，因而能支持不同机构、不同专长研究者的协同。

### 4.3 国际合作

国际连接主要来自三个层面。

- **新加坡南洋理工大学经历**：2009—2012年博士后阶段建立了新加坡研究联系。公开论文《The Closest and Farthest Points to an Affine Ellipse or Ellipsoid》列示陈双敏、辛士庆、何颖、王国瑾等作者及南洋理工大学 / 浙江大学机构信息，体现了计算几何与图形学方向的跨国合作。
- **北美与港澳合作节点**：SIGGRAPH 2023 获奖论文的公开报道列示香港大学博士生窦志扬、美国德州大学达拉斯分校博士生王宁娜、美国德州大学达拉斯分校郭小虎教授及美国德州农工大学王文平教授等合作者。该成果将山东大学 IRC 的学生培养与香港、美国研究网络联结在同一项顶级会议成果中。
- **国际学术共同体嵌入**：在 SIGGRAPH、SPM、GMP 等国际会议持续发表和获奖，并担任 IEEE TVCG Associate Editor，使其合作网络不仅依赖项目共同作者，也通过期刊编辑、同行评审和国际会议组织进入更广泛的学术互动网络。

国际合作的特点不是泛化的“访问式”联系，而是与具体几何问题绑定：点云法线定向、网格生成、三维重建、形状抽象和几何度量等。这种问题导向合作更有利于形成稳定的算法—代码—数据—论文共同体。

## 五、业界合作关系深度分析

### 5.1 Autodesk 经历：工业软件视角进入学术研究

辛士庆教授于2007年4月至2009年8月在上海 Autodesk 任软件工程师。该段经历处在博士攻读后期，与其计算几何研究形成直接互补。Autodesk 是 CAD、三维建模、仿真和数字内容创建软件的重要企业平台，软件工程岗位通常要求算法不仅正确，还需面对大模型数据、数值稳定性、计算效率、用户交互及产品迭代等约束。

从其后续研究轨迹看，Autodesk 经历的深层价值主要体现在：

1. **问题选择的工程性**：辛士庆教授长期聚焦离散测地线、Voronoi / Power 图、网格剖分、曲面重建与路径规划等基础问题；这些问题是 CAD、几何建模、制造和仿真软件中的底层能力，而非脱离应用的纯理论命题。
2. **算法评价标准的产品化**：其测地线算法被强调具有时间和空间优势，且被 CGAL 采用。与单纯以理论复杂度或论文指标衡量不同，这反映出对可实现性、资源效率和软件复用价值的重视。
3. **从工业问题返回学术创新**：个人主页明确指出其成果已在 CAD、数字几何处理、虚拟现实、机器人路径规划、智能制造等领域应用和验证。这种“工业约束—学术抽象—再落地”的循环，是其学术关系网络中企业经历最核心的作用。

需要区分的是：公开资料能确认其曾在 Autodesk 任职，但未披露其在职期间的具体产品线、项目名称、直接企业合作者或后续是否存在正式联合项目。因此，本报告将 Autodesk 定位为其重要的**职业与工程经验节点**，而不将其表述为已证实的持续企业联合研发关系。

### 5.2 CGAL 算法库贡献：从论文影响到开源基础设施影响

CGAL（Computational Geometry Algorithms Library）是国际计算几何与几何处理领域的重要开源算法库。辛士庆教授主页指出，其提出的测地线算法凭借时间与空间效率优势，成为“唯一被 CGAL 使用的测地线算法”。这一事实具有比一般论文引用更深的产业与社区意义：

- **可复用性**：算法进入通用库，意味着其他研究者和工程开发者可在统一接口下调用，成果从“作者团队可运行”转化为“社区可复用”。
- **工程可信度**：算法库通常对接口设计、鲁棒性、维护性和文档化有较高要求。被纳入 CGAL 表明该成果通过了开源几何软件生态的实际使用门槛。
- **影响扩散路径**：该贡献连接了学术论文作者、CGAL 维护与用户社区、CAD / CAE / 数字制造开发者及教学用户，使辛士庆教授的网络影响不局限于直接共同作者。
- **与 Autodesk 经历的耦合**：工业 CAD 软件经验强调算法工程化，CGAL 采用则提供开源基础设施层面的外部佐证；二者共同塑造了“面向软件基础设施的几何算法研究”特色。

### 5.3 面向企业场景的合作与转化接口

公开教师主页列示的近年科研项目包括机器人装配引导定位技术开发服务、砂型缺陷检测技术研究及系统软件开发、钻爆法隧道开挖数字化控制技术研究、单板 PCB 复杂图形等距偏移线快速生成算法研究等。虽然页面未逐项披露合作企业名称、经费规模及成果归属，但项目命名已呈现出鲜明的产业问题接口：

| 应用接口 | 可对应的几何技术能力 | 可能受益产业 |
|---|---|---|
| 机器人装配引导定位 | 三维感知、点云处理、路径规划、几何约束优化 | 智能制造、自动化装配 |
| 砂型缺陷检测 | 三维智能检测、形状分析、缺陷识别 | 铸造与质量检测 |
| 隧道开挖数字化控制 | 三维重建、空间建模、测量与仿真 | 基础设施与工程数字化 |
| PCB 等距偏移线 | 平面 / 曲线几何、偏置计算、鲁棒算法 | 电子制造与 EDA / CAM |
| 复杂 CAD 曲面与网格重建 | SDF、网格提取、曲面重建与拓扑保持 | CAD / CAM、工业元宇宙、增材制造 |

这些项目表明，辛士庆教授的企业关系不应仅理解为某一家软件公司的履历，而应理解为以几何算法为底座、面向制造、检测、机器人和工程数字化的**多行业技术扩散网络**。其显著优势在于：不同产业问题虽然表象各异，但可回归到共同的几何表示、距离计算、网格生成、特征提取与优化求解框架，因而有助于形成可迁移的算法资产。

## 七、Connection圈层总结

辛士庆教授的学术关系网络可概括为五个相互连接的圈层：

1. **师承与学术源头圈层：浙江大学—王国瑾教授**  
   博士阶段由王国瑾教授指导，建立应用数学、计算几何与 CAD/CG 的交叉基础。该圈层提供其研究范式和早期学术共同体入口；鲍虎军、彭群生均是浙江大学 CAD/CG 领域的重要学者，但公开教师主页明确的博士导师为王国瑾，故不应将前二者误列为其博士导师。

2. **核心协同圈层：屠长河—IRC 团队**  
   屠长河是现阶段最关键的共同指导与合作搭档。以徐瑞的 SIGGRAPH 2023 最佳论文、宗辰的 SPM 2023 最佳论文为代表，二人构建了从学生培养到国际顶会成果的稳定协同机制；陈双敏、周元峰、江铭炎、贾晓红、王鹏飞等构成围绕几何处理与三维计算的扩展节点。

3. **学生与学术传承圈层：博士、硕士与联合培养学生**  
   以已培养博士11名、硕士34名的规模为基础，学生网络连接点云处理、网格化、交叉场、神经 SDF、智能检测和人机交互等议题。其特征是学生常在双导师或多导师体系中接受训练，网络密度和跨领域能力较强。

4. **跨机构与国际合作圈层：南洋理工大学、香港 / 美国合作伙伴及几何处理共同体**  
   南洋理工大学博士后经历、浙江—宁波—青岛区域合作链，以及与香港大学、美国德州大学达拉斯分校、美国德州农工大学等合作者在 SIGGRAPH 成果中的连接，共同构成国际化的研究协作面。王文平、郭小虎、何颖等是该圈层中具有代表性的学术节点。

5. **产业与开源基础设施圈层：Autodesk—CGAL—智能制造应用**  
   Autodesk 软件工程师经历提供工业软件问题意识；CGAL 采用测地线算法提供开源基础设施影响；机器人装配、砂型检测、隧道数字化、PCB 偏移计算等项目将其算法连接至制造和工程场景。该圈层的价值在于将几何理论、软件工程和产业应用贯通。

总体而言，辛士庆教授不是以单一机构或单一合作对象为中心的研究者，而是处在一个由**浙江大学师承、IRC 双导师协同、学生梯队、国际几何处理合作者、工业软件与开源算法库**共同组成的多层网络中。其网络核心竞争力在于把严格的几何理论转化为可验证、可实现、可迁移的计算工具；这既促进顶级学术成果的产生，也为 CAD、三维重建、机器人和智能制造建立了稳定的合作接口。
