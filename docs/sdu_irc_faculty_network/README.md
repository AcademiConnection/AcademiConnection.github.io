## 二、教师的角色定位

**团队负责人与学术谱系枢纽：** 屠长河教授是IRC的现任负责人，2003年在山东大学获得计算数学博士学位（导师为孟祥旭教授），1993年留校任教至今。他的研究方向横跨计算机图形学、数字几何处理、3D视觉和智能机器人，带领团队在SIGGRAPH 2023获得最佳论文奖（国内科研单位首次获此荣誉）。屠长河是连接IRC上下两代学者的核心枢纽——向上继承孟祥旭的学术血脉，向下培养出周元峰（2009年博士）、李曼祎（2018年博士）、曾琼（2015年博士）等已成为教师的下一代学者，形成了山东大学图形学方向的四代学术谱系。此外，他与辛士庆教授形成了极为紧密的"双导师"搭档模式，几乎所有近期SIGGRAPH/SPM论文均为二人共同通讯指导。在国际合作层面，他与德州农工大学王文平教授保持了20余年的深度合作关系，王文平是连接山大IRC与国际图形学界的核心桥梁。

**几何处理核心搭档：** 辛士庆教授（浙江大学博士，师从王国瑾教授）是屠长河在IRC最核心的学术搭档。他2017年从宁波大学加入山东大学，与屠长河形成了覆盖几乎所有近期高水平论文的联合指导模式。辛士庆的标志性成就包括提出被CGAL算法库采用的测地线算法（唯一被CGAL使用的测地线算法）、3次获得最佳论文奖（SPM 2017、SPM 2023、SIGGRAPH 2023）。他曾在Autodesk担任软件工程师（2007-2009），这段工业经历为他的研究提供了问题意识。他与屠长河的搭档模式是IRC近年学术产出爆发的关键结构因素。

**3D打印与几何制造：** 吕琳教授（香港大学博士，齐鲁青年学者）是IRC在3D打印和面向智能制造的几何计算方向的核心力量。她2007-2009年在法国INRIA访问，2011年加入山大。她的研究成果已转化应用6项专利，核心算法被集成到国产云CAD平台，并应用于航空发动机和重大装备部件。她与屠长河、辛士庆同属 IRC 核心教授层，在SPM 2020获最佳论文一等奖、2020年获山东省自然科学一等奖。

**智慧医疗与产业转化：** 周元峰教授（屠长河2009年博士毕业生）现为山东大学软件学院副院长，是IRC学术家族中产业转化能力最突出的成员。他的研究方向涵盖智能图形图像处理和计算医学，主持国家重点研发计划项目1项、千万级横向项目2项，总立项经费近三千万元。他担任山东省工业技术研究院智慧医疗与精准正畸研发中心主任，将图形学技术应用于医疗领域，获IEEE VR 2024最佳论文奖、GMP 2025最佳论文奖等多个国际奖项。他是屠长河→下一代教师传承链中"学术与产业双轮驱动"的典型代表。

**学术奠基人：** 孟祥旭教授（1998年中科院计算所博士，泰山学者）是山东大学计算机图形学方向的奠基人。他1985年留校任教，1997年晋升教授，2000-2013年担任计算机科学与技术学院院长和软件学院院长，是屠长河的博士导师。他的研究方向涵盖人机交互与虚拟现实、CAD/CAM/CIMS，获国家科技进步二等奖2项，兼任CCF CAD/CG专委会副主任。他代表的不仅是个人学术成就，更是山东大学图形学方向从1980年代CAD教研室到今天IRC的学术传承起点——汪嘉业教授创建CAD教研室（1981年），传至孟祥旭，再传至屠长河，形成了跨越四十年的三代学术血脉。

**青年学者梯队：** 李曼祎（屠长河2018年博士毕业生，曾在SFU和Daniel Cohen-Or合作博士后研究）和曾琼（屠长河2015年博士毕业生，博士后合作导师为陈宝权，2025年9月晋升教授）是IRC学术家族第四代的代表。李曼祎在山东大学软件学院建立了独立的研究组，获2024年CCF自然科学一等奖、山东省优秀青年科学基金（海外），曾在Intelligent Project Solutions Inc.担任AI科学家。钟凡（浙江大学2010年博士）专注计算机视觉方向，其自动抠图算法被三星、NVIDIA等企业采用，是IRC在视觉/AR方向的独特力量。三人代表了IRC在保持几何处理主线的同时向AI、可视化、视觉等方向拓展的趋势。

## 三、团队关系网络的整体观察

**1. "孟祥旭→屠长河→周元峰/李曼祎/曾琼"四代学术谱系是理解IRC内部权力结构的核心线索。** 这条传承链从1980年代汪嘉业教授创建CAD教研室算起，跨越40余年：汪嘉业（一代）→孟祥旭（二代，1998年博士）→屠长河（三代，2003年博士）→周元峰（四代，2009年博士）/李曼祎（四代，2018年博士）/曾琼（四代，2015年博士）。在这条链上，每一代人都培养了下一代教师，形成了完整的"内生传承"闭环。这与中科大GCL的"四代传承"叙事在结构上高度相似，但山大的谱系更强调从CAD/制造业信息化到纯几何处理再到AI+图形的方向演进。

**2. "屠长河—辛士庆"双导师搭档模式是IRC近年学术产出爆发的关键结构因素。** 辛士庆2017年加入山大后，与屠长河形成了几乎覆盖所有近期高水平论文的联合指导模式。二人的互补性极强：屠长河提供团队领导力、产业资源和学术血脉，辛士庆带来浙大几何处理的理论深度和CGAL算法库的工程能力。SIGGRAPH 2023最佳论文（徐瑞一作）、SPM 2023最佳论文（宗辰一作）均为二人共同通讯指导。这种"PI+学术搭档"的模式在国内图形学团队中并不多见，更接近国际实验室的co-PI结构。

**3. 汪云海和陈宝权的先后离职对IRC方向版图产生了结构性影响。** 陈宝权（IRC创始人，2013年创建）后转入北京大学，汪云海（可视化方向核心教授，国家级青年人才）于2023年12月转入中国人民大学。二人的离去使IRC在可视化和VR方向有所收缩，但通过钟凡（视觉/AR）和曾琼（数据可视化）的补充，以及屠长河—辛士庆在几何处理方向的持续强势输出，团队整体竞争力未受显著影响。汪云海在山大期间指导的博士生（如赵跃）仍在与他联合发表论文，形成了跨校的师生合作延续。

**4. 王文平教授是连接IRC与国际图形学界的关键桥梁。** 德州农工大学的王文平（Wenping Wang）教授出现在团队20余篇共同论文中，是几乎所有SPM和SIGGRAPH Asia获奖论文的合作者。他曾是香港大学教授（吕琳的博士导师也在港大），与屠长河的合作可追溯到2000年代。这条"山大—港大—德州农工"的国际合作链条是IRC区别于纯本土团队的重要特征。

**5. 产业合作覆盖"超算渲染—3D打印—智慧医疗—制造业信息化"四大方向，且各成员的产业合作各有侧重。** 屠长河主持研发了国际首个部署于神威太湖之光的并行渲染引擎RWing，并担任国家重点研发计划"工业软件"专项首席科学家，其纺织图案处理成果已应用于100余家企业。吕琳的3D打印几何算法被集成到国产云CAD平台，6项专利已转化应用。周元峰在智慧医疗领域有千万级横向项目，总经费近三千万元。孟祥旭作为山东省制造业信息化专家组组长，建立了覆盖中国重汽、潍柴、浪潮等龙头企业的产业合作网络。辛士庆的测地线算法被CGAL开源库采用（间接影响全球图形学软件生态），近年 also directly 面向机器人装配定位、砂型缺陷检测等工业场景。这种"基础理论→开源工具→商业产品"的全链条产业化能力是IRC的显著优势。
