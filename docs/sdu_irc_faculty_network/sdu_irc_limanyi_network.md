## 五、业界合作关系深度分析

### 5.1 Intelligent Project Solutions Inc. (IPS) — AI科学家经历

2019–2021年在SFU从事博士后研究期间，李曼祎同时在Intelligent Project Solutions Inc.（IPS，官网 ips-ai.com）兼职担任AI科学家（intern research scientist），从事布局数字化与编辑（Layout digitalization and editing）项目。

**IPS公司概况：**

IPS是一家专注于为流程工业和制造业提供AI驱动的数字化转型方案的科技公司。其核心产品iEng是一套基于深度学习、计算机视觉和自然语言处理的数字数据平台，主要服务于工程设计、资产管理和采购领域。具体产品线包括：

- **iDrawings**：将工程图纸（如P&ID管线图）数字化为结构化数据的智能软件
- **iDocuments**：将工程文档数字化为结构化工程属性与数据的软件
- **iWorkflow**：整合工程数据以构建数字工作流、自动化业务流程的平台

IPS的服务覆盖智能P&ID转换、工程文档与数据管理、采购数据管理、数字资产管理、数字孪生数据集成、数字移交及工程数据迁移等。其客户主要来自石油化工、能源、制造等流程工业领域。

**李曼祎在IPS的工作意义：**

这段业界经历与李曼祎的核心研究方向——3D室内场景的布局理解与生成——高度相关。IPS的布局数字化项目涉及对工程图纸和场景布局的AI解析、结构化与编辑，这与学术研究中场景布局合成、结构化表征学习等问题在方法论上相通。这段经历使李曼祎成为少数兼具顶级学术发表与工业界AI落地经验的青年学者，也为其回国后申请山东省优秀青年科学基金（海外）提供了重要的海外背景支撑。

### 5.4 学术-工业网络的协同效应

3. **人才-项目循环**：其学生陈浩然在SymBridge项目中参与人机交互系统开发，将学术训练与企业需求结合，形成了"学生培养–项目执行–成果产出"的良性循环。

## 七、Connection圈层总结

李曼祎的学术关系网络可按圈层结构总结如下：

**第一圈层（导师与核心合作者）：**
- **屠长河**（山东大学，博士导师）：合著11+篇，从博士阶段至今持续合作，覆盖其全部学术生涯。回国后形成"软件学院–计算机学院"跨院系联合指导模式。
- **Hao (Richard) Zhang**（SFU，博士后导师）：合著8+篇，是GrUVi实验室网络的核心锚点。GrUVi作为全球排名前列的视觉计算实验室，为李曼祎提供了SFU乃至整个北美图形学界的学术通道。
- **Daniel Cohen-Or**（特拉维夫大学，ACM Fellow、SIGGRAPH Achievement Award）：合著2篇，但作为GRAINS（李曼祎代表性工作之一）的共同作者，具有高影响力学术背书意义。他自2016年起兼任SFU客座教授，是GrUVi网络与以色列图形学界的桥梁人物。

**第二圈层（IRC同门与SFU同期）：**
- **IRC同门**：辛士庆（山东大学，合著2篇）、徐瑞（SIGGRAPH 2023最佳论文得主）、董秋杰等。屠长河团队培养的学生在图形学顶会屡获佳绩，李曼祎是其中成功回国的代表。
- **SFU GrUVi同期**：Akshay Gadi Patil（合著4篇，核心合作者）、Manolis Savva、Ali Mahdavi-Amiri等。GrUVi校友网络辐射全球学术与工业界（Adobe、Google、Amazon等）。
- **陈宝权**（北京大学，前SDU IRC创始主任）：虽合著仅2篇，但作为IRC的创立者，他与李曼祎存在机构层面的历史渊源——李曼祎正是在陈宝权担任IRC主任期间（2013–2018）攻读博士学位的。

**第三圈层（现单位同事与跨校合作者）：**
- **山东大学软件学院同事**：孟磊、周元峰、王鹏飞、朱君秋、武蕾、王璐等，以及计算机科学与技术学院的孟祥旭（合著2篇）。软件学院人机交互与虚拟现实研究中心为她提供了回国后的学术平台，同事间的合作（如DreamFont3D、Hierarchical Scenes）体现了中心内部的多方向协同。
- **跨校合作者**：胡瑞珍（深圳大学）、刘健（沈阳工业大学）、马月昕（上海科技大学）、徐凯（国防科技大学）等。这些合作者多为图形学领域活跃的青年学者，形成了面向特定研究方向（如手-物交互、灵巧抓取、人机共生）的项目制合作网络。

**第四圈层（工业界与跨界）：**
- **IPS (Intelligent Project Solutions Inc.)**：李曼祎的业界经历使其成为图形学领域中少数具备"学术顶会发表+工业AI落地"双重背景的青年学者。
- **乐聚机器人**：通过具身智能交互项目建立企业合作，为学术研究提供机器人硬件验证平台。
- **加拿大NRC-IRAP / Mitacs Acceleration**：参与加拿大政府产学合作项目，积累了国际科技项目经验。

**总体特征：**

李曼祎的学术网络呈现出"双导师驱动、双平台支撑"的鲜明特征——博士导师屠长河提供了山东大学IRC的国内学术根基，博士后导师Hao Zhang提供了SFU GrUVi的国际学术视野。两个平台均为计算机图形学领域的重要研究基地，使她的合作网络自然辐射国内外学术界与工业界。回国后，她以软件学院人机交互与虚拟现实研究中心为依托，在保持与屠长河密切合作的同时，积极拓展跨机构合作网络（深圳大学、沈阳工业大学、上海科技大学等），并通过乐聚机器人等企业合作项目将学术研究向具身智能应用延伸。其2024年CCF科技成果自然科学一等奖（与国防科技大学徐凯团队、SFU张皓共同获得）标志着其学术成果已获得国家级认可，未来学术影响力有望进一步提升。
