## 二、教育背景与职业履历

荆一楠于2007年毕业于复旦大学计算机系，获理学博士学位；这是其个人主页能够直接确认的教育信息。公开网页未披露其本科院校、入学与毕业阶段、博士学位论文题名及博士导师姓名，因此不能据其与复旦数据库前辈的共事或论文署名，推定其为施伯乐、汪卫、孙未未等任何一位教授的直接学生。其2005—2006年的论文曾与张根度、王雪平、肖晓春等复旦作者合作，2008—2015年又与孙未未等合作；这些均是可观察的论文合作线索，不能替代正式师承记录。

其职业生涯的可确证节点包括：2007年获博士学位后留在复旦任教（具体入职职级与年份区间公开资料未完整披露）；2012年至2013年赴美国南加州大学（USC）InfoLab访问与合作研究；此后持续在复旦计算机学科任职。DASLab现行主页已标为“教授、博士生导师”，办公地点为江湾校区交叉学科2号楼A3029。由于数据科学家名录中的“副教授、专业硕士导师”属较早或未同步更新的资料，本报告以个人主页的现行身份为主，并保留用户指定标题中的历史职称表述。

代表性成果可按阶段理解。时空数据方向中，他与Ling Hu、Wei-Shinn Ku、Cyrus Shahabi合作的《Authentication of k Nearest Neighbor Query on Road Networks》发表于IEEE TKDE（2013），讨论道路网络k近邻查询认证；《Circle of Friend Query in Geo-Social Networks》（2012）和《Voronoi-based aggregate nearest neighbor query processing in road networks》（2010）分别体现地理社交和路网聚合近邻查询。系统与数据分析方向中，POLYTOPE（WWW 2019）面向探索式查询提出灵活采样系统；近期《A Dual-Layer End-to-End Cost Estimation Model for LSM-Tree-Based Database Systems》（IEEE TKDE，2025）、PURPLE和MetaSQL（2024）则转入数据库成本估计与LLM辅助SQL生成。个人主页统计其已在SIGMOD、VLDB、ICDE、WWW、SIGIR、AAAI、SIGSPATIAL、TKDE等发表论文50余篇，并获授权发明专利10项。

## 四、学术合作网络

### 4.1 学术谱系与师承关系

荆一楠是复旦本校获得计算机博士学位并长期任教的数据库学者，其“机构谱系”可明确放入复旦长期建设的数据库与数据管理共同体：该方向2013年依托复旦计算机学科建立上海市数据科学重点实验室，王晓阳、何震瀛、张凯等与其同属DASLab合作环境；汪卫、孙未未等也是复旦数据科学家名录中的相关教授。然而，这一共同体归属不等于直接师承。当前一手资料未披露荆一楠博士导师，故“施伯乐/汪卫/孙未未—荆一楠”的师徒链均应标为待核实，不能绘制为已证实的谱系边。

其可直接确认的外部学术连接，是2012—2013年在USC InfoLab的访问合作。随后TKDE道路网络查询认证论文与Cyrus Shahabi、Wei-Shinn Ku、Ling Hu联署，构成时空数据管理方向的国际合作节点。此处应区分：访问合作和共同论文可以确认学术联系，但个人主页没有说明Shahabi或Ku为博士/博士后导师，因此不能将其称作导师关系。

### 4.2 核心学术合作网络

以论文共同署名为依据，荆一楠近期最密集的内部合作圈是DASLab的何震瀛（Zhenying He）、王晓阳（X. Sean Wang）、张凯（Kai Zhang）。这些作者共同覆盖AI4DB、索引与查询优化、向量/跨模态检索、流图查询和数据分析等方向；其关系应界定为同事和稳定论文合作者，而非师生关系。早期合作网络则包括孙未未、张根度、王雪平、肖晓春等复旦作者，研究主题可见网络追踪、移动自组网、检索性能与道路网络查询等演进路径。

在议题层面，合作网络有三个活跃簇。第一簇是数据库内核与分析系统：与何震瀛、张凯、王晓阳及学生作者合作LSM-tree成本估计、在线索引调优、近似查询与探索式洞察发现。第二簇是AI4DB/NL2SQL：任彤辉、范元凯等作者与上述资深合作者共同推进PURPLE、MetaSQL及约束驱动的NL2SQL研究。第三簇是时空与检索：从Shahabi、Ku等国际作者参与的路网认证，到近期向量检索、视频检索与图查询，显示其方法能力从空间查询延伸到新型数据模态。共同署名反映的是研究合作强度，不代表作者之间均存在直接培养关系。

## 七、Connection圈层总结

荆一楠的学术关系网络可概括为四层。核心层是复旦DASLab内部的数据库与数据管理协作网络：他与何震瀛、王晓阳、张凯等在论文和实验室活动中反复共现，研究由传统数据库扩展至AI4DB、数据分析与金融数据场景。第二层是青年作者与公共培养网络，任彤辉、范元凯、叶飞、张航等人的出现显示了稳定的人才梯队，但除非有导师名单或本人声明，均应称为实验室成员/论文合作者，而不宜直接标注为荆一楠学生。第三层是国际学术合作层，以USC InfoLab访问经历及与Cyrus Shahabi、Wei-Shinn Ku等在时空查询研究中的共同论文为代表。第四层是应用与产业延伸层，由国家重点研发、战略咨询、金融科技研究议题和腾讯赛事等连接构成；其特点是技术场景明确，但个人校企项目的公开颗粒度较低。

从谱系角度，最可靠的表述是“复旦本土培养、嵌入复旦数据库与数据科学共同体的学者”，而不是把同事关系或早期共同论文加工成师徒链。有关博士导师、施伯乐—汪卫—孙未未等前辈与其间的直接师承、逐名学生的导师归属，以及具体企业合作项目，目前均没有充足公开一手证据，应保留为待核实事项。这样的边界不削弱其网络价值，反而能够清楚显示：荆一楠的可证实影响力主要来自持续的高水平论文协作、复旦数据管理平台、USC访问合作和数据库智能化/金融科技的交叉布局。
