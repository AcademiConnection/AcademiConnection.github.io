孙未未是复旦大学数据库团队本土培养的第三代骨干学者，从本科（少年班）到博士均就读于复旦计算机学科，师承施伯乐先生开创的复旦数据库学派。其研究脉络清晰呈现出从"移动数据管理"到"时空大数据"再到"AI与数据科学"的三段演进：早期深耕无线数据广播调度与XML数据广播索引，中期围绕移动对象数据库、路网空间查询和轨迹压缩形成了系统性的学术积累（代表作PRESS发表于VLDB 2014），近十年则将时空数据管理与深度学习结合，在轨迹恢复、出行时间估计、交通信号控制等智能交通方向持续产出，并扩展至跨模态检索、不规则时间序列建模（NeurIPS 2023）等领域。除科研外，他亦是国内程序设计竞赛教育界的重要人物，长期担任复旦ACM队总教练并执掌CCPC组委会，在教学与竞赛育人两条线上均具有全国性影响力。据其个人主页，他主持国家863课题、国家自然科学基金等科研项目与企业合作项目20余项，曾获上海市科技进步奖特等奖、华为价值合作成果奖，并曾担任圆通速递院士专家工作站首席专家。

## 二、教育背景与职业履历

孙未未的求学经历完整地发生在复旦大学。1988年，他考入复旦大学少年班；1992年获计算机科学与技术学士学位；1995年开始攻读硕士，据百度百科词条记载"1995年开始师从施伯乐教授"，1998年获计算机软件与理论专业硕士学位；随后继续攻读博士，2002年获同专业博士学位。需要说明的是，其博士学位论文导师的正式署名在学位论文库等权威渠道中未见公开披露，但从其博士期间（2001至2006年）的多篇论文均与施伯乐（Bole Shi）联合署名（如2001年MSWiM会议的自适应按需广播调度算法、2003年Wireless Networks期刊的按需广播成本高效调度算法等），且2004年与施伯乐、杨卫东共同翻译出版《现代数据库管理》（机械工业出版社"计算机科学丛书"）来看，其在学术谱系上明确属于施伯乐开创的复旦数据库学派，硕士阶段的直接师承关系有明确记载，博士阶段可视为同一谱系的延续（此点在引用时应予以区分）。2004至2005年，他作为访问学者赴德国康斯坦茨大学交流一年，这是其履历中唯一一段较长的海外经历。

毕业后他留校任教至今，历经讲师、副教授、教授的完整晋升轨迹（各职称晋升的具体年份未见公开披露），先后任职于复旦大学计算机科学技术学院及其整合更名后的计算与智能创新学院。2004年前后公开出版物作者简介中尚称其为"副教授"，目前已为教授、博导。职业身份的另一条主线是竞赛教育：他长期担任复旦大学程序设计竞赛队（ACM队）教练、总教练，带队多次晋级ICPC全球总决赛，并出任CCPC中国大学生程序设计竞赛组委会主席（百度百科及2025年公开报道中另有"组委会副主席"表述，以教师主页最新表述为准），2024年12月仍以总教练身份出席复旦大学程序设计竞赛颁奖典礼。教学方面，其主讲课程《数据结构》入选复旦大学首批本科优质课程，同时为本科荣誉课程和上海市本科重点课程，参与编写的《数据结构教程》被评为普通高等教育"十一五"国家级规划精品教材。

## 四、学术合作网络

### 4.1 学术谱系与师承关系

孙未未的学术谱系须置于复旦数据库学科的整体脉络中理解。复旦大学数据库研究由施伯乐先生开创——施伯乐1957年毕业于北京大学数学系计算数学专业，长期执教复旦，1985年晋升正教授，曾任计算机科学系系主任、复旦大学首席教授，其数据库项目在1987至2003年间八次获上海市科技进步奖，其中"上海图书馆新馆计算机管理系统"（1998年）与"新型数据库技术及其应用"（2003年）分获上海市科技进步一等奖，培养了包括王轶彤（1999年博士，师从施伯乐）在内的一大批数据库人才。2013年，该方向建立了上海市数据科学重点实验室——国内第一个省部级数据科学重点实验室，孙未未现列入该实验室"数据科学家"名单。在这一谱系中，孙未未属于施伯乐直接指导（硕士阶段有明确记载）的第三代学人，与汪卫（教授、教育部新世纪优秀人才，曾任计算机学院副院长）、朱扬勇（数据科学方向带头人）等构成复旦数据库团队的中坚层；荆一楠、何震瀛等教授（均为同事型合作者，师承归属另见各自报告）延续了团队的代际梯队。值得强调的是，孙未未与施伯乐的关系不止于师生：二人除联合发表论文外，还共同翻译了《现代数据库管理》教材，学术继承关系较为紧密。

### 4.2 核心学术合作网络

从DBLP全部86条发表记录的署名格局看，孙未未的合作网络可分为四圈。第一圈是长期学术搭档郑白桦（Baihua Zheng）：二人自2009年起合作发表论文约35篇（据OpenAlex统计），覆盖路网聚合查询、轨迹压缩（PRESS、COMPRESS）、地图更新（COBWEB、GLUE）、轨迹恢复（RNTrajRec、PILOT-C）等几乎全部主线方向，郑白桦为复旦大学博士、长期任教于新加坡管理大学，近年据公开资料已转任香港科技大学（广州）数据科学与分析学域（职级细节以校方页面为准），这一"复旦—新加坡—广州"的连线是孙未未学术网络中最稳定的国际通道。第二圈是海外高校合作者：新南威尔士大学的Wei Wang（2006年尚在复旦时即与其合作，2013至2017年间持续联署，系复旦数据库谱系的海外延伸）、北德克萨斯大学Yan Huang（路网空间查询方向多项合作）。第三圈是产业研究机构，尤其是微软亚洲研究院系：城市计算创始人郑宇（Yu Zheng）与其合作的PRESS是轨迹压缩领域的标志性工作（VLDB 2014），马维英、Eric Chang、Yuning Jiang等参与其视觉语义嵌入（UniVSE，CVPR 2019）与地图提取（DeepDualMapper，AAAI 2020）工作，上海交通大学任侃及微软亚洲研究院研究员参与ContiFormer（NeurIPS 2023）。第四圈是院内同事：与肖仰华（知识工场实验室）同列上海市数据科学重点实验室"数据科学家"名单、与汪卫、王晓阳、何震瀛、荆一楠等同属数据库与数据管理团队，与阚海斌同为学院"101"计划相关教师，但从公开论文署名看，他与肖仰华、阚海斌之间未见直接合著记录，属于同事与学科协作关系而非科研合作关系。此外，他作为ACM SIGSPATIAL China执委参与该分会"新星奖"评审（2024年度评委还包括吴华意、高云君、丛高等），嵌入国内空间数据学术共同体的服务网络。

## 五、业界合作关系深度分析

孙未未的业界合作与其研究方向转型高度同构，可分为四条主线。第一条是ICT头部企业的系统研发合作：其教师主页明确表述"和行业领导企业合作，解决企业关键技术的性能突破或研发关键子系统并上线运营"，并曾获华为价值合作成果奖，结合其数据库与大数据系统背景，此类合作应聚焦数据系统性能优化方向（具体项目内容未见公开披露）；微软亚洲研究院则是其论文层面的长期产业伙伴（郑宇、马维英等，见第四章）。第二条是物流行业：他曾担任圆通速递院士专家工作站首席专家、智慧物流国家工程实验室特聘专家，将其在轨迹数据管理、智能交通调度方面的积累延伸至快递物流场景，这也是其"智能交通与物流"研究方向的产业落点。第三条是大健康领域：现担任海阳大健康专家工作站首席专家（海阳位于山东），显示其近年向医疗健康数据应用方向的拓展。第四条是以竞赛为纽带的校企合作：在复旦大学程序设计竞赛颁奖典礼上，华为、腾讯的校园招聘经理与其共同为获奖学生颁奖，ACM/CCPC竞赛体系使其与头部企业的招聘与技术品牌部门保持常态化连接。需要说明的是，网络流传其与阿里巴巴等企业存在数据库方向深度合作的说法，本报告未检索到可确证的公开依据；此外，有资料提及名为"Gongfu"的系统与其相关，在DBLP论文库及公开检索中亦未见对应记录，均待核实。总体而言，其产业合作呈现"企业横向项目+专家工作站+竞赛生态"的多元结构，横跨ICT、物流、健康三个行业。

## 七、Connection圈层总结

综合来看，孙未未的学术关系网络呈现"双内核、四圈层"的结构。第一个内核是复旦数据库谱系：作为施伯乐一脉的本土传人，他向上承接施伯乐、汪卫、朱扬勇等构成的学科传统，向下与荆一楠、何震瀛等同事教授共同支撑院内数据库梯队的代际延续，并依托上海市数据科学重点实验室与肖仰华等"数据科学家"形成院内协作网络；这一内核赋予其学科正统性与稳定的院内资源。第二个内核是"孙未未—郑白桦"学术搭档：跨越十五年以上、约35篇联署论文的合作贯穿其轨迹数据管理研究的全部主线，并通过郑白桦连接起新加坡与香港的学术圈层。向外第一圈是学生网络，早期（2001至2014年）以无线广播、空间查询方向为主，中期（2014至2020年）以轨迹与智能交通为主，近期（2020年后）向大模型与AI算法方向迁移，呈现清晰的研究主题接力；第二圈是国际学术合作者（Wei Wang、Yan Huang等）与微软亚洲研究院系产业研究伙伴（郑宇、马维英、任侃等）；第三圈是以CCPC、ICPC为载体的竞赛教育共同体，这一维度使他的影响力显著溢出学术圈层，进入全国高校计算机教育与头部企业招聘生态；第四圈是物流（圆通、智慧物流国家工程实验室）、大健康（海阳工作站）与ICT（华为）的产业合作网络。其网络的独特价值在于"学术谱系+竞赛育人+产业落地"三线并进：对希望建立连接的学者而言，时空数据管理与智能交通是其最活跃的学术接口；对产业观察者而言，其"关键子系统上线运营"式的横向合作模式与专家工作站布局显示了明确的工程转化导向。本报告中未确证事项（博士学位论文导师正式署名、上海市科技进步奖特等奖的具体项目、华为合作细节、部分学生中文名与去向、Gongfu系统等）均已如实标注，供后续进一步查证。
