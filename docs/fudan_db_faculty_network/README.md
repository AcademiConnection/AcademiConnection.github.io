# 复旦大学数据库与数据管理团队学术关系网络报告

## 团队简介

复旦大学数据库研究源远流长，学科传统可追溯至施伯乐先生（1936年生，中国数据库学科的奠基人之一、复旦大学计算机学科开拓者）自二十世纪七十年代起开创的数据库教学与研究体系。依托计算机科学与技术一级学科"大数据与数据科学"方向，当前团队形成"三大载体、两代学人"的格局：其一为 DASLab（数据分析与安全实验室，daslab.fudan.edu.cn），由王晓阳教授（CCF会士、CAAI会士、前计算机学院院长）主持；其二为上海市数据科学重点实验室（国内首个省部级数据科学重点实验室，2013年筹建、2015年成立），由朱扬勇教授任主任；其三为以孙未未教授为代表的移动与时空数据管理研究线。团队研究覆盖数据库系统（NL2SQL、查询处理与优化、LSM-tree、向量数据库）、时空数据管理（轨迹压缩、路网查询）、数据科学与数据要素（数据学、数据财政、数据自治）等方向，在 SIGMOD、VLDB、ICDE、NeurIPS 等会议持续产出。

本报告聚焦五位代表性教师：王晓阳（复旦本科、USC博士，海外任教二十年（含佛蒙特大学冠名讲席教授、美国NSF项目主管）后2011年回复旦任院长，接续施伯乐传统）；朱扬勇（复旦博士、施伯乐学科谱系，"数据学Dataology""数据财政""大数据试验场"概念提出者，2023年荣休后仍活跃于数据要素领域）；孙未未（复旦本硕博自主培养，施伯乐一系，移动与时空数据管理带头人）；何震瀛（哈工大博士，DASLab 教授，数据库系统与AI4DB）；荆一楠（复旦博士，DASLab 教授，金融科技与时空数据管理）。

## 研究方向与圈层结构

团队学术网络呈五层结构。第一圈层是施伯乐谱系核心：王晓阳（本科与硕士阶段师从施伯乐）、朱扬勇（博士联合署名高度关联施伯乐）、孙未未（硕士师从施伯乐、博士期间多篇论文与施伯乐联合署名）构成复旦数据库"自主培养+海外回流"的两代学人；施伯乐门下同门还包括史一兵（万达信息创始人）、周礼栋（微软亚洲研究院院长）、陈齐彦（DaoCloud CEO）、姚毓林等，形成横跨学界业界的"伯乐门"网络（2025年同门发起"伯乐基金"捐赠）。第二圈层是 DASLab 内部网络：王晓阳—何震瀛（哈工大博士，哈工大时期论文均与李建中团队联合署名）—荆一楠—张凯（华东师大）形成固定合作群，2024年以荆一楠为第一完成人、王晓阳为主要完成人联合星环科技获吴文俊人工智能技术发明奖。第三圈层是师承与外部网络：孙未未与新加坡管理大学郑白桦（复旦博士）长期合作（联署约35篇），并接入微软亚洲研究院郑宇/马维英城市计算网络（VLDB 2014轨迹压缩PRESS）；王晓阳的 USC 背景连接 Seymour Ginsburg 理论谱系与 USC InfoLab（荆一楠曾访问）。第四圈层是产业网络：复旦—星环科技校企联合研究中心（王晓阳任主任）、银联商务（何震瀛）、圆通速递院士专家工作站与智慧物流国家工程实验室（孙未未）、上海数据交易所与上海数据集团（朱扬勇，数据要素市场化政策咨询）。第五圈层是学生网络：DASLab 与数据库方向毕业生广泛流向 OceanBase、字节、美团、拼多多、TikTok 等产业界，以及学术界多地。

## 产业转化亮点

团队产业转化呈"数据库产品+数据要素制度"双线：数据库技术层面，与星环科技的校企联合研究中心直接对接国产数据库产业，NL2SQL、向量检索等成果（GAR/GenSQL/Purple 系列、LiveBin）覆盖金融科技场景（银联商务、浦发银行"智荟杯"NL2SQL 竞赛全国第二）；数据要素制度层面，朱扬勇作为上海数据研究院学术副院长与上海数据交易所的核心学界顾问，其"数据财政""数据自治""数据盒"等概念直接参与上海乃至国家数据要素市场化配置的政策话语建构，是学术界影响数据基础制度的独特样本。
