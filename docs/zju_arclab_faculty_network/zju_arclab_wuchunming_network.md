## 二、教育背景与职业履历

吴春明是一位"纯浙大"履历的本土学者：1985年至1989年就读于浙江大学计算机系获工学学士学位，1989年至1992年在该校人工智能专业获工学硕士学位，1992年至1995年获计算机应用专业工学博士学位（其博士导师公开渠道未检索到明确记载，待核实），1995年博士毕业后留校任教。1995年至2004年，他在浙江大学计算机系人工智能研究所工作，历任讲师、副教授（1997年晋升），这一阶段他的研究带有明显的人工智能底色；2005年晋升教授、博士生导师，继续在人工智能研究所任职至2009年；2010年起转入计算机系统结构与网络安全研究所，任教授、博士生导师、副所长至今。从人工智能研究所转向网络与安全研究所的这段履历，也解释了他此后的研究主线——将智能优化与决策方法融入网络体系结构，即今日所称的"网络智能"。

他同时是国家级科技咨询体系中的活跃人物：曾担任国家"十二五"863计划信息领域网络与通信技术主题专家组专家，现任国家"十三五"重点研发计划"网络空间安全"重点专项科技规划组成员、编制组专家，国家"网络空间安全"专项专家分委会委员，以及国家2030科技专项"国家网络空间安全"重大项目实施方案编制组专家。需要澄清的是，关于其"曾任浙江大学软件学院相关领导职务"的说法，在浙大个人主页、百度百科、中兴通讯《中兴通讯技术》编委页及浙大官方团队页面等公开信源中均无任何记载，其行政履历清晰显示始终在计算机学院（人工智能研究所→系统结构与网络安全研究所）体系内，该说法（待核实）。其领导的INST实验室（创新网络与安全技术实验室，主任职务待核实）是其当前主要的科研组织载体。

## 三、学生培养情况

### 1. 潘高宁（杭州电子科技大学网络空间安全学院特聘教授、博士生导师，直接指导博士）

潘高宁2018年9月至2023年9月在浙江大学攻读网络空间安全专业博士学位，其杭电个人主页明确记载"导师：纪守领教授，吴春明教授"，即由吴春明与NESA实验室的纪守领联合指导，是跨课题组联合培养的直接例证。其代表作V-SHUTTLE（可扩展且语义感知的虚拟机虚拟设备模糊测试系统）获ACM CCS 2021最佳论文奖——这是CCS创办28年来中国团队以第一作者身份第二次获此殊荣，并获"黑客奥斯卡"Pwnie Awards最具创新研究奖提名；相关工具在蚂蚁集团业务系统中实际部署。2023年毕业后他加盟杭州电子科技大学，任特聘教授、博导，获2024年度ACM SIGSAC中国"优博提名奖"，现为CCS、S&P等顶会PC Member。

### 2. 张栋（福州大学计算机与大数据学院教授、至诚学院副院长，论文合作/疑似博士师承）

张栋本、硕、博均就读于浙江大学，2010年获计算机科学与技术博士学位，现为福州大学教授、至诚学院副院长，研究方向为网内智能、可编程网络安全与SDN。其福州大学主页所列的IEEE/ACM IWQoS 2021最佳论文奖、IEEE INFOCOM 2021最佳论文候选奖等指导学生获奖记录，与吴春明个人主页所载"基于可编程交换机的高性能网络功能虚拟化部署框架获IWQoS 2021最佳论文奖""面向可编程网络的低开销网络测量获INFOCOM 2021最佳论文候选奖"完全对应，二者为IWQoS 2021最佳论文LightNF的共同署名作者。综合判断张栋博士阶段极可能师从吴春明，但正式师承关系的公开记录尚待核实。

### 3. 黄群（北京大学计算机学院研究员，长期论文合作者）

黄群是吴春明在可编程网络方向最重要的校外合作者之一，现为北京大学计算机学院研究员（曾任CCF ADL《算网融合》讲习班学术主任）。二人合作的高性能网络功能虚拟化部署框架LightNF获IEEE/ACM IWQoS 2021最佳论文奖。其早年教育经历与师承关系公开渠道未检索到明确记载（待核实）。

### 4. 陈翔（Xiang Chen，LightNF论文第一作者，论文合作）

陈翔为LightNF: Simplifying Network Function Offloading in Programmable Networks（IWQoS 2021最佳论文）的第一作者，合作团队横跨浙江大学与北京大学。其现职与培养归属公开渠道未检索到可靠信息（待核实）。

### 5. 林性伟（蚂蚁集团安全光年实验室研究员，论文合作/校企联合培养）

## 四、学术合作网络

### 4.1 实验室内部合作（ARClab：陈文智等）

吴春明与ARClab的连接分三个层次。建制层面，他自2010年起担任系统结构与网络安全研究所副所长，而ARClab正是依托该研究所于1990年创立的实验室，所长层的行政管理直接覆盖ARClab的建制运转。论文层面，其与ARClab/NESA实验室负责人纪守领的合作最为突出：OpenAlex数据显示2017年至2024年二人合作论文约25篇，纪守领学术版图中吴春明是仅次于NESA内部核心成员的最重要校内合作者之一；二人联合指导的博士生潘高宁以V-SHUTTLE获CCS 2021最佳论文奖，Scavenger、Autospear两项成果分别入选2021、2022年BlackHat-Asia大会，将ARClab的安全研究与网络测量、可编程网络能力深度结合。与陈文智本人的直接共同署名论文公开渠道未检索到（待核实），但二人同为研究所核心管理者，属同建制的紧密同事圈层。

### 4.2 跨机构合作

校外方面，他与北京大学黄群团队在可编程网络功能卸载方向形成持续合作（LightNF）；与清华大学出身的网络测量学者孟子立（Zili Meng，现为香港科技大学助理教授）合作发表LightNF；与福州大学张栋保持长期合作，张栋团队在SIGCOMM、INFOCOM、ICNP、IWQoS等顶会持续产出。校内方面，除纪守领团队外，其早年的人工智能研究所背景（1995—2009年）使其与浙大人工智能方向学者保持历史性联系。产业界，其团队与蚂蚁集团安全光年实验室的联合研究产出顶会最佳论文并在生产环境部署。

### 4.3 国际合作

吴春明的国际合作以安全与网络方向的顶级国际会议及工业界顶级舞台为主：其团队成果Scavenger、Autospear分别入选2021年、2022年BlackHat-Asia（世界黑帽大会亚洲站），学生潘高宁的V-SHUTTLE获Pwnie Awards（"黑客奥斯卡"）提名；其研发的XFlow系统曾入围全球开放网络峰会（Open Networking Summit）展示。云漏洞研究成果获得Redhat、Oracle等国际厂商的CVE致谢二十余件。与海外高校建立的长周期联合研究关系公开渠道未检索到明确记载（待核实）。

## 五、业界合作关系深度分析

### 5.1 产业合作

吴春明是浙大网络方向教师中产业组织角色最为显性的一位。其一，他担任浙江大学—中兴通讯联合创新中心执行主任，与中兴通讯保持长期的电信设备级产学研合作，《中兴通讯技术》期刊亦聘其为编委。其二，他担任拟态防御产业联盟理事会副主任，深度参与邬江兴院士所倡导的动态异构冗余（拟态防御/内生安全）产业生态，其"动态网络结构化主动防御"研究正与该产业方向同源。其三，其团队与蚂蚁集团在云安全方向形成"论文—漏洞—部署"闭环：V-SHUTTLE等工具发现QEMU、KVM、VirtualBox等虚拟化平台零日漏洞上百个，并在蚂蚁业务系统中实际部署。他主持和参与国家973、863、国家科技基础条件平台建设、国家重点研发计划等二十余项课题，承担多项面向运营商与网络安全产业的攻关任务。

### 5.2 创业孵化与开源生态

公开渠道未检索到吴春明直接参与创业孵化或担任创业公司导师的记录（待核实）。其成果转化路径偏向"安全能力输出"型：通过CVE致谢、工业界顶级会议（BlackHat、CanSecWest、HITB）报告与产业联盟标准协作实现落地，而非孵化企业或主导开源社区。其学生与合作伙伴中，孟子立获字节跳动奖学金、潘高宁与蚂蚁集团的深度绑定等，构成了间接的产业人才网络。

## 七、Connection圈层总结

吴春明的学术关系网络呈现清晰的"同心圆"结构。最内圈是研究所建制：作为系统结构与网络安全研究所副所长，他与ARClab主任陈文智共同处于研究所的管理核心，ARClab在其建制辐射范围之内。第二圈是安全研究共同体：与纪守领团队约25篇的合作论文（2017—2024）和联合指导的潘高宁，使他实质上成为NESA实验室之外与ARClab安全方向耦合最深的校内学者；CCS、IWQoS、INFOCOM三项2021年度顶会奖项均诞生于这一交叉带。第三圈是全国网络学术与治理网络：863主题专家组、重点研发专项编制组、《电子学报》编委等身份使其嵌入国家网络空间安全的科技决策咨询体系。最外圈是产业生态：中兴通讯联合创新中心、拟态防御产业联盟、蚂蚁集团云安全合作构成"电信设备—内生安全—互联网云安全"三条产业支线。

总体而言，吴春明是ARClab周边教师中学术与行政势能最强的一位：他既是浙大网络方向从SDN走向可编程网络与网络智能的技术掌舵人，又以研究所副所长身份为ARClab提供建制支撑，还通过纪守领联合培养渠道直接参与ARClab学术生态的产出。他的网络特征可概括为"建制内中枢+跨实验室桥接+国家咨询+产业联盟"四重角色的叠加，是理解浙大系统与网络安全学科板块时不可绕开的连接点。
