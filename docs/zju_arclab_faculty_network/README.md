# 浙江大学计算机系统结构实验室（ARClab）教师学术关系网络报告 · 总览索引

**报告生成时间：** 2026年8月3日

**覆盖范围：** 浙江大学计算机系统结构实验室（Computer Architecture Laboratory, ARClab，arc.zju.edu.cn）全部8位核心专任教师，以及2026年8月25日第二批补录的2位周边教师（姜晓红、吴春明，同属ARClab依托的系统结构与网络安全研究所，但不在官网8人名单内）。实验室创立于1990年，依托浙江大学计算机科学与技术学院系统结构与网络安全研究所，现任实验室主任为陈文智求是特聘教授。

**关于覆盖边界的说明：** ARClab官方团队页面除本报告覆盖的8位核心教师外，还列出了武汉科技大学教授胡威、杭州电子科技大学副教授程雨夏两位外校教师，以及杨晔、王吾冰两位博士后。前两位系ARClab培养后赴外校任教的校友，虽仍保持合作关系但主聘单位已不在浙大；后两位为博士后而非专任教师。参照此前各实验室报告的一致口径（只覆盖"老师"即专任教职人员），这四位未纳入本次调研范围。

**数据方法：** 以ARClab官网教师名录及各教师个人主页为核心数据源，交叉DBLP、OpenAlex、Google Scholar等学术数据库核实论文合作网络与引用数据，并结合浙江大学官方新闻、实验室论文录用公告、校企合作签约报道、竞赛获奖公告等确认师生传承关系、职务变迁与学生毕业去向。每人一份独立报告，重点覆盖学生培养与去向追溯、学术合作网络、业界合作关系深度分析三大板块。首批8份报告已完成交叉验证；2026年8月25日补录的2份周边教师报告同样经过独立事实核验与交叉检查。

## 二、八位教师的角色定位

陈文智教授是ARClab无可争议的掌门人与核心枢纽。他是浙江大学求是特聘教授、计算机和教育技术双博士生导师、浙江大学信息学部副主任，曾任计算机学院副院长和信息技术中心主任。其研究横跨计算机体系结构与系统软件、智能计算、网络空间安全、智能教育四大板块，2007年至2025年间四次以第一完成人身份获得浙江省科技进步一等奖，两次以第一完成人身份获得国家级教学成果二等奖，2024年获评国家级教学名师。他同时兼任浙江大学与苹果公司、阿里巴巴、蚂蚁金服、安恒信息四家企业共建的联合研究中心负责人，是ARClab全部产学研网络的汇聚点。DBLP合作数据显示，实验室内几乎所有教师的论文都以他为共同署名节点，这种中心度在国内高校实验室中相当罕见。

张紫徽是ARClab中一位路径极为特殊的教师。他并非传统的博士—博士后—讲师晋升路径出身，而是一位具有深厚产业背景的技术高管：先后担任过淘宝网IT负责人、阿里巴巴集团IT负责人、阿里云飞天事业部云邮箱总监，并作为创校成员参与创办马云发起的杭州云谷学校并担任技术负责人，2018年4月加盟浙江大学信息技术中心任总工程师。他设计了浙大"云计算+数据中台+浙大钉"的智慧校园技术框架，主导推动阿里云飞天系统在浙大校园落地（使浙大成为全球第一家阿里云落地的高校）。他与陈文智在信息技术中心、智云实验室、ARClab三个组织中同时构成正副搭配，这种"三重同构"的搭档结构在国内高校中相当少见。

王总辉是ARClab的另一位副主任，也是实验室的技术多面手。他身兼浙江大学系统结构与脑机工程研究所副所长、杭州国家具身智能应用中试基地前沿应用与测评实验室主任、浙江大学网信人工智能创新团队执行主任等多个职务，研究方向覆盖具身智能、人工智能安全、零知识证明、计算机体系结构、大模型训练推理加速等。他与陈文智的DBLP共同署名达52篇，是实验室内合作最紧密的一对。他指导的博士生林溢泉连续多年在HPCA、MICRO等体系结构顶会发表论文，支撑起ARClab在体系结构方向的持续产出。

魏成坤是ARClab新生代中最活跃的学术骨干。他2021年获浙江大学计算机博士学位（导师陈文智），经三年博士后后转为研究员、博士生导师，研究方向覆盖计算机系统结构、云计算、高性能网络、数据安全与异构算力融合。他曾获NDSS 2024杰出论文奖（安全领域四大顶会之一），并作为核心成员参与获得2023年度浙江省科技进步一等奖。他与阿里云在SIGCOMM上形成了"三代传承"的合作链条——从自己一作的Achelous，到通讯作者的Triton，再到指导学生蒋骁翀完成的Spillway（SIGCOMM 2026），后者已在阿里云3000余台服务器的生产环境部署。

纪守领是ARClab中学术体量最大的一位。他本硕就读于黑龙江大学，此后赴美取得佐治亚州立大学计算机科学与佐治亚理工学院电子与计算机工程双博士学位，主要导师为佐治亚理工的Raheem Beyah教授。他现为浙江大学求是特聘教授、教育部长江学者、国家青年特聘专家，NESA实验室（网络系统与安全实验室）负责人，OpenAlex收录论文469篇、被引8159次、h指数47，曾获IEEE S&P 2025杰出论文奖、ACM CCS 2021最佳论文奖，累计十项最佳论文奖，并入选爱思唯尔中国高被引学者。其NESA实验室约35人规模，采取纪守领、陈建海、张旭鸿三PI结构，毕业生去向覆盖普林斯顿、UIUC、CMU、伯克利、ETH、佐治亚理工、普渡等海外顶尖院校博士项目，以及蚂蚁集团、阿里巴巴、百度、华为云等企业。

施青松是ARClab资历最深的教师，也是实验室历史的活见证。他1983年毕业于杭州大学物理系电子技术专业，80年代初曾在杭州广播电视技术研究所从事模拟电子产品研发，1986年进入杭州大学计算机系任教并曾任系统教研室与系统结构实验室副主任，1998年四校合并后并入浙江大学。1994年起他在石教英教授主持下参与浙大计算机体系结构方向的教学体系改革，与陈文智在《高级计算机系统结构》等课程中同为主讲教师。需要特别澄清的是，他与石教英、陈文智之间是同事与合作者关系，而非师生关系。他还曾任浙大—英特尔嵌入式技术中心副主任、英特尔—浙大多核技术实验室副主任。

陈建海是ARClab在竞赛与区块链两条线上的负责人。他本科毕业于湖南大学应用数学专业，硕博就读于浙江大学计算机科学与技术专业，现为副教授、博士生导师，同时担任智能计算与系统实验室（Incas-lab）区块链负责人、NESA实验室联合负责人、浙江大学超算队（ZJU SPC）负责人。他率领浙大超算队多次在ASC世界大学生超级计算机竞赛中获一等奖，并于2016年夺得世界最高Linpack计算性能冠军、打破世界纪录。其区块链项目Designer获2018全球迅雷区块链应用开发大赛第一名。他还是第44届世界技能大赛网站设计项目浙江省技术专家组组长、国家级裁判。

王则可是本次调研中公开信息最为有限的一位。ARClab官方页面仅有一行"浙江大学计算机科学与技术学院研究员"的介绍，发布于2020年5月。经多方检索后仍未能获得其完整的教育背景、博士导师、学生名单等信息，相关报告已如实标注了信息缺口，未作臆测填补。

## 三、全实验室关系网络的整体观察

ARClab的师资网络呈现出几个鲜明的结构性特征。

第一是"石门弟子"这一独特的学术传承共同体。ARClab的学术源流可上溯至石教英教授（1937—2025），他是浙江大学CAD&CG国家重点实验室创始主任、曾任浙大副教务长与科研处处长，据浙大讣告记载是国内"最早引入世界领先的计算机体系结构内容"的学者之一。石教英门下形成了图形学与体系结构两条支脉，陈文智是体系结构一脉的领军者。ARClab于2020年10月举办的"第一届雅客论坛"，正是以"石门弟子群英荟萃"为主题，联合部分石门弟子与企业合作伙伴共同发起，陈文智还在会上将其永平教学贡献奖奖金捐赠给石教英基金会。需要注意的是，"石门弟子"这一称谓在实践中带有一定的荣誉与产业导师色彩，并非严格等同于正式的博士指导关系——例如安恒信息董事长范渊虽被ARClab官方称为"范渊师兄"并出席雅客论坛，但其可考学位来自南京邮电大学与美国圣何塞州立大学，并无浙大学位记录，相关报告已就此作出明确标注。

第二是"双副主任"的异质互补架构。ARClab设有两位副主任，但二者的角色完全不同：张紫徽代表的是产业侧，其价值在于阿里系的深厚人脉与大规模IT工程能力，为实验室打通了浙大智慧校园这一巨型应用场景；王总辉代表的是学术与技术侧，在体系结构、AI安全、具身智能等方向持续产出顶会论文并指导博士生。这种"一产一学"的副手配置，使得ARClab在承接大型横向项目与保持学术产出之间获得了较好平衡，也是这个实验室区别于纯学术型实验室最显著的特点。

第三是异常密集且成体系的校企联合平台集群。陈文智一人即兼任浙江大学与苹果公司、阿里巴巴（智云联合研究中心/AZFT智能计算系统实验室）、蚂蚁金服（金融科技研究中心）、安恒信息（前沿技术联合研究中心）四家企业联合平台的负责人或联合主任，涵盖教育科技、云计算、金融科技、网络安全四个方向。智云实验室之下还进一步孵化出开拓、方寸、图灵、点石等多个校企子实验室，合作方包括锐捷、网新图灵、城云科技、金桥信息等，截至2023年3月已建成十个以上子实验室、近20家签约伙伴。魏成坤与阿里云在SIGCOMM上形成的三代论文传承、纪守领团队与蚂蚁集团在AI安全上的深度绑定（其论文作者单位中阿里系出现达66人次）、陈建海与早稻科技的智能风控联合实验室，共同构成了一张从基础研究延伸至生产系统的产学研网络。

第四是"教学成果"与"科研成果"并重的双轨评价格局，这在国内计算机类实验室中不算常见。陈文智两获国家级教学成果二等奖（均排名第一）、获评国家级教学名师与浙江省教学名师，牵头提出"系统能力培养"教学理念；施青松长期承担计算机硬件基础课程教学并主持教育部—英特尔精品课；王总辉重构英伟达深度学习课程并设计体系结构与嵌入式系统课程实验；陈建海则通过超算队与世界技能大赛在竞赛育人方向建立声誉。这种对教学的高度投入，与实验室"数智驱动的全链路一体化创新教学支撑平台"等成果直接相关，也解释了为何ARClab能同时在"学在浙大""智云课堂"这类教育信息化产品上持续投入。

第五是官网信息滞后与身份误判风险在本次调研中反复出现。ARClab官网对纪守领的介绍仅有一句话，严重低估了其求是特聘教授、长江学者的实际学术地位；陈建海的职称在两个页面上分别标注为副教授与讲师；实验室新闻中频繁出现的"张嘉恒老师"极易被误认为实验室内部教师，但经考证实为新加坡国立大学助理教授（UC Berkeley博士，师从Dawn Song，zkBridge创造者），与ARClab属跨机构国际合作关系而非内部师资。此外，施青松、王则可等教师在OpenAlex等聚合数据库中的学术画像均存在与同名学者混同的污染问题（施青松的档案中混入了聚氨酯化学、抗癌化合物、液氢、海上风电等完全无关领域的文献）。这些问题提示，涉及人物身份、职称、师承的信息务必通过多信源交叉印证，不可仅凭单一网页或聚合数据库记录下结论。
