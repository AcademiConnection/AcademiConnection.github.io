## 一、学者基本信息

## 二、教育背景与职业履历

王总辉的职业轨迹是一条极为纯粹的"浙大内生"路径。根据ARClab官方教师页面的记载，他于2007年从浙江大学计算机学院毕业，获得计算机科学与技术专业博士学位，并在毕业当年即留校任教。这意味着截至2026年，他已在浙江大学计算机学院连续工作近二十年，其整个学术生涯从未离开过浙大玉泉校区的曹光彪大楼这一物理坐标。关于其本科与硕士阶段的就读院校，公开渠道未见明确披露；考虑到其博士阶段在浙大完成并直接留校，且长期扎根于浙大计算机系统结构学科脉络，其本硕阶段亦在浙江大学完成的可能性较高（推测），但在缺乏权威信源佐证的情况下，本报告不对此作确定性断言。

关于其博士导师，公开资料同样没有直接标注。但有一条重要的间接线索值得关注：ARClab在2020年10月举办了"第一届雅客论坛"，该论坛由ARClab"联合部分石门弟子（石教英老师门下的弟子）、企业合作伙伴共同发起"，以"培养卓越创新、软硬结合的系统结构人才"为目标。石教英教授是浙江大学计算机图形学与系统结构领域的资深前辈学者（1937年生，1973年进入浙大无线电系，1978年转入计算机系），ARClab将自身学术谱系明确追溯至"石门"，说明该实验室的师承源头可上溯至石教英一脉。王总辉作为2007年毕业于浙大计算机学院并留校、长期在计算机系统结构与网络安全研究所工作的学者，其博士阶段导师很可能出自这一学术谱系（推测），但具体导师身份需以更权威的信源为准。

从研究方向的演进看，王总辉的职业履历可以清晰划分为两个阶段。第一阶段是2007年至2018年前后的"传统系统结构期"。ARClab 2018年版的教师简介显示，他当时的主要研究方向为"云计算、嵌入式系统和计算机体系结构等"，承担的项目以"核高基"和"新一代宽带无线移动通信网"等国家重大科技项目子项为主，已发表20多篇SCI和EI论文，职称为"高级工程师，硕导"。这一阶段他的角色更接近于一位深耕系统底层、支撑国家重大工程项目的工程型学者，学术产出以SCI/EI论文为主，尚未大规模进入国际顶会赛道。第二阶段是2019年前后至今的"AI融合爆发期"。个人主页最新版本显示，其研究方向已扩展至具身智能、零知识证明、大语言模型安全、RAG/智能体安全等一系列前沿交叉领域，论文数量从"20多篇"跃升至"60多篇"，发表平台也从SCI/EI升级为CVPR、USENIX Security、ICML、ICLR、HPCA、ASPLOS等顶级会议，职称序列也由"硕导"升格为"博士生导师"。这一转型的时间节点与ARClab整体从传统虚拟化/存储研究转向AI安全与AI系统研究的战略调整高度同步，也与他个人在2019年前后开始承担国家网信办"音视频XXXX系统"项目、2020年起承担科技部国家重点研发计划课题"网络多媒体XXXX技术研究"（课题负责人，百万级）等内容安全类项目的经历相吻合。

在教学方面，王总辉长期承担《深度学习基础——理论与实践》《数字逻辑设计》《计算机体系结构》《嵌入式系统》和《高级计算机体系结构》等课程的一线教学工作。其中值得关注的是，他作为英伟达（NVIDIA）校园大使重构了英伟达《深度学习基础——理论与实践入门》课程，设计了包含10个主题、8个实验和1个课程设计的体系，并采用DLI+Kaggle双实验平台；他还负责设计《计算机体系结构》课程实验，旨在培养学生高性能处理器的自主设计能力；《嵌入式系统》课程创新实验则引导学生在国产嵌入式GPU开发板上开发边缘AI应用；面向研究生的《高级计算机体系结构》包含多家国内知名GPU厂商的合作课程内容，并于2024年获评"浙江大学专业学位博士核心课程"、2025年获"浙江省专业学位研究生优秀教学案例"。这些教学工作的共同特征是深度绑定产业界的真实技术栈与硬件平台，构成了他产学融合定位的教育侧支撑。

## 三、学生培养情况

王总辉是ARClab学生培养体系中承担实际指导工作最密集的教师之一。通过系统梳理ARClab官网2023年至2026年的66条实验室新闻，可以还原出一份相当完整的、由"陈文智教授和王总辉老师"共同指导的学生名单及其研究方向谱系。

在体系结构与高性能计算方向，**林溢泉**是最具代表性的博士生。他以第一作者身份连续产出多项顶级成果：2024年8月论文"PARS: A Pattern-Aware Spatial Data Prefetcher Supporting Multiple Region Sizes"被CCF-A类期刊TCAD录用，分析了区域大小对数据预取器的影响并提出支持多种区域大小的预取方案；2025年11月论文"I-POP: Ignite Positive Prefetchers"被HPCA 2026录用，提出高性能低开销的多预取器协同管理方案；2026年7月论文"PRISM: A Miss-Attribution-Guided Temporal Prefetcher Beyond Metadata Management"被MICRO 2026录用，对时序预取器作用下仍存在的缓存缺失进行系统性归因分析。林溢泉一人支撑起ARClab在处理器预取器这一体系结构核心课题上的连续突破，其HPCA论文也使ARClab实现了HPCA 2023、2024、2025、2026连续四年录用的纪录。

**陆涛**是王总辉指导学生中已明确毕业的代表，其去向与研究脉络最为清晰。他在读博期间即以第一作者身份在ASPLOS 2024（2024年10月录用）发表"BatchZK: A Fully Pipelined GPU-Accelerated System for Batch Generation of Zero-Knowledge Proofs"，与硕士生陈于勋合作，提出完全流水线化的GPU加速批量零知识证明生成系统；2026年3月，由陆涛、王浩宇等完成的论文"Accelerating GPU Inference of Large Language Models with Moderately Unstructured Sparse Weight Matrices"被DAC 2026录用，解决中等稀疏度下LLM难以在GPU上获得实际加速的业界难题；2026年7月，USENIX Security '26录用的TensorZKP论文中，ARClab官网明确标注"第一作者陆涛为浙江大学计算机系统结构实验室毕业博士，主要研究方向为密码学工程与GPU高性能计算"。陆涛因此成为王总辉门下"密码学工程+GPU高性能计算"这一细分方向的开创性学生，其从BatchZK到TensorZKP的研究主线连贯清晰，标志着王总辉在零知识证明硬件加速方向已形成稳定的培养能力。

在AI安全与大模型安全方向，**杨勇**是由陈文智与王总辉共同指导的核心博士生。他以第一作者身份完成的"PRSA: Prompt Stealing Attacks against Real-World Prompt Services"于2025年6月被USENIX Security 2025录用，提出了针对现实世界提示词服务的提示词窃取攻击方法，直击大模型商业化应用中提示词作为核心资产的知识产权保护痛点。**高袁圣**是另一位在读博士生，其论文"Boosting Large Language Models for Mental Manipulation Detection via Data Augmentation and Distillation"于2026年1月被WWW 2026录用，由陈文智与王总辉共同指导，提出了增强大语言模型精神操纵检测能力的系统性框架并构建了面向真实场景的精神操纵对话数据集，这一工作与王总辉"内容安全"研究方向直接呼应。

**袁新宇**是近期表现极为突出的一年级博士生，在入学第一年内即产出三项顶级成果，其中两项由陈文智与王总辉共同指导：2026年1月论文"Divide, Harmonize, Then Conquer It: Shooting Multi-Commodity Flow Problems with Multimodal Language Models"被ICLR 2026录用；2026年3月论文"Learning-based Sketches for Frequency Estimation in Data Streams without Ground Truth"被CCF-A类期刊TKDE录用，首次将压缩感知思想纳入学习型流算法设计；此外他还有一篇"LMTE: Putting the Reasoning into WAN Traffic Engineering with Language Models"于2025年12月被INFOCOM 2026录用（该篇由陈文智单独指导）。**李鑫**是二年级硕士生，其论文"Otil: Accelerating Diffusion Model Inference via Communication-Efficient Multi-GPU Parallelism"于2026年3月被CVPR 2026录用，由陈文智与王总辉共同指导，聚焦多GPU并行下的扩散模型推理加速。**马哲**是较早期的博士生，其论文"Let All be Whitened: Multi-teacher Distillation for Efficient Visual Retrieval"于2023年12月被AAAI 2024录用，由陈文智、王总辉共同指导。**包晗**的论文"Pluggable Watermarking of Deepfake Models for Deepfake Detection"于2024年4月被IJCAI 2024录用，同样由陈文智与王总辉指导，提出主动式模型水印技术。

另有几项由陈文智与王总辉联合指导但官网未披露第一作者姓名的重要成果，包括2025年6月被ICCV 2025录用的"An Inversion-based Measure of Memorization for Diffusion Models"（扩散模型记忆风险度量），以及2025年6月被IEEE TIFS录用的"Invisible-Face: Rethinking Facial Attribute Privacy in Social Media Photo Sharing"（社交媒体人脸属性隐私保护对抗扰动框架）。

在已毕业学生方面，除陆涛外，**刘沛宇**是另一位可确认的博士毕业生。浙江大学"智慧物联网项目制导师"页面将刘沛宇列为王总辉近三年研究生培养的典型案例，其博士毕业论文题目为《物联网系统云端容器镜像及终端设备的安全与隐私分析技术研究》，代表作包括以第一作者、王总辉为通讯作者的"cMobiDesk: A Lightweight Solution for Android Desktop Virtualization"（ICCCBDA 2022），以及参与的ASE 2021、CCS 2021等CCF-A类论文。刘沛宇的研究主题横跨虚拟化与物联网安全，恰好落在王总辉早期"云平台、虚拟化、嵌入式系统安全"方向的核心地带。

关于毕业去向，ARClab官网的两篇毕业主题推送提供了整个实验室层面的参考坐标。2020年春季，郗茜、凃松林、张晓雨三位同学毕业，分别进入谷歌、字节跳动、华为。2021年，李国玺、魏成坤、刘炎东、刘径心、杨会东、杨嘉琪、汪佳玮七位同学完成毕业答辩，其中李国玺进入华为，魏成坤以博士后身份留在ARClab继续深造，其余同学"都如愿进入国际国内知名企业"。需要说明的是，这两批毕业生的具体指导教师归属官网未逐一标注，因此不能确定其中哪些人由王总辉直接指导（推测其中部分学生曾接受其联合指导）。总体而言，ARClab毕业生的去向呈现出"头部科技企业为主、少数留校深造"的鲜明格局，与该实验室长期紧密的产业合作生态高度一致。

## 四、学术合作网络

王总辉的学术合作网络具有清晰的同心圆结构，其核心特征是"以陈文智为轴心的实验室内部深度绑定"叠加"因具体技术方向而外扩的跨机构专家合作"。

最核心的合作关系无疑是与**陈文智**教授的长期搭档。陈文智是浙江大学求是特聘教授、国家级高层次人才、计算机和教育技术双博士生导师，现任浙江大学信息学部副主任，曾任浙江大学计算机学院副院长、浙江大学信息技术中心主任，同时担任ARClab实验室主任以及"浙江大学—阿里巴巴"智云联合研究中心主任、AZFT智能计算系统实验室主任、"浙江大学—蚂蚁金服"金融科技研究中心联合主任、"浙江大学—安恒信息"前沿技术联合研究中心主任、"浙江大学—苹果公司"科技创新中心主任。陈文智获得过国家级教学成果二等奖2项（均排名第1）、浙江省教学成果一等奖2项（均排名第1）、浙江省科技进步一等奖4项，以及全国宝钢优秀教师奖、国家级教学名师、浙江省"万人计划"教学名师、霍英东教育教学奖等荣誉。二人的合作模式极为固定：陈文智作为实验室主任与对外资源枢纽把控方向与产业对接，王总辉作为副主任承担具体的学生指导与技术攻关，几乎所有ARClab与王总辉相关的论文都以"陈文智教授和王总辉老师指导"的形式署名。这种"教授+高级工程师"的双人指导组合，是理解王总辉学术身份的关键——他的学术产出几乎完全嵌入在陈文智的团队框架内运行，但其技术贡献的独立性和具体性又极为突出。

**张嘉恒**的身份是本次调查中最值得澄清的一环。经核实，与王总辉共同指导USENIX Security '26 TensorZKP论文的"张嘉恒老师"，并非ARClab内部教师，而是**新加坡国立大学（NUS）计算机系助理教授、博士生导师Jiaheng Zhang**。这一判断有多重证据支撑：其一，浙江大学计算机科学与技术学院官网记载，2025年11月11日，NUS助理教授Jiaheng Zhang在浙大玉泉校区逸夫工商楼101会议室作了题为"Efficient Zero-Knowledge Proofs and Applications in Large Language Models（高效零知识证明以及在大模型中的应用）"的学术报告，时间点恰在TensorZKP论文录用（2026年7月）之前约八个月，与合作节奏高度吻合；其二，张嘉恒的研究领域为计算机安全与隐私、应用密码学、零知识证明、AI安全与区块链，与TensorZKP的技术内核完全对应；其三，他本人在ASPLOS等体系结构会议上有发表记录，而陆涛的前作BatchZK正是发表于ASPLOS 2024，二者在"零知识证明的GPU硬件加速"这一细分交叉领域构成天然的互补合作关系。张嘉恒2018年毕业于上海交通大学致远学院（ACM班）计算机科学方向，后赴加州大学伯克利分校师从Dawn Song教授攻读博士，2023年获博士学位后加入新加坡国立大学；他曾获Facebook Fellowship、福布斯亚洲30 Under 30、《麻省理工科技评论》"35岁以下科技创新35人"亚太区、世界人工智能大会云帆"璀璨明星"奖以及新加坡教育部Robert Brown青年研究员奖，并开发了zkBridge跨链桥技术。因此，王总辉与张嘉恒的关系应准确定性为**跨国跨机构的对等学术合作**，而非实验室内部的师徒或上下级关系——这也正是张嘉恒未出现在ARClab官方教师名录页面的根本原因。这一合作对王总辉具有重要意义：它使ARClab在零知识证明这一密码学理论门槛极高的方向上，获得了来自伯克利—NUS密码学谱系的理论支撑，而ARClab则贡献了GPU体系结构与高性能计算的工程实现能力，双方形成"密码学协议设计 × 硬件加速实现"的典型互补格局。

**魏成坤**是ARClab内部另一位与王总辉形成方向分工的关键人物，其身份演变值得特别说明。根据ARClab官网2021年3月的毕业推送，魏成坤当年完成毕业答辩后"将以博士后的身份继续留在ARClab深造、致力于推进实验室学术科研方面的进一步发展"，是一位典型的"本土培养、留所任职"的青年研究人员。他早在2021年7月就与陈晓露老师共同主持ARClab暑期全员会议，说明其在实验室内部已承担教师级职能。魏成坤的学术产出极为亮眼：与孟文龙合作的"LMSanitator: Defending Prompt-Tuning Against Task-Agnostic Backdoors"于2023年8月被NDSS 2024录用，并在2024年2月的会议上从140篇录用论文中脱颖而出斩获**杰出论文奖（Distinguished Paper Award）**，全场仅4篇获此殊荣；他还是CCS 2023两篇论文（DPMLBench、Securely Sampling Discrete Gaussian Noise）以及SIGCOMM 2023论文Achelous的作者。在指导学生方面，魏成坤与王总辉形成了清晰的方向分工：魏成坤主导LLM文本安全与网络系统方向（指导孟文龙的USENIX Security 2025 GradEscape、TIFS的Dialogue Injection Attack、ACL 2025论文，指导施熠的AAAI 2026论文，指导蒋骁翀的SIGCOMM 2026 Spillway论文，以及TMC的分布式限速算法），而王总辉主导体系结构、GPU加速、多模态与视觉安全方向。二人共同构成陈文智之下的"双副手"结构，覆盖了ARClab几乎全部技术版图。

在ARClab内部，王总辉的其他同事还包括：**张紫徽**（浙江大学信息技术中心总工程师，ARClab副主任，曾出席浙大—安恒信息联合研究中心揭牌仪式）、**施青松**（副教授，负责软硬结合课程建设）、**纪守领**（研究员、博士生导师，网络安全领域知名学者，与王总辉在刘沛宇、傅丽蓉等学生的IoT安全论文中有多次共同署名，如CPscan、iFIZZ、Focus等）、**陈建海**（副教授；注：ARClab早期页面标注为讲师，现已更新为副教授）。此外，ARClab的合作网络还延伸至已在外校任职的关联学者，包括**程雨夏**（杭州电子科技大学计算机学院副教授）和**胡威**（武汉科技大学教授、CCF嵌入式系统专委会委员），二人被列于ARClab教师页面，构成实验室向外辐射的校外学术节点。

在跨机构与产业合作者方面，ARClab与阿里云、蚂蚁集团、安恒信息的合作在论文层面有直接体现。**刘博**（安恒信息高级副总裁，浙江大学—安恒信息前沿技术联合研究中心常务副主任）以"安恒信息刘博博士"身份与陈文智共同指导了WWW 2026论文DASGen，是产业界人员直接进入ARClab学生指导序列的典型案例。与阿里云的合作产出了SIGCOMM 2023的Achelous、SIGCOMM 2024的Triton、ASPLOS 2025的OS2G等网络虚拟化与DPU卸载成果；与蚂蚁集团的合作产出了IEEE TPDS 2025的Beehive去中心化调度框架，以及NeurIPS 2024大语言模型隐私挑战赛（LLM-PC）中"Morse ARClab"联合参赛队伍夺得攻击赛道冠军和最佳实用防御奖的成绩。

## 五、业界合作关系深度分析

王总辉的产业连接密度在高校教师群体中属于第一梯队，且其产业角色与陈文智存在明确分工：陈文智负责校级、院级层面的战略性平台搭建（阿里、蚂蚁、安恒、苹果等联合研究中心的主任职务几乎都由陈文智担任），而王总辉则深入到具体的产业技术领域担任专家与执行负责人，尤其在具身智能、汽车产业、信息安全标准化和AI人才认证四条战线上形成了独立的产业影响力。

**具身智能中试基地：从学术研究到国家级产业平台的跃迁。** 王总辉最重要的产业身份是国家人工智能应用中试基地（具身智能）前沿应用与测评实验室主任，同时兼任该基地学术委员会委员兼秘书。这一"主任+学委会委员+秘书"的三重身份组合意味着他既是技术执行负责人，又深度参与基地的学术决策与日常运转协调。该基地（亦称"国家具身智能应用中试基地"，落地于杭州高新区滨江）是国家级中试平台，其战略地位极高：2026年7月16日，在世界人工智能大会召开前夕，基地联合华为云、魔芯科技在杭州举办"模生万物 芯向未来"主题发布会，正式发布魔芯科技MoWorld 3D世界模型——这是全球首个全栈基于国产NPU构建的三维世界模型，标志着我国具身智能核心技术自主可控取得关键突破。发布会汇聚产业界、学术界及投资领域近150位嘉宾，华为云、传化集团、联想控股、现代汽车、吉利集团、杭开控股、华策影视等产业链重点企业代表悉数参会；发布会当日恰逢浙江省委十五届九次全会在杭州召开，全会期间组织考察了该基地。滨江区2025年人工智能产业规模达478.3亿元，占杭州市总量的47.3%，并明确依托该基地在具身智能赛道形成先发优势。王总辉主管的"前沿应用与测评实验室"在这一体系中承担的是具身智能技术的应用验证与能力测评职能，这恰恰是连接实验室原型与产业化部署之间最关键的一环——中试基地的本质就是解决科研成果"最后一公里"的工程化与标准化问题，而"测评"能力更是产业标准话语权的直接来源。考虑到王总辉同时是浙江省信息安全标准化技术委员会委员并参与制定标准与规范10余项，其在具身智能测评标准制定上的潜在影响力值得高度关注。

**长三角新能源汽车产业链与交通大模型：垂直行业的技术下沉。** 王总辉担任长三角新能源汽车产业链联盟专家以及浙江省汽车工业技术创新协会专家委员会专家，这两项兼职与其研究方向中的"交通大模型、数字交通"形成直接呼应，也与其长期深耕的"嵌入式系统"技术积累一脉相承。汽车产业是长三角地区的支柱产业之一，而智能网联汽车恰好处在嵌入式系统、车载算力、AI模型部署、系统安全等多个技术领域的交汇点——这些领域几乎完整覆盖了王总辉的研究方向清单。从技术逻辑看，其在GPU推理加速（如陆涛、王浩宇的DAC 2026稀疏矩阵LLM推理加速工作）、边缘AI（其《嵌入式系统》课程即引导学生在国产嵌入式GPU开发板上开发AI应用）、二进制代码漏洞挖掘与嵌入式系统安全方面的积累，均可直接迁移至车载智能系统的算力优化与安全防护场景。此外，其研究方向中的"具身智能"与新能源汽车的自动驾驶技术在感知—决策—控制的技术栈上高度同源，二者在世界模型、多模态大模型等底层技术上共享同一套方法论。需要说明的是，公开渠道未见其在汽车产业链联盟中具体承担项目的详细披露，本报告仅就其技术能力与产业需求的匹配关系作出分析。

**内容安全与王选新闻科学技术奖：国家级媒体科技赛道的深耕。** 2025年，王总辉获得王选新闻科学技术奖一等奖，这是国家级奖项，被称为全国新闻科技最高奖。这一奖项与其研究方向中的"内容安全、AI音视频分析、AI辅助创作、数字教师"高度相关，也与其承担的国家网信办"音视频XXXX系统"项目（2019年8月至2020年8月，项目负责人，百万级）以及科技部国家重点研发计划课题"网络多媒体XXXX技术研究"（2020年7月至2023年6月，课题负责人，百万级）形成完整的项目—成果闭环。这条产业线索揭示了王总辉一个容易被忽视的重要面向：他在国家网信体系与新闻媒体科技领域拥有实质性的技术积累与官方认可，其"浙江大学网信人工智能创新团队执行主任"的身份正是这一积累的组织化体现。从学术侧看，其团队在AI生成内容检测（如包晗的Deepfake模型水印、马哲的视觉检索蒸馏、扩散模型记忆度量、Invisible-Face人脸隐私保护）方面的持续产出，与内容安全的国家需求形成了紧密对应。

**CCF大模型能力认证LMCC：AI人才评价体系的区域主导权。** 王总辉担任CCF大模型能力认证LMCC青少年组浙江省主席，同时兼任LMCC成人组杭州、宁波、金华三个区域的主席，这是一项容易被低估但产业教育意义深远的兼职。LMCC是中国计算机学会于2025年8月确定开展的认证项目，其官方定位是"全面提升学生的数字素养与科学技能，发现和培养大批具有创新能力和合作精神的人工智能高端人才，建立人工智能领域人才评价体系，推动教育强国建设"。该认证已建立由认证委员会、技术委员会、命题委员会、认证办公室组成的组织架构，并面向全国征询区域主席，以CCF各办事处及会员活动中心所在城市为核心，每个重点城市征询1名区域主席统筹区域内认证全流程工作。王总辉一人同时担任浙江省青少年组主席与三个重点城市的成人组主席，这意味着他实际上掌握了浙江省内AI能力认证体系相当大比例的组织实施权。其产业教育意义在于三个层面：其一，人才评价标准是产业人才供给的上游闸门，谁定义了"什么是合格的大模型人才"，谁就在事实上影响了区域AI人才培养的方向与规格；其二，认证体系天然连接高校、中小学、培训机构与用人企业，是极为高效的产学研人才对接网络；其三，青少年组认证指向的是更长周期的AI人才梯队建设，与浙江省"人工智能产业创新发展第一区"的战略布局形成人才侧的长期支撑。结合王总辉作为英伟达校园大使重构深度学习课程、在研究生课程中引入多家国内GPU厂商合作内容的教学实践，可以看出他在"AI人才培养产业化"这条线上有着系统性的布局，而非零散的社会兼职。

**其他产业生态节点。** ARClab整体的产业合作网络也为王总辉提供了丰富的资源背景，包括浙江大学—蚂蚁集团金融科技研究中心（2020年9月成立，下设全球金融科技实验室、数据安全与隐私保护实验室和智能计算实验室）、浙江大学—安恒信息前沿技术联合研究中心（2021年8月成立）、与鹏博士集团合作的前沿技术研究中心（2020年5月成立）、AZFT（浙江大学—阿里巴巴前沿技术研究中心）智能计算系统实验室，以及诞生于ARClab实验室并在2023年云栖大会亮相的开源大模型项目OpenBuddy。此外，ARClab作为主要单位参与的"云网端新型融合计算架构及应用"项目荣获2023年度浙江省科学技术进步奖一等奖（2024年11月颁发），这一奖项的技术内涵与王总辉的云平台、虚拟化、体系结构方向高度契合。

## 六、重要奖项与学术兼职

在科研奖项方面，王总辉的荣誉体系呈现"国家级行业大奖+省级科学奖+国际期刊长效影响力奖"的三元结构。最具分量的是**王选新闻科学技术奖一等奖**（2025年），这是国家级奖项，为全国新闻科技领域的最高奖，对应其在AI音视频分析、内容安全与网信人工智能方向的长期积累。**浙江省自然科学奖三等奖**（2023年）代表了其在基础研究层面获得的省级认可。**Frontiers of Computer Science（FCS）期刊Test of Time Paper Award**（2023年）则是一项特殊而有说服力的荣誉——时间检验奖（Test of Time Award）通常授予发表若干年后仍持续产生重要学术影响的论文，这类奖项无法通过短期的论文数量堆砌获得，而是对研究工作长期生命力的直接验证，说明王总辉早期的某项研究成果在多年之后依然被学术共同体广泛引用和认可。此外，他还是ARClab参与的"云网端新型融合计算架构及应用"项目获2023年度浙江省科学技术进步奖一等奖的相关团队成员之一（推测其参与程度需以正式获奖名单为准）。

在教学奖项方面，王总辉获得**国家级教学成果二等奖**（2018年）、**浙江省教学成果一等奖**（2016年）和**国家级精品资源共享课**（2013年，对应《嵌入式系统》课程）。其负责的《高级计算机体系结构》课程于2024年获评"浙江大学专业学位博士核心课程"，2025年获"浙江省专业学位研究生优秀教学案例"。这一系列教学荣誉与陈文智在教学领域的国家级教学名师、国家级教学成果二等奖2项等成就构成呼应，反映出ARClab"科研与教学双轮驱动"的团队特色，也印证了王总辉作为高级工程师序列教师在课程建设与实验设计上的核心贡献。

在学术与社会兼职方面，其职务可归为四类。学术组织与期刊类：《信息网络安全》期刊编委。标准化类：第三届浙江省信息安全标准化技术委员会委员（2025—2030年任期），并参与制定标准与规范10余项。产业智库类：长三角新能源汽车产业链联盟专家、浙江省汽车工业技术创新协会专家委员会专家。人才认证与教育类：CCF大模型能力认证LMCC青少年组浙江省主席、LMCC成人组杭州/宁波/金华区域主席，以及英伟达校园大使。校内与国家级平台职务方面，他担任浙江大学系统结构与脑机工程研究所副所长、ARClab副主任、浙江大学网信人工智能创新团队执行主任、国家人工智能应用中试基地（具身智能）前沿应用与测评实验室主任及基地学术委员会委员兼秘书。

## 七、Connection圈层总结

综合上述全部信息，王总辉的学术关系网络可以按亲密度与功能性划分为五个圈层，而贯穿这五个圈层的核心线索是他作为"陈文智副手+ARClab技术多面手+具身智能与安全交叉方向开拓者"的独特复合定位。

**第一圈层：与陈文智的深度绑定关系。** 这是理解王总辉全部学术活动的基础坐标。他与陈文智的合作绝非普通的同事关系，而是一种高度制度化、高频次、覆盖全方向的固定搭档模式——ARClab近三年几乎所有涉及体系结构、GPU加速、多模态与视觉安全方向的论文，指导教师都是"陈文智教授和王总辉老师"这一不变组合。陈文智作为求是特聘教授、国家级高层次人才、信息学部副主任，掌握着与阿里巴巴、蚂蚁集团、安恒信息、苹果等企业的战略级合作平台以及校内的行政资源；王总辉则作为高级工程师序列的技术负责人，承担实际的技术攻关与学生指导。这种"资源型正职+技术型副职"的搭配，使王总辉得以在不必承担大量对外事务的情况下，将精力集中于技术本身与学生培养，这也解释了他为何能同时覆盖如此宽广的研究方向。需要指出的是，这一定位既是优势也构成某种约束：他的学术产出高度嵌入陈文智的团队框架，个人学术品牌的独立辨识度相对弱于同等产出水平的独立PI。

**第二圈层：ARClab内部的同僚与分工网络。** 其中最重要的是魏成坤——这位2021年从ARClab毕业后留所做博士后的青年研究人员，如今已成为与王总辉并列的"另一位副手"，二人形成了清晰的方向分工：魏成坤主攻LLM文本安全（孟文龙的NDSS杰出论文、USENIX Security、TIFS、ACL系列）与网络系统（蒋骁翀的SIGCOMM 2026），王总辉主攻体系结构与GPU加速（林溢泉的HPCA/MICRO/TCAD、陆涛的ASPLOS/DAC/USENIX Security）以及多模态与视觉安全（李鑫的CVPR、包晗的IJCAI、马哲的AAAI、ICCV与TIFS工作）。这一分工使ARClab在陈文智之下形成了稳定的"双引擎"结构。同圈层还包括ARClab副主任张紫徽（浙江大学信息技术中心总工程师）、施青松副教授（软硬结合课程建设）、纪守领研究员（网络安全，与王总辉在IoT安全论文上有多次共同署名）、陈建海副教授，以及已外派任职的程雨夏（杭州电子科技大学）和胡威（武汉科技大学）。

**第三圈层：学生梯队。** 这是王总辉学术影响力最直接的载体，也是其"技术多面手"特质的最佳注脚。已毕业者以陆涛（密码学工程与GPU高性能计算，从BatchZK到TensorZKP的完整研究主线）和刘沛宇（物联网系统云端容器镜像及终端设备安全与隐私）为代表；在读博士生包括林溢泉（处理器预取器，支撑ARClab连续四年HPCA录用）、杨勇（提示词窃取攻击，USENIX Security 2025）、高袁圣（大模型精神操纵检测，WWW 2026）、袁新宇（一年级即产出ICLR/TKDE/INFOCOM三项成果）、马哲（视觉检索蒸馏）、包晗（Deepfake模型水印）；硕士生包括李鑫（扩散模型多GPU并行推理，CVPR 2026）、陈于勋（BatchZK合作者）等。从ARClab整体毕业去向看，学生主要流向谷歌、字节跳动、华为等国内外头部科技企业，少数选择留所做博士后。这一梯队的方向分布极为发散——从缓存预取器到零知识证明再到大模型内容安全，恰恰印证了王总辉能够在计算机系统全栈范围内提供有效指导的罕见能力。

**第四圈层：跨机构学术合作网络。** 该圈层的典型代表是新加坡国立大学助理教授**张嘉恒（Jiaheng Zhang）**。经核实，张嘉恒并非ARClab内部教师，而是一位UC伯克利博士（师从Dawn Song）、上海交大致远学院ACM班本科出身的国际青年密码学专家，2025年11月曾受邀在浙大计算机学院作零知识证明与大模型应用的学术报告，随后与王总辉、陈文智共同指导了USENIX Security '26的TensorZKP论文。这一合作构成了典型的能力互补：NUS方提供零知识证明的密码学协议设计能力，ARClab方提供GPU张量核心编程与高性能计算的工程实现能力，最终产出了"首次将GPU张量核心引入ZKP加速"的突破性成果（sum-check协议约88倍加速，端到端较CPU基线约955倍、较最先进SIMT GPU实现约36.2倍提升）。这一圈层的存在表明，王总辉正在通过引入外部顶尖理论资源来突破自身在密码学等理论门槛较高领域的能力边界，是其研究版图扩张的重要策略。

**第五圈层：产业与政策网络。** 这是王总辉区别于纯学术型教师的最鲜明特征，也是其个人独立影响力最强的领域。该圈层包括：国家人工智能应用中试基地（具身智能）——他作为前沿应用与测评实验室主任及学委会委员兼秘书，深度参与这一汇聚华为云、魔芯科技、传化集团、联想控股、现代汽车、吉利集团、华策影视等企业的国家级产业平台；长三角新能源汽车产业链联盟与浙江省汽车工业技术创新协会——对应其交通大模型与数字交通方向；浙江省信息安全标准化技术委员会——对应其标准制定影响力；CCF大模型能力认证LMCC——他一人统筹浙江省青少年组及杭州、宁波、金华三市成人组的认证工作，掌握区域AI人才评价体系的组织实施权；以及经由ARClab延伸的阿里云、蚂蚁集团、安恒信息、鹏博士、英伟达等企业生态。

总体判断，王总辉是一位在中国顶尖高校系统结构实验室中颇具典型性又相当特殊的学者样本。说其典型，是因为他体现了大型实验室"正职把方向、副职抓落实"的经典运行机制，其个人学术轨迹几乎完全内生于浙大——2007年博士毕业留校，此后近二十年未曾离开。说其特殊，则在于三点：其一，作为"高级工程师"这一非典型学术职称序列的教师，他却带出了HPCA、MICRO、ASPLOS、USENIX Security、CVPR、ICLR、ICML等横跨体系结构、安全、AI三大领域顶会的学生，打破了工程序列教师难出顶级学术成果的刻板印象；其二，他的研究方向宽度远超常规PI，从缓存预取器到零知识证明再到具身智能测评，这种"全栈覆盖"能力使他成为ARClab不可替代的技术枢纽；其三，他在产业与政策网络中的角色深度已超出一般高校教师范畴，具身智能国家级中试基地的测评实验室主任与LMCC区域主席这两项职务，分别让他站在了"技术标准定义"和"人才标准定义"这两个产业上游位置。展望其发展路径，具身智能与AI安全的交叉方向很可能成为他未来最重要的学术标识——这一方向既承接了他在体系结构与嵌入式系统上的二十年积累，又契合国家级中试基地赋予他的平台资源，同时还能吸纳其团队在大模型安全、内容安全上的既有优势，是其全部能力要素能够形成合力的最佳汇聚点。
