## 二、教育背景与职业履历

屠可伟的学术生涯始于上海交通大学计算机科学与工程系，分别于2002年和2005年获得学士和硕士学位。硕士期间，他跟随导师课题组从事知识工程方向的研究，这是符号主义人工智能的一个分支。这一早期训练奠定了他此后将符号方法与统计/神经方法相结合的研究底色。

随后他赴美深造，于2012年在美国爱荷华州立大学（Iowa State University）计算机科学系获得博士学位。博士期间，他选择了文法（grammar）学习作为主要研究方向，认为文法作为一种建模复杂结构的方法，不仅适用于语言，还可拓展至图像、视频等其他数据类型。博士导师信息在公开主页未明确标注（待核实）。据其自述，导师给予了他充分的选题自由，使他能够花一两年时间广泛探索后确定长期研究目标。

2012年至2014年，屠可伟在加州大学洛杉矶分校（UCLA）统计系与计算机系从事博士后研究。博士后阶段，他将研究方向从自然语言处理扩展到计算机视觉，尝试将语言文法技术迁移到视觉领域。UCLA期间的博士后合作导师信息在公开主页未明确标注（待核实）。

2014年2月，屠可伟加入上海科技大学信息科学与技术学院、任助理教授和研究员的具体任职时间与职称组合待核实。此后随着深度学习革命对原有研究路线的冲击，他决定回归自然语言处理领域，探索文法与深度学习的结合，这成为他过去七八年的主要研究方向。随着Transformer和大语言模型的兴起，他的研究重点进一步聚焦于从语言结构视角改进、创新和解释Transformer架构与大语言模型。

在职业晋升方面，屠可伟曾任长聘副教授；其于2024年9月正式晋升为常任正教授的时间待核实。当前学院官方主页及个人主页均列其为正教授、副院长。他同时担任信息科学与技术学院副院长。CSRankings相关排名口径及名次待核实。

## 四、学术合作网络

### 4.1 本组与校内合作

屠可伟课题组是上科大信息学院下属的独立PI研究组，以自然语言处理和机器学习为核心方向。课题组内部形成了以博士生为核心发动机的科研团队，高年级学生（如蒋成跃、杨松霖、胡翔、楼超、吴昊易、赵一达等）在组内形成了紧密的内部合作网络，多名学生在同一篇论文中以共同作者出现。

从论文合作模式来看，组内形成了若干研究方向小组：（1）句法分析与结构化模型方向——杨松霖、楼超、赵一达；（2）Transformer架构与LLM效率方向——吴昊易、胡翔；（3）信息抽取与知识探测方向——蒋成跃、贾子霞、吴伟琪。这些方向之间也存在交叉合作。

在校内跨组合作方面，屠可伟参与了上科大"视觉与数据智能中心"（由虞晶怡、何旭明、屠可伟、廖奇峰等教授组成），并与其他校内教授有论文层面的合作。此外，屠可伟担任学院副院长，在学院管理与学科建设层面与院内其他教授保持协作关系。

## 五、业界合作关系深度分析

### 5.1 产业合作

屠可伟课题组的产业合作呈现出鲜明的"学术-产业双向赋能"特征，核心合作对象包括：

**阿里巴巴达摩院（DAMO NLP）**：联合论文可由学校新闻和屠可伟个人主页中的论文条目交叉确认，其中ACL 2023论文的官方新闻明确列达摩院为合作机构；其个人主页亦将ACL 2023论文的代码链接至ModelScope/AdaSeq示例。因此，本报告确认双方存在联合论文与AdaSeq相关合作。联合论文总数、“规模最大、最深入”、学生长期实习、共同开发关系及SemEval获奖系统中屠可伟的具体参与方式，均待核实。

**其他企业**：毕业生去向覆盖腾讯、百度、网易、米哈游、乐言（初创企业）、小马智行（自动驾驶初创企业）等，这些企业虽然暂未形成大规模学术论文合作，但通过人才输送建立了产业联系。

## 七、Connection圈层总结

屠可伟教授的学术关系网络可按以下圈层结构进行概括：

**第一圈层（核心团队）**：以屠可伟为PI、其指导的博士生和硕士生的内部团队。课题组保持小规模（在读约12人），师生比高，导师深度参与每位学生的科研。核心学生包括蒋成跃、杨松霖、胡翔、楼超、吴昊易、赵一达、纪鹏宇、贾子霞、陈卓等，他们在组内形成紧密的内部合作网络，研究方向覆盖句法分析、结构化Transformer、LLM高效推理、信息抽取等。

**第二圈层（产业合作伙伴）**：阿里巴巴达摩院是核心产业合作方，形成"联合培养+联合发表+开源共建"的深度合作模式。蚂蚁集团在结构化语言模型方向有持续投入。BIGAI/通研院在信息抽取等方向有合作。这一圈层是屠可伟组的学术影响力向产业转化的主通道。

**第三圈层（毕业生网络）**：截至2023年已有14名毕业生（5博9硕），去向横跨国际顶尖高校（MIT、马里兰、爱丁堡、NUS等）和国内头部企业（阿里星两人、腾讯、百度、网易、米哈游、乐言、小马智行、通研院、国防科大等）。这一毕业生网络不仅扩大了屠可伟组的学术影响力，也形成了产业界的人才口碑效应。

**第四圈层（学术共同体）**：在国际层面，屠可伟组与MIT（Yoon Kim）等有直接合作，论文发表在ACL/EMNLP/NAACL/AAAI/ICLR/ICML/NeurIPS等全部NLP与AI核心顶会。在国内层面，与浙大（Yu-Feng Li）、国防科大（Hai-Tao Zheng）等有合作。屠可伟本人担任ACL Rolling Review执行编辑及多个顶会领域主席，在学术服务层面深度参与学术共同体建设。

**第五圈层（教育与社会影响）**：屠可伟通过教材《动手学自然语言处理》和EACL 2021等Tutorial，在NLP教育领域建立了广泛影响。作为上科大信息学院副院长，他在学院治理和国际合作中也扮演重要角色。其高中母校为江苏省常州高级中学（与招生的学生吴昊一同校），这一地域人脉网络在其招生工作中也有所体现。

总体而言，屠可伟组的学术网络以"小而精"的课题组为核心，通过阿里巴巴达摩院这一产业合作主轴实现学术影响力的产业转化，同时以高质量毕业生输送和顶会论文产出在国内外NLP学术界建立了有辨识度的学术声誉。其研究路线从文法学习出发，历经符号-统计-神经方法的融合，最终聚焦于语言结构驱动的Transformer与大语言模型创新，在这一方向上形成了独特的学术标签。
