## 二、中心背景与研究方向概述

北京大学高能效计算与应用中心（CECA）由UCLA讲席教授、北大校友丛京生（Jason Cong）于2010年12月创建并担任创始主任，是北大在体系结构、EDA与高能效计算方向的跨院系研究平台。丛京生本人是FPGA与可定制计算领域的世界级学者（IEEE Fellow 2000、ACM Fellow 2008、美国国家工程院院士2017、中国工程院外籍院士2019、2024年ACM Charles P. Thacker计算突破奖与Phil Kaufman奖双料得主），其学生与合作伙伴遍布全球学术界和EDA产业界（AutoESL被Xilinx收购、Falcon Computing等创业谱系）。

中心的研究方向覆盖"算法—架构—EDA工具—芯片应用"全栈：孙广宇（清华本硕、Penn State博士，导师谢源）专注领域定制计算架构、存算一体与scale-up互连，体系结构顶会（ISCA/MICRO/HPCA/ASPLOS）成果近200篇，五次最佳论文奖（ISCA 2025、HPCA 2023、IEEE TCAD 2019均为国内第一单位首次），并入选HPCA和FPGA名人堂；梁云（同济本科、新加坡国立大学博士）深耕EDA与软硬件协同设计，是北大超算队创始指导教师；林亦波（上海交大本科、UT Austin博士，导师David Z. Pan）专注机器学习驱动的EDA物理设计与开源工具生态。2025年度CCF科技成果奖自然科学奖一等奖"面向人工智能领域的定制架构设计理论与方法"（第一完成人孙广宇，主要完成人含董德尊、张宸、关义金、梁云、王润声，完成单位北大、国防科大、上海交大）是中心近年最重要的集群性成果，相关理论已应用于天河超算及智能计算机研制。

## 三、关系网络与圈层结构概述

CECA的网络结构呈"海外学术枢纽+本土梯队+产业应用链"的三层格局。最上层是丛京生所代表的UCLA—北大通道：丛京生1985年本科毕业于北大计算机系，此后经UIUC博士、UCLA任教，于2010年回母校创建CECA，形成"北大本科—UCLA博士—北大CECA"的人才循环。罗国杰（2005北大学士、2011 UCLA博士，其UCLA博士导师一般公开资料多认为师从丛京生）、张宸（北大博士，导师丛京生/孙广宇，2017年毕业去微软亚洲研究院）等均是该循环的产物。

中间层是本土培养的EDA/体系结构梯队。孙广宇来自Penn State谢源体系（谢源后执教UCSB，是新型存储与三维集成方向的国际权威）；梁云来自新加坡国立大学体系（博士后在UIUC）；林亦波来自UT Austin的David Z. Pan（潘建中）体系——潘建中是EDA领域国际权威，其UTDA实验室培养了大量华人EDA学者，林亦波与该网络（于淼 Bei Yu、黄崇维 Tsung-Wei Huang等）保持密切合作。此外林亦波与王润声、黄如院士团队（集成电路学院）深度绑定，共同维护DREAMPlace（被NVIDIA集成）、OpenPARF、CircuitNet等开源项目。

产业应用层方面，中心的成果通过国防科大进入天河超算与智能计算机研制，指导多款AI芯片设计；与华为、AMD、Intel、微软亚洲研究院、商汤等企业有长期科研合作；丛京生的AutoESL（2011年被Xilinx收购，现属AMD）是高层次综合工具产业化的标杆案例。学生去向上，CECA毕业生进入华为海思、上海立芯、阿里、腾讯、英特尔、微软亚洲研究院等企业，或赴UCLA、普渡、UT Austin等海外名校深造。

## 四、数据说明与勘误

本系列报告经过独立事实核查流程审查，主要修正包括：丛京生报告补充中国工程院外籍院士（2019）、2024年ACM计算突破奖、CECA创始主任（2010年创建）等关键信息，头衔修正为"协理副教务长"；孙广宇报告最佳论文奖次数由6次修正为5次（依集成电路学院官方页面），2025年度CCF奖项统一为官方全称"CCF科技成果奖自然科学奖一等奖"；林亦波报告标题职称由"助理教授"更新为"长聘副教授"（2025年起），补全所属团队，更新孙广宇称谓；罗国杰UCLA博士导师在各报告中统一表述为"待核实"（官方页面未明确记载，避免与丛京生报告口径冲突）；梁云报告中CCF奖项全称已统一。各报告中标注"（待核实）"的内容为公开资料暂未确证的信息。
