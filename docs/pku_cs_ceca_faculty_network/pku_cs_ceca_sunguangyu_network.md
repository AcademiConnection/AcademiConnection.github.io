## 二、教育背景与职业履历

孙广宇的学术训练并非“哈工大本科、北大博士”路径。北京大学集成电路学院现行官方主页明确记载：他于2003年获清华大学电子工程系学士学位，2006年获清华大学微电子所硕士学位，2011年获美国宾夕法尼亚州立大学计算机科学博士学位。因此，关于“哈工大本科、北大博士”的说法与公开官方资料不符，不应采纳。

其博士阶段以新型非易失存储器及体系结构为主线。公开访谈与人物报道显示，他2006年赴宾夕法尼亚州立大学攻读计算机体系结构方向博士；在博士期间转入谢源（Yuan Xie）教授指导组，研究新型存储器及其体系架构。谢源系其博士导师；其博士论文题为 *Exploring Memory Hierarchy Design with Emerging Memory Technologies*，获2012年EDAA Outstanding Dissertation Award。该阶段形成了“器件特性—存储层次—体系架构”贯通的研究方法，也使其与陈怡然（Yiran Chen）等新型存储和体系结构研究者建立了长期论文合作。

职业履历可归纳为以下时间线：

- **2003年**：清华大学电子工程系本科毕业。
- **2006年**：清华大学微电子所硕士毕业；其硕士研究主要涉及SRAM设计。
- **2006—2011年**：宾夕法尼亚州立大学计算机科学系博士研究生，导师为谢源教授；2011年获博士学位。
- **2011年8月—2017年8月**：加入北京大学，在信息科学技术学院/CECA任助理教授。CECA旧主页记录其2011年回国后即在中心任教。
- **2017年8月—2025年8月**：北京大学长聘副教授。
- **2025年9月—至今**：北京大学长聘教授。北京大学2025年CCF科技成果奖新闻同时称其为“北京大学教授、集成电路学院设计自动化与计算系统系副主任”。

上述经历也解释了其组织归属的演变：早期公开页面多使用“北京大学信息科学技术学院特聘研究员、CECA长聘副教授”的称谓；随着集成电路学院及设计自动化与计算系统系的建制发展，现行官方教师页以集成电路学院长聘教授为准。CECA页面未同步更新职称，不宜据此判断其当前职级。

国际合作网络的上游核心是博士导师**谢源（Yuan Xie）**。孙广宇在宾夕法尼亚州立大学博士期间接受谢源指导；谢源后任加州大学圣塔芭芭拉分校（UCSB）教授并兼任CECA客座/兼职教授，构成“博士训练—CECA国际联结”的持续桥梁。公开论文记录还显示孙广宇与谢源、陈怡然、Jia Di等人在新型存储器架构上长期合作；例如关于非易失存储器与体系结构影响的综述论文，以及STT-RAM等工作。

### 5.1 产业合作与成果应用

孙广宇的产业关联呈现"基础方法—国家级计算平台/智能计算机—芯片设计支持"三层结构。最强的公开证据来自2025年度CCF科技成果奖自然科学奖一等奖公告：相关理论和方法"已应用于天河超算及智能计算机研制，并指导了多款人工智能芯片的设计与实现"。这表明其成果并非仅停留在论文层面，而是通过国防科技大学等合作端进入高性能计算与智能计算系统研制流程；不过公告未披露具体芯片型号、企业名称和商业化合同，报告不作进一步推断。

在行业交流层面，孙广宇曾在以华为技术专家为参与者的CNCC“AI网络互联创新”论坛报告“面向CXL的软硬件协同数据管理技术”；在2025全球AI芯片峰会的存算一体技术研讨中，与华为昇腾、阿里云、微纳核芯、寒序科技等产业专家同场交流。这些活动可反映其技术议题与产业生态的对接，但属于技术交流或共同论坛，**不应自动解读为项目合作或股权关系**。

### 5.2 创业孵化与技术转化

目前未发现可靠公开资料证明孙广宇本人创办、控股或担任某一AI芯片企业高管，也未见可核验的企业孵化清单；因此，本报告不编造“创业公司”或“孵化企业”关系。能确认的是，他所在研究线的成果被CCF公告表述为“指导多款人工智能芯片的设计与实现”，并与天河超算和智能计算机研制发生应用连接。这是一种以方法论、工具和架构设计为核心的技术扩散路径，而非公开可验证的个人创业路径。

## 七、Connection圈层总结

**第一圈层：博士导师与长期学术合作核心。** 谢源是其博士导师，也是贯穿新型存储、三维集成与体系结构的上游学术枢纽；陈怡然构成器件—体系结构交叉合作节点。该圈层塑造孙广宇从微电子存储器件转向计算机体系结构和高能效设计的研究范式。

**第二圈层：CECA与集成电路学院的组织近邻。** 孙广宇位于CECA和设计自动化与计算系统系的交汇处，与梁云、罗国杰、林亦波、王润声等形成日常教学、科研组织和项目协同网络。其中梁云、王润声已由CCF一等奖共同完成人关系直接验证；罗国杰和林亦波的组织协作紧密，但本报告不将其一概等同为论文合作者。

**第三圈层：跨机构重大项目网络。** 以孙广宇为第一完成人的2025年度CCF科技成果奖自然科学奖一等奖，将北京大学、国防科技大学和上海交通大学连接起来；董德尊、张宸、关义金、梁云、王润声为项目主要完成人。该圈层将定制架构理论、自动化设计方法与天河超算/智能计算机等重大应用场景相连。

**第四圈层：国际论文与人才流动网络。** 谢源所在的UCSB、陈怡然所在的杜克大学、Jason Cong所在的UCLA等构成国际合作节点。邹乐其、高欣赴UCLA深造，周喆赴普渡大学攻读博士（后两者需与孙广宇的师生关系进一步核实），显示CECA培养网络对北美体系结构和计算机系统学术生态的连接。

**第五圈层：产业与应用生态。** 研究支持方包括华为、百度、AMD、Intel、MSRA、腾讯；成果应用端则明确连接天河超算、智能计算机研制及多款AI芯片设计。该圈层的核心特点是以架构理论、自动化工具、存算一体和互连技术向产业扩散，而不是以已公开披露的个人创业公司为中心。对具体企业产品、联合开发和转化主体，应在获得项目公告、专利/合同或企业正式披露后再做精确归因。
