# 中国科学技术大学 先进数据系统实验室（ADSL）教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

先进数据系统实验室（Advanced Data Systems Lab，ADSL，官网 http://adsl.ustc.edu.cn/ ）隶属于中国科学技术大学计算机科学与技术学院，依托国家高性能计算中心（合肥）与安徽省高性能计算重点实验室运行，是我国存储系统与数据系统研究方向最具代表性的高校团队之一。实验室的历史脉络可追溯至陈国良院士开创的中科大并行计算学派，由许胤龙教授（国家高性能计算中心（合肥）常务副主任）领衔组建，现有特任教授、特任研究员、副教授等多名教师，以及博士生近 20 名、硕士生 40 余名。

实验室的研究覆盖存储系统（纠删码容错、键值存储、分布式文件系统、SSD 可靠性）、大规模分布式系统（一致性、云原生数据库、RDMA 分离式内存）、图计算与数据隐私，以及近年快速拓展的大模型基础系统软件（并行化训练计划生成、量化推理、MoE 训练与推理、向量数据库）等方向。近五年在 FAST、OSDI、SOSP、ATC、VLDB、SIGMETRICS、INFOCOM、ICDE、EuroSys、HPCA 等系统顶会及 ToS、TC、TPDS 等顶刊发表论文 50 余篇，博士生连续两届（2022 张强、2023 王一多）获中国科学院院长奖特别奖，是中科大系统方向顶会产出的主力团队之一。

实验室与华为、平凯星辰（PingCAP/TiDB）、阿里巴巴、百度、微软亚洲研究院等产业界力量建立了深度合作，学生去向横跨高校教职（华中科技大学胡燏翀等）与头部企业研究体系（阿里星、华为、PingCAP 等），形成了"存储 + 分布式 + 大模型系统"三位一体的研究与人才培养生态。

## 研究方向与圈层结构概述

ADSL 的研究布局可概括为三条主线：其一是许胤龙—吕敏主导的存储可靠性与数据布局方向（纠删码、数据重构、RAID 恢复），其数学根基源自许胤龙的组合数学与图论背景；其二是李永坤主导的数据密集型存储系统方向（LSM-tree KV 存储、图计算 I/O、池化内存），承接港中文 John C.S. Lui 的随机建模传统；其三是李诚主导的分布式与智能计算系统方向（一致性系统、云原生数据库、大模型训练/推理系统），带有 MPI-SWS 与 Oracle Labs 的国际化基因。吕自成（John C.S. Lui）以长江讲座教授身份加盟，将港中文网络编码与随机系统研究网络接入实验室。

圈层结构上，内层是"许胤龙 + 李永坤 + 李诚 + 吕敏"的高密度合作内核（共同论文、共同专利、联合指导），外接陈国良院士的高性能计算中心机构网络；中层通过学生谱系辐射——学术线以胡燏翀（华中科技大学教授）为代表延伸至华科存储学派，企业线以"阿里星"得主、白有辉（华为→回校）、陈浩/阮超逸（阿里巴巴）等连接产业界；国际圈层则经李诚的 MPI-SWS/INESC-ID 一致性系统谱系、微软亚洲研究院联合培养（林郅琦）以及港中文（Lui、Patrick P.C. Lee）网络展开。

## 产业转化亮点

实验室的产业合作以"真问题驱动 + 顶会论文 + 落地部署"为特征：与平凯星辰（PingCAP）围绕 TiDB 数据库开展战略合作并举办联合研讨会；与华为保持长期合作（HIRP 项目、计算网络联合创新项目、昇腾人才通道）；与阿里云 PolarDB 团队合作发表 VLDB 论文（内存分离弹性部署）；与百度合作的分布式文件系统元数据成果（CFS，EuroSys 2023）部署于百度生产环境 Ceph 集群；与微软亚洲研究院联合培养的 nnScaler、Tessel 等大模型训练系统成果已开源。学生创业与人才输送方面，毕业生中既有高校教授（胡燏翀、李志鹏），也有华为、阿里、字节、PingCAP 等企业的核心研发力量，"阿里星"得主更成为实验室人才培养质量的标志性名片。
