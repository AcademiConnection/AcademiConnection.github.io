## 二、教育背景与职业履历

李永坤本科毕业于中国科学技术大学计算机科学与技术专业，于2008年7月获学士学位。随后赴香港中文大学计算机科学与工程学系攻读博士学位，师从国际知名的随机建模与网络系统专家 John C.S. Lui 教授（吕自成教授，ACM/IEEE Fellow，香港中文大学 Choh-Ming Li 讲席教授，同时也是 ADSL 实验室的长江讲座教授）。博士期间他主要围绕固态存储（SSD）系统的随机建模与可靠性分析开展研究，成果发表于 ACM SIGMETRICS、IEEE SRDS 等会议及 ACM ToS、IEEE TC、Queueing Systems 等期刊。

博士毕业后，他留在香港中文大学网络编码研究所（Institute of Network Coding, CUHK）从事博士后研究，合作导师为 John C.S. Lui 教授与 Patrick P.C. Lee 教授，研究重心逐步从 SSD 可靠性分析转向键值（KV）存储、纠删码存储与去重等系统方向。

约2014年前后，李永坤加入中国科学技术大学计算机科学与技术学院，加入许胤龙教授领衔的国家高性能计算中心（合肥）存储研究团队（即后来的先进数据系统实验室，ADSL），历任特任教授等职务至今，博士生导师、硕士生导师。据百度百科及其实验室公开介绍，他还担任安徽省高性能计算重点实验室主任。在中科大期间，其研究从 SSD/RAID 可靠性逐步扩展到 LSM-tree 键值存储优化、图计算 I/O 优化、分布式/池化内存系统，近年又延伸至面向 LLM 训练与推理的存储支持、Serverless 数据传递、RDMA 分离式内存架构等前沿方向，在 FAST、ATC、OSDI、ICDE、SIGMETRICS、MICRO、TPDS 等顶级会议与期刊持续产出。

## 三、学生培养情况

李永坤作为（共同）指导教师，依托 ADSL 实验室（在读博士生近20名、硕士生40余名、本科生10余名）培养了大批存储系统方向的研究生。实验室近年博士生连续获得中国科学院院长奖特别奖（2022届张强、2023届王一多），培养质量在中科院系统内处于前列。根据其实验室人员页面及论文署名，代表性学生包括（多为与许胤龙教授等联合指导）：

### 1. 张强（博士毕业生，直接指导博士生）

张强（Qiang Zhang）是李永坤指导的2022届博士毕业生，是实验室 KV 存储方向的代表性学生。他作为第一作者发表了 UniKV（ICDE 2020，面向混合负载的统一索引 KV 存储）和 DEPART: Replica Decoupling for Distributed Key-Value Storage（USENIX FAST 2022，分布式 KV 存储的副本解耦）等顶会论文，均以李永坤为通讯作者。据实验室官网通报，张强荣获2022年度中国科学院院长奖特别奖，是该实验室博士生首次获得该奖项；其博士论文成果与其后实验室与 PingCAP 等企业的 KV 存储合作研究方向高度相关。其毕业后的具体去向公开资料披露有限。

### 2. 郭帆（博士毕业生，现为闽江学院教师）

郭帆（Fan Guo）是实验室云计算与存储方向的早期代表性学生，博士期间以第一作者发表 SmartMD: A High Performance Deduplication Engine with Mixed Pages（USENIX ATC 2017）、HP-Mapper: A High Performance Storage Driver for Docker（ACM SoCC 2019）、DCUDA（SoCC 2019，GPU 动态调度与热迁移）等论文，研究覆盖内存去重、容器存储驱动与 GPU 资源调度。毕业后入职闽江学院计算机学院任教，仍与李永坤保持合作，作为共同作者参与了 TC 2023 内存去重、TCC 2023 GPU 调度等后续论文。值得注意的是，李永坤2024年10月曾应邀赴闽江学院作学术报告，体现了其延续性的师生学术网络。

### 3. 姚路路（博士毕业生，2020届）

姚路路（Lulu Yao）博士期间主要研究虚拟化环境下的内存动态调整与内存去重，以第一作者发表 Progressive Memory Adjustment with Performance Guarantee in Virtualized Systems（ICPP 2021），并作为主要作者参与 TC 2023 的内存去重论文及多篇 ATC/TOS 论文，其硕士-博士期间工作与多项中科大专利（如"一种基于状态感知的虚拟机内存动态调节方法"）直接相关。毕业后去向公开资料披露有限。

### 4. 汪睿（博士毕业生）

汪睿（Rui Wang）是实验室图计算 I/O 优化方向的代表性学生，以第一作者发表 GraphWalker: An I/O-Efficient and Resource-Friendly Graph Analytic System for Fast and Scalable Random Walks（USENIX ATC 2020）与 XPGraph: XPline-Friendly Persistent Memory Graph Stores（MICRO 2022，与浙江大学何水兵等合作），并作为核心作者参与 TPDS 2025 二维均衡图划分、ICPP 2025 PTWalker 等论文，是实验室"随机游走/图分析"研究线从 ATC 到 TPDS 持续产出的主力。毕业后去向公开资料披露有限。

### 5. 朱文喆（在读博士生，2020级）

朱文喆（Wenzhe Zhu）是实验室当前最核心的在读博士生之一，长期在云存储 I/O 调度方向工作：作为第一作者发表 DiffForward: On Balancing Forwarding Traffic for Modern Cloud Block Services（ACM SIGMETRICS 2023），作为主要作者参与 MinFlow（FAST 2024）、Bubble（SC 2025）、FineMem（OSDI 2025）、CoCache（ICS 2026）、Mitigating Dual Load Imbalance（ICDE 2026）等论文，研究覆盖云块存储流量调度、Serverless 数据传递、分离式内存管理等多个方向，是实验室近五年高产线的中坚力量。

### 6. 李涛（在读博士生，2024级）

李涛（Tao Li）以第一作者发表 MinFlow: High-performance and Cost-efficient Data Passing for I/O-intensive Stateful Serverless Analytics（USENIX FAST 2024，录取率约21.5%），解决了 I/O 密集型有状态 Serverless 分析中的高性能数据传递问题，是李永坤代表性的 Serverless 方向成果，并被列为其官方主页代表性论文之一。他目前在读博士阶段继续从事存储与计算协同方向研究。

### 7. 张擎洋（在读博士生，2023级）

张擎洋（Qingyang Zhang）以第一作者发表 Mitigating Resource Usage Dependency in Sorting-based KV Stores on Hybrid Storage Devices via Operation Decoupling（USENIX ATC 2025，录取率约15.8%），并作为共同作者参与 CoCache（ICS 2026）等工作，延续实验室在混合存储设备上 LSM-tree KV 存储优化的主线方向。

### 8. 魏国立（在读博士生，2024级）

魏国立（Guoli Wei）以第一作者发表 DMTree: Towards Efficient Tree Indexing on Disaggregated Memory via Compute-side Collaborative Design（USENIX FAST 2026），该论文获 FAST 2026 杰出工件奖（Distinguished Artifact Award），代表了实验室在 RDMA 分离式内存架构上的最新前沿成果，并得到了与香港大学崔鹤鸣教授等的外部合作支持。

此外，实验室整体培养成果亦十分突出：2020级博士生王一多（师从许胤龙教授、李诚副教授）获2023年度中国科学院院长奖特别奖；实验室学生成果先后入选 SOSP 2023（gSampler、SPFresh）、OSDI 2024（Cuber）、EuroSys 2024（Noctua）、HPCA 2024（Tetris）等系统顶会，形成了高水平人才梯队。据公开资料，实验室毕业生多进入华为、阿里等企业研发岗位及高校任教（如许胤龙教授指导的学生曾获评"阿里星"）。

## 五、业界合作关系深度分析

### 5.1 主要产业合作（华为、PingCAP、阿里等）

据中国科大计算机学院官方介绍，李永坤主持 PingCAP、华为、阿里等企业提供的多项企业合作项目，产业合作是其研究体系的重要支柱：

- **PingCAP**：李永坤的核心研究方向 LSM-tree 键值存储（RocksDB/TiKV 类系统）与 PingCAP 的 TiKV/TiDB 产品线高度契合。其 HashKV（ATC 2018）、ElasticBF（ATC 2019，热点感知的弹性布隆过滤器）、UniKV（ICDE 2020）、DEPART（FAST 2022）、ATC 2025 混合存储 KV 论文等构成了国内最活跃的 KV 存储研究线之一。据百度百科明确记载，"其研究成果在 PingCAP 等企业落地应用"，即实验室的 KV 存储优化技术已进入 PingCAP 生产系统，是其实际产业影响力的直接证据。
- **华为**：合作形式多元。实验室层面获得华为 HIRP（华为创新研究计划）项目支持；李永坤主持"华为-中国科学技术大学计算网络联合创新项目"（见其学院科研列表）。其 ATC 2021 论文 Differentiated Key-Value Storage Management 与 ICDE 2020 论文 UniKV 的合作者（刘振、崔秋、刘璐/汤璐等）据论文署名推断来自华为研发团队，涉及云存储 KV 系统的差异化 I/O 管理，直接面向华为云存储/数据库产品需求。
- **阿里巴巴**：主持阿里提供的合作项目；实验室多篇云缓存与调度论文（HPUCache IWQoS 2022、ICPP 2022 图分析论文）的合作者（陈飞、王鹏程、韩磊等）据署名推断来自阿里体系；此外实验室（许胤龙组）学生曾获"阿里星"（阿里顶级校招人才计划），形成人才输送与科研合作的双重联系。
- **腾讯**：2015年获 CCF-腾讯犀牛鸟基金，并获优秀奖（当年全国仅少量团队获评），这是其早期业界合作的开端。

### 5.2 产学研与创业孵化

- **专利布局**：作为主要发明人持有/申请"键值数据库内布隆过滤器的配置方法""基于分层分配的多层数据库的布隆过滤器构造方法""异构内存架构下基于任务感知的资源分配方法""虚拟机内存动态调节"等多项国家发明专利，实验室整体申请专利近20项，专利方向与其企业合作项目（KV 存储、内存管理）高度对齐，具备明确的转化导向。
- **从论文到产品的研究路线**：其研究呈现出"顶会论文 → 开源系统/专利 → 企业落地"的完整链条。以 KV 存储为例，从 ElasticBF/HashKV 的算法创新，到 DEPART/UniKV 的系统设计，再到 PingCAP 落地，形成了可持续的产学研闭环。
- **人才双向流动**：实验室毕业生大量进入华为、阿里、字节等企业基础软件岗位（详见第三章），同时企业工程师深度参与论文联合发表（ATC/ICDE/IWQoS 等），形成"人才+成果"双通道的产学研生态。
- **孵化与咨询**：据公开资料，暂未发现李永坤本人直接创办或持股公司的记录；其产业影响主要通过联合研究项目、专利转化与人才输送实现，走的是"深度技术合作"而非"自主创业"路线。

## 七、Connection圈层总结

李永坤的学术关系网络呈现典型的"单一强枢纽 + 同心圆扩散"结构：

- **核心圈（导师与师门）**：香港中文大学 John C.S. Lui（吕自成）教授是最核心节点——既是博士导师，又以长江讲座教授身份加盟其所在实验室，Patrick P.C. Lee、谢宏、Helen Chan 等 CUHK 系合作者构成其国际学术根基；其学生谱系（张强、郭帆、汪睿、姚路路、朱文喆、李涛、张擎洋、魏国立等）是该网络中最活跃的产出力量。
- **实验室合作圈**：以 ADSL 实验室为平台，与许胤龙（存储与纠删码、联合指导学生与专利）、吕敏（图计算与内存）、李诚（分布式系统）形成稳定的四教授协作核心，共同支撑国家高性能计算中心（合肥）与安徽省高性能计算重点实验室的科研体系。
- **国内合作圈**：浙江大学何水兵、西安交通大学王平安、广州大学吴思、电子科技大学谢宏、香港大学崔鹤鸣，以及韦恩州立大学 Song Jiang 等散点式合作者，覆盖图计算、持久内存、分离式内存等方向。
- **产业圈**：PingCAP（成果落地）、华为（HIRP + 联合创新项目 + 联合论文）、阿里（合作项目 + 人才输送"阿里星"）、腾讯（犀牛鸟基金）构成完整的国产基础软件产业合作带；企业工程师常态化参与论文发表，是其区别于纯学术型学者的显著特征。
- **人才辐射圈**：毕业生进入华为、阿里等头部企业及闽江学院等高校任教，实验室博士生连续获得中科院院长奖特别奖，人才网络与产业网络相互加强。

总体而言，李永坤是一位以 KV 存储/分布式存储为技术主线、以 CUHK 师门为学术根基、以 ADSL 实验室为组织平台、以华为/PingCAP/阿里为产业支点的"产学研贯通型"学者，其网络结构在国产数据库与云存储基础软件领域具有较高的连接价值。
