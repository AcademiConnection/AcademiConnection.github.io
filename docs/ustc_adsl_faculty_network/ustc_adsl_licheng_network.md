## 二、教育背景与职业履历

李诚的学术路径横跨中国、德国、瑞士与葡萄牙，是典型的"欧洲系统学派 + 工业界研究院 + 回国建制"路线。2005年前后进入南开大学就读，2009年获南开大学计算机科学与技术学士学位。随后赴德国，进入马克斯·普朗克软件系统研究所（MPI-SWS）的 Dependable Systems Group 攻读博士学位，由时任 MPI-SWS 教职的 Rodrigo Rodrigues 指导，并获萨尔大学（Saarland University）联合培养博士学位（2016年）。其博士论文题为《Building fast and consistent (geo-)replicated systems: from principles to practice》，聚焦异地多活（geo-replicated）系统的快速性与一致性权衡。博士期间（2012年）他以第一作者在 OSDI 2012 发表《Making Geo-Replicated Systems Fast as Possible, Consistent when Necessary》（即广受引用的"RedBlue 一致性"工作），并陆续在 ATC 2014、EuroSys 2015（Visigoth 容错）等会议上与导师及里斯本/康奈尔的合作者发表系列成果。

**关于博士导师的考证说明**：其个人主页明确写道"我曾是我在 INESC-ID 的博士导师 Rodrigo Rodrigues 手下的副研究员"，可确认其博士导师为 Rodrigo Rodrigues（先后任职于 MPI-SWS 与葡萄牙里斯本高等技术学院/INESC-ID），而非 Björn Brandenburg（后者虽同在 MPI-SWS，但属实时系统组，与李诚无师生关系）。其博士阶段的重要合作者还包括 MPI-SWS 的 Allen Clement、Viktor Vafeiadis、Pedro Fonseca（时任博士生，后任普渡大学教授）、康奈尔大学的 Johannes Gehrke，以及里斯本 NOVA 大学 / INESC-ID 的 Nuno Preguiça、João Leitão、Daniel Porto 等——这一"分布式一致性"学术谱系构成了他最早的学术圈层。

Comput. 2021（ECR）等一作成果。据公开论文署名信息，其毕业后加入阿里巴巴（参与云原生数据库与存储相关方向的后续合作论文署名，如 ASPLOS 2023 持久内存解耦论文）。

### 4. 林郅琦（微软-中国科大联合培养博士）

林郅琦（Zhiqi Lin）是 ADSL 与微软亚洲研究院联合培养的博士生（2021 级），据微软学术合作官方微博介绍，他在微软亚洲研究院度过了六年时光，师从李诚并接受 MSRA 系统组（缪游山 Youshan Miao、杨懋 Mao Yang 等）联合指导。他以第一作者在 OSDI 2024 发表《nnScaler: Constraint-Guided Parallelization Plan Generation for Deep Learning Training》，并在 HPCA 2024 发表《Tessel: Boosting Distributed Execution of Large DNN Models via Flexible Schedule Search》，此外还有 SoCC 2020《PaGraph》（GNN 训练缓存）、TPDS 2021 等一作成果。nnScaler 相关成果已开源，成为大模型并行化训练计划生成领域的代表性工作。

### 5. 王一多（在读博士生，2020 级）

王一多（Yiduo Wang）为 ADSL 2020 级博士生，主攻分布式文件系统元数据管理。他以第一作者在 SC 2021 发表《Lunule: an agile and judicious metadata load balancer for CephFS》，并以第一作者在 EuroSys 2023 发表《CFS: Scaling Metadata Service for Distributed File System via Pruned Scope of Critical Sections》——后者与百度工程师（曹彪、孙岩、周飞等）合作，相关成果已部署于百度生产环境的 Ceph 集群。王一多因上述工作获 2023 年中国科学院院长奖特别奖（ADSL 官网新闻），并持续参与后续 TOS 期刊扩展及 SOSP 2025 Mantle（与百度、清华合作的云对象存储元数据系统）等研究。

### 6. 许冠斌（在读博士生，2020 级）

### 7. 金泽文（在读博士生，2021 级）

### 8. 龚平（在读博士生，2023 级）

龚平（Ping Gong）为 ADSL 2023 级博士生，是李诚团队近年来产出最高的学生之一。他以第一作者在 SOSP 2023 发表《gSampler: General and Efficient GPU-based Graph Sampling for Graph Learning》，随后以第一作者在 ACL 2025 Findings 发表《HATA: Trainable and Hardware-Efficient Hash-Aware Top-k Attention for Scalable Large Model Inference》，并深度参与 VLDB 2024（GNN 训练特征压缩）、TPDS、TMLR 等多项工作，研究横跨图学习系统与大模型推理加速。

## 五、业界合作关系深度分析

### 5.1 Oracle 经历与国内头部企业合作

**Oracle Labs Swiss（约 2016–2017）**：李诚博士毕业后即加入甲骨文公司在瑞士苏黎世的实验室（Oracle Labs Swiss），任高级技术研究员（Senior Member of Technical Staff）。该实验室以"产学研式工业研究"著称，这段经历为他后来将学术系统研究与企业真实场景结合的风格奠定了基础；公开论文记录中该阶段的直接产出较少，其此后回到导师 Rodrigues 所在的葡萄牙 INESC-ID 任副研究员（2017 年前后），随后回国。

**微软（最深入的产业合作）**：李诚 2019–2020 年入选微软亚洲研究院"铸星计划"并获 2019 年 MSRA 科研合作基金资助，由此开启了与微软体系的长期合作。其形态包括：（1）学生联合培养——林郅琦作为"微软-中科大联合培养博士"在 MSRA 度过六年并产出 OSDI/HPCA 一作论文，刘逸菲（VPTQ, EMNLP 2024；rStar-Coder, NeurIPS 2025）等学生亦深度参与 MSRA 项目；（2）联合研究——与 MSRA 系统组（缪游山、杨懋、杨凡等）及 MSR Redmond DeepSpeed 团队（何雨纵）持续发表 OSDI、SOSP、HPCA、SC、NSDI、ICML、AAAI 等成果；（3）成果开源落地——nnScaler（大模型训练并行化计划生成）、SPFresh（十亿级向量检索原地更新）等均已开源。

**华为**：据 ADSL 官网，实验室获华为 HIRP 项目支持。更深层的人才-技术纽带是其博士生白有辉 2021–2025 年在华为昇腾产品线工作四年，将大模型训推加速技术应用于国产昇腾芯片体系并获多项公司级奖励，2025 年白有辉回校后这一校企通道仍在延续（如面向昇腾生态的开源 CXL 接口库等，据公开社区活动信息）。

**阿里巴巴**：与阿里云 PolarDB 团队合作产出 VLDB 2021 内存解耦云数据库部署、ASPLOS 2023 持久内存解耦等论文（合作者包括曹伟、张英强等）；毕业生陈浩、阮超逸先后加入阿里巴巴，形成"联合研究 + 人才输送"的双向关系。

**百度**：CFS 元数据服务成果（EuroSys 2023）与百度工程师合作并部署于百度生产 Ceph 集群；SOSP 2025 的 Mantle（云对象存储层次化元数据）同样是与百度、清华的联合工作，合作者王一多毕业后仍持续参与百度相关系统研究。

**字节跳动**：据科大新闻，实验室 2026 年获 OSDI 最佳论文的工作由博士生陈泺帆、硕士生王晨晗共同一作完成，字节跳动 Seed 工程师张伟东为共同通讯作者，显示其产业合作版图进一步扩展至字节大模型团队。

**经费面**：据其个人主页，实验室近五年年均科研经费约 50 万美元，来源包括科技部、教育部、国家自然科学基金委、中国科学院、安徽省，以及华为、阿里、百度等企业合作；其个人主持 JKW 智能专项、国自然专项课题、科技部重点研发计划子课题、安徽省科技创新攻坚计划等项目。

### 5.2 产学研与创业孵化

- **平台建设**：李诚兼任合肥综合性国家科学中心人工智能研究院信息计算平台主任，负责面向大模型与智能计算的公共算力与数据平台建设，这使其研究（大模型训练/推理系统）与国家级科学基础设施直接对接，也为实验室获取真实的大规模训练负载与工程验证场景提供了渠道。
- **开源生态**：团队成果 nnScaler、SPFresh、gSampler、VPTQ 等均以开源形式发布，其中 nnScaler 被纳入微软相关开源生态、VPTQ 等 LLM 低比特量化工作被业界广泛使用；团队还参与龙蜥（Anolis）智算生态社区活动（据公开报道，白有辉代表团队发布面向 multi-agent 长上下文管理的开源工作）。
- **技术转化**：代表性落地包括百度生产集群（CFS/Mantle 元数据系统）、华为昇腾产品线（大模型训推加速）、阿里云 PolarDB（内存解耦架构）。
- **创业孵化**：据公开资料，未见李诚本人或其学生主导创办公司的明确记录；其产学研模式以"顶会成果 + 开源 + 头部企业联合落地 + 平台建制"为主，属于学者主导型的产学研路线，而非孵化器型的创业路线。

## 七、Connection圈层总结

**核心圈（师生与实验室内核）**：博士导师 Rodrigo Rodrigues（MPI-SWS→INESC-ID）及其一致性系统谱系（Nuno Preguiça、João Leitão、Allen Clement、Johannes Gehrke 等）是李诚学术身份的"源点"；回国后的核心圈则是 ADSL 内部——许胤龙（25+ 篇合作，实验室学术掌舵人）、李永坤、吕敏、吕自成（港中文讲席教授、ADSL 长江讲座教授）及由学生转型的同事白有辉。这一圈层支撑起实验室"存储 + 分布式 + 大模型系统"三位一体的研究布局。

**学生/梯队圈**：已毕业学生流向清晰——白有辉（华为四年→回校任特任副研究员）、陈浩与阮超逸（阿里巴巴），在读主力林郅琦（微软-中科大联培）、王一多、许冠斌、金泽文、龚平、陈泺帆等持续产出顶会一作论文。学生网络同时是连接下一圈层的"桥"：林郅琦通向微软，阮超逸/陈浩通向阿里云数据库体系，王一多通向百度，白有辉通向华为昇腾。

**产业圈**：微软（MSRA 系统组 + MSR Redmond DeepSpeed，铸星计划起点）为最厚重的产业关系；其次为阿里（PolarDB 联合研究 + 人才输送）、百度（Ceph 元数据系统生产部署）、华为（HIRP + 昇腾人才通道）、诺基亚贝尔实验室（陈瑞川）与字节跳动 Seed（OSDI 2026 最佳论文合作）。产业合作的典型范式是"企业导师 + 联合培养学生 + 顶会论文 + 开源/生产落地"。

**国际学术圈**：保留 MPI-SWS/欧洲一致性学派的血缘（Rodrigues、Vafeiadis、Shapiro），并在存储与智能系统方向与 Xiaosong Ma、Sam H. Noh（UNIST）、Feifei Li（犹他）、Ashraf Aboulnaga（CMU）、崔鹤鸣（港大）、Patrick Lee（港中文）、陈康（清华）等形成稳定的跨国/跨境合作网络。

**总体结构**：李诚的网络呈现"双中心辐射"结构——学术中心在合肥 ADSL（与许胤龙共治），产业中心在微软体系；两条主线通过"联合培养博士"机制交汇。其圈层演进轨迹清晰：欧洲博士圈（一致性理论）→ 甲骨文/葡萄牙工业与学术过渡圈 → 国内实验室建制圈 → 大模型时代的"微软 + 国内云厂商 + 国家科学中心平台"三线并进的产业-平台圈，是中国系统方向青年学者中产学研网络较为完备的典型样本。
