## 五、业界合作关系深度分析

### 5.1 可以确认的“产业相关性”

韩恺主页直接列出推荐系统、社会计算系统、在线广告和金融交易的AI技术作为机器学习与大数据处理应用场景。其论文进一步提供了较强的场景化证据：

- **在线广告与平台经济：** SIGMOD 2021论文研究社交广告中的收益最大化；WWW 2023论文研究带次模目标的收益最大化定价。这说明其机制设计与优化算法已针对广告市场/平台资源分配问题建模。
- **社交网络与推荐：** TKDE 2020的在线社交网络种子选择、ICDE 2022的大规模在线社交网络影响力最大化，以及会话推荐相关的TKDE/TOIS论文，构成从图扩散、营销投放到推荐系统的应用链。
- **众包与隐私：** TON/TMC/MobiHoc系列论文涉及移动众包定价、质量感知定价、预算约束、差分隐私机制，具备面向平台型众包系统的直接问题意识。
- **金融交叉潜力：** 主页将金融交易列为AI技术应用方向；上财的新机构环境也提供金融数据与计算经济学交叉条件。但公开材料没有给出某家金融机构的具体联合研究、数据合作或横向项目名称，故只能表述为“研究主题与机构环境形成潜在接口”。

### 5.2 直接产业合作与人才流动应严格区分

原苏大官方履历提及学生进入华为、百度、字节跳动、网易、拼多多、招商银行等单位。这是**人才培养网络**的高可信历史自述，不是这些企业与韩恺本人存在直接项目合作的证据。针对“直接产业合作”，本报告仅能确认原单位履历所称其曾承担国家自然科学基金重点、面上、青年项目及科技部科技创新2030—“新一代人工智能”重大项目；公开检索未获得足以核实的企业委托项目名称、经费、合同主体、联合实验室或企业共同作者清单。

因此，关系深度可分为：

| 层级 | 判断 | 结论 |
|---|---|---|
| 研究问题与产业场景 | 在线广告、推荐、社交网络、众包、金融交易均在个人主页或论文中可见 | 深度较高，属“算法面向产业场景” |
| 学生就业连接 | 多家互联网、通信与金融企业被原单位履历列为毕业去向 | 中高，属“人才网络”，非合同合作 |
| 企业共同研发/横向项目 | 未发现可公开交叉确认的项目名称、企业单位或成果归属 | 不宜认定；证据不足 |
| 上财财经交叉落地 | 主题高度契合，但加入时间短且未见公开项目材料 | 处于可观察阶段，不能提前定性 |

特别说明：网络检索中出现一篇关于“北京理工大学重庆创新中心负责人韩恺”的产业化报道，但其单位、职业履历与本报告对象不符，属于同名异人，已排除，不纳入任何产业合作判断。

## 七、Connection圈层总结

韩恺的关系网络可概括为“中科大教育与任职根系—新加坡国际合作节点—苏州大学学生与青年学者延展—上财ITCS财经交叉新接口”的四层结构。

1. **第一圈层：长期研究与培养核心。** 崔爽等由个人主页标注的独立指导学生，及贺煌、唐杰、唐少杰、罗俊等在多个年份、多个主题持续共著的研究者。该层的特点是合作连续、主题稳定、论文证据密集。
2. **第二圈层：方法—应用桥接者。** 肖晓奎、黄珂珂、Aixin Sun、Andrew Lim、Çigdem Aslay、Laks V. S. Lakshmanan等合作者，把次模优化与影响力最大化、图数据管理、社交广告和机制设计相连。此层的关系以论文共著为依据，不统一假定其行政或项目隶属关系。
3. **第三圈层：学生与校友扩散网络。** 原单位公开履历所示，学生去向覆盖海外高校和互联网、通信、金融、科研机构。它体现人才培养的外溢能力，但应与“教授本人直接产学研合作”严格区分。
4. **第四圈层：上财/ITCS新建网络。** 现任组织归属明确，但公开共著或共同项目仍不足以勾勒稳定的校内合作图。最值得持续观察的方向是计算经济学、算法机制设计、金融交易AI、推荐/广告与社会计算的交叉落地。

**总体判断。** 韩恺的网络优势在于把有理论保证的组合优化、在线算法与机制设计，持续嵌入社交网络、广告、推荐和众包等大规模数据场景；其学生培养链条进一步增强了这一网络的延续性。对上财ITCS而言，他带入的是已有国际与跨机构共著基础、长期学生培养经验以及算法经济学应用连接。对于尚无公开材料支撑的导师姓名、企业合同合作、上财校内共同项目与具体兼职届次，本报告均保留为“公开资料未披露”或“证据不足”，不作推断性补全。
