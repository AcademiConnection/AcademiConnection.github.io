## 七、Connection圈层总结

Jannik Peters的学术关系网络以**计算社会选择（Computational Social Choice）**为核心轴线，呈现出清晰的"学术师承—博后流动—独立建网"三层结构：

**第一圈层（师承与指导关系）**：
- 博士导师 **Markus Brill**（柏林工业大学→华威大学→牛津大学）：这是Jannik Peters最核心的学术关系，二人合著论文超过7篇，涵盖比例性公理、多赢家投票、参与式预算等方向。Markus Brill本身师承Felix Brandt（慕尼黑工业大学）并曾在Vince Conitzer（杜克大学）、Edith Elkind（牛津大学）处做博士后，属于计算社会选择领域的重要学术传承链。
- 博士后合作导师 **Warut Suksompong**（NUS）：Jannik Peters在新加坡国立大学从事博士后研究期间与Suksompong合作3篇以上论文，涉及审批制投票、比例性委员会重构等方向。Suksompong是亚洲计算社会选择领域的重要学者。

**第二圈层（高频合作者）**：
- **Chris Dong**（4篇以上）：比例性多赢家投票方向的核心合作者。
- **Haris Aziz**（UNSW）：审批制投票方向的知名学者，合作2篇以上。
- **Edith Elkind**（牛津大学）：时序投票方向合作者，计算社会选择领域顶尖学者。
- **Niclas Boehmer**、**Leon Kellerhals**、**Nicholas Teh**、**Anton Baychkov**等：多次合作者，构成稳定的研究合作圈。

**第三圈层（ITCS内部网络）**：
- Jannik Peters加入上海财经大学ITCS后，尚未在公开论文记录中出现与ITCS同事的合著论文。但其研究方向（计算社会选择、算法博弈论）与ITCS多位教师存在交叉，特别是与Pinyan Lu（Algorithmic Game Theory）、Zhihao Tang（Algorithmic Game Theory）、Fu Hu（Mechanism Design, Pricing and Game Theory）的研究兴趣高度互补，未来形成内部合作网络的潜力较大。

**国际化特征**：Jannik Peters的合作网络覆盖德国（博士阶段与早期论文）、英国（导师Brill转任牛津后维持合作）、新加坡（博士后阶段）、澳大利亚（Aziz）、法国（Dominik Peters同行）等多国机构，体现了计算社会选择这一领域天然的国际协作属性。其从欧洲（德国）到亚洲（新加坡→中国）的地理流动轨迹，也使其成为连接欧洲计算社会选择学界与亚洲（尤其中国）学术界的重要桥梁型学者。

**学术影响力**：截至2026年，Jannik Peters在DBLP上可检索到67条论文记录，涵盖AAAI、ACM-EC、ICML、NeurIPS、AAMAS、IJCAI等计算机科学顶级会议，以及Social Choice and Welfare等社会选择领域权威期刊。2022年获AAAI杰出论文奖（独著论文），表明其在匹配理论方向具有独立的原创性贡献能力。加入ITCS后，其2025–2026年的发表依然保持高产（2025年5篇以上、2026年6篇以上），研究方向持续聚焦于比例性表示、多赢家投票、度量畸变等计算社会选择核心议题。
