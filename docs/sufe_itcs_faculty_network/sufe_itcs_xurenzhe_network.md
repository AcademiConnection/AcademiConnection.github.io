## 二、教育背景与职业履历

### （一）教育背景

徐韧喆的教育背景为典型的"清华本博直读"路径，且本硕博均在清华大学计算机科学与技术专业。

- **崔鹏**：清华大学计算机系教授、清华大学媒体与网络实验室负责人，国家杰出青年科学基金获得者，研究方向涵盖因果推断、稳定学习、分布外泛化、图表示学习与社会网络挖掘，是国内"稳定学习/因果机器学习"学派的代表人物之一。崔鹏组是国内 OOD 泛化与因果 ML 领域的高产出实验室，孵化了 NICO/NICO++ 等知名基准数据集。
- **李博**：清华大学经济管理学院管理科学与工程系长聘副教授（统计与数据科学方向）。2002 年北京大学数学系学士，2006 年加州大学伯克利分校统计学博士（导师为著名统计学家 Peter Bickel），2006 年起任职清华经管。研究方向为数据驱动决策、因果推断、机器学习与经济学交叉。李博与崔鹏组有长达十余年的稳定合作关系，是崔鹏组在"因果推断/异质性处理效应"方向上的关键合作 PI，并因此成为徐韧喆的联合导师。

两位导师的搭配决定了徐韧喆的研究底色：崔鹏赋予其机器学习与因果稳定学习的方法论训练，李博赋予其统计推断与经济学的理论视角——这正是其日后转向"算法博弈论 × 平台经济学"的伏笔。
