## 二、教师的角色定位

**ITCS创始人与学术家族始祖：** 陆品燕教授是ITCS的灵魂人物。他1982年出生于浙江平湖，2009年在清华大学获得计算机博士学位（师从图灵奖得主姚期智），随后在微软亚洲研究院(MSRA)理论组工作六年（2009-2015），历任副研究员、研究员、主管研究员。2015年12月，他放弃了MSRA的稳定职位，全职加入上海财经大学——一所此前几乎没有理论计算机科学传统的财经类高校——从零开始创建ITCS。这一决定在当时颇具远见：仅用五年时间，ITCS就在CSRankings算法与复杂性及计算经济学方向排名亚洲第一、世界前十，在STOC/FOCS/SODA三大顶会发表论文近30篇。陆品燕本人的学术贡献横跨#P问题分类定理、全息算法、近似计数和算法博弈论，获2019年ACM杰出科学家奖和ICCM数学奖银奖。他还在2017年创建了华为TCS Lab并任创始主任，是理论计算机科学在国内产业界落地的重要推动者。2024年12月，他以ITCS为核心成立了计算机与人工智能学院并出任院长，标志着ITCS从研究中心向完整学院建制的升级。

**MSRA系教师与算法博弈论核心：** Nick Gravin教授（俄罗斯籍，IMO金牌）是ITCS仅次于陆品燕的核心成员。他在NTU读博期间即为陆品燕在MSRA的实习生，博士毕业后在MSR New England和MIT做博士后，随后被陆品燕招募到ITCS。他的研究方向涵盖算法博弈论、凸离散几何和在线学习，是ITCS在机制设计和拍卖理论方向的核心力量。伏虎副教授（Cornell博士，导师Robert Kleinberg）的路径则更为国际化——他曾在MSR New England和Caltech做博士后，2016-2020年在UBC任助理教授，约2020年加入ITCS。伏虎的研究聚焦机制设计和在线算法，他的加入为ITCS补充了来自北美顶尖学府的理论深度。二人加上陆品燕和唐志皓，构成了ITCS在算法博弈论方向的"四核心"格局。

**国际青年学者集群：** 唐志皓（港大博士，导师T.-H. Hubert Chan，北大本科）现为ITCS长聘副教授兼计算机与人工智能学院副院长，是ITCS在线算法和算法博弈论方向的多产学者，在JACM发表论文2篇、STOC/FOCS各3篇，三次获得最佳论文奖（FOCS 2020、AAMAS 2024、IJTCS-FAW 2023）。郭子超（港中文博士，IMO/IOI双银牌）的研究横跨图谱理论和算子理论，他的加入为ITCS拓展了纯理论方向。陶一馨（NYU Courant博士，导师Richard Cole，上交大ACM致远班本科）和贺烈（EPFL博士，导师Martin Jaggi，中科大本科）分别从LSE和腾讯/EPFL来到ITCS，前者专注公平分配和资源分配，后者专注随机优化和机器学习——贺烈的加入标志着ITCS从纯理论向理论+机器学习交叉方向的拓展。韩恺教授（中科大博士，少年班校友）于2025年9月从苏州大学特聘教授转入ITCS，是团队最新的正教授级成员，研究方向涵盖次模优化、机制设计和社交网络分析。Jannik Peters（柏林工业大学博士，导师Markus Brill）是ITCS在计算社会选择方向的代表，其独著论文获AAAI 2022 Distinguished Paper Award。

**陆品燕学术家族的下一代：** 徐韧喆（清华大学博士，导师李博）是ITCS最年轻的助理教授之一，他的研究方向跨越算法博弈论和机器学习（特别是OOD泛化与稳定学习），此前在清华崔鹏组接受训练。陆品燕培养的已毕业学生中也有多人已成为教师或在产业界担任要职，如Chihao Zhang（张驰豪，上海交通大学副教授）、金耀楠（Yaonan Jin，Columbia University博士后/华为TCS Lab核心研究员），他们虽不在ITCS现任名单中，但在各报告中被提及为陆品燕学术家族的重要枝蔓。

## 三、团队关系网络的整体观察

**1. "姚期智→陆品燕→ITCS"学术传承链与MSRA理论组经历是团队最核心的学术身份标识。** 陆品燕作为图灵奖得主姚期智在清华的嫡系博士生，继承了理论计算机科学的核心学术传统。2009-2015年在MSRA理论组的六年经历则是他学术生涯的第二关键阶段——MSRA不仅为他提供了工业界的研究环境，更让他培养了一批实习生（其中多人后来成为各高校骨干），形成了"MSRA理论组→ITCS"的人才管道。这一"清华—MSRA—上财"的独特路径使ITCS在创建之初就拥有了远超普通新建研究中心的学术和人脉资源。

**2. ITCS是中国高校中高度国际化、多国学者汇聚的理论计算机研究团队。** 11位现任教师中，3位为外籍或境外学者（Nick Gravin为俄罗斯籍，Jannik Peters为德国籍，郭子超为中国香港籍），其余教师也多有海外博士或博士后经历——康奈尔、港大、港中文、NYU Courant、EPFL、NTU、柏林工大等。这种高度国际化的人员构成在国内理论计算机科学领域非常少见，与陆品燕本人在MSRA和MSR New England建立的国际合作网络直接相关。团队中多位教师（陆品燕、伏虎、Gravin）都与微软研究院体系有直接关联，形成了"微软研究院系→ITCS"的人才迁移路径。

**3. 算法博弈论是ITCS的最大公约数，但团队的研究版图正在从纯理论向"理论+机器学习"交叉方向拓展。** 在陆品燕、Gravin、伏虎、唐志皓、陶一馨五人的研究中，算法博弈论、机制设计、在线算法构成了一个高密度的主题簇。但近年来新加入的贺烈（机器学习优化）、徐韧喆（机器学习+博弈论）、韩恺（次模优化+社交网络）等人的研究方向已明显向ML方向倾斜。特别是2024年12月计算机与人工智能学院的成立，标志着ITCS正在从纯理论计算机科学研究中心向涵盖AI理论的更广领域拓展。陆品燕本人也在2025年与至知创新研究院（九坤投资）共建了大模型联合实验室，这是ITCS向AI应用领域延伸的重要信号。

**4. 产学研合作模式独特，以"华为TCS Lab"为核心构建了理论计算机科学与产业界的桥梁。** 陆品燕于2017年创建华为TCS Lab并任创始主任，这是国内极少数由企业资助的理论计算机科学实验室之一。TCS Lab不仅资助理论研究，还通过实习生网络将MIT、UCB、北大等顶尖高校的学生与华为连接起来。金耀楠（陆品燕指导的学生）是TCS Lab的核心研究员。除了华为，陆品燕还与蚂蚁金服/万向区块链在区块链+博弈论方向有合作，并在2025年与至知创新研究院共建大模型联合实验室。伏虎也与Google Research（广告拍卖方向）、微软研究院有直接合作。这种"企业TCS Lab+直接产业合作+学生网络辐射互联网平台"的三层产学研模式是ITCS区别于纯学术型理论研究中心的显著特征。

**5. 交叉验证过程中发现的人名拼写讹误问题值得注意。** 由于11份报告由不同的subagent独立撰写，本次交叉核查中发现并修复了大量人名拼写错误——最典型的是陆品燕的名字在多份报告中被误写为"陆品岩""陆品言""陆品彦"等多个错误变体（约25处），徐韧喆的名字在全文件中被误写为"许仁哲"（约25处），以及多名同事的姓名在他人报告中被误写（如"伏虎"被写作"傅湖""傅羽""傅昊"，"唐志皓"被写作"唐志昊""唐志浩"，"陶一馨"被写作"陶一心""陶忻昕""陶一新"，"韩恺"被写作"韩凯"，"王晓"被写作"王骁"等）。此外还发现Bundit Laekhanukit被误列为现任ITCS成员的问题。这些错误均已修正，但提示在使用本报告集数据时需注意人名准确性。
