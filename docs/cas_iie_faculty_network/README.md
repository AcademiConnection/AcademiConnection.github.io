# 中科院信息工程研究所 学术关系网络报告

## 团队简介

本报告集涵盖中国科学院信息工程研究所（IIE CAS）核心研究人员的学术关系网络。信工所成立于2011年，是中国科学院直属科研机构，拥有网络空间安全防御全国重点实验室（前身为信息安全国家重点实验室）、信息内容安全国家工程研究中心等国家级科研平台。全所929名在职职工，109名研究员级研究人员，是国家网络空间安全领域的战略科技力量。

本报告聚焦信工所密码理论、体系结构安全、数据安全、多媒体安全等核心方向的关键研究人员，并纳入曾任信工所总工/副所长、现国科大密码学院院长荆继武教授。

## 团队架构

信工所以郭莉所长为行政核心，侯锐副所长（兼全国重点实验室主任）为科研领军，林东岱研究员为密码学学术带头人（中国密码学会副理事长），赵险峰研究员为多媒体安全方向带头人。荆继武教授虽已转任国科大密码学院院长，但作为信工所首任总工程师，其学术传承（师从曾肯成教授）对信工所密码学方向的奠基性贡献不可忽视。

林东岱研究员本科毕业于山东大学数学系（1980-1984），与王小云院士同校同期，是连接信工所与山大密码团队的自然纽带。
