# 学术关系网络

本网站汇集高校与研究实验室教师的学术关系网络调研资料，重点呈现学者的教育与职业履历、师承谱系、合作者、团队培养体系及产学研合作情况。

资料按“高校 / 实验室 → 教师个人报告”两级组织。可通过上方导航或以下入口进入各机构总览；每份机构总览均提供对应教师的完整报告链接。

## 使用说明

本站内容主要基于公开资料整理，涵盖院系和实验室官网、学者个人主页、DBLP 作者记录、论文及公开报道。部分学者可能存在同名、职业履历更新或公开资料不完整等情况；如发现需要修订之处，请以学者及所属机构的最新公开信息为准。
