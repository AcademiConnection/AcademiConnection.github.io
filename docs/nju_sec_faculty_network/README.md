## 全团队关系网络的整体观察

南大网安方向呈现"双轨并行"格局。其一是仲盛领导的COSEC（网络与信息安全实验室，建制在软件学院）：仲盛本人是耶鲁大学2004年博士（UIUC/杜克的流传说法不实）、布法罗NSF CAREER经历，回南大后形成了以许封元（威廉玛丽学院博士、NEC Labs研究员经历，合作53次）、毛云龙（36次）、张媛（52次）等为骨干的国际顶会路线团队，研究覆盖安全多方计算、AI安全与区块链；许封元的导师Qun Li（威廉玛丽学院）与仲盛的长期合作，构成"仲盛—Qun Li—许封元"的师承三角。其二是谢俊元代表的本土工程路线：1986年南大硕士毕业的他在入侵检测、防火墙等方向的成果主要发表于中文期刊与工程项目，与COSEC无直接共同论文；但其另一重身份——IIP智能信息处理组（与王崇骏合作55次）及2011年创立的南大中德HPI研究院——使其成为南大对德学术合作与智能化软件方向的枢纽。两人与谢磊（CCF南京现任主席）等的交叉，使网安、IIP与Dislab三个圈子在南大计算机学科内部形成错综的同事网络。

三人之间的一个结构性事实是：谢俊元与仲盛、许封元之间无DBLP直接共同论文记录，"同城不同轨"；而仲盛—许封元的53次合作是本组最紧密的学术纽带。
