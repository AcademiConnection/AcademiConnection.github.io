## 二、教育背景与职业履历

薛广涛1994年9月至1998年7月就读于上海大学计算机软件专业（本科），1998年9月至2001年2月于上海大学攻读计算机组织与系统结构专业硕士，2001年3月至2004年6月于上海交通大学攻读计算机软件与理论专业博士并获工学博士学位（2004年9月授位）。其博士导师的姓名公开资料未明确披露；不过其学术轨迹显示，他与李明禄教授（原交大网络与服务计算研究所、现任浙江师范大学杰出教授）自早期起保持长期紧密的科研合作与共同指导关系。

职业履历方面，薛广涛2004年9月留校任计算机系讲师，2008年1月升任副教授，2016年1月起任教授。其间三次外出访学：2005年香港理工大学、2009年香港科技大学、2013年3月至2014年3月国家公派赴美国德克萨斯大学奥斯汀分校（UT Austin）访问——UT Austin之行对他影响深远，此后与该校Lili Qiu教授团队建立了持续多年的高产合作。行政路径上，他2016年4月至2024年1月担任电院副院长（曾代表学院出席交大-华为操作系统专项班捐赠签约暨开班典礼等活动），2023年12月至2025年1月转任计算机系党总支书记，2024年3月起出任上海市Web3可信数据流通与治理重点实验室主任，2025年1月起任上海交通大学网络信息中心主任。2023年前后，他从原"网络与服务计算研究所"归入计算机学院重组后的智能软件与系统研究所（学院官网该所[组织成员](https://www.cs.sjtu.edu.cn/yjjg/805.html)将其列于首位，成员还包括李颉、曹健、陈奕超、陈雨亭、吴晨涛、娄炯、潘昊、钱诗友、俞嘉地、杨岚青、黄林鹏、陈游旻、徐尔茨、薛栋梁、张一鸣、钟浩、沈艳艳、林云、刘盛云等）。

在科研选题上，薛广涛的研究呈现清晰的演进脉络：早期（2005—2015）以无线网络优化、车载自组织网络、智慧城市数据活化与传感器网络产业化为主；中期（2016—2020）转向移动群智感知与物联网智能感知（联邦学习、移动安全感知）；近年（2021年至今）一方面在系统方向深耕云存储故障检测（FAST/ATC）、分布式系统稳定性，另一方面依托上海市Web3重点实验室向数据流通与治理、区块链方向扩展，与李颉形成方向互补。

## 三、学生培养情况

### 1. 鲁瑞明（博士生，直接指导）

鲁瑞明系薛广涛与李明禄共同指导的博士生，其论文"Perseus: A Fail-Slow Detection Framework for Cloud Storage Systems"获[USENIX FAST 2023最佳论文奖](https://news.sjtu.edu.cn/jdyw/20230303/179470.html)，系国内首次获此殊荣；该工作与阿里云合作完成，提出了一种适用于大规模数据中心的非侵入式、细粒度慢盘检测框架。其后续去向公开资料未详细披露。

### 2. 潘昊（2022届博士，直接指导/联合指导）

潘昊为计算机系2022届博士，导师为薛广涛教授与陈奕超副教授（[交大新闻](https://news.sjtu.edu.cn/jdyw/20230207/178740.html)），博士论文获上海市计算机学会优秀学位论文奖；研究方向为电磁旁路信道、摩尔纹安全通信与视觉增强，代表成果包括MagneComm+（近场电磁感应通信）、ScreenID（屏幕亮度特征的二维码安全）、DoCam、OISSR等。毕业后其任职去向公开资料未详细披露（现亦列为智能软件与系统研究所成员）。

### 3. 丁典（2023届博士，直接指导）

丁典2023年8月答辩，博士论文《基于人体电容旁路信道的智能感知技术研究》，导师为薛广涛教授（[答辩公告](https://www.seiee.sjtu.edu.cn/xzzx_notice_yjs_cat7/8938.html)），研究内容涵盖基于人体电容的用户身份认证、手势识别与行为嗅探；答辩委员会由李明禄、曹健等教授组成。其代表论文包括Handpad（UIST 2024）、LeakThief（SECON 2023）等。

### 4. 其他学生（审慎表述）

## 四、学术合作网络

### 4.1 研究所内部（智能软件与系统研究所及原网络与服务计算所）

薛广涛的核心校内合作者群体呈"老中青"结构：资深层为李明禄（长期合作者、鲁瑞明共同导师，现任浙师大杰出教授）与曹健（服务计算方向长聘教授）；中生代为陈奕超（UT Austin博士，2018年加入，与其联合指导潘昊，共同产出大量移动感知论文）、俞嘉地（移动计算）、纪尧（系统安全）、吴晨涛（存储与区块链）；青年层为娄炯、潘昊、钱诗友、曾鸿鸿（博士后）等。他与讲席教授李颉的搭档关系尤为关键：两人在ESFL联邦学习投毒检测、V2PCP充电桩交易、面向数据智能的分级存储（2025年度上海市计算机学会科学技术奖）等工作中联合署名，并在上海市Web3重点实验室形成"薛广涛任主任、李颉任首席科学家"的领导班子，共同支撑起交大Web3/区块链方向的学术与组织架构。

### 4.2 跨机构合作（国内）

与清华大学存储方向（舒继武团队，PERSEUS、ATC 2022 NVMe现场故障分析、ToS对象存储迁移等论文合作）；与中南大学任炬（Ju Ren）在移动安全感知方向合作（Magspy、GPMS等）；与上海电力大学等电力行业院校保持学术交流（曾出席"智能计算与智能电网"研讨会并作学会层面致辞，提出新一代信息技术与新型电力系统结合的联合攻关方向）。

### 4.3 国际合作

与美国UT Austin的Lili Qiu教授团队是合作最紧密的国际伙伴——2013—2014年公派访问后，双方联合在MobiCom（PMSat、GPMS）、NSDI（Acoustic Sensing with Metasurface）、ToN/TMC等发表论文十余篇，Lili Qiu团队的Hao Pan、Yi-Chao Chen（后者后全职加入交大）均深度参与。此外与香港理工大学（2005访问）、香港科技大学（2009访问）保持早期合作联系。

## 五、业界合作关系深度分析

薛广涛的产业合作横跨云存储、操作系统、电力与物联网多个板块，且与其行政职务形成叠加：

1. **阿里云（云存储）**：PERSEUS慢盘检测框架系交大与阿里云共同提出并在大规模数据中心部署验证（[交大新闻](https://news.sjtu.edu.cn/jdyw/20230303/179470.html)）；ATC 2022的NVMe SSD现场故障研究亦有产业界作者参与。其2022年上海市技术发明一等奖"面向多云协同的智能数据平台关键技术与应用"（第一完成人）亦属云与数据平台方向的应用成果。
2. **华为（操作系统与异构计算）**：主持"上海交通大学-华为下一代异构并行操作系统联合实验室"（2022—2026）及"CPU-GPU-DPU融合架构研究和统一编程接口设计"等委托研发项目（见[科研项目列表](https://faculty.sjtu.edu.cn/xueguangtao/zh_CN/kyxm/150553/list/index.htm)）；任电院副院长期间参与推动交大-华为操作系统专项班的人才联合培养。
3. **电力行业（物联网+电网）**：主持国网福建电科院"面向电网复杂场景的'感-智'两体协同与主动运维技术研究"（2026—2027）等项目，研究方向与新型电力系统深度结合。
4. **存储与数据产业生态**：作为主要完成人（与吴晨涛、李颉等）获2025年度上海市计算机学会科学技术奖的"面向数据智能的分级存储关键技术与应用"，完成单位包括上海霄云信息、浪潮数据、星环科技、方一信息、忆恒创源等存储产业链企业（[交大新闻](https://news.sjtu.edu.cn/zhxw/20260329/220922.html)）。
5. **地方政府与园区**：主持"上海交大-紫竹高新区"材料化工和生农医药概念验证中心项目（2025—2027）；早年主持工信部"低功耗传感器网络系列节点、网关设备的研制与产业化"重大专项（2010—2014）及863智慧城市一期/二期课题，成果面向城市级物联网落地。
6. **学术组织枢纽**：作为上海市计算机学会副理事长兼秘书长，长期主持学会年度活动与专委会生态，是上海地区产学研交流网络的组织性节点（如计算机视觉专委会2025学术年会、WAIC相关活动等）。

## 七、Connection圈层总结

薛广涛是交大计算机系本土成长、以学术与行政双线并进的"枢纽型"学者：学术上从物联网/移动计算起家，经UT Austin访问后与Lili Qiu团队建立长期国际合作，近年以FAST/ATC等系统方向顶会最佳论文跻身分布式存储与感知系统一线；行政上先后执掌电院副院长、计算机系党总支书记、网络信息中心主任等要职，同时以上海市计算机学会秘书长的身份运营上海学术共同体。其合作网络的三条主线清晰可辨：**校内主线**是与李颉的Web3重点实验室搭档及与陈奕超、俞嘉地、吴晨涛、李明禄等构成的研究所内部协作网；**产业主线**是阿里云（云存储）、华为（操作系统/异构计算）、国网系统（电力物联网）及存储产业链企业的多板块产学研布局；**学生主线**上已确认的直接指导弟子包括鲁瑞明（FAST最佳论文）、潘昊、丁典等，联合指导与合作署名的青年学者群体（娄炯、钱诗友、李亦杰、陆宇等）则构成了研究所的梯队储备。他与李颉的组合是理解交大智能软件与系统研究所当前版图的关键入口。
