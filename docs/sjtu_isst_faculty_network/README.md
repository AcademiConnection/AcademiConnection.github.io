# 上海交通大学 智能软件与系统研究所 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

智能软件与系统研究所是上海交通大学计算机学院下设研究所，所长为薛广涛特聘教授（上海市Web3可信数据流通与治理重点实验室主任、校网络信息中心主任），副所长为陈榕，成员包括李颉、曹健、黄林鹏、吴晨涛、陈雨亭、薛栋梁、钱诗友、郑圣安等。研究所覆盖智能软件工程、服务计算、分布式系统与存储、物联网与智能感知、区块链/Web3、数据治理等方向，是计算机学院"软硬兼顾"格局中软件与系统侧的主力建制之一；与 IPADS（并行与分布式系统，见 [sjtu_ipads_faculty_network](../sjtu_ipads_faculty_network/)）、可扩展计算研究所（见 [sjtu_sce_faculty_network](../sjtu_sce_faculty_network/)）为并列协作关系。

研究所的两张名片是"Web3/区块链"与"存储与内存计算"：前者由薛广涛（主任）与日本工程院外籍院士、IEEE Fellow 李颉讲席教授（首席科学家）领衔，依托上海市Web3重点实验室和校级区块链研究中心，网络覆盖斯雪明、骆源、孔令和、李建华等跨院系学者；后者以黄林鹏特聘教授（863内存计算首席专家、Intel-SJTU持久内存联合实验室）为代表，与吴晨涛存储团队共同构成"面向数据智能的分级存储"（2025年度上海市计算机学会科学技术奖）的完成班底。服务计算方向由曹健长聘教授（摩根士丹利金融服务计算创新中心主任）承接张申生 CIMS/工作流传统。2024年11月从华为入职的张一鸣特聘教授（国防科大博士、CCF优博、前华为2012实验室高级专家、阿里达摩院Fellow）则为研究所注入分布式存储与系统方向的产业级力量。

## 圈层结构概述

研究所网络呈现"双带头人+多谱系汇流"结构。李颉（日本筑波大学教授回国）与薛广涛（本土成长、历任电院副院长）构成 Web3 实验室"首席科学家+主任"双核，联合署名 ESFL、V2PCP、分级存储等成果，并通过校级区块链研究中心将网络与密码学研究所骆源、先进网络研究所孔令和、网安学院李建华、斯雪明院士等纳入同一平台。曹健承接上海交大 CIMS 与工作流的"张申生传统"，以服务计算和金融科技（摩根士丹利创新中心）延伸至产业界。黄林鹏的 DDST 实验室代表存储与内存计算一脉，学生郑圣安（2019届博士、清华博后）留校后晋升长聘教轨副教授（现属先进人工智能研究所），形成"DDST—郑圣安课题组"一老一青的融合团队。张一鸣带来国防科大分布式计算学派（卢凯、李东升）与华为/阿里产业履历的双重网络，与薛广涛多年联合发表（Perseus, FAST 2023 最佳论文）并连接清华舒继武团队。产业网络覆盖阿里云（PERSEUS 慢盘检测部署）、华为（异构并行操作系统联合实验室）、Intel（持久内存联合实验室）、摩根士丹利（金融计算）、国网福建电科院及霄云、浪潮、星环等存储产业链企业。需要澄清的边界：李颉无"NTT 长期任职"与"IEEE Life Fellow"的公开依据；黄林鹏并非区块链安全方向、不属谷大武密码学团队；张一鸣与字节跳动创始人同名但为不同人。
