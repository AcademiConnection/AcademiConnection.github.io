## 二、教育背景与职业履历

曹健2000年3月于南京理工大学获得博士学位（博士导师公开资料未披露，博士论文曾被评为南京理工大学优秀博士论文，攻读期间获该校董事会基金奖特等奖），同年进入上海交通大学计算机系从事博士后研究，2002年1月出站后留校任副教授，2007年晋升教授，后获聘长聘教授。博士后期间及留校初期，他与上海交大计算机集成制造（CIMS）领域的[张申生教授](http://www.wanfangdata.com.cn/details/detail.do?_type=perio&id=jsjjczzxt200104004)长期合作，在《计算机集成制造系统-CIMS》等刊物联名发表协同产品开发约束模型、Agent与工作流集成技术等论文（如2001年《支持协同产品开发的约束模型研究》、2004年《基于服务的Agent与工作流集成技术研究》），这段经历奠定了其在工作流与协同信息系统方向的研究基础——任务线索中"孙永强团队传承"的说法未见公开资料支持，可确认的学术传承脉络是与张申生团队的博士后合作。任职期间多次赴美国斯坦福大学任访问学者。

其研究从早期的工作流/协同计算逐步演进为"服务计算+智能数据分析"双主线：主持国家自然科学基金项目6项、国家重点研发计划课题2项、863计划课题2项、上海市科委重点项目2项及企业横向课题30余项。研究方向细化为：智能数据分析与决策支持（个性化推荐、AIOps、医疗/旅游/金融行业应用）、服务与网络计算（智能服务流程管理、服务协同）、协同与社会计算（智能流程管理、开源软件协同），近年又扩展到基于大语言模型的业务流程异常检测与推荐等前沿方向（AAAI 2025多篇论文）。

## 三、学生培养情况

### 1. 钱诗友（CIT实验室副主任、上海交通大学副研究员）

钱诗友现任CIT协同智能技术实验室副主任、上海交通大学副研究员，研究方向为数据分发网络中的匹配算法、云计算调度、出租车路径推荐与容器技术。他与曹健自2013年前后起联名发表大量论文（含INFOCOM 2019、TPDS 2021、IEEE TITS 2022等），是曹健课题组论文网络中出现频率最高的合作者之一，两人为"长期论文合作+同事"关系；其博士阶段导师信息公开资料未明确披露。他是曹健近年产出（发布/订阅系统事件匹配、微服务调度方向）的实际执行核心，并作为主要完成人之一参与2025年度上海市计算机学会科技进步一等奖获奖项目。

### 2. 朱能军（博士毕业，现为上海大学教师）

朱能军在曹健指导下从事推荐系统研究，两人联名在TOIS、TKDD、WSDM、IJCAI、ICDM等发表多篇论文（如TOIS 2022"Learning a Hierarchical Intent Model for Next-Item Recommendation"、WSDM 2020论文），是曹健学生谱系中学术产出系统性的代表。现为上海大学教师（据[CIT实验室校友名录](https://cit.sjtu.edu.cn/team)），并作为主要完成人参与上述上海市计算机学会科技进步一等奖项目。

## 五、业界合作关系深度分析

曹健课题组的产学研模式是"金融科技旗舰+行业横向课题"双轮驱动：

- 摩根士丹利：担任上海交大摩根士丹利金融服务计算创新中心主任（据[百度百科](https://baike.baidu.com/item/曹健/3350074)），围绕金融服务计算开展长期合作研发，教授《金融服务计算》研究生课程，其硕士毕业生中有多人入职摩根士丹利。
- 携程（Ctrip）：[CIT实验室合作单位](https://cit.sjtu.edu.cn/)，支撑其旅游个性化服务、出租车轨迹数据分析方向的研究。
- 三星电子：据公开介绍曾开展合作研发。
- 上港集团（SIPG）与港口行业：其港口行业科技进步一等奖及部分上海市科技进步奖与港口物流信息化应用相关。
- 瑞金医院：医疗决策支持与智能治疗方案推荐方向的落地合作方。
- 逐日科技、声通科技：2025年上海市计算机学会科技进步一等奖"服务流程自适应建模与智能管控关键技术及应用"的完成单位，成果在智能客服、政务服务、智慧供应链、金融、智慧园区及大规模服装定制等行业落地，近三年相关应用累计新增产值约25亿元（据[上海交大新闻](https://news.sjtu.edu.cn/zhxw/20260329/220922.html)）。
- 企业横向课题累计主持30余项，国家重点研发计划课题（如事件驱动大规模服务调用与可靠性保障）等亦有产业应用背景。

## 七、Connection圈层总结

曹健的学术关系网络呈现清晰的"三环结构"：内核是CIT实验室（与钱诗友共同执掌），中环是上海交大智能软件与系统研究所（与所长薛广涛、李明禄构成研究所内最紧密的论文合作三角），外环由三类节点构成——以赵海燕（上海理工）、王杰（中科大）为代表的跨校学术合作圈，以Buyya（墨尔本）、Xu（UTS）、熊辉（港科大广州）为代表的国际合作圈，以及以摩根士丹利、携程、上港集团、瑞金医院、声通科技为代表的产业落地圈。其学脉上承张申生的CIMS/工作流一系（博士后合作出身），自身又培养了朱能军（上海大学）等进入高校任教的博士，学生去向高度集中于金融科技与互联网企业。在Connection图谱中，他是连接"服务计算/BPM学术圈—上海本地产学圈—金融行业"的关键枢纽节点。
