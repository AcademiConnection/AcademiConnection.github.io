## 二、教育背景与职业履历

王长波教授的学术生涯起步于武汉理工大学。1995年9月，他进入武汉理工大学攻读学士学位，1999年毕业后继续在该校攻读硕士学位至2002年4月。随后，他考入浙江大学，于2002年9月至2006年3月期间在浙江大学攻读博士学位。王长波在浙江大学期间师从彭群生教授——彭群生是我国计算机真实感图形领域的主要学术带头人之一，浙江大学CAD&CG国家重点实验室的创始人之一，2021年亚洲图形学学会终身成就奖获得者、2022年度国家自然科学奖二等奖获得者。王长波在彭群生指导下从事真实感绘制研究，其博士期间代表性工作包括发表于《计算机学报》的"海市蜃楼现象的真实感绘制"（2006年，与王章野、周麒、彭群生合作），该论文展现了其在自然现象物理建模与真实感渲染方面的扎实功底。

2006年6月，王长波博士毕业即加入华东师范大学软件学院任讲师，正式开启独立学术生涯。2008年10月晋升副教授。2009年12月至2010年12月，他赴美国纽约州立大学石溪分校（Stony Brook University）从事博士后研究，进一步拓展了在国际图形学界的学术视野。石溪分校在计算机图形学领域拥有深厚底蕴，这段经历为其后续的国际化合作奠定了基础。

回国后，王长波在华东师范大学的学术晋升路径清晰且迅速。2012年8月，他破格晋升为教授、博士生导师，并出任软件学院副院长。此后，随着华东师大学科架构的调整，他于2015年10月至2019年7月担任计算机科学与软件工程学院教授、常务副院长；2019年7月至2023年4月转任计算机科学与技术学院教授、党委书记；2023年5月至今任数据科学与工程学院教授、党委书记。这一职业轨迹横跨软件学院、计算机学院和数据学院三大院系，体现了其在学科建设和管理方面的综合能力。

值得特别说明的是，王长波教授并非从上海交通大学调入华东师范大学。他自2006年博士毕业后即入职华东师范大学，至今已在华东师大任教近二十年。他与上海交通大学的紧密联系主要源于学术合作关系——特别是与上海交通大学马利庄教授团队的深度合作。马利庄教授目前同时挂职"上海交通大学/华东师范大学"双聘身份，领导两校联合的视觉与媒体智能（VMA）团队，王长波是该团队在华东师大方的核心成员。

此外，王长波曾荣获国家示范性软件学院卓越成就奖（2021年），表彰其在担任软件学院副院长、常务副院长期间为软件学院学科建设做出的重要贡献。

## 四、学术合作网络

### 4.1 实验室内部合作：华东师大VMA团队

王长波教授所在的华东师范大学视觉与媒体智能（Visual and Media Intelligence, VMA）团队是一个跨机构、跨学科的研究集体。该团队由上海交通大学马利庄教授领导，核心成员以华东师范大学计算机科学与技术学院为依托，形成了"上海交大-华东师大"双校联动的独特合作模式。团队内部合作紧密，主要体现在以下几个方面：

在学术会议组织方面，2023年8月的"计算机图形学-几何设计与人工智能"联合大会（CAD/CG 2023 + GDC 2023 + CAD/Graphics 2023）是团队协作能力的集中展示。马利庄教授任联合大会主席，王长波任CAD/CG 2023大会主席，何高奇任程序委员会秘书长，宋海川任GDC 2023程序主席，李晨辉任国际会议程序委员会秘书及大会组织主席，谭鑫任大会组织主席，张志忠任宣传主席，谢源任竞赛主席，李洋任组织主席，林绍辉任课程主席，李晨任海报主席。这一配置几乎覆盖了团队全部核心成员，体现了高度的团队协同性。

在科研成果产出方面，团队近年来在TPAMI、TOG、TIP、TVCG等顶刊以及CVPR、ICLR、ICCV、AAAI等顶会稳定有工作发表。2024年CVPR收录的多篇论文（如PromptAD）均由团队成员联合署名，华东师范大学为第一单位。团队研究的核心方向包括预训练大模型、跨模态学习、训练加速、自动驾驶、异常检测等。

在CSIG三维视觉与数字内容决策咨询专家团队中，华东师大VMA团队贡献了超过10名成员（含王长波），是该专家团队中除上海交大外最大的机构力量。团队成员的学科专长覆盖了计算机图形学、三维视觉、虚拟/增强现实、计算机视觉与机器学习、数据可视化、计算机辅助设计与3D打印、多模态视觉感知、计算机动画仿真等主要方向，形成了一个较为完整的图形学与视觉研究矩阵。

### 4.2 跨机构合作：上海交大-华东师大图形学网络

王长波与上海交通大学马利庄教授团队的合作是其学术网络中最核心的跨机构合作关系。这一合作关系具有以下深层特征：

**历史渊源**：马利庄教授曾获上海市科技进步特等奖（第一完成人），而王长波也获同一奖项，二人很可能在该项目中有合作关系。公开信息显示，马利庄教授目前同时挂职"上海交通大学/华东师范大学"双聘身份，这意味着他实质上跨越两校领导VMA团队，而王长波作为华东师大方的党委书记和教授，是这一双校合作在华东师大的主要对接人和执行者。

**合作深度**：2024年世界互联网大会领先科技奖项目"社会治理智能化的视觉理解共性技术及应用"是这一合作的最重要里程碑。在该项目的19位主要完成人中，王长波位列第四，前三名分别为马利庄（上海交大）、吴运声（腾讯）、卢策吾（上海交大）。值得注意的是，完成人名单中华东师大方面的人员还包括谢源（第7位）、谭鑫（第10位）、宋海川（第17位）、李晨辉（第19位），这与CSIG专家团队的华东师大成员高度重合，说明两校团队在项目层面已形成实质性的深度融合。

**合作领域**：该项目围绕"人物-行为-场景的一体化视觉表达与理解"这一重大科学问题，涵盖高精准人物视觉识别、行为概念理解与社会行为认知、复杂场景视觉理解应用创新平台等核心技术。项目已发表论文318篇（含Nature及子刊），授权发明专利298项，新增经济价值超102亿元，覆盖全球140多个行业。王长波在该项目中的具体贡献很可能集中于计算机图形学方向——特别是场景结构表达、三维场景理解与重建等技术环节，这与CSIG专家团队中标注其学科专长为"计算机图形学"的定位一致。

**合作生态**：除马利庄外，王长波还与上海交大的卢策吾教授（CSIG专家团队联合首席专家，行为理解与机器人学习方向）和盛斌教授（CSIG专家团队成员，虚拟/增强现实方向）存在直接的合作关系。2025年CVPR上海论文分享学术报告会上，王长波主持开幕式，马利庄以"上海交通大学/华东师范大学"双聘身份致辞，进一步体现了这一跨校合作的常态化和机制化。

### 4.3 中科大图形学派渊源与合作

王长波教授虽然博士毕业于浙江大学而非中国科学技术大学，但他与中科大图形学派（特别是刘利刚教授）存在明确的学术合作关系。这一合作构成了其学术网络中另一条重要的跨机构脉络。

**合作证据**：在刘利刚教授领导的中科大GCL实验室（Graphics & Geometric Computing Laboratory）的发表论文列表中，王长波多次以共同作者出现。具体包括：2019年的"EdgeNet: Deep metric learning for 3D shapes"（CAGD, 第一作者Mingjia Chen，王长波第二作者，刘利刚通讯作者）和"Deep Video-Based Performance Synthesis from Sparse Multi-View Capture"（Computer Graphics Forum, 第一作者Mingjia Chen，王长波第二作者，刘利刚通讯作者）；2020年的"Cross-domain retrieving sketch and shape using cycle CNNs"（Computers & Graphics, 同样的作者组合）。这些合作聚焦于三维形状的深度学习检索、视频性能合成与跨域检索，体现了王长波在三维几何分析与深度学习交叉方向的研究兴趣。

**学术传承**：虽然王长波的直接导师是浙江大学的彭群生教授，但浙江大学CAD&CG国家重点实验室与中国科大GCL实验室同属中国计算机图形学领域的核心力量，两者之间有着深厚的学术渊源。刘利刚教授本人也毕业于浙江大学（博士），与王长波同属浙大CAD&CG学派谱系，在学术谱系上具有同源关系。此外，陈发来教授（中国科学技术大学，出现在GDC 2023程序委员会名单中）也是中科大图形学派的核心人物，与王长波同属一个学术共同体。

**合作意义**：这一中科大合作线为王长波的研究注入了几何计算与三维形状分析的视角，与其本人在真实感绘制和可视化方向的研究形成互补。联合培养学生（如前述的Mingjia Chen）也是这一合作的重要产出。

### 4.4 国际合作

王长波教授的国际合作网络主要包括以下几个节点：

**美国纽约州立大学石溪分校（Stony Brook University）**：2009-2010年，王长波在该校进行博士后研究，这是其国际学术经历的核心环节。石溪分校在计算机图形学领域有深厚传统，这段经历为其后续的国际化视野奠定了基础。

**美国德州大学达拉斯分校张康（Kang Zhang）教授**：张康是王长波的重要国际合作伙伴。二人于2012年合著出版了教材《计算机图形学原理》（机械工业出版社，华章教育系列），该书系统介绍了计算机图形学的基本原理和经典算法。此后，二人持续合作，如在Multimedia Tools and Applications上发表的"An End-to-end Model for Chinese Calligraphy Generation"（2021年，与周霈驰、赵子鹏、李晨联合署名），探索了基于深度学习的书法生成技术。张康教授现为德州大学达拉斯分校计算机科学系终生教授、可视计算实验室主任。

**美国石溪分校/纽约州立大学Hong Qin教授**：在周霈驰的论文"A Novel Transformer-based Graph Generation Model for Vectorized Road Design"（CAVW, 2024）中，Hong Qin作为合作作者出现，表明王长波团队与纽约州立大学石溪分校的Hong Qin教授在计算机动画与图形生成方向存在学术合作。

## 五、业界合作关系深度分析

### 5.1 世界互联网大会领先科技奖项目：社会治理智能化的视觉理解共性技术及应用

2024年11月（乌镇峰会期间），由上海交通大学马利庄教授领衔、华东师范大学等单位联合完成的项目"社会治理智能化的视觉理解共性技术及应用"荣获2024年世界互联网大会领先科技奖。王长波作为第四完成人深度参与了该项目，这是其产业合作网络中最重要的一项成就。

该项目的产业影响力极为显著。项目已发表论文318篇（含Nature及子刊），授权发明专利298项，新增经济价值超102亿元，覆盖全球140多个行业。从19位主要完成人的构成来看，该项目是一个典型的"学术-产业"联合体：马利庄（上海交大，学术领衔）、吴运声（腾讯，产业代表）、卢策吾（上海交大，学术）、王长波（华东师大，学术/图形学）、盛斌（上海交大，VR/AR）、陈敏刚（产业）、谢源（华东师大，三维视觉）、吴永坚（产业）、丁守鸿（产业）、谭鑫（华东师大）、陈玉珑（上海交大）、汪铖杰（产业）、孔令和（上海交大）、院旺（产业）、宋海涛（华东师大/产业）、李永露（上海交大）、宋海川（华东师大）、李晨辉（华东师大）、周千寓（产业）。完成人中约半数来自产业界，包括腾讯等互联网头部企业的技术骨干，体现了该项目从学术研究到产业落地的完整链条。

王长波在该项目中的角色定位为计算机图形学方向的专家，其贡献很可能集中在三维场景理解与重建、场景结构表达等图形学核心技术环节，为项目的视觉理解平台提供了图形学理论与方法支撑。该项目经40位海内外权威专家评审，从全球申报成果中脱颖而出，入选20项获奖成果之一（关键技术类），代表了互联网领域的国际性领先科技水平。

### 5.2 华鑫股份金融科技联合实验室

王长波教授在金融科技领域的产业合作同样引人注目。他担任华鑫股份·华东师范大学金融科技联合实验室主任，这一校企合作平台是华东师范大学在金融科技方向产学研融合的重要载体。

该联合实验室的合作模式包括：联合研发课题（学院青年教师张伟、李晨辉、宋海川等分别承担年度联合研发课题）、联合培养卓越人才（设立金融科技专业学位硕士特色班）、奖学/奖教金颁发（华鑫奖学金、华鑫奖教金）、实训基地与信创综合实习基地建设等。合作方上海华鑫股份有限公司是上海地区重要的金融证券企业，旗下华鑫证券在金融科技领域布局深厚。

王长波作为联合实验室主任，主导了多项校企交流活动，包括组织学术年会、年度学术论坛、企业走访等活动。他还以上海市计算机学会金融科技专委会主任的身份，将学术研究与金融产业需求对接，推动了可视化技术在金融数据分析中的应用。2025年12月的"CSIG企业行-走进同花顺"活动即为典型案例——王长波以CSIG可视化与可视分析专委会秘书长身份致辞，推动了专委会与同花顺公司在金融数据可视化方向的产学研合作。

### 5.3 卓越工程师学院与产业生态

王长波还担任华东师范大学卓越工程师学院人工智能领域负责人，这一角色使其在产学研合作方面具有更广泛的影响力。2024年11月，他带领电子信息工程博士班赴天聚地合（苏州）科技股份有限公司（聚合数据，港股上市）和联讯仪器有限公司参观交流，推动校企合作培养模式和实践基地建设。这些活动体现了王长波在构建"学术研究-工程实践-产业应用"全链条产学研生态方面的持续努力。

此外，王长波主持了包括国家自然科学基金面上项目4项（62072183、61672237、61272199、61070128）、国家自然科学基金青年项目（60603076）、教育部博士点基金项目、上海市青年科技启明星项目、上海市科委自然科学基金项目、国家863计划子课题等在内的10余项国家及省部级科研项目。其国际合作论文包括与香港大学Jia Pan教授合作发表于IEEE Transactions on Robotics的机器人抓取规划研究（2023年），显示了其在产业应用导向研究中的国际化视野。

## 七、Connection圈层总结

王长波教授的学术关系网络可从以下圈层进行总结：

**第一圈层——华东师大VMA团队核心圈**：这是王长波学术网络的最内层，包括何高奇教授（VR/AR与计算机视觉）、谢源教授（三维视觉）、李晨辉副教授（数据可视化）、宋海川副教授（CAD与3D打印）、李洋副教授（计算机视觉与机器人感知）、林绍辉研究员（CV与机器学习）、谭鑫副研究员（三维视觉）、张志忠副研究员（多模态视觉感知）、李晨副研究员（计算机动画与自然景观建模）等。这一圈层以华东师大计算机科学与技术学院为物理依托，由马利庄教授跨校领导，王长波作为核心成员和前学院党委书记扮演着学术与行政双重枢纽角色。

**第二圈层——上海交大马利庄DCVLab团队合作圈**：这是王长波学术网络的第二层，核心节点为马利庄教授（上海交大特聘教授、人工智能研究院副院长）。2024年世界互联网大会领先科技奖项目是这一圈层合作的具体体现，19人完成人名单中包含了上海交大的卢策吾、盛斌、陈玉珑、孔令和、李永露等成员。这一圈层的合作模式为"上海交大学术领衔+华东师大团队执行+产业界深度参与"，形成了产学研一体化的合作生态。

**第三圈层——浙大CAD&CG学术传承圈**：王长波的博士导师彭群生教授是浙江大学CAD&CG国家重点实验室的创始人，这一学术血脉将王长波与浙大图形学派紧密联系。彭群生（2021年亚洲图形学学会终身成就奖、2022年国家自然科学奖二等奖）的学术影响力辐射整个中国图形学界。王长波的同门师兄姐包括王章野（浙大CAD&CG实验室副教授）等，其博士论文"海市蜃楼现象的真实感绘制"即为与浙大团队的联合成果。这一圈层代表了王长波学术血脉的根基。

**第四圈层——中科大刘利刚-陈发来图形学派合作圈**：通过刘利刚教授（中科大GCL实验室）的合作论文，王长波与中科大图形学派建立了跨机构学术联系。刘利刚同样出身浙大（博士毕业于浙江大学CAD&CG实验室），与王长波同属浙大学派谱系，在学术谱系上具有同源性。联合培养学生Mingjia Chen的合作论文是这一圈层的具体产物。陈发来教授（中科大）作为GDC会议程序委员，也在同一学术共同体中。

**第五圈层——金融科技产业生态圈**：以华鑫股份·华东师大金融科技联合实验室为核心载体，辐射上海华鑫股份有限公司、华鑫证券、同花顺、聚合数据等金融科技企业。王长波以上海市计算机学会金融科技专委会主任身份统筹这一产学研网络，将可视化技术与金融数据分析需求对接。这一圈层是其学术研究向社会应用转化的重要通道。

**第六圈层——学术组织与会议服务圈**：王长波在CCF、CSIG、上海市计算机学会、上海市图学学会等多个学术组织中担任重要职务，并通过组织ChinaVis、VINCI、CAD/CG等系列会议构建了广泛的学术人脉。作为CCF CAD&CG专委会常务委员和CSIG可视化与可视分析专委会秘书长，他在中国图形学与可视化社区中具有显著的学术影响力。国际合作伙伴张康（德州大学达拉斯分校）和博士后经历所在的石溪分校则构成了其国际化圈层。

总体而言，王长波教授的学术关系网络呈现出"扎根华东师大、联通上海交大、承继浙大血脉、辐射中科大、对接金融产业"的多维结构。他既是华东师大图形学与可视化方向的领军人物，也是上海交大马利庄团队在华东师大方的核心对接人，更是中国计算机图形学社区在长三角地区的重要组织者和连接者。其2024年世界互联网大会领先科技奖的获奖，标志着这一学术网络已从基础研究走向服务国家社会治理重大需求的产业化应用阶段。
