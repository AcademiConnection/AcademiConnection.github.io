## 二、教育背景与职业履历

何高奇的学术训练起点在华东师范大学数学系：1993年9月至1997年7月获理学学士，随后直升该系硕士，1997年9月至2000年7月获理学硕士。数学训练构成其后来从事算法、图形学和三维场景计算的基础。2004年2月至2007年12月，他在浙江大学CAD&CG国家重点实验室攻读博士并获工学博士。公开材料没有直接写明博士导师；鉴于他与潘志庚在2006—2016年间有多篇共同发表的VR相关论文，且潘志庚当时长期在该实验室主持VR与多媒体研究室、具有博士生导师资格，可将潘志庚视为其浙江大学VR学术谱系中的重要合作前辈，但不能据此把师生关系写作已获官方确认的事实。

时间线如下：

- **1993.09—2000.07：华东师范大学数学系。** 完成本科和直升硕士阶段，形成与现工作单位的早期校友连接。
- **2000.07—2003.07：华为技术有限公司光网络研究部。** 这是可由校方主页直接确认的三年企业研发经历；公开资料还提及“华为金牌奖”，但缺少可复核的奖项年份、项目和等级，故仅作为背景信息，不作为本报告的核心结论。
- **2004.02—2007.12：浙江大学CAD&CG国家重点实验室博士阶段。** 研究主线进入计算机图形学、虚拟现实与交互式三维内容。与潘志庚、张明敏、吕沛等人的共同论文，如2006年 *Virtual Network Marathon: Fitness-Oriented E-Sports in Distributed Virtual Environment*，反映其在浙大VR研究群体中的合作轨迹。
- **2007.12—2018.09：华东理工大学信息科学与工程学院计算机科学与工程系。** 任副教授；其间承担院长助理、工会主席等服务职务。该阶段与药学/计算化学的长期交叉合作尤其重要，后续发展为VRPharmer等成果。
- **2011.07—2011.09：新加坡国立大学访问副教授；2012.07—2013.07：Cornell University访问副教授；2014.09—2015.08：北京航空航天大学访问副教授。** 北航访问期间公开注明合作导师为赵沁平院士，使其与中国虚拟现实技术与系统全国重点实验室的重要学术节点建立了实质性访问联系。
- **2018.10—2022.12：华东师范大学计算机科学与技术学院副教授；2022.12至今：教授、博导。** 2018年回归母校后，逐步并入以马利庄为核心的视觉与媒体智能团队；学院对外报道明确将何高奇列为该团队主要成员。
- **近年：区域科技治理与产学研服务。** 学院新闻显示其以党委委员、教师第一党支部书记身份挂职普陀区科委副主任，参与区校数智化对接。这是其学术网络向政府场景、产业场景延伸的组织性节点，而非学院副院长职务。

代表性成果可从三条线索理解。第一，VR与具身交互线包括虚拟网络马拉松、2024—2025年与陈柳阳等合作的压力感知鞋与VR跳跃交互（IEEE VRW）。第二，三维视觉线包括CVPR 2024论文 *CLIP-Driven Open-Vocabulary 3D Scene Graph Generation via Cross-Modality Contrastive Learning*，作者为陈梁港旭、王雪娇、卢嘉乐、林绍辉、王长波、何高奇。第三，AI4Science线包括发表于 *Bioinformatics* 的 **VRPharmer: Bringing Virtual Reality into Pharmacophore-based Virtual Screening with Interactive Exploration and Realistic Visualization**：该软件将药效团生成、编辑和虚拟筛选放入VR交互流程，联合华东师大、华东理工、北京大学等多方完成。

## 三、学生培养情况

公开网页没有提供何高奇名下完整、逐名可核验的毕业生名册，也未逐一标注论文作者的导师关系。因此，本节严格区分“可由论文共同署名观察到的高频学生型作者/团队成员”与“已公开确认的职位去向”：后者在本次检索中十分有限，不能凭共同论文虚构师承或就业。DBLP公开书目对其91条记录的统计显示，陈梁港旭（17篇）、卢嘉乐（9篇）、王雪娇（5篇）、蔡怡青（7篇）、陈柳阳（2篇）等人在不同课题线上持续出现；以下使用“培养关联”而非未经证实的“直属学生”。这同样揭示了其培养的两个通道：科研论文带动的三维视觉/交互研究，以及《算法分析与设计》与竞赛带动的本科能力培养。

### 1. 陈梁港旭（公开职位未见，核心论文作者型培养关联）

陈梁港旭（Lianggangxu Chen）是何高奇近年共同论文中频率最高的早期作者之一：DBLP书目记录显示双方共同发表至少17项（2021—2024），覆盖视频多模态人格分析、开放词汇三维场景图等主题。在CVPR 2024的开放词汇3D场景图工作中，他列为第一作者，何高奇为末位作者之一，与王雪娇、卢嘉乐、林绍辉、王长波共同组成跨课题组指导结构。这种“学生型第一作者—多位教授联合署名”的结构说明其培养不局限于单一VR应用，而是将视觉语言模型、场景图和3D关系建模纳入马利庄团队的共同研究平台。公开检索未发现其当前工作单位或职称的可靠来源，故不作毕业去向判断。

### 2. 卢嘉乐（公开职位未见，核心论文作者型培养关联）

卢嘉乐（Jiale Lu）在DBLP记录中与何高奇有至少9项共同发表，活跃区间为2022—2024，是三维视觉方向的稳定合作者。在上述CVPR 2024论文中，卢嘉乐与陈梁港旭、王雪娇构成前列作者群；论文聚焦“CLIP驱动的开放词汇三维场景图生成”，需要同时处理三维对象、关系标签和跨模态对齐。这显示何高奇的培养网络通过与林绍辉的高效视觉学习、王长波的图形学专长耦合，使学生获得跨模态三维研究的联合指导资源。现有公开材料不足以确认其学位层级、导师登记或就业单位，报告仅将其作为高频科研培养关联人记录。

### 3. 王雪娇（公开职位未见，核心论文作者型培养关联）

王雪娇（Xuejiao Wang）与何高奇至少有5项共同书目记录，主要集中于2024—2026年，处于三维视觉研究线的持续产出阶段。她出现在CVPR 2024开放词汇3D场景图论文的核心作者序列中，也与陈梁港旭、卢嘉乐、林绍辉、王长波、何高奇形成交叉署名网络。对学生培养而言，这类协作意味着研究训练同时接触视觉语言表征、三维关系推理及计算机图形学表达；而何高奇的角色更适合描述为团队联合指导网络中的导师节点，而非在无导师名单佐证时断言其为独立主导师。公开搜索未给出可确认的职务/去向。

### 4. 蔡怡青（公开职位未见，多模态行为分析培养关联）

蔡怡青（Yiqing Cai）在DBLP中与何高奇共同发表至少7项（2021—2024），代表其从多模态行为/情感分析到视觉智能方向的学生型研究联系。与陈梁港旭共同署名的 *Video-based multimodal personality analysis*（ICGIP 2021）将视频表征和人格分析相联，符合何高奇主页所列“多模态场景智能理解”及其与心理学交叉的研究定位。该例表明，其培养内容并非只面向三维建模，也强调从多模态数据中建立行为层面的可解释分析。由于公开资料未说明蔡怡青的培养身份、毕业年份和就业去向，本报告不将其标注为已证实的硕/博士毕业生。

### 5. 陈柳阳（网易（杭州）网络有限公司，论文共同作者型培养关联）

陈柳阳（Liuyang Chen）是本报告中唯一在检索结果中能看到明确署名单位的年轻合作者：IEEE关于 *Jumping-At-Air* 的页面标注其单位为网易（杭州）网络有限公司，何高奇为共同作者。两人在2024和2025年围绕压力感知鞋、真实跳跃到虚拟跳跃的轨迹重定向持续合作。该案例尤其有价值：它表明何高奇的VR培养/协作网络与游戏工业的交互硬件、沉浸式体验需求相接，但“现为网易作者”不能自动推导为“何高奇毕业生”。更稳妥的理解是：该合作把其在VR自然交互的研究线连接到游戏企业研究开发场景，为学生和团队成员提供从原型硬件到应用体验评估的产业化问题。

### 6. 李晓凡（公开职位未见，团队共同培养网络中的学生型作者）

李晓凡在学院报道的CVPR 2024论文 *PromptAD: Learning Prompts with Only Normal Samples for Few-Shot Anomaly Detection* 中为第一作者。论文署名中的张志忠、谭鑫、谢源和马利庄构成其直接课题线的主要指导节点，何高奇并非该篇作者；但学院同时明确何高奇属于马利庄领导的视觉与媒体智能团队。因此，李晓凡应被放在“团队共享培养生态”而非“何高奇直属学生”位置：其成果反映出何高奇所处团队能给研究生提供异常检测、视觉语言模型、医学场景（长海医院）等跨课题资源。纳入此例是为呈现团队层面人才培养，而不是扩大何高奇个人导师名下学生数量。

### 7. 竞赛与课程学生群体（本科生，群体性培养对象）

除论文作者外，何高奇教授还通过《算法分析与设计》覆盖规模更大的本科培养群体。该课程教学团队由何高奇、肖春芸、李晨组成，在第三届上海市高校教师教学创新大赛获一等奖，改革强调OBE理念、计算思维训练资源、理论实践联动与学习行为数据驱动的多元评价。学院新闻另称其指导学生参加算法赛事累计获得4金、11银、11铜，并多次获优秀组织奖；这是一项团队性累计成绩，公开报道没有列出每位获奖学生姓名，因而不能补造个人名单。其人才培养特征由此可归纳为：以课程打牢算法和程序能力，以科研共同署名进入视觉/VR前沿，再以竞赛和企业问题缩短教学与产业之间的距离。

## 四、学术合作网络

### 4.1 实验室内部：以马利庄领导的视觉与媒体智能团队为核心的协作结构

何高奇与马利庄团队的关系有明确机构证据，而非仅由主题相似推断。华东师范大学计算机学院在CVPR 2024报道中写明：视觉与媒体智能团队“由马利庄教授领导，主要成员包括王长波教授、谢源教授、何高奇教授等”。CSIG在2023年公布的“三维视觉与数字内容决策咨询专家团队”又将马利庄、卢策吾列为首席专家，何高奇列为团员。两项独立公开组织信息共同支持“紧密合作者/团队成员”结论。

这一内部网络并非传统单PI放射型，而是按研究模块分工：马利庄负责三维视觉与数字内容的学术枢纽；王长波连接计算机图形学；谢源、林绍辉连接三维视觉和机器学习；张志忠、谭鑫聚焦多模态感知与极端场景理解；李晨辉提供可视分析，宋海川负责CAD与3D打印，李洋连接机器视觉，何高奇则主要承接VR/AR、混合现实、数字孪生、交互可视分析与AI4Science。何高奇与王长波共同发表至少44项，是其书目网络中最强的长期合作边；与林绍辉至少15项共同发表，说明团队内的3D视觉—高效学习协同具有持续性。

需特别澄清“上海交大DCVLab”的表述：马利庄同时是上海交通大学教授，且CSIG团队的首席专家身份构成上海交大节点；但本次直接找到的华东师大官方新闻将何高奇列为华东师大视觉与媒体智能团队成员。故最准确的说法是，他通过马利庄领导的跨校/跨单位学术共同体与上海交通大学DCVLab网络紧密关联，而不是将其误写成上海交大在编教师或DCVLab独立成员。

### 4.2 跨机构与国际网络：浙大VR谱系、北航VR节点和AI4Science交叉

跨机构网络存在三条较清晰的路径。其一是浙江大学CAD&CG国家重点实验室的博士与合作谱系。何高奇与潘志庚的共同论文延续十年左右，涉及虚拟马拉松、虚拟环境与交互；这是其VR研究根源。其二是北京航空航天大学节点：2014—2015年访问副教授期间以赵沁平院士为导师，连接国内虚拟现实技术与系统研究的重要平台。其三是华东理工大学—华东师范大学—药物设计协同：与李洪林团队长期合作，在VRPharmer中把计算机图形学/VR连接到药效团虚拟筛选、计算药物发现。

国际联系以访问经历为主，公开可确认的是2011年新加坡国立大学、2012—2013年Cornell University访问副教授；这些经历证明其曾进入国际研究环境，但尚无公开材料可支持将特定海外教授列为长期共同作者或学生导师。论文合作层面，IEEE VRW工作中有网易（杭州）作者陈柳阳，三维视觉团队通过CVPR等国际会议与全球同行保持可见度；这些是国际发表与产业协同的通道，不能夸大为海外实验室的正式联盟。

## 五、业界合作关系深度分析

### 5.1 从华为光网络研究到VR/AR与数字内容：工程研发能力的来源

何高奇的企业联系首先来自亲历：2000年7月至2003年7月在华为技术有限公司光网络研究部工作。该段经历发生在其博士训练之前，使其学术路径不是从纯理论图形学直接进入高校，而是在通信研发与工程约束中积累过系统经验。公开页面并未披露其在华为的具体项目、专利或岗位职责，因此不能将后来的计算机视觉/VR成果归因于某项华为技术；但这段经历能够合理解释其研究中反复出现的“可用系统”取向，如实时交互、可视分析、场景仿真、数字孪生和工业大模型。

研究成果的产业可迁移性体现在两类原型。第一类是沉浸式交互：虚拟网络马拉松、压力感知鞋驱动的VR跳跃等，需要低成本传感、运动阶段识别、实时轨迹映射和用户体验设计，可与游戏、健身、文旅和教育XR场景对接。陈柳阳署名网易（杭州）网络有限公司的IEEE VRW论文提供了可观察的游戏产业连接，但公开资料没有说明网易是项目资助方、雇主合作方还是作者当时的单位，不能进一步断言合作合同关系。第二类是虚拟筛选和可视计算：VRPharmer把药物设计的可视化操作转化为VR环境中的药效团构建、编辑与筛选，论文由多所高校和实验室联合完成，显示其更擅长充当“交互计算与领域科学”之间的技术整合者。

### 5.2 当前产业与公共部门协同：工业知识、空间数据、智慧教育和区域数智化

当前合作已从通用VR原型转向更加明确的行业问题。校方主页列出何高奇主持的企业合作项目“城市三维空间数据可视建模和渲染研究”（2025.06—2026.06）和“多模态焊接知识图谱构建和应用”（2026.04—2029.04）；这些项目分别对应空间计算/数字孪生和制造知识工程/工业大模型。由于主页没有公开合作企业名称、经费或验收指标，报告不对合作方和商业化规模做猜测。但从项目题目可见，其产业合作已从展示型VR扩展到可维护的三维空间数据资产、跨模态制造知识组织和面向工程流程的智能应用。

AI4Science是另一条高价值转化链。何高奇主持或参与面向同步辐射实验的统一用户交互界面与通用插件、中科院面向动态原位衍射散射实验的智能反馈系统等项目。这些任务要求将实验数据、物理知识、可视化界面和模型推理并置，契合其主页所述“面向工业和科学计算的大模型”。VRPharmer则是更成熟的前例：华东师大、华东理工、上海市新药设计重点实验室、北京大学等协同，把VR交互引入药物虚拟筛选流程，说明其产业/应用网络不只服务互联网内容，也深入医药研发工具链。

公共部门侧，普陀区科委副主任挂职与学院—普陀区的数据局党建联建，使其拥有区域数智化场景入口。学院新闻称他在挂职期间推动18名学院骨干教师进入区级专家库，并组织区校对接活动。应注意，这证明的是政府科技服务与资源联结能力，不代表个人拥有行政决策权或企业投资关系。综合来看，何高奇的业界网络可概括为“通信研发背景—XR交互原型—生命科学可视计算—工业知识与空间数字孪生—区域数智化服务”的递进链条。

## 七、Connection圈层总结

**第一圈层：核心团队与高频共同作者。** 以马利庄领导的华东师大视觉与媒体智能团队为组织中心，何高奇与王长波（至少44项共同书目）、林绍辉（至少15项）形成最稳定的技术合作边；谢源、张志忠、谭鑫、李晨辉、宋海川、李洋等构成三维视觉、图形学、可视分析、CAD/3D打印与机器视觉的模块化协作群。马利庄也是连接上海交通大学DCVLab网络的最关键桥梁。

**第二圈层：学术谱系与跨校研究平台。** 浙江大学CAD&CG国家重点实验室及潘志庚合作谱系为VR与人机交互基础；北航赵沁平院士的访问导师关系提供国内VR国家级平台连接；华东理工大学李洪林团队将其带入计算药物设计和AI4Science。这个圈层解释了其研究何以横跨VR、图形学、视觉和科学计算。

**第三圈层：学生与青年研究者培养网络。** 陈梁港旭、卢嘉乐、王雪娇、蔡怡青等高频论文作者构成三维视觉/多模态方向的核心学生型作者群；陈柳阳则把VR交互研究接到网易（杭州）游戏产业单位。由于公开导师名册不足，最严谨的表述是“共同论文所揭示的培养关联”，而非把所有共同作者认定为直属学生。课程和算法竞赛学生群体则构成规模更大的本科人才入口。

**第四圈层：产业、公共部门与国际访问网络。** 华为光网络研究部经历提供早期企业研发节点；网易署名论文、城市三维空间数据、焊接知识图谱、VRPharmer和同步辐射交互系统分别连接游戏XR、空间数字孪生、智能制造、医药研发和大科学装置。普陀区科技服务挂职带来区域治理场景；新加坡国立大学、Cornell University和北航访问经历构成国际/国内高水平学术交流节点。整体上，何高奇不是单纯依赖论文共著的视觉研究者，而是处于“马利庄三维视觉共同体—VR交互与图形学谱系—AI4Science与产业工程场景”三条网络交汇处的整合型节点。
