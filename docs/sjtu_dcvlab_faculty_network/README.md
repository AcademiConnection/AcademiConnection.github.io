# 上海交通大学 DCVLab（马利庄组）学术关系网络报告

## 团队简介

数字媒体与计算机视觉实验室（DCVLab，又名DMCV）由马利庄教授创立并领导。马利庄1963年生于浙江余姚，浙江大学CAD&CG国家重点实验室博士（导师梁友栋教授），1996年获国家杰出青年科学基金（信息学部初审复审均名列第一），2002年加入上海交通大学任特聘教授，现任上海交通大学人工智能研究院副院长。实验室依托计算机应用研究所，是上海交大-商汤科技"深度学习与计算机视觉"联合实验室的实体依托。

团队的核心特色是"上海交大/华东师大"跨校联合的视觉与媒体智能（VMA）团队模式：马利庄自2017年6月起兼任华东师范大学特聘教授，联合华东师大王长波（图形学/可视化，数据科学与工程学院党委书记）、谢源（三维视觉，国家优青）、何高奇（VR/AR）、李晨辉、宋海川、谭鑫等学者形成跨校研究集群。团队学术谱系可追溯至浙大CAD&CG学派——马利庄师从梁友栋（师承苏步青），王长波师从彭群生，分别代表浙大图形学两大导师脉络。

团队成果丰硕：CVPR 2022发表14篇、ICCV 2023录用10篇、CVPR 2024发表24篇。2024年领衔获世界互联网大会领先科技奖（项目"社会治理智能化的视觉理解共性技术及应用"，19位主要完成人，横跨两校及腾讯等产业方），项目累计发表论文318篇、授权发明专利298项、新增经济价值超102亿元。马利庄另以第一完成人获上海市科技进步特等奖（健康码相关项目）。

## 研究方向与圈层结构

团队研究方向覆盖计算机图形图像、计算机视觉、数字人物/人物视觉、三维视觉、VR/AR、数字内容生成（AIGC）与智能医学。学术网络呈五层结构：第一圈层为实验室核心团队（马利庄-卢策吾-盛斌三教授领导核心，易冉、李永露等新生代力量）；第二圈层为华东师大VMA联合团队（王长波、谢源、何高奇、李晨辉、宋海川等）；第三圈层为浙大CAD&CG学派谱系（梁友栋-马利庄、彭群生-王长波两大脉络，鲍虎军等同门）；第四圈层为产业合作网络（腾讯优图、商汤、思谋、华为）；第五圈层为国际合作网络（港中文贾佳亚-卢策吾师承链、悉尼科技大学陶大程、德国Fraunhofer IGD等）。

## 产业转化亮点

产业合作是团队最突出的特征：与腾讯优图合作的人脸识别与身份验证技术大规模应用于健康码系统（上海市科技进步特等奖）；马利庄担任上海交大-商汤科技联合实验室主任；2024年世界互联网大会领先科技奖项目覆盖社会治理、智慧城市等场景。医疗AI是第二增长曲线：盛斌与上海六院贾伟平院士团队合作研发DeepDR系列糖尿病视网膜病变AI诊断系统（发表于JAMA、Nature Medicine、Lancet Digital Health），并部署于20万人规模社区筛查。创业孵化方面，院旺创立元智波信息技术（罕见病AI筛查，马利庄个人投资），卢策吾联合创立穹彻智能（具身智能）。
