## 二、教育背景与职业履历

曹艺馨的学术生涯具有鲜明的跨地域、跨机构特色，其求学与早期职业经历横跨中国与新加坡两大NLP研究重镇。

**教育背景。** 曹艺馨于2018年在清华大学计算机科学与技术系获得博士学位。清华大学是中国NLP研究的顶尖学府，拥有以孙茂松教授、刘知远教授等为代表的知识工程与自然语言处理研究团队。曹艺馨在博士期间的研究聚焦于知识图谱与自然语言处理的交叉领域，为后续学术生涯奠定了坚实基础。

**新加坡阶段（2018-2023）。** 博士毕业后，曹艺馨赴新加坡开展研究工作，其职业轨迹涵盖了新加坡三所顶尖高校。首先，他在新加坡国立大学（NUS）的NExT++研究中心（Tsinghua-NUS-Southampton Centre for Extreme Search）担任Research Fellow，该中心由NUS蔡达成（Tat-Seng Chua）教授与清华大学孙茂松教授共同领导，是多媒体与知识工程领域具有重要国际影响力的联合研究中心。随后，他转入南洋理工大学（NTU）担任Research Assistant Professor。之后，他加入新加坡管理大学（SMU），担任Assistant Professor。在SMU期间，他与Aixin Sun教授建立了紧密的合作关系，共同指导学生并在知识图谱、信息抽取、LLM评估等方向产出大量高质量论文。

**复旦大学阶段（2023至今）。** 曹艺馨以青年研究员身份加入复旦大学计算机科学技术学院，成为FVL实验室的核心成员。FVL实验室由姜育刚（Yu-Gang Jiang）教授主导，是复旦大学在计算机视觉与多模态学习领域的主力研究团队。曹艺馨的加入为该实验室在NLP与知识工程方向补充了重要力量，使FVL的研究版图从视觉延伸至语言与多模态交叉。作为博士生导师，他目前积极招收博士研究生和各类研究人员，开展面向大语言模型时代的前沿研究。曹艺馨同时入选国家级青年人才计划与上海市青年领军人才计划，体现了其学术实力获得的高度认可。

## 三、学生培养情况

曹艺馨在SMU和复旦大学两个阶段均积极指导研究生和博士后，其学生网络横跨新加坡与中国，已形成颇具规模的学术传承体系。以下列举其代表性学生及指导关系。

### 1. 应嘉浩（Jiahao Ying）（博士研究生，复旦大学）

应嘉浩是曹艺馨在复旦大学指导的博士生，是其当前最核心的学生之一。两人合作频繁且产出密集，2024年合作发表了多篇关于大语言模型评估与改进的论文，包括"Automating Dataset Updates Towards Reliable and Timely Evaluation of Large Language Models"（与Shuicheng Yan等合作）、"LLMs-as-Instructors: Learning from Errors Toward Automating Model Improvement"（EMNLP 2024 Findings）以及"Intuitive or Dependent? Investigating LLMs' Behavior Style to Conflicting Prompts"（ACL 2024）。应嘉浩的研究方向聚焦于LLM自动评估与模型自我改进，与曹艺馨近期研究兴趣高度契合。

### 2. 马宇博（Yubo Ma）（博士研究生，复旦大学/SMU）

马宇博是曹艺馨指导的博士研究生，参与了多项重要合作研究。其代表性工作包括"SciAgent: Tool-augmented Language Models for Scientific Reasoning"与"MMLONGBENCH-DOC: Benchmarking Long-context Document Understanding with Visualizations"。后者是与复旦大学姜育刚（Yu-Gang Jiang）团队及王嘉琦（Jiaqi Wang）等人合作的大型多模态文档理解基准测试工作。马宇博的研究跨越了科学推理与多模态文档理解两个前沿方向，展现了曹艺馨课题组研究的广度。

### 3. 辛凯（Kai Xiong）（博士研究生，合作指导）

辛凯是哈尔滨工业大学的博士生（导师为丁效、刘挺、秦兵教授），与曹艺馨保持着活跃的合作关系。两人合作发表了"Meaningful Learning: Advancing Abstract Reasoning in Large Language Models via Generic Fact Guidance"和"Intuitive or Dependent? Investigating LLMs' Behavior Style to Conflicting Prompts"（ACL 2024）等论文。这种跨机构的学生指导合作模式，体现了曹艺馨在NLP学术网络中的桥梁角色。

### 4. 苑长森（Changsen Yuan）（研究生，合作指导）

苑长森是北京理工大学的研究生（与黄何燕教授合作），曹艺馨作为合作指导参与了其研究。代表性合作论文包括发表于Information Processing & Management的"Screening through a broad pool: Towards better diversity for lexically constrained text generation"。该工作展示了曹艺馨在文本生成方向的研究积累。

### 5. 肖昌奕（Changyi Xiao）（研究生，合作指导）

肖昌奕参与了曹艺馨在知识图谱嵌入方向的研究，其合作论文"Knowledge Graph Embedding by Normalizing Flows"发表于AAAI 2023，该工作与何向南（Xiangnan He）教授合作，从群论视角统一了知识图谱嵌入方法。该论文的GitHub代码仓库（github.com/changyi7231/NFE）反映了其学术影响力。

### 6. 苗展（Zhanmiao）（研究生，合作指导）

苗展是曹艺馨早期在新加坡阶段合作指导的学生，参与了知识图谱与推荐系统的交叉研究。代表性工作包括与王翔（Xiang Wang）、何向南、蔡达成等合作的KGAT系列论文（KDD 2019）以及"Explainable Reasoning over Knowledge Graphs for Recommendation"（AAAI 2019），这些工作在知识图谱辅助推荐方向具有重要影响力。

### 7. 其他学生与研究人员

曹艺馨在SMU和复旦期间还指导或合作指导了多名研究生和研究人员，包括参与SciAgent项目的Zhibin Gou、Junheng Hao等，以及参与多模态文档理解项目的多位复旦学生。其学生网络呈现出"新加坡-中国"双轨并行的特色，SMU阶段培养的学生多聚焦于信息抽取与知识图谱，而复旦阶段的学生则更侧重于大语言模型评估与多模态推理。

### 5.2 产业转化与应用场景

曹艺馨的研究成果在多个产业场景中具有应用价值，其产业合作呈现出清晰的应用导向。

## 七、Connection圈层总结

曹艺馨的学术关系网络呈现出清晰的圈层结构，从内到外可分为以下几个层次：

**第一圈层：实验室与学生。** 曹艺馨在复旦大学FVL实验室指导的博士生应嘉浩、马宇博等构成了其最核心的学术生产团队。这些学生直接参与其研究方向的设计与执行，是LLM评估、多模态推理等前沿工作的第一线推动者。同时，他在SMU阶段培养的学生网络（与Aixin Sun共同指导）也持续产出高质量成果。

**第二圈层：校内合作伙伴。** 复旦大学FVL实验室的姜育刚教授、NLP团队的黄萱菁教授、以及王嘉琦等构成了曹艺馨在校内的紧密合作圈。这一圈层的独特价值在于将FVL的视觉能力、复旦NLP的语言能力、以及曹艺馨自身的知识工程能力三者融合，形成了多模态+NLP+知识图谱的交叉研究优势。复旦大学金融科技研究院则为产业转化提供了校内平台。

**第三圈层：新加坡学术网络。** 曹艺馨在新加坡国立大学NExT++中心、南洋理工大学和新加坡管理大学的工作经历使其拥有深厚的学术根基。核心人物包括Aixin Sun（SMU，最紧密合作者）、Tat-Seng Chua（NUS，NExT++中心联席主任）、Qianru Sun等。这一圈层在知识图谱、信息抽取等传统NLP方向提供了长期稳定的合作支持。NExT++中心本身作为清华大学与NUS的联合研究平台，也是连接曹艺馨母校清华与新加坡学术圈的纽带。

**第四圈层：清华大学与国内学术界。** 曹艺馨的母校清华大学及其NLP团队（孙茂松、刘知远等）构成了其学术根脉。通过NExT++中心以及其他渠道，他与清华系学术网络保持着长期联系。国内合作者还包括中科大的何向南教授（知识图谱+推荐系统）、人大的王翔教授（推荐系统）、中科大的杨勋教授（多媒体检索）以及哈工大的丁效、刘挺教授等。这一圈层覆盖了知识工程、推荐系统、多媒体等NLP与AI的多个子领域。

**第五圈层：产业合作网络。** 曹艺馨的产业合作以与Shuicheng Yan团队的合作最为活跃，涉及LLM评估与改进等前沿方向，关联企业可能包括天工AI/昆仑万维等。与微软研究院的合作（Weizhu Chen等）聚焦于科学推理与工具增强。Google的研究基金支持则体现了国际科技巨头对其学术工作的认可。随着曹艺馨在复旦的持续发展，特别是依托复旦大学金融科技研究院在金融大模型与知识图谱方向的布局，其产业合作有望进一步向金融科技领域延伸。

**总体评价。** 曹艺馨是一位具有国际化视野的青年学者，其学术关系网络跨越中国（清华大学、复旦大学、中科大等）与新加坡（NUS、NTU、SMU）两大NLP研究高地。在知识图谱与传统NLP领域，他拥有深厚的学术积累和稳定的合作网络；在LLM评估与多模态推理等新兴方向，他正在通过与Shuicheng Yan、复旦FVL团队等的合作快速拓展影响力。作为国家级青年人才计划入选者，他在复旦大学FVL实验室的角色不仅是NLP方向的学术引领者，更是连接视觉与语言、学术与产业的关键桥梁人物。
