## 研究方向与圈层结构概述

FVL实验室的研究围绕视觉智能展开，涵盖多模态大模型、视频内容分析、视频生成、具身智能、可信AI、知识图谱、文档理解、自动驾驶等方向。实验室以"多元协同的视觉计算理论"为核心理论框架，由姜育刚教授和薛向阳教授共同奠定，获2023年度国家自然科学二等奖。近年来，实验室在具身智能方向布局深远，成立了可信具身智能研究院（TEAI），汇聚了吴祖煊、贾萧松、叶子逸等青年学者。

在学术圈层结构上，FVL呈现"姜育刚—薛向阳双核心—青年骨干"的协作架构。姜育刚教授作为实验室主任和复旦大学副校长，其学术影响力辐射全国AI领域，Google Scholar引用超35000次。薛向阳教授作为复旦计算机视觉方向的学术前辈，与姜育刚形成了"前辈引领-后继开拓"的合作范式。吴祖煊、陈静静、陈智能等教授均已成长为各自方向的独立PI。曹艺馨（清华大学博士、NUS/NTU/SMU经历）、马兴军（吉林大学/清华/墨尔本大学/迪肯大学经历）、付彦伟（QMUL博士、迪士尼研究经历）等青年学者为实验室引入了多元化的学术血脉。贾萧松（上海交通大学博士，师从严骏驰）和叶子逸（清华大学博士，师从刘奕群）作为最新加入的助理教授，分别在自动驾驶和具身智能方向开拓新领域。

## 产业转化亮点

FVL实验室的产业转化能力突出。姜育刚教授构建的开源数据集（CU-VIREO374、THUMOS、FCVID、WildDeepfake、LVIS-Instruct4V等）被国内外学者及企业广泛使用，其多模态研究成果被英伟达、阿里巴巴、深度求索等企业的大模型研发团队采用。2019年姜育刚任极链科技AI研究院首席科学家，推动了视频AI技术的产业化。吴祖煊教授联合创立了NeoteAI具身智能公司，2026年完成近亿元天使轮融资。付彦伟教授在博士期间即创立苏州德沃科技，并在WAIC展示触觉AI传感器和车灯组装系统。陈智能教授与百度在OCR方向深度合作，与腾讯在多模态方向联合培养博士生。实验室研发的应用系统多次服务国家关键领域的重要任务，包括高铁智能巡检系统等。2026年实验室成果获上海市科技进步一等奖。
