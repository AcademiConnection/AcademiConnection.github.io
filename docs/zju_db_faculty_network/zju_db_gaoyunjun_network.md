2010年，高云君加入浙江大学计算机科学与技术学院任教，后成长为教授、博士生导师及求是特聘教授，并承担软件学院、计算机软件所和宁波国际科创中心的管理工作。早期论文已与陈刚、白华（Baihua Zheng）、陈纯（Chun Chen）等共同研究空间查询与最近邻检索；回校后与陈刚在教材、数据库查询、道路网络与时空数据管理方面持续合作。现有公开材料能够确认二人是长期学术合作者和同校数据库方向同事，但没有找到可直接证明“高云君为陈刚博士生”的一手材料，故该师承关系标为（待核实），不据合作论文推断。

## 三、学生培养情况

高云君早期个人论文页以“#”标记其在读或已毕业学生；结合学校新闻和学生个人主页，可识别出以下已任教或进入科研岗位的代表性成员。关系类型只按公开证据标注，不以共同署名替代导师关系。

### 1. 房子荃（浙江大学软件学院研究员，博士导师直接指导）

浙江大学计算机学院公布的2023年优秀博士论文信息明确载明：房子荃博士论文《轨迹大数据管理与分析关键技术研究》的指导老师为高云君。房子荃现为浙江大学软件学院研究员；2024年以第一作者、高云君以通讯作者发表的动态图神经网络训练系统论文获DASFAA 2024 Best Paper Award。这构成从轨迹大数据到动态图/图学习系统的连续培养与合作链路。

### 2. 朱轶凡（浙江大学软件学院研究员，团队培养）

朱轶凡个人主页显示，其2024年获浙江大学计算机科学与技术博士学位后留校，加入由高云君负责的DAILY实验室，现从事多模态数据管理、向量数据库与新硬件加速。公开页面没有直接列出其博士导师，故不标注为“博士导师直接指导”；但其留校后进入该团队、并以团队负责人信息建立的关系，可以确认是团队培养关系。其获得2024年度ACM SIGMOD中国优博论文奖，也显示该团队在新型数据管理人才培养上的延续性。

### 3. 孙琦晨、王启隆（浙江大学软件学院硕士生，论文合作）

二人与房子荃、陈璐、高云君共同完成“Distributed Temporal Graph Neural Network Learning over Large-Scale Dynamic Graphs”，并获DASFAA 2024最佳论文。学校新闻将两人标注为软件学院硕士研究生；未见能够明确其导师归属的公开材料，因此仅标注论文合作，而不推定为高云君直接指导。

### 4. 刘沛根、王信荐等（浙江大学软件学院硕士生，团队培养）

浙江大学软件学院报道显示，刘沛根、王信荐、丁瑞、缪婧、邹慧、齐明杰、罗万相是开源分布式多智能体框架Agent-Kernel的核心贡献者。项目由高云君教授团队、毛玉仁研究员团队与阿里通义实验室联合提出。报道未逐一列出导师，故这些学生与高云君之间按团队培养关系记录；他们体现了团队由传统数据库走向大模型系统工程的新增人才节点。

## 四、学术合作网络

### 4.1 实验室内部合作

陈刚是高云君最稳定的校内合作节点之一。两人共同署名多篇数据库论文，并与江大伟合著《大数据管理系统》。在高云君公开论文中，陈刚多次与其学生共同出现于道路网络空间关键词查询、度量数据索引、不完整数据与大数据管理研究，反映出数据库与数据智能实验室内部“查询处理—时空数据—大数据系统”的协作轴。陈璐、房子荃则代表面向动态图学习和数据智能的新一代校内协作链条。

高云君还通过计算机学院和软件学院的交叉岗位连接两类组织资源：计算机学院提供数据库理论、算法与博士培养基础，软件学院侧重系统实现、工程化和产业协作。该双重组织位置使其能够将学生论文、开源系统与产学研项目衔接起来。

### 4.2 跨机构合作

论文网络显示其与香港浸会大学的Baihua Zheng、香港科技大学相关研究者、以及多所高校研究者在空间数据库、度量空间与不确定数据方向长期共同署名。例如，发表于VLDBJ和TKDE的多篇工作中，Baihua Zheng与陈刚及高云君共同出现；这类合作将浙江大学的查询处理研究接入香港地区的空间数据管理网络。

与浙江大学内部不同研究团队的合作也具有问题驱动特征：如动态图神经网络工作连通软件学院与计算机学院；面向智慧港口的培养项目中，高云君作为何晓飞团队成员之一参与自动驾驶研究，说明其数据库与大数据能力可嵌入智能交通和行业场景。就阿里云或OceanBase的正式联合研发而言，尚未找到能够直接确认其为该企业数据库产品技术负责人的公开证据。

### 4.3 国际合作

高云君的海外任职经历构成国际网络的职业基础：香港城市大学、SMU、SFU和NTU是其博士后或访问阶段的主要节点。论文层面，丹麦奥胡斯大学的Christian S. Jensen与其在度量索引、动态拼车、轨迹数据管理等多项工作中共同署名；香港浸会大学的Baihua Zheng也是持续出现的合作者。该国际合作网络围绕空间、时空和移动数据管理展开，并在VLDB、ICDE、SIGMOD等共同学术场域中延展。

## 五、业界合作关系深度分析

### 5.1 产业合作

公开信息可以确认，高云君团队与阿里通义实验室联合提出Agent-Kernel，双方共同搭建“赛博ZJU”万智能体系统。这是有明确项目、共同技术产出和开源成果的产业合作，合作主题从数据库延伸到分布式大模型智能体与社会模拟。

此外，浙江大学曾在智慧港口卓越培养项目中将高云君列为何晓飞团队成员，合作企业/实践基地为杭州飞步科技有限公司；该关系更适宜界定为跨团队的联合培养与应用场景联系。检索未发现高云君与阿里云PolarDB、OceanBase存在可由一手公开资料确认的长期联合实验室、任职或核心产品研发关系，因而不作实质合作断言。（待核实）

### 5.2 创业孵化与开源生态

目前能清楚定位的开源节点是Agent-Kernel。学校报道将其称为开源分布式大规模多智能体开发框架，采用模块化微内核和插件化设计，支持大规模智能体扩展、在线配置调整与行为校验。其核心贡献者由团队硕士生构成，且与阿里通义实验室协同，形成“教师—学生—企业研究团队—开源社区”的扩散路径。

除该项目外，公开材料不足以证明高云君本人直接创办数据库创业公司或孵化特定商业实体，相关创业关联为（待核实）。从其40余项授权发明专利、软件著作权和多项系统论文可见较强工程转化基础，但专利授权并不等同于已商业化或创业孵化。

## 七、Connection圈层总结

第一圈层（核心圈层）由浙江大学数据库与数据智能实验室的长期合作与培养关系构成。陈刚是最显著的稳定合作节点，二人围绕空间查询、度量数据、不完整数据、大数据管理和教材建设形成持续交集；房子荃、朱轶凡以及参与Agent-Kernel的青年研究人员和学生，构成从博士培养到留校研究、从论文到开源系统的团队延展。

第二圈层是国内跨团队和跨场景网络。它包括计算机学院、软件学院及宁波国际科创中心等组织节点，并通过智慧港口、图神经网络和多模态/向量数据库等主题与智能交通、软件系统和数据智能方向相连。此圈层的特点不是单一数据库产品协作，而是以数据管理方法服务复杂应用。

第三圈层是国际学术合作网络。Christian S. Jensen、Baihua Zheng等合作者，以及高云君在香港、新加坡和加拿大的访问经历，使其时空数据与查询处理研究嵌入国际数据库共同体；VLDB、SIGMOD、ICDE等会议既是成果发表场域，也是合作扩展平台。

第四圈层是产业与开源生态。阿里通义实验室与团队共同推进Agent-Kernel，是目前证据最明确的企业协作节点；开源框架将学生贡献、分布式系统能力和大模型应用连接到更广泛开发者生态。总体而言，高云君的学术关系网络以浙大数据库团队为中心，以陈刚等长期合作者和学生培养为骨架，向国际时空数据研究、跨学科数据智能应用及大模型系统开源合作三方面扩展；对阿里云、OceanBase及创业实体的关系仍应保持审慎表述。
