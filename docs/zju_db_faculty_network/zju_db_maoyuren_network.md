## 二、教育背景与职业履历

毛玉仁1991年6月出生于内蒙古赤峰。2014年6月在重庆大学获学士学位，2017年6月在浙江大学获硕士学位，2022年2月在澳大利亚新南威尔士大学（UNSW）获博士学位，博士期间主要从事机器学习特别是多任务学习研究，成果发表于ICML、ACL等国际顶级学术会议。其博士导师身份未见公开权威披露（待核实）；从其博士期间及之后的论文署名看，与UNSW的Xuemin Lin、Yu Hao、Xin Cao等学者保持长期合作。

在读博前后，毛玉仁曾在支付宝、微软亚洲研究院、英特尔亚太研发中心等多家单位从事研发工作，2018年曾以子系统负责人身份参与"支付宝新春五福项目"，系统承载了约7亿支付宝用户的需求。2022年6月起加入浙江大学软件学院，任平台"百人计划"研究员，从事机器学习与数据智能方向的科研与教学工作，并加入高云君负责的DAILY实验室。在数据库与大数据智能分析研究团队的招生资料中，其研究标签为"大模型智能体、智能数据湖"，并担任团队联系人。近三年在ICML、NeurIPS、SIGMOD、VLDB、ACL、TKDE等CCF-A类/SCI一区期刊会议发表论文二十余篇。

## 四、学术合作网络

### 4.1 实验室内部合作

毛玉仁与高云君的合作最为密切，是其近三年SIGMOD、VLDB、TKDE、ICDE等绝大多数数据库论文的共同作者；与陈璐（Lu Chen）在语义连接发现Snoopy（TKDE 2025/ICDE 2026）等工作中合作。其与朱轶凡共同完成scRAG（ICDE 2025），与实验室其他成员（如Zhonghao Hu等）构成稳定的论文合作网络。

### 4.2 跨机构合作

国内跨机构合作包括：与浙江大学知识图谱方向的Ningyu Zhang、Huajun Chen及清华大学的Lun Du合作（ForeAgent, ACL 2026，依托浙江大学—蚂蚁集团知识图谱联合实验室）；与蚂蚁集团研究人员Ying Zhang、Longbin Lai、Zhengping Qian、Renjie Sun等在私有化大模型G-Boost、智能体基准OpenHospital等工作中合作；与快手公司在WWW 2026的短视频搜索重排序工作中合作（合作者含Yi Zhang等）。学界合作对象还包括中山大学的Yixiang Fang等。

### 4.3 国际合作

国际合作以UNSW的Xuemin Lin、Xin Cao、Yu Hao为核心，体现在动态图嵌入（TKDE 2024）、图神经网络链接预测（TKDE 2025）等论文中；此外与新加坡管理大学的Baihua Zheng在表格发现BIRDIE（PVLDB 2025）中合作。其曾任/现任多个国际顶会PC成员，形成持续的跨国学术服务网络。

## 五、业界合作关系深度分析

### 5.1 产业合作

毛玉仁具备较深的产业履历：曾任职支付宝（并负责新春五福项目子系统）、微软亚洲研究院、英特尔亚太研发中心。当前产学合作以蚂蚁集团最为突出——通过浙大—蚂蚁知识图谱联合实验室开展大模型与数据智能方向研究（G-Boost、OpenHospital、SQL-Factory等工作含蚂蚁作者）；他曾破解华为发布的技术难题并获"火花奖"；亦与快手合作发表短视频搜索论文。此外，其提出的C3方法曾登顶Text-to-SQL国际榜单Spider零样本方法全球第一，成为该领域重要基线。

### 5.2 创业孵化与开源生态

毛玉仁是大模型开源教育生态的代表性推动者。他与学生组成学习小组，联合撰写开源中文教材《大模型基础》（分六大章节、283页，高云君为编撰总指导），在GitHub获得1.6万余Stars（据浙江大学计算机学院2026年7月报道），成为网上推荐最多的大模型学习书籍之一；参与学生包括葛宇航、李佳晖、张超、董雪梅、宓禹、樊怡江、徐文溢、胡中豪等（据媒体报道）。他还把研究生课程《大模型原理与技术》录屏上传至B站，并在社交平台开设免费学习账号，致力于"大模型普惠教育"。未见其本人主导创业孵化的公开信息（待核实）。

## 七、Connection圈层总结

从内圈到外圈，毛玉仁的学术网络可以分层描述：第一圈层是DAILY实验室与高云君领导的数据库团队，他与高云君、陈璐及一批学生作者构成其近三年SIGMOD/VLDB/TKDE成果的核心生产网络，并担任团队招生联系人；第二圈层是浙江大学校内跨方向合作网络，主要是与Ningyu Zhang、Huajun Chen、Lun Du等在知识图谱与大模型方向的协同，依托浙大—蚂蚁联合实验室展开；第三圈层是产业界连接，蚂蚁集团（既往任职+当前联合实验室）、华为（火花奖）、快手（WWW 2026合作）、微软亚洲研究院与英特尔（既往任职）构成其"学术—工程"双向通道；第四圈层是国际化脉络，UNSW（Xuemin Lin、Xin Cao、Yu Hao）与新加坡管理大学（Baihua Zheng）的合作延续其博士训练网络。

总括而言，毛玉仁是浙大数据库团队从传统数据库研究向"大模型+数据智能"转型中的关键青年学者：他兼具工业界大型系统研发经历与机器学习理论训练，以大模型智能体赋能数据湖为主线，学术产出处于数据库与人工智能两大社区的交汇处；同时，其以《大模型基础》开源教材和公开课程为代表的开源与科普实践，使其在学术圈层之外形成了罕见的公众影响力网络。其国家级人才称号等信息尚待进一步核实。
