## 二、教育背景与职业履历

柯翔宇2020年博士毕业于新加坡南洋理工大学（NTU）。从其博士期间论文署名与合作模式看，其工作与NTU的Arijit Khan教授（不确定图、众包实体分辨方向）及Gao Cong教授（种子与标签联合发现等方向）深度绑定，Arijit Khan为其博士导师的可能性最大，但未见官方履历明确披露（待核实）。博士期间及毕业后，他先后在新加坡南洋理工大学和新加坡国立大学（NUS）任博士后研究员，并于2022年加入浙江大学，任计算机科学与技术学院、软件学院平台"百人计划"研究员，开展大数据智能管理与分析方向的研究，获宁波市甬江人才工程青年科技创新项目资助。

其学术成果发表于SIGMOD、VLDB、ICDE、TKDE等数据库顶级会议与期刊。据OpenAlex统计（2026年8月），其署名论文约72篇，总被引约376次，h指数约11。代表性工作覆盖不确定图可靠性计算、二部图蝴蝶计数、图摘要、基于Graph Transformer的社区搜索、图神经网络解释性，以及向量检索方向的高引工作Starling（磁盘驻留图索引，SIGMOD 2024）等。研究强调理论分析与实际应用并重，成果曾在社交网络广告投放、智能交通规划、自闭症儿童脑图谱甄别等现实任务中得到采用。

## 四、学术合作网络

### 4.1 实验室内部合作

柯翔宇与高云君的合作紧密：二人联合发表Starling、MUST、GTS等向量与多模态检索系列工作，并联合开源向量检索方法PSP（Proximity graph with Spherical Pathway，据媒体报道可与图索引向量检索结合提升RAG效率，合作者还包括向量检索领域学者傅聪）。他与朱轶凡同在玉泉校区则通楼402办公，并在Legend（VLDBJ 2026）等工作中与朱轶凡、学生李忠根合作完成CPU-GPU-SSD异构系统研究；与团队其他成员（陈璐等）在度量空间与图数据管理议题上互补。

## 七、Connection圈层总结

从内到外，柯翔宇的学术网络分层清晰。第一圈层是DAILY实验室：他与高云君构成向量检索与图数据管理方向的核心师生型合作轴（Starling、MUST、GTS、PSP等），与同办公室的朱轶凡及团队学生形成紧密的日常协作；第二圈层是浙大数据库与数据智能实验室整体，包括陈璐、毛玉仁、房子荃等在多模态、大模型、时空方向的互补布局；第三圈层是新加坡学术血缘——NTU的Arijit Khan与Gao Cong及其门下的不确定图、众包与图挖掘研究谱系，以及NUS博士后阶段的扩展连接；第四圈层是产业与国际协作，包括与傅聪等向量检索开源社区的协作、Legend论文中体现的阿里巴巴合作关系，以及美国、丹麦等地的论文级国际连接。

总括而言，柯翔宇是浙大数据库团队从新加坡引进的"系统+算法"型青年学者：博士与博士后阶段的不确定图、众包、图查询训练，叠加浙大阶段向向量检索与GPU加速的拓展，使其恰好卡位"大模型时代向量数据库"这一产业与学术双重热点。其开源方法PSP与Starling系列使他在RAG基础设施生态中具备可见度，而作为CCF数据库专委执行委员的社区身份则进一步巩固了其在国内数据库学术共同体中的节点地位。
