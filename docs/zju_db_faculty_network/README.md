## 二、各位教师的角色定位

陈刚是实验室的学术带头人与行政顶点。他长期执掌浙大计算机学科：2017年7月至2024年1月任计算机学院院长，2024年1月起任浙江大学党委常委、副校长，为长江学者特聘教授（2017年度）、国家"万人计划"科技创新领军人才。其学术方向为云原生数据库与高性能数据管理系统，获VLDB 2014/2019最佳论文奖、中国电子学会科技进步特等奖（2019，第一完成人）。升任副校长后，他与高云君的"双核"结构转为"名誉掌舵+学术运营"格局。

高云君是实验室日常学术运营的核心。求是特聘教授、软件学院常务副院长，优青（2015）、杰青（2020）连续获得者，研究方向大数据管理与挖掘、时空数据管理、云原生数据库与AI for DB。实验室对外以"DAILY"（Databases and Intelligent anaLYtics lab）名义运转，高云君为实际负责人，近年与蚂蚁集团共建联合研究中心（2025年升级），产学研结合紧密。

陈璐与柳晴构成实验室的中坚双PI：陈璐为国家特聘青年专家（2021），深耕数据清洗、数据集成与大数据质量管理；柳晴聚焦数据库可用性、图数据分析。两人均为百人计划研究员，支撑实验室在数据质量与图数据两条主线上的持续产出。

青年梯队呈现鲜明的"国际化+内生"混合结构：毛玉仁（UNSW博士，曾任支付宝、微软亚研、英特尔）2022年入职后成为团队招生联系人，研究大模型与数据库交叉，其《大模型基础》开源教材GitHub星标超1.6万，是国内最有影响力的LLM入门教材之一；柯翔宇（NTU博士，NTU/NUS博士后）2022年加入，为CCF数据库专委执行委员；朱轶凡是实验室内生培养的新生代——竺可桢学院本科、浙大博士（2024），以第一作者获ACM SIGMOD中国优秀博士学位论文奖（2024），同年留校任百人计划研究员，标志着实验室谱系进入自我繁殖阶段。

## 三、全实验室关系网络的整体观察

第一，"院长-副院长"双核驱动的行政红利。陈刚（副校长）与高云君（软件学院常务副院长）分别在校区级与学院级掌握行政资源，使实验室在交叉建制（计算机学院+软件学院双平台）中获得罕见的资源覆盖，百人计划研究员多同时在两个学院平台列名。

第二，浙大数据库学派的代际结构清晰。陈刚、高云君为第一代双核（两人师承关系未见一手公开记录，已标注待核实），陈璐、柳晴为引进中坚，毛玉仁、柯翔宇、朱轶凡为第三代青年梯队。朱轶凡作为本土博士直升百人计划研究员，是实验室"内生繁殖"能力的直接证据。

第三，产学研深度绑定。实验室与蚂蚁集团联合研究中心（2025年升级）、华为（毛玉仁获华为火花奖）等企业合作紧密，研究方向从传统数据库自然延伸至云原生数据库（与蚂蚁OceanBase生态）、AI for DB、大模型+数据管理（毛玉仁《大模型基础》教材）等前沿交叉。

第四，学术共同体影响力。团队在SIGMOD/VLDB/ICDE数据库三大会持续产出，朱轶凡的SIGMOD中国优博与高云君2024-2025年的多项最佳论文/提名奖项，显示实验室正处于产出高峰期。整体格局为"行政双核+中坚双PI+青年三杰"，是华五高校中数据库方向配置最完整的团队之一。
