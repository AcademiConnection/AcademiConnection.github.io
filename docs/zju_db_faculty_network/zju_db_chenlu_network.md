## 二、教育背景与职业履历

陈璐于2016年6月获浙江大学计算机科学与技术专业工学博士学位。官方主页未公布其博士导师，因此师承关系记为（待核实）。毕业后，她于2016年10月至2017年9月在新加坡南洋理工大学从事博士后研究；2017年10月至2019年7月任丹麦奥尔堡大学助理教授，2019年8月晋升副教授。2020年回到浙江大学，受聘“百人计划（A类）”研究员。

这一履历使其研究网络呈现“浙大培养—新加坡博士后—丹麦高校任教—回归浙大数据库团队”的跨国流动轨迹。其公开主页列举的成果覆盖VLDBJ、TKDE、SIGMOD、VLDB、ICDE、SIGIR等期刊与会议，研究议题与数据质量、数据治理、时空/度量空间数据和数据库可用性相连。学院招生团队资料将其列为“数据库与大数据智能分析研究团队”成员，研究标签为多模态数据库与大数据治理；该团队由高云君负责。

## 四、学术合作网络

### 4.1 实验室内部合作

最清晰的内部组织关系是高云君负责的“数据库与大数据智能分析研究团队”。陈璐与高云君在数据库、大数据治理、时空/度量空间数据、数据库可用性等议题上具有高度交叉；二人亦共同参加过CCF数据库专委走进高校活动，分别作“大数据治理：现状与展望”和“大数据治理与智能分析”报告。这说明两人存在可公开确认的团队与学术传播协同，但公开材料不足以认定为师生关系或逐篇论文合作关系。

团队同侪包括柳晴等数据库教师。陈璐的多模态数据管理与数据治理研究，可与图数据、智能数据湖、向量数据库及大图数据管理方向形成互补。关于“与陈刚关系密切”的线索：学院研究所名录显示陈刚与陈璐同属计算机软件研究所序列，且公开介绍称数据库与数据智能实验室由陈刚带领；然而，未检索到足以确认其直接导师、直接汇报或具体共同论文的官方材料，故仅表述为同院所/实验室组织关联。

## 七、Connection圈层总结

**第一圈层：浙大数据库团队。** 陈璐是浙江大学计算机学院“百人计划”研究员、博士生导师，处在高云君负责的数据库与大数据智能分析团队中。围绕数据治理、多模态数据管理、时空与度量空间数据管理的共同问题，形成其最稳定的本校研究共同体。陈刚与其存在院所及实验室组织关联，但直接学术关系尚待进一步确认。

**第二圈层：学生与青年研究者。** 她公开招收博士、硕士、本科科研学生，具备直接指导资格；由于公开学生名录不足，本报告不虚构学生网络。团队多导师并列的组织方式意味着学生网络可能同时连接数据库、图数据、智能数据湖和向量数据等相邻方向。

**第三圈层：国际职业经历与数据库共同体。** 南洋理工大学博士后经历、奥尔堡大学教师经历以及VLDB、ICDE等国际会议服务，构成其国际学术网络的可确认骨架。

**第四圈层：应用与产业接口。** 数据质量、治理和大数据分析天然面向产业数据基础设施；专利也提供转化接口，但现有公开材料不足以识别具体企业、开源社区或创业实体。

总体而言，陈璐的关系网络以浙江大学数据库团队为组织中心，以新加坡—丹麦职业经历为国际延展，以数据库顶级会议的论文和服务网络为专业连接。对师承、学生名单、与陈刚的直接合作及企业项目，均应在获得论文作者信息、项目公示或正式简历后再作细化。
