## 二、教育背景与职业履历

陈刚于1995年6月获浙江大学计算机应用专业硕士学位，1998年6月获浙江大学计算机应用专业博士学位，本硕博均完成于浙江大学，其博士阶段处于浙大计算机学科老一辈学者（如何志均创办的计算机系、董金祥等工程数据库学者）奠定的学术土壤之中；其博士导师的直接记载未见公开权威来源（陈刚早期论著与董金祥长期联合署名，师承关系（待核实））。1999年他破格晋升副教授，2003年破格晋升教授，2005年3月受聘博士生导师，此后长期执掌浙江大学数据库研究方向，并曾任浙江大学软件研究所所长。

在行政轨迹上，陈刚于2017年7月至2024年1月担任浙江大学计算机科学与技术学院院长、计算机科学与技术学院和软件学院党委副书记；2024年1月起任浙江大学党委常委、副校长。任学院院长期间，他主持学院研究生招生、学科建设等全局工作，卸任时提出学院应"更具国际化视野、继续传承学院文化、勇于拓展大项目、继续培养学科领军人才"。任副校长后，他分管领域涉及科研组织（如出席重大科研仪器研制专题沙龙并致辞）、校企合作签约（阿里巴巴、蚂蚁集团等）以及地方校友与产业对接事务。学术上，他围绕批流混合时态大数据实时处理、云数据库管理技术、互联网大数据处理方向持续产出，研究工作获VLDB 2014、VLDB 2019最佳论文奖，并作为第一完成人获中国电子学会科技进步特等奖（2019）、教育部科技进步一等奖（2016）、浙江省科学技术一等奖（2011、2020）。

## 四、学术合作网络

### 4.1 实验室内部合作

陈刚领导的浙大数据库团队形成了以数据库系统与大数据智能计算为核心的稳定合作网络：高云君（大数据管理与分析、DB与AI融合）、伍赛（数据库系统）、陈珂、寿黎但（数据挖掘与机器学习）、陈璐（时空与度量空间数据管理）等均为长期联合署名者（DBLP可见Gang Chen与Ke Chen、Lidan Shou等持续合著至近年）。团队标志性成果包括VLDB 2014、VLDB 2019两届最佳论文奖，以及"互联网大数据处理"方向的系列系统研发。王备（待核实）承担的Crown系统研发亦属团队内部的系统方向支线。

### 4.2 跨机构合作

校内层面，陈刚与软件学院尹建伟（早期与陈刚、董金祥联合署名论著，后任软件学院院长、国家杰青）保持长期合作关系；他亦为浙江大学人工智能省部共建协同创新中心领导班子成员（与庄越挺、吴飞、肖俊并列）。与老一辈学者董金祥的长期合作构成其学术谱系的直接源头。2023年他作为学院院长在网络空间安全西湖论坛作"领域大模型应用生态构建关键技术与系统"特邀报告，显示其合作版图已延伸至大模型与数据安全交叉领域。

### 4.3 国际合作

陈刚研究工作长期发表于VLDB等国际顶级会议并两获最佳论文奖，担任包括VLDB在内的多个国际会议程序委员会委员及TKDE、VLDBJ、TPDS、JCST等期刊评审专家。浙大数据库团队与国际数据库学界联系紧密：新加坡国立大学黄铭钧院士（Beng Chin Ooi，中国科学院外籍院士）与浙大数据库方向保持长期密切合作（2026年浙大为其举办追思会时由高云君代表回顾其对中国数据库学科与人才培养的贡献）；团队成员蔡登的UIUC/Jiawei Han学术谱系亦构成中美数据挖掘方向的连接通道。陈刚本人具体国际合作者名单（待核实）。

## 五、业界合作关系深度分析

### 5.1 产业合作

陈刚的产业合作以浙江大学副校长身份主导的校企战略合作为主线：2025年9月，浙江大学与阿里巴巴集团成立人工智能安全联合实验室，陈刚作为副校长出席签约仪式；2025年11月，蚂蚁集团与浙江大学共建聚焦"AI for Data"的联合研究中心，覆盖从底层数据库到结构化数据分析处理与应用的全链路技术攻坚，陈刚出席并致辞表示"高度重视与蚂蚁集团的战略合作"。此外，其团队成果曾获中国电子学会科技进步特等奖（2019，第一完成人），反映其数据库与大数据技术在产业界的落地。浙大学生团队在OceanBase数据库大赛（2022–2023年第二届）中夺冠，亦体现了团队与国产数据库产业的深度互动。

## 七、Connection圈层总结

第一圈层（核心圈层）是陈刚直接领导的浙大数据库与数据智能实验室团队：包括其直接指导的博士生（如王皓波）、团队培养成长起来的学术骨干高云君、陈璐、王备（待核实）等，以及伍赛、陈珂、寿黎但等长期合作者。这一圈层构成了浙大数据库方向的学术中坚，以VLDB最佳论文、省部级特等/一等奖成果为标志，并通过高云君进一步向下延伸出房子荃、毛玉仁等新一代骨干，形成三代传承的谱系结构。

第二圈层是浙大校内的学术合作网络：以董金祥为代表的学术前辈与谱系源头，以尹建伟（软件学院）、蔡登（机器学习）、庄越挺/吴飞（人工智能协同创新中心）等为代表的院内跨方向合作者，以及任奎、吴飞等现任学院领导班子成员构成的管理协作层。这一圈层使陈刚的影响从数据库小组扩展至整个浙大计算机学科的组织与治理层面。

第三圈层是产业与国际合作网络：对内有阿里巴巴（人工智能安全联合实验室）、蚂蚁集团（"AI for Data"联合研究中心）等头部企业的战略合作，以及与OceanBase等国产数据库生态的人才互动；对外有以黄铭钧院士为代表的国际数据库学界纽带、VLDB/SIGMOD等国际会议组织网络的参与。作为浙江大学党委常委、副校长，陈刚的Connection网络已从一名数据库学者的学术共同体，演化为贯通"学术谱系—学科治理—产业战略—国际合作"的多层级枢纽，其核心圈层的学术火种（数据库与大数据智能计算）正通过第二、三圈层持续放大。
