## 二、教育背景与职业履历

宁雪妃的学术道路始终扎根于清华大学电子工程系。2012年入读清华大学电子科学与技术专业，2016年获学士学位；随后直升博士研究生，师从杨华中教授和汪玉教授，于2021年获电子科学与技术博士学位。博士期间的研究聚焦于模型压缩与神经网络架构搜索（NAS）。

2021年12月至2023年12月，宁雪妃在汪玉教授和Pinyan Lu教授指导下从事博士后研究。2024年3月正式就任清华大学电子工程系助理研究员（研究系列助理教授），并同时创建并领导NICS-EFC实验室下的高效深度学习算法团队（Efficient Algorithm Team，简称EffAlg）。

2019年3月起，宁雪妃开始独立开展神经架构搜索与模型压缩方向的研究工作。2020年初，她开始指导三名本科生的首批科研项目，这标志着EffAlg团队的雏形形成。此后团队持续壮大，至2024年已有10余名硕博研究生及本科生。2025年起，由于个人安排，团队日常管理由赵天晨（Tianchen Zhao）接手负责，宁雪妃仍在部分项目中参与指导，团队继续正常运转并招募新生。

## 三、学生培养情况

作为EffAlg团队的创建者，宁雪妃从零起步构建了一支专注于高效深度学习的研究力量。截至2024年，团队共培养和正在指导约10名研究生及若干本科生，涵盖博士和硕士两个层次。

**核心学生及代表性合作成果：**

- **赵天晨（Tianchen Zhao）**：博士研究生，EffAlg团队2025年起日常负责人。与宁雪妃合著多篇高质量论文，包括ICLR 2025的ViDiT-Q（扩散Transformer量化）、ECCV 2024的MixDQ（少步文本到图像扩散模型量化）、ICLR 2024的USF（扩散模型采样框架）等，是团队在生成模型量化与加速方向的核心力量。
- **李士尧（Shiyao Li）**：博士研究生（2025年毕业，入职阿里）。合作发表ICML 2024的量化大语言模型评估、CVPR 2025的MBQ（视觉语言模型量化）、TCSVT 2024等论文。
- **刘恩恕（Enshu Liu）**：硕士研究生。合作发表ICLR 2025的LCSC（检查点线性组合优化扩散模型）、ICLR 2024的USF等论文，在生成模型高效化方向有突出贡献。
- **傅天宇（Tianyu Fu）**：博士研究生。共同一作发表CoLM 2025的MoA（混合稀疏注意力）论文，是大语言模型长文本压缩方向的骨干。
- **黄浩峰（Haofeng Huang）**：本科生。共同一作参与MoA等核心论文，展现了团队对本科生的深度培养。
- **赵君博、施祥生、钟凯**等已毕业学生分别在华为、启元实验室、字节跳动等企业就职。

团队毕业生的去向覆盖了国内头部科技企业（阿里巴巴、字节跳动、腾讯、华为、美团、快手等）以及高校深造（上海交通大学、香港科技大学等），形成了良好的产学研输送链条。

## 五、业界合作关系深度分析

宁雪妃的业界合作深度在青年学者中极为突出，主要体现在两个层面：

**深鉴科技（DeePhi Tech）**：2016年由汪玉、韩松、姚颂（CEO）和单羿（CTO）共同创立的AI芯片公司；姚颂是汪玉课题组的本科生，而非博士生。深鉴科技于2018年被赛灵思（Xilinx，现AMD）以约3亿美元收购；收购后，创始团队向清华大学捐赠500万美元。这一产学研转化路径为宁雪妃后续的产业合作奠定了基础。

**无问芯穹（Infinigence AI）**：2023年5月由汪玉教授发起创办的AI基础设施公司，定位为"大模型时代的算力运营商"。核心团队包括CEO夏立雪（汪玉博士生）、首席科学家兼联合创始人戴国浩（上海交通大学）以及CTO颜深根（前商汤）。宁雪妃作为EffAlg团队负责人，与无问芯穹保持深度学术合作关系——团队主页明确声明"与Infinigence-AI有深度学术合作"，双方联合发表MoA、LV-Eval等论文，并共同举办技术活动。无问芯穹累计融资约10亿元人民币。

此外，宁雪妃还与华为、苹果中国、AMD中国、vivo等企业在技术交流层面保持活跃互动，多次受邀在企业内部分享高效深度学习与生成模型压缩的前沿报告。2025年1月在智源研究院年度AI趋势讨论会上做推理优化方向的邀请报告。

宁雪妃的学术关系网络可概括为以下四个圈层：

**第一圈层（导师与核心合作者）：** 汪玉教授（博士导师、实验室负责人、专著合著者、几乎所有论文的合作者）和杨华中教授（博士导师、期刊论文合作者）构成其学术根基。二位导师为宁雪妃提供了从博士培养到职业发展的全方位支撑。微软研究院的林子南博士作为最重要的跨机构合作伙伴，共同主导多个研究项目，是学术网络中的关键节点。

总体而言，宁雪妃作为一位90后青年学者，在博士毕业仅五年内即构建了一个以清华NICS-EFC为核心、辐射国内外顶级高校与研究院所、深度链接产业界的多圈层学术合作网络，其学术影响力（Google Scholar引用1800+、顶会论文40余篇）与产业转化能力（深鉴科技、无问芯穹）并重，是高效深度学习方向产学研融合的代表性青年学者。
