## 二、教育背景与职业履历

戴国浩于2010年考入清华大学电子工程系，2014年获工学学士学位，同年起在NICS-EFC实验室直攻博士学位，2019年获工学博士学位（导师汪玉教授），博士期间研究方向即为"智能场景下稀疏计算快速高能效电路与系统设计"。据公开报道，他自大二起便进入汪玉教授实验室，从学习者逐步成长为可独立负责大方向的骨干。

2019年博士毕业后，他留校在清华大学电子工程系NICS-EFC实验室从事博士后研究，期间以助理研究员身份参与汪玉、杨华中团队的稀疏计算项目（如2021年提出的dgSPARSE稀疏计算项目），并参与指导本科生科研（曾共同指导2020届本科生黄古玥获IEEE/ACM微体系结构国际研讨会学生研究竞赛第一名）。NICS-EFC实验室的Postdoc Alumni列表显示，戴国浩于2022年博士后出站，去向为上海交通大学。

2022年，戴国浩正式加盟上海交通大学电子信息与电气工程学院清源研究院，任长聘教轨副教授，创建人工智能设计自动化创新实验室（DAI Lab）。2023年5月，他参与联合创立无问芯穹并出任首席科学家，负责公司整体技术战略。2025年，他作为上海交大人工智能学院副教授出席浦江创新论坛、中国生成式AI大会等重要场合，是其研究路线"从顶天的书架走向立地的货架"的集中体现。

## 五、业界合作关系深度分析（无问芯穹）

无问芯穹（Infinigence AI）是理解戴国浩产业网络的核心。该公司于2023年5月成立，由清华大学电子工程系长聘教授汪玉作为发起人推动创立，定位为"大模型时代的算力运营商"，依托"多元异构、软硬协同"技术打造连接"M种模型"与"N种芯片"的"MxN"大模型软硬件联合优化平台。公司累计融资约10亿元人民币。

创始团队结构呈现鲜明的"师生组合拳"特征：

作为首席科学家，戴国浩负责无问芯穹的技术战略，其核心主张是将学术界积累的稀疏计算新范式产业化：通过先验知识驱动的结构化稀疏、机器学习驱动的动态编译和细粒度并行稀疏架构，在工艺和峰值算力较低的芯片上实现对高端硬件的超越，将等效算力提升一个数量级。团队已落地稀疏计算库等10余项软件著作权和发明专利；其技术量化指标包括：文生文应用算力提升13倍、文生图算力提升27倍；打通六类异构芯片生态壁垒，实现"4+2式"混合训练，集群算力利用效率最高达97.6%；推出具备21B智能水平而仅消耗3B规模计算量的端侧多模态轻量模型。

无问芯穹同时是戴国浩学术研究与产业落地的"转接头"：上海交大与无问芯穹联合团队完成的ViDA论文（视频扩散Transformer加速器）获ASP-DAC 2025最佳论文奖，是其"上交实验室+无问芯穹"产研协同闭环的直接证据。公司入驻上海徐汇模速空间，与地方政府共建"算力生态超市"，也使戴国浩深度嵌入上海大模型产业生态。此外，无问芯穹曾向清华大学捐赠以支持AI for Science研究，延续了汪玉团队（深鉴科技时期向清华捐赠500万美元）反哺母校的传统。

## 七、Connection圈层总结

**第一圈层（导师与师承核心）：** 汪玉（博士导师）与杨华中（师祖，清华电子系）。戴国浩在清华12年的全部训练都在NICS-EFC完成，汪玉既是其学术导师也是其创业的发起人，两人的合作论文覆盖2013-2025年长达13年，是其网络中不可替代的锚点。

**第二圈层（NICS-EFC同门）：** 夏立雪（无问芯穹CEO，汪玉博士生）、曾书霖（汪玉博士生、无问芯穹核心成员）、宁雪妃（NICS-EFC毕业、清华助理研究员）、朱振华、孙汉博等。这一圈层同时横跨学术与产业：夏立雪、曾书霖与戴国浩构成无问芯穹的"汪玉学生帮"，宁雪妃等则保持了清华-上交之间的持续学术合作。

**第三圈层（上海交大现单位）：** 清源研究院/人工智能学院DAI Lab自建梯队（李金昊、徐健荣、刘君眉、连垚秀、黄珊、徐宁翊等），以及清源研究院定制计算方向的同事与合作者（含北大、MSRA的量化合作网络）。该圈层2023年后快速扩张，是其作为独立PI的学术大本营。

**第四圈层（国际与产业）：** 国际端以谢源（UCSB，师承外延）、韩松（MIT，高效AI硬件共同体）、Zhongming Yu（UCSD）、黄古玥（UCSB）等为代表；产业端以无问芯穹创始班底为核心——颜深根（CTO，商汤背景）与戴国浩分别覆盖算力平台工程与算法-芯片联合优化两端。无问芯穹累计近10亿元融资、与模速空间共建算力生态，使这一圈层的产业辐射力远超一般青年学者。

**总体评价：** 戴国浩的connection网络呈"单点深根、多向开花"结构——根系深植于NICS-EFC一个实验室（本硕博博后12年），但通过无问芯穹这一产业平台和上交DAI Lab这一学术平台，将清华系的技术范式（算法-编译-架构联合优化、稀疏计算软硬协同）成建制地输出到上海的大模型产业生态中。他是观察"NICS-EFC人才外溢效应"的最佳样本之一：汪玉-夏立雪-戴国浩-曾书霖的师生创业链条，与汪玉-姚颂-单羿的深鉴科技链条构成了该实验室两代产学研转化的双螺旋。
