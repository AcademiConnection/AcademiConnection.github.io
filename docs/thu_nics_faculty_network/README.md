# 清华大学NICS-EFC实验室 学术关系网络报告

## 团队简介

本报告集涵盖清华大学电子工程系汪玉教授创建的NICS-EFC实验室（高效能计算与信号处理研究组）核心教师及关键校友的学术关系网络。NICS-EFC实验室聚焦智能芯片、高能效电路与系统、领域专用加速器设计、高效深度学习、多智能体强化学习等方向，是中国AI硬件加速领域的顶尖研究团队，也是产学研结合的标杆——孵化了深鉴科技（被赛灵思约3亿美元收购）和无问芯穹（累计融资近10亿元）两家明星企业。

## 团队架构

NICS-EFC以汪玉教授为核心，形成了"学术研究→知识产权转化→创业孵化→回馈学校"的完整产学研闭环。实验室核心教职包括宁雪妃（高效深度学习）、余金城（多机协同/具身智能），关键校友包括韩松（MIT副教授，深鉴科技联合创始人）、于超（深圳研究生院助理教授，MAPPO算法作者）、戴国浩（上海交大副教授，无问芯穹首席科学家）。

实验室的创业谱系形成两条清晰的"师徒搭档"链条：第一条是"汪玉-姚颂（本科）-韩松-单羿"创立深鉴科技（2016→2018被赛灵思收购），第二条是"汪玉-夏立雪（博士）-戴国浩-颜深根"创立无问芯穹（2023至今）。这两条链条代表了中国高校科技成果转化的成功范式。
