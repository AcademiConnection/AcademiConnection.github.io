## 五、业界合作关系深度分析

### 5.1 鹏城实验室双聘与鹏城云脑项目

陈杰于2018年加入北京大学的同时受聘为鹏城实验室双聘教师，这一身份是其产业合作网络的核心支柱。鹏城实验室（Pengcheng Laboratory）是由广东省政府批准设立、深圳市政府建设的二类事业单位，以网络通信、人工智能和网络空间安全为重点研究方向，汇聚31位院士和2000余位各类人才。

**鹏城云脑重大科技基础设施项目**：陈杰作为课题负责人主持"鹏城云脑网络智能重大科技基础设施"项目（PCL2021A13，2021年6月至2025年12月，经费2,167万元）。该项目由鹏城实验室牵头，联合华为、北京大学、清华大学等单位协同攻关，建成国内首个全国产芯片超大规模AI智算集群。平台连续斩获IO500、AIPerf500等多项国际榜单全球第一，支撑上千个国产大模型研发。该项目先后获2023年度广东省科技进步特等奖和2025年度国家科技进步一等奖（2026年7月公布）。其主持课题属于项目组成部分，个人完成人身份公开资料未核实。

**在鹏城实验室的角色**：高文院士为鹏城实验室主任兼网络智能研究部责任院士，田永鸿为网络智能部副主任兼云脑研究所所长兼鹏城云脑技术总师，陈杰作为双聘教师参与网络智能研究部的科研工作。网络智能研究部下设云脑研究所、开源研究所、视觉智能研究所、云脑使能研究所，拥有500余人研究团队。

**华为合作关系**：通过鹏城云脑项目，陈杰与华为形成间接但深度的产业合作关系。鹏城云脑基于华为昇腾AI芯片构建全国产智算集群，涉及芯片互联、全栈软件系统（含CANN、MindSpore等华为软件栈）等关键技术。2024年华为"祖冲之奖"的授予也体现了这一产业关联。

### 5.2 百度飞桨产学研合作与AI4Science产业化

**百度飞桨与RT-DETR**：陈杰与百度PaddleDetection团队在实时目标检测方向有明确的产学研合作。RT-DETR（Real-Time DEtection TRansformer）论文由百度与北京大学联合发表（百度为第一单位，陈杰为通讯作者），该成果为首个在速度和精度上同时超越YOLO系列的端到端Transformer检测器，2024年获CVPR年度最有影响力论文排名第二。RT-DETR代码已开源至百度飞桨PaddleDetection框架（github.com/PaddlePaddle/PaddleDetection），成为飞桨生态中目标检测的核心模型之一，被产业界广泛部署应用于自动驾驶、视频监控等场景。

**医学AI产业化**：陈杰主持多项医学人工智能应用项目，包括深圳市医学研究专项资金重点项目"人工智能辅助的酶工程及其生物医药应用"（300万元，2024—2026）、广东省高水平大学冲补强计划AI4S交叉研究专项"面向First-in-Class原研药发现的生命小系统动力学"（200万元，2024—2026，联合主持）、"AI驱动的共价药物靶标发现和分子设计"（50万元，2024—2026，联合主持）等。广东省防控新型冠状病毒感染科技攻关应急专项"小样本新型冠状肺炎的多模态可解释性早期诊断"（800万元，2020—2021，主持）已结题。此外，深圳市发改委"大规模医疗健康仿真实验系统项目"（4,339.50万元，2022—2025，主持）为医疗AI仿真系统的产业化提供了基础设施支撑。

**产学研交流**：2025年4月，陈杰参与北京大学信息工程学院与无锡市集成电路产业科技镇长团的交流活动，就人工智能领域研究进行介绍，推动产学研协同发展。

## 七、Connection圈层总结

陈杰的学术关系网络呈现出以"高文—田永鸿—陈杰"研究三角为轴线、以"北京大学—鹏城实验室—华为/百度"为三角支撑的多层次结构，兼具欧洲学术根基和中国产业落地的独特特征。

**第一圈层（核心研究三角）**：高文院士、田永鸿教授与陈杰副教授构成北大深圳校区AI研究的核心三角。北大官方新闻反复以"高文院士、田永鸿教授、陈杰副教授研究团队"指称这一集体。三人共同获得2023年广东省科技进步特等奖、2024年首届"祖冲之奖"年度重大成果奖和2025年度国家科技进步一等奖（2026年7月公布）。陈杰与田永鸿并非师生关系——陈杰博士毕业于哈工大，田永鸿博士毕业于中科院计算所，两人在北大深研院形成独立PI间的联合团队合作关系。陈杰与高文的合作则可追溯至2006年博士期间论文，跨越哈工大、奥卢大学和北京大学三个阶段。高文为鹏城实验室主任，田永鸿曾任信息工程学院院长（2022年6月—2025年6月），现为网络智能部副主任兼云脑研究所所长，陈杰为双聘教师，形成"院士挂帅—教授执行—副教授攻关"的层级搭配。

**第二圈层（欧洲学术根基）**：奥卢大学CMVS中心是陈杰的学术"第二故乡"。Matti Pietikäinen作为CMVS中心主任和LBP方法奠基人，与陈杰共事十余年并共同发表多篇TPAMI论文。Guoying Zhao同为CMVS中心核心成员，在局部特征描述子和人脸分析方向与陈杰长期合作。这段欧洲经历赋予了陈杰在视觉特征表示领域的深厚根基——其2010年TPAMI论文WLD描述符（引用1,300+）即诞生于此时期，并成为其学术生涯的重要奠基性工作。

**第三圈层（国内跨机构合作者）**：山世光（中科院计算所）自博士期间延续合作至今。纪荣嵘（厦门大学）在神经架构搜索和目标检测方向形成跨校TPAMI论文合作链条，且合作网络中反复出现田永鸿的身影，构成"北大—厦大"学术纽带。周鹏（广州国家实验室）在AI4S方向形成"北大—广州国家实验室"合作联盟，2025年1月Nature Machine Intelligence论文即为此联盟的标志性成果。

**第四圈层（产业合作网络）**：鹏城实验室双聘身份是陈杰产业合作的核心枢纽。鹏城云脑项目将陈杰与华为昇腾芯片生态深度绑定——他主持的鹏城云脑重大科技基础设施课题（2,167万元）直接服务于全国产AI算力系统的建设与优化。百度飞桨生态通过RT-DETR产学研合作形成另一产业支点——该模型开源至PaddleDetection框架，被产业界广泛部署，2024年获CVPR年度最有影响力论文第二名。医学AI方向的多项省市重大项目（累计经费逾5,000万元）将学术研究与酶工程、药物发现、医学影像诊断等产业应用场景紧密连接。

**独特定位**：陈杰是本系列报告覆盖学者中唯一拥有十余年欧洲（芬兰奥卢大学）全职研究经历、随后深度参与中国国产AI算力基础设施建设（鹏城云脑）、同时在AI4Science方向产出Nature Machine Intelligence级别成果的学者。其学术轨迹横跨"欧洲局部特征表示传统—中国大模型与具身智能前沿—AI4Science交叉创新"三个阶段，在"国际学术根基—国家级算力工程—产业开源落地"三个维度均保持了独特贡献。2025年度国家科技进步一等奖（2026年7月公布）和CVPR 2024年度最有影响力论文的双重认可，标志着其在工程系统和学术研究两个维度均达到了国际领先水平。
