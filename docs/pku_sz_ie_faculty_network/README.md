# 北京大学深圳研究生院信息工程学院团队 学术网络报告

本目录收录北京大学深圳研究生院信息工程学院（及科学智能学院）五位学者的学术关系网络报告，覆盖田永鸿、王荣刚、张健三位教授，陈杰副教授与袁粒助理教授。该团队依托北京大学视频与视觉技术国家工程研究中心（深圳）和鹏城实验室，形成了以"高文—田永鸿—陈杰"研究三角为轴线、以"北京大学—鹏城实验室—华为/百度"为三角支撑的学术格局：田永鸿作为信息工程学院院长、鹏城云脑技术总师，主导超大规模国产智能算力系统建设；王荣刚作为副院长、广东省超高清沉浸媒体技术重点实验室主任，深耕三维沉浸影像与超高清编解码；张健的VILLA实验室聚焦压缩感知、AIGC生成与安全。

团队边界须特别澄清：田永鸿与袁粒、陈杰之间均为同事与合作关系，而非师生关系。陈杰博士毕业于哈尔滨工业大学（2007年）、曾在芬兰奥卢大学CMVS中心工作十一年，2018年回国后作为独立PI与田永鸿组成联合团队，北大官方新闻以"高文院士、田永鸿教授、陈杰副教授研究团队"指称这一稳定研究集体，三人共同获2025年度国家科技进步一等奖（鹏城云脑）。袁粒博士毕业于新加坡国立大学（2021年，师从颜水成、冯佳时实验室），为科学智能学院独立PI，2024年与田永鸿联合发起Open-Sora Plan，田永鸿在相关合作中是合作PI/联培指导者而非袁粒的导师。张健与田永鸿则分属VILLA与PKU-ML两个不同课题组，王荣刚与中科院计算所高文院士为长期科研合作关系（2020年国家技术发明一等奖第三完成人），其博士导师未公开披露、不以"加入AVS工作组"推定师生关系。

## 研究方向与圈层结构概述

本目录五份报告呈现四大研究主轴：一是智能算力与AI4S链（田永鸿—陈杰），以鹏城云脑II全国产E级AI算力平台、盘古α两千亿参数模型、SpikingJelly脉冲神经网络框架和Nature Machine Intelligence病毒变异预测工作为标志；二是超高清与沉浸媒体链（王荣刚），主持IEEE 1857.9沉浸视频编码等国际国内标准，建设广东省超高清沉浸媒体技术重点实验室（高文院士任学术委员会主任）；三是视觉重建生成与安全链（张健），从ISTA-Net深度展开网络到T2I-Adapter、EditGuard等AIGC安全成果；四是多模态与生成式AI链（袁粒），以VOLO、T2T-ViT视觉架构和ChatExcel、ChatLaw应用为代表。

圈层结构上，第一圈层为高文院士—田永鸿的师承与鹏城实验室正副职搭配轴心；第二圈层为深研院校内学术搭档（陈杰的AI4S联合团队、黄铁军与田永鸿的脉冲视觉合作、袁粒的AIGC搭档关系）；第三圈层为跨机构合作网络（中科院自动化所李国齐、广州国家实验室周鹏、华为诺亚方舟实验室、KAUST的Bernard Ghanem等）；第四圈层为深圳产业生态（华为、百度、大疆、京东方、兔展智能等）。需注意张健与田永鸿为同院不同课题组（VILLA与PKU-ML），直接合著记录较少。

## 产业转化亮点

- **鹏城云脑产业化**：基于华为昇腾构建首个全国产E级AI智算集群，带动10余个万卡智算集群、25个智算中心建设，获2023年广东省科技进步特等奖与2025年度国家科技进步一等奖；盘古α为业界首个全开源2000亿参数中文大模型。
- **RT-DETR开源落地**：首个速度精度同时超越YOLO系列的端到端Transformer检测器，开源至百度飞桨，获CVPR 2024年度最有影响力论文第二名。
- **超高清全链条体系**：王荣刚参与的项目获2020年度国家技术发明一等奖（第三完成人）与2025年度国家科技进步二等奖，与大疆、央视、京东方协同攻关超高清摄录一体机、显示驱动芯片；自由视点系统应用于北京冬残奥会。
- **AIGC生态影响**：张健团队T2I-Adapter被Stability AI集成至Stable Doodle、Hugging Face下载超300万次，获华为火花奖；VILLA毕业生大量入职字节跳动、腾讯、美团。
- **应用产品化**：袁粒指导学生团队开发ChatExcel（自然语言操作表格），其博士生金鹏的高能效大模型架构被美团LongCat系列模型采用。
