## 三、学生培养情况

田永鸿自加入北京大学后开始独立指导研究生，课题组（PKU-ML）依托视频与视觉技术国家工程研究中心运行。以下列出已确认或高度可信的主要学生（博士或研究团队成员），每人均附有合作证据。

### 1. 聂志伟（博士毕业生，高文、田永鸿联合指导；陈杰主页另将其列为所指导博士生，可能为联合培养，公开口径存在差异）

聂志伟于北京大学获计算机博士学位，据百度百科及多家学术媒体报道，其博士期间"师从北京大学高文院士、科学智能学院创院院长田永鸿教授"；陈杰官方主页在"学术荣誉"部分亦将聂志伟列为其指导博士生。综合来看，聂志伟由高文、田永鸿联合指导，陈杰主页另将其列为所指导博士生，可能为联合培养，公开口径存在差异。博士毕业即受聘于复旦大学类脑智能科学与技术研究院，任长聘教轨助理教授、博士生导师，组建AI4EDGE Lab，为独立PI。近五年在Nature Machine Intelligence、Nature Communications、ICML、AAAI等期刊会议发表学术论文近三十篇。他深度参与鹏城云脑系列集群建设，具有4,000卡以上大规模AI集群训练经验，作为核心成员支撑了首个国产软硬件一体AI生命科学研究平台"鹏程·神农"的全流程构建（鹏城国家实验室与华为联合发布）。是2025年1月Nature Machine Intelligence论文E2VD的共同作者，在田永鸿与陈杰联合广州国家实验室周鹏研究员的AI4S研究中担任博士生骨干。

### 2. 陈光耀（2023年博士毕业，田永鸿指导博士生）

陈光耀为北京大学计算机学院2018级博士研究生，计算机应用技术专业，师从田永鸿教授。2023年7月通过博士论文答辩，同年获北京大学优秀博士学位论文奖。博士论文题目为《开放视觉场景下未知类建模与学习方法研究》，聚焦开放场景下未知类检测与新类别发现。研究成果已在IEEE TPAMI、NeurIPS、ICCV等国际顶级期刊会议发表论文十余篇，并作为主要技术骨干参与编制全球首个人工智能模型表示与压缩技术国际标准IEEE 2941和国内首个AI模型技术国家标准。成果已在百度、华为等企业产品中获得应用。

### 3. 翟云鹏（2023年博士毕业，田永鸿指导博士生）

翟云鹏于2023年12月通过博士论文答辩。研究方向涉及行人重识别和无监督学习。在IJCV、IEEE TKDE等国际期刊发表论文，与田永鸿、彭沛翔等合作发表多篇关于群体进化博弈的无监督行人重识别研究工作。

### 4. 李马（2022年博士毕业，田永鸿指导博士生）

李马于2022年12月通过博士论文答辩。研究方向涉及视频编码与视频恢复。其论文"Residual-Based Video Restoration for HEVC Intra Coding"（与田永鸿、黄铁军合作）获2018年IEEE多媒体大数据国际会议（BigMM 2018）最佳论文奖，田永鸿为通讯作者。

### 5. 李佳宁（2022年博士毕业，田永鸿指导博士生）

李佳宁于2022年5月通过博士论文答辩。研究方向聚焦事件相机视觉与脉冲神经网络，在IEEE TIP、AAAI、CVPR等顶级期刊会议发表多篇论文，包括异步时空记忆网络用于连续事件目标检测、视网膜形态目标检测等工作。与田永鸿、黄铁军、朱林等人合作密切，是课题组在神经形态视觉方向的核心学生之一。

### 6. 朱林（2022年博士毕业，田永鸿与黄铁军联合指导/密切合作的博士生）

朱林于2022年5月通过博士论文答辩。研究方向为脉冲相机超高时间分辨率视觉重建与事件视频重建。其博士论文相关工作同时署名田永鸿与黄铁军，公开信息不足以明确区分唯一导师，据多源论文署名推断为课题组与黄铁军团队联合培养/密切合作指导。博士论文相关工作发表于IEEE TPAMI（与田永鸿为通讯作者）和CVPR，提出基于脉冲神经网络的潜在辅助事件视频重建方法。与李佳宁同为课题组神经形态视觉方向的主要贡献者。

### 7. 彭沛翔（约2016—2017年博士毕业，田永鸿指导博士生，现为研究团队成员）

彭沛翔为课题组早期毕业的博士生，毕业时间约在2016—2017年间。毕业后继续以研究团队成员身份与田永鸿合作，在行人重识别、群体行为分析、强化学习等方向发表多篇论文（IJCV、IEEE TKDE等），并参与指导课题组后续学生。在课题组内部承担类似"副导师"的角色，2023年仍以共同作者身份出现在翟云鹏等人的论文中。

## 五、业界合作关系深度分析

### 5.1 鹏城云脑与华为昇腾生态

田永鸿在鹏城实验室的角色是其业界合作网络中最核心的一环。作为鹏城云脑技术总师，他主导了超大规模国产智能算力系统的底层系统设计与技术创新。

**鹏城云脑项目概况**：该项目由鹏城实验室牵头，联合华为公司、北京大学、清华大学等单位协同攻关，建成国内首个全国产芯片（华为昇腾Ascend）超大规模AI智算集群。田永鸿与团队深耕底层系统设计，创新超大规模国产AI集群的高效互联架构，通过软硬件深度优化大幅提升大模型训练并行效率。平台连续斩获IO500、AIPerf500等多项国际榜单全球第一，支撑上千个国产大模型研发。2025年度获国家科技进步一等奖，高文院士为主持人，田永鸿为核心牵头人之一。

**产业化带动效应**：项目带动了华为昇腾大规模产业化，牵引科大讯飞、中国移动等互联网和运营商企业搭建10余个万卡昇腾智算集群，相关国产芯片累计出货超100万片。项目同步为讯飞星火、移动九天等国内超半数国产大模型的训练迭代及规模化应用提供全链条支撑，引领全国25个智算中心建设。

**盘古α模型**：2021年4月，田永鸿在华为HDC全球开发者大会上发布业界首个全开源2000亿参数中文预训练语言模型"盘古α"。该模型基于鹏城云脑II大科学装置，在高文院士亲自布局和方向性指导下，田永鸿教授和曾炜副研究员带领实验室师生联合鹏城实验室、华为诺亚方舟实验室和MindSpore团队组建技术联合攻关团队完成。模型在16个下游任务中大部分指标优于SOTA模型。这是国产全栈式AI基础设施支持2000亿级超大规模语言模型训练的首次验证。

**与华为的具体合作维度**：

| 维度 | 内容 |
|------|------|
| 芯片层面 | 基于华为昇腾AI芯片构建全国产智算集群 |
| 软件层面 | 全栈软件系统协同优化，包括CANN、MindSpore等华为软件栈 |
| 模型层面 | 联合华为诺亚方舟实验室开发盘古α超大规模预训练模型 |
| 生态层面 | 带动全国多地智算中心落地，形成可复制的国产智算建设方案 |

## 七、Connection圈层总结

田永鸿的学术关系网络呈现出以"高文—田永鸿"师承关系为轴线、以"北京大学—鹏城实验室—华为"为三角支撑的多层次结构。

**第一圈层（核心导师与合作者）**：高文院士是田永鸿整个职业生涯的核心人物。田永鸿本人公开确认高文为其导师（2024年北大计算机学院毕业典礼发言）。从博士阶段的师生关系，到北京大学的同事关系，再到鹏城实验室的正副职搭档关系，两人的合作贯穿视频编码（IEEE 1857标准）、数字视网膜概念提出（2018年）、鹏城云脑系统建设（2018年至今）和AI4S研究（2025年1月Nature Machine Intelligence）等全部关键节点。高文是鹏城实验室主任，田永鸿是网络智能部副主任兼云脑研究所所长，形成了"院士挂帅+杰青执行"的典型合作模式。

**第二圈层（校内学术搭档）**：黄铁军是田永鸿在神经形态视觉和脉冲相机方向最密切的合作者，两人在2017年国家技术发明二等奖中分列前两位（黄铁军第1、田永鸿第2），在多篇TPAMI论文中合作发表，同属2024年北大优秀研究生导师团队。陈杰副教授是AI4S方向的长期联合团队合作者，与高文、田永鸿组成稳定研究三角，成果发表于Nature Machine Intelligence。袁粒是信息工程学院独立PI，与田永鸿在AIGC视频生成方向构成学术搭档，联合发起Open-Sora Plan。课题组毕业生彭沛翔等以研究团队成员身份留组继续合作。

**第三圈层（跨机构合作者）**：中科院自动化所李国齐是SpikingJelly框架的共同通讯作者（2023年Science Advances），形成了"北大—中科院"脉冲神经网络合作联盟。广州国家实验室周鹏研究员在AI4S方向合作（2025年1月Nature Machine Intelligence）。华为诺亚方舟实验室在盘古α超大规模预训练模型开发中联合攻关。

**第四圈层（产业合作网络）**：华为是田永鸿产业合作的最核心伙伴，鹏城云脑项目基于华为昇腾芯片构建，形成了深度的"学术—产业"绑定关系。海康威视、海信网络科技、云天励飞等企业在视频智能处理和数字视网膜产业化中参与合作。百度、华为等企业在IEEE 2941标准成果转化中受益。AI Agent联合实验室（与元空智能共建）和全球科学智能发展联盟是科学智能学院层面的新型产学研协同平台。

**独特定位**：田永鸿是唯一同时深度参与"底层算力系统建设"（鹏城云脑）、"前沿类脑计算研究"（脉冲神经网络、SpikingJelly）和"国际标准制定"（IEEE 2941）三个维度的学者。他既是IEEE Fellow和国家杰青（含延续资助），又是鹏城云脑技术总师和曾任信息工程学院院长（2022年6月—2025年6月），在"学术研究—工程系统—行政管理"三重角色中保持了罕见的平衡。2025年度国家科技进步一等奖和2025年IEEE Hans Karlsson标准奖的双重认可，标志着他在工程系统和标准制定两个维度均达到了国际顶级水平。
