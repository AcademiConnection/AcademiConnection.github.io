## 四、VILLA实验室与学生培养

### 4.1 实验室概况与研究方向

视觉信息智能学习实验室（Visual-Information Intelligent Learning LAB，简称VILLA）由张健于2019年创立，依托北京大学信息工程学院运行，实验室网站为 https://villa.jianzhang.tech/ 。VILLA同时属于北京大学视频与视觉技术国家工程研究中心（深圳分中心）和广东省超高清沉浸媒体技术重点实验室。

VILLA的核心研究方向为"视觉重建生成与安全"，具体涵盖以下子方向：

- **压缩感知与图像重建**：ISTA-Net（CVPR 2018，引用超1800次）提出迭代软阈值算法启发的深度展开网络，兼具可解释性和高效性，已成为压缩感知深度展开方法的代表性工作；后续工作包括GSR（组稀疏表示模型，ESI高被引论文）、TransCL（TPAMI 2023）、PCNet（TPAMI 2025）、IDM（TPAMI 2025）等。
- **扩散模型与视觉内容生成**：T2I-Adapter为文生图扩散模型提供可控适配器，在GitHub获超3700星标；DragonDiffusion和DiffEditor实现扩散模型上的拖拽式图像编辑；ReVideo实现视频运动与内容控制重制。
- **AIGC内容鉴伪与版权保护**：EditGuard（CVPR 2024）实现多功能图像水印与篡改定位；CRoSS（NeurIPS 2023）利用扩散模型实现可控鲁棒安全图像隐写；GS-Hider（NeurIPS 2024）将信息隐藏于3D高斯泼染。华为火花奖获奖项目即针对"面向AIGC溯源证真的大容量数字水印技术"。

## 七、Connection圈层总结

张健的学术关系网络呈现以"哈工大博士训练—北大/KAUST博士后—北大深研院独立建组"为主线、以"压缩感知—扩散模型—AIGC安全"为研究主轴的多层次结构。

**第一圈层（师承与博士后合作导师）**：赵德斌教授（哈工大博士导师）、高文院士（北大博士后合作导师）和Bernard Ghanem教授（KAUST博士后合作导师）构成张健学术训练的三大支柱。赵德斌在哈工大为其奠定了稀疏表示与压缩感知的理论基础；高文院士在北大为其提供了视频编码与视觉技术的学术平台（NERCVT），且高文本人同为哈工大博士（1988年），存在校友传承关系；Bernard Ghanem在KAUST将其引入深度学习与计算机视觉的前沿研究，两人后续保持长期合作（ISTA-Net等高引论文及2025年TPAMI论文均可佐证）。这三位导师的信息均由张健个人主页（jianzhang.tech/cn/）明确披露，非从共著关系推断。

**第二圈层（同校同事与跨机构合作者）**：田永鸿教授为同院同事但分属不同课题组（PKU-ML vs VILLA），两人在学院和NERCVT层面交集但研究方向侧重不同。熊瑞勤研究员同属NERCVT体系，在多篇论文中与张健形成跨校区合作关系。KAUST的赵琛（Chen Zhao）通过Bernard Ghanem的连接成为长期跨机构合作者。此外，论文署名显示与马思伟教授（NERCVT副主任）、清华大学深圳国际研究生院张永兵教授等存在合作论文。

**第三圈层（VILLA实验室成员）**：陈斌和牟冲是VILLA最核心的两位博士毕业生，分别代表压缩感知和AIGC两个研究方向的技术骨干，毕业后均入职字节跳动。VILLA实验室自2019年创立以来已培养30余位硕士和博士毕业生，其中多人转博继续在北京大学深造，多人入职字节跳动、腾讯、美团等头部科技企业，形成了产学研紧密结合的人才输送通道。

**第四圈层（产业合作网络）**：张健的产业合作网络以深圳为地理中心，辐射字节跳动、华为、OPPO、腾讯、创维、兔展智能等企业。其中兔展智能通过联合实验室形式实现深度绑定（北京大学深圳研究生院-兔展智能AIGC联合实验室），华为通过火花奖和MindSpore项目实现深度技术对接，字节跳动既是论文合作单位也是VILLA毕业生的主要就业去向（3人入职），腾讯通过ARC Lab联合研发和毕业生输送（2人入职）建立联系。T2I-Adapter被Stability AI集成至Stable Doodle产品、与Hugging Face合作推出SDXL适配器（下载量超300万次），标志着VILLA的研究成果已在全球AIGC生态中产生实际产业影响。

**独特定位**：张健在北大深圳研究生院信息工程学院的定位独特——他是VILLA实验室唯一负责人，研究重心聚焦于"视觉重建生成与安全"这一交叉领域，将压缩感知的优化理论与深度学习的生成能力相结合（ISTA-Net → IDM系列工作），同时延伸至AIGC安全与版权保护（EditGuard、CRoSS、火花奖项目）。与同院的田永鸿教授相比，张健更侧重底层视觉算法与AIGC安全应用，田永鸿更侧重分布式机器学习系统与超大规模算力基础设施，两者在学院层面互补。华为火花奖的获得标志着张健在产学研深度融合方面获得产业界最高级别的认可之一。
