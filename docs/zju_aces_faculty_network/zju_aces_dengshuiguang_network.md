## 二、教育背景与职业履历

邓水光于 2002 年获浙江大学计算机专业学士学位，随后在浙江大学计算机科学与技术学院直接攻读博士学位，2007 年获博士学位，博士阶段的研究即聚焦 Web 服务自动组合等服务计算核心问题，其 2007 年发表于《软件学报》的论文《基于回溯树的 Web 服务自动组合》署名为邓水光、吴健、李莹、吴朝晖，显示其博士训练是在以吴朝晖、吴健为代表的服务计算团队中完成，其正式博士指导教师为吴朝晖还是吴健，公开资料未见明确记载（待核实）。其后他与 Zhaohui Wu、Jian Wu 合著了由 Academic Press 出版的专著《Service Computing》，可视为这一学术谱系的延续。

博士毕业后邓水光留校任教，从讲师/副教授逐步晋升为教授、博士生导师，并获聘浙江大学求是特聘教授。2014 年和 2015 年分别赴美国麻省理工学院与斯坦福大学访问研究，拓展了在国际服务计算与软件工程界的合作网络。近十余年来，他主持国家杰出青年基金项目、国家重点研发计划重点专项项目、国家自然科学基金区域联合重点项目、浙江省自然科学基金重大项目等，并先后担任浙江省现代服务业电子服务工程技术研究中心副主任、浙江大学计算机学院-筑家易智慧城市研究中心主任、CCF 杭州分部副主席等职务（另曾任浙江大学社会科学研究院副院长，2021年11月—2025年7月，据校社科院2025年7月22日任免文件），学术与行政管理双线并进。

邓水光长期通过浙江大学计算机学院与软件学院招收硕士、博士研究生。可确认的直接指导博士生代表为赵海亮：2019 年获武汉理工大学学士学位，2024 年获浙江大学计算机科学与技术专业博士学位，师从邓水光教授，其间受 CSC 资助赴南洋理工大学联合培养（合作导师汤学彦），现为浙江大学软件学院平台"百人计划"研究员，研究方向为分布式计算、边缘计算与服务计算，曾获 ICWS 2019 最佳学生论文奖。其余历年毕业博士的完整名单主页未集中公开（待核实）。

## 四、学术合作网络

### 4.1 实验室内部合作（与尹建伟等）

邓水光是浙江大学 ACES（先进计算与新兴软件/服务实验室，以尹建伟教授为学术带头人）的核心教师之一。该实验室横跨浙大计算机学院与软件学院，师生规模近 200 人，围绕量子计算、边缘计算、智能计算及其赋能的新兴服务展开研究。尹建伟与邓水光长期深度合作：二人共同主导的 ISO/TS 5777、ISO/TS 5788 互联网医疗健康服务国际标准获多国投票通过立项，是 ISO 内首个立项的互联网医疗健康服务国际标准；2026 年公布的教育部科学研究优秀成果奖（工程技术）一等奖项目"复杂服务系统跨界融合关键技术与应用"由尹建伟牵头、邓水光为主要完成人（合作者还包括哈工大王忠杰、郑小林、李龙飞、金小艇等）。两人还多次共同组织 CCF 先进计算与新兴服务高峰论坛、中国数字服务大会等学术会议。此外，李莹（浙大教授）、吴朝晖、吴健等构成其学术谱系的源头合作者。

### 4.2 跨机构合作

国内层面，邓水光与上海交通大学曹健（Jian Cao，云计算与服务供给方向多篇合作论文）、杭州师范大学李文娟（Wenjuan Li）、哈尔滨工业大学王忠杰（CCF 服务计算专委主任，共同担任秀湖会议执行主席）等保持稳定合作；在数据科学与工程专业学位项目中，其所在团队与阿里巴巴、华为、国家电网建立了联合培养合作。其论文合作网络还覆盖电子科技大学、中南大学等高校（其同期与浙大服务计算团队的邝砾后任职中南大学，同期关系待核实）。

### 4.3 国际合作

国际层面，其论文署名显示与维也纳工业大学 Schahram Dustdar、悉尼大学 Albert Y. Zomaya、圣路易斯华盛顿大学 Yixin Chen 等服务计算/分布式系统领域知名学者均有合作；2014-2015 年在 MIT、Stanford 的访问经历进一步连接了美国学术圈。学生培养上，其博士生通过 CSC 项目赴新加坡南洋理工大学等机构联合培养，形成持续的国际化通道。

## 七、Connection圈层总结

邓水光的学术关系网络可分四个圈层。第一圈层是学术谱系源头与合作核心：吴朝晖、吴健、李莹所在的浙大服务计算团队是其学术起点，尹建伟则是其当前最紧密的合作伙伴，二人构成 ACES 实验室的双核心，并共同将合作延伸至 ISO 国际标准与国家级科技奖励。第二圈层是实验室梯队：以赵海亮、席萌为代表的已出站青年学者，以及孙斌强、陈明帅、程冠杰、杜鑫、智晨、秦臻等研究员组成的团队骨干，形成了服务计算—边缘计算—类脑计算—大模型软件工程的多方向人才蓄水池。第三圈层是国内学术共同体：以 CCF 服务计算专委为枢纽，连接哈工大王忠杰、上交曹健、北大金芝等软件工程与服务计算学者。第四圈层是产业与国际网络：华为、阿里巴巴、国家电网等产业伙伴，MIT、Stanford 的访问经历，以及 Dustdar、Zomaya、Yixin Chen 等国际同行。

总括而言，邓水光是浙大服务计算谱系从"吴朝晖—吴健时代"向"智能服务与类脑计算时代"过渡的关键枢纽人物：向上承接学派，向下培养梯队，横向联动产业与国际标准组织。其网络结构呈现"实验室双核心（与尹建伟）+ 学会枢纽（CCF 服务计算专委）+ 产业转化（专利与 ISO 标准）"三位一体的特征，是理解中国服务计算学界产学研生态的一个典型样本。
