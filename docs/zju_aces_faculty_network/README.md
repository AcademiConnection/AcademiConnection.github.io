## 二、各位教师的角色定位

尹建伟与邓水光构成 ACES 实验室的"行政-学术"双核。尹建伟深耕服务计算、业务流程管理与数智服务技术，2019年获国家杰青，先后执掌软件学院（2024年起任院长）与宁波国际科创中心，并于2026年7月29日经浙大计算机学院干部宣布会任命接替调任杭州电子科技大学副校长的任奎出任计算机学院院长——至此浙大计算机学院院长继任链为：陈刚（2017-2024）→ 任奎（2024-2026.7）→ 尹建伟（2026.7起）。

邓水光是实验室的科研产出核心与国际学术名片。国家杰青（2021）、万人计划青年拔尖人才、IET/EAI双会士，研究方向服务计算、API与代码智能、智能化软件工程，2020年代在API大模型（与业界的代码智能合作）方向布局深远。他获国家科技进步二等奖（2010）及省部一等奖多项，2025年度教育部科学研究优秀成果奖（工程技术）一等奖"复杂服务系统跨界融合关键技术与应用"由尹建伟牵头、邓水光为主要完成人，是两人合作的代表作。

两人的博士导师归属（吴朝晖/吴健团队谱系）均因公开信息有限标注"（待核实）"，但二人与原浙大校长吴朝晖院士所在的服务计算学术共同体（现代服务业/服务科学方向）的学术亲缘关系明确，是浙大"现代服务计算"学派的中生代代表。

## 三、全实验室关系网络的整体观察

第一，"行政双肩挑"的顶配结构。实验室两位核心教师分别执掌计算机学院与社科院，叠加软件学院、宁波国际科创中心的建制资源，是浙大计算机学科内行政密度最高的组合之一，为实验室在"数智服务+现代服务业"方向的产学研布局提供强支撑。

第二，谱系内生与师承待考并存。邓水光指导的博士（如赵海亮等新一代百人计划研究员）已开始回流浙大，形成初步的内生繁殖；但两人与上一代（吴朝晖谱系）的正式师承关系缺乏一手公开记录，报告均采取审慎标注。

第三，产学研双引擎。实验室长期服务国家现代服务业战略，2025年度教育部一等奖与多项省部级奖励均面向产业落地；邓水光在API/代码智能方向与头部企业的合作，以及尹建伟在宁波国际科创中心的载体建设，构成"奖项+平台"两条产业通道。

第四，体量精干的"双核小组"。与大型实验室不同，ACES 以两位教授为核心，通过联合指导（两人共同指导的博士生）与跨机构合作（服务计算专委、IEEE TSC等学术组织网络）放大影响力，结构上属于"小核心、大网络"类型。
