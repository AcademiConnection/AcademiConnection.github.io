## 二、各位教师的角色定位

陈华钧是实验室创始人与学术带头人，浙大生物工程学士（2000）、计算机博士（2004），曾访学耶鲁大学与卡内基梅隆大学。他长期耕耘知识图谱方向，牵头发起中文开放知识图谱OpenKG（2016），与阿里巴巴共建知识引擎联合实验室，构建了60亿实体、600亿三元组的千亿级商品知识图谱（获钱伟长一等奖、教育部技术发明一等奖），近年转向知识增强大模型（KnowLM、OneKE、KAG）与AI4Science（在Nature Machine Intelligence、Nature Biotechnology发表论文），是国内"知识工程学派"当之无愧的领军人物。

张宁豫是实验室面向大模型时代的中坚力量，浙大博士（导师陈华钧），曾就职于之江实验室与阿里巴巴，现为软件学院副教授/研究员、启真优秀青年学者。他主导DeepKE、EasyEdit、OceanGPT（首个海洋大模型，ACL 2024）等开源项目，实验室GitHub组织zjunlp的主要运营者，学生陈想现为南京航空航天大学教授。

张文是实验室知识图谱表示学习方向的核心教师，合肥工业大学本科（2015）、浙大博士（2020，导师陈华钧），曾访学苏黎世大学，现为软件学院副教授、特聘研究员。她是NeuralKG开源框架的第一开发者，入选百度2023年度AI华人女性青年学者榜，与蚂蚁集团在知识图谱增强生成（KAG）方向深度合作。

张强是实验室AI4Science方向的引进PI，山东大学本科、中科院硕士、UCL博士（导师Emine Yilmaz）与博后，以"浙大科创百人"加入杭州国际科创中心。他专长机器学习与生物分子智造，主导蛋白质语言模型（DePLM，NeurIPS 2024）等研究，将实验室的知识增强技术延伸至生命科学，是团队学科交叉的桥梁。

邓淑敏是实验室最新一代青年教师，西安电子科技大学本科（2017保研浙大）、博士师从陈华钧（与张宁豫联合指导），曾在新加坡国立大学从事博后研究（合作导师Bryan Hooi），2026年起任浙大百人计划研究员独立建组，国家级青年人才，研究方向知识图谱与AI4Science，担任IEEE TASLP副编辑及多个顶会领域主席。

郑国轴是实验室的工程化奠基者，1978年生，2010年获浙大计算机博士学位，曾任先进技术研究院副研究员（承担高分专项），现为计算机学院副研究员。他长期承担实验室知识工程平台与工程化建设（DeepKE、NeuralKG核心贡献者），与陈华钧保持十余年合作，并兼职浙大舟山海洋研究中心开展跨学科研究，是"学术PI+工程骨干"双轮结构的另一轮。

## 三、全实验室关系网络的整体观察

ZJUKG的师资网络呈现出几个较为清晰的结构性特征。

第一是"知识图谱旗舰"的鲜明学科旗帜。实验室是国内知识图谱方向当之无愧的中心节点：OpenKG社区汇聚全国产学研力量，CCKS（全国知识图谱大会）等学术组织深度参与，培养了陈想（南航教授）等遍布全国的知识图谱研究者，形成了以浙大为根节点的国内知识工程人才树。

第二是"大厂共建实验室"的深度产业绑定。与阿里巴巴的合作始于2014年，2018年成立浙大-阿里巴巴知识引擎联合实验室（陈华钧任主任），产出藏经阁、千亿级商品知识图谱等标志性成果；与蚂蚁集团联合研发中心产出OneKE、KAG等知识增强大模型技术。相比项目制合作，这种十年期联合实验室模式使产业需求与学术产出高度耦合，是国内产学研结合的标杆案例。

第三是"内部繁殖+外源引进"的混合师资结构。张宁豫、张文、邓淑敏构成陈华钧谱系的内生传承链（其中邓淑敏为"陈华钧—张宁豫"两代联合指导，显示谱系进入第三代），张强为UCL引进的外源PI补充AI4Science能力，郑国轴提供工程化底座——四种角色互补，兼具清华THUNLP式的极简核心与哈工大SCIR式的规模组织之长。

第四是"开源社区驱动"的影响力扩张模式。zjunlp GitHub组织维护DeepKE、EasyEdit、NeuralKG、KnowLM、OneKE等十余个开源项目，OceanGPT等科学大模型系列（海洋、中医药）成为垂直领域大模型的代表作，"知识增强+开源工具链"构成实验室区别于纯NLP实验室的独特技术品牌。
