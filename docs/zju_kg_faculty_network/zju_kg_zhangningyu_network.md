## 二、教育背景与职业履历

张宁豫于浙江大学获得博士学位，博士导师为陈华钧教授（浙江大学计算机科学与技术学院求是特聘教授、知识引擎实验室创始人）。博士期间，他的研究聚焦于知识图谱构建，致力于将文本中的信息转化为结构化的实体与关系网络，使知识从线性叙述转向可计算、可推理的图结构表达。

博士毕业后，张宁豫并未直接留校任教，而是先后进入产业界与新型研发机构积累经验。他首先在之江实验室开展工作，从国家战略需求的角度审视技术价值与研究边界；随后进入阿里巴巴，参与知识图谱在搜索中的应用实践，切身体会到技术从理论走向现实的路径与挑战。这段产业经历深刻影响了他后来的研究风格——注重将知识图谱与大模型的基础研究同实际应用场景紧密结合。

此后，张宁豫回到浙江大学，进入软件学院任教，获聘副教授、研究员，并入选浙江大学"启真优秀青年学者"计划。关于用户原始信息中提到的"百人计划"：经核实，张宁豫的官方主页标注为"启真优秀青年学者"，而非浙大"百人计划研究员"。"启真优秀青年学者"是浙江大学面向优秀青年教师的遴选计划，与"百人计划"属于不同人才体系，此处予以澄清。目前他同时担任职务为智能科学与工业软件所副所长，办公地址位于浙江大学西溪校区北园东大楼六楼。

在学术兼职方面，他担任多个国际期刊的 Associate Editor，包括 TMLR、Neural Networks、Machine Intelligence Research、ACM TALLIP 及 Information Processing & Management（IP&M），并担任 ACL、EMNLP、NeurIPS、ICLR、ICML、KDD 等顶级会议的领域主席（Area Chair），ARR Action Editor，IJCAI 高级程序委员，以及多个 Nature 子刊的审稿人。

张宁豫作为陈华钧组的核心教师，独立或与陈华钧联合指导了多名博士和硕士研究生。其学生培养特点是"产学研融合"，多名学生在就读期间即参与头部互联网企业的实际项目，毕业后进入高校任教或进入产业界。以下列出代表性学生。

### 1. 陈想（南京航空航天大学教授，博士毕业生）

陈想是张宁豫与陈华钧联合指导的博士毕业生，目前任南京航空航天大学计算机科学与技术学院教授。其研究方向涵盖大模型安全与可信人工智能、自然语言处理、知识图谱、具身智能等，在 NeurIPS、ICLR、IJCAI、ACL、EMNLP 等顶级会议或期刊发表学术论文 50 余篇，其中第一作者发表 CCF/CAAI A 类论文 10 余篇，Google Scholar 引用 4000 余次。陈想曾获中国中文信息学会"博士学位论文激励计划"、江苏省信息技术学会青年科技奖、浙江大学优秀毕业生、阿里巴巴优秀学术实习生等荣誉，并入选首批江苏青年科技人才"U35培育"对象。他目前主持国家自然科学基金青年项目、CCF-滴滴盖亚学者科研基金、CAAI-华为 MindSpore 科研基金等项目，是张宁豫学生中学术发展最为突出的代表之一。

乔硕斐本科毕业于北京航空航天大学沈元荣誉学院，后进入浙江大学计算机科学与技术学院，师从张宁豫副教授与陈华钧教授。他最初以硕士身份入学，后转为博士研究生。主要研究方向为知识增强的大模型智能体及其应用，以第一作者在 ICML、NeurIPS、ICLR、ACL 等顶级会议发表多篇论文。其代表性工作包括 KnowSelf（ACL 2025，智能体知识边界感知）、语言模型提示推理综述（Reasoning with Language Model Prompting: A Survey）等。乔硕斐是张宁豫目前培养的在读博士生中成果最为突出的学生之一。

### 5.2 创业孵化与技术转化

张宁豫主导研发的多个开源系统具有显著的产业转化潜力：

- **DeepKE**：知识获取与知识抽取工具包，支持低资源、文档级和多模态场景下的实体、关系和属性抽取，已演化出 DeepKE-LLM 和 OneKe 版本，是知识图谱构建领域的重要开源工具。
- **OceanGPT·沧渊**：首个海洋领域大语言模型，被 ACL 2024 录用，在海洋科学任务和海洋工程具身智能方面展现了独特能力。
- **EasyEdit**：知识编辑框架，ACL 2024 论文，GitHub 星标数可观，已成为知识编辑领域的事实标准工具之一。
- **KnowLM/智析（Zhixi）**：知识增强大语言模型框架，包含预训练和微调的标准化框架。
- **LightMem**：轻量记忆系统；**SkillNet**：智能体技能图谱系统；**Mechanist**：AI机理科学家系统。

这些开源项目不仅服务于学术社区，也为产业界提供了可直接使用的技术工具。DeepKE 和 EasyEdit 在 GitHub 上的活跃度和社区贡献体现了其产业影响力。张宁豫团队的开源策略（统一在 github.com/zjunlp 下管理）形成了系统化的技术输出品牌，为未来可能的创业孵化或技术授权奠定了基础。

此外，张宁豫曾在阿里巴巴从事知识图谱在搜索中的应用实践，这段经历使他深刻理解了技术从理论走向产业的路径与挑战。其培养的学生中，多人进入或曾在头部互联网企业实习和工作，形成了学术训练与产业实践相结合的人才培养模式。

## 七、Connection圈层总结

张宁豫的学术关系网络呈现出以"知识"为核心、产学研深度融合的多圈层结构：

**第一圈层（导师与学术根基）**：以陈华钧教授为中心。张宁豫作为陈华钧的博士毕业生，继承了知识图谱与自然语言处理的研究脉络，并在大模型时代拓展至知识编辑、智能体等新方向。陈华钧不仅是其博士导师，更是长期的科研合作伙伴和学术资源支撑者。两人的"师承→合作→联合指导"模式构成了 ZJUKG 实验室的核心运转机制。

**第二圈层（实验室同事）**：以张文副教授为代表的实验室内部合作者。张宁豫、陈华钧、张文三人合著《大模型知识增强》专著，构成了实验室的"铁三角"教师团队。漆桂林教授等则为知识图谱课程教学和 OpenKG 社区提供了跨校合作支撑。

**第三圈层（学生培养网络）**：张宁豫培养的学生已开始形成独立的学术节点。陈想（南京航空航天大学教授）、邓淑敏（浙江大学百人计划研究员）是其中最为突出的代表，二人均已获得独立教职和国家级人才项目支持，分别在南航和浙大建立了自己的研究组。乔硕斐、李周博、姚云志等在读博士生则在知识编辑、知识增强智能体等前沿方向持续产出高水平成果。这一学生网络正在向南京航空航天大学、新加坡国立大学等机构辐射。

**第四圈层（产业合作网络）**：以蚂蚁集团为核心，辐射阿里巴巴、腾讯、百度、华为等头部企业。浙大-蚂蚁集团联合研究中心为最深入的产业合作平台，蚂蚁集团研究人员直接参与论文撰写和项目开发。CCF-百度松果、CCF-腾讯犀牛鸟、CAAI-华为 MindSpore 等基金构成了多企业并行合作的产业生态。张宁豫本人在阿里巴巴和之江实验室的从业经历，为其产业合作提供了人脉和经验基础。

**第五圈层（开源与学术社区）**：以 zjunlp GitHub 组织为核心的开源生态，涵盖 DeepKE、EasyEdit、OceanGPT、KnowLM 等多个高影响力项目。通过 OpenKG 社区和蚂蚁集团联合推出的 OpenSPG，张宁豫在开源知识图谱生态中扮演了连接学术界与产业界的桥梁角色。同时，通过担任 ACL、EMNLP、NeurIPS 等顶级会议的领域主席和多个国际期刊的副编辑，他在全球 NLP 和知识工程学术社区中建立了广泛的学术声誉。

总体而言，张宁豫的学术网络呈现出"根基在浙大知识引擎实验室、学生辐射全国高校、产业深度绑定蚂蚁与阿里、开源影响全球社区"的四维结构，是 ZJUKG 实验室中产学研融合特征最为鲜明的教师之一。
