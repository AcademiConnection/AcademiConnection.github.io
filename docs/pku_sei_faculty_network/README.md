# 北京大学计算机学院软件工程研究所（SEI）学术关系网络报告

## 团队简介

北京大学计算机学院软件工程研究所（Software Engineering Institute, SEI）是中国软件工程学科的发源地和最重要的研究基地之一，依托高可信软件技术教育部重点实验室（Key Laboratory of High Confidence Software Technologies, Ministry of Education）和软件工程国家工程研究中心（北京）两大国家级平台开展教学科研工作。研究所的历史可追溯至1983年杨芙清院士创建的软件工程研究团队，1999年正式建所，历经杨芙清院士（创始所长，1999—2003）、梅宏院士（第二任所长，2003—2012）、谢冰教授（第三任所长，2012年至今）三任所长的传承发展。

研究所以"青鸟工程"（国家"八五"、"九五"重点科技攻关项目）起家，建立了我国软件构件化生产的技术体系，两次获得国家科技进步二等奖；其后在网构软件、构件化应用服务器等方向持续突破，先后获得2008年国家技术发明二等奖、2018年国家技术发明一等奖（燕云DaaS系统，入选世界互联网领先科技成果）、2022年度陈嘉庚科学奖信息技术科学奖等国家级奖励。当前研究所以智能化软件工程（AI for SE）、软件工程赋能人工智能（SE for AI）、软件供应链与开源生态、高可信软件理论为核心方向，汇聚了包括两位中国科学院院士（杨芙清、梅宏）、多位 IEEE/ACM Fellow（谢涛、金芝、张大庆等）和国家杰青获得者在内的顶级师资阵容。

## 研究方向与圈层结构概述

软工所的学术网络呈现清晰的三代传承结构。第一代以杨芙清院士为核心，师承徐献瑜先生，留苏归国后主持研制我国早期操作系统，开创青鸟工程，培养出邵维忠、陈向群、张路等骨干；第二代以梅宏院士为核心（杨芙清的博士后与学术继承人），联合谢冰、金芝等国防科大博士背景的教授，将研究推进到网构软件与构件化中间件时代，培养出黄罡、周明辉、熊英飞、郝丹等中坚力量；第三代以黄罡、刘譞哲、熊英飞、周明辉为代表，在云边端融合、智能软件工程、开源生态等新方向开花结果。2019年谢涛讲席教授（UIUC正教授、ACM SIGSOFT杰出研究奖大满贯得主）全职加入并出任软件科学与工程系主任，与谢冰所长构成当前软工所"双核领导层"，2014年张大庆讲席教授（IEEE Fellow）加入带来普适计算与智能感知方向，进一步扩展了研究所的学科版图。

研究方向上，研究所形成五大支柱：以金芝、谢涛、熊英飞为代表的智能化软件工程与代码大模型方向；以梅宏、黄罡、刘譞哲为代表的系统软件与云边端融合方向；以谢冰、赵俊峰、邹艳珍为代表的软件供应链与开发环境方向；以周明辉为代表的开源生态与经验软件工程方向；以张大庆为代表的普适计算与智能感知方向。张路、郝丹、陈向群等长期支撑的软件测试与操作系统教学科研体系则是研究所的传统根基。

## 产业转化亮点

软工所的产学研转化在全国高校软件工程学科中具有标杆地位。杨芙清院士主导的青鸟工程孵化了北大青鸟公司（含青鸟软件上市公司）；梅宏、黄罡团队的燕云DaaS系统获2018年国家技术发明一等奖，孵化出北京因特睿软件有限公司，并经神州控股、中国电子等企业实现规模化产业应用；周明辉主持制定我国首个OSI认证的开源许可证"木兰宽松许可证"（MulanPSL），已被33万余个开源项目采用；谢涛、熊英飞团队与华为、微软、字节跳动（Trae）、DeepSeek等企业在代码大模型、智能软件工程方向深度合作，其学生已进入DeepSeek创始团队。谢涛团队创建的国际软件工程公益社区（掘金、InfoQ等渠道的软工公开课体系）在产业界拥有广泛影响力。
