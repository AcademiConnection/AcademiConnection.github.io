张大庆是中国普适计算领域的领军学者，其学术生涯横跨意大利、新加坡、法国和中国，形成了从情境感知计算到泛在无线感知的完整理论谱系。2014年加入北京大学后，他带领团队在国际上首次提出基于菲涅尔区的无线感知理论，自2016年起在普适计算旗舰会议ACM UbiComp发表论文三十余篇，累计数量位居国际第一。[来源：PKU计算机学院报道](https://cs.pku.edu.cn/info/1263/3965.htm)

## 二、教育背景与职业履历

- **本科阶段**：中国科学技术大学校友。USTC校友活动记录显示其校友编号为9617（具体专业与毕业年份公开资料未详尽披露），可确认其本科或早期求学阶段与中国科学技术大学相关。[来源：USTC校友网](https://aga.ustc.edu.cn/info/1197/27048.htm)
- **1996年**：获意大利罗马大学"La Sapienza"（University of Rome "La Sapienza"）博士学位。博士阶段的研究奠定了其在情境建模与普适计算领域的学术起点。[来源：PKU英文主页](https://cs.pku.edu.cn/info/1233/2054.htm)
- **2000—2007年**：在新加坡资讯通讯研究院（Institute for Infocomm Research, I²R）从事智能家庭、数字医疗和普适计算等方面的研究。该阶段的研究聚焦于情境感知中间件、智能家居和普适老年照护，其基于OWL的情境模型在此期间成型并被国际同行广泛采用。[来源：百度百科](https://baike.baidu.com/item/张大庆/67124832)
- **2004年**：受聘为西北工业大学教授、博士生导师（可能为兼职/客聘性质，同期仍在新加坡I²R任职）。[来源：百度百科](https://baike.baidu.com/item/张大庆/67124832)
- **约2007—2014年**：在法国国立电信学院（Institut TELECOM SudParis，现为Institut Polytechnique de Paris / IP Paris的一部分）担任教授。此阶段论文署名单位标注为"Handicom Lab, Institut Telecom SudParis"或"Institut TELECOM SudParis"。研究主题从情境感知扩展到社会与社区智能（SCI）、移动群智感知（MCS）和城市计算，与浙江大学潘纲/於志文团队、IBM Research的Francesco Calabrese等建立了广泛的国际合作。[来源：多篇论文署名](https://link.springer.com/article/10.1007/s12652-012-0116-0)
- **2011年**：入选"陕西省百人计划"（依托西北工业大学）。[来源：百度百科](https://baike.baidu.com/item/张大庆/67124832)
- **2014年**：加入北京大学计算机学院（原计算机科学技术系），任高可信软件技术教育部重点实验室讲席教授，后任北京大学智能无线感知与应用研究中心主任。自加入北大后，研究重心全面转向泛在无线感知理论和技术。[来源：PKU计算机学院](https://cs.pku.edu.cn/info/1263/3965.htm)
- **2019年6月**：当选欧洲科学院（Academia Europaea）外籍院士。[来源：百度百科](https://baike.baidu.com/item/张大庆/67124832)
- **2019年11月**：当选IEEE Fellow。入选理由为其在普适计算和情境感知领域的贡献。[来源：百度百家号报道](https://baijiahao.baidu.com/s?id=1750346720581265099)
- **2025年12月**：当选中国计算机学会（CCF）会士。[来源：百度百科](https://baike.baidu.com/item/张大庆/67124832)
- **持续 affiliations**：部分论文（如2024年USENIX NSDI论文）仍标注其双重隶属"Peking University and Institut Polytechnique de Paris"，表明其与法国IP Paris保持学术联系。[来源：USENIX NSDI'24论文](https://www.usenix.org/conference/nsdi24/presentation/yi)

**履历要点**：张大庆的学术路径呈现"意大利（博士）→新加坡（I²R研究员）→法国（TELECOM SudParis教授）→中国（北京大学讲席教授）"的跨欧亚流动特征。在法国期间，他同时与西北工业大学保持联系（2004年受聘、2011年陕西省百人计划），形成中法双轨学术布局。加入北大后，将研究重心从情境感知/城市计算转向无线感知基础理论，创建了北京大学智能无线感知与应用研究中心。需注意：用户问题中提及"比利时蒙斯大学（UMONS）"和"鲁汶大学"，经多轮检索未找到张大庆在这两所机构任职的直接证据；其欧洲主要任职机构为法国Institut TELECOM SudParis（现IP Paris）。

## 四、学术合作网络

### 4.1 北大内部合作圈

张大庆隶属于北京大学计算机学院软件工程研究所和高可信软件技术教育部重点实验室。在北大内部，其合作呈现以下结构：

- **软件工程研究所交叉合作**：张大庆参与本科生课程"信息技术导论"（与金芝、谢冰合授），在研究所层面与金芝、谢冰等软件工程方向教授有教学组织层面的联系。其高可信实验室发表记录中，张大庆的论文与软件工程研究所其他成员的论文并列出现，表明其在研究所内的学术独立性较高，研究主题与软件工程主流方向有所不同（聚焦普适计算而非传统软件工程）。[来源：PKU-SEI教学页面](https://www.sei.pku.edu.cn/Education1/Teaching.htm)
- **王乐业（Leye Wang）**：北京大学计算机学院/人工智能研究院助理教授，张大庆在法国时期培养的博士。加入北大后与张大庆保持密切合作，在移动群智感知方向联合发表多篇论文（IEEE TMC 2019、Computer Networks 2019等）。[来源：PKU AI研究院](https://www.ai.pku.edu.cn/en/info/1337/1650.htm)
- **吴丹（Dan Wu）**：张大庆团队成员，在WiFi感知理论与通信感知一体化方向共同发表综述（2022年通信感知一体化设计论文），是团队核心研究人员之一。[来源：微信学术文章](https://mp.weixin.qq.com/s?id=2651165443)
- **跨所合作**：与北京大学网络与信息系统研究所的王亚沙（Yasha Wang）、吕岩（Qin Lv）等在移动群智感知方向有合作论文（IEEE Computer 2019、IEEE TMC 2019）。

### 4.2 国内高校合作网络

张大庆在国内学术合作网络极为广泛，形成了以普适计算专委会为核心的学术共同体。

- **西北工业大学（NPU）**：张大庆2004年受聘NPU教授，与NPU计算机学院有深厚渊源。主要合作者包括**郭斌（Bin Guo）**和**於志文（Zhiwen Yu）**，两人在群智感知、社会智能等方向与张大庆合著大量论文（IEEE TMC、UbiComp等）。NPU团队与张大庆团队在2010-2015年间合作尤为密切，TripPlanner（IEEE T-ITS 2015）等论文是代表性合作成果。[来源：NPU论文页面](https://hcps.nwpu.edu.cn/kxyj/xslw.htm)
- **浙江大学**：与**潘纲（Gang Pan）**、**李石坚（Shijian Li）**、**吴朝晖（Zhaohui Wu）**等在情境感知、城市计算方向有长期合作。陈龙彪（张大庆的博士生）在浙大获得博士学位，构成浙大—TELECOM SudParis—北大的三角合作通道。
- **中国科学院软件研究所**：张扶桑（张大庆指导的博士后）在中科院软件所任副研究员/研究员期间，与张大庆保持联合指导关系。MobiCom 2022论文（Mobi²Sense）由北京大学、中科院软件所及美国麻省大学合作完成。[来源：高可信实验室报道](https://hcst.pku.edu.cn/info/1029/1661.htm)
- **清华大学**：在AIoTSys 2023等会议中有合作交流；张大庆团队的无线感知研究与其他普适计算团队形成互补关系。
- **北京航空航天大学**：张扶桑2025年加入北航，将菲涅尔区无线感知衍射模型等理论带到北航，延续与张大庆的合作关系。
- **重庆大学**：陈超（张大庆博士生）在重庆大学任教授，将城市计算与时空数据挖掘方向扩展。
- **厦门大学**：陈龙彪在厦门大学任副教授，继续在群智感知方向与张大庆有学术联系。

张大庆的国际合作网络覆盖欧洲、北美和亚洲多国，是其在普适计算领域国际影响力的核心支撑。

- **英国阿尔斯特大学（Ulster University）**：**Chris Nugent**教授在普适老年照护和智慧健康方向有合作，AIoTSys 2023面板讨论为代表性合作活动。[来源：PKU机构库](https://ir.pku.edu.cn/handle/20.500.11897/769196)
- **挪威奥斯陆大学**：**Zhang Yan**在AIoTSys 2023面板讨论中与张大庆共同参与。
- **日本法政大学（Hosei University）**：**Runhe Huang**在IoT和数字孪生方向有合作（AIoTSys 2023）。
- **新加坡I²R**：早期任职机构，在情境感知和智能家居方向的合作网络延续至今。

### 5.1 核心企业合作

张大庆的无线感知研究具有极强的产业落地导向，与企业界的合作深度在普适计算领域学者中尤为突出。

**（1）华为（Huawei）**

华为是张大庆团队最核心的产业合作伙伴。2022年，张大庆团队与华为等企业合作在国内率先将WiFi感知落地商用。2023年，团队获"首届华为WiFi感知大赛"一等奖。在CNCC 2023等会议上，张大庆与华为技术人员就无线感知边界、信号评估标准等展开技术对话。2025年，华为联合WAA（世界WLAN应用联盟）发布智慧园区WiFi CSI感知白皮书，张大庆团队的理论成果为该白皮书提供了学术支撑。合作方向涵盖WiFi感知商用化、通信感知一体化（ISAC）、6G感知标准等。[来源：PKU计算机学院](https://cs.pku.edu.cn/info/1263/3965.htm)、[华为网络峰会2025](https://e.huawei.com/au/news/2025/solutions/campus/smart-campuses-wlan)

**（2）维沃移动通信有限公司（vivo）**

张大庆团队与vivo在通信感知一体化方向有直接合作。2022年发表的综述论文"基于CSI的通信感知一体化设计：问题、挑战和展望"中，vivo研究人员姚健、姜大洁、秦飞为共同作者，张大庆为通讯作者。这表明团队与vivo在WiFi/CSI感知技术标准化和手机端感知应用方面有实质性联合研究。[来源：微信学术文章](https://mp.weixin.qq.com/s?id=2651165443)

**（3）小米（Xiaomi）**

团队成员牛凯（Kai Niu）博士毕业后加入北京小米移动软件有限公司。USENIX NSDI 2024论文（BFMSense: WiFi Sensing Using Beamforming Feedback Matrix）由北京大学、中科院软件所、UMass和小米联合完成，标志着WiFi感知技术向商用设备落地的关键突破——首次利用商用WiFi设备的波束成形反馈矩阵（BFM）替代CSI进行感知，解决了CSI仅能从极少数设备提取的问题。[来源：NSDI'24](https://www.usenix.org/conference/nsdi24/presentation/yi)

**（4）其他企业关联**

- **腾讯**：张扶桑在张大庆团队期间曾主持"腾讯犀牛鸟专项研究计划"。[来源：北航主页](https://cst.buaa.edu.cn/info/1111/4243.htm)
- **英特尔、中兴、丰田、LG电子**：作为SSC 2025全球无线感知竞赛的联合发起方，与张大庆团队在竞赛层面有合作联系。张大庆指导的AIR@PKU团队在该竞赛中夺冠。[来源：PKU计算机学院](https://cs.pku.edu.cn/info/1263/4230.htm)
- **北京市自然科学基金-小米创新联合基金**：张扶桑曾获此资助。[来源：北航主页](https://cst.buaa.edu.cn/info/1111/4243.htm)

### 5.2 产业合作模式与特点

张大庆的产业合作呈现"理论→标准→产品"的全链条特征：

1. **理论引领**：菲涅尔区感知理论、感知信噪比模型等基础理论为企业产品开发提供了定量指导。例如，华为WiFi感知白皮书中关于感知范围边界的论述直接基于张大庆团队的理论成果。
2. **标准推动**：张大庆积极推动WiFi感知标准化（IEEE 802.11bf标准，预计2026年出台）和6G感知标准（计划2030年），其理论成果为标准制定提供学术依据。[来源：36氪/量子位报道](https://36kr.com/p/2920208788020105)
3. **竞赛牵引**：通过华为WiFi感知大赛（2023年冠军）和SSC 2025全球无线感知竞赛（2025年冠军），将学术界与产业界的技术需求对接。
4. **人才输送**：团队成员（如牛凯入职小米）直接进入企业研发岗，将学术成果转化为产品能力。
5. **应用场景拓展**：合作应用场景涵盖智慧康养（天津养老院WiFi呼吸监测）、智能家居（非接触手势控制）、安防（入侵检测）、车载（疲劳驾驶检测、车内儿童/宠物遗忘检测）等。

## 七、Connection圈层总结

张大庆的学术关系网络呈现"四圈层"结构：

**第一圈层——北大无线感知团队核心**：以牛凯、王炫之、高睿扬、李洋、吴丹、李文威、姚智允等在读博士和博士后为骨干，构成菲涅尔区感知理论、感知信噪比模型、移动感知等方向的论文产出主力。团队自2016年起在ACM UbiComp发表论文数量位居国际第一，近年在MobiCom（2022最佳论文Runner-up）、JSAC、IEEE TMC等期刊/会议持续产出。

**第二圈层——已毕业学生学术网络**：张扶桑（北航教授、国家优青）、王乐业（北大助理教授）、陈龙彪（厦大副教授）、陈超（重庆大学教授、国家优青）等已独立建组，在北航、北大、厦大、重庆大学等形成普适计算的"张大庆学派"分支。这批学者在群智感知、城市计算、无线感知衍射模型等方向延续了张大庆的理论脉络，且彼此之间保持合作发表关系。

**第三圈层——国内普适计算学术共同体**：以CCF普适计算专委会为组织平台，张大庆作为主任，连接了国内普适计算领域的核心力量。与NPU郭斌/於志文、浙大潘纲/李石坚、西北工业大学於志文团队等的合作论文构成密集的共著网络。通过专委会组织的暑期课程、感知大赛、华人沙龙等活动，张大庆对国内普适计算研究群体的凝聚和方向引领发挥了组织性作用。

**第四圈层——国际与产业合作网络**：国际层面，与法国IP Paris（Djamal Zeghlache等）、美国UMass Amherst（Jie Xiong）、英国Ulster University（Chris Nugent）、IBM Research（Francesco Calabrese）等机构的合作覆盖了从情境感知到无线感知的完整研究谱系。产业层面，与华为（WiFi感知商用化与标准）、vivo（通信感知一体化）、小米（BFM感知商用设备）的合作将理论成果推向产品化，形成了学术界罕见的"理论→标准→产品"全链条转化能力。

张大庆的学术Connection网络最显著的特征是其**从情境感知到无线感知的理论连续性**与**跨国跨机构的学术流动性**。他的学术生涯跨越意大利、新加坡、法国、中国四国，在每一阶段都建立了实质性的研究合作网络，并将这些国际资源在加入北大后整合为以无线感知为核心的系统性研究力量。其培养的近十位国家级青年人才已在中国多所高校形成辐射，使北大成为中国普适计算和无线感知领域最具国际影响力的研究基地之一。
