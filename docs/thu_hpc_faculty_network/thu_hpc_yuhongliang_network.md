此外，余宏亮曾作为项目负责人主持国家自然科学基金青年科学基金项目《P2P流媒体点播中的网络波动问题研究》（批准号60603071，依托单位清华大学，研究期限2007年1月—2009年12月，资助经费27万元）。这是余宏亮个人层面唯一被明确检索到的、以其本人为项目负责人的国家级科研基金项目，体现了其在P2P流媒体系统方向的独立研究能力，与其早期在VOD系统用户行为研究方面的学术积累一脉相承。

## 七、Connection圈层总结

**第一圈层：核心学术伙伴与可能的指导教师。** 郑纬民院士是余宏亮学术网络中最核心、持续时间最长的节点。从博士阶段（EuroSys 2006）到留校后近十年（计算机学报2010），二人在几乎所有可考的公开论文和国家级奖励项目中均同时出现，郑纬民在多篇论文中位于通讯作者/末位作者位置，且是2007年国家科技进步二等奖项目的总负责人，2015年国家技术发明二等奖项目的核心领衔人之一。虽然官方材料未明确标注"博士导师"身份，但综合合作强度和角色分工，郑纬民应被视为余宏亮学术生涯中分量最重的前辈与合作者。

**第二圈层：高性能所存储方向同事圈。** 陈康、武永卫、张悠慧、鞠大鹏、姜进磊、舒继武等人构成了余宏亮在存储系统与分布式系统方向的所内同事网络。这一圈层的紧密度体现在两个具体的国家级奖项团队（2007年国家科技进步二等奖、2015年国家技术发明二等奖）以及2021年合著的《大数据存储技术》专著中，反映出余宏亮长期是清华高性能所"存储系统研究团队"的稳定成员之一，尽管近年来该团队的对外影响力（如武永卫团队的趋境科技产业化）主要由武永卫、章明星等人承接和放大，余宏亮本人未见公开的产业化角色。

**第三圈层：具体课题合作者。** 高崇南（系统建模）、向小佳（存储虚拟化与远程镜像）、徐亦达（容灾云技术）等属于余宏亮在具体研究课题上的合作者，合作深度和持续时间不及第一、第二圈层，更接近于单篇论文或单次课题的协作关系。

**第四圈层：研究所行政/职称同僚（非学术合作证据充分）。** 赵颖副研究员与余宏亮共用办公室分机号、同属高性能所"副高"职称序列，但二人研究方向（存储系统 vs. 数据挖掘/AI for Science）完全不同，未检索到任何联合署名的学术合作证据。这一关系应被定性为行政/职称层面的"同僚"，而非学术意义上的"同一课题组"，是本报告在核实用户提供背景信息时得出的重要澄清。

**第五圈层：国际合作圈（有限）。** Ben Y. Zhao（原UCSB、后芝加哥大学）是余宏亮目前可考的唯一较明确的国际合作者，合作成果为其代表作 EuroSys 2006 论文。除此之外，公开渠道未检索到余宏亮与其他海外学者建立持续合作关系的证据。

**第六圈层：产业与学生培养圈（信息空白）。** 如前文如实说明，公开渠道未检索到余宏亮独立指导研究生的信息，也未检索到其以顾问、首席科学家等身份参与产业化项目的证据。这使得余宏亮的关系网络呈现出"内聚于清华高性能所存储团队、缺乏对外产业辐射和独立人才培养谱系"的特征，与翟季冬、武永卫等近年高度活跃于产学研一线的同所教授形成结构性差异。

总体而言，余宏亮的学术关系网络是一个以郑纬民为核心枢纽、高度内聚于清华大学高性能计算研究所存储系统研究团队的紧密网络。他在2005—2012年间通过与郑纬民、陈康等人的持续合作，在广域网存储、容灾恢复、虚拟机迁移等方向产出了一批有影响力的会议论文，并作为团队核心成员参与了两项国家级科技奖励；国际合作层面则以Ben Y. Zhao这一早期合作为代表，但未形成持续的跨国网络。近十余年来，其公开学术活动趋于平稳，2021年参与合著行业专著是其近年可考的主要公开成果，而学生培养、产业合作、学术兼职等维度的公开信息均较为有限，本报告对此均如实标注为"公开渠道未检索到相关信息"，未做主观推断或编造。
