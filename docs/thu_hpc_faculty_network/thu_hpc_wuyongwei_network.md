## 一、学者基本信息

武永卫，男，1974年7月出生于甘肃省白银市平川区，清华大学计算机科学与技术系教授、博士生导师，高性能计算研究所副所长（英文页面标注 Vice Head），兼任计算机系副主任。他是并行与分布式处理、云存储及大数据系统领域的国际知名专家，同时也是清华系AI算力创业公司「趋境科技」的首席科学家。

武永卫长期从事计算机系统方面的研究工作，专注于并行与分布式系统的设计、实现、评价和应用。具体研究方向涵盖运行时环境、数据存储与管理、虚拟化、资源管理调度、性能分析、分布式协同与一致性、可靠性与容错等。近年来，其研究重心向大模型推理系统优化方向延伸，提出了"以存换算"和"全系统异构协同"的原创技术路线，在AI基础设施领域产生了广泛的产业影响。据其官方主页列出的代表性论文统计，武永卫在TPDS、ToC、TKDE、OSDI、ASPLOS、HPCA、ATC、EuroSys、HPDC、ICS、ICPP、FAST、SOSP等计算机系统领域顶级期刊与会议发表学术论文百余篇。其Google Scholar论文总引用量估计在数千量级（推测），h-index具体数值未在公开渠道查到准确数据。

## 二、教育背景与职业履历

### （一）教育背景

武永卫的本科与硕士均在兰州大学完成，专业为计算数学；博士毕业于中国科学院系统科学研究所（现中科院数学与系统科学研究院），专业为应用数学，获理学博士学位。

需要特别指出的是，武永卫的博士导师并非郑纬民。他于2002年获得中科院系统所博士学位后，同年10月进入清华大学计算机系高性能研究所从事博士后研究，此后留在清华任教。郑纬民是其博士后阶段的合作导师和长期的学术合作者、引路人，二人在此后的二十余年中形成了深厚的师生情谊与合作关系。武永卫在中科院系统所的博士导师身份，目前公开资料中未见明确记载，推测其导师可能为该所从事计算数学或符号计算方向的学者——其早期论文涉及吴文俊院士开创的"吴方法"（符号计算中的特征列方法）的分布式实现，合作者包括中科院软件所的林东岱研究员。

### （二）职业履历时间线

- **1996年**：获兰州大学理学学士学位（计算数学）。
- **1999年**：获兰州大学理学硕士学位（计算数学）。
- **2002年**：获中国科学院系统科学研究所理学博士学位（应用数学）；同年10月，进入清华大学计算机系高性能研究所从事博士后研究。
- **2004年前后**：博士后出站，留校任教（推测为助理研究员/讲师阶段）。
- **2007年**：任清华大学计算机科学与技术系高性能计算研究所副所长。
- **2008年**：兼任中国国家网格运行管理中心副主任。
- **2015年**：任清华大学计算机科学与技术系副主任（副系主任），分管教学与学生工作等。
- **2019年**：入选中组部"万人计划"科技创新领军人才。
- **2022年11月**：当选IEEE Fellow，当选理由为"对高性能数据存储和数据密集型计算系统的贡献"。
- **2023年**：先后当选亚太人工智能学会会士（AAIA Fellow）和中国计算机学会会士（CCF会士）。
- **2026年3月**：正式出任趋境科技首席科学家，同时在清华大学的教职与行政职务保持不变。

### （三）行政与社会兼职

武永卫在学术界担任多项重要职务。他曾任教育部高等学校计算机类专业教学指导委员会秘书长，中国计算机学会（CCF）教育工委主任委员。在国际学术界，他曾担任第19届IEEE/ACM CCGrid 2019、第29届IEEE/ACM SC 2016、第22届IEEE/ACM HPDC 2013等重要国际会议的程序委员会主席或委员；担任IEEE Transactions on Sustainable Computing指导委员会委员（2015—2019）、IEEE Transaction on Cloud Computing编委（2014—2019）、IEEE Cloud Computing编委（2015—2018）、Journal of Grid Computing编委（2013年至今）、Journal of Cluster Computing编委（2013年至今）。此外，他还担任九源智能计算系统生态联合体秘书长。

武永卫的学生群体呈现出明显的"学术—产业双轨"特征。一部分学生留校或回国任教，如章明星回到清华高性能所任副教授，成为大模型推理系统方向的学术新星；另一部分学生进入产业界，在趋境科技、华为、阿里、月之暗面等企业发挥关键作用。尤其值得注意的是，武永卫的多位学生和团队成员深度参与了趋境科技的创立和技术转化，形成了"清华高性能所—开源社区—创业公司"的完整产学研闭环。

## 五、业界合作关系深度分析

### （一）趋境科技的创立与发展

趋境科技（北京趋境科技有限责任公司，英文名 Approaching.AI）是武永卫产业化布局的核心载体。该公司于2023年底正式落地，源自清华大学计算机系高性能计算研究所的技术成果转化，已完成清华大学技术转移入股，属于清华官方技术转化落地企业。公司核心团队全部来自清华大学高性能计算所，配备院士、高校教授组成科研智囊。

趋境科技的创立背景与大模型推理算力瓶颈密切相关。2023年以来，随着大模型技术的全面爆发，推理环节成为AI产业落地的核心命脉，算力效率与成本控制成为关键问题。武永卫团队基于在计算系统、存储系统领域超过20年的技术积累，提出了"以存换算"和"全系统异构协同"的原创技术路线，直接切入了大模型推理降本增效的核心赛道。

从投资方结构来看，入局阵营可分为三类：一线财务VC（高瓴、弘晖、华控等）看重赛道成长性；地方国资（河南投资集团、杭州福成等）意在落地区域智算中心转型需求；产业资本（华为哈勃、星连资本等）瞄准国产算力适配的技术落地。

### （三）技术路线与核心产品

趋境科技的技术路线以"以存换算"和"全系统异构协同"为核心，具体包括三大原创技术：

1. **全系统异构协同**：通过将不同计算任务合理分配至GPU、CPU、内存和SSD，打破算力瓶颈，充分发挥各类硬件资源的算力潜力。GPU负责注意力和主干网络的高并行计算，CPU承担稀疏专家模块的推理任务，实现高效的CPU+GPU协同执行。

2. **以存换算**：通过充分挖掘显卡外部内存乃至磁盘的存储潜力以及近存计算能力，构建全局共享的KVCache复用机制与存算异构协同体系，大幅降低重复计算量，提升推理效率。该方案有效缓解了长序列、智能体集群以及稀疏大模型推理带来的资源压力。

3. **虚实同构**：通过虚拟化与同构技术实现资源灵活调度与配置优化。

公司核心产品为ATaaS（Approaching.AI Token as a Service）高效能AI Token生产服务平台，定位为"高品质AI Token工厂"。该平台面向企业级人工智能推理需求，采用"少模型、深优化"的差异化路线，提供标准化Token生产与共运营两种服务模式。据公开报道，自2026年春节以来，趋境科技平均单台算力的AI Token生产效率提升3倍以上，总产能增长超过30倍；某头部万亿级参数大模型的高品质AI Token日均产量已稳定突破万亿量级；2026年6月单月收入已超2025年全年，部分成熟业务已跨过成本线。

2026年7月，趋境科技华东区域总部落地杭州萧山钱江世纪城，计划在五年内建成万卡级集群规模的高品质AI Token工厂。

### （四）KTransformers开源项目

KTransformers是由趋境科技与清华大学KVCache.AI团队联合研发的高性能异构推理框架，聚焦大模型推理阶段的系统创新。该项目以章明星为主导，武永卫和郑纬民为团队核心。

KTransformers的技术核心是面向CPU+GPU异构架构的MoE（Mixture of Experts）推理系统方案，通过创新的"专家延迟机制"，让原本只能依赖昂贵多卡GPU的大模型能在CPU参与的硬件环境中实现接近同等性能的推理体验。该框架兼容GLM、Kimi、Minimax、Qwen等主流大模型。

KTransformers的学术影响力与产业采用情况十分突出：

- **学术认可**：项目论文"KTransformers: Unleashing the Full Potential of CPU/GPU Hybrid Inference for MoE Models"入选计算机系统领域顶级会议SOSP 2025，获得了全球系统学术界的最高背书。
- **开源影响力**：截至2025年底，KTransformers及其关联项目Mooncake在GitHub上的总星标数已超过2万（部分报道记为18k+），是国内大模型推理领域最具影响力的开源项目之一。
- **产业采用**：相关技术已落地月之暗面Kimi、阿里、蚂蚁集团、讯飞等多个业内平台，在数万张GPU算力集群上实现规模化落地，支撑了万亿参数级模型的超大规模服务。
- **生态合作**：KTransformers与主流推理框架SGLang宣布合作，双方架构合入同一分支，推动全GPU推理与异构推理的融合。
- **专利布局**：围绕"以存换算"技术路线已取得发明专利授权36项。

### （五）Mooncake推理架构

Mooncake是与KTransformers并列的另一项核心开源项目，由清华大学团队与月之暗面（Moonshot AI）公司合作开发。Mooncake是月之暗面大语言模型服务Kimi的底层推理服务平台，采用以键值缓存（KVCache）为中心的分离架构，将预填充和解码集群分开，高效利用推理集群中未充分利用的CPU、DRAM、SSD和NIC资源，建立分离的KVCache缓存池。

Mooncake论文"Mooncake: Trading More Storage for Less Computation — A KVCache-centric Architecture for Serving LLM Chatbot"荣获FAST 2025（USENIX文件与存储技术会议）埃里克·里德尔最佳论文奖（Erik Riedel Best Paper Award），第一作者为博士生秦若愚，导师为章明星，团队署名为章明星、武永卫、郑纬民。Mooncake已在数千个节点上运行，每天处理超过1000亿个token，使Kimi在NVIDIA A800和H800集群上分别比以前的系统多处理115%和107%的请求。

Mooncake项目的共建方包括清华大学、月之暗面Kimi、9#AISoft、阿里云、蚂蚁集团等机构，体现了武永卫团队在产学研协同方面的强大组织能力。

武永卫团队与国内头部科技企业建立了多层次的合作关系：

1. **华为**：武永卫团队于2024年荣获第五届华为"奥林帕斯奖"（存储领域最高荣誉），获奖成员包括章明星、郑纬民、秦若愚、姜进磊。华为通过哈勃投资于2026年2月入股趋境科技。在2026年中关村论坛上，华为昇腾计算业务副总裁兼首席产品规划师叶耀荣与趋境科技共同发布ATaaS平台。趋境科技还基于开源推理引擎SGLang完成了Kimi K3在华为昇腾AtlasA3上的Day0推理适配，充分发挥昇腾超节点架构优势。武永卫团队早期参与的"飞天云操作系统核心技术及产业化"项目获中国电子学会科技进步特等奖（2017），该项目与阿里云深度合作，也与华为等企业在存储系统领域有技术对接。

3. **月之暗面（Moonshot AI/Kimi）**：这是武永卫团队最深入的产业合作之一。Mooncake推理架构即为Kimi的底层推理平台，双方在FAST 2025最佳论文上共同署名。在2026年中关村论坛上，京东Infra产品负责人也参与了ATaaS平台的联合发布。

4. **蚂蚁集团**：参与Mooncake项目共建，相关技术已在蚂蚁平台落地。

5. **科大讯飞**：Mooncake/KTransformers相关技术已在讯飞平台落地。

6. **中科曙光**：中科曙光智能计算产品事业部总经理参与ATaaS平台发布，是趋境科技的产业合作伙伴。

武永卫团队在2020年10月曾帮助北京智源人工智能研究院搭建十台NVIDIA V100集群，用于训练中国最早的大规模预训练语言模型CPM，体现了其团队在大模型基础设施建设方面的先驱作用。

## 七、Connection圈层总结

武永卫的学术关系网络呈现出清晰的圈层结构，其角色定位可概括为"高性能所副所长+产业化推动者"。

**第一圈层：学术核心圈。** 以郑纬民院士为精神领袖和学术导师，武永卫为副所长和实际执行者，陈康、章明星、姜进磊等为所内核心合作者，构成清华高性能所的"内核"。郑纬民提供战略视野和院士级学术背书，武永卫负责学术方向把握和团队管理，章明星作为新生代学术领袖承担前沿技术突破。这一圈层的合作密度极高，从国家技术发明奖到华为奥林帕斯奖、FAST最佳论文，核心成果均出自这一团队。

**第二圈层：师生传承圈。** 武永卫培养的博士生群体形成了第二圈层，以章明星为代表已实现"学生—同事—创业伙伴"的角色转化。章明星从武永卫的博士生成长为清华副教授、KTransformers/Mooncake项目主导者、趋境科技联合发起人，体现了武永卫在学术传承和人才孵化方面的卓越能力。秦若愚等新一代博士生正在延续这一传承。艾智远等进入产业的学生则成为技术转化的桥梁。翟季冬作为高性能所所长，与武永卫形成正副搭档的管理协作关系，也属于这一圈层。

**第三圈层：所内/系内协作圈。** 陈文光、舒继武、杨广文等清华计算机系同仁构成更广泛的校内合作网络。在计算机系副主任的行政岗位上，武永卫与系主任尹霞、系党委书记刘奕群、副系主任徐恪、唐杰、李国良等系领导团队协作，负责教学管理和学生工作。

**第四圈层：产业生态圈。** 这是武永卫近年来最活跃的圈层，以趋境科技为枢纽，连接了郑纬民院士（首席科学顾问）、章明星（联合发起人）、艾智远（CEO）等核心团队，以及华为（哈勃投资+昇腾适配）、月之暗面/Kimi（Mooncake合作）、阿里（飞天云+Mooncake）、蚂蚁集团、科大讯飞、中科曙光、京东、并行科技等产业合作伙伴。投资方网络涵盖高瓴创投、河南投资集团、华为哈勃、星连资本、华控基金等一线机构。通过九源智能计算系统生态联合体秘书长的身份，武永卫进一步将影响力扩展至国家算力网络和智算中心体系。

**第五圈层：国际合作圈。** 包括Kai Hwang（USC）、Xuehai Qian（USC）、Christos Kozyrakis（Stanford）、Onur Mutlu（ETH Zurich/CMU）、Shan Lu（UChicago）、Jinyang Li（NYU）等国际学者，合作产出ASPLOS、HPCA、MICRO、OSDI等系统领域顶会论文。

总体来看，武永卫的Connection网络具有三个显著特征：一是**学术纵深强**，从郑纬民院士到章明星副教授再到秦若愚等博士生，形成了三代学者的传承链条；二是**产业化程度高**，通过趋境科技这一载体，将学术成果高效转化为产业产品，实现了"论文—开源—创业—融资—规模化落地"的完整闭环；三是**生态辐射广**，以清华高性能所为原点，向华为、阿里、月之暗面等头部企业以及国家算力网络体系辐射，在大模型推理基础设施这一关键赛道上占据了核心节点位置。武永卫本人则在这一网络中扮演着"承上启下"的关键角色——向上承接郑纬民院士的战略引领，向下培育章明星等新生代学术领袖，向外推动趋境科技的产业化落地，是连接学术研究、开源社区、创业公司和产业生态的枢纽型人物。
