### 1.3 博士导师核实（重点）

此前对陈文光教授的研究报告中曾"推测王豪杰可能是翟季冬教授的学生"。本次通过多重独立权威渠道交叉核实，基本可以确认这一判断，证据链如下：

3. **通讯作者模式**：在王豪杰作为第一作者的多篇核心论文（PET/OSDI'21、Optimizing DNNs/TC'23、Efficient memory allocator/JTH 2022 等）中，翟季冬均为合作者，且在大多数以学生为第一作者的论文中翟季冬担任通讯作者，符合"导师—学生"合作模式。

5. **办公联系方式**：其办公电话 010-62795471 与翟季冬主页所示电话一致，表明其办公位置在 PacMAN 实验室翟季冬团队区域。

综合上述证据，**王豪杰的博士导师为翟季冬教授**这一判断已由"推测"升级为可由公开权威渠道相互印证的结论。需要补充说明的是，PacMAN 实验室由翟季冬与陈文光共同主持，因此陈文光在王豪杰博士培养过程中也扮演了重要的共同指导角色（详见第三章）。至于陆游游副教授，他是高性能所党支部书记、王豪杰的入党介绍人之一，但其研究方向（闪存/持久内存存储系统）与王豪杰（编译器/HPC）差异较大，两者更主要是组织关系上的培养联系，而非学术上的导师—学生关系。此前关于"陆游游师承关系"的推断应予修正：陆游游是王豪杰的政治培养联系人，而非学术导师。

## 四、业界合作关系深度分析

王豪杰的研究路线与国产算力生态高度绑定，其业界合作网络具有鲜明的"产学研一体化"特征。

### 4.1 启元实验室

根据公开报道，王豪杰 2022 年开始参与启元实验室的相关工作，2023 年正式入职计算机系后在国产高性能计算系统和国产人工智能芯片的适配与编译优化等方面展开进一步研究。启元实验室是北京市扶持的国产算力新型研发机构，与清华高性能所联系紧密。王豪杰在启元实验室框架下主导九源软件栈关键模块 InfiniTensor 的开发，是其连接"学术研究—国产算力落地"的核心通道。

### 4.2 九源智能计算生态联合体与趋境科技

九源智能计算系统生态联合体由郑纬民院士担任理事长，武永卫教授担任秘书长，趋境科技为首席科学顾问单位。王豪杰所主持的 InfiniTensor 被定位为"九源软件栈的关键模块——跨平台智能编译优化系统"，服务于国产芯片上人工智能应用的高效部署。这意味着王豪杰在九源生态中承担"编译层负责人"的角色，是连接院士级战略（郑纬民、武永卫）与工程实现的关键中间层。其 GitHub 提交记录（haojie0429@gmail.com）显示 InfiniTensor 项目在开源社区持续活跃。

### 4.3 华为

在 2024 年 6 月清华大学高性能所举办的"人工智能时代的计算机体系结构、计算系统和高性能计算挑战与发展"研讨会上，王豪杰做了题为"多层次协同优化的人工智能编译器"的特邀报告，该会议与华为有明确的"企业报告、交流合作"环节。华为方面高耀清（智能时代计算机架构、编程编译技术）、姚骏（盘古大模型）等高管出席，表明王豪杰与华为在编译器/大模型系统层面存在交流。具体深度合作细节未能从公开渠道进一步核实。

### 4.4 阿里巴巴达摩院、之江实验室、北京智源研究院

通过 BaGuaLu 项目（PPoPP'22），王豪杰与上述机构的研究人员建立了协作关系。该项目是新一代神威超算上 174 万亿参数大模型训练平台，作者列表含杨红霞、刘鑫等达摩院/智源研究人员。这是王豪杰参与的最大规模跨机构产学研合作之一。

### 4.5 国产芯片生态

王豪杰的研究深度绑定国产算力：新一代神威超级计算机（SWAlloc 内存分配器、SWPyTorch/SWTensorFlow 适配）、国产人工智能芯片（InfiniTensor 跨平台编译）等。其"矢志报国、勇于攻坚"的公众形象（清华优秀博士后报道）与国产芯片"卡脖子"攻关直接挂钩，这使其在国产芯片企业生态中具有独特的"学术—工程桥梁"地位。具体合作企业名单未能从公开渠道完整核实。

### 4.6 开源社区

王豪杰通过 InfiniTensor、以及参与 PET、EINNET、FreeTensor、GraphSet、Korch 等一系列开源研究系统，在国内 AI 编译器开源社区具有较高的影响力。其 GitHub 账号 whjthu 活跃，并以 Co-authored-by 形式直接参与 InfiniTensor 的代码提交。这是其连接青年工程师、实习生、研究生的"工程型人脉"通道，与学术合作网络形成互补。

1. **博士导师**：确认翟季冬为博士导师（由实验室归属、论文指导关系、入党介绍人、通讯作者模式、办公联系方式等多重独立证据相互印证），此前"推测"可升级为"基本确认"。陈文光为事实上的共同指导教师。
