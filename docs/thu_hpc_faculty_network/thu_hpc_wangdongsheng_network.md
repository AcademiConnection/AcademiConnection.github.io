## 一、学者基本信息

汪东升，1966年生，清华大学计算机科学与技术系教授、博士生导师，高性能计算研究所资深教授之一。他是国内处理器体系结构与硬件安全交叉领域的代表性学者，长期主持清华大学微处理器与SoC研究中心（后更名为微处理器与SoC技术研究中心）的工作，现任清华大学CPU中心主任、数据安全研究所所长，同时是国家精品课程"计算机体系结构"的主讲教师。他所领导的团队在2019年发现的现代处理器重大安全漏洞"骑士"（VoltJockey / CVE-2019-11157），是国内研究团队发现的首个处理器硬件漏洞，这一成果使他成为中国硬件安全领域最具国际能见度的学者之一。

需要特别指出的是，用户背景信息中"其博士导师可能为郑纬民、王鼎兴等清华老一辈学者"的推测并不成立。经核实，汪东升的本科、硕士、博士三个学位全部在哈尔滨工业大学完成，他与清华的渊源始于1995年博士毕业后的博士后阶段。他与郑纬民、王鼎兴等清华老一辈学者的关系是长期同事与项目合作关系，而非师承关系。

## 二、教育背景与职业履历

汪东升1985年考入哈尔滨工业大学计算机系，此后在哈工大连续完成了本、硕、博三个阶段的学习：1989年获工学学士学位，1992年获工学硕士学位，1995年获工学博士学位（计算机系统结构专业），专业方向均为计算机科学与技术。哈工大计算机系是国内计算机学科的老牌重镇，在计算机体系结构、容错计算等方向有深厚积累，这一背景直接塑造了汪东升日后的研究品味——他至今仍将"容错计算"列为自己的主要研究方向之一，这在以性能优化为主流的体系结构界并不常见，而是典型的哈工大系统结构学派的印记。

关于其博士导师的具体姓名，公开渠道（清华大学计算机系官网、高性能计算研究所官网、百度百科等）均未披露。哈工大计算机系统结构方向在上世纪九十年代的学术带头人包括李仲荣、方滨兴等，但没有任何公开材料能够坐实其中任何一位是汪东升的博士导师，因此本报告不作推测性指认。值得注意的一个侧面线索是，CCF体系结构专委会2012至2019两届的副主任名单中，汪东升与哈尔滨工业大学的季振洲长期并列，两人同为副主任，这至少说明他与哈工大体系结构学脉保持着持续的组织性联系。

1995年10月，汪东升博士毕业后进入清华大学从事博士后研究，至1997年9月出站，并获得清华大学第三届"十佳优秀博士后"称号。这两年是他从哈工大体系转入清华体系的关键过渡期。出站后他留校任教，此后近三十年再未离开清华大学计算机系，是所内资历最深的教授之一。

他的职业生涯中最具标志性的时间节点是2003年。这一年，他牵头成立了微处理器与SoC研究中心并担任负责人，这个团队后来成为他学术生涯的主要载体。同年，团队参与研制成功了当时国内主频最高的、具有自主知识产权的微处理器THUMP。需要澄清的是，THUMP107处理器的研制是清华大学高性能计算研究所的集体工程，郑纬民院士作为高性能所的学科带头人主导了这一方向的战略布局——公开资料明确记载"在他（郑纬民）的带领下，用一年的时间研制成功了中国当时运行频率最高的高性能嵌入式CPU-THUMP107，其最高频率为500MHz"。汪东升在其中扮演的是核心技术骨干与后续SoC产品化的主要推动者角色，其个人主页表述为"团队自成立以来，成功研制了当时国内主频最高的具有自主知识产权的微处理器THUMP（2003年）"。这是理解他与郑纬民关系的关键：不是师生，而是同一重大工程中的资深带头人与核心执行者。

此后二十余年，他的技术路线可以清晰地划分为三个阶段。

第一阶段是2003至2012年的自主处理器与SoC工程期。团队以THUMP处理器为基础，衍生设计了视频编解码处理芯片、移动存储卡控制器、流量分配器、云终端等多类设备。2009年，团队获得"核高基"国家科技重大专项"众核处理器关键技术及应用性研究"的支持，成功研制了64核以上的多核SoC仿真平台，该平台在神舟六号载人飞船的仿真测试中发挥了重要作用——这是他的研究成果进入国家重大工程序列的标志性事件。2012年，团队与苏州云计算中心合作研制了基于云存储的个人移动计算环境，这也解释了他"苏州工业园区特约专家"这一社会兼职的由来。

第二阶段是2013至2018年的智能加速与视频编码期。2015年，团队研制的高性能视频编码算法模块被应用于某公司的H.265编码芯片中（官方表述使用了打码处理，未披露企业名称）。2018年，团队基于FPGA研制了深度神经网络加速平台。这一时期他在AAAI、NIPS等人工智能顶会以及IEEE TIP等期刊上有所斩获，代表作包括2016年发表于IEEE TIP、目前被引186次的"CU Partition Mode Decision for HEVC Hardwired Intra Encoder Using Convolution Neural Network"，以及2018年AAAI的"Computation Error Analysis of Block Floating Point Arithmetic Oriented Convolution Neural Network"和2018年的"SNrram"、"HitNet"等工作。这一阶段他与刘振宇（Zhenyu Liu，DBLP合作37次，为其第二高频合作者）在视频编码硬件方向的合作最为密集，双方还共同与早稻田大学的Takeshi Ikenaga教授合作（9篇）。

第三阶段是2019年至今的处理器安全期，这是他学术影响力真正爆发的阶段。2019年，团队一举发现了ARM TrustZone和Intel SGX两大主流可信执行环境的重大安全漏洞，相关成果发表于ACM CCS 2019并被命名为VoltJockey，漏洞编号CVE-2019-11157，中文名"骑士"。清华计算机系官网对此的表述是"2019年发现现代处理器重大漏洞骑士，此后陆续发现5个处理器安全漏洞"。自此，他将团队的主攻方向全面转向处理器微架构安全，并在此后七年间持续产出高水平成果。

他的历任与现任职务包括：清华大学CPU中心主任（依托原清华大学信息科学技术国家实验室，该实验室后重组为北京信息科学与技术国家研究中心BNRIST）、清华大学数据安全研究所所长、清华大学计算机学科学位评定委员会委员、清华大学计算机系教学工作委员会委员。在校外，他担任哈尔滨工程大学兼职教授、苏州工业园区特约专家、国家计算机网络与信息安全管理中心科技委常委，并兼任上市公司山东新北洋信息技术股份有限公司的独立董事。

## 三、学生培养情况

汪东升的学生培养呈现出鲜明的"少而精"特征，其培养体系的最大特点是与团队的固定研究骨干（吕勇强、王海霞等）形成了紧密的联合指导结构，学生的成长路径往往是"清华博士 → 清华博士后 → 高校教职或团队留任"。

在所有已毕业学生中，**邱朋飞**是最突出的一位，其成长轨迹与导师的研究转型高度同步。邱朋飞2015年从哈尔滨工业大学计算机科学与技术系获得学士学位——与汪东升本人的本科母校完全一致，这一巧合暗示了汪东升在哈工大生源上的持续影响力。2015年至2020年，他在清华大学计算机系攻读博士，导师为汪东升教授，博士期间受国家留学基金委资助赴美国马里兰大学交流学习一年（这直接对应了团队与马里兰大学Gang Qu教授的深度合作，详见第四节）。2020年博士毕业后，他继续在清华大学做了两年博士后（入选清华大学"水木学者"计划），2022年加入北京邮电大学网络空间安全学院李小勇教授团队，现为特聘副研究员/副教授、博士生导师。

邱朋飞的成果清单几乎可以视为汪东升团队处理器安全方向的缩影：他以第一作者身份发现的"骑士"漏洞是国内研究团队发现的首个处理器硬件漏洞；此后又相继发现通用处理器的"频率隐藏通道"和"PMU侧信道"漏洞；他设计的大规模分布式硬件漏洞挖掘与安全检测平台，发现了被国家信息安全漏洞共享平台（CNVD）收录的首批四个处理器微架构漏洞。他以第一或通讯作者身份在CCS、HPCA、DAC、IEEE TCAD、中国科学·信息科学等发表论文26篇，获得中国计算机学会自然科学一等奖、湖南省自然科学奖二等奖、清华大学优秀博士学位论文奖、Intel漏洞赏金奖励（目前国内学者唯一一次获得该奖励）、两次AsianHOST年度唯一最佳论文奖，并于2025年获得ACM SIGSAC China"新星奖"（每年评选不超过3名）。值得注意的是，邱朋飞离开清华加入北邮后，与汪东升的合作不但没有中断，反而更加频繁——2023年以来汪东升几乎每一篇处理器安全论文的作者列表中都有邱朋飞的名字（DBLP合作27次，为其第五高频合作者），两人已经从师生关系演变为跨机构的长期学术伙伴关系。

**刘畅**（Chang Liu 0117）是团队近年产出最高的另一位学生（DBLP合作11次），研究方向为ARM与AMD处理器的内存消歧单元（Memory Disambiguation Unit）安全。他的代表作包括2023年DAC的"Leaky MDU: ARM Memory Disambiguation Unit Uncovered and Vulnerabilities Exposed"（这就是王海霞主页中提到的"幻影"漏洞）、2024年HPCA的"Uncovering and Exploiting AMD Speculative Memory Access Predictors for Fun and Profit"、2025年ASPLOS的"MDPeek: Breaking Balanced Branches in SGX with Memory Disambiguation Unit Side Channels"，以及2026年HPCA的"SSBleed"。从他的合作者名单看，他与新加坡国立大学的Trevor E. Carlson教授、南方科技大学的张殷乾（Yinqian Zhang）教授均有多篇合作，属于团队中国际化程度较高的学生。

**金宇**（Yu Jin 0010）是团队处理器安全方向的另一位活跃学生，代表作包括2023年AsianHOST的"Overtake: Achieving Meltdown-type Attacks with One Instruction"、2024年DAC的"Whisper: Timing the Transient Execution to Leak Secrets and Break KASLR"、2025年CCS的"GhostCache"以及2025年AsianHOST最佳论文奖论文"PPA: Novel Page Prefetcher-Based Side-Channel Attacks"。后两项工作均为与清华大学电子工程系邓舒文助理教授的联合成果，其中GhostCache针对RISC-V与ARM芯片的弱一致性缓存，获得了ARM安全团队的认可、开源香山团队的感谢以及SiFive的首个公开漏洞报告感谢。

**融凯源**（2022级博士生）与**方骏祺**（2024级博士生）是团队当前的在读博士生，两人合作的论文"OCCUPY+PROBE: Cross-Privilege Branch Target Buffer Side-Channel Attacks at Instruction Granularity"获得了第三十三届NDSS的杰出论文奖（Distinguished Paper Award）。该工作逆向分析了Intel Core第9代至第14代处理器的分支目标缓冲器，提出的侧信道可绕过第11至14代处理器BTB中引入的硬件隔离机制，并以98%的准确率提取了Linux Kernel Crypto API的RSA私钥。这一成果说明汪东升的学生培养质量在其职业生涯晚期仍保持在极高水准。

其他从论文合作记录中可以识别的团队成员还包括：**孙日辉**（Rihui Sun，DVFS故障注入攻击GPU深度学习加速器方向）、**杨轶豪**（Yihao Yang，隐藏PMU事件挖掘方向）、**张世轩**（Shixuan Zhang，缓存形式化验证方向，2026年GLSVLSI的XcptProof一作）、**高强**（Qiang Gao，PMU-Leaker方向）、**段宇章**（Yuzhang Duan）、**兰泽儒**（Zeru Lan）、**韩逸**（Yi Han）、**李洲洋**（Zhouyang Li）等。这些学生的成果高度集中于AsianHOST、DAC、ASP-DAC、ICCAD等硬件安全与EDA领域会议，形成了鲜明的团队研究标识。

关于用户提出的"所内是否有教师为其学生（如张悠慧、渠鹏等体系结构方向教师）"这一核实要求，结论是否定的。张悠慧是清华大学高性能计算研究所研究员，与汪东升在DBLP上有15次合作记录，两人在体系结构方向长期共事，但没有任何公开材料显示张悠慧是汪东升的学生——张悠慧的博士学位在清华大学获得，其学术脉络更接近郑纬民、汪东升共同参与的THUMP处理器项目群，属于同一代际的合作者而非弟子。至于"渠鹏"，在清华大学高性能计算研究所现有的教师名录（正高：陈婧、陈康、陈文光、李兆麟、钱学海、舒继武、汪东升、武永卫、薛巍、杨广文、翟季冬、郑纬民、张悠慧；副高：章明星、黄震春、姜进磊、陆游游、余宏亮等）中并未出现此人，推测用户可能指的是"钱学海"教授。钱学海是2021年前后从美国南加州大学回国加入清华高性能所的教授，博士毕业于伊利诺伊大学厄巴纳-香槟分校，与汪东升无师承关系，两人同为计算机系教学工作委员会委员，属于同事关系。

真正称得上"由汪东升培养并留在清华体系内"的，是他的两位长期合作研究人员，但两人都不是他的博士生：**吕勇强**2006年获清华大学计算机软件与理论博士学位，先后在Synopsys和Magma任职后于2009年回清华任助理研究员，现为北京信息科学与技术国家研究中心副研究员；**王海霞**2004年获中科院计算所计算机系统结构博士学位，1994至1998年在南开大学读自动控制本科，2005至2006年在清华做博士后，2006年12月起任清华助理研究员、副研究员。两人都是先在别处完成学业，再加入汪东升团队成为固定科研骨干的，属于"学术伙伴"而非"学生"。

## 四、学术合作网络

基于DBLP"Dongsheng Wang 0002"档案187项成果的合作者统计，汪东升的学术网络呈现出一个极为清晰的结构：一个由三人构成的高度稳定的核心圈层，一个由学生构成的中间层，以及一个以马里兰大学为枢纽的国际合作层。

### 核心合作圈层

**王海霞**（Haixia Wang，合作45次）是他合作最频繁的学者，也是团队处理器安全方向在形式化验证与安全缓存设计上的技术支柱。她的主要贡献包括构建通用处理器漏洞挖掘平台（发现"幻影"Leaky MDU漏洞，论文发表于DAC）、提出基于模型检验的处理器安全形式化验证方法（验证发现1种新的分支预测类漏洞变种、5种缓存侧信道攻击策略以及1种针对非包含缓存的跨核攻击方式，论文发表于TIFS、ASP-DAC）、提出可提供至多512个分区的隔离式安全缓存设计（论文发表于TDSC）。她与汪东升共同获得2020年CCF自然科学一等奖、2020年中国电子学会科技进步一等奖、2022年山东省科学技术进步一等奖，成果入选2023年世界互联网大会领先科技成果集。

**刘振宇**（Zhenyu Liu，合作37次）是团队在视频编解码硬件方向的核心，主要活跃于2013至2018年期间。他与汪东升在HEVC硬件编码器的CU/PU模式决策、率失真代价估计、CNN加速等方向上产出了大量成果，其中包括团队被引最高的论文（2016年IEEE TIP，186次）。他同时是团队与日本早稻田大学Takeshi Ikenaga教授合作的主要桥梁。这条合作线也是"2015年研制的高性能视频编码算法模块应用于某公司H.265编码芯片"这一产业化成果的技术来源。

**吕勇强**（Yongqiang Lyu，合作30次）是团队处理器安全方向的另一位核心研究人员，也是"骑士"漏洞的主要贡献人与相关CCS 2019、TCAD 2020论文的通讯作者。他致力于回答"什么样的处理器是安全的"这一学术界与产业界共同关注的难题，在漏洞发现、修复与安全验证三个环节都有贡献。他此前作为技术骨干参与完成"核高基"面向先进工艺的数字芯片后端设计"先进EDA工具平台"研发，并在2015年以第四完成人身份获得国家科技进步二等奖（"普适计算软硬件关键技术与应用"，第一完成人为史元春）。他2023年入选国家级高层次人才，获得过IEEE AsianHost 2019最佳论文奖、ACM CHI 2015最佳论文提名奖。

需要指出的是，汪东升、吕勇强、王海霞、邱朋飞这四人正是2020年CCF自然科学一等奖"现代处理器重大安全漏洞发现"的完整获奖人名单，且排序恰好为汪东升第一、吕勇强第二、邱朋飞第三、王海霞第四。这份名单是理解汪东升核心学术圈层最权威的一份文件。

**薛一波**（Yibo Xue，合作23次）是团队早期在网络流量分析与网络安全方向的合作者，两人合作的"An Novel Hybrid Method for Effectively Classifying Encrypted Traffic"（2010年）被引69次。**郑纬民**（Weimin Zheng，合作18次）的合作主要集中在早期的存储与分布式系统方向，如ADMAD、R-ADMAD等去重归档存储系统工作，反映了THUMP项目时期以及高性能所内部的项目协同。**张悠慧**（Youhui Zhang，合作15次）与他在体系结构方向有稳定的合作。**巨大鹏**（Dapeng Ju，合作9次）近年重新活跃于处理器安全方向，参与了2026年NDSS的OCCUPY+PROBE与2026年HPCA的SSBleed两项工作。

### 跨机构与国际合作网络

汪东升最重要的国际合作伙伴是美国马里兰大学帕克分校的**Gang Qu**（屈钢）教授，两人在DBLP上合作28次，是其第四高频合作者。Gang Qu是硬件安全与低功耗设计领域的国际权威学者，IEEE Fellow。这条合作线的建立与邱朋飞2018年前后赴马里兰大学的一年访学直接相关，此后迅速演化为团队最稳定的国际合作通道。从2023年至2026年，团队在AsianHOST、DAC、ASP-DAC、ICCAD、TCAD、TCAS-I、TODAES等场合发表的处理器安全论文中，Gang Qu几乎无一缺席，通常署名于作者列表末位，扮演国际方资深合作者的角色。这种合作模式对团队的国际能见度提升起到了关键作用——"骑士"漏洞之所以能够进入Intel官方公告并获得Intel漏洞赏金，与这条美方学术通道的存在不无关系（推测）。

另一条重要的国际合作线通向**新加坡国立大学的Trevor E. Carlson**教授。刘畅2025年ASPLOS的MDPeek与2026年HPCA的SSBleed均有Carlson参与。这条线较新，但产出的会议档次很高，说明团队在体系结构顶会上的突破得益于这类国际协作。

在国内跨机构合作方面，团队与**北京邮电大学**形成了最紧密的连接。邱朋飞2022年加入北邮网络空间安全学院李小勇（Xiaoyong Li）教授团队后，团队与北邮的**王春卢**（Chunlu Wang，合作16次）、**李小勇**（合作5次）等人建立了常态化合作。近三年团队发表的Whisper（DAC 2024）、Overtake（AsianHOST 2023）、PMU-Spill（TCAS-I 2023）、AutoGuard（AsianHOST 2024）、Split+Prune（AsianHOST 2025）等论文，几乎都是清华—北邮联合署名。这是一条典型的"学生毕业后成为跨机构合作节点"的网络扩张路径。

与**南方科技大学张殷乾**（Yinqian Zhang）教授的合作是另一条值得注意的线索。张殷乾是可信执行环境安全领域的知名学者，与团队在2024年HPCA、2025年CCS、2026年HPCA上均有合作。

与**清华大学电子工程系邓舒文**（Shuwen Deng）助理教授的合作则代表了团队在校内的跨院系扩张。邓舒文属于刘勇攀、杨华中教授团队，其GhostCache工作（CCS 2025）与PPA工作（AsianHOST 2025最佳论文奖）均与汪东升团队的金宇联合完成，研究对象覆盖了RISC-V与ARM架构的新兴商用与开源芯片。

此外，团队与**哈尔滨工程大学董剑**（Jian Dong 0010）的合作（近年多篇AsianHOST、DAC论文）呼应了汪东升"哈尔滨工程大学兼职教授"的社会兼职身份，构成了一条稳定的东北高校合作通道。与**香港科技大学（广州）的傅腾蛟、陈韵**在PPA工作中的合作，以及与**夏威夷大学Yingfei Dong**（合作4次）的早期合作，进一步补全了其跨机构版图。

在所内合作方面，汪东升与郑纬民、张悠慧的合作有实质性的论文产出，但与舒继武（存储方向）、陈文光（PACMAN课题组）、翟季冬、武永卫、钱学海等其他高性能所同事，公开的论文合作记录很少甚至没有。这反映出高性能计算研究所内部实际上是由若干个方向相对独立的课题组构成的松散联合体——存储组、PACMAN组、汪东升的微处理器与SoC组各自为战，共同的连接点更多体现在教学工作委员会、党支部活动、教师沙龙等组织层面，而非科研层面。2026年计算机系第三期教师沙龙由高性能所承办、陆游游主持、陈文光与汪东升共同分享的记录，正是这种组织性连接的典型例证。

## 五、业界合作关系深度分析

汪东升的产业界网络是其学术生涯中极具特色的一部分，其形态在2019年前后发生了根本性的转变：从"自主处理器研制的技术供给方"转变为"处理器安全的独立第三方检测者与国家级安全智库成员"。

### 自主处理器与国家重大专项时期的产业连接

2003年THUMP处理器的研制是他产业连接的起点。THUMP107作为当时国内主频最高（500MHz）的自主知识产权高性能嵌入式CPU，其意义不仅在于技术本身，更在于它使清华大学计算机系成为国内少数具备完整处理器设计能力的高校团队之一。以THUMP为基础，团队向产业界输出了一系列具体的芯片设计成果：视频编解码处理芯片、移动存储卡控制器、流量分配器、云终端等。这些产品化尝试说明团队的定位并非纯学术研究，而是带有明确工程交付属性的产学研单元。

2009年获得的"核高基"国家科技重大专项"众核处理器关键技术及应用性研究"是其参与国家重大专项的核心记录。该项目成果——64核以上的多核SoC仿真平台——在神舟六号载人飞船的仿真测试中发挥了重要作用，这标志着他的技术进入了国家航天工程的验证链条。需要说明的是，公开材料对这一应用的描述较为简略，具体的合作单位（推测为中国航天科技集团下属研究院所）并未披露。此外，团队骨干吕勇强还曾作为技术骨干参与完成"核高基"面向先进工艺的数字芯片后端设计"先进EDA工具平台"研发，这条线索表明团队与国产EDA产业也有实质性接触，并在近年"开展安全芯片设计与验证技术研究，促进EDA工具在安全芯片设计方面的能力提升"。

2012年与苏州云计算中心合作研制基于云存储的个人移动计算环境，是他与地方产业平台合作的代表，也是他获聘"苏州工业园区特约专家"的直接原因。2015年，团队研制的高性能视频编码算法模块被应用于某公司的H.265编码芯片中——官方主页在此处使用了"***公司"和"某公司"的打码表述，未披露企业名称。考虑到2015年前后国内在H.265编码芯片领域布局的企业主要包括海思、瑞芯微、全志等，这家企业推测可能是华为海思，但没有任何公开材料能够证实这一点，本报告不作确定性判断。

关于用户提出的"是否与华为海思、龙芯、飞腾等国产CPU厂商合作"这一核实要求，有一条明确的公开证据：邱朋飞的北京邮电大学个人主页中记载，他"作为骨干参与科技部重点研发、JKW基础加强、国家自然科学基金面上、**华为公司横向合作**等多项项目"。由于邱朋飞的博士与博士后阶段（2015至2022年）全程在汪东升团队度过，这条华为横向合作项目极大概率是以汪东升为负责人、由团队承接的。这是目前能够找到的、关于汪东升团队与华为存在正式产业合作关系的最直接证据。至于龙芯、飞腾等其他国产CPU厂商，公开渠道未见任何与汪东升团队的合作记录，用户提及的这一可能性无法证实。

### 处理器安全时代的产业影响力

2019年之后，汪东升团队的产业影响力呈现出一种独特的形态：不是通过技术转让或联合研发，而是通过"发现漏洞—通报厂商—影响产品设计"这一链条来施加影响。这种影响的量级远超传统的横向课题。

"骑士"漏洞（CVE-2019-11157）的处置过程是最具说服力的案例。该漏洞影响Intel和ARM两大主流处理器厂商的大量已部署产品，团队的漏洞发现工作"获得主流处理器厂商公告认可"，并"在漏洞修复和安全设计方面积极配合厂商，提升处理器产品安全性"。邱朋飞因此获得了Intel漏洞赏金奖励，是目前国内学者唯一一次获得该奖励。这意味着团队的研究成果直接进入了Intel的产品安全响应流程，实质性地改变了后续产品的微架构设计。

此后团队的多项工作都延续了这一模式。团队设计的大规模分布式硬件漏洞挖掘与安全检测平台，发现了被国家信息安全漏洞共享平台（CNVD）收录的首批四个处理器微架构漏洞。2024年HPCA的工作揭示了AMD推测性内存访问预测器的安全问题；2025年ASPLOS的MDPeek攻破了Intel SGX中的平衡分支保护；2026年NDSS的OCCUPY+PROBE绕过了Intel第11至14代Core处理器BTB中引入的硬件隔离机制——这三项工作分别指向AMD和Intel两家国际巨头的最新产品。与清华电子系联合完成的GhostCache工作则获得了ARM安全团队的认可，得到开源RISC-V处理器"香山"团队的感谢，并获得了SiFive（RISC-V架构主要推动厂商）的首个公开漏洞报告感谢。

这里有一个值得深入解读的战略维度。汪东升团队的漏洞研究对象几乎全部是Intel、AMD、ARM等国际厂商的商用处理器，而非国产CPU。这一选择与国内"自主可控"的产业政策背景形成了微妙的呼应关系。团队骨干吕勇强在《中国网信》杂志发表的《从处理器漏洞分析网络安全新风险》一文中明确阐述了这一逻辑："当前，我国进入自主处理器产业快速发展的关键时期，在突破处理器、芯片等'卡脖子'难题的关键节点上，须做好漏洞安全的防范工作，避免'安全失控'局面的发生。"换言之，团队的定位是：通过系统性地揭示国外主流处理器的硬件安全缺陷，为国产处理器替代提供技术层面的论证支撑，同时为国产处理器的自主设计提供安全设计的方法论积累。这一定位使得汪东升的研究天然具备了政策与产业双重价值。他担任国家计算机网络与信息安全管理中心科技委常委、清华大学数据安全研究所所长这两项职务，正是这种"国家级安全智库"角色的制度化体现。

值得注意的是，团队的研究成果连续入选世界互联网大会领先科技成果集（"现代处理器重大漏洞发现"，2023年，基础研究组），这是国家层面对其产业与战略价值的公开背书。

### 企业治理层面的连接

汪东升还兼任山东新北洋信息技术股份有限公司（简称"新北洋"，深交所上市公司，主营专用打印扫描设备与智能自助终端）的独立董事。这是他在企业治理层面唯一公开的正式职务。这一角色与其处理器安全研究的技术方向关联不大，更多体现的是学术声望在资本市场治理结构中的应用。他所获得的2022年山东省科学技术进步一等奖（与王海霞等团队成员共享），推测可能与其在山东省内的产业合作有关，但公开材料未披露具体项目内容。

### 产业影响的总体评价

综合来看，汪东升团队的产业合作深度呈现出"早期强工程交付、近期强规则影响"的双阶段特征。在自主处理器时代，团队通过THUMP及其衍生芯片、核高基专项、神舟六号仿真测试等具体交付物建立产业连接；在处理器安全时代，团队则通过漏洞披露机制、CNVD收录、厂商公告认可、国际漏洞赏金等渠道，获得了远超横向课题金额的产业话语权。后一种影响力更难量化，但对芯片产业的实际渗透力更强——每一个被修复的微架构漏洞，都意味着数以亿计的处理器产品设计被改写。

需要如实说明的是，尽管团队与产业界的互动痕迹明确，但绝大多数具体的合作企业名称、合同金额、项目周期等信息均未公开。华为横向合作项目是唯一被明确点名的企业合作，且信息来源是学生的个人主页而非官方项目公告。因此本节的分析在很大程度上依赖于对公开成果链条的推断，而非直接的合同证据。

## 六、重要奖项与学术兼职

汪东升的奖项体系可以分为国家级、省部级、学会级与校级四个层次，其中最具分量的是2020年中国计算机学会自然科学一等奖。

在国家级层面，他获得过国家科技进步二等奖1次。清华计算机系官网的表述为"曾获国家科技进步二等奖 一次"，2025年毕业典礼教师代表介绍中的表述为"曾获得国家科技进步二等奖1次，省部级一等奖3次、二等奖3次"。需要注意的是，官网"奖励与荣誉"栏目列出的是"省部级一等奖三次、省部级二等奖两次"，与毕业典礼介绍的"二等奖3次"存在一处细微出入，这类差异在高校官网的不同页面间较为常见，推测源于统计口径与更新时间的不同。已知的省部级二等奖至少包括北京市科技进步二等奖和教育部科技进步二等奖。

**2020年中国计算机学会（CCF）自然科学一等奖**是他学术生涯的巅峰奖项，获奖项目名称为"现代处理器重大安全漏洞发现"，完成人排序为汪东升（第一）、吕勇强（第二）、邱朋飞（第三）、王海霞（第四）。CCF自然科学一等奖是国内计算机领域基础研究的最高荣誉之一，每年授予数量极为有限。与此配套的还有2020年中国电子学会科技进步一等奖（部分材料记为2019年），以及2022年山东省科学技术进步一等奖。此外，"现代处理器重大漏洞发现"成果入选了2023年世界互联网大会领先科技成果集（基础研究组）。

在团队层面，近年的重要论文奖项包括：第三十三届NDSS杰出论文奖（OCCUPY+PROBE，2026年，学生融凯源、方骏祺）、AsianHOST 2025最佳论文奖（PPA，与电子系邓舒文团队联合）、IEEE AsianHost 2019最佳论文奖（吕勇强）。邱朋飞个人还两次获得AsianHOST年度唯一最佳论文奖，并获得2025年度ACM SIGSAC China"新星奖"。

在校级荣誉方面，他曾获清华大学优秀共产党员、清华大学先进工作者、清华大学研究生"良师益友"以及清华大学第三届"十佳优秀博士后"等称号。其中"良师益友"是清华大学由研究生投票评选的教师荣誉，含金量在校内教师群体中认可度较高，这与他被邀请作为教师代表在2025年清华大学计算机系毕业典礼上发言、以及在2026年计算机系教师沙龙上专门分享育人经验（围绕"做系统与写论文、成事与成人、个人发展与团队发展"三个话题）的记录相互印证，说明他在教书育人方面获得了系内外的广泛认可。他还是国家精品课程"计算机体系结构"的主讲教师，2024年计算机系1994级校友入学30周年纪念活动中，他与马少平以及杨士强、边计年、陈祖舜等离退休教师一同作为教师代表发言。

学术兼职方面，他的职务清单可以分为三类。

学术组织类：中国计算机学会体系结构专业委员会副主任（连任2012–2016、2016–2019两届，两届的主任均为国防科技大学窦勇，副主任团队还包括哈尔滨工业大学季振洲、东北大学王兴伟、南京理工大学张功萱等）、中国计算机学会YOCSEF荣誉委员。

期刊编委类：International Journal on Embedded Systems（EURASIP JES）Associate Editor。

政府与产业智库类：国家计算机网络与信息安全管理中心科技委常委、苏州工业园区特约专家、哈尔滨工程大学兼职教授、山东新北洋信息技术股份有限公司独立董事。

校内管理类：清华大学CPU中心主任、清华大学数据安全研究所所长、清华大学计算机学科学位评定委员会委员、清华大学计算机系教学工作委员会委员。

需要说明的是，与同为高性能所资深教授的郑纬民（中国工程院院士）、舒继武等人相比，汪东升目前没有公开的院士、长江学者、杰青等国家级人才称号记录。他的学术地位更多建立在具体的技术突破（"骑士"漏洞）与长期的学科组织服务（CCF体系结构专委会副主任）之上，而非人才帽子体系。这一点在评估其学术网络的层级时值得注意。

## 七、Connection圈层总结

综合前述分析，汪东升的学术关系网络可以划分为五个层次。

**第一圈层：核心科研共同体（4人）**

这一圈层由汪东升本人与吕勇强、王海霞、邱朋飞三人构成，其边界由2020年CCF自然科学一等奖的完成人名单精确界定。这是一个极为稳定的四人核心，成员分工明确：汪东升负责战略方向与团队领导，吕勇强负责漏洞发现与安全验证方法论，王海霞负责形式化验证与安全缓存设计，邱朋飞负责具体的漏洞挖掘与攻击实现。这个核心的特殊之处在于，它并非典型的"导师—学生"树状结构，而是"资深教授 + 两位固定研究员 + 一位杰出弟子"的混合结构——吕勇强与王海霞都不是汪东升的学生，而是各自完成学业后加入团队的独立研究人员，两人在团队中的地位接近于合伙人而非下属。邱朋飞虽已在2022年离开清华加入北邮，但从近三年的论文合作强度看，他实际上仍是这个核心的活跃成员。这一圈层是汪东升全部学术产出与产业影响力的发动机。

**第二圈层：门生与团队学生（约10至15人）**

这一圈层由汪东升历年指导的博士生与硕士生构成，其中已经形成独立学术身份的是邱朋飞（北京邮电大学网络空间安全学院特聘副研究员/副教授、博士生导师，ACM SIGSAC China新星奖获得者）。当前活跃的在读与近毕业学生包括刘畅（ARM/AMD内存消歧单元方向，ASPLOS、HPCA一作）、金宇（缓存与预取器侧信道方向，CCS一作、AsianHOST最佳论文）、融凯源（2022级，NDSS杰出论文奖）、方骏祺（2024级，NDSS杰出论文奖）、孙日辉、杨轶豪、张世轩、高强等。

这一圈层的一个显著特点是"清华博士—清华博士后—外校教职"的成才路径正在被反复复制，且毕业生离开后与团队的合作不但不中断反而加强，形成了跨机构的网络扩张。由于团队规模不大且汪东升在职业生涯早期以工程项目为主，公开可查的已毕业博士生数量相当有限，本报告只能确认邱朋飞一人的完整去向。这是本报告在信息获取上的一处明确局限。

**第三圈层：清华内部同事网络**

在所内，汪东升与郑纬民（合作18次，THUMP项目时期的战略领导者与项目伙伴，非师承）、张悠慧（合作15次，体系结构方向同代同事，非师生）构成了有实质论文产出的合作关系；与舒继武、陈文光、翟季冬、武永卫、薛巍、杨广文、钱学海、陈康、陈婧等高性能所同事则主要通过教学工作委员会、系务活动、教师沙龙等组织渠道连接，科研合作稀少。这反映了高性能所内部"存储组—PACMAN组—微处理器与SoC组"三足鼎立、各自独立的实际格局。

跨院系方面，他与清华大学电子工程系的邓舒文助理教授（隶属刘勇攀、杨华中团队）建立了近两年最活跃的校内跨院系合作，共同产出了GhostCache（CCS 2025）与PPA（AsianHOST 2025最佳论文奖）两项高影响力成果。他还与计算机系的季向阳（Xiangyang Ji，合作9次，生物特征认证方向）有稳定合作。作为CPU中心主任与数据安全研究所所长，他在北京信息科学与技术国家研究中心（BNRIST）体系内也占据着重要节点位置，吕勇强与王海霞的人事关系均挂靠于此。

**第四圈层：跨机构与国际学术网络**

国际方向的绝对枢纽是马里兰大学帕克分校的Gang Qu教授（合作28次）。这条通道由邱朋飞的国家留学基金委访学项目开启，现已成为团队每一项处理器安全成果的标配国际合作方，是团队国际能见度与漏洞披露渠道的重要支撑。新加坡国立大学的Trevor E. Carlson教授（ASPLOS 2025、HPCA 2026）是近年新增的高质量国际合作节点。日本早稻田大学的Takeshi Ikenaga教授（合作9次）则代表了视频编码时代留下的国际合作遗产。

国内跨机构方向，最重要的是北京邮电大学网络空间安全学院节点（王春卢16次、李小勇5次、邱朋飞27次），这条通道由邱朋飞2022年的就职直接建立，现已成为团队近三年论文的常规合著方。其次是南方科技大学张殷乾教授（可信执行环境安全方向）、哈尔滨工程大学董剑（与其兼职教授身份对应）、香港科技大学（广州）的傅腾蛟与陈韵。夏威夷大学的Yingfei Dong是早期分布式系统时代的合作者。

**第五圈层：产业与政策网络**

这一圈层的构成较为特殊，其连接方式不是常规的横向课题，而是漏洞披露机制。团队的成果直接触达Intel（官方公告认可 + 漏洞赏金）、ARM（安全团队认可）、AMD（HPCA 2024推测性内存访问预测器工作）、SiFive（首个公开漏洞报告感谢）等国际处理器厂商的产品安全响应流程，同时也获得了开源RISC-V处理器"香山"团队的感谢。国内产业方面，唯一被公开点名的企业合作是华为公司横向合作项目（信息来源为邱朋飞的北邮个人主页）。政策与治理层面，他通过国家计算机网络与信息安全管理中心科技委常委、清华大学数据安全研究所所长、苏州工业园区特约专家等职务连接政府侧，通过山东新北洋独立董事职务连接资本市场。

### 网络结构的整体特征

汪东升的学术网络最鲜明的特征，是它经历过一次彻底的、成功的重构。2018年之前，他的网络以刘振宇（视频编码）、薛一波（网络安全）、郑纬民（存储与分布式）为主要合作者，研究分散于SoC设计、视频编码、云存储、神经网络加速等多个方向，产出以中等档次会议与期刊为主，虽然工程价值突出，但学术影响力有限。2019年"骑士"漏洞的发现成为一个决定性的转折点：此后他将全部资源集中于处理器微架构安全这一单一方向，网络也随之收缩重构为以吕勇强、王海霞、邱朋飞、Gang Qu为核心的紧凑团队，产出档次跃升至HPCA、ASPLOS、CCS、NDSS等顶级会议。

这次重构的成功有三个关键因素。其一是二十余年自主处理器研制积累的微架构工程知识，使团队具备了别人不具备的"从内部理解处理器"的能力——这正是发现硬件漏洞的先决条件。其二是Gang Qu这条国际通道的建立，使团队的成果能够进入国际厂商的响应体系并获得权威背书。其三是国家在"卡脖子"背景下对处理器安全的战略需求，为团队提供了政策与资源上的强力支撑。

从年龄结构看，汪东升生于1966年，已届六十岁，但从2025至2026年的产出（NDSS杰出论文奖、HPCA、ASPLOS、CCS各1篇以上）看，其团队仍处于产能与影响力的高位。融凯源、方骏祺等在读博士生的表现，以及邱朋飞作为已独立门户弟子的持续活跃，共同构成了这个学术家族的可持续性保障。

### 关于信息获取局限性的说明

本报告在撰写过程中遇到了若干无法通过公开渠道解决的信息缺口，在此如实列明。

其一，汪东升的博士导师身份无法确认。清华大学官方页面、高性能计算研究所页面、百度百科等所有公开渠道均只记载其在哈尔滨工业大学获得博士学位，未披露导师姓名。本报告拒绝就此作出任何推测性指认。

其二，其历年指导的博士生完整名单与毕业去向无法获取。清华大学计算机系与高性能计算研究所均未公开教师的学生名录，本报告只能通过论文合作记录与零星的新闻报道反推出部分学生姓名，且仅能确认邱朋飞一人的完整职业去向。考虑到他自1997年留校至今近三十年的执教历史，实际培养的研究生数量应当远超本报告所能识别的范围。

其三，产业合作的具体细节高度受限。官方主页对2015年H.265编码芯片的合作方使用了打码处理；核高基专项与神舟六号仿真测试的具体协作单位未披露；除华为横向合作项目外，与其他国产CPU厂商（龙芯、飞腾、海光等）的合作关系无任何公开记录可查，用户提出的相关假设无法证实。

其四，量化的引用数据不可靠。OpenAlex对其档案的合并存在明显错误，混入了光学、化学等无关领域的论文；Google Scholar上未能定位到其经过验证的个人主页。因此本报告采用DBLP的收录数量（187项）作为主要计量依据，而对引用数与h-index仅作参考性引用并明确标注了数据质量问题。

其五，用户提及的"渠鹏"一名在清华大学高性能计算研究所现有教师名录中不存在，推测应为"钱学海"之误。钱学海与汪东升无师承关系。
