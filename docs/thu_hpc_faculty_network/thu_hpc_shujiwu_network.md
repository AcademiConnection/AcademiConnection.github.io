从研究轨迹看，舒继武的主线不是某一种存储介质的局部优化，而是"介质换代驱动系统软件重构"这一贯穿性命题。从2000年代的网络存储与存储虚拟化（TH-MSNS），到2010年代前期的闪存与开放通道SSD（TH-SSS、ParaFS、ReconFS），再到2010年代后期至2020年代前期的持久性内存与RDMA（TH-DPMS、Octopus、KucoFS、FlatStore、Sherman），直至近年的分离式内存、计算型存储与大模型存储（λ-IO、TeRM、Mobius、HCache、GPU Checkpoint/Restore），每一轮转型都遵循同一方法论：先识别新硬件与旧软件栈之间的语义错配，再重写抽象层与一致性协议，最后推动产业落地。这一方法论直接塑造了他的关系网络形态——学术上与体系结构、数据库、可靠性理论多个社群交叉，产业上与华为、阿里、快手、浪潮、中兴等企业形成从课题资助到产品部署的长链条。

## 二、教育背景与职业履历

舒继武的学术训练路径横跨三所院校，且与常见的"本硕博一校直升"模式差异明显。他1991年毕业于国防科技大学计算机系软件专业，获工学学士学位；1996年在江苏大学获计算科学与技术工学硕士学位；1998年在南京大学计算机系获计算机科学与技术工学博士学位。这一"国防科大—江苏大学—南京大学"的组合意味着他早期的知识背景兼具军队院校的系统工程训练与南京大学计算机软件学派的理论熏陶。关于其南京大学博士阶段的具体导师姓名，公开可检索的清华官方教师页、个人主页和南京大学公开材料均未直接列出，本报告不将任何具体学者指认为其博士导师；网络上偶见的与徐家福、谢立等南大软件学派前辈相关的联想，缺乏可引用的公开证据链，只能标为**推测且不纳入事实关系图谱**。

真正对其学术方向起决定性作用的，是博士后阶段。1999年1月他进入清华大学计算机系从事博士后研究，2000年1月至6月赴香港理工大学开展合作研究，2000年10月博士后出站后留清华任教。多篇公开报道明确记载其博士后合作导师为中国工程院院士郑纬民——中国网络存储系统的开拓者之一。舒继武本人在公开访谈中表示郑纬民院士是"对他影响最大的人"，不仅是数据存储科研道路上的引路人，更教会了他如何思考和解决问题。这条师承链构成了理解其全部关系网络的起点：他的研究方向（网络存储）、他所在的组织平台（高性能计算研究所）、他早期的国家级项目参与路径（863海量存储、深腾系列集群），都直接承接自郑纬民的学术资源与产业连接。

当前在读学生规模约二十余人，博士生包括林家桢（六年级）、冯杨洋、曾少勋、陈鉴、王耀龙（五年级）、张庶杰、杨倚天、李泽祺（四年级）、郭昊、范如文、高世伟（三年级）、蒋昊迪、白华君、边润华（二年级）、罗以彬、黄俊荣、田昊冬、刘义祥（一年级），另有都政、程卓、罗先强、杨佳东等，硕士生包括陈纪源、任庭旭、孙源泽。这一梯队近年在竞赛与顶会上表现突出：2025年由高世伟、范如文等组成的团队获ASPLOS/EuroSys大模型推理优化竞赛冠军，2026年由高世伟、范如文、任庭旭、罗以彬组成的团队在MLSys 2026混合专家模型内核优化挑战赛中夺冠，两次的指导教师均为舒继武与陆游游，后者还有腾讯AI系统专家提供技术支持。

### （五）培养体系的结构性特征

三点值得强调。其一，**双导师协同已成为常态**。近年绝大多数重要成果（Sherman、Nap、λ-IO、TeRM、Mobius、GPU Checkpoint/Restore等）的指导教师栏都同时出现舒继武与陆游游，说明这是一个由资深PI与中生代PI共同运行的团队，而非单一导师制。这也意味着在判断具体学生的师承时必须区分"舒继武直接指导""舒陆联合指导""陆游游指导"三种情形——谢旻晖属于第三类。

其二，**学术与产业两条出口并重且均达到顶尖水准**。学术侧输出了清华、上海交大、北航、人大、厦大、天大、北方工业大学、伦敦国王学院的教职；产业侧则以华为为最大接收方，且以"天才少年"这一最高层级引进（杨帆、杨者），阿里巴巴近年成为第二大接收方（李俊儒、颜彬、吕文豪）。这种双出口结构使他的关系网络同时具备学术再生产能力与产业需求牵引能力。

其三，**南京大学是其重要的生源地**。陆游游（2009届）、谢旻晖（2019届）均为南大本科出身，考虑到舒继武本人的南大博士背景，这条通道很可能存在长期的非正式推荐关系（**推测**，公开材料未记载正式的推荐机制）。

## 四、学术合作网络

### （一）清华内部：郑纬民—舒继武—陆游游/张广艳的三代结构

清华高性能计算研究所内部，舒继武处在承上启下的中枢位置。**郑纬民**院士是其博士后合作导师，也是其早期国家级项目的引路人；两人的合作在文献层面有直接体现，例如《基于非易失性存储器的存储系统技术研究进展》（《科技导报》2016）由舒继武、陆游游、张佳程、郑纬民共同署名，Extending the Lifetime of Flash-based Storage（FAST'13）由陆游游、舒继武、郑纬民共同署名。即便在近年，郑纬民仍在存储组的重大成果中提供指导——2024年ISC24发布的IO500榜单夺冠新闻明确提到该成果"得到计算机系高性能所郑纬民院士、陈文光教授以及鹏城实验室的精心指导和大力支持"。这条链条使舒继武成为清华存储学脉从第一代（郑纬民）向第三代（陆游游、张广艳）传递的关键节点。

**陆游游**是其最紧密、最高频的合作者，也是最重要的学术继承人。两人的关系历经三个阶段：2009—2014年的师生阶段（陆游游为其博士生），2014年后的同事阶段（陆游游留校），以及2020年前后开始的联合PI阶段（存储研究组官网将两人并列为"导师团队"）。二人的共同署名论文横跨FAST、OSDI、ATC、EuroSys、ASPLOS、SC、VLDB、NSDI、SOSP等几乎所有系统顶会，且近年的分工趋于清晰：陆游游更多主导GPU系统、向量搜索、LLM推理等新兴方向，舒继武则在持久内存、纠删码、存算融合等传统强项与产业大项目中把关。

**张广艳**是其2008年毕业的博士生，现为清华计算机系长聘副教授、国家杰青。值得注意的是，张广艳并未留在存储研究组，而是发展出独立的团队（fastsys.cs.tsinghua.edu.cn），研究方向偏向开放通道SSD综述与大规模存储系统，并与郑纬民合作组织FITEE"新型存储系统设计与应用"专题。他现任CCF信息存储技术专业委员会副主任，与舒继武曾任的主任职务形成学脉在学会组织层面的接续。**陈文光**教授作为高性能所同事，在IO500等大型系统工程中提供支持。

### （二）国内存储共同体：与华中科技大学、国防科大/中山大学的三角关系

中国存储学术共同体的组织骨架长期由三个团队支撑：清华（郑纬民—舒继武—陆游游/张广艳）、华中科技大学（冯丹—王芳—周可—胡燏翀）、国防科技大学/中山大学（方粮—肖侬—王意洁）。CCF信息存储技术专业委员会的历届主任更迭精确地反映了这一结构：2012—2016届主任方粮（国防科大），副主任包括冯丹、李战怀、舒继武、许鲁、朱平；2016—2019届主任冯丹（华科），副主任包括李战怀、舒继武、肖侬、许鲁、朱平；2020—2024届主任舒继武（清华），副主任为肖侬、王芳，秘书长王意洁。

这种轮值结构使三方的关系性质是**长期共治的同行伙伴，而非上下级或师承**。可观察的密集共同活动包括：第29届全国信息存储技术学术会议（NCIS2023）由舒继武（清华/闽江学院）、肖侬（中山大学）、冯丹（华中科技大学）共同担任大会主席，该次会议同时也是CCF存储专委的换届工作会议，程序委员会主席包括中山大学陈志广、清华陆游游、华科胡燏翀；2024年5月第十三期CCF秀湖会议以"新应用和硬件驱动下的存储技术创新"为题，舒继武作开场特邀报告《存储系统发展的主要趋势：机遇与挑战》，同场专家包括郑纬民、孙凝晖、金海、冯丹、肖侬、周可，以及浪潮数据总经理李辉。此外，舒继武自2017年起担任依托华中科技大学的信息存储系统教育部重点实验室学术委员会委员，这是清华与华科团队之间最正式的制度化连接。

### （三）国际合作：香港中文大学、威斯康星、佛罗里达

**Patrick P. C. Lee（李柏晴，香港中文大学）**是其最稳定的国际合作者，合作聚焦纠删码与故障恢复。可确认的共同署名论文包括Reconsidering Single Failure Recovery in Cluster File Systems（DSN'16）、Seek-Efficient I/O Optimization in Single Failure Recovery for XOR-Coded Storage Systems（SRDS'15，Nominated Best Paper）、Boosting Full-Node Repair in Erasure-Coded Storage（ATC'21），以及TDSC 2020、TPDS 2019等多篇期刊论文。这些工作多以沈志荣（现厦门大学副教授）为纽带，形成"清华—港中大—厦大"的三角合作圈。

**Andrea Arpaci-Dusseau与Remzi Arpaci-Dusseau（威斯康星大学麦迪逊分校）**代表文件系统领域最权威的国际连接。二人与舒继武、陆游游、陈游旻、朱博弘共同署名FAST'21论文Scalable Persistent Memory File System with Kernel-User Space Collaboration（即KucoFS）。这一合作的形成路径清晰：陈游旻2019—2020年赴威斯康星ADSL实验室访问，指导教师即Remzi、Andrea与Xiangyao Yu，学生流动直接转化为论文合作。

### （四）跨学科与校内交叉合作

在清华校内，他与电子工程系刘勇攀、汪玉、杨华中团队在非易失IO系统与能量采集节点方向有多篇DAC论文合作；与北京大学孙广宇团队合作了Hi-fi Playback（ISCA'15，赛道存储器移位误差容忍）。这些工作显示其研究触角从系统软件向下延伸至体系结构与电路层。近年SOSP'25论文μTPS的作者名单中出现上海交通大学沈艳艳、黄林鹏与梅宏院士，说明其合作圈在向数据库与软件工程社群扩展。

## 五、业界合作关系深度分析

舒继武的产业合作是国内计算机学界"产学研闭环"最完整的样本之一。其独特之处在于，合作不停留在横向课题或冠名奖学金层面，而是形成了"企业出题—联合攻关—论文发表—产品部署—人才输送"的完整链条。清华官方教师页所列的"Industry-Sponsored Projects"（企业委托项目）时间跨度从2017年延续至2026年，构成一条几乎不间断的资助线。

### （一）华为：从奥林帕斯奖到FusionStorage与磁带云归档

华为是其最深度、最长期的产业伙伴，合作可分为四个层次。

**第一层是标志性的奥林帕斯奖。**华为于2019年设立"奥林帕斯奖"，面向全球科学家悬赏解决数据存储领域的重大难题。2020年，舒继武率队以"持久性内存存储系统构建与关键技术"成果获得该奖首届唯一大奖及100万元奖金。这一奖项的分量在于其评审门槛——华为将其定位为牵引数据存储领域基础理论突破的最高级别产业奖。获奖团队的核心成员包括陆游游、博士后陈游旻、博士生汪庆、硕士生朱博弘，可见该成果是整个研究组的集体产出。同年，相关成果还获得中国计算机学会科学技术奖技术发明一等奖。

**第二层是产品级技术落地。**2021年，其团队获深圳市科学技术奖一等奖，获奖项目为"新一代分布式存储系统FusionStorage 6.3"——FusionStorage正是华为的分布式存储商用产品线（后整合入OceanStor Pacific系列）。这是校企合作从论文层面进入商用产品层面的直接证据。

**第三层是联合论文与生产系统披露。**近年最具代表性的是FAST 2026论文《Cost-efficient Archive Cloud Storage with Tape: Design and Deployment》（Best Paper Candidate），作者名单为汪庆、杨帆、刘强、肖庚、陈永鹏、兰颢、陈雷鸣、陈邦柱、刘晨瑞、白平昌、黄斌、罗子淦、谢明宇、王宇、陆游游、吴华涛、舒继武——十七位作者中包含大量华为工程师，且第二作者杨帆正是2022年毕业赴华为的"天才少年"。这种"毕业生在企业侧、导师在学校侧"的联合署名模式，标志着合作已深入华为的真实生产系统。类似地，华为的黄克骥（Keji Huang）反复出现在其团队论文中，包括TeRM（FAST'24）、SwitchTx（VLDB'22）、OSDI'25纠删码内存存储论文，是华为侧长期对接的技术负责人。

**第四层是人才输送。**李明强（2011博士）、杨帆（2022博士，天才少年）、杨者（2024博士，天才少年）、陈佩（2021硕士）、方科栋（2022硕士）构成一条持续十余年的输送链。"天才少年"是华为最高规格的应届生引进计划，一个课题组连续产出两名入选者，在国内极为罕见。

**第五层是战略咨询与议程设置。**2024年华为云生态大会上，舒继武作《AI大模型时代，云存储发展的机遇与挑战》主题演讲，与华为云存储服务产品部部长林超同台，提出"AI原生的文件存储服务"与"以GPU为中心的模型数据存储服务"两条破局思路。他还参与了CNCC2021华为CCF胡杨林基金论坛，与华为战略与业务发展副总裁肖然、华为计算产品线副总裁姜涛等共同介绍技术趋势与基金投入方向。这意味着其角色已超出承接项目的研究者，而是参与华为存储技术路线图制定的外部智囊。

### （二）阿里巴巴：从Open-Channel SSD到近年的人才承接

阿里巴巴的合作起点是开放通道SSD（Open-Channel SSD）。舒继武团队提出的"软件直管的开放通道闪存存储架构"获Linux 4.4内核及后续版本支持，这是中国存储学界少有的被主流开源内核直接采纳的架构级贡献。清华官方页面明确表述该方向研究"获得华为、阿里、中兴、快手等公司资助，部分成果已转化到公司并获得应用"。近年阿里巴巴成为其博士毕业生的第二大接收方（李俊儒2024、颜彬2026、吕文豪2026），说明合作从技术转移延伸到了人才通道。

### （三）快手：推荐系统存储层的深度耦合

快手方向的合作以推荐系统的内存/存储瓶颈为切入点，成果链条完整。Kraken（SC'20）由谢旻晖、Kai Ren、陆游游、林家桢、杨广旭、吴碧海、杨帆、徐万鸿、舒继武共同署名，其中多名作者来自快手，论文主题是大规模实时推荐的内存高效连续学习。后续的PetPS（VLDB'23）、Fleche（EuroSys'22）延续这一方向。清华计算机系官方新闻明确指出，谢旻晖博士论文的"相关技术已在快手公司线上推荐业务中落地应用"，且他在人大任教后仍主持"快手校企合作项目"。这是"学生毕业—技术留在企业—校企合作延续"的典型样本。

### （四）浪潮、中兴与国家级平台

浪潮的连接主要通过CCF存储专委的组织平台实现。2024年6月，CCF信息存储技术专委会首场"走进企业"活动即选择浪潮信息，主题为"大模型时代数据中心存储技术创新和应用"；同年5月的CCF秀湖会议上，浪潮数据总经理、国家信息存储工程技术研究中心主任李辉与舒继武同为特邀报告人。**推测**这类互动更多属于产业议程共建而非具体技术合同，公开材料未见二者的联合论文或联合产品。

中兴通讯出现在清华官方页面所列的资助企业名单中（"华为、阿里、中兴、快手等公司资助"）。此外，2016年毕业的博士罗圣美具有中兴通讯研发背景，可能属于在职培养通道（**推测**）。

在国家级平台层面，他曾任863计划"海量存储系统关键技术"重大项目总体专家组副组长（2008—2010），这是国内存储领域最重要的国家级科技计划之一，该职务意味着他在存储技术路线的国家层面规划中拥有话语权。他还长期任职于灾备技术国家工程实验室（副主任及技术委员会委员，2008—2021）和高效能服务器和存储技术国家重点实验室（学术委员，2008—2018；荣誉委员，2018起）——后者依托浪潮，构成与浪潮体系的制度化连接。2021—2026年任北京信息灾备技术产业联盟副理事长，这是典型的产业联盟型职务。

### （五）国家重大专项与项目布局

其主持或参与的国家级项目呈现清晰的方向演进。早期以973计划一级课题"下一代互联网存储按需部署模型与服务质量研究"（2004—2009）和863重大课题子课题"海量存储系统软件和关键技术"（2009—2010）为主；中期转向国家自然科学基金杰青项目"大规模网络存储系统的可靠性关键技术研究"（2010—2013）与两个自然科学基金重点项目（2013—2017网络公用数据存储可靠性与灾备；2019—2023新型分布式存储系统高可靠性）；2018年起承担国家重点研发计划重点专项项目"TB级持久性内存存储技术与系统"（2018—2021）及配套课题；最新一轮则明确转向AI基础设施——国家重点研发计划重点项目"面向大模型训练的异构计算存储系统"（2024—2027）、子课题"面向大模型训练的高效容错软件与异构计算存储系统"（2024—2027），以及国家自然科学基金联合重点项目"面向大规模深度学习模型的存算一体智能异构计算系统研究"（2023—2026）。这条演进线与其产业合作的重心迁移（从传统存储到AI存储）高度同步。

### （六）标准制定

公开材料中未检索到舒继武个人牵头制定某项国家标准或行业标准的直接记载。可以确认的是他通过CCF存储专委主任、863总体专家组副组长、多个国家级实验室学术委员的身份，参与了存储技术方向的规划与共识形成——例如CCF秀湖会议明确以"充分讨论形成共识，发出倡议，促进产学研政融合"为目标。将其表述为"参与技术路线共识与产业倡议的形成"比"主导标准制定"更贴合公开证据；后者属于**推测**。

## 七、Connection圈层总结

将上述材料按亲疏与性质分层，可以得到一张以舒继武为中心、辐射学术与产业两端的关系图谱。需要说明的是，圈层划分反映的是关系强度与性质，而非重要性排序。

**第一圈层——学脉源头与最紧密的学术共同体。** 核心是郑纬民院士（博士后合作导师，中国网络存储开拓者）与陆游游（其博士生，现存储组共同PI）。这两人分别构成他向上承接与向下延伸的轴线。郑纬民赋予他方向、平台与国家级项目通道；陆游游则是其学术资产的主要继承与放大者，两人的联合署名几乎覆盖了2015年以来存储组的全部重要成果。张广艳（2008博士，清华副教授、杰青、CCF存储专委副主任）虽已独立发展团队，但在学脉与学会职务上构成第二条延伸线。这一圈层的特征是"同机构、跨代际、长期共同署名"。

**第二圈层——已成建制的门生网络（"中国存储学派"的第二代教席）。** 包括上海交通大学陈游旻、北京航空航天大学廖晓坚、厦门大学沈志荣与高聪明、上海交通大学郑圣安、天津大学张余豪、北方工业大学傅颖勋、伦敦国王学院毛海宇、俄亥俄州立大学汪旸，以及作为再传弟子的中国人民大学谢旻晖（陆游游指导）。这一圈层的价值在于，它已经在清华之外形成了多个自我繁殖的存储研究据点，且这些据点之间仍保持合作（如陈游旻与舒继武共同署名SOSP'25的μTPS）。到2026年，国内系统存储方向的青年教席中，出自清华存储组的比例已相当可观，这是"学派"而非"实验室"的判据。

**第三圈层——国内存储共同体的同侪治理网络。** 主要成员是华中科技大学冯丹、王芳、周可、胡燏翀，中山大学/国防科技大学肖侬，国防科技大学方粮、王意洁，西北工业大学李战怀，中科院计算所许鲁，江南计算所朱平。这一圈层的连接机制是CCF信息存储技术专业委员会的轮值主任制与全国信息存储技术学术会议（NCIS）的联合主席制，而非论文合作。舒继武2020—2024年任主任，前任冯丹、前前任方粮，形成清华—华科—国防科大三方共治的稳定结构。他同时担任依托华科的信息存储系统教育部重点实验室学术委员会委员，是这一圈层最正式的制度化纽带。**这一圈层的性质是"同行共治"，不应误读为师承或从属关系。**

**第四圈层——国际学术合作网络。** 香港中文大学Patrick P. C. Lee（纠删码与故障恢复，合作最持久）、威斯康星大学麦迪逊分校Andrea与Remzi Arpaci-Dusseau（文件系统领域权威，经陈游旻访学建立连接）、佛罗里达大学Tao Li（存内计算/PIM）、Song Jiang（相变存储器可靠性）、微软研究院Anirudh Badam与Tomas Moscibroda（日志结构NVM）。这一圈层规模不大但质量高，且多数由学生流动或学术访问触发，体现"人带关系"的形成机制。

**第五圈层——产业合作与人才输送网络。** 华为处于绝对核心位置，连接形态最为立体：奥林帕斯奖（2020）、FusionStorage 6.3产品奖（2021）、黄克骥等技术专家的长期联合署名、FAST'26磁带归档的十七人产学联合论文、两名"天才少年"（杨帆、杨者）与多名硕博的人才输送、华为云生态大会的战略议题演讲。阿里巴巴以Open-Channel SSD技术转移起步、近年成为主要人才接收方（李俊儒、颜彬、吕文豪）。快手在推荐系统存储层形成Kraken—PetPS—Fleche的连续产出，并有技术在线上业务落地。腾讯（高健、张佳程）、第四范式（王晶）、中兴（资助方）、浪潮（通过CCF专委与国家重点实验室的组织连接）构成外围。这一圈层最值得注意的特征是，产业关系并非停留在资金层面，而是通过毕业生在企业内部形成技术接口，使合作能够跨越"项目周期"持续存在。

**综合判断。** 舒继武在中国存储学界的位置可以概括为"承前启后的枢纽型奠基者"。他并非中国网络存储研究的最初开创者——那一角色属于郑纬民、冯丹等第一代学者；但他是把这一领域从"跟随国际、系统研制"推进到"引领国际、顶会顶刊高密度产出并反哺产业"的关键中间代表。三项证据支撑这一判断：其一，他建立并长期运行的清华存储研究组，是国内存储方向顶会产出最密集、毕业生教席分布最广的团队，具备学派的自我繁殖能力；其二，他在CCF存储专委主任、863总体专家组副组长、多个国家级实验室学术委员等职务上参与了国家层面的存储技术议程设置，具备学科组织能力；其三，他与华为的合作从奥林帕斯奖到商用产品再到生产系统联合论文，走通了国内计算机学界罕见的完整产学研闭环，具备产业转化能力。这三种能力的叠加，使他区别于单纯的高产学者，而更接近于一个领域生态的构建者。

需要保留的不确定性有三点。其一，其南京大学博士阶段的导师姓名在公开材料中无法确认，任何具体指认都属推测。其二，随着他自2020年起相继担任厦门大学信息学院院长、闽江学院院长、闽江大学校长，其在清华存储组的日常参与程度是否发生变化，公开材料无法判断；但从2025—2026年他仍作为通讯/末位作者出现在FAST、OSDI、SOSP等顶会论文，以及仍担任MLSys 2026竞赛团队指导教师来看，其科研参与并未中断。其三，其在标准制定层面的具体贡献缺乏可引用的公开记载，报告仅以"参与技术路线共识与产业倡议形成"表述。
