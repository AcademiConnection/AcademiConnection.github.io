## 二、二十七位教师的角色定位

郑纬民院士是高性能所当之无愧的精神领袖与学术奠基人，中国工程院院士，长期担任研究所创始所长，培养了陈文光、张悠慧等多位现任骨干教授，其个人合作网络几乎覆盖了全所三代教师，是整个关系网络无可争议的中心节点。

翟季冬教授是研究所现任所长（2025年接任），PacMAN实验室负责人，长期从事高性能计算系统软件与性能分析研究，独立培养了金煜阳、王豪杰等多位青年教师，是研究所行政与学术传承的现任枢纽。

陈文光教授师从郑纬民，曾任ACM中国理事会主席（2017-2020），是并行编译与大数据系统方向的领军人物，与翟季冬共同主持PacMAN实验室，是连接"郑纬民一代"与"翟季冬一代"的关键桥梁。

武永卫教授现任副所长，长期指导章明星等青年骨干，是清华系AI算力创业公司"趋境科技"的首席科学家，Mooncake（FAST 2025最佳论文）与KTransformers项目的核心推动者，代表了研究所在大模型基础设施领域的最新产业布局。

舒继武教授是存储系统方向的领军人物，长期领导存储研究组（Storage Research Group），培养了陆游游、张广艳两位现已独立发展的副教授，三人共同构成了研究所在持久内存与分布式存储领域的完整代际梯队，舒继武本人还曾在厦门大学、闽江学院等校担任院长、校长等外部行政职务。

杨广文教授是超算应用与并行算法方向的资深教授，长期布局国家超算无锡中心与太初元碁等产业平台，赵文来副研究员是其嫡传博士生并在这些平台中担任技术执行角色，师徒二人共同构成了研究所面向国产超算产业化的重要力量。

薛巍教授是研究所前任所长，长期从事系统软件与超算应用研究，代表性工作AP3ESMv2曾运行于神威（Sunway）系列超算系统。

钱学海教授的研究方向覆盖高性能计算相关领域，是正高职级中活跃的合作节点之一。

张悠慧研究员师从郑纬民，专注类脑计算方向，是渠鹏助理研究员的博士及博士后合作导师，二人构成了研究所在类脑计算方向的师承主线。

汪东升教授本硕博均毕业于哈尔滨工业大学，并非郑纬民学生，是研究所内少见的"非清华本校培养"资深教授代表。

陈康研究员长期与清华计算机系软件研究所的陈渝副教授保持跨研究所合作，在操作系统、可信执行环境和无服务器计算方向产出多项顶会成果（ASPLOS、SOSP、OSDI、EuroSys），部分工作与蚂蚁集团生产系统需求紧密绑定。

陈婧教授、李兆麟教授分别在各自研究方向上活跃，其中李兆麟本硕博同样毕业于哈尔滨工业大学，与汪东升构成研究所内"HIT系"教师的另一实例。

章明星副教授是武永卫的嫡传弟子，在清华博士后期间曾赴深信服担任首席算法技术专家，2022年回归清华任教，是趋境科技的联合发起人，Mooncake与KTransformers两大开源项目的直接发起者与通讯作者，2024年与武永卫、郑纬民、姜进磊等共同获得华为第五届奥林帕斯奖最高荣誉。

陆游游副教授、张广艳副教授均师从舒继武，二人分别在持久内存文件系统和网络存储可靠性方向发展出相对独立的研究方向，陆游游兼任高性能所党支部书记，张广艳拥有独立的FASTsys课题组网站，二人共同支撑起舒继武退居幕后之后存储组的日常运转。

黄震春副研究员是研究所内资历最深的教师之一，师从已故的李三立院士，长期从事空间信息网格研究，其学术脉络与当前主流的AI基础设施方向有明显代际差异，代表了研究所更早期的网格计算传统。

姜进磊副研究员的真实学术起点是清华CSCW研究奠基人史美林教授，2008年前后从CSCW实验室转入高性能所MADSys实验室，现为SOSP、OSDI、ASPLOS等顶会的活跃共同作者，是研究所内"学术转型"的典型案例。

余宏亮副研究员、赵颖副研究员共用同一间办公室分机号，但研究方向截然不同（余宏亮专注并行与存储系统，赵颖专注数据挖掘与AI for Science），经核实二人并非同一研究团队，仅为办公空间毗邻的巧合。

鞠大鹏副研究员长期参与国家863重点项目与郑纬民主导的海量存储系统研发，2007年国家科技进步二等奖获奖团队成员之一，与张悠慧、余宏亮同组。

韩旭助理研究员的学术根基实际在自然语言处理领域（THUNLP实验室），师从刘知远，是OpenBMB开源社区与MiniCPM系列大模型的核心推动者，代表了高性能所在"大模型时代"跨方向吸纳青年人才的战略布局，与传统高性能计算方向的教师形成鲜明对比。

金煜阳助理研究员是翟季冬的嫡传博士生，清华学生超算团队教练之一，凭借ScalAna项目获得IEEE TPDS 2025年度最佳论文奖，是研究所内最年轻的骨干之一。

渠鹏助理研究员（现已晋升副研究员）师从张悠慧，专注类脑计算与向量处理器架构，与爱丁堡大学Boris Grot教授有国际合作，经核实此前流传的"CCF优博"荣誉实为与韩旭的张冠李戴。

闪英迪助理研究员专注分布式存储与KVCache存储系统，师承脉络指向陈康（推测），2022至2024年间曾赴北京中关村实验室工作后回归清华，与Mooncake生态可能存在关联（推测）。

王豪杰助理研究员经交叉核实确认师从翟季冬（而非此前部分材料推测的陆游游），是InfiniTensor开源项目的主持者，深度绑定启元实验室与国产算力生态。

赵文来助理研究员是杨广文的嫡传博士生，同时在国家超级计算无锡中心、太初元碁、海南自贸港研究院等多个平台担任技术与管理职务，是师徒二人共同布局产业化生态的直接执行者。

## 三、全研究所关系网络的整体观察

高性能所的师资网络呈现出几个较为清晰的结构性特征。

第一是"三代同堂"的学术传承结构，且传承路径存在明显的"双主干"现象。郑纬民作为创所元老培养了陈文光、张悠慧等教授级学生，形成第一条主干；舒继武培养了陆游游、张广艳两位副教授，形成第二条相对独立的"存储组"主干。翟季冬、武永卫、章明星等人又在陈文光、郑纬民一代的基础上培养出金煜阳、王豪杰等更年轻的助理研究员，使得整个研究所呈现出"郑纬民/舒继武（一代）→陈文光/武永卫/翟季冬/陆游游/张广艳（二代）→章明星/金煜阳/王豪杰等（三代）"的清晰代际链条。值得注意的是，汪东升、李兆麟两位教授均本硕博毕业于哈尔滨工业大学，并非这条清华内生传承链条的产物，构成了研究所师资来源多元化的例外。

第二是"存量学术方向"与"新兴产业方向"并存的双轨格局。以舒继武-陆游游-张广艳为代表的存储系统方向、以杨广文-赵文来为代表的超算应用方向、以黄震春为代表的网格计算方向，都属于研究所建立已久的传统优势领域；而以武永卫-章明星为代表的大模型推理系统（Mooncake、KTransformers、趋境科技）、以韩旭为代表的大模型算法（THUNLP、OpenBMB、MiniCPM）、以翟季冬-金煜阳为代表的性能分析与国产算力生态（InfiniTensor、启元实验室），则代表了研究所近三到五年内主动布局的新兴方向。这种新老并存的格局也解释了为什么本次调研中会出现"韩旭的学术根基实际在NLP领域"这类看似"错位"却实为战略布局的案例。

第三是与工业界深度绑定的产学研生态，且已发展出成体系的创业公司集群。武永卫、章明星深度参与的趋境科技，郑纬民、武永卫、章明星、姜进磊共同获得华为奥林帕斯奖的Mooncake"以存换算"方案，杨广文、赵文来布局的太初元碁与国家超算无锡中心，陈康与陈渝团队和蚂蚁集团生产系统深度绑定的Occlum/Skyloft系列成果，陆游游、张广艳存储组与华为、阿里巴巴的长期合作（华为奥林帕斯奖、阿里云百PB级日志存储部署），共同构成了一幅覆盖"大模型推理基础设施—国产超算产业化—云原生安全系统—企业级存储"的完整产学研图谱，这一图谱的密度与广度在国内高校计算机系中都属少见。

第四是所长职务的历史更迭与信息更新滞后问题。研究所的行政负责人历经"郑纬民（创所所长）→薛巍→翟季冬（现任所长，2025年起）"的更迭，本次调研中发现由于多位教师的官方个人主页更新周期不一，部分历史资料仍沿用"薛巍任所长"或笼统提及"郑纬民院士任所长"的表述，本系列报告已通过交叉验证统一为"翟季冬现任所长"这一最新事实，并对历史时点的表述保留其原有语境（如某教师2020年获奖时"时任所长为薛巍"这类历史快照予以保留）。

第五是同名与信息污染问题在数据核实过程中反复出现。渠鹏与韩旭的荣誉存在被公开材料混淆的情况（CCF优秀博士学位论文奖实际归属韩旭而非渠鹏）；多位教师的OpenAlex、Google Scholar学术画像存在与同名学者混同的问题（如陈康、汪东升、张悠慧、姜进磊等人的引用数据均检测到同名污染，本系列报告在各自文件中已改用机构过滤或DBLP数据加以说明）；此外，郑纬民院士的院士身份在个别文件的初稿中曾被误记为"中国科学院院士"，经交叉验证已统一更正为"中国工程院院士（2019年当选）"。这些问题提示，涉及人物身份、荣誉归属的信息在缺乏权威信源直接确认时，务必通过多信源交叉印证，不可仅凭单一网页或聚合数据库的记录下结论。

## 数据来源与说明

各报告数据主要来源于清华大学计算机系高性能计算研究所官方教师名录及各教师个人主页（hpc.cs.tsinghua.edu.cn）、清华大学计算机系官方新闻、学科发展研讨会报道、党建活动报道、获奖公告，以及DBLP、Google Scholar、OpenAlex等学术数据库。由于本系列报告由多个独立调研流程分批完成，初稿中出现的部分事实性矛盾（如所长继任时间线表述不一、个别师承关系的误判、院士类型的笔误等）已在交叉验证阶段逐一核查并直接修正，具体修正内容包括：统一"翟季冬现任所长（2025年起）"的表述并保留历史时点快照的原始语境；确认王豪杰助理研究员的真实导师为翟季冬（而非此前部分材料推测的陆游游）；确认渠鹏助理研究员的真实导师为张悠慧、CCF优秀博士学位论文奖实际归属韩旭；统一郑纬民院士为"中国工程院院士"的表述。报告中标注为"推测"的师生关系或合作关系不代表官方确认的正式记录，如遇后续信息更新，请以学者本人或学校官方发布为准。
