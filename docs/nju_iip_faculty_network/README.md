## 全团队关系网络的整体观察

IIP的核心结构是"谢—王双核心"的平辈共治形态：谢俊元（55次合作，2009-2026年，占王崇骏DBLP记录约四分之一）与王崇骏于2011年11月17日共同创立中德HPI研究院，二人分别提供安全工程积淀与现任负责人角色，与LAMDA式的"导师—学生"传承结构形成对照。这一口径经两份报告独立统计核验一致。王崇骏的另一重要网络节点是高阳（南大机器学习元老，另有报告）——但经核验二人在DBLP上零合作，纯属同事关系；高阳仅与谢俊元有6次合作（2005-2026）。IIP的学生梯队呈三代结构：吴骏/张雷（中生代，吴骏的"社会律"研究线持续15年）、杜云涛/程浩/陈明材（2018-2025主力）、张宝明/宋鉴清/李双杰（新生代）。IIP的产出形态偏应用：ICTAI是其国际主阵地（36篇），40余项产品化成果与江苏省文旅消费大数据重点实验室等平台体现其政企落地路线，这一点与软件所的顶会路线形成互补。
