## 一、学者基本信息

王崇骏（Chongjun Wang），南京大学计算机学院教授、博士生导师，任职于南京大学计算机学院及计算机软件新技术国家重点实验室，是南京大学智能信息处理研究组（IIP）的现任负责人。他长期兼任多项建制性职务：南京大学计算机应用研究所副所长、南京大学（中德）HPI研究院联合创始人兼副院长（并在HPI研究院中方联合导师团队中任Coordinator）、南京大学SAP创新联合实验室（筹）联合创始人、江苏省文旅消费大数据重点实验室学术主任、国家人工智能基金投资委员会委员，另任江苏省电子学会软件专委会秘书长、中国人工智能学会粗糙集专业委员会委员，并为全国干部教育培训南京大学基地兼职讲师。其研究兴趣是智能体及多智能体系统（自主智能与群体智能）、复杂网络理论及应用、大数据分析及智能系统，近年延伸至大模型驱动的智能体（LLM Agent）方向。

**教育与工作经历：**
- 1998年起从事机器学习、模式识别研究；2002年10月至2003年1月赴加拿大进行合作科研。
- 2004年6月获南京大学计算机科学博士学位（博士论文《智能化刺绣CAD中若干图像处理问题的研究》），随后留校任教至今。
- 现为南京大学计算机学院教授、博导，IIP研究组负责人，中德HPI研究院副院长。

**学术兼职与荣誉：**
- 国家自然科学基金匿名评审人，福建、北京等省市自然科学基金评议专家，《计算机学报》《软件学报》《自动化学报》《计算机研究与发展》等一级学报审稿人；
- 曾任第二届中国Agent理论与应用学术会议（Agent2008）联系人之一；
- 截至2025年底，主持和参与国家重点研发计划、973、发改委4G专项、工信部产业化基金、国家自然科学基金、国家社会科学基金等国家及省部级基金与企事业资助项目80余项；近五年发表论文100余篇、授权专利40余项、出版专著3部；有40余项科研成果获得产品化和商品化推广（人工智能+、大数据+、金融科技与区块链+等领域）。
- 公开资料未见其个人获省部级科技奖励的记录；其成果主要以工程产品化与行业应用形式体现。

**研究主线与代表性贡献：**
1. **智能Agent与多智能体系统：** 自博士阶段起持续深耕，从早期的多智能体入侵检测、Agent理论，到近年的社会律（social law）综合、机制设计（路径拍卖、移动群智感知、蜂窝流量卸载），再到2026年"Agent三十年：从模型建构到能力涌现"的范式总结报告，是IIP自主智能与群体智能方向的主导者。
2. **复杂网络理论及应用：** 与谢俊元共同推进的网络分析、链接预测等研究构成IIP第二支柱。
3. **大数据分析及智能系统：** 面向教育医疗、政务、金融科技、文旅消费等行业的智能化解决方案，是其实验室"理论—原型—行业落地"路线的载体，对应江苏省文旅消费大数据重点实验室等平台。
4. **学习理论与图学习（经学生推进）：** 2019年以来，学生团队在噪声标签学习、长尾学习、图神经网络（AAAI 2025两篇）、持续学习、测试时自适应等方向形成稳定的CCF-A/B级产出；2022年起与南大图形学团队（郭延文、郭洁等）合作点云补全与三维生成（CVPR 2025、IEEE TVCG多篇）。

### 3.1 南京大学博士阶段（2004届）

王崇骏2004年6月获南京大学博士学位，博士论文为《智能化刺绣CAD中若干图像处理问题的研究》（万方学位论文库收录）。该课题直接延续计算机应用研究所陈世福、谢俊元团队1990年代获国家教委科技进步二等奖的智能刺绣系统成果线（IEPS智能刺绣编程系统1991年二等奖、天木电脑刺绣打版系统1993年二等奖）——即其博士训练是在南大计算机应用（CAI）传统的获奖成果脉络中完成的。**其博士学位导师未见公开披露**；从早期DBLP合作者结构（陈世福，2004-2008年合作9次，为其留校初期最主要的共同作者）与博士课题归属看，其师承应属计算机应用研究所陈世福体系，此为基于证据的推断而非直接记载。
