## 二、教师的角色定位

**团队创始人与学术核心：** 尹一通教授是南大TCS理论组的创始人和灵魂人物。他2003年从南京大学计算机系本科毕业，2009年获Yale大学计算机科学博士学位，同年回到母校任教。在过去十余年间，他从零开始构建了一个6人的理论计算机科学研究团队，研究方向覆盖随机算法、采样与计数（MCMC理论）、数据结构下界和并行分布式计算。他是"新基石研究员"获得者（腾讯资助1500万/5年），担任CCF理论计算机科学专委会副主任。他长期维护TCS Wiki（tcs.nju.edu.cn/wiki），为国内理论计算机科学社区提供了重要的教学资源平台，并组织了"计算理论之美"暑期学校（2021/2023/2024/2025）和Theory Day（2017/2018/2019/2025）等系列活动。团队中5位教师由他招募。

**近似算法领域的国际顶尖学者：** 栗师教授是清华首届姚班毕业生，2014年从Princeton博士毕业（导师Moses Charikar，现斯坦福Knuth讲席教授），2023年从纽约州立大学布法罗分校（终身副教授）辞职回国加入南大。他的核心贡献包括设施选址问题1.488近似算法（保持十年最优纪录）和关联聚类1.73-近似算法（FOCS 2023），获FOCS 2012最佳论文奖和NSF CAREER Award。他是国家级高层次引进人才。

**量子计算与信息论方向：** 姚鹏晖教授2014年从NUS博士毕业（双导师Rahul Jain和Miklos Santha），曾在荷兰CWI、滑铁卢IQC、马里兰QuICS做博士后（Hartree Fellow）。他的研究覆盖经典和量子通信复杂性、信息论和量子计算，与Anurag Anshu、Oded Regev、Aram Harrow等顶尖学者有合作。他指导的毕业生叶泽坤现已在福州大学任副教授。

**算法+学习理论交叉方向：** 黄棱潇副教授2022年12月加入南大，此前在华为理论计算机实验室工作两年（2020-2022）。他清华IIIS博士毕业（导师李建），曾在EPFL和Yale做博后。他的研究方向横跨大数据算法、计算社会选择和学习理论，是团队中唯一有企业研究实验室经历的成员。

**采样计数与差分隐私方向：** 刘景铖副教授是UC Berkeley博士（2019，导师为哥德尔奖得主Alistair Sinclair），曾在Caltech做讲席博士后。他的研究方向与尹一通有高度重叠（计数采样和计算相变），二人联合指导了多名学生并合著了FOCS 2023、STOC 2025等论文。他还与Google的Kunal Talwar和Pasin Manurangsi等差分隐私专家有合作。

**图算法领域的新星：** 张天翼副教授是团队最年轻的成员，2025年刚加入南大。他2021年从清华博士毕业（导师段然），随后在特拉维夫大学（导师Shiri Chechik和Shay Solomon）和ETH（导师Rasmus Kyng）做博士后。他作为合作者获得STOC 2025最佳论文奖（Vizing定理近线性时间算法），其博士导师段然在同一届STOC也获得最佳论文奖，师生同届获奖极为罕见。仅在2024-2025两年就发表约15篇顶会论文。

## 三、团队关系网络的整体观察

**1. 南大TCS理论组是一个由尹一通主导构建的"海归+本土"混合型团队，国际化程度极高。** 6位教师中4位有海外博士学位（Yale、Princeton、NUS、UC Berkeley），2位有国内博士学位（清华）但博士后均在海外完成（特拉维夫/ETH和EPFL/Yale）。尹一通本人从Yale回国后，利用自己在Simons Institute、EPFL Bernoulli Center等国际机构建立的合作网络（如Heng Guo at Edinburgh、Zongchen Chen at Georgia Tech），为团队带来了持续的国际学术资源。

**2. 团队研究方向高度互补，没有明显的方向重叠问题。** 尹一通和刘景铖虽然都在采样计数领域，但前者侧重MCMC理论和数据结构，后者侧重计算相变和差分隐私，形成了"算法理论+隐私理论"的互补。栗师专注组合优化和近似算法，姚鹏瀚覆盖量子方向，黄棱潇做学习理论与计算社会选择，张天翼专攻图算法。6人的研究方向恰好覆盖了TCS的主要分支。

**3. 清华姚班/交叉信息院是团队的重要人才来源。** 栗师是清华首届姚班毕业生，黄棱潇是清华交叉信息院（IIIS）李建教授的博士生，张天翼虽然博士毕业于清华计算机系但导师段然在IIIS。3人中有2人直接出自IIIS体系，体现了姚期智创建的理论计算机科学人才培养体系对国内高校的辐射效应。这与上财ITCS（陆品燕本人也是姚期智学生）有相似的"姚期智网络"特征，但路径不同——南大的清华系教师均是通过"清华培养→海外博后→回流南大"的路径加入。

**4. 华为理论实验室是团队的重要产业连接。** 黄棱潇在加入南大前曾在华为理论计算机实验室工作两年（2020-2022），这为团队提供了与华为的间接产业连接。此外尹一通指导的毕业生陈海敏已加入华为。华为理论实验室（现华为TCS Lab）是国内极少数由企业资助的纯理论计算机科学实验室，与上财ITCS的陆品燕形成了不同路径的产学研模式。

**5. 张天翼的STOC 2025最佳论文奖是团队国际影响力的标志性事件。** 他作为合作者获得的Vizing定理近线性时间算法论文是图论领域的突破性成果，且其博士导师段然同届获奖，体现了清华图论学派（姚期智→段然→张天翼）的传承链。张天翼的加入使南大TCS在图算法方向获得了显著增强。
