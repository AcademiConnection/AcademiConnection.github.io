## 二、教师的角色定位

**研究所所长与参数复杂性专家：** 陈翌佳教授是研究所所长，拥有上海交大和德国弗莱堡大学双博士学位（弗莱堡导师为Jörg Flum，参数复杂性理论的奠基人之一）。他的研究方向为参数复杂性理论和有限模型理论，是国内该方向的代表性学者。

**BASICS实验室创始人与并发理论元老：** 傅育熙教授是BASICS实验室的创始人，研究方向为进程代数（chi-calculus）和交互理论。他在上交大任教数十年，培养了93名毕业研究生，是董笑菊、龙环等多位教师的博士导师，是研究所内学术辈分最高的成员。

**BASICS传承与并发理论延续：** 董笑菊（副所长，傅育熙博士生）和龙环（副教授，傅育熙博士生，2009年博士毕业）延续了BASICS实验室的并发理论方向。董笑菊近年研究重心转向数据可视化，龙环继续在并发理论和Petri网方向深耕。

**算法博弈论方向：** 陶表帅副教授2020年从密歇根大学安娜堡分校博士毕业（本科南洋理工大学数学），2021年加入上交大。他在EC 2022发表独立作者论文，研究方向涵盖算法博弈论、社会选择和公平分配。

**量子计算方向：** 王启圣副教授2022年从清华博士毕业，先后在名古屋大学和爱丁堡大学工作，2026年加入上交大。他入选2025年国家级青年人才计划，代表作为sample-to-query lifting和samplizer框架，发表于SICOMP和TIT。

**计数采样方向：** 杨宽副教授2020年从Oxford博士毕业（导师Leslie Ann Goldberg和Andreas Galantis，Clarendon Scholar），本科上交致远学院（导师陆品燕Pinyan Lu）。他在随机k-SAT计数方向有突破性成果（STOC 2025）。张驰豪副教授2016年从上交博士毕业（导师傅育熙/陆品燕），港中文博后，研究方向为采样算法和MCMC理论，与南大TCS组（尹一通等）有密切合作。

**算法方向：** 刘思学副教授来自Princeton/CMU，研究方向为亚线性算法和数据结构。张宇昊副教授来自港大（导师黄志毅），研究方向为在线算法和在线匹配。二人分别代表了不同子方向的算法研究力量。

**形式化方法方向：** 汪宇霆副教授来自明尼苏达大学（导师Gopalan Nadathur），与耶鲁大学邵中教授长期合作，在POPL连续发表4篇论文（2019/2022/2024/2025），以第一完成单位极为罕见。他主持CCF-华为胡杨林基金形式化专项项目（Rust编译验证）。

**数据库与产业转化方向：** 尹强副教授的经历独特——上交硕博（BASICS实验室出身）后转向数据库系统，曾在阿里巴巴达摩院任技术专家三年。他获华为火花奖（2025）、VLDB最佳论文亚军（2025）和EuroSys最佳Artifact奖（2022），是研究所中业界合作最深入的教师。

## 三、团队关系网络的整体观察

**1. 研究所研究方向极为多元，从纯理论到系统到产业转化均有覆盖。** 12位教师的研究方向涵盖参数复杂性（陈翌佳）、并发理论（傅育熙/董笑菊/龙环）、算法博弈论（陶表帅）、量子计算（王启圣）、计数采样（杨宽/张驰豪）、算法（刘思学/张宇昊）、形式化方法（汪宇霆）和数据库系统（尹强）。这种多样性在国内理论计算机科学研究所中相当突出，但也意味着团队内部的研究交叉相对有限——绝大多数教师之间的研究方向并不直接重叠。

**2. BASICS实验室是研究所的历史根基，傅育熙→董笑菊/龙环的师承链是团队最清晰的内部传承。** 傅育熙教授创建的BASICS实验室是研究所的前身和核心力量，他培养的董笑菊和龙环现在仍是研究所成员，形成了"傅育熙→董笑菊/龙环"的内部师承链。但近年来BASICS方向（并发理论）在团队中的比重有所下降，新加入的教师多为其他方向。

**3. "陆品燕网络"在本团队中有显著影响。** 杨宽和张驰豪两位教师都与上财ITCS的陆品燕有直接关联——杨宽本科时受陆品燕指导（致远学院），张驰豪博士期间陆品燕也是指导者之一。这一"陆品燕→上交TCS"的人才管道使得上交TCS与上财ITCS形成了跨校的学术纽带。

**4. 清华大学是团队的重要人才来源。** 王启圣（清华博士2022）和杨宽（上交致远/受陆品燕指导）都与清华体系有关联。这反映了姚期智创建的理论计算机科学人才培养体系对国内多所高校的辐射效应，与南大TCS组（栗师/黄棱潇/张天翼均出自清华）的情况类似。

**5. 尹强的"学术界→产业界→学术界"路径是团队产业转化的独特案例。** 他在阿里巴巴达摩院工作三年后回到上交任教，获华为火花奖和VLDB最佳论文亚军，主持CCF-蚂蚁联合基金。这种"理论出身→产业历练→回归学术"的路径使他成为团队中业界合作最深入的成员，也为团队带来了数据库系统和大数据管理这一偏应用的维度。汪宇霆的CCF-华为胡杨林基金项目则代表了团队在形式化方法方向与华为的产业合作。
