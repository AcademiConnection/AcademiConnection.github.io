## 七、Connection圈层总结

尹强的学术关系网络呈现出"理论根基+工业实践+学术回归"的独特跨界特征：

**BASICS传承圈层**：尹强作为上海交通大学BASICS实验室培养的博士，其学术根基在并发理论和进程代数领域。博士阶段与龙环、徐贤的合作论文（ICE 2015）是其学术传承的见证。这段经历使其在理论计算机科学方面有扎实的基础训练。

**学术转型**：从博士阶段的并发理论研究，到博士后阶段的数据库系统研究，再到达摩院的工业级数据库研发，尹强完成了一次成功的学术转型——从纯理论计算机科学转向数据科学交叉领域。在理论计算机科学研究所的研究版图中，他负责"交叉领域——（数据科学）数据查询处理和优化"方向，是研究所与数据科学社区的关键桥梁。

**学术影响力**：在SIGMOD、VLDB、ICDE等数据库顶级会议和TODS、VLDBJ等顶级期刊上发表论文20余篇，加上VLDB 2025最佳论文亚军和EuroSys 2022最佳Artifact奖，尹强在数据库系统社区已建立了坚实的学术声誉。

**独特定位**：在理论计算机科学研究所中，尹强的定位独树一帜——他既理解理论计算机科学的严谨方法论，又具备大规模数据库系统的工程实践经验。这种"理论+工程"的双重能力使其在产学研合作中具有独特的竞争优势。

**发展阶段**：尹强处于学术生涯的快速上升期，2026年2月从助理教授晋升为长聘教轨副教授，多项奖项和项目的加持表明其发展势头强劲。
