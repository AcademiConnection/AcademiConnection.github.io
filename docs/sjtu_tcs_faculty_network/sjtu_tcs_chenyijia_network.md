**弗莱堡时期的导师与合作网络。** 根据其弗莱堡时期及此后发表的论文署名与致谢信息，陈翌佳在弗莱堡的博士导师为 **Jörg Flum** 教授。Flum 是参数复杂性理论的奠基人之一，与 Rodney Downey、Michael Fellows 同为该领域的开创者。Flum 与 Grohe 合著的 *Parameterized Complexity Theory*（Springer, 2006）是该领域的标准教材。陈翌佳与 Flum 的合作从弗莱堡时期延续至今，二人合著了多篇关于有界非确定性（bounded nondeterminism）、参数化模型检测（parameterized model-checking）和同态计数（homomorphism counts）的重要论文。

同时，陈翌佳与 **Martin Grohe**（当时在柏林洪堡大学，现任职于RWTH Aachen）建立了长期合作关系。Grohe 是有限模型论和算法图论领域的世界级权威。陈翌佳在2004年从弗莱堡毕业后曾在洪堡大学短期工作（2004.10-2005.9），这段时间与 Grohe 的地理接近性进一步巩固了二人的合作。

**上海交大第一博士期间的信息。** 陈翌佳1995-2000年在上海交大攻读计算机软件与理论博士学位。从时间线和同院系关系推断，他与同在BASICS实验室的资深教授傅育熙（Yuxi Fu）在组织上属于同一学术体系，但公开资料未明确标注其第一博士导师的具体身份。

陈翌佳担任两本国际理论计算机科学期刊的编委，这在理论计算机科学领域具有相当的学术声誉。LMCS 是该领域的重要开放获取期刊，TOCS 则是 Springer 旗下的老牌理论期刊。

## 七、Connection圈层总结

陈翌佳的学术关系网络呈现出以**欧洲理论计算机科学传统（特别是德国弗莱堡—洪堡学术谱系）为核心，以上海交通大学—复旦大学为国内基座，以参数复杂性理论为学术纽带的圈层结构**。

**第一圈层（核心合作者）：**
- **Jörg Flum（弗莱堡大学）**：博士导师、20余年长期合作者，参数复杂性理论的共同奠基者。这是陈翌佳学术网络中最核心、最持久的关系。
- **Martin Grohe（RWTH Aachen，原洪堡大学）**：重要合作者，有限模型论与算法图论的权威，从洪堡时期延续至今的合作关系。

**第二圈层（研究所内部与国内合作者）：**
- **张驰豪（上交TCS研究所）**：早期合作者（参数计数复杂性综述），现为同研究所同事。
- **杨宽（上交TCS研究所）**：同属计数算法方向，研究所同事。
- **傅育熙（上交TCS研究所）**：BASICS实验室资深教授，长期同事。
- **林冰凯（Bingkai Lin）**：k-边诱导子图问题的合作者，连接中日参数复杂性研究网络。
- **复旦大学理论计算机科学社群**：2014-2021年任教期间建立的校内网络。

**第三圈层（学术影响圈层）：**
- **致远学院ACM班/Hopcroft班学生群体**：通过线性代数、算法、数理逻辑等核心课程的持续教学，影响多届理论计算机科学方向学生。
- **国内TCS社群**：通过CCF学术活动、CCF自然科学奖等渠道与国内理论计算机科学社群保持连接。
- **中山大学逻辑与认知研究所**等逻辑学社群：通过学术报告等形式保持与国内逻辑学界的联系。

**学术特色总结：** 陈翌佳的研究具有鲜明的"逻辑驱动"特征——从参数复杂性类的逻辑刻画出发，经由有限模型论和描述复杂性理论，最终延伸至一阶逻辑与同态计数的算法应用及其与图神经网络的交叉。他的学术网络以纯理论为核心，以长期国际合作（特别是与Flum和Grohe的合作）为支柱，同时通过教学和研究所管理在国内理论计算机科学人才培养中发挥重要作用。作为上交TCS研究所所长，他在团队建设和学科发展方向上具有战略影响力。
