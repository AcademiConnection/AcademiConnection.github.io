# 上海交通大学 X-LANCE 跨媒体语言智能实验室 教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

X-LANCE（Cross-Media Language Intelligence Laboratory，跨媒体语言智能实验室，官网 [x-lance.sjtu.edu.cn](https://x-lance.sjtu.edu.cn/)）是上海交通大学计算机学院面向人工智能时代信息入口的核心研究团队，由俞凯教授于2012年创立（原名 SpeechLab，后扩展为 X-LANCE）。实验室现有7位教师（1位特聘教授、4位副教授、1位助理教授、1位科研助理）、130余位在读学生（41名博士、34名硕士、52名本科生）和166余位校友，累计发表论文483余篇，是国内高校中规模最大、覆盖最全的语音与语言智能研究团队之一。

实验室五大研究方向涵盖对话式语言计算与智能体（LLM基础技术、Agent协作、对话系统）、语音与音频基础模型（语音识别/合成/分离/自监督学习）、多模态理解与跨媒体生成（文本-语音-音频-视觉的表示对齐与可控生成）、AI for Science 与可信领域AI（材料/生命科学基础模型与可信评估）、教育智能与情感计算（自适应学习、学习分析、情感计算与教育AI标准）。实验室拥有数百张GPU（H800/A800/A10），具备工业级数据分析与研发能力。

实验室与思必驰（AISpeech）公司深度绑定，共建"SJTU-AISpeech Joint Lab for Intelligent Human-Computer Interaction"，是语言计算国家人工智能开放创新平台的技术依托单位。实验室负责人俞凯教授2025年当选ISCA Fellow（国际语音通讯协会Fellow，内地首位），亦为IEEE Fellow（2026年度）。核心教师中，陈露主导开发的DFM/ChemDFM系列对话大模型已部署于智能座舱与科研场景，其转化专利获第23届中国专利奖优秀奖；陈谐带来剑桥学术血统与微软工业经验，专注音频基础模型；吴梦玥在医疗AI与音频情感计算方向独树一帜；吴晓宝注入NLP/LLM国际化视角（ACL 2025 Senior Area Chair Highlights Award）。

## 圈层结构概述

X-LANCE 的学术谱系以俞凯的剑桥大学工程系博士导师 Steve Young（POMDP对话系统理论创始人）为源头，形成"一源多流"结构。陈谐同样毕业于剑桥工程系（导师Mark Gales），延续剑桥语音处理血脉；陈露的博士导师未见官方明示但长期在俞凯团队成长，主导DFM/ChemDFM大模型方向；吴梦玥带来墨尔本大学的多媒体音频研究视角，开辟医疗AI交叉方向；吴小宝来自NTU（导师Anh Tuan Luu），为实验室注入NLP/LLM的国际化学术联系。实验室通过"SJTU-AISpeech联合实验室"实现产学研闭环，技术成果经思必驰部署于奔驰、奥迪、比亚迪、美的、海尔等企业产品，DFM系列大模型从实验室到智能座舱的转化路径是典型范例。国际学术网络则经俞凯的ISCA Fellow、IEEE SLTC委员身份以及剑桥校友圈延伸至全球语音与AI学术社区。
