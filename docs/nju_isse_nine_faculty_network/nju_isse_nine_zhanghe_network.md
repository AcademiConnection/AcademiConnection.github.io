## 一、学者基本信息

张贺（He Zhang），南京大学软件工程教授、博士生导师，软件研发效能实验室主任，入选南京大学登峰人才计划（A-层次），兼任澳大利亚联邦科学与工业研究组织（CSIRO）资深首席科学家（Senior Principal Scientist）。他在南京大学智能软件与工程学院专兼职教师名单中列于教授序列（该学院与软件学院共享师资，依托计算机软件新技术全国重点实验室平台）。他是国际软件工程研究联盟（ISERN）成员（南京大学代表）、中国计算机学会会员（高级会员）、软件工程专委会与服务计算专委会委员。其研究以**经验软件工程与循证软件工程**为方法论根基，覆盖软件研发效能、DevOps与容器技术、软件体系结构、软件质量保证、区块链与智能合约等方向。

**教育与工作经历：**
- 澳大利亚新南威尔士大学（UNSW）博士毕业，以最优成绩获博士学位（Ph.D），师从Ross Jeffery教授与Barbara Kitchenham教授（经验软件工程奠基人）。
- 先后在爱尔兰国家软件工程研究中心（Lero）任研究员，在澳大利亚国家信息与通讯科学院（NICTA）任资深研究员/高级研究员，并在爱尔兰利默里克大学（UL）信息技术系和UNSW计算机科学与工程系任教。
- 在欧洲和澳洲从事软件工程研究与实践十余年后回国加入南京大学。

**学术服务与荣誉：** 发表ICSE、TSE等软件工程重要期刊会议论文240余篇（DBLP收录230条，详见第二章），其中12篇会议/期刊长文获国际最佳/最具影响论文奖；著有英文专著两部、中文教材两部；主持国家自然科学基金、国家重点研发计划及江苏省重点研发计划等国家级项目多个。

**重要澄清（关于"UNLV回流"线索）：** 委托背景称张贺"2023年前后自内华达大学拉斯维加斯分校（UNLV）回流"。经对南大智能软件与工程学院专兼职教师名单、软件学院教师主页及DBLP记录的核验，本目录所指的张贺为UNSW博士、原Lero/NICTA研究员、南京大学软件学院教授（鼓楼校区费彝民楼办公），其公开履历中**无任何UNLV任职记录**。UNLV确有一位研究经验软件工程的"He Zhang"（Zhe Yu合作网络等），但与南大张贺为不同人物，二者研究方向相近导致极易混淆。本报告按南大官方履历撰写，UNLV线索判定为记忆误置，详见第七章。

## 三、博士教育背景与导师追溯

### 3.1 UNSW博士阶段

张贺于澳大利亚新南威尔士大学（UNSW）计算机科学与工程系攻读博士学位，以最优成绩毕业。其博士导师为两位经验软件工程奠基人：

- **Ross Jeffery：** 澳大利亚院士级学者、UNSW教授、NICTA研究项目负责人，国际软件过程与经验软件工程研究的开创者之一，ISERN核心人物。DBLP记录显示张贺自2006年起与Jeffery持续合作（19次，至2014年），早期论文集中于软件过程仿真、过程改进证据评估等方向。
- **Barbara Kitchenham：** 英国Keele大学教授，循证软件工程（Evidence-Based Software Engineering）与系统文献综述方法（如Kitchenham标准SLR流程）的奠基人，全球软件工程实证方法学最有影响的学者之一。与张贺合作14次（2006-2014），奠定其循证方法论底色。

双导师组合（过程工程+实证方法）直接塑造了张贺的研究风格：以严格的经验研究方法研究软件过程与研发效能问题。

## 六、Connection圈层总结

**第一圈层——导师双核（海外阶段）：** Ross Jeffery与Barbara Kitchenham（合计33次合作，2006-2014）构成其学术谱系源头，分别赋予软件过程工程与循证实证方法两条研究基因；博士毕业后二者的退出标志着其学术独立。
