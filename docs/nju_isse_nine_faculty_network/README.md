## 全团队关系网络的整体观察

本组四人代表南大苏州校区"通信网络+软件工程"双翼的师资结构。杨鲲是翼展最宽的节点：从UCL博士、埃塞克斯讲席教授到2024年执掌NINE，其688条DBLP记录、784位合作者构成的"英国NCL—电子科大数能网络—南大NINE"三段式网络，使NINE自成立起即嵌入国际6G与边缘智能社区；向路平（南安普顿Hanzo学派博士、Accelercomm联合创始人）2023年起与杨鲲合作61次，是"杨鲲网络南大化"的关键执行者。赵阳明则带来另一条独立通道——电子科大—布法罗—中科大的量子网络谱系，与杨鲲的合作（6次，2025年起）刚刚开启，代表NINE向"后经典网络"的扩张。

张贺是四人中唯一的软件工程学者，也是与南大既有体系融合最深的一位：UNSW博士（Ross Jeffery与Barbara Kitchenham双导师）、Lero/NICTA研究员经历使其成为国际经验软件工程社区在南大的锚点（ISERN南大代表），与荣国平（62次）、邵栋（49次）自2010年起的持续共署表明其与南大软件学院的联系远早于本次苏州校区建制；需要澄清的是，原缺失清单中"UNLV回流"的说法系同名误置——南大张贺无UNLV履历，UNLV的He Zhang为另一学者。
