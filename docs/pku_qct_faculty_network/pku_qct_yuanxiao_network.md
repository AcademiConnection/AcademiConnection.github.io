袁骁是北京大学量子计算理论方向的领军青年学者之一。他的研究聚焦于"如何让量子计算走向实用化"这一核心问题，系统性地连接了量子算法的理论设计、应用探索与实验实现，覆盖量子化学、量子材料和量子AI等交叉领域。他提出的变分量子算法通过动态构建浅层量子线路实现高效量子模拟；其"虚拟量子资源蒸馏"理论框架为在噪声设备上有效利用量子资源提供了新思路；将量子嵌入方法与量子计算结合模拟强关联材料电子结构，并拓展至分子对接问题，为药物发现提供了量子解决方案。

## 二、教育背景与职业履历

袁骁的学术履历横跨中国与欧美的顶尖量子研究机构，其导师谱系堪称量子信息领域的"全明星阵容"：

- **2017.1—2017.7**：中国科学技术大学助理研究员，师从**潘建伟院士**和**陈宇翱教授**，从事量子基础理论和实验验证研究。
- **2017.8—2020.9**：英国牛津大学博士后，师从**Simon Benjamin教授**，研究量子计算、量子模拟与量子机器学习。
- **2019.10—2020.10**：美国斯坦福大学博士后，师从**Patrick Hayden教授**（量子信息论权威），研究量子信息论与量子引力。

### 4.2 跨机构合作（重点：中国科学技术大学）

袁骁与中科大潘建伟团队的合作是其学术网络中最具分量的一条主线，也是"北大理论+中科大实验"强强联合的典范：

- **潘建伟院士**：袁骁2017年在中科大担任助理研究员期间即在潘建伟、陈宇翱指导下工作，奠定了长期合作基础。2023年7月，潘建伟、朱晓波、彭承志团队与袁骁合作，在"祖冲之二号"超导量子计算原型机上实现了**51个超导量子比特簇态**的制备与验证，将所有量子系统中真纠缠比特数目的世界纪录由24个大幅提升至51个，成果发表于《Nature》。该工作首次演示了基于测量的变分量子算法，袁骁团队贡献了变分量子本征求解器等核心算法方案。
- **陆朝阳教授**：合作发表PRL论文"Schrödinger-Heisenberg Variational Quantum Algorithms"（ZX Shang, MC Chen, X Yuan, CY Lu, JW Pan, PRL 131, 060406），将薛定谔绘景与海森堡绘景统一到变分量子算法框架中。
- **张明明（中科大）**：Nature 51比特纠缠态论文的重要合作者，是理论与实验团队之间的关键纽带人物。
- **陈宇翱教授**：袁骁在中科大期间的联合导师，量子基础理论与实验验证方向的早期引路人。
- **最新进展（2026）**：中科大潘建伟、朱晓波、彭承志、龚明团队再次与北大袁骁团队合作，基于105比特"**祖冲之3.1**"超导量子处理器，在《Nature Physics》发表大规模簇态制备与验证工作——实现了最高95比特一维簇态和72比特二维簇态的制备与验证，并完成对称性保护拓扑相探测和基于测量的量子计算实验。袁骁课题组在其官网对该论文进行了专题解读。

除中科大外，袁骁与清华交叉信息研究院（博士母校）、香港地区高校（其主持基金委香港合作研究项目）等也保持学术联系。

## 五、业界合作关系深度分析

### 5.1 超导量子计算平台合作（理论—硬件协同）

袁骁与中科大超导量子计算团队围绕"祖冲之"系列处理器的合作，是国内"算法理论团队+硬件原型机团队"深度耦合的标杆案例：

- **51比特真纠缠态（Nature 2023）**：基于"祖冲之二号"平台，双方将并行多比特量子门保真度提升至99.05%、读取精度提升至95.09%，结合大规模量子态保真度验证判定方案，实现51比特一维簇态制备（保真度0.637±0.030，超过纠缠判定阈值13个标准差），并首次演示基于测量的变分量子算法。
- **105比特簇态与拓扑相模拟（Nature Physics 2026）**：基于升级后的"祖冲之3.1"处理器（读出保真度中位数99.35%、受控Z门保真度99.50%），通过"动态关耦"等硬件优化技术实现95比特一维簇态、72比特二维簇态，并在同一平台上完成对称性保护拓扑相探测和基于测量的量子计算演示。
- 在超导平台上，袁骁团队还通过硬件优化和错误缓解技术将大规模量子化学模拟的计算精度提升了约**两个数量级**。

这类合作直接服务于中国超导量子计算从"量子优越性演示"迈向"实用化量子算法"的产业级目标，对国内量子计算产业链（量子处理器研制、量子软件与算法服务）具有直接的技术溢出价值。

### 5.2 量子模拟的产业应用

袁骁的研究在化学与材料科学中具有明确的产业应用前景：

- **量子计算化学**：其RMP综述系统梳理了变分量子本征求解器等算法在分子体系上的应用路线图；PRL变分量子模拟、微扰量子模拟等工作为NISQ（含噪声中等规模量子）时代的化学模拟提供了实用算法工具箱。
- **材料科学**：将量子嵌入方法与量子计算结合，从头模拟强关联材料电子结构（npj Computational Materials），有望应用于新能源材料、催化剂设计等产业场景。
- **药物发现**：将量子计算方法拓展至分子对接问题，为制药行业提供了量子解决方案。
- **专利布局**：14项专利显示其团队注重理论成果的工程化转化，涉及量子算法与量子设备应用等方向。
