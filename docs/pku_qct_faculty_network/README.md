# 北京大学量子计算理论团队 学术关系网络报告

## 团队简介

本报告集涵盖北京大学量子计算理论团队的学术关系网络。团队核心成员位于北京大学前沿计算研究中心（CFCS），由袁骁研究员（量子模拟和量子信息实验室）和李彤阳研究员（QUARK Lab量子算法实验室）组成。两位学者分别从物理和信息论科学两个视角切入量子计算理论研究，形成了量子模拟/量子信息（袁骁）与量子算法/量子复杂性理论（李彤阳）的互补布局。

## 团队架构

袁骁和李彤阳于2020-2021年间先后加入CFCS，分别创立量子模拟和量子信息实验室、QUARK Lab。两人的学术谱系互补：袁骁的学术脉络跨越北大物理→清华交叉信息院（马雄峰）→中科大（潘建伟）→牛津（Benjamin）→斯坦福（Hayden），扎根量子物理实验与理论的交叉地带；李彤阳从清华姚班→马里兰大学→MIT理论物理中心，立足量子计算与理论计算机科学的融合。

团队与中科大潘建伟/陆朝阳组保持密切合作，袁骁与中科大团队合作在超导量子计算平台上实现了51比特纠缠态（Nature 2023）和105比特簇态（Nature Physics 2026）等里程碑成果。
