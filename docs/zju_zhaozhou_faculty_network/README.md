# 浙江大学 赵洲副教授生成式人工智能课题组 教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

赵洲副教授课题组（隶属浙江大学计算机科学与技术学院）是国内生成式人工智能与多模态学习方向最具产出特色的青年团队之一。赵洲（香港科技大学博士，2013-2015年微软亚洲研究院联合培养）为浙江大学计算机学院副教授、博导，国家优秀青年科学基金获得者（2022），Google Scholar引用约1万次。课题组以浙江大学竺可桢学院本科生为核心研究力量，在语音合成、歌声合成、视觉合成、音频合成、3D人脸合成和多模态学习等方向产出了一批具有国际影响力的工作。

课题组的标志性成果包括 FastSpeech 系列语音合成模型（NeurIPS 2019 / ICLR 2021，非自回归并行合成，被微软、英伟达、阿里巴巴、腾讯等公司广泛应用）、DiffSinger（歌声合成）、GeneFace（3D说话人合成）、Real3D-Portrait（ICLR 2024 Spotlight，单图3D虚拟人）、Make-An-Audio、PNDM（视觉合成）等。多位学生荣获"华为天才少年""阿里星""百度奖学金""字节奖学金"等顶级荣誉，2022年赵洲获浙江大学竺可桢学院十佳专业导师。课题组的"跨模态内容高效生成理论与方法"获CSIG自然科学奖一等奖（完成人：赵洲、张圣宇、万瑶、杨敏、何晓飞）。

## 圈层结构概述

赵洲的学术网络以"竺可桢学院本科生→顶会论文→产业巨头"为鲜明特色。核心圈层是课题组学生群体：任意（FastSpeech系列第一作者，华为天才少年/阿里星/百度/字节奖学金，现任HeyGen新加坡基础视频模型团队负责人）、刘静林（DiffSinger/GeneFace，华为天才少年/阿里星）、黄融杰（GenerSpeech/Make-An-Audio，字节奖学金）、叶振辉（GeneFace/Real3D-Portrait/MimicTalk）、刘鲁平（PNDM）、夏炎（多模态泛化）、程诗卓（手语生成/多模态表征）等。这一群体以竺可桢学院本科生为主力，在NeurIPS、ICLR、ICML、CVPR、ACL等顶会密集发表，形成了"语音合成→视觉合成→多模态理解"的递进式研究路线。

校内合作圈层以吴飞教授（人工智能研究所所长、本科生院院长，2024年端云协同综述共著）和何晓飞教授（CSIG一等奖共著）为核心。产业圈层以微软亚洲研究院（FastSpeech系列联合开发，合作者谭旭、秦涛、刘铁岩等）和字节跳动（Real3D-Portrait/MimicTalk联合研发，任意等学生流入）为双支柱，延伸至华为（天才少年计划接收方）、阿里巴巴（长序列记忆论文合作）和英伟达/腾讯（FastSpeech技术应用）。赵洲本人2013-2015年在微软亚洲研究院的联合培养经历是微软合作通道的起源。整体而言，这是国内生成式AI领域"以学生培养质量驱动产业影响力"的标杆型课题组。
