# 复旦大学 系统软件与安全实验室（S3L，"复旦白泽"团队）教师学术关系网络报告

## 团队简介

复旦大学系统软件与安全实验室（S3L）是复旦大学计算与智能创新学院（原计算机科学技术学院）下属的网络安全研究团队，以杨珉教授为学术带头人，以"为国家铸坚盾，为行业育英才"为初心，长期致力于安全攻防、人工智能安全、无人驾驶系统安全和数据安全等网络安全领域的技术和治理研究。实验室现有教授3名（杨珉、张源、张谧）、副教授1名（杨哲慜）、高级讲师与讲师若干（朱东来、陈荣华）、青年副研究员（杨广亮、张晓寒）、助理研究员（张磊、洪赓）与副研究员（戴嘉润、潘旭东）等构成的完整梯队，师生总数约170人。实验室在IEEE S&P、ACM CCS、USENIX Security、NDSS网络安全四大顶级会议上发表论文60余篇，被公开报道称为国内唯一实现四大顶会杰出论文奖"大满贯"的团队；2024年获评复旦大学"钟扬式"科研团队。

实验室的育人特色是"教、赛、研、产"深度融合：以学生为主体的复旦白泽战队（Whitzard，2018年4月孵化，杨珉与张源共同指导）已斩获全国大学生信息安全竞赛五连冠（2020-2024）、DEFCON AutoDrive CTF第一名（2021、2022）、Trend Micro CTF全球总冠军（2020）等50余项国际国内比赛冠军，战队成员连续两年获评微软全球最具影响力安全研究员。2026年，团队研制的白泽智能体Whitzard在国际AI安全基准CyberGym评测中以91.2%的成功率位列全球第二、高校第一。实验室的AI安全方向由张谧教授领衔的白泽AI团队承担，其联合起草国家标准《生成式人工智能服务安全基本要求》，研发的"复旦JADE"大模型安全评测与治理平台是国内首个中文大模型安全评测平台。

实验室的产业合作覆盖华为、百度、阿里（阿里投入1500万元共建"复旦-阿里应用程序安全联合研究中心"）、腾讯、同盾科技、奇安信等企业，各类项目总经费超过9000万元（部分统计超1亿元）；与上海市大数据中心"一网通办"的联合攻关成果获第十五届上海市决策咨询研究成果奖一等奖（2026年1月）；团队发现的身份认证机制重大安全问题获习近平总书记多次重要批示及十余次党和国家领导人批示，多项关键技术突破国际封锁。

## 圈层结构

本组报告覆盖的学者构成一个以杨珉教授为圆心的同心圆结构。核心圈层为"杨珉—张源—张谧"教授铁三角：杨珉掌舵学科资源与国家战略对接（973/重点研发双首席、国务院学位委员会学科评议组成员），张源主导系统安全攻防技术与白泽战队建设，张谧负责AI安全与大模型治理及国家标准化工作。第二圈层为骨干教师与青年教师：杨哲慜（小程序/移动安全，四大顶会21篇）、杨广亮（系统安全，海外引进）、朱东来、张晓寒、张磊（USENIX Security 2022杰出论文第一作者）等。第三圈层为实验室自主培养留校的青年一代：洪赓（网络犯罪治理与AI安全治理）、戴嘉润（漏洞攻防）、潘旭东（AI安全），三人构成"前沿AI风险研究"青年铁三角。最外圈为学生传承圈层：刘丰毓（CCS 2025杰出论文第一作者、白泽CTF战队队长）、邬梦莹（NDSS 2026最佳论文第一作者）、张智搏（USENIX Security 2022共同一作）等新生代，以及通过白泽战队连接的本硕博贯通人才培养网络。

对外合作圈层包括：国内高校（香港中文大学、约翰斯·霍普金斯大学、清华段海新/张超团队、北大谢涛团队、普渡钱志云、印第安纳廖晓靖、港理工罗夏朴等）的学术合作网络；以"复旦-阿里联合研究中心"为枢纽、覆盖华为/百度/腾讯/奇安信/同盾的产业合作网络；以上海市大数据中心、执法机关与中央网信办为通道的国家治理网络；以及依托上海创智学院、TC260标准工作组和联合国AI治理研讨会的标准化与政策网络。

## 产业转化亮点

- 复旦-阿里应用程序安全联合研究中心：阿里投入1500万元共建，推动应用程序安全研究成果产业化；2025年S&P杰出论文即由实验室与阿里安全部联合完成。
- 白泽智能体Whitzard：2026年在CyberGym国际AI安全基准中以91.2%成功率位列全球第二、高校第一，全程仅调用单个国产基础模型、全量测试成本不足5000元，为国产大模型与智能体安全能力建设提供直接支撑。
- 复旦JADE大模型安全评测与治理平台：国内首个中文大模型安全评测平台，迭代至8.0版本，安全能力被腾讯、蚂蚁等企业平台收录。
- 漏洞治理技术输出：团队及白泽战队累计发现数百个零日漏洞并获大量CVE/CNVD编号（如MOCGuard确认161个零日漏洞、获73个CVE编号；HouseFuzz获45个CVE/CNVD编号），检测与防护技术在华为、百度、支付宝等企业落地，服务全球数十亿用户。
- 政务安全转化：与上海市大数据中心联合攻关"一网通办"政务数字化安全，获第十五届上海市决策咨询研究成果奖一等奖（2026年1月）。
