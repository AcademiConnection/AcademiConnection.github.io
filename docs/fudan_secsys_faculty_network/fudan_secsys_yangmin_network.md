杨珉教授是复旦大学培养并在本校成长起来的网络安全领域领军学者，1979年1月生，中共党员。他自2006年前后博士毕业（公开报道存在2006/2007两种口径，待学位档案核定）后留校任教，从最初的操作系统和编译工具链研究起步，2010年起前瞻性地转向安卓移动安全方向，逐步将研究版图拓展至人工智能安全、无人驾驶安全、区块链安全与隐私保护等前沿领域。作为国家973计划项目首席科学家和国家重点研发计划首席科学家，他带领团队在网络安全国际四大顶级会议（S&P、CCS、USENIX Security、NDSS）上发表论文60余篇，被公开报道称为国内唯一实现四大顶会杰出论文奖"大满贯"的团队带头人。其研究成果获习近平总书记多次重要批示及十余次党和国家领导人批示，多项关键技术突破国际封锁，成果在华为、百度、阿里等龙头企业形成应用，服务全球数十亿用户。2023年9月起任计算机科学技术学院院长兼党委副书记，学院后更名为计算与智能创新学院，现任执行院长。

## 二、教育背景与职业履历

杨珉的教育经历完整在复旦大学完成。他本科和硕士均就读于复旦大学计算机相关专业，博士阶段同样在复旦大学攻读，研究方向为计算机网络。关于其本科、硕士的具体入学年份和博士导师信息，公开报道中未见权威详细披露，待证实。2006至2007年间博士毕业后（澎湃新闻报道称2006年毕业，复旦大学官方报道称为2007年毕业，此处表述差异可能源于毕业与留校入职的时间节点不同），杨珉曾收到多家企业的录用通知，因不舍校园的自由宽松氛围而选择留校任教。

留校初期，杨珉从事操作系统和编译工具链方向的基础软件研究。2011年，他在计算机系统领域最顶尖的国际学术会议USENIX ATC上发表了来自中国大陆的第一篇论文，标志着其早期学术实力。2010年前后，他敏锐预见到移动互联网的飞速发展将催生前所未有的安全挑战，做出重大研究转型，开始系统性开展安卓移动安全研究。2013年，他在ACM CCS（第20届ACM计算机与通信安全会议）上同时发表两篇安卓安全论文，引起国内外学术同行与产业的极大反响，这也被视为中国网络安全研究在移动安全领域跻身国际前沿的标志性事件。同年，以美国为首的西方国家通过《瓦森纳协定》将网络安全技术增补为对华禁运门类，更加坚定了杨珉团队走自主创新之路的决心。

职业履历的关键节点如下：

- 2006/2007年：复旦大学博士毕业，留校任教。
- 2010年：研究重心转向安卓/移动安全。
- 2011年：在USENIX ATC发表中国大陆第一篇论文。
- 2013年：在ACM CCS同时发表两篇安卓安全论文。
- 2015年前后：担任国家973计划项目"移动应用恶意行为检测控制的基础理论与关键技术"首席科学家。
- 2018年5月：出任同盾科技移动安全研究院首席科学家。另有复旦大学招生宣讲材料称其曾担任百度首席移动安全科学家（未见其他权威公开来源，待进一步证实）。
- 2019年3月：当选上海市青年联合会第十二届副主席。
- 2019年9月：获国家网络安全优秀教师奖。
- 2021年：公开报道其入选教育部长江学者特聘教授。
- 2023年9月：任复旦大学计算机科学技术学院院长兼党委副书记。同年指导研发复旦大学CFFF智算平台，支撑伏羲天气预报大模型等重大科研成果。
- 2024年9月：所带领的系统软件与安全实验室获评复旦大学2024年"钟扬式"科研团队。
- 2026年1月：作为作者代表的研究成果获第十五届上海市决策咨询研究成果奖一等奖。
- 2026年8月：团队研制的白泽智能体Whitzard在国际AI安全基准CyberGym评测中以91.2%成功率位列全球第二、高校第一。
- 现任：复旦大学计算与智能创新学院执行院长兼党委副书记、教授、博士生导师。

## 三、学生培养情况

杨珉教授长期坚持"为国家铸坚盾，为行业育英才"的育人初心，探索构建了"德育先行，教赛研产融合并举"的网络安全育人体系。实验室现有师生约170人，规模庞大、梯队完善。以下列举若干代表性学生：

### 1. 张磊（复旦大学助理研究员，杨珉指导的博士生）

张磊是杨珉教授指导的博士毕业生，现为复旦大学系统软件与安全实验室助理研究员（网络空间国际治理研究基地助理研究员），主要从事移动生态安全治理技术研究。他曾获得ACM SIGSAC中国优博奖和ACM中国优博提名奖。2022年，张磊作为第一作者（与博士生张智搏共同一作，合作方包括约翰斯·霍普金斯大学）在USENIX Security 2022上发表论文"Identity Confusion in WebView-based Mobile App-in-app Ecosystems"，荣获杰出论文奖。该论文揭示了微信、支付宝、抖音、今日头条等主流移动应用在小程序生态系统中的身份混淆安全问题，是USENIX Security创办30余年来中国大陆高校首次获此殊荣。张磊的研究方向涵盖移动应用安全、漏洞检测等，目前担任实验室漏洞治理方向的重要指导教师。

### 2. 刘丰毓（复旦大学21级硕博连读生，杨珉与张源共同指导）

刘丰毓是复旦大学2021级硕博连读生，同时担任复旦白泽CTF战队队长。他的导师为张源教授和杨珉教授，是杨珉的重要学生之一。2025年，刘丰毓作为第一作者在ACM CCS 2025上发表论文"BACScan: Automatic Black-Box Detection of Broken-Access-Control Vulnerabilities in Web Applications"（与香港中文大学合作完成），荣获杰出论文奖。该研究针对长期位居OWASP Top 10首位的越权漏洞，提出了首个反馈驱动的黑盒检测框架，显著提升了检测精度。刘丰毓在白泽战队中担任CTF战队队长角色，在多项国内外安全攻防竞赛中表现突出，是杨珉"教赛研产融合"育人模式的典型代表。

### 3. 邬梦莹（复旦大学博士生，杨珉团队学生）

邬梦莹是复旦大学2021级本科保研硕博连读生，属于杨珉系统软件与安全实验室培养的优秀博士生。她的主要研究方向为网络犯罪及互联网测量，特别是网络黑灰产对网络资源的滥用问题。她以第一作者（含学生一作）身份在网络安全顶会ACM CCS及NDSS、软件工程顶会IEEE/ACM ICSE上发表了三篇论文，研究成果在政府部门和工业界均落地实战。在攻读博士学位期间，她积极发挥实验室"传帮带"作用，协助导师建设科研梯队，带领本科生参与科研，协助导师指导的本科生曾获"挑战杯"全国特等奖、全国大学生信息安全竞赛一等奖等奖项。

### 4. 张智搏（复旦大学博士生，杨珉团队学生）

张智搏是杨珉团队培养的博士生，曾与张磊共同作为第一作者在USENIX Security 2022上发表关于移动应用小程序身份混淆安全问题的杰出论文。该研究由复旦大学与约翰斯·霍普金斯大学合作完成，揭示了微信、支付宝等主流应用的严重安全威胁。其具体毕业去向待证实，但作为USENIX Security杰出论文的共同第一作者，其学术影响力已获国际认可。

### 5. 杨哲慜（复旦大学副教授，杨珉团队成员）

杨哲慜是复旦大学计算与智能创新学院副教授、博士生导师，隶属于系统软件与安全实验室，是杨珉团队中的核心青年教师力量。他主要从事操作系统、系统安全、程序分析与运行时环境技术研究，在ACM CCS发表过焦点论文，相关成果被美国纳斯达克官网报道。从其论文署名与研究轨迹看，其博士阶段长期在杨珉指导下开展研究（2011年起即与杨珉合作），学界普遍视其为杨珉门下培养的博士，但正式导师归属未见权威公开署名（待核）。他主讲《计算机系统基础》课程，2023年获复旦大学青年教师教学竞赛工科组二等奖，参与"教赛研产"融合的网络安全新工科育人模式项目（获复旦大学研究生教学成果特等奖）。多次指导学生在全国大学生信息安全竞赛中获奖，研究成果两次被央视"3·15晚会"引用。作为实验室核心成员，他与杨珉长期密切合作。

### 6. 杨广亮（复旦大学青年副研究员，杨珉团队引进人才）

杨广亮是复旦大学计算机学院青年副研究员（助理教授），2021年加入杨珉团队。他2019年博士毕业于德州农工大学，后于佐治亚理工学院做博士后。研究领域为计算机系统安全，包括代码安全分析、操作系统安全、Web安全、移动安全等，已在S&P、CCS、USENIX Security、NDSS四大顶会发表15篇论文，获得USENIX Security 2022和ACM SIGSOFT 2024杰出论文奖。他长期担任S&P、CCS、USENIX Security等顶会程序委员，获上海市海外青年领军、华为新工科等人才基金支持。杨广亮虽非杨珉指导的毕业生，但作为杨珉团队引进的优秀青年学者，是团队实现四大顶会杰出论文奖"大满贯"的核心贡献者之一。

### 7. 洪赓（复旦大学助理研究员，杨珉团队成员）

洪赓是复旦大学网络空间国际治理研究基地（复旦发展研究院）助理研究员、兼聘计算与智能创新学院，系统软件与安全实验室青年导师，属于杨珉团队的重要青年研究人员。据其个人主页，他2017年至2022年在复旦大学攻读博士学位，导师为杨珉教授，现为实验室网络犯罪治理与AI安全治理方向的骨干力量。

### 8. 戴嘉润（复旦大学副研究员，杨珉团队青年教师）

戴嘉润是复旦大学系统软件与安全实验室副研究员、硕导，杨珉团队在AI安全与漏洞攻防方向的青年教师。据其个人主页，他本科与博士均就读于复旦大学，2023年6月获网络空间安全博士学位，博士期间由杨珉教授与张源教授联合指导（据其个人主页披露），并作为早期成员参与白泽战队建设。他是白泽智能体Whitzard研发的核心技术骨干之一。

### 9. 潘旭东（复旦大学副研究员，杨珉团队青年教师）

潘旭东是复旦大学系统软件与安全实验室副研究员、硕导，杨珉团队在AI安全方向的青年教师。据张谧教授白泽AI团队公开材料，其为该团队培养的博士毕业生（受张谧与杨珉共同指导）。在2026年CyberGym国际AI安全基准测试中，他与戴嘉润作为团队青年教师代表接受采访，表示91.2%的成功率只是新的起点，团队将继续深化理论突破，以具备安全边界的硬核科技护航国家数字经济社会安全。这表明二人是白泽智能体Whitzard研发的核心技术骨干。

## 四、学术合作网络

### 4.1 学术谱系与师承关系

杨珉的学术谱系根植于复旦大学计算机学科。他在复旦大学攻读学士、硕士和博士学位，博士期间研究方向为计算机网络，博士导师信息未见权威公开披露，待证实。留校后，他将研究重心从计算机网络转向操作系统与编译工具链，再转向移动安全乃至更广泛的网络空间安全领域，形成了独特的学术发展轨迹。

在师承传承方面，杨珉堪称复旦大学网络安全学科的开创者和领军人。他培养的学生和引进的青年教师构成了一个层次分明的学术谱系：

- **第一代（杨珉本人）**：复旦大学本硕博完整培养，国家973首席科学家、长江学者特聘教授。
- **第二代（杨珉指导的博士/引进的青年教师）**：包括张磊（助理研究员，USENIX Security杰出论文第一作者，ACM SIGSAC中国优博奖）、杨哲慜（副教授，CCS焦点论文）、杨广亮（青年副研究员，四大顶会15篇论文，USENIX Security杰出论文奖）、洪赓（助理研究员）、戴嘉润/潘旭东（副研究员，白泽智能体核心骨干）等。其中杨广亮为海外引进人才，博士毕业于德州农工大学，并非杨珉直接指导的博士生，但加入了杨珉的团队。
- **第三代（在读博士生）**：包括刘丰毓（CCS 2025杰出论文第一作者）、邬梦莹（CCS、NDSS、ICSE三篇第一作者）、张智搏（USENIX Security 2022共同一作）等。这些学生同时在白泽战队中担任核心角色，体现了"教赛研产融合"的育人特色。

值得一提的是，实验室中的张源教授为复旦大学计算机学院2014届博士（2009至2014年在职攻读，博士期间即与杨珉深度合作），其正式学位导师归属未见权威公开署名，与杨珉形成了紧密的学术伙伴关系，共同指导了包括刘丰毓在内的众多学生，是白泽战队的联合指导教师。

### 4.2 核心学术合作网络

杨珉的学术合作网络覆盖国内外多个一流研究团队和产业伙伴，主要体现在以下几个层面：

**实验室内部合作核心**：杨珉与实验室教授张谧、张源形成了稳定的"铁三角"学术合作关系。张谧教授专注于AI智能体安全治理研究，张源教授（获2020 ACM SIGSAC China Rising Star称号）是白泽战队的直接指导教师，专攻系统安全与程序分析方向。此外，杨广亮（系统安全与漏洞挖掘方向）、杨哲慜（程序分析与区块链安全方向）等青年教师的加入进一步拓宽了团队的研究版图。

**国内高校合作**：杨珉团队与香港中文大学建立了深度的学术合作关系。2025年CCS杰出论文即由复旦大学系统软件与安全实验室与香港中文大学合作完成。此外，团队与约翰斯·霍普金斯大学在移动安全领域有实质性合作（USENIX Security 2022杰出论文为合作成果）。

**国际学术合作**：复旦大学博士后招聘信息中提到"根据研究进展赴美国合作教授接受联合培养"，表明杨珉团队与美国高校存在联合培养机制。具体合作院校和个人待进一步确认。

**学术服务平台**：杨珉发起创办了"网络安全研究国际学术论坛"，构建了网安领域的育人与学术交流大生态。他还担任教育部重点实验室评估组专家、国家自然科学基金重点及面上项目会评专家、网络空间安全重点专项会评专家等学术服务职务。

## 五、业界合作关系深度分析

### 5.1 主要业界合作与项目

杨珉团队与产业界的合作深度和广度在国内高校网络安全领域名列前茅，主持的各类项目总经费超过1亿元。主要合作包括：

- **华为**：杨珉主持华为企业项目，多项关键技术成果在华为产品中形成应用，服务全球用户安全需求。杨广亮等青年教师亦获华为新工科人才基金支持。团队研究成果还入选了华为等技术生态的实践应用。
- **百度**：杨珉与百度有深度的产学研合作（另有复旦招生宣讲材料称其曾任百度首席移动安全科学家，待核实）。团队发现的身份认证机制重大安全问题研究成果应用于百度等企业。此外，团队中有博士生荣获全球遴选的20万元百度奖学金。
- **阿里巴巴**：阿里巴巴投入1500万元与复旦大学共建"复旦-阿里应用程序安全联合研究中心"，推进科研成果产业化应用。2025年S&P杰出论文即由复旦大学系统软件与安全实验室与阿里巴巴集团安全部联合完成，该研究提出了面向微服务系统的跨服务静态漏洞检测方案mscan，同时入选BlackHat USA 2025工业界会议，充分彰显学术研究与产业实践的双重价值。
- **同盾科技**：2018年5月，杨珉出任同盾科技移动安全研究院首席科学家。同盾科技是国内专业的第三方智能风险管理服务商，杨珉结合同盾在实际商业场景中的应用，带领团队在移动安全领域取得基础理论和核心技术的突破，加速产学研联动。
- **上海市大数据中心**：杨珉团队与上海市大数据中心联合攻关，聚焦政务数字化安全领域的公共服务平台安全体系构建与能力提升，相关成果获第十五届上海市决策咨询研究成果奖一等奖（2026年1月），为上海市"一网通办"的稳健建设与高效运行筑牢安全屏障。
- **国家层面合作**：杨珉带领团队发现身份认证机制重大安全问题后，放弃公开发表，第一时间上报国家。研究成果获习近平总书记多次重要批示及十余次党和国家领导人批示，多项关键技术突破国际封锁。

### 5.2 产业转化与人才流动

杨珉团队的产业转化与人才流动呈现出"双向循环"的独特模式：

**学术成果产业转化**：团队的诸多研究成果直接转化为产业应用。例如，移动应用安全检测技术应用于百度、阿里等企业的产品安全防护，服务全球数十亿用户；微信、支付宝等小程序生态安全研究成果帮助企业修复重大安全漏洞；漏洞挖掘与检测技术被华为等企业采纳。团队成果入选973重大成果和突出进展、十三五国家科技创新成就，获中央网信办颁发的2021年度最具价值漏洞奖。

**人才流动与产学研融合**：杨珉本人在学术与产业之间跨界游走，兼具学者与产业智囊的双重身份。他曾担任同盾科技移动安全研究院首席科学家（另有材料称其曾任百度首席移动安全科学家，待核实），同时保持复旦大学教职。这种模式也影响了团队的人才流向：部分博士生毕业后进入华为、百度、阿里等头部企业安全部门，将学术研究成果带入产业实践；部分青年教师（如杨广亮）从海外顶尖高校加入团队，带来国际前沿的系统安全研究视角；同时，企业安全团队的工程师也以联合研究的形式参与实验室项目。以学生为主体的白泽战队在Trend Micro CTF国际赛（2020年全球总冠军）、DEFCON AutoDrive CTF（2021、2022年第一名）等国际国内顶尖比赛中斩获50余项冠军，这些实战能力高度契合产业需求，形成了"竞赛-科研-产业"的良性循环。

**CFFF智算平台**：2023年，杨珉指导研发复旦大学CFFF智算平台，支撑伏羲天气预报大模型等重大科研成果。这一平台不仅服务于科研计算，也为产学研合作提供了重要的基础设施支撑。此外，杨珉还主导推动了复旦大学AI大课建设（2024年启动，全校108门AI-BEST课程），将AI安全理念融入全校人才培养体系。

## 七、Connection圈层总结

杨珉教授的学术关系网络呈现出多层次、宽领域、深融合的鲜明特征，可以从以下几个圈层加以概括：

**核心学术圈层**：以复旦大学系统软件与安全实验室（S3L）为内核，形成了一个由3名教授、8名副教授、3名讲师及若干助理研究员/副研究员组成的大型研究团队（师生总数约170人）。杨珉作为学术带头人和实验室缔造者，与张谧教授（AI安全治理方向）、张源教授（系统安全与攻防方向）构成了学术领导核心。青年教师群体包括杨哲慜、杨广亮、朱东来、陈荣华、张晓寒、张磊、洪赓、戴嘉润、潘旭东等，覆盖了从操作系统安全到人工智能安全的完整研究版图。这个核心圈层被公开报道称为国内唯一实现网络安全四大顶级会议杰出论文奖"大满贯"的团队，2026年更有8篇论文被USENIX Security 2026接收，展现出强大的团队产出能力。

**学生传承圈层**：杨珉培养了多代优秀博士生，形成了清晰的学术传承链。从张磊（USENIX Security 2022杰出论文第一作者）到刘丰毓（CCS 2025杰出论文第一作者），从邬梦莹（CCS/NDSS/ICSE三篇第一作者）到张智搏，每一代学生都在国际顶级会议上取得了标志性成果。以这些学生为主体组建的复旦白泽战队（2018年4月成立，张源与杨珉共同指导），已斩获50余项国际国内顶尖比赛冠军，包括Trend Micro CTF全球总冠军（2020）、DEFCON AutoDrive CTF第一名（2021、2022）、全国大学生信息安全竞赛五连冠等，并在2026年以白泽智能体Whitzard在CyberGym国际AI安全基准评测中位列全球第二、高校第一。白泽战队的成长史，本质上是杨珉"教赛研产融合"育人理念的制度化成果。

**产业合作圈层**：杨珉与华为、百度、阿里巴巴、同盾科技、上海市大数据中心等企业和政府机构建立了深度的产学研合作关系，合作项目总经费超过1亿元。他本人曾担任同盾科技移动安全研究院首席科学家（另有材料称其曾任百度首席移动安全科学家，待核实），阿里巴巴投入1500万元共建联合研究中心，上海市"一网通办"安全体系研究成果获上海市决策咨询成果一等奖。这些合作不仅是经费支撑，更是研究成果落地转化的关键通道，团队的诸多技术成果直接服务于全球数十亿用户的安全需求。

**国家战略圈层**：杨珉的研究工作深度对接国家网络安全战略需求。他带领团队发现的身份认证机制重大安全问题获习近平总书记多次重要批示及十余次党和国家领导人批示；担任国家973计划和国家重点研发计划双重首席科学家；作为第八届国务院学位委员会网络空间安全学科评议组成员参与国家学科建设决策；兼任复旦大学中国网络空间战略研究所副所长和上海市网络空间安全战略研究所执行所长，直接服务于国家和上海市的网络安全治理。他在《瓦森纳协定》网络安全技术对华禁运背景下坚持自主创新，多项关键技术突破国际封锁，成果入选十三五国家科技创新成就。

**学术影响圈层**：杨珉团队在S&P、CCS、USENIX Security、NDSS四大顶会发表论文60余篇（部分统计口径达70余篇），国内名列前茅。他本人获2018 ACM SIGSAC Best Supervisor Award，团队成员获USENIX Security 2022杰出论文奖（大陆高校首次）、ACM CCS 2025杰出论文奖、IEEE S&P 2025杰出论文奖等。团队还发起创办了"网络安全研究国际学术论坛"，构建了网安领域的学术交流生态。杨珉担任国家自然科学基金重点项目和面上项目会评专家、网络空间安全重点专项会评专家、教育部重点实验室评估组专家等多项学术服务职务，在国内外学术界拥有广泛的影响力。

综上，杨珉教授的Connection圈层以复旦大学S3L实验室为学术内核，以白泽战队为育人载体，以华为/百度/阿里/同盾等为产业合作伙伴，以国家973/重点研发计划和中央网信办/国务院学位委员会为战略对接通道，构建了一个覆盖"教学-科研-竞赛-产业-国家战略"全链条的学术生态体系。他以"为国家铸坚盾，为行业育英才"为初心，将个人学术追求与国家网络安全事业深度融合，成为中国网络空间安全领域最具影响力的学者之一。
