## 二、教师角色定位

陈岭是浙大普适计算实验室主任，教授、博导。其博士导师为陈纯院士与陈根才教授（个人主页明确记载），属于陈纯谱系在普适计算方向的传承者；博士后阶段师从诺丁汉大学 Steve Benford（普适计算国际权威）。研究方向为普适计算、时空数据管理、移动群智感知、室内定位与智慧城市。

DBLP 记录其论文约200篇，最高频合作者为陈根才（96篇），显示其学术网络以浙大本校谱系为轴心；同时作为 AZFT（阿里-浙大前沿技术研究中心）与 OPPO-浙大联合创新中心骨干，产学研通道发达。

---

## 三、实验室关系网络的整体观察

CCSL（普适计算实验室，2008年成立）是浙大普适计算方向的核心建制，与 CCNT（潘纲脑机团队，普适计算起家）、EAGLE（卜佳俊团队）在"泛在感知—时空数据—群智应用"方向上形成互补三角。陈岭同时执掌鸿程智慧城市大型软件研究院副院长职务，是实验室将学术成果导入智慧城市产业的桥梁。作为单一PI实验室，其结构以"陈纯谱系学术轴+企业联合中心产业轴"双轮驱动，学生谱系多循论文署名推断（已审慎标注待核实项）。
