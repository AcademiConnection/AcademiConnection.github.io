## 二、各位教师的角色定位

陈纯是实验室的学术带头人与旗帜性人物，中国工程院院士（2015），浙江缙云人，1955年生，本硕博均就读于浙江大学（师从何志均），曾任计算机学院院长（2009-2017）。他从纺织CAD起家，是国内区块链研究的最早推动者之一，2016年推动成立趣链科技并出任董事长/首席科学家，其学生李伟为趣链科技CEO（2026年1月起任董事长）、蔡亮曾任趣链科技副董事长（后任浙大软件学院副院长），形成"院士掌舵、学生操盘"的产学研标杆。

任奎是实验室实际运营的学术核心，求是讲席教授，集AAAS/ACM/CCF/IEEE四会士于一身，研究方向数据安全与AI安全（对抗样本、模型安全），美国纽约州立大学布法罗分校博士，回国前任教于伊利诺伊理工学院。2026年7月经浙江省政府任命出任杭州电子科技大学副校长（主持行政日常工作），其在浙大的行政职务交接情况以官方发布为准。秦湛是任奎最重要的合作者（合著论文90余篇），副院长、百人计划研究员，UB博士、曾任UTSA助理教授，牵头制定ISO/IEC 27565隐私计算国际标准。

杜文亮是2025年1月全职加盟的求是讲席教授，ACM Fellow / IEEE Fellow（2023），在雪城大学任教二十余年，SEED安全实验平台的缔造者——该平台已被全球80多个国家1180余所学校采用，是国内安全学界罕见的"平台型"引才。杜跃进是另一位业界引进的领军学者（2025年求是特聘教授），曾任CNCERT副总工程师、阿里巴巴技术副总裁兼首席安全专家、360集团副总裁兼首席安全官，代表"政-产-学"跨界的数字安全治理路线。

中坚层面，王志波（国家优青）聚焦AI安全与隐私计算，田纳西大学博士、曾任武汉大学教授；韩劲松（港科大博士、曾任西安交大教授）深耕数据安全，获NDSS 2026杰出论文奖；申文博（长聘副教授）专注系统安全与程序分析，5项国际会议杰出论文奖（NDSS/AsiaCCS/ACSAC/ESORICS/S&P）；周亚金是区块链安全公司BlockSec联合创始人兼CEO，2026年转任香港中文大学副教授，其S&P 2026 Test-of-Time Award印证了长期学术影响力。

青年与特色方向上，常瑞（副教授）从事智能计算系统及安全、形式化方法与LLM程序分析；张帆专注硬件安全与侧信道攻击、密码学（康涅狄格大学博士，师从时杰/Aggelos Kiayias）；赵永望深耕操作系统形式化验证（ARINC653国际标准委员会国内唯一委员），创办望安科技并支撑元心OS获EAL5+安全认证。

## 三、全实验室关系网络的整体观察

第一，"院士+双平台"的顶层设计。实验室以陈纯院士为学术委员会主任/主任、任奎为常务副主任，依托2022年批复的区块链与数据安全全国重点实验室与2018年组建的网络空间安全学院双建制运转，形成"学术权威+运营核心"的二元治理结构。任奎2026年调任杭电副校长、周亚金转任港中文，预示实验室进入代际调整期，秦湛、王志波等中坚的作用将进一步凸显。

第二，"政产学界旋转门"的人才结构。实验室在两年内连续引进杜文亮（学界平台型）、杜跃进（政产跨界型）两类领军学者，加上自带创业身份的周亚金、赵永望，形成国内安全院系中罕见的"学界泰斗+平台缔造者+监管老将+安全创业者"复合阵容。

第三，创业谱系发达。从陈纯-趣链科技（李伟、蔡亮），到周亚金-BlockSec、赵永望-望安科技，实验室的创业孵化覆盖区块链底层平台、区块链安全审计、安全认证评估三条赛道，是中国安全界"教授创业"密度最高的单位之一。

第四，国际标准与平台输出。秦湛牵头ISO/IEC 27565、赵永望参与ARINC653国际标准、杜文亮的SEED平台全球采用，显示实验室影响力已从论文输出升级为标准与教育基础设施输出。

第五，内部合作高度向心。任奎-秦湛（90余篇合著）构成最紧密的师生合作对；王志波、常瑞等与任奎团队在AI安全方向形成联合培养网络；申文博、周亚金、张帆、赵永望各自在系统安全、区块链安全、硬件安全、内核验证方向保持相对独立的PI结构，整体呈"一超多强"格局。
