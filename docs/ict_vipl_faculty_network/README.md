# 中科院计算所VIPL视觉信息处理与学习研究组 学术网络报告

本目录收录中国科学院计算技术研究所VIPL（Visual Information Processing and Learning，视觉信息处理与学习）研究组三位核心学者的学术关系网络报告：陈熙霖研究员、山世光研究员与王瑞平研究员。VIPL研究组由高文院士于1997年在中科院计算所创建，现隶属于智能信息处理重点实验室与智能算法安全全国重点实验室，是中国计算机视觉领域最具影响力的研究团队之一。陈熙霖现任中科院计算所所长、党委书记，为本组学术领衔；山世光现任智能信息处理重点实验室主任、智能算法安全全国重点实验室副主任；王瑞平领导视觉场景理解组。

三人的关系结构清晰且须准确界定：陈熙霖、山世光、王瑞平之间均为同实验室长期合作关系，而非师生关系。陈熙霖本硕博均毕业于哈尔滨工业大学（1994年博士），博士导师未公开披露；山世光1999—2004年在计算所攻读博士，导师信息亦未公开披露，从研究实习员一路成长为所务委员；王瑞平则是高文院士在中科院计算所指导的博士（2010年毕业，个人主页明确记载），后经清华大学戴琼海博士后与马里兰大学Larry S. Davis合作，2012年回所建组。2015年度国家自然科学二等奖"视觉模式的局部建模及非线性特征获取理论与方法研究"的完成人排序（陈熙霖、山世光、高文、王瑞平、柴秀娟）最权威地定格了以陈熙霖为核心、山世光/王瑞平为支柱、高文为院士级合作支点的"计算所视觉学派"核心圈层。

## 研究方向与圈层结构概述

VIPL的研究主线沿"视觉特征表示—以人为中心的感知—开放场景理解"演进：陈熙霖、山世光主导的生物启发特征表示与人脸识别理论体系支撑了2015年国家自然科学二等奖；山世光近年拓展至情感计算、唇语识别、视线估计与AI安全（与张杰共同负责AI Safety and Trustworthiness研究组）；王瑞平聚焦真实开放环境下的场景图生成、任意样本检测与具身智能，2022年以第一完成人获CSIG自然科学一等奖。

圈层结构上，第一圈层为VIPL核心合作"铁三角"（陈熙霖—山世光—王瑞平，三项国家级/学会级大奖均为共同完成人）；第二圈层为实验室研究员梯队（蒋树强、常虹、王树徽、韩琥、许倩倩、阚美娜、张杰等，均为同事关系而非学生）；第三圈层为高文院士与北大体系的联合培养纽带（高文曾担任VIPL博士生答辩导师）；第四圈层为可确认的学生培养链（王瑞平的博士导师为高文；山世光名下有何振梁、胡蓝青、牛雪松、冯大蕗、孙蕴嘉、孙旭冉等经答辩记录确认的博士；陈熙霖名下有乔师师、元玉慧、杨丰远、郝蔼明等）；第五圈层为产业转化与学术社区网络。三人合计数十次担任CVPR、ICCV、NeurIPS等领域主席，深度嵌入国内外CV学术共同体治理。

## 产业转化亮点

- **人脸识别规模化落地**：团队技术应用于华为Mate20、Nova3、荣耀Magic等旗舰手机及云/端照片归类服务，并落地公安部出入境管理局护照人脸查重系统、全国人口人脸比对系统及11个省级户口查重系统（团队级成果，与个人项目相区分）。
- **中科视拓创业**：山世光2016年创办中科视拓（北京/南京），开源SeetaFace系列人脸识别引擎（SeetaFace2/6商用级算法），经历多轮融资，2024—2025年被东方国信控股收购，为VIPL产学研转化的代表性载体。
- **平台级企业合作**：VIPL研究组与华为、好未来、腾讯、平安、中国移动、高通、松下等数十家企业开展委托研发，成果集中应用于公共安全、智能装备、医疗健康领域。
- **国际竞赛与学生培养**：团队获ICCV 2025、WWW 2025手语识别挑战赛多赛道冠军，近10年培养博士30余名，多人获中科院、CCF、CAAI优秀博士论文奖。
