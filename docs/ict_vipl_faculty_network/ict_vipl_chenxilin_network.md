## 七、Connection圈层总结

陈熙霖研究员的学术关系网络可归纳为以下圈层：

### 第一圈层：哈工大—CMU—计算所的学术主轴

本硕博均毕业于哈尔滨工业大学计算机系（1988/1991/1994），博士导师未公开披露；1994–2004年在哈工大从讲师至教授，2001–2004年赴CMU计算机学院访问，回国后扎根中科院计算所。这一"哈工大培养+CMU访问+计算所深耕"的路径构成其学术身份的底色。

### 第二圈层：VIPL研究组平台核心圈

以VIPL研究组为载体，形成"陈熙霖（学术领衔）—山世光、王瑞平（长期合作核心，非学生）—蒋树强、常虹、王树徽、韩琥、许倩倩等研究员—数十名硕博研究生"的梯队结构。2015年国家自然科学二等奖五人完成排序（陈熙霖、山世光、高文、王瑞平、柴秀娟）是这一圈层最权威的公开定格。

### 第三圈层：高文院士与中科院计算所体系

与高文院士（第三完成人）通过获奖项目、VIPL博士生联合指导深度联结；同时依托中科院智能信息处理重点实验室、智能算法安全全国重点实验室和JDL联合实验室体系，处于中科院视觉智能研究的中枢位置。

### 第四圈层：产业转化网络（VIPL平台级）

以VIPL研究组平台对接华为、好未来、腾讯、平安、中国移动、高通、松下等数十家企业，人脸检测与识别等技术实际落地于华为手机、平安科技、中国移动产品体系；注意该合作归属研究组平台而非个人。

### 第五圈层：国内外学术治理网络

通过PRCV/ChinaMM/CEAI/FG等会议主席职务、CVPR/ICCV/NeurIPS顶会Area Chair经历、国内外期刊编委职务，以及计算所所长、党委书记和曾任中科院国际合作局局长的行政身份，同时占据学术共同体治理与科研管理两个枢纽位置。

### 整体特征

1. **谱系审慎性**：博士导师公开信息缺失，本报告坚持只写可证事实，不以合作论文署名反推师生关系（山世光、王瑞平均为同事而非学生）。
2. **平台型影响力**：其影响力以VIPL研究组平台为放大器，学生培养（近10年30余名博士、多人获优博）、竞赛冠军（ICCV/WWW 2025手语识别挑战赛）与产业转化均以团队形态呈现。
3. **基础研究引领**：以第一完成人获国家自然科学二等奖，学术重心在视觉表示、建模与理解的基础方法层。
4. **学术—行政双轨**：从实验室主任、副所长到中科院国际合作局局长再到所长、党委书记，完成从单纯学者到国家科研机构掌舵者的转变。
