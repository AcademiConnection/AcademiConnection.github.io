## 二、各位教师的角色定位

何晓飞是 ZJULearning 的创始学术带头人与浙大机器学习学科的旗帜性人物，国家杰青（2011）、IAPR会士、首届万人计划青年拔尖人才，深耕机器学习理论、流形学习与矩阵分析。他的职业轨迹是浙大教授中罕见的"学界-业界-学界"完整往返：2015-2016/2017年出任滴滴出行高级副总裁兼研究院创始院长，2017年8月创办自动驾驶公司飞步科技并长期执掌，2026年初卸任公司职务后实质回归浙大，重新列入计算机学院2026年官方导师团队，与蔡登共同带领 ZJULearning。

蔡登是实验室在何晓飞"出走"十年间的实际守护者与共同负责人。他是国家优青、青年973首席科学家，AAAI 2012最佳论文奖得主，研究方向机器学习、数据挖掘、多标签学习与图学习，其代表性工作（如文档摘要的数据重构方法、LUT-NN查找表神经网络）兼具理论深度与工程影响力。需特别说明：蔡登与何晓飞是长期合作者而非师生（蔡登博士师从韩家炜），两人以"合作双核"结构维系实验室运转。

## 三、全实验室关系网络的整体观察

第一，"合作双核"而非"师生谱系"。与典型的"教授-学生"传承型实验室不同，ZJULearning 的核心结构是何晓飞-蔡登两位同龄合作者的对等组合（DBLP长期合著，AAAI 2012最佳论文即为二人合作的产物），学生培养上存在两人联合指导的交叉网络（如武伯熹）。

第二，"旋转门"教授的回归样本。何晓飞在滴滴（研究院创始院长）与飞步科技（创始人）的十年业界经历，使其成为国内"教授创业-回归"周期的代表性观察样本；2026年回归后实验室预计重新扩张。

第三，谱系网络外溢显著。实验室培养/联合培养的学生与关联学者散布于国内机器学习学界（与吴飞团队等浙大AI方向保持同事合作关系，联合举办"大模型与工业智能营"等活动），蔡登的课堂与开源工具（如Matlab工具箱、LUT-NN）在国内ML社区具有广泛影响。

第四，规模精干、方向经典。实验室以机器学习基础理论与经典问题（降维、聚类、多标签、图学习）为根，在深度学习时代保持"理论底色"，是浙大AI版图中区别于CAD&CG（视觉）与吴飞团队（跨媒体智能）的方法论基座。
