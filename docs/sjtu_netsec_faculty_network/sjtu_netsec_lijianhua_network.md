## 二、教育背景与职业履历

李建华的本科、硕士、博士三个学位均在[上海交通大学电子工程系](https://cs.sjtu.edu.cn/jiaoshiml/lijianhua.html)完成，属于典型的交大本土培养路径：

- 1982—1986年：电子工程专业本科；
- 1988—1991年：通信与信息系统工学硕士；
- 1995—1998年：通信与信息系统工学博士。

在本科与硕士之间，他曾在中船总公司精密测试技术研究所担任助理工程师（1986—1988年）。其博士阶段的导师信息在交大官方教师页及公开简历中均未披露。

职业履历方面（据[计算机学院教师页](https://cs.sjtu.edu.cn/jiaoshiml/lijianhua.html)）：

- 1991—2000年：上海交通大学电子工程系任教，历任讲师、副教授，并担任系党总支副书记；
- 2000—2013年：参与创建上海交通大学信息安全工程学院，任教授、[常务副院长（后曾任院长）](https://baike.baidu.com/item/李建华/9439731)——该学院是国内首批信息安全专业人才培养基地之一；
- 2013—2019年：任网络空间安全学院教授（二级）、院长，为学院建制调整后的首任院长（注：学院官网About页记载2016年12月由信息安全工程学院更为现名，教师页口径为2013年任职，本报告以教师页为准并注明差异）；
- 2019—2025年：任上海交通大学网络安全技术研究院长聘教授、院长；
- 2025年至今：计算机学院特聘教授。

其行政轨迹贯穿了交大网安学科从"信息安全工程学院"到"网络空间安全学院"再到"网络安全技术研究院/计算机学院"的整个建制演变史，是该学科的奠基性建制人物。

科研平台建设方面，他先后牵头建立（详见[网络空间安全学院教师页](https://infosec.sjtu.edu.cn/DirectoryDetail.aspx?id=133)）：

- 上海市信息安全综合管理技术研究重点实验室（2002年）；
- 信息安全管理监控与服务教育部工程研究中心（2006年）；
- 上海交通大学信息安全服务技术研究实验室（2007年，具备CNAS认可的信息安全检测测评资质）；
- 信息内容分析技术国家工程实验室（2009年国家发改委批准，后转设为国家工程研究中心）；
- 2015年经中央网信办批准建设网络空间安全人才培养国家级基地。

他还曾牵头制订"十五"国家863计划信息安全技术发展战略规划，任国家863计划信息安全技术专家组首席专家/管理专家、S219二期总体组组长、上海世博会安保顾问咨询专家、云南省网络安全检查专家组组长等职务。

## 三、学生培养情况

### 1. 人才培养总体格局

李建华自2000年信息安全工程学院创建起长期担任学院与研究院主要领导，是交大网安学科人才培养体系的主要设计者之一。官方介绍称其主持/参加了40余项国家863、自然科学基金、攻关计划等项目，主导研制网络安全综合管理系统、高速内容过滤系统、网络舆情监控系统等十余项科研成果，所依托的信息安全工程学院是国内首家信息安全专业人才培养基地（教育部、科技部、上海市政府共同发起），2019年入选首批国家一流网络安全学院建设示范项目。其直接指导的博士生完整名单在公开资料中未见系统披露，下述人员均需区分"同事/引进人才"与"学生"关系。

### 2. 潘理（长期共事的学科骨干，非可确认的师生关系）

潘理2002年在交大电子工程系获博士学位后即在李建华主导的信息安全工程学院体系内任教，两人2004年即合作发表论文《基于物理隔离技术的安全电子邮件系统的实现》（《计算机工程》，与陈俊超合作），此后长期在网络安全技术研究院共事（李建华任院长、潘理任直属党支部书记），并共同参与信息内容分析技术国家工程研究中心的工作。鉴于潘理博士论文导师信息未公开披露，不宜仅凭长期共事与论文合作推定师生关系。

## 五、业界合作关系深度分析

李建华的产业合作是其学术网络中最具特色的部分，呈现"平台型产学研"特征：

1. **云网融合与CDN安全产业联盟**：其领衔的"大规模云网融合系统内容高效可靠分发与主动防御技术研发及产业化"项目由上海交通大学联合[网宿科技、奇安信、科来网络、上海鹏越惊虹](https://news.sjtu.edu.cn/jdyw/20231116/190661.html)四家企业共同完成，获2023年世界互联网大会领先科技奖（李建华作为代表上台领奖并发布成果）。该项目攻克超大规模云网融合环境DDoS攻击防御与APT跨域协同防御难题，研制九大类云网内容分发与主动防御工具装备，形成电子政务、在线教育等近二十个行业一体化解决方案，是李建华产业合作网络的标志性成果。
2. **智能网联汽车安全**：研究院在上海市经信委支持下启动[国家级智能网联汽车信息安全研发与公共服务平台](https://news.sjtu.edu.cn/jdyw/20220810/173503.html)建设；与上海智能网联汽车技术中心有限公司共建智能网联安全技术研究所（陈秀真任副所长、周志洪任技术主任），并组织CyberTank战队参加世界智能驾驶挑战赛信息安全攻防赛、数字中国创新大赛车联网安全赛等赛事。
3. **安全检测测评服务**：其建立的上海交通大学信息安全服务技术研究实验室是全国第一批信息安全等级保护测评机构并通过CNAS认可，长期面向教育、医疗、金融、交通、政府等行业提供测评与咨询服务；张保稳等教师曾承担华为云安全评估体系研究等横向项目。
4. **金融与政务安全**：官方介绍称其为"政府上网工程安全、信息内容安全管理、金融信息安全保障体系进行了积极探索"，成果包括网络安全综合管理系统、网络舆情监控系统等十余项自主知识产权系统。
5. **863产业化基地 legacy**：2000年代初其作为国家863计划信息安全产业化基地（东部）专家委员会专家，深度参与了上海乃至全国信息安全产业园区的早期布局，为后续的产学研网络奠定了基础。

## 七、Connection圈层总结

李建华是上海交通大学网络空间安全学科的建制奠基人：从2000年创建信息安全工程学院（863信息安全人才培养基地），到2013年任网络空间安全学院首任院长，再到2019年组建网络安全技术研究院并执掌信息内容分析技术国家工程研究中心，其个人履历几乎等同于交大网安学科的发展史。其Connection网络呈现三个鲜明圈层：**其一，院内核心圈**——以网络安全技术研究院为载体，聚集了潘理、蒋兴浩、刘功申、王士林、陈秀真等一批内容安全/网络治理方向的骨干（多为共事同事而非其亲手指导的学生）；**其二，政产协同圈**——通过国家工程实验室/工程研究中心平台与网宿科技、奇安信、科来网络等企业及中央网信办、公安部等部委形成深度绑定，是典型的"国家任务牵引型"产学研网络；**其三，学术兼职圈**——通过中国网络空间安全协会副理事长、教育部教指委副主任委员等职务在全国网安学界拥有制度性影响力。需要说明的是，其可确认的"师承—学生"链条在公开资料中较为模糊，学术影响力更多通过建制与平台而非个人学术谱系传递——这与同院谷大武团队（密码学，IACR谱系清晰）形成鲜明对照，两个体系在学院内并行互补。
