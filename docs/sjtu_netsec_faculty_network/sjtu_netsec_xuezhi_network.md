## 二、教育背景与职业履历

薛质1992年于上海交通大学获得学士学位，1997年作为访问学者赴美国贝尔实验室进行合作科研，2001年于上海交通大学获得博士学位（以上据[学院教师页](https://infosec.sjtu.edu.cn/DirectoryDetail.aspx?id=35)）。本硕博均在上海交通大学完成，属本校培养体系出身；其本科专业、博士导师及所属院系在官方页面中均未披露，公开论文亦未提供可佐证的师承信息，本报告不作推断。

职业履历方面，薛质长期在信息安全工程学院（后为网络空间安全学院，现并入计算机学院）从事教学科研，曾任学院副院长（百度百科表述），并曾担任学院党总支书记——学院官网[历任领导页](https://infosec.sjtu.edu.cn/Leadership.aspx)记载历任党总支书记为"程龙根、王佩筠、薛质、李生红、孔令和"，确认其曾任该职。需要说明：2025年4月学校任命的计算机学院（网络空间安全学院、密码学院）新领导班子（常务副院长吴帆，副院长朱浩瑾、郁昱、伍军、谷大武兼职等）中已无薛质，其副院长、党总支书记均为历史任职。题设线索中"曾任网络信息中心主任"一说，未发现任何公开证据支持；上海交大网络信息中心主任一职由管海兵（曾任）、薛广涛（现任）先后担任，与薛质无关。

其行政—行业身份方面，薛质现任[上海市信息网络安全管理协会会长](https://baike.baidu.com/item/薛质/2141218)，2025年经上海市科协批准在[上海科旭网络科技股份有限公司建立专家工作站并任首席专家](https://sast.gov.cn/content.html?id=1966053293624934401&cid=359)。科研上，他主持及参加省部级以上科研项目30余项，包括国家863项目"安全主动网技术研究"、教育部"新世纪网络课程建设工程——计算机通信网"、"网络信息安全基础环境研究"等，获上海市科技进步一等奖2项、二等奖1项、三等奖1项，申请技术专利15项。

## 三、学生培养情况

### 1. 论文指导成绩（官方确认）

薛质指导的学生/团队研究成果被[USENIX Security 2021](https://news.sjtu.edu.cn/jdzh/20210225/142057.html)录用：论文《Sharing More and Checking Less: Leveraging Common Input Keywords to Detect Bugs in Embedded Systems》由网络空间安全学院陈力波（第一作者）、蔡洤朴、薛质（通信作者）等师生及国内外科研机构研究人员联合撰写，校新闻明确称"师生"团队，据此可确认其中包含其指导的学生，但具体哪位作者为其在读学生，公开资料未逐一披露。

### 2. 陈力波、王轶骏（实验室骨干，疑似其培养学生）

[网络与系统安全实验室](https://infosec.sjtu.edu.cn/Lab.aspx)现由薛质任负责人，成员包括李生红、施勇、王轶骏、刘铭、陈力波。其中陈力波（USENIX Security 2021第一作者，现为学院教师）与王轶骏（IEEE S&P 2023论文合作者，现为学院教师）在薛质担任通信作者/资深作者的系列论文中反复出现，从署名结构看疑似其培养的博士生并留校任教，但公开资料未明确披露博士导师归属，此处作审慎表述。

### 3. IEEE S&P 2023论文署名的青年作者

[GeeSolver论文](https://www.seiee.sjtu.edu.cn/index_news/8816.html)（验证码求解器，S&P 2023）作者为赵瑞杰、邓现文、王衍豪、严志聪、韩争光、陈力波、薛质、王轶骏。前五位青年作者按署名惯例应为实验室研究生，但学院新闻仅称"我院"成果，未逐一披露导师归属；本报告仅将其列为薛质—王轶骏—陈力波合作网络中的青年研究者，不推定具体师承。

### 4. 课程育人

薛质负责的《操作系统》课程被认定为2021年度上海高等学校一流本科课程；合著教材《操作系统教程》（陆松年主编，薛质、潘理、翁亮等编著，电子工业出版社2006年）。

## 四、学术合作网络

### 4.1 研究所内部

**网络与系统安全实验室**是薛质的核心学术阵地：其作为负责人，与李生红（教授，后任网安学院党总支书记）、施勇、王轶骏、刘铭、陈力波构成固定团队。论文层面的高频合作者包括陈力波（嵌入式系统漏洞挖掘、验证码安全方向，USENIX Security 2021、IEEE S&P 2023均署名）、王轶骏（S&P 2023署名）。学院层面，他与谷大武（院长）、邱卫东、李生红等属学院同事，公开活动中未见与其有深度科研交叉；其与信息安全与密码学研究所（谷大武团队）属同一学院不同实验室的平行关系。

### 4.2 跨机构合作

USENIX Security 2021论文为与"国内外知名科研机构研究人员"的联合工作（校新闻表述），表明其团队在嵌入式系统安全方向存在跨机构合作，但合作方具体机构公开资料未详列。产业界方面，2025年建立的上海科旭网络科技股份有限公司专家工作站，是可直接确认的产学研合作载体。此外，其1997年贝尔实验室访问经历构成其与国际工业研究界的早期联系。

### 4.3 国际合作

薛质的国际合作公开记录较少：除1997年贝尔实验室访问学者经历外，其团队论文主要发表于USENIX Security、IEEE S&P等国际顶会（与国外机构共同作者署名），但未查到其本人主导的持续国际联合项目或外籍长期合作者；此方面公开资料披露有限。

## 五、业界合作关系深度分析

薛质的产业合作以"安全服务与测评"为主线，偏重行业治理与实战工具：

1. **安全测评与渗透测试工具。** 其主持开发的网络渗透测试平台和专用工具"成果处于国内领先地位"（学院教师页），并开发"计算机信息系统安全保护等级评估工具"和"涉及国家秘密的计算机信息系统安全保密测评工具"（百度百科），服务于信息系统风险评估、安全检测与等级保护测评业务，客户以政府与涉密系统单位为主。
2. **行业协会治理。** 担任上海市信息网络安全管理协会会长，是上海地区网络安全行业组织的重要学术代表，连接本地监管、企业与学界。
3. **企业专家工作站。** 2025年经上海市科协批准，在上海科旭网络科技股份有限公司建站任首席专家，开展面向企业的技术攻关合作。
4. **国防与保密方向。** 其课题组2026年科研助理招聘公告显示，团队承担国防软件项目，涉及项目全生命周期管理与质量管理体系，表明其科研任务中含国防军工背景课题。
5. **课程与教材服务。** 主持教育部"新世纪网络课程建设工程——计算机通信网"项目，面向全国网络课程建设。

## 七、Connection圈层总结

薛质是上海交大网络空间安全学院系统安全方向的资深教授与实验室负责人，其学术网络呈现"本校一贯培养+实验室梯队+行业治理"三重结构：**（1）师承层**——本硕博均在上海交大完成（导师未披露），是学院本土成长起来的元老级教师；**（2）团队层**——以网络与系统安全实验室为枢纽，形成陈力波、王轶骏、施勇、刘铭等骨干梯队，研究从传统渗透测试、入侵检测演进到嵌入式漏洞挖掘（USENIX Security 2021）与验证码安全（S&P 2023）等顶会级成果；**（3）行业层**——通过上海市信息网络安全管理协会会长、科旭网络专家工作站、等级保护与涉密测评工具等载体，深度嵌入上海本地网络安全产业与政府治理体系。他曾担任学院副院长与党总支书记，是学院发展史上的重要管理者，但现已退出学院领导班子。与谷大武密码学团队、蒋兴浩内容安全团队相比，薛质一系更显"工程实战+行业服务"色彩，国际学术合作相对有限。其早年贝尔实验室访问经历是其国际网络的主要支点。
