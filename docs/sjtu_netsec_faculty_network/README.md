# 上海交通大学 网络空间安全学院（其余团队） 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

上海交通大学网络空间安全学科发端于2000年创建的信息安全工程学院（国内首批信息安全人才培养基地，李建华历任常务副院长、院长），2016年12月学院更名为网络空间安全学院，2025年并入新成立的计算机学院（网络空间安全学院、密码学院）。学院下设信息安全与密码学研究所（谷大武、邢朝平，已有独立目录 [sjtu_iisec_faculty_network](../sjtu_iisec_faculty_network/) 覆盖）、人工智能与认知安全研究所、系统安全研究所、网络空间安全研究所（含信息内容分析技术国家工程研究中心/网络安全技术研究院体系）、密码分析与大数据安全实验室（邱卫东）等建制。

本目录覆盖密码学所以外的三个团队共6位代表性教师：人工智能与认知安全研究所以朱浩瑾特聘教授（IEEE Fellow、国家杰青）为所长，刘功申（长聘教授、学院系主任）与蒋兴浩（长聘教授，现任交大党委常委、副校长）任副所长，成员含陈国兴、孟岩、孙锬锋等，聚焦内容安全、AI 安全与认知安全——2024年度上海市科技进步一等奖《复杂对抗场景下的网络媒体内容安全检测关键技术与应用》（蒋兴浩牵头、蚂蚁智信等参与）即出自这一集群；系统安全研究所以薛质教授（USENIX Security 2021、S&P 2023 通信作者）为代表；网络空间安全研究所/研究院体系以李建华特聘教授（信息安全工程学院/网安学院院长、国家工程研究中心主任）为建制奠基人，潘理长聘教授（二级）为其长期副手。清单中其余教师（王士林、许可、李生红、邱卫东、化存卿等）作名单级记录，后续可按需增补。

## 圈层结构概述

网安学院（除密码学所外）的网络以"建制传承+国家任务"为鲜明特征。李建华一脉构成学科的组织骨架：其2000年起执掌信息安全工程学院（历任常务副院长、院长）、2016年12月学院更名为网络空间安全学院后继续任院长、2019年组建网络安全技术研究院并执掌信息内容分析技术国家工程研究中心，潘理、蒋兴浩、刘功申、王士林、陈秀真等骨干多为共事同事而非其亲手指导的学生——影响力经由建制与平台而非个人学术谱系传递，与谷大武团队（密码学、IACR谱系清晰）形成学院内两个并行互补的体系。人工智能与认知安全研究所呈"朱浩瑾—刘功申—蒋兴浩"三驾马车结构：朱浩瑾（滑铁卢沈学民门下）的学术谱系最国际化，自培养的孟岩已获 ACM China 优博；刘功申通过与 BCMI 张倬胜的"安全+NLP"联合指导形成跨实验室通道；蒋兴浩以副校长身份连接学科与校级治理，其与蚂蚁智信的深度伪造检测合作（日均数十亿次调用）是产业落地的标杆。薛质的系统安全线以 USENIX Security 2021（陈力波一作）等顶会成果和 CTF 生态（0ops/蓝莲花背景的姜开达、王轶骏、陈力波教学团队）见长。产业网络总体呈"国家任务牵引型"：网宿科技、奇安信、科来（2023世界互联网大会领先科技奖）、蚂蚁集团、神州数码及中央网信办、公安部等部委构成主要节点。
