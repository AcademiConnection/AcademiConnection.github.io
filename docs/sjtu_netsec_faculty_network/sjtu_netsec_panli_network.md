## 二、教育背景与职业履历

潘理的求学路径为"西电—南邮—交大"的三校接力（据[计算机学院教师页](https://cs.sjtu.edu.cn/jiaoshiml/panli.html)）：

- 1996年：西安电子科技大学计算机通信专业学士（本科直升，电子工业部优秀毕业生）；
- 1999年：南京邮电大学计算机应用专业硕士（直升，学位论文获江苏省优秀硕士论文）；
- 2002年8月：上海交通大学通信与信息系统专业博士。

其博士导师及博士论文题目在交大官方教师页、学院介绍及公开简历中均未披露。考虑到其博士毕业时李建华正在交大电子工程系任教授（后于2002年共同进入信息安全工程学院体系），且两人自2004年起持续合作，外界常将二人视作同一团队，但公开资料不足以确认师承关系，本报告不作推定。

职业履历方面，潘理[2002年至今](https://infosec.sjtu.edu.cn/DirectoryDetail.aspx?id=176)一直在上海交通大学任教，先后辗转于电子信息与电气工程学院电子工程系、信息安全工程学院/网络空间安全学院、网络安全技术研究院、计算机学院等建制，历任讲师、副教授、研究员，现为长聘教授（专业技术二级）。访问经历包括：

- 2008年1—7月：美国IBM Research T.J. Watson Center，从事访问控制策略与安全管理方向访问研究；
- 2014年1月—2015年1月：美国Boston University访问。

他在网络安全技术研究院担任直属教工党支部书记（[与院长李建华搭档](https://www.seiee.sjtu.edu.cn/index_news/7474.html)），并于2021年率支部与中移（上海）信息通信科技有限公司开展["党建和创"](https://news.sjtu.edu.cn/zhxw/20211117/162745.html)合作。

其科研轨迹经历了清晰的三阶段转型：

- **早期（2002—2012年前后）**：聚焦网络安全隔离交换系统、访问控制策略和下一代网络，承担863项目"不同密级系统间的安全交换"（2007AA01Z457）及两项国家发改委信息安全专项（电子政务云安全检查评估、电力信息系统安全运维平台）；
- **中期（2013年起）**：依托973课题"社交网络群体行为与群体情感理论研究"（2013CB329603，603万元）转向社交网络群体行为分析与网络舆情监管；
- **当前**：以网络空间内容治理、大数据与AI安全和大模型社会计算为主轴，作为首席专家主持两项国家重点研发计划项目（"法院智能化综合管理与决策关键技术研究"2018YFC0830500，经费2238万元；"面向溯源治理的多元跨数据权属法律监督线索挖掘技术研究"2023YFC3306100，经费1497.9万元）。

## 五、业界合作关系深度分析

潘理的产业合作呈现鲜明的"行业大数据落地"特征，与其"网络空间治理"研究方向互为表里：

1. **司法与政务信息化**：作为首席专家主持的两项国家重点研发计划项目均以行业落地为考核目标，形成的审判大数据态势分析系统、群体行为分析系统等已在电子政务、网信、司法领域应用于数百家单位；其团队深度参与检察机关数字检察建设研讨（详见其[在海丝中央法务区论坛的演讲](https://www.thepaper.cn/newsDetail_forward_28820805)）。
2. **电信与电力行业**：早期承担国家发改委专项"电力信息系统安全运维服务综合管理平台"（2012—2014，350万元）；2015年与上海交大电院团队合作发表电信行业常态化审计技术研究论文（与周文杰、张伟合作）；2021年起与中移（上海）信息通信科技有限公司建立"党建和创"合作关系。
3. **交通行业**：主持国家科技支撑计划子课题"高速公路网运行状态智能监测与安全服务保障关键技术研发及系统集成"（2014—2016，95万元）。
4. **网络安全隔离产品化**：其早期主导研制的网络安全隔离交换系统（863项目成果）已形成产品化应用，是其"工程化"路线的起点；该方向亦使其与等级保护、密码应用检测等安全服务生态（研究院信息安全服务技术研究实验室）产生交集。
5. **产学研奖项绑定**：作为完成人之一获得2023年世界互联网大会领先科技奖（李建华领衔、联合网宿科技/奇安信/科来网络/上海鹏越惊虹的项目），表明其嵌入李建华主导的云网融合产业联盟网络。

## 七、Connection圈层总结

潘理是李建华一手缔造的交大网安"内容安全—网络治理"体系中的二号人物和学术执行核心：教育背景为西电—南邮—交大三校接力，2002年博士毕业后即进入信息安全工程学院体系，二十余年与李建华形成"院长—书记/副主任"的稳定搭档结构。其Connection网络有三个层次：**其一，院内圈层**——作为国家工程研究中心副主任和研究院党支部书记，处于李建华网络的正中心，同时通过吴鹏、郑聪惠等留院学生建立了相对独立的课题组谱系（社交网络分析、知识图谱、内容治理方向）；**其二，司法政务圈层**——以两项国家重点研发计划为杠杆，深度嵌入法院（重庆三级法院应用）、检察（数字检察、法律监督线索挖掘）与网信系统，并与法学、传播学等文科力量形成罕见的"工科—社科"交叉网络（网络空间治理研究中心、犯罪学学会副会长），这是其区别于典型网安学者的最大特色；**其三，产业圈层**——从早期的安全隔离交换产品、电力/电信行业项目，到作为主要完成人分享世界互联网大会领先科技奖的云网融合产业联盟，其产业合作始终是"行业落地型"而非"资本孵化型"。总体而言，潘理是典型的"建制内成长、工程化落地、跨学科拓展"的网安学者，其个人学术声望（CCF杰出会员、TNNLS/TKDE等高水平产出）与李建华的平台资源高度互补。
