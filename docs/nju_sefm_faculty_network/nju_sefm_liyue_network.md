## 一、学者基本信息

李樾（Yue Li），南京大学计算机学院教授、博士生导师，计算机软件研究所（软件新技术全国重点实验室）**PASCAL（Programming Languages and Static Analysis）小组负责人**（与谭添准聘助理教授共同主持）。其研究聚焦程序分析与静态分析：指针分析、过程间分析、反射分析、程序切片及面向安全与缺陷检测的分析应用；并主导开源分析框架 **Tai-e**（Java静态分析）与 **Qihe**（Verilog静态分析）。他与谭添合讲的"软件分析"课程自2020年起开设，讲义与视频在国内程序分析学习者中影响广泛，是南大程序分析教学品牌的缔造者之一。

**教育与工作经历（依据其个人主页）：**
- 2006-2010年，西北工业大学软件工程学士。
- 2010-2012年，西北工业大学软件工程硕士。
- 2012-2016年，澳大利亚新南威尔士大学（UNSW）计算机科学博士（导师：**薛京灵 Jingling Xue 教授**；博士论文《Understanding and analyzing Java reflection》）。
- 2016-2017年，UNSW研究助理（Research Associate）。
- 2017-2019年，丹麦奥胡斯大学（Aarhus University）博士后（CASA中心，合作者：**Anders Møller 教授**）。
- 2019年3月起任南京大学计算机科学与技术系（现计算机学院）副教授，后晋升教授；入选国家级青年人才计划、南京大学登峰人才计划、南京大学"紫金学者"。

**荣誉与奖项（依据个人主页及公开资料）：**
- 国家级青年人才计划；南京大学登峰人才计划、紫金学者
- CGO 2013最佳论文奖（*Query-directed Adaptive Heap Cloning for Optimizing Compilers*，与Yulei Sui、薛京灵）
- ECOOP 2016杰出论文奖（*Program Tailoring: Slicing by Sequential Criteria*）
- ISSRE 2017最佳论文提名（Java反射分析系列工作）
- OOPSLA杰出软件制品奖（Distinguished Artifact）；据公开资料其论文另获ICSE 2025最佳软件制品奖等（待与南大官方新闻核验）

**研究主线与代表性贡献：**
1. **Java反射分析：** 博士论文主题，系列成果（ECOOP 2014、SAS 2015、ISSRE 2017、TOPLAS 2017发表）系统解决反射调用导致的分析不完备问题，是Java静态分析基础设施层面的标志性工作。
2. **指针分析精度与效率：** 与谭添、Yannis Smaragdakis等提出选择性上下文敏感性（TOPLAS 2020、OOPSLA 2021），并发表"指针分析"系统综述（TOSEM 2021）。
3. **分析框架建设：** 主导Tai-e（ISSTA 2023工具论文）与Qihe，前者已成为国内Java静态分析研究与教学的事实性基础设施之一；面向数据库后端应用（OOPSLA 2025）、微服务系统（FSE 2025）、Verilog硬件描述语言的指针/数据流分析持续拓展。
4. **跨语言与安全应用：** 与许畅等合作安卓安全分析框架PacDroid（ICSE 2025）、跨语言指针分析（ICSE 2025）等。

### 3.1 UNSW博士阶段（2012-2016）

李樾2012年进入新南威尔士大学攻读博士，导师为薛京灵（Jingling Xue）教授——澳大利亚程序分析与编译优化领域的代表性学者。博士论文《Understanding and analyzing Java reflection》聚焦Java反射机制对静态分析的破坏问题，相关成果发表于ECOOP 2014、SAS 2015、ISSRE 2017与TOPLAS 2017，构成其学术立身之本。值得注意的是，其与谭添的合作始于2012年（ISSRE 2012系统挂起分析），早于二人先后进入薛京灵门下：**二人同为西北工业大学软件工程校友（李樾2006级本科、谭添2009级本科）、先后在UNSW薛京灵组攻读博士（谭添2017年毕业）、又先后在奥胡斯大学Anders Møller的CASA中心从事博士后**，形成罕见的"三段同轨"履历。2019年二人同期加入南京大学并共建PASCAL。

## 五、业界合作关系深度分析

### 5.1 华为——"华为-南大下一代程序设计创新实验室"

南大官方新闻显示，李樾与谭添的TOPLAS 2020选择性上下文敏感指针分析工作受"华为-南大下一代程序设计创新实验室"支持，Tai-e框架亦在该合作框架下发展。这是其可确认的最早产业合作通道，连接华为在编程语言与编译基础设施方向的需求。

### 5.2 产业界论文合作者

TSE 2024论文《Generic Sensitivity: Generics-Guided Context Sensitivity for Pointer Analysis》（第一作者李昊峰，现中科院计算所副研究员）的作者名单中包含多位业界研究者（Jie Lu、Haining Meng、Liqing Cao、Yongheng Huang、Lian Li、Lin Gao、Peng Di、Liang Lin、Chenxi Cui等），属泛型指针分析的产学联合发表；**其具体所属企业在论文公开页面未标注，无法确认主体**。

### 5.3 人才输送型产业连接

## 六、Connection圈层总结

**第一圈层——"双PI共同体"谭添：** 35次合作覆盖2012年至今的全部阶段，从西工大校友、UNSW同门（薛京灵）、奥胡斯同期博士后到南大共同建组，二人构成国内程序分析领域最紧密的青年教师搭档之一。PASCAL的一切产出（论文、Tai-e、课程）均为二人共同署名的产物。

**第二圈层——上游导师链：** 薛京灵（14次）定义其博士期研究范式；Anders Møller与Yannis Smaragdakis提供博士后与理论合作通道；Thomas Reps的加入（TOPLAS 2026）标志其向程序分析理论最高谱系的延伸。国际谱系清晰且逐级上升。

**第三圈层——软件所同事网络：** 许畅（12次）、马晓星（9次）是回国后最主要的合作教师；与曹春（I2Ec）、卜磊（SEG）等同所教师分属不同小组、通过实验室组织与交叉论文弱连接；蒋炎岩、黄宇为同所同事（均有独立PI报告）。李樾的引入使软件所的版图从"网构软件+形式化方法"扩展出"编程语言与静态分析"第三极。

**第四圈层——PASCAL学生梯队与人才出口：** 张腾、陈沁林、梁宇飞、崔家才、张乃仁等构成2023-2026年高产出引擎；毕业生向头部企业（腾讯/美团/阿里/蚂蚁/华为/米哈游/Citadel）与国际顶尖博士项目（威斯康星/伯克利）的双向输出，使其网络同时具备产业与学术延展性。

**第五圈层——业界接口：** 华为-南大联合实验室（TOPLAS 2020/Tai-e）为可确认通道；泛型敏感度TSE 2024论文含业界合作者；Qihe/Vide面向EDA需求但合作主体未披露。

**产出规模与发展阶段：** 43条DBLP记录、60位合作者——"少而精"的顶会顶刊画像（A类及以上约20篇）。2023年以来的加速期与学生梯队成熟同步，其发展阶段相当于从"建组生存期"进入"方向扩张期"：从Java指针分析核心向数据库应用、微服务、硬件描述语言三个应用纵深推进，同时以Tai-e教学生态扩大影响力。作为软件所最年轻的正教授之一，其"教学品牌+开源工具+顶会产出"三位一体的网络构建模式在国内同方向青年学者中具有代表性。
