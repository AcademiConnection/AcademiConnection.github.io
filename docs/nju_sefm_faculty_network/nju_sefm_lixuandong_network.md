李宣东是南京大学软件工程学科的旗帜性人物。其领导的**软件工程组（SEG, Software Engineering Group）**是国内规模最大、延续性最强的形式化方法与软件工程研究团队之一，骨干包括王林章、赵建华、陈鑫、张天、卜磊、左志强、王豫等；团队长期依托计算机软件研究所（后为软件新技术全国重点实验室）与软件学院运行。2006—2022年间他先后执掌计算机系与软件学院两大学术治理机构，是南大计算机学科与软件工程学科（教育部第四/五轮学科评估全国前列）的组织者之一。2023年南大苏州校区设立智能软件与工程学院后，李宣东出任首任院长，推动软件工程与AI融合的新布局。

## 五、业界合作关系深度分析

1. **DBLP署名层面的企业合作稀疏**：其论文合作者中几乎未见企业署名作者，公开论文网络未显示稳定的产业合作通道（与吕建线形成对照）。
2. **国家重大任务渠道**：SEG长期承担国家863、973课题与"核高基"重大专项相关研究（形式化验证与软件质量保障方向），此类任务通常涉及国内基础软件企业（操作系统/EDA/航天等），但具体企业合同与成果转化细节公开资料未披露。
3. **学术共同体的产业连接**：作为CCF软件工程专委主任与系统软件专委前主任，其主导的CNCC/中国软件大会等场合与华为、阿里、腾讯等企业研发负责人（如阿里通义李永彬、华为夏鑫等）同台研讨"大模型赋能软件工程"；此类互动属学术共同体层面，未见个人级合作项目公开。
4. **中创软件基金**：李宣东1998年获中创软件人才奖，2024年作为推荐专家出席该基金颁奖仪式——该基金（中创软件股份）是国内软件工程界主要的产学研奖项渠道，可视为其与企业界的主要制度化连接点。

## 六、Connection圈层总结

- **中心圈（师承待核）**：郑国梁（前辈/疑为博士导师）→ 李宣东 → 王林章、赵建华、卜磊、张天、潘敏学、左志强、陈鑫等（SEG谱系，师承以学位档案为准）。
- **团队圈**：SEG是南大"软件工程/形式化方法"主线的组织载体，内部以"李宣东—王林章/赵建华"为双核，向外辐射移动测试、程序分析、混合系统验证三条子线。
- **同事圈**：吕建、马晓星（软件所治理层，各有独立报告）；黄宇、蒋炎岩（独立PI，仅作圈层引用）。
- **国际圈**：Guoqing Harry Xu（UCLA，程序分析合作线）、苏振东（UC Davis→ETH）、Wensheng Dou（中科院软件所）等；欧洲形式化方法共同体（FM、ICTAC、TASE会议网络）。
- **业界圈**：个人署名层面的企业合作未见于公开数据库；产业连接主要通过国家重大专项（细节未公开）与CCF/中创软件基金等学术共同体渠道。
