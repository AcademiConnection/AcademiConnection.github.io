## 三、博士教育背景与导师追溯

- **本科**：国防科技大学计算机系计算机软件专业（1987–1991）
- **硕士**：南京大学计算机系计算机软件专业（1991–1994），师从**徐家福教授**（中国计算机软件学先驱、南大软件学科奠基人之一，软件新技术国家重点实验室名誉主任）
- **博士**：南京大学计算机系计算机软件与理论专业（1998–2001），师从**吕建院士**（网构软件方法学与软件自动化方向）
- **学术谱系位置**：陶先平是南大软件学科"徐家福→吕建"两代学脉的直接传人：硕士导师徐家福是中国最早的软件学奠基人之一，博士导师吕建则是软件新技术国家重点实验室（现软件新技术全国重点实验室）的创建领导者。这一谱系决定了陶先平长期处于南大软件所（网构软件、中间件、普适计算）的组织核心。1994年起留校任讲师、副教授，2005年晋升教授

## 六、Connection圈层总结

陶先平的学术关系网络可归纳为四个圈层：

1. **血缘圈（导师谱系）**：徐家福（硕士）→ 吕建（博士），南大软件学科两代嫡传；这使其天然位于南大软件所组织核心，是"网构软件学派"的中生代代表
2. **核心协作圈**：吕建（83次）＋汪亮（55次）＋顾涛（36次）＋胡昊（17次）；前两位构成"导师—接班人"的南大内部主轴，顾涛则是其普适计算方向最重要的国际合伙人（中澳长期合作）
3. **学生辐射圈**：马骏、董恺、叶海波、徐经纬、朱晓瑞、李晅松等博士毕业生分布于南大、东南、南航、河海、南理工，形成以南京为中心的普适计算学术辐射网
4. **交叉扩展圈**：近年通过前沿交叉中心（CIC）向数据挖掘（Hanghang Tong）、开源生态、多智能体与大模型应用扩展，合作者网络年轻化明显

**Connection要点**：若以陶先平为节点建立学术网络，最具历史纵深的是"徐家福–吕建–陶先平–汪亮"四代南大软件学脉链；最具国际价值的是与顾涛（麦考瑞）的中澳普适计算轴；最具当代活力的是CIC青年群体（郑志文、张杰锐、张明雅等）。其与许畅、蒋炎岩、王林章同为软件所同事但合作强度分化明显，反映软件所内部"普适计算线"与"软件测试分析线"的分工格局。
