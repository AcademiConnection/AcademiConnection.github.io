## 七、Connection 圈层总结

**第一圈层——国际化上游导师链（博士与博士后）：** 左志强的学术谱系自基础训练起即为"程序分析、系统、编译"的国际化路线：新加坡国立大学（导师 Siau-Cheng Khoo）提供形式化与程序分析的经验训练，奠定博士阶段基本范式；加州大学（UCLA → UC Irvine）的 Harry Xu（徐昊）作为博士后合作导师，将其推向系统与编译器层面，此阶段合作的 Grapple（EuroSys'19）与后来的系列工作构成其学术立身之本，定义了"系统 + 程序分析"双栖的上游基因。

**第二圈层——SEG 课题组的同事网络：** 进入南大后，左志强嵌入软件工程组（SEG）协作体系：李宣东为课题带头人（SEG 资深教授、所在课题组的组长），王林章、赵建华、张天、卜磊、陈鑫、王豫等构成教师同事圈。论文署名层面其多为通讯作者，李宣东作为合作者共同署于顶会论文（HybridPersist/OOPSLA'25 非易失内存编程系列、TOPLAS 分布式数据流分析期刊扩展版），呈"课题组长-成员协同"的产出模式，奠定其在南大软件工程与程序分析方向的高内聚学术网络。

**第三圈层——跨组程序分析网络：** 与软件所其他小组及校内静态分析方向同行（如李樾、谭添等 PASCAL 组）形成方向互补的弱连接协作，多以共享顶会与程序分析工具链为平台，构成校内的学术协作网络。

**第四圈层——业界转化网络：** 通过 CCF-华为创新研究奖（GPU/PGO 方向）、阿里 AIR 创新研究奖（分布式存储完整性）、以及向头部企业（华为、阿里、腾讯等）的程序分析/编译器方向转化，连接产业需求，是其研究通向现实基础设施（编译器、AI/深度学习编译器、分布式存储）的端口；具体合作深度、合同与转化规模公开信息未披露。

**第五圈层——学术社区网络：** 担任 PLDI、FSE、ICSE、ASE、ASPLOS、CC 等一级会议 PC/RC 成员，属高密度的社区协作网络，支撑其在程序分析与系统方向的学术话语权。

**整体画像：** 左志强是"国际训练 + SEG 内聚 + 系统/编译前沿 + 产业转化"复合型青年学者。其网络特征：上游国际化双导师（NUS 博士 + UC Irvine 博后），中游高内聚 SEG（组长李宣东 + 组内同事），下游刚性对接头部企业（华为/阿里/腾讯）与 AI 编译前沿，是一条从"系统分析基础设施"到"AI 编译工业化"的连接性通道型学术网络，当前处于学术发力的上升期。
