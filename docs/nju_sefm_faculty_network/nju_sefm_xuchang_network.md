## 六、Connection圈层总结

许畅的学术关系网络可归纳为四个圈层：

1. **血缘圈（导师谱系）**：港科大张成志（CASTLE）→ 南大吕建/马晓星体系的双重嵌入，使其成为连接华南（港科大）与华东（南大）软件工程两大重镇的枢纽人物
2. **核心协作圈**：蒋炎岩（45次）＋马晓星（77次）＋吕建（65次）＋曹春（35次），构成南大软件所"自适应软件＋程序分析＋系统验证"铁三角之外的测试分析主线
3. **学生辐射圈**：13名以上博士毕业生（含联培），向南大、南航及工业界辐射；与蒋炎岩共享的联培学生群体（李聪、欧先锋、刘含之等）产出了SOSP/EuroSys级别的标志性成果
4. **外部明星圈**：谢涛（北大）、苏振东（ETH）、刘烨庞（SUSTek）、Tingting Yu等，覆盖程序分析、软件安全与大模型软件工程前沿

**Connection要点**：若以许畅为节点建立学术网络，最具价值的连接是其博士导师张成志（港科大CASTLE）与同事蒋炎岩（南大SPAR）两条强边；前者解释其测试与移动软件工程的学术渊源，后者解释其近年在系统顶会（SOSP/EuroSys/ASPLOS）的爆发性产出。
