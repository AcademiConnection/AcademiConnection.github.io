## 三、博士教育背景与导师追溯

- **本科**：南京大学计算机科学系，1982年获学士学位。
- **博士**：南京大学计算机科学系，1988年获计算机软件专业博士学位，**导师为徐家福教授**（中国计算机软件学科奠基人之一、中国大陆第一位计算机软件博士的指导者、软件新技术国家重点实验室名誉主任，2018年1月逝世）。吕建1984年11月即留校任教，博士为在职攻取。
- **师承谱系**：徐家福—吕建一线是南大软件学科的"主干师承"。徐家福先生早年开创中国程序设计与软件自动化研究，吕建继承并拓新为软件自动化与网构软件方法学。
- **反向追溯（学生辈）**：以软件所与CCF官方资料可确认的吕建博士生包括：
  - **蒋炎岩**（博士论文获2018年CCF优秀博士学位论文奖；南大软件所官方宣传页明确标注"导师：许畅、马晓星、吕建"）；
  - **魏恒峰**（2017年CCF优博，与黄宇共同指导，现任湖南大学副教授）；
  - **杨怡玲**（2016年CCF优博，与黄宇共同指导）。
  - 马晓星、陶先平、曹春、许峰等骨干均在吕建团队中成长（DBLP合作跨度均超过20年），其博士学位均获自南京大学；但除上述CCF优博名单外，其余成员的导师归属未见官方逐人披露，本报告不作推断。

## 五、业界合作关系深度分析

1. **腾讯（数据平台/AI Lab通道）**：DBLP可见吕建与腾讯杨文华（曾任腾讯数据平台部负责人）、顾斌等在2013—2018年间合著约10篇论文（KDD/TKDE/CIKM/ASONAM等，社区问答质量预测、信任推理等方向），是其在DBLP上最清晰的业界署名合作线。
2. **华为（实验室整体合作）**：南京大学计算机学院与华为（含南京研究所）在系统软件、开源（openEuler/openGauss社区）等方向有长期合作，吕建作为实验室主任与院士是此类合作的牵头人之一；但以其个人名义署名的华为合作论文未见公开记录，具体项目内容公开资料未披露。
3. **学术共同体—产业桥梁**：吕建担任国家"核高基"科技重大专项总体专家组专家、863/973咨询专家等职，长期参与国家软件产业科技规划；2026年前后其公开活动的重点议题为"计算与智能产学研融合"（推动南京算力/软件产业与高校联动），显示其卸任校长后转向产学研整合的角色。
4. **奖项渠道的产业关联**：何梁何利基金科学与技术进步奖（2020年度前后）等由基金会渠道授予，非直接企业合作。
