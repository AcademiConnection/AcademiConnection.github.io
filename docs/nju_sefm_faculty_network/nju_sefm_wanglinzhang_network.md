## 三、博士教育背景与导师追溯

- **博士**：南京大学（软件工程方向），毕业年份与论文导师**未在公开权威来源中直接披露**。其DBLP记录自2004年起即与李宣东持续共同发表（至今74次），且长期任职于李宣东领导的软件工程组（SEG），学术谱系上明确归属南大软件工程学派；综合公开信息推断其博士阶段在南大软件工程组完成（导师李宣东的可能性最大），但**该推断未经官方简历直接证实**，供后续核验
- **学术谱系位置**：南大软件工程学派由郑国梁教授开创、李宣东教授发扬光大；王林章与赵建华、张天、卜磊等同为该学派中生代骨干。与软件所（吕建–马晓星–许畅一系，网构软件/自适应软件主线）相比，软件工程组以"形式化方法＋软件测试验证"为主线，两线同属软件新技术全国重点实验室
- **备注**：DBLP中另存在姓名高度相似的"Lin-Zhang Wang"（pid 08/7620，机构锁定为非南大），本报告已通过机构与研究方向双重锁定排除混淆

## 六、Connection圈层总结

王林章的学术关系网络可归纳为四个圈层：

1. **血缘圈（学派谱系）**：南大软件工程学派（郑国梁→李宣东）中生代核心；李宣东以74次合作构成其网络中的绝对中心边，其学术身份本质是"李宣东体系的工程化与产业化延伸"
2. **核心协作圈**：赵建华（27次）＋张天（16次）＋卜磊（14次）＋高凤娟（13次）＋司徒凌云（10次）＋茅兵（9次），构成南大"形式化验证×软件测试×系统安全"的铁三角网络
3. **国际圈**：Yu Wang（特拉华，24次）为核心的美方合作群（Tingting Yu、Le Guan、Peng Liu等IoT/嵌入式安全方向），叠加NTU刘杨、UCLA徐国淦等程序语言方向节点
4. **产业圈**：华为（9项横向项目＋胡杨林基金专项管委会主任）为绝对重心，辅以十四所（CETC）、浪潮与第三方测试中心，形成"学术验证—工程落地—标准制定"闭环

**Connection要点**：若以王林章为节点建立学术网络，最强的两条边分别是学术侧的李宣东（南大SEG）与产业侧的华为系统软件线。他是南大软件工程团队中"国家纵向项目（国防、重点研发）＋头部企业横向项目＋标准化工作"三线并举的代表人物，也是理解南大软件工程组（区别于软件所网构软件线）组织结构的关键节点。
