**报告生成时间：** 2026年8月

**覆盖范围：** 南京大学计算机软件研究所（计算机软件新技术全国重点实验室）软件工程与形式化方法方向核心教师，共11人：吕建、李宣东、马晓星、许畅、陶先平、王林章、曹春、卜磊、李樾、潘敏学、程龚。该团队以南大"网构软件"学派与SEG（软件工程组）两条主线为主干，是中国软件工程学科评估的支柱力量。

**数据方法：** 以DBLP官方作者消歧记录（pid）为核心数据源统计发表与合作网络，结合软件所官网（ics.nju.edu.cn）、计算机学院官网、各教师个人主页、南大官方新闻与奖项公示页交叉确认职务、师承与企业合作。每人一份独立报告，重点覆盖导师追溯、学生培养与业界合作三大板块。

**团队边界说明：** 黄宇（DisAlg小组）与蒋炎岩（iSE实验室）均出自软件所但已公开声明以独立PI运行，另有独立报告，本目录仅在圈层层面交叉引用，不列为本团队成员。

## 全团队关系网络的整体观察

本团队呈现出南大计算机学科最完整的"四代学脉"结构。第一代徐家福（软件所创始人）、郑国梁（SEG创始人）培养了吕建（1988年博士）与陶先平（2001年博士）；吕建向下贯通马晓星、许畅、曹春等骨干，形成"网构软件—人机物融合"主线；李宣东主持的SEG则发展出形式化验证（卜磊、赵建华、张天）、软件测试（王林章、潘敏学）与大规模程序分析（左志强）三条子线。两条主线在论文署名层面基本并行、在实验室治理与人才培养层面深度协同，是软件所内部的稳定分工格局。

师承与优博产出高度密集：吕建直接与联合指导的博士中产生了3位CCF优秀博士学位论文奖得主（2016杨怡玲、2017魏恒峰——均与黄宇联合指导；2018蒋炎岩——官方记载导师为许畅、马晓星、吕建三人）。2010年后引进的许畅（港科大张成志门下）与自主培养新引进的李樾、谭添（均为UNSW薛京灵门下）为团队注入了两条外部学术谱系：前者连接港科大CASTLE网络并在近年与蒋炎岩共同产出SOSP 2023最佳论文、EuroSys 2025最佳学生论文；后者建立起"南大—澳洲"程序分析连线，使软件所形成网构软件、形式化方法、程序分析"三极"格局。

产业合作方面，华为是覆盖面最广的伙伴：王林章承担华为横向项目累计逾千万元，李樾的PASCAL组有华为-南大联合实验室官方新闻佐证，马晓星出席华为openJiuwen开源活动；吕建团队与腾讯AI Lab在2013–2018年有论文合作记录。程龚与博世的知识图谱落地合作是团队工业界转化的代表案例。整体上，团队的产学研形态以国家纵向任务（973/863/重点研发）与头部企业横向项目为主，具体合同细节多未公开。
