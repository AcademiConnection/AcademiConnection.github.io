## 二、教育背景与职业履历

艾杨于2012年9月至2016年6月在厦门大学通信工程专业学习，获学士学位；2016年9月考入中国科学技术大学信息与通信工程专业攻读博士学位，导师为凌震华教授（语音合成与语音信号处理领域知名学者，现任语音及语言信息处理国家工程研究中心副主任），2021年6月获博士学位。博士期间，他于2020年2月至2020年8月赴日本国立情报学研究所（NII）进行联合培养，师从国际语音合成权威山崎至（Junichi Yamagishi）教授，这段经历为其后续与国际同行在声码器、语音质量增强方向的合作奠定了基础。

其职业履历有一段值得注意的经历：2021年7月至2022年3月，他在国防科技大学（合肥）担任讲师；2022年4月回到中国科学技术大学从事博士后研究（合作导师凌震华）；2024年1月起出任中国科学技术大学特任副研究员。从其主持与参与的科研项目看，他已独立主持国家自然科学基金青年项目"面向语音生成的抗卷绕相位谱预测"（2024—2026）、安徽省自然科学基金青年项目"结合相位预测的高质量高效率辅助式语音增强方法研究"（2023—2025）及中科大青年创新基金"高效率高鲁棒的神经网络声码器研究"（2023—2024），并作为核心成员（排名2/34）参与科技部攻关项目子课题"智能语音移植模型和算法工具包研发"、排名2/35 参与中科院战略性先导科技专项（C类）课题"多语种语音合成关键技术"、排名3/31 参与国家重点研发计划课题"面向冬奥场景的多语种语音处理关键技术"等重大项目，深度嵌入中科大语音团队的国家重大任务体系。

艾杨是中科大语音实验室自主培养（本硕博贯通培养链：厦门大学本科—中科大博士）并向外辐射的青年学者样本。其网络上游为凌震华（博士导师，合著85篇）与山崎至（NII 联合培养导师）构成的"中科大—NII"语音生成双师承；中游为实验室内部的协同网络——与戴礼荣、张结、吴及及科大讯飞陈丽萍等的合作，使其嵌入"凌震华团队—NERC-SLIP—科大讯飞"的国家级重大任务体系（冬奥多语种、智能语音移植、先导 C 类项目均排名前三）；下游为正在形成的学生梯队（以杜荟鹏、鲁叶欣、郑瑞晨、江晓航为代表的合作指导研究生）。其学术标签极为鲜明：以 NSPP 为旗帜的语音相位建模方向，以及 APCodec 系列为代表的并行幅度-相位神经编解码器方向，均属语音生成与低码率编码交叉的前沿。跨界合作（中科大心理学系的脑激活语音表征、立命馆大学的医疗影像 AI）显示出超出传统语音圈的多模态拓展能力。业界层面，小米青年学者与讯飞产业化管道构成其"个人品牌+体制通道"的双重支撑。总体而言，艾杨是典型的"单点技术深耕型"青年学者：以相位建模这一细分技术为锚点，沿语音合成—语音增强—音频编解码—语音大模型 token 化的技术主线快速扩张，其圈层价值在于连接了学术前沿（NII、Blizzard Challenge 社区）与中国语音产业核心（讯飞、小米）。
