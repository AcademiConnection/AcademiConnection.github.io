# 中国科学技术大学语音及语言信息处理国家工程研究中心学术关系网络报告

## 团队简介

语音及语言信息处理国家工程实验室于2011年由国家发改委正式批准成立，由中国科学技术大学与科大讯飞股份有限公司联合共建，是我国语音产业界唯一的国家级研究开发平台；2021年底通过国家发改委优化整合评估，纳入新序列并转建为语音及语言信息处理国家工程研究中心（NERC-SLIP）。实验室的学术源头可追溯至王仁华教授1985年创立的中科大语言通信实验室（我国最早的人机语音通信实验室之一），其学生团队于1999年创立科大讯飞，开创了中国语音产业"产学研一体化"的独特生态。

团队现任核心教师包括戴礼荣（曾任国家工程实验室副主任2011-2022）、杜俊、凌震华（国家工程研究中心副主任）、郭武、宋彦、张结等教授/副教授，以及艾杨等青年骨干。研究方向覆盖语音识别、语音合成、语音增强与分离、说话人识别、语种识别、语音评测、自然语言处理与音频大模型全链条。代表性成果包括：Blizzard Challenge 国际语音合成评测2006-2019年连续十四年第一、NIST 2008世界说话人识别大赛综合成绩世界第一、"多语种智能语音关键技术及产业化"获2023年度国家科技进步一等奖。

## 研究方向与圈层结构概述

团队学术谱系以"王仁华学派"为根基，呈四代传承结构。第一代王仁华教授创立语言通信实验室，主持KD系列文语转换系统（获2002年国家科技进步二等奖），推动创立科大讯飞；第二代戴礼荣（1997年博士）任国家工程实验室副主任十余年，是承上启下的枢纽人物，同代还有郭武（NIST评测冠军团队核心）；第三代凌震华（博士2008年，硕博师从王仁华，语音合成/LauraTTS方向）与杜俊（博士2009年，推断师承戴礼荣，语音增强/识别方向）执掌两大主力方向，同为2023年国家科技进步一等奖完成人（分列第4、第9）；第四代以艾杨（特任副研究员，NSPP/APCodec作者，2024小米青年学者）、陈航等为代表。外部网络方面，佐治亚理工Chin-Hui Lee教授是团队十余年来的核心国际合作者（参与产出两项IEEE SPS最佳论文奖）；新加坡I2R、南洋理工及荷兰代尔夫特（张结博士母校）构成国际支线。

产业网络以科大讯飞为绝对核心：国家工程实验室由校企联合共建（刘庆峰任主任、胡郁任执行主任、王仁华任技术委员会主任），专利、项目、人才三线深度绑定（张仕良等毕业生直接进入讯飞核心研发）；杜俊团队与腾讯（智能回声消除/语音增强横向课题）、凌震华/艾杨团队与小米（青年学者计划）等亦有持续合作。

## 产业转化亮点

"多语种智能语音关键技术及产业化"（2023年度国家科技进步一等奖）是团队产学研体系的集大成之作，完成人横跨中科大（凌震华、杜俊、戴礼荣团队）与科大讯飞（刘庆峰、刘聪等）、华为、中国移动，凌震华-杜俊研究团队的语音合成与增强技术直接支撑讯飞产品线。Blizzard Challenge十四连冠确立了中国语音合成研究的国际地位；普通话口语评测技术（讯飞-中科大理大谱系）推广至全国普通话等级考试；DCASE国际声音事件检测挑战赛多届冠军（杜俊、王青团队）持续转化为智能音频应用。
