# 中国科学技术大学 数据科学实验室（LDS）教师学术关系网络报告

> 报告生成时间：2026年8月26日

## 团队简介

数据科学实验室（Lab for Data Science，LDS，官网 https://data-science.ustc.edu.cn/ ）由中国科学技术大学人工智能与数据科学学院副院长何向南教授于 2019 年创立并领衔，隶属人工智能与数据科学学院（大数据学院沿革），实行"合肥本部 + 苏州高等研究院"双基地运行，依托国家高性能计算中心（合肥）等平台。实验室聚焦数据挖掘、信息检索与推荐系统、因果推断、图机器学习及大模型与推荐的交叉方向，近年在 SIGIR、KDD、WWW、NeurIPS、ICML、ICLR、RecSys 等顶级会议持续高产，是中科大乃至国内推荐系统与数据挖掘方向最具国际影响力的团队之一。

实验室的标志性成果包括 NCF（WWW 2017，推荐系统深度学习化的里程碑论文）、NGCF/LightGCN（SIGIR 2019/2020，图推荐的奠基工作）、SGL（SIGIR 2021）、KuaiRec/KuaiRand 快手联合数据集（CIKM 2022）与 AlphaEdit（ICLR 2025 杰出论文奖，大模型知识编辑）。团队获 2024 年度吴文俊人工智能自然科学奖一等奖（"网络用户行为的图建模理论与方法"，何向南排名第一），何向南、王翔分别入选 AI 2000 信息检索与推荐领域全球最具影响力学者榜单，形成"何向南 + 王翔"双 PI、冯福利/王文杰/吴剑灿/高崇铭等梯队成员环绕的师资结构。此前该团队在报告体系中完全未被覆盖，本报告系列为其首次建档。

## 研究方向与圈层结构概述

LDS 的研究布局沿"图建模—因果推断—大模型"三个阶段演进：早期以 NCF 完成推荐系统从线性模型到深度学习的范式转换；中期以 NGCF/LightGCN/SGL 构成图神经网络推荐的完整方法体系，并以 PDA 等工作开辟因果去偏推荐方向；近年全面转向大语言模型与推荐/对齐的交叉（AlphaEdit、AlphaDPO、DiffRec 等），同时在无偏推荐评测基准（KuaiRec/KuaiRand）上建立了学界—业界数据合作的样板。

圈层结构上，LDS 呈现罕见的"同源整建制移植 + 本土造血"复合结构：核心圈由何向南（NUS 蔡达成谱系）、王翔（北航→NUS 蔡达成博士，何向南为其博士 Mentor）、冯福利（北航→NUS 蔡达成博士）、王文杰（山东大学→NUS 博士）这一"NUS NExT++ 学派"班底构成，叠加吴剑灿、高崇铭等中科大本土培养的骨干，形成"海归整建制 + 本土梯队"双循环，且核心成员全部留任中科大教职序列，具备极强的内部繁殖能力。外层则通过"中科大—合工大（汪萌、洪日昌）—浙大（肖俊）"的吴文俊奖获奖联合体、微软亚洲研究院（SGL、连德浩、谢幸）、人大/清华推荐系统学术共同体、上海人工智能实验室（王翔联合聘用）以及快手/腾讯/蚂蚁等产业合著网络辐射；学术上游锚定蔡达成 NExT++ 中心，是 LDS 最稳定的国际合作轴心。

## 产业转化亮点

LDS 的产业转化以"开源资产 + 数据集共建 + 联合署名"为主要形态而非公司孵化：与快手联合发布的 KuaiRec（全观测数据集）与 KuaiRand（随机曝光无偏数据集）已成为推荐系统评测的社区标准资源；LightGCN、SGL、AlphaEdit 等模型与算法的开源实现在工业界推荐/LLM 团队中被广泛复用，何向南引用量超 5 万次（h 因子超 100，2025 年学院口径）、王翔超 3.5 万次，反映其成果的产业渗透力；PDA、AlphaDPO 等论文与腾讯（凌国辉等）、蚂蚁（郭辉峰等）研究人员联合署名，高崇铭、吴剑灿等的近期论文持续出现快手研究人员（盖坤、蔡庆鹏等）署名，构成"学界方法 + 业界数据/场景"的稳定合作模式。何向南 2020 年获阿里巴巴达摩院青橙奖（含 100 万元奖金与数据资源支持），华为诺亚方舟、百度研究院、微软亚洲研究院亦见于实验室官方介绍的产学研合作名单。
