## 二、教育背景与职业履历

[官方履历](http://jxin.gr.xjtu.edu.cn/)载明：辛景民1984—1988年就读西安交通大学自动控制专业获工学学士；1991—1993年、1993—1996年分别获庆应义塾大学电气工学硕士、博士。另据公开资料，其1988—1990年在邮电部第十研究所工作（该段经历仅注明来源为公开资料，个人主页未载）。1996—2002年先后在日本TAO、JST、YRP移动通信基盘技术研究所工作，2002—2007年任富士通研究所研究员，2007年起任西安交通大学教授。其个人主页明确为“Ph.D. (Keio University)”。因此辛景民不是郑南宁学生，二人关系应定位为人机所/学院的同团队学术与建制协作。关于学院行政职务的时间口径：2020年校新闻以人工智能学院常务副院长身份出现；2025年公开报道曾称其任执行院长；2026年学院官网执行院长为孙宏滨；具体交接时间以学院公告为准，本报告不断言其当前任执行院长。

时间线：1988年西交本科；1988—1990年邮电部第十研究所（公开资料）；1993年庆应硕士；1996年庆应博士；1996—2007年日本科研与产业研发经历；2007年至今西交教授；2020年校新闻以人工智能学院常务副院长身份出现；2025年公开报道曾称执行院长，2026年学院官网执行院长为孙宏滨。

## 三、学生培养情况

公开检索未找到辛景民个人主页发布的、可逐名验证的学生名单。为遵守关系证据边界，以下列出5项明确培养/协作节点而不将其论文作者或同院教师写成学生。

### 1. 博士生导师资格（直接培养节点）

教师主页明确标注辛景民为博士生导师、硕士生导师。这确认其具有独立研究生培养职责，但页面未披露可对应姓名的名册，因此不能生成具名学生关系。

### 2. 模式识别与信号处理研究生训练（研究方向节点）

官方主页将统计与阵列信号处理、模式识别、系统辨识和自适应滤波列为研究兴趣。这些构成其研究生课题训练的公开方向，属于培养范围描述，不等价于某位合作者的师生身份。

### 3. 国家级教学成果团队（协同培养节点）

[校方新闻](https://news.xjtu.edu.cn/info/1033/199838.htm)列明辛景民为郑南宁主持的国家级研究生教学成果一等奖完成人。该成果的主题是团队协同培养，支持其作为培养体系核心成员；郑南宁、孙宏滨、薛建儒、兰旭光等均为独立PI或团队教师，不是辛景民学生。

### 4. 人机所研究生培养平台（平台节点）

学院官方介绍载明人机所自1986年起开展人工智能硕士、博士培养，学院2021年获批人工智能交叉学科博士授权点。辛景民自2007年回校后在此平台工作，公开材料可确认的是其参与团队培养环境，未公开的个人指导名单不作补足。

### 5. 产教融合教学体系（机制节点）

国家级教学成果报道明确该体系通过前沿引领、产教融合、团队协同培养研究生。辛景民作为完成人可被确认为该机制的建设者；这是一项团队培养/科研协作依据，而不是对企业人员或同事的个人指导声明。
