## 二、教育背景与职业履历

公开资料口径的教育与职业履历：刘跃虎1984年毕业于西安交通大学计算机软件专业并留校任教，1989年获西安交通大学硕士学位；1984—1996年在西安交通大学计算机系任教；1996年获日本文部省国费奖学金公派赴庆应义塾大学留学，2000年获工学博士学位；2000年4月起应聘日本通信综合研究所特别研究员，从事图像处理与可视化研究；2002年回国后任职于西安交通大学人工智能与机器人研究所，现从事人工智能学院科研与教学工作。上述履历均标公开资料口径。此外，公开资料载其曾任人工智能与机器人研究所副所长（未见官方页面现任确认，不作为现任职务陈述）。可确认的是，他长期在人机所研究生培养体系中担任导师：苏永强官方页明确列出其2003—2006年硕士阶段由郑南宁、刘跃虎指导，2006—2012年博士阶段由刘跃虎指导。由此可定位其为人机所视觉/模式识别培养链的导师节点，但不能推定其他行政职务或海外长期合作。

团队时间背景为：人机所由郑南宁、宣国荣于1985年启动创建、1986年正式成立，2018年在其基础上成立人工智能学院，2022年团队获批人机混合增强智能全国重点实验室。全国重点实验室无公开成员名单，刘跃虎与该实验室的关系按人机所团队关联处理，不作成员身份断言；其具体个人职务未见当前公开材料确认，故按团队归属而非职务陈述。
