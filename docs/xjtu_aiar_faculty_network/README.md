# 西安交通大学人工智能与机器人研究所团队 学术网络报告

本目录收录西安交通大学人工智能与机器人研究所（人机所）七位核心学者的学术关系网络报告，覆盖郑南宁院士、辛景民、孙宏滨、薛建儒、兰旭光、刘跃虎、张雪涛。人机所由郑南宁与宣国荣于1986年在计算机控制教研室基础上创建，2018年在其基础上成立人工智能学院，2022年团队获批建设人机混合增强智能全国重点实验室，是国内最早开展人工智能硕博培养的建制化团队之一，2021年获批人工智能交叉学科博士授权点。

团队组织结构须特别澄清为人机所与全国重点实验室两级平台的关系：人工智能与机器人研究所、人工智能学院与全国重点实验室是同一团队不同层级的研究与培养载体，而非互相独立或互相替代的机构——薛建儒的视觉认知计算与智能车实验室即同时标识为三者的一部分。学院现任领导层为党委书记兰旭光、院长华刚（兼职）、执行院长孙宏滨。同时须界定成员关系：郑南宁与辛景民为同团队协作关系而非师生（辛景民博士毕业于日本庆应义塾大学，与郑南宁同为庆应校友但学术训练独立）；孙宏滨、薛建儒、兰旭光、刘跃虎等均为团队核心的独立PI，相互之间及与郑南宁之间不构成师生关系，不应混入郑南宁学生名单。确证的师承链为：张雪涛本硕博均师从郑南宁院士（2012年博士），杨勐（2008—2014年博士）师从郑南宁，苏永强硕士由郑南宁、刘跃虎联合指导、博士师从刘跃虎，方建武为薛建儒博士后（2016—2022）。

## 研究方向与圈层结构概述

团队研究主线可归纳为四个方向：一是计算机视觉与模式识别基础研究（郑南宁—张雪涛—刘跃虎链，延伸至人眼视觉、注视注意与MIT视觉感知合作）；二是智能车与视觉认知计算（薛建儒实验室，从认知计算到具身智能）；三是具身智能与机器人（兰旭光方向，依托全国重点实验室首席科学家建制，与中国自动化学会共融机器人专委会衔接）；四是信号处理与统计学习（辛景民，日本庆应—富士通产业研发背景）。

圈层结构上，第一圈层为宣国荣—郑南宁的人机所创建与传承轴，及其确认的学生节点（张雪涛、杨勐、苏永强、高占宁、刘子怡等联合培养案例）；第二圈层为团队核心教师协同网络（辛景民、孙宏滨、薛建儒、兰旭光、刘跃虎、王飞等独立PI），以郑南宁主持的2022年国家级研究生教学成果一等奖（"价值塑造、前沿引领、产教融合、团队协同"培养体系，辛景民、孙宏滨、薛建儒、兰旭光、张雪涛等共同完成）为制度性定格；第三圈层为航天工程协作网络（中国空间技术研究院、北京空间飞行器总体设计部等）与国际节点（MIT、宾夕法尼亚大学GRASP、法国里昂中央理工、美国西北大学）；第四圈层为产教融合平台（国家人工智能产教融合创新平台、视觉信息与应用国家工程研究中心、校企联合实验室）。

## 产业转化亮点

- **航天国家工程**：张雪涛、王飞、郑南宁等完成"中国空间站机械臂视觉感知与目标测量关键技术及工程应用"，应用于天和机械臂及嫦娥五/六号表取采样机械臂，获2023年中国自动化学会科技进步奖，为团队最具标志性的国家任务转化。
- **智能车与无人驾驶**：人机所长期开展无人驾驶智能车研究，薛建儒的视觉认知计算与智能车实验室面向认知计算与具身智能场景，衔接学院智能车方向与产教融合平台。
- **国防与横向项目**：张雪涛主持北京机电工程研究所横向项目（目标捕获技术设计支撑环境，245万元），苏永强承担西安渭南科赛图像、中国铁道科学研究院等横向课题，体现团队视觉技术的行业延展。
- **产教融合建制**：孙宏滨任国家人工智能产教融合创新平台副主任（2023年获批）与视觉信息与应用国家工程研究中心副主任，构建校企协同培养与技术转化接口；兰旭光以具身智能首席科学家身份推动OpenOcto等代理式AI应用示范。
- **教学成果转化**：郑南宁领衔、团队共同完成的人工智能高层次人才培养体系获2022年国家级教学成果一等奖，2025年再获陕西省教学成果特等奖，培养体系本身成为可输出的"成果"。
