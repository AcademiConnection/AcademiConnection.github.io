## 二、教育背景与职业履历

郑南宁1972年进入西安交通大学工业自动化专业学习，1975年毕业（本报告不称学士）；1981年获该校硕士学位，1985年获日本庆应义塾大学工学博士学位；其校方主页明确列出博士学位和研究方向，校方报道载明其硕士阶段导师为宣国荣，博士导师未见权威公开记载。1985年回国后，他与宣国荣于1985年启动创建人机所、1986年正式成立，组织国内较早的人工智能研究生培养与科研工作。2018年，人机所基础上成立人工智能学院；2022年团队获批建设人机混合增强智能全国重点实验室。其职业脉络由学科创建、研究团队建设和国家级平台建设连续构成。

时间线：1972—1975年西交工业自动化专业学习毕业；1981年西交硕士（校方报道载明导师宣国荣）；1985年庆应博士并回国启动创建人机所（1986年正式成立）；2000年团队获国家自然科学基金创新研究群体首批资助；2018年人工智能学院成立；2022年获吴文俊人工智能最高成就奖并建设全国重点实验室。

### 2. 苏永强（副教授，硕士联合指导节点）

[苏永强官方导师页](http://mob.xjtu.edu.cn/teacher_content.jsp?wbtreeid=1170&wbwbxjtuteacherid=3311)载明其2003—2006年在人机所读硕士，导师为“郑南宁、刘跃虎”；后续博士导师为刘跃虎。因此只能称其为郑、刘联合指导的硕士培养对象，不能表述为郑南宁博士生。

### 3. 高占宁（研究员，联合培养节点）

[王乐学生页面](https://gr.xjtu.edu.cn/en/web/lewang/2)明确写明高占宁2012—2018年博士阶段由王乐、Gang Hua与郑南宁共同指导，毕业后任阿里巴巴达摩院研究员。该证据支持“共同指导博士”而非单独师承。

### 4. 刘子怡（研究员，联合培养节点）

同一官方学生页面列明刘子怡2015—2021年博士阶段由王乐与郑南宁共同指导，毕业后进入北京便利蜂研究院。其关系应准确表述为联合培养，不能因其产业去向扩大为郑南宁个人企业合作。

### 5. 团队协同培养体系（制度性培养节点）

[国家级教学成果一等奖新闻](https://news.xjtu.edu.cn/info/1033/199838.htm)列明郑南宁主持、辛景民、孙宏滨、薛建儒、兰旭光等共同完成“价值塑造、前沿引领、产教融合、团队协同”的研究生培养体系。该节点说明其培养网络具有团队协同属性，但不产生对任何共同完成人的师生认定。

### 4.1 团队内部与平台协作

宣国荣是郑南宁回国后共同创建人机所的导师和事业合作伙伴，校方报道对此有明确记载。辛景民、孙宏滨、薛建儒、兰旭光等是同一团队现任核心教师，在国家级教学成果中共同署名；他们是协同育人和科研组织关系，不是应被混入郑南宁学生名单的同院独立PI。人机所、人工智能学院与全国重点实验室是同一团队的研究与培养载体，层级不同而非互相替代的个人课题组。
