## 二、教育背景与职业履历

### 教育经历

- **2013--2017年**：本科就读于中国科学技术大学精密仪器系（9系）。在校期间受益于中科大计算机科学通识教育，广泛涉猎计算机与人工智能知识，为后续学术生涯奠定基础。
- **2017--2021年**：新加坡国立大学（NUS）电子与计算机工程系直博，获全额博士奖学金。读博期间加入新加坡工程院院士**颜水成**教授与**冯佳时**教授联合实验室，从事计算机视觉与神经网络架构设计研究。代表性博士阶段工作包括 T2T-ViT（ICCV 2021，千引）和 VOLO（TPAMI 2022），在视觉 Transformer 领域取得突破性成果。
- **哈佛大学交流（约2019年，博士二年级）**：赴哈佛大学神经生物系，在美国科学院院士 **Margaret S. Livingstone** 教授的认知神经科学实验室进行访问研究。期间从事"猴脑模型"相关工作——训练模型预测猕猴下颞皮层面孔选择性神经元的响应，并研究生成对抗图像对灵长类视觉行为的干扰效应。该成果发表于 arXiv 论文"Adversarial Images for the Primate Brain"（合作者包括 Gabriel Kreiman、Francis E.H. Tay、Jiashi Feng、Margaret S. Livingstone）。这段跨学科经历使袁粒深刻认识到人工智能与脑科学之间的密切联系，成为其后续投身 AI 交叉研究的关键起点。

### 职业履历

- **2021年末至今**：博士毕业后，袁粒同时收到哈佛大学博士后、北大深研院及多所名校的教职 offer，最终选择加入北京大学深圳研究生院信息工程学院，任助理教授、博士生导师，并建立独立课题组（PKU-YuanGroup）。

- **2024年3月**：与田永鸿教授共同发起 Open-Sora Plan，GitHub 组织 PKU-YuanGroup 迅速成为全球关注的AIGC开源社区。
- 职称核实：截至2026年7月，北京大学深圳研究生院官方报道仍称袁粒为"助理教授"（见金鹏博士毕业新闻，2026年7月7日发布），尚未见晋升副教授的正式公示。CCF 计算机视觉前沿讲习班（2025年8月）等学术活动介绍中亦标注为"北京大学"助理教授。

## 七、Connection圈层总结

袁粒的学术关系网络呈现出鲜明的"年轻学者、跨界创新、产研融合"特征，可从三个圈层理解：

**核心圈层（导师与学生）**：博士师从颜水成、冯佳时（NUS），继承了视觉 Transformer 与高效深度学习的学术血脉；哈佛交流期间受 Margaret Livingstone 指导，获得神经科学/AI交叉视野。在北大深研院建立独立课题组后，培养了金鹏（2026北大优秀博士论文，美团LongCat）、林斌（Open-Sora Plan核心开发者）、宁鲲鹏与姚佳雨（ChatExcel）等优秀学生，形成以AIGC和高效大模型为核心的新一代研究力量。

**学术合作圈层**：与田永鸿教授构成北大深圳校区AIGC领域的学术搭档关系，在 Open-Sora Plan、多篇论文及联合培养中深度合作。与鹏城实验室在算力资源和人才培养方面保持紧密联系。学术合作者还包括 NUS 的 Francis E.H. Tay 教授、哈佛 Gabriel Kreiman 教授等。

**产业合作圈层**：以兔展智能（董少灵、周星）为核心产业伙伴，共建联合实验室并联合发起 Open-Sora Plan；与华为昇腾团队在国产算力训练方面建立战略协作；通过学生培养间接连接美团等互联网企业。袁粒的产学研模式以"学生兴趣驱动->实验室研发->开源社区放大->产业落地转化"为特色路径，ChatExcel、ChatLaw、Open-Sora Plan 均循此路径发展。

**学术影响力**：Open-Sora Plan 获超1万 GitHub star，迭代至 v1.5.0（并已于2026年3月发布新一代 Helios 模型），被中国工程院院士**王坚**高度赞誉，为2024年开源社区视觉空间模型中引用次数最多的模型之一。该项目可生成《黑神话·悟空》第三结局等视频，展现了文生视频技术在文化内容创作领域的应用潜力。袁粒以"90后"助理教授的身份，在归国短短数年内即构建了横跨学术界、开源社区与产业界的协同创新网络，成为中国AIGC领域最具影响力的青年学者之一。
