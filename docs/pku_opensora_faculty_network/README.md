# 北京大学信息工程学院 Open-Sora 课题组学术关系网络报告

## 团队简介

Open-Sora 课题组是北京大学深圳研究生院信息工程学院袁粒助理教授领衔的多模态大模型与 AIGC 研究团队（GitHub 组织 PKU-YuanGroup），以"开源复现全球顶级闭源模型"为鲜明特色。2024年3月 Sora 发布后，田永鸿与袁粒两位老师带领学生团队与兔展智能（北大校友企业）联合发起 Open-Sora Plan，在 GitHub 上集结全球开源社区力量复现 Sora 视频生成技术，项目获超1万 star，迭代至 v1.5.0 并于2026年3月发布新一代 Helios 模型，被中国工程院院士王坚高度赞誉，是2024年开源社区视觉空间模型中引用次数最多的模型之一。

课题组的前身成果同样以爆款开源项目著称：ChatExcel（2023年，国内首个生成式 AI Excel 工具，累计访问量突破千万）、ChatLaw（2023年7月，国内首个法律场景大语言模型）均循"学生兴趣驱动→实验室研发→开源社区放大→产业落地转化"的路径发展。技术路线上，团队代表性工作包括 T2T-ViT（ICCV 2021 千引工作）、VOLO（TPAMI 2022）、Spikformer（ICLR 2023 脉冲 Transformer）及 Open-Sora Plan 的 CausalVideoVAE、Skiparse Attention 等核心模块。

## 研究方向与圈层结构概述

袁粒的学术网络呈"国际师承—北大搭档—开源社区—产业伙伴"四层结构。第一层是新加坡国立大学的博士训练（2021年毕业，导师颜水成、冯佳时），颜水成实验室的视觉 Transformer 谱系（T2T-ViT、VOLO）构成其技术底座；哈佛大学 Margaret S. Livingstone 院士实验室的神经科学交流经历（灵长类视觉对抗图像研究）则塑造了其 AI for Science 的交叉视野。第二层是北大深研院搭档圈：与田永鸿教授（信息工程学院院长）在 Open-Sora Plan、MADAv2、Spikformer 等项目中深度合作，部分博士生为鹏城实验室联培。第三层是学生传承网络：金鹏（2026年北大优博，MoE++/MoH 被美团 LongCat 采用）、林斌（Open-Sora Plan 技术报告一作）、宁鲲鹏与姚佳雨（ChatExcel 核心开发者，毕业后共同创立元空智能）等构成高产梯队。第四层是产业网络：以兔展智能（CEO 董少灵为北大深研院校友）为核心伙伴共建"北大-兔展AIGC联合实验室"（袁粒任副主任）；与华为昇腾合作实现 v1.5.0 完全国产算力训练（"昇腾纯血版"）；Open-Sora Plan 的算力基础之一为鹏城云脑。

## 产业转化亮点

课题组是国内高校 AIGC 开源转化的标杆：ChatExcel 从实验室项目成长为累计访问量破千万的现象级工具，并由学生创业公司元空智能完成商用转化（2026年与深研院共建联合实验室）；ChatLaw 开创国内法律大模型产品先河；Open-Sora Plan 则在国产算力（华为昇腾512卡集群）上完成大规模视频生成模型训练，探索出"开源社区+国产芯片"的自主技术路线。袁粒本人在2023年入选福布斯亚洲30 Under 30（科学与社会领域），是深圳产学研生态中成长最快的青年学者代表。
