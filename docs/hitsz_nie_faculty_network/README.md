# 哈尔滨工业大学（深圳） 聂礼强教授智能媒体研究组 教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

聂礼强教授智能媒体研究组（隶属哈工大深圳计算机科学与技术学院，前身为山东大学 iLearn 智能媒体研究中心）是国内多媒体内容分析与多模态学习方向最具影响力的团队之一。聂礼强教授（西安交大本科、新加坡国立大学博士，师从 Chua Tat-Seng 教授）曾任山东大学计算机学院教授、山东省人工智能研究院院长，2022年加入哈工大（深圳），现任计算机学院院长。团队核心教师包括邵睿教授（多模态大模型与具身智能）和吴建龙教授（多模态学习与计算机视觉），以及山东大学 iLearn 中心留守团队的尉寅玮、宋雪萌、甘甜等教师，形成了"山大—哈工深"双基地协作模式。

团队研究方向覆盖多媒体内容分析与搜索、跨模态检索与预训练、多模态大模型（LION/MoME/LION-FS 系列）、视频理解与生成、具身智能（VLM to VLA）。在 ACM MM、SIGIR、CVPR、NeurIPS、ICCV、ECCV、ICML、ICLR 等顶级会议发表论文200余篇，获 ACM MM 2022 最佳论文奖、SIGIR 2021 最佳学生论文奖、SIGIR 2019 与 ACM MM 2019 最佳论文提名。聂礼强2019年获 ACM 中国"新星奖"，2020年获达摩院青橙奖并入选 MIT TR35 中国区榜单，2022年当选 IAPR Fellow。与快手、华为深度合作，短视频摘要生成算法在快手落地、日处理约3000万条短视频，获山东省科技进步一等奖（排名第一）。

## 圈层结构概述

团队学术谱系呈现"一源三流"结构。源头是聂礼强在 NUS 师从 Chua Tat-Seng（蔡达成，NUS 计算机学院创院院长、ACM SIGMM 成就奖获得者）形成的多媒体信息检索学术根脉。三条支流分别为：邵睿带来的港浸会阮邦志（Pong C. Yuen）+ NTU 刘子纬/Chen Change Loy 的计算机视觉与多模态学习路线；吴建龙带来的北大林宙辰/查红彬的深度学习与优化路线；以及山大 iLearn 中心尉寅玮/宋雪萌/甘甜等留守教师延续的跨模态检索与预训练路线。

产业圈层以快手和华为为双支柱：快手方面，ACM MM 2022 最佳论文成果（Search-oriented Micro-video Captioning）在快手平台落地日处理约3000万条短视频，团队与快手保持持续联合发表与合作；华为方面，有千万元级横向合作项目。学生培养形成"NUS—山大/哈工深"双通道：本科毕业生沈乐洋在聂礼强与邵睿联合指导下本科阶段即发表3篇CCF-A类顶会论文（NeurIPS/CVPR×2），毕业后赴NUS师从蔡达成攻读博士，体现了从本科到博士的完整培养链条与学术传承。山大 iLearn 中心毕业生则遍布NUS、人大、北航、NTU等海内外高校和字节跳动、快手、阿里等企业。
