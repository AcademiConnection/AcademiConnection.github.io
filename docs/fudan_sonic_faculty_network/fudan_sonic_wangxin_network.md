王新是复旦大学计算机网络方向的代表性学者与学院治理核心人物。他本科与硕士均出身西安电子科技大学信息论/通信与电子系统专业（师从通信教育家樊昌信教授），博士毕业于日本静冈大学，1995年与1998年曾两度在华为从事电信级视频会议系统与 DVB-S 卫星数字电视系统研发，兼具"学院派+产业一线"的复合履历。2002年起任教复旦大学，长期主持 SONIC 实验室，在网络编码、分布式存储编码（RAID-6/再生码）、SDN 控制平面、多视图视频传输等方向产出了一批发表于 IEEE/ACM ToN、TIT、JSAC、INFOCOM、CoNEXT 等网络领域顶级期刊会议的成果，并先后主导建设复旦大学—谷歌 Android 实验室、复旦大学—Xilinx SDN 实验室两个校企联合平台。2021年起转任学院党委书记，从学术带头人转型为学院治理的"把舵人"，历经计算机科学技术学院更名整合为计算与智能创新学院的全过程。

## 二、教育背景与职业履历

王新的教育轨迹横跨中日两国、信息论与计算机网络两个学科。1994年7月与1997年3月，他在西安电子科技大学先后获信息论专业工学学士与通信与电子系统专业工学硕士学位，两段培养的导师均为樊昌信教授。1997年至2002年间，他赴日本静冈大学信息学部攻读计算机专业，2002年3月获工学博士学位，导师为移动计算领域学者 Tadanori Mizuno 教授。值得注意的是，其简历中明确记载"1995年和1998年在华为公司参与中国早期电信级视频会议系统与 DVB-S 系统的研制"，即他在西电求学与赴日读博的间隙曾两次进入华为从事工程实践，这段经历使其成为国内计算机学院书记群体中少见的具有九十年代国产通信设备一线研发经验的学者。

其职业履历自2002年起完全锚定复旦大学：2002年回国任复旦大学计算机科学与工程系（后为计算机科学技术学院）教师，历经副教授至教授、博士生导师的完整晋升；其后转入学校信息化管理条线，先后任复旦大学校园信息化办公室副主任、主任，主导过学校层面的信息化建设工作；2021年起任计算机科学技术学院党委书记，主持学院党委工作并负责人事事务；2025年4月学校整合计算机科学技术学院、软件学院等单位成立计算与智能创新学院后，出任新学院党委委员、书记。在学院治理条线之外，他同时是上海市智能信息处理重点实验室研究人员，并长期坚持授课，主讲《信息与编码理论》《移动计算》《移动互联网》《数字逻辑与部件设计》《网络创新实验》等本研课程。

## 三、学生培养情况

王新自2002年起指导研究生，其学生群体以网络编码、存储编码、SDN、无线网络为研究底色。需要说明的是，其教师主页未公开完整的毕业生名录，以下列举以论文署名格局与主页新闻为依据，确证与推断分别标注：

### 1. 邱堃（复旦大学空间互联网研究院（筹）助理研究员，留校发展的青年骨干）

邱堃（论文署名 Kun Qiu，生于1991年）是王新—赵进合作指导格局下培养的 SDN 方向代表学生，以第一作者发表了 ParaCon（IEEE TNSM 2017）、FastRule（IEEE JSAC 2019）、Efficient Recovery Path Computation（IEEE JSAC 2019）及 ICDCS 2018、ICPP 2018 系列论文，合作者包括赵进、哥廷根大学 Xiaoming Fu、巴黎 Stefano Secci 等。其现为复旦大学空间互联网研究院（筹）助理研究员、硕士生导师（据复旦教师主页，2023年9月入职），研究 SDN 与空间互联网方向，是王新团队毕业生中可确证的留校任教者。其博士阶段由王新直接指导的正式署名虽未见公开学位论文佐证，但从其长年以第一作者与王新、赵进联合发表论文及所属学科（计算机系统结构）推断，属于王新实验室培养的嫡系学生。

### 2. 殷询（网络编码方向代表学生，去向待核实）

殷询（论文署名 Xunrui Yin）是王新在网络编码理论方向最核心的学生，以第一作者与王新、加拿大卡尔加里大学李宗鹏（Zongpeng Li）教授等合作，在 IEEE TIT（2014、2018）、IEEE INFOCOM（2012、2013、2014）、IEEE TCOM、ISIT 等顶级 venues 发表了"图拟阵视角下的多播网络编码"系列成果，将代数编码与网络拓扑结构（图子式理论）相连接，是该实验室理论性最强的一支工作。其与王新的师生关系依据多年第一作者署名格局推断，毕业后去向公开资料未披露。

### 3. 王燕（存储编码方向代表学生，去向待核实）

王燕（论文署名 Yan Wang）以第一作者与王新合作发表 MDR Codes（IEEE JSAC 2014，新一代存储系统专刊）、Two New Classes of 2-Parity MDS Array Codes（IEEE Communications Letters 2016），并参与 INFOCOM 2014 分布式存储数据再生工作，是王新在 RAID-6 码与最小 I/O 修复方向的核心学生，其师生关系同样依据署名格局推断，后续去向公开资料未披露。

### 4. 沈嘉杰（云存储与纠删码方向学生，去向待核实）

沈嘉杰（论文署名 Jiajie Shen）以第一作者与周扬帆、王新合作发表 Efficient Scheduling for Multi-block Updates in Erasure Coding based Storage Systems（IEEE TC 2018）、IPFS 存储 I/O 性能分析（IWQoS 2019）、云际存储网络编码方法（SRDS 2018）等，且其分布式存储更新调度工作获第21届全国信息存储技术学术会议（NCIS 2015）最佳论文，体现王新与周扬帆在存储方向存在事实上的联合指导。

### 5. 郑莹、陈浩宇等（近年培养的博士生）

据王新主页新闻，其指导的博士生郑莹、陈浩宇等与徐跃东、王新合作的深度强化学习鲁棒性论文"Leveraging Domain Knowledge for Robust Deep Reinforcement Learning in Networking"被 IEEE INFOCOM 2021 录用，显示近年其实验室已延伸至智慧网络与 AI for Networking 方向；另吴胜男同学与周扬帆、王新合作的文档自动生成工具用户体验研究被 CHI 2021 录用，体现其学生网络已扩展至人机交互与软件工程交叉领域。

### 6. 陈喆、张旭、李学兵等（无线与系统方向学生，多为推断）

陈喆（Zhe Chen，WiFi 定位与 MU-MIMO，ACM CoNEXT 2017 AWL、IEEE TMC 2020）、张旭（Xu Zhang，多视图视频传输 MuVi/PoM 系列）、李学兵（Xuebing Li，QUIC 综述与 Artemis 命名路由系统）等人均以第一作者身份与王新长期联合发表论文，属其实验室培养的学生或紧密合作的青年研究者（其中陈喆、张旭等的学位归属与现去向因同名学者较多、公开资料未披露，待核实）。

总体来看，王新的学生网络呈现"理论编码—存储系统—SDN/网络系统—AI 融合"的代际演进特征：2008—2014年前后以网络编码与 P2P 流媒体（SonicStream/SonicVoD 系统）为主，2013—2019年转向存储编码与 SDN，2020年前后进一步向 IPFS、QUIC、深度强化学习网络等新方向布局。与杨珉安全团队"顶会论文+竞赛"的培养模式不同，王新团队更侧重网络系统与编码理论的持续深耕，毕业生去向以高校教职与网络/存储类企业研发为主。

## 四、学术合作网络

### 4.1 学术谱系与师承关系

王新的学术谱系有两条清晰的主干。其一是西电通信/信息论学派：导师樊昌信教授（1931年生，北京大学1952届毕业）是西安电子科技大学通信工程学科的主要创始人与带头人、综合业务网国家重点实验室学术委员会原主任、信息科学研究所原所长，其主编的《通信原理》教材被600余所高校采用、累计印刷逾百万册，系 IEEE Life Fellow、IEE Fellow 及中国通信学会/中国电子学会会士（需要说明的是，樊昌信先生为学会会士身份，公开资料中未见其入选两院院士的记载）。王新本硕两段师从樊昌信，打下了信息论与编码理论的根基，这直接解释了其日后网络编码、MDS 阵列码、再生码研究的理论底色，也使其与西电 ISN 国家重点实验室保持着长期联系（其主页链接中即包含 ISN 国家重点实验室）。其二是日本静冈大学 Mizuno 学派：Tadanori Mizuno 教授长期任教于静冈大学信息学部，是日本移动计算与普适网络领域的代表学者，研究覆盖移动计算环境下的用户认证、移动 IP 多路径聚合（SHAKE 系统）、网络家电互联（μVNC）等，与三菱电机等日本产业界合作密切。王新在该实验室完成的博士训练，使其天然携带移动计算与泛在网络的视角，与其后移动互联网方向的布局一脉相承。此外，其博士前后在华为的工程经历可视为第三重"产业师承"——九十年代华为视频会议与 DVB-S 团队的系统级研发文化，深刻影响了其后来"以系统出论文"的研究风格。

### 4.2 核心学术合作网络

从其主页"合作者"栏与论文署名看，王新的合作网络可分四圈。第一圈是 SONIC 实验室内部及复旦同事：赵进（教授，SDN/可编程数据平面，自2008年前后即与王新联合发表论文，现为实验室网络方向的实际执行核心，二人共同指导了邱堃等学生）、徐跃东（教授，2009年香港中文大学博士、法国 INRIA 博士后，2013年入职复旦电子工程系——需要澄清的是，徐跃东并非王新的学生，而是长期紧密合作的同事兼论文伙伴，二人在多视图视频传输、网络经济学等方向持续合作至今）、周扬帆（教授，软件工程，存储与移动应用方向多次联合指导学生）、陈阳（教授，社交计算）、薛向阳（教授，多媒体资深学者，早年网络编码论文的合作者），以及吕智慧教授、吴杰研究员、魏东升等学院网络条线同事。第二圈是国际学术界：与多伦多大学李葆春（Baochun Li）教授团队在网络编码与分布式存储再生方面的长期合作（INFOCOM 2009 Nuclei、INFOCOM 2010/2013 再生码系列，其主页直接链接 iQua Group）、与卡尔加里大学李宗鹏教授在网络编码理论上的深度合作（多项 TIT/INFOCOM 成果）、与哥廷根大学 Xiaoming Fu、巴黎国立工艺学院 Stefano Secci、马萨诸塞大学 Amherst Tilman Wolf、INRIA Eitan Altman、香港中文大学吕荣聪、香港科技大学 Pan Hui、北京邮电大学 Jessie Hui Wang 等的合作，构成其国际发表网络的主干。第三圈是国内学术共同体：除复旦同事外，还包括上海博达数据通信等合作企业方的技术团队。第四圈是学会服务网络：通过 CCF 理事、互联网专委会副主任委员、上海市计算机学会网络专委会主任委员等任职，与国内网络学界保持广泛连接。2023年，其与吕智慧、吴杰、赵进合作、以网宿科技为第二完成单位的"云网边融合架构下大规模在线服务智能部署与加速关键技术及应用"获 CCF 科技进步二等奖，是这一合作网络产研结合的标志性成果。

### 4.3 学院治理搭档关系

作为学院党委书记，王新先后与三任行政一把手搭档。2021年其出任计算机科学技术学院党委书记时，院长为计算机视觉学者姜育刚（2020年任命、2021年4月试用期满正式任职），二人在2021—2022年间构成"书记王新+院长姜育刚"的党政搭档；2022年姜育刚转任复旦大学人事处处长（2023年12月升任副校长）后，杨珉以副院长（主持工作）身份接棒，并于2023年9月正式任院长。2025年4月学院整合组建计算与智能创新学院后，副校长汪源源兼任院长、杨珉任执行院长，王新继续出任新学院党委书记。在这套"党委领导+院长负责"的治理结构中，王新以资深网络学者和信息化管理出身主持党委工作、负责人事事务，与历任院长形成了学界少见的"双教授搭档"格局；学院近年推动的创新学院实体化建设、长聘制人事改革、本研融通培养等重大变革，均由其党委班子与行政班子协同推进。值得一提的是，同院的杨珉（安全方向）与张源团队属于系统软件与安全实验室（S3L），与王新的 SONIC 实验室是各自独立的团队，二者仅在学院治理层面为同僚关系。

## 五、业界合作关系深度分析

王新的产业连接可分三个历史阶段。第一阶段是产业一线经历（1995—1998年）：两度在华为参与中国早期电信级视频会议系统与 DVB-S 卫星数字电视系统研制，这段经历不仅奠定了其系统研发能力，也使其与华为及国产通信产业保持了长期的情感与业务连接（其主页至今保留华为官网链接）。第二阶段是校企联合实验室建设（2008年前后—2020年代初）：他负责复旦大学—谷歌 Android 实验室与复旦大学—Xilinx SDN 实验室两个平台，前者聚焦移动互联网应用开发与人才培养（其2012年获首届谷歌奖教金即与此相关），后者支撑了其团队在 SDN 流表更新、快速重路由等方向的 JSAC 系列成果，使其成为国内较早与全球头部 IT 厂商共建平台的网络学者。第三阶段是产研成果转化（2010年代至今）：与 CDN/边缘计算厂商网宿科技的合作成果获2023年度 CCF 科技进步二等奖；其主页链接的上海博达数据通信（网络设备厂商）、上海未来宽带中心（IPv6/宽带应用示范）等机构，亦是其 IPv6 家庭网络、网络编码数据分发等成果的产业合作方向。在科研项目层面，其主持的课题覆盖863计划（SDN 关键技术及应用、多核处理器路由器计算与缓存）、国家自然科学基金（分布式存储冗余编码性能优化、基于网络编码的新型路由技术）、上海市科委重大项目等，均具有鲜明的面向产业系统的特色。总体而言，其业界合作模式的独特性在于：以"编码理论+网络系统"为技术内核，以联合实验室与行业应用改造项目为载体，走"高校技术验证—企业场景落地"路线，与其早年华为工程师经历形成首尾呼应。

## 七、Connection圈层总结

综合来看，王新教授的关系网络呈现"学术谱系—实验室共同体—学院治理—产业生态"四层嵌套的结构。最内层是其师承与自建谱系：向上承接西电樊昌信（信息论/通信原理学派）与静冈大学 Mizuno 教授（移动计算学派）两条学术血脉，以及华为九十年代系统工程文化的"产业师承"；向下则通过 SONIC 实验室培养了邱堃（留校任空间互联网研究院助理研究员）、殷询、王燕、沈嘉杰等覆盖网络编码理论、存储编码、SDN、云存储的学生梯队。第二层是以赵进、徐跃东、周扬帆、陈阳等为核心的复旦同事合作圈——其中需特别澄清的是，徐跃东系香港中文大学博士出身的同事型深度合作者而非其学生——叠加李葆春、李宗鹏、Xiaoming Fu 等国际合作伙伴，构成其三十年学术产出的基本盘。第三层是学院治理网络：作为党委书记，他先后与姜育刚、杨珉、汪源源三任院长搭档，掌舵复旦计算机学科从传统院系向"计算与智能创新学院"实体化转型的关键五年，其信息化办公室主任的履历使其在学院数字化治理中具有独特的话语权。第四层是产业生态圈：从早年的华为工程师，到谷歌、Xilinx 联合实验室的建设者，再到与网宿科技合作获奖，其产业连接横跨通信设备、互联网平台与 CDN/边缘计算三代技术周期。这一网络格局的独特价值在于：王新是少数同时占据"西电信息论嫡系—日本移动计算博士—华为早期工程师—头部校企实验室建设者—学院党委书记"五重身份的国内网络学者，其圈层的枢纽性更多体现在治理与整合（学院转型、产研平台、学术共同体服务）而非单点学术声量。对于希望与之建立连接的学者或机构而言，网络编码与存储系统理论、SDN/空间互联网、AI for Networking 及校企联合实验室共建是最有效的切入通道；对于观察者而言，其网络中尚待补全的信息包括：多个代表性学生的确切学位归属与去向、两项省部级科技奖励的具体年份与完成人排序，以及计算与智能创新学院整合后 SONIC 实验室的组织形态变化，这些均已如实标注，供后续进一步查证。
