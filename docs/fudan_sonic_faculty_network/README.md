# 复旦大学网络与分布式计算团队（SONIC 实验室等）学术关系网络报告

## 团队简介

复旦大学计算机学科的网络与分布式计算方向以 SONIC 实验室（Self-Organizing Network and Information Coding Laboratory，后表述亦为 StOrage, Networking, and Intelligent Computing Laboratory）为核心载体之一，由王新教授负责，同时涵盖学院网络方向多位独立建组的教授。方向研究覆盖新一代互联网体系结构、无线与移动网络、数据中心网络、网络存储系统、网络编码、可编程网络与在网计算、边缘计算与分布式机器学习系统等，依托上海市智能信息处理重点实验室等平台，在 IEEE/ACM ToN、INFOCOM、SIGCOMM、NSDI 等网络与系统旗舰会议持续产出。

本报告聚焦两位代表性教师：王新（SONIC 实验室负责人，2021年起任计算机科学技术学院党委书记、2025年4月起任计算与智能创新学院党委书记，新一代互联网与网络编码方向的学科带头人）与徐扬（姚士华讲席教授，国家特聘青年专家，边缘计算与在网计算方向，复旦大学 SIGCOMM 长文纪录的缔造者——其团队连续四年（2023—2026）在 SIGCOMM 发表长文，2023年 BMW Tree 为复旦首篇 SIGCOMM 长文）。两位教授与徐跃东（Yuedong Xu，香港中文大学博士）等共同构成复旦网络方向的骨干梯队。

## 研究方向与圈层结构

方向学术网络呈四层结构。第一圈层是学院治理网络：王新作为学院党委书记，与院长汪源源（复旦大学副校长兼）、执行院长杨珉（详见 fudan_secsys 报告）共同领导2025年4月新成立的计算与智能创新学院，前院长姜育刚已于2023年12月升任复旦大学副校长（详见 fudan_fvl 报告）；网络方向与系统软件（彭鑫）、系统安全（杨珉/张源）等方向同处一个学院建制。第二圈层是师承与外部网络：王新出自西安电子科技大学樊昌信教授（IEEE Life Fellow、中国通信学会会士，中国信息论与纠错编码学科奠基人之一）门下，博士于日本静冈大学师从 Tadanori Mizuno 教授（移动计算学派），并有华为早期电信级视频会议系统与 DVB-S 系统的产业经历；徐扬本科毕业于北京邮电大学、博士毕业于清华大学（2007），入职复旦前任纽约大学坦登工程学院研究副教授，其清华网络研究背景连接北邮—清华通信网络谱系。第三圈层是学术共同体：徐扬担任 IWQoS 2026 程序共同主席、APNET 2025 大会共同主席，与国防科技大学郭得科教授等共同主持 CCF Computility 2025"分布式机器学习与在网计算"论坛，获 ACM CoNEXT 2022 最佳论文奖；王新曾任 CCF 互联网专委会副主任委员、上海市计算机学会网络专委会主任委员。第四圈层是产业网络：王新负责复旦—谷歌 Android 实验室与复旦—Xilinx SDN 实验室，与网宿科技等合作获 CCF 科技进步二等奖；徐扬团队与字节跳动（NSDI 2026 Medley 基于字节实测数据）、华为（网存算协同）等在分布式训练网络方向合作密切。

## 产业转化亮点

网络与分布式计算方向的产业转化紧扣"算力网络国家战略"：徐扬团队的在网计算与可编程调度成果（BMW Tree、InfiniFlow、Scale-up PIFO 等）直接面向大模型分布式训练的网络瓶颈问题，与字节跳动等企业的真实生产数据结合验证，是"学术顶会成果+产业实测"的典型范式；王新主导的 IPv6 家庭应用示范系统与网络编码加速技术面向新一代互联网基础设施，其谷歌 Android 实验室与 Xilinx SDN 实验室是复旦较早的校企联合平台样本。方向整体深度参与 CCF 算力网（Computility）共同体，是"东数西算"背景下算力网络研究的活跃学术力量。
