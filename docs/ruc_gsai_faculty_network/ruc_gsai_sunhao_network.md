## 一、学者基本信息

孙浩，现任中国人民大学高瓴人工智能学院副院长、长聘教授、博导，国家高层次青年人才。2010年本科毕业于河海大学工学专业，2011年获哥伦比亚大学硕士学位（M.S.），2013年获哥伦比亚大学哲学硕士学位（M.Phil.），2014年获哥伦比亚大学工程力学博士学位（Ph.D.）。2014至2017年在美国麻省理工学院（MIT）从事博士后研究，随后先后任美国匹兹堡大学终身序列助理教授（2017-2018）、美国东北大学终身序列助理教授（2018-2021），同时保留MIT兼职研究员（2017-2023）和东北大学兼职教授（2021-2023）身份。2021年全职加入中国人民大学高瓴人工智能学院任长聘副教授，2025年5月起任副院长，2025年8月晋升长聘教授。

研究方向为科学智能（AI for Science）与智能科学计算，具体包括物理信息人工智能、符号学习与推理、物理世界模型、智能全波反演、智能气象预报等前沿交叉方向。以第一/通讯作者在 Nature Machine Intelligence（2篇）、Nature Computational Science（封面文章）、Nature Communications（3篇）等国际一流期刊和 ICLR、NeurIPS、KDD、ICML、AAAI、IJCAI 等计算机顶会发表及录用论文70余篇，发表其他合作论文30余篇。主持国家高层次人才计划青年项目（300万人民币）、国家自然科学基金重大研究计划培育项目及面上项目、美国自然科学基金重点项目及面上项目等科研项目二十余项（共计3500余万元）。

荣誉方面，获2018年福布斯北美"30位30岁以下精英榜"（科学类）、2019年美国十大华人杰出青年、中国智能计算科技创新人物、AI100先锋青年等荣誉。

## 六、Connection 圈层总结

**第一圈层（核心学术伙伴）：Yang Liu（刘洋，中科院国科大，33次合作，2015年至今）。** 这是孙浩学术网络中最核心、最持久的合作关系，贯穿其从哥伦比亚博士阶段到人大教授的完整学术生涯。Yang Liu作为共同通讯作者出现在大量论文中，两人形成了"双核心"驱动模式——孙浩侧重AI算法与物理建模，Yang Liu侧重工程科学应用与计算验证。这种合作模式与赵鑫-文继荣的"双核心"模式有相似之处，但孙浩-Yang Liu的合作更偏向平等学术伙伴而非上下级关系。

**第二圈层（学院领导与平台支撑）：文继荣（23次合作，2021-2026）。** 作为人大高瓴人工智能学院执行院长，文继荣为孙浩提供了关键的学术平台和资源支持，两人在多篇文章中共同通讯，尤其在Nature子刊级别的重磅成果（如Nature Computational Science封面论文）中文继荣作为共同作者出现，体现了学院层面的战略协同。但与赵鑫案例中文继荣373次的极致绑定不同，孙浩与文继荣的合作频次（23次）更为适度，反映了孙浩作为相对独立的研究方向负责人（AI for Science）在学院中的定位。

**第三圈层（自主培养团队梯队）：** 王琦（19次）、任普（17次）、饶成平（14次）、万涵（12次）、阮恺（6次）等博士生和博士后构成了孙浩团队近年产出爆发式增长的直接贡献者。团队2025年产出35篇论文，较2022年的13篇增长近3倍，与2023-2024年入学的多名博士生进入科研产出期高度吻合。团队规模约20人（14名博士+3名硕士+2名博士后），较赵鑫AI Box团队（近50人）更为精干，研究方向更聚焦。

**第四圈层（华为产学研网络）：** 以刘洪升（12次）、张毅（10次）、王梓栋（10次）为代表的华为研究团队，构成了孙浩在产业界最密集的合作网络。2024-2025年间，华为研究人员参与了团队至少6篇顶会论文的联合发表，合作方向集中于AI加速PDE求解和流体仿真，体现了孙浩团队在"AI for Science"赛道上与华为的深度绑定。这种合作模式在本系列报告涉及的学者中具有独特性——赵鑫团队的产业合作以阿里巴巴和百度为主（大模型/信息检索方向），而孙浩团队的产业合作以华为为主（科学计算/物理仿真方向），反映了两位学者不同的研究赛道对产业生态的自然选择。

**第五圈层（博士导师与学术渊源）：Raimondo Betti（哥伦比亚大学）、Oral Buyukozturk（MIT）。** 两位导师分别为结构健康监测和基础设施感知领域的资深学者，为孙浩奠定了从工程力学到AI for Science的学科转型基础。孙浩的学术轨迹——从结构健康监测（哥伦比亚博士）到物理信息深度学习（MIT博士后）再到AI for Science（人大教授）——体现了"工程问题驱动→物理建模→AI算法创新"的清晰演进路径，这一路径的起点正是Betti和Buyukozturk的学术传承。

**跨学科合作网络：** 孙浩的学术网络呈现出显著的跨学科特征，合作者涵盖土木工程（Betti、Buyukozturk、Jian-Xun Wang）、物理学（Zhong-Yi Lu、Ze-Feng Gao）、气象学（Xiaoye Zhang、Xueshun Shen）、材料科学（Peng-Jie Guo）、计算机科学（Wenbing Huang、Chongxuan Li、Ruihua Song）等多个学科，这种跨学科网络是其AI for Science研究方向的必然产物，也使其在人大高瓴学院中扮演着连接AI与传统科学的桥梁角色。
