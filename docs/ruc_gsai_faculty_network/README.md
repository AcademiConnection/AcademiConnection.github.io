## 全院关系网络的整体观察

人大高瓴人工智能学院的师资网络呈现出几个较为清晰的结构性特征。

第一是"双核心"绑定现象。文继荣与赵鑫构成学院信息检索与大模型方向的双核心，二人合作论文数在全网络中遥遥领先，共同带动了学院在大语言模型领域的集中产出；类似的紧密师徒/同事绑定关系也出现在窦志成、宋睿华、徐君等人的团队中，多人早年均有微软亚洲研究院（MSRA）的工作经历，构成了一条贯穿多个教师关系网络的"MSRA校友线"，是学院产学研人脉的重要底色。

第二是学科交叉团队的聚集效应。祁琦、沈蔚然、王子贺、胡迪等人围绕计算经济学、博弈论与机器学习的交叉方向形成了紧密的小团体，彼此高频合作，构成了一个相对独立于信息检索主线的子网络。

第三是业界合作的高度集中性。全院教师的产业合作对象高度重合于阿里巴巴（达摩院、通义千问、阿里妈妈）、百度（文心团队）、华为（诺亚方舟实验室）、腾讯、字节跳动、快手、蚂蚁集团、智源研究院等头部机构，且呈现"人才培养—输送—反哺合作"的双向链路：大量毕业生进入这些企业的研究团队后，又与母校教师建立起持续的产学研合作关系，形成滚雪球式扩张的产业网络。

第四是重名消歧的普遍挑战。刘勇、张骁、孙浩、陈旭、祁琦、高欣等多位教师的英文姓名在 DBLP 上存在大量同名条目，报告撰写过程中均通过机构历史、研究方向、早期论文合作者等多重信息完成身份定位，个别学者（如潘云鹤院士、高欣讲座教授）因主体学术活动集中于本院之外的机构或年代早于 DBLP 索引完善期，报告采用了不同于标准方法论的框架呈现。

第五是类脑智能与 AI 治理的国际化桥梁。曾毅（自中科院自动化所加盟人大的确切时间未见官方披露，现列学院专任教师、吴玉章讲席教授）将类脑认知智能团队（BrainCog"智脉"生态）与 AI 伦理治理建制（北京前瞻人工智能安全与治理研究院院长、联合国 AI 高层顾问机构专家、首届 TIME 100/AI 思想者）一并带入学院，使高瓴在"技术—安全—治理"交叉方向的国际话语权显著增强，也构成学院与传统 NLP/检索主线并行的另一条研究主线。

## 数据来源与说明

各报告数据主要来源于 DBLP 官方作者记录、中国人民大学高瓴人工智能学院官网教师主页、Google Scholar、ORCID、AI Box 等实验室主页及公开报道。由于部分学者存在 DBLP 重名或多身份标识的情况，报告中的合作次数统计可能存在小幅误差；博士导师等未经学者本人公开确认的信息均基于早期论文合著模式与机构履历综合判断，如遇后续信息更新，请以学者本人官方发布为准。
