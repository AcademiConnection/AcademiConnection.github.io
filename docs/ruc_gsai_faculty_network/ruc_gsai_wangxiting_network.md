**研究方向：** 大模型的解释、对齐与评测（可解释、负责任的人工智能）。具体细分为：高普适性概念解释与神经元功能解读（稀疏自编码器 SAE、概念激活向量 CAV）、大模型价值观对齐（内部对齐 / 外部对齐）、跨学科的大模型能力评测（心理测量学方法）。
