## 一、学者基本信息

- 2020年9月至今，中国人民大学高瓴人工智能学院，长聘副教授

**学术影响力：** 据DBLP统计，其发表记录共202篇。发表学术论文100余篇（学院官网口径），申请专利30余项。曾获WWW 2004最佳论文提名奖（论文"Learning Block Importance Models for Web Pages"）、AIRS 2012最佳论文奖（"The Reusability of a Diversified Search Test Collection"）、CLSW 2019优秀论文奖（"Love is as Complex as Math": Metaphor Generation System for Social Chatbot）、2022年度教育部自然科学一等奖。曾任SIGIR短文和讲习班主席、ACL领域主席（Area Chair）、EMNLP资深领域主席（Senior Area Chair），以及Information Retrieval Journal主编。其算法完成了人类史上第一本人工智能创作的诗集《阳光失了玻璃窗》（微软小冰，2017年5月出版）。2021-2022年作为学术带头人，主导发布文澜（WenLan）系列多模态预训练大模型，成功落地快手、OPPO等企业产品；2023年参与发布"玉兰"（YuLan）系列大语言模型的研发。2024年，其团队获得华为开发者年度盛典"先锋项目奖"。

## 三、博士教育背景与导师/师承分析

### 3.1 本硕阶段（清华大学，1996-2003年）

宋睿华1996年考入清华大学计算机科学与技术系，2000年获学士学位后继续攻读硕士，2003年硕士毕业，导师为**马少平**教授（清华大学计算机系资深教授，人工智能与自然语言处理方向）。

### 3.2 博士阶段（上海交通大学，2006-2010年，"MSRA-高校联合培养"典型样本）

宋睿华于2003年4月硕士毕业后即加入微软亚洲研究院担任研究员，2006年9月至2010年12月在职攻读上海交通大学计算机系博士学位，2010年获博士学位。**其博士导师为两位——上海交通大学俞勇教授与微软亚洲研究院/微软全球资深副总裁洪小文（Hsiao-Wuen Hon）教授**，这是MSRA与国内顶尖高校联合培养博士的典型模式：学籍导师提供高校平台与学术训练规范，MSRA导师（通常兼具高校兼职教授身份）提供研究方向指导、计算资源与产业数据支持。

DBLP记录显示，俞勇教授与宋睿华合作7次（2007-2016年），洪小文合作6次（2007-2011年），合作年份集中在博士在读及毕业后数年。这一时期宋睿华的核心研究方向（个性化搜索、搜索结果多样化评测）已经与MSRA的信息检索团队（文继荣领导的互联网搜索与挖掘组）深度绑定，博士阶段的真正科研训练场域也在MSRA完成，与窦志成（"南开学籍、MSRA真正培养"）路径高度相似。

**洪小文（Hsiao-Wuen Hon）背景说明：** 洪小文历任微软亚洲研究院院长（2004-2007年代理、2007年后正式）、微软亚太研发集团主席、微软全球资深副总裁，是MSRA历史上任期最长的院长之一，也是宋睿华博士阶段之所以能够深度融入MSRA研究体系的关键人物。

### 3.3 MSRA真正的学术领路人——文继荣

尽管俞勇、洪小文是宋睿华官方认定的博士导师，但从DBLP合作频次看，**文继荣（Ji-Rong Wen）是宋睿华学术生涯中合作强度最高、持续时间最长的合作者（47次，2003-2026年，跨度23年从未中断）**。宋睿华2003年加入MSRA时，文继荣正是互联网搜索与数据挖掘组的核心负责人，宋睿华在该组从事个性化搜索方向研究，与彼时同组的窦志成（2005年以实习生身份加入该组）、马维英（时任MSRA常务副院长）构成了同一研究团队的核心班底。

这一现象与窦志成报告中所述"MSRA互联网搜索与挖掘组整建制迁移至人大高瓴"高度吻合：文继荣（组负责人，2013年离开MSRA加入人大）、窦志成（组内研究员，2014年加入人大）、宋睿华（组内主管研究员，2020年经微软小冰阶段后加入人大）三人先后从同一MSRA团队转投人大高瓴人工智能学院，是国内高校AI学科建设史上较为罕见的"团队整体迁移"案例。宋睿华与文继荣的合作跨越了MSRA时期（2003-2017年，搜索/挖掘方向）、微软小冰时期（合作趋缓）与人大高瓴时期（2020年至今，大模型/多模态方向）三个阶段，是全网络中唯一贯穿其全部职业生涯阶段的合作者。

### 5.2 微软小冰（Xiaoice）首席科学家：产品级AI技术的学术转化核心（2017-2020年）

2017年7月，宋睿华正式加入微软小冰团队并出任首席科学家，直至2020年8月（微软小冰已于2020年7月13日分拆为独立公司，由原CEO李笛领导），是微软小冰这一现象级AI产品在情感计算、内容生成方向的核心学术负责人之一。

**产品级技术与学术转化的代表性成果：**

- **AI作诗：** 主导研发的多模态文本生成技术支撑了小冰"AI作诗"能力，其算法完成了人类史上第一本完全由人工智能创作的诗集《阳光失了玻璃窗》（2017年5月出版，139首诗自数万首候选中精选，未经人工润色）。学术转化论文包括2018年"Image Inspired Poetry Generation in XiaoIce"（与谢幸、聂建云等合著）以及2019年"Evaluating Image-Inspired Poetry Generation"（NLPCC 2019）。
- **情感计算对话：** 小冰基于情感计算框架（Emotional Computing Framework）构建，强调情商优先于智商的交互设计理念（微软小冰负责人李笛主导的核心产品哲学）。学术层面对应论文包括2019年"Neural Response Generation with Relevant Emotions for Short Text Conversation"、2020年"What If Bots Feel Moods? Towards Controllable Retrieval-based Dialogue Systems with Emotion-Aware Transition Networks"（SIGIR 2020）。
- **隐喻生成：** 2019年"Love is as Complex as Math: Metaphor Generation System for Social Chatbot"获CLSW 2019优秀论文奖，将社交聊天机器人的修辞创作能力学术化、可评测化，第一作者郑丹宁与合作者周晋、胡天冉均为小冰团队成员。
- **音效检索：** 2019年"From Text to Sound: A Preliminary Study on Retrieving Sound Effects to Radio Stories"（SIGIR 2019），面向小冰"电台"类产品的音效自动匹配技术。
- **故事可视化：** 2019年"Neural Storyboard Artist: Visualizing Stories with Coherent Image Sequences"（ACM MM 2019，与刘倍、付建龙、金琴合作），是宋睿华后续多模态创作研究方向（TeViS、ScaMo等文本到视频分镜生成系列工作）的直接思想源头。

**小冰团队核心合作者（周晋，Jin Zhou）：** 周晋与宋睿华合作9次（2019-2022年），是微软小冰团队内部与宋睿华学术产出关联最紧密的同事，二人合作论文涵盖隐喻生成、剧本生成（ScriptWriter，2020年ACL，与窦志成、朱余韬合作完成）等方向，是学术研究与产品研发直接对接的典型案例。

**微软小冰独立化及后续：** 2020年7月13日，微软将小冰业务分拆为独立公司运营，由原微软全球执行副总裁沈向洋出任董事长，原微软（亚洲）互联网工程院副院长李笛出任CEO。宋睿华在分拆后一个月即离开小冰、加入中国人民大学，其职业转型时间点与小冰独立化事件高度吻合。小冰公司后续持续在AI聊天机器人、虚拟人、内容生成等方向产品化演进（如"半藏森林"数字克隆人产品），2025年李笛本人也已离开小冰公司另行创业（"明日新程"/Nextie项目），但宋睿华本人自2020年后未再有与小冰公司在职人员的DBLP可查合作记录，其技术传承体现为研究方向的延续（情感计算、多模态创作理念直接影响其人大团队的AIGC研究路线），而非持续性的合作关系。

### 5.3 华为：从产学研合作到"先锋项目奖"

宋睿华团队与华为的合作呈现从论文合作到官方技术奖项认可的递进关系：

- **Zhao Cao（曹朝）：** 与宋睿华合作3次（2022-2024年，代表论文"Multi-Modal Experience Inspired AI Creation"ACM MM 2022、"Going Beyond Closed Sets"PRCV 2023、"Understanding Human Preferences"WWW 2024）。曹朝在这些合作发生期间任华为泊松实验室（Poisson Lab）主任、华为云EI服务产品部首席架构师，2025年5月正式加盟人大高瓴人工智能学院任教授，这意味着宋睿华与华为的这一合作通道，未来将随曹朝的教职身份转化为校内同事合作。
- **Hao Jiang（江浩）：** 与宋睿华合作5次（2022-2026年），2024年WWW论文"Understanding Human Preferences: Towards More Personalized Video to Text Generation"的合作者之一，与曹朝同期出现在多篇论文中，推测同属华为相关团队或华为云合作项目。
- **2024年华为开发者年度盛典"先锋项目奖"：** 2024年12月14-15日，宋睿华团队在华为开发者年度盛典上荣获"先锋项目奖"，由团队博士生靳楚豪代表出席领奖并与业界嘉宾交流。该奖项旨在表彰对华为技术生态建设做出积极贡献、体现创新精神和实践价值的项目，是宋睿华团队产学研合作从论文层面上升至官方技术生态认可层面的标志性事件。

### 5.4 快手（Kuaishou）：文澜多模态大模型的落地伙伴与可灵团队合作

- **文澜3.0联合发布（2022年）：** 2022年北京智源大会期间，由文继荣领衔、中国人民大学24位师生组成的文澜团队与快手公司联合发布视频-文本多模态预训练大模型"文澜3.0"，基于千万级视频-文本数据训练，宋睿华作为文澜项目学术带头人之一深度参与该项目的对外合作与产品化推进。
- **Fuzheng Zhang / Di Zhang 0026 / Kun Gai（快手核心技术团队）：** 与宋睿华团队合作发表2篇代表性论文——2023年"Parrot: Enhancing Multi-Turn Chat Models by Learning to Ask Questions"（第一作者孙宇冲）、2024年正式发表版"Parrot: Enhancing Multi-Turn Instruction Following for Large Language Models"（ACL 2024）。三位合作者分别为快手大模型/推荐算法方向的资深技术负责人（Kun Gai即甘坤，曾任快手首席产品官/AI技术负责人）。
- **Ruiming Tang / Guorui Zhou（快手可灵/大模型团队）：** 2026年ACL论文"DPWriter: Reinforcement Learning with Diverse Planning Branching for Creative Writing"（第一作者曹倩）与二人合作完成，属团队最新的创造性写作强化学习研究，延续了与快手大模型团队的长期合作关系。

### 5.5 蚂蚁集团（Ant Group）：RAG与GUI Agent方向合作

- **Yanchu Guan / Dong Wang 0062 / Chenyi Zhuang / Jinjie Gu（蚂蚁集团）：** 2025年NLPCC论文"ReGA: Reasoning and Grounding Decoupled GUI Navigation Agents"（第一作者关楷斯，与孙宇冲共同完成），面向GUI导航智能体的推理与定位解耦方法，是团队在Agent方向与蚂蚁集团的直接合作成果。
- **Xiaojiang Liu / Peng Zhang / Meng Cao：** 2025年多篇音视频生成相关CoRR预印本（VSSFlow、Taming Text-to-Sounding Video Generation）合作者，据其署名模式推测为企业研究机构背景（具体机构未在公开渠道明确标注，需以论文机构标注为准）。

### 5.6 OPPO：文澜模型的无障碍应用落地

2021年文澜团队（智源悟道·文澜项目，文继荣领衔，宋睿华参与）与OPPO合作，基于文澜团队研发的双塔多模态预训练模型BriVL（Bridging Vision and Language），推出"无障碍图像功能"技术，成功落地OPPO手机的视障人士读图功能，是团队多模态大模型走向公益性产品化应用的代表性案例，也是宋睿华"多模态理解、创作和交互"研究方向直接服务社会价值的典型例证（与学院"智能而有温度"的育人理念相呼应）。

## 六、Connection圈层总结

**第一圈层（贯穿全职业生涯的学术领路人）：** 文继荣（47次，2003-2026年，跨度23年从未中断）——宋睿华学术生涯中唯一贯穿MSRA、微软小冰、人大高瓴三个阶段的合作者，也是"MSRA互联网搜索与挖掘组整体迁移至人大高瓴"现象中的核心枢纽人物。窦志成（26次）作为同一MSRA团队的另一支柱，与宋睿华构成"三人同源"的特殊学术关系。

**第二圈层（博士教育的双重导师）：** 俞勇（上海交通大学，7次）与洪小文（微软全球资深副总裁/前MSRA院长，6次）构成宋睿华博士阶段"高校学籍+MSRA科研训练"双轨培养模式的官方认定导师，与窦志成、赵鑫等本系列已查询学者的"MSRA系"培养路径高度相似，进一步印证了MSRA在2000-2015年间对中国信息检索/人工智能学术梯队建设的深远影响。

**第三圈层（现单位自主培养团队）：** 孙宇冲（24次）、吴弋涵（27次）、王希华（19次）、谈文卉（15次）、靳楚豪（14次）、曹倩（12次）、关楷斯（10次）等一批博士生，是宋睿华2020年加入人大后组建的多模态理解/创作/交互课题组核心成员，团队呈现"精专型"特征——不追求文继荣、赵鑫团队式的大规模产出，而是在音视频生成、具身智能、Agent、创造性写作等垂直方向持续深耕，2024年获华为"先锋项目奖"是团队产学研成果获官方认可的标志性事件。

**第四圈层（业界深度合作网络，本报告重点）：**
- **微软亚洲研究院**：14年任职经历塑造的终身学术根基，现役MSRA研究员Jianlong Fu（14次）、Bei Liu（13次）、Xing Xie（16次）持续合作至今，是"MSRA校友+现役同事"双重纽带保持最活跃的合作线；
- **微软小冰**：2017-2020年首席科学家经历，AI作诗（《阳光失了玻璃窗》）、情感计算对话是其学术生涯中产品级技术转化的巅峰代表，团队成员周晋（9次）是产学结合的直接纽带；
- **华为**：从曹朝（3次，泊松实验室原主任，2025年转任人大高瓴教授）的论文合作发展为2024年"先锋项目奖"的官方技术生态认可；
- **快手**：文澜3.0联合发布（2022年）与可灵/大模型团队（Fuzheng Zhang、Kun Gai、Ruiming Tang、Guorui Zhou）的持续论文合作，是多模态大模型技术落地的核心产业伙伴；
- **蚂蚁集团**：GUI Agent、RAG方向的新兴合作方向（2024-2025年）；
- **OPPO**：文澜模型无障碍读图功能的公益性落地案例。

**第五圈层（国际学术伙伴）：** Tetsuya Sakai（21次，早稻田大学，11年评测方向长期合作）、Jian-Yun Nie（17次，蒙特利尔大学，与人大高瓴多位学者共享的国际合作网络节点）、Shinji Watanabe（8次，CMU，近年语音处理方向新增合作）。

**产出规模与趋势：** 202篇发表记录中，2021年以后占比59.4%（120/202），2025年单年产出38篇为历史最高，2022-2026连续五年保持10篇以上，加速曲线与人大高瓴学院整体在生成式AI浪潮中的产出爆发高度吻合。合作者总数433人中，单次合作者198人（45.7%），覆盖SIGIR、ACL、CVPR、ICCV、NeurIPS、AAAI、ACM MM、WWW等信息检索、自然语言处理与多模态领域顶会的广泛协作网络。宋睿华的合作网络相较同系列已查询的文继荣、窦志成、赵鑫等"院长/学科带头人"级学者规模更为精简（433人 vs. 千余人级别），但产学研深度（尤其是首席科学家级别的产品经验）和研究方向的独特性（AIGC、情感计算、具身智能交叉）在本系列人大高瓴学者中具有鲜明的辨识度。
