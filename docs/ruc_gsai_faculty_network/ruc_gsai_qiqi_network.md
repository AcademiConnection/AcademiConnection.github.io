## 一、学者基本信息

祁琦（Qi Qi），女，中国人民大学高瓴人工智能学院长聘副教授、博士生导师，国家高层次人才青年专家，CCF中国计算机学会计算经济学专委秘书长。主要研究方向为AI+经济，涵盖算法博弈论、机制设计、在线广告、多智能体系统、大模型、运筹优化与智能决策，属于人工智能、优化和经济多个学科的交叉领域。

**教育经历：**
- 2002年9月—2003年7月，上海交通大学（后交换至香港城市大学）
- 2003年9月—2006年1月，香港城市大学计算数学系，学士
- 2006年2月—2008年1月，香港城市大学计算机系，硕士
- 2008年9月—2012年6月，美国斯坦福大学管理科学与工程系，博士（导师：叶荫宇教授）

**工作经历：**
- 2012年7月—2021年6月，香港科技大学工业工程及决策分析系，助理教授、博士生导师（获十佳教师奖）
- 2021年8月至今，中国人民大学高瓴人工智能学院，长聘副教授

**研究方向：** 博弈论与机制设计（在线广告：autobidding、生成式广告、广告排序、出价、归因、生态优化；平台经济：流量营销、用增、优惠券投放优化、联运、定价）、多智能体系统、大模型、运筹优化、智能决策、智慧治理。

## 三、博士教育背景与导师追溯

### 3.1 博士阶段（斯坦福大学，2008—2012年）

祁琦2008年进入斯坦福大学管理科学与工程系攻读博士学位，2012年获博士学位。官方主页明确记载其博士导师为**叶荫宇（Yinyu Ye）教授**。叶荫宇是斯坦福大学K.T. Li讲席教授、INFORMS会士，2009年获运筹学与管理科学领域最高荣誉——冯·诺依曼理论奖（John von Neumann Theory Prize），主要研究领域为数学规划、优化算法设计与分析、计算博弈/市场均衡。叶荫宇现为香港中文大学（深圳）数据科学学院特聘教授、上海交通大学智能计算研究院特聘教授。

### 3.2 博士期间DBLP记录与合作者

祁琦在斯坦福博士期间（2008—2012年）的DBLP记录显示，其合作者仍以香港城市大学时期的合作者为主——邓小铁（5篇）、卜天明（3篇）、Amin Saberi（2篇，斯坦福大学教授）。其中2012年发表于Operations Research的"On Algorithmic Solutions for Envy-Free Cake Cutting"（与邓小铁、Amin Saberi合作）是其博士期间的重要成果。Amin Saberi为斯坦福大学管理科学与工程系教授，该合作可确认其斯坦福学术网络的连接。

叶荫宇在DBLP中的共著记录出现于2020年之后（共7篇，2020—2026年），主题为Tarski不动点计算与超模博弈、Fisher市场均衡、LLM服务调度等。这表明博士导师关系在祁琦独立发展后以新的研究问题重新激活，而非贯穿全期的持续共著。

### 3.3 香港城市大学本科/硕士期的师承关系

祁琦2003—2008年在香港城市大学完成本科和硕士学习，其最早DBLP记录（2006年）即始于这一时期。在此阶段，**邓小铁**是其最核心的学术引路人。邓小铁当时任教于香港城市大学计算机系，研究方向为算法博弈论与互联网经济。两人自2007年起持续合作至2025年，共计31次，是祁琦全网络中合作频次最高的学者。

邓小铁现为北京大学前沿计算研究中心讲席教授、ACM/IEEE Fellow、欧洲科学院院士、北京大学多智能体研究中心主任。他在祁琦学术生涯中的角色可概括为：香港城大时期的直接指导者、博士期间及此后长期延续的核心合作者，两人的合作主题从早期的赞助搜索拍卖理论，经PPA完全性、资源分配机制，延伸至近年的竞赛理论与市场均衡设计。

### 3.4 早期合作者卜天明

卜天明（Tian-Ming Bu）在2006—2012年间与祁琦合作8篇，是早期仅次于邓小铁的第二核心合作者。两人合作主题集中于赞助搜索拍卖中的竞价策略、套利机会与前向纳什均衡。卜天明的机构归属在公开资料中未明确披露。

## 六、Connection圈层总结

**第一圈层——博士导师与早期师承：** 叶荫宇（7次，2020-2026年，斯坦福大学，冯·诺依曼理论奖得主）为官方确认的博士导师，其合作在祁琦独立发展后以Tarski不动点、Fisher市场、LLM调度等新问题重新激活。邓小铁（31次，2007-2025年，北京大学/前香港城市大学）是祁琦全网络中合作频次最高的学者，从香港城大本科/硕士期的直接指导者延续为长期合作者，构成其算法博弈论方向的学术根基。卜天明（8次，2006-2012年）是早期赞助搜索拍卖研究的第二核心合作者。

**第二圈层——博士生团队与学术延续：** 李维安（30次，2019-2026年，现为山东大学副教授）是祁琦团队中合作最密集的学生，毕业后持续大量共著，已成为事实上的核心学术伙伴。陈洲（12次，2017-2026年，现为东南大学副教授）为第二高频学生。王闻蔚（3次，现为阿里巴巴达摩院）和金耀楠（4次，华为天才少年）的毕业去向体现了学术向产业的输送通道。Ningyuan Li（12次，2022-2026年）等在读/青年合作者构成当前产出的执行层。

**第三圈层——人大高瓴校内"计算经济学"集群与交叉合作：** 沈蔚然（3次）、林衍凯（3次）、孙浩（4次）、魏哲巍（2次）、陈旭（2次）、徐君（2次）、张骁（2次）、文继荣（1次）构成校内合作网络。其中祁琦-沈蔚然-王子贺三人构成人大高瓴的"计算经济学"研究集群，共同组织研讨会、共同入选CCF计算经济学专委执行委员会。校内合作以LLM+博弈论交叉项目和推荐公平性为两个主要接口，频次不高但方向互补性强。

- **阿里巴巴/阿里妈妈**：Changyuan Yu（12次）、Yuchao Ma（11次）、Bingzhe Wang（10次）为核心通道，Jian Xu、Bo Zheng为阿里妈妈团队资深研究员。合作产出集中于AAAI、KDD、WWW、NeurIPS等顶会，主题为电商广告拍卖、autobidding、生成式广告、广告归因。
- **美团**：2024-2025科研合作最高奖，合作方向包括优惠券投放、流量营销、广告归因。Bingzhe Wang等为主要对接人。
- **百度**：机制设计框架应用于百度广告拍卖系统（提高约5%营收），研究成果已在百度落地。
- **字节跳动**：研究成果已落地，具体合作细节待进一步披露。
- **华为**：通过校内LLM项目（ICLR 2025）间接连接，Xiuqiang He为华为诺亚方舟实验室研究员。

- **两项美国专利**：在线广告方向，体现早期产学研转化能力。

**第五圈层——国际学术伙伴：** 斯坦福大学是国际合作的中心节点，Amin Saberi（3次，博士期间）、Devansh Jalota与Marco Pavone（各3次，2020-2023年）分别对应博士阶段和近年重启的斯坦福连接。Ron Lavi（以色列理工学院，2次）和Kazuo Iwama（京都大学，1次）为算法博弈论方向的 episodic 国际合作者。
