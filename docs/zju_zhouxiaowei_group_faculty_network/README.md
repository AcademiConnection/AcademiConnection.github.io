## 团队概况

周晓巍课题组（浙大3D Vision Group / zju3dv联合体）是CAD&CG全国重点实验室三维视觉方向的旗舰团队。周晓巍为浙大本科—港科大博士—宾大GRASP博士后路径的国际化研究者，2017年回国入选国家级青年项目，现为求是特聘教授，代表性工作包括 PVNet、DeepSnake、NeuralBody、NeuralRecon、LoFTR、Diffuman4D 等，其中 NeuralBody（CVPR 2021，学生彭思达一作）入选最佳论文候选、NeuralRecon（CVPR 2021，孙佳明一作）为Oral+最佳论文候选。

彭思达是周晓巍与鲍虎军共同指导的博士（2023年毕业），以博士期间 PVNet、Deep Snake、Neural Body 三大一作工作获2024 CCF优博与2022 Apple Scholar，毕业后直接留校任软件学院百人计划研究员，与周晓巍维持联合课题组（zju3dv）。其团队以 StreetWorld 平台与 OnSite 自动驾驶挑战赛第四赛道切入自动驾驶闭环仿真生态（吉利汽车、国创中心、NVIDIA等产业方）。

## 学术谱系概览

周晓巍的谱系特征是"非浙大博士的团队核心"：博士毕业于香港科技大学（导师待核实）、宾大GRASP博后，回国后与鲍虎军（浙江省自然科学奖一等奖共同完成人）、章国锋、崔兆鹏构成 zju3dv 平行协作网络。下游人才网络呈现"学术+创业"双通道：彭思达（留校任教）、孙佳明（LoFTR/NeuralRecon 一作，创办4DV.ai，曾任职商汤/DJI）为代表。

## 数据说明与勘误

1. **NeuralRecon第一作者更正（本轮最重要勘误）**：初稿及常见公开报道存在多种误传。经CVF官方bibtex与arXiv:2104.00681核实，NeuralRecon（CVPR 2021，Oral+最佳论文候选）第一作者为孙佳明（Jiaming Sun，作者列表：Jiaming Sun、Yiming Xie、Linghao Chen、Xiaowei Zhou、Hujun Bao），既非"Shichao Li"（初稿周晓巍报告的错误说法），也非彭思达（初稿彭思达报告将其误列为一作成果）。已在两份报告中统一更正，并在彭思达报告中加入显式澄清。
2. **DeepSnake第一作者更正**：DeepSnake（CVPR 2020，Oral）第一作者为彭思达（arXiv:2001.01629），初稿周晓巍报告误写为"Xingyi Li"，已更正；同时该论文已补入彭思达的博士期间三大一作代表作（取代误传的NeuralRecon与PVN3D）。
3. **PVN3D归属澄清**：PVN3D（CVPR 2020）为清华/阿里团队工作（第一作者Yisheng He），与彭思达无关，初稿据"主页一篇CVPR 2020 oral"推断将其列为彭思达一作成果属错误，已删除。
4. **彭思达履历修正**：其本科专业为信息工程（非计算机）；2023年6月答辩、2023年7月直接入职浙大软件学院，无ETH Zurich博士后阶段（"博后师从Marc Pollefeys"传闻无依据，个人主页时间线无缝衔接）；PVNet为CVPR 2019（非ICCV 2019）。
