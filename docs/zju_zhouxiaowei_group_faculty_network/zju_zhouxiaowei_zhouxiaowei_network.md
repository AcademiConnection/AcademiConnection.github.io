### 2.2 香港科技大学博士阶段（2013年毕业）

公开资料显示，周晓巍于2013年在香港科技大学获得博士学位。

### 2.3 宾夕法尼亚大学GRASP博士后阶段（2014—2017年）

CCF简介和百科资料显示，他于2014年至2017年在宾夕法尼亚大学GRASP机器人实验室从事博士后研究。

浙江大学英文主页称其曾任宾夕法尼亚大学计算机与信息科学领域博士后研究人员。

其间与Kostas Daniilidis、Menglong Zhu、Georgios Pavlakos、Spyridon Leonardos等共同发表研究。

例如《Multi-Image Matching via Fast Alternating Minimization》（ICCV 2015）由周晓巍、Menglong Zhu、Kostas Daniilidis署名。

论文可确认GRASP阶段合作网络，但未能直接证明Kostas Daniilidis是其博士后合作导师。

周晓巍的学术谱系可概括为“浙江大学本科—香港科技大学博士—宾夕法尼亚大学GRASP博士后—浙江大学任教”。

浙江大学本科与回归任教使其嵌入CAD&CG全国重点实验室和计算机学院的组织网络。

香港科技大学博士阶段提供跨区域视觉与图形学连接，但博士导师尚不能由现有材料确认。

GRASP博士后阶段形成以Kostas Daniilidis及多位合著者为代表的国际合作圈。

该圈层有论文署名支撑，但合著不被转换为师承关系。

在浙大内核圈层中，鲍虎军、章国锋与周晓巍通过CAD&CG平台、联合培养和省级奖项形成明确连接。

彭思达是已确认学生节点：由周晓巍与鲍虎军共同指导，毕业后留校任教并继续合作。

孙佳明连接图像匹配、商汤联合实验室经历与4DV.ai创业，但其正式学位师生关系为（待核实）。

沈泽宏、王源等合著者体现论文或主题关联，学生身份与去向均不能超出证据。

产业圈层以浙江大学—商汤联合研究、之江实验室协作和主页列示的企业应用为主要特征。

其中，省自然科学一等奖完成单位的组合提供了最清晰的产学研协作实证。

Apple Scholar是彭思达个人获得的学术荣誉，应与课题组企业合作区分。

整体结构呈现“实验室共同体为内核、三维视觉论文为骨架、国际博士后合作为外延、产业联合研究与应用为转化接口”的特征。

其优势在于几何视觉、深度学习、图形学表示与实际系统需求的交叉连接。

其边界在于不少公开材料仅证明合著或共同平台，无法证明具体师生、行政隶属或商业合作深度。
