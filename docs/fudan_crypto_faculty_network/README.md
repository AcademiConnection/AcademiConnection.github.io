# 复旦大学网络空间安全基础与前沿交叉方向（密码学、编码与区块链）学术关系网络报告

## 团队简介

复旦大学网络空间安全一级学科下设"网络空间安全基础与前沿交叉"方向，是学院理论色彩最浓的研究方向之一，涵盖密码学、编码理论、区块链技术、算法与计算复杂性、图论及其应用、人工智能基础理论等。方向现有教授3人、青年研究员1人、副教授4人、讲师1人，在编码与信息论顶级期刊 IEEE Transactions on Information Theory 上发表论文50余篇，承担国家重点研发计划、国家自然科学基金重点项目、863计划等课题；方向教师获海外优青、上海市领军人才、上海市优秀学术带头人、上海市东方学者、上海市曙光学者等人才项目。

方向的领军人物为阚海斌教授（二级教授、特聘教授），其学术足迹从复旦数学研究所的抽象代数传统（师从许永华教授）出发，经日本先端科学技术大学院大学（JAIST）任教时期，形成"密码学理论（安全布尔函数、编码网格表示、属性密码）+区块链工程（零知识证明、安全多方计算结合链上技术）"的双线格局。方向拥有两个省部级区块链平台：上海区块链工程技术研究中心（2018年11月获批，2024年6月上海市科委验收获"优秀"）与上海区块链与知识产权保护专业技术服务平台，并建有区块链虚拟仿真国家一流课程与区块链应用操作员评测机构。

本报告聚焦阚海斌教授（方向带头人，上海区块链工程技术研究中心主任），其个人报告完整呈现该方向的谱系、合作与产业网络。

## 研究方向与圈层结构

方向学术网络呈四层结构。第一圈层是复旦数学—密码学谱系：阚海斌师从复旦数学系原系主任许永华教授（抽象代数与本原环理论专家），承袭复旦代数传统转入密码学，与计算机学院算法方向的朱洪教授（计算复杂性）亦有长期合作，体现"数学所—计算机学科"的学科交叉路径。第二圈层是国际密码与编码网络：JAIST 时期与 Hong Shen 的密集合作（含两篇 IEEE-IT），以及与东京大学今井秀树（Hideki Imai）、巴黎八大 Sihem Mesnager、隆德大学 Thomas Johansson、香港大学韩光跃、纽卡斯尔大学 Feng Hao、哥伦比亚大学 Moti Yung 等国际密码学名家的论文合作网络。第三圈层是学生与同门网络：培养的学生包括张亮（现海南大学网安学院讲师）、袁晨（经南洋理工大学邢朝平二次读博后任上海交通大学长聘教轨副教授）、许扬（青年研究员、海外优青）等，形成复旦密码学向华东多校的学术扩散。第四圈层是校内协同：与杨珉/张源系统安全团队（S3L，详见 fudan_secsys 报告）、阚海斌兼任副主任的上海市智能信息处理重点实验室、以及多媒体安全团队（张新鹏/钱振兴）共同构成学院网络空间安全学科的三大支点。

## 产业转化亮点

方向产业转化以"区块链基础设施+行业落地"为主线：阚海斌作为第一完成人以"基于区块链与属性密码的数据存证、确权、共享交换技术及应用"获2022年上海市科技进步一等奖；其图论与组合优化成果应用于洋山四期自动化码头集装箱调度（带权二分图匹配建模）；上海区块链工程技术研究中心入驻徐汇"数链空间"并牵头区块链虚拟仿真国家一流课程与区块链应用操作员评测机构，构建了从理论研究、工程开发到职业技能认证的完整转化链条，是高校密码学团队参与上海数字经济基础设施建设的代表性样本。
