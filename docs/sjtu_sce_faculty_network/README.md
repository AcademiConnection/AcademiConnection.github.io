# 上海交通大学 可扩展计算研究所 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

可扩展计算研究所（Institute of Scalable Computing）是上海交通大学计算机学院下设研究所，现任所长为戚正伟长聘教授，副所长为蒋力、李健，成员含管海兵、顾小东、梁晓峣、刘方鑫、李希君、马汝辉、彭博、宋涛、宋卓然、姚建国等十余人，并依托上海市可扩展计算与系统重点实验室。从研究所名录沿革看，该所整合了原并行与分布计算研究所与体系结构方向的队伍（官方未明文表述重组过程），形成"虚拟化与云计算、可扩展智算系统、体系结构与EDA、处理器芯片架构"四大方向。它与陈海波领衔的 IPADS 实验室（并行与分布式系统研究所，见 [sjtu_ipads_faculty_network](../sjtu_ipads_faculty_network/)）为协作关系而非同一建制，共同构成交大计算机系统方向的"IPADS + 可扩展计算"协同格局。

研究所汇聚多位重量级学者：管海兵讲席教授（国家杰青、长江特聘、CCF会士，2024年8月起任上海交通大学副校长，曾获国家科技进步二等奖（2014年，第一完成人）与国家技术发明二等奖各一项，华为两代联合实验室校方负责人）、梁晓峣教授（哈佛博士、前英伟达资深架构师、ACCA 实验室主任、ISCA/MICRO 名人堂，昇腾 AI 处理器架构著作作者）、戚正伟（虚拟化与程序分析、GiantVM 系列）、蒋力（港中文博士，2021年起任华为首席研究专家，兼期智研究院）、李健（法国洛林理工博士，SDIC 研究组负责人，英特尔 QAT 十余年合作）。产学研网络触达华为、英特尔、燧原科技、壁仞、阿里等，开源成果进入 Linux、Xen、KVM 社区。

## 圈层结构概述

研究所内部网络呈现"双核+所长枢纽"结构：管海兵（副校长、学术最高资历）与梁晓峣（GPU体系结构旗帜）分别代表虚拟化/云计算与处理器芯片两条主线；戚正伟以所长身份承担组织枢纽，其 SDIC 相关研究与李健形成双导师搭档（SDIC 官网 faculty 页并列管海兵、李健）。学生谱系方面，管海兵团队的马汝辉、陈全等已成长为所内骨干，梁晓峣与燧原科技（张亚林等）通过 2022 年吴文俊芯片专项一等奖及联合实验室形成人才-产业双通道（注意：燧原创始人并非其学生，属研究所级合作）。跨机构合作以"国家队+产业巨头"为特征：与陈海波 IPADS 的多项国家级奖项联合完成人网络、与中科院计算所（韩银和/李晓维）的 HPCA 合作、与 CMU（Edmund Clarke 接待访学）、香港中文大学（蒋力母校）等国际节点。产业网络上，管海兵-华为（异构OS联合实验室、鲲鹏昇腾卓越中心）、李健-英特尔（QAT十余年）、蒋力-华为（在职首席研究专家）、梁晓峣-英伟达/昇腾（职业履历+著作）构成四个不同模式的产学研纽带。
