## 二、教育背景与职业履历

戚正伟于1995—1999年在西北工业大学飞机设计专业完成本科，1999—2002年在该校计算机软件与理论专业完成硕士；2002—2005年在上海交通大学计算机系攻读计算机软件与理论博士。学院当前教师页仅明确列出其上海交大博士阶段[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/qizhengwei.html)，其较完整的本硕阶段见电院历史英文资料[来源](https://yjwb.seiee.sjtu.edu.cn/english/detail/2129_968.htm)。公开一手资料未披露其博士学位导师，故不将共同论文作者或后续访问接待教师推定为博士导师。

其于2006年起在上海交通大学任讲师、副教授、教授；2008年任微软亚洲研究院访问教师；2011—2012年赴卡内基梅隆大学计算机系访学。历史资料表明该次访学由 Edmund M. Clarke 接待[来源](https://yjwb.seiee.sjtu.edu.cn/english/detail/2129_968.htm)，这属于访问期间的学术接待关系，并非其博士指导关系。现任可扩展计算研究所所长，承担研究所组织与学术方向协调职责[来源](https://www.cs.sjtu.edu.cn/jiaoshiml.html)。

## 五、业界合作关系深度分析

与**华为**的关联有可公开确认的成果和出版两层证据：其专著《深入浅出系统虚拟化：原理与实践》获2021年教育部—华为“智能基座”突出贡献奖，《数据中心虚拟化：原理与实践》由华为联合出版[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/qizhengwei.html)。这说明合作至少覆盖人才培养/教材与系统虚拟化知识传播；但教师页未披露戚正伟个人主持的华为横向项目，故不把研究所级合作直接归为其个人项目。

研究所官方介绍称，团队与华为、阿里、燧原、壁仞深度合作，部分成果被 Linux、Xen、KVM 等开源社区采用[来源](https://www.cs.sjtu.edu.cn/yjjg/818.html)。该信息可作为戚正伟担任所长期间的研究所生态背景；它并不逐项说明由戚正伟本人负责，报告中应严格区分“研究所级合作”和“个人可证实合作”。

关于**英特尔**：本次可获取的教师页、研究所页和学校新闻未提供戚正伟与英特尔开展项目合作的直接证据。因此不确认该线索。关于**IBM**，其著作曾获 IBM 出版计划资助[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/qizhengwei.html)，这是出版支持关系，不等同于研发或横向项目合作。

## 七、Connection圈层总结

**第一圈层：直接培养与核心研究协作。** 有明确导师证据的节点为博士生汪沄；围绕 GiantVM、GPU/FPGA 虚拟化形成的张进、贾兴国、余博识、管海兵等作者群是核心论文协作圈，但应避免将其一概视作学生。

**第二圈层：研究所同事与组织协同。** 戚正伟以所长身份连接可扩展计算研究所的虚拟化、智算、芯片架构和软硬协同研究方向。管海兵是同时具备机构同事与多篇论文合作证据的强连接；蒋力等成员则主要为共同机构节点。

**第三圈层：跨机构和国际学术网络。** Bingsheng He、Xue Liu、Baris Kasikci 分别通过 GPU 虚拟化、Android 审计、FPGA Hypervisor 论文形成可追溯的合作关系；CMU/Edmund M. Clarke 则代表访学接待和国际交流链路。

**第四圈层：产业与开源生态。** 个人层面可直接确认华为联合出版及教育项目荣誉、微软亚洲研究院访问经历和 IBM 出版资助；研究所层面与华为、阿里、燧原、壁仞及 Linux/Xen/KVM 社区存在合作与成果采用。英特尔合作及戚正伟博士导师均属公开资料未披露事项。
