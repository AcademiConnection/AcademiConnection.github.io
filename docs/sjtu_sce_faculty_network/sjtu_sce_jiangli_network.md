## 二、教育背景与职业履历

蒋力于2003年9月—2007年7月在上海交通大学获计算机科学与技术学士学位；2008年8月—2010年7月在香港中文大学获计算机科学与工程 MPhil；2010年11月—2013年10月在香港中文大学取得计算机系统结构博士学位[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/jiangli.html)。因此，用户线索中的“中国科学技术大学教育背景”不获当前官方履历支持；其博士授予单位为香港中文大学而非上海交通大学。公开教师页及个人主页没有披露博士导师姓名，不能依据论文合作者推定导师。

他于2012—2013年在杜克大学任访问学者，2014—2017年任上海交通大学计算机科学与工程系讲师，2017—2024年任副教授，2024年起任上海交通大学计算机学院研究员[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/jiangli.html)。因此“副教授/长聘教轨”是其历史职称线索，其中“副教授”在2017—2024年得到官方履历支持；截至本报告资料的现任职称应写为“研究员”，公开资料未将其标为“长聘教轨”。

同时，他自2020年起任上海期智研究院高性能计算杰出科学家，自2021年起在华为任异构通信处理器科学家、高级研究专家（首席）[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/jiangli.html)。学院英文教师页进一步称其为华为数据通信处理器实验室主任、通信处理器关键技术高级专家/首席科学家[来源](https://cs.sjtu.edu.cn/en/jiaoshiml/jiangli.html)，构成稳定的产学双向身份连接。

## 五、业界合作关系深度分析

蒋力的产业关系具备个人层面的直接任职与项目证据。其官方履历显示自2021年起在**华为技术有限公司**任异构通信处理器科学家、高级研究专家（首席）；英文教师页补充其任华为数据通信处理器实验室主任[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/jiangli.html) [来源](https://cs.sjtu.edu.cn/en/jiaoshiml/jiangli.html)。因此，华为不仅是论文或资助对象，更是其长期产业任职节点。用户提供的智能网卡/DPU、RDMA 线索与该通信处理器角色具有主题相关性，但本次查得的一手页面未把其研究直接定名为 RDMA 或 DPU，报告不将此作为已证实的个人代表方向。

学院教师页称他承担二十余项国家、省部级及与**华为、阿里云**的横向课题，多项技术落地应用；英文教师页还列出**蚂蚁集团、中兴通讯**，并称部分技术已在产品线部署或评测[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/jiangli.html) [来源](https://cs.sjtu.edu.cn/en/jiaoshiml/jiangli.html)。其 3D IC 测试架构被纳入 IEEE P1838 标准；神经网络压缩技术被应用于国内首家量产存算一体芯片；若干技术在华为、阿里巴巴产品线测试或大规模试用[来源](https://www.cs.sjtu.edu.cn/jiaoshiml/jiangli.html)。这构成从标准、芯片到产品验证的多层次转化链。

研究所层面还与华为、阿里、燧原、壁仞深度合作[来源](https://www.cs.sjtu.edu.cn/yjjg/818.html)。这可解释蒋力所处的产业生态，但除其个人履历明确列出的企业外，不应推断其个人直接负责所有研究所合作。关于**字节跳动**合作，当前一手教师页、个人主页和官方新闻未给出直接项目证据；关于**达摩院青橙奖**，其官方获奖列表未列该奖，故不予确认。

## 七、Connection圈层总结

**第一圈层：直接培养与高频课题协作。** 汪宗武是有官方新闻明确支持的联合指导博士生；刘方鑫、郝敏、宁杨、黄时远、汪宗武等构成以论文为证的高频合作群。必须区分：只有汪宗武的联合指导关系获直接公开表述，其余主要为论文或项目协作。

**第二圈层：研究所内部协同。** 蒋力以副所长身份嵌入可扩展计算研究所的体系结构、EDA、AI 加速与软硬芯协同方向。刘方鑫和管海兵同时具备同所与持续共同署名证据，是较强的内部连接；戚正伟等同事则以研究所组织关系为主。

**第三圈层：跨校及国际学术网络。** CUHK 的 MPhil/博士训练和杜克访问经历构成跨境学术流动节点；何哲陟的联合指导和多位外部作者的共同论文构成面向 ReRAM、PIM、神经渲染与芯片设计的课题网络。

**第四圈层：产业—标准—产品转化。** 华为是最强个人产业节点，兼具任职、通信处理器实验室职责和横向课题；阿里云、蚂蚁集团、中兴通讯则有项目合作证据。IEEE P1838 标准采纳、量产存算一体芯片应用和产品线测试将其关系网络从企业合作延展至标准与产业化。字节跳动合作、RDMA/DPU 为核心个人研究方向、达摩院青橙奖，以及博士导师姓名，均属当前公开一手资料未披露或未支持事项。
