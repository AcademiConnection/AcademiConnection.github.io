## 四、学术合作网络

### 4.1 Kozyrakis 师承关系

Christos Kozyrakis 是 Delimitrou 的博士导师，也是她学术生涯中最核心的合作者。两人的合作关系从 Stanford 博士期间开始，并在 Delimitrou 独立后持续延续。

#### 4.1.1 Kozyrakis 简介

Christoforos (Christos) Kozyrakis 是 Stanford University 电气工程与计算机科学系教授，Computer Systems Laboratory (CSL) 成员。他于 2002 年在 UC Berkeley 获得博士学位，导师为 David A. Patterson（图灵奖得主）。Kozyrakis 的研究方向涵盖计算机体系结构、云计算系统、事务内存、硬件安全等。

#### 4.1.2 Kozyrakis-Delimitrou 合作论文

两人在 Stanford 期间（及 Delimitrou 加入 Cornell 后的过渡期）合作发表了多篇高影响力论文：

| 论文 | 会议/年份 | 简介 |
|------|-----------|------|
| Paragon: QoS-Aware Scheduling for Heterogeneous Datacenters | ASPLOS 2013 | 异构数据中心的 QoS 感知调度器，获 ASPLOS'24 Influential Paper Award |
| Quasar: Resource-Efficient and QoS-Aware Cluster Management | ASPLOS 2014 | 利用推荐系统思想进行集群资源管理 |
| HCloud: Resource-Efficient Provisioning in Shared Cloud Systems | ASPLOS 2016 | 混合云资源供给系统 |
| Bolt: I Know What You Did Last Summer... In the Cloud | ASPLOS 2017 | 云计算安全审计系统 |

**合作关系深度：★★★★★（最核心工业合作伙伴）**

Delimitrou 与 Google 的合作关系最为持久和多维：

### 圈层特征总结

Christina Delimitrou 的学术关系网络呈现出"**一个核心、两个延伸、多重工业界桥梁**"的结构：

1. **一个核心**：以 Kozyrakis 师承关系为核心，通过 Patterson→Kozyrakis→Delimitrou 的学术谱系，深植于计算机体系结构领域最具影响力的学术传统
2. **两个延伸**：
   - 向上延伸至同门师兄妹（Sanchez、Belay 等在 MIT 形成 MAST Lab 校友聚集）
   - 向下延伸至自己培养的 SAIL 实验室学生群体
3. **多重工业界桥梁**：与 Google、Microsoft、Intel、Facebook、Amazon 等六大科技公司建立了深度的资助、研究和人才输送关系，是学术界与工业界之间罕见的"超级连接者"

从 Stanford 博士生到 Cornell 独立 PI 再到 MIT 副教授，Delimitrou 的学术网络不断扩展，从单一的师承关系发展为涵盖学术界同门、独立培养学生、多维工业界合作的完整学术生态系统。她的经历是 Stanford MAST Lab 学术家族"学术传承+工业落地"模式的典型代表。
