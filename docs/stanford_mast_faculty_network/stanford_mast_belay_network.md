## 四、学术合作网络

### 4.1 Kozyrakis 师承关系及持续合作

Adam Belay 与博士导师 Christos Kozyrakis 之间不仅存在师生传承关系，在 Belay 加入 MIT 后仍保持着活跃的学术合作：

- **Shinjuku** (NSDI 2019)：Belay 与 Kozyrakis、David Mazières 联合发表的微秒级抢占式调度系统论文。Shinjuku 的代码托管在 [github.com/stanford-mast/shinjuku](https://github.com/stanford-mast/shinjuku)，明确标注了 Stanford MAST Lab 的归属，体现了 Belay 作为 MAST Lab 校友与母实验室的持续纽带。
- **IX 操作系统** (OSDI 2014, Best Paper / TOCS 2016)：Belay 博士期间的核心工作，与 Kozyrakis 及 Edouard Bugnion 联合完成。IX 重新设计了数据中心操作系统的数据面抽象，实现了低延迟、高吞吐和强保护的统一。
- **Dune** (OSDI 2012)：Belay 博士早期工作，与 Kozyrakis、David Mazières 等联合发表，利用硬件虚拟化扩展为用户态提供安全的特权 CPU 特性访问。

此外，Kozyrakis 的在读学生 Kostis Kaffes 作为 Shinjuku 的第一作者，与 Belay 形成了"师弟-师兄"式的跨机构合作，进一步巩固了 Stanford MAST Lab 与 MIT PDOS 之间的学术桥梁。

## 五、业界合作关系深度分析

### 5.1 Google

Adam Belay 与 Google 有着深厚的渊源。在 2016 年获得 Stanford 博士学位后，他曾加入 Google 工作了约一年，从事数据中心网络相关的研发工作，随后才正式加入 MIT 担任教职。这段工业界经历深刻影响了他在 MIT 的研究方向，使其系统研究始终与数据中心的实际需求保持紧密联系。

- **研究资助**：Belay 获得了 Google 颁发的研究奖（Research Award），体现了 Google 对其研究方向的持续关注和支持。
- **人才输送**：其博士生 Inho Cho (PhD 2023) 毕业后加入 Google 担任软件工程师，延续了 MIT-Google 的人才通道。
- **研究方向关联**：Belay 在 Google 期间从事的数据中心网络工作，直接启发了他后来在 MIT 的 Shenango（微秒级 CPU 调度）、Caladan（干扰消除）和 Junction（内核旁路）等研究项目，这些项目均聚焦于数据中心环境的性能优化。

### 5.2 Microsoft / Microsoft Research

Belay 与 Microsoft 的合作关系尤为密切，涉及多个层面：

- **Microsoft Research (MSR) 深度合作**：Belay 与 MSR 的多位研究员保持着长期、系统性的合作关系。Íñigo Goiri、Rodrigo Fonseca、Esha Choukse 和 Sameh Elnikety 作为 MSR 的研究员，与 Belay 联合发表了 Junction (NSDI 2024) 和 Compound AI Systems (HotOS 2025) 等重要论文。Ricardo Bianchini（MSR，同时在 Microsoft 任职）也是 Compound AI Systems 论文的合作者。这种合作模式表明 Belay 的研究得到了 Microsoft Research 的直接关注和资源投入。
- **人才输送**：其博士生 Jonathan Behrens (PhD 2022) 毕业后加入 Microsoft，在 Azure Linux 团队担任高级工程师，从事 Linux 内核的工程化开发。Azure Linux（原名 CBL-Mariner）是 Microsoft 为 Azure 云平台定制的 Linux 发行版，Behrens 的工作将 Belay 研究组在操作系统安全方面的成果（如 Ward、TEA 等应对瞬态执行攻击的工作）与 Microsoft 的云基础设施需求结合了起来。
- **PDOS 组的 Microsoft 资助**：MIT PDOS 组在主页上明确感谢了包括 Microsoft（通过 MSR 的研究资助）在内的多家企业的支持。

### 5.3 Meta (Facebook)

Belay 获得了 Meta（原 Facebook）颁发的研究奖（Research Award）。Meta 作为全球最大的数据中心运营商之一，其云计算基础设施对操作系统和网络系统的研究有着直接需求。Belay 在微秒级调度、内核旁路和云计算资源管理方面的研究与 Meta 的数据中心优化目标高度契合。

### 5.4 量化金融行业

Belay 培养的学生在量化金融领域有着显著的布局：
- **Zain Ruan** (PhD 2024) 加入 Renaissance Technologies 担任系统分析研究员。Renaissance Technologies 是全球最顶尖的量化对冲基金之一，对低延迟系统和高性能计算有极高要求。Ruan 在 Belay 组期间从事了 Nu (NSDI 2023) 和 Quicksand 等微秒级资源管理研究，这些技能直接适用于量化交易系统。

这一去向模式表明，Belay 培养的系统研究训练（尤其是微秒级延迟优化、CPU 调度和网络系统）在量化金融行业具有高度竞争力。

### 5.5 清洁能源云计算

- **Lana Honcharuk** (本科 2024) 加入 Crusoe 担任软件工程师。Crusoe 是一家专注于利用伴生气（stranded natural gas）进行清洁能源云计算的初创公司，其商业模式与 Belay 参与的 Treehouse (HotCarbon 2022) 论文中关于碳感知数据中心软件的研究理念相呼应。

### 5.6 开源软件与产业影响

Belay 领导开发的多个系统软件项目已开源并在工业界产生了实际影响：

| 项目 | GitHub | 技术领域 | 产业影响 |
|------|--------|---------|---------|
| **Junction** | [github.com/JunctionOS/junction](https://github.com/JunctionOS/junction) | 内核旁路技术，使未修改的 Linux 二进制程序获得内核旁路性能 | 面向云工作负载的通用网络加速 |
| **Caladan** | [github.com/shenango/caladan](https://github.com/shenango/caladan) | 干扰感知的 CPU 调度，消除"吵闹邻居"问题 | 数据中心多租户隔离 |
