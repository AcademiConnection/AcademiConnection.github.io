# 中国科学技术大学 网络空间安全学院教师学术关系网络报告

> 报告生成时间：2026年8月26日

## 团队简介

中国科学技术大学网络空间安全学院成立于 2017 年 8 月，依托信息科学技术学院建制，2016 年即获批网络空间安全一级学科博士学位授权点，是我国网络空间安全人才培养与科研的重镇。学院现任领导层为：党总支书记谭勇，执行院长林璟锵（2025 年 4 月起；俞能海教授在 2017/2018 年至 2024 年间长期担任执行院长；据校党委组织部 2025 年 6 月任免通知，其已不再担任信息与智能学部副部长职务），副院长张卫明、陈彦，院长助理刘斌。学院与中国科大-耶鲁大学可信软件联合实验室、深信服联合实验室（俞能海任主任）、数字安全安徽省重点实验室等平台深度关联，并牵头参与教育部网络空间安全实战能力人才培养（"网安人才评价白皮书"相关）等国家级教育工程。

本报告系列覆盖学院两条主线上的五位代表性教师：一是俞能海—张卫明领导的多媒体内容安全团队（信息处理中心 IPC 与智能认知安全实验室 AICS Lab，及俞能海领导的视觉智能与安全课题组 VIS），以信息隐藏、深伪检测、AIGC 安全与合成现实技术闻名；二是林璟锵代表的系统安全与密码应用方向（源于中科院信息工程研究所冯登国/荆继武谱系）。标志性成果包括：2020 年 Facebook/Microsoft 深伪检测挑战赛（DFDC）全球亚军（2265 支队伍、30 万美元奖金，中国队伍最好成绩）、ACM IH&MMSec 2018 最佳学生论文奖、ACM CCS 2024 Distinguished Artifact Award（GenderCARE）、"合成现实数字人钱学森"（央视级标杆应用）、抗屏摄水印溯源系统（落地中电科、中金所、国家电网）等。

## 研究方向与圈层结构概述

学院报告覆盖的网络呈"双主线、三谱系"结构。第一条主线是多媒体内容安全：俞能海（南邮→清华→中科大博士的工科复合路径）自 1990 年代起经营多媒体信号处理，2000 年代后转向信息安全，形成 IPC（信息处理中心）—AICS Lab（俞能海、张卫明共同负责）—VIS（视觉智能与安全）三层课题组体系；张卫明以"解放军信息工程大学密码学—上海大学信息隐藏（张新鹏学派）"复合路径于 2013 年加入，与俞能海构成二十年"双导师制"联合培养轴心，输出陈可江（副教授）、周文柏（副教授）、王垚飞（合工大副教授）、方晗（NUS Research Fellow）等代表毕业生，其中陈可江、周文柏、俞能海、张卫明构成 CCS 2024 GenderCARE、DFDC 亚军、合成现实数字人等标志性成果的核心署名组合，并与新加坡 A*STAR 张杰、NUS Ee-Chien Chang 形成稳定的境外合作带。第二条主线是系统安全与密码应用：林璟锵出自中科院信息工程研究所（硕士导师冯登国、博士导师荆继武），2020 年由信工所研究员转任中科大教授，2025 年出任执行院长，代表学院与国家级密码研究建制（信息安全国家重点实验室、商用密码检测体系）及产业界（蔚来联合实验室、三未信安独立董事经历）的连接。

圈层结构上，核心圈是俞能海—张卫明"压阵双导师 + 中生代带队（陈可江、周文柏、刘斌、储琪）+ 博士生执行"的梯队；学术圈辐射 MSRA 铸星计划（周文柏、储琪、连德富式通道）、A*STAR、NUS、港中文 MMLab/城大廖菁及国内安全共同体（中国网络空间安全学会、CSIG 数字媒体取证与安全专委会、金融密码杯等）；产业圈以合肥高维数据（校友田辉创办，抗屏摄水印溯源系统产业化载体）、周文柏创办的合肥艾达纪元（合成现实成果作价入股，2026 年完成种子轮融资）、灵境赛博（数字人落地）、深信服（联合实验室）为代表性节点，形成"技术授权 + 成果作价入股 + 竞赛声誉型转化"并存的产学研生态；公共影响圈则以"数字人钱学森"（中关村论坛、央视科技创新盛典）与网安人才白皮书、行业校友会为外延。

## 产业转化亮点

学院产业化路径呈现三种形态。其一是成果作价入股创业：2025 年"基于合成现实技术的新质数字资产构建与保护"成果经中科大资产处公示作价转化（约 204 万元），受让主体为周文柏创办的合肥艾达纪元科技有限公司（周文柏持股 29.5%、俞能海 20%、张卫明 7%），2026 年 1 月完成种子轮融资（同创伟业领投，合肥产投、科大硅谷跟投），是"高校教授持股 + 青年教师操盘"的新样本。其二是技术系统落地：张卫明团队的抗屏摄水印溯源系统经合肥高维数据产业化，应用于中电科、中金所、国家电网等单位，获工信部网络安全技术应用试点示范项目与国家网安宣传周创新产品优秀奖（第一名）。其三是标杆应用与声誉转化：合成现实数字人钱学森（与灵境赛博合作，跨界语音团队凌震华等）、《英雄联盟：双城之战2》面部年轻化技术应用、DeepFaceLab 开源工具（GitHub 46k+ stars，与 GPT-2 同列 2020 年十大 GitHub 流行 Python 项目），构成"攻防一体"的国际技术品牌。
