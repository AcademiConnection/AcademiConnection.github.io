## 一、学者基本信息

陈海波，1982年11月出生于湖南省邵阳市，上海交通大学特聘教授、校务委员会委员，并行与分布式系统研究所（IPADS）所长，领域操作系统教育部工程研究中心主任，人工智能操作系统研究院院长。同时担任华为Fellow、华为基础软件首席科学家。陈海波是中国计算机系统领域最具国际影响力的学者之一，其研究成果通过产学研深度结合被应用到数十亿设备，在操作系统、分布式系统与系统安全领域产生了广泛的学术与产业影响。按照csrankings.org的统计，其近十年在操作系统领域顶会SOSP/OSDI上发表的论文数居世界第一。

## 二、教育背景与职业履历

### 2.1 教育背景

陈海波的本硕博均就读于复旦大学，博士导师为臧斌宇教授（Binyu Zang），这一师生关系已在其个人主页明确记载。臧斌宇教授后也加入上海交通大学软件学院，现任IPADS研究所教授，与陈海波形成了长期的学术搭档关系。

2000年9月，陈海波进入复旦大学计算机科学与技术专业本科学习，2004年7月获得学士学位（计算机软件与理论方向）。随后继续在复旦大学攻读计算机系统结构专业博士学位，师从臧斌宇教授，2009年1月获得博士学位，其博士论文荣获2011年全国优秀博士学位论文奖（CCF优秀博士论文奖，2009年）。

### 2.2 职业履历

陈海波的职业轨迹呈现出从复旦到交大、从学术到产学研深度融合的特征。2009年4月至2011年12月，他在复旦大学担任讲师。期间，2011年3月至6月，他以访问科学家身份赴麻省理工学院（MIT）PDOS实验室/CSAIL进行短期访问，合作者为Frans Kaashoek教授（ACM Fellow、美国工程院院士）。此前，2008年1月至6月，他曾在微软亚洲研究院（MSRA）担任研究实习生，导师为Frans Kaashoek教授；2008年8月至11月，在VMware公司担任技术实习生。

2011年12月（一说2011年9月），陈海波加入上海交通大学软件学院，被聘为教授、博士生导师，时年29岁，是当时交大最年轻的教授之一。此后他历任长聘教授、特聘教授。2015年8月至2016年2月，他赴新加坡国立大学（NUS）担任访问教授。

约2017年初，陈海波开始与华为建立深度合作关系，加入华为担任操作系统内核实验室主任、首席科学家，后晋升为华为Fellow、华为基础软件首席科学家。这一身份使其同时横跨学术界与产业界，成为中国操作系统产学研结合的核心人物。值得注意的是，陈海波在加入华为后仍保留上海交通大学教职，以"双重身份"推动学术研究与产业落地的双向转化。

## 四、学术合作网络

### 4.1 IPADS内部合作

IPADS实验室内部形成了高度紧密的合作网络，陈海波作为实验室所长，几乎参与了实验室绝大多数论文的指导工作。从论文署名模式来看，陈海波通常作为通讯作者或最后一位作者出现，体现了其作为实验室学术领导者的角色。

与陈榕的合作是IPADS内部最重要的学术搭档关系之一。两人合作发表了大量分布式系统方向的论文，涵盖RDMA分布式事务处理（SOSP 2015最佳论文级工作）、分布式图计算（EuroSys 2015最佳论文PowerLyra）、RDMA键值存储（OSDI 2020、OSDI 2018）等。陈榕在分布式系统性能优化方面提供了核心技术贡献，陈海波则在系统架构设计和战略方向上提供指导。

与夏虞斌的合作主要体现在操作系统方向，包括安全虚拟化（ISCA 2015）、机密计算（OSDI 2021的PENGLAI安全飞地）等。两人还合著了操作系统教材。

与臧斌宇的合作贯穿了陈海波的整个学术生涯。从复旦大学时期开始，臧斌宇作为陈海波的导师，在虚拟化安全（SOSP 2011 CloudVisor）等早期工作中发挥了关键指导作用。臧斌宇加入交大后，两人形成了"导师-学生"到"同事-合作者"的转型，共同指导了大量学生。在博士答辩中，臧斌宇经常作为导师出现，而陈海波团队的教师（如陈榕、夏虞斌、糜泽羽）则担任答辩委员会委员，体现了IPADS内部联合指导的常态化模式。

与年轻一代教师的合作中，魏星达在RDMA和Serverless计算方向、古金宇在微内核和安全方向、糜泽羽在系统安全和PowerInfer方向、杜冬冬在Serverless和系统安全方向，均与陈海波保持了高频合作。从近年论文来看，这些年轻教师已开始作为通讯作者或独立指导学生，陈海波则更多承担战略性指导角色。

## 五、业界合作关系深度分析

陈海波在产业界的合作深度在中国计算机学术界极为罕见。他不仅在学术上保持高产，更将研究成果大规模推向产业落地，形成了"学术研究-技术转化-产业部署-反馈驱动新研究"的良性循环。

### 5.1 与华为的合作（核心产业关系）

陈海波与华为的合作是其产业关系的核心，也是中国产学研结合最具代表性的案例之一。

**合作起源与时间线：** 据公开报道，陈海波约在2017年初开始与华为建立正式合作关系，加入华为担任操作系统内核实验室主任、首席科学家。彼时华为尚未遭遇美国制裁，但已开始布局自主操作系统。陈海波的加入为华为操作系统研发提供了关键的学术支撑。此后，他逐步晋升为华为Fellow（华为最高技术荣誉）和华为基础软件首席科学家，同时保留上海交通大学教职。

**OpenHarmony（开源鸿蒙）：** 这是陈海波与华为合作的最重要成果。2020年9月，华为将智能终端操作系统基础能力代码捐赠给开放原子开源基金会，命名为OpenAtom OpenHarmony。陈海波担任OpenHarmony项目群技术指导委员会（TSC）创始主席，负责技术方向的总体把控。在他的领导下，OpenHarmony从零起步，截至2025年9月已汇聚超过9200名社区贡献者，累计贡献代码逾1.3亿行，推出70多个行业发行版，1300余款软硬件产品通过兼容性认证，广泛落地于金融、交通、教育、能源、政务、工业乃至航天等关键领域。以OpenHarmony为底座的鸿蒙生态设备数量已超过9亿台，华为基于OpenHarmony打造的鸿蒙5操作系统已于2024年发布，截至2025年9月已有60余款终端设备搭载。2025年9月，陈海波在开源鸿蒙技术大会上宣布开源鸿蒙6.0版本正式发布。IPADS团队为OpenHarmony贡献了安全微内核、分布式可信执行环境、文件快速共享与备份、Ark运行时内存调优、图形渲染性能优化、端侧大模型推理框架等多项核心技术。

2023年，陈海波作为第一完成人的"OpenHarmony智能终端操作系统基座"项目获CCF科技进步特等奖。该项目成果广泛应用于华为公司3.3亿台终端产品和国家关键行业终端。

**EROFS文件系统：** 这是IPADS与华为合作中技术转化最成功的案例之一。EROFS（Enhanced Read-Only File System）是一种面向移动设备的高性能只读压缩文件系统，由上海交通大学/华为陈海波团队研发，研究成果发表于USENIX ATC 2019。EROFS通过固定压缩输出块大小和灵活的原始数据存储方式，解决了Squashfs等传统只读文件系统在移动设备上的读放大和内存占用问题。EROFS已进入Linux内核主线，并于2022年被Google采纳为Android 13的默认只读分区文件系统，成为Android官方标准。这意味着该技术从学术研究出发，最终成为全球数十亿Android设备的基础设施组件，是中国学者在操作系统底层技术方面对全球开源社区的重要贡献。

**openEuler：** 陈海波参与了openEuler操作系统社区的建设，并作为作者出版了《openEuler操作系统核心技术与行业应用实践》一书，系统介绍了openEuler的"四梁八柱"技术体系及其在14个关键基础行业的应用实践。openEuler是华为主导的服务器操作系统开源社区，与OpenHarmony形成"云端+终端"的双操作系统开源生态布局。

**联合实验室：** 上海交通大学与华为建立了"下一代异构并行操作系统联合实验室"（2022年-2026年），由陈榕教授负责具体执行，开展异构计算环境下的操作系统研究。

**人才输送：** 华为是IPADS毕业生的最大去向之一，至少有20余位毕业生加入华为，涵盖操作系统内核开发、安全架构、分布式系统等多个方向，为华为操作系统研发提供了持续的人才供给。

### 5.2 PowerInfer开源项目

PowerInfer是IPADS在机器学习系统方向的标志性开源项目，由糜泽羽发起并主导。该项目展示了IPADS在大模型时代的前沿探索能力。

**PowerInfer-1.0**（2023年底发布）：面向PC场景的快速大模型推理框架，在消费级GPU（如RTX 4090）上实现了比llama.cpp高达11倍的推理加速。该项目曾连续三天登顶GitHub趋势榜，5天内获得5K GitHub Star，目前已达8.3K星标。

**PowerInfer-2.0**（2024年发布）：面向手机的大模型推理引擎，使Mixtral 47B模型在智能手机上达到11 tokens/s的推理速度，与llama.cpp相比平均加速25倍，最高达29倍。配套的大模型优化技术Turbo Sparse进一步提升了框架性能。

**SmallThinker模型**（2025年）：IPADS联合初创公司"本智激活"（Zenergize AI）在HuggingFace开源了端侧原生大模型SmallThinker系列，包含4B和21B两个稀疏模型尺寸。其中4B模型在1GB峰值内存下推理速度达19.41 tokens/s，21B旗舰模型在百元级国产RK3588开发板上实现相较于Qwen-14B高达21倍的推理加速。SmallThinker曾登顶HuggingFace趋势总榜第二名，7天下载量突破10万。

PowerInfer项目的成功体现了IPADS"研究-开源-创业"的全链条能力，也展示了陈海波团队在大模型系统领域从操作系统底层到应用层的贯通研究能力。

### 5.3 ChCore微内核与操作系统教学

ChCore是IPADS为操作系统教学设计的实验性微内核操作系统，由古金宇主持研发，陈海波和夏虞斌提供总体指导。ChCore采用微内核架构，基于ARM指令集开发，通过渐进式实验模块帮助学生理解进程管理、内存管理与设备驱动等核心机制，同时融合了Wayland图形化、AI推理等传统内核实验不具备的内容。历经五年教学实践，ChCore已支撑多届学生完成操作系统课程实验、毕业设计与科研原型，部分研究成果已在主流国际会议发表。

配套教材《操作系统：原理与实现》（原名《现代操作系统：原理与实现》）由陈海波和夏虞斌合著，2020年出版，获得了2020年度"最受读者喜爱的IT图书奖"、2022年上海交通大学优秀本科生教材奖、机工科技2023年度计算机领域十大好书等荣誉。截至2024年10月，该教材已被清华大学、北京大学等近200所高校采用为教学用书。2026年，关于ChCore的教学实践论文被SIGCSE TS 2026接收，这是上海交通大学首次在该计算机教育领域顶级会议发表长文。

ChCore的研究成果也通过产学研合作应用于开源鸿蒙操作系统、航天卫星操作系统、OPPO智能终端操作系统、南方电网的电力鸿蒙操作系统等实际系统，体现了教学科研平台的产业辐射能力。

### 5.4 与其他企业的合作

**阿里巴巴/蚂蚁集团：** IPADS与阿里巴巴及蚂蚁集团有持续的研究合作和人才输送关系。多位毕业生进入阿里云和蚂蚁集团从事系统软件相关工作。从论文来看，IPADS与阿里巴巴的研究团队在数据库系统、分布式事务等方向有合作论文。陈海波曾与OceanBase首席科学家阳振坤同台讨论中国根技术发展。

## 七、Connection圈层总结

以陈海波为中心，可以清晰地识别出四个层次的学术与产业关系网络：

### 7.1 核心圈层：IPADS教师团队

IPADS教师团队是陈海波学术影响力的核心载体，形成了一个以"复旦-交大"学术传承为纽带的紧密团队。这个团队的独特之处在于：臧斌宇是陈海波的博士导师，后追随陈海波加入交大IPADS；陈榕与陈海波师出同门（均毕业于复旦大学臧斌宇组），形成了分布式系统方向的黄金搭档；夏虞斌与陈海波合著教材，在操作系统方向形成互补。年轻一代教师中，魏星达、古金宇、糜泽羽、杜冬冬均为陈海波（或联合臧斌宇）指导的博士生，留校后各自开拓独立方向，形成"老中青"三代梯队。这种"自繁殖"式的人才培养模式确保了IPADS研究方向的延续性和团队的凝聚力。IPADS目前拥有14位教师（含臧斌宇和余炀），37名博士生、61名硕士生和15名本科生，是国内系统领域规模最大、产出最高的研究团队之一。

### 7.2 学生圈层：已毕业博士生及去向

陈海波培养的学生已形成庞大的学术与产业网络。在学术界，大量毕业生赴海外名校（Cornell、NYU、UCSD、UPenn、UCLA、UIUC、Princeton、Georgia Tech、UT Austin等）攻读博士，正在成为下一代系统研究者的生力军。在国内，部分毕业生留校任教（魏星达、古金宇、糜泽羽、杜冬冬等），延续IPADS的研究血脉。

在产业界，华为是最大的学生去向（20余人），这与陈海波在华为的角色直接相关。这些毕业生在华为从事操作系统内核、安全架构、分布式系统等核心研发工作，构成了华为操作系统研发的重要技术力量。阿里巴巴/蚂蚁集团、字节跳动、腾讯等头部互联网企业也是重要去向。值得注意的是，IPADS毕业生在量化金融领域（Jump Trading、Optiver、宽德投资、九坤投资等）有显著存在，这反映了系统领域人才在低延迟系统设计方面的跨界竞争力。

在创业方面，何文泰创立的TrustKernel（安全操作系统）和糜泽羽参与的本智激活（端侧AI）代表了IPADS技术转化的创业路径。

### 7.3 产业圈层：华为为核心的合作伙伴

陈海波的产业关系网络以华为为绝对核心，形成了中国计算机学术界最深的产学研合作模式。陈海波作为华为Fellow和基础软件首席科学家，不仅在技术层面指导OpenHarmony和openEuler的发展方向，更在战略层面参与华为操作系统生态的整体布局。IPADS团队的研究成果（EROFS进入Linux内核和Android标准、OpenHarmony安全微内核、ChCore教学内核等）直接转化为华为产品的技术能力，而华为的产业需求又反过来驱动IPADS的研究选题，形成了独特的"需求-研究-落地"闭环。

除华为外，IPADS还与阿里巴巴、三星、AMD等企业有研究合作，并有大量毕业生分布在字节跳动、腾讯、蚂蚁集团、谷歌、英伟达、Meta等全球科技企业。然而，华为无疑是合作深度和规模最大的伙伴，这种合作已经持续近十年，产出了数十亿设备级别的技术部署影响。

### 7.4 国际学术圈层

陈海波在国际操作系统社区的影响力已达到中国学者的最高水平。作为ACM SIGOPS自1965年成立以来的首位非北美主席，他在国际操作系统社区的领导地位得到正式认可。他与MIT的Frans Kaashoek教授、NYU的Jinyang Li教授等国际顶级学者有实质性合作。他担任Communications of the ACM首位中国学者编委，使中国系统研究的声音得以在国际最高学术平台上传播。

IPADS的论文持续发表在SOSP、OSDI、ASPLOS、ISCA、MICRO、EuroSys、USENIX Security、SIGMOD、VLDB、NeurIPS等涵盖系统、架构、安全、数据库和AI领域的顶级会议，获奖频次在中国高校中无出其右。近十年SOSP/OSDI论文数世界第一的统计（csrankings.org）进一步确认了IPADS在全球操作系统研究中的领先地位。

陈海波还通过APSys和ChinaSys等区域性学术社区的建设，推动了中国及亚太地区系统研究生态的发展。APSys会议由他于2011年参与创立并担任首届大会主席，现已成为亚太地区系统领域的重要学术会议；ChinaSys作为中国系统研究者的学术社区，由他联合创立并长期担任主席（2018-2022年），为中国系统研究者的学术交流和国际发声提供了重要平台。

### 7.5 圈层互动与整体网络特征

陈海波关系网络最显著的特征是四个圈层之间的深度互动：IPADS教师团队的研究成果通过陈海波在华为的角色直接转化为产业技术（核心圈层-产业圈层）；华为的产业需求驱动IPADS新的研究方向（产业圈层-核心圈层）；IPADS培养的学生大量进入华为等企业（学生圈层-产业圈层）；部分优秀学生留校任教成为新的核心圈层成员（学生圈层-核心圈层）；国际学术声誉提升了IPADS对优秀生源的吸引力（国际圈层-学生圈层）；国际学术合作带来了前沿研究视角和方法（国际圈层-核心圈层）。这种多圈层互动的良性循环，是陈海波个人影响力能够持续放大的结构性原因，也使IPADS成为中国计算机系统领域产学研一体化的标杆性团队。
