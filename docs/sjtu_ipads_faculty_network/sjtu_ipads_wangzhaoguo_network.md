## 四、学术合作网络

### （一）IPADS核心圈：陈海波及系统软件共同体

陈海波是王肇国最稳定、最具枢纽性的公开合作对象之一。二人共同署名覆盖2014年EuroSys论文《Using Restricted Transactional Memory to Build a Scalable In-Memory Database》、2016年SIGMOD多核数据库工作、2019年PODC Paxos/Raft工作、2020年XIndex、2021年Polyjuice、2022年WeTune和Ad Hoc Transactions、2023年OSDI Flux、2024年WeBridge与SQLSolver、2025年CACM文章等多个时期。关系性质应表述为“长期共同论文作者、IPADS同事与团队协作伙伴”，而非未经证实的师承关系。陈海波作为IPADS核心负责人、OpenHarmony项目群技术指导委员会主席，也使这一合作兼具系统学术网络与开源生态组织网络属性。

陈榕（Rong Chen）与王肇国之间的可确认关系是复旦—IPADS背景上的研究合作和现同事连接。公开论文包括2017年APSys《Extracting More Intra-transaction Parallelism with Work Stealing for OLTP Workloads》、2021年NSDI分散标量时间戳MVCC工作，以及2023年OSDI Flux。陈榕的公开履历显示其2007年至2012年在复旦工作、2012年起在上海交大任职；这使双方在系统软件和高并发事务问题上存在持续的组织重叠。至于两人是否为同门或存在导师关系，属于推测，暂无直接公开证据。

董明凯（Mingkai Dong）连接了事务性存储、持久内存、文件与存储系统三条线。王肇国、董明凯与陈海波等人共同发表2015年《Persistent Transactional Memory》；后续还共同署名2017年TOS论文《Efficient and Available In-Memory KV-Store with Hybrid Erasure Coding and Replication》。董明凯现为IPADS副研究员，其后续工作转向文件系统与DNA存储；因此，二人的合作体现IPADS内部从事务内存/键值存储到持久化存储基础设施的知识连续性。

古金宇（Jinyu Gu）与王肇国的直接代表合作是2019年USENIX ATC论文《Pisces: A Scalable and Efficient Persistent Transactional Memory》。该文还由俞倩倩、王夏阳、臧斌宇、管海兵和陈海波共同署名，说明Pisces不是两人之间的单线合作，而是IPADS在持久内存事务机制上的团队型成果。古金宇现为IPADS副研究员，研究操作系统内核、系统安全和机器学习系统，并承担OpenHarmony具身智能PMC相关工作；因而他构成王肇国“事务存储—操作系统—开源鸿蒙”邻接网络的重要节点。

### （二）纽约大学与国际合作圈：Jinyang Li及延展伙伴

Jinyang Li是王肇国纽约大学阶段最明确的国际长期合作节点。公开共同论文至少横跨2014年EuroSys、2015年USENIX ATC（Spartan）、2016年SIGMOD、2017年APSys、2019年PODC、2021年OSDI Polyjuice、2023年ICDE/VLDB、2024年SIGMOD SQLSolver以及2025年VLDB Sonata等。王肇国在NYU完成博士后与非终身制助理教授任职，论文合作从内存数据库扩展至共识协议、事务调度、SQL验证和跨数据库事务，表明这一连接并未随着其2018年回国而中断。

这种合作网络的学术价值在于将上海交大IPADS的系统工程传统与NYU的分布式系统、数据库研究相连。PODC 2019论文把Paxos与Raft的优化迁移问题置于分布式理论语境；Sonata和SQLSolver则把合作推进到可串行化多数据库事务和SQL语义验证。王肇国还与Aurojit Panda在2023年VLDB分布式事务批量提交论文中共同署名，体现该网络并非只围绕单一实验室，而是连接到更广泛的北美分布式系统研究群体。

### （三）数据库理论、程序验证与交叉合作圈

Ruzica Piskac是SQLSolver与Text-to-SQL工作中的国际合作伙伴，分别共同署名2024年SIGMOD《Proving Query Equivalence Using Linear Integer Arithmetic》和2025年SIGMOD Text-to-SQL验证修复论文。该连接将王肇国团队对SQL等价性与查询重写的工程问题，连接到SMT、程序逻辑与形式化验证社区。Guoliang Li出现在2025年VLDB Industry Track论文GRewriter作者名单中，体现其团队在GaussDB查询重写产品化时与数据库优化器学术界的合作拓展。

在生命科学与自主实验方向，2025年AutoDNA预印本由王肇国、陈海波与吴明瑜、王嘉斌、董志远、范春海等多位跨学科作者共同完成。该网络将系统软件、AI、实验仪器与生物/化学研究连接起来；由于论文为预印本且项目仍处早期，关于其最终平台形态与产业化影响的判断应视为**推测**，不宜夸大为已完成的成熟产品。

## 五、业界合作关系深度分析

### （一）华为云GaussDB：从论文方法到数据库产品

华为是王肇国业界合作中公开证据最完整的对象。其团队的WeTune针对SQL查询重写规则“难以完全依赖人工专家积累”的问题，通过枚举候选规则、SQL等价性验证和代价评估自动挖掘高质量规则。王肇国与华为GaussDB数据库优化器专家的公开技术对谈说明，华为云GaussDB团队与王肇国团队已完成WeTune 2.0在GaussDB产品上的落地；个人主页亦明确写作“已在GaussDB商业版中落地使用”。后续GRewriter以“Practical Query Rewriting with Automatic Rule Set Expansion in GaussDB”为题进入VLDB 2025 Industry Track，作者中出现多位GaussDB相关人员，显示合作已从原始规则发现工具扩展到实际规则集扩张和产品工程问题。

这层关系不是简单的冠名资助，而是可观察到的“理论—工具—产品”闭环：SQLSolver提供等价性验证底座，WeTune自动合成/筛选规则，GRewriter面向GaussDB工程落地。它也解释了为什么王肇国在数据库系统研究中重视正确性与性能并重：查询重写一旦改变SQL语义会直接影响生产系统，因此形式化验证是产业转化的安全边界。

华为专项联培基地则构成人才培养层的合作。上海交通大学华为专项联培基地公开活动中，王肇国强调校内学习与企业实践的双通道以及科研成果落地；其个人主页的研究生课程“并行与分布式数据库系统”也标注由上海交通大学与华为联合开设，高校负责理论、企业负责真实应用与挑战。由此，华为合作同时覆盖技术转化、课程共建与学生实践三条链路。

### （二）OpenHarmony智能数据管理生态：组织型产学研连接

王肇国个人主页和上海交大计算机学院教师页将其列为“OpenHarmony技术指导委员会智能数据管理TSG负责人”。在公开活动层面，他与中国科学技术大学李永坤共同作为2025年OpenHarmony智能数据管理分论坛出品人，并在合肥城市技术论坛与李永坤共同主持；论坛还汇集陈海波、香港中文大学John C.S. Lui、华为OS内核实验室主任贾宁、华为嵌入式数据库首席专家周敏奇、华为终端BG专家李有福等产学研参与者。这表明王肇国是这一智能数据管理议题的高可见度组织者和学术接口。

但应当区分“个人主页当前职务表述”与“历史媒体报道中的组织角色”：2024年OpenHarmony技术大会报道曾将智能数据管理TSG星光贡献者列为李永坤。因此，关于TSG负责人的公开表述存在时间和角色层级差异；较稳妥的结论是，王肇国在当前上海交大/本人页面中被列为负责人，并与李永坤共同组织相关活动，而历史报道所列李永坤信息可能反映当时的负责人或代表身份。不能据此推断两人之间有从属关系。

OpenHarmony本质上是由开放原子开源基金会孵化运营、面向全场景智能终端的开源操作系统项目。王肇国在其中的产业连接并不等同于某一家企业雇佣关系，而是通过TSC/TSG、技术论坛、高校技术俱乐部、年度课题和华为等共建单位构成的开放治理网络。其与陈海波（OpenHarmony TSC主席）、古金宇（OpenHarmony相关PMC工作）、华为终端与数据库专家之间形成了IPADS内部系统能力与外部终端/数据管理需求之间的桥梁。

### （三）华为奖项与合作边界

## 七、Connection圈层总结

**第一圈层：团队、核心共同作者与直接培养对象。** 该圈层以王肇国本人、IPADS和其学生/校友为核心。陈海波是长期合作与机构枢纽；唐楚哲、丁浩然、丁丁、张孝东、于乾勉、王友运、周洲、王嘉琛、沈嘉欢等连接事务、查询优化、验证和存储方向。这个圈层最明显的特征是共同论文与学生培养高度重合，研究成果可沿“学生—论文—博士后/企业去向”追踪。

**第二圈层：IPADS及复旦—上海交大系统软件共同体。** 陈榕、董明凯、古金宇、臧斌宇、管海兵等构成围绕持久内存、存储、操作系统、事务处理与系统安全的近邻协作网。它以IPADS为共同组织平台，同时受到复旦计算机系统结构训练背景影响。陈海波和王肇国同属复旦系统结构博士背景，但正式师承关系尚无公开证据，应避免把这一圈层误写为单一导师谱系。

**第三圈层：国际学术合作与方法论桥梁。** Jinyang Li及纽约大学经历构成最持久的国际连接，合作覆盖内存数据库、共识协议、事务与SQL语义；Aurojit Panda进一步延展了分布式事务合作；Ruzica Piskac把SQLSolver接入形式化验证与程序逻辑社区；Guoliang Li等则连接数据库优化器研究。该层的作用是将IPADS的工程系统研究与国际分布式系统、数据库理论和验证方法相互导通。

**第四圈层：产业产品、开源治理与人才联培。** 华为云GaussDB是可确认的产品化合作节点，WeTune/SQLSolver/GRewriter构成技术落地链；华为专项联培与联合课程形成教育链；OpenHarmony TSC/智能数据管理活动则形成开源治理和生态链。陈海波、李永坤、华为终端及数据库专家、古金宇等均在这一层发生组织性连接。学生流向华为、字节跳动、阿里巴巴、网易、Jump Trading、摩根士丹利，又进一步把该层扩展到互联网、数据库产品、量化金融和金融科技。

总体而言，王肇国的关系网络不是以单一“导师—学生”链条为主，而是以“复旦系统训练—NYU国际合作—IPADS团队协同—学生国际/产业流动—华为及OpenHarmony产学研转化”五条相互交织的链路构成。其中心竞争力在于将分布式系统的语义与一致性问题转化为可验证、可优化、可部署的数据库和系统软件能力；其网络的持续扩张则来自学生去向、共同论文和开源/产业组织角色的相互强化。
