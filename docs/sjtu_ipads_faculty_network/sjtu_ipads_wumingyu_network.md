关于姓名用字，需要在报告开头作一处重要的事实澄清。委托方在背景信息中给出的中文名写作"吴明瑼"（"瑼"字），但经过对上海交通大学软件学院官方教师名录（http://www.se.sjtu.edu.cn/Data/View/279 ）、上海交通大学计算机学院（网络空间安全学院、密码学院）官方教师名录（https://www.cs.sjtu.edu.cn/jiaoshiml/wumingyu.html ）、IPADS研究所英文与中文个人主页（https://ipads.se.sjtu.edu.cn/pub/members/mingyu_wu 及其中文镜像）以及上海交通大学新闻网官方新闻稿（https://news.sjtu.edu.cn/jdzh/20250924/214607.html ）四个独立官方渠道的交叉核实，其正确的中文姓名为**吴明瑜**（"瑜"，美玉之意），而非"吴明瑼"，亦非委托方提示中的可能误写"吴明宇"。上述所有官方页面在姓名、英文名（Mingyu Wu）、邮箱（mingyuwu@sjtu.edu.cn）、教育背景（2011—2015本科、2015—2020博士）、博士导师（陈海波教授）以及三篇代表作（Espresso@ASPLOS'18、Platinum@ATC'20、GCPersist@VEE'20）等所有关键字段上完全一致，可以确认为同一人，不存在同名混淆问题。因此本报告后文一律采用官方用字"吴明瑜"。

从发表脉络上看，吴明瑜的学术产出具有极强的方向纯度和连续性。自2017年在PPoPP上发表首篇关于托管运行时上向量化机器学习性能恢复的工作起，他就将研究锚定在"高级语言运行时系统"这一核心命题上，并沿着三条相互交织的主线持续深耕近十年：其一是垃圾回收（GC）算法优化，从ScissorGC（VEE'19）、Platinum（ATC'20）、Jade（EuroSys'24）一直到最新的分离式垃圾回收DGC（OSDI'26）；其二是Java对非易失内存（NVM）的原生支持，代表作包括Espresso（ASPLOS'18）、GCPersist（VEE'20）、DwarfGC（SOSE'18）以及Bridging the Performance Gap（EuroSys'21）；其三是面向服务器无感知计算（Serverless/FaaS）场景的虚拟机支持，包括BeeHive（ASPLOS'23）、Flock（IEEE TC'23）、Desiccant（EuroSys'24的Frozen Garbage工作）和ZCOT（ATC'22）。这种"一以贯之、层层递进"的研究布局，使他在国内乃至国际的语言运行时系统研究社区中形成了鲜明的个人学术标签。

## 二、教育背景与职业履历

吴明瑜的完整履历是IPADS"自主培养、扎根本土"人才路径的又一个典型样本，其时间线由其IPADS中文主页"个人经历"栏目明确给出，与软件学院、计算机学院两处官方教师名录记载完全吻合。

2011年9月至2015年6月，吴明瑜就读于上海交通大学软件学院，攻读软件工程专业本科学位。2015年9月，他直接在本校软件学院开始博士阶段学习，专业为计算机科学与技术，**博士导师为陈海波教授**——这一师承关系并非推测，而是由上海交通大学软件学院官方教师名录页面在"教育背景"栏目中以"2015-2020 上海交通大学 计算机科学与技术 博士（导师：陈海波教授）"的形式明确标注，同时IPADS中文个人主页在个人经历栏中亦以"2015.09 - 2020.08，上海交通大学软件学院，博士生，导师：陈海波"再次确认，其英文主页的自述"I received my Ph.D. degree in computer science from SJTU in 2020, advised by Prof. Haibo Chen"构成第三重独立佐证。三个官方来源相互印证，这一导师关系属于经过完整核实的确认事实。博士期间（2015—2020）他产出了包括PPoPP 2017、ASPLOS 2018（Espresso）、SOSE 2018（DwarfGC）、APSys 2018（最佳论文亚军）、VEE 2019（ScissorGC）、VEE 2020（GCPersist）、USENIX ATC 2020（Platinum）在内的密集成果，其中Espresso与Platinum两篇均由他担任第一作者，构成了他此后学术生涯的两大技术支柱。

2020年8月博士毕业后，他于同年11月即入职上海交通大学软件学院，出任助理研究员（硕士生导师），实现了从学生到教职的无缝衔接。2023年12月，他晋升为上海交通大学计算机学院（软件学院）副教授、博士生导师，完成了向独立PI的角色转变。值得注意的是，在他晋升副教授的同一时期，上海交通大学正在推进软件学院与计算机学院的机构整合，因此他在两个学院的教师名录中同时挂名，这也解释了其职称在两套系统中呈现"副教授/副研究员"双重表述的现象。

在教学方面，吴明瑜承担了相当密集且成体系的教学任务，覆盖本科到研究生的完整链条：软件学院《编译原理与技术》（SE3355，2021—2025年秋季学期）、《云操作系统设计与实践》（SE3356，2022—2026年春季学期）、《系统设计与开发大型课程设计（系统软件）》（SE4353，2022—2025年秋季学期），以及研究生课程《计算机系统设计和实现》（EI6708，2023—2026年春季学期）。其中研究生课程《计算机系统设计和实现》深度融入了OpenHarmony操作系统内容，是与华为合作开展的产学合作协同育人项目，并入选2025年华为产学合作协同育人项目优秀案例。同时，他主导构建的教学系统miniK8s以论文形式发表于SIGCSE TS 2026——这是上海交大计算机学院首次在国际计算机教育领域顶级会议SIGCSE Technical Symposium上发表长文，据上海交大新闻网报道，该论文由杜冬冬助理研究员与吴明瑜副研究员共同担任第一作者，陈海波教授与臧斌宇教授共同担任通讯作者。这一成果说明吴明瑜在系统教学法层面同样投入了严肃的研究精力，是IPADS"科研与教学互哺"传统的实践者。

## 三、学生培养情况

作为2020年入职、2023年底晋升博导的青年PI，吴明瑜已经建立起一支规模相当可观、梯队完整的研究团队，其学生数量与毕业生规模在同代IPADS青年教师中属于较为突出的水平。根据其个人主页公开的学生列表，目前在读的博士生包括李欣睿（Xinrui Li）、司锦泽（Jinze Si）、吕鸿涛（Hongtao Lyu）、李宇涵（Yuhan Li）四人；硕士生包括马晓倩（Xiaoqian Ma）、杨景凯（Jingkai Yang）、任博俊（Bojun Ren）、刘博越（Boyue Liu）、杨圣涵（Shenghan Yang）、孙宇宸（Yuchen Sun）六人；本科生包括郝宇航（Yuhang Hao）、胡杰淼（Jiemiao Hu）、刘晓峰（Xiaofeng Liu）三人。需要说明的是，上述中文姓名系依据拼音的常见对应关系还原（推测），官方主页仅以英文拼音形式列出，个别用字可能与本人实际用字存在出入。

在这批在读学生中，博士生吕鸿涛（Hongtao Lyu）无疑是当前团队中最具产出能力的核心成员。他以第一作者身份完成了发表于OSDI 2026的《Shaving the Peaks: Taming Tail Latency for Managed Workloads via Disaggregated Garbage Collection》——这是吴明瑜独立带队后的标志性成果，也是他个人首篇OSDI论文，且该论文作者列表仅包含吕鸿涛、李宇涵和吴明瑜三人，完全未出现陈海波、臧斌宇等资深教授的名字，是吴明瑜真正实现学术独立的最强信号。此外，吕鸿涛还以第一作者身份完成了两篇预印本工作：《FairBatching: Fairness-Aware Batch Formation for LLM Inference》（arXiv 2025，合作者含刘博越、吴明瑜、陈海波）以及《CoAgent: Concurrency Control for Multi-Agent Systems》（arXiv 2026，合作者含张定言、吴明瑜、魏星达、陈海波）。博士生李欣睿则以第一作者完成了发表于ACM TACO 2025的《Object-Aware Memory Compression for Smartphones》，该工作面向智能手机场景的内存压缩，呼应了吴明瑜近年向智能终端操作系统方向的拓展。博士生李宇涵作为OSDI 2026论文的第二作者深度参与了DGC项目。

在已毕业校友方面，吴明瑜主页列出了11位alumni及其去向，构成了观察其学生培养产出的最直接窗口。这批校友的去向呈现出清晰的"顶尖量化交易机构 + 头部科技企业 + 海外顶尖高校深造"三分格局：赴Optiver（全球顶级高频量化交易公司）的有杨振宇（Zhenyu Yang）、李哲（Zhe Li）、杨延飞（Yanfei Yang）三人，占比接近三成，这一现象与语言运行时/GC方向所要求的极致低延迟工程能力和量化交易行业对JVM调优人才的强烈需求高度契合；赴华为的有曹旭杰（Xujie Cao）、姬浩迪（Haodi Ji）、赵子铭（Ziming Zhao）三人；赴腾讯的有刘书畅（Shuchang Liu）、陈沛东（Peidong Chen）两人；赴阿里巴巴的有汤家伟（Jiawei Tang）；赴百度的有王帅威（Shuaiwei Wang）；此外李昊宇（Haoyu Li）赴美国哥伦比亚大学（Columbia University）攻读博士学位，是这批校友中唯一走上学术道路的一位。

其中，赵子铭（Ziming Zhao）是吴明瑜学生中学术产出最为丰厚的一位，他以第一作者身份完成了EuroSys 2024的《Characterization and Reclamation of Frozen Garbage in Managed FaaS Workloads》（获ACM Artifacts Evaluated / Artifacts Functional徽章）、IEEE TC 2023的《Flock: Towards Multitasking Virtual Machines for Function-as-a-Service》以及ASPLOS 2023的《BeeHive: Sub-second Elasticity for Web Services with Semi-FaaS Execution》三篇高水平论文，构成了吴明瑜"FaaS语言虚拟机支持"这一研究主线的核心骨架，其毕业后加入华为。李昊宇（Haoyu Li）则是吴明瑜早期GC研究线上的关键合作者，二人合作的APSys 2018论文《Analysis and Optimization of Java Full Garbage Collection》获得最佳论文亚军奖，并进一步发展为VEE 2019的ScissorGC，他随后赴哥伦比亚大学深造。杨延飞（Yanfei Yang）以第一作者完成了EuroSys 2021的NVM垃圾回收工作，王帅威（Shuaiwei Wang）参与了ATC 2022的ZCOT，李哲（Zhe Li）则以第一作者完成了VEE 2022的混合内存对象置放工作（该论文作者仅李哲与吴明瑜二人）。

整体而言，吴明瑜的学生培养呈现出三个显著特点：一是研究课题高度聚焦，学生工作几乎全部落在GC优化、FaaS运行时、NVM支持、移动端内存管理这四个紧密相关的子领域内，形成了强烈的团队技术共识；二是学生独立署名度高，多篇论文以学生为第一作者、吴明瑜为唯一或主要指导者，且近年OSDI'26等成果已不再挂靠资深教授，显示其独立指导能力已经成熟；三是就业出口具有鲜明的方向特色，Optiver等量化机构与华为、阿里等云厂商的双重吸纳，直接反映了高级语言虚拟机人才在低延迟金融交易系统与大规模云服务两大产业场景中的稀缺性。

## 四、学术合作网络

吴明瑜的学术合作网络以IPADS研究所内部为绝对核心，呈现出"一位导师主轴 + 两位资深教授稳定加持 + 同代青年学者横向联动 + 工业界工程师纵向嵌入"的四重结构。

**陈海波教授**是这一网络中最核心、最稳定的节点。作为吴明瑜官方认定的博士导师，陈海波出现在吴明瑜绝大多数论文的作者列表中，从2017年的PPoPP到2026年的SIGCSE TS，合作时间跨度长达近十年，是贯穿其全部学术生涯的关键人物。陈海波现为上海交通大学特聘教授、校务委员会委员、领域操作系统教育部工程研究中心主任、人工智能操作系统研究院院长，是ACM Fellow、IEEE Fellow、CCF Fellow和国家杰出青年科学基金获得者，其本科与博士均毕业于复旦大学（博士论文获全国优博），2011年9月起任教于上海交通大学。按照csrankings.org的统计，陈海波近十年在SOSP/OSDI上发表的论文数居世界第一。对吴明瑜而言，陈海波不仅是学位导师，更是其研究成果得以对接华为、阿里等产业资源的关键枢纽。

**臧斌宇教授**是吴明瑜合作网络中频次仅次于陈海波的资深学者。臧斌宇是IPADS的核心创建者与领军人物之一，出现在吴明瑜从Espresso（ASPLOS'18）、Platinum（ATC'20）、GCPersist（VEE'20）、ScissorGC（VEE'19）、EuroSys'21、ZCOT（ATC'22）、BeeHive（ASPLOS'23）、Flock（IEEE TC'23）、SGX-friendly Java Runtime（IEEE TC'24）、Jade（EuroSys'24）、Frozen Garbage（EuroSys'24）直到TACO'25、SIGCSE TS'26在内的十余篇论文中，是其学术生涯中出现频率最高的第二位资深合作者。在SIGCSE TS 2026的miniK8s论文中，臧斌宇与陈海波共同担任通讯作者，说明二人对吴明瑜的支持不仅限于科研，也延伸至教学研究领域。

**管海兵教授（Haibing Guan）**是吴明瑜早期学术生涯中的重要合作者，主要出现在其博士阶段（2017—2020年）的四篇论文中：PPoPP 2017、Espresso（ASPLOS'18）、GCPersist（VEE'20）和Platinum（ATC'20）。管海兵是上海交通大学计算机领域在系统虚拟化方向的资深教授，长期主持上海市可扩展计算与系统重点实验室相关工作。值得注意的是，管海兵在2020年之后基本淡出了吴明瑜的合作者列表，这一变化推测与吴明瑜博士毕业后研究重心从"虚拟化+NVM硬件协同"逐步转向"云原生FaaS运行时与移动端运行时"有关，早期由管海兵主导的硬件虚拟化视角在其新阶段研究中的权重相应下降。

在**IPADS内部同代青年学者的横向合作**方面，吴明瑜与多位同期成长起来的青年教师形成了紧密的互动关系。**魏星达（Xingda Wei）**是其中最重要的一位：二人共同参与了EuroSys 2024最佳论文《Serialization/Deserialization-free State Transfer in Serverless Workflows with RDMA-based Remote Memory Map》（第一作者陆芳明，通讯作者魏星达，吴明瑜为共同作者），该工作的期刊扩展版也于2025年3月发表在ACM TOCS上；此外二人还共同参与了2026年的CoAgent预印本工作。这一合作关系颇具代表性——魏星达的RDMA分布式系统专长与吴明瑜的语言运行时/序列化专长在"Serverless工作流免序列化状态传递"这一命题上实现了精准互补，共同催生了亚洲高校历史上第二篇EuroSys最佳论文（首篇同样由IPADS获得）。**杜冬冬（Dong Du，曾用名杜东）**是另一位重要的同代合作者，二人共同担任SIGCSE TS 2026 miniK8s论文的共同第一作者，在系统教学平台建设方向上形成了深度协同。**王肇国（Zhaoguo Wang）**副教授参与了ASPLOS 2023的BeeHive工作。此外，陈榕（Rong Chen）教授通过EuroSys 2024最佳论文及其TOCS期刊版与吴明瑜产生了间接合作关联。

在**跨机构与国际交流**方面，吴明瑜的论文合作者绝大多数来自上海交通大学本机构，纯学术意义上的跨校国际合作论文较为罕见，这与IPADS整体相对独立自主的科研发表策略一致。但他在机构层面的国际交往并不缺席：据软件学院新闻报道，在泰国清迈大学代表团访问上海交大软件学院期间，吴明瑜作为教师代表出席并向代表团介绍了自己的研究领域和科研成果，与李国强副教授、张言博士一同参与了双方关于师生互访、学生联培、学术研讨及科研合作的座谈，会后代表团参观了IPADS实验室。

## 五、业界合作关系深度分析

吴明瑜所深耕的高级语言虚拟机方向，是计算机系统研究中产业耦合度最高的领域之一。Java虚拟机及其垃圾回收器直接决定了阿里巴巴、腾讯、字节跳动等中国互联网企业绝大部分核心业务系统的服务质量，尤其是尾延迟（tail latency）表现；而ArkTS/方舟运行时则是华为鸿蒙生态的技术底座。这一天然的产业属性，使吴明瑜的研究成果具备了远超一般学术论文的落地价值，其与企业的合作关系也因此呈现出多层次、实质化的特点。

**与阿里巴巴的合作是其产业关系中最深入、最具实证性的一条主线。** 这一合作至少可以追溯到2020年的USENIX ATC论文Platinum——这篇提出面向交互式服务的CPU高效并发垃圾回收器的论文，作者列表中的**Sanhong Li（李三红）、Chuansheng Lu、Tongbao Zhang** 三人均为阿里巴巴JVM团队（阿里巴巴Dragonwell JDK/AJDK的核心研发力量）成员，其中李三红是阿里巴巴Java虚拟机技术的公认代表人物、阿里巴巴Dragonwell开源JDK的关键推动者。Platinum针对的核心问题——交互式在线服务中GC暂停导致的尾延迟抖动——正是阿里巴巴双十一级别大规模Java服务面临的经典痛点，学术方法与产业需求在此形成了完美对接。这一合作在2024年的EuroSys论文**Jade: A High-throughput Concurrent Copying Garbage Collector**中达到高峰：该论文由吴明瑜担任第一作者，合作者阵容多达十二人，其中**Liang Mao（毛亮）、Yude Lin、Yifeng Jin、Xiaowei Lu、Hao Tang、Denghui Dong（董登辉）** 等多位均为阿里巴巴JVM/Dragonwell团队工程师（推测，依据在于这批姓名此前长期出现在阿里巴巴JDK相关技术输出中，且论文主题为面向生产级高吞吐场景的并发拷贝式GC，非工业界深度参与难以完成），另有吴明瑜自己的学生李哲、吕鸿涛、汤家伟参与其中——值得注意的是，汤家伟毕业后正是去了阿里巴巴，形成了"学生参与产学合作项目—毕业进入合作企业"的完整人才输送闭环。此外，2024年发表于IEEE TC的《Toward An SGX-friendly Java Runtime》中同样出现了Sanhong Li的名字，以及Shaojun Wang、Lei Yu、Haitao Song等工业界研究人员。

**与华为的合作则主要体现在人才培养、终端运行时与荣誉认可三个层面。** 荣誉层面，吴明瑜的计算机学院官方页面与IPADS中文主页均明确列出其获得**华为火花奖**（华为面向学术界设立、认可青年学者研究工作对华为技术方向具有启发价值的奖项），这是其与华为存在实质性技术交流的官方证据。人才培养层面，他主讲的研究生课程《计算机系统设计和实现》是与华为合作开展的OpenHarmony产学合作协同育人项目，课程内容深度融入了OpenHarmony的架构解析（涵盖终端内核、媒体、互联、应用框架、安全、图形六大主题，重点讲解EROFS文件系统、方舟运行时ArkTS、分布式软总线等华为自研创新设计），并采用"企业专家进课堂"的模式定期邀请OpenHarmony技术专家授课，该课程于2025年入选华为产学合作协同育人项目优秀案例。技术层面，其IPADS中文主页明确记载研究成果"已经被OpenJDK、CPython等主流语言运行时社区接收并合入主线"，而软件学院/计算机学院页面进一步将**ArkTS**（华为方舟运行时的编程语言）与OpenJDK、CPython并列为接收其成果的运行时社区，这意味着他在鸿蒙生态的语言运行时层面有过实质性的代码贡献。此外，其研究方向近年明确向"智能终端操作系统"拓展，ACM TACO 2025的《Object-Aware Memory Compression for Smartphones》正是面向智能手机内存压缩的工作，与华为终端场景高度契合；其毕业生中有曹旭杰、姬浩迪、赵子铭三人进入华为，也侧面印证了双方在人才层面的紧密联系。

**成果开源与社区贡献是其产业影响力的第三条路径。** 吴明瑜团队的成果被OpenJDK主线接收，意味着其GC优化算法已经进入全球Java开发者的默认工具链，这是学术成果影响力的最高形式之一——它不依赖于任何单一企业的采纳决策，而是通过开源社区实现了全行业的普惠式落地。CPython社区的贡献则显示其研究视野并不局限于Java生态，而是覆盖了更广泛的动态语言运行时。IPADS研究所整体也高度重视开源回馈，其GitHub组织（SJTU-IPADS）维护着os-course-lab、skvm等高影响力仓库，其中"skvm（the language virtual machine for agent skills）"这一面向智能体技能的语言虚拟机项目，与吴明瑜近年宣称的"面向AI for Science等领域的新型运行时系统"和"mobile agents"研究兴趣方向高度吻合（推测其可能参与或关联该项目）。

**与量化交易行业的间接联系值得单独指出。** 虽然公开资料中未见吴明瑜与Optiver等机构的正式科研合作记录，但其毕业生中有杨振宇、李哲、杨延飞三人加入Optiver这一全球顶级高频量化交易公司，比例之高在系统方向的实验室中相当罕见。这一现象的技术逻辑很清晰：高频交易系统对Java运行时的微秒级延迟控制、GC暂停消除、内存布局优化有着近乎极致的要求，而吴明瑜团队在Platinum、Jade等工作中积累的正是这一整套核心能力。因此可以判断（推测），吴明瑜实验室实际上已经成为国内低延迟金融系统领域一个重要的人才供给源，这构成了一种非合同化但极为真实的产业连接。

综合来看，吴明瑜的产业合作模式与其导师陈海波"研究成果通过产学研深度结合被应用到数十亿设备"的路径一脉相承，但呈现出更聚焦的行业切口：他不追求覆盖全部云计算场景，而是牢牢占据"高级语言运行时"这一垂直但不可替代的技术咽喉，通过阿里巴巴JVM团队（服务端Java）、华为（终端ArkTS与鸿蒙生态）、OpenJDK/CPython社区（全球开源基础设施）三条渠道，实现了学术成果向产业价值的高效转化。

## 六、重要奖项与学术兼职

在学术荣誉方面，吴明瑜的履历以"高含金量、精准聚焦"为特征。其最重要的荣誉是**EuroSys 2024最佳论文奖**（Best Paper Award），获奖论文为《Serialization/Deserialization-free State Transfer in Serverless Workflows with RDMA-based Remote Memory Map》，第一作者为陆芳明，通讯作者为魏星达，吴明瑜作为核心共同作者参与其中。这一奖项的分量在其IPADS中文主页中有明确注解——"最佳论文奖，亚洲第二次，首次也由IPADS实验室获得"，即在EuroSys这一欧洲系统领域最高级别会议的历史上，亚洲高校总共仅两次获得最佳论文奖，且两次均由IPADS摘得。EuroSys 2024共收到484篇投稿、接收71篇（接收率14.7%），最佳论文奖全场仅评选出两篇。

其第二项重要荣誉是**APSys 2018最佳论文亚军奖**（Best Paper Runner-up），获奖论文为《Analysis and Optimization of Java Full Garbage Collection》（作者：李昊宇、吴明瑜、陈海波），这是他在博士第三年取得的成绩，该工作后续发展为VEE 2019的ScissorGC系统。第三项是**华为火花奖**，由华为面向学术界颁发，用于表彰其研究工作对华为技术方向的启发和贡献价值（其计算机学院官方页面与IPADS中文主页均列出该奖项，具体获奖年份未见官方明确披露）。

此外，其论文多次获得学术共同体的可复现性认证：ATC 2022的ZCOT工作获得USENIX颁发的"Artifacts Functional"和"Results Reproduced"双徽章，EuroSys 2024的Frozen Garbage工作获得ACM颁发的"Artifacts Evaluated"和"Artifacts Functional"徽章。这类徽章虽非传统意义上的"奖项"，但在系统研究社区中被视为对研究严谨性和工程质量的重要背书，其分量不容忽视。在评审服务方面，他还于2026年获得**PPoPP 2026杰出审稿人**（Distinguished Reviewer）称号，这是对其审稿质量与投入程度的正式认可。

在学术兼职方面，吴明瑜的服务记录清晰地反映出其学术影响力自2022年起持续攀升的轨迹。他担任程序委员会成员的会议包括：**ASPLOS 2027**（体系结构与操作系统交叉领域的顶级会议，CCF-A类）；**PPoPP 2026与PPoPP 2027**（并行程序设计原理与实践领域的旗舰会议，CCF-A类，其中2026年届获杰出审稿人）；**VEE 2022**（虚拟执行环境国际会议，是其所在语言虚拟机方向最对口的专业会议）；以及**ChinaSys 2022与ChinaSys 2025**（中国系统研究领域最重要的学术共同体活动）。从这一序列可以看出，他的服务范围正在从早期的领域专业会议（VEE）和国内学术共同体（ChinaSys）稳步扩展至PPoPP、ASPLOS这类国际顶级会议，且2026、2027连续两年受邀担任PPoPP程序委员并获杰出审稿人认可，说明其在国际并行计算与运行时系统社区中的声誉正在稳固建立。

## 七、Connection圈层总结

以吴明瑜为中心考察其学术关系网络，可以清晰地识别出四个层次分明、由内向外辐射的圈层，而这一网络最鲜明的整体特征在于它的"垂直深度"远大于"水平广度"——他并非那种合作者遍布全球、论文机构署名横跨数国的"广谱型"学者，而是在高级语言虚拟机这一相对狭窄的技术纵深上，将学术、产业、教育三条脉络牢牢编织在一起的"钉子型"学者。

**第一圈层是以陈海波教授为绝对核心的师承轴心。** 陈海波作为吴明瑜官方确认的博士导师（这一关系由软件学院教师名录、IPADS中英文主页三处独立官方来源交叉确认），不仅是其学位授予的指导者，更是从2017年PPoPP到2026年SIGCSE TS长达近十年、几乎覆盖其全部重要论文的共同作者。与陈海波并列构成这一核心圈层的还有臧斌宇教授——作为IPADS的领军人物，臧斌宇同样出现在吴明瑜十余篇论文中，并在miniK8s论文中与陈海波共同担任通讯作者。管海兵教授则构成了这一圈层中的"早期变量"：他深度参与了吴明瑜博士阶段2017—2020年的四篇论文，为其奠定了硬件虚拟化与NVM协同设计的视角，但在2020年之后逐渐淡出，这一变化标志着吴明瑜研究重心从"硬件协同"向"云原生与终端运行时"的战略转移（推测）。

**第二圈层是IPADS内部同代青年学者构成的横向协作网。** 其中魏星达是最重要的一位——二人在Serverless状态传递问题上的互补合作（魏星达提供RDMA分布式系统视角，吴明瑜提供序列化/运行时视角）直接催生了EuroSys 2024最佳论文，并延续至ACM TOCS期刊版和2026年的CoAgent预印本。杜冬冬是第二位关键伙伴，二人在系统教学研究方向上共同担任SIGCSE TS 2026论文的共同第一作者，开辟了IPADS在计算机教育顶会上的先河。王肇国、陈榕等IPADS教师则通过BeeHive、EuroSys最佳论文等具体项目与其形成了点状协作。这一圈层的存在方式颇具IPADS特色：这些青年学者彼此之间并非简单的"同事"关系，而是共享同一套学术传承（多数为陈海波、陈榕、臧斌宇门下培养）、共享同一批学生资源、在不同技术切面上互为对方提供能力补位的紧密共同体。

**第三圈层是吴明瑜作为独立PI亲手建立的学生梯队及校友网络。** 在读方面，以博士生吕鸿涛为核心（OSDI'26第一作者，另有两篇预印本一作），加上李欣睿（TACO'25一作）、司锦泽、李宇涵四位博士生，以及马晓倩、杨景凯、任博俊、刘博越、杨圣涵、孙宇宸六位硕士生和三位本科生，团队规模在IPADS青年PI中属于较大者。校友方面，11位毕业生中，赵子铭（三篇高水平论文的第一作者，现华为）与李昊宇（APSys最佳论文亚军一作，现哥伦比亚大学攻读博士）是学术产出最突出的两位。校友去向的三元格局——Optiver等量化机构（杨振宇、李哲、杨延飞）、华为/阿里/腾讯/百度等科技企业（曹旭杰、姬浩迪、赵子铭、汤家伟、刘书畅、陈沛东、王帅威）、海外顶尖高校（李昊宇）——本身就构成了一张覆盖低延迟金融、云计算基础设施和国际学术界的隐形关系网，其价值将随时间推移而持续放大。特别值得注意的是OSDI 2026论文的作者构成（吕鸿涛、李宇涵、吴明瑜三人，无资深教授挂名），这是吴明瑜完成从"陈海波门下学生"到"独立学术门户"角色转换的最明确标志。

**第四圈层是深度嵌入的工业界工程师网络与开源社区连接。** 阿里巴巴JVM/Dragonwell团队是其中最实质性的部分：李三红（Sanhong Li）从Platinum（ATC'20）到SGX-friendly Java Runtime（IEEE TC'24）跨越四年出现在其论文中，毛亮（Liang Mao）、董登辉（Denghui Dong）等六位工程师共同参与了Jade（EuroSys'24）这一十二人作者阵容的大型产学合作项目，Chuansheng Lu、Tongbao Zhang等则参与了Platinum。这些工程师并非挂名合作者，而是承担了生产级JVM系统实现与真实负载验证的实质性工作。华为方向的连接则通过火花奖、OpenHarmony产学合作育人项目、ArkTS运行时代码贡献以及三位入职华为的毕业生等多条渠道构成。而OpenJDK与CPython社区的主线代码接收，则将其影响力从特定企业延伸至全球开发者生态——这是一种"去中心化"的产业连接，不依附于任何单一商业主体，却具备最广泛的技术辐射面。

综合而言，吴明瑜的学术关系网络呈现出一种可以概括为"深井式"的结构特征：他从IPADS这一口深井中生长出来（本科—博士—留校，导师陈海波），选定了高级语言虚拟机这一条纵深赛道，然后沿着这条赛道同时向学术（EuroSys/OSDI/ASPLOS顶会 + PPoPP/ASPLOS程序委员）、产业（阿里JVM团队、华为鸿蒙、OpenJDK/CPython主线）和教育（编译原理、云操作系统、miniK8s教学系统研究、华为协同育人优秀案例）三个方向持续掘进。相较于同实验室转向AI基础设施赛道的魏星达等同代学者，吴明瑜的选择更为"守正"——高级语言运行时是一个不追风口、迭代缓慢但永不过时的基础软件领域，而他近年向智能终端操作系统、AI for Science运行时和移动智能体运行时的谨慎拓展，则显示出他正在尝试将这套深厚的运行时系统功底迁移至新兴计算范式，为下一个十年寻找新的技术落点。
