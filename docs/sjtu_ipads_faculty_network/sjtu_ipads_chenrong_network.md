## 二、教育背景与职业履历

陈榕的完整学术训练与早期职业生涯全部在复旦大学完成，这一点对理解他后来的学术网络至关重要——他并非"外来引进"到上海交大，而是随着导师和整个团队的迁移一同来到交大的。

**教育背景（均在复旦大学）：**

- 2000年9月–2004年7月，复旦大学计算机科学与技术专业，本科（学士学位）
- 2004年9月–2007年7月，复旦大学计算机软件与理论专业，硕士（硕士学位）
- 2008年9月–2011年7月，复旦大学计算机系统结构专业，博士（博士学位）

其博士导师已通过其英文主页明确核实为 **臧斌宇（Prof. Binyu Zang）教授**。主页原文表述为"I earned my Bachelor's (2000), Master's (2004), and Ph.D (2011) degrees (Advisor: Prof. Binyu Zang) in computer science, all from Fudan University"。这一师承关系在其早期论文的作者署名中亦可交叉验证——VEE'06 的 Live Updating Operating Systems Using Virtualization、ICPP'07 的 Mercury、PACT'10 的 Tiled MapReduce、EuroSys'11 的 Cerberus，臧斌宇均为末位（通讯）作者。

值得注意的是，硕士毕业（2007年7月）与博士入学（2008年9月）之间存在一年多的间隔，这一时期陈榕已作为工程师在复旦大学任职，属于典型的"边工作边读博"路径。

**职业履历：**

- 2007年7月–2012年1月，复旦大学，工程师
- 2008年1月–2008年6月，微软亚洲研究院（MSRA），研究实习生（Research Intern，指导人为MIT的 Frans Kaashoek 教授）
- 2012年2月–2015年12月，上海交通大学，助理研究员
- 2014年9月–2015年3月，新加坡国立大学（NUS），访问教授
- 2016年1月–（约2021年前后），上海交通大学，副教授
- 现今，上海交通大学，教授、博士生导师

其英文主页的自述略有不同："I have been a professor in the School of Computer Science at Shanghai Jiao Tong University and a member of IPADS since January 2012"——这里的"since January 2012"指的是加入IPADS的时间点（与"2012年2月起任助理研究员"基本吻合，仅一个月的口径差异），而非担任教授的时间点。以上海交大软件学院官方教师名录的分段履历为准更为精确。

2008年上半年在微软亚洲研究院的实习经历是其学术生涯的一个关键节点。该实习的指导人是MIT计算机科学与人工智能实验室（CSAIL）的 Frans Kaashoek 教授（ACM图灵奖得主候选级别的系统研究巨擘、MIT PDOS组负责人），当时Kaashoek正在MSRA访问。这次实习直接催生了 OSDI'08 的 **Corey: An Operating System for Many Cores** 一文——该论文的作者列表包含 Silas Boyd-Wickizer、Frans Kaashoek、Robert Morris（Robert Morris亦为MIT PDOS核心教授）、张铮（Zheng Zhang，时任MSRA）、吴鸣（Ming Wu，MSRA）等一批国际系统领域的重量级人物。对于一位当时尚未正式入学博士的研究者而言，以第三作者身份进入OSDI论文的作者列表，这是极为罕见的起点，也为他日后与国际系统社区的对话建立了信誉基础。

从复旦到交大的迁移，需要放在整个IPADS团队的历史脉络中理解。臧斌宇教授于2001年11月至2013年12月任复旦大学教授（曾任复旦大学软件学院院长），2014年1月转任上海交通大学教授（后任上海交大软件学院院长）；陈海波教授2004–2009年在复旦读博（获全国优秀博士学位论文），2009年4月至2011年12月在复旦任讲师，2011年9月/12月起转入上海交通大学任教授。陈榕的迁移时间（2012年1月/2月）恰好紧随陈海波之后、早于臧斌宇。也就是说，IPADS的核心班底本质上是一个从复旦大学整体迁移到上海交通大学的系统研究团队，陈榕是这一迁移中的关键第二梯队成员。这一"复旦系统"的历史渊源，是理解他此后学术合作网络高度内聚特征的根本原因。

## 三、学生培养情况

学生培养是陈榕学术网络中最具信息量的部分。据上海交大研究生院主页平台的统计口径，他已毕业学生29人、在校学生15人。其IPADS英文主页维护了一份相当完整的在校生与校友名单，本节以该名单为基础，结合各项目论文的署名顺序还原培养脉络。需要说明的是，主页列出的名单侧重于第一作者或有显著贡献的学生，与研究生院29人的行政统计口径存在差异（后者包含联合培养、行政挂靠等情形）。

### 3.1 已毕业博士生（6人可查）

陈榕独立或联合指导的博士生数量不多但质量极高，几乎每一位的博士论文都对应一个在国际顶会上完整展开的系统项目。

**魏星达（Xingda Wei，2021年毕业，与臧斌宇、陈海波联合指导）** 是陈榕最具代表性的学生。博士论文题为 *Fast Distributed Transaction Processing using RDMA and NVM*，核心工作覆盖 DrTM/DrTM+H、XStore、DST、librdpma 四个项目，博士期间的发表记录堪称惊人——SOSP 2015（一作）、EuroSys 2016（二作）、ATC 2017（一作）、ACM TOCS 35(1)（三作）、OSDI 2018（一作）、ATC 2019（二作）、OSDI 2020（一作）、NSDI 2021（一作）、ATC 2021（一作）、ACM TOS、IEEE TPDS 等。其博士论文获 **ACM SIGOPS Dennis M. Ritchie Doctoral Dissertation Award 优胜奖（Honorable Mention）**，是亚太地区首位获此殊荣的博士；同时获 ACM中国优秀博士论文提名奖、ACM ChinaSys优秀博士论文奖。他还曾获2018年微软学者奖学金和2020年华为奥林帕斯先锋奖（与陈榕同一团队）。毕业后直接留任 **上海交通大学长聘教轨副教授**，成为IPADS新一代骨干。目前魏星达已从"学生"身份转变为陈榕最重要的科研合作伙伴，二人共同领导"Modern AI Infrastructure"和"Emerging Distributed Systems"两个研究方向（陈榕主页中明确标注这两个方向为"collaborated with Xingda Wei, 2020--"），并共同指导博士生程荣鑫。

**沈思捷（Sijie Shen，2023年毕业，与臧斌宇联合指导）**，博士论文题为 *Efficient Large-scale Hybrid Transactional/Analytical Processing Systems*，主导 DrTM 与 Vegito 项目，发表 ATC 2017（二作）、OSDI 2021（一作，Vegito）、IEEE TPDS 33(10)（一作）、ATC 2023（一作，GART）。毕业后加入 **阿里巴巴集团，入选阿里星（AliStar）计划**——这是阿里面向全球顶尖博士毕业生的最高规格招聘计划，每年录取人数极少。值得注意的是，沈思捷在离开学术界后仍持续与陈榕团队合作，2025年的 ATC'25 KVCache论文和2026年的 OSDI'26 LMetric论文中他都是作者，形成了从"学生"到"工业界合作对接人"的角色转换。

**宋晓妞（Xiaoniu Song，2025年毕业）**，博士论文题为 *High-Performance GPU Caching System for Deep Learning*，主导 GNNLab、UGache、ProMoE 三个项目，发表 EuroSys 2022（三作）、SOSP 2023（一作，UGache）、ACM TOCS 44(1) No.3（一作）、ProMoE（arXiv一作）。毕业后加入 **Anuttacon**（一家由米哈游背景资本支持的AI游戏创业公司，创始人为米哈游联合创始人蔡浩宇）。这一去向体现出陈榕学生的就业选择已不局限于传统大厂，也进入前沿AI创业公司。

**韩明聪（Mingcong Han，2026年毕业）**，博士论文题为 *Heterogeneous Processors Scheduling System For Deep Learning Applications*，是陈榕GPU调度方向的核心执行者，主导 REEF、DISB、PICKER、XAuto、XSched 项目，发表 OSDI 2022（一作，REEF）、ICPP 2023（二作）、OSDI 2025（二作，XSched）、SOSP 2025（六作）、ATC 2025（三作）、ACM TOCS 44(1) No.1（一作）、EuroSys 2026（一作，PICKER）。毕业后加入 **字节跳动Top Seed计划**（字节跳动面向顶尖博士毕业生的大模型专项招聘计划，待遇与自由度对标业界最高水平）。

**张涵泽（Hanze Zhang，2026年毕业）**，博士论文题为 *Efficient Synchronization Methods for Heterogeneous Data Centers*，主导 FissLock、DecLock、DiFache 项目，发表 OSDI 2022（二作）、OSDI 2024（一作，FissLock）、ACM TOCS 44(1) No.1（四作）、ACM TOCS 44(1) No.6（一作）、VLDB 2026（一作）等。毕业后加入 **字节跳动**。

综合来看，已毕业的5位博士（另有1位2026届在统计口径上可能尚未完成手续）的去向呈现"1留任学界（上海交大教职）+ 4进入头部产业界（阿里星、字节Top Seed×2、AI创业公司）"的格局，且4位产业界去向全部是对应企业面向顶尖博士的最高档次通道。这在国内系统方向的博士培养中属于第一梯队水平。

## 四、学术合作网络

陈榕的合作网络具有极为鲜明的"高内聚、强纵深"特征——绝大部分论文的合作者集中在IPADS内部与少数几家深度绑定的企业实验室，跨机构的松散合作相对较少。这与许多广泛"撒网式"合作的学者形成对比，反映的是系统领域"一个团队长期攻坚一个系统栈"的研究范式。

### 4.1 IPADS内部核心合作圈

**陈海波（Haibo Chen）** 是陈榕合作最频繁、最持久的对象，几乎所有论文中都能看到二人的共同署名。二人的关系跨越了三重身份：复旦同级同学（同为2000年入复旦本科、2004年本科毕业）、复旦同门（同出臧斌宇门下，陈海波2009年博士毕业获全国优博）、上海交大IPADS的同事与所长-骨干关系。陈海波现为上海交通大学特聘教授、IPADS所长、领域操作系统教育部工程研究中心主任、人工智能操作系统研究院院长，国家杰青、ACM Fellow、IEEE Fellow、CCF Fellow，2023年7月至2025年6月任ACM SIGOPS主席（ACM SIGOPS自1965年创建以来首位北美以外的主席，也是我国学者首次担任ACM专委会主席）。二人的合作跨度从2006年的VEE论文一直延续到2026年的OSDI/EuroSys论文，长达二十年。在论文分工上，通常由陈榕担任通讯作者（主页中标注星号的论文绝大多数如此），陈海波置于作者列表末位，形成了稳定的"陈榕主导具体项目、陈海波提供战略把关"的协作模式。

**臧斌宇（Binyu Zang）** 既是陈榕的博士导师，也是持续的合作者。臧斌宇现为上海交通大学长聘教授、CCF会士，2024年获"CCF杰出教育奖"，曾任复旦大学软件学院院长与上海交通大学软件学院院长，2011年全国优秀博士学位论文指导教师。在陈榕独立带团队后，臧斌宇的角色从"导师"转为"共同指导人"——魏星达（2021）与沈思捷（2023）两位博士生均由陈榕与臧斌宇联合指导。二人的直接合作论文包括 VEE'06、ICPP'07、PACT'10、EuroSys'11、PPoPP'15、NSDI'21（DST）、ATC'21（远程持久内存刻画）、OSDI'21（Vegito）、ATC'23（GART）等。

**魏星达（Xingda Wei）** 的关系最为特殊，是陈榕学术网络中"学生—同事—共同PI"三重身份叠加的典型案例。作为2021年毕业的博士生留校任教后，魏星达迅速成长为陈榕的对等合作者。陈榕的主页明确将两个当前主力研究方向标注为"collaborated with Xingda Wei, 2020--"：Modern AI Infrastructure（KunServe、BlitzServing、Sirius、KVCache、ProMoE、GNNLab等）与Emerging Distributed Systems（Vegito/GART、MITOSIS、DecLock/DiFache、ANNS加速等）。二人在OSDI 2023（两篇：Mitosis与SmartNIC刻画）、EuroSys 2024（最佳论文）、SOSP 2025（PhoenixOS）、OSDI 2025（BlitzScale）、EuroSys 2026（KunServe）等论文中反复共同署名，并联合指导博士生程荣鑫。这种"师生反转为搭档"的结构在IPADS内部形成了一条清晰的学术传承链。

**夏虞斌（Yubin Xia）** 是IPADS另一位教授、博士生导师，国家级青年人才计划入选者、CCF杰出会员、ACM杰出会员，研究方向为操作系统与系统结构，曾获SOSP最佳论文奖、DSN十年时间验证奖、教育部技术发明一等奖、上海市技术发明一等奖等，现任上海交通大学-OpenHarmony技术俱乐部主任。需要指出的是，从陈榕主页公开的代表性论文列表来看，**陈榕与夏虞斌的直接共同署名论文并不多见**——二人虽同属IPADS且在多项国家级项目、教育部工程研究中心、以及国家技术发明奖等团队性成果中同为参与人，但在具体的OSDI/SOSP论文层面各有主攻方向（夏虞斌侧重系统安全、可信执行环境、微内核，陈榕侧重分布式性能与异构算力调度）。因此，二人的关系更准确的定位是"同一研究所内的平行方向负责人与机构级项目共同参与人"，而非高频论文共同作者。（用户背景信息中提及的"与魏星达、夏虞斌合著的OSDI/SOSP论文"，就魏星达部分完全成立且频次极高；夏虞斌部分在陈榕主页的代表作列表中未见明确对应，此处如实说明。）

**王肇国（Zhaoguo Wang）** 是IPADS教授，国家优青获得者、重点研发计划项目负责人，主攻分布式系统与数据库系统，曾获2023 ACM SIGMOD研究亮点奖、SIGMOD 2022最佳论文优胜奖、CCF青年科技奖、ACM ChinaSys新星奖、华为奥林帕斯先锋奖及两次华为火花奖。二人的合作有明确记录：NSDI 2021 的 DST（Decentralized Scalar Timestamp）论文中王肇国为第四作者，OSDI 2023 的 Automated Verification of Idempotence for Stateful Serverless Applications 中王肇国为第二作者（该文第一作者丁浩然为王肇国的学生）。这两篇论文分别落在事务时间戳排序与Serverless形式化验证方向，体现出陈榕与王肇国在"数据库/事务语义"与"系统实现"交界处的互补合作。

**顾金雨（Jinyu Gu）** 与 **吴明瑜（Mingyu Wu）** 是IPADS的年轻教师，在陈榕近期论文中多次出现：顾金雨参与 OSDI 2023 Mitosis 与 SOSP 2025 PhoenixOS，吴明瑜参与 EuroSys 2024 最佳论文。

此外，**管海兵（Haibing Guan）** 教授（上海交大区域高性能计算中心方向）参与了 PPoPP 2015 的 SYNC or ASYNC 论文。

## 五、业界合作关系深度分析

陈榕的产业合作是其学术网络中最具实质性的部分，主页自述"先后主持多项国家重点研发计划、自然科学基金等项目/课题，以及十余项企业合作项目"。这些合作不是浅层的横向课题，而是深度嵌入到具体系统产品线的联合研发。

### 5.1 华为：最深度的战略合作伙伴

华为是陈榕（及整个IPADS）最重要的产业合作方，合作层次覆盖奖项、联合实验室、人才输送与技术转化四个维度。

**奖项层面**，2020年陈榕团队获得 **首届华为奥林帕斯先锋奖（排名第1）**。当年的奥林帕斯奖体系中，清华大学舒继武教授团队获"奥林帕斯奖"及百万悬红，上海交通大学陈榕团队与华中科技大学冯丹教授团队分获"奥林帕斯先锋奖"（奖金50万元人民币）。奥林帕斯奖是华为面向全球征集数据存储领域世界级难题解决方案的最高规格学术奖项，历届获奖者包括郑纬民院士、Onur Mutlu、Torsten Hoefler、尤洋、金海等。2025年，陈榕团队又获得 **华为优秀技术合作项目奖**。

**联合实验室层面**，"上海交通大学-华为下一代异构并行操作系统联合实验室"（2022年1月–2026年12月）是陈榕主持的旗舰级产学研平台。这一联合实验室的定位——"下一代异构并行操作系统"——与陈榕2021年以来主推的研究方向（Operating Systems for GPUs, XPUs, and Beyond）高度重合，XSched、PhoenixOS、REEF、PICKER 等成果均在此框架下产出。XSched（OSDI'25）作为"跨多种XPU的统一抢占式调度框架"，其技术意图与华为昇腾（Ascend）NPU生态对异构算力统一调度的需求高度对应（此处为基于技术方向与合作背景的**推测**性判断，官方文献未明示与昇腾产品线的直接绑定）。

**存储与AI基础设施层面**，FAST'26 的 "Fast cloud storage for AI jobs at Huawei Cloud"（AI-Turbo）是直接冠以华为云名义的联合研究成果，说明合作已进入华为云生产系统的真实负载刻画与优化层面。OSDI'25 的 BlitzScale 中华为云的单一舟（Yizhou Shan）为共同作者。

**奖项与人才层面**，陈榕2023年获国家技术发明二等奖（排名第6）、2019年上海市技术发明一等奖（排名第4）、2018年教育部技术发明一等奖（排名第3），这三项均为IPADS团队集体成果，与华为方向的操作系统技术转化密切相关。IPADS另一位教授陈海波以第一完成人身份获得CCF科技进步特等奖（"OpenHarmony智能终端操作系统基座"项目，完成单位包括华为技术有限公司、上海交通大学和中国科学院软件研究所），可见IPADS与华为的整体绑定深度。人才输送方面，2020年（王宁、王思远）与2021年（龚振涵）共有三位硕士毕业生进入华为。

### 5.2 阿里巴巴：图计算与AI推理的双线合作

与阿里巴巴的合作是陈榕产业网络中论文产出最密集的一条线，参与的阿里方研究人员形成了稳定的班底。

**图神经网络与图计算方向**：EuroSys 2021 的 FlexGraph 与 EuroSys 2022 的 GNNLab 均为陈榕（通讯作者）与阿里巴巴团队的联合成果，阿里方作者包括 **王磊（Lei Wang）**、**尹强（Qiang Yin）**、**田超（Chao Tian）**、**余文渊（Wenyuan Yu）** 与 **周靖人（Jingren Zhou，阿里云CTO兼达摩院院长）**。ATC 2023 的 GART（Bridging the Gap between Relational OLTP and Graph-based OLAP）作者列表更为庞大，除陈榕团队外还包括阿里的王磊、**赖龙彬（Longbin Lai）**、**陶乾（Qian Tao）**、**苏立（Li Su）**、余文渊、周靖人。这一系列工作直接支撑了阿里的图计算平台（GraphScope生态）建设。

**大模型推理与KVCache方向**：ATC 2025 的 "KVCache Cache in the Wild: Characterizing and Optimizing KVCache Cache at a Large Cloud Provider" 是与阿里云的深度合作成果，作者包括陈榕的博士毕业生沈思捷（现阿里星）、阿里的**方晨光（Chenguang Fang）**与余文渊。更值得注意的是，该研究配套开源了 **阿里通义千问百炼平台的真实使用轨迹数据集**（github.com/alibaba-edu/qwen-bailian-usagetraces-anon）——能够获得并公开发布头部云厂商大模型服务的生产级trace，这在学术界是极为稀缺的资源，反映了双方合作的信任层级。OSDI 2026 的 LMetric（Simple is Better: Multiplication May Be All You Need for LLM Request Scheduling）延续了这一合作，作者中同样包含沈思捷、方晨光、余文渊、周靖人。

**科研项目层面**，"超大规模图神经网络训练GPU加速方法的研究"（2023年3月–2024年3月）是与阿里方向对应的横向课题。

**人才输送层面**，2015年王鹏、2018年薛翔、2019年姚有杨与周晓丽、2023年沈思捷（阿里星）、2024年施琳（阿里云）陆续进入阿里体系，形成了长期的校友通道。

### 5.3 三星、字节跳动与其他

**三星**：陈榕主持"三星技术咨询服务"项目（2025年8月–2026年8月），属于国际企业的技术咨询类合作。

**字节跳动**：2026届两位博士毕业生韩明聪（Top Seed计划）与张涵泽同时进入字节跳动，加上2022届硕士吴金奇，字节已成为陈榕学生的重要去向。目前尚未见到陈榕与字节跳动的联合署名论文（此处基于主页公开论文列表判断）。

**昆仑芯（百度旗下AI芯片公司）**：2024年王天霞、2025年彭冠文两位硕士生进入昆仑芯，方向与陈榕的XPU调度研究高度契合。

**英伟达**：2025年张一雯（SOSP 2023 UGache 二作）加入英伟达。

**量化交易机构**：Jump Trading、Optiver、九坤投资、中金所、世纪前沿——这条通道从2023年起逐年扩大，是陈榕团队低延迟系统技术（RDMA、内存事务、锁管理）在金融科技领域的间接价值体现。

### 5.4 开源生态建设

陈榕团队在开源方面的投入相当系统化，几乎每个主要项目都配套发布了可复现的开源实现，主要托管于 GitHub 的 SJTU-IPADS、XpuOS、blitz-serving、ProjectMitosisOS、SiriusInfTra、smartnickit-project 等组织下。代表性开源项目包括 XSched、PhoenixOS、REEF、UGache、GNNLab、KunServe、DrTM、DrTM+H、XStore、DST、Wukong 系列、librdpma、KRCORE、FissLock、Vegito、DISB（推理基准测试套件）等。多篇论文获得 USENIX 全部三项徽章（Artifacts Available / Artifacts Functional / Results Reproduced）或 ACM Badges v1.1 认证，GNNLab 更获得 EuroSys 2022 Gilles Muller 最佳制品奖优胜奖（Honorable Mention）。陈榕2022年做过一场题为 "Evaluation-centric Research: Experiences from A Decade of Systems Research" 的报告，反映出他在方法论层面对可复现性的自觉重视。

## 七、Connection圈层总结

以陈榕为中心，其学术关系网络可以清晰地划分为五个圈层。这一网络的最大特征是"垂直深度远大于水平广度"——他不是一位广泛撒网的合作者，而是在一条从复旦到交大、从多核OS到异构算力OS的主线上，与少数几组人建立了极长时间跨度的深度绑定。

### 第一圈层：师承与同门内核（复旦血脉）

这一圈层由 **臧斌宇** 与 **陈海波** 构成，是陈榕整个学术生涯的根基。臧斌宇是其博士导师，二人的合作从2006年VEE延续到2023年ATC，横跨18年，并在魏星达、沈思捷两位博士生的培养上继续以"联合指导"的方式延续师承。陈海波则是同级同门加二十年搭档，从复旦本科同届到IPADS所长-骨干的关系，是陈榕几乎每一篇顶会论文的共同作者。这个三人组从复旦大学整体迁移至上海交通大学，构成了IPADS的创始内核。理解陈榕的学术网络，必须先理解这是一个"复旦系统学派"在上海交大的延续与扩张。

### 第二圈层：亲传弟子与"学生转同事"链（IPADS新生代）

这一圈层的核心是 **魏星达**——他完成了从"陈榕的博士生"到"陈榕的对等合作PI"的完整跃迁，目前与陈榕共同领导两个主力研究方向并联合指导博士生。这条"师生反转"链是陈榕网络中最具活力的部分，也是IPADS学术传承机制的典型样本。

其次是已毕业的博士 **沈思捷**（阿里星）、**宋晓妞**（Anuttacon）、**韩明聪**（字节Top Seed）、**张涵泽**（字节跳动），以及在校的 **王佳丽**、**程荣鑫**、**沈炜航**、**杨金荣**。这一圈层的显著特征是"每人对应一个完整系统项目"——沈思捷对应Vegito/GART、宋晓妞对应GNNLab/UGache、韩明聪对应REEF/XSched、张涵泽对应FissLock/DecLock、沈炜航对应XSched/PICKER。这种"一人一系统"的培养模式使得每位博士毕业时都带着一份可辨识的技术资产进入产业界，也解释了为何他们能够进入各企业面向顶尖博士的最高档次通道。

在硕士层面，**陈彦哲**、**时佳新**、**姚有杨**、**谢晨宁**、**杨建邦**、**卢方明**、**张一雯**、**程可** 等人虽为硕士，却承担了 DrTM+R、Wukong、PowerSwitch、GNNLab、EuroSys'24最佳论文、UGache、FissLock 等重量级工作的第一作者或核心作者角色。陈榕对硕士生科研强度的要求显著高于常规水平，这是其团队高产出的重要来源。

本科生层面，**张运昊**（本科生独立完成SOSP'17一作，赴康奈尔）与 **张凯源**（本科生独立完成PPoPP'15一作，赴华盛顿大学）代表了这条链的极致案例。加上赴宾大的 **钟可** 与赴JHU的 **娄畅**，构成了一条通往北美顶尖系统研究组的输送通道。

### 第三圈层：IPADS平行同事（机构内协作）

这一圈层包括 **夏虞斌**（操作系统与系统安全，ACM/CCF杰出会员）、**王肇国**（分布式系统与数据库，国家优青）、**顾金雨**、**吴明瑜**，以及交大内部的 **管海兵**。这些人与陈榕的关系是"同一屋檐下的平行方向负责人"——在具体论文层面的共同署名频次不如第一、第二圈层，但在国家重点研发计划、教育部工程研究中心、国家技术发明奖等机构级成果中共同参与。其中王肇国与陈榕在 NSDI'21 DST 与 OSDI'23 Serverless幂等性验证两篇论文上有明确的实质性合作；顾金雨与吴明瑜则在近期的 Mitosis、PhoenixOS、EuroSys'24 等项目中频繁出现。需要客观指出的是，陈榕与夏虞斌之间未见高频的论文级直接合作，二者更多是研究所层面的战略同盟关系。

### 第四圈层：产业界深度绑定网络

这一圈层是陈榕网络中最具"重量"的部分，由三条主线构成。

**华为线** 最为厚重：首届奥林帕斯先锋奖（2020，排1）、上海交通大学-华为下一代异构并行操作系统联合实验室（2022–2026）、华为优秀技术合作项目奖（2025）、FAST'26 华为云AI存储论文、OSDI'25 BlitzScale 中的华为云单一舟，加上三位硕士毕业生入职华为。这条线的实质是IPADS整体与华为在国产操作系统（含OpenHarmony、昇腾算力生态）上的长期战略绑定，陈榕负责其中"异构并行操作系统"这一关键板块。

**阿里线** 最为高产：从 OSDI'16 Wukong 中的李飞飞开始，到 FlexGraph（EuroSys'21）、GNNLab（EuroSys'22）、GART（ATC'23）、KVCache刻画（ATC'25）、LMetric（OSDI'26），与阿里方的 **周靖人**（阿里云CTO）、**余文渊**、**王磊**、**尹强**、**赖龙彬**、**方晨光** 等形成稳定的联合作者班底。这条线的独特价值在于陈榕团队能够获取并公开阿里通义千问百炼平台的生产级使用轨迹，这是极稀缺的学术资源。加上沈思捷（阿里星）等六位校友入职阿里，形成了完整的"论文合作+人才输送+数据获取"闭环。

**其他产业节点** 包括三星（技术咨询服务）、昆仑芯（两位硕士）、英伟达、字节跳动（三位毕业生）、苹果、微软、腾讯、百度、谷歌、PayPal，以及Jump Trading、Optiver、九坤投资、中金所、世纪前沿等一批量化交易机构。量化金融这条通道是2023年之后新出现的，与陈榕团队在RDMA低延迟、内存事务、锁管理等技术上的积累直接相关，构成了一条区别于传统互联网就业的差异化路径。

### 第五圈层：国际学术共同体

这一圈层相对松散但起点极高。**MIT PDOS** 组（Frans Kaashoek、Robert Morris、Silas Boyd-Wickizer 等）通过 OSDI'08 Corey 建立联系，是陈榕进入国际系统社区的"入场券"。**Pen-Chung Yew（明尼苏达大学）** 通过 VEE'06 与 ICPP'07 与其合作，指向复旦时期的历史国际联系。**微软亚洲研究院**（张铮、吴鸣、Lex Stein）是Corey合作的中介平台。**新加坡国立大学** 通过2014–2015年的访问教授经历建立机构联系。**李飞飞**（原犹他大学，现阿里云）则是从学界跨向业界的桥梁人物。

在社区服务层面，陈榕通过担任 ACM TOCS 副编辑、OSDI/SOSP/EuroSys/ASPLOS 四大顶会的多届PC委员（EuroSys 连续五届）、SOSP 2021 AMA共同组织者等角色，已经从"论文作者"进入了"领域守门人"的位置。这一层身份的实质影响力，往往超过论文数量本身。

### 网络的整体判断

综观五个圈层，陈榕的学术关系网络呈现出三个结构性特征。

其一是 **"复旦-交大双城单脉"的师承结构**。整个网络的根基不是分散的多师承，而是臧斌宇一脉从复旦到交大的完整迁移。这使得IPADS内部的信任成本极低，也使得陈榕能够在长达二十年的时间尺度上与同一批人推进同一条技术主线。

其二是 **"一人一系统"的培养机制与随之而来的产业溢出**。每位博士生对应一个从设计到开源到顶会发表的完整系统，这既保证了学术产出质量，也使得学生毕业时具有可辨识、可迁移的技术资产。29位毕业生中，进入阿里星、字节Top Seed这类顶尖通道的比例极高，进入量化交易与AI芯片这类高技术门槛领域的比例也在快速上升。

其三是 **"研究方向随算力形态演进而快速转身"的能力**。从多核OS（2004–2012）→ 大规模图分析（2012–2015）→ RDMA事务与存储（2014–2020）→ 图查询（2015–2021）→ 数据中心网络（2020–2025）→ GPU/XPU操作系统与AI基础设施（2021至今），陈榕在二十年间完成了五次以上的方向切换，且每次切换后都能在3年内产出OSDI/SOSP级别的成果。这种转身能力的底层支撑，正是其网络中华为、阿里等产业伙伴对真实负载与前沿硬件的持续供给——这也是本报告认为其产业合作不应被视作"横向课题"，而应视作其学术生命力的核心组成部分的原因。
