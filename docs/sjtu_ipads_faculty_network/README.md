## 二、十四位教师的角色定位

陈海波是IPADS研究所的创始所长，特聘教授，ACM/IEEE/CCF三料会士，国家杰出青年基金获得者，曾任华为操作系统首席科学家，是开源鸿蒙项目群技术指导委员会创始主席。他自复旦大学时代起即在操作系统与系统软件领域深耕，率队将整个研究团队从复旦大学迁移至上海交大，是IPADS学术网络与产业网络的绝对中枢，几乎所有其他13位教师都与其存在直接的师承、合作或同事关系。

臧斌宇是IPADS的奠基元老，CCF会士，早在复旦大学时期即招募本科生陈海波加入其研究团队并担任其博士导师，后又主导推动整个团队从复旦转会上海交大。他是陈海波的博士导师，也是这一学术家族"承上启下"的关键人物，目前更多承担软件学院教学体系建设与工程教育认证方面的领导角色。

陈榕教授是IPADS早期核心成员之一，与陈海波、夏虞斌同属复旦转会上海交大的团队，博士导师为臧斌宇，长期专注操作系统与分布式系统研究，指导培养的学生数量在组内名列前茅，毕业生广泛分布于字节跳动、阿里巴巴、Jump Trading、Optiver等企业及Google、苹果等海外机构。

夏虞斌教授的求学背景较为特殊，博士毕业于北京大学（师从程旭教授），并非复旦系出身，2012年加入上海交大后才与陈海波、臧斌宇成为同事，现任软件学院副院长，是"蓬莱"可信执行环境系统的发起人，在RISC-V安全生态和openEuler社区中影响广泛。

王肇国教授本科毕业于南京大学软件学院，博士毕业于复旦大学，后赴纽约大学从事博士后与助理教授工作，2018年加入上海交大，主要研究分布式系统与数据库系统，与古金宇等人在数据库智能化方向合作密切，是OpenHarmony智能数据管理技术组负责人。

糜泽羽副教授、魏星达长聘教轨副教授、古金宇副研究员、华志超副研究员均为IPADS"土生土长"培养出的青年骨干，本科或博士均就读于上海交大，师承陈海波、臧斌宇、夏虞斌等资深教授（部分为联合指导），毕业后直接留校任教，代表了IPADS人才培养体系的自我造血能力。其中糜泽羽因PowerInfer开源项目和大模型端侧推理研究广受关注，并已创业成立独立公司；魏星达在RDMA分布式系统领域屡获国际奖项；古金宇深度参与开源鸿蒙生态的多项产学研落地项目；华志超近年转向可信执行环境与大模型安全交叉方向。

吴明瑜副教授的博士导师明确为陈海波，专注高级语言虚拟机与持久内存领域，与阿里巴巴Dragonwell JDK团队保持密切合作，研究成果已合入OpenJDK、CPython等主流开源项目。

董明凯副研究员和杜冬冬副研究员是另外两位由IPADS自主培养的青年研究员，均在陈海波等资深教授联合指导下完成博士学业后留所工作。董明凯以EROFS文件系统进入Linux内核主线并成为Android官方分区文件系统这一产学研成功案例著称，近年又转向DNA存储这一前沿交叉方向；杜冬冬则在Serverless计算和可信执行环境领域持续产出，并在RISC-V国际基金会等开源治理组织中担任职务。

冯二虎助理教授是一位特殊案例：他在IPADS完成博士培养后，于2025年转入新成立的人工智能学院担任tenure-track助理教授，但仍与IPADS团队保持紧密的科研协作关系，其研究成果已影响到AMD、苹果、高通等国际芯片厂商的产品安全设计。

余炀助理研究员的履历在全组中独树一帜：他于复旦大学取得博士学位后，并未直接进入学术界，而是在中国农业银行数据中心和一家科技公司担任了近八年的产业界职务，直至2024年才回归学术界加入上海交大IPADS，是团队中少有的"产研双重经历"型学者，其研究方向也延续了这段经历，聚焦开源鸿蒙操作系统在金融、电力、港口等关键基础设施行业的落地。

## 三、全研究所关系网络的整体观察

IPADS研究所的师资网络呈现出几个较为清晰的结构性特征。

第一是"复旦转会"奠定的历史根基与"自我造血"的当代格局并存。陈海波、臧斌宇、陈榕三人构成了从复旦大学并行处理研究所整体迁移至上海交大的历史主线，这一"团队转会"事件是理解IPADS组织基因的关键背景；而糜泽羽、魏星达、古金宇、华志超、吴明瑜、董明凯、杜冬冬等七位青年教师均为上海交大本地培养、毕业后直接留所任教的"土著"人才，形成了清晰的"创始一代—土著新生代"两层学术传承结构，师承关系高度集中于陈海波、臧斌宇、夏虞斌三人的联合指导网络。

第二是"基础研究—开源生态—产业落地"三位一体的产学研贯通模式，这是IPADS区别于许多同类实验室的最突出特征。具体案例包括：EROFS文件系统进入Linux内核主线并成为Android系统官方分区文件系统（董明凯）；PowerInfer开源项目在大模型端侧推理领域产生广泛影响并已孵化为独立创业公司（糜泽羽）；蓬莱可信执行环境系统进入openEuler发行版并催生了独立创业公司TrustKernel（夏虞斌）；开源鸿蒙操作系统在航天卫星、南方电网电力物联网、OPPO智能终端等多个关键基础设施场景的规模化落地（古金宇、余炀）；EIDS等与阿里巴巴的直接联合研发项目（华志超）；Dragonwell JDK相关成果合入OpenJDK主线（吴明瑜）。这些案例共同构成了从操作系统内核到上层应用系统的全栈产学研图谱，与IPADS"顶天立地"的系统软件研究定位高度一致。

第三是与华为的合作关系尤为深厚且贯穿几乎每一位教师。openEuler、OpenHarmony两大开源操作系统生态的技术指导委员会中均有IPADS教师担任重要职务（陈海波为开源鸿蒙TSC创始主席，夏虞斌任上海交大-OpenHarmony技术俱乐部主任，臧斌宇、王肇国、古金宇等亦有相应任职），"华为火花奖""华为奥林帕斯先锋奖"等企业奖项在青年教师群体中获奖密度很高（魏星达、董明凯等均两次获奖），体现出IPADS与华为在操作系统底层技术上的长期战略绑定关系。

第四是"大导全覆盖"与"小导快速成长"的指导梯队。14位教师中有9位已具备独立招收博士生的资格，仅董明凯、杜冬冬、冯二虎、余炀四位最年轻的研究系列/助理教授级教师尚未见到独立招生的公开记录，但均已在合作指导或团队协作中承担实质性的学生培养职责。已毕业学生的去向呈现出鲜明的"学术—产业—量化金融"三条路径：学术路径覆盖字节跳动Seed、DeepSeek等前沿AI机构以及高校教职；产业路径高度集中于华为、阿里巴巴、字节跳动等中国头部科技企业；此外还有相当比例的毕业生进入Jump Trading、Optiver、九坤投资等量化交易机构，这一去向特征在多位教师的报告中均有体现，是IPADS毕业生就业图谱的一个鲜明特色。

第五是职称信息因人事序列不同而存在滞后与差异的问题。上海交大计算机学院与软件学院分属不同的人事管理序列，加之近年学院机构调整（如计算机学院从电子信息与电气工程学院中独立、人工智能学院新设），导致古金宇、华志超、杜冬冬、董明凯等多位教师在不同官方页面上出现"副教授"与"副研究员"、"助理研究员"与"副研究员"等新旧职称表述并存的情况。本系列报告统一以计算机学院最新教师名录为权威依据，并在正文中如实说明这一信息滞后现象，不作武断判断。
