# 上海交通大学 APEX数据与知识管理实验室 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

APEX 数据与知识管理实验室（APEX Data and Knowledge Management Lab）隶属于上海交通大学计算机学院计算机应用研究所，由俞勇特聘教授于1990年代末创建并担任负责人，是国内历史最悠久的互联网数据挖掘与机器学习研究团队之一。实验室官网将其组织为数据挖掘、强化学习、多智能体学习、机器学习系统四个研究组，规模约21名博士生、11名硕士生、17名本科生，研究方向覆盖推荐系统、强化学习与决策智能、LLM 智能体与具身智能。俞勇教授更广为人知的身份是上海交大 ACM 班（2002年创办）创始人和 ACM-ICPC 世界冠军队（2002、2005、2010 三冠）教练，其"ACM 班—ACM 竞赛队—APEX 实验室"三位一体的培养体系输出了被称为"中国AI黄金一代"的大批人才（李磊、李沐、陈天奇、杨笛一、戴文渊、林晨曦等）。

现任学术带头层包括：俞勇（负责人、特聘教授，2018年创办伯禹教育并任董事长，2025年与张一鸣共同发起知春创新中心）、张伟楠（教授、计算机应用研究所副所长，强化学习与智能体方向的实际学术负责人，UCL 博士、与汪军长期合作）、刘卫文（长聘教轨副教授，曾任华为诺亚方舟实验室主任工程师）、林江浩（助理教授，安泰经管学院，张伟楠与俞勇联合指导博士毕业生）、温睦宁（研究副教授，张伟楠与温颖联合指导博士毕业生，兼任人工智能学院研究助理教授）。同属计算机应用研究所的智能语音团队（钱彦旻 AudioCC 实验室）与图形学数字人团队（潘烨）另见 [sjtu_audiocc_faculty_network](../sjtu_audiocc_faculty_network/) 目录与潘烨报告；马利庄、盛斌的 DCVLab 已有独立目录覆盖。

## 圈层结构概述

APEX 的学术网络以俞勇为源头与组织核心，但其谱系结构与常见认知有一处重要修正：张伟楠是俞勇创办的 ACM 班本科毕业生（2011届），博士阶段就读于 UCL（第三方权威报道记载其导师为汪军），2016年回校任教后成为俞勇在 APEX 的学术衣钵继承者与联合指导伙伴——二人为"班系传承+同事合作"关系而非博士师生关系。俞勇直接指导的研究生圈包括戴文渊（第四范式创始人）、王昊奋、沈键（《动手学强化学习》合著者）、林江浩（俞勇与张伟楠联合指导）等；ACM 班校友圈（李磊、李沐、陈天奇、杨笛一等640余人）是其影响力最外扩的一层，但须与研究生严格区分。张伟楠的网络则以 UCL 汪军为最强跨机构节点（SeqGAN、IRGAN、MAgent、MALib、SMARTS 等合作），并以强化学习教育生态（RLChina、Easy RL）延伸至开发者社区；产业合作达摩院青橙奖、华为诺亚方舟（SMARTS）等。潘烨（UCL 博士、迪士尼研究院）代表计算机应用研究所内另一支外引型力量，与马利庄（DCVLab）存在联合指导博士生的跨实验室纽带。
