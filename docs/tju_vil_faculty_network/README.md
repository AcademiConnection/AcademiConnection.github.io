# 天津大学智能与计算学部 视觉智能实验室（ViL）学术关系网络报告

> 报告生成时间：2026年8月24日
> 报告组标识：TJU-VIL

## 团队说明

本报告组对应"天津大学智能与计算学部视觉智能实验室"（Visual Intelligence Laboratory, ViL，主页 http://www.tjuvil.net/ ）。实验室由冯伟讲席教授领衔，核心方向为开放环境微变视觉感知、多视角视频协同分析、计算机视觉与机器学习及其产业化应用（文物本体微变监测为代表）。已核查既有报告目录（tju_wise软件工程团队等），ViL此前未被覆盖，无重复。

依据ViL官网教师页及补充核实，本报告组覆盖7位教师：冯伟、万亮、尚凡华、刘红英、林迪、张乾、潘志一（2025年7月新加入，官网教师页更新滞后，据其个人主页确认）。其中林迪为IDV Lab负责人（与ViL网络高度重叠），刘红英行政隶属医学院（医工双栖），报告中均已如实说明。

## 团队核心脉络

**冯伟**：西北工业大学本硕（1996-2003）、香港城市大学博士（2004-2008，导师据推断为刘志强）、香港中文大学博士后，2010年加入天大。研究方向为主动机器人视觉与微变视觉感知，主导文物本体微变监测系统（"物体指纹"技术），应用于敦煌莫高窟、故宫等21省71家文博单位，成果入选国家"十三五"科技创新成就展，获2025年度天津市技术发明一等奖。

**万亮**：与冯伟为西北工业大学同期同窗（本硕1996-2003，据公开履历推断），香港中文大学博士，2011年加入天大。现为英才教授、医学院副院长，研究方向为计算机视觉与智能医学图像分析（域泛化、多模态），指导学生获MICCAI FLARE 2024国际挑战赛冠军。

**尚凡华**：西安电子科技大学博士（焦李成实验室），杜克大学/香港中文大学博士后，2018-2022年任西电教授，2022年加入天大任英才教授。研究方向为优化算法及理论（VR-SGD、随机ADMM等）、隐私保护与联邦学习，与罗智泉、林宙辰、James Cheng等优化领域学者合作密切。

**刘红英**：西安电子科技大学本硕、早稻田大学博士（导师Satoshi Goto）、焦李成博士后，2023年入职天大医学院任英才副教授。与尚凡华自西电时期起长期合作（"优化方法+图像应用"组合），现与万亮共同带领智能医学影像分析团队，是ViL与医学院之间的医工桥接节点。

**林迪**：中山大学学士、香港中文大学博士，长聘副教授。TAGNet（TPAMI 2022）等成果与冯伟联合，与冯伟共享博士生培养（丁良锋等），IDV Lab与ViL网络高度重叠。

**张乾**：冯伟指导的博士（2023年答辩毕业留校），"长周期深耕型"学者——自2015年硕士阶段即参与微变检测研究，现为团队现场系统工程化骨干与对外技术代言人。

**潘志一**：山东大学泰山学堂本科、山大硕士（屠长河/Yangyan Li联合指导）、北京大学博士（李戈，2025年毕业），2025年7月加入ViL。弱监督点云语义分割方向（NeurIPS 2024 DGNet、AAAI、TPAMI一作多篇），核心合作者包括高伟（北大深研院）、蒋鹏、屠长河（山东大学IRC团队负责人）、腾讯刘杉等。

**团队网络特征**：以冯伟为绝对中心的"双核同窗"结构（冯伟-万亮西工大同窗），西电系（尚凡华-刘红英）与北大系（潘志一）两翼注入；产业侧以文博行业（敦煌研究院、故宫、恒达文博等）深度产学研合作为特色；学生网络中韩瑞泽（深圳理工大学助理教授、2024 CAAI优博激励计划）等已向外扩散。
