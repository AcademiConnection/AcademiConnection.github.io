## 五、业界合作关系深度分析

### 5.1 核心业界伙伴

1. **文博机构（依托国家重点研发计划专项）**：作为国家重点研发计划"重大自然风险灾害监测预警与防范"专项《数字文化遗产安全保护与利用关键技术研究和示范》项目负责人，其团队成果已在**敦煌研究院、湖南博物院**部署使用（据ViL实验室主页"数字文化遗产安全保护与利用"方向介绍：众智标注平台1套、数字文化遗产智能计算引擎、论文6篇、发明专利5项、软著5项）。更广意义上，ViL整体成果覆盖故宫、兵马俑等数十个遗产地与博物馆。
2. **医疗机构（依托医学影像方向）**：ViL主页明确其医学影像方向"和多家医院开展密切合作"；天津市自然科学基金项目"基于多模态深度学习的脑膜瘤脑侵袭与分级术前影像预测"为与医院联合主持项目（据医学院页面）。2025年5月其在CCF数字医学分会活动中与天津医科大学总医院医学影像科刘风副教授等同台研讨，推断天津本地三甲医院是其主要临床合作方（具体医院名单待核实）。
3. **阿里云天池平台**：2025年1月指导学生陈强等获天池数据算法赛之智源行业数据应用大模型挑战赛（医学赛道）开发组第一名，体现团队与产业界数据竞赛生态的对接。
4. **政府与智库**：完成中国工程科技发展战略天津研究院重点咨询研究项目《天津市智能医疗产业发展研究》，并曾承担"天津市移动医疗设备产业技术创新战略"相关研究（2018-2019），对天津市智能医疗产业政策有直接智力输出。

### 5.2 产学研合作模式

万亮的业界合作呈现**"国家任务牵引+医工交叉转化+区域产业咨询"**的三元模式：

- **国家任务牵引型**：以国家重点研发计划首席科学家身份，组织"关键技术攻关—示范工程—文博机构落地"的完整链条，敦煌、湖南博物院的部署是典型的示范应用模式；
- **医工交叉转化型**：依托医学院副院长行政职务与教育部智能医学工程专业"101计划"《智能医学影像分析》核心课程牵头专家身份，将CV技术（域泛化、多模态学习）转化为医学人才培养体系与临床科研合作（脑膜瘤术前预测、医学报告生成等）；
- **区域产业咨询型**：通过工程科技智库咨询项目服务天津市智能医疗与移动医疗设备产业规划，属于"科学家进智库"的软科学合作模式。

总体来看，其业界网络以事业单位（博物馆、医院）和政府智库为主，商业化企业合作相对克制，与冯伟偏重文博装备的路线形成互补——万亮更多承担医学方向的产业化与教育标准化输出。

## 七、Connection圈层总结

万亮教授的学术关系网络可以概括为**"一核两翼一桥梁"**：

- **一核：ViL双核心**。与冯伟的西北工业大学同窗渊源（1996-2003本硕同期）是整个网络的起点，两人2010/2011年先后加入天津大学后共建视觉智能实验室，形成"冯伟—万亮"双核心，联合署名跨越图形学、阴影检测、手语识别、医学影像约十五年，联合指导的学生（章成超、高丽清、胡连宇等）同时出现在两人主页动态中。
- **两翼：香港学术圈与医学共同体**。其一翼为以香港中文大学（Pheng-Ann Heng、黄田津）、港城大（侯军辉、宋林琦）、港理工、港大构成的香港学术走廊；另一翼为MICCAI/IEEE TMI/IEEE JBHI医学影像共同体及天津本地医院网络（天津医科大学总医院等，推断）。
- **一桥梁：医工交叉的制度化桥梁**。作为计算机学科出身却担任医学院副院长的学者，万亮把ViL的视觉技术（域泛化、多模态）制度化地导入天津大学智能医学工程体系——从"101计划"核心课程牵头，到国家重点研发计划医学信息图计算课题，再到天津市智能医疗产业咨询，她是天津大学"新医科"版图中计算机视觉方的关键节点人物。

**圈层强度评估**：与冯伟的同窗+共事纽带（极强）；与朱磊、Pheng-Ann Heng、Song Wang等的长期论文合作（强）；与敦煌研究院、湖南博物院、天津医院的任务型合作（中强，依托国家项目）；与学生群体（李佳燨、高丽清、章成超、王正扬、赵俊庭、胡连宇、张玉鹏、刘天灵、陈强等）的师承纽带（持续扩张中，2024-2025年成果井喷）。

**对潜在合作者的启示**：希望与万亮建立连接的路径，最自然的是通过ViL实验室（冯伟—万亮双导师体系）的研究生/博士后通道，或通过医学影像多模态方向（其当前报告主题"面向精准诊疗的多模态医学影像理解"）的学术合作；业界方面，文博数字化与医学AI落地两个场景均已在国家级项目中跑通示范模式。教育背景中2007-2011年的履历空窗与博士导师信息、医学院副院长任职时间等细节仍待进一步核实。
