## 二、教育背景与职业履历

崔勇于1995年考入清华大学计算机科学与技术系，1999年获得清华大学工学学士学位，随后在清华继续攻读博士学位，2004年获工学博士学位。他的本科和博士教育均在清华大学计算机系完成，属于"清华土著"学者。据公开资料，其博士期间研究方向即聚焦于互联网体系结构与IPv6过渡技术。

## 三、学生培养情况

崔勇作为博士生导师，培养了多位在网络领域具有影响力的青年学者和产业骨干。以下列举代表性学生：

### 1. 赖泽祺（副教授，博士毕业生）

赖泽祺于2013年9月至2018年7月在清华大学计算机系攻读博士学位，导师为崔勇教授。博士期间（2016年9月至2017年10月）获联合培养机会赴美国普渡大学（Purdue University）电气与计算机工程系访学，合作导师为Y. Charlie Hu教授。博士毕业后，赖泽祺先加入腾讯科技（深圳）有限公司CSIG多媒体实验室担任高级研究员，负责腾讯会议音视频网络传输引擎中的低延迟拥塞控制算法研发。2019年12月，他以水木学者计划回到清华网络科学与网络空间研究院，先后担任助理研究员（合作导师吴建平教授）、助理教授（2022年起），现已晋升为副教授、博士生导师。赖泽祺的研究方向聚焦天地一体化互联网体系结构和网络空间安全，在MobiCom、NSDI、INFOCOM、S&P、NDSS等国际顶级会议和ToN、TMC等顶刊上累计发表CCF-A类论文29篇，并获得USENIX NSDI 2024杰出论文奖。他是崔勇学生中最具代表性的一位，不仅在学术上延续并拓展了导师的网络体系结构研究方向，还实现了从产业界到学术界的成功转型。

### 2. 王莫非（Mowei Wang，博士毕业生，核心合作者）

王莫非是崔勇指导的博士研究生，是其研究团队中最高产的合作者之一。从崔勇教师主页的论文列表可见，王莫非以第一作者或共同作者身份在IEEE Network、ACM SIGMETRICS、IEEE INFOCOM等顶级会议和期刊上发表了大量论文，研究主题涵盖机器学习与网络、数据中心网络拓扑自适应（Smart DCN）、网络数字孪生（Digital Twin for Networking）、图神经网络网络性能建模（xNet）等。其代表性工作包括"Machine Learning for Networking: Workflow, Advances and Opportunities"（IEEE Network 2018）和"Neural Network Meets DCN: Traffic-driven Topology Adaptation with Deep Learning"（ACM SIGMETRICS 2018）等。王莫非在崔勇团队中扮演了数据驱动网络研究方向的领军角色，其工作极大推动了机器学习在网络领域的应用研究。据公开资料，王莫非与崔勇持续合作发表高水平论文，是崔勇团队中的核心成员。

### 3. 肖思含（Shihan Xiao，博士毕业生）

肖思含是崔勇指导的博士生，在数据中心网络和无线网络方向有深度贡献。其代表性工作包括"Diamond: Nesting the Data Center Network with Wireless Rings in 3D Space"（NSDI 2016，后扩展发表于IEEE/ACM Transactions on Networking 2018），提出了在三维空间中用无线环嵌套数据中心网络的创新架构。此外，肖思含还在移动设备能耗优化、流量感知虚拟机迁移等方面发表了多篇论文（IEEE TMC、IEEE INFOCOM等），并与崔勇合作完成了多项关于数据中心网络拓扑自适应和流量调度的研究。据公开论文记录，肖思含在崔勇团队中专注于数据中心网络的创新架构设计。

### 4. 鄂金龙（Jinlong E，博士毕业生）

鄂金龙是崔勇指导的博士生，主要研究方向为云存储和跨云文件协作。其代表性工作包括"CoCloud: Enabling Efficient Cross-Cloud File Collaboration based on Inefficient Web APIs"（IEEE TPDS 2017，以及IEEE INFOCOM 2017），以及"HyCloud: Tweaking Hybrid Cloud Storage Services for Cost-Efficient Filesystem Hosting"（IEEE/ACM Transactions on Networking 2020，IEEE INFOCOM 2019）。鄂金龙的研究关注于如何利用不高效的Web API实现高效的跨云文件协作，以及混合云存储服务的成本优化。此外，他还参与了OpenStack Swift类云存储系统同步瓶颈的研究（IEEE TPDS 2018）。

### 5. 张磊（Lei Zhang，博士毕业生）

张磊是崔勇指导的博士生，主要研究方向为拥塞控制与网络数字孪生。其代表性工作包括"DeepCC: Bridging the Gap Between Congestion Control and Applications via Multi-Objective Optimization"（IEEE/ACM Transactions on Networking 2022），以及关于网络数字孪生的"Digital Twin for Networking: A Data-driven Performance Modeling Perspective"（IEEE Network 2023）。此外，张磊还与崔勇合作发表了关于DDoS防御的SAV-D研究（IEEE Internet Computing 2023）和低延迟传输协议DTP（APNet 2019）等。张磊的工作体现了崔勇团队从传统网络协议设计向数据驱动与AI赋能网络研究方向的演进。

除上述五位代表性学生外，崔勇还培养了多位博士生和硕士生，包括但不限于：王紫逸（Ziyi Wang，视频流媒体低延迟传输方向，多篇INFOCOM/ToN论文）、左旭彤（Xutong Zuo，低延迟网络与自适应比特率方向）、史航（Hang Shi，多路径传输MPTCP与低延迟传输协议方向，USENIX ATC 2018）、刘聪（Cong Liu，中间盒服务与加密协议方向，INFOCOM 2018）等。这些学生毕业后部分进入学术界继续从事网络研究，部分进入腾讯、华为等产业界从事技术研发工作。

## 四、学术合作网络

### 4.1 实验室内部合作

崔勇所在的清华大学计算机系网络技术研究所是清华计算机网络学科的核心力量，以吴建平院士为学科带头人，形成了一个结构紧密、分工明确的研究团队。崔勇作为网络所所长，在这一团队中扮演着承上启下的关键角色。

**与吴建平院士的合作**：吴建平院士是崔勇的学术引路人和团队总负责人。两人合作密切，共同完成多项重要成果，包括IETF国际标准RFC 5565（Softwire Mesh Framework，2009年）和RFC 7040（Public IPv4 over IPv6 Access Network，2013年）等。在SAVA（源地址验证体系结构）项目中，吴建平为项目总负责人，崔勇为主要完成人之一，该项目于2023年获国家科技进步一等奖。此外，两人还合著了计算机网络教材《计算机网络》（清华大学出版社，吴建平、徐明伟、崔勇著）。崔勇在多次学术活动中以吴建平团队核心成员身份进行汇报和报告。

**与徐明伟教授的合作**：徐明伟是网络所的另一位重要教授，与崔勇有多项合作。两人共同发表了多篇论文（如关于IPv4/IPv6过渡中源地址验证的研究）和IETF标准RFC 8638（IPv4 Multicast over IPv6 Multicast in Softwire Mesh Networks，2019年）。他们还合作编写了计算机网络教材。在学科建设中，两人同属网络所核心教师团队。

**与尹霞教授的合作**：尹霞现任清华大学计算机系主任，与崔勇在网络所和系级管理层面有密切协作。在多项学术活动和学科建设中，崔勇向尹霞汇报工作。例如，在清华大学-南威软件联合研究中心揭牌仪式中，尹霞主持活动，崔勇作为网络所所长出席。在下一代互联网科研创新研讨会中，崔勇主持会议，徐恪（系副主任）介绍系整体情况，体现了团队内部的层级协作关系。

**与徐恪教授的合作**：徐恪现任计算机系副主任，在下一代互联网科研创新研讨会等学术活动中与崔勇共同出席，两人在学科建设和科研合作方面有紧密联系。在论文合作方面，徐恪（Ke Xu）与崔勇共同发表了关于P2P流量矩阵估计的论文（IEEE TPDS）。

**与李丹教授的合作**：李丹（Dan Li，后调往其他单位）与崔勇合作发表了关于数据中心网络可靠组播（IEEE Transactions on Computers 2014）和P2P流媒体防欺骗（IEEE Transactions on Multimedia 2009）等论文。

**与宋佳兴的合作**：宋佳兴担任网络所党支部书记，与崔勇在网络所的管理和学科建设方面形成党政协同的工作模式。

### 5.2 产学研融合

崔勇的产学研合作模式具有以下特点：

第一，**技术转化型合作**。崔勇提出的4over6等IPv6过渡技术被IETF制定为10余项RFC国际标准，部分成果被国际设备商和运营商广泛采用，实现了从基础研究到国际标准再到产业应用的全链条转化。其团队研发的端到端时延敏感传送系统推动了视频点播、直播、虚拟现实等新型流媒体应用的发展。

第二，**联合研究中心模式**。崔勇依托清华大学网络研究院和网络所，与多家企业建立了联合研究中心或联合实验室，形成了制度化的长期合作机制。这些联合机构涵盖下一代互联网、网络安全、天地一体化、数字治理等多个方向。

第三，**学术活动搭建产学研桥梁**。崔勇多次组织"下一代互联网科研创新研讨会"等学术活动，邀请产业界和学术界校友共聚一堂，旨在构建产学研高效沟通平台。他还担任中国通信学会智能体通信专业委员会主任委员，联合中关村实验室等机构组织学术活动，推动智能体通信创新与标准体系建设。

第四，**政策咨询与标准制定**。崔勇作为中国通信标准化协会理事，参与制定多项通信行业标准和国际标准。其SAVA技术成果被国家IPv6规模部署政策文件采纳，为国家网络空间安全战略提供了技术支撑。

## 七、Connection圈层总结

崔勇的学术关系网络呈现出以清华网络所为核心、向外辐射的多层结构，可划分为以下圈层：

**核心圈层（实验室内部）**：以吴建平院士为学术领袖，崔勇作为网络所所长和团队核心成员，与徐明伟、尹霞（现任系主任）、徐恪（系副主任）等构成清华计算机网络学科的核心教师团队。网络所内部还有宋佳兴（党支部书记）等同事。在学术传承上，崔勇处于吴建平院士的"学术谱系"中，是吴建平团队在SAVA、IPv6等方向的主要执行者和传承者。赖泽祺作为崔勇培养的博士生，已留校任教并晋升副教授，形成了"吴建平—崔勇—赖泽祺"的三代学术传承链条。王莫非、肖思含、张磊、鄂金龙等博士毕业生构成了崔勇的直接学生圈层，在数据驱动网络、数据中心网络、云存储、拥塞控制等方向延续和拓展了导师的研究版图。

**合作圈层（学术伙伴）**：在国内，崔勇与程秀珍（George Washington Univ）、任奎、李琦（清华网络研究院）等学者保持长期论文合作关系。在国际上，与Jiangchuan Liu（SFU）、Xin Wang、Charlie Hu（Purdue）、Minlan Yu（Harvard）等学者通过联合发表论文和学生联合培养建立了稳固的合作关系。在IETF国际标准制定领域，崔勇与多位国际专家合作完成RFC标准，形成了标准制定层面的国际合作网络。

**产业圈层**：崔勇的产业合作网络覆盖面广泛。在运营商层面，与中国电信建有联合研究中心，与中国移动有合作项目；在设备商层面，与华为有长期合作关系（包括在华为2012实验室作报告）；在安全企业层面，与奇安信、360、绿盟科技分别建有联合研究中心；在互联网企业层面，通过学生赖泽祺与腾讯建立了联系；在其他产业合作方面，与中国电科（天地一体化）、紫光（态势感知）、南威软件（数字治理）、中国建设银行（战略合作）等均有深度合作。

**标准与行业圈层**：崔勇在IETF担任softwire工作组主席，在IEEE多个重要期刊担任编委，在中国互联网协会、中国通信学会、中国通信标准化协会等多个行业组织中担任重要职务。他成功在北京组织了SIGCOMM 2019大会（计算机通信领域最高学术会议），并担任ACM MM 2019领域主席。在最新的学术服务中，他担任中国通信学会智能体通信专业委员会主任委员，推动AI与通信融合的前沿研究。

总体而言，崔勇的学术关系网络以清华网络所为根节点，通过师生传承、学术合作、国际标准制定和产学研合作四条主线向外延伸，形成了以"下一代互联网体系结构"为核心主题、覆盖学术—标准—产业全链条的关系网络。他既是吴建平院士团队的核心执行者，也是独立引领多个研究方向的学术带头人，在清华大学计算机网络学科中扮演着承上启下的关键角色。
