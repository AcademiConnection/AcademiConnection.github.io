# 清华大学 计算机系网络技术研究所（网络所）教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

清华大学计算机系网络技术研究所（网络所）与清华大学网络研究院（INSC，网络科学与网络空间研究院）实行"一体两翼"运行，是我国计算机网络学科的发源地和最重要的人才培养与科研基地之一。团队由吴建平院士于上世纪八十年代创建，以"下一代互联网"国家重点科研领域为核心阵地，先后建成 CERNET（中国教育和科研计算机网）、CNGI-CERNET2（世界最大纯 IPv6 主干网）和国家重大科技基础设施"未来互联网技术基础设施 FITI"，形成了"三张网"接续递进的互联网基础设施创新谱系。

团队学术成就的标志性体现是 2023 年度国家科学技术进步奖一等奖"下一代互联网源地址验证体系结构 SAVA 关键技术与规模化应用"（联合中国电信、华为、新华三、赛尔网络完成），15 位主要完成人中 12 位来自清华网络学科团队。团队教师80余人分布在计算机系网络所、网络研究院、电子系、深圳研究院数据与信息研究院、信息化技术中心等单位，围绕下一代互联网体系结构、IPv6 过渡与源地址验证、网络路由与高性能路由器、数据中心网络与 RDMA、网络测量与安全、智能网络等八大科研方向布局。吴建平院士还获国际互联网协会（ISOC）Postel Service Award（2010）并入选国际互联网名人堂（2017），是国际互联网领域的权威学者。

## 研究方向与圈层结构概述

清华网络学科呈现典型的"一源多流"谱系结构。源头是吴建平院士近四十年经营的下一代互联网学术共同体：李星教授作为 CERNET 建设的"总设计师"型搭档构成双核；第二代学者徐恪（体系结构与路由）、尹霞（IPv6 过渡与 SAVA）、徐明伟（SDN 与网络测量）、崔勇（IPv6 过渡与 IETF 标准，现任网络所所长）分别在核心方向上开宗立派；第三代李丹等则将研究前沿拓展至数据中心网络、RDMA 与 AI 训练网络（NASP 实验室），在 SIGCOMM/NSDI 等国际顶会上形成高密度产出。行政体系上，尹霞现任计算机系主任、徐明伟现任网络研究院院长、徐恪任计算机系副主任，团队在院系治理层面亦占据枢纽位置。

产业圈层上，团队与中国电信、华为、新华三、赛尔网络通过 SAVA 等国家级项目形成深度绑定；比威网络等承担了路由器成果转化；阿里云、中兴则与李丹团队在 RDMA/数据中心方向持续联合发表。国际圈层经由 CERNET 与全球学术网互联、IETF 标准化（崔勇任 softwire 工作组主席、多部 RFC）、APAN/APNIC 合作以及吴建平的国际荣誉（Postel 奖、互联网名人堂）展开。

## 产业转化亮点

团队产业转化的最大标志是 SAVA 技术的规模化应用：源地址验证体系在中国电信、华为、新华三的设备与网络中落地部署，支撑国家网络空间可信治理，获国家科技进步一等奖。更早的 CERNET 建设本身即是产学研一体的国家工程——赛尔网络作为 CERNET 全国运营主体本身就是成果转化的载体；徐恪团队的高性能路由器软件平台在比威网络产品化并应用于 CERNET2、中国电信、中国移动网络。国际标准层面，崔勇的 4over6 过渡技术被 IETF 采纳为 9 项 RFC（获2013年度国家技术发明奖二等奖），是国产网络技术进入国际标准体系的代表案例。当前，FITI 国家重大科技基础设施与 IPv6 规模部署国家战略继续为团队提供成果转化的大舞台，李丹团队的 RDMA/数据中心网络技术与阿里云、华为、中兴的合作则代表了面向 AI 时代算力网络的新一代转化方向。
