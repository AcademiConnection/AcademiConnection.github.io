## 二、教育背景与职业履历

熊英飞1982年出生，学术路径横跨中日加三国。2000年至2004年就读于电子科技大学计算机科学专业，获学士学位。本科期间品学兼优，多次获得人民特等奖学金（前1%），并获IBM优秀学生奖学金、三星奖学金等荣誉。2004年在全国信息学奥林匹克竞赛（四川赛区）获一等奖，展现了早期在算法与编程方面的天赋。

2004年至2006年，熊英飞以预博士（Pre-Ph.D.）身份进入北京大学，师从杨芙清院士和梅宏教授（梅宏后任北京大学信息科学技术学院院长，2011年当选中国科学院院士）。在北大期间，他获得 Canon 奖学金和校长学习优秀奖，并在"百度之星"全国程序设计大赛中进入前50名。

2006年10月，熊英飞赴日本东京大学信息工学系攻读博士学位，导师为**胡振江**（Zhenjiang Hu）教授和**竹内正人**（Masato Takeichi）教授。东京大学期间，他的研究聚焦双向变换（bidirectional transformation），提出了基于差别的双向变换框架（delta-based bidirectional transformation），该框架后来成为最广泛使用的两大双向变换模型之一。他于2009年9月获得博士学位，在读期间获东京大学留学生特别奖学金（三年）。

2009年12月至2011年11月，熊英飞赴加拿大滑铁卢大学从事博士后研究，合作导师为 **Krzysztof Czarnecki** 教授。在滑铁卢大学 GSD（Generative Software Development）实验室期间，他与 Zinovy Diskin 和 Czarnecki 合作发表了将基于状态的双向变换扩展为基于差别的双向变换的奠基性论文（ICMT 2010），进一步完善了博士阶段的理论框架。

2012年4月，熊英飞回国加入北京大学信息科学技术学院（现计算机学院）软件研究所，入选"青年人才"计划（相当于预聘制助理教授）。2018年晋升为新体制长聘副教授。2020年至2024年担任计算机学院院长助理，2021年起担任软件研究所副所长。他是北京大学编程语言实验室的创始核心成员，该实验室由其博士导师胡振江教授于2019年创建，熊英飞担任副主任。

在北大任职期间，熊英飞主持了国家自然科学基金优秀青年基金、国家重点基础研究发展计划（973）青年科学家专题项目、国家重点研发计划课题等国家级科研项目，以及来自微软、华为等企业的横向项目。

## 五、业界合作关系深度分析

### 5.1 产业技术应用与合作

熊英飞的研究具有极强的产业转化导向，其成果在多个领域得到实际应用：

**华为公司：** 熊英飞与华为的合作始于其回国初期。根据其知乎专栏自述，回国发表程序修复论文后，华为是最早主动联系交流技术应用的国内企业之一。华为工程师向其阐述的实际需求——"几万名程序员，哪怕只自动修复1%的缺陷，每年也是千万元级的成本节省"——深刻影响了熊英飞对研究方向产业价值的认识。此后，熊英飞承担了来自华为的多个横向项目，其程序分析和缺陷修复技术在华为开发流程中得到应用，博士毕业生梁晶晶也入职华为担任软件工程师。

**中兴公司（ZTE）：** 2021年至2024年，熊英飞担任北京大学-中兴联合基础软件实验室管理办公室主任，该联合实验室是产学研深度合作的制度化体现。其 ICSE 2026 论文 PredicateFix 提出的静态分析告警修复方法已在中兴公司部署使用，并获得开发者的积极反馈。这标志着熊英飞团队的研究已从实验室原型进入企业生产环境。

**新一代 Linux 内核配置项目：** 熊英飞基于差别的双向变换理论被应用于新一代 Linux 内核配置系统，通过双向变换技术实现内核配置的一致性维护。这是其基础理论研究在开源系统中的典型应用案例。

**燕云 DaaS 系统：** 燕云 DaaS（Desktop as a Service，桌面即服务）系统采用了熊英飞的研究成果，具体涉及软件适配和配置管理方面的技术。

**微软公司：** 熊英飞曾承担微软公司的横向研究项目（2015年获微软亚研院合作奖），其早期研究中的编译器测试和程序分析技术与微软的开发工具有关联。

**DeepSeek（深度求索）：** 熊英飞虽然本身不任职于 DeepSeek，但其学生朱奇浩作为创始团队成员深度参与了 DeepSeek-Coder 系列代码大模型的研发。熊英飞本人作为 DeepSeek-Coder 论文的共同作者，其在代码生成评估、程序合成方法论方面的研究成果为该模型的训练策略和质量提升提供了学术支撑。高可信软件技术教育部重点实验室的报道明确指出"他的工作帮助产生了一系列不同规模的效果同期最优代码生成神经网络模型，如 DeepSeek-Coder 模型"。DeepSeek-Coder 在多项基准测试中超越了 Codex 和 GPT-3.5 等闭源模型，是开源代码大模型的里程碑。

### 5.2 创业孵化与技术成果转化

熊英飞团队在学生培养中展现出显著的产业孵化能力：

- **DeepSeek 创始团队：** 博士毕业生朱奇浩作为创始团队核心成员加入 DeepSeek，将其在博士期间积累的代码大模型研究经验直接应用于产业级产品开发。DeepSeek 在2024年至2025年成为中国最具影响力的 AI 公司之一，其代码模型被全球开发者广泛使用。

- **学生产业分布：** 熊英飞的硕士和博士毕业生中，多位进入顶尖科技公司：Google（2人，包括王然、高哲）、Amazon（刘馨元）、腾讯（王杰、杨晓东）、华为（梁晶晶、曾沐涵）、字节跳动相关生态等。这种广泛的产业分布使得熊英飞的研究网络与产业界形成了自然的技术扩散通道。

- **开源贡献：** 熊英飞团队长期坚持研究工具的开源发布，包括 ACS 程序修复工具、玲珑代码生成框架等，相关代码和工具在其个人主页和 GitHub 上公开，降低了产业界采用其研究成果的门槛。

- **国际程序修复竞赛：** 2024年，熊英飞团队在国际自动程序修复竞赛（APR Competition）的 Java 功能错误赛道获第一名、AI 生成代码赛道获第二名，展示了其技术在国际竞争中的领先地位。

## 七、Connection圈层总结

熊英飞的学术关系网络呈现以"师生传承+产学研融合"为特色的四圈层结构：

**第一圈层（核心导师与合作者）：** 胡振江（博士导师、现任实验室领导）、Krzysztof Czarnecki（博士后导师）、竹内正人（博士联合导师）。这三人构成了熊英飞学术基因的核心来源——胡振江的双向变换理论框架、Czarnecki 的模型驱动工程视角、竹内正人的程序演算学派，三者交汇形成了熊英飞独特的"从理论到工具到产业"的研究风格。胡振江2019年加盟北大后，师生二人从导师-学生关系转变为同事-合作者关系，共同打造了北大编程语言实验室这一中国程序设计语言研究的重要基地。

**第二圈层（核心学生群体）：** 熊英飞回国14年间培养了14名博士毕业生，形成了以陈俊洁（天津大学教授）、蒋嘉俊（天津大学副研究员）、朱奇浩（DeepSeek创始团队）、邹大明（ETH Zurich博后）、纪如意（密歇根大学博后）、孙泽宇（中科院软件所）、王博（北京交大讲师）等为代表的学术传承网络。其中天津大学已成为熊英飞学生群体最集中的校外机构（陈俊洁、蒋嘉俊），形成了北大-天大的学术合作轴线。朱奇浩加入 DeepSeek 则将学术网络延伸至 AI 产业最前沿。

**第三圈层（校内同事与合作者）：** 编程语言实验室的张昕、Sergey Mechtaev、王迪、陈红杰等青年教师，以及软件研究所的梅宏院士、金芝教授、谢冰教授、张路教授、李戈教授等，共同构成了熊英飞的日常学术生态。高可信软件技术教育部重点实验室（杨芙清院士创立）提供了平台支撑。

**第四圈层（国际学术与产业网络）：** 包括 IFIP WG 2.4 的国际程序变换学者社群、滑铁卢大学 GSD 实验室的网络、Abhik Roychoudhury（新加坡国立大学）、Tao Xie（伊利诺伊大学）、Xin Xia（莫纳什大学）等国际合作者，以及华为、中兴、微软、DeepSeek 等产业合作伙伴。熊英飞是 IFIP WG 2.4 唯一中国籍成员，这一身份使其成为连接中国程序设计语言研究与国际前沿的桥梁。

**网络结构特征：** 熊英飞的学术网络具有"中日加三国学术背景+产学研双轨驱动"的鲜明特征。从东京大学的双向变换理论出发，经滑铁卢大学的模型驱动工程实践，最终在北京大学落地为涵盖程序分析、合成、修复的完整研究体系。其学生群体的去向——半数进入高校教职、半数进入产业界——恰好映射了熊英飞自身"学术深度+产业影响"双重定位的成功。在 DeepSeek-Coder 等代码大模型兴起的背景下，熊英飞的研究网络正处于学术影响力与产业影响力双重增长的快车道。
