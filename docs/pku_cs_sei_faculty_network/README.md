## 二、各位教师的角色定位

杨芙清是中国软件工程学科奠基人，1955年留北大师从计算数学家徐献瑜，1957-1958年赴苏联科学院计算中心与莫斯科大学研修程序设计自动化，回国后主持研制150机操作系统等我国早期系统软件，1980年代起总主持"青鸟工程"（历时三十余年的国家软件工程技术攻关），1991年当选中国科学院院士。她的学术谱系构成中国软件工程的半壁江山：梅宏院士（上海交大博士、北大博后）、谢冰、张路、张世琨、赵俊峰等均出其门下或团队。

谢冰是现任软件研究所所长，1970年生，1998年国防科技大学博士毕业后加入北大，2012年接替梅宏出任所长，国家杰青，现任北大科学研究部部长。他承续青鸟体系主持研发Trustie（可信软件资源生产与共享环境，国家技术发明二等奖2015），与国防科大王怀民院士团队形成"北软所—国防科大"核心合作轴，学生陈俊洁（天津大学教授）获CCF优秀博士学位论文奖。

张路是软件所资深教授，1995年本科、2000年博士均毕业于北大，长江学者特聘教授、国家杰青，深耕软件测试与质量保证，是可信软件工程研究组的学术骨干，学生郝浩（上海交大教授）、李立立（阿尔伯塔大学助理教授）等形成学术输出。

李戈是智能化软件工程方向的旗帜，1999年山东工业大学本科、2006年北大博士，教育部长江学者，是国际上最早从事"基于深度学习的程序理解与生成"研究的学者之一，其孵化企业北京硅心科技（aiXcoder）将代码大模型技术落地航天、金融等领域，是"产学研一体"的代表。

熊英飞是程序语言与软件工程方向的学科带头人，2004年电子科大本科、北大预博士（师从杨芙清/梅宏）、2009年东京大学博士（导师胡振江/Masato Takeichi）、滑铁卢大学博后（Krzysztof Czarnecki），2012年回北大任教，现任软件所副所长。他在程序修复（ACS）、双向变换等方向做出国际影响成果（国家技术发明一等奖排名6、5次SIGSOFT杰出论文奖），学生朱奇浩为DeepSeek创始团队成员。

周明辉是开源软件生态方向的带头人，1995/1999/2002年国防科大学士/硕士/博士，博雅特聘教授、计算机学院副院长，主导木兰宽松许可证（中国首个开源许可证）、开源供应链治理等影响开源生态的基础性工作，其OSS-Lab与华为、百度、字节跳动均有协作。

## 三、全实验室关系网络的整体观察

北大软件所的师资网络呈现出几个较为清晰的结构性特征。

第一是"院士奠基、四代传承"的谱系纵深。从杨芙清（第一代）到梅宏、谢冰、张路（第二代），再到李戈、周明辉、熊英飞（第三代），直至陈俊洁（天津大学教授）、朱奇浩（DeepSeek）等第四代，跨越六十余年而谱系不断，是中国计算机学科中延续性最强的师承链条之一，其"青鸟工程"更是贯穿国家五代科技攻关计划。

第二是"国家级工程平台"的组织形态。以软件工程国家工程研究中心、可信软件全国重点实验室（与北大软微等共建）为载体，该所长期承担国家攻关任务（青鸟系统、Trustie、操作系统国产化），产出多次国家科技进步/技术发明二等奖以上奖励，是"高校研究所办国家级工程"的典型样本。

第三是"国际化+本土化"双轨师资结构。核心教师来源呈两源分化：本土系（杨芙清—张路一脉，北大博后梅宏、国防科大博士谢冰/周明辉）与国际系（东大博士熊英飞、斯坦福访问的李戈），前者支撑国家工程体系，后者对接国际学术前沿（FSE/ICSE/POPL/OOPSLA），两轨在智能化软件工程方向汇流。

第四是"从工具到创业"的产业转化梯次。从青鸟工具链（产业化至北大青鸟体系）、Trustie平台（山东中创等企业应用），到燕云DaaS（熊英飞参与、反向工程成果转化）、aiXcoder（李戈孵化），再到学生创业（DeepSeek朱奇浩），形成"国家级平台—校企联合实验室—教师创业—学生创业"四层转化梯次，产业化能力在国内软件工程学界首屈一指。
