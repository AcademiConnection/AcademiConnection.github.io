# 上海交通大学清源研究院 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

清源研究院（Qingyuan Research Institute，官网 [qingyuan.sjtu.edu.cn](http://www.qingyuan.sjtu.edu.cn/)）是上海交通大学电子信息与电气工程学院于2019年12月成立的面向人工智能基础理论与技术创新的研究院，由上海交大与商汤科技联合共建，研究方向涵盖人工智能芯片、智能机器人、医学图像、计算机视觉与自然语言处理，并与商汤科技、上海人工智能实验室保持合作。研究院实行校内导师与商汤等行业导师联合培养硕博人才的机制，徐宁仪、刘鹏飞、蔡盼盼、邓志杰、张健夫等校内导师与商汤科技行业导师（朱升发、张弛、姚勇强等）对接联培（[2023级联培入驻会](http://www.qingyuan.sjtu.edu.cn/a/dian-yuan-qing-yuan-yan-jiu-yuan-2023-ji-lian-pei-.html)）。

研究院教师构成多元的AI研究矩阵：徐宁仪（CCC定制计算与智能芯片、辉羲智能创始人）代表"AI芯片"方向；刘鹏飞（GAIR生成式人工智能研究组，复旦博士+CMU博士后，师承线索经Graham Neubig展开）与邓志杰（DENG Lab，清华大学本博一贯制（2017学士/2022博士，师从张钹、朱军，TSAIL 出身），高效生成模型与推理加速）构成大模型研究双核；顾磊磊（BISLab智能仿生视觉实验室，港科大范智勇组）深耕微纳仿生传感与助盲系统；黄维然（MIFA Lab，清华姚期智/陈卫门下、前华为中央研究院）专注机器学习理论与基础模型，其归属同时列于先进网络研究所与清源研究院（双重归属，另见 [sjtu_anri_faculty_network](../sjtu_anri_faculty_network/)）。刘鹏飞与邓志杰的合作（LiveTalk等联合署名且GAIR学生交叉）是院内最密集的学术协作关系。

## 圈层结构概述

清源研究院的网络以"校企共建平台+多元学术谱系"为特征。谱系上，五位建档教师来自五条互不重叠的学术血脉：徐宁仪出自清华（电机系杨华中等合作网络，导师未披露），顾磊磊出自港科大范智勇仿生器件组，邓志杰出自清华TSAIL（张钹/朱军门下），刘鹏飞出自复旦NLP（黄萱菁团队时期）+CMU Graham Neubig博士后，黄维然出自清华交叉信息院姚期智/陈卫门下并携华为产业经验——这种"多源汇流"结构使研究院成为校内少有的跨谱系AI聚合平台。院内合作最突出的是刘鹏飞—邓志杰组合（LiveTalk实时交互视频扩散模型等多篇联合署名、GAIR学生交叉），将语言模型与视频生成两条主线耦合；徐宁仪—刘鹏飞—邓志杰—蔡盼盼等作为联培校内导师与商汤行业导师对接。产业网络上，研究院整体依托商汤共建与联培机制，教师个人则各有接口：徐宁仪创辉羲智能（具身智能计算）、刘鹏飞联合创立Inspired Cognition并获蚂蚁InTech奖、邓志杰技术应用于美团LongCat并参与生数科技Vidu S1联合署名、顾磊磊推进助盲系统落地。国际连接以刘鹏飞的CMU/Neubig—创智学院网络最为显著。需注意的边界：清源研究院是电院建制下的大平台，徐雷（CMaCH主任）曾兼任商汤清源研究院首席科学家属于企业侧研究院职务，与本目录交大清源研究院不是同一实体；黄维然双重归属先进网络研究所，其深度报告收录于本目录并在ANRI目录交叉引用。
