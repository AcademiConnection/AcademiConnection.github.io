# 中国科学技术大学 智能计算与应用实验室教师学术关系网络报告

> 报告生成时间：2026年8月26日

## 团队简介

智能计算与应用实验室由中国科学技术大学计算机科学与技术学院陈华平教授负责，是中科大"智能优化—调度应用"方向的主要团队。陈华平的学术身份横跨计算机系统平台与管理科学：其早期承担曙光 3000 客户端集成环境、合肥网格节点、国家网络计算环境平台建设子课题、CNGI 国家网格应用等国家级计算平台任务，近年论文重心集中在将智能优化方法（估计分布算法、差分进化、蚁群等群体智能方法）应用于制造/物流/资源调度场景——批处理机与流水车间调度、能效调度、敏捷地球观测卫星调度、云计算资源调度、无人机配送决策支持等，成果发表于 IEEE Transactions on Evolutionary Computation、IJPR、IJPE、COR 等演化计算与生产运作领域期刊。

该实验室在报告体系中此前完全未被覆盖。需要说明的边界：实验室官方公开介绍未提供可核验的现任完整成员名单，本报告系列以负责人陈华平一人建档；陈华平曾任计算机科学与技术学院执行院长（至少 2010–2013 年间，该职后由李向阳于 2016 年出任院长前接任）与软件学院院长（至 2025 年下半年卸任，现任软件学院院长为李向阳），是中科大计算机学科建制中兼具学术与行政履历的资深教授，曾获国家科技进步二等奖与中科院科技进步二等奖（公开页面未载明项目与排名），并担任全国工程管理专业学位研究生教育指导委员会委员（2011–2021）、科技部高性能计算重点专项总体专家组重大专项评审委员会委员（2016–2021）等公共职务。

## 研究方向与圈层结构概述

陈华平的网络可概括为"算法内核—调度应用共同体—国家平台与产业人才出口"三层结构。核心圈以实验室为轴心，研究方法是估计分布算法、差分进化、蚁群等智能优化，问题对象覆盖批处理机、流水车间、卫星、云资源与配送调度；Rui Xu、Shengchao Zhou、Xu Zheng、Chuang Liu、Xueping Li（田纳西大学）等是可由论文反复核对的合作作者。学术圈经 IEEE TEVC（与西班牙 J. A. Lozano 的估计分布算法合作）、IJPR/IJPE/COR 等渠道连接演化计算、组合优化与生产运作领域，辅以芝加哥大学、香港理工大学、香港城市大学的访问经历；国内层面与清华、国防科大等优化方向团队属同行圈层参照而非已证实合作。产业与公共平台圈以曙光/网格/CNGI/淮河水专项等国家级任务为平台，以毕业生流向阿里、网易、华为等企业为外围连接；其"项目/人才出口"与"具名企业直接合作"在报告中严格区分。

## 产业转化亮点

本团队产业化的形态以"国家计算平台任务 + 行业调度系统 + 人才输出"为主：早期曙光 3000 客户端集成环境与合肥网格节点建设属国产计算体系的基础设施任务；淮河水专项调度技术与防灾减灾系统体现公共治理场景落地；近年面向制造与物流企业的调度优化（含与 Xueping Li 等合作的无人机配送决策支持研究）延续应用导向。公开资料未见以其为创始人的创业公司或成果作价转化记录，与 LDS（开源资产辐射）、网安学院（成果作价入股）等团队的转化模式形成对照。
