# 北京大学信息工程学院 ADSP 现代信号与数据处理实验室学术关系网络报告

## 团队简介

北京大学深圳研究生院现代信号与数据处理实验室（ADSPLAB）成立于2006年，由邹月娴教授创立并担任主任至今，是北京大学信息工程学院历史最悠久的实验室之一。实验室同时依托深圳物联网智能感知技术工程实验室（ELIP，2012年成立，邹月娴任副主任），研究方向从早期的信号处理与数字通信逐步演进为计算听觉、智能人机对话、数据智能分析三大方向，核心特色是基于深度网络与稀疏表示的模式识别理论及其在语音、音频、多模态智能中的应用。

ADSPLAB 的学术网络具有鲜明的"国际化—产学研"双重特征：一方面与香港大学、新加坡南洋理工大学、英国萨里大学、美国约翰霍普金斯大学等保持长期合作；另一方面与腾讯（俞栋团队合著论文20余篇）、微软亚洲研究院等产业界建立深度合作，累计承担企业横向项目十余项。2024年实验室迎来标志性成果——Interspeech 2024 一届三奖：辛逸飞（DiffATR，最佳论文）、杨东超（SimpleSpeech，最佳学生论文）、王赫麟（最佳论文提名），集中展现了实验室在语音与语言智能方向的产出能力。

## 研究方向与圈层结构概述

邹月娴的学术网络以三条主线展开。其一是学术传承线：成都电讯工程学院（现电子科技大学）本硕起步，硕士期间参与"七五"预研项目进入 AI 领域；1996年赴香港大学攻读博士（2000年毕业，一说2001年），据论文署名推断导师极可能为 Shing-Chow Chan 教授；博士毕业后在新加坡理工学院工作约五年，2005年归国加入尚处拓荒期的北大深研院，成为元老级教师。其二是学生培养线：二十年培养逾百名研究生，形成"实验室—腾讯/阿里/美团等头部企业—牛津/JHU/CMU/CUHK 等海外名校"的双通道人才网络，近年代表包括程旭欣（美团，ZeroNLG/VARGPT）、杨邦（鹏城实验室，ZeroNLG 一作）、辛逸飞（阿里巴巴，Interspeech 2024 最佳论文）、杨东超（CUHK 读博）、王赫麟（JHU 读博）等。其三是产业与平台线：作为鹏城实验室双聘教授建立联合培养通道；与腾讯俞栋团队长期合作（语音分离、目标声音提取等）；与北大计算机学院孙栩团队在对话系统与跨模态语言智能方向联合发表十余篇论文并共同指导学生。

## 产业转化亮点

实验室多项研究成果受到工业界关注并进入转化通道：远程非接触话者身份确认系统（深圳市技术创新计划项目）、基于局部特征和稀疏表示的车型识别（企业委托项目）、人工智能语音唤醒技术（公司委托项目）等均直接对接产业需求；语音声源定位、多模态大模型推理优化等方向持续输出专利与开源成果。学生进入腾讯、阿里、美团、鹏城实验室等机构形成稳定的人才输送管道，是深研院产学研一体化的典型样本。
