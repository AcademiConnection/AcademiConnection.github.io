## 二、教育背景与职业履历

张奇于2003年在山东大学计算机科学与技术专业获得学士学位。同年，他进入复旦大学攻读研究生学位，师从复旦大学计算机科学技术学院吴立德教授。吴立德教授是中国NLP领域的先驱之一，正是吴立德推荐张奇关注自然语言处理方向。彼时复旦有数据库、多媒体等热门研究方向，而张奇选择了"让计算机理解人类语言"这一愿景。2005年1月至2006年1月期间，张奇曾在美国Palo Alto的Bosch Research and Technology Center（博世研究与技术开发中心）担任研究实习生（Research Intern），积累了早期的产业研究经验。

2009年，张奇在复旦大学获得计算机应用专业理学博士学位，随后留校任教，加入复旦大学计算机科学技术学院。据百度百科资料显示，其博士导师为吴立德教授。需要注意的是，黄萱菁教授也是张奇长期合作的密切伙伴，桂韬的博士论文明确记载"师从黄萱菁教授和张奇教授"，说明张奇与黄萱菁构成复旦NLP实验室的师承与合作核心。

在职业发展方面，张奇自2009年留校后逐步晋升为教授、博士生导师。2011年入选上海市教委"晨光计划"。此后入选复旦大学"卓越2025"人才培育计划，最终获得"国家级领军人才"称号（待核实具体为杰青还是优青）。他兼任上海市智能信息处理重点实验室副主任，成为复旦NLP实验室的核心骨干之一。近年来，张奇担任复旦眸思大模型负责人，并兼任中工互联（北京）科技集团有限公司首席科学家，深度参与产学研结合。

张奇的研究经历完整覆盖了NLP领域从规则方法到统计学习、深度学习、预训练模型再到大语言模型的全部技术演进阶段，这一经历使他在大模型时代成为学界与产业界的重要桥梁人物。

## 三、学生培养情况

张奇作为博士生导师，培养了大批优秀学生，其学生广泛分布于国内外高校和头部科技企业。根据其个人主页及公开资料，以下列出代表性学生。

### 1. 桂韬（复旦大学副研究员/硕士生导师，博士毕业生）

桂韬是张奇培养的最具代表性的学生之一。桂韬本科毕业于国防科技大学计算机仿真专业，随后在复旦大学攻读硕士和博士学位，师从黄萱菁教授和张奇教授，主要研究方向为自然语言处理、信息抽取及其鲁棒性与泛化性分析。在读博期间，桂韬发表A、B类长文18篇，其中以第一作者或通讯作者发表12篇，曾获COLING 2018领域主席推荐奖、NLPCC 2019杰出论文奖。桂韬还获得了2019年百度奖学金（全球10名华人博士之一，NLP领域唯一获奖者）、IBM奖学金（全国10名博士生之一）、华为天才少年计划NLP领域唯一获奖者等荣誉，并获2021年复旦大学"学术之星"特等奖。毕业后桂韬留校任复旦大学现代语言学研究院、计算机科学技术学院青年副研究员，入选第七届"中国科协青年人才托举工程"和上海市启明星计划，获2023年WAIC"云帆奖"璀璨明星奖和NeurIPS 2023大模型对齐Track最佳论文奖。桂韬与张奇、黄萱菁合著《自然语言处理导论》《大规模语言模型：从理论到实践》（后者另含郑锐为合著者）。他是张奇学术传承的核心延续者。

### 2. 彭明龙（Minlong Peng，在读博士生）

彭明龙是张奇指导的在读博士生，在多项研究中与张奇紧密合作。其研究方向涉及命名实体识别、序列标注等NLP核心任务。彭明龙在EMNLP 2017、EMNLP 2018等顶级会议中作为共同作者发表多篇论文，研究方向涵盖对抗神经网络在Twitter词性标注中的应用、跨域迁移学习等。彭明龙也是TextFlint鲁棒性评测平台开发团队的核心成员之一。

### 3. 符金兰（Jinlan Fu，在读博士生）

符金兰是张奇指导的在读博士生，研究方向涉及序列标注和自然语言理解。她以共同作者身份在AAAI 2018和NAACL 2021等CCF-A类会议上发表论文，包括关于中文分词中融合词典的神经网络方法以及大上下文标注的研究。符金兰的研究体现了张奇团队在基础NLP任务上的持续深耕。

### 4. 郑锐（Ruì Zhèng，博士生/合作者）

郑锐是张奇指导的博士生，在ACL 2022上发表以"Flooding-X: Improving BERT's Resistance to Adversarial Attacks via Loss-Restricted Fine-Tuning"为题的论文，该论文中郑锐为共同第一作者。郑锐也是《大规模语言模型：从理论到实践》（第1版及第2版）的核心作者之一，与张奇、桂韬、黄萱菁共同完成了这部大模型领域的重要教材。郑锐的研究方向聚焦于预训练语言模型的鲁棒性提升和大语言模型技术。

### 5. 费子楚（Zichu Fei，硕士生）

费子楚是张奇指导的硕士生，在EMNLP 2022上以第一作者发表论文"ProofInfer: Generating Proof via Iterative Hierarchical Inference"，合作者包括张奇、周鑫、桂韬、黄萱菁。该研究针对证明树生成任务提出迭代层次推理方法，采用分治算法将证明树递归编码为纯文本。费子楚的研究体现了张奇团队在推理与证明生成等前沿方向的探索。

### 6. 高颂杨（Songyang Gao，硕士生）

高颂杨是张奇指导的硕士生，在EMNLP 2022上发表论文"Kernel-Whitening: Overcome Dataset Bias with Isotropic Sentence Embedding"，合作者包括窦士涵、张奇、黄萱菁。该研究针对数据集偏差问题引入表示标准化和核白化方法。高颂杨的研究方向涵盖自然语言表示学习与去偏差方法。

### 7. Yeyun Gong（龚业允，校友，微软亚洲研究院）

Yeyun Gong是张奇指导的毕业生之一，毕业后加入微软亚洲研究院（MSRA）。张奇与Yeyun Gong多次合作发表论文，包括EMNLP 2016上的"Keyphrase Extraction Using Deep Recurrent Neural Networks on Twitter"等。Yeyun Gong在MSRA从事自然语言处理和信息检索相关研究，是张奇学生中进入国际顶级企业研究院的代表性案例。

## 五、业界合作关系深度分析

### 5.1 产业合作

张奇是复旦NLP实验室中产学研结合最为深入的教授之一，其产业合作涵盖大模型研发、工业AI应用和企业级知识引擎等多个层面。

**中工互联（北京）科技集团有限公司**是张奇最重要的产业合作伙伴。张奇担任中工互联首席科学家，与创始人、董事长智振建立了深度战略合作关系。双方合作的核心成果包括：

- **智工·工业大模型**系列：这是中国首款工业大模型产品，已迭代至3.0版本。张奇团队与中工互联联合发布了工业领域首个嵌入式多模态大模型产品（2.8B参数）和首个轻量化开源大模型预训练底座（1.6B参数，3.2T Token）。智工大模型在预训练阶段注入大量工业知识，应用于图纸理解、产品质检、异常检测等工业场景，并与某工业控制器龙头企业合作搭建了知识库系统。

- **复旦眸思大模型**：张奇作为眸思大模型负责人，带领团队开发了多视觉专家混合架构的多模态大模型。该模型被应用于"听见世界"公益助盲APP，将图像转换为语音帮助视障人士。该项目由复旦大学NLP实验室与视觉与学习实验室联合开发，中工互联提供全方位支持。

- **智工知语企业级知识引擎**：该产品于2024年获中国高交会优秀科研成果创新奖。

在更广泛的产业合作层面，张奇团队的技术应用于书生浦语、字节豆包、DeepSeek、联想AI PC等10余个大模型产品（据百度百科介绍，具体合作方式待核实）。张奇还多次在年度生成式AI大会等产业峰会上做主题报告，与蚂蚁集团、联汇科技等企业有交流合作。张奇在访谈中强调"NLP是一门应用导向的学科，研究应该对工业界有所助益"，这一定位指导了他的产学研合作策略。

### 5.2 创业孵化与技术转化

张奇在技术转化和创业孵化方面展现了活跃的参与度，但其角色更多体现为"学术首席科学家"模式而非直接创业：

- **中工互联模式**：张奇以首席科学家身份深度参与中工互联的产品研发，这实质上是一种"学者+企业"的产学研融合模式。中工互联在工业大模型领域的产品化能力与张奇团队的NLP技术能力形成互补，智工系列产品的持续迭代体现了这种合作模式的可持续性。

- **学生流向产业界**：张奇培养的大量学生进入阿里巴巴、腾讯、百度、字节跳动、微软亚洲研究院、Facebook（Meta）、科大讯飞等头部科技企业，形成了一个隐性的人才输送和技术转化网络。这些校友在各自企业中从事NLP相关工作，间接将张奇团队的研究理念和方法论扩散到产业界。

- **开源项目**：张奇团队主导或参与开发了多个开源项目，包括FudanNLP（国内首家中文自然语言开源系统）、FastNLP（轻量级NLP工具包）、TextFlint（多语言鲁棒性评测平台）等。这些项目被包括联合国教科文组织在内的国内外多家研发机构采用，体现了技术转化为开源生态的贡献。

- **教材影响力**：张奇与桂韬、黄萱菁合著的《自然语言处理导论》和《大规模语言模型：从理论到实践》累计销量超3万册，在大模型人才培养方面产生了广泛的产业影响力。这些教材被众多企业和高校用作大模型技术的学习资料。

## 七、Connection圈层总结

张奇的学术关系网络可以从以下几个圈层进行总结：

**第一圈层：复旦NLP实验室核心圈**。这是张奇关系网络中最紧密的一层，以黄萱菁教授为核心"枢纽"，邱锡鹏教授为平行核心，桂韬为传承延伸。张奇与黄萱菁构成"学术搭档"关系——共同指导学生、合著教材、联合发表论文，形成了复旦NLP实验室"吴立德-黄萱菁-张奇-桂韬"的代际传承链条。邱锡鹏则与张奇在MOSS、眸思等项目中形成横向协作。这一圈层是张奇学术网络的基础支撑。

**第二圈层：学生与校友网络圈**。张奇培养的30余名学生形成了一个覆盖国内外主要科技企业和高校的人才网络。其中，留在学术界的桂韬（复旦副研究员）、Jin Qian（山东大学）等延续了学术传承；进入产业界的校友广泛分布于微软亚洲研究院（Yeyun Gong）、Facebook/Meta（Yan Wu、Haomin Yu）、阿里巴巴（Ya Guo、Xiaoying Han等）、腾讯（Haoran Huang、Yang Wang等）、百度（Kang Han）、科大讯飞（Binbin Deng）、联想（Huan Chen）等头部企业。这一圈层是张奇连接学术与产业的重要桥梁。

**第三圈层：产业合作深度圈**。以中工互联为核心，张奇构建了"首席科学家+企业"的产学研深度融合模式。智工工业大模型、眸思多模态大模型、智工知语知识引擎等产品体现了这一合作的深度。此外，张奇团队技术与字节豆包、书生浦语、DeepSeek、联想AI PC等大模型产品的关联（据百度百科），说明其影响力已延伸至更广泛的产业生态。

**第四圈层：国内学术社区圈**。张奇通过在中国中文信息学会（理事、多个专委会常务委员）、CCF（大模型论坛常务委员）、全国信息检索大会（程序委员会联合主席）等学术组织中的服务，构建了覆盖国内NLP/IR学术界的广泛网络。这一圈层使张奇在国内学术政策制定、方向引领等方面具有影响力。

**第五圈层：国际学术网络圈**。通过在ACL、EMNLP、SIGIR、IJCAI、AAAI、COLING、WSDM等国际顶级会议的长期服务（领域主席、程序委员等），以及IBM Faculty Award等国际合作，张奇建立了与国际NLP/IR社区的联系。其学生进入NUS、UT Austin等海外高校也进一步拓展了这一网络。

总体而言，张奇的学术关系网络呈现"以复旦NLP实验室为核心、以学生网络为延伸、以产业合作为特色、以学术服务为辐射"的多层结构。其在产学研结合方面的深度参与，特别是通过中工互联的工业大模型实践，使其成为中国NLP学界中最具产业转化能力的学者之一。同时，通过合著教材和培养人才，张奇在大模型时代的人才生态建设中也发挥了重要影响力。
