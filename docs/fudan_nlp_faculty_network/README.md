## 二、各位教师的角色定位

吴立德是复旦NLP研究的奠基人，1937年生于上海，1955年考入复旦数学系，1959年提前毕业留校，1975年协助创建复旦计算机科学系并任第二任系主任（1982-1985）。他同时深耕CV与NLP两个领域，是同时获得CCF-CV终身学术贡献奖与中文信息学会会士的学者，共培养26名博士、66名硕士，退休后仍坚持开设NLP讨论班至2016年，构建了复旦NLP"吴立德—黄萱菁/邱锡鹏—桂韬"的完整代际谱系。

黄萱菁是实验室现任学术带头人，1998年在吴立德指导下获博士学位后留校，2006年晋升教授，曾赴UMass Amherst师从信息检索泰斗Bruce Croft访问研究。她与邱锡鹏、张奇共同主导MOSS大模型研发，合著两部NLP教材，学生网络覆盖桂韬（留组任教）等新一代骨干，并担任CCF NLP专委会主任等要职。

邱锡鹏是实验室面向大模型时代的旗帜性人物，博士师从吴立德（共同导师黄萱菁），国家优青。他2023年主持发布国内首个开源对话式大模型MOSS（GitHub星标超7万），所著《神经网络与深度学习》是国内深度学习领域最具影响力的教材之一。其学生创业现象显著：孙天祥（日行迹智能→百度）、李世民（模思智能CEO）等构成复旦系大模型创业的重要力量。

张奇是实验室骨干，2009年博士毕业于复旦（导师吴立德）后留校，上海市智能信息处理重点实验室副主任。他与黄萱菁、桂韬合著《自然语言处理导论》《大规模语言模型：从理论到实践》，主持研发"复旦眸思大模型"（面向视障人群的多模态大模型），并担任中工互联首席科学家推动工业大模型落地。

桂韬是实验室最年轻的核心教师，国防科大本科，2016年进入复旦硕博连读，2021年获博士学位（导师黄萱菁、张奇共同指导）。他是实验室鲁棒性、可解释性与Agent研究线（TextFlint、AgentGym等）的核心力量，2022年获国家自然科学基金青年基金，正处于从学生骨干向独立学术带头人的转型期。

魏忠钰是复旦NLP生态中"系外同盟军"的代表，哈工大本硕、港中文博士、UTD博后，2016年入职大数据学院创立Fudan DISC课题组。他深耕社会计算、多模态大模型与智慧医疗（DISC-MedLLM、DISC-FinLLM），牵头复旦-中电金信智能金融科技联合研究中心（黄萱菁任学术委员会主任），与FudanNLP形成了覆盖计算机学院与大数据学院的复旦NLP双子星格局。

## 三、全实验室关系网络的整体观察

FudanNLP的师资网络呈现出几个较为清晰的结构性特征。

第一是"单一师承、代际密集"的谱系结构。实验室现任四位核心教师全部出自吴立德一脉（黄萱菁、邱锡鹏、张奇为其直接博士弟子，桂韬为再传弟子），且黄萱菁与张奇共同指导桂韬、与邱锡鹏互为同门搭档，这种高密度内部师承在国内顶尖NLP实验室中独树一帜，也使实验室的学术风格（统计NLP传统→深度学习→大模型）保持了极强的连续性。

第二是"开源先行"的技术路线影响力。从吴立德时代的FudanNLP（国内首个中文NLP开源系统），到邱锡鹏的FastNLP，再到2023年发布MOSS（国内首个开源对话大模型，早于多数国内厂商），复旦NLP始终以开源作为扩大影响力的核心策略，MOSS的发布也直接带动了实验室在国际大模型社区的声誉。

第三是"学术—产业—创业"的三通道输出。学生去向横跨学术界（CMU、爱丁堡等海外深造后任教）、头部企业（字节、阿里、腾讯、DeepSeek、Apple）与自主创业（模思智能、日行迹智能），加上张奇担任中工互联首席科学家、魏忠钰运营校企联合研究中心，形成了"创业公司+企业首席科学家+联合实验室"三种产学研模式并行格局。

第四是跨院系协同的复旦NLP生态。FudanNLP（计算机学院）与Fudan DISC（大数据学院）的双核结构，加上与姜育刚（副校长、视觉方向）、马兴军等学者的交叉合作，以及上海创智学院（邱锡鹏、魏忠钰均为全时导师）等新型平台，使复旦NLP的实际影响力远超单一实验室的边界。
