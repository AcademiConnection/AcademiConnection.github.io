## 二、教育背景与职业履历

邱锡鹏的学术生涯与复旦大学紧密相连。1997年，他考入复旦大学攻读学士学位。值得注意的是，他本科入学时的专业并非计算机科学——据其在专访中回忆，上大学之前他几乎没有接触过计算机，正是在复旦的通识教育中，所有理科专业都需要学习编程语言，他由此对计算机编程产生了浓厚兴趣，并辅修了计算机作为第二专业。2001年本科毕业后，他继续在复旦大学攻读博士学位，师从吴立德教授。吴立德教授是复旦大学首席教授、计算机软件博士生导师，1937年4月生于上海、籍贯江苏宜兴，1955年考入复旦、1959年留校任教，1975年协助成立复旦计算机科学系，长期从事图像处理、模式识别、计算机视觉和自然语言处理等方面的研究，是复旦NLP研究的奠基人。

邱锡鹏读博所在的研究小组比较尊重个人兴趣。他的博士论文方向实际上是计算机视觉，但他的研究兴趣更多地偏向于机器学习底层算法。由于导师吴立德教授同时也在做自然语言处理方向的研究，邱锡鹏对NLP并不陌生。这段经历为他后来将机器学习方法应用于自然语言处理奠定了独特的基础。关于其博士毕业年份，多个来源存在出入：其个人主页及多数官方资料表述为"于复旦大学获得理学学士和博士学位"；36氪等媒体报道称其"1997年考入复旦大学，先后获得理学学士和博士学位，并自2007年起留校任教"；而搜狐的一次专访则称"2001年毕业后继续攻读博士学位，直到2006年毕业后加入复旦大学计算机科学技术学院"。综合判断，其博士毕业时间在2006年左右，留校任教时间约在2006至2007年间（待核实）。

留校后，邱锡鹏逐步将研究重心转向自然语言处理领域。他在自然语言处理的基础模型和基础算法上形成了大量创新研究成果。2015年是一个重要的时间节点：他入选首届中国科协青年人才托举工程，同年复旦大学首次开设《神经网络与深度学习》课程，由于当时没有合适的教材，邱锡鹏决定亲自编写讲义，这份讲义后来被扩写为专著《神经网络与深度学习》（俗称"蒲公英书"），成为国内AI教育领域的经典教材，豆瓣评分9.4分，被上百家高校作为教材采用。

此后，邱锡鹏主持研发了一系列具有广泛影响力的开源项目：早期开发了FudanNLP（中文NLP工具包）和FastNLP（轻量级NLP工具包），被国内外数百家单位使用；发布了CPT、BART-Chinese等中文预训练模型。2023年2月20日，他带领团队发布了国内首个对话式大型语言模型MOSS，成为国内大模型开源生态的标志性事件。此后团队又陆续推出SpeechGPT（端到端语音交互模型）、AnyGPT（全模态大模型）等。

在职业发展方面，邱锡鹏先后获得国家自然科学基金优青项目（青B）和国家杰出青年科学基金（青A/杰青）资助。他目前同时担任复旦大学教授、上海创智学院全时导师及院长助理（或副院长），并孵化了模思智能（Moss Intelligence）公司，担任创始人兼首席科学家。

## 四、学术合作网络

### 4.1 实验室内部合作

复旦大学自然语言处理实验室（FudanNLP）是邱锡鹏学术合作网络的核心圈层，主要由以下学者构成：

**黄萱菁**：复旦大学教授、博士生导师，复旦大学NLP实验室的另一位学术带头人。1993年获复旦大学计算机学士学位，1998年获复旦大学计算机博士学位（导师亦为吴立德），2006年起任复旦大学教授。黄萱菁与邱锡鹏构成了实验室的"双核"领导结构，两人在大量论文中共同署名，共同指导多位博士生（如刘鹏飞、陈新驰、龚经经、孙天祥、代俊奇、徐凝雨、汪燠欣等均标注"共同导师：黄萱菁"）。黄萱菁在2024年5月公开介绍AnyGPT等MOSS后续工作时，以"MOSS团队成员"身份出现，体现了两人在大模型方向的深度协作。

**张奇**：复旦大学计算科学技术学院教授、博士生导师，复旦大学NLP实验室核心成员。2003年进入复旦大学攻读研究生（导师为吴立德），长期从事自然语言处理研究。张奇积极推动产学研结合，在多模态、推理能力等方向与邱锡鹏密切合作，是钱伟长一等奖项目的核心完成人之一。他在AGI技术访谈中强调"NLP是一门应用导向的学科，研究应该对工业界有所助益"。

**桂韬**：复旦大学副研究员，邱锡鹏团队核心成员。桂韬在对抗鲁棒性、可控生成、推理智能体等方向与邱锡鹏有大量合作论文（ACL 2022有多篇联合论文），也是钱伟长一等奖项目的核心完成人之一。他开发的AGG平台通过统一环境奖励信号让模型在复杂任务中实现无监督学习。桂韬经常与邱锡鹏联合出席学术活动（如大连理工"百川讲堂"讲座、CCF ADL讲习班等）。

**姜育刚**：复旦大学教授，计算机科学技术学院/上海市智能视觉计算协同创新中心。姜育刚主要研究方向为计算机视觉，与邱锡鹏在多模态大模型（如"眸思"多模态大模型及"听见世界"公益助盲项目）上有跨方向合作，MOSS项目入选复旦大学2023年度十大科技进展时，完成人名单中包含姜育刚。

**马兴军、吴祖煊**：复旦大学教师，参与了MOSS相关项目，在2023年度复旦大学十大科技进展"MOSS：通用可信人工智能模型"中作为完成人出现。

### 5.1 产业合作与开源生态

邱锡鹏的产业合作以开源生态为核心特征，形成了从学术研究到产业落地的完整链条：

**MOSS开源生态**：2023年2月20日，邱锡鹏团队发布MOSS——国内首个公开邀请公众参与内测的类ChatGPT对话式大语言模型，参数规模约160亿。MOSS的发布在国内AI界产生了巨大反响，服务器发布当天即被挤爆。2023年4月，MOSS升级版正式开源上线，成为国内首个插件增强的开源对话语言模型。MOSS的开源策略是邱锡鹏"一直以来学术坚持"的体现，他认为高校应积极参与大模型生态建设。MOSS后续衍生出SpeechGPT（2023年，端到端语音交互模型）、AnyGPT（2024年，全模态大模型）、MOSS-Plugin（插件增强版本）、MOSS-Speech（语音大模型）、MOSS-Transcribe-Diarize（多说话人语音识别）、MOVA（音视频同步生成模型）等系列模型，构建了完整的开源模型矩阵。GitHub上OpenMOSS组织、FudanNLP组织、nndl组织、nex-agi组织的开源项目总Star数超过73,000个。

**与上海人工智能实验室的算力与平台合作**：MOSS研发得到了上海人工智能实验室的有力支持，后期通过开源方式与业界社区分享。邱锡鹏团队与上海AI实验室在OpenLMLab开源平台、算力资源调配等方面有深度合作。

**与头部企业的间接合作**：邱锡鹏的学生大量进入字节跳动、阿里巴巴/阿里云、百度、华为、腾讯、小米、蚂蚁集团、DeepSeek等头部科技企业，形成了人才层面的产业合作网络。特别是在大模型方向，黄绵秋加入阿里巴巴千问团队、陆星宇加入阿里云、叶家升加入DeepSeek、邢书豪加入上海人工智能实验室等，使邱锡鹏实验室与国内大模型产业生态建立了深度的关联。

**间接产业合作与共识构建**：在2023世界人工智能大会等场合，邱锡鹏与百度文心、阿里通义、华为盘古、讯飞星火、商汤日日新等大模型团队同台，共论国产大模型发展。虽然这些主要是平台性的学术-产业交流，但邱锡鹏在其中扮演了"学术界大模型代表"的角色，发挥了产学研桥梁作用。

### 5.2 创业孵化

**模思智能（Moss Intelligence）**：2024年11月25日，模思智能在上海成立，由邱锡鹏及其学生创办，是邱锡鹏创业孵化的核心载体。公司由上海创智学院与复旦大学联合孵化，邱锡鹏担任首席科学家，其学生李世民（2020级硕博）担任联合创始人兼CEO。模思智能聚焦于下一代强交互基础模型研发与商业化，核心定位为"情境智能"（Context Intelligence），区别于主流大模型"文本优先"的技术路径，聚焦全模态、情境理解、统一Token三大核心技术范式。

模思智能的核心团队兼具顶尖学术实力与丰富产业经验，博士占比近50%，核心成员均来自复旦MOSS团队，同时吸纳了阿里、字节、理想等头部企业的产业人才，形成了"学术研发+工程落地+商业化运营"的全链路团队架构。公司产品主要包括：MOSS-Speech模型（原生语音理解与生成）、MOSS-Transcribe-Diarize（多说话人自动语音识别，在AISHLL-4等多个基准测试中超越GPT-4o和Gemini）、MOVA（音视频同步生成模型）等。2026年4月，模思智能宣布完成数亿元天使轮融资，投资方为IDG资本、华为哈勃、元禾控股和智谱系机构星连资本，代表了顶级VC对邱锡鹏团队技术实力的认可。

**日行迹智能**：邱锡鹏的另一位学生孙天祥（2019级直博）创立了日行迹智能，专注于AI4AI方向（让AI自主研究AI）。多位邱锡鹏学生（邵云帆、刘向阳、汤琼等）毕业后加入日行迹智能，形成了实验室内部的创业孵化生态。

**开源社区的产业辐射**：邱锡鹏开发的FudanNLP和FastNLP开源工具包已被国内外数百家单位使用，其教材《神经网络与深度学习》在GitHub上关注数超过1.5万（待核实最新数据），这些开源和教学活动间接地为产业界培养了大量专业人才，形成了广泛的产业影响。

## 七、Connection圈层总结

邱锡鹏的学术关系网络呈现出鲜明的圈层结构，可以从内到外分为五个圈层：

**第一圈层——实验室核心团队**：这是邱锡鹏学术网络的最内圈，包括黄萱菁（联合实验室带头人、共同指导大量博士生）、张奇（实验室核心成员、产学研推动者）、桂韬（副研究员、多方向合作者）。三人加上邱锡鹏本人构成了复旦NLP实验室的领导核心，共同完成了钱伟长一等奖项目等标志性成果。此外，姜育刚（多模态合作）、马兴军、吴祖煊等也在MOSS等项目中紧密合作。

**第二圈层——指导的学生网络**：邱锡鹏十余年来培养了百余名学生，形成了庞大的人才网络。其中代表性学生包括：早期阶段的刘鹏飞（2014级，CAAI优博，CMU博后）、陈新驰（2013级，CIPSC优博，爱丁堡博后）、龚经经（2015级，腾讯）；中期阶段的李孝男（2020级，Apple）、李世民（2020级，模思智能CEO）；大模型阶段的孙天祥（2019级直博，MOSS主开发者，百度基础模型负责人）、颜航（2019级，上海AI实验室）。这些学生已分布在国内外顶尖高校、科技公司、研究机构和创业公司，形成了覆盖学术界和产业界的人才辐射网络。特别值得一提的是，邱锡鹏的学生去向高度集中于大模型相关领域（阿里巴巴千问、阿里云、DeepSeek、百度基础模型、上海AI实验室等），使其实验室成为国内大模型人才的核心输出节点之一。

**第三圈层——复旦校内与上海本地合作网络**：这一圈层包括复旦大学计算机学院AI方向的其他教师（薛向阳、颜波、冯瑞、张文强、张军平等近30名教师形成的AI研究群体）、上海人工智能实验室（MOSS算力支持、人才输送通道）、上海创智学院（联合人才培养和创业孵化平台）。复旦大学在CSRankings AI方向全球排名第15位，华东AI生态圈的形成与邱锡鹏团队的活跃密切相关。

**第四圈层——国内跨机构合作网络**：这一圈层包括清华大学的刘知远（大模型学术合作）、北京智源人工智能研究院、上海科技大学的赵登吉和屠可伟、以及通过CIPS和CAAI等学术组织连接的广泛国内NLP/AI学者群体。邱锡鹏在多个CCF ADL讲习班、CIPS前沿技术讲习班中担任学术主任或讲者，与国内同行建立了深度的学术交流关系。

**第五圈层——产业与创业生态**：这是邱锡鹏网络的外圈但极具影响力的一层。核心载体是模思智能（2024年成立，获IDG资本、华为哈勃、元禾控股等数亿元投资），辐射至日行迹智能（学生孙天祥创立）等创业公司。通过开源生态（MOSS系列模型累计Star超73,000个），邱锡鹏与国内大模型产业界建立了广泛连接——其学生分布在百度、阿里、字节、腾讯、华为、DeepSeek等几乎所有国内头部大模型团队中。模思智能的投资方包括华为哈勃，表明邱锡鹏的产业网络已延伸至华为等科技巨头的战略投资层面。

总体而言，邱锡鹏的学术关系网络具有以下显著特征：一是**以复旦NLP实验室为枢纽**，形成了从吴立德（学术源头）到黄萱菁/邱锡鹏（传承发展）再到新一代学生（孙天祥、李世民等）的清晰学术传承谱系；二是**以开源MOSS为超级节点**，将学术研究、人才培养和产业转化有机串联，形成了国内高校中少见的"开源-育人-创业"全链条模式；三是**人才输出高度集中于大模型方向**，使邱锡鹏实验室成为国内大模型人才的核心供给者之一，其学生在百度基础模型、阿里千问、DeepSeek等关键岗位的分布赋予了实验室在产业生态中的独特影响力；四是**创业孵化能力突出**，模思智能和日行迹智能两家由学生主导的创业公司形成了实验室内部的创业传承链条，这在学术型实验室中颇为罕见。
