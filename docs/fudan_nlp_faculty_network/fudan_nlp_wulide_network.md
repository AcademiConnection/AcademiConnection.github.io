## 二、教育背景与职业履历

吴立德1937年4月出生于上海，籍贯江苏宜兴。1955年，他凭借个人兴趣考入复旦大学数学系数学专业。当时的复旦数学系大师云集，苏步青、陈建功两位教授均于1955年当选为中国科学院首批学部委员（院士）。因当时院系调整需要部分学生提前毕业留校，吴立德于1959年1月提前大学毕业并留校任教，被分配到郑绍濂老师负责的概率论教研组，从事概率论与数理统计方面的纯理论研究。他参与编写了郑绍濂主持的《概率论与数理统计》教材，该书被国内多所高校采用。1979年，吴立德与汪嘉冈、李贤平、卞国瑞三位老师合著的三卷四册《概率论》（上海科技出版社）累计发行超过60万册。

吴立德早期科研以数学应用为导向，参与了两个标志性工程项目：一是上海水文地质大队地面沉降问题的数学建模，建立了开采量、回灌量与地下水水位及沉降幅度之间的数学模型（该项目获1978年全国科学大会奖）；二是地质部石油地震勘探资料的数字处理系统研发，由吴立德任研究组组长，在719大型计算机上以汇编语言完成了完整的处理系统（同样获1978年全国科学大会奖）。这些项目让他深刻认识到电子计算机的重要性，也使他的研究方向从一维信号处理自然延伸至二维图像处理和模式识别。

1975年10月，复旦大学成立计算机科学系，吴立德从数学系转入计算机系并参与了新系的创建。全系约三分之二的教师来自数学系、三分之一来自物理系。1977年，吴立德开始招收硕士研究生，研究方向包括模式识别。1978年，他越级晋升为副教授，同年获上海市先进工作者称号。1980年1月至1982年12月，吴立德赴美国进行为期两年的访问学者研究：在普林斯顿大学期间，合作导师为著名模式识别专家Theodosios Pavlidis教授（2000年国际模式识别最高奖"傅京孙奖"获得者），从事直线链码相关研究；在布朗大学期间，合作导师为Ulf Grenander教授，研究方向为数学统计。1982年，他在TPAMI（《IEEE Transactions on Pattern Analysis and Machine Intelligence》）上发表论文"On the Chain Code of a Line"，成为中国大陆学者在该顶级期刊上发表的第一篇论文。1984年，吴立德经国家教育委员会特批晋升为教授。同年发表TPAMI第二篇论文，提出了一种基于统计模型的分段逼近算法。

1982年至1985年，吴立德担任复旦大学计算机科学系主任。1985年起，他开始负责上海市计算机应用软件水平考试的组织和命题工作，该考试后来发展为国家计算机技术与软件专业技术资格（水平）考试（即"软考"），吴立德是其早期推动者之一。1986年，他被批准为计算机软件学科博士生指导教师。1987年开始招收博士研究生，首批博士生为庄青和翁富良，同年开启自然语言处理方向的研究——从中文分词方法入手，逐步深入到句法分析、语义分析等领域。1988年，他的第一个NLP方向硕士生徐坚毕业，毕业论文为英文句法自动分析系统。同年获得首个国家自然科学基金项目《早中期机器视觉中的新方法》，1988年获国家人事部"中青年有突出贡献专家"称号。1990年起享受国务院政府特殊津贴。1991年获首个NLP方向的国家自然科学基金《自然语言（汉语）理解中语义解释新方法的研究》，同年和1992年承担两个863课题。1993年出版专著《计算机视觉》（复旦大学出版社）。1997年与博士生黄萱菁合著《大规模中文文本处理》，这是国内首部中文统计自然语言处理专著。1998年获上海市优秀教育工作者称号。

2000年起，吴立德开始语义视频信息检索研究，并参加文本检索会议（TREC）评测，取得优异成绩（TREC/QA自动问答评测获第3名）。2007年，他从复旦大学计算机科学技术学院延聘退休。退休后的十年间（2007—2016），他坚持每周到张江校区开设NLP专题讨论班，采用手写板书方式为学生授课。2018年获CCF-CV终身学术贡献奖，2021年当选中国中文信息学会会士，成为同时获得计算机视觉领域和自然语言处理领域两项中国学术界最高荣誉的唯一学者。

## 三、学生培养情况

吴立德教授在计算机视觉和自然语言处理两个领域共培养了26名博士生、66名硕士生，完成近50项科研项目，出版7部专著、发表200余篇论文。以下列出其主要学生及其师承关系：

### 1. 黄萱菁（复旦大学特聘教授，博士生导师，吴立德博士生）

黄萱菁是吴立德在NLP方向培养的代表性学生之一。她1993年获复旦大学计算机理学学士学位，此后在复旦大学获得计算机理学博士学位（百科词条记载为1998年获博士学位，部分报道提及1999年毕业，具体以1998年为准）。她的博士导师即吴立德教授。1996年，她与吴立德合作在《模式识别与人工智能》发表论文《基于机器学习的无需人工编制词典的切词系统》，展现了早期在统计NLP方面的工作。黄萱菁的研究最初涉及计算机视觉，后转向自然语言处理——据她回忆，因导师吴立德"一手做视觉，一手做自然语言"，她在研究生第二年转入NLP方向。博士毕业后留校任教，2000年晋升副教授，2006年起任复旦大学信息学院、计算机学院教授、博士生导师。2008—2009年赴美国麻省大学阿默斯特分校（UMass Amherst）CIIR实验室做访问学者。现为复旦大学特聘教授、国家级领军人才，兼任中国计算机学会理事/自然语言处理专委会主任、中国中文信息学会理事、国际计算语言学学会（ACL）执委/亚太分会主席。发表论文200余篇，被引3万余次，获钱伟长中文信息处理科学技术奖等多项荣誉。黄萱菁是吴立德退休后复旦NLP方向的学术带头人，也是FudanNLP实验室当前的核心领导者之一。

### 2. 邱锡鹏（复旦大学特聘教授，MOSS系统负责人，吴立德博士生）

邱锡鹏本科毕业于复旦大学化学系，属于"半路出家"——得益于复旦通识教育接触编程后辅修计算机为第二专业，随后在复旦大学计算机学科攻读博士学位，师从吴立德教授。他的博士论文方向为计算机视觉，但研究兴趣更多偏向机器学习底层算法，因导师吴立德同时从事NLP研究，他对自然语言处理并不陌生。留校后研究兴趣逐步聚焦于NLP。邱锡鹏在访谈中特别提到吴立德对他"深远积极的影响"：吴教授数学专业出身、功底深厚，治学严谨、授课通俗易懂，是他一直佩服并学习的榜样。邱锡鹏现为复旦大学特聘教授、上海创智学院院长助理、CAAI Fellow，主要研究方向为自然语言处理基础技术和基础模型，发表CCF A/B类论文80余篇，被引用4万余次。他编著的《神经网络与深度学习》被上百家高校作为教材。2023年2月，他主持研发的MOSS成为国内首个公开发布的对话式大语言模型。曾获ACL 2017杰出论文奖、2022年度钱伟长中文信息处理科学技术奖一等奖、2024年度CCF-ACM青年科技奖、2025年度吴文俊人工智能科学技术奖自然科学一等奖等。邱锡鹏是吴立德学术血脉中影响力最为广泛的传承者之一，使复旦NLP在大模型时代占据国内引领地位。

### 3. 张奇（复旦大学教授，上海市智能信息处理重点实验室副主任，吴立德研究生）

张奇2003年进入复旦大学攻读研究生学位，导师为吴立德教授。据张奇回忆，当时复旦有数据库和多媒体等热门方向，吴立德推荐他关注自然语言处理领域。张奇2009年于复旦大学获得计算机应用专业博士学位并留校任教，现为复旦大学计算机科学技术学院教授、博士生导师。他长期从事自然语言处理与信息检索研究，在ACL、EMNLP、SIGIR等顶级会议发表论文200余篇，获美国授权专利4项，著有《自然语言处理导论》《大规模语言模型：从理论到实践》（累计销量超3万册）。曾获WSDM 2014最佳论文提名奖、COLING 2022杰出论文奖、钱伟长中文信息处理科学技术一等奖、IBM Faculty Award等。张奇强调"NLP是一门应用导向的学科，研究应该对工业界有所助益"，其团队研发的"智工知语企业级知识引擎"获2024年中国高交会优秀科研成果创新奖，多个技术应用于书生浦语、字节豆包、DeepSeek等10余个大模型产品。他目前还担任复旦大学"眸思"（MouSi）多模态大模型负责人。

### 4. 庄青（吴立德首批博士生之一）

庄青是吴立德1987年开始招收博士研究生后的首批博士生之一，其博士课题为三维物体的识别研究，属于计算机视觉方向。关于庄青的具体毕业年份和后续去向，公开信息较少（待核实）。

徐坚是吴立德在自然语言处理方向培养的第一个硕士研究生，1988年毕业，毕业论文方向为自然语言处理中的句法分析，论文题目为《FDATN——一个英文句法自动分析系统》。这标志着吴立德NLP研究的正式起步。关于徐坚的后续职业去向，公开信息有限（待核实）。

### 8. 吴立德学生群体整体概况

吴立德在数十年的教学生涯中培养了二十余名博士和六十余名硕士，涵盖计算机视觉和自然语言处理两大方向。他在复旦建系五十周年大会上发言时以"小树已成林"概括学科发展，提到学院五十年间累计培养上万名人才，涌现出专家教授、企业高管、部队将领等杰出校友。他的学生中，黄萱菁、邱锡鹏、张奇构成了复旦NLP实验室三代传承的核心链条：吴立德 → 黄萱菁（第一代传承） → 邱锡鹏、张奇（第二代传承），使FudanNLP从上世纪70年代的初创发展至今日在大模型时代的引领地位。

## 四、学术合作网络

### 4.1 实验室内部合作

复旦大学自然语言处理实验室（FudanNLP）由吴立德于上世纪70年代创建，经过40余年发展形成了紧密的内部合作网络。实验室当前以黄萱菁、邱锡鹏、张奇三人为核心教授，共同带领团队在自然语言处理底层分析、文本检索、自动问答、社会媒体分析、神经网络结构研究、信息抽取等方向开展研究。三人在ACL、EMNLP、SIGIR、COLING等顶级会议上频繁联合发表论文，例如ACL 2022中实验室12篇长文录用、EMNLP 2022中14篇长文录用均体现了三位教授的高密度合作。黄萱菁与张奇联合团队在信息抽取方向的研究成果获COLING 2022杰出论文奖。此外，实验室开发了FudanNLP（国内首家中文自然语言处理开源系统，被联合国教科文组织等机构采用）和FastNLP等开源系统，体现了内部协作的工程化产出。吴立德退休后仍通过专题讨论班为实验室师生授课十年（2007—2016），维持了实验室的学术传统传承。

### 4.2 跨机构合作

吴立德及其实验室的跨机构合作主要体现在以下方面：

- **与上海水文地质大队的合作**（上世纪60年代）：吴立德早期参与的上海地面沉降数学建模项目，是与上海水文地质大队合作完成的工程应用研究，该成果获1978年全国科学大会奖。
- **与地质部物探大队的合作**（上世纪60—70年代）：联合地质部第四物探大队、第六物探大队和第一海洋地质调查大队，由吴立德任组长开发石油地震勘探数字处理系统，同样获1978年全国科学大会奖。
- **与复旦大学数学系的合作**：吴立德与汪嘉冈、李贤平、卞国瑞合著《概率论》三卷四册教材，是复旦数学系内部的重要学术合作成果。
- **与上海市科委的合作**：1985年起，吴立德负责上海市计算机应用软件水平考试的组织与命题工作，该考试由上海市科委出资、复旦大学计算机系执行，后推广至全国。
- **与上海人工智能实验室的合作**：邱锡鹏团队研发MOSS大模型时得到上海人工智能实验室的有力支持，这是实验室近年来最重要的跨机构产学研合作之一。

### 4.3 国际合作

吴立德的国际合作始于1980—1982年赴美国普林斯顿大学和布朗大学的访问学者经历。在普林斯顿大学，他与模式识别专家Theodosios Pavlidis教授合作从事直线链码研究，相关成果发表于TPAMI。在布朗大学，他与Ulf Grenander教授合作进行数学统计方面的工作。这两段国际合作奠定了吴立德在模式识别和计算机视觉领域的学术基础。在其后的学术生涯中，吴立德实验室长期参加TREC（文本检索会议）等国际评测，在TREC/QA自动问答评测中获得第3名，在文本蕴涵评测RITE和阅读理解评测SQuAD中均位居前列。黄萱菁2008—2009年赴美国麻省大学阿默斯特分校CIIR实验室做访问学者，进一步拓展了实验室的国际学术联系。当前实验室在ACL、SIGIR、EMNLP、NeurIPS、ICML、AAAI、IJCAI等国际顶级会议和期刊上发表论文150余篇，保持持续的国际学术影响力。

## 五、业界合作关系深度分析

### 5.1 产业合作

吴立德及其领导的FudanNLP实验室在产业合作方面具有深厚的传统和突出的成果，主要体现在以下几个层面：

**（1）开源系统的产业辐射**

实验室发布的FudanNLP是国内首家中文自然语言处理开源系统，采用Java编写，提供分词、词性标注、句法分析、文本相似度计算等工具及数据集。该系统被包括联合国教科文组织在内的国内外多家研发机构采用。此后，实验室又推出FastNLP等开源系统，持续为大模型时代的技术社区提供基础设施。邱锡鹏研发的MOSS大模型于2023年2月发布后即开源，成为国内影响力最大的开源大型语言模型之一。这种开源策略体现了实验室将学术成果辐射产业界的核心理念。

**（2）校企合作项目**

张奇教授作为实验室核心成员，强调"NLP是一门应用导向的学科，研究应该对工业界有所助益"。他主持了包括国家自然科学基金、国家863计划、国家科技支撑计划和国际合作项目在内的10余项科研课题，并承担了大量校企合作项目。其团队研发的"智工知语企业级知识引擎"获2024年中国高交会优秀科研成果创新奖，多个技术应用于书生浦语、字节豆包、DeepSeek、联想AI PC等10余个大模型产品。这反映了实验室与字节跳动、联想、DeepSeek等企业的深度技术合作。

**（3）大模型时代的产业联动**

2023年MOSS的发布使FudanNLP实验室成为国内大模型研发的重要力量。实验室与上海人工智能实验室建立了密切的合作关系，MOSS研发项目得到上海人工智能实验室的有力支持。邱锡鹏提出国内大模型需要"从头到底有一套自主研发的技术，适配国内的配套硬件"，强调上海在AI全链条企业方面的生态优势。实验室还推出多模态大模型"复旦·眸思"（张奇负责），开发了"听见世界"APP为视障者提供服务，体现了从技术研究到产业应用的完整链路。

**（4）早期产业实践：软考体系**

吴立德1985年起推动的计算机应用软件水平考试，从上海市科委出资、复旦命题起步，逐步推广至全国多省，最终由国家人事部接管成为国家"软考"体系。这一制度性建设对计算机软件产业人才评价体系产生了深远影响，1989年获上海市科技进步三等奖。吴立德因此被誉为中国计算机"软考"的早期推动者之一。

### 5.2 创业孵化

吴立德实验室在创业孵化方面的影响主要通过其学生的产业实践体现：

- **黄萱菁**作为国家级领军人才，注重产研结合与科技向善，主持多项国家自然科学基金和国家重点研发计划项目，推动NLP技术在文本分析、社会媒体分析等场景的落地应用。
- **邱锡鹏**主持研发的MOSS系列大模型已成为国内最具影响力的开源大模型之一。其著作《神经网络与深度学习》被上百家高校用作教材，MOSS的开源策略为国内学术界和产业界提供了重要的技术底座和实践经验。
- **张奇**团队的技术直接应用于字节豆包、DeepSeek等多个大模型产品，并在企业级知识引擎领域实现产业化落地。其参与翻译的《现代信息检索》教材也在产业界有广泛影响。

吴立德本人在建系五十周年大会发言中提到，学院五十年间培养的校友中有"企业高管"等杰出人才，许多校友通过设立基金等方式反哺学院。虽然吴立德本人未直接参与企业创办，但其学术传承体系通过学生群体深刻影响了中国NLP产业的技术生态。

## 七、Connection圈层总结

吴立德教授的学术网络可从以下圈层进行总结：

**第一圈层：核心学术传承圈（直系师承关系）**

吴立德 → 黄萱菁（1998年博士毕业，复旦NLP第一代传承人） → 邱锡鹏、张奇（第二代传承人，当前实验室核心）。这一师承链条构成了复旦NLP四十年发展的核心骨架。黄萱菁作为吴立德退休后的学术接班人，与邱锡鹏、张奇共同将实验室从传统NLP推向大模型时代的最前沿。吴立德在计算机视觉方向的传承（如庄青、翁富良等早期博士生）亦为其学术网络的重要组成部分，但公开信息相对有限。

**第二圈层：实验室内部合作圈**

FudanNLP实验室以黄萱菁、邱锡鹏、张奇三人为核心，形成了紧密的内部合作网络，在ACL、EMNLP等顶级会议上联合发表论文，共同开发FudanNLP、FastNLP、MOSS等开源系统。实验室现有教师团队还包括薛向阳、姜育刚、颜波等近30名AI方向教师，构成了复旦大学计算机学科人工智能研究的整体力量。

**第三圈层：复旦校内合作圈**

吴立德的学术网络延伸至复旦数学系（郑绍濂等概率论教研组前辈）、计算机系早期创建团队（1975年建系时从数学系和物理系转入的教师群体）以及当前的计算与智能创新学院。其早期工程合作涉及上海水文地质大队、地质部物探大队等外部机构。

**第四圈层：国际合作圈**

吴立德的国际学术网络始于1980—1982年在普林斯顿大学（合作导师Theodosios Pavlidis）和布朗大学（合作导师Ulf Grenander）的访问学者经历。实验室长期参加TREC等国际评测，黄萱菁2008—2009年赴UMass Amherst做访问学者，实验室持续在ACL、SIGIR、NeurIPS等国际顶会发表论文，保持了国际学术影响力。

**第五圈层：产业合作与影响圈**

实验室通过FudanNLP和MOSS等开源系统辐射全球产业界。张奇团队与字节跳动、DeepSeek、联想等企业建立技术合作，QI奇团队的"智工知语"知识引擎实现产业化落地。MOSS与上海人工智能实验室的合作代表了大模型时代产学研协同的新模式。吴立德1985年起推动的"软考"体系则从制度层面深刻影响了中国计算机软件产业的人才评价标准。

**第六圈层：学术影响圈**

吴立德是同时获得计算机视觉领域（CCF-CV终身学术贡献奖，2018年）和自然语言处理领域（中国中文信息学会会士，2021年）两项中国学术界最高荣誉的唯一学者。1997年与黄萱菁合著的《大规模中文文本处理》是国内首部中文统计NLP专著。其培养的26名博士和66名硕士广泛分布于学术界和产业界，使吴立德的学术影响力从上世纪70年代延续至今日的MOSS大模型时代，成为中国NLP学术谱系中不可或缺的源头性人物。
