# 山东大学智能算法与软件实验室（IALS）教师学术关系网络报告索引

## 一、团队概况

智能算法与软件实验室（Intelligent Algorithm and Software Laboratory, IALS）隶属山东大学计算机科学与技术学院，学术源头为 1980 年代马绍汉教授创立的理论计算机研究团队，是山东大学"计算理论与智能算法"学科方向的主要承载单位。

实验室在学院博士招生体系中对应"智能算法与软件团队"，2022 年团队简介页列出 7 位成员：朱大铭（二级教授）、郭炅（泰山学者特聘教授）、冯好娣、崔学峰、姜海涛、时阳光、彭朝晖。团队自述承担国家自然科学基金重点项目、重大国际合作项目与多项面上项目，累计经费超过 1000 万元，在 JACM、ACM TALG、JCSS、Algorithmica、Theoretical Computer Science、Bioinformatics、IEEE/ACM TCBB 等发表论文 300 余篇。

## 四、团队关系网络的主要特征

- **一条师承主轴**：马绍汉→朱大铭→姜海涛三代同堂，构成团队"计算理论"血统的骨架；郭菲、蒲莲容、张舒等学生在高校与科研机构扩散。
- **两种方法传统并存**：基因组重组/近似的"近似比分析"传统（朱大铭、姜海涛、冯好娣）与参数化算法、核心化传统（郭炅）互补；时阳光则带来算法博弈论与学习论这一相对独立的方法支线，与团队其他成员无共著，属"共享品牌、独立 PI"。
- **跨实验室连接**：郭炅与 IRC 的辛士庆、屠长河在 ACM TOG 2024 与 CAD 2025 有共同署名，是 IALS 与 IRC 之间可核实的跨团队边；姜海涛、彭朝晖则分别通过国家重点研发计划课题与校企平台向外延伸。
- **产业形态偏"轻"**：团队整体以纵向课题与理论会议产出为主，横向项目与专利较少，与同院 IRC、GAI Lab 的产业化强度形成对照；彭朝晖是团队中产业平台最密集的成员（山东大学—电科金仓、山东大学—浪潮科技数据要素治理研究中心）。
