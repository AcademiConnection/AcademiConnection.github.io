# 浙江大学 杨莹春副教授课题组 教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

杨莹春副教授课题组（隶属浙江大学计算机科学与技术学院 CCNT 实验室体系）是一个以说话人识别（声纹识别）为核心的小型课题组。杨莹春2000年获浙江大学电气学院控制理论与控制工程博士学位（博士导师据论文署名推断为诸静教授，已审慎标注），2002年在浙大计算机学院 CCNT 实验室完成博士后研究后留校任教，从此扎根生物特征识别领域二十余年。

课题组的研究主线是声纹识别与语音安全，尤其聚焦说话人内在变化（如情感变化）导致的识别失配问题，近年拓展至深伪语音检测（anti-spoofing）、生物行为识别、脑机接口、遥感计算（语义分割与域适应）与音乐可视化计算等方向。作为硕士生导师，杨莹春培养了以硕士研究生为主体的学生梯队（张震川、谢杨、蔡宇翔、赵新平、全杰、单振宇等），深伪语音检测方向已传承两代学生。课题组论文发表于 ICASSP、Interspeech、ODYSSEY、CCBR、PRCV 等语音与模式识别会议及 IEEE TGRS 等期刊。

由于课题组规模较小（单一教师），本报告系列仅含杨莹春一位教师的独立报告，其学术网络的定位是嵌入浙大 CCNT/ACES 大团队（吴朝晖、尹建伟、邓水光等）的"声纹识别与语音安全"专门节点，而非独立的实验室体系。

## 圈层结构概述

杨莹春的学术网络呈现"一核两翼"结构。内核是浙大 CCNT/ACES 实验室体系：博士后阶段的导师性人物吴朝晖（前浙大校长）是其与"脑机融合的混合智能理论与方法"项目（2016年吴文俊人工智能科学技术奖创新奖一等奖，15位完成人中列末位）的纽带；尹建伟、邓水光（ACES 实验室）则是其遥感计算方向的主要合作者，将其纳入"钱塘离朱智能遥感大模型"与国家高分重大专项"高分网格二期"平台。左翼是声纹识别的国际国内学术共同体（Interspeech/ODYSSEY 社区）；右翼是产业与国家工程网络——早期参与钱塘中间件平台（据百度百科，通过Intel/Sun认证），近年经遥感大模型服务国家电网、航天科技、北控集团等企业。学生的典型去向为互联网与安全企业。整体而言，这是一个"小而专"的课题组：以声纹识别为独立学术标识，同时在大型团队项目中承担专门技术角色。
