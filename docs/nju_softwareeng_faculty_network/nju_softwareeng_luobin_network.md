## 一、学者基本信息

骆斌，南京大学软件学院二级教授、博士生导师，南京大学计算机软件新技术全国重点实验室（原国家重点实验室）教授，南京大学赵世良讲座教授，国家"万人计划"教学名师，享受国务院政府特殊津贴，CCF杰出会员。他是南京大学软件学院的主要创建人之一，现任教育部软件工程教学指导委员会副主任（第一届至第三届，2013-2017/2018-2025/2026-2030），江苏省计算机学会特色化软件人才培养专业委员会主任；曾任南京大学软件学院副院长（2002-2020年，其中2002-2008年主持学院工作）、教育部计算机教学指导委员会软件工程分委员会委员（2004-2012年）、第十届中国计算机学会理事。

**教育与工作经历：**
- 1985年进入南京大学计算机科学系学习，先后获得计算机软件专业理学学士、工学硕士学位。
- 1992年参加工作；1988年起从事智能操作系统与数据库研究；2000年初获计算机应用技术专业工学博士学位，同年任副教授。
- 2003年晋升教授，2006年获聘博士生导师，2008年定为三级教授，2012年晋升二级教授。
- 2002年作为核心成员参与创建南京大学软件学院（筹备组成员为张大良、陈道蓄、骆斌、黄细良、朱怀宏），任专职副院长至2020年。
- 现为软件学院教授、博士生导师，语言智能处理实验室（LIPLab）负责人。

**研究主线与代表性贡献：**
1. **软件工程学科与专业建设：** 主持（软件工程）国家一流专业和（软件工程主干课程）国家级教学团队，参与倡议设立软件工程一级学科，主编《计算与软件工程》《操作系统教程》《需求工程》《软件过程与管理》等系列教材。
2. **智能软件工程：** 指导团队围绕代码预训练模型（SPT-Code、FAIR）、代码摘要、神经程序修复（StandUp4NPR、偏好集成程序修复）、缺陷定位与追踪（RAT、ABLoTS复现）等方向在TOSEM、TSE、ICSE、ASE、AAAI等发表系列论文，在ICSE 2024、ASE 2023、MSR 2023三次获ACM SIGSOFT Distinguished Paper Award。
3. **司法大数据与智慧司法：** 自2001年"法院综合信息系统"（江苏省科技进步二等奖，第1完成人）起持续深耕司法信息化，团队在法律条文推荐、司法判决预测、证据链建模等方向持续产出（TKDD 2021、AAAI 2026等）。
4. **大规模应用工程：** 主持多项千万级重大科研项目，作为主要完成人（应用项目主持人）获2006年国家科技进步二等奖（对象化与主体化的软件开发技术、平台与应用）。

**教学与荣誉：** 因软件工程专业实践教学体系、人才培养体系、关键课程/教材体系建设于2005、2009、2014年连续三届获国家教学成果二等奖（均第1完成人），2023年获第九届国家教学成果一等奖，2021年获首届国家优秀教材二等奖；另获2025年南京大学卓越教学奖、首届高校计算机专业优秀教师奖、宝钢教育基金优秀教师特等奖提名奖，并十余次获省部级科技/教学奖励。《计算机操作系统》MOOC在Coursera、中国大学慕课、学堂在线累计注册学习者超42万人次。

## 三、教育背景与学术谱系

### 3.1 南京大学本硕博（1985-2000）

骆斌的本科、硕士、博士均在南京大学完成，学科脉络从计算机软件（本硕）转向计算机应用技术（博士）。1988年起他从事智能操作系统与数据库研究，这一出身使其长期承担《计算机操作系统》课程与《操作系统教程》教材建设——该教材第一至四版由孙钟秀院士主编，骆斌自2003年第三版起参编、第六版起主编，构成南大操作系统教学传统的代际交接（此为教材传承关系，其博士导师未在公开资料中列明，报告不作推断）。

### 3.2 软件学院创建者角色（2001-2020）

2001年南京大学开始申报示范性软件学院，2002年2月成立由张大良、陈道蓄、骆斌、黄细良、朱怀宏组成的筹备组；同年4月学院成立，陈道蓄兼任首任院长，骆斌任专职副院长并于2002-2008年主持学院工作，直至2020年卸任副院长。软件学院其后发展为拥有软件工程一级学科博士点的学院，据CSRankings统计（2015-2025）南大软件工程方向位列世界第一。骆斌的学术网络因此天然带有"学院组织者"属性：学院内各实验室（艾塔实验室η-ETA、软件研发效能实验室、COSEC、媒体识别与理解、语言智能处理等）的负责人多为其后辈同事。

### 3.3 与吕建院士的项目合作

骆斌作为主要完成人（应用项目主持人）获2006年国家科技进步二等奖，获奖项目"对象化与主体化的软件开发技术、平台与应用"与南京大学计算机软件新技术国家重点实验室吕建院士（时任实验室主任、后任南京大学校长）的软件方法学体系一脉相承。此外，LIPLab核心成员葛季栋的博士导师即吕建（2007年毕业），使骆斌团队与南大软件学科的最高学术谱系形成直接连接。

## 六、Connection圈层总结

**第一圈层——LIPLab自培养团队：** 葛季栋（106次）、李传艺（98次）、冯奕（16次）及博士生群体构成骆斌学术网络的内环。该团队以"司法NLP起家—代码智能深化—LLM安全延伸"为主线，已输出冯奕、李传艺两位独立PI。

**第二圈层——南大软件学科谱系：** 通过教材传承（孙钟秀）、国家奖项目（吕建）与学院创建者身份，骆斌嵌入南大软件学科的顶层结构；葛季栋的吕建门背景进一步强化了这一连接。学院现任领导层（仲盛、卜磊等）与各实验室负责人均处于其"同事—后辈"网络中。

**第三圈层——跨院系合作：** 陈振宇/房春荣（计算机学院iSE实验室，17+7次）、张胜（边缘计算，9次）、胡昊（8次）等构成面向测试、边缘计算的校内协作层。

**第四圈层——国际合作：** UTDallas（Vincent Ng，29次）、JKU林茨（Egyed，6次）、天普大学（Du/Guizani/Wu，57次合计）构成美欧双通道，分别覆盖NLP、软件工程实证与网络安全。

**第五圈层——应用与产业落地：** 智慧司法（中央政法委示范工程）、华为/腾讯企业项目、军队科技进步奖与千万级工程项目构成其应用网络；教材与MOOC则将影响扩展至全国软件工程教育共同体。

**产出规模与发展阶段：** 203条DBLP记录、274位唯一合作者，2017年后年均约16条的稳定产出表明骆斌处于"资深组织者+团队化产出"阶段：其个人署名重心已从一线研究转向方向把关与资源组织，学术增量主要由LIPLab梯队与毕业生网络承载。
