## 全团队关系网络的整体观察

软件学院（南京）的这组教师呈现"教学名师+工程应用+智能化新生代"的层叠结构。骆斌是软件学院的创建级人物：2002-2020年长期主持学院教学工作，三获国家教学成果奖并主笔2023年一等奖，其LIPLab以司法NLP（与法院系统合作的诉讼服务智能化）和程序修复为两大应用主线，学生骨干葛季栋（106次合作）、李传艺（98次）构成稳定署名单元，近年在ICSE/ASE/MSR连获三项SIGSOFT杰出论文奖是其学术侧的亮眼成绩。何铁科的艾塔实验室（η-ETA Lab，2024年前后组建）以图机器学习与大模型为方法主线，与昆士兰大学Hongzhi Yin等保持国际连线，并与骆斌LIPLab通过CHASE等联合论文构成软件学院内部的"智能化软件工程双引擎"。冯奕代表LIPLab的代际传承——骆斌博士生、UTDallas随Vincent Ng访学后留校，研究方向从法律NLP延伸至大模型推理与Agent。

本组的交叉网络锚点包括：仲盛（软件学院院长，另有报告）、卜磊（副院长，另有报告）、陈振宇团队（计算机学院iSE，何铁科博士阶段合作线）、以及骆斌与吕建在2006年国家科技进步二等奖项目上的合作（详见骆斌报告）。
