## 研究方向与圈层结构概述

HCP-Lab的研究围绕多模态人工智能和具身智能展开，涵盖多模态感知与理解、多模态物理世界模型（精准可控的图像视频生成、3D场景生成）、具身智能技术及应用（"感知-规划-执行"通用模型架构、类人通用机器人）三大方向。实验室以"攀学术高峰、踏应用实地"为工作理念，形成了产学研用体系化研究模式。

在学术圈层结构上，HCP-Lab呈现"林倞—梁小丹/李冠彬—青年骨干"的传承与协作架构。林倞教授作为创始人和商汤科技前执行院长，其学术影响力辐射全国AI领域，Google Scholar引用近5万次，H指数103+。梁小丹教授作为林倞的博士弟子和CMU Eric Xing的博士后，已成为具身智能方向的领军青年学者。李冠彬教授（香港大学博士，师从俞益洲）引入了港大MMLab的学术血脉，并出任计算机学院副院长。王可泽、王广润、刘阳、杨思蓓、董浩业、魏朋旭、王州霞等青年科学家各自在视频生成、人体建模、具身智能、视觉推理等方向形成了差异化的研究特色。其中7人为国家级青年人才，体现了实验室在人才引进方面的突出成效。

## 产业转化亮点

HCP-Lab的产业转化能力极为突出。林倞教授曾任商汤科技研究院执行院长/首席研发总监，带领企业搭建大规模AI基础设施，这段经历为实验室奠定了深厚的产业基础。实验室与字节跳动、华为、广州视源科技等知名企业开展广泛合作。梁小丹教授获华为"难题揭榜"火花奖，华为战略研究院为其团队提供百万级晟腾算力支持。林倞教授创办了拓元智慧（X-Era AI），王广润教授担任首席科学家，聚焦物理空间智能和大物理模型。实验室发布的PhyAgentOS自进化具身智能操作系统赋能全球具身智能技术挑战赛冠军，24篇论文被CVPR 2026录用。实验室指导的博士生梁小丹、王可泽、王广润等分别获得CCF、ACM China和CAAI优秀博士论文奖，形成了从学术到产业的完整人才输送链条。
