## 研究方向与圈层结构概述

AIR的研究围绕人工智能产业应用展开，覆盖智慧物联（边缘计算、移动计算）、智慧交通（自动驾驶、车路协同）、智慧医疗（医疗大模型、AI for Health）、大数据智能（信息检索、自然语言处理、大语言模型）和智能机器人（具身智能、视觉与机器人）五大方向。AIR的独特定位是"高校+产业"双引擎模式，既承担国家级科研项目，又通过孵化企业实现技术转化。

在学术圈层结构上，AIR呈现"张亚勤—各方向首席—青年研究员"的层级架构。张亚勤院士作为创始院长，其微软和百度的产业经历为AIR奠定了强大的产学研基础。马维英、李航、聂再清、刘云新等首席研究员均有微软亚洲研究院（MSRA）的长期工作经历，形成了以MSRA校友为核心的学术网络。刘洋教授作为NLP领域专家出任院长，兰艳艳、刘菁菁分别在AI for Science和多模态大模型方向形成特色。周谷越副教授作为李泽湘教授的弟子，将机器人创业体系引入AIR。

## 产业转化亮点

AIR的产业转化能力极为突出。院级合作单位包括水木分子（药物发现大模型）、求之科技（具身智能机器人）、华深智药（AI药物设计）、清智资本（AI产业投资）、紫荆智康（医疗AI）等孵化和合作企业。刘洋教授团队的Agent Hospital和紫荆智康在医疗AI领域取得了突破性进展，其人工智能医院在USMLE考试中达到96%的准确率。兰艳艳教授团队的AIRFold获得国际蛋白质结构预测比赛CAMEO全球冠军，基因调控AI大模型发表于Nature正刊。聂再清教授主导的水木分子开发了BioMedGPT和全原子基座PharMolix-FM。周谷越副教授的DISCOVER Lab在具身智能和机器人方向与求之科技深度合作。微软亚洲研究院作为AIR团队的核心前雇主，为AIR提供了丰富的人才资源和产业连接。
