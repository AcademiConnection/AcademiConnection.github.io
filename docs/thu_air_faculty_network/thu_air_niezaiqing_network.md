## 二、教育背景与职业履历

聂再清本科与硕士均毕业于清华大学计算机科学与技术系。1991年至1996年攻读计算机科学与技术学士学位，1996年至1998年攻读计算机应用硕士学位，在清华园完成了扎实的计算机系统结构与软件算法工程基础训练。1999年，聂再清赴美深造，进入亚利桑那州立大学（Arizona State University, ASU）计算机科学系攻读博士学位，师从国际著名人工智能科学家、美国人工智能学会（AAAI）前主席 Subbarao Kambhampati 教授。博士期间，他专注于互联网异构数据集成、覆盖与重叠统计挖掘（BibFinder/StatMiner系统）以及数据源排名（SourceRank）等开创性方向，于2004年获得计算机科学博士学位。

2004年博士毕业后，聂再清加入微软亚洲研究院（MSRA），开启了长达13年的工业研究院核心研发历程。在MSRA期间，他从副研究员起步，历任主管研究员、高级研究员，最终晋升为首席研究员（Principal Researcher）。聂再清是业界“应用驱动型研究”（Deployment-Driven Research）的杰出践行者与先锋人物。他开创性地提出了对象级别（Object-level）互联网搜索理论与大数据实体关系挖掘算法，是微软知名创新产品“人立方”（Renlifang）关系搜索引擎和“微软学术搜索”（Microsoft Academic Search）的发起人与技术负责人，同时作为技术负责人主导了微软自然语言理解开发者平台 LUIS（Language Understanding Intelligent Service）以及企业智能助理 EDI 的研发。这些突破性技术引领了全球大数据驱动知识图谱（Knowledge Graph）挖掘与语义理解的工业潮流。因其卓越贡献，聂再清在微软期间被授予微软公司最高员工荣誉之一——Microsoft Golden Star奖。

2017年10月，在万物互联与语音智能交互大爆发的前夜，聂再清加盟阿里巴巴集团，出任阿里巴巴人工智能实验室（AI Labs）北京研发中心负责人、阿里巴巴达摩院关键业务技术领军人，并担任战略级智能硬件“天猫精灵”的首席科学家。在此期间，聂再清带领团队从零到一构建了天猫精灵的全栈算法研发与技术体系，涵盖语音语义一体化理解、海量知识图谱、多轮人机交互、个性化推荐以及智能家居IoT联动等关键技术，推动天猫精灵走进数千万中国家庭，成为全球销量前三的智能音箱产品。他还主导研发了对抗电话骚扰的AI智能助理“二哈”，引发业界广泛关注。2019年，聂再清带领的算法团队荣获吴文俊人工智能科技进步奖。

2020年，随着张亚勤院士回国创立清华大学智能产业研究院（AIR），聂再清应邀重返母校，全职加入清华大学智能产业研究院，担任首席研究员、国强教授（后任万国数据教授）。在AIR这一面向第四次工业革命的产学研创新高地上，聂再清敏锐捕捉到大模型与生成式AI对传统工业和前沿科学的颠覆性潜力，迅速开辟了“AI for Life Science（生命科学大模型与智能体）”与“车路协同自动驾驶（V2X）”两大前沿战略方向。他担任“十四五”国家重点研发计划BTIT融合项目新药研发大模型课题负责人，并于2023年6月联合发起孵化了清华系AI生物医药企业“水木分子”（PharMolix）并出任首席科学家，带领团队先后发布并开源了全球首个可商用百亿参数多模态生物医药大模型 BioMedGPT、对话式药物研发助手 ChatDD 系列、OpenBioMed 智能体平台以及全原子基座模型 PharMolix-FM，同时发布了全球首个真实场景车路协同数据集 DAIR-V2X，实现了横跨学术前沿与千亿级产业落地的高维贯通。

## 三、学生培养情况

在二十余年的学术与工业研究生涯中，聂再清始终坚持“做有用的科研、育复合型领军人才”的育人理念。在微软亚洲研究院期间，他长期指导清华、北大、中科院等名校联合培养博士生与实习生；在阿里巴巴期间亲自指导博士后；在清华大学智能产业研究院（AIR）建立团队后，更是深度打通学术研究与产业落地，培养了一批在多模态大模型、AI制药与车路协同领域的青年新锐。以下列举其代表性学生与科研弟子：

### 1. 俞海宝（清华大学智能产业研究院博士后/香港大学博士，博士弟子/合作指导）

俞海宝是聂再清在清华AIR车路协同自动驾驶方向的核心学术骨干与主要研究者之一，博士毕业于香港大学（由罗平教授与聂再清教授联合指导），随后在清华AIR从事博士后研究。俞海宝作为第一作者主导研发并发布了全球首个基于真实场景的大规模多模态车路协同数据集 DAIR-V2X（发表于 CVPR 2022，单篇引用已突破 530 次），该数据集被北京市高级别自动驾驶示范区与百度Apollo全面采用，成为全球车路协同感知领域的标准基准。此后，他进一步作为一作发表了连续时序车路协同数据集 V2X-Seq（引用 160 余次）以及端到端车路协同自动驾驶通用框架 UniV2X（AAAI 2025），构建了从数据集到协同感知、运动预测及端到端决策规划的完整学术体系。

### 2. 罗依珍（清华大学智能产业研究院博士生/水木分子核心算法研究员，博士弟子）

罗依珍是聂再清在清华AIR生物医药基础大模型方向的核心学术骨干与开门弟子之一，深度参与水木分子的底层算法架构设计。罗依珍在多模态生物医药表征学习领域做出了系统性贡献，作为第一作者主导研发了全球首个开源百亿参数多模态生物医药大模型 BioMedGPT-10B（发表于 IEEE JBHI 2024），首次将自然语言、化学小分子与蛋白质氨基酸序列映射到统一语义特征空间；作为一作发表了多模态分子基座模型 MolFM 以及蛋白质突变解释与工程化语言模型 MutaPLM（NeurIPS 2024）。同时，罗依珍也是车路协同开创性工作 DAIR-V2X 的共同第一作者，展现了跨领域复合科研能力。

### 3. 朱军（清华大学计算机系博世人工智能冠名教授、TSAIL课题组共同主任，MSRA实习生/学术指导弟子）

朱军教授（IEEE/AAAI/ACM Fellow，陈嘉庚青年科学奖、科学探索奖得主）在清华大学计算机系攻读硕博学位期间（2004–2007年），曾在微软亚洲研究院全职实习研究，聂再清博士是其核心指导导师之一。在聂再清与文继荣、马维英、张钹院士的共同指导下，朱军早期深耕互联网结构化数据挖掘、二维条件随机场（2D CRF）与统计学习模型，两人联合发表了《Object-level ranking》（2005）、《2D Conditional Random Fields for Web information extraction》（ICML 2005）、《Simultaneous record detection and attribute labeling in web data extraction》（KDD 2006）、《StatSnowball》（WWW 2009）等一系列奠基性高引论文，直接支撑了微软“人立方”与“微软学术搜索”的技术底层。这段工业界研究训练为朱军日后在概率图模型与贝叶斯机器学习领域的学术突破打下了重要基石。

### 4. 樊思齐（清华大学智能产业研究院博士生/水木分子算法研究员，博士弟子）

樊思齐是聂再清团队在多模态智能体与协同感知交叉方向的杰出博士生。在车路协同方向，樊思齐作为第一作者提出了面向实用化协同感知的查询流机制 QUEST，并参与了路侧协同感知数据集 RCooper 与端到端系统 UniV2X 的研发；在AI制药领域，他主导开发了面向化学分子图像与文献识别的光学化学结构理解大模型 OCSU（首作者），并参与了 BioMedGPT-Mol、Co-Generative 从头功能蛋白质设计等工作，其成果横跨计算机视觉、大模型推理与计算生物学。

### 5. 赵素媛（清华大学智能产业研究院博士生，博士弟子）

赵素媛在聂再清指导下专注于单细胞生物学与空间转录组基础大模型研究。她作为第一作者在顶级机器学习会议 ICML 2024 上发表了 LangCell（语言-细胞跨模态预训练模型），创新性地利用自然语言语义引导单细胞基因表达谱的身份表征理解；此外，她主导开发了多尺度空间转录组基座模型 SToFM，并在单细胞分治对比学习表征与蛋白质突变语言模型 MutaPLM（NeurIPS 2024）中做出关键贡献，是团队在微观生命科学多组学建模领域的中坚力量。

### 6. 张家欢（清华大学智能产业研究院研究员/水木分子算法负责人，团队核心骨干/指导研究员）

张家欢在清华AIR团队中担任资深算法研究员，并出任水木分子算法研发负责人。他在大模型高效微调、提示学习（Hard Sample Aware Prompt-Tuning）与多模态生物医学大语言模型架构研发中发挥了核心技术领导作用。张家欢作为核心作者参与了 BioMedGPT-10B、BioMedGPT-LM、LangCell 以及心电图大模型 ECG-LM 的研发，并主导了水木分子商业化对话式药物研发助手 ChatDD 系列（ChatDD-Insight、Discovery、Trial）的工程化落地与技能封装（OpenBioMed Skills）。

钟泽轩本科就读于北京大学信息科学技术学院，在本科期间进入微软亚洲研究院由聂再清博士与曹涌博士指导实习。期间，钟泽轩作为第一作者在人工智能顶级会议 AAAI 2018 上发表了《CoLink: An Unsupervised Framework for User Identity Linkage across Multiple Social Networks》，提出跨社交网络用户身份无监督关联框架。本科毕业后，钟泽轩赴普林斯顿大学计算机系攻读博士学位（师从陈丹琦教授），成长为国际自然语言处理与大语言模型检索增强（RAG/Dense Retrieval）领域的知名青年学者。

### 4.1 课题组与院内合作网络

清华大学智能产业研究院（AIR）汇聚了由张亚勤院士领衔的国际顶尖产学研师资阵营，聂再清在此构建了紧密协同、多学科交叉的内部合作网络：

- **张亚勤院士（AIR创始院长、讲席教授）**：张亚勤院士作为全球智能计算与通信领域的权威学者，倡导“以企业真实痛点定义前沿科研”的AIR模式。张亚勤与聂再清共同作为水木分子的联合发起人，在宏观战略上推动生命科学与自动驾驶基础模型的研发，并在“AI+生命健康”峰会及国家级重大项目论证中深度协同。
- **马维英教授（AIR首席科学家、惠妍讲席教授）**：马维英与聂再清早在微软亚洲研究院（MSRA）时期便有十余年深度合作（合著论文18篇，包括对象级别搜索与Web信息抽取），两人在清华AIR再度汇合，作为水木分子联合发起人，共同探索“AI for Science”在新材料、蛋白质设计与小分子生成中的前沿范式（如 Mol-AE、ESM All-Atom 等工作）。
- **周浩副教授（清华AIR副研究员、前字节跳动AI Lab总监）**：周浩在生成式AI与分子表征学习领域造诣深厚，与聂再清团队在蛋白质语言模型（MutaPLM）、分子3D完形填空自编码器（Mol-AE）、空间转录组大模型（SToFM）等工作上展开了紧密合作，形成了互补的研究合力。
- **兰艳艳教授、刘洋教授等AIR核心学者**：在信息检索、大模型评估与自然语言生成方面保持定期的学术工作坊交流与联合研讨，共同推动清华AIR在生成式AI底座技术上的协同创新。

- **香港大学与香港中文大学**：在自动驾驶领域，聂再清与香港大学罗平教授（Ping Luo）团队长期联合培养博士生并攻关车路协同端到端大模型（DAIR-V2X、V2X-Seq、UniV2X）。

## 五、业界合作关系深度分析

### 5.1 微软亚洲研究院与阿里巴巴技术攻坚

聂再清拥有长达16年的世界级工业研究院与互联网巨头核心技术研发经历，是国内工业界与学术界深度融合的典范学者。

**（一）微软亚洲研究院（MSRA, 2004–2017）：知识图谱与实体搜索的工业先驱**

在MSRA的13年间，聂再清作为首席研究员，主要负责自然语言理解与实体搜索挖掘的前沿研发，是“Deployment-Driven Research”（部署驱动型科研）的核心代表：
1. **“人立方”（Renlifang）与大数据实体关系搜索引擎**：2008年前后，聂再清团队率先研发并发布了全球首个中文人际关系搜索引擎“人立方”，通过对数以亿计的中文网页进行实体抽取、关系挖掘与多源信息消歧，将扁平的网页文本转化为立体的“人-关系-事件”网络图谱。这一工作比Google在2012年正式提出“Knowledge Graph（知识图谱）”概念早了近四年，成为现代知识图谱工业应用的全球先驱之一。
2. **微软学术搜索（Microsoft Academic Search）**：聂再清发起并主持了微软学术搜索的底层技术架构研发，构建了覆盖全球数千万学者、学术机构与论文引用的学术知识图谱，提出了著名的“Object-level Ranking”对象级别排序算法，该系统不仅直接服务于全球科研人员，更为后来的 Bing 学术、Semantic Scholar 等学术引擎奠定了算法基础。
3. **微软 LUIS 自然语言理解平台**：聂再清作为技术负责人主导了微软云端对话式AI开发者平台 LUIS（Language Understanding Intelligent Service）的早期架构开发，将意图识别、槽位填充与实体抽取封装为可按需微调的通用云端API，成为微软 Cognitive Services 与 Azure 智能云的基石组件之一。

因上述开创性技术对微软产品与全球工业界的重大贡献，聂再清荣获微软公司最高员工荣誉——Microsoft Golden Star奖。

**（二）阿里巴巴集团与天猫精灵（2017–2020）：千万级智能终端交互体系奠基**

2017年10月，聂再清加入阿里巴巴人工智能实验室（AI Labs），担任北京研发中心负责人兼天猫精灵首席科学家：
1. **天猫精灵全栈对话与算法基石**：聂再清带领算法团队从零到一构建了天猫精灵的智能认知中枢，攻克了远场语音识别后的语音语义一体化理解、海量意图分发、多轮槽位继承与家庭复杂场景下的个性化内容推荐。天猫精灵在短短三年内出货量突破数千万台，跃居中国第一、全球第三的智能硬件生态。
2. **反电信骚扰AI“二哈”**：聂再清主导研发了首个能够主动接听并智斗骚扰电话的交互智能体“二哈”（AI Copycat），通过自然流畅的多轮反问、逻辑陷阱和语音合成，成功将来电骚扰电话的平均通话时长拖延至数分钟，引发全网热议并树立了人机对抗对话的工业标杆。
3. **产学研深度协同**：在阿里期间，聂再清发起并主持了与中科院自动化所、清华大学、南洋理工大学的多项产学研合作项目，带领团队于2019年斩获吴文俊人工智能科技进步奖。

**（一）水木分子（PharMolix）：生命科学基础大模型与智能体闭环**

水木分子成立于2023年6月，由清华大学智能产业研究院（AIR）孵化，张亚勤院士与马维英教授共同发起，聂再清教授出任发起人兼首席科学家。公司构建了全球领先的“自研管线+工具赋能”双轮驱动模式：
1. **全栈大模型与智能体矩阵**：
   - **BioMedGPT系列**：相继开源 BioMedGPT-1.6B、BioMedGPT-10B（全球首个可商用百亿参数多模态生物医药大模型）以及 BioMedGPT-R1 推理大模型，实现自然语言、小分子SMILES和蛋白质氨基酸序列的统一语义空间对齐；
   - **ChatDD 药物研发智能体**：推出 ChatDD-Insight（情报洞察与水木知了APP）、ChatDD-Discovery（计算设计平台）与 ChatDD-Trial（临床试验设计），将药物早研、靶点筛选、分子优化等流程封装为数十项自主调用的专业技能（OpenBioMed Skills）；
   - **PharMolix-FM**：推出全原子生物分子基础模型，实现从原子级别对大分子、小分子相互作用的高精度物理建模。
2. **自研管线落地验证**：2025年，水木分子首条自研自身免疫疾病双特异性抗体管线启动，依托 ChatDD-Discovery 完成分子计算设计并进入湿实验验证，实现了从纯软件算法向真实创新药管线的跨越。
3. **顶尖产业与资本阵容**：团队汇聚了前药明康德副总裁邢杰（COO）、前Pathos高级副总裁潘琦博士（生物医药首席科学家），并与博奥晶方等达成战略合作，展现了极强的商业转化与资本号召力。

**（二）DAIR-V2X 与北京市高级别自动驾驶示范区生态**

在车路协同自动驾驶领域，聂再清团队依托北京市高级别自动驾驶示范区与北京车网科技，联合百度Apollo共同打造了数据驱动的车路协同研发生态：
- **全球首个真实场景车路协同数据集 DAIR-V2X**：涵盖超7.2万帧图像与点云数据，实现车端与路端相同时空下的联合高精度3D标注，彻底终结了车路协同领域长期依赖仿真数据的历史；
- **产业挑战赛与技术标准**：连续发起主办“清华AIR-百度Apollo车路协同自动驾驶算法挑战赛”，吸引全球数百支顶尖车企与算法团队参与，推动了 UniV2X、QUEST 等端到端算法向车路协同示范区物理基础设施的部署落地。

### 第一圈层：核心学术传承与奠基团队

最内核为博士导师 Subbarao Kambhampati 教授（前AAAI主席）以及MSRA早期的知识挖掘奠基团队。Kambhampati 教授授予其严谨的学术方法论与国际化视野；在MSRA建立初期，聂再清与文继荣、马维英、张钹院士等前辈学者密切协作，共同奠定了中国乃至全球互联网实体搜索与知识图谱的底层方法论。这一圈层构成了聂再清学术信誉与工业创新直觉的源头。

### 第二圈层：培养的弟子与科研骨干

聂再清指导的学生与科研骨干构成了其关系网络中最具活力与创新爆发力的圈层：
1. **学术大家接力**：早期在MSRA指导的朱军已成长为清华大学计算机系博世人工智能冠名教授、三大国际学会（ACM/IEEE/AAAI）会士；在MSRA指导的钟泽轩赴普林斯顿大学攻读博士并成为NLP新星；
2. **AIR两大赛道中坚力量**：在车路协同赛道，俞海宝主导了 DAIR-V2X 与 UniV2X；在AI制药赛道，罗依珍、樊思齐、赵素媛、张家欢等博士生与研究员主导了 BioMedGPT、MolFM、LangCell、MutaPLM、OCSU 等一系列重磅工作，并成为水木分子的算法骨干。

### 第三圈层：清华大学与AIR核心共同体

依托清华大学智能产业研究院（AIR），聂再清与院长张亚勤院士、首席科学家马维英教授形成了深度信任的战略铁三角，同时与周浩副教授、兰艳艳教授等中青年学者形成多学科交叉合力。张亚勤院士的产业战略格局、马维英教授的AI for Science视野与聂再清的实体大模型落地能力高度互补，构成了AIR在AI+生命健康与AI+智能交通两大战略方向的顶层支柱。

### 第四圈层：跨机构与国际学术圈

横向连接国内顶尖高校与科研院所：中国人民大学高瓴人工智能学院（文继荣团队，知识图谱与信息检索）、中国科学院自动化研究所（赵军、刘康团队，知识图谱与智能问答）、新加坡南洋理工大学（缪春燕团队，联邦学习与情感计算）、香港大学（罗平团队，视觉与协同感知）。这一网络保障了团队前沿算法理论的持续迭代与国际顶会论文的高产输出。

### 第五圈层：产业与资本闭环

最外层是聂再清通过深度创业孵化与工业战略合作构建的产业与资本网络。在生命科学领域，孵化企业“水木分子”贯通了从开源多模态基座（BioMedGPT）、对话式智能体助手（ChatDD）到自研创新药管线的商业飞轮，聚合了药明康德、Pathos 等行业顶尖医药专家与产业资本；在智能网联汽车领域，DAIR-V2X 与北京市高级别自动驾驶示范区、百度Apollo深度绑定，将学术成果直接转化为支撑国家级智能网联道路建设的技术标准与基础设施。

综上所述，聂再清教授的关系网络展现了从理论奠基（知识图谱/对象搜索）、工业实战（MSRA/天猫精灵）、前沿学术（清华AIR）到产业重塑（水木分子/车路协同）的完整闭环，是中国人工智能领域少有的兼备深厚学术功底、战略级工业落地经验与顶尖产学研孵化能力的领军学者。
