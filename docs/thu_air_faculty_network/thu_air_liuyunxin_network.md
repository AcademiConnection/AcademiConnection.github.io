## 二、教育背景与职业履历

刘云新1975年出生，1993年进入中国科学技术大学，主修理论与应用力学和计算机软件，获双学士学位（1993—1998）。在中科大求学期间，他同时打下了力学与计算机两个学科的基础，这种跨学科的学术训练为他后来在系统层面思考计算问题提供了独特视角。1998年，刘云新考入清华大学计算机系，攻读计算机系统结构硕士学位（1998—2001），正式踏入计算机系统研究领域。在清华硕士期间，他接触到计算机体系结构和系统软件的核心知识，为后续在移动系统方向的深耕奠定了根基。

2001年，硕士毕业的刘云新加入微软亚洲研究院（MSRA），由此开启了在这家全球顶级工业研究机构近二十年的职业生涯。在MSRA期间，他历任助理研究员、副研究员、研究员、主管研究员、高级研究员及主任研究员，逐步成长为该院移动计算领域的领军人物。值得关注的是，在全职工作期间，他于2006年考入上海交通大学，攻读计算机应用技术博士学位（2006—2011），以在职方式完成了博士学位。在MSRA工作期间，刘云新先后在无线与网络组（Wireless and Networking, W&N）、移动与感知系统组（Mobile and Sensing System, MASS）和智能云与边缘组（Intelligent Cloud and Edge, ICE）从事研究，最终担任异构与极限计算组（Heterogeneous and Extreme Computing, HEX）的研究经理（Research Manager），负责移动计算、边缘计算和异构计算等方向的统筹规划与团队管理。

在MSRA的近二十年里，刘云新的研究成果产生了深远的学术与产业影响。他于2008年设计开发了学术界首个专门针对移动设备的虚拟机监控器原型系统，首次提出手机多模态概念及基于轻量级系统虚拟化的实现，开创了移动系统虚拟化研究方向。他领导孵化了微软内部用于网络测试的产品级工具——Network Emulator for Windows Toolkit（NEWT），该工具成为高精度模拟多样化网络环境的事实标准。他的研究成果成功应用于Visual Studio、XBOX XDK和Windows Phone等多项微软产品中，并被ABC News、The Register、NetworkWorld等国际媒体广泛报道。

2021年4月，刘云新离开工作二十年的微软亚洲研究院，加入清华大学智能产业研究院（AIR），出任首席研究员、清华大学国强教授（后转为万国数据教授），并担任AIR副院长。加入清华后，他迅速组建研究团队，聚焦端侧AI、边缘智能、AI智能体和具身智能等前沿方向，同时积极推动产学合作，担任清华大学-亚信科技联合研究中心主任。2023年，他作为负责人牵头国家重点研发计划"异构设备智能计算关键技术标准研究与应用"项目，这是AIR成立以来牵头的第一个国家重点研发项目。2024年12月，刘云新当选IEEE Fellow，这是对其在移动计算和边缘智能领域长期贡献的国际最高认可之一。

## 三、学生培养情况

刘云新在微软亚洲研究院工作近二十年期间，指导和培养了大批实习学生和青年研究员，其中许多人已成为学术界和产业界的中坚力量。加入清华AIR后，他作为博士生导师正式开展研究生培养工作，同时以AIR博士后合作导师的身份吸引优秀青年学者。他的学生和团队成员普遍具备系统研究与AI应用的复合能力，在MobiCom、MobiSys、SenSys等顶会持续产出高水平成果。以下列举若干代表性学生及团队成员。

### 1. 李元春（清华大学AIR助理研究员/助理教授，MSRA时期指导的青年研究者/AIR同事）

李元春是刘云新在清华AIR的核心团队成员之一。他2014年获北京大学信息科学技术学院学士学位，2019年获北京大学计算机科学与技术系博士学位（期间2016—2017年赴卡内基梅隆大学任访问博士生），2019年至2021年在微软亚洲研究院历任研究员及主管研究员。在MSRA期间，李元春与刘云新有密切的工作关系。2021年，李元春与刘云新同期加入清华AIR，任助理研究员/助理教授。李元春的研究方向聚焦边缘计算、人工智能与系统软件，在ICSE、ESEC/FSE、ISSTA等国际会议发表论文50余篇，获UbiComp 2016最佳论文提名奖、IS-EUD 2017最佳论文奖和GreenCom最佳论文奖。他与刘云新及微软亚洲研究院合作开发的AutoDroid系统发表于MobiCom 2024，实现大语言模型驱动的安卓应用任务自动化，是该方向具有里程碑意义的工作。李元春主持和参与国家自然科学基金、科技部重点研发等项目，是刘云新团队中连接系统软件研究与AI智能体应用的关键人物。

### 2. 文浩（清华大学AIR博士研究生，AutoDroid核心开发者）

文浩是刘云新在清华AIR指导的博士研究生，也是AutoDroid项目的核心第一作者。他以第一作者身份在MobiCom 2024发表论文"AutoDroid: LLM-powered Task Automation in Android"，该工作由刘云新和李元春共同指导，将大语言模型与安卓应用的动态分析相结合，实现了无需人工介入的任务自动化系统。文浩随后在MobiSys 2025以第一作者发表论文"AutoDroid-V2: Boosting SLM-based GUI Agents via Code Generation"，进一步将AutoDroid升级为基于代码生成的小模型智能体架构。此外，他还在MobiCom 2025发表论文"LLM-Explorer: Towards Efficient and Affordable LLM-based Exploration for Mobile Apps"。文浩的研究方向为LLM驱动的移动智能体，是刘云新团队在AI Agent方向的代表性博士生，其AutoDroid系列工作在学术界和开源社区产生了广泛影响。

### 3. 蒋世奇（微软亚洲研究院研究员，MSRA指导/长期合作者）

蒋世奇是刘云新在MSRA时期指导和合作的重要研究人员。他在刘云新指导下开展了端侧深度学习推理优化的系统性研究，以第一作者或核心作者身份在MobiCom 2021（Flexible High-resolution Object Detection on Edge Devices）、MobiCom 2022（MobiDepth: Real-Time Depth Estimation Using On-Device Dual Cameras）、MobiSys 2022（CoDL: Efficient CPU-GPU Co-execution for Deep Learning Inference on Mobile Devices）、MobiSys 2024（Empowering In-Browser Deep Learning Inference on Edge Through Just-In-Time Kernel Optimization）等顶会发表多篇论文。蒋世奇后加入微软亚洲研究院任研究员，在2025年NSDI论文"AVA: Towards Agentic Video Analytics with Vision Language Models"中与曹婷等人继续合作。他是刘云新-曹婷合作链条上的核心桥梁人物，在端侧AI推理优化方向形成了系统性的研究脉络。

### 4. 赵山辉（清华大学AIR博士研究生，LLM智能体方向）

赵山辉是刘云新指导的博士研究生，在LLM驱动的移动智能体方向开展了前沿研究。他以核心作者身份参与AutoDroid（MobiCom 2024）和AutoDroid-V2（MobiSys 2025）项目，并在MobiCom 2025以第一作者发表论文"LLM-Explorer: Towards Efficient and Affordable LLM-based Exploration for Mobile Apps"。赵山辉与文浩构成了刘云新团队中AI智能体方向的核心博士生组合，共同推动了AutoDroid系列从原型到实用系统的迭代演进。

### 5. 贾富成（清华大学AIR博士生/研究助理，端侧推理优化方向）

贾富成是刘云新团队中聚焦端侧深度学习推理优化的研究人员。他以第一作者身份在MobiSys 2022发表论文"CoDL: Efficient CPU-GPU Co-execution for Deep Learning Inference on Mobile Devices"（与蒋世奇、曹婷等合作），并在MobiSys 2024以第一作者发表论文"Empowering In-Browser Deep Learning Inference on Edge Through Just-In-Time Kernel Optimization"。贾富成的工作聚焦于在异构移动处理器上实现高效的深度学习推理，包括CPU-GPU协同执行和浏览器内JIT内核优化，是刘云新团队在异构计算方向的代表性成果产出者。

### 6. 韦建宇（中国科学技术大学/MSRA实习生，刘云新兼职博导学生）

韦建宇是刘云新以中国科学技术大学兼职博导身份指导的学生之一。他以第一作者身份在MobiSys 2023发表论文"NN-Stretch: Automatic Neural Network Branching for Parallel Inference on Heterogeneous Multi-Processors"，与曹婷、蒋世奇等人合作。韦建宇的研究聚焦于面向异构多处理器的神经网络自动分支并行推理，体现了刘云新在中科大兼职指导的研究布局。此外，他还参与了nn-Meter（MobiSys 2021）等代表性工作，该工作由微软亚洲研究院团队主导，刘云新作为核心合作者参与。

### 7. 邓永恒（清华大学AIR相关博士生，联邦学习方向）

邓永恒是刘云新团队中联邦学习方向的研究人员。他以第一作者身份在SenSys 2022发表论文"TailorFL: Dual-Personalized Federated Learning under System and Data Heterogeneity"，与任炬、刘云新等人合作。该工作针对系统和数据异构性下的联邦学习双重个性化问题提出了创新方案。邓永恒的研究体现了刘云新团队从移动计算向隐私计算和分布式智能方向的自然延伸，与亚信科技联合研究中心的联邦学习和隐私计算研究方向高度契合。

### 8. 王曼妮（微软亚洲研究院时期合作者，端侧AI推理方向）

王曼妮是刘云新在MSRA时期指导的合作者之一，聚焦移动设备深度学习推理优化。她以第一作者身份在MobiCom 2021发表论文"AsyMo: Scalable and Efficient Deep-Learning Inference on Asymmetric Mobile CPUs"（与曹婷、刘云新、徐丰远合作），该工作获得了MobiSys 2021最佳论文奖（作为nn-Meter团队成员）。王曼妮还在MobiCom 2022参与了Romou论文（Rapidly Generate High-Performance Tensor Kernels for Mobile GPUs）的工作。她的研究涵盖了非对称移动CPU推理优化和移动GPU内核生成，是刘云新-曹婷合作在端侧AI推理方向的早期核心产出者。

## 四、学术合作网络

### 4.1 核心研究合作网络

刘云新的学术合作网络以微软亚洲研究院近二十年的工作经历为基础，在加入清华AIR后进一步扩展至学术界和产业界。其核心合作网络呈现以下几条主线。

**刘云新-曹婷合作轴线（端侧AI推理）：** 曹婷是刘云新最为密切的学术合作者。曹婷博士毕业于澳大利亚国立大学（博士导师为Steve Blackburn和Kathryn McKinley，图灵奖得主David Patterson曾撰专文推荐其工作），2018年至2025年在微软亚洲研究院任首席研究员及研究主管，2025年7月加入清华AIR任研究员/教授。两人合作涵盖AsyMo（MobiCom 2021）、nn-Meter（MobiSys 2021，获最佳论文奖）、CoDL（MobiSys 2022）、MobiDepth（MobiCom 2022）、Romou（MobiCom 2022）、NN-Stretch（MobiSys 2023）、LUT-NN（MobiCom 2023）以及浏览器内推理优化（MobiSys 2024）等多项顶会论文。曹婷的研究成果集成到微软Office、Windows、Bing及华为鸿蒙等产品中，两人共同塑造了端侧AI推理优化这一研究方向。

**刘云新-李元春合作轴线（AI智能体与软件系统）：** 李元春自MSRA时期即与刘云新密切合作，加入AIR后两人共同指导AutoDroid系列项目。此外，两人在FedBalancer（MobiSys 2022）、ReMoS（ICSE 2022）、TaintStream（ESEC/FSE 2021）等论文中均有合作。这条合作轴线将移动计算与软件工程相融合，开辟了LLM驱动智能体研究的新方向。

**刘云新-任炬-张耀星合作轴线（边缘计算与物联网）：** 任炬（清华大学AIR研究员）和张耀星（清华大学教授、中国工程院院士）与刘云新在多个边缘计算和物联网方向开展合作，共同发表论文包括CoDL（MobiSys 2022）、MobiDepth（MobiCom 2022）、TailorFL（SenSys 2022）、Hyperion（SenSys 2022）等。张耀星院士团队与刘云新团队在端侧AI和边缘智能领域形成了紧密的协同关系。

**刘云新-徐丰远合作轴线（安全与隐私）：** 徐丰远现任南京大学计算机科学与技术系教授，此前曾在NEC Labs Princeton任研究员并在MSRA做访问研究者。他与刘云新合作了AsyMo（MobiCom 2021）、PECAM（MobiCom 2021）等论文，研究方向涉及移动系统安全与隐私保护。徐丰远还主持国家重点研发计划项目课题，与刘云新在边缘安全协同方向有学术共鸣。

**刘云新-Li Lyna Zhang合作轴线（AI推理延迟预测）：** Li Lyna Zhang是微软亚洲研究院的研究员，与刘云新合作了nn-Meter（MobiSys 2021，最佳论文奖）等代表性工作。nn-Meter是一个面向多样化边缘设备的深度学习模型推理延迟预测系统，在26,000个模型的数据集上显著超越了先前最优方法，是该领域的里程碑式工作。

**与上海交通大学的学术纽带：** 刘云新博士毕业于上海交通大学（2006—2011），虽然其博士是在职攻读，但这一经历使他与上交计算机学院建立了学术联系。上海交通大学计算机学院常务副院长吴帆教授（国家自然科学基金杰出青年科学基金获得者）与刘云新在CNCC等学术论坛中多次共同出席，共同探讨端边云智能计算和大小模型协同等议题。此外，陈奕超副教授（上海交通大学，移动计算与无线感知方向）亦在MSRA上海做访问学者（2023—2024），体现了上交与MSRA及刘云新团队的学术纽带。

**跨机构合作者网络：** 刘云新的论文合作者涵盖微软全球各研究院（雷德蒙德、剑桥等）、罗格斯大学（如Yanyong Zhang、Dipankar Raychaudhuri，MobiCom 2021 Elf论文）、圣母大学（Toby Jia-Jun Li，AutoDroid论文）、韩国KAIST（如Sung-Ju Lee，FedBalancer论文；Sung Ju Hwang，ICLR 2022论文）等机构的学者。他与麦吉尔大学、新加坡科技设计大学等也有学术交集。此外，清华大学计算机系黄罡教授、刘轩哲教授团队（Melon论文，MobiSys 2022）也是刘云新在清华校内的重要合作者。

**与南京大学的合作：** 南京大学计算机系的 Haipeng Dai（戴海鹏）教授与刘云新近期合作发表了TMC 2026论文"Efficient VLM Inference System with LoRA Adapters at the Edge"，同时曹婷、李元春等人亦参与该论文，展现了刘云新团队与南京大学在边缘大语言模型推理方向的最新合作。

## 五、业界合作关系深度分析

### 5.1 微软亚洲研究院近二十年深耕

刘云新在微软亚洲研究院工作了近二十年（2001—2021），这段经历是其学术身份和合作网络的核心基石。在MSRA期间，他先后辗转于四个研究组——无线与网络组（W&N）、移动与感知系统组（MASS）、智能云与边缘组（ICE）和异构与极限计算组（HEX），最终担任HEX组的研究经理和主任研究员。这种跨组经历使他的研究视野横跨网络、移动系统、边缘计算和异构计算四大领域，形成了极为罕见的系统性研究能力。

在MSRA期间，刘云新完成了多项具有深远影响的代表性工作。2008年，他设计了学术界首个移动设备虚拟机监控器原型系统，开创了移动系统虚拟化研究方向。他领导孵化的Network Emulator for Windows Toolkit（NEWT）成为微软内部网络测试的事实标准工具。他的研究成果被集成到Visual Studio 2010（为此获得2010年Tech Transfer Award）、XBOX XDK和Windows Phone等产品中。2008年，他获得MSRA"Tech Transfer of Year"奖和两项Ship-It Award（分别用于Games for Windows LIVE和XNA/DirectX SDK/Xbox XDK），2006年获得MSRA"Demo of Year"奖。

刘云新在MSRA期间指导和合作了大量实习生和青年研究员，其中许多人已成为学术界的活跃力量。这一时期形成的合作网络——特别是与曹婷、蒋世奇、Li Lyna Zhang等人的紧密协作关系——在他加入清华AIR后得以延续和深化。曹婷于2025年7月正式加入清华AIR，标志着这对研究搭档在清华的重新聚首。

### 5.2 亚信科技联合研究中心与产业合作

加入清华AIR后，刘云新最引人注目的产业合作是担任清华大学（智能产业研究院）-亚信科技（中国）有限公司联合研究中心主任。该联合研究中心最初名为"智能计算联合研究中心"，于2023年3月21日正式升级为"6G网络与智能计算联合研究中心"，在中国工程院院士、AIR时任院长张亚勤和亚信科技CEO高念书的见证下，由刘云新与亚信科技首席科学家叶晓舟博士代表双方签署合作协议。

联合研究中心的研究方向覆盖6G网络、自智网络、通信IT架构演进、通信人工智能、大数据、隐私计算、联邦学习和数智化应用等领域，并致力于打造通信行业TelcoGPT大模型应用。刘云新在揭牌仪式上回顾了此前两年双方的合作成果，重点介绍了智能边缘计算、基于强化学习的算网优化、联邦学习和隐私计算等方面的研究进展。双方已联合发布业内首部《AIGC(GPT-4)赋能通信行业应用白皮书》，并计划联合产业伙伴发布全球首部《6G OSS技术白皮书》和《6G BSS技术白皮书》。亚信科技方面的核心对接人包括首席技术官、高级副总裁、IEEE Fellow欧阳晔博士和首席科学家叶晓舟博士（联合研究中心副主任）。

除亚信科技外，刘云新还参与了AIR与长安科技的合作。2026年4月，长安科技与清华AIR共建"交通场景通用人工智能联合研究中心"，刘云新作为AIR副院长和联合研究中心管委会委员出席签约仪式，体现了他在AIR产业合作战略布局中的管理角色。这表明刘云新不仅在学术研究上保持高产，还作为AIR副院长参与统筹院内产业合作的整体推进。

### 5.3 国家重点研发计划与学术-产业协同

2023年，刘云新作为负责人牵头国家重点研发计划"异构设备智能计算关键技术标准研究与应用"项目，这是清华大学智能产业研究院成立以来牵头的第一个国家重点研发项目。该项目聚焦异构设备智能计算的关键技术标准研究与应用，与刘云新长期积累的异构计算、移动计算和边缘智能研究方向高度契合。项目的立项标志着AIR在国家级科技计划中获得了重要突破，也体现了刘云新在学术-产业协同创新中的领导力。

此外，刘云新团队的研究成果实际应用于微软产品（Visual Studio、XBOX XDK、Windows Phone）和华为鸿蒙系统（通过曹婷的合作），展现了从基础研究到产业落地的完整链路。在CNCC 2024等技术论坛中，刘云新作为Panel嘉宾与国防科技大学苏金树教授、香港中文大学邢国良教授、清华大学徐恪教授等共同探讨大模型时代下的边缘智能计算，展现了其在学术界战略对话中的活跃角色。

## 七、Connection圈层总结

刘云新的学术关系网络可从以下圈层加以概括。

**第一圈层：清华AIR核心团队。** 这是最紧密的圈层，以刘云新在AIR直接指导的博士研究生和团队成员为核心，包括文浩、赵山辉、贾富成、邓永恒等在读博士生，以及李元春（助理研究员/助理教授）等同组教师。该圈层以端侧AI推理优化、LLM驱动的移动智能体和联邦学习为主要研究方向，近年在MobiCom、MobiSys、SenSys等顶会持续产出论文。曹婷于2025年加入AIR后，这一圈层的端侧AI推理方向得到进一步强化。任炬研究员和张耀星院士作为同院合作者，构成了边缘计算和物联网方向的协同力量。

**第二圈层：微软亚洲研究院遗产网络。** 刘云新在MSRA工作近二十年建立的这一网络是其学术身份的重要根基。核心节点包括曹婷（MSRA首席研究员→清华AIR研究员）、蒋世奇（MSRA研究员）、Li Lyna Zhang（MSRA研究员）、Jianyu Wei（中科大/MSRA实习生）等。这一网络的大部分成员在刘云新加入清华后仍保持密切的论文合作关系，形成了MSRA-清华AIR的学术人才流动通道。刘云新在MSRA期间指导和合作的实习生群体已广泛分布于学术界和产业界，构成了一个隐形的学术共同体。

**第三圈层：清华AIR院内合作与管理圈层。** 作为AIR副院长，刘云新与AIR院长张亚勤院士（已转任创始院长）、院长刘洋教授、首席研究员聂再清、首席研究员刘菁菁等构成了AIR的领导核心。在产业合作方面，他以联合研究中心管委会委员身份参与AIR与长安科技等企业的合作推进，展现了在院内产业合作战略中的管理角色。

**第四圈层：亚信科技及产业合作网络。** 刘云新作为清华-亚信科技联合研究中心主任，与亚信科技首席技术官欧阳晔（IEEE Fellow）、首席科学家叶晓舟建立了深度的产学合作关系。联合研究中心聚焦6G网络、联邦学习、隐私计算和TelcoGPT等方向，是刘云新将学术研究向通信产业落地的主要通道。此外，他在MSRA期间的研究成果应用于微软和华为等产品，形成了跨越多家科技巨头的产业影响力。

**第五圈层：国内学术社区与国际会议网络。** 刘云新凭借MobiSys 2023 TPC共同主席、MobiHoc 2021大会共同主席、IEEE TMC副主编等角色，在移动计算国际学术社区中拥有显著的议程设置影响力。国内层面，他与上海交通大学（母校纽带，吴帆教授等）、中国科学技术大学（兼职博导）、南京大学（戴海鹏教授等新近合作）等高校保持学术联系，并在CNCC、CCF Computility等论坛中与国内移动计算和边缘计算领域的学者进行战略对话。其博士毕业于上海交通大学的经历，使他在上交-清华的校际学术交流中扮演着天然的桥梁角色。

整体而言，刘云新的学术关系网络以"MSRA二十年积累+清华AIR学术创业"为双轮驱动，以端侧AI和边缘智能为核心研究方向，形成了从基础研究到产业落地的完整闭环。其网络的核心特征是：研究合作高度集中于移动计算和AI系统领域，合作者关系持久且深度（如与曹婷跨越五年的十余篇顶会合作论文），产业合作以亚信科技联合研究中心和国家重点研发计划为两大支柱，学生培养以系统研究能力与AI应用视野的复合化为核心导向。
