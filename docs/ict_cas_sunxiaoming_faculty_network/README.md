## 二、教师的角色定位

**团队负责人与学术谱系枢纽：** 孙晓明研究员是团队的创始人和学术核心。他1982年出生于山东青岛，高中时期获国际数学奥林匹克(IMO)金牌后保送清华大学计算机系。在清华期间，他的学术道路上得到了四位老师的接力引导：大四时马少平教授推荐他进入应明生教授团队（首次接触量子计算），研一时应明生推荐他赴香港城市大学交流（遇到邓小铁和姚期智），最终姚期智成为其博士论文导师。2005年博士毕业后在清华高等研究院工作六年，2011年加入中科院计算所。他的研究方向横跨量子计算和经典计算复杂性，在STOC/SODA/FOCS等顶会发表论文，代表性工作包括Quantum Lovász Local Lemma等。他是CCF会士（2024年当选）、CCF量子计算专委主任、曾任CCF理论计算机科学专委主任（2024年由肖鸣宇接任）。2026年3月，他发起成立了"中科量枢"量子计算公司并任首席科学家，完成了从纯理论研究向产业转化的关键一步。此外他还是计算所学位委员会委员，参与了2026年度研究生毕业典礼等重大活动。

**同门师妹与核心搭档：** 张家琳研究员与孙晓明同为姚期智在清华培养的博士生（孙2005年毕业，张2010年毕业），构成了一种独特的"同门+同事+合作者"搭档关系。她在清华基础科学班获学士学位后，在清华高等研究院获应用数学博士学位，随后赴美国南加州大学(USC)做博士后（2010-2012），2012年9月加入中科院计算所。她的研究方向涵盖量子计算、在线算法、近似算法和计算博弈论，DBLP收录论文105篇，合著者约80人。她与孙晓明的合著论文达78篇，是孙晓明网络中合作最密集的学者。作为CCF理论计算机科学专委秘书长（2024-2027任期），她在学术组织工作中也扮演着重要角色。她指导的学生张智杰（2022年博士毕业，与孙晓明联合指导）现任福州大学副教授，获COCOON 2022最佳论文奖，是团队培养的下一代学者的代表。

**量子物理与量子信息的桥梁：** 田国敬副研究员是团队中唯一具有量子信息物理 backgrounds 的成员。她2017年在北京邮电大学获博士学位（导师高飞教授和温巧燕教授），博士论文获中国通信学会全国优秀博士学位论文，2014-2015年在新加坡国立大学Center for Quantum Technologies联合培养。2017年加入计算所后，她为团队补充了量子非局域性、量子模拟等偏物理方向的研究能力，与孙晓明的量子算法和张家琳的量子线路优化形成了互补。她是CCF量子计算专业组执行委员和CCF理论计算机专委执行委员，2019年入选博士后创新人才支持计划（全国计算机专业仅16人）。她参与了2019年孙晓明组织的《量子计算与量子信息》10周年版翻译工作，是该翻译团队中最年轻的成员。

## 三、团队关系网络的整体观察

**1. "姚期智→孙晓明/张家琳"同门师姐弟关系是团队最核心的学术身份标识。** 孙晓明和张家琳都是图灵奖得主姚期智在清华大学培养的博士生，二者毕业相差五年（2005 vs 2010），但都在姚期智的量子计算和理论计算机科学方向接受训练。2012年张家琳加入计算所后，与孙晓明形成了覆盖量子算法、量子线路优化、在线算法等多个方向的联合研究模式，二人合著论文78篇，在SODA、ICML等顶会共同发表多项成果。这种"同门搭档"模式与山东大学IRC的"屠长河—辛士庆"双导师模式有相似之处，但孙—张关系的独特性在于二人是真正的同门师姐弟（同一导师），而非从外部引进的互补型搭档。

**2. 团队规模精干（3人核心教师），但学术谱系清晰、方向互补性强。** 孙晓明负责量子算法与计算复杂性的理论框架，张家琳覆盖量子线路优化和在线算法/计算博弈论，田国敬补充量子非局域性和量子模拟的物理视角。三人分工明确、互补性强，在 quantum circuit optimization、quantum nonlocality、quantum algorithm design 等方向形成了完整的研究链条。团队虽小，但在孙晓明的领导下在STOC/SODA/FOCS/ICALP等理论计算机顶会以及Physical Review A/Quantum Science and Technology等物理期刊上均有发表，兼具理论与实验的双重影响力。

**3. "马少平→应明生→邓小铁→姚期智"四位老师接力引导的学术引路人谱系是孙晓明个人学术道路的独特特征。** 这一谱系在2021年王选杰出青年学者奖的采访中被孙晓明本人详细讲述：马少平在大四时推荐他进入应明生团队接触量子计算，应明生在研一时推荐他赴香港城市大学深造（在那里遇到邓小铁和姚期智），姚期智最终成为其博士论文导师。这一四步接力引导的过程体现了清华计算机系在人才培养上的精细化和个性化，也解释了孙晓明为何能在量子计算这个高度交叉的领域深耕二十余年。

**4. 2026年"中科量枢"公司的成立标志着团队从纯理论研究向产业转化的关键一步。** 孙晓明于2026年3月发起成立了"中科量枢"量子计算公司并任首席科学家，完成了两轮天使融资（各数千万元），已申请近20项专利。这是继上财ITCS的华为TCS Lab模式之后，理论计算机科学领域又一个产业转化的典型案例，但路径不同——中科量枢是孙晓明亲自发起的创业公司，而非企业资助的联合实验室。此外，团队还通过CCF-华为胡杨林基金（张家琳负责2024年度评审记录整理）建立了与华为的产学研合作通道，并与玻色量子合作设立基金，与腾讯在量子算法方向有合作。

**5. 《量子计算与量子信息》10周年版翻译项目是团队学术影响力的一个独特侧面。** 2019年孙晓明组织翻译了Nielsen & Chuang的经典教材《量子计算与量子信息》10周年版，翻译团队包括尚云（中科院数学院）、李绿周（中山大学）、魏朝晖（清华大学）、田国敬（计算所）等。这一项目历时三年完成，不仅体现了孙晓明在量子计算学术共同体中的组织号召力，也使田国敬作为最年轻的翻译团队成员获得了学术能见度。该教材已成为国内量子计算领域最重要的中文参考书之一。
