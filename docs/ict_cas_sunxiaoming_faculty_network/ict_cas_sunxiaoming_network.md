### 2.2 学术引路人谱系

孙晓明的学术成长路径体现了多位重要导师的接力引导，这一谱系在中国理论计算机科学界具有标志性意义：

2. **应明生教授**（清华大学）：引领孙晓明进入量子计算领域。在应明生团队期间，孙晓明完成了第一篇关于量子信息中态分辨的论文。研一时期，应明生又将孙晓明推荐至香港城市大学继续深造。应明生是清华大学高等研究院教授，主要从事量子信息与量子计算的理论研究。

3. **邓小铁教授**（当时香港城市大学，现北京大学前沿计算研究中心讲席教授）：孙晓明在香港城市大学交流期间的重要导师。邓小铁在算法博弈论领域做出重要贡献，是国际知名理论计算机科学家。

4. **姚期智教授**（Andrew Yao，图灵奖得主）：孙晓明的博士论文导师。姚期智的研究领域极为广泛，涵盖量子计算、计算复杂性、密码学、通信复杂性及计算几何等，在每个领域均做出了突破性成果。2004年姚期智回国创办清华大学高等研究院，孙晓明是其早期博士生之一。

## 五、业界合作关系深度分析

### 5.1 创立中科量枢——量子计算产业化旗舰

2026年3月，孙晓明作为发起人及首席科学家，在北京海淀区正式成立了北京中科量枢科技有限公司（简称"中科量枢"）。这是孙晓明从纯学术研究向产业转化迈出的最重要一步，也是其学术成果商业化的核心载体。

**公司概况**：
- 成立时间：2026年3月
- 发起人及首席科学家：孙晓明
- 联合创始人兼CEO：李宗威
- 公司定位：量子计算操作系统及算法平台公司，脱胎于中科院计算所量子计算实验室
- 核心方向：量子计算与AI深度融合，构建链接底层硬件与上层应用的量子核心基础设施
- 产品矩阵：量子计算操作系统、编译平台、量子算法及行业应用的全栈式软件产品

**融资情况**（成立4个月完成两轮融资）：
- 天使轮：普华资本、知壹投资联合领投，九坤创投跟投，金额数千万元人民币
- 天使+轮：北工量子基金独家投资，金额数千万元人民币

**技术积累与知识产权**：
- 团队牵头承担国家量子科技重大专项、自然科学基金杰青和重点项目、中科院先导专项等30余项高水平科研任务
- 累计产出Nature Physics（封面文章）、NC、PRL等国际顶刊顶会论文百余篇
- 荣获IEEE TPDS最佳论文奖
- 拥有近20项量子计算领域已授权发明专利
- 牵头出版两部国内高校广泛采用的量子计算核心教材

**团队背景**：核心团队成员来自清华、北大、中科院、剑桥、南加州大学等国内外顶尖院校，拥有超过二十年的量子计算理论与算法研究积累。

中科量枢的成立标志着孙晓明完成了从"学术研究者"到"学术+产业双轨领导者"的转型。公司瞄准2025–2035年量子计算产业加速爆发的窗口期，着力破解量子计算从实验室技术走向规模化应用所面临的"实用化、工程化、商业化"难题。业界将中科量枢称为量子计算领域的"国家队"入场。

### 5.2 量子计算产业生态合作

#### 5.2.1 与玻色量子的合作

2025年2月，孙晓明主持了CCF-玻色量子计算应用创新基金的评审会。该基金由CCF与北京玻色量子科技有限公司共同发起，旨在通过"真实应用场景+真实业务数据+量子真机验证"三合一战略，联合各大高校和企业实现AI、金融、生物制药、通信、交通物流等行业的量子计算应用探索。孙晓明作为CCF量子计算专委主任主持评审，明确表示将"重点支持量子算法开发、行业场景验证，加速拓展量子计算生态，推动'量子计算+'在人工智能、金融、生物医药等领域的实用化突破"。

首期评审共资助7个项目，涵盖广州医科大学附属妇女儿童医疗中心、中山大学、浙江大学、中南大学、香港科技大学（广州）、上海交通大学、中国科学院大学等机构。

#### 5.2.2 与腾讯的量子计算合作

孙晓明与腾讯杰出科学家张胜誉建立了稳定的学术-产业合作关系：
- 2024年6月共同担任CCF ADL148《量子计算》讲习班学术主任
- 在多个学术会议中共同推动量子计算学术交流
- 张胜誉在量子态制备、量子酉算符综合等方面有重要理论贡献，与孙晓明团队在量子线路优化领域有互补性

#### 5.2.3 与华翊量子的对话

在CCF主办的量子计算对话活动中，孙晓明与华翊量子CEO姚麟、清华大学教授刘雷波就"从'山雨欲来'到'插电即用'"主题展开讨论，涉及量子计算对现有网络安全体系的影响及从业者布局建议。这一对话体现了孙晓明在量子计算产学研对话中的桥梁角色。

#### 5.2.4 与超导量子硬件方的合作

通过Nature Physics论文的合作，孙晓明团队与南科大俞大鹏院士团队建立了量子算法软件与超导量子硬件的深度合作通道：
- 共同开发了基于超导量子比特的8比特量子处理器
- 实现了高保真度的QuAND门操作
- 成功构造了最多8比特的Toffoli门
- 传统编译方法需要与比特数成平方或三次方数量的两比特门，基于QuAND门的编译方法只需线性数量甚至更低

### 5.3 与密码学相关领域的合作

孙晓明的研究横跨量子计算与计算复杂性理论，其工作与密码安全领域有天然关联：

1. **密码学理论基础**：孙晓明在采访中多次强调计算复杂性是现代密码学的安全基石。RSA公钥密码体系的安全性依赖于大数质因数分解的计算困难性，而量子计算中的Shor算法可在原理上破解RSA。孙晓明的研究涉及密码协议复杂性中的理论难题，这也是其获得王选杰出青年学者奖和2013年中国密码学会优秀青年奖的核心原因。

2. **量子搜索与密码分析**：在机器之心的报告中，孙晓明详细阐述了Grover搜索算法在密码分析中的应用——可将暴力枚举从2^90降到2^45量级。这直接关系到对称密码体系的安全性评估。

3. **量子线路优化与SAT问题**：团队发表的"Quantum logic synthesis for Satisfiability Problems"（arXiv 2021）涉及将SAT问题的量子求解通过优化量子线路实现，这对后量子密码学分析具有直接意义。

4. **国家密码安全背景**：量子计算对经典密码体系的潜在威胁是国家量子科技战略的核心驱动力之一。孙晓明团队承担的国家量子科技重大专项等项目中，密码分析是不可回避的应用方向。

### 5.4 与国家科技战略的深度对接

孙晓明的学术研究与国家量子科技战略形成了高度契合的对接关系：

1. **国家级科研项目**：牵头承担国家量子科技重大专项、自然科学基金杰青和重点项目、中科院先导专项等30余项高水平科研任务。

2. **政策咨询角色**：
   - 工业和信息化部信息通信科学技术委员会委员——直接参与工信部在量子信息领域的科技决策咨询
   - 全国量子计算与测量标准化技术委员会委员——参与国家量子计算标准的制定
   - 2025年7月与张海懿（中国信息通信研究院技术与标准研究所所长）共同发表量子信息技术发展与应用专题文章

3. **"十五五"规划对接**：2026年8月，孙晓明在大湾区量子科学论坛开幕式上明确表示，"十五五"规划纲要将量子科技列为未来产业布局首位，他作为CCF量子计算专委主任正积极推动从科研为主向产业发展的战略转型。

4. **量子计算人才培养**：组织翻译Nielsen & Chuang经典教材、出版两部量子计算核心教材、承办CCF量子计算博士生论坛、组织CCF ADL讲习班——这些工作直接服务于国家量子计算人才培养战略。

### 5.5 专利与知识产权布局

孙晓明团队拥有近20项量子计算领域已授权发明专利，涵盖量子算法设计、量子线路优化、量子编译、量子操作系统等核心技术方向。这些专利构成了中科量枢公司的核心知识产权基础，也是其获得多轮风险投资的底气所在。

## 七、Connection圈层总结

孙晓明研究员的学术关系网络可从以下圈层进行总结：

### 第一圈层：学术谱系核心

孙晓明处于以**姚期智**为核心的学术谱系的关键节点。他从马少平到应明生，再到邓小铁和姚期智，经历了一条典型的"清华-港城大-清华"培养路径。这一谱系使其天然处于中国理论计算机科学的顶层网络中。姚期智作为图灵奖唯一华人得主，其学术后裔遍布国内顶尖高校和研究院所，孙晓明是其中在量子计算方向最重要的传承者之一。

### 第二圈层：实验室团队

孙晓明在中科院计算所建立的量子计算与算法理论实验室，汇聚了**张家琳**（姚期智博士、南加大博士后、研究员）、**田国敬**（副研究员）等核心成员，以及一批年轻学生和研究人员。实验室在量子算法设计、量子线路优化、量子编译、量子模拟、量子机器学习、量子纠错等方向形成了体系化的研究能力。团队成员来自清华、北大、中科院、剑桥、南加州大学等顶尖院校。

### 第三圈层：国内学术合作网络

- **CCF量子计算专委网络**：作为主任，统筹李绿周（副主任，中山大学）、吴俊杰（常务委员）等核心成员，以及朱晓波、孙麓岩、尚云、姚鹏晖、翁文康、高飞、郭国平、曾贵华等学术委员，形成国内量子计算学术组织的核心网络。
- **跨机构合作网络**：与清华大学（姚期智、冯元、姚鹏晖）、南科大（俞大鹏、燕飞）、中山大学（李绿周）、中科大（朱晓波、李震宇）、北京大学（邓小铁）、中科院系统（尚云、骆顺龙）等建立了稳定合作关系。

### 第四圈层：产业转化网络

- **中科量枢**：作为发起人和首席科学家，带领团队从纯学术研究迈向产业化。CEO李宗威负责商业运营。
- **投资方网络**：普华资本、知壹投资、九坤创投、北工量子基金等投资方。
- **产业合作伙伴**：玻色量子（联合基金）、腾讯（张胜誉）、华翊量子（姚麟）。
- **国家战略对接**：工信部信息通信科技委员会、全国量子计算与测量标准化委员会、国家量子科技重大专项等。

### 第五圈层：国际学术网络

- **合作者**：Shang-Hua Teng（哥德尔奖得主）、Man-Hong Yung、Shachar Lovett等国际学者。
- **学术服务**：COCOON会议steering committee主席，Information and Computation等期刊编委。

### 整体特征

孙晓明的关系网络具有以下显著特征：

1. **谱系纯正，传承清晰**：从IMO金牌到清华姚班，从姚期智学术谱系到中科院计算所实验室主任，学术传承脉络清晰，且每一步都有重量级导师引领。

2. **产学研深度融合**：从纯理论研究者到创立中科量枢、担任首席科学家，完成了从学术到产业的闭环。其近20项专利、两部教材、百余篇顶刊顶会论文构成了深厚的知识资产。

3. **政策影响力突出**：同时担任CCF量子计算专委主任、工信部信息通信科技委员会委员、全国量子计算与测量标准化委员会委员，在学术组织、政策咨询、标准制定三个维度均具有话语权。

4. **密码-量子双重身份**：既有量子计算的理论深度，又有密码学的应用关联（中国密码学会优秀青年奖），在量子计算对密码安全影响的国际前沿议题上具有独特定位。

5. **桥梁角色显著**：在学术界与产业界之间（中科量枢）、在理论CS与量子物理之间（南科大Nature Physics合作）、在国家战略与基层人才培养之间（教材翻译、博士生论坛、ADL讲习班），孙晓明均扮演着关键的桥梁与连接者角色。
