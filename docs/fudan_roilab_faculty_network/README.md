# 复旦大学智能机器人研究院 ROILab 教师网络报告索引

## 团队简介

复旦大学机器人智能实验室（ROILab）依托复旦大学智能机器人研究院和计算机科学技术学院，以机器人智能为主轴，围绕人工智能、机器人、计算机视觉和知识图谱开展研究。实验室负责人张文强研究员同时担任智能机器人研究院副院长、上海市智能信息处理重点实验室副主任和上海智能机器人工程技术研究中心副主任，在复旦的计算机学科平台与智能机器人研究院之间承担学科连接角色。ROILab的研究覆盖视频理解、视觉鲁棒性、工业异常检测、情感计算、少样本学习、知识图谱抽取等方向，形成从基础算法、数据集到应用系统的研究链条。

团队依托国家自然科学基金、科技创新2030"新一代人工智能"重大项目、上海市科委重大攻关项目及30余项校企合作项目，将学术研究与医疗机器人、智能制造、装备运维等产业场景深度耦合。在国际学术传播方面，团队论文发表于CVPR、ECCV、ICCV、NeurIPS、AAAI、IJCAI、ACM Multimedia、ICRA及IEEE Transactions等会议和期刊，并公开维护FERV39k细粒度表情识别数据集和LVOS长时视频目标分割数据集等开放资源。

目前，ROILab已确认的核心教师为张文强研究员（研究员、博士生导师）。团队公开可见的研究生、博士后及论文作者包括王龑（博士后、共同通讯作者）、周新宇（团队博士生）、洪凌屹（团队博士生）、王浩然（团队论文一作）、佟璇（团队论文一作）等，他们在情感计算、视频分割、工业异常检测等方向参与团队研究。公开材料未逐一公布导师分配，上述成员的师承关系不作超出公开来源的推定。

## 研究方向与圈层结构概述

### 研究方向

ROILab以张文强为组织节点，围绕以下主题展开研究：

- **视觉感知与理解**：视频目标分割（LVOS数据集）、细粒度表情识别（FERV39k数据集）、视觉对抗鲁棒性、显著性目标识别
- **机器人智能**：在线学习发育、上下文注意力选择、感知与认知表达
- **工业视觉**：工业异常检测中真实异常样本稀缺问题、外观缺陷感知建模与仿真成像
- **知识图谱**：实体关系抽取等知识表示研究
- **医疗与健康管理**：自动化柔性支气管手术机器人、中西医健康管理机器人、仲景中医药语言大模型

### 圈层结构

**第一圈层：复旦平台与ROILab核心。** 张文强以复旦计算机学院研究员、智能机器人研究院副院长及ROILab负责人身份，连接研究生、博士后和共同署名作者。王龑、周新宇、洪凌屹、王浩然、佟璇等公开可见成员分布在情感计算、视频分割、工业异常检测等方向。

**第二圈层：跨主题学术合作。** 以视觉表情识别、视频对象分割、对抗鲁棒性、少样本学习、知识图谱抽取为节点，张文强与多位共同作者形成论文合作网络，问题导向强、主题跨度大。

**第三圈层：校内外科研平台与项目共同体。** 国家自然科学基金、科技创新2030重大项目、上海市科委重大攻关项目，以及智能信息处理与智能机器人平台，将团队与基础研究、医疗机器人、装备可靠性、工业视觉等资源网络相连。

**第四圈层：产业应用与国际学术传播。** 产业侧以校企合作、手术机器人、智能制造和中医AI等应用链呈现；国际侧以CVPR、ICRA、ICCV、NeurIPS等发表渠道及FERV39k、LVOS等开放资源构成对外学术连接。

## 产业转化亮点

- **智能制造与工业视觉**：科技创新2030重大项目"复杂工况环境下的外观缺陷感知建模与仿生成像"（2020AAA0108301）面向工业质检场景。佟璇一作的ICRA论文《Component-aware Unsupervised Logical Anomaly Generation for Industrial Anomaly Detection》针对工业制造中异常样本稀缺问题，以生成与检测方法服务质量控制。
- **医疗机器人**：上海市科委重大攻关项目"自动化柔性支气管手术机器人"将机器人感知、控制与临床流程相连，对应医疗器械和临床辅助方向。
- **装备运维**：上海市科委关于轴承性能评估的项目，通过多源信息融合实现装备运维与可靠性评价，连接工业装备产业需求。
- **中医AI与健康管理**：ROILab公开介绍过"中西医健康管理机器人"等智能服务机器人原型。张文强在实验室交流中介绍仲景中医药语言大模型，体现团队面向医疗健康产业的应用探索。
- **获奖与产业认可**：教育部技术发明奖二等奖（2016，排名1/6）、吴文俊人工智能科技进步奖二等奖（2016，排名1/12）、中国国际工业博览会特等奖（2017，排名1/4）、日内瓦国际发明展银奖（2018，排名1/7）、罗马尼亚科学院特别奖（2018，排名1/7），奖项共同指向技术发明、人工智能应用与工业展示。
