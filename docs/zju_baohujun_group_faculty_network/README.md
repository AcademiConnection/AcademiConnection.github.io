## 团队概况

鲍虎军组（混合现实研究团队 / zju3dv 大团队的核心）是浙江大学CAD&CG全国重点实验室的三维视觉与虚拟现实研究主力。团队围绕三个方向展开：几何计算与物理模拟、图形绘制与虚拟现实、三维视觉与增强现实。鲍虎军教授为团队奠基人，曾两次担任973项目首席科学家（2002年"虚拟现实的基础理论、算法及其实现"、2009年"混合现实的理论与算法"），并获2013年国家自然科学奖二等奖（"复杂对象的几何表示和计算理论与方法"，第一完成人）。

团队与 zju3dv 开源组织（GitHub 128 个仓库、数万 Stars）深度绑定，章国锋（SLAM/AR）、周晓巍（三维视觉）两位大团队核心骨干分别在本报告系列的独立目录中单列，崔兆鹏（SFU博士、ETH博士后背景）为团队国际化青年骨干。章国锋/鲍虎军团队孵化的影溯科技（InSpatio，2026年完成数千万美元Pre-A轮融资）与王锐创立的光线云科技，构成了团队产业转化的两条主线。

## 学术谱系概览

鲍虎军处于承上启下的谱系节点：上游为CAD&CG实验室创始人彭群生教授（师从关系有较强间接佐证，待博士论文原始文献确认）；下游梯队中，章国锋（SLAM与三维视觉）为长期紧密合作者（导师关系有较强间接佐证），周晓巍（求是特聘教授，非鲍虎军博士毕业生，博士毕业于香港科技大学）及其学生彭思达构成第二层传承，崔兆鹏、赵博明等青年一代则在神经隐式表示、高斯泼溅等新范式上延伸团队影响力。
