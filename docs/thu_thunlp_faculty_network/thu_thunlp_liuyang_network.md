## 二、教育背景与职业履历

刘洋教授的学术生涯起步于武汉大学。1998年至2002年，他在武汉大学计算机学院攻读学士学位。随后，他进入中国科学院计算技术研究所（ICT/CAS）攻读博士学位，师从刘群教授和林守勋研究员，于2007年获得博士学位。在博士期间，他的研究聚焦于统计机器翻译，代表性工作包括树到串对齐模板（Tree-to-String Alignment Template），该工作于2006年获得COLING/ACL 2006 Meritorious Asian NLP Paper Award。

博士毕业后，刘洋留在中国科学院计算技术研究所工作，先后担任助理研究员（2007–2009）和副研究员（2009–2011）。在中科院计算所期间，他继续深耕统计机器翻译方向，在词对齐、翻译模型等方面做出了重要贡献。

2011年，刘洋加入清华大学计算机科学与技术系，先后担任副教授（2011–2019）和教授（2019年至今）。在清华大学期间，他逐步从统计机器翻译转向神经机器翻译，并进一步扩展到大语言模型、多模态学习、自主智能体和AI for Science等前沿方向。

2020年，刘洋出任清华大学智能产业研究院（AIR）执行院长，2025年起升任AIR院长。在此期间，他还兼任人工智能医院（AI Agent Hospital）联席执行院长，推动AI在医疗领域的产业应用。

在教学方面，刘洋长期承担清华大学计算机系的基础课程教学，包括"程序设计基础""形式语言与自动机""人工智能""自然语言处理""深度学习前沿与热点"等本科生和研究生课程。近年来，他还开设了"大模型与生成式AI"等新课程，紧跟学术前沿。

刘洋的研究方向经历了几次重要拓展：早期聚焦统计机器翻译（2002–2013），中期转向神经机器翻译与深度学习NLP（2013–2020），近年来全面布局大语言模型、多模态学习、自主智能体、智慧医疗和AI for Science（分子动力学模拟、蛋白质设计、晶体结构预测等）等方向。他主持研制了"九歌"人工智能诗歌生成系统，该系统基于超过80万首人类诗歌训练，曾登上中央电视台《机智过人》节目，是AI与人文融合的标志性成果。他还与李 Deng合编了Deep Learning in Natural Language Processing（Springer, 2018）一书。

## 四、学术合作网络

### 4.1 实验室内部合作

刘洋在THUNLP实验室内部与孙茂松教授形成了长期紧密的合作关系。自2011年加入清华以来，刘洋的许多博士生均与孙茂松院士联合指导，形成了"孙茂松–刘洋"的联合培养模式。两人的合作覆盖了从统计机器翻译到深度学习NLP的广泛领域。在实验室内部，刘洋与刘知远教授也构成了THUNLP的"二刘老师"格局——刘洋聚焦机器翻译和大模型方向，刘知远聚焦知识计算与语言理解，两者互补支撑实验室的整体研究版图。

刘洋课题组的核心团队成员李鹏博士是其最重要的科研合作者，几乎参与了刘洋所有研究方向（大模型、多模态、智能体、AI for Science）的论文工作。此外，刘洋还与清华大学的黄文炳（Wenbing Huang）教授在AI for Science方向（分子动力学、蛋白质设计、晶体生成等）有密切合作，共同发表了多篇ICLR/ICML论文。与宋森（Sen Song）教授、刘华平（Huaping Liu）教授在具身智能和视觉语言模型方向也有合作。

近年来，随着刘洋出任AIR院长，他与AIR团队的研究人员（如马维兹 Weizhi Ma等）在智慧医疗AI方向开展了新的合作研究。

### 4.2 跨机构合作

在国内，刘洋与多个研究机构保持合作关系。他与上海人工智能实验室在多语言神经机器翻译方面有合作，ACL 2023杰出论文奖的获奖工作即由AIR与清华大学计算机系、北京信息科学与技术国家研究中心、上海人工智能实验室、腾讯、中国科技大学等单位共同完成。

刘洋还与中科院计算技术研究所保持学术联系——这是他的博士母校，其导师刘群后来先后赴爱尔兰都柏林城市大学和华为诺亚方舟实验室，两人在机器翻译方向有着学术传承关系。此外，刘洋与清华大学交叉信息研究院（IIIS）也有合作，曾与IIIS的Wei Xu教授联合指导博士生程勇。

在教学术兼职方面，作为中国中文信息学会计算语言学专业委员会主任，刘洋与国内各高校的NLP研究团队（哈尔滨工业大学、复旦大学、北京大学、中国科学院等）均有广泛的学术交流与合作。

### 4.3 国际合作

在国际层面，刘洋曾担任ACL亚太分会（AACL）执行委员会委员、Computational Linguistics期刊编委、ACM TALLIP副主编等国际学术职务，与全球NLP学术界保持密切联系。他的多篇论文发表于ACL、EMNLP、COLING、ICLR、ICML、CVPR等国际顶级会议。

在具体国际合作方面，刘洋与邓力（Li Deng，前微软首席科学家）合编了Deep Learning in Natural Language Processing（Springer, 2018）一书，系统梳理了深度学习在NLP领域的应用。从论文合作来看，刘洋近期与阿里巴巴达摩院的李向刚（Xiangang Li）在OpenChat开源语言模型上有合作（ICLR 2024），与腾讯的研究人员在多语言机器翻译方面有合作（ACL 2023杰出论文）。

刘洋还曾担任SIGHAN信息官，积极参与国际中文信息处理社区的学术服务。

## 五、业界合作关系深度分析

### 5.1 产业合作

刘洋教授在产学研合作方面布局广泛，与多家科技企业建立了深度合作关系：

**腾讯合作：** 刘洋课题组与腾讯在多语言神经机器翻译方向有直接合作。2023年获得ACL杰出论文奖的工作"Knowledge Transfer in Incremental Learning for Multilingual Neural Machine Translation"即由清华大学AIR与腾讯等机构联合完成，展示了学术研究与产业应用紧密结合的模式。该研究解决了大规模翻译模型增量学习中的灾难性遗忘问题，具有直接的产业应用价值。

**阿里巴巴合作：** 刘洋与阿里巴巴达摩院有多项合作联系。其学生米尔阿迪力江毕业后即加入阿里巴巴达摩院工作，从事NLP算法研发。在论文层面，刘洋与达摩院李向刚合作发表了OpenChat工作（ICLR 2024），这是一个利用混合质量数据训练开源语言模型的项目，体现了学术界与产业界在大模型研发上的协同。

**搜狗合作：** 刘洋在机器翻译方向长期与搜狗保持合作关系。搜狗曾是清华大学NLP组在机器翻译领域的重要产业合作伙伴，双方在翻译系统评测、数据共享等方面有合作历史。（具体合作项目的详细信息待核实。）

**万国数据（GDS）合作：** 刘洋持有的"万国数据教授"（GDS Professor）冠名教席直接反映了万国数据对清华大学AIR研究的支持。万国数据是中国领先的数据中心服务商，其与清华AIR的合作聚焦于AI算力基础设施建设与AI产业应用的结合。

**冬奥合作：** 刘洋团队参与了面向2022北京冬奥会的机器翻译项目，为冬奥术语平台和多语言翻译服务提供技术支持。

**九歌系统产业转化：** 刘洋主持研制的"九歌"人工智能诗歌生成系统本身即是产学研结合的典型案例。该系统基于超过80万首诗歌训练，部署为公开Web服务（jiuge.thunlp.org），曾登上中央电视台《机智过人》节目，在社会层面产生了广泛影响。

### 5.2 创业孵化与技术转化

刘洋作为AIR院长，积极推动AI技术的产业转化。清华大学智能产业研究院（AIR）的定位即为准产业研究机构，致力于将前沿AI研究转化为产业应用。在AIR框架下，刘洋推动设立了"人工智能医院"（AI Agent Hospital）项目，探索AI在医疗领域的深度应用，包括可进化的医疗智能体、医疗对话系统等方向。

在学生创业方面，刘洋培养的多名毕业生进入工业界后担任技术骨干，例如在阿里巴巴达摩院、腾讯等企业从事NLP和大模型研发。其学生参与开发的OpenChat等开源项目也在产业界产生了较大影响。

刘洋还通过承担科技创新2030"新一代人工智能"重大项目等国家级产业导向科研项目，将学术研究与国家AI战略需求紧密结合。他近期的研究布局——从大模型、多模态到AI for Science（蛋白质设计、分子模拟）和智慧医疗——均具有强烈的产业应用导向。

## 七、Connection圈层总结

刘洋教授的学术关系网络呈现出多层次、跨领域的结构特征，可从以下圈层进行总结：

**第一圈层——核心研究团队：** 以刘洋本人为中心，李鹏博士为最核心的科研骨干，加上当前课题组的博士生和博士后群体（焦锐、孔祥喆、杨宗瀚、陈思捷、程子俊等约20人），构成紧密的学术共同体。这一圈层是刘洋研究方向执行和论文产出的主体力量。课题组当前聚焦三大方向：人工智能基础模型（多语言、多模态、可信生成与对齐）、自主智能体（工具学习、可进化智能体、医疗智能体、具身智能）、AI for Science（分子动力学、蛋白质设计、晶体结构预测）。

**第二圈层——THUNLP实验室内部：** 孙茂松院士作为实验室带头人和联合导师，与刘洋形成了"师生+合作者"的紧密关系。刘知远教授作为实验室另一位核心教师，与刘洋在研究方向上形成互补。这一圈层构成了THUNLP实验室的整体学术生态，使实验室在机器翻译、知识图谱、大模型等方向上形成了完整的学科布局。

**第三圈层——清华校内跨院系合作：** 与黄文炳教授（AI for Science）、宋森教授和刘华平教授（具身智能/视觉语言）、交叉信息研究院（IIIS）等校内团队的合作。随着刘洋出任AIR院长，这一圈层进一步扩展到AIR体系下的产业研究合作网络。

**第四圈层——国内产业合作：** 腾讯（多语言机器翻译、ACL 2023合作论文）、阿里巴巴达摩院（OpenChat、人才输送）、万国数据（冠名教席）、搜狗（机器翻译合作）等企业构成了刘洋的产业合作网络。作为AIR院长，刘洋的产业合作角色进一步强化，推动学术成果向产业转化。

**第五圈层——国际学术界：** 通过ACL、ICLR、ICML等顶级会议的论文发表和学术服务（AACL执委、Computational Linguistics编委等），刘洋与全球NLP学术界保持密切联系。与邓力合编的学术专著、与多方国际研究者的论文合作构成了国际化学术网络。

**第六圈层——学术传承网络：** 刘洋的导师刘群教授后赴华为诺亚方舟实验室任语音语义首席科学家，形成了"中科院计算所NLP→清华NLP→产业界"的学术传承脉络。刘洋培养的学生毕业后进入阿里巴巴达摩院、腾讯、高校等，进一步扩展了这一传承网络。

总体而言，刘洋教授的学术关系网络呈现出"以学术为根基、以产业为外延"的结构特征。从早期的机器翻译专家，到如今统领AIR的产业研究领袖，他的网络覆盖了从基础研究到产业应用的完整创新链条，是清华大学NLP领域产学研融合的关键节点人物。
