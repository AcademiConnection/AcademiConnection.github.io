## 二、教育背景与职业履历

姚远的学术履历具有"清华本校连续培养 + 海外博士后 + 回国独立建组"的典型路径，且与 THUNLP（清华大学自然语言处理与社会人文计算实验室）及面壁智能形成了深度绑定的产学研共同体。

教育方面，姚远本科与博士均就读于清华大学计算机科学与技术系。2018年获得学士学位后，直升博士，为 THUNLP 2018级博士生，博士论文题目为《基于多模态大模型和结构化知识的图文理解方法研究》，论文指导教师为刘知远（时任副教授），实验室学术带头人则为孙茂松教授。其博士阶段即围绕"高效可信多模态大模型"展开系统性工作：提出多模态能力跨语言泛化训练方法，构建百亿参数级中英双语多模态大模型 VisCPM；提出首个多模态大模型提示学习方法 CPT；提出基于人类细粒度修正反馈的多模态对齐方法 RLHF-V，在抗过泛化幻觉方面实现优于 GPT-4V 的可信度。代表性成果发表于 ACL、EMNLP、ICCV、ICLR 及 Nature Communications 等顶级会议与期刊。

职业履历方面，2023年博士毕业后，姚远于同年9月赴新加坡国立大学（NUS）计算机学院担任博士后研究员，直至2026年1月。（任务背景中提及"曾在CMU等访问"，公开渠道未检索到 CMU 访问记录，其海外经历目前可核实的是 NUS 博士后，CMU 一说待核实。）2026年1月，姚远正式入职清华大学人工智能学院，担任助理教授、全职PI，开启独立课题组建设。值得一提的是，在博士及博士后期间，他已深度参与乃至主导面壁智能 MiniCPM-V 与 MiniCPM-o 系列高效多模态/全模态大模型的研发，并以"多模态首席科学家"身份在产学研两端积累了远超普通青年学者的工程化与产业化经验，这为其回国后迅速组建团队、推动端侧多模态落地奠定了资源基础。

## 五、业界合作关系深度分析

### 5.1 产业合作

姚远的产业合作高度集中于面壁智能（ModelBest）这一单一但体量巨大的产业节点，并由此向手机、汽车、机器人三大硬件赛道辐射。其本人担任面壁智能多模态首席科学家，主导 MiniCPM-V 与 MiniCPM-o 两条核心产品线，是公司端侧多模态技术的实际操盘手。面壁智能由刘知远与曾国洋（曾国阳）于2022年8月联合创立，CEO 为原知乎 CTO 李大海，估值已超 200 亿元，并启动 A 股 IPO 辅导，是端侧大模型赛道估值最高的独角兽之一。

具体产业合作落地上：在手机端，MiniCPM 系列端侧模型搭载于三星旗舰机型上市，覆盖多款旗舰；在汽车端，其 SuperMate 智能座舱产品已搭载长安马自达 EZ-60、吉利银河 M9 等车型，预计有数十万辆汽车搭载其端侧模型；在机器人端，2026 年 WAIC 上发布的 MiniCPM-Robot 系列（RobotManip 与 RobotTrack）与乐聚机器人、宇树科技等本体厂商形成合作，实现展厅导览 Agent、巡检 Agent、机器狗指令跟随等场景落地。此外，MiniCPM 系列全球累计下载量已突破数千万次，开源生态本身构成一种"产业级合作基础设施"。与英特尔的合作亦体现在其所获"英特尔中国学术成就奖"上，反映其在算力厂商端的产业认可。

### 5.2 创业孵化

姚远本人目前以"高校教师 + 企业首席科学家"双重身份运行，并未独立创业，但其深度嵌入 THUNLP 的创业孵化范式之中。THUNLP 是国内罕见的"导师带学生创业"密集型实验室：孙茂松—刘知远—曾国洋这一传承链孵化出面壁智能（端侧大模型），涂存超博士创办幂律智能（法律 AI），岂凡超博士创办深言科技（信息处理），形成了 THUNLP 系创业集群。姚远作为刘知远的博士、面壁智能多模态技术核心，既是这一创业生态的受益者（借助面壁工程团队与数据资源完成学术产出），也是其关键节点（MiniCPM-V/o 的技术主导者）。虽然他选择回归高校而非自立门户，但其"以企业首席科学家身份反哺学术研究"的模式，实质上是 THUNLP 创业孵化范式的延伸形态——将产业算力、数据与工程化能力注入高校课题组，加速学术成果产出与落地，这种"学术—产业双轨"机制正是其能够在博士及博士后阶段即主导具有全球影响力的开源项目的结构性原因。

第四圈层——院校与平台圈（制度圈）。清华大学人工智能学院（全职 PI 所属）、端侧智能北京市重点实验室（骨干）、CAAI 吴文俊奖体系、WAIC 体系等构成其制度性背书网络。人工智能学院与 IIIS 同属姚期智院士院长体系，两院系关系紧密，姚远在该层面的跨院系合作空间值得关注（IIIS 隶属关系待核实）。

第五圈层——国际合作圈（海外圈）。以 NUS 博士后经历为节点，叠加 MiniCPM-V/o 在国际开源社区的辐射（含"被斯坦福抄袭"事件反向印证的国际能见度），构成其海外学术连接。该圈层相对前四圈层较弱，仍以 NUS 与开源社区两条线索为主，CMU 等其他海外连接待核实。

总体而言，姚远是一个以 THUNLP 师承为根、以面壁智能产业线为干、以 MiniCPM-V/o 全球开源影响力为冠的"产学研高度一体化"青年学者，其网络结构在同龄助理教授中极为罕见——学术产出与产业落地互为表里，使其在端侧多模态大模型这一细分赛道上具备显著的资源与影响力优势。
