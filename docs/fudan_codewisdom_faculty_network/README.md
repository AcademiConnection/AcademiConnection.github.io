# 复旦大学软件工程实验室（CodeWisdom）及软件工程方向教师学术关系网络报告

## 团队简介

复旦大学软件工程方向以软件工程实验室（官网 se.fudan.edu.cn）为核心载体，实验室历史可追溯至赵文耘教授开创的软件工程学科传统，现任领军人物为彭鑫教授（计算与智能创新学院副院长）。团队研究工作聚焦国家战略性需求和产业共性问题，围绕智能化时代的软件工程与系统软件技术展开，形成 AI4SE（软件智能化开发与运维：将大模型与Agent技术应用于复杂软件的开发、测试与运维）与 SE4AI（面向智能化系统的工程化方法：智能汽车、智能制造、自主无人系统中的基础软件支撑与AI原生系统质量保障）两大主线。核心成员包括赵文耘、彭鑫、陈碧欢、吴毅坚、沈立炜、沙朝锋、李敏波、董震、茹炳晟（首席技术专家）等。

本报告聚焦三位代表性教师：彭鑫（CodeWisdom 团队领导者，国家级高层次人才计划入选者，研究软件智能化开发与智能汽车基础软件）；赵卫东（副教授，自建商务智能/数字智能研究室，教学与产业应用并重的"双师型"教师，非 CodeWisdom 团队成员）；卢暾（教授、计算与智能创新学院副院长，隶属协同信息与系统实验室 CISL，从事 CSCW 与社会计算研究，实际归属"人机交互与协同计算"学科方向）。三人虽分属不同实验室，但同处学院软件工程与协同计算教学科研体系，构成"软件智能化（彭鑫）—行业智能化应用（赵卫东）—人机协同与社会计算（卢暾）"的互补格局。

## 研究方向与圈层结构

三位教师的学术网络呈四层结构。第一层是校内学科建制：彭鑫与卢暾现任计算与智能创新学院副院长，学院现任院长为汪源源（2025年4月起，复旦大学副校长兼）、执行院长为杨珉（详见 fudan_secsys 报告）、党委书记为王新（详见 fudan_sonic 报告，前院长姜育刚已于2023年12月升任复旦大学副校长，详见 fudan_fvl 报告）；彭鑫的软件工程实验室与赵文耘的学科传统一脉相承，师承网络（赵文耘—彭鑫—陈碧欢/刘名威等）是复旦软件工程自主培养的典型谱系。第二层是师承与外部网络：赵卫东出自东南大学盛昭瀚教授门下（系统工程与复杂系统建模学派），经复旦管理科学与工程博士后（黄丽华教授合作）转入软件学院；卢暾出自四川大学，博士后入复旦与顾宁教授（CCF会士、IET Fellow）形成近二十年"实验室双核"合作，并有 CMU 访问经历。第三层是产业网络：彭鑫团队与华为（校企联合实验室、智能基座）、智能汽车产业链（中国汽车工程学会汽车基础软件分会、蔚来/上汽零束/斑马/联合电子等）合作密集，并深度参与 CCF 开源发展委员会与龙蜥社区；赵卫东长期承接京东、中国移动、日立电梯、上海申通地铁等企业课题，产业生态从 IBM 经历腾讯/百度/阿里云 MVP 演进到华为智能基座与魔搭社区；卢暾团队与微软亚洲研究院（谢幸，负责任的推荐系统）、美团、联想等保持合作。第四层是学生网络：CodeWisdom 培养的刘名威（现中山大学副教授）、黄凯锋（同济大学）等已形成学术扩散；CISL 培养的于方玉（2024 博士）等构成 CSCW 新生力量。

## 产业转化亮点

软件工程方向的产业转化呈"汽车软件+智能化运维+行业大数据"三线布局：彭鑫作为《车载智能计算基础平台参考架构2.0》特邀解读专家和中国汽车工程学会汽车基础软件分会副主任，直接参与国家智能汽车基础软件标准体系建设，其团队的软件智能化开发技术通过华为智能基座与校企联合实验室落地；团队主办的智能软件挑战赛与开源项目（GitHub FudanSELab，ClassEval 基准等）在 LLM4SE 领域形成国际影响；赵卫东的写作机器人、智能语音催收、图书智能标引等成果直接服务企业一线；卢暾团队的 SimuLine（大模型智能体新闻推荐模拟平台）与面向残疾人出行的信息无障碍系统体现了"科技向善"导向的社会计算落地。
