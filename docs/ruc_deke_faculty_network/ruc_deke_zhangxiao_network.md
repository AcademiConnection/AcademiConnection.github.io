## 一、学者基本信息

张孝，男，1972年生，中国人民大学信息学院教授、博士生导师，现任信息学院副院长、纪委书记（百度百科另载其兼任计算机系教师党支部书记）。中国计算机学会（CCF）高级会员、教育工委执行委员（百度百科载"教育工委主任助理"）、数据库专委会委员、虚拟现实与可视化专委会委员、CSP认证委员会和CCSP竞赛技术委员会委员、北京电子学会软件专业委员会理事。

1972年出生，中国人民大学硕士及学士（本科为信息学院经济信息管理专业），中国科学院计算技术研究所博士（数据库与知识库专业），**师从中国著名数据库专家王珊教授**。1996—1997年曾任 ORACLE 大学兼职讲师，1997年以访问学者身份在香港中文大学系统工程与工程管理系从事合作研究与开发，2006年2月—2007年1月作为公派访问学者在美国印第安纳大学计算机系 DSI&DDE 实验室从事 e-Science 相关的元数据管理（metadata management）、数据出处（provenance）领域访问研究。

张孝是中国人民大学数据库学科的代表性中坚人物之一：从1996年起作为主要技术骨干参与了从国家"863"数据库重大专项、国家"核高基"重大专项到"973"计划的一系列国产数据库系统研发项目（Kingbase ES 金仓数据库、PXRDB 纯XML-关系数据库系统、并行数据库系统 PBASE 等），先后获得国家科技进步二等奖、教育部科技进步一等奖、CCF科技进步一等奖、北京市科学技术奖一等奖/二等奖等多项国家级和省部级奖励，2021年获教育部-华为"智能基座"优秀教师称号。其学术特色是**大型数据库系统体系的原理分析、设计和实现技术**——尤其擅长开源数据库系统 PostgreSQL 源代码（在人大长期开设《PostgreSQL源代码深入剖析》课程），近十余年研究重心转向**数据库测试基准**，是学院"新型数据库基准测试研究"方向的负责人。

### 研究方向

据人大信息学院官方教师页面：

- **数据库系统原理与实现**：关系数据库理论、并行数据库系统、分布式数据库系统、对象关系数据库系统、中间件技术、移动数据库；大型数据库系统体系的原理分析、设计和实现技术，熟悉 PostgreSQL 源代码
- **数据库测试基准**：近期核心方向，包括新型数据库基准测试研究（学院"数据库与智能信息检索实验室"官方列名方向）、TPC-C/E 性能调优、XML-关系数据库系统评测基准（Renda-RX）、时序数据库基准（TS-Benchmark）
- **WEB大数据获取和应用技术**：海量 web 数据提取/集成/分析、数据库体系结构
- **非结构化数据管理**：视频数据管理、多媒体数据高维索引与 kNN 检索
- **空间/时间关键词检索、元数据与数据出处管理**：top-k 空间关键词检索、间隔关键词查询（INK）、provenance

> 注：任务背景中提到的"内存数据库、云数据库、图数据库/知识图谱查询"并非其官方页面对外宣称的核心方向；公开资料中与其相关的工作更接近"云环境下的查询优化与索引"（CIKM 2014 INK、TPDS 云上重复检测等）与"图数据存储缓冲管理"（DASFAA 2016 I/O-Efficient Buffer Batch Replacement），未见以图数据库/知识图谱查询为主要方向的证据。

## 三、博士教育背景

### 博士阶段（中国科学院计算技术研究所，1998.9—2001.6）

张孝在中科院计算所攻读数据库与知识库专业博士学位，导师为**王珊教授**。这一安排体现了上世纪90年代末人大数据库学科与中科院计算所的深度合作（王珊当时在人大任职，同时在中科院计算所有博士生指导关系；具体的联合培养机制公开资料未披露）。

博士期间（及硕士后期），张孝即作为核心技术人员深度参与了国家"863"数据库专项的研发，据其官方页面自述"从1996年以来作为主要技术骨干参与了一系列DBMS科研开发项目"：

## 六、业界合作关系深度分析

张孝的产学研合作贯穿国产数据库发展三十年，呈现"**国产数据库系统研发主线 + 国际厂商合作支线 + 教育生态建设**"的三层结构。

### 1. 人大金仓 / 国产数据库（核心主线）

**合作深度：★★★★★（二十余年持续绑定）**

- 2002—2003年，国家863数据库重大专项"**通用数据库管理系统Kingbase ES研发**"课题副组长——Kingbase ES 即人大金仓（后为电科金仓）的起点产品，该成果获2005年北京市科学技术奖一等奖（张孝排名5/25）；
- 其后参与核高基"大型通用数据库管理系统与套件研发及产业化"（国产数据库高性能高安全关键技术研究，陈红负责）与"数据库集群系统协作研发"核高基外协项目（2010—2011，负责人）；
- 2015—2016年主持北京人大金仓信息技术股份有限公司横向课题"面向多核大内存的TPC-C&E的性能调优"（35万元）——直接服务于金仓数据库的 TPC 基准性能优化；
- 近年持续参与"101计划"数据库系统课程建设与全国系统能力大赛数据库赛道，电科金仓为共建企业方，张孝在相关研讨会中承担主持角色。

### 2. 华为（教学与生态合作）

**合作深度：★★★☆☆（教育合作层面，未见内核研发的直接公开证据）**

- 2021年获教育部-华为"智能基座"**优秀教师**称号——全国性教学奖项；
- 依托其建设教育部-华为"智能基座"数据库课程虚拟教研室（中国人民大学），推动国产数据库技术进入教学体系；
- 归属存疑的 IEEE TSE 2025 论文《A Comprehensive Study of Bugs in Relational DBMS》研究了 MySQL、SQLite 与** openGauss（华为开源数据库）**的缺陷实证——若归属成立，则构成其与 openGauss 生态的学术连接。**未检索到张孝直接参与华为高斯 GaussDB 内核研发的公开证据**，其与华为的公开关联集中于数据库人才培养与课程生态。

### 3. HP（国际合作）

2007—2009年两期 **HP-DEKE 国际合作项目"可扩展复杂并行计算系统"**，张孝任副组长（负责人王珊）——涉及其并行数据库系统实现的核心专长，是 DEKE 与国际厂商的早期代表性合作。

### 4. 诺基亚西门子通信（NSN）

2012—2013年主持两期诺基亚西门子通信公司横向课题"云数据索引技术研究"（8.6万 + 17.2万元），属云计算早期产业合作。

### 5. ORACLE（个人早期业界经历）

1996—1997年任 ORACLE 大学兼职讲师——中国数据库产业起步阶段的个人经历，也解释其后来"擅长大型商用/开源数据库系统原理分析"的技术底色（另长期研究 PostgreSQL 源代码并开设课程）。

### 6. 能源行业应用

2014—2015年主持中国电力科学研究院横向课题"大规模复杂有源配电网聚类分析"（39.4万元）；博士前后与电网系统合作者（盛万兴、刘科研等）联合发表配电网应急检测论文（Trans. Edutainment 2016）。

### 7. 产学研模式总结

与同院系偏算法研究的教师不同，张孝的产业合作以**"系统实现 + 基准评测"**为轴心：早期（1996—2005）深度参与国产数据库从0到1的研发（并行数据库→嵌入式数据库→Kingbase ES），中期（2007—2015）转向云数据管理与国际厂商合作，近期（2015年后）以 TPC 基准调优、数据库课程生态（智能基座、101计划、系统能力大赛）形式持续服务国产数据库产业。其本人即是中国人民大学数据库学科"产学研一体"传统（萨师煊—王珊开创）在第二代的典型承载体。
