## 三、博士教育背景

### 博士阶段（北京大学，2019—2024年）

张心怡于 2019 年至 2024 年在北京大学计算机学院攻读博士学位，导师为**崔斌教授（Prof. Bin Cui）**，所属实验室为崔斌领导的**北京大学数据与智能实验室（PKU-DAIR）**。其博士学位论文《数据库系统参数自动调优方法研究》获评**2024 年北京大学优秀博士学位论文**（当年北大计算机学院仅 3 篇入选），2025 年再获 **CCF 数据库专委博士学位论文激励计划**。论文将数据库调优流程拆解为参数空间构建、配置搜索、调优知识迁移三个模块，并开发了数据库参数自动调优系统 **DBTune**，部分技术已在业界落地。

博士期间的核心成果为数据库参数调优"三部曲"，全部以第一作者发表在 SIGMOD/VLDB：

- **ResTune（SIGMOD 2021）**：面向云数据库的资源导向调参方法，基于元学习迁移调优知识，在阿里云数据库自治服务（DAS）中落地，为业界第一个正式上线的数据库配置参数智能调参功能
- **Towards Dynamic and Safe Configuration Tuning（SIGMOD 2022）**：面向动态负载的安全配置调优
- **A Unified and Efficient Coordinating Framework for Autonomous DBMS Tuning（SIGMOD 2023）**：自治调优的统一协调框架
- **Facilitating Database Tuning with Hyper-Parameter Optimization（VLDB 2022）**：超参优化实验综述
- **An Efficient Transfer Learning Based Configuration Adviser for Database Tuning（PVLDB 17(3)，VLDB 2024）**：跨实例迁移学习配置推荐

此外还与同门合作了 LightIndex/MFIX 索引推荐（ICDE 2024）、ContTune 流式系统保守贝叶斯调优（PVLDB 2023，与北邮邵蓥侠合作）、Spark 在线调优（PVLDB 2023）、DBPA 事务数据库性能异常基准（SIGMOD 2023）等成果。

### 导师崔斌教授

崔斌，北京大学博雅特聘教授、计算机学院副院长、数据科学与工程研究所所长，IEEE Fellow、CCF Fellow、教育部长江学者特聘教授，DSE（Data Science and Engineering）期刊主编，曾任 VLDB 2024 大会共同主席、CCF 数据库专委副主任（2020—2027）。本科毕业于西安交通大学（1996年，教改班），博士毕业于新加坡国立大学（2004年），2004—2006年在 Singapore-MIT Alliance 从事博士后研究。研究方向为数据库系统、AI 系统与应用、大数据管理与分析，发表论文 200 余篇，获 VLDB 2022 最佳可扩展数据科学论文奖、WWW 2022 最佳学生论文奖等。其与腾讯、阿里巴巴、百度、字节跳动、苹果、微软等企业均有密切项目合作，这一产学研网络为张心怡的产业合作提供了直接渠道。需要说明的是，**调研任务背景中推测的"博士导师为北京大学高军教授"不成立**——北大优博新闻、字节跳动奖学金官方报道及其实验室公众号均明确记载其指导教师为崔斌教授。

张心怡博士期间的代表作 ResTune（SIGMOD 2021）即为与阿里云的合作成果。据阿里云官方技术社区报道，该工作由达摩院-数据库与存储实验室-智能数据库团队与北大崔斌组联合研发，针对 RDS MySQL、RDS PostgreSQL、PolarDB 等云数据库的 OLTP 性能参数调优，**在阿里云数据库自治服务（DAS）产品中落地，是业界第一个正式上线的数据库配置参数智能调参功能**。论文合作者 Tieying Zhang（张铁赢）、Jian Tan（谭剑）即为当时参与该合作方向的业界研究者。入职人大后，她主持 **CCF-阿里云瑶池科研基金**"基于代码大模型的数据库系统参数调优"（2024-11至2025-11，已结项并获评优秀结项 2/8），将调优研究延伸至 LLM 时代。

### 2. 字节跳动（ByteDance）

**合作深度：★★★★☆（奖学金 + 横向项目 + 论文合作者）**

字节跳动与张心怡的联系体现在三个层面：① 2023 年获**字节跳动奖学金**（全球仅 13 人，含 10 万元科研奖励），字节评审委员会明确评价其成果"与工业界实际应用成果契合度高"；② 入职人大后主持**字节跳动横向项目**"大小模型结合的高效 HTAP 数据库代价估计方案"（2025-9至2026-9，在研，项目负责人），与其 VLDB 2026 HTAP 存储优化论文方向对应；③ 博士期间核心合作者**张铁赢（Tieying Zhang）**现为字节跳动美国实验室高级研究科学家（曾担任 2022 年 CCF VLDB 暑期学校 AI4DB 主讲人），在 ResTune 与中文期刊论文 RLO 中均有合作。

### 3. 华为（Huawei）

**合作深度：★★★☆☆（专项基金）**

主持 **CCF-华为胡杨林基金**"通用解耦 OLTP 优化器的高效描述接口"（2025-10至2026-10，在研，项目负责人），研究方向从参数调优扩展至查询优化器接口层。目前 DBLP 记录中未检索到明确标注华为机构隶属的联合论文。

### 4. 腾讯（Tencent）与其他线索

其博士期间参与的 DBPA 事务数据库性能异常基准（SIGMOD 2023）与数据库性能优化综述（Sci. China Inf. Sci. 2023）的作者群（Yaofeng Tu、Zhongliang Li 等）具有产学研背景（据论文主题与合作网络推断为崔斌实验室的企业合作方向，具体机构公开资料未明确披露）；本科阶段的 MSQL+ 论文（PVLDB 2018）合作者包括 Anqun Pan（潘安群）等据公开资料任职于腾讯 TDSQL 团队的研究者，表明人大 DEKE 与腾讯 TDSQL 的传统合作渠道在其本科阶段即有体现。此外，其导师崔斌教授官网明确列出腾讯、百度、快手等企业为其课题组长年合作方，构成潜在延伸渠道。

### 5. 国产数据库产业生态（电科金仓/人大金仓）

2025 年 10 月，张心怡作为强基班班主任带队赴**中电科金仓（原人大金仓）**开展交流活动。人大金仓由人大数据库团队（杜小勇、王珊等）于 1999 年创立，是国产数据库领军企业，作为 DEKE 实验室的"嫡系"产业延伸，为张心怡的国产数据库研究提供了天然的产业对接渠道（目前以交流活动为主，未见联合论文）。

### 6. 产学研合作总结

张心怡的产业合作模式可概括为"**调优技术纵深落地**"型——博士阶段以 ResTune 在阿里云 DAS 实现业界首个上线的智能调参功能为起点，独立后通过 CCF 专项基金（阿里云瑶池、华为胡杨林）和字节跳动横向项目，将研究主线从传统机器学习调优（元学习、贝叶斯优化、迁移学习）平滑升级至 LLM 驱动调优（代码大模型、LLM Agent），其企业合作对象与其技术演进路径保持了精确的同步。相较资深教授的"广撒网"式合作，其合作企业数量不多但单个合作深度高，且均有经费与成果产出支撑。

## 七、Connection 圈层总结

**第一圈层（博士导师与北大系学术网络）：** 崔斌教授（DBLP 合作 17 次记录，全网络最高频）是张心怡学术生涯的塑造者，其领导的 PKU-DAIR 实验室提供了博士期间的全部学术训练和产业合作渠道。即便在其入职人大后，双方仍保持合作（DistVec，ICDE 2026）。北大同门（常卓、李阳、苗旭鹏、秦彦昭、黄诗月等）构成其博士期间的主要论文合作网络。值得注意的是，崔斌同时是 CCF 数据库专委副主任、DSE 期刊主编，这一学术组织网络对青年学者的成长具有放大效应。

**第二圈层（人大 DEKE 现单位网络）：** 卢卫教授（13 次）与杜小勇教授（12 次）是其入职后的最高频合作者——卢卫是她在人大本科阶段的启蒙合作者（2018 年 MSQL+），如今成为日常科研中最紧密的同事；杜小勇作为 DEKE 实验室主任、CCF 大数据专委主任，为其提供学术平台与资源支撑。张超副教授（HTAP 论文合作者）是实验室内 AI4DB 方向的同龄合作者。"人大本科—北大博士—人大任教"的双母校闭环是其区别于其他海归/外校引进青年教师的核心网络特征。

**第三圈层（国际学术合作网络）：** 美国犹他大学 Feifei Li（李飞飞）教授（10 次）是博士期间由调优合作（ResTune、SIGMOD 2022/2023 系列）引入的国际合作者，合作延续至其独立后的 LLM Agent 调优工作（VLDB 2026，共同作者还包括 Mo Sha）；清华大学李国强/李国良团队（ST-Raptor，SIGMOD 2025）则代表国内 AI4DB 顶校团队的横向联结。这一"人大—北大—清华—Utah"的多点国际国内网络在国内数据库青年学者中较为罕见。

**第四圈层（产学研合作网络）：** 阿里云（ResTune 落地 DAS + 瑶池基金优秀结项）、字节跳动（奖学金 + HTAP 横向项目 + 张铁赢合作渠道）、华为（胡杨林基金）是最重要的产业合作方，电科金仓（人大金仓）提供国产数据库生态的天然纽带。其产学研路径与导师崔斌的企业网络高度同源，体现了 PKU-DAIR 产学研传统的代际传承。
