## 一、学者基本信息

范举，中国人民大学信息学院教授（2022年至今，此前2015—2022年为副教授）、博士生导师，任职于数据工程与知识工程教育部重点实验室（DEKE），入选国家级人才项目（国家自然科学基金优秀青年科学基金，2022）。据百度百科及高校讲座介绍，其2025年12月起担任中国人民大学信息学院数据科学与技术系负责人，现任中国计算机学会（CCF）YOCSEF主席（2024年12月曾连任YOCSEF AC副主席）、CCF数据库专业委员会与大数据专家委员会执行委员，担任国际期刊 Data Science and Engineering 执行副主编（Associate Managing Editor），并持续担任 SIGMOD、VLDB、ICDE 等数据库三大顶会程序委员会委员近20次。

范举主持国家自然科学基金优青项目、重点项目课题、面上项目、青年项目，以及CCF-华为胡杨林基金数据库专项、CCF-腾讯犀牛鸟基金等多项产学研项目。在SIGMOD、VLDB、ICDE、TKDE等CCF-A类会议/期刊发表论文70余篇（其人大官网早期页面表述为"40余篇"，系页面更新时点差异）。个人荣誉包括2017年度ACM中国新星奖（ACM China Rising Star Award，全国仅2名）、宝钢优秀教师奖、中国人民大学教学标兵（2020）；团队成果获ACM SIGMOD研究亮点奖、ICDE 2025最佳论文亚军奖（第一作者为其团队讲师张超）。2025年10月，其团队发布面向数据科学的Agentic大模型 DeepAnalyze（开源一周获GitHub超1000 Star）。

### 研究方向

- **智能数据库技术（AI4DB）**：基于深度学习/大模型的数据库测试、查询生成、数据库配置调优（SIGMOD 2025 RALM调优论文）、Text-to-SQL（CodeS、TACO基准、Reward-SQL）、数据智能体（DeepAnalyze、Data Agent）

## 三、博士教育背景

### 博士阶段（清华大学，2007—2012年）

范举2007年至2012年在清华大学计算机系攻读工学博士学位，导师为**周立柱教授**（该信息来自百度百科；人大信息学院官方教师页仅列学历未列导师，故标注为二手来源）。周立柱为清华大学计算机系原系主任、数据库学科带头人，长期主持垂直搜索引擎、数据库系统等方向研究。

范举博士期间的研究主线是**数据库易用性与Web数据检索**，代表成果包括：

- **ICDE 2011**："Interactive SQL Query Suggestion: Making Databases User-friendly"——交互式SQL查询建议
- **CIDR 2011**（DBease，与李国良、冯建华等）：面向易用数据库的系统愿景论文
- **VLDB 2012**："SEAL: Spatio-Textual Similarity Search"——时空-文本相似度检索（其少数涉足空间数据的工作）
- **IJCAI 2013**："Crowdsourcing-Assisted Query Structure Interpretation"——众包辅助查询结构解析，为其后续众包方向的起点

博士阶段几乎所有论文均与**李国良**（2009年博士毕业留校，时为清华青年教师/博后阶段）和**周立柱**共同署名，形成了"周立柱—李国良—范举"的清华数据库团队三代协作链。需要说明：李国良与范举是否为严格意义上的同门师兄弟（即李国良亦师从周立柱），公开一手资料未能直接核实，但两人博士期间同在周立柱领导的清华数据库团队、2010年起持续共同发表论文（至2026年累计57次，为其全网络最高频合作者），学术上构成典型的"师兄—师弟"关系。

### 博士后阶段（新加坡国立大学，2012—2015年）

2012年至2015年，范举在新加坡国立大学计算机学院从事博士后研究，合作于**Beng Chin Ooi（黄铭钧）教授**领导的数据库团队（据共同署名论文推断；官方履历未列博士后导师）。这一阶段其研究重心转向**众包数据管理与医疗数据分析**，代表成果包括：

- **ICDE 2014 / TKDE 2015**："A Hybrid Machine-Crowdsourcing System for Matching Web Tables"与"CrowdOp: Query Optimization for Declarative Crowdsourcing Systems"——众包查询优化的奠基性工作
- **SIGMOD 2015**："iCrowd: An Adaptive Crowdsourcing Framework"
- **VLDB 2014**：GEMINI医疗数据分析系统（与新加坡总医院合作）

博后阶段核心合作者：Beng Chin Ooi（6次）、Kian-Lee Tan（8次）、Meihui Zhang（13次，时为NUS团队成员）、Stanley Kok、Meiyu Lu、Wang-Chiew Tan。这段经历奠定了其众包/人在回路研究方向的国际视野，也使其与NUS数据库团队建立了长期联系。

## 六、业界合作关系深度分析

范举的产学研合作呈现"**基金牵引—成果落地—联合论文**"的三层结构，合作方覆盖腾讯、华为、微软、阿里及新兴LLM企业，且多项成果有明确的工业落地记录。

### 1. 腾讯（★★★★☆：基金资助+三年深度落地合作+多篇联合论文）

腾讯是范举最早也最深入的产业合作方。官网明确记载：（1）2016年主持CCF-腾讯犀牛鸟基金；（2）2017—2019年主持腾讯犀牛鸟专项基金（获2017年度CCF-腾讯犀牛鸟基金优秀奖）；（3）**连续三年与腾讯社交广告部门合作**，通过人在回路数据融合技术构建精准用户画像，成果在腾讯上线使用，提升了微信广告投放效果，并合作发表A类论文。对应的联合论文包括AAAI 2020"Social Influence Does Matter: User Action Prediction for In-Feed Advertising"与ICDE 2021"A Human-in-the-loop Approach to Social Behavioral Targeting"（腾讯方合作者Qingfei Meng、Chong Peng、Gong Chen、Sheng Yao等，据论文主题推断）。此外，AAAI 2024 DINGO论文与腾讯方研究者Zhanhui Kang及Xingwu Sun等合作（中文名与具体职务未核实）；Unicorn系列论文中的Peng Wang亦来自腾讯（据公开资料）。

### 2. 华为（★★★★☆：胡杨林基金+GaussDB相关系统研究）

范举2022—2023年主持CCF-华为胡杨林基金数据库专项。DBLP记录显示SIGMOD 2025论文"Automatic Database Configuration Debugging using Retrieval-Augmented Language Models"与Bin Wu、Jian Tan（华为数据库团队，据公开资料）合作，该方向成果获评首届CCF产学合作基金优秀案例（其个人主页2025年1月新闻）。团队青年教师张超的HTAP查询优化成果落地GaussDB数据库内核。百度百科另载其数据集成工具Unicorn等成果已在华为、阿里等真实场景落地应用。

### 3. 微软（★★★☆☆：MSRA/雷德蒙联合论文）

SIGMOD 2024"Auto-Formula: Recommend Formulas in Spreadsheets"与微软的Yeye He、Surajit Chaudhuri（SIGMOD/PVLDB历史主席级学者）、Weiwei Cui、Dongmei Zhang、Haidong Zhang合作，属于其团队学生（陈思蓓）与微软在表格智能方向的深度合作；ChatPipe（SIGMOD 2024）亦有Hanbing Liu参与（机构归属未核实）。

### 4. 阿里及LLM/RL新兴企业（★★★☆☆：起步加速中）

SIGMOD 2025数据库配置调优论文的合作者还包括Feifei Li与Jingren Zhou（阿里巴巴，据公开资料）。2025—2026年，范举团队与产业界LLM/RL研究力量出现密集的arXiv合作（ETS、Reasoning and Tool-use Compete in Agentic RL、OFA-Diffusion、TANDEM等），合作者Mingyang Yi、Xi Chen、Peng Li、Jie Song、Fuxin Jiang、Tieying Zhang等多来自头部大模型/科技公司（具体机构归属未在一手来源中逐一核实，不排除蚂蚁集团等）。这批工作表明其团队正将Data Agent研究延伸至RL训练与对齐技术。

### 5. 其他应用型合作

- **北京市大数据中心**：Unicorn等数据治理成果落地应用（据百度百科与人大官网新闻）；
- **新加坡医疗系统（NUS博后时期）**：GEMINI系统（VLDB 2014）与新加坡总医院医生团队（Gerald Choon Huat Koh等）合作；
- **人大新闻学院（学科交叉）**：2020年新冠疫情期间利用人在回路数据融合技术构建武汉新冠肺炎求助者画像，联合发布研究报告（总阅读量20万+，被南方周末等转载），相关论文发表于Journal of Medical Internet Research（JMIR 2020）。

### 6. 产学研合作总结

范举的产业合作模式可概括为"**数据治理落地**"型：以人在回路数据融合（腾讯广告画像）、数据库智能化调优（华为）、表格/数据准备智能化（微软）为主线，基金资助与论文合作并重。与纯学术型学者不同，其官网明确以"成果在腾讯/华为/阿里/北京市大数据中心真实场景落地"作为核心业绩叙事。2025年后随着DeepAnalyze开源（一周1000+ Star）及其与LLM/RL产业团队的合作，其产学研重心正转向**开源数据智能体生态**。

## 七、Connection 圈层总结

**第一圈层（贯穿生涯的最核心合作者）：** 李国良（清华教授，57次合作，2010—2026年从未间断）与唐南（Nan Tang，港科大（广州）副教授，49次，2020—2026）构成范举学术网络的"双引擎"——前者是清华数据库团队的师兄与合作导师型人物，代表"清华—人大"跨校轴线（CodeS、Reward-SQL、Data Agent等旗舰成果均为三方合作）；后者是其数据准备/数据智能体方向的共同主导者。两人与其形成事实上的"铁三角"：2020年后大量论文由"范举+李国良+唐南"共同署名。

**第二圈层（博士导师与师承网络）：** 周立柱教授（清华，11次，2008—2013）为博士导师，奠定了其数据库系统根基；Beng Chin Ooi/Kian-Lee Tan（NUS，博后团队）提供国际化训练；冯建华（清华）、王建楠（SFU，清华博士同学）构成清华同门网络。师承谱系上，范举属"清华数据库学派"南下北上扩散的一支：本人入职人大，师兄李国良留守清华，形成了国内数据库界最具产出能力的跨校合作轴之一。

**第三圈层（现单位平台与自主团队）：** 杜小勇教授（46次合作）领导的DB-IIR/DEKE实验室是其学术平台，范举负责数据治理方向并领导RUC-DataLab/DBAI小组；自主培养的学生梯队（范明浩、顾子惠、张宇昕、陈思蓓、屠建宏、刘通宇、杨晨羽等）已在SIGMOD/VLDB/ICDE形成规模化产出；团队讲师张超获ICDE 2025最佳论文亚军奖，标志团队已具备培养独立青年学者的能力。2025年12月其出任数据科学与技术系负责人，学术组织角色进一步上升。

**第四圈层（产学研与国际网络）：** 腾讯（三年社交广告落地+两期犀牛鸟基金）、华为（胡杨林基金+SIGMOD 2025联合论文）、微软（Yeye He/Chaudhuri表格智能合作）、MIT（Madden/Cao）、阿里（Jingren Zhou/Feifei Li）构成其产业与国际合作网络；2025年后与LLM/RL产业团队的密集arXiv合作与DeepAnalyze开源标志着其向"Data Agent开源生态"的转型。

**产出规模与趋势：** DBLP收录148条记录（正式发表约111篇），2024—2026年连续三年年产出20篇以上，为国内数据库方向产出最高的中坚学者之一。研究方向演进路径清晰：数据库易用性（清华博士期）→众包/人在回路数据管理（NUS博后—人大副教授期）→数据准备与AI4DB（2018—2022）→LLM+数据系统/Data Agent（2023至今），每一阶段均踩中领域范式转换节点。个人荣誉（ACM中国新星奖2017、优青2022）与团队荣誉（SIGMOD研究亮点奖、ICDE 2025最佳论文亚军）双线齐升。
