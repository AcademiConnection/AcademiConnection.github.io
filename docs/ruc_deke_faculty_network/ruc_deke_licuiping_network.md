## 一、学者基本信息

李翠平，女，工学博士，中国人民大学信息学院计算机科学与技术系教授、博士生导师，现任信息学院副院长（据人大信息学院2024—2025年多项官方新闻，以副院长身份出席学院活动）。中国计算机学会杰出会员、CCF大数据专家委员会常务委员、CCF数据库专委会委员，国家自然科学基金通讯评议专家，曾任CIKM 2010、ICDE 2009等国际会议程序委员，TKDE、JCST、《软件学报》、《计算机学报》等期刊匿名评审专家。2003年毕业于中科院计算所获博士学位，2008—2009年在美国UIUC大学计算机系访问交流。长期从事数据库教学与科研工作，研究方向为大数据分析与挖掘、基于机器学习的数据库系统、深度学习、图表示学习、社会网络分析、自然语言处理及推荐系统。先后在SIGKDD、SIGMOD、VLDB、EDBT等重要国际会议和TKDE、KAIS、JCST、《软件学报》等国内外期刊发表论文100多篇，出版著作3部，申请国家发明专利6项。2007年入选北京市组织部优秀人才培养资助计划，2009年入选教育部新世纪优秀人才支持计划，2011年获中国计算机学会"青年科学家奖"，2015年获CCF科技进步一等奖，2017年获高等学校科学研究优秀成果奖科技进步奖一等奖，2018年获国家科学技术进步奖二等奖。2018年获得国家重点研发计划"云计算和大数据"重点专项支持（数据仓库与商务智能实验室DWBI两位教授陈红、李翠平分别于2016年和2018年获该专项支持，总经费近5000万元）。

## 三、博士教育背景

### 博士阶段（中科院计算所，2000—2003年）

李翠平于2000年9月至2003年7月在中国科学院计算技术研究所攻读博士学位，获工学博士学位，**博士导师姓名公开资料未披露**（人大信息学院官方教师页与DEKE实验室官方页面均仅列"中科院计算所博士研究生"，未注明导师；学位论文库未检索到可公开确认的导师记录）。

值得注意的是，其博士期间的研究已深度嵌入中国人民大学数据库团队与新加坡国立大学的国际合作网络：

- **2002年PAKDD**（其首篇DBLP收录论文）："Efficient Constraint-Based Exploratory Mining on Large Data Cubes"，与李胜恩（Sheng-En Li）、**王珊**、**杜小勇**合作——彼时她尚在计算所攻读博士，署名合作方即为人大数据工程与知识工程研究所核心人物；
- **2002.09—2003.03 新加坡国立大学访问学者**（博士在读期间），随后产出2004年JCST论文"Incremental Maintenance of Quotient Cube Based on Galois Lattice"（与Kum-Hoe Tung、王珊）和2004年KDD论文"Incremental maintenance of quotient cube for median"（与丛高、Anthony K. H. Tung、王珊）；
- 博士研究主题为**数据立方体的高效维护与约束挖掘**：商立方体基于Galois格的增量维护、中位数商立方体增量维护、分配型与非分配型聚合的增量维护（JCST 2004/2006），属于王珊团队"数据仓库与OLAP"经典研究脉络的延续。

这一履历表明：李翠平虽博士学位授予单位为中科院计算所，但其博士阶段的研究工作与人大王珊团队高度绑定，这直接解释了她2003年博士毕业后即入职中国人民大学信息学院任讲师的职业路径。**需要特别说明：本报告调研未发现任何一手依据表明王珊是其博士生导师；两者关系应定性为"博士期间起的长期论文合作者与学术领路人"，而非师生关系。**

### UIUC访问（2008—2009年）

2008年2月至2009年2月，李翠平赴美国伊利诺伊大学香槟分校（UIUC）计算机系访问交流。访问期间及随后产出了一批与**韩家炜教授团队**的合作论文：2010年EDBT"Region-based online promotion analysis"（与Tianyi Wu、Yizhou Sun、韩家炜）、2010年EDBT"Fast computation of SimRank for static and dynamic information networks"（本人一作，合作者含韩家炜、Guoming He、Yizhou Sun、Yintao Yu、Tianyi Wu）。其中SimRank快速计算后来发展为她的代表性研究主线之一（TKDE 2012 GPU SimRank、DASFAA 2013/2014、Inf. ## 五、现单位团队与核心合作者

### 所属团队：数据仓库与商务智能实验室（DWBI）

李翠平所在的数据仓库与商务智能实验室（DWBI）成立于2002年，附属于数据工程与知识工程教育部重点实验室（DEKE）和人大信息学院计算机系，实验室负责人为陈红教授。实验室研究方向沉淀为三块：大数据分析与挖掘（大图数据/知识图谱）、大数据安全与隐私、大数据管理与系统（AI赋能的数据库管理与新硬件加速数据处理）。实验室承担了华为、中保信、腾讯等企业横向合作项目，研制了并行数据仓库系统ParaWare 2.0、基于GPU的OLAP系统GOLAP、无线传感器网络查询处理系统TinyQP、个人决策助理系统PDA等系统。李翠平本人在该实验室中与陈红构成"双核心"：陈红、李翠平分别于2016年和2018年获国家重点研发计划"云计算和大数据"重点专项支持（总经费近5000万元），实验室成果获2015年CCF科技进步一等奖、2016年教育部科技进步一等奖、2018年国家科技进步二等奖。

## 六、业界合作关系深度分析

李翠平的产业合作呈现"数据库国产化+头部企业横向项目+国际大厂联合论文"三线并进的格局。

### 1. 蚂蚁集团/OceanBase（数据库旋钮调优与LLM for DB）

**合作深度：★★★★☆（2024—2026年密集联合论文，覆盖SIGMOD/PVLDB/ICDE三大数据库顶会）**

DBLP记录显示，2024年起张铁赢、陈建军（7次合作）以及Shuai Wang、Rui Shi持续出现在李翠平-陈红-张静团队的论文中，合作主题全部集中于数据库智能化运维：

| 论文 | 会议/期刊 | 年份 | 合作内容 |
|------|----------|------|----------|
| E2ETune: End-to-End Knob Tuning via Fine-tuned Generative Language Model | PVLDB | 2025 | 基于微调生成式语言模型的数据库端到端旋钮调优 |
| AgentTune: An Agent-Based LLM Framework for Database Knob Tuning | SIGMOD | 2025 | 基于Agent的LLM数据库旋钮调优框架（合作者含墨尔本大学Renata Borovica-Gajic） |
| OmniSQL: Synthesizing High-quality Text-to-SQL Data at Scale | PVLDB | 2025 | 百万级Text-to-SQL数据合成，训练出匹敌GPT-4o/DeepSeek-V3的开源模型（7B/14B/32B） |
| LLMIdxAdvis: Resource-Efficient Index Advisor Utilizing LLM | arXiv→后续发表 | 2025 | 基于LLM的索引推荐 |
| Llmia: an Out-Of-The-Box Index Advisor Via in-Context Learning With LLMs | ICDE | 2026 | 即插即用型LLM索引顾问 |

张铁赢、陈建军长期从事OceanBase/蚂蚁集团的数据库智能化研究，该合作线代表了国产分布式数据库（OceanBase）与人大DWBI实验室在"AI for DB"方向的深度产学研绑定。

### 2. 华为、中保信、腾讯（DWBI实验室横向项目）

**合作深度：★★★☆☆（实验室层面横向项目，个人DBLP署名较少）**

据DWBI实验室官方介绍，实验室承担了华为、中保信、腾讯等企业的横向合作项目，内容涵盖云计算与大数据、制造业大数据管理、新型硬件环境数据管理、大数据隐私保护等。李翠平作为实验室双核心之一（2018年国家重点研发计划"制造业大数据管理系统标准、规范与测评"课题负责人），深度参与该合作网络，但多数横向项目成果不以联合署名论文形式呈现于DBLP。

### 3. 蚂蚁之外的其他LLM/DB产业线索

- **CodeS开源Text-to-SQL模型**（SIGMOD 2024）：论文含Jun Zhu、Renjie Wei、Hongyan Pan等非人大作者（推测为企业合作者），是首个系列化开源Text-to-SQL专用语言模型之一；
- 其官方主页列出"企事业单位合作项目：特定主题\*\*\*\*研究"、"基于\*\*\*\*知识库"等横向项目（涉密名称），表明存在未公开的产业合作。

### 4. 学生毕业去向工业界

由于DBLP不含机构角色信息，学生去向仅能从合作轨迹推断：其"AI for DB"方向学生（李好洋、黄心梅、李依言等）的论文持续出现蚂蚁集团合作者，大概率有蚂蚁/OceanBase实习或联合培养通道；早期学生（吴垚、吴云乘、赵丹等）的隐私保护与群智感知方向与华为、腾讯等企业的数据安全业务对口。

### 5. 产学研合作总结

李翠平的产业合作模式可概括为"**国产数据库智能化**"型——依托DWBI实验室与国家重点研发计划的平台，将团队在数据仓库/OLAP领域二十余年的积累，转化为面向OceanBase等国产数据库的LLM旋钮调优、索引推荐、Text-to-SQL产品化研究。与同院高瓴学院学者偏互联网推荐/大模型的合作模式不同，其产学研合作的垂直度极高，几乎全部集中在数据库系统本身。

## 七、Connection 圈层总结

**第一圈层（长期核心搭档）：** 陈红教授（195/208篇合作，占全部记录的94%）是李翠平学术网络的绝对中心。自2006年首篇合作论文（ADMA/ICDM流数据频繁项集挖掘）起，两人在2006—2026年间形成了中国数据库界罕见的"二十年双核"结构：陈红侧重数据管理与隐私安全体系，李翠平侧重数据挖掘与学习型数据库方法，两人共同支撑起DWBI实验室的教学科研体系（陈红任数据库与商务智能教育部工程研究中心主任，李翠平任信息学院副院长）。这一绑定的强度甚至超过了张骁报告中徐君-张骁（~25次）一个数量级。

**第二圈层（学术领路人与早期国际网络）：** 王珊教授（11次，2002—2017年）是李翠平博士期间的论文合作者与职业领路人——李翠平2003年从中科院计算所博士毕业即入职王珊领导的人大数据库团队，其早期代表作（SIGMOD 2006 DADA、VLDB 2007主导关系分析、KDD 2004商立方体）均出自这一合作。需要再次强调：无一手依据表明存在师生关系，两者是"学派传承+论文合作"关系。同期的新加坡国立大学网络（Anthony Tung、Beng Chin Ooi、Gao Cong）和UIUC韩家炜团队（2008—2009访问期间2篇合作）构成其早期国际化通道。杜小勇（DEKE实验室主任，7次合作）为长期同事。

**第三圈层（团队中生代与学生梯队）：** 张静教授（67次，2018—2026）是团队中生代核心——几乎所有2018年后的团队论文由"陈红+李翠平+张静"三导师结构署名，学生第一作者执行；赵素云教授（39次）带来模糊粗糙集/弱监督学习的交叉方向。学生梯队中，李好洋（Text-to-SQL，RESDSQL曾登顶Spider榜、CodeS/OmniSQL开源模型）、胡宇轩（LLM压缩与SAM Decoding推测解码）、纪涛（学习型索引）、黄心梅（旋钮调优）等是当前产出主力。团队2024年26篇、2025年20篇的高产主要来自"LLM+DB"和"LLM压缩"两大学生方向。

**第四圈层（产学研与国际合作网络）：** 蚂蚁集团/OceanBase（张铁赢、陈建军、Shuai Wang、Rui Shi，2024—2026年E2ETune/AgentTune/OmniSQL/Llmia等密集联合发表）是最重要的产业合作方；DWBI实验室层面的华为/中保信/腾讯横向项目提供长期产业支撑。国际合作方面，昆士兰大学尹红志（12次，推荐系统）、SFU王克（6次，隐私保护）、清华唐杰（6次，AMiner）、新加坡管理大学廖资资与NUS蔡达成（知识图谱问答）构成稳定的外部学术连接。

**产出规模与趋势：** DBLP收录208条记录（正式发表约170篇），2002—2026年持续产出25年无间断，2019年后年均15篇以上进入高产期，2024年达峰值26篇。研究方向演进清晰：数据立方体/数据仓库（2002—2008）→ 主导关系分析/Skyline查询/流数据（2006—2013）→ SimRank与信息网络分析（2010—2015）→ GPU数据库与推荐系统（2014—2020）→ 隐私保护查询与差分隐私（2015—2023）→ LLM+数据库（Text-to-SQL、旋钮调优、学习型优化器）与LLM压缩（2022年至今），完整映射了中国数据库研究从OLAP时代到AI for DB时代的范式迁移。
