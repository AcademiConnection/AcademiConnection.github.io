## 七、Connection 圈层总结

**第一圈层（长期同单位论文合作）：** 杜小勇与刘红岩是最稳定、证据最充分的合作节点。杜小勇的联系贯穿 2005 年语义 Web 到 2025 年推荐研究，兼具 DBIIR 同事关系和论文合作；刘红岩则在社交网络、兴趣挖掘、直播及跨域推荐上持续合作。王珊以 2005 年语义 Web 论文确认早期合作，但公开检得的直接共同成果较少，宜置于第一圈层边缘而非作高频绑定判断。

**第二圈层（跨机构学术合作）：** 韩家炜代表 UIUC 访问期间的明确合作关系，研究重点是多关系与数据流挖掘；Jeffrey Xu Yu 等通过图数据研究形成跨机构论文联系。这一层是“论文合作/访问合作”，不是师承。

**第三圈层（直接指导与人才培养）：** 王启一的个人主页明确写明博士导师为 Prof. Jun He；王泽华、周敏程、王婷婷、李梦瑶的 DBIIR 校友记录明确列何军为导师。该层是本报告中证据最直接的**直接指导关系**，应与实验室同事和论文作者严格区分。

**第四圈层（产学研与应用）：** MSRA 项目和深锶科技横向项目是有公开项目依据的合作线索；Google、美团、中国银行数据中心则是受指导学生的就业节点。前者可称项目合作，后者仅为人才流向，不能混同。

总体而言，何军的网络以人大 DEKE/DBIIR 的数据库和数据挖掘共同体为本地核心，由早期语义 Web、关系数据挖掘和检索，逐步扩展至图/社交数据、推荐及多模态数据智能。其博士导师身份未公开披露，是师承分析中不可跨越的证据缺口。
