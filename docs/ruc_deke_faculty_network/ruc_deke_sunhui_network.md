## 一、学者基本信息

孙辉，中国人民大学信息学院计算机科学与技术系副教授。2005年于清华大学获得工学博士学位（1996—2005年在清华大学计算机系连续完成学士、硕士、博士学业）。2005年入职中国人民大学信息学院任讲师，2017年起任副教授。研究方向为高性能数据库、数据分析。社会兼职为中国计算机学会（CCF）全国青少年信息学奥林匹克竞赛（NOI）科学委员会副主席，曾任 IOI 2015 中国队领队。讲授课程为《程序设计导论》《程序设计实践》。电子邮箱：sun_h@ruc.edu.cn。

## 三、博士教育背景

### 博士阶段（清华大学计算机系，2000—2005年）

孙辉于1996年考入清华大学计算机系，2000年获工学学士学位后继续在本系攻读研究生，2000—2005年完成硕士、博士阶段学业，2005年获清华大学工学博士学位，属于典型的本校直通式培养路径（本硕博均在清华计算机系完成，总计9年）。

其博士导师姓名在人大官方师资页及公开网络资料中均**未披露**，学位论文题目亦未检索到（CNKI 等学位论文库无公开可检索的对应记录）。仅可确认其博士培养阶段处于清华大学计算机系数据库研究语境之下——2000年代初期清华数据库研究组的核心教师包括周立柱教授、冯建华教授等，但孙辉的具体导师归属无公开证据，本报告不做推断。

博士期间的研究成果未在 DBLP 中体现（可确认归因的论文最早为2015年），这与2000年代中期国内博士生主要在中文期刊（如《软件学报》《计算机学报》《计算机研究与发展》）发表成果、而 DBLP 对这些期刊收录不全的情况相符，也可能其博士成果以系统研发为主。从其入职人大后的论文看，其技术功底集中于**并行/异构平台上的数据库查询处理**（CPU/MIC 协同的 Join 优化、众核哈希构建），这一"高性能数据库"取向与清华数据库组当时的系统研发传统一脉相承。

## 八、数据来源与局限性说明

本报告主数据来自 DBLP 作者记录与出版物检索（通过 DBLP API 及镜像站 dblp.uni-trier.de，截至2026年8月），结合人大信息学院官方师资页及网络公开资料交叉验证。

主要信息源：
- 中国人民大学信息学院官方师资页（info.ruc.edu.cn）：确认职称（副教授）、教育与工作经历（清华本硕博、2005年讲师入职、2017年晋升副教授）、研究方向（高性能数据库、数据分析）、社会兼职（CCF NOI 科学委员会副主席）、电子邮箱
- DBLP 作者检索（109个同名记录比对）与三个已消歧记录（31/3925-1/-2/-3）的排除性核验
- DBLP 出版物 API 联合检索（以陈红、李翠平、杜小勇、赵素云、周开来等合作者为锚点，从 pid 31/3925 聚合桶的157篇论文中甄别出7篇可归因论文）
- NOI 官网新闻（noi.cn，2015年）：确认其 IOI 2015 中国队领队与 NOI 科学委员会委员身份
- 数据工程与知识工程教育部重点实验室官网（deke.ruc.edu.cn）：核验实验室在职团队名单（未列孙辉）及实验室背景

**主要局限性：**
1. **DBLP 消歧为推断性质**：人大孙辉无 DBLP 独立消歧记录，7篇论文的归因依据是"合作者全部为人大 DEKE 成员+主题吻合+时间吻合"，置信度高但非 DBLP 官方确认；不排除该聚合桶中仍有未发现的孙辉论文（尤其与其他合作者或中文期刊发表的部分）；
2. **清华博士导师未披露**：公开资料（人大师资页、学位论文库检索、网络搜索）均未披露其博士导师姓名，第四章师承分析因此存在结构性缺口；
3. **发表统计可能偏低**：DBLP 对中文期刊（《软件学报》《计算机学报》等）收录不全，其2005—2014年（讲师阶段）的中文论文可能完全缺失；其官网"科研成果"栏目为空白，无法补充核对；
4. **学生身份为推测**：周开来、吴天震、张小莹等合作者的博士生身份及导师归属（陈红/李翠平名下）系根据论文署名顺序与合作模式推断，未逐一核实；
5. **DEKE 任职身份未明确**：DEKE 官网当前在职人员名单未列孙辉，其在实验室的正式身份（固定研究人员/流动人员）公开资料未披露，本报告仅依据其系别、方向与合作网络判断其"研究工作嵌入 DEKE 团队"；
6. **Google Scholar 缺失**：未找到可确认归属的 Google Scholar 主页，引用数据无法统计。
