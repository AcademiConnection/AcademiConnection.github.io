## 一、学者基本信息

覃雄派（1971— ），男，广西百色人，中国人民大学信息学院计算机科学与技术系副教授（较早的公开资料如《数据科学概论》教材作者简介中曾记为"讲师、硕士生导师"，其后晋升副教授）。其本、硕、博均在中国人民大学完成：1994 年毕业于中国人民大学信息系，2001 年和 2009 年分别在中国人民大学信息学院获得工学硕士和工学博士学位；2001 年起留校任教于信息学院计算机系至今。研究兴趣包括高性能数据库、并行计算、大数据分析等。他是数据工程与知识工程教育部重点实验室（DEKE）数据库团队（数据库与智能信息检索实验室 DBIIR）"可信数据科学"方向（与陈跃国共同负责）的骨干成员，与陈跃国、杜小勇合著教材《数据科学概论》。

代表性成果方面：其与王珊、王会举、杜小勇合著的《大数据分析——RDBMS 与 MapReduce 的竞争与共生》（软件学报，2012，23(1): 32-45）于 2013 年入选"领跑者 5000——中国精品科技期刊顶尖学术论文"；其参与署名的《架构大数据：挑战、现状与展望》（王珊、王会举、覃雄派、周烜，计算机学报，2011，34(10): 1741-1752）是中国大数据系统架构方向的早期高影响力中文综述。

### 研究方向

- **高性能数据库与主内存数据库**：主内存数据库并行恢复、数据库系统自优化
- **并行计算与大数据分析系统**：MapReduce/Hadoop 生态、RDBMS 与 MapReduce 融合架构（LinearDB、HC-Store 等）、SQL-on-Hadoop 系统实验评测、星型模式并行聚合查询
- **查询处理与数据仓库**：多维直方图与相关性检测（COCA/HY-COCA）、宽表布局优化（Rainbow）、内存列存混合索引
- **实时日志分析与基准测试**：实时日志摄取与索引、行为数据实时分析工具、时序数据库与工业大数据基准（TS-Benchmark、MiDBench）

## 三、博士教育背景

### 博士阶段（中国人民大学，2003—2009 年）

覃雄派于 2003 年至 2009 年在中国人民大学信息学院攻读博士学位，2009 年获工学博士学位。其博士期间（及前后数年）的研究成果集中发表于 PDCAT 2008、WAIM 2008、SpringSim 2009、APWeb/WAIM 2009 等会议，主题为：

- **主内存数据库并行恢复**：A Parallel Recovery Scheme for Update Intensive Main Memory Database Systems（PDCAT 2008）、Simulation of main memory database parallel recovery（SpringSim 2009）——面向高更新负载主内存数据库系统的并行恢复机制；
- **查询优化与统计信息估计**：COCA——基于更精确相关性检测的多维直方图（WAIM 2008，与曹巍、王珊），该工作后续在 2015 年扩展为中文期刊论文 HY-COCA（计算机科学）；
- **数据库系统自优化**：Lightweight Data Mining Based Database System Self-optimization（APWeb/WAIM 2009）。

值得注意的是，覃雄派是典型的"在职长期攻读"路径：1994 年本科毕业后有约七年间隔（此段经历公开资料未披露），2001 年获硕士学位并留校任教，2003 年在职攻读博士，2009 年获学位，其时已 38 岁。这一路径与人大数据库团队同期培养的曹巍（2004—2009 在读博士，期间公派纽约大学联合培养，师从 Dennis Shasha）等人并行。

其参与的 SQL-on-Hadoop 系统实验研究（BPOE 2014、IEEE BigData Congress 2017）系统评测了 Hadoop 生态商业与开源产品的性能，MiDBench（Bench 2018）面向工业多模型大数据基准，TS-Benchmark（ICDE 2021）面向时序数据库——基准测试工作天然与数据库/大数据产业界形成技术与影响力层面的连接，但未检索到标注企业隶属的直接联合署名论文。

### 4. 产学研总结

覃雄派的产业合作模式可概括为"**企业资助 + 系统原型**"型：以 EMC 中国研究院资助项目为最正式的纽带，围绕 Hadoop 高性能数据仓库开展联合研究；其余产业连接多为应用驱动（量化金融、工业与日志数据分析）而非深度绑定。与陈跃国（华为、金融科技）和柴云鹏—卞昊穹（腾讯 TDSQL、协同创新实验室）相比，其个人名下的现代产业合作网络相对收窄，2018 年后 DBLP 记录中的企业关联署名基本消失。

## 七、Connection 圈层总结

**第一圈层（王珊—杜小勇学术体系与历史最核心合作者）：** 王珊（14 次合作，2008—2015，全网络最高频）是其博士阶段至今最重要的学术关系人——博士期间论文全部与其联合署名，并共同完成《架构大数据》《大数据分析——RDBMS 与 MapReduce 的竞争与共生》两篇入选"领跑者 5000"的高影响力中文论文；杜小勇（12 次）作为团队负责人提供项目平台。这一圈层奠定了他在人大数据库学派"萨师煊—王珊"谱系中的位置。

**第二圈层（现役核心同事与合作伙伴）：** 陈跃国（10 次，2014—2023）是其 2014 年以后最核心的合作者，两人共同负责 DEKE"可信数据科学"方向、合著《数据科学概论》教材，覃雄派深度参与了陈跃国主导的 Rainbow（ICDE 2018）、MiDBench、TS-Benchmark（ICDE 2021）、DiCausal/Flowris（DASFAA 2023）等项目。周烜（5 次，现华东师范大学教授）、曹巍（5 次，人大副教授、同期博士同事）构成其平辈合作网络。

**第三圈层（培养学生与团队梯队）：** 其参与指导的学生中，卞昊穹是标志性人物——从博士期间与其联合署名（BPOE 2014、APWeb 2015、ICDE 2018 Rainbow），到经腾讯 TDSQL、EPFL 历练后回人大任副教授并获中国专利金奖，体现了人大数据库团队"老带新"的传承链条；此外还有靳国栋、孙乔及 TS-Benchmark/MiDBench 团队成员等。

**第四圈层（产业与国际网络）：** EMC 中国研究院（2011—2012 正式资助项目，李芙蓉等联合论文）是最明确的产业合作节点；量化金融应用合作（合作方未披露）次之；国际上通过 Keqin Li（SUNY New Paltz，2 次合作）接入并行计算学术网络。整体而言，其网络重心在人大校内与中文数据库学术共同体，而非国际顶会或深度产业绑定。

**产出规模与风格：** DBLP 收录 32 条（2008—2023），高峰期年均 3—4 条，以系统实现与实验评测类工作见长（MapReduce 融合架构、SQL-on-Hadoop 评测、日志分析、基准测试），叠加多篇未入 DBLP 的高影响力中文期刊论文，属于"中英文双轨、系统与教学并重"的稳健型学者。
