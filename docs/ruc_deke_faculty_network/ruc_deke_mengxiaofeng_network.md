## 一、学者基本信息

孟小峰，1964年生，中国人民大学信息学院教授、博士生导师；人大信息学院教师页亦列其为副院长。其主持的网络与移动数据管理实验室（WAMDM）隶属中国人民大学信息学院计算机科学与技术系及数据工程与知识工程教育部重点实验室（DEKE）。

个人主页列其为中国计算机学会（CCF）会士、CCF理事，曾任CCF数据库专委会秘书长（1999—2015）；同时列有中国保密协会隐私保护专委会副主任（2015年起）。实验室官网新闻记录其于2024年当选中国人工智能学会（CAAI）会士；CAAI公开会议报道可确认其担任CAAI社会计算与社会智能专委会主任。由于官网资料版本不一，未将“CCF常务理事”及其起始年份作为确定事实写入。
