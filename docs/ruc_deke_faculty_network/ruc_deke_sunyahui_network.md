## 一、学者基本信息

孙亚辉，博士，中国人民大学信息学院副教授（2022年起，入选中国人民大学"杰出学者"计划），官方师资页现列于**计算机科学与技术系**（其个人中文 CV 另署"数据科学与技术系"，两者应为同一团队建制，以官网为准）。其所在的人民大学"**数据库与智能信息检索实验室**"是数据工程与知识工程教育部重点实验室（DEKE）的重要组成部分，据实验室官网，孙亚辉担任其中"**图计算与分析**"方向的负责人。中国计算机学会（CCF）数据库专委会执行委员、字节跳动 OpenViking 开源项目（The Context Database for AI Agents）开源委员会委员。

其学术轨迹颇具特色：**本科与硕士均为哈尔滨工业大学航空航天工程背景（星敏感器标定方向），博士阶段在澳大利亚墨尔本大学转向图上 Steiner 树/网络优化问题，再经澳大利亚国立大学、南洋理工大学、新加坡国立大学的博士后与研究经历，最终以"图与向量数据管理算法与系统"为学术主线落地人大数据库团队**。近年研究重心是 CPU/GPU 异构平台上的图数据库、向量数据管理，以及面向大模型检索增强生成（RAG）与智能体（agent）的新数据管理算法与系统——即任务背景中所述"向量数据库、GPU 加速的数据库/查询处理、高维数据管理"方向，与官方表述一致。

以第一作者或独立通讯作者身份在 SIGMOD、PVLDB（VLDB）、IEEE/ACM Transactions on Networking（ToN）等 CCF A 类会议与期刊发表多篇论文，另在 ICDE（2026，已录用）、《计算机学报》（2026，中文 CCF A 类，已录用）有独立通讯作者成果。

## 三、博士教育背景

### 博士阶段（澳大利亚墨尔本大学，2014—2018）

博士论文《Classical, prize-collecting and node-weighted Steiner tree problems in graphs》（墨尔本大学知识库 hdl.handle.net/11343/214000；调研期间该校知识库服务不可用，未能直接核验论文元数据中的导师署名）。博士期间的研究横跨三个应用面：

- **组合优化理论**：经典 Steiner 树、罚收集 Steiner 树、点加权 Steiner 树的快速启发式与 Physarum（黏菌）启发算法（IEEE CEC 2016）；
- **通信网络设计**：大型低成本通信网络设计、无线传感网络中继节点部署（ToN 2019、ToN 2020 两篇）；
- **生物网络分析**：癌症相关信号通路识别、药物重定位子网络识别（BMC Systems Biology 2016、BMC Bioinformatics 2017）。

这一阶段的 Steiner 树研究主线直接延续至今——其回国后的全部顶会论文（PVLDB 2022、SIGMOD 2025、ICDE 2026）均为 Group Steiner Tree 搜索问题在数据库场景下的深化，研究脉络高度连贯。

### 硕士阶段（哈尔滨工业大学，2012—2014）

航空航天工程方向，公开成果为星敏感器在轨标定与像面位移分析（CCC 2013、《红外与激光工程》2014），与耿云海联合署名——耿云海为推断的硕士导师（依据两篇论文的持续联合署名，未见官方披露）。其从航天工程转向图数据库的跨学科路径，使其成为人大数据库团队中少见的"非科班数据库出身"的教师，也构成其在异构硬件系统与算法设计交叉方向上的独特底色。

## 六、业界合作关系深度分析

孙亚辉的产业合作集中爆发于 2023 年之后，与国家重点研发计划落地及大模型/向量数据库浪潮的时间线高度吻合，呈现"**国家重大任务牵引 + 新兴数据库厂商合作 + AI Agent 生态卡位**"三层结构。

### 1. 国家重点研发计划与国产数据库系统（核心主线）

**合作深度：★★★★★（2023—2026 持续）**

国家重点研发计划"**基于新型硬件的原生数据库系统**"（2023—2026）中，清华大学李国强为项目总负责人，中国人民大学陈红负责"面向混合负载的智能异构计算技术"课题，任务为研发基于 CPU/GPU 异构平台的关系、图、向量数据库——**孙亚辉带队研发其中基于 CPU/GPU 异构平台的图数据库**。这是其"图计算与分析"方向在国家层面的主要承载，也直接催生了其团队 SIGMOD 2025 / ICDE 2026 / 计算机学报 2026 的 GPU 图数据库论文群。

### 2. PingCAP（平凯星辰）

**合作深度：★★★★☆（2025—2027 校企合作项目主要参与人）**

PingCAP 是国产分布式数据库 TiDB 的厂商，近年大力投入向量检索与 AI 场景（TiDB Vector）。孙亚辉的向量数据管理研究方向与 PingCAP 的技术路线直接对口，2025—2027 年校企合作项目是其产业合作的最新支线（具体课题内容公开资料未披露）。

### 3. 电科金仓（原人大金仓）

**合作深度：★★★★☆（2025—2026 校企合作项目主要参与人）**

人大金仓是脱胎于人大数据库学科（王珊、萨师煊一脉）的国产数据库代表厂商，2024 年并入中国电科。孙亚辉与之的合作（2025—2026）延续了 DEKE"学科—产业共生"的传统，但其本人与金仓并无学缘关系，属新一代教师对实验室产业传统的接续（具体课题内容公开资料未披露）。

### 4. 字节跳动 OpenViking 开源生态

**合作深度：★★★☆☆（开源治理角色）**

孙亚辉为字节跳动 **OpenViking** 开源项目委员会委员（OpenViking: The Context Database for AI Agents，openviking.ai）——这是面向 AI Agent 的上下文数据库开源项目，与其"面向 RAG、智能体的新数据管理算法与系统"研究方向完全对应，是其在 AI 数据管理新兴生态中的卡位。

### 5. 华为（教学与生态）

**合作深度：★★☆☆☆（教学生态层面）**

其"程序设计实践"课程为人大-华为"智能基座"项目系列课程（2023—）。未检索到其参与华为 GaussDB/openGauss 内核研发的公开证据，合作限于人才培养与课程共建层面。

### 6. OceanBase 及产业认知活动

曾作为 2022 级图灵实验班班主任带队走访国产分布式数据库厂商 OceanBase 公司，属于面向学生的产业认知活动，未见技术研发层面的直接合作。

### 7. 产学研模式总结

与张孝等"系统实现派"前辈"二十余年绑定单一国产厂商"的模式不同，孙亚辉的产业合作是**大模型时代的新形态**：以国家重点研发计划（GPU 异构图/向量数据库）为学术锚点，同时对接 TiDB（新兴分布式+向量数据库）、电科金仓（传统国产数据库）、字节跳动（AI Agent 基础设施）三条性质各异的产业线，并通过 OpenViking 委员会身份参与开源治理——覆盖了"传统国产数据库 + 新兴数据库厂商 + AI 基础设施"三个板块，布局宽度在其资历的青年教师中相当突出。
