# 中国人民大学 数据工程与知识工程教育部重点实验室（DEKE）数据库团队教师学术关系网络报告

> 报告生成时间：2026年8月

## 团队简介

数据工程与知识工程教育部重点实验室（Data Engineering and Knowledge Engineering，DEKE）依托中国人民大学信息学院建设，是中国数据库学科的策源地，其学术源头可追溯至萨师煊先生开创的数据库教学与研究传统和萨师煊—王珊合著的《数据库系统概论》教材体系。实验室现任主任为杜小勇教授（2006年起接替首任主任王珊），副主任包括卢卫、陈跃国、汪云海等。实验室内含多个研究团队：以杜小勇领衔的数据库与智能信息检索实验室（DB-IIR）、陈红领导的数据库与商务智能实验室（DWBI）、孟小峰领导的网络与移动数据管理实验室（WAMDM），以及柴云鹏负责的云计算与大数据系统实验室（CloudLab，另见 ruc_cloudlab_faculty_network 系列）等，共同构成人大数据库研究"一体多翼"的格局。

团队研究主线覆盖传统数据库内核（事务处理、内存数据库、分析型数据库）、大数据管理与系统实现（XML/图/时空数据、数据集成与基准测试）、新型数据管理（隐私保护、联邦学习、差分隐私、众包与群智计算）和 AI 时代的数据库智能化（AI4DB：学习型数据库、旋钮调优、Text-to-SQL、LLM for data management；DB4AI：向量数据库与 GPU 加速）四个层面。代表性产业化成果是国产数据库"人大金仓"（Kingbase，1999年创办，2024年更名电科金仓），其"数据库管理系统核心技术的创新与金仓数据库产业化"项目获2018年国家科学技术进步奖二等奖，是中国人民大学首次获得国家级科技"三大奖"；产业合作方面与腾讯共建协同创新实验室（TDSQL 方向），与蚂蚁集团 OceanBase 在数据库智能化运维方向密集合作。

本目录覆盖 DEKE 数据库方向的19位教师，其中王珊教授作为学术谱系源头人物建立档案型报告，其余18位按网络型报告呈现。

## 研究方向与圈层结构概述

DEKE 团队的网络结构以"谱系—平台—产业"三重纽带组织。第一重是学术谱系：萨师煊—王珊构成学科源头，但需要特别说明的是，除张孝（官方页面明确"师从王珊"）和杜小勇（官网记载硕士师从萨师煊）外，其他骨干教授与王珊的师生关系均无公开一手依据——陈红、李翠平博士毕业于中科院计算所，范举、张静、张心怡分别出自清华周立柱、唐杰、北大崔斌门下，张超出自陆嘉恒门下，李直旭出自昆士兰大学，他们是以"学派同代/后辈成员"身份嵌入 DEKE 平台的，本目录在各自报告中均如实区分了"确认师承"与"学派归属"。

第二重是平台组织：杜小勇作为 DEKE 主任和 DB-IIR 实验室领导，与卢卫（90次联合署名）、陈跃国（40次）、张孝（20次）等构成合作密度最高的平台内核；陈红—李翠平—张静构成 DWBI 实验室的"三导师"结构（陈红与李翠平合作195篇，为全网络最强绑定之一）；孟小峰的 WAMDM 实验室相对独立，以隐私保护与群智感知为主线。三条线共同培养了吴云乘、赵展浩、李好洋、侯佳敏等新一代学者。

第三重是产业网络：人大金仓（王珊、杜小勇、张孝、张延松、陈红、李翠平均为2018年国家科技进步二等奖完成人）代表国产数据库的"学派创业"路径；腾讯 TDSQL 协同创新实验室（杜小勇任主任，卢卫、柴云鹏、陈红等人大侧阵容，与潘安群等腾讯工程师持续联合署名）和蚂蚁 OceanBase（李翠平团队张铁赢、陈建军合作渠道）构成当前两大产学支柱；阿里云、华为、字节跳动则通过基金与横向项目覆盖张心怡等新锐教师。

## 产业转化亮点

团队产业合作的标志性成果是人大金仓的创立与产业化：1999年杜小勇作为主要创始人创办北京人大金仓信息技术股份有限公司并任第一任总经理，王珊担任技术奠基人，历经二十余年攻关后以2018年国家科学技术进步二等奖收官，金仓数据库已成为党政与关键行业国产数据库替代的主力产品之一。当代的产业转化则呈现"云数据库+AI"转向：与腾讯共建的协同创新实验室（TDSQL）持续产出 SIGMOD/ICDE 级联合论文；DWBI 团队的 Text-to-SQL 开源模型 CodeS/OmniSQL 与蚂蚁 OceanBase 的智能化运维合作；CloudLab 的 PixelsDB 云原生数据湖开源生态（详见 ruc_cloudlab_faculty_network 系列）。人才培养上，团队毕业生广泛进入腾讯、阿里、华为、蚂蚁等企业的数据库团队，形成"国产数据库国家队—互联网云数据库—开源生态"的完整人才环流。
