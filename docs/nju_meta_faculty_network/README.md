# 南京大学智能图形与三维视觉研究组（Meta Graphics & 3D Vision Lab）教师学术网络团队索引

南京大学智能图形与三维视觉研究组（NJU Meta Graphics & 3D Vision Lab）依托南京大学计算机科学与技术系（计算机学院）与计算机软件新技术全国重点实验室，由郭延文教授牵头组建并担任负责人（PI）。研究组教师团队由四位教师构成：郭延文（教授、博士生导师）、过洁（长聘副教授、特聘研究员、博士生导师）、张岩（副教授）、李元琪（助理研究员，研究组自主培养并于2024年博士毕业后留校）。四位教师研究方向互补——郭延文侧重三维计算机视觉与智能图形学（空间智能），过洁专注图形渲染（物理渲染、实时渲染、可微渲染与神经渲染），张岩聚焦三维计算机视觉与多媒体计算，李元琪深耕三维重建与生成——共同支撑研究组在空间智能、智能图形和高性能渲染领域的系统性研究。

研究组实行多教师协同指导模式，团队累计发表图形学与视觉领域CCF-A类论文200余篇，共同指导博士生10余人、硕士生40余人。团队代表性成果包括SIGGRAPH、CVPR、ICCV、ACM TOG、IEEE TVCG等顶会顶刊论文，以及国产渲染引擎体系（Moer Renderer、MoerEngine、Moer-lite，其中Moer Renderer获CCF CAD&CG专委2024年度优秀图形开源软件奖）、LiDAR-Net点云数据集、TransparentGS/GlossyGS神经渲染等工作。团队主页记载已有80余名毕业硕博士就业于一线科技企业，30余项应用成果服务于行业一线企业。

需要说明的是，四位教师之间的师生关系需准确区分：郭延文与过洁是同组教师同事关系，并非师生关系（过洁2013年获南京大学博士学位，其博士导师为潘金贵教授；郭延文则于2006年在浙江大学CAD&CG国家重点实验室获博士学位，导师为彭群生教授）。李元琪的博士导师为郭延文教授；张岩于2006年在吉林大学获博士学位，2008年南京大学博士后出站后留校任教。团队与华为、OPPO、三星等头部公司合作项目二十余项（据郭延文近期讲座简介口径为三十余项），系研究组整体层面的产业合作成果。

## 研究方向与圈层结构概述

研究组的整体研究方向覆盖三维计算机视觉（三维场景重建与理解、点云处理、材质重建）、智能图形学（三维生成、矢量图形）、图形渲染（物理渲染、实时渲染、可微渲染与逆渲染、NeRF与3D Gaussian Splatting等神经渲染）及多媒体计算。从各份报告的圈层分析看，团队成员的学术网络可归纳为以下结构：

- **师承与学缘圈层**：郭延文承袭浙江大学CAD&CG学派（导师彭群生教授）；过洁为南大本土培养（博士导师潘金贵教授），并有微软亚洲研究院（MSRA）网络图形组访学经历；张岩出身吉林大学少年班并完成本硕博培养，在南大博士后阶段与孙正兴教授建立了长期合作关系；李元琪本科毕业于南京大学物理学院，后师从郭延文获计算机博士学位。
- **团队内部圈层**：四位教师构成紧密的内部合作网络，联合指导硕博学生，在光照估计、材质重建（ShadowMover、SIGGRAPH 2025多图像SVBRDF重建、MatMart等）方向深度合作。
- **跨机构学术圈层**：团队与中国科学技术大学刘利刚教授（GCL实验室）、南京航空航天大学魏明强教授、浙江大学周昆教授与徐巍、国防科技大学徐凯教授、UCSB的Ling-Qi Yan、德州农工大学/原香港大学的王文平、北京师范大学郭建伟等学者，以及南京大学校内王崇军教授团队保持论文合作。
- **产业合作圈层**：团队整体与华为、OPPO、三星等企业保持长期合作，成果应用于中石化、巴斯夫、国家电网、腾讯、米哈游、阿里巴巴、苏交科集团、网易游戏等企业，并通过江苏《智库专报》进入政策咨询层面。
- **国际学术圈层**：以SIGGRAPH、CVPR、ICCV等顶会为国际合作的主要载体；郭延文早年多次访问香港中文大学、香港大学及UIUC。

## 产业转化亮点

- **工业数字孪生落地**：团队三维场景分析和智能重建研究成果应用于流程工业数字化，落地对象包括中国石化、巴斯夫（BASF）、国家电网等世界500强企业；研究组Demo展示的"工业场景智能建模与质量核验"系统融合图纸文档、现场点云和AI算法，服务工业场景建模、校核与质量检查；系统性成果登载于《中国人工智能学会通讯》。
- **国产渲染引擎开源生态**：过洁带领团队研制国产真实感渲染引擎Moer Renderer（获CCF CAD&CG专委2024年度优秀图形开源软件奖）及实时渲染引擎MoerEngine、轻量级渲染引擎Moer-lite，覆盖从离线高质量渲染到实时轻量化渲染的完整技术谱系，已在文物保护、基础教育、消费电子、交通设施和影视娱乐等行业获得应用。
- **校企联合研发与联合实验室**：团队与OPPO联合发表CVPR 2024论文（基于像素间半透明先验的材质估计）；过洁担任南京大学-OPPO软件技术创新联合实验室副主任；郭延文、过洁分别获华为"难题揭榜"火花奖；过洁与三星电子合作开发室内外光照估计系统，与爱奇艺合作优化VR场景渲染性能。
- **学生与成果的双向输送**：团队毕业生去向包括腾讯、华为、米哈游、NVIDIA、字节跳动、阿里巴巴、网易游戏、美团、Momenta、小米等头部科技企业；团队主页记载"80余名毕业硕博士就业一线大厂"、"30余项应用成果服务于行业一线企业"。
- **政策与智库影响**：郭延文牵头撰写的"加快江苏元宇宙技术创新和产业发展的对策建议"刊发于中共江苏省委宣传部《智库专报》。

需要说明的是，除公开资料明确归属于个人的合作项目（如过洁与三星的光照估计系统合作、与爱奇艺的VR渲染优化合作，郭延文、过洁分别获华为火花奖，张岩承担华为、OPPO、阿里巴巴等企业横向课题）外，本索引中的产业合作成果均系研究组整体层面的记载，不归属到个人。
