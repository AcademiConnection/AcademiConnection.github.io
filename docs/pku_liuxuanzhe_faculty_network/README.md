## 二、五位教师的角色定位

**梅宏**是这个团队在时间维度上的源头。他1992年在北京大学随杨芙清院士做博士后期间，接续了"青鸟工程"的软件工程传承脉络，此后提出"网构软件"方向，并在南京航空学院、上海交通大学、北京理工大学等多所高校任职后，最终以北大计算机学院教授、可信软件平台研究组学术带头人的身份，成为刘譞哲、黄罡两人共同的师承起点——刘譞哲是他2003级的直博生，黄罡则是他2000级的博士生。梅宏的角色更多体现在团队初创期的项目牵引（如2018年国家技术发明一等奖）和长期的精神引领，而非日常科研的具体参与。

**黄罡**是团队实际运作中最核心的"合伙人"级人物。DBLP数据显示他与刘譞哲合著论文达118篇，跨度从2005年持续至今，占其个人全部学术产出的近四成，这一比例远超他与导师梅宏的合作论文数量（84篇）。两人共同讲授《软件工程》课程、共同主持云-端融合系统研发（"燕云"平台）、共同指导学生马郓，形成了一种"共同经营同一团队"的紧密结构，而非普通的师门同事关系。

**刘譞哲**是当前团队对外呈现的核心负责人和公众形象代表。他身兼软件研究所副所长、北大-字节跳动豆包大模型联合实验室主任等职务，近年主导的AI Infra系统软件研究方向（大模型训练/推理系统）产出了MegaScale、DistServe、MuxFlow等一系列在SOSP、OSDI、NSDI等顶会发表并已在字节跳动、阿里云等企业生产环境实际部署的系统性成果，是团队近五年学术影响力和产业合作快速扩张的主要驱动者。

**金鑫**是刘譞哲在AI Infra方向最重要的平级合作伙伴。他拥有普林斯顿大学（师从Jennifer Rexford）到加州大学伯克利分校（合作导师Ion Stoica）再到约翰斯·霍普金斯大学助理教授的国际化履历，2021年回北大任教后迅速与刘譞哲形成"金鑫-刘譞哲团队"这一对外并称的合作品牌，两人共同指导的博士生（如吴秉阳、赵怡浩）在OSDI、SCIS等顶级期刊会议上发表了多项大模型系统软件的代表性成果。

**马郓**是这个团队"传帮带"效果的典型例证。他2011年至2017年在北大信科直博期间，官方文献表述其课题组归属为"黄罡教授、刘譞哲副教授课题组"，呈现出黄罡挂名指导、刘譞哲实际日常指导的双轨师承结构。2020年博士后出站后，他任教于北大人工智能研究院，与刘譞哲、金鑫等人从师生关系转变为青年教师间的平级合作关系，并在2025年共同获得中国电子学会科学技术奖技术发明一等奖，实现了从"团队学生"到"团队骨干"的完整成长闭环。

## 三、团队关系网络的整体观察

**其一，双学术带头人的师承结构决定了团队的底层凝聚力。** 梅宏与黄罡并列担任可信软件平台研究组学术带头人，前者提供学术方向的战略引领和历史传承，后者承担日常科研组织和团队运营的实际职能，这种"精神领袖+运营核心"的分工模式，在刘譞哲逐渐成长为对外核心代表人物后依然保持稳定，形成了梅宏-黄罡-刘譞哲三代人接力却始终紧密捆绑的师承链条。

**其二，"AI Infra系统软件"方向的兴起重塑了团队的对外形象与合作网络。** 传统上团队以"网构软件""云-端融合"等软件工程主题为标签，但近五年随着大模型技术浪潮，刘譞哲与金鑫领衔的AI Infra方向异军突起，团队对外的公众形象与产业合作重心已明显转向大模型训练推理系统优化，这也是团队近年在字节跳动、阿里云、微软、英伟达等头部企业获得广泛技术采纳和生产环境部署的直接原因。

**其三，产学研转化能力是团队区别于纯学术团队的显著特征。** 从黄罡主导的"燕云"云端融合互操作平台（技术许可费达9500万元）、梅宏推动的北京大学-神州控股协同创新中心，到刘譞哲、金鑫主导的北大-字节跳动豆包大模型联合实验室及在多家互联网公司智算中心的实际部署，团队展现出从技术发明到产业化落地的完整链条能力，这在国内高校系统软件团队中较为突出。

**其四，青年人才培养呈现"内部孵化+平级化"的路径特点。** 马郓的成长轨迹表明，团队倾向于让学生在读博期间接受多位导师的共同指导（而非单一导师制），毕业后再通过合作发表论文、共同申报奖项等方式，逐步将其转化为平级的合作伙伴，而非维持长期的上下级师生关系。这种模式有助于团队快速扩大学术影响力覆盖面。

**其五，官方信息存在职务表述滞后或矛盾的情况，需要谨慎甄别。** 部分网络资料（如百度百科）将刘譞哲的职务误标注为软件研究所"所长"，而北大官方招聘公告等更权威信源明确其实际职务为"副所长"；梅宏的院士类型也曾被误传为"中国工程院院士"，实际应为"中国科学院院士"。本报告集在撰写过程中已对这些矛盾点进行核实并采用更可靠的结论，读者在参考其他渠道信息时也应注意甄别信源权威性。

## 数据来源与说明

本报告集所有内容均基于公开网络信息独立调研整理，主要信源包括北京大学计算机学院官方网站及教师主页、北京大学新闻网、高可信软件技术教育部重点实验室官方网站、DBLP学术数据库、OpenAlex学术数据库、各类学术会议与奖项官方公告、主流媒体报道及企业官方技术博客等。

由于同名学者数据库合并等问题，部分学者的OpenAlex等聚合平台引用数据可能存在偏差，报告撰写过程中已尽量通过合作者网络、机构归属等信息进行交叉甄别。个别历史细节（如具体奖项完成人排序、部分学生的确切毕业年份）如信息来源存在分歧，报告中已如实标注证据强度或采用更权威信源的表述，不做主观臆测。

本报告集共包含5位核心教师的独立报告及本索引文件，合计约21万字符。如需了解某位教师的详细学术履历、师承关系、学生培养情况或产业合作细节，请查阅对应的独立报告文件。
