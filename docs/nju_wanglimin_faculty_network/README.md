# 南京大学 王利民教授媒体计算组（MCG）教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

媒体计算组（MCG，Media Computing Group，官网 [mcg.nju.edu.cn](https://mcg.nju.edu.cn/)）隶属南京大学计算机学院和计算机软件新技术全国重点实验室，由王利民教授负责。王利民2007年进入南京大学计算机系本科，2011年赴香港中文大学 MMLab 师从汤晓鸥教授攻读博士，2015-2018年在苏黎世联邦理工学院（ETH Zurich）从事博士后研究，2018年回国加入南京大学，2018年入选国家级青年人才项目（多个公开来源将其归为国家优青），是南大当时最年轻的教授之一。

团队研究方向聚焦视频理解与多模态大模型，研究脉络贯穿视频深度学习的技术演进史：TDD（2015年首次在 UCF101 上突破90%识别精度，超过Google和Facebook同期方法）、TSN（稀疏时间片段建模架构，首届 ActivityNet 挑战赛冠军）、VideoMAE（视频掩码自监督预训练，成为领域标准方法），到 InternVideo 系列视频理解大模型（与上海人工智能实验室、深圳先进技术研究院联合研发：2022 InternVideo1.0 → 2024 InternVideo2.0 → 2025 InternVideo2.5，被 Google、Meta、NVIDIA 等企业关注使用，并支持央视巴黎奥运会赛事回放集锦生成），再到 VideoChat-Flash（2025，长视频理解）与 Video-o3（2026，主动推理）。王利民在 IJCV、TPAMI、CVPR、ICCV、NeurIPS 等发表论文100余篇，Google Scholar 引用3.4万余次，两篇一作论文单篇引用超4000次。获广东省技术发明一等奖、ACM MM 2023 Best Paper Honorable Mention、世界人工智能大会青年优秀论文奖，入选 AI 2000 全球最具影响力学者榜单（2022）和爱思唯尔中国高被引学者（2021-2023）。担任 CVPR/ICCV/NeurIPS 领域主席、TPAMI 副编辑（2025）与 IJCV 编委。

## 圈层结构概述

王利民的学术网络以"CUHK MMLab 师承 + 上海AI实验室联合研发"为两大支柱。师承圈层的源头是香港中文大学 MMLab 的汤晓鸥教授——王利民是其招收的首位南大本科生，这一谱系将其接入中国计算机视觉最大的学术-产业生态（MMLab 校友网络遍布商汤、旷视及各高校）；ETH Zurich 的博士后经历则补充了欧洲计算机视觉研究的国际化训练。组织圈层以南京大学计算机软件新技术全国重点实验室为基地，与武港山、唐杰、刘杰等校内教师协同；联合研发圈层则与上海人工智能实验室深度绑定——InternVideo 系列是其与上海AI实验室、深圳先进技术研究院联合产出的成果，学生和博后群体（童湛、曾祥宇等）构成大模型研发的主力。学生网络中，VideoMAE 第一作者童湛（与腾讯优图 Yibing Song 等合作）、TimeLens/TimeSuite 系列作者曾祥宇、陈廷王等已在长视频理解方向形成新生代梯队。产业影响圈层包括 Google/Meta/NVIDIA 对 InternVideo 的关注使用、央视巴黎奥运会的回放集锦应用（南大官方报道口径），以及 VideoMAE/InternVideo 开源代码的全球开发者社区。
