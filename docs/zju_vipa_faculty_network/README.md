## 研究方向与圈层结构概述

VIPA课题组的研究围绕视觉智能与模式分析展开，涵盖计算机视觉、深度学习、知识蒸馏、病理AI诊断、AI安全、推荐系统、在线学习优化、工业大数据等方向。课题组以"基础研究+产业应用"双轮驱动为特色，在AI+医疗（OmniPT病理AI助手）、AI+工业（数字化车间/未来工厂）、AI+能源（电力巡检/风电预测）三大领域形成了显著的产业转化成果。

在学术圈层结构上，VIPA呈现"宋明黎—青年骨干—新生代"的传承谱系。宋明黎教授作为课题组创始人，培养了冯尊磊、宋杰等已成长为副教授的核心骨干。王灿教授作为AAAI 2012最佳论文获得者和ICPC世界冠军教练，在数据挖掘和算法竞赛领域形成了独特的影响力网络。陈佳伟和宛袁玉作为百人计划研究员，分别在推荐系统和在线学习方向引入了新的学术血脉——陈佳伟传承自陈纯院士和何向南教授，宛袁玉传承自张利军教授。贝毅君副研究员在工业大数据和智能制造方向搭建了学术与产业的桥梁。

## 产业转化亮点

VIPA课题组的产业转化能力突出。在AI+医疗方向，课题组与浙江大学附属第一医院合作开发的OmniPT病理AI助手在胃癌、肠癌等病理诊断中取得突破性进展，获中央电视台《焦点访谈》报道。在AI+工业方向，贝毅君副研究员的研究成果应用于浙江省省级数字化车间/未来工厂项目，获浙江省科技进步一等奖。在AI+能源方向，课题组与国家电网、南方电网合作开展电力巡检和风电预测研究，获吴文俊人工智能科学技术进步一等奖。在学术竞赛方面，王灿教授自2005年起担任浙江大学ICPC总教练，2011年带队夺得ICPC世界总决赛冠军，2025年获ICPC终身教练奖。课题组与阿里巴巴、华为、舜宇光学、之江实验室等企业和机构保持密切合作关系。
