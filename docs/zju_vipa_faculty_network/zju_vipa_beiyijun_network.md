## 二、教育背景与职业履历

贝毅君博士毕业于浙江大学，获工学博士学位，其博士期间的研究工作即与浙江大学软件学院及计算机科学与技术学院的学术 Tradition 密切相关。早在2009年，贝毅君便以作者身份在《浙江大学学报（工学版）》上发表了题为《基于权重哈尔小波的XML包含连接估计方法》的论文，展现出在数据处理与基础算法方面的扎实功底。博士毕业后，贝毅君留校任教，任职于浙江大学软件学院，担任副研究员、博士生导师，并兼任软件学院大数据研究中心副主任。

贝毅君的职业发展始终围绕浙江大学宁波校区展开。软件学院大数据研究中心设于宁波，贝毅君长期在此开展研究工作，其研究方向从早期的大数据存储与管理，逐步延伸至机器学习、制造服务、工业大数据、数字孪生和工业互联网等领域。在学术兼职方面，贝毅君自2022年起连续担任浙江大学软件学院研究生奖学金评审委员会委员，参与学院研究生培养管理与评审工作。在社会服务方面，他担任浙江省智能制造专家委员会专家，为浙江省制造业数字化转型提供技术咨询与智力支持。此外，贝毅君还积极参与知识传播活动，2022年在"工业互联网赋能企业数字化转型升级"高级研修班及"智能制造技术及应用高级研修班"中担任授课专家，讲授《大数据如何赋能智能制造》课程，从智能制造概念到表现形式，深入剖析工业大数据的基础和应用情况。

在产学研结合方面，贝毅君展现出强烈的成果转化意识。他于2016年参与合作创办宁波沙塔信息技术有限公司（核心团队以浙江大学软件学院师生为主），担任董事及大股东，该公司专注于工业互联网技术研发与应用，拥有iWork平台、iDevCloud设备云平台及iDAT数据采集盒等自主知识产权产品。2023年，贝毅君进一步创办浙江宇丰信息技术有限公司并担任法定代表人，将研究方向向大模型驱动的工业智能应用拓展。2025年，贝毅君作为核心成员及课题三负责人参与了国家重点研发计划"面向共同富裕的公共服务普惠供给技术及应用"项目，标志着其研究从工业领域向公共服务的数字化普惠供给延伸。

## 三、学生培养情况

作为VIPA课题组的核心成员和博士生导师，贝毅君在学生培养方面发挥了重要作用。他于2011年荣获宁波市研究生学术节"最佳指导教师奖"，体现了其早期在研究生指导方面的突出表现。贝毅君的研究生主要分布在浙江大学软件学院（宁波校区），研究方向涵盖人脸防伪检测、行为识别、迁移学习、工业大数据分析等VIPA课题组的重点方向。以下列举其代表性学生及培养情况：

高克威是贝毅君指导的重点学生之一，在人脸防伪检测和迁移学习领域与贝毅君有深度合作。高克威作为共同作者参与了贝毅君2025年发表于Pattern Recognition期刊的论文"Target-directed Progressive Gradient Adjusting for Transfer Learning"，以及发表于《中国图象图形学报》的"面向人脸视频防伪检测的大规模中文数据评测基准"一文。此外，高克威还参与了"Behavior Capture Guided Engagement Recognition"（Pattern Recognition 2025）等论文的研究工作。其研究方向聚焦于迁移学习中的梯度调控与人脸防伪检测技术，是贝毅君在VIPA课题组视觉安全方向的核心学生。

### 2. 娄恒瑞（博士/硕士生，学术合作者）

娄恒瑞是VIPA课题组中在人脸防伪检测和AI伪造检测领域的活跃学生。作为共同作者，娄恒瑞参与了多项重要论文的撰写，包括发表于《中国图象图形学报》的中文人脸视频防伪数据集评测基准论文、ACM MM 2025的"A Large-scale Universal Evaluation Benchmark For Face Forgery Detection"、ICML 2025的"STD-FD: Spatio-Temporal Distribution Fitting Deviation for AIGC Forgery Identification"以及ICCV 2025的"Spatial-Temporal Forgery Trace based Forgery Image Identification"等。娄恒瑞还在ICML 2026发表的病理图像分析论文"Cello: A Universal Cell-wise Feature Aggregation framework for Reliable Pathology Images Analysis"中担任第一作者，显示出在病理AI方向的跨领域研究能力。贝毅君在这些论文中均作为重要作者参与指导。

## 四、学术合作网络

### 4.1 VIPA课题组内部合作

贝毅君作为VIPA课题组的核心成员，与课题组负责人宋明黎教授及其团队保持着紧密的学术合作关系。VIPA课题组由宋明黎教授创立并领导，研究方向涵盖视觉感知增强、视觉嵌入、基于视觉的人机交互与机器学习四个方面。课题组在浙江大学计算机科学与技术学院和软件学院均有人员分布，贝毅君作为软件学院方向的代表，将课题组的视觉智能研究拓展至工业大数据和制造服务领域。

在课题组内部，贝毅君与冯尊磊副教授的合作最为密切。冯尊磊是浙江大学软件学院副教授，同为VIPA课题组成员，兼任浙江大学创新软件研发中心研究人员。两人共同参与了多项重要研究：在人脸防伪检测领域，2025年共同发表了《面向人脸视频防伪检测的大规模中文数据评测基准》（中国图象图形学报），构建了中文人脸视频防伪数据集（CHN-DF），并联合发布了大规模通用评测基准（ACM MM 2025）；在病理AI领域，冯尊磊作为OmniPT病理大模型的技术负责人之一，与贝毅君在课题组内共同推进了病理图像分析的相关研究。此外，两人还共同参与了ICML 2025（STD-FD）、ICCV 2025（Spatial-Temporal Forgery Trace）等顶级会议论文的合作。

在论文合作方面，贝毅君2025年发表于Pattern Recognition的两篇论文均以冯尊磊为通讯作者："Target-directed Progressive Gradient Adjusting for Transfer Learning"和"Behavior Capture Guided Engagement Recognition"。这体现了VIPA课题组内部明确的分工协作模式：贝毅君作为第一作者或重要合作者负责研究方向的确定和论文撰写，冯尊磊作为通讯作者负责技术指导和质量把控。

宋明黎教授作为课题组负责人，在多项论文中与贝毅君共同署名，包括《中国图象图形学报》的人脸防伪检测数据集论文、ACM MM 2025评测基准论文、ICML 2025的AIGC伪造识别论文以及ICCV 2025的伪造图像识别论文等。此外，课题组其他成员如宋杰（副教授）、雷杰、金苍宏、胡秉德等也参与了与贝毅君的多个合作项目。

### 4.2 跨机构与跨领域合作

贝毅君的学术合作网络不仅限于VIPA课题组内部，还延伸至多个机构和领域：

**工业大数据与制造服务领域**：贝毅君长期与浙江省制造业企业保持合作，其研究成果已应用于浙江省省级数字化车间/未来工厂项目。作为浙江省智能制造专家委员会专家，他与宁波市经信局、宁波市软件行业协会等机构和部门建立了稳定的合作关系。2022年，贝毅君在"工业互联网赋能企业数字化转型升级"高级研修班中与捷创研究院院长王春江、宁波和利时智能科技有限公司等业界专家共同授课，拓展了产业合作网络。

**病理AI与医疗交叉领域**：通过VIPA课题组的平台，贝毅君间接参与了浙江大学计算机学院宋明黎教授团队与浙江大学医学院附属第一医院章京教授团队的"计算机+医学"交叉合作。OmniPT病理大模型的研发集合了宋明黎团队、冯尊磊团队及宁波市临床病理诊断中心的力量，贝毅君作为课题组成员参与了相关工作。该合作始于2020年，2022年6月联合申请到数字病理人工智能医疗器械临床试验中心（工信部与国家药监局联合审批）。

**公共服务与社会发展领域**：2023年起，贝毅君作为课题三负责人参与国家重点研发计划"面向共同富裕的公共服务普惠供给技术及应用"项目，这使其合作网络扩展至公共管理、社会服务等领域的研究团队。2025年5月，贝毅君参加了在浙江大学宁波科创中心举行的浙江省工程师学会工程创新论坛暨浙江大学国家卓越工程师学院工程博士年会，与来自全国各地的近150位工程博士和产业界人士进行交流。

## 五、业界合作关系深度分析

### 5.1 工业大数据与未来工厂

贝毅君在工业大数据和未来工厂领域的业界合作是其学术生涯中最具特色和深度的方向。作为浙江省智能制造专家委员会专家，贝毅君长期参与浙江省制造业数字化转型的技术咨询和方案评审工作，其研究成果已直接应用于浙江省省级数字化车间/未来工厂项目。

**宁波沙塔信息技术有限公司**是贝毅君产业布局的核心载体。该公司成立于2016年9月，由贝毅君指导的学生钟钊瑜担任法定代表人，贝毅君本人持有35%股份并担任董事。沙塔信息以浙江大学软件学院师生为核心团队，专注于工业互联网技术研发与应用，主营业务包括云计算大数据、工业智能系统研发与集成。公司拥有三大自主知识产权产品线：iWork平台（数字化车间应用系统）、iDevCloud设备云平台和iDAT数据采集盒。2017年初，沙塔信息推出自主研发的数字化车间应用系统，并针对工业PaaS、机联网、智能制造和智慧工业提出多项解决方案。2022年12月，沙塔信息凭借"面向机加工行业的工业互联网平台解决方案"获得第四届中国工业互联网大赛全国总决赛三等奖，并获评宁波市优秀工业互联网平台、市智能制造优秀系统解决方案供应商、省级产业数字化服务商等荣誉。2021年，沙塔信息上榜"2021年度宁波创业创新风云榜"。

**浙江宇丰信息技术有限公司**是贝毅君2023年1月创办的第二家产业实体，由贝毅君亲自担任法定代表人，注册资本1000万元人民币。宇丰信息代表了贝毅君将工业大数据研究与大模型技术融合的最新探索。该公司拥有"宇丰"品牌下完整的工业软件产品矩阵，包括ERP系统、BI可视化分析系统、WMS系统、生产培训平台、工业互联网平台链接系统、工业设备监测集群管理平台、车间生产线分析系统、VR设备管理系统等16项软件著作权和7项专利。值得关注的是，宇丰信息在2025至2026年间获得多项与大模型相关的发明专利授权，包括"基于大语言模型的工业数据智能查询方法及系统"（2026年5月授权）、"基于大模型的工业HMI生成方法与系统"（2025年12月授权）、"一种基于大模型和MES系统的生产异常预测方法及系统"（2026年2月公开）等，显示出贝毅君正将大模型技术深度引入工业制造场景。此外，宇丰信息还拥有"一种工业边缘网关的数据传输方法及系统""一种工业边缘网关的智能数据采集方法及系统"等边缘计算相关专利，以及"一种基于虚拟现实的汽车零件组装培训方法及系统"等VR/AR工业应用专利。该公司于2025年进入宁波市科技型中小企业名单，并参与了市级重点行业中小企业数字化改造试点项目。

在项目层面，贝毅君主持和参与了多项与工业大数据直接相关的国家级和省部级项目，包括国家重点研发计划、国家核高基计划、国家自然科学基金、浙江省重点研发计划、浙江省公益技术应用研究等。其研究成果获浙江省科技进步一等奖1项、宁波市科技进步三等奖1项，出版战略新兴产业教材《RFID技术在物联网中的应用》，完成教育部产学合作专业综合改革项目2项。

### 5.2 智能制造与产业生态

贝毅君在智能制造领域的产业生态布局呈现出"学术研究-技术咨询-产业落地"三位一体的特征：

**浙江省智能制造专家委员会**：作为该委员会专家，贝毅君直接参与浙江省智能制造政策咨询、项目评审和技术指导工作。浙江省是中国制造业大省，智能制造是省级战略重点，贝毅君的专家身份使其能够将最新研究成果快速对接产业需求。2022年，贝毅君在"工业互联网赋能企业数字化转型升级"高级研修班和"智能制造技术及应用高级研修班"中担任授课专家，向宁波市制造业企业技术骨干讲授工业大数据如何赋能智能制造，包括数据建模、专题模块分析等内容，并结合宁波本土企业成功案例进行讲解。

**宁波市产业生态**：贝毅君的产业活动以宁波为核心阵地。宁波是中国重要的制造业基地和工业互联网创新高地，2021年软件业收入达593.9亿元。贝毅君通过沙塔信息和宇丰信息两家公司，深度参与宁波工业互联网生态建设，与蓝卓、数益工联、创元信息等本地工业互联网企业共同构成宁波工业软件产业集群。沙塔信息获评省级产业数字化服务商，宇丰信息参与市级中小企业数字化改造试点项目，两家公司在宁波工业互联网产业链中扮演技术服务商和系统集成商角色。

**产学研合作网络**：贝毅君的产学研合作网络涵盖多个层面。在企业层面，与宁波和利时智能科技有限公司等工业自动化企业建立合作关系；在协会层面，与宁波市软件行业协会保持密切互动，协会会长夏建峰亲自为贝毅君授课的高级研修班致辞；在政府层面，与宁波市经信局、宁波市人力资源和社会保障局等部门有项目合作；在高校层面，依托浙江大学软件学院和浙江大学宁波科创中心，参与市校合作项目。2025年2月宁波市人民政府与浙江大学全面深化战略协议签约后，贝毅君的产学研合作获得了更大的政策支撑。

**国家重点研发计划项目**：贝毅君作为课题三负责人参与"面向共同富裕的公共服务普惠供给技术及应用"国家重点研发计划项目，标志着其产业合作从工业制造领域向公共服务领域的拓展。该项目以共同富裕为目标，研究公共服务普惠供给技术，贝毅君负责的课题三预计聚焦于数字化技术如何支撑公共服务的普惠化与均等化，这与其在工业互联网和大数据领域的技术积累形成互补。

## 七、Connection圈层总结

**核心圈层（VIPA课题组）**：贝毅君的学术核心圈层以浙江大学VIPA课题组为中心。课题组负责人宋明黎教授（浙江大学计算机科学与技术学院教授、博士生导师，视觉感知教育部-微软重点实验室副主任）是贝毅君最核心的学术合作伙伴，两人共同署名发表了包括人脸防伪检测数据集、ACM MM评测基准、ICML AIGC伪造识别、ICCV伪造图像识别等多项重要论文。冯尊磊副教授（浙江大学软件学院副教授）是贝毅君在软件学院方向最密切的合作伙伴，两人共同构建了CHN-DF中文人脸视频防伪数据集，并联合培养了多名研究生。其他核心成员包括宋杰（副教授，金融智能与数据理解方向）、雷杰（参与多项人脸防伪与病理AI论文）、金苍宏（软件学院教师）等。

**学生圈层**：贝毅君培养的学生分为学术型和产业型两类。学术型学生以高克威、娄恒瑞、刘尔腾、郭松源、赵卓阳、林森等为代表，主要在人脸防伪检测、迁移学习、行为识别、病理AI等方向开展研究，多篇论文发表于Pattern Recognition、ACM MM、ICML、ICCV等顶级期刊和会议。产业型学生以钟钊瑜（沙塔信息法定代表人）、罗森（宇丰信息核心成员）等为代表，将贝毅君在工业大数据和制造服务领域的研究成果转化为实际产品和解决方案。这种"学术+产业"双轨制培养模式是贝毅君学生培养的显著特征。

**产业圈层**：贝毅君的产业合作网络以宁波为中心，以沙塔信息和宇丰信息两家公司为载体，覆盖工业互联网平台、数字化车间、工业大数据分析、大模型工业应用等多个层面。作为浙江省智能制造专家委员会专家，贝毅君在浙江省制造业数字化转型中扮演技术与政策桥梁角色。其产业合作涵盖宁波和利时智能科技有限公司、捷创研究院、宁波市软件行业协会、宁波市经信局等多个企业和机构，形成了从技术研发、产品落地到政策咨询的完整产业生态链。

**学术-产业跨界圈层**：贝毅君的独特定位在于其横跨学术研究与产业应用的双重身份。一方面，他作为VIPA课题组成员参与人脸防伪检测和病理AI等前沿视觉智能研究，发表了Pattern Recognition、ACM MM、ICML、ICCV等顶刊顶会论文；另一方面，他通过创办和运营科技公司，将工业大数据研究成果转化为数字化车间和未来工厂的实际应用，相关成果获浙江省科技进步一等奖。近年来，贝毅君更将大模型技术引入工业制造场景，在宇丰信息开展基于大语言模型的工业数据智能查询、大模型驱动的工业HMI生成等前沿探索，展现出学术研究与产业创新深度融合的发展态势。
