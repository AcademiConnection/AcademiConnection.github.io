## 二、教育背景与职业履历

宋杰的学术道路横跨四川大学与浙江大学两所国内顶尖高校，其成长轨迹体现了从本科基础训练到博士阶段深耕前沿的完整学术培养链条。2015年6月，他在四川大学计算机科学与技术学院获得工学学士学位。四川大学计算机学科历史悠久，在计算机软件与理论、信息安全等方向具有深厚积淀，为宋杰打下了扎实的工程基础和系统思维。本科毕业后，他进入浙江大学计算机科学与技术学院攻读工学博士学位，师从宋明黎教授，于2020年6月获得工学博士学位。

宋明黎教授是浙江大学计算机科学与技术学院教授、博士生导师，VIPA（Vision Intelligence and Pattern Analysis）课题组负责人，同时担任视觉感知教育部-微软重点实验室（浙江大学）副主任。宋明黎教授于浙江大学获得计算机科学与技术博士学位，本科毕业于西北工业大学，2004年获微软研究奖学金（Microsoft Research Fellowship），研究方向涵盖计算视觉、模式识别、机器学习、嵌入式机器视觉和视觉交互，在IEEE T-PAMI、IEEE T-IP、CVPR、ECCV、ACM MM等顶级期刊和会议上发表论文200余篇。宋明黎教授是IEEE高级会员和ACM专业会员，担任Information Sciences和Neurocomputing副主编，以及ICML、NeurIPS、ICLR、ECAI、AAAI等多个顶级会议的领域主席。宋杰在博士期间师从宋明黎教授，深度参与了VIPA课题组在知识蒸馏、模型安全、高效深度学习等方向的研究工作，这段经历奠定了其后续学术发展的核心方向。

博士毕业后，宋杰留校任教，任职于浙江大学软件学院，担任副教授、博士生导师。浙江大学软件学院是国家级示范性软件学院，在人工智能、大数据、计算机视觉等方向具有雄厚的科研实力。宋杰在软件学院归属于"视觉智能与数据挖掘团队"，该团队负责人为宋明黎教授，核心成员包括陈纯教授（中国工程院院士）、王灿教授、冯雁副教授、叶德仕副教授、冯尊磊副教授、陈佳伟百人计划研究员、宛袁玉百人计划研究员等。宋杰在团队中聚焦于计算机视觉与人工智能安全方向，同时也是团队在模型轻量化和高效推理领域的核心骨干。

在职业发展过程中，宋杰的研究方向从博士阶段的知识蒸馏和模型安全，逐步扩展到多模态推理加速、模型轻量化部署、无线智能通信等前沿领域。他主持了国家自然科学基金项目、浙江省基础公益项目、之江实验室开放课题、CCF-百度松果基金等多项国家级和省部级课题，并作为核心成员参与科技创新2030"新一代人工智能"重大项目。他的研究成果获得了2023年度中国人工智能学会吴文俊人工智能科学技术进步一等奖，个人也入选宁波市"甬江育才工程"领军人才。截至2026年，宋杰已在国际顶级期刊和会议上发表论文70余篇，成为VIPA课题组中产出最为丰硕的青年学者之一。

## 三、学生培养情况

宋杰作为博士生导师，在高效深度学习、可解释人工智能、知识蒸馏、多模态推理等方向培养了一批优秀研究生。他的学生广泛参与NeurIPS、CVPR、IJCAI、AAAI等顶级会议的论文发表，在可解释AI、知识蒸馏、模型加速等前沿方向产出了多项代表性成果。以下列举若干代表性学生及团队成员。

### 1. 黄启涵（博士研究生，可解释AI与概念学习方向）

黄启涵是宋杰指导的博士研究生，也是VIPA课题组在可解释人工智能方向的代表性学生。他作为第一作者在NeurIPS 2024发表论文"LG-CAV: Train Any Concept Activation Vector with Language Guidance"，提出了利用视觉语言模型高效训练概念激活向量的方法，拓展了概念激活向量的应用场景，合作者包括宋杰、薛梦琦、张皓飞、胡秉德、王慧琼、姜昊（阿里巴巴集团）、王新根（浙江邦胜科技股份有限公司）和宋明黎。此外，他还在IJCAI 2024作为第二作者发表论文"ProtoPFormer: Concentrating on Prototypical Parts in Vision Transformers for Interpretable Image Recognition"，将原型学习引入Vision Transformer以实现可解释图像识别。黄启涵的研究方向聚焦于将大语言模型与可解释性技术相结合，代表了宋杰团队在可解释AI前沿的最新突破。

### 2. 薛梦琦（博士研究生，可解释AI与原型学习方向）

薛梦琦是宋杰和宋明黎联合指导的博士研究生，在可解释深度学习方向有多篇高水平产出。她作为第一作者在IJCAI 2024发表论文"ProtoPFormer: Concentrating on Prototypical Parts in Vision Transformers for Interpretable Image Recognition"（合作者包括黄启涵、张皓飞、Jingwen Hu、宋杰、宋明黎、金苍洪），提出了基于原型部件的Vision Transformer可解释图像识别框架。该工作将原型学习与Transformer架构深度融合，在保持高性能的同时显著提升了模型决策过程的可解释性。薛梦琦还参与了NeurIPS 2024的LG-CAV论文工作。她的研究体现了宋杰团队在可解释人工智能方向从概念激活到原型部件的系统化推进。

### 3. 邱天（博士研究生，神经网络优化与降噪方向）

邱天是宋杰指导的博士研究生，在神经网络通道降噪方向有代表性产出。他作为第一作者在NeurIPS 2024发表论文"Dual-Perspective Activation: Efficient Channel Denoising via Joint Forward-Backward Criterion for Artificial Neural Networks"（合作者包括高晨超、冯尊磊、雷杰、胡秉德、王新根、高艺、宋明黎），提出了一种端到端可训练的双视角激活（DPA）机制，结合前向传播和反向传播的双重视角，在线建立联合判据并实时更新，有效解决了人工神经网络中的通道噪声干扰问题。该工作汇聚了浙江大学、大连理工大学和浙江工业大学的力量，展示了宋杰团队在跨机构合作培养方面的能力。邱天的研究方向聚焦于神经网络内部机制的深层理解与优化，代表了宋杰团队在深度学习理论基础方向的探索。

### 4. 胡秉德（博士研究生，多模态与可解释AI方向）

胡秉德是宋杰指导的博士研究生，作为核心合作者参与了团队多项重要研究。他同时出现在NeurIPS 2024的两篇论文（LG-CAV和DPA）作者列表中，是宋杰团队中跨方向产出最为密集的学生之一。胡秉德的研究横跨可解释人工智能与神经网络优化两个方向，体现了宋杰在培养学生时注重多方向交叉融合的理念。他的参与工作涵盖了从概念激活向量的语言引导训练到双视角通道降噪等多个前沿课题。

### 5. 张皓飞（研究生，可解释AI方向）

张皓飞是宋杰团队的研究生，在可解释深度学习方向有多篇合作产出。他作为合作者参与了IJCAI 2024的ProtoPFormer论文和NeurIPS 2024的LG-CAV论文，两篇论文均聚焦于将可解释性技术引入深度神经网络。张皓飞的研究方向围绕原型部件学习和概念激活向量展开，与黄启涵和薛梦琦形成了紧密的研究小组，体现了宋杰团队在可解释AI方向的系统性布局。

### 6. 王慧琼（研究生，可解释AI方向）

王慧琼是宋杰团队的研究生，参与了NeurIPS 2024论文LG-CAV的研究工作。该论文汇聚了浙江大学（黄启涵、宋杰、薛梦琦、张皓飞、胡秉德、王慧琼）、阿里巴巴集团（姜昊）和浙江邦胜科技股份有限公司（王新根）的研究力量，展示了宋杰团队在产学研协同培养方面的特色。王慧琼的研究方向聚焦于利用视觉语言模型增强深度神经网络的可解释性。

### 7. 李平（博士研究生，知识蒸馏与动作识别方向）

李平是宋杰和宋明黎联合指导的博士研究生，在知识蒸馏方向有代表性产出。他作为第一作者发表了论文"Channel-wise Dynamic Knowledge Distillation via Adaptive Sample Generation for Action Recognition"（合作者包括Ping Chenhao、宋杰、宋明黎），提出了一种自适应样本感知的通道动态知识蒸馏方法（ASCD），通过自适应样本生成模块和通道动态蒸馏模块，在UCF101、Kinetics-400、Something-Something-v2等视频基准和CIFAR-100、ImageNet等图像数据集上展现了最优性能。该工作体现了宋杰团队在知识蒸馏方向的持续深耕，从早期模型复用和知识聚合发展到通道级动态蒸馏的精细化管理。

### 8. 陈凯旋（Kaixuan Chen，研究生，强化学习方向）

陈凯旋是宋杰和宋明黎联合指导的研究生，参与了强化学习方向的研究。他作为合作者参与了论文"Ask-AC: An Initiative Advisor-in-the-Loop Actor-Critic Framework"（合作者包括刘顺宇、Wang Xinchao、Yu Na、宋杰、陈凯旋、冯尊磊、宋明黎），提出了一种主动式的顾问参与Actor-Critic框架，允许智能体在不确定状态下主动寻求顾问干预，在静态和非静态环境中显著提升了学习效率。该工作展示了宋杰团队在强化学习与高效学习范式方向的探索。

## 五、业界合作关系深度分析

### 5.1 核心产业合作伙伴

宋杰的产业合作网络覆盖互联网科技、电力能源、人工智能基础设施等多个领域，体现了其研究从理论到应用的完整转化链条。

**阿里巴巴集团（核心产业合作伙伴）：** 阿里巴巴是宋杰最重要的产业合作方之一。在NeurIPS 2024论文"LG-CAV: Train Any Concept Activation Vector with Language Guidance"中，阿里巴巴集团的姜昊（Hao Jiang）作为合作者参与，该工作将视觉语言模型技术应用于概念激活向量的高效训练。更为瞩目的是，2026年浙江大学宋明黎教授团队与阿里巴巴集团安全部联合提出了MetaCompress——一套面向多轮视觉问答的学习式Token压缩框架，被CVPR 2026录用。该框架仅根据输入图像本身即可生成最优压缩映射，在高达90%的Token压缩率下精度优于主流方法，为多模态大模型的高效部署提供了关键技术支撑。宋杰作为VIPA课题组核心成员深度参与了这一与阿里巴巴安全部的合作研究。此外，浙江大学是AFAC2023金融智能挑战赛的联合举办方之一（与蚂蚁集团旗下蚂蚁财富、蚂蚁保、网商银行以及上海交通大学、西安交通大学、中央财经大学等联合举办），宋杰所在的团队在这一校企合作的金融AI赛事中发挥了学术支撑作用。

**南方电网（重大产业合作）：** 宋杰作为第5完成人（共15人）参与了"基础模型与知识融合的复杂电力巡检视觉智能分析关键技术及应用"项目，该项目荣获2023年度吴文俊人工智能科学技术进步一等奖。该项目的完成单位包括南方电网数字电网研究院有限公司、浙江大学、清华大学深圳国际研究生院、商汤集团有限公司、广东电网有限责任公司和中国南方电网有限责任公司，体现了电力行业与高校、AI企业的深度产学研融合。项目聚焦设备巡检领域的机巡视觉智能识别和大规模电力系统网络智能分析与优化计算，将基础模型技术与知识融合方法应用于复杂电力巡检场景，是国家重点研发计划、国家发改委新一代人工智能标杆工程和工信部人工智能产业创新任务揭榜挂帅任务的支撑成果。宋杰在该项目中承担了视觉智能分析关键技术的研发工作，是其将计算机视觉研究应用于国家重大产业场景的代表性产出。

**之江实验室（新型研发机构合作）：** 宋杰主持了之江实验室开放课题项目。之江实验室是浙江省人民政府主导举办的新型研发机构，聚焦智能科学与技术的前沿研究。宋杰与之江实验室的合作体现了其在人工智能基础设施和前沿技术方向的参与。在团队层面，冯尊磊等同事也与浙江实验室（Zhejiang Lab）有密切合作（如视觉边界知识迁移论文），形成了课题组与之江实验室在视觉智能领域的系统化合作通道。

**百度（CCF-百度松果基金项目）：** 宋杰主持了CCF-百度松果基金项目。该项目是中国计算机学会与百度联合设立的科研资助项目，旨在支持人工智能领域的前沿基础研究。宋杰获得该项目资助，体现了其在高效深度学习和模型轻量化方向的研究受到产业界认可，也代表了其与百度在AI技术方向的科研合作。

### 5.2 产业应用落地方向

宋杰的产业合作不仅涵盖多个行业，更在具体技术落地方向上形成了清晰的应用转化路径。

**多模态大模型高效部署方向：** 与阿里巴巴集团安全部合作的MetaCompress框架（CVPR 2026）是宋杰在多模态大模型推理加速方向的标志性产业应用成果。该技术解决了多轮视觉问答场景下的Token压缩问题，通过轻量级元生成器实现端到端的压缩映射学习，在90%压缩率下保持精度，推理效率与基线方法持平。这一技术对于降低多模态大模型的部署成本、提升端侧推理效率具有直接产业价值，可应用于智能客服、视觉交互、内容审核等阿里巴巴核心业务场景。宋杰在个人主页中将"多模态推理加速"和"模型轻量化部署"列为首要研究方向，与其产业合作方向高度一致。

**电力行业智能巡检方向：** 通过与南方电网的合作，宋杰将计算机视觉和基础模型技术应用于电力设备巡检的视觉智能识别。该项目覆盖了无人机巡检中的目标检测、缺陷识别、场景理解等关键环节，将深度学习模型部署到边缘计算设备上实现实时巡检分析。这一方向的研究成果已在中国南方电网的实际巡检业务中得到应用，获中国电力科技创新一等奖、广东省科技进步二等奖等多项行业奖励，是宋杰将学术研究转化为国家重大基础设施应用的重要案例。

**金融科技方向：** 浙江大学作为AFAC2023金融智能挑战赛的联合举办方，宋杰所在团队参与了赛事的学术组织工作。该赛事由蚂蚁集团发起，聚焦"金融数据验真"、"金融数据理解"和"金融场景理解"三大方向，吸引了4728支队伍参赛。宋杰团队在金融AI场景的技术积累和学术影响力为赛事提供了学术支撑，同时也为后续与蚂蚁集团在金融科技方向的深入合作奠定了基础。

**可解释AI产业应用方向：** 宋杰在可解释人工智能方向的系列研究成果（包括NeurIPS 2024的LG-CAV和IJCAI 2024的ProtoPFormer）具有直接的产业应用价值。概念激活向量和原型部件学习技术可用于AI模型决策过程的透明化和可审计化，在金融风控、医疗诊断、安全审查等对模型可解释性有高要求的场景中有广阔应用前景。与阿里巴巴集团和浙江邦胜科技股份有限公司的合作，正是推动可解释AI技术从实验室走向产业落地的重要通道。

**知识蒸馏与模型压缩方向：** 宋杰在知识蒸馏方向的长期研究积累（从早期的知识聚合到近期的通道动态蒸馏）为模型轻量化部署提供了核心技术支撑。其指导的学生李平在动作识别知识蒸馏方向的最新成果，以及宋杰主持的CCF-百度松果基金项目，均聚焦于将大模型知识高效迁移至小模型的技术路径，在端侧AI部署、边缘计算等产业场景中有直接应用价值。

## 七、Connection圈层总结

宋杰的学术关系网络以浙江大学VIPA课题组为圆心，逐层向外辐射，形成了层次分明、虚实结合的学术合作生态。

**第一圈层（导师与核心团队）：** 以宋明黎教授为核心的VIPA课题组和视觉智能与数据挖掘团队构成宋杰学术网络的第一圈层。这一圈层包括博士导师宋明黎教授（最核心的合作者与学术引路人）、团队学术带头人陈纯院士（顶层学术引领）、以及团队核心成员王灿教授、冯尊磊副教授、冯雁副教授、叶德仕副教授、陈佳伟研究员、宛袁玉研究员等。第一圈层的特征是共享研究平台、联合指导学生、共同承担重大项目，是宋杰学术产出最密集的合作圈层。在论文合作上，宋杰几乎所有顶级会议论文均有宋明黎作为合作者，体现了师承关系的深度绑定。

**第二圈层（指导学生与团队校友）：** 宋杰直接指导的博士和硕士研究生构成第二圈层的核心，包括黄启涵、薛梦琦、邱天、胡秉德、张皓飞、王慧琼、李平、陈凯旋等。这些学生是宋杰学术产出的第一作者主力，在NeurIPS、IJCAI等顶级会议上以第一作者身份发表多篇论文。此外，团队校友如雷杰（现浙江工业大学助理研究员）也属于这一圈层，他们从VIPA课题组出发走向其他高校，保持了跨机构的学术协作关系。第二圈层的特征是以宋杰为导师或联合导师的学生培养链条，以及通过校友网络维持的学术传承。

**第三圈层（浙江大学内部合作者）：** 除VIPA课题组成员外，宋杰在浙江大学内部还与软件学院、计算机学院的其他学者保持合作，如金苍洪等。此外，浙江大学软件学院常务副院长尹建伟教授（2002届浙大计算机应用技术博士、国家杰出青年基金获得者）所在团队与蚂蚁集团联合完成的"面向金融场景的可信高效机器学习平台研发与应用"项目也获2023年吴文俊人工智能科学技术奖，体现了软件学院在金融AI方向的团队化布局。宋杰作为软件学院教师，在这一更宽泛的学院合作生态中发挥其在视觉智能方向的独特作用。

**第四圈层（跨机构与产业合作者）：** 这一圈层包括国际合作伙伴（美国斯蒂文斯理工学院Wang Xinchao教授）、跨校合作者（大连理工大学高晨超、南京大学张利军等）和产业合作伙伴（阿里巴巴集团姜昊、浙江邦胜科技王新根、南方电网数字电网研究院、商汤集团、之江实验室、百度等）。第四圈层的特征是围绕具体项目或论文形成的任务型合作，既包括学术前沿的国际协作（如可解释AI和元学习方向与Wang Xinchao的合作），也包括产业落地的产学研融合（如与阿里巴巴在多模态大模型方向的MetaCompress合作、与南方电网在电力巡检方向的吴文俊奖项目合作）。这一圈层是宋杰将学术研究转化为社会价值的关键通道，也是其学术网络持续扩展的外围动力来源。

总体而言，宋杰的学术关系网络呈现出"以师承为根基、以学生为延伸、以团队为依托、以产业为外延"的典型青年学者成长模式。作为2020年获得博士学位的年轻副教授，他已在短短数年间构建了覆盖国际-国内-校内-团队四个维度的合作网络，在NeurIPS、CVPR、IJCAI等顶级会议上持续产出，并与阿里巴巴、南方电网等头部企业建立了实质性的产学研合作关系，展现出强劲的上升势头和广阔的发展前景。
