## 团队概况

章国锋组是浙江大学CAD&CG全国重点实验室混合现实研究团队（团队负责人鲍虎军教授）中的SLAM/三维重建/增强现实方向核心力量，与GitHub开源组织 zju3dv、OpenXRLab 扩展现实开源平台深度绑定。章国锋教授为全国百篇优博与CCF优博获得者、国家杰出青年科学基金获得者，与鲍虎军教授构成 zju3dv 大团队的双核心。

产业转化是该组最鲜明的标签：2025年章国锋创立影溯科技（InSpatio，2025年4月24日工商注册、7月正式运营），2026年完成数千万美元Pre-A轮融资（光合创投、顺为资本、红杉中国等投资），先后开源 InSpatio-WorldFM（无限时长3D世界模型）与 InSpatio-World（实时4D世界模型，WorldScore-Dynamic实时/交互级榜首），成为国内空间智能赛道的头部创业公司。谢天副研究员则代表团队的应用系统落地路线，其VTS智能驾驶虚拟仿真平台与OnSite自动驾驶挑战赛构成"仿真平台-竞赛评价-产业对接"的产学研闭环。

## 学术谱系概览

章国锋为浙大本土培养（2003本科—2009博士—留校任教），博士导师归属未见原始文献直接确认（长期与鲍虎军构成双核心合作）。下游人才网络中，陈硕（AFM微纳三维重建，成果入选《Nature Reviews Materials》研究亮点）为其官方确认的在读博士生；朱子涵（NICE-SLAM第一作者）师从鲍虎军/许威威；宋友盛（NICE-SLAM第二作者）现为Google DeepMind研究科学家。谢天为"浙大本科—浙大博士—休斯顿大学博士后—之江实验室—回归浙大"的循环型路径。
