# 北京大学视频与视觉技术国家工程研究中心团队 学术网络报告

本目录收录北京大学视频与视觉技术国家工程研究中心（NERCVT，前身为数字视频编解码技术国家工程实验室）三位核心学者——高文院士、黄铁军教授与马思伟教授的学术关系网络报告。该团队以"视频编码—视觉理解—智能算力"三位一体为格局：高文院士作为中心主任、AVS工作组组长和鹏城实验室主任，创立了中国自主视频编解码标准体系AVS并领衔研制鹏城云脑；黄铁军教授作为中心副主任、多媒体信息处理全国重点实验室主任和北京智源人工智能研究院理事长，在AVS标准（秘书长）、脉冲视觉与大模型方向持续突破；马思伟教授作为中心副主任、AVS视频组长，是高效视频编码与超高清视频系统方向的学术传承核心。

三人的关系结构需要注意清晰界定：高文是马思伟（中科院计算所，2005年博士）和田永鸿的博士导师，是明确的师生传承脉络；而黄铁军并非高文的学生——黄铁军本硕毕业于武汉工业大学、博士毕业于华中理工大学，1999—2001年在高文实验室从事博士后研究，与高文构成"AVS工作组组长—秘书长"的长期合作搭档关系。团队通过AVS系列标准、鹏城云脑、脉冲视觉三条主线，将北大本部、鹏城实验室、中科院计算所（高文1997年创建VIPL研究组，现由陈熙霖接棒）连接为国内视频与视觉技术领域最具影响力的学术网络之一。

## 研究方向与圈层结构概述

团队研究主线覆盖三条互补脉络：其一，视频编码标准链（高文—马思伟—王苫社），从AVS1到AVS3再到面向8K+5G的新一代标准，并向国际标准（DVB、IEEE 1857、VVC提案）延伸；其二，视觉信息处理与类脑计算链（黄铁军—田永鸿—余肇飞），以脉冲连续摄影原理、视觉特征压缩、SpikeCV开源框架为代表；其三，智能算力与平台链，以高文、田永鸿牵头的鹏城云脑和黄铁军主导的智源研究院（Emu3、FlagOS）为两大平台出口。

圈层结构上，第一圈层为北大中心核心传承圈（马思伟、田永鸿、王苫社、王荣刚及长期合作者黄铁军）；第二圈层为中科院计算所VIPL学术网络（陈熙霖、山世光），构成北大—计算所视觉联盟；第三圈层为鹏城实验室与智源研究院的平台生态；第四圈层为产业生态圈；第五圈层为国家标准与科技战略圈。马思伟报告中同时强调边界：鹏城云脑由高文、田永鸿团队牵头，马思伟牵头的"视觉感知编解码关键技术及超高清视频产业化应用"（2025年度国家科技进步二等奖）为另一独立获奖项目，华为仅为中心层面的可核查产业关联。

## 产业转化亮点

- **AVS标准产业化生态**：AVS3纳入DVB核心规范，支撑央视4K/8K频道、北京冬奥会8K直播；专利池每台终端仅收1元，终结国外高额专利费；学生王苫社创办博雅睿视，发布首颗自研AVS3视觉智算芯片SPARK RE3200。
- **鹏城云脑与昇腾生态**：首个全面自主可控E级AI算力平台，连续获IO500、AIPerf500全球第一，带动昇腾芯片出货超100万片，支撑讯飞星火、移动九天等超半数国产大模型训练，获2025年度国家科技进步一等奖。
- **脉冲视觉转化**：北大孵化脉冲视觉（北京）科技有限公司，超高速脉冲相机已在运营高铁、6马赫风洞中验证，获2024年日内瓦发明展金奖，并与北京市人形机器人创新中心合作具身视觉。
- **视觉特征压缩**：黄铁军、田永鸿技术体系应用于百度、腾讯、海信产品及30多个城市视频联网，获2017年国家技术发明二等奖。
- **超高清全链条应用**：马思伟团队与联想（裸眼3D全息通信）、咪咕（沉浸式视频）等有可核查合作。
