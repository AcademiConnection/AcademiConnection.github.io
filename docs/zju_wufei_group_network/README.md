# 浙江大学 吴飞团队（跨媒体智能/多模态）学术关系网络报告

> 报告生成时间：2026年8月24日
> 报告组标识：ZJU-WUFEI

## 团队说明

本报告组对应第五批第6组"浙大吴飞组（多模态——挂浙大，放这里提醒）"。吴飞教授为浙江大学求是特聘教授、国家杰青（2016），现任浙江大学本科生院院长，曾任浙江大学人工智能研究所所长、上海高等研究院常务副院长，主要研究方向为人工智能、多媒体分析与检索、跨媒体计算、统计学习理论与端云协同机器学习。其学术谱系上承潘云鹤院士与庄越挺教授开创的浙大跨媒体计算学派。已核查浙大既有报告目录（arclab、baohujun、cadcg、fast、jinxiaogang、kg、vipa、xuweiwei、yyc、zhangguofeng、zhaozhou、zhoukun、zhouxiaowei），吴飞团队此前未被覆盖，无重复。

因吴飞团队核心为"庄越挺→吴飞→赵洲"跨媒体学派传承链（吴飞现任行政职务以本科生院院长为主），本组报告以吴飞为轴心，补充其师承源头庄越挺教授（浙大跨媒体计算学派奠基者）共同成篇。赵洲已在独立目录（`../zju_zhaozhou_faculty_network/`）单独成篇，肖俊在 CAD&CG 目录（`../zju_cadcg_faculty_network/`）单独成篇。

2026年8月25日第二批补录：况琨、张圣宇两位团队核心成员升级为独立报告；另补录谱系外围成员余宙（现为杭州电子科技大学教授、计算机学院副院长，浙大博士校友，国家优青，与吴飞团队保持合作）。重要更正：况琨并非吴飞博士生，其为清华大学博士（2019，导师杨士强/崔鹏），与吴飞为团队紧密合作者——吴飞、庄越挺两份既有报告中的相关表述已同步修正。

## 团队核心脉络

**吴飞**：兰州大学本科（1992-1996）、澳门大学硕士（1996-1999）、浙大博士（1999-2002，师从庄越挺，据公开资料推断）、UC Berkeley统计系访问学者（2009-2010，郁彬课题组，经主页英文版核实）。2002年留校任教，2011年教授。国家杰青（2016）、CAAI会士、国务院学位委员会智能科学与技术学科评议组成员、教育部101计划《人工智能引论》负责人。代表成果：智海新一代人工智能科教平台（2020年发布）、智海-三乐教育大模型（联合高教社、阿里云）、敦煌残片缀合算法（与张涌泉团队合作，延伸至敦煌垂直领域大模型专利）、端云协同分布式机器学习系统。学生：张圣宇（2023浙大优博，已核实）、赵洲（教授，师承推断）、王永威等；况琨（清华博士）为团队核心合作者而非学生。

**庄越挺**：浙大本硕博（1986/1989/1998），UIUC访问学者师从Thomas S. Huang（1997-1998）。杰青（2005）、长江学者（2008）、973首席科学家、CAAI会士（2018）、CSIG会士（2019首批）、2025年3月当选CAAI副理事长。曾任浙大计算机学院院长（2009-2017）、人工智能研究所所长（2006-2015）。国家科技进步二等奖3次（2010年CADAL项目为第一完成人）。CADAL大学数字图书馆（250万册）技术总负责人。

**谱系关系**：何志均→潘云鹤（院士）/Thomas S. Huang（UIUC）→庄越挺→吴飞→赵洲/张圣宇等，构成浙大跨媒体计算学派的传承主线（师生关系均据公开资料推断并已在报告中标注）。CADAL项目将浙大与北大（高文、黄铁军、田永鸿）等高校连接，是跨校合作的重要节点。况琨（清华博士，导师杨士强/崔鹏）作为因果推断方向的团队核心合作者，与吴飞联合获得吴文俊人工智能科技进步一等奖（智慧司法项目）；余宙（杭电）经ANetQA（CVPR 2023）联合署名与"跨媒体因果推断"课题与本团队保持谱系外围关联。
