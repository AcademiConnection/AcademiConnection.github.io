## 二、教育背景与职业履历

张圣宇本科毕业于武汉大学，2018年9月以暑期实习优胜生身份从武汉大学保送浙江大学，成为吴飞教授的直博生（其本人在浙江大学优博专访中明确致谢导师吴飞，导师吴飞亦撰文确认）。2021–2022年，他作为访问学者赴新加坡国立大学计算机学院 NExT++ 实验室交流，师从多媒体检索权威 Chua Tat-Seng（蔡达成）教授。2023年获浙江大学计算机科学与技术学院工学博士学位，博士学位论文《面向端云场景的因果启发深度学习算法研究》（官方喜报口径；部分宣传稿作“端云协同”）获评浙江大学2023届优秀博士学位论文。该论文提出"云向端因果泛化—端向云因果蒸馏—端云因果协同推断"的完整技术体系，解决大模型向海量端设备迁移中的虚假关联与泛化难题，是"因果机器学习×端云协同"交叉方向的代表性成果。

博士毕业后，张圣宇加入浙江大学软件学院，任平台"百人计划"研究员、博士生导师，成为吴飞"端云协同分布式机器学习系统"方向的学术传人。其研究从博士阶段的因果启发端云协同（云向端C2D、端向云D2C、端云协同推断C&D），演进为当前的大小模型协同进化、端侧智能体（GUI Agent、移动自动化）与跨媒体生成。代表性成果包括：端云协同综述《Edge-Cloud Polarization and Collaboration: A Comprehensive Survey for AI》（TKDE 2022，其博士阶段的领域奠基之作）、ModelGPT（大模型生成定制化小模型）、MergeNet（跨异构模型知识迁移）、EcoAgent（端云协同多智能体移动自动化框架）等。他亦作为发明人之一参与敦煌垂直领域大模型专利研发（与吴飞、张涌泉、严骏驰等，据专利著录）。2025年起，他作为论坛主席组织 ChinaLLM2026"大小模型端云协同技术"论坛、CSIG 2025"规模化与轻量化协同演进"技术论坛（与吴飞共同担任主席），并在智源社区等平台参与 Agent 前沿研讨，学术组织能力快速上升。
