# 中国科学技术大学 量子软件/量子算法交叉方向教师学术关系网络报告

> 报告生成时间：2026年8月26日

## 团队简介

中国科学技术大学是全球量子科研重镇，但其量子版图由多支体系构成：物理学院的潘建伟—陆朝阳团队（量子硬件与量子优越性，"九章"系列）、郭国平团队（量子物理/微电子体系，本源量子创始人，量子工程与产业化），以及计算机学院的量子软件交叉方向。本报告系列聚焦第三支——以张昱教授（S4Plus 研究组，量子编程系统与编译）为可确证代表的"量子计算 × 计算机科学"交叉力量，并纳入谈海生教授（算法与系统方向，"量子算法"邻接节点）。

需要明确的机构边界：该交叉方向不同于潘建伟团队与郭国平团队；张昱的谱系锚点是计算机学院陈意云（1946–2022）代表的程序设计语言/编译学派（合著《编译原理》国家级规划教材三版），而非陈国良高性能计算谱系（二者仅有合译《虚拟机》2009 的教材纽带）。其标志性成果是 Quingo 量子编程框架——国内五大自主量子编程框架之一（与华为 HiQ、本源 QPanda、软件所 isQ、量易伏并列），及 CODAR（DAC 2020）、QCIR（ICCAD 2022）、PauliForest（TCAD 2025）等量子编译系列论文；学生团队获首届天衍量子计算挑战赛专业组特等奖（2025）。谈海生则代表算法侧的弱连接：其官方履历（中科大本科—港大博士（导师 Francis C. M. Lau）—清华交叉信息院姚期智团队博后—暨南大学—2016 年入职中科大，现任特任教授、人工智能与数据科学学院副院长）以在线算法/边缘计算为主线，量子仅为项目合同与方向条目层面的接口。

## 研究方向与圈层结构概述

张昱的网络以"一条师承主线、一个研究组内核、三个辐射圈层"为结构。师承主线是陈意云编译学派——她从读博期间合著国家级规划教材起步，接掌《编译原理和技术》课程并牵头"101"计划教材《高级编译原理和技术》，成为该学派在中科大的第二代旗帜，其研究方法论即"用编译器与程序语言的方法吃每一个新兴计算平台"（虚拟化、边缘计算、量子、AI、云原生）。内核圈是 S4Plus 研究组的量子编程系统梯队（Quingo、CODAR、QCIR、PauliForest 及 2026 年与本源量子郭国平联合发表的 UCC 优化 TCAD 论文，张昱任通讯作者）。辐射圈层包括：院内智能感知团队（张燕咏、吉建民、李厚强，CVPR/MobiCom/OSDI 级合作与 IEEE P3184 标准共事）、国内量子共同体（CCF 量子计算专委执行委员，接入创始主任郭光灿、现任主任孙晓明的 CQCC 体系；与华为 HiQ、本源 QPanda、软件所 isQ 构成自主量子软件竞合网络）、国际程序语言圈（耶鲁访学、华盛顿大学 Michael D. Ernst 的 CGO 2025 合作、Eric Petit）及 ISO/IEC JTC 1/WG 14 量子计算标准体系。谈海生的网络则是"算法方法内核—网络/边缘系统应用—AI 教学与产业组织—量子算法项目接口"四层结构，作为经典算法优化与在线调度的连接节点接入量子方向的算法对话。

## 产业转化亮点

该方向的产业形态是"开源框架 + 标准制定 + 产业赛事"而非创业孵化：Quingo 生态（含 Quingo-runtime、DQCSim-QCIS 等）对接本源量子超导量子计算机的 QCIS 指令集，是国内量子软件自主可控路线的代表成果之一；张昱主持华为、龙芯、阿里巴巴、蚂蚁金服、微软、Intel 等企业创新合作项目，其中华为绑定最深（智能基座优秀教师奖、绿色计算大赛双特等奖、鲲鹏/昇腾教学生态），龙芯合作对准 LoongArch 国产指令集；其学生经天衍量子计算挑战赛（中国信通院主办，量子信息网络产业联盟、中电信量子、中科弧光、国盾量子承办）进入量子软件产业人才通道。标准化维度上，张昱任 ISO/IEC JTC 1/WG 14 量子计算工作组委员、IEEE P3184 副主席并牵头安徽省地方标准 2 部，与合肥作为国内量子计算标准制定重镇的产业地位相衔接。谈海生侧的产业连接（华为优秀高校合作项目、MSRA 项目资助、腾讯犀牛鸟、KubeEdge 专著生态）则属算法与系统的应用外溢，不涉量子产业链。
