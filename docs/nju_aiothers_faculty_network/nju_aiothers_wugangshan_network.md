## 一、学者基本信息

武港山（Gangshan Wu），男，1967年2月生，博士，南京大学计算机科学与技术系教授、博士生导师，南京大学多媒体教研室主任，现任**南京大学计算机学院、软件学院、人工智能学院联合党委书记**（主持党委全面工作，近年南大三院实行联合党委建制后的官方新闻口径；此前长期任人工智能学院党委书记）。他是南京大学媒体计算研究组（Multimedia Computing Group，MCG）的创建者与负责人，研究方向为媒体内容分析、多媒体信息检索、计算机视觉计算与智能信息处理。需要说明其**跨建制身份**：武港山的教授建制在计算机科学与技术系，而其行政职务在人工智能学院——他是2017年10月与李宣东（时任计算机系主任）共同提出"南京大学人工智能学科高峰计划"建设方案的两位署名人之一（人工智能学院官网院史记载），该方案直接催生了2018年人工智能学院（南京本部）的成立。

**教育与工作经历：**
- 1967年2月出生；博士学位（具体院校、年份与博士导师公开资料未披露，本报告不作推断）。
- 曾在台湾交通大学资讯工程学系进修。
- 长期任教于南京大学计算机科学与技术系，任教授、博士生导师、多媒体教研室主任；创建并领导MCG媒体计算研究组。
- 2018年起任南京大学人工智能学院党委书记；现以南院联合党委建制主持党委全面工作。

**博士导师：** 公开资料未披露。从论文署名看，其2008年前后的论文与南大多媒体方向前辈张福炎教授（南大多媒体教研传统开创者）共同署名，提示其学术根系在南大本部多媒体教研体系，但导师关系未获公开证实，本报告不作认定。

**研究主线与代表性贡献：**
1. **多媒体内容分析与检索：** 代表作MM'12《A bag-of-objects retrieval model for web image search》（与微软亚洲研究院Linjun Yang、李世鹏合作）提出面向Web图像搜索的对象袋检索模型，是其早期国际代表性工作；后续扩展至查询上下文图像相关性预测（IEEE Trans. Multimedia 2014）。
2. **图像/视频处理与立体视觉：** 2010年代前期围绕立体匹配、图像重定向、显著性检测、深度感知显著目标检测展开（ICCV 2015 StereoSnakes等），学生群体（琚燃、耿文静、徐向阳等）形成集中产出。
3. **视觉关系与场景图理解：** 2019-2025年与任桐伟、于凡（Fan Yu）等推进视觉关系检测（Visual Relation of Interest Detection等系列工作）。
4. **视频理解与视频恢复（依托MCG团队）：** 王利民2018年加入后，MCG在视频理解（TSN时代即有布局）、视频基础模型（VideoMAE、InternVideo系列）、目标跟踪（MixFormer）方向成为国内主力之一；武港山署名的视频恢复/超分辨率工作（RVRT等）与ETH Zurich团队联合完成。
5. **行业系统研发：** 主持数字博物馆、海量地质数据处理等系统研发，体现其"计算机应用技术与系统开发"底色。

**学术服务与荣誉：** 获1999年江苏省科技进步（科技成就）二等奖、2007年江苏省教学成果特等奖、2009年高等教育国家级教学成果二等奖。多次带队参加TRECVID国际评测（2009年起的DBLP记录）及NTIRE/AIM/VOT等国际挑战赛。

## 三、博士教育背景与导师追溯

### 3.1 学历与学术根系

武港山的博士教育履历（院校、年份、导师）在个人主页、学院页面及公开百科中均未披露，本报告不作推断。可确认的事实链有二：其一，其2000年即有DBLP记录，2003年起持续发表，学术成熟期始于南大计算机系任教期间；其二，其早期代表作（MM'12对象袋检索）及其学生（任桐伟2008年起的ICME/ICME'08论文）与南大多媒体教研传统（张福炎教授一系）存在明确的共同署名联系。因此其学术根系可稳妥地定位于**南京大学计算机系多媒体教研体系**。

### 3.2 MCG的组织者角色与代际结构

武港山并非单一论文导师，而是MCG的组织者与"根系教师"。研究组的代际结构如下：

```text
张福炎等南大多媒体教研前辈（教材与教研传统）
  └─ 武港山（教授，MCG负责人，1990年代起在南大多媒体方向成长）
       ├─ 任桐伟（副教授，2006年起共同署名，多媒体检索/视觉关系）
       ├─ 唐杰（副教授，2007年起共同署名，对象建模/并行计算）
       ├─ 王利民（教授，2018年自外部加入，视频理解/视频基础模型）
       │    └─ MCG视频理解方向博士生群体（2019年至今）
       └─ 历届博士生：琚燃、耿文静、徐向阳、于凡、高子腾、童湛、崔宇涛等
```

这一结构的特点是"教师层多核心、学生层多代际"：任桐伟、唐杰与武港山的合作跨越近二十年，属于南大自培养的稳定同事；王利民则是2018年引进的顶配学术力量（TSN/VideoMAE/InternVideo等方向国际主力），其加入使MCG整体产出进入全国第一梯队。武港山以党委书记的行政身份与研究组负责人的学术身份并行，体现"行政—学术"双轨。
