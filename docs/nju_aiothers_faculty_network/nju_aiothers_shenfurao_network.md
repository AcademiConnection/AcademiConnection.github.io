## 一、学者基本信息

申富饶（Furao Shen），男，1973年10月生，南京大学人工智能学院、计算机科学与技术系教授、博士生导师。现任**南京大学人工智能学院党委副书记**（分管教学；学院官网新闻及华东师大、江苏理工学院等兄弟院校来访新闻均以"党委副书记/副书记"称谓报道；2023年前后个别校级新闻稿亦有"副院长"称谓，本报告以官网新闻主流口径为准）。兼任科沃斯讲席教授、计算机软件新技术全国重点实验室成员、南京智能制造软件新技术研究院首席科学家；中国计算机学会（CCF）杰出会员；入选"创业南京"科技顶尖专家集聚计划A类专家。他是**自组织增量神经网络（SOINN，Self-Organizing Incremental Neural Network）的提出者**，是南大人工智能学院神经网络方向的代表性教师，长期全面统筹学院本科生与研究生教学工作。

**教育与工作经历：**
- 1991-1995年，南京大学数学系计算数学与应用软件专业，学士。
- 1995-1998年，南京大学数学系计算数学专业，硕士。
- 2000-2003年，日本FOURSIS株式会社高级研究员。
- 2003-2006年，日本东京工业大学智能系统科学专业，获工学博士学位；博士阶段在Osamu Hasegawa（长谷川修）实验室完成，与导师联合提出SOINN。
- 2003-2009年，先后任日本科学技术振兴机构（JST）研究员、日本学术振兴会（JSPS）21世纪COE项目研究员、JSPS特别研究员、JSPS外国人特别研究员。
- 2009年前后归国加入南京大学，历任量子物理与人工智能特聘教授、赵世良讲席教授、科沃斯讲席教授。
- 现任人工智能学院教授、党委副书记。

**博士导师：** 东京工业大学Osamu Hasegawa教授。其2004-2013年与Hasegawa的26次DBLP合作覆盖SOINN原始论文及其系列扩展，是典型的"师生—联合提出者"关系。

**研究主线与代表性贡献：**
1. **自组织增量神经网络（SOINN）：** 2006年与长谷川修在Neural Networks发表SOINN原始论文，提出能够在不遗忘旧知识条件下增量学习新模式的神经网络模型，是非平衡/在线增量学习方向的代表性工作，曾获IJCNN 2009特邀讲座专门介绍；后续V-SOINN（多维数据可视化）、不均衡学习SOINN等系列扩展持续至2023年。2023年在电子工业出版社出版专著《自组织增量学习神经网络》。
2. **IC神经元模型：** 领导研发的IC neuron模型发表于Neural Networks期刊（2022），以更少神经元构建网络，应用于深度神经网络结构优化。
3. **数据增强与类增量学习：** 2022年起团队在数据增强（Image Data Augmentation for Deep Learning: A Survey、EntAugment（ECCV 2024）、AdaAugment、RL-Selector（ICCV 2025））与少样本类增量学习（Dual Prototypes、Embedding Space Allocation、Free-Flow Increments等）方向形成集中产出。
4. **对抗攻防与视觉安全：** 与刘小亮、聂长海等合作的人脸识别对抗补丁攻击与防御系列（RSTAM、NeRFTAP、RADAP（Pattern Recognition 2024）等）形成应用导向的攻防研究线。
5. **机器人智能与产业应用：** UWB+LiDAR室内定位、双摆臂履带机器人深度强化学习控制、雷达脉冲分选、点云配准等应用研究；拥有20余项国家发明专利与4项国际专利。

**学术服务与荣誉：** 2021年获"南京大学计算机学科美德之星奖"；曾获教育部、联合国教科文组织颁发的优秀指导教师奖励；指导学生团队获中国国际大学生创新大赛全国金奖；获南京大学教授进中学报告金牌讲师等奖励。

## 三、博士教育背景与导师追溯

### 3.1 从数学到神经网络：本硕博的跨学科轨迹

申富饶的本硕训练均为南京大学数学系计算数学专业（1995/1998），这为其后来的神经网络模型数学化研究（SOINN的拓扑分析、联想记忆容量分析）提供了基础。1998年硕士毕业后进入日本产业界（FOURSIS株式会社高级研究员，2000-2003），随后于2003年进入东京工业大学智能系统科学专业攻读博士，2006年获工学博士学位。

### 3.2 东京工业大学：长谷川修实验室与SOINN的诞生

其博士阶段的实验室为Osamu Hasegawa（长谷川修）主持的智能系统实验室。SOINN（Self-Organizing Incremental Neural Network）由两人联合提出，2006年前后发表于Neural Networks，其核心思想——以增量方式在线生成/删除神经元、无需预知类别数、兼顾噪声鲁棒性与拓扑保持——成为其后申富饶二十年研究纲领的起点。DBLP记录显示两人2004-2013年合作26次，涵盖SOINN原始工作、在线学习扩展与机器人应用；申富饶在2005-2009年间的JSPS研究员身份也均在东京工业大学/JST体系内。

## 五、业界合作关系深度分析

### 5.1 科沃斯（Ecovacs）：讲席教授冠名

申富饶兼任**科沃斯讲席教授**。科沃斯是全球服务机器人头部企业（扫地机器人等家用机器人），以企业冠名讲席的形式与南大建立合作。这一讲席身份是其与机器人产业最直接的制度性连接；具体合作项目（联合研发、人才输送规模等）公开资料未披露。

### 5.2 南京智能制造软件新技术研究院：首席科学家

其兼任南京智能制造软件新技术研究院首席科学家，并入选"创业南京"科技顶尖专家集聚计划A类专家。该研究院面向智能制造产业的软件新技术转化，与其团队在机器人智能（UWB+LiDAR室内定位专利、履带机器人深度强化学习控制）方向的应用研究直接对应。

### 5.3 专利与成果转化

官方履历列示其拥有20余项国家发明专利与4项国际专利，代表案例如"一种融合UWB和LiDAR的室内定位方法"（2020年申请、2024年授权）。专利组合覆盖神经网络结构、室内定位、机器人控制等方向，是其实际产业连接的直接证据。
