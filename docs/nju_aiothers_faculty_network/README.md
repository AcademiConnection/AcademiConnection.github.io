## 全团队关系网络的整体观察

本组教师勾勒出南大人工智能学院"LAMDA之外"的另一半图景，其网络形态可分三类。第一类是**本土传承的行政与学派支柱**：武港山与申富饶均为学院创院元老——武港山是2017年"人工智能学科高峰计划"的两位署名人之一（与李宣东），其MCG研究组是南大多媒体方向的源头（王利民即出自该组，与王利民合作98次）；申富饶师承东京工业大学长谷川修，SOINN（自组织增量神经网络）使其成为南大神经网络方向的独立旗帜。第二类是**国际顶尖学者的引进网络**：Muggleton（ILP奠基人、皇家工程院院士）经由戴望州（其博士后，现智科院副院长）的学术通道加盟，为学院带来符号推理的国际纵深；陈开明作为Isolation Forest共同发明人与周志华保持了长达16年、21次合作的伙伴关系，是LAMDA谱系与国际机器学习社区的又一连接点；卓汉逵（杨强联合培养、Kambhampati博后）补齐了智能规划方向；Reeve（2025年入职）代表学院向机器学习理论的最新扩张。第三类是**R&L Group的双骨干**：史颖欢（高阳-史颖欢合作163次）与霍静（高阳-霍静151次）是高阳学派在医学影像与强化学习方向的执行主力，两人与祁磊、李文彬共同构成R&L的"内生培养—留校"梯队。

本组与LAMDA的关系呈"并行共生"形态：高阳学派与周志华学派分别占据学院的两大建制，直接合著稀少（周志华-陈开明是例外，源于Isolation Forest的第三方合作）；Muggleton-周志华的Logic Vision合作（3次）则是符号学习与统计学习在新阶段的交汇信号。
