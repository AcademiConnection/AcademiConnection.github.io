# 上海交通大学 人工智能学院（SAI） 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

上海交通大学人工智能学院（School of Artificial Intelligence, SAI）于2024年4月20日揭牌成立，是设于徐汇校区的"特区学院"，与上海人工智能实验室深度共建，实行"学院—算法院—工业创新研究院"一体化运行机制。学院不设全职院长：鄂维南院士任首席顾问，杨一帆任党委书记，王延峰教授任执行院长，张娅（教授，医疗AI）任副院长，卢策吾（兼）任副院长（另见 [sjtu_mvig_faculty_network](../sjtu_mvig_faculty_network/)）；李永露、严骏驰等亦有归属（已另有独立目录覆盖）。学院专职教师约50人，多数由约翰·霍普克罗夫特计算机科学中心（JHC）、电院及产业界汇聚而来，呈现鲜明的"国际化血统+产业科学家回流"特征。

本目录为学院建立12位代表性教师的深度报告，覆盖学院领导层（王延峰、张娅）、视觉与多模态（谢伟迪）、大模型与NLP（赵沛霖）、数据挖掘与无线感知（金梦）、多智能体（温颖）、机器学习理论（李帅）、NLP/机器学习（林洲汉）、机器人灵巧操作（连文昭）、程序验证（曹钦翔）、时空数据与科研智能体（陈思衡）、AI芯片与高效计算（戴国浩）等学院主要方向。清单中其余教师（连文昭以外的李彦玮、张志鹏、周晓、张林峰、王钰、钱忱、刘松桦、程远、陈立鹏、陈明达、相里元博、夏纫秋、孙健华等）因公开学术网络资料相对有限或与已覆盖教师网络重叠，暂作名单级记录，后续可按需增补。

## 圈层结构概述

SAI 的教师网络呈现三条鲜明主线。其一是"全球顶尖实验室谱系汇聚"：谢伟迪出自牛津 VGG（Zisserman）、林洲汉出自 Mila（Bengio）、连文昭出自杜克（Lawrence Carin）、曹钦翔出自普林斯顿（Appel）、温颖出自 UCL（汪军）、李帅出自港中文（梁广锡/张胜誉）、金梦出自清华博后（刘云浩系）、赵沛霖经 NTU（Steven Hoi），学院几乎每位教师都携带一条国际一流学术血缘，这是 JHC 传统在新学院的延续。其二是"产业科学家回流"：赵沛霖（腾讯AI Lab八年）、连文昭（Vicarious/Google X/Figure AI）、陈思衡（Uber ATG/MERL）、戴国浩（无问芯穹联合创始人）、张娅（雅虎实验室）等，与学院"产教融合"定位呼应。其三是"医疗AI与医工交叉集群"：王延峰、张娅、谢伟迪构成医疗AI铁三角，锚定新华医院、瑞金医院、六院等临床节点。校内连接方面，温颖与计算机学院 APEX 张伟楠（同出汪军门下）联合指导温睦宁（现留任SAI），李帅与张伟楠有 Agentic AI 合著，戴国浩横跨清源研究院，形成 SAI 与计算机学院各研究所之间的多点耦合。
