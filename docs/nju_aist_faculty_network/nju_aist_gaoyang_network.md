## 一、学者基本信息

高阳（Yang Gao），南京大学智能科学与技术学院（苏州校区）教授、博士生导师，现任学院党委书记兼执行院长；同时兼任南京大学健康医疗大数据国家研究院常务副院长、南京大学—中国移动联合研究院院长。他是中国人工智能学会会士（CAAI Fellow）、江苏省人工智能学会执行副理事长。需要特别说明其**双重建制身份**：高阳长期任职于南京大学计算机科学与技术系/计算机学院，是南大机器学习与人工智能研究的资深教授；智能科学与技术学院（苏州校区，2022年成立）组建后，他以资深教授身份出任执行院长，成为该苏州新学院的主要学术与行政负责人。他与人工智能学院（南京本部）的周志华教授是多年的同事与同辈学者——两人均出自南大计算机系、长期共事于计算机软件新技术全国重点实验室体系，是南大机器学习学派的两条并行主线；但两人分属不同建制（高阳在苏州校区智科院，周志华在本部人工智能学院），两院并非同一学院。

**教育与工作经历：**
- 1993年，大连理工大学本科毕业。
- 1996年，南京理工大学计算机辅助设计方向硕士毕业。
- 2000年，南京大学计算机科学与技术系博士毕业，此后留校任教至今。
- 2003年，入选IBM中国访问学者计划，访问香港大学ETI；此后访问西悉尼大学（2004）、香港浸会大学（2005）、新西兰梅西大学（2006）。
- 2018年至今，任南京大学计算机系教授，领导"推理与学习研究组"（Reasoning & Learning Group，R&L Group）。
- 2022年起，出任南京大学智能科学与技术学院（苏州校区）党委书记兼执行院长。

**博士导师：** 公开资料未披露其2000年南京大学博士学位的导师姓名，本报告不作推断。

**研究主线与代表性贡献：**
1. **强化学习与博弈**：长期深耕强化学习，包括值函数逼近、策略迭代、多智能体强化学习；其团队2009年获RL竞赛Tetris项目第二名。
2. **多智能体系统与群体智能**：研究信念修正、智能体理论、多智能体协同决策，是南大该方向的代表性团队。
3. **机器学习与模式识别**：研究覆盖度量学习、集成学习等。
4. **计算机视觉与医学影像**：与史颖欢、沈定刚等合作开展医学影像分析，形成大量IEEE TMI/TIP产出。

**学术服务与荣誉：** 中国人工智能学会会士；CCF人工智能与模式识别专委、CAAI机器学习专委（曾任秘书长）、江苏省计算机学会人工智能专委副主任等；2009年入选江苏省"333高层次人才培养工程"中青年科技带头人，2010年入选教育部新世纪优秀人才，2019年任江苏省高校科技创新团队带头人，2022年获评江苏省军民融合创新带头人、天池特聘教授。

## 三、博士教育背景与导师追溯

### 3.1 南京大学博士阶段（1996-2000）

高阳于1996-2000年在南京大学计算机科学与技术系攻读博士学位，2000年毕业并留校任教。其博士论文研究方向公开资料未详细披露；从其2003年后的早期发表看，研究集中于智能体理论与多智能体系统，与其后二十余年的研究主线一致。博士导师信息公开资料未披露。

### 3.2 与周志华的同事关系

高阳与周志华（1998年硕士、2000年博士均毕业于南大计算机系，LAMDA创始人）几乎同期完成博士学位并留校，两人此后在南京大学计算机系、计算机软件新技术全国重点实验室共事逾二十年。他们是南大机器学习研究的两条并行主线：周志华一系以机器学习理论与其LAMDA实验室为代表（本部人工智能学院）；高阳一系以强化学习、多智能体与智能体理论为代表（计算机系R&L Group，后延伸至苏州智科院）。两人直接论文合作极少，其关系性质是**长期同事与学派同辈**，而非师生或合作者。这一区分对理解南大AI学科版图很重要：本报告系列中的LAMDA教师网络（周志华、詹德川、叶翰嘉等）与高阳的R&L网络基本不重叠。

### 3.3 R&L Group的代际培养

高阳的学术谱系通过R&L Group实现代际延续，最典型的链条是：

```text
高阳（南大博士2000届，R&L Group创始人）
  └─ 史颖欢（南大博士2013届，导师高阳；现任南大计算机系教授）
  └─ 李文彬、祁磊、霍静等（R&L教师层/出身成员）
       └─ R&L博士生群体（2010年代至今）
```

史颖欢个人主页明确其为R&L Group成员、"led by Prof. Yang Gao"，且其2007年本科、2013年博士均在南大完成——其163次DBLP合作与高阳覆盖2009-2026年全程，是典型的"师生—同事—梯队"连续关系。李文彬、祁磊、霍静等的高频合作同样呈现这一模式。

## 六、Connection圈层总结

**第一圈层——R&L Group骨干：** 史颖欢（163次）、霍静（151次）、李文彬（93次）、祁磊（93次）、王磊（55次）构成高阳学术网络的绝对核心。这一圈层是典型的内生培养型网络：从高阳的博士生到南大/东南大学教职，再到持续联合发表，形成了南大计算机系内LAMDA之外最重要的机器学习学派。

**第二圈层——学生与青年梯队：** 杨天培、田品卓、胡钰晶、陈子轩、丁天宇、陈兴国、杨尚东等数十位高频青年合作者，覆盖2008-2026年的强化学习、多智能体、视觉与医学影像研究，是网络中规模最大的圈层。
