## 全团队关系网络的整体观察

智科院是南大苏州校区布局中最"年轻"的学院，其教师网络呈现三种鲜明形态。第一种是**本土学派的延伸**：高阳作为南大机器学习元老（2000年南大博士），以R&L Group为基座培养了史颖欢、霍静、李文彬、祁磊等骨干（合作均超90次），形成强化学习、群体智能与医学影像的自主学派，与本部LAMDA（周志华）并行发展、直接合著极少，构成南大机器学习"双星"的另一半；戴望州则是周志华的博士（2019），经帝国理工Muggleton博后回归，充当LAMDA与国际归纳逻辑编程社区的桥梁。第二种是**产业界/海外回流型**：单彩峰（QMUL博士、荷兰飞利浦研究院13年）带来欧洲工业研究脉络，现通过中科院自动化所与华中科技大学通道大规模联合培养；陈硕（南理工杨健系、RIKEN杉山将系）属于纯海外学术回流。第三种是**新建制下的青年聚合**：司晨阳（王亮—谭铁牛谱系、NTU Ziwei Liu博后）代表视觉生成方向的青年力量，其VBench、FreeU等成果已进入开源社区主流管线。

与南大既有体系的连接点集中于：谭铁牛（现任南大党委书记，与单彩峰12次合作——学院治理与学术网络在此交汇）、周志华（LAMDA，戴望州的导师）、以及高阳与本部AI学院的长期同事网络。学院整体产业转化以高阳兼任的南大—中国移动联合研究院为最大平台，青年教师中符天凡的创业实践（苏州蒂法生物科技）是AI for Science落地的代表。

## 数据来源与说明

各报告数据主要来源于DBLP官方作者记录、智科院与计算机学院官网师资页、个人主页及官方新闻。姓名重名问题在本组尤为突出（Yang Gao、Ke Wang、Shuo Chen、Liu Zhibo 等均有数十个DBLP消歧条目），已按机构历史与代表作人工锁定并在各报告局限性章节说明；王轲的DBLP pid页面近期返回410（DBLP作者记录重整中），其统计基于检索API按作者标签过滤，已在报告中标注该风险。博士导师推断（单彩峰—龚少刚、陈硕—杨健、司晨阳—王亮）均已在报告中降级为"未获公开确认"的表述。
