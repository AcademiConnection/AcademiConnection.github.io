## 五、业界合作关系深度分析

### 5.1 Altizure 创业 — 从实验室到被苹果收购

姚遥学术生涯中最独特的产业经历，是作为 Altizure 创始团队核心成员参与了这家公司从 0 到 1 的创业全过程。Altizure 是权龙教授在港科大创立的公共三维重建云平台——用户通过手机或无人机拍摄照片并上传至平台，即可自动生成三维模型。2020 年，Altizure 被苹果公司收购，姚遥亦随收购加入苹果。

这一路径在学术报告人中的意义在于：
- MVSNet 系列不仅是学术论文，更是 Altizure 产品的核心技术组件，实现了"论文→代码→产品"的完整闭环。
- 标准 CVPR/ECCV 发表经历了产业需求检验，证明其三维重建方法在实际场景中具有实用性。

### 5.2 Apple 高级研究员 — Object Capture API 与消费级三维视觉

姚遥在苹果公司任高级研究员期间，核心贡献之一是参与 **Apple Object Capture API**（WWDC 2021 发布）的研发。该 API 是苹果面向消费级市场推出的三维重建工具，允许用户通过 iPhone/iPad 拍摄照片序列自动生成可用于 AR/VR 的三维模型。它可被视作 Altizure 技术在苹果生态中的延续——从云端服务变为设备端 API，大幅降低了三维重建的使用门槛。

这一产学研路径的直接结果是：姚遥的研究（MVSNet 系列）最终进入**数以亿计苹果设备的系统级功能**，这是三维视觉领域罕见的学术成果直接落地消费级产品的案例。

### 5.3 Neural4D — 独立创业/技术品牌

姚遥的个人主页明确列出了 **Neural4D**（https://www.neural4d.com/）作为其参与的 Products 之一。根据其 Research 板块与 News 更新，Neural4D 同时承载了：
- **TEXTRIX**（2025 年 12 月）：原生纹理生成工具
- **ComGS**（2025 年 9 月）：3DGS 组合/编辑工具
- 更多研究论文与技术的产业化出口

Neural4D 的商业结构、团队规模和运营数据公开资料未披露。

### 5.4 苹果 Object Capture 技术的学术根源与产业映射

| 时间线 | 形态 | 关键事件 |
|--------|------|----------|
| 2018 | 学术论文 | MVSNet（ECCV 2018）发表，基于深度学习的多视图立体匹配 |
| 2019 | 产品 | Altizure 平台依托 MVSNet/R-MVSNet 技术运营 |
| 2020 | 收购 | Altizure 被苹果收购，姚遥加入苹果 |
| 2021 | 平台级产品 | Apple Object Capture API（WWDC 2021）发布 |
| 2022–至今 | 新实验室 | 南大 NJU-3DV / NJU-PIL 成立，继续推进 3D 内容生成 |

这构成了一条清晰的"学术论文 → 初创公司 → 技术收购 → 平台级产品 → 回归学术界"的完整闭环。在三维视觉领域，能完成这一链条的研究者极为稀少。

### 5.5 产业问题与技术路线的对应关系

| 产业/应用约束 | 姚遥团队相关技术议题 | 代表通道 |
|--------------|-------------------|----------|

## 七、Connection 圈层总结

**第一圈层——博士导师与同门网络。** 权龙（Long Quan）是姚遥整个学术生涯的起点与核心引路人。博士期间与骆子新、李世伟、方天、沈天蔚等形成的合作单元延续至今（如 Matrix3D，CVPR 2025），是姚遥学术网络中最稳定、最长寿的圈层。该圈层的学术风格——三维重建以几何为核心、强调实际产品验证——也已成为姚遥团队的显著标志。

**第二圈层——南大智科院新团队。** 姚遥在苏州校区与朱昊、龙霄潇共同指导 NJU-PIL 实验室，组建了以"三维视觉 + 物理智能"为主线的年轻团队。与本科导师曹汛（南大电子学院）的持续合作（ICLR 2025、CVPR 2025 多篇）则将智科院与电子学院的研究力量打通，构成南大校内跨学科合作的重要通道。

**第三圈层——产学研闭环（Altizure → Apple → NJU）。** 这是姚遥区别于多数青年教师的独一无二圈层。MVSNet→Altizure→Apple Object Capture API 的完整链条，使其学术成果达到了消费级产品的直接影响力。这一经历带来的不仅是产业经验，更有苹果公司的研究资源网络（Yang Tsin 等合作者）。回国后 Neural4D 品牌的运营则表明其继续以独立技术品牌推动成果转化。

**第四圈层——国际三维视觉学术社区。** 以南大—港科大—苹果为三角节点，姚遥在基于学习的多视图立体（MVS）、可微渲染、三维内容生成等领域建立了覆盖 CVPR/ICCV/ECCV/ICLR 等顶会的发表网络。其 2024–2025 年的高产期（Gaussian-Flow Highlight、Direct2.5、Matrix3D、Flow Distillation Sampling 等）表明网络正快速扩张。

**第五圈层——前沿拓展：世界模型与物理智能。** 2025–2026 年姚遥实验室密集发布了 SpatailVID 数据集、P3D-Bench、LingBot-World、LingBot-Map、Procedura 等工作，标志着研究方向从三维重建/生成向视频世界模型、流式感知、Agentic 三维建模等前沿领域延伸。这一拓展与其实验室更名（NJU-3DV → NJU-PIL）同步，显示其对物理智能方向的中长期布局。
