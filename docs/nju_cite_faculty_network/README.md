# 南京大学 CITE（计算摄像与智能成像团队）教师网络报告索引

南京大学电子科学与工程学院计算摄像与智能成像团队（CITE）由曹汛教授组建并领衔，聚焦光谱视频成像、计算摄像、光场成像、计算机视觉与图像视频处理等交叉方向。团队依托南京大学电子科学与工程学院开展教学与科研工作，研究内容横跨信号处理、电路与系统、光学等综合交叉领域，成果发表于 IEEE T-PAMI、IJCV、Light、Optica 等期刊及 Nature 子刊。团队带头人曹汛系清华大学戴琼海院士博士弟子、"80后"国家重大科研仪器研制项目负责人，曾作为第4完成人参与获2012年国家技术发明一等奖的"立体视频重建与显示技术及装置"项目，为最年轻的国家科技三大奖一等奖完成人之一，并获第26届中国青年五四奖章。

团队研究方向覆盖光谱成像硬件设计、计算摄像算法、视频处理与传输、超构表面光学器件等多个交叉环节。在基础前沿方面，团队与祝世宁院士、王漱明教授团队及哈尔滨工业大学肖淑敏教授团队合作，在微型化光场光谱4D成像、微型化快照偏振立体成像等方向取得突破，成果发表于 Nature Communications 与 Optica；在工程化方面，团队研发了"光线基因"系列光谱相机和亿像素阵列计算摄像机，后者作为南京大学—江苏省广播电视总台多模态视听融媒大模型联合实验室成果亮相江苏省城市足球联赛决赛现场。据南京大学官方报道，曹汛已培养青年高科技人才六十余名，去向以国防军工、民族企业等科研创新一线为主。

本目录为该团队教师网络系列报告的集合。目前 CITE 仅收录曹汛教授一份报告，后续如团队其他教师报告生成，将在此索引中补充。

## 研究方向与圈层结构概述

**研究方向**：

- **光谱视频成像**：提出棱镜-掩模调制的光谱视频成像方法（PMVIS），研制手持、机载、车载、云台等系列光谱相机，推动光谱成像由"静"至"动"的跨越。
- **微型化多维成像**：与祝世宁院士团队、王漱明教授、哈尔滨工业大学肖淑敏教授团队合作，实现微尺度下同时集成光谱和深度信息采集的4D（x, y, z, λ）动态成像系统及微型化高效快照偏振立体成像。
- **亿像素阵列计算摄像**：阵列式设计突破单一光学镜头与传感器的分辨率限制，具备亿像素级实时视频流输出能力。
- **立体视频与光场成像**：源自戴琼海院士团队的立体视频重建与显示技术及光场拍摄矩阵技术。

**圈层结构**（详见报告第七章）：

- **第一圈层·学术谱系核心**：以清华大学戴琼海院士为核心的计算摄像学术谱系，曹汛与季向阳、刘烨斌、索津莉等共同构成该谱系重要节点。
- **第二圈层·校内跨学科合作**：包括与祝世宁院士、王漱明教授、王振林教授的超构表面光学合作轴，以及与朱昊、陈浩两位准聘助理教授的阵列计算摄像合作轴。
- **第三圈层·学生培养**：确认的学生包括博士研究生周凯来（光谱成像与化工气体监测方向，"挑战杯"主体赛道一等奖项目参与者）和硕士毕业生李涵（亿级像素交互式直播系统方向）；另有刘振、郑诗雨、周一凡、余一婉等论文共同作者，其身份仅据论文署名收录，不据此认定为曹汛指导学生。
- **第四圈层·产业转化网络**：涵盖化工安全监测、技术转化实体、高端影视应用、亿像素摄像与移动终端应用等方向。
- **第五圈层·国际学术网络**：包括担任 IEEE T-CSVT、Signal Processing Letters 编委、CVPR 领域主席、SPIE 光谱成像和信号处理国际会议联合主席（2017、2019、2022年）等。

## 产业转化亮点

- **化工安全监测**：光谱相机预警系统应用于全国10余个省市的大型化工园区和重点企业（包括江苏洋口、中石化等）；2022年应急管理部发文（〔2022〕5号）建议向全国化工园区推广该项技术。
- **技术转化实体**：曹汛推动科技成果转化，实现国产光谱视频相机产品零的突破，技术转化实体融资估值已逾10亿元（据南京大学官方报道；实体名称及曹汛在其中的职务公开报道未披露，本索引不作推断）。
- **高端影视应用**：光场拍摄矩阵技术应用于2016年上映的国内首部真人CG电影，实现人物角色3D真人数字化，此前该技术仅为美国好莱坞掌握。
- **亿像素摄像**：亿像素阵列计算摄像机亮相2025年江苏省城市足球联赛决赛，实现视频画质从高清、超高清到亿像素的跨越，体现南京大学与江苏省广播电视总台的产学研深度合作。
- **移动终端应用**：微型化光场光谱4D成像系统为移动终端在数字支付、食品安全、环境监控等领域的拓展应用提供技术支撑，具有消费电子产业化前景。
