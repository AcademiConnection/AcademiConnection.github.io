## 二、教育背景与职业履历

蒋冬梅的学业与职业轨迹高度集中于西北工业大学，属于典型的"本土培养、长期深耕"型学者：

- **博士阶段（至2000年）**：2000年在西北工业大学获计算机科学与技术工学博士学位。其博士前后时期的多篇早期论文（如 2003—2004 年发表于《计算机应用》《电子科学学刊》的音视频连续语音识别、基于 Viseme 的连续语音识别系统等工作）均与西北工业大学赵荣椿教授联名，赵荣椿是西工大早期语音/信号处理方向的代表性教授。公开资料未明确记载其博士导师身份，但从长期联名发文与共同署名单位看，赵荣椿在其学术成长中扮演了重要的前辈/指导者角色（审慎推断，待核）。
- **博士后（2000.12—2003.11）**：于西北工业大学控制科学与技术博士后流动站从事研究。
- **任教（2003.11 至今）**：进入西北工业大学计算机学院任教。
- **海外访学（两段比利时经历）**：2001.11—2002.6 与 2006.6—2007.10，两次赴比利时布鲁塞尔自由大学（VUB），参与中国科技部与比利时政府间国际合作项目研究。这段经历奠定了她此后近二十年的中比合作主线。
- **晋升节点**：2010年5月晋升教授，2011年4月被聘为博士生导师。
- **国际合作制度建设**：自2005年起担任西北工业大学与 VUB "听视觉信号处理"联合实验室中方联系人；2011年起担任中欧 LIAMA 研究联盟西北工业大学联系人；参与制定西北工业大学与 VUB 硕士双学位联合培养方案，推动两校科研合作与人才联合培养机制。据陕西省语音与图像信息处理重点实验室资料，2011年她所在团队推动 VUB 与西工大一同加入中欧 LIAMA 联盟，2014年参与推动签署两校"最重要合作伙伴关系协议"等5项合作协议。

从履历看，蒋冬梅是 ASLP@NPU 前身（1995年成立的语音处理研究组）成长起来的第二代骨干：博士期间即在赵荣椿、谢磊所在的语音团队从事研究，2003年正式任教后逐步成为实验室三位教授之一，并以中比国际合作作为个人学术网络的鲜明主线。

## 四、学术合作网络

### 4.1 实验室内部合作（谢磊、付中华、张蓬）

- **谢磊（Lei Xie）**：合作关系最为长期的核心搭档。两人早在2000年代初即联名发表音视频连续语音识别方面的工作（如2003年《计算机应用》"一种基于数据筛的音频视频连续语音识别系统"、2004年《电子科学学刊》"基于Viseme的连续语音识别系统及Talking Head"，均同时包含 VUB 合作者）。谢磊后来成为 ASLP@NPU 负责人并主导语音识别/合成/大模型方向的产业化研究，蒋冬梅则深耕视听觉情感计算与多模态融合方向，二人形成"一个实验室、两条主线"的互补分工。值得注意的是，两人与 VUB 的交集（谢磊曾在 VUB 从事科研工作，蒋冬梅两度访学 VUB）是实验室中比合作传统的重要来源。
- **付中华（Zhonghua Fu）**：ASLP@NPU 核心教师之一（副教授，非教授），主要方向为语音与音频信号处理。
- **张蓬（Peng Zhang）**：实验室学术带头人之一，方向为计算机视觉与遥感图像处理。同理，其与蒋冬梅的直接合著记录较少，合作更多体现为实验室层面的共同体（共同的省级重点实验室平台、联合项目与联合指导）。

结构性观察：ASLP@NPU 的"三位教授+一位副教授"架构中，蒋冬梅是唯一以"语音-视觉跨模态（音视频）"为核心标签的教授，恰处谢磊（纯语音侧）与付中华/张蓬（视觉侧）之间的桥梁位置，这在学科交叉合作上具有独特价值。

### 4.2 跨机构学术合作

- **比利时布鲁塞尔自由大学（VUB，ETRO 系）**——最核心的海外合作节点。长期合作者包括 Hichem Sahli（教授，视听觉信号处理）、Jan Cornelis（教授）、Ilse Ravyse、Isabel Gonzalez 等。合作产出涵盖音视频语音识别、Talking Head、视觉语音合成、音视频情感识别等，自2000年代初持续至2010年代。以她为中方联系人的"西北工业大学—VUB 听视觉信号处理联合实验室"（2005年起）与硕士双学位联合培养方案是其制度化载体。
- **中欧 LIAMA 研究联盟**：2011年起担任西工大联系人，将个人中比合作扩展为联盟层面的多边合作。
- **实验室层面的其他国际合作网络**（经由 ASLP@NPU/省级重点实验室共享，非其个人直接联名为主）：香港城市大学（创意媒体/媒体计算联合实验室）、英国东英吉利大学（UEA，签署合作协议）、新加坡南洋理工大学（NTU）、新加坡国立大学（NUS）、新加坡资讯通讯研究院（I2R）、美国约翰霍普金斯大学（JHU）、美国华盛顿大学、台湾成功大学、美国休斯顿大学、日本东京大学等。
- **国内学术共同体**：以陕西省图像图形学会、陕西省信号处理学会理事身份嵌入本地学术圈；作为中国航空学会信号与信息处理等专业学术会议的常任作者群体成员。

### 4.3 合作网络特征总结

蒋冬梅的合作网络呈典型的"单枢纽强辐射"结构：以西北工业大学（本部）+ 布鲁塞尔自由大学（海外枢纽）为双锚点，前者提供团队与生源，后者提供国际合作通道、联合发表与双学位机制；在此之上通过 LIAMA 联盟实现多边扩展。与谢磊的高频内部共事、与 Hichem Sahli 的高频跨国共著，构成其合作网络的两大稳定轴。其署名论文数量（据百科自述50余篇）明显少于谢磊等高产学者，反映出其角色偏向合作组织者、国际渠道建设者与研究生指导者，而非高产第一作者型研究者。
