# 西北工业大学 音频语音与语言处理实验室（ASLP@NPU）教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

ASLP@NPU（Audio, Speech and Language Processing Lab，音频语音与语言处理实验室，官网 [nwpu-aslp.org](http://www.nwpu-aslp.org/)）隶属西北工业大学计算机学院，依托空天地海一体化大数据应用技术国家工程实验室和陕西省语音与图像信息处理重点实验室，是国内语音、音频与语言智能领域最具影响力的研究团队之一。实验室成立于1995年，由谢磊教授领衔，现有三位教授（谢磊、蒋冬梅、张蓬）和一位副教授（付中华）构成的教师核心，以及50余名硕博士研究生。

实验室围绕语音识别、语音合成、语音增强、口语对话系统以及新兴音频语言大模型等方向开展前沿研究，始终坚持学术创新与实际应用并重。实验室的标志性开源贡献——WeNet 语音识别工具包和 WenetSpeech 中文语音数据系列——已被学术界和工业界广泛采用。谢磊教授发表论文400余篇，Google Scholar引用超18000次（H-index 63），担任 ISCA SIG-CSLP 副主席、IEEE/ACM TASLP 与 IEEE SPL 高级领域编委。实验室在 ICASSP DNS 竞赛中两次蝉联冠军，多项研究成果已实现产业落地。

## 圈层结构概述

ASLP@NPU 的学术谱系以西北工业大学计算机系本土培养为核心纽带。谢磊、蒋冬梅均为西工大博士毕业，早期共同师从赵荣椿教授（语音识别先驱），实验室即从1995年的语音小组发展而来。蒋冬梅2000年获博士后的国际化视野将实验室与比利时布鲁塞尔自由大学（VUB，Hichem Sahli 教授）和中比联合实验室、LIAMA 联系人机制链接起来，形成持续的国际合作通道。付中华同样为西工大本硕博本土培养，在语音前端处理方向深耕，并以科大讯飞西安研究院常务副院长身份担当产学研桥梁。张蓬是团队中唯一的海外引进教师——NTU博士、芬兰 Mekitec OY 首席科学家，2012年破格回国任副教授、2017年晋升教授，研究方向为计算机视觉与音视频融合，为实验室注入了视觉维度的跨模态研究能力。

产业圈层方面，实验室与腾讯（共建联合实验室）、云知声（共建联合实验室）、华为（AI名师、HIRP项目）、字节跳动、科大讯飞、小米等十余家企业保持深度合作。学生培养产出了大量人才，毕业生进入阿里、百度、腾讯、美团、字节、小米及Google、微软等国内外头部企业，以及高校教职（如已毕业博士在高教任教），WeNet 和 WenetSpeech 的开源社区也为实验室构建了广泛的学术影响力网络。
