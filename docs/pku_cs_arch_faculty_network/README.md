## 二、团队背景与研究方向概述

北京大学计算机学院系统结构研究所的核心是微处理器研究开发中心（Microprocessor Research and Development Center, MPRC），由程旭教授于2001年2月创立（前身可追溯至1995年前后即已启动的自主CPU研究），是全国唯一专业从事自主CPU和系统芯片研发的教育部工程中心（"微处理器及系统教育部工程研究中心"）。MPRC于1999年完成国内首套16位自主指令系统UniCore16，2002年流片国内首颗自主32位CPU系统芯片"北大众志-863 CPU"，2003年量产进入市场推广，是中国自主CPU研发的先驱力量之一，与中科院龙芯、方舟科技并列为21世纪初国产CPU"三驾马车"。

研究所的研究方向覆盖计算机体系结构全链条：指令集架构与处理器核设计（程旭、易江芳、陆俊林）、SoC设计与IC物理实现（管雪涛、刘锋）、处理器微结构与存储系统（佟冬）、编译工具链与基础软件（刘先华）、视频编解码软硬件协同设计（刘锋）。团队在HPCA、PACT、ICS、ICCD、TACO等体系结构顶级会议与期刊持续发表成果，2024年仍有ICCD论文产出。

## 三、关系网络与圈层结构概述

本研究所的关系网络以程旭为绝对核心。程旭1994年自哈尔滨工业大学博士毕业后被杨芙清院士点名招入北大（被称为"关门弟子"），1996年组建CPU研发团队，围绕其形成了"师-生-同事"三位一体的稳定结构：陆俊林（2009年北大博士）、刘先华（2007年北大博士）、易江芳（2007年北大博士）等为MPRC培养的博士并留校任教；佟冬（1999年哈工大博士）与程旭同源哈工大系统结构学科；刘锋（2005年西安电子科技大学博士）则以博士后身份加入，程旭为其博士后合作导师。这一核心团队协作关系延续二十余年，极为稳定。

产业转化方面，2002年成立的北京北大众志微系统科技有限责任公司（程旭任董事长）承载了MPRC的产业化使命，历经网络计算机（NC）、千元本、桌面云三个阶段，虽因Wintel生态壁垒未能大规模商业化，但开创了国内首个自主CPU系统芯片量产的先河。MPRC毕业生大量流向英伟达、AMD、Marvell、威盛等国际芯片企业，代表性学生如王箫音（博士，后任荣科科技副总裁）横跨学术、产业与资本市场。国际合作方面，团队与Intel共建联合实验室、联合UCLA等六校成立国际SoC研究中心、获AMD X86 Geode技术授权。
