## 二、教育背景与职业履历

易江芳于1999年在中国人民解放军信息工程大学获得学士学位；北大英文教师页面明确记载其于2007年获得北京大学博士学位。该页面没有披露博士专业、论文题目或导师姓名。因此，尽管其博士阶段与程旭教授领导的 MPRC 在研究主题、后续共同署名及团队归属上具有高度关联，本报告**不将“师从程旭”作为已确认事实**，该师承关系应标注为（待核实）。

其可由公开来源确认的职业轨迹如下：

- **1999年**：获中国人民解放军信息工程大学学士学位。
- **2007年**：获北京大学博士学位。
- **2007年后（具体入职年月待核实）**：任职北京大学计算机相关院系；旧版英文页将其列为 School of EECS 计算机科学与技术系 Assistant Professor。
- **2009年前后**：以北京大学 MPRC 研究人员身份参与“北大众志-SK”SoC 体系结构工作，并与程旭、陆俊林、刘姝共同发表相关论文。
- **2010年代至今**：持续在 MPRC/系统结构研究所从事 UniCore、PKUnity、处理器微体系结构、验证、缓存一致性及虚拟内存方向研究。
- **现阶段**：北大计算机学院官方页列为系统结构研究所副教授。

其技术贡献具有从“CPU 正向设计”到“体系结构研究与人才培养”的连续性。北大英文介绍明确称其承担 UniCore-3 的 ISA 设计和微体系结构实现；该处理器被描述为 64 位乱序超标量微处理器，支持1至4核、私有 L1 与共享 L2 缓存、硬件 MOESI 协议和精确中断。其公开成果还包括基于存储序号的远距离 store-load forwarding、将机器学习用于微处理器回归测试集生成，以及用于缓存一致性验证的并行仿真框架。

## 三、学生培养情况

公开的院系页面未提供易江芳个人名下的研究生名册、学位授予年度或校友去向；而当前北大计算机学院“计算机体系结构”招生导师清单中列有程旭等人，但未列易江芳。因此，以下8人不是依据名册直接确认的“独立指导毕业生”，而是依据 OpenAlex 论文著录及北大学报论文作者单位，识别出的**与易江芳在北大体系结构/MPRC 课题中直接共同产出的青年研究者或学生候选人**。为避免将论文署名关系错误等同于导师关系，各人的毕业年份、现去向及“是否由易江芳独立/共同指导”均保留（待核实）。这一处理同时保留了可追溯的人才培养网络线索。

### 1. 班义琨（毕业年份及现去向待核实，论文合作者/学生候选人）

班义琨与张炜奇、周昱晨、程旭、易江芳共同完成虚拟内存地址转换研究。北大学报2020年论文《利用内存映射连续性提高TLB地址覆盖范围的技术评测》明确列出班义琨为作者、作者单位为北京大学信息科学技术学院系统结构研究所。OpenAlex 同时收录其参与的英文论文 *Coalesced TLB to Exploit Diverse Contiguity of Memory Mapping*（2019）。这表明其在内存映射连续性与 TLB 覆盖范围方向处于易江芳—程旭团队的直接研究协作链条中；但公开资料不足以判定其学位层次、毕业年份和毕业后的具体任职。

### 2. 周昱晨（毕业年份及现去向待核实，论文合作者/学生候选人）

周昱晨是上述 TLB 连续性研究的共同作者。北大学报文献将其与班义琨、张炜奇、易江芳共同署于系统结构研究所地址；OpenAlex 记录显示其与易江芳、程旭、班义琨共同发表 *Coalesced TLB* 研究。其工作侧重典型基准程序中的内存映射连续性分布及翻译覆盖范围评测，体现了团队以真实负载评估微体系结构机制的培养路径。其是否为易江芳直接指导学生、毕业时间和当前去向均为（待核实）。

### 3. 陈东伟（毕业年份及现去向待核实，论文合作者/学生候选人）

陈东伟与佟栋、杨春、程旭、易江芳合作发表 *FlexPointer: Fast Address Translation Based on Range TLB and Tagged Pointers*（2022/2023）。该工作围绕范围 TLB 与带标记指针加速地址翻译，延续了团队在虚拟内存与 TLB 方向的研究脉络。论文共著可确认其与易江芳有直接科研合作，但可公开确认的材料不足以说明其是硕士生、博士生或已毕业校友，亦未找到毕业年份和任职去向，均为（待核实）。

### 4. 崔宇杰（毕业年份及现去向待核实，论文合作者/学生候选人）

崔宇杰与陈炜、程旭、易江芳合作发表 *Hyperion: A Highly Effective Page and PC Based Delta Prefetcher*（2024）。从题目与作者结构看，该成果聚焦基于页和 PC 的 Delta 预取机制，属于处理器访存性能优化研究。其与易江芳的关系可稳妥界定为论文共同作者；其培养身份、毕业年份、所在单位及后续职业去向没有找到可引用的公开资料，均应标为（待核实）。

张振浩与佟栋、王晓音、易江芳等合作发表 *SOLE: Speculative One-Cycle Load Execution with Scalability, High-Performance and Energy-Efficiency* 及 *Active Store Window: Enabling Far Store-Load Forwarding with Scalability and Complexity-Efficiency*（均为2012年记录）。这些工作与易江芳官方介绍中“远距离 store-load forwarding”和低能耗访存执行优化的研究描述相互对应，显示其是该处理器访存执行研究线的重要共同产出者。现有公开检索未能确认其师生关系、学位完成年份及职业去向（待核实）。

## 四、学术合作网络

### 4.1 实验室内部合作

易江芳的核心学术网络以北大系统结构研究所和 MPRC 为中心。**程旭**是最稳定的共同作者和团队枢纽：双方在2009年北大众志-SK SoC、2010年 UniCore CPUs 与 PKUnity SoCs 进展、2019年 Coalesced TLB 和2023年 FlexPointer 等工作中共同署名。程旭自2002年起担任 MPRC 主任的公开资料，与这一长期协作关系一致，但不构成易江芳博士导师关系的直接证据。

共同作者还包括**陆俊林、佟栋、王晓音、关雪涛、刘先华、杨春、罗国杰**等。其中，陆俊林与易江芳、程旭在北大众志-SK SoC 上直接合作；佟栋和王晓音集中出现在访存执行、预取、验证研究中；杨春既是北大系统结构研究所公开列出的助理研究员，也与易江芳共同参与 FlexPointer 和硬件模糊测试—工业验证研究；罗国杰则参与近期硬件验证工作。网络形态上，易江芳承担了从处理器设计、性能机制到验证方法的跨主题连接角色。

### 4.2 跨机构合作

可确认的跨机构合作主要体现为 MPRC 的平台级与产业化协作，而非易江芳个人主页列示的个人合作项目。MPRC 曾与 Intel 建立北大—英特尔软硬件协同设计联合实验室；与 UCLA、UCSB、两岸清华、交通大学、浙江大学等共同建立国际 Giga-scale SoC 研究中心；并与联想（深圳）板卡设计中心、Mentor Graphics 建立系统设计联合实验室。易江芳作为 MPRC 处理器设计与验证研究者，处于这一合作平台所覆盖的技术生态中；但没有公开资料能够逐一确认她在各联合实验室项目中的个人职责（待核实）。

在国内学术共同体层面，她参加“龙芯杯”全国大学生计算机系统能力培养大赛的颁奖、点评工作，并带队翻译编著计算机体系结构经典书籍，显示其与国产 CPU、RISC-V 和计算机系统能力培养社群存在持续连接。

### 4.3 国际合作

## 五、业界合作关系深度分析

### 5.1 从 MPRC 研发链到北大众志产品化

易江芳的产业关联最核心的载体是 MPRC。她的北大英文介绍明确说明：其长期投入由 MPRC 研制的 UniCore 系列微处理器，并负责 UniCore-3 的 ISA 设计和微体系结构实现。该经历意味着她的研究并非只停留在算法或模拟层面，而是进入了指令系统、乱序超标量实现、缓存一致性与精确中断等可落实到处理器产品的关键环节。

“北大众志-SK”SoC 是这种产学研衔接的具体节点。2008年《计算机学报》论文（程旭、陆俊林、易江芳、刘姝）说明，该 SoC 将 CPU、南北桥、显示控制器和多类 I/O 集成到单芯片，并面向 UMPC 的高集成度、性能与低功耗需求。易江芳作为作者之一，其可确认角色是该成果的学术共同研发者；论文和主页材料未公开分工比例，故不宜将她表述为单独的产品负责人。

MPRC 的成果转化链包括北京北大众志微系统科技有限责任公司。公开资料称该公司于2002年为推进北大众志 CPU 产业化而成立，专注自主 CPU 和系统芯片产品化；相应网络计算机曾进入教育、政务、医疗等应用场景。对于易江芳而言，较准确的关系表述应是：她的 UniCore/PKUnity 与 SoC 研究服务于 MPRC—北大众志的自主 CPU 技术链；未发现她本人在企业担任管理职务、持股或直接商业任职的可靠公开证据（待核实）。

### 5.2 创业孵化与企业协同

从组织结构看，北大众志是北大 MPRC 成果产业化的衍生企业，体现高校工程研发中心将 CPU、SoC、系统软件和终端方案向市场迁移的孵化路径。该路径并非典型的“个人教授创业”叙事，而是以实验室平台、校办企业和区域制造/应用基地共同推进：北京北大众志微系统科技有限责任公司负责芯片与系统产品化，常州北大众志网络计算机有限公司承担网络计算机成果转化与应用拓展。

对易江芳的网络价值而言，她连接的是三类能力：其一，面向自主指令系统与微体系结构的源头研发；其二，功能验证、缓存一致性和硬件模糊测试等保证复杂芯片可用性的工程方法；其三，RISC-V 与系统能力竞赛、教材翻译等人才与生态建设。前两者为产品化降低设计和验证门槛，后者则扩大工程人才供给与技术传播。Intel、Mentor Graphics、联想等联合实验室为 MPRC 提供了软硬件协同设计、EDA/系统设计和板卡设计的企业接点；但易江芳参与这些企业合作的项目名称、合同角色和成果归属尚无公开材料可确认（待核实）。

## 七、Connection圈层总结

**第一圈层：MPRC—系统结构研究所核心。** 易江芳以北大系统结构研究所副教授和 MPRC 研究者身份，围绕程旭、陆俊林、佟栋、王晓音、杨春、罗国杰等形成长期协作网络。该圈层的共同对象是自主 CPU、SoC、微体系结构、地址转换和验证。

**第二圈层：论文共同产出与人才培养候选网络。** 班义琨、周昱晨、陈东伟、崔宇杰、张振浩、熊巧丽、郭六成、马瑞阳等在不同年份与其共同发表处理器访存、TLB、预取、缓存一致性和验证论文。他们是观察其科研训练网络的重要节点，但公开资料未足以将其全部确认为正式指导毕业生，故相关身份、年份与去向均应保留（待核实）。

**第三圈层：自主计算生态与产业化网络。** MPRC、UniCore、PKUnity、北大众志及其网络计算机应用构成从 ISA/CPU/SoC 到产品化与教育、政务等应用的转化链。易江芳的独特位置在于兼具架构设计和验证能力，连接研发与工程交付。

**第四圈层：国内外协同与教育生态。** 机构层面，MPRC 与 Intel、UCLA、UCSB、联想、Mentor Graphics 等建立过合作平台；国内层面，她参与龙芯杯及体系结构教材传播，连接国产计算、RISC-V 与系统能力培养社群。需要注意的是，这一层多为团队/机构网络，不能在缺少项目材料时简单归因于她个人的直接合作。

总体而言，易江芳的关系网络呈现“**北大 MPRC 核心研发—处理器工程验证—自主 CPU 产业化—系统人才培养**”的链式结构。其公开可见的最强连接不是以个人学术头衔为中心，而是以长期嵌入自主处理器研发、设计验证与系统教育的工程型学术网络为中心。
