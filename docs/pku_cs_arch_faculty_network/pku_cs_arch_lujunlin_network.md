## 二、教育背景与职业履历

陆俊林的学术训练和任职主线均在北京大学完成。北京大学信息科学技术学院英文主页明确记载：其于**2002年获北京大学学士学位**，于**2009年获北京大学博士学位**；该公开页未列出博士导师姓名，故本报告不作推定（待核实）。2009年博士毕业后留校任教，研究和教学长期嵌入系统结构研究所、微处理器研究开发中心（MPRC）所代表的自主CPU与SoC研发脉络。现行计算机学院师资页确认其为系统结构研究所教授，研究领域为计算机体系结构。[官方师资页](https://cs.pku.edu.cn/info/1013/2881.htm)

其研究路径具有鲜明的“体系结构—芯片—系统”贯通特点：早期关注片上网络、片上通信及系统芯片设计；随后持续参与自主CPU、异构SoC、存储层次和软硬协同设计。其旧版英文主页还记载其参加过国家科技重大专项、国家863计划等十余项项目。与此相应，计算机系统结构实验室公开介绍显示，该实验室是教育部所属专门从事微处理器及系统芯片研究开发的工程中心，研究覆盖现代微处理器结构、优化编译、操作系统、模拟与性能评测、软硬件协同设计和SoC设计；陆俊林任实验室副主任。[实验室介绍](http://lab-equip-query.pku.edu.cn/Lab/LabInfoDetail?sysbh=0010101)

## 四、学术合作网络

### 4.1 实验室内部合作

陆俊林的核心合作圈位于北京大学计算机系统结构实验室/MPRC。实验室公开页面列程旭为主任，陆俊林、刘先华为副主任；因此，程旭—陆俊林—刘先华构成组织治理和教学科研协同的关键节点。[实验室页面](http://lab-equip-query.pku.edu.cn/Lab/LabInfoDetail?sysbh=0010101) 研究上，陆俊林与程旭、佟冬、王宏伟在NoC与处理器结构方向合作，代表性成果包括层次化NoC和支持服务质量的路由器；与程旭、易江芳、刘姝共同参与PKUnity-SK SoC论文。该网络以自主CPU/SoC的端到端研发为共同任务，而非单一论文合作。

教学上，陆俊林与刘先华、陈向群、管雪涛、孙广宇共同组成《计算机系统导论》跨学院课程团队。课程团队涵盖信息科学技术学院、电子学院、计算机学院、集成电路学院，说明其内部网络不仅跨研究组，也跨越硬件、软件与系统教学环节。[课程报道](https://eecs.pku.edu.cn/info/1011/5533.htm)

### 4.2 跨机构合作

跨机构关系主要沿两条线展开。第一条是国家任务与产业化线：其公开英文主页称其参与国家科技重大专项、863计划等项目；MPRC公开页面说明实验室受到“211工程”“985计划”“863计划”“核高基”重大专项支持。由此可确定其处在高校—国家任务—工程中心的协作框架中，但具体项目合作单位与项目分工需要逐项立项材料确认。[实验室介绍](http://lab-equip-query.pku.edu.cn/Lab/LabInfoDetail?sysbh=0010101)

第二条是计算机教育协同线。2024年计算机“101计划”核心课程建设工作会由陆俊林与郭耀主持，参会和报告嘉宾来自浙江大学、北京航空航天大学、国防科技大学、中国人民大学、昆明理工大学等机构，覆盖130余所高校的300余位试点相关人员。这是以课程建设、教材试点和师资培训为中心的跨校网络，并不应误解为其个人科研合著网络。[会议报道](https://cs.pku.edu.cn/info/1263/3221.htm)

### 4.3 国际合作

可公开确认的国际关联主要是教育与实验室合作接口，而非以陆俊林为作者的国际长期合作清单。旧版英文主页记载其参与ACM SIGCSE China Chapter、ACM CE2016 Curriculum Guidelines相关工作；MPRC历史介绍提及中心曾与Intel、UCLA建立联合实验室。上述信息说明MPRC具有国际课程标准与联合实验室接触面，但目前公开资料不足以确认陆俊林在Intel/UCLA联合实验室中的具体角色、合作起止时间或国际共同指导关系（待核实）。因此，不将一般性的实验室国际合作叙述扩大为其个人国际合作者名单。

## 五、业界合作关系深度分析

### 5.1 自主CPU与产业化：从MPRC研发到北大众志

陆俊林的业界关联不能简单理解为单次企业委托，而是嵌在MPRC的技术转化链路中。北京大学计算机系统结构实验室公开介绍指出：1999年，实验室研制支持CPU正向设计的软硬件协同设计环境及16位CPU原型；2002年，基于实验室开发的北大众志-863 CPU系统芯片的网络计算机开始试用；同年，为推进CPU和系统芯片产品化、产业化，北京大学批准成立北京北大众志微系统科技有限责任公司。[实验室介绍](http://lab-equip-query.pku.edu.cn/Lab/LabInfoDetail?sysbh=0010101)

陆俊林作为实验室副主任、MPRC研究成员，其论文记录可精确显示参与的技术环节：在《面向UMPC的北大众志-SK系统芯片设计》中，他与程旭等人讨论了把CPU、芯片组、显示控制和多类I/O集成为单芯片的SoC架构，并以多媒体加速、层次化存储和低功耗方案面向教育、电子政务及个人信息处理。由此可将其产业关联界定为**自主处理器/SoC关键架构与系统化设计的研发—验证—产品化接口**，而非在缺少股权、职务或合同公开证据时将其称作企业高管或创业者。[论文索引](http://www.wanfangdata.com.cn/details/detail.do?_type=perio&id=jsjxb200811002)

该网络的技术价值在于：研究问题从NoC、存储层次、处理器预执行等微结构议题，延续到SoC集成、软硬协同和应用系统；组织价值则在于以工程研究中心为载体，连接国家重大项目、研究生训练和企业化承接。北大众志的具体经营状态、陆俊林是否曾担任该企业任何法定/管理职务，均未在本报告采用的权威公开材料中证实，待核实。

### 5.2 创业孵化与人才流动

本报告未发现可公开证实陆俊林本人创办企业、持股或担任北大众志高管的材料，因此不能将“北大众志源自MPRC产业化”直接等同于“陆俊林个人创业”。可以确认的是，MPRC/计算机系统结构实验室作为教育部工程研究中心，具有明确的产业化使命和真实产品研发环境；这为成员和学生提供从体系结构、编译/操作系统到芯片和应用系统的工程训练场景。

其更可见的“孵化”角色目前体现在教育创新与人才入口建设：一是将《计算机组成》建设成国家级精品在线开放课程；二是参与建设国家级一流本科课程《计算机系统导论》；三是作为信息科学技术学院副院长参与图灵班、信息学夏令营、推免与生涯指导等活动。2024年信息学夏令营中，他介绍了本科—研究生衔接和科教融合协同培养模式；2023年图灵班论坛中，他主持信息学竞赛人才培养论坛。这些工作有助于形成“中学信息学—本科系统能力—科研/产业实践”的长链条，但不应替代对其直接研究生去向的逐人确认。[夏令营报道](https://eecs.pku.edu.cn/info/1040/6234.htm)

## 七、Connection圈层总结

- **第一圈层：MPRC/系统结构实验室核心协作圈。** 以程旭（实验室主任）、陆俊林与刘先华（实验室副主任）为组织骨架，叠加佟冬、王宏伟、易江芳、刘姝等在NoC、处理器和PKUnity SoC论文中出现的研发协作节点。该圈层的共同目标是自主CPU、处理器结构与SoC系统研发。
- **第二圈层：系统能力课程与计算机本科培养圈。** 陈向群、管雪涛、孙广宇、刘先华等共同构成《计算机系统导论》团队；陆俊林以《计算机组成》、系统导论及混合式课程实践，将体系结构知识扩展为大规模本科教学影响力。
- **第三圈层：拔尖人才与招生培养圈。** 围绕图灵班、信息学竞赛人才培养、全国优秀中学生信息学夏令营、浙江招生组以及学院推免/生涯指导，连接中学教练、竞赛学生、院系教学管理者及校友导师。该圈层的强项是人才入口和本科—研究生衔接，而非个人实验室毕业生名册。
- **第四圈层：国家任务与产业转化圈。** 通过MPRC、国家863/核高基等项目背景及北大众志产业化链路，连接高校工程研究中心、国家重大任务与自主CPU/SoC产品化场景。陆俊林的可证实角色是研发和实验室管理/教学节点；企业职务、投资关系及直接创业身份均应逐项核实。
- **第五圈层：全国及国际教育协同圈。** 通过计算机“101计划”、ACM SIGCSE China Chapter、CE2016课程指南以及图灵班论坛，连接国内高校课程改革网络与国际计算教育标准化讨论。有关Intel、UCLA联合实验室属于MPRC层面的历史国际关联，陆俊林的个人参与程度待核实。

总体而言，陆俊林的网络呈现“**自主处理器研发共同体 + 系统能力课程共同体 + 拔尖人才培养共同体**”三层叠合结构。其最稳固、证据最充分的关系是MPRC内部协作、国家级课程建设和学院本科培养管理；直接指导研究生的完整名录及其毕业去向则仍需依托一手校友/学位档案补齐，不能由论文署名替代。
