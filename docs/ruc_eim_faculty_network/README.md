# 中国人民大学 信息学院经济信息管理系教师学术关系网络报告

> 报告生成时间：2026年8月

## 团队简介

经济信息管理系是中国人民大学信息学院历史最悠久的建制之一，可追溯至萨师煊先生1950年代创建的经济信息（经济数学）教学传统，是"信息技术×经济管理"交叉学科的策源地。现任系主任为**程絮森教授**（教育部青年长江学者，2024年12月起接任；前任系主任许伟任期为2019—2024年）。全系五位教授覆盖数字经济的完整谱系：**程絮森**（曼彻斯特大学商学院信息学博士，曾任职对外经贸大学九年）深耕电子商务与社交媒体用户行为；**梁循**教授（海外博士，教育履历官方未披露）长期从事社交大数据挖掘与金融科技，与京东、腾讯、华为等企业有长期横向合作；**余力**教授（北航系统工程博士，推断师承刘鲁）聚焦数据挖掘与推荐系统；**左美云**教授（哈工大管理科学与工程博士，吴玉章讲席教授、曾任信息学院副院长）是国内"智慧养老/智慧医养"方向的代表性学者与组织者；**许伟**教授（中科院管理科学与工程博士、信息学院与智慧治理学院双副院长）主攻金融科技与智慧治理，是国家级青年人才。

该系的特点是"IS（信息系统）国际范式+人大经管基因"的双轨结构：一方面深度嵌入国际信息系统学界（HICSS、ICIS、PACIS、MISQ/ISR 等会议与期刊），另一方面依托人大财经学科优势发展金融科技、智慧养老、智慧治理等中国特色交叉方向。系内已荣退的资深教授包括杨小平（经济信息管理系原系主任）等。

## 研究方向与圈层结构概述

该系的学术网络呈现"国际 IS 圈+国内交叉学科联盟"双环结构。国际环上，程絮森经曼彻斯特大学接入欧洲 IS 学派（与 Alex Zarifis 29次合作、HICSS 深度参与），许伟经香港城市大学马建（26次合作）与中科院汪寿阳接入"港校 IS+预测科学"谱系，左美云经新加坡国立大学潘善琳（约9次）接入环太平洋 IS 共同体；三人分别构成 HICSS 三个 minitrack 的组织网络。国内环上，左美云以中国老年学和老年医学学会智慧医养分会主任委员身份构建了横跨30余家高校与产业机构的"智慧医养联盟"（周俊杰、马丹等学生已扩散至各高校），是全系最大的自主学术共同体；梁循则与京东、腾讯、华为、日立、方正、农行、阿里等企业保持长期项目合作，是全系产业网络最密集的学者。

系内协同方面，许伟—梁循—杨小平合著的《金融数据挖掘》代表系内知识传承；许伟的 LISA 实验室（陈润宇、袁慧等学生梯队）与程絮森的电商研究团队是当前产出主力；余力与卢卫等计算机系教师在 MVideoRec 等成果上存在跨系合作。

## 产业转化与人才培养亮点

该系的产业转化路径高度多元：梁循与许伟代表"企业横向课题+联合实验室"模式（金融风控、电商预测、智慧城市）；左美云代表"社会服务+产业联盟"模式（智慧医养分会、《智慧医养研究动态》会刊、135期月度追踪）；程絮森代表"政策咨询"模式（首都发展与战略研究院副院长，数字经济政策研究）。人才培养上，毕业生广泛进入金融机构科技部门、互联网企业与政府部门，学术后代中陈润宇（对外经贸大学副教授）等已形成新一代辐射节点。作为"计算机×经管"的交叉建制，该系是人大信息学院区别于纯工科院校信息学院的独特资源。
