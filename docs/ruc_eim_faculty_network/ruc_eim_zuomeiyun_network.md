## 一、学者基本信息

左美云，男，1971年生，中国人民大学信息学院经济信息管理系教授（吴玉章讲席教授、二级教授），曾任信息学院副院长（学院现任领导页已不再列名，个人教师页仍保留该表述，卸任时间约2023—2024年），管理科学与工程专业与电子信息专业博士生导师、硕士生导师。全国社会科学基金重大项目和教育部社科重大项目首席专家，主持国家自然科学基金项目5项（最近一项后评估特优）。他是国内"智慧养老/智慧医养"研究方向的代表性学者与组织者——担任中国老年学和老年医学学会智慧医养分会主任委员（首届2018年成立至今连任）、中国人民大学智慧养老研究所所长，发起并持续组织全国性智慧养老与智慧医疗发展论坛、中日智慧养老论坛及中埃智慧医养论坛，主编月度会刊《智慧医养研究动态》（截至2025年已出版135期），并持续发布"中国智慧医养领域发展十件大事"。

主要学术兼职：中国信息经济学会副理事长；中国老年学和老年医学学会智慧医养分会主席（主任委员）；信息系统协会中国分会（CNAIS）常务理事。校内兼职：中国人民大学智慧养老研究所所长、数据工程与知识工程教育部重点实验室研究员、国家发展与战略研究院社会系统工程研究中心研究员、区块链研究院研究员、元宇宙研究中心研究员。

主要荣誉：教育部新世纪优秀人才；教育部宝钢优秀教师奖；霍英东青年教师基金获得者；北京市高等学校教学名师奖；中国信息协会"中国信息化百名学术带头人"；中国人民大学"十大教学标兵"、杰出学者、明德学者、先进工作者；中国老年学和老年医学学会2023年度"争先创优先进个人"、2024年度"先进个人"。著作《信息系统开发与管理教程》（清华大学出版社）获北京市精品教材奖；论文《企业知识管理内容框架》（中国人民大学学报，2003）获北京市第八届哲学社会科学优秀成果二等奖。

## 三、博士教育背景

### 博士阶段（哈尔滨工业大学管理学院，1995—1998年）

左美云于1995年至1998年在哈尔滨工业大学管理学院攻读管理科学与工程专业博士学位（管理信息系统方向），获管理学博士学位，据第三方引用页面为"中国首批管理学博士学位获得者"之一。**其博士导师在人大官网、百科词条及可检索的公开资料中均未披露**，本报告如实说明。

其教育轨迹具有鲜明的"工科→管理"复合背景：本科（电子精密机械）与硕士（工业自动化仪表）均在哈工大机电学院接受工科训练，博士阶段转入管理学院管理科学与工程专业。这一背景直接塑造了其"技术+管理"结合的研究风格——从早期的企业信息化成熟度、IT项目管理（GERT工期估算），到知识管理，再到智慧医养中的技术应用采纳研究。

哈工大管理学院是中国信息管理与信息系统专业的主要发源地之一（该专业始建于1978年，管理科学与工程为国家重点学科），左美云在此接受了国内最早一批MIS学科训练，这也解释了其与哈工大电子健康研究圈（郭熙铜教授、Doug Vogel教授等）后续在智慧养老/电子健康领域持续合作的现象——2023年第九届智慧养老与智慧医疗发展论坛即由人大智慧养老研究所与哈工大联合主办。

博士毕业当年（1998年），其专著《知识经济的支柱——信息产业》由中国人民大学出版社出版，显示其在博士阶段已聚焦信息产业与信息化主题。

### 国际学术网络中的"准师承"关系

在缺乏明确博士师承的情况下，理解左美云学术网络的关键是其2010年代与**新加坡国立大学潘善琳（Shan Ling Pan）教授**的长期合作（~9篇，2010—2019）。两人合作覆盖ICIS、PACIS、JAIS、ISJ、IJIM、JASIST、IEEE TEM等IS领域顶级发表渠道，主题包括中国移动绿色IT领导力、机场大型IT项目敏捷性、B2C平台资源编排、平台运营敏捷性等案例研究。潘善琳是国际IS学界案例研究方法的代表性学者，这一合作实质上为左美云及其学生提供了国际发表的方法论通道——其多名学生（如参与该系列论文的博士生）通过此渠道进入国际IS学术共同体。2013年左美云赴纽约州立大学布法罗分校任访问教授，亦属其国际化网络的一环。

## 六、业界合作关系深度分析

左美云的产业合作与其"智慧养老"学术组织工作高度绑定，呈现"**学术联盟驱动型**"特征——以中国老年学和老年医学学会智慧医养分会为平台，将养老产业各方（企业、政府、医疗机构、高校）纳入统一网络，而非以单一企业横向项目为主。

### 1. 智慧医养产业联盟（中国老年学和老年医学学会智慧医养分会）

**合作深度：★★★★★（发起者与实际领导者）**

智慧医养分会2018年成立、挂靠人大信息学院，左美云任主任委员，会员119余名，横跨学界、养老产业与科技企业。分会产业侧活动包括：每月出版会刊《智慧医养研究动态》（累计135期）；每年发布"中国智慧医养领域发展十件大事"；自2018年起与合肥工业大学、上海大学、汕头大学、哈尔滨工业大学、上海交通大学等联合举办5次以上全国性智慧养老与智慧医疗发展论坛（截至2025年已办至第九届）；联合主办三届中日智慧养老论坛及首届中埃智慧医养论坛；开设"智慧医养大讲堂"系列讲座及青年学者论坛。该分会于2023、2024年连续获评总会"先进集体"，左美云连续两年获"先进个人"。

### 2. "老友帮"公益平台

**合作深度：★★★☆☆（自建运营的落地平台）**

左美云团队开发并运营国内第一个专门面向老年人的公益型社交网络平台"老友帮"（www.rd1860.com），是其智慧养老研究从论文走向实践落地的标志性载体，"在老年人信息化领域引起了很大的反响"（官网表述）。该平台亦为其学生提供了真实场景的用户研究数据来源。

### 3. 政府与企事业横向项目

**合作深度：★★★☆☆（项目量大但单点分散）**

官网披露其主持"各类政府系统以及其他企事业项目30余项"。可考证的早期项目包括：铁路货车维修信息系统开发、大庆炼油厂信息系统开发、企业信息化成熟度模型及评价软件研制等，均为典型的企业信息化/IT项目管理横向课题。近期研究（IJIM 2020论文）涉及地方政府养老服务的IT治理机制，反映其与地方民政系统的政策研究合作。北京市社科基金重点项目、国家社科重大项目（智慧养老数据资源体系建设）均属面向国家养老战略的政策研究。

### 4. 产业合作总结

与典型CS学者的企业联合发文模式不同，左美云的DBLP记录中几乎没有企业署名作者，其产业合作主要体现为**平台化、组织化的联盟运作**：通过分会把智慧养老产业链（智慧医养产品与服务商、养老机构、政府部门）组织进学术共同体，再通过论坛、会刊、年度十件大事等机制持续运营。这种"学会经济"模式使其成为国内智慧医养领域事实上的学术枢纽之一。此外，其"老友帮"平台与政府养老IT治理研究构成产学研的两翼。

**产出规模与方向演进：** DBLP收录69条（2005年起），官网另列大量中文文献（总量无法完整统计）。方向演进清晰：企业信息化/IT项目管理（1998—2007）→ 知识管理/信息系统采纳（2007—2015）→ 智慧养老/智慧医养与老年健康信息学（2015年至今），近三年进一步融入医疗AI方法。其独特定位在于：**以学术组织能力而非纯论文产出构建学术影响力**——智慧医养分会、研究所、论坛体系、会刊与年度十件大事构成一个自我强化的领域生态，使其成为国内智慧养老研究无可绕开的枢纽人物之一。
