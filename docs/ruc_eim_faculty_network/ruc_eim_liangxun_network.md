## 一、学者基本信息

梁循（Xun Liang）现为中国人民大学信息学院经济信息管理系教授。人大信息学院教师页将其列于经济信息管理系“教授”栏目；信息学院博士招生页面及2022年博士生导师名单均将其列为计算机应用技术“智慧社会与信息系统”方向导师，且其指导博士生的答辩公告可交叉印证其博士研究生指导资格。故本报告将其称为**教授、博士生导师**。

其官方教师页列出的研究方向为：人工智能风险治理、智能体、可信检索增强生成、社交网络管理、知识管理、智能金融、知识图谱、大模型安全性评测、数字经济。社会网络智能计算实验室页面则将团队研究概括为社会网络分析、机器学习、金融大数据、网络心理学、网络金融及网络舆情等。二者共同显示其研究由社会计算与网络信息挖掘，扩展至图学习、金融数据应用以及生成式人工智能安全治理。

梁循的“智能金融、金融大数据、网络金融”是校方/实验室公开研究方向；同时，教师页列出农行及多家互联网企业项目。因此，可以将其业界网络概括为**“社会计算与数据智能方法面向金融及平台场景的项目合作网络”**。但公开一手资料没有给出各企业项目的具体题目、起止时间、成果归属、联合署名人员或资金规模，也没有直接说明哪一项属于金融科技。因此不能将这些项目进一步写成“深度联合实验室”“长期独家金融科技合作”或列出未经披露的合作成果。

DBLP 中2019年金融时间序列预测等记录表明金融数据是书目主题之一，但该 pid 存在前述元数据局限，且论文共同署名不能替代企业合作证据。故本节严格区分：**企业项目关系**来自官方教师页，**金融研究主题**来自教师/实验室页和书目，二者尚不能逐项一一对应。
