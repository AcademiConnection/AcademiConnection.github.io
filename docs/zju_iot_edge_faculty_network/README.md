## 二、教师角色定位

董玮是 EmNets（物联网与智能边缘计算）实验室的学术带头人，现为浙江大学计算机学院副院长、长江学者特聘教授、国家万人计划青年拔尖人才、CCF杰出会员、ACM中国SIGMOBILE副主席。他深耕物联网、智能边缘计算、无线感知与联邦学习边缘化方向，曾在香港科技大学从事访问研究。

其学生谱系已现"反哺"形态：博士生赵志为现任电子科技大学教授，高艺已任浙江大学教授（与董玮的EAGLE平台长期合作；"陈纯—卜佳俊—董玮"式的直接师承链证据不足，报告中已按可证实的平台协作与合作发表关系处理）。

---

## 三、实验室关系网络的整体观察

EmNets 隶属 EAGLE（浙江大学创新软件研发中心）大平台，与卜佳俊团队共用工程化建制。实验室与阿里巴巴等企业保持长期联合研究合作（边缘计算、IoT平台方向），在 SIGCOMM/MobiCom/TON 等网络与移动计算顶级会议持续产出。作为单一PI型实验室，其网络结构以"PI-学生-业界平台"三点为主轴，学术合作跨香港科大、电子科大等节点，属于浙大物联网方向的精干攻坚力量。
