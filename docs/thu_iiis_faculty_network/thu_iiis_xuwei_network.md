## 二、教育背景与职业履历

### 教育经历

徐葳的求学路径横跨中美顶尖学府，展现了扎实的系统与工程根基：

1. **清华大学计算机系（本科前两年）**：徐葳在清华大学计算机系完成两年本科学习，打下了扎实的计算机科学基础。之后转学至美国继续深造。
2. **宾夕法尼亚大学（University of Pennsylvania）**：在宾夕法尼亚大学获得计算机科学学士学位。宾大的工程与应用科学学院（SEAS）在计算机系统和网络领域具有雄厚实力。
3. **加州大学伯克利分校（UC Berkeley）**：在伯克利EECS系获得计算机科学硕士和博士学位（2010年）。博士期间，他是著名RAD Lab（Reliable Adaptive Distributed systems Lab）的成员，导师为David Patterson教授和Armando Fox教授。博士论文研究方向为"通过分析自由文本控制台日志进行系统问题检测"（analyzing free text console logs for problem detection），这一工作将自然语言处理技术应用于大规模分布式系统的运维诊断，体现了其跨学科研究的早期探索。

David Patterson教授是计算机体系结构领域的泰斗，2017年因RISC指令集架构和RAID存储系统的贡献获图灵奖，同时也是RISC-V的奠基人。Armando Fox教授则是软件工程和云计算领域的知名学者，擅长将研究成果转化为教学实践。在两位大师的指导下，徐葳不仅习得了系统设计的深层功底，也深受其"产学研结合"理念的影响。

### 职业履历

- **2010-2012：Google总部软件工程师**。博士毕业后，徐葳加入Google总部担任软件工程师，工作约2.5年，负责基础架构（infrastructure）可靠性方面的研发。这段经历使他深入理解了超大规模数据中心的实际运行挑战，为他后来在清华的数据中心网络和分布式系统研究提供了珍贵的工程直觉。
- **2013年：加入清华大学交叉信息研究院**。应姚期智院士邀请，徐葳回国加入交叉信息研究院，从助理教授做起。据徐葳本人回忆，在Google工作期间，通过导师David Patterson的介绍与姚期智院士会面，这次会面成为他2013年回国的一大动力。他曾表示："我一直都说，是姚期智先生把我从国外捡回来的。"
- **2013-2024：助理教授 -> 长聘副教授 -> 教授**。在清华期间，徐葳逐步晋升，历任助理教授、长聘副教授、教授。同时担任过多项重要行政职务：助理院长、教育部在线教育研究中心国际合作总监、清华大学金融科技研究院副院长兼区块链研究中心主任等。
- **2024年11月至今：交叉信息研究院副院长**。根据2024年11月的任命通知，徐葳被任命为清华大学交叉信息研究院副院长。
- **2018年至今：华控清交联合创始人兼首席科学家**。通过转化姚期智院士和徐葳教授的科研成果，清华大学于2018年发起成立了华控清交信息科技公司，徐葳担任首席科学家。

## 三、学生培养情况

徐葳自2013年在交叉信息研究院独立指导研究生以来，已培养了一批优秀的博士和硕士研究生。他的课题组目前聚焦四大方向：安全和鲁棒的AI应用、AI安全、隐私保护应用、高性能分布式LLM训练与推理。以下根据公开信息梳理其已毕业和在读学生的情况。

### 1. 王国赛（Guosai Wang）（博士毕业生，徐葳指导）

王国赛是徐葳早期指导的博士研究生之一，在数据中心硬件故障分析和隐私保护数据检索方面有重要贡献。他作为第一作者在DSN 2017发表的论文"What Can We Learn from Four Years of Data Center Hardware Failures?"荣获**DSN 2017最佳论文奖**，该论文对大规模数据中心中硬件故障的模式和规律进行了系统性分析，具有重要的工业界影响力。此外，他还在SIGIR 2018发表了关于数据检索模式隐私保护的工作。王国赛的研究深度结合了徐葳在Google积累的数据中心运维经验与学术前沿。毕业后，王国赛参与华控清交的研发工作，将隐私保护计算技术产业化。

### 2. 李培伦（Peilun Li）（博士毕业生，徐葳指导）

李培伦在区块链系统领域做出了突出贡献。他在USENIX ATC 2020发表的论文"A Decentralized Blockchain with High Throughput and Fast Confirmation"（与姚期智院士等人合作）提出了一种高性能去中心化区块链系统Conway，该系统是徐葳课题组在联盟区块链方向的重要成果。他还在APSys 2016发表了关于分布式存储优化的论文。李培伦的研究体现了徐葳课题组在分布式系统和区块链交叉领域的核心竞争力。

### 3. 李晨星（Chenxing Li）（博士毕业生，徐葳指导）

李晨星是徐葳在区块链系统方向的核心学生。他在OSDI 2023发表的论文"LVMT: An Efficient Authenticated Storage for Blockchain"提出了一种高效的区块链认证存储系统，发表在操作系统领域最顶级会议OSDI上。此前，他参与了Conway区块链系统的研发（USENIX ATC 2020）。李晨星的工作将密码学认证技术与分布式存储系统深度融合，代表了徐葳课题组在区块链基础设施方向的最高学术水平。

### 4. 李轶（Yi Li）（博士毕业生，徐葳指导）

李轶是徐葳在隐私保护计算方向的核心学生。他在KDD 2019发表的论文"PrivPy: General and Scalable Privacy-Preserving Data Mining"提出了一套通用且可扩展的隐私保护数据挖掘框架，是该方向的代表性工作。此外，他还在PKDD 2017发表了关于差分隐私跨机构数据挖掘的论文"PEM"。李轶的研究直接支撑了华控清交PrivPy多方安全计算平台的技术基础。毕业后，李轶继续在隐私计算领域深耕，参与了多项学术与产业合作。

### 5. 赵博涵（Bohan Zhao）（博士毕业生/在读，徐葳指导）

赵博涵在数据中心网络和分布式系统方向表现突出。他以第一作者在NSDI 2023发表论文"NetRPC: Enabling In-Network Computation in Remote Procedure"（与吴文斐合作），提出了将计算能力下沉到网络设备的远程过程调用框架。随后在ASPLOS 2024发表论文"Training Job Placement in Clusters with Statistical In-Network Aggregation"，研究集群中训练任务的放置与网络内聚合优化。这两篇论文均发表在系统与体系结构领域的顶级会议上，展现了徐葳课题组在网内计算（in-network computing）方向的前沿探索。

### 6. 范晓昱（Xiaoyu Fan）（博士后，徐葳指导）

范晓昱是徐葳课题组的博士后研究员，在多方安全计算（MPC）的工程化和自动化方面做出了重要贡献。她在CCS 2022发表的论文"NFGen: Automatic Non-linear Function Evaluation Code Generator for General-purpose MPC Platforms"提出了一种自动化的MPC非线性函数求值代码生成器，大幅降低了MPC应用的开发门槛。此后，她在IPDPS 2025发表论文"Pair-then-Aggregate"，提出了大规模MPC计算的并行编程范式和自动并行执行引擎。该工作与蚂蚁集团（Ant Group）合作，体现了学术界与工业界在隐私计算领域的深度协同。

### 7. 郑舜（Shun Zheng）（博士毕业生，徐葳指导）

郑舜在机器学习和自然语言处理交叉领域有突出贡献。他在EMNLP 2019发表论文"Doc2EDAG: An End-to-End Document-level Framework for Chinese Financial Event Extraction"，在ACL 2019发表论文"DIAG-NRE"，在JMLR 2017发表了关于分布式双坐标优化的论文。郑舜的研究方向横跨金融文本分析和分布式优化，体现了徐葳课题组在金融科技和自然语言处理交叉方向的探索。毕业后，郑舜进入微软亚洲研究院（MSRA）工作。

### 8. 班宇坤（Yikun Ban）（博士毕业生，徐葳指导）

班宇坤在反欺诈和大数据分析方向有重要贡献。他在WWW 2019发表论文"No Place to Hide: Catching Fraudulent Entities in Tensors"，利用张量分析方法检测电商平台中的欺诈实体。该工作与刘鑫（McGill大学）等人合作，结合了学术研究与实际反欺诈场景的需求。

## 五、业界合作关系深度分析

### 5.1 华控清交信息科技有限公司

华控清交是徐葳产业转化最核心的企业，也是其学术网络向产业延伸的最重要节点。

**公司概况**：
- 成立时间：2018年9月6日
- 性质：由清华大学通过转化姚期智院士和徐葳教授的科研成果发起成立的数据科技企业
- 核心理念：实现数据"可用不可见，使用可控可计量"
- CEO：张旭东（前高盛全球合伙人，1989年进入华尔街，2013年从高盛退休）
- 首席科学家：徐葳
- 核心技术团队：多位成员来自清华大学"姚班"

**技术产品**：
公司已自主研发并推出了一系列基于多方安全计算（MPC）的隐私计算技术产品，已注册的软件著作权包括：
- 清交PrivPy多方计算平台
- 多方安全计算明文模拟器软件
- 多方安全计算缓存系统
- 明密文混合计算系统
- 多方安全计算数据市场平台
- 隐匿查询系统
- 多维隐私数组科学计算库软件

其中，PrivPy平台直接源于徐葳课题组在KDD 2019发表的学术成果PrivPy，体现了从学术论文到产品的完整转化链条。

**融资与估值**：
- B轮融资近7亿元人民币，估值达45亿元
- 投资方包括：联想创投、国科投资、中关村科学城、华兴资本、OPPO集团、大湾区共同家园发展基金、复星创富等知名机构

**行业影响**：
- 2021年，华控清交参与了北京国际大数据交易所以及湖南大数据交易所的建立，为我国新型数据交易所提供了重要的技术支持
- 参加了《多方安全计算金融应用技术规范》等30多个行业标准的制定
- 入选北京市专精特新"小巨人"企业名单
- 是国内首家突破明文数据交易方式、把"新型"数据交易模式和平台付诸实施的企业

**徐葳的角色**：作为联合创始人兼首席科学家，徐葳负责公司的技术战略方向和核心技术研发。他将姚期智院士的多方安全计算理论通过工程实现大幅提升效率，使之从学术理论走向产业应用。徐葳将这一过程描述为"产学研"实践，深受其导师David Patterson教授和姚期智院士两位图灵奖得主的影响。

### 5.2 图灵人工智能研究院（南京）

**机构概况**：
- 2018年4月，由清华大学与南京市合作共建
- 依托清华大学交叉信息研究院科研优势

## 七、Connection圈层总结

徐葳教授的学术与产业网络呈现出独特的"伯克利-清华-产业"三角结构，其核心圈层可概括如下：

### 第一圈层：核心学术-产业共同体

1. **姚期智院士**：徐葳最关键的学术与产业合作伙伴。姚期智不仅是徐葳回国任教的引路人，更是华控清交的共同创始人。两人的合作完美互补——姚期智提供理论基础（多方安全计算、混淆电路），徐葳提供系统工程实现能力，共同将MPC从理论推向产业落地。这一合作关系是徐葳整个学术产业网络的核心轴心。

2. **David Patterson教授**：徐葳的博士导师，2017年图灵奖得主。Patterson不仅传授了系统设计的深层功底，更重要的是促成了徐葳与姚期智院士的会面，这一连接改变了徐葳的职业轨迹。Patterson的"产学研结合"理念也深刻影响了徐葳后来创建华控清交的路径。

3. **张旭东（华控清交CEO）**：前高盛全球合伙人，华控清交的联合创始人兼CEO。张旭东的华尔街金融背景与徐葳的技术背景形成了"技术+金融"的互补组合，共同推动华控清交成为隐私计算行业的领军企业。

### 第二圈层：学术合作网络

4. **龙帆（Fan Long）**：区块链系统方向的长期合作者，共同发表多篇顶会论文（OSDI, ATC, SOCC）。
5. **Thomas Moscibroda**：前MSR/IIIS讲席教授，区块链与系统领域的国际合作者。
6. **刘洋（清华大学）**：NLP方向合作者，机器翻译领域的联合研究。
7. **刘锌（McGill大学）**：反欺诈与优化方向的国际合作者。
8. **吴文斐**：数据中心网络方向的合作者。

### 第三圈层：学生培养网络

徐葳培养的学生构成了其学术影响力的延伸网络。已毕业学生主要流向：
- **产业界**：进入华控清交等科技企业，将研究成果直接转化为产品（如王国赛、李轶）
- **工业界实验室**：进入微软亚洲研究院等企业研究机构（如郑舜）
- **学术继续深造**：在系统、安全、AI等方向继续学术生涯

### 第四圈层：产业生态网络

9. **华控清交技术团队**：多位清华姚班毕业生组成核心技术研发团队
10. **北京国际大数据交易所、湖南大数据交易所**：华控清交参与建设的新型数据交易基础设施
11. **联想创投、国科投资、华兴资本等投资方**：华控清交的投资机构网络
12. **蚂蚁集团**：在MPC工程化方向的科研合作伙伴
13. **南京图灵人工智能研究院生态企业**：通过副院长角色连接的AI产业孵化网络
14. **金融机构与监管部门**：通过金融科技研究院和AI安全治理活动连接的银行、证券、监管机构网络

### 网络特征总结

徐葳的connection网络呈现出以下鲜明特征：

- **双图灵奖传承**：师从David Patterson（2017图灵奖），受姚期智院士（2000图灵奖）邀请回国，其学术血统直接连接两位图灵奖得主，这在华人学者中极为罕见。
- **理论-工程桥梁**：徐葳的核心价值在于将姚期智院士的密码学理论通过系统工程实现落地，这一"理论到工程"的转化能力使其成为产学研链条中不可替代的关键节点。
- **从数据中心到数据流通**：其研究兴趣从Google时代的数据中心基础设施运维，逐步扩展到隐私保护计算和数据要素流通，形成了"数据全生命周期"的研究视角。
- **多维度行政角色**：同时担任交叉信息研究院副院长、金融科技研究院副院长、图灵AI研究院副院长、AI治理研究院首席专家等多重角色，使其网络覆盖学术、产业、政策和治理等多个维度。
- **产业深度与学术高度并重**：既在OSDI、NSDI、CCS等系统顶会持续产出，又成功孵化估值45亿元的科技企业，是少数能同时在学术顶会和产业落地两方面取得突出成就的华人学者。
