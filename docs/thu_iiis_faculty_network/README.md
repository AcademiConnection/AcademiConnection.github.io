# 清华大学交叉信息研究院（IIIS）教师学术关系网络报告

## 团队简介

清华大学交叉信息研究院（Institute for Interdisciplinary Information Sciences, IIIS）由2000年图灵奖得主姚期智院士于2011年创立，下辖人工智能基础研究中心和量子信息中心（CQI）两大核心科研机构。研究院以"最优秀的本科生和最优秀的本科教育"为理念，于2005年创办清华学堂计算机科学实验班（姚班），涵盖计算机科学、人工智能和量子信息科学三大方向。

截至2026年，IIIS累计培养研究生360余名、本科毕业生660余名，全日制在校生610余人；5位校友荣获斯隆奖，32位海外引进高层次人才加盟。研究院全职教师队伍涵盖理论计算机科学、密码学、人工智能（强化学习、机器人学、计算机视觉等）、量子计算（离子阱、超导、中性原子、量子网络等）等前沿方向。

本报告选取10位代表性教师，覆盖IIIS三大研究方向的学术领袖与青年骨干。

## 研究方向与圈层结构

IIIS的教师网络呈现出"三大方向、一代人"的结构特征：

**量子信息方向（姚期智—段路明—马雄峰为核心）**：姚期智院士统领全局，段路明教授担任量子中心（CQI）执行主任，主攻离子阱量子计算并创办华翊量子；马雄峰教授深耕量子密码学与QKD，与中国电信量子集团深度合作。三人构成量子信息方向的"院长—中心主任—核心PI"三级架构。

**人工智能方向（黄隆波、李建、袁洋、陈建宇、许华哲、高阳等为骨干）**：覆盖强化学习理论（黄隆波）、理论CS与ML理论（李建）、AI基础理论与智能医疗（袁洋）、机器人学与自动驾驶（陈建宇）、RL与机器人视觉触觉（许华哲）、计算机视觉与RL（高阳）等子方向。

**"伯克利归国四子"现象**：陈建宇、许华哲、高阳三位助理教授均为UC Berkeley博士毕业（其中许华哲与高阳师出同门，均为Trevor Darrell指导），连同前边塞科技创始人吴翼（Berkeley PhD，师从Stuart Russell），被业界并称为"伯克利归国四子"。四人分别在星动纪元、破壳机器人/星海图、千寻智能等具身智能企业中担任核心角色，构成中国具身智能赛道的高密度人才和技术网络。

**姚班校友军团**：姚期智创办的姚班培养了大批顶尖人才，其中包括楼天城（小马智行）、印奇/唐文斌/杨沐（旷视科技）、龙凡（Conflux树图区块链）、姚顺雨（腾讯首席AI科学家）、陈立杰（UC Berkeley助理教授，后加入OpenAI）等。这些校友在学术界和产业界的影响力构成了IIIS最独特的"人才外溢"效应。

## 产业转化亮点

IIIS教师的产业转化涵盖量子计算、机器人/具身智能、金融科技、区块链等多个领域：

- **华翊量子（HYQubit）**：段路明创办，离子阱量子计算公司，已向中国移动交付HYQ-B100百比特量子计算机
- **星动纪元（RobotEra）**：陈建宇联合创办，人形机器人公司，2026年估值约500亿元，筹备港股IPO
- **星海图 / 破壳机器人**：许华哲先后联合创办，具身智能/通用人形机器人公司
- **千寻智能**：高阳参与创办，具身智能与视觉强化学习应用
- **华控清交**：徐葳联合创办，隐私计算与多方安全计算公司，估值约45亿元
- **Conflux树图区块链**：姚班校友龙凡、姚期智指导，高性能公链项目
