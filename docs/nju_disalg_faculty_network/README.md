# 南京大学计算机软件研究所分布式算法小组（DisAlg）教师网络报告索引

南京大学计算机软件研究所分布式算法小组（DisAlg，Distributed Algorithm）是依托南京大学计算机科学与技术系、计算机软件研究所及计算机软件新技术国家重点实验室开展研究的团队。根据南京大学计算机软件研究所官网组织页，DisAlg 目前仅收录黄宇教授为小组负责人，也是该页所列的唯一负责人。黄宇的研究方向为分布式算法、分布式系统、形式规约与系统可靠性，其团队长期面向上述方向招收博士、硕士及本科生。

从公开可确认的组织结构看，黄宇的研究活动嵌入南京大学软件所的基础研究环境之中。软件所的马晓星、许畅、蒋炎岩、吕建等教授属于软件所层面的同事、协作或学术环境节点，并非 DisAlg 的共同 PI；其中吕建与黄宇共同指导的两位博士魏恒峰、杨怡玲分别获 2016 年、2017 年 CCF 优秀博士学位论文奖，是当前最明确、最可核实的学生培养连接。除这两例外，黄宇个人主页未披露当前或既往学生名册，因此不以论文署名推定其他作者为其学生。

本目录收录 DisAlg 教师网络分析报告。除黄宇外，软件所官网未列出 DisAlg 的其他小组负责人或成员，故当前报告集仅含一份教师报告；后续如有新的官方披露，可在此基础上扩展。

## 研究方向与圈层结构概述

黄宇及 DisAlg 的研究主线为"分布式算法—系统正确性—形式规格与代码协同"，具体议题包括分布式数据一致性、形式规约与模型检验（如 TLA+ 共识协议组合式模型检验）、面向真实系统的规格构建（如 EuroSys 2025 的多粒度分布式系统规格、SandTable）等。近期成果按其个人主页所列状态表述：SysMoBench（ICLR 2026，已录用）为与英属哥伦比亚大学、伊利诺伊大学香槟分校等研究者合作的工作；Specula 为 2026 年 7 月的 arXiv 预印本。

教师报告将黄宇的网络归纳为四个圈层：

- **第一圈层：DisAlg 单一负责人及共同培养纽带。** 黄宇为官网确认的 DisAlg 唯一负责人；与吕建共同指导魏恒峰（现任湖南大学副教授）、杨怡玲两位 CCF 优博奖获得者。
- **第二圈层：南京大学软件所协作生态。** 吕建、马晓星、许畅、蒋炎岩共享软件所组织环境，但关系性质不同，均不得表述为黄宇团队的共同 PI。
- **第三圈层：规格、模型检验与开源系统的项目网络。** 围绕 SandTable、Converos、SysMoBench、Specula 等项目的合作网络，并通过 ZooKeeper TLA+ 规格贡献连接 Apache ZooKeeper 开源社区。
- **第四圈层：跨机构学术与产业接口。** 以 Ivan Beschastnikh、Tianyin Xu 等国际合作者为代表的论文协作，以及以 Alibaba AIR、华为技术合作项目、CCF—华为胡杨林基金为代表的工程问题协作。

## 产业转化亮点

- **产学研联合项目。** 黄宇个人主页列出与产业方或产学研基金相关的明确技术议题项目，包括 Alibaba AIR 资助的"RDMA 和 NVM 加速 ParallelRaft 的设计与验证"（2021年1月起）、CCF—华为胡杨林基金"分布式系统深层缺陷检测"（2023年11月）、华为技术合作项目"网络操作系统竞争条件动态分析"（2025年3月）、CCF—华为胡杨林基金"分布式系统模型检验引导的测试"（2025年12月）。
- **开源系统社区衔接。** EuroSys 2025 论文将 ZooKeeper 的形式规格贡献合并至 Apache ZooKeeper 仓库，形成学术规格与开源系统社区的直接衔接；SandTable 等工作亦提供可复现的开源资源。
- **实用型验证框架。** CCF 公开活动材料显示，黄宇曾报告其团队提出的实用型 Conformance 框架，将抽象模型、实现代码与系统测试联系起来，用于并发和分布式系统中深层错误的发现、复现和修复支持。公开资料未披露该框架是否已被具体企业产品线采用、项目经费规模或知识产权安排。

需要说明的是，截至报告日期，公开资料未披露黄宇创办或控制企业、孵化公司、融资事件、股权关系或正式技术转移公司的信息；团队的可见"转化"更适合界定为研究工具、形式规格和真实系统缺陷分析的工程接口，而非商业化运营。
