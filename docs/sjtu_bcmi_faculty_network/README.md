# 上海交通大学 BCMI 实验室（吕宝粮组）学术关系网络报告

## 团队简介

仿脑计算与机器智能研究中心（BCMI，Brain-inspired Computing and Machine Intelligence）成立于2002年，由吕宝粮教授与张丽清教授共同发起设立，隶属于上海交通大学计算机科学与工程系（现计算机学院通用人工智能研究所）。两位创始人均出身日本理化学研究所（RIKEN）：吕宝粮（京都大学博士，理研1994-2002）主攻情感脑机接口与临床转化，张丽清（中山大学博士，1997-2002师从信息几何学派创始人甘利俊一Amari）主攻仿脑计算、张量学习与视觉计算，形成了"情感BCI + 类脑计算"双核并行的格局。

实验室是全球情感脑机接口领域的引领者：吕宝粮与郑伟龙（吕宝粮博士生，现为副教授，经哈佛MGH/MIT博士后训练）发布的SEED系列情绪脑电数据集（SEED/SEED-IV/SEED-V/SEED-VII/SEED-OLF）是全球最大、使用最广的情绪脑电基准，衍生论文数千篇；2024年团队成果入选"华瑙-2024年度中国脑机接口十大进展"。近年与瑞金医院深度医工交叉，产出Gram（通用脑电大模型）、CerebraGloss（首个临床脑电图解读大模型，ICLR 2026）等脑电大模型成果。

实验室网络的独特性在于"游戏产业反哺脑科学"：米哈游创始人蔡浩宇是吕宝粮的硕士生，2021年米哈游与瑞金医院共建"脑病中心-米哈游联合实验室"（吕宝粮任主任），同年吕宝粮创立上海零唯一思科技有限公司（吕宝粮持股51%、米哈游持股49%），将其"情绪X光机"抑郁症客观评估系统推向临床（已在多家三甲医院试用、评估超4500名患者），并牵头制定国内首个情感脑机接口团体标准。

## 研究方向与圈层结构

团队研究方向覆盖情感脑机接口（情绪EEG识别、多模态融合）、脑电大模型（Gram、LaBraM、CerebraGloss）、仿脑计算与张量学习、盲信号分离、语音精神健康评估（抑郁症/精神分裂症语音标志物）等。学术网络呈五层结构：第一圈层为BCMI双核及嫡系（吕宝粮—郑伟龙师生共创、张丽清Amari信息几何谱系：Amari/Cichocki→张丽清→赵启斌，赵启斌现任理研AIP张量学习团队主任形成代际闭环）；第二圈层为交大校内"联邦"（清源研究院、瑞金医院广慈教授体系、俞凯X-LANCE语音实验室、徐雷/卢宏涛等）；第三圈层为临床医学网络（瑞金医院孙伯民/徐纪文/陆勇、上海市精神卫生中心、北大六院、宣武医院）；第四圈层为产业网络（米哈游、零唯一思、盈趣科技SPEED联盟、微软亚洲研究院铸星计划）；第五圈层为国际网络（RIKEN、Cichocki、哈佛MGH、MIT、墨尔本大学）。

## 产业转化亮点

产业转化呈"数据集—诊断系统—大模型"三级链条：SEED系列数据集奠定全球学术影响力；零唯一思科技的"情绪X光机"实现抑郁症客观评估临床落地（覆盖4家顶尖医院、4500+患者评估），并牵头制定国内首个情感脑机接口团体标准；与瑞金医院合作的Gram/CerebraGloss脑电大模型将EEG解读推向临床级精度，LaBraM（ICLR 2024 Spotlight）成为脑电基础模型的标准底座。2025年7月联合盈趣科技等发起SPEED联盟，共建"脑机接口版ImageNet"开放生态。人才创业网络同样突出：蔡浩宇（米哈游）、侯晓迪（图森未来/Bot Auto，张丽清本科科研训练学生）、孔旗（九识智能，吕宝粮博士生）构成覆盖游戏、自动驾驶、无人配送的创业矩阵。
