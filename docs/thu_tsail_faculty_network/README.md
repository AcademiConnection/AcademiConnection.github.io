## 研究方向与圈层结构概述

TSAIL 课题组的研究核心围绕统计人工智能与学习理论展开，涵盖概率建模与推理、贝叶斯深度学习、扩散模型、对抗攻防、可解释机器学习、计算神经科学、强化学习等方向。课题组以"第三代人工智能"理论为统领，强调数据与知识双驱动、可信与安全并重，形成了从基础理论到算法实现再到产业落地的完整链条。

在学术圈层结构上，TSAIL 呈现"张钹—朱军—青年学者"三代传承谱系。张钹院士作为中国第一位人工智能领域的中国科学院院士，培养了近90名博士，其学术影响力辐射全国AI领域。朱军教授作为核心传承者，不仅在学术上延续张钹的理论方向，更将研究拓展到产业孵化领域，形成了"理论—算法—开源—创业—资本"全链条覆盖的独特生态。胡晓林、陈键飞、苏航等青年学者各自在深度学习与脑科学、高效机器学习、AI安全等方向形成了差异化的研究特色。

## 产业转化亮点

TSAIL 课题组的产业转化能力尤为突出。RealAI（瑞莱智慧）由田天、陈键飞等TSAIL成员于2018年联合创立，张钹院士与朱军教授共同担纲首席科学家，聚焦AI安全与可信人工智能，累计服务300余家客户。生数科技（Vidu视频大模型）由朱军课题组孵化，2023年创立，估值突破20亿美元，其核心算法U-ViT和DPM-Solver源自TSAIL的扩散模型研究。此外，课题组扩散模型算法被DALL-E 2和Stable Diffusion采用，开源项目ZhuSuan、Tianshou等在全球AI社区具有广泛影响。NIPS 2017对抗攻防竞赛中，TSAIL团队包揽全部三个赛道冠军，进一步确立了其在AI安全领域的国际领先地位。
