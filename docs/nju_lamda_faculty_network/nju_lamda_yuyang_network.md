## 三、博士教育背景与导师追溯

### 3.1 博士阶段（南京大学，2004-2011年）

俞扬2004年在南京大学计算机科学与技术系获学士学位后，留在本校直接攻读博士学位，师从周志华教授，2011年获博士学位。博士论文研究方向为演化学习（Evolutionary Learning）的理论基础，建立了演化算法的运行时间分析框架和Pareto优化逼近工具。

**博士导师：周志华（Zhi-Hua Zhou）**

周志华是LAMDA研究所所长、南京大学人工智能学院创院院长，中国科学院院士（2025年），欧洲科学院外籍院士，ACM/AAAI/AAAS/IEEE/IAPR Fellow。他是国内人工智能领域的领军学者，所著《机器学习》教材（清华大学出版社，2016年）被全国335家单位选作教材。周志华在DBLP上与俞扬合作63次，合作跨度长达20年（2005-2025年），是俞扬学术生涯中持续时间最长、影响最深远的导师。

**博士学位论文荣誉：**
- 2011年中国计算机学会优秀博士学位论文奖
- 2013年全国优秀博士学位论文奖

### 3.2 博士期间的学术起步

俞扬在博士期间的研究集中于演化学习，与周志华、钱超（当时为同实验室成员）等合作，形成了LAMDA在演化计算理论方向的独特优势。博士期间的工作获得了GECCO'11 Best Theory Paper、PAKDD'08 Best Paper、PAKDD'06数据挖掘竞赛冠军等多项奖励，为后续转向强化学习奠定了优化理论基础。

## 五、业界合作关系深度分析

### 5.1 南栖仙策（Polixir Technologies）——俞扬创立的强化学习产业化公司

南栖仙策是俞扬学术成果产业化的核心载体，由南京大学人工智能创新研究院技术孵化，2018年9月由俞扬及其博士生秦熔均联合创立。俞扬任创始人兼CEO，秦熔均任CTO。

**公司定位与技术路线：** 南栖仙策专注于通用智能决策，核心产品为智能决策工业软件"仙启"。与行业主流的无模型（model-free）强化学习路线不同，南栖仙策选择了基于"世界模型"（环境模型学习）的强化学习路线，独创"数据克隆"技术——从有限历史数据中抽象底层原理，生成更多符合原理的数据，在虚拟世界中推演亿万种结果以寻找最优决策。

**核心产品与开源项目：**
- **仙启：** 智能决策工业软件正式版，将强化学习落地技术（环境模型学习、策略迁移等）凝练为工业级工具
- **REVIVE：** 环境学习与强化学习开源软件
- **ZOOpt：** 无导数优化Python工具箱（GitHub开源）
- **NeoRL：** 近真实世界离线强化学习基准平台

**应用领域：** 工业制造、工业控制、促销策略等真实场景。南栖仙策与西安大唐达成战略合作，聚焦网信领域自主智能对抗系统产品研发。

**国际化影响：** 2021年ICML举办"Reinforcement Learning for Real Life"研讨会，南栖仙策作为唯一受邀的中国创业公司，与DeepMind、Google、Facebook、Microsoft、Nvidia、Adobe、滴滴等国际科技公司共同探讨强化学习落地难题，俞扬作为创始人受邀参加"Research-to-RealLife Gap"主题讨论。

**秦熔均（CTO）背景：** 南京大学博士，师从俞扬教授，主攻博弈与强化学习算法和理论。2018年联合创立南栖仙策，负责面向现实业务的决策技术（离线强化学习）研发及落地应用。2021年入选福布斯中国U30s和胡润中国U30s创业领袖榜单。

### 5.2 琶洲实验室（Pazhou Lab）——广州产学研合作平台

DBLP记录中俞扬的机构标注除南京大学外，还包括"Pazhou Lab, Guangzhou, China"。琶洲实验室是广东省重点建设的省级实验室，位于广州琶洲人工智能与数字经济试验区，聚焦人工智能与数字经济领域。俞扬在琶洲实验室开展强化学习相关研究，是其在广州的产学研合作平台。

### 5.3 英特尔（Intel）——强化学习落地合作

俞扬团队与英特尔（中国）在强化学习落地方面有合作。据公开报道，南京大学与英特尔合作，将游戏作为算法效力检验平台，通过一台服务器4个CPU48个盒子，用4天时间完成强化学习功能，打败内置游戏AI bot。英特尔第二期AI实践者之声夏令营活动走进南京大学，俞扬以《强化学习决策》为主题进行技术分享。

### 5.4 华为——人才输送与技术合作

华为是俞扬团队毕业生的主要去向之一。庞振家（2020届硕士，入选2018腾讯犀牛鸟精英研究生计划）、张凯峰（2020届硕士，入选2018腾讯犀牛鸟精英研究生计划）、张超（2019届硕士，入选2017腾讯犀牛鸟精英研究生计划）等毕业生均加入华为。章宗长教授在2012年曾在华为诺亚方舟实验室担任研究工程师，这一人脉连接为LAMDA强化学习团队与华为的合作提供了通道。

### 5.5 腾讯——多智能体与学术交流合作

2025年中国多智能体应用大会上，俞扬作为南京大学人工智能学院副院长，与腾讯AI平台部智能计算中心总监邓民文等围绕多智能体技术的关键突破与产业落地路径展开深入探讨。俞扬团队多名学生入选腾讯犀牛鸟精英研究生计划，形成了持续的人才输送通道。

### 5.6 阿里巴巴——人才输送

周文吉（2019届硕士，CCF-A类论文3篇，入选2017腾讯犀牛鸟精英研究生计划）、侍竞成（2018届硕士）等毕业生加入阿里巴巴，形成了从LAMDA强化学习团队到阿里巴巴的人才输送管道。

### 5.7 华大智造（MGI）——AI for Science跨界合作

2025年，华大智造杨梦团队联合南京大学俞扬团队在Genome Medicine杂志发表研究论文，将强化学习引入单细胞组学分析，开发了肿瘤克隆演化建模新框架scRevol。该研究将强化学习与图算法整合，利用PPO算法进行克隆识别，展示了强化学习技术在生物信息学领域的跨界应用潜力。

### 5.8 ICML RL4RealLife——国际产学研平台

俞扬是ICML"Reinforcement Learning for Real Life"研讨会的核心推动者之一。该研讨会聚焦强化学习从研究走向现实应用的鸿沟，邀请了DeepMind、Google、Facebook、Microsoft、Nvidia、Adobe、滴滴、MathWorks等国际公司的参与。俞扬作为南栖仙策创始人和南京大学教授，是连接学术界与产业界强化学习落地研究的重要桥梁。

## 六、Connection圈层总结

**第一圈层——LAMDA强化学习"双核心"与导师：** 章宗长（66次）是俞扬在LAMDA内最紧密的学术搭档，两人共同主导LAMDA强化学习方向的研究与团队管理，自2021年起合作急剧升温。周志华（63次）作为博士导师和LAMDA所长，是俞扬学术生涯的奠基人，合作横跨20年（2005-2025年）。三人构成了LAMDA强化学习方向的核心引领结构。钱超（48次）是演化学习方向的长期合作者，延续了博士期间的合作关系。
