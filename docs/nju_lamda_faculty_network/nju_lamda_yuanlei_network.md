## 三、博士教育背景与导师追溯

### 3.1 博士阶段（南京大学，?–2023年12月）

袁雷在南京大学计算机科学与技术系攻读博士学位，师从俞扬教授，2023年12月获博士学位。博士论文研究方向为多智能体强化学习，聚焦开放环境中的多智能体协作问题。

**博士导师：俞扬（Yang Yu）**

俞扬是南京大学人工智能学院副院长、教授、博士生导师，LAMDA实验室核心成员，国家万人计划青年拔尖人才。博士毕业于南京大学（导师周志华教授，2004-2011年），研究方向从演化学习转向强化学习。俞扬是南栖仙策（Polixir Technologies）创始人兼CEO，致力于强化学习的产业化落地。俞扬在DBLP上与袁雷合作约61次（2021-2026年），是袁雷学术生涯中最核心的导师与合作者。

在俞扬的指导下，袁雷的博士研究形成了清晰的主线：从多智能体通信机制（AAAI 2022）到多智能体协作的鲁棒性（AAAI 2023），再到开放环境中与任意队友的协作（DAI 2023最佳论文），构成了LAMDA在多智能体强化学习方向的核心研究脉络。

### 3.2 师承谱系

袁雷的学术师承可追溯为：

**周志华（LAMDA所长、中国科学院院士）→ 俞扬（LAMDA教授、南栖仙策创始人）→ 袁雷（LAMDA助理研究员）**

这一师承谱系体现了LAMDA实验室"内部培养-留校任教"的学术传承模式。袁雷作为俞扬指导下2023届博士毕业生，与许天（2024届博士，LAMDA讲师）同为俞扬团队留校任教的骨干，构成了LAMDA RL Lab的"第二代"学术力量。

袁雷不仅是俞扬的学术继承人，也是俞扬产业化布局的重要关联人物。俞扬创办的南栖仙策（Polixir）是LAMDA RL Lab的直接产业化载体——LAMDA RL Lab官网（https://lamda-rl.nju.edu.cn/）直接展示南栖仙策的核心产品REVIVE作为"Supported Product"。袁雷的多篇论文被公开报道为"南京大学与南栖仙策团队合作"成果（如DAI 2023最佳论文、ICLR 2023 ODIS等），表明其研究工作与南栖仙策的技术路线紧密关联。

## 五、业界合作关系深度分析

### 5.1 南栖仙策（Polixir Technologies）——导师俞扬创立的强化学习产业化公司

南栖仙策是袁雷学术生态中最重要的产业化连接。该公司由俞扬教授及其博士生秦熔均于2018年联合创立，俞扬任创始人兼CEO，由南京大学人工智能创新研究院技术孵化。

**袁雷与南栖仙策的多重关联：**

1. **师承关系：** 袁雷的博士导师俞扬是南栖仙策创始人兼CEO，袁雷作为俞扬最频繁合作的学生（61次），其研究直接服务于俞扬的强化学习产业化路线。

2. **联合研究成果：** 多篇论文被公开报道为"南京大学与南栖仙策团队合作"成果，包括：
   - **DAI 2023最佳论文"Learning to Coordinate with Anyone"（Macop算法）：** 袁雷作为第一作者，该工作被南栖仙策官方宣传，强调其"推进了集群协同的有无人系统在开放现实世界的落地应用"
   - **ICLR 2023论文"Discovering Generalizable Multi-agent Coordination Skills from Multi-task Offline Data"（ODIS方法）：** 同样被报道为南京大学与南栖仙策团队合作的成果
   - 以上论文的研究方向（开放环境多智能体协作、离线多智能体强化学习）与南栖仙策的核心技术路线（基于世界模型的强化学习落地）高度一致

3. **LAMDA RL Lab与南栖仙策的制度化连接：** LAMDA RL Lab官网（https://lamda-rl.nju.edu.cn/）将南栖仙策的核心产品REVIVE列为"Supported Product"，明确标注"REVIVE is Polixir's next-generation intelligent decision-making system"。这表明LAMDA RL Lab与南栖仙策之间存在制度化的技术合作关系，袁雷作为RL Lab核心成员，处于这一合作链条的关键节点。

4. **专利合作：** 袁雷作为发明人之一的专利CN113286275A"一种基于多智能体强化学习的无人机集群高效通信方法"（申请单位：南京大学），发明人包括俞扬、詹德川、周志华、袁雷、秦熔均（南栖仙策CTO）、庞竟成、管聪等，体现了学术团队与产业化团队的深度融合。

5. **南栖仙策技术方向演进：** 南栖仙策目前已从工业控制场景拓展至"无人系统与低空反无领域"（据其官网http://polixir.ai/），与袁雷的研究方向（多智能体sim2real、多智能体具身智能）形成直接对接。
