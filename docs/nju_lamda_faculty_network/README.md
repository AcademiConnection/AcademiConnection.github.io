## 全实验室关系网络的整体观察

LAMDA实验室二十位教师的关系网络呈现出高度紧密的"自我繁殖式"师承结构。周志华作为实验室创立者和绝对核心，其亲自培养的博士生中有黎铭、俞扬、王魏、李宇峰、高尉、詹德川、钱超、许天等多人留校任教，形成了国内人工智能领域罕见的师徒同事化规模。在此基础上又衍生出第二代、第三代传承：詹德川与姜远联合指导的叶翰嘉留校后与周大蔚形成第三代师承，构成"周志华→詹德川→叶翰嘉→周大蔚"完整的四代学术家谱；俞扬培养的赵鹏、袁雷、许天同样体现了这种滚雪球式的团队扩张模式。

产业合作方面，华为是覆盖面最广的合作伙伴，2019年成立的"华为-南大LAMDA人工智能联合实验室"由周志华担任主任，几乎所有教师的报告中都能找到与华为诺亚方舟实验室的合作线索或毕业生输送记录。其余合作对象包括阿里巴巴（近年在多模态大模型、GUI Agent等方向合作显著增多，尤其与叶翰嘉、詹德川、张利军团队）、腾讯、字节跳动、第四范式、蚂蚁集团等。俞扬创办的南栖仙策（Polixir Technologies）是实验室最具代表性的产学研自主孵化案例，形成了一条从强化学习理论研究直接转化为工业决策软件产品的完整链路，其博士生袁雷、许天的研究方向与工作均与该公司深度关联。吴建鑫指导的首位学生刘国清创立的佑驾创新（MINIEYE）则是LAMDA计算机视觉方向技术转化为自动驾驶产业应用的典型案例。

从学术出身看，多数教师为周志华亲传弟子或南大本校培养，但也存在若干"外部输入型"学术谱系：张利军博士毕业于浙江大学、博士后阶段师从密歇根州立大学Rong Jin后加入南大，其学术网络与合作模式明显不同于本土培养体系；陈开明长期任职于澳大利亚多所高校（怀卡托大学、迪肯大学、莫纳什大学、联邦大学），是Isolation Forest算法的发明人之一，近年才加入南京大学，其国际网络以日本、澳大利亚学者为主；章宗长博士毕业于中国科学技术大学（师从陈小平），并有罗格斯大学、新加坡国立大学、斯坦福大学的访学经历，与俞扬构成LAMDA强化学习方向国内外资源互补的"双核心"。

DBLP重名消歧在本系列调研中是普遍性挑战，尤其是王魏（Wei Wang，DBLP同名超过290个）、黎铭（Ming Li，需与滑铁卢大学同名理论计算机学者严格区分）、俞扬（Yang Yu，DBLP同名79个）等学者，均通过机构历史、研究方向、代表作反查等方式完成精确身份定位；对于青年学者（如谭志豪、王天佐）由于从业时间较短，业界合作信息相对有限，报告中如实反映了这一现状。

## 数据来源与说明

各报告数据主要来源于 DBLP 官方作者记录、LAMDA实验室官网教师主页、南京大学计算机学院/人工智能学院官网、公开学术报道及企业官方信息。由于部分学者存在 DBLP 重名或多身份标识的情况，报告中的合作次数统计可能存在小幅误差；博士导师等未经学者本人公开确认的信息均基于早期论文合著模式与机构履历综合判断，如遇后续信息更新，请以学者本人官方发布为准。
