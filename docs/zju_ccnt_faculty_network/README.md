## 二、各位教师的角色定位

潘纲是脑机智能全国重点实验室的主任与旗帜人物，国家杰青获得者、中国人工智能学会会士/常务理事，长期深耕脑机接口与普适计算。从早期参与"大鼠机器人"（视觉采集—计算解码—电刺激引导的动物机器人实验）到近年主导非侵入式脑机接口研究，他是国内脑机接口从"标志性演示"走向"系统化建制"的关键推动者。

赵莎是植入式/微创脑机接口方向的特聘研究员，参与GB/T 47023-2026脑机接口国家标准起草，在神经接口与EEG基础模型方向与潘纲、李石坚形成紧密合作线，是实验室面向"电极—信号—解码"全链条的核心技术力量。

许科帝代表实验室的医工交叉支线：他隶属生物医学工程与仪器科学学院/求是高等研究院，担任南湖脑机交叉研究院脑机接口与平台中心主任，浙江省杰青，深耕神经工程与康复机器人。他领衔创办博灵脑机（据上市公司公告持股51%并任总经理），是实验室"教授创业"路线的代表。

李石坚以普适计算与群智感知为根基，担任实验室支部书记，是潘纲团队在移动计算与EEG基础模型方向的长期合作者（DBLP合著记录达百余量级），其方向为脑机智能提供了"泛在感知—群体智能"的方法论底座。

杨国青是嵌入式系统与智能硬件的工程化中坚，主持ESE工程中心，作为主要完成人参与的项目获国家技术发明奖，并创办太机脑（类脑智能硬件方向），职称口径以个人主页"副研究员"为准。

## 三、全实验室关系网络的整体观察

第一，"一个主任、三条战线"的格局。实验室以潘纲为学术核心，形成计算机学院（赵莎、李石坚）、生仪/求是高等研究院（许科帝）、工程中心（杨国青）三条建制战线，覆盖"算法—电极—系统—平台"的脑机智能全栈。

第二，医工交叉建制发达。依托南湖脑机交叉研究院与求是高等研究院，实验室与医疗机构、康复场景深度绑定，许科帝的博灵脑机、杨国青的太机脑分别代表"脑机康复"与"类脑硬件"两条产业化路径。

第三，标准制定与国家任务参与度高。赵莎参与脑机接口国家标准起草、杨国青参与国家技术发明奖项目、李石坚获国家科技进步二等奖（2015），显示团队在国家层面的话语权。

第四，谱系以"合作关系"为主、"师承关系"为辅。现有教师与潘纲之间多为长期论文合作而非师生传承（EEG基础模型系列等合著证据充分，师承证据不足），实验室尚处于以合作网络凝聚的阶段，未形成数据库实验室式的内生繁殖链。
