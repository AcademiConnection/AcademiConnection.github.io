## 二、教育背景与职业履历

### 教育经历

- **1993年—1997年**：浙江大学，获工学学士学位（计算机科学与技术）。  
- **1997年—2002年**：浙江大学，获工学博士学位（计算机科学与技术），师从**彭群生**教授。彭群生教授是浙江大学CAD&CG国家重点实验室创始人之一，1988年与研究生邵敏之合作的论文被SIGGRAPH'88录用，实现了中国学者在该会议"零的突破"（[百度百科-彭群生](https://baike.baidu.com/item/彭群生/5944890)）。

### 职业履历

- **2002年—2008年**：在**微软亚洲研究院**（MSRA）工作，担任研究员。在此期间，周昆与微软亚洲研究院网络图形组主管**童欣**等同组合作，开展了GPU并行计算、几何建模等方向的研究，发表了多篇SIGGRAPH论文。微软亚洲研究院的这段经历为周昆后续的研究风格奠定了"学术与产业并重"的基础（[雷锋网报道](https://www.leiphone.com/category/academic/5Wc91CKcCRcrG4ZX.html)；在MSRA的具体职务头衔待核实）。

- **2007年**：入选教育部长江学者特聘教授。  
- **2008年**：获国家杰出青年科学基金资助，同年全职加入浙江大学。  
- **2013年至今**：担任浙江大学计算机辅助设计与图形系统全国重点实验室主任（实验室主任先后由石教英、彭群生、周昆等教授担任）（[百度百科-CAD&CG实验室](https://baike.baidu.com/item/浙江大学计算机辅助设计与图形学国家重点实验室/2505411)）。  
- **2024年**：主持国家自然科学基金创新研究群体项目（项目名称：智能图形计算）（[CAD&CG实验室官网-人才队伍](http://www.cad.zju.edu.cn/talent-team)）。  
- **2025年**：主持新一代人工智能国家科技重大专项项目、国家重大科研仪器研制项目。

### 核心学术贡献概述

周昆长期从事计算机图形学和人工智能研究，在以下方向取得了系统性创新成果：

1. **微分域几何计算**：提出了基于Laplace坐标的几何处理方法，与特拉维夫大学Sorkine-Hornung的工作并称为该领域的奠基性贡献，推动了微分域几何处理成为国际研究热点。
2. **GPU并行计算**：团队首个提出构建KD树的GPU算法，开发了BSGP（Bulk-Synchronous GPU Programming）语言和RenderAnts系统——后者将电影渲染管道的全部阶段映射到GPU上运行，速度比Pixar的RenderMan快一个数量级（[雷锋网](https://www.leiphone.com/category/academic/5Wc91CKcCRcrG4ZX.html)）。
3. **3D人脸形状回归**：2013年发表的"3D Shape Regression for Real-Time Facial Animation"提出利用单目RGB摄像头进行实时精确3D人脸跟踪的开创性方法，该论文获2024年ACM SIGGRAPH时间检验奖（[浙大新闻](http://www.cs.zju.edu.cn/csen/2024/0705/c38564a2943514/page.htm)）。
4. **单幅图像头发建模与数字化身技术**：提出了从单幅图像重建头发的三维模型方法，以及完整的数字化身（Digital Avatar）技术体系，相关技术被全球4000余家企事业单位授权使用（[浙江大学个人主页](https://person.zju.edu.cn/kunzhou)）。

周昆团队的产业合作具有"产学研深度融合"的鲜明特征，研究成果通过技术授权和联合研发的方式在大量企业中落地：

**（1）与相芯科技的深度合作**

相芯科技（FaceUnity）成立于2016年，孵化于浙江大学CAD&CG实验室，由周昆教授带领团队创立：据公开报道，周昆为公司实际控制人及第一大股东（持股约48.1%），公司法定代表人、执行总裁兼CTO为周昆的学生秦昊，团队另一创始人侯启明亦持有股份（[百度百科报道](http://baijiahao.baidu.com/s?id=1783429910190590966)）。2018年，相芯科技与浙江大学合作共建"智能图形计算联合实验室"，研发投入占比保持在70%以上。相芯科技在ACM SIGGRAPH发表论文80余篇，获知识产权超110项，技术已在手机、汽车、金融、电商、互娱等20多个领域落地，业务遍及200多个国内外地区，拥有4000余家合作客户，SDK访问量超过1000亿次（[相芯科技官网](https://www.faceunity.com/about.html)）。

**（2）与网易的产业合作**

网易（杭州）网络有限公司作为主要完成单位参与了2023年浙江省科学技术奖一等奖项目（完成人：周昆、胡志鹏、金小刚、李冬平、刘新国、邵天甲、任重、翁彦琳、范长杰、李林橙、秦昊、米楠）。网易游戏雷火事业群与CAD&CG实验室在游戏渲染、数字人等方向有长期合作。

**（3）技术授权与规模化应用**

周昆团队的研究成果在华为、腾讯、迪士尼公司、国家卫星气象中心、中电集团等500余家（后扩展至4000余家）企事业单位得到规模化应用。团队拥有发明专利100余项，论文引用1万余次（[浙江大学个人主页](https://person.zju.edu.cn/kunzhou)、[杭师大新闻](https://www.hznu.edu.cn/c/2021-11-05/2624748.shtml)）。

### 5.2 创业孵化与技术转化

周昆教授在学术研究之外，积极推动技术转化和创业孵化，形成了以CAD&CG实验室为核心的图形学产业生态：

**（1）相芯科技（FaceUnity）——数字化身与AR特效**

- **成立时间**：2016年  
- **创始人**：周昆教授带队创立，学生秦昊担任执行总裁兼CTO  
- **核心产品**：AvatarX数字人平台、AR视频特效SDK  
- **技术来源**：周昆团队在数字化身、3D人脸形状回归、单幅图像头发建模等方向的十余年研究成果  
- **荣誉资质**：国家级专精特新"小巨人"企业、国家高新技术企业、国家科学技术进步奖、浙江省科学技术进步一等奖、杭州市准独角兽企业（连续5年上榜）等  
- **产业影响**：技术覆盖全球200多个地区，4000余家合作客户，SDK访问量超1000亿次  

相芯科技是周昆团队学术成果产业化最成功的案例之一。2013年SIGGRAPH时间检验奖论文中的3D人脸跟踪技术，以及后续的单视角图像数字人建模技术，构成了相芯科技数字人产品的核心算法基础。2025年度国家科学技术进步奖二等奖（"智能化三维数字人制作关键技术及应用"）正是对这一产学研路径的国家级认可（[浙大新闻](http://www.news.zju.edu.cn/2026/0708/c93325a3187082/page.htm)、[相芯科技官网](https://www.faceunity.com/zh-CN/)）。

**（2）光线云科技（Rayvision）——云原生实时渲染引擎**

- **成立时间**：2021年  
- **创始人**：王锐（浙江大学CAD&CG实验室教授、博士生导师）  
- **核心产品**：RaysEngine——全球首款云原生实时渲染引擎  
- **技术来源**：王锐在复杂光场高效采样、实时绘制算法、绘制架构自动优化等方面的研究成果（30余篇顶级论文、30余项专利）  
- **融资情况**：天使轮到A轮总融资金额近1亿元，投资方包括红杉中国种子基金、Star VC、高瓴创投、51WORLD、摩尔线程、前海方舟等  
- **应用客户**：华为、腾讯、网易、西门子等  

光线云虽非周昆直接创办，但作为CAD&CG实验室孵化的企业，是实验室图形渲染技术产业生态的重要组成部分。光线云的核心团队来自浙大CAD&CG实验室的教授及学者，产研人员占比高达80%以上（[新浪财经](https://t.cj.sina.com.cn/articles/view/1180504637/465d123d01900yjpz)、[百度百家号](https://baijiahao.baidu.com/s?id=1741856623991137716)）。

**（3）杭州智播未来科技——AI数字人直播**

- **成立时间**：2025年1月  
- **创始人**：秦昊（周昆博士生， former 相芯科技CTO）  
- **技术来源**：源自浙大CAD&CG实验室周昆教授团队的数字人技术  
- **业务方向**：专注货架电商AI直播  

智播未来是周昆团队技术转化链的延伸——从学术研究到相芯科技的产品化，再到面向具体行业的垂直应用。公司已累计服务商家1500+，2026年618期间完成超45000场直播（[搜弧报道](https://www.sohu.com/a/1065600118_122976082)）。

## 七、Connection圈层总结

周昆教授的学术关系网络呈现清晰的圈层结构，从学术师承到产业生态形成了完整的"学术—产业"转化链条：

**第一圈层（导师与核心团队）**

- **导师彭群生**：浙江大学CAD&CG实验室创始人之一，中国计算机图形学奠基人之一，1988年实现中国学者在SIGGRAPH"零的突破"。彭群生指导的学生中有3人获国家杰出青年科学基金，周昆是其最杰出的学生之一。2020年度国家自然科学奖二等奖的完成人中，周昆（第一完成人）和彭群生共同获奖，体现了师承关系的学术传承。
- **实验室前主任石教英**：CAD&CG实验室的早期主任之一，同样是2020年度国家自然科学奖二等奖的完成人之一。
- **核心团队成员**：邵天甲（百人计划研究员，国家自然科学奖共同完成人）、任重（副教授，RenderAnts核心开发者）、侯启明、吴鸿智、陈翔、郑友怡等，构成了周昆团队的研究主力。

**第二圈层（同门与实验室同侪）**

- **王章野**（浙江大学副教授，2002年获浙大计算机图形学博士学位，与周昆同年获博士学位，同属彭群生指导的博士群体）
- **金小刚**（浙江大学教授，CAD&CG实验室成员，2023年浙江省一等奖共同完成人，SIGGRAPH 2025论文通讯作者）

- **相芯科技**（FaceUnity）：周昆作为实际控制人/大股东带领团队创立的核心孵化企业，学生秦昊任法定代表人、执行总裁兼CTO，翁彦琳、范长杰等团队成员为核心技术骨干，侯启明亦为股东，技术源自实验室数字化身研究（[百度百科报道](http://baijiahao.baidu.com/s?id=1783429910190590966)）。

**总结**

周昆教授的学术关系网络具有以下显著特征：

1. **师承清晰**：彭群生→周昆→邵天甲/秦昊/翁彦琳等，形成了三代学术传承链条，且每代人均在国家科技奖励中获得认可。
2. **产学研一体**：从CAD&CG实验室到大星系创业企业（相芯科技、光线云、智播未来），形成了独特的"学术研究—技术转化—产业应用"闭环，研究成果直接驱动产品创新。
3. **国际化程度高**：通过微软亚洲研究院经历、Visual Informatics期刊、ACM/IEEE Fellow身份和SIGGRAPH等国际会议，与全球图形学社区深度连接。
4. **产业影响力巨大**：技术被4000余家企业使用，SDK访问量超1000亿次，获国家科技进步奖，是计算机图形学领域产学研结合的标杆。
5. **团队培养体系完备**：团队核心成员涵盖副教授/研究员（任重、侯启明、吴鸿智、陈翔、郑友怡、邵天甲）到产业精英（秦昊、翁彦琳、范长杰、Chen Cao），既有留在学术界的顶尖学者，也有走向产业界的创业者和技术骨干。
