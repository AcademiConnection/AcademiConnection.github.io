# 浙江大学 周昆组（图形与并行系统实验室）教师学术关系网络报告

## 概述

本目录收录浙江大学计算机辅助设计与图形系统全国重点实验室（CAD&CG）图形与并行系统实验室（Graphics and Parallel Systems Lab，GAPs）全部七位固定教职人员的学术关系网络报告。该实验室由周昆教授于2010年与任重、侯启明共同创建，三人此前均在微软亚洲研究院（MSRA）工作，是"浙大—MSRA图形学人才回流"的代表案例。实验室在微分域几何计算、真实感图形实时绘制、GPU并行计算、虚拟数字人、外观建模、3D打印智能设计、数字内容生成等方向长期处于世界前列，其数字人研究成果孵化出相芯科技（FaceUnity）等知名企业。

## 团队学术谱系概览

周昆组是典型的"MSRA回流+浙大本土培养"双源结构团队。周昆本人为浙大彭群生教授2002年博士毕业生，2002—2008年在微软亚洲研究院工作后回浙大，2013年起任实验室主任，先后当选IEEE Fellow（2015）、ACM Fellow（2021），获国家自然科学奖二等奖2项（2013、2020）、国家科技进步奖二等奖1项（2025）、ACM SIGGRAPH时间检验奖（2024，亚洲团队首次）、亚洲图形学学会杰出技术贡献奖（2022）、科学探索奖（2021）、陈嘉庚青年科学奖（2016）、MIT TR35（2011）等荣誉。

任重与侯启明同样出自MSRA互联网图形组（IG组）：任重2002年浙大博士毕业后在MSRA工作五年，2010年回浙大与周昆、侯启明共建GAPs实验室；侯启明以程序设计能力著称，五次获国际C语言混乱代码大赛（IOCCC）奖项（二手来源，待逐项核实），并参与RenderAnts GPU渲染系统研发。吴鸿智为复旦大学本科、耶鲁大学博士（师从Julie Dorsey与Holly Rushmeier），后加入团队专注外观采集与建模。陈翔的教育经历公开资料有限（待核实），其研究方向覆盖物理仿真与可计算制造。郑友怡为浙大数学本科、香港科技大学博士，曾任职KAUST、上科大，2017年加盟浙大，开辟数字内容生成与数字化口腔交叉方向。邵天甲为清华大学博士（导师郭百宁，非周昆），曾在MSRA实习四年并任UCL访问研究员、利兹大学讲师，2019年以百人计划研究员身份加入团队，是2020年国家自然科学奖二等奖第二完成人。

团队产业生态以相芯科技为核心：该公司2016年孵化自CAD&CG实验室，周昆为实际控制人及第一大股东（约48.1%），其学生秦昊任法定代表人、执行总裁兼CTO，翁彦琳、范长杰等团队成员为技术骨干，其数字人技术源自周昆团队2013年SIGGRAPH时间检验奖论文等成果。"智能化三维数字人制作关键技术及应用"项目先后获2023年度浙江省科技进步一等奖与2025年度国家科技进步二等奖。此外，实验室教授王锐创办光线云科技（RaysEngine），秦昊2025年二次创业智播未来；团队与芯原股份共建智能图形处理器联合研究中心，与网易保持长期数字人合作。
