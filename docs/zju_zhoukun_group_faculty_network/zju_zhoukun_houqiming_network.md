### 微软亚洲研究院经历

侯启明在微软亚洲研究院（MSRA）的Internet Graphics（IG）组担任Researcher（研究员）。根据周昆教授在知乎的公开回答，在MSRA期间IG组高手云集，"任重、启明、孙鑫、威威、律迪、王希、黄欣、敏敏、耀华等人通力合作并肩战斗"，侯启明被明确列为Researcher系列。周昆评价其"工程和coding能力当世罕见，是我所认识的最强的两位程序员之一，也是创新和工程紧密结合的典范"。来源：https://www.zhihu.com/question/63167378 。

在MSRA期间，侯启明参与了多项重要研究工作，包括预计算辐射度传输（PRT）、GPU渲染管线、以及Fogshop等代表性项目。其合作者包括沈向洋（Harry Shum，时任MSRA院长）、郭百宁（Baining Guo，时任MSRA Distinguished Scientist）、John Snyder（MSRA Principal Researcher）、宫民旻（Minmin Gong）、孙鑫（Xin Sun）等国际知名学者。

值得注意的是，MSRA的IG组在中国图形学发展史上具有里程碑式的地位。以沈向洋、郭百宁为首的MSRA研究团队曾在SIGGRAPH上发表9篇论文，占当年SIGGRAPH全球论文接收总量（98篇）的十分之一。侯启明作为IG组的核心成员之一，深度参与了这一黄金时期的研究工作。浙大与MSRA是中国图形学研究最出名的两个机构，二者早期在图形学的人才培养与相互输送上有着深厚渊源——从浙大毕业的童欣（1999年博士毕业）、刘利刚、周昆、任重等先后加入MSRA，形成了一条独特的人才流动通道。侯启明正是这条通道上的典型代表：从浙大学生到MSRA研究员，再回到浙大任教。来源：https://www.zhihu.com/question/63167378 。

### 回归浙江大学与实验室创建

2010年前后，图形学研究在MSRA的比重逐渐下降，多位研究人员陆续离开回到浙江大学。在这一背景下，侯启明与周昆教授、任重博士一起，于2010年在浙江大学CAD&CG国家重点实验室建立了图形与并行系统实验室。这一信息由任重的浙大个人主页明确记载："2010年全职回浙大工作，并和周昆教授、侯启明博士一起建立了图形与并行系统实验室。"来源：https://mypage.zju.edu.cn/renzhong/651316.html 。

从时间线来看，侯启明的职业生涯可以分为两个主要阶段：（1）微软亚洲研究院工业研究阶段，在IG组从事图形学前沿研究，在GPU并行渲染、GPU编程语言等方向积累了深厚的研究与工程经验；（2）浙江大学学术研究阶段（2010年至今），作为副教授持续从事计算机图形学、并行计算与编译器方向的教学科研工作，并参与多项产业合作项目。

2010年前后，图形学研究在MSRA的比重逐渐下降，以沈向洋、郭百宁领衔的IG组多位核心成员陆续离开。这一时期恰逢中国高校对图形学高端人才需求急剧上升的窗口期，周昆率先回到浙大并于2007年入选教育部长江学者特聘教授，随后任重和侯启明也分别回归。三人于2010年共同建立图形与并行系统实验室，标志着浙大-MSRA图形学人才回流的一个重要节点。此后，该实验室逐步发展壮大，吸纳了吴鸿智、陈翔、郑友怡、邵天甲等新一代研究者，成为中国计算机图形学领域产出最高、产业影响力最强的研究团队之一。

根据浙江大学计算机学院科研团队介绍表，图形与并行系统实验室近年来在微分域几何计算理论与方法、真实感图形实时计算理论与方法、数字化身技术、3D打印等方向取得了多项原创成果，被国内外知名媒体广泛报导，相关技术在逾千家国内外企业成功应用。实验室还培养了大批优秀学生，包括3名微软学者奖学金和竺可桢奖学金获得者。侯启明在这一团队中专注于GPU并行计算和编译器方向，是团队在系统层面研究的技术支柱。来源：浙江大学计算机学院科研团队介绍表。

## 四、学术合作网络

### 4.1 实验室内部合作

侯启明所在的图形与并行系统实验室是一个紧密合作的研究团队，由周昆教授领衔，团队成员之间有深厚的学术合作纽带。以下分析侯启明与各核心成员的合作关系。

**与周昆（Kun Zhou）教授的合作：** 周昆是侯启明最重要的学术合作者和引路人。二人的合作关系始于MSRA时期，侯启明曾是周昆的学生在MSRA实习。他们合著了多篇重要论文，包括Fogshop（SIGGRAPH 2007，与Minmin Gong、John Snyder、Baining Guo、Harry Shum合著）、RenderAnts（SIGGRAPH Asia，与Zhong Ren、Minmin Gong、Xin Sun、Baining Guo合著）、SPAP: A Programming Language for Heterogeneous Many-Core Systems（2010年技术报告，与Baining Guo合著）等。周昆在知乎上公开评价侯启明为"我所认识的最强的两位程序员之一"，足见二人合作的深度与互信。2010年二人共同创建图形与并行系统实验室后，合作进一步深化，在GPU并行渲染、领域专用编程语言等领域产出多项成果。

在MSRA期间，二人的代表性合作成果包括：（1）Fogshop论文，该研究提出了一种实时设计和渲染非均匀单散射介质的方法，发表于ACM Transactions on Graphics，是体积渲染方向的重要工作，合著者还包括宫民旻、John Snyder、郭百宁和沈向洋；（2）RenderAnts论文，该系统是首个能在GPU上实现交互式Reyes渲染的系统，将RenderMan着色器编译为GPU着色器并在GPU上执行Reyes管线的全部阶段（包括包围/分裂、切割、着色、采样、合成和过滤），通过精心设计的数据并行算法和动态调度算法实现高性能渲染，与Pixar的PRMan相比速度快一个数量级以上；（3）SPAP编程语言（2010年技术报告），提出了面向异构多核系统的容器化编程语言，在x86 CPU和CUDA GPU上实现了编译器和运行时。来源：https://www.microsoft.com/en-us/research/people/hshum/publications/ ；http://www.researchgate.net/publication/265023061 。

**与任重（Zhong Ren）副教授的合作：** 任重与侯启明同为MSRA IG组的老同事，二人于2010年与周昆一同从MSRA回到浙大创建实验室。在MSRA期间，二人合著了RenderAnts论文以及Radiance Transfer Biclustering论文（IEEE TVCG 2011，与孙鑫、周昆、郭百宁合著），后者提出了一种实时渲染全频率辐射度传输的双尺度算法，在介观尺度上通过积分局部入射辐亮度和双向纹理函数来计算着色，在宏观尺度上使用双聚类技术无损压缩预计算传输矩阵。此外，二人还共同参与了浙江大学-FaceUnity智能图形联合实验室的研究工作，在2021年共同发表了Neural Compositing论文。二人的合作关系横跨MSRA和浙大两个阶段，是实验室内部最紧密的合作对之一。来源：https://mypage.zju.edu.cn/renzhong/651316.html ；http://ieeexplore.ieee.org/document/5453360/ 。

### 5.2 创业孵化与技术转化

**GPU领域专用编程语言（DSL）的技术转化：** 侯启明主持了国家自然科学基金青年科学基金项目"图形处理器上的领域专用编程语言设计研究"，依托单位为浙江大学。该项目旨在研发一套核心DSL研发平台及相应的优化编译器，在程序建模、物理仿真、运动特效绘制等领域研发支持自动GPU并行化的DSL。结题摘要显示，项目组在ACM SIGGRAPH、Pacific Graphics等高水平学术会议上发表论文3篇（均被SCI收录），获得国家发明专利1项。该研究具有面向产业应用的潜力，其DSL平台技术可转化为GPU编程工具链。来源：https://baike.baidu.com/item/图形处理器上的领域专用编程语言设计研究/57074575 。

**SPAP编程语言：** 2010年，侯启明与周昆、郭百宁共同发表了技术报告"SPAP: A Programming Language for Heterogeneous Many-Core Systems"，提出了SPAP（Same Program for All Processors）这一面向异构多核系统的容器化编程语言。该语言旨在简化异构编程，通过提供处理器特定的优化实现来提升性能，已在x86 CPU和CUDA GPU上实现编译器和运行时。SPAP的设计理念是用容器（container）这一高级原语屏蔽处理器特定的并发和性能问题，程序员可见的容器行为与其顺序对应物一致，从而实现类似传统顺序编程的编程风格。此外，SPAP系统还支持通过处理器间并行化方案自动将计算分布到不同处理器上以实现性能提升。这项研究展示了从底层编译器到上层应用的全栈技术能力，具有转化为商业GPU编程工具的潜力，也为后续国家自然科学基金青年科学基金项目中GPU DSL的研发奠定了技术基础。来源：http://www.researchgate.net/publication/265023061 。

**RenderAnts渲染系统的技术影响：** RenderAnts是侯启明在MSRA期间参与的重要项目，该系统是首个能在GPU上实现交互式Reyes渲染的系统，将RenderMan着色器编译为GPU着色器，在GPU上执行Reyes管线的全部阶段（包括包围/分裂、切割、着色、采样、合成和过滤），通过精心设计的数据并行算法和动态调度算法实现高性能渲染，与Pixar的PRMan相比速度快一个数量级以上。此外，RenderAnts还提出了基于work stealing的多GPU调度技术，支持可扩展的多GPU渲染。该技术对于电影特效渲染和实时渲染管线具有重要产业价值，展示了侯启明在GPU渲染系统设计方面的全栈技术能力。来源：MSRA RenderAnts论文。

**团队整体的技术转化影响力：** 值得指出的是，图形与并行系统实验室在周昆教授的带领下，其研究成果已在逾千家（最新数据为4000余家）国内外企事业单位成功应用，取得了显著的社会和经济效益。团队培养了大批优秀学生，包括3名微软学者奖学金和竺可桢奖学金获得者。侯启明作为团队核心成员，在这一技术转化生态中承担着GPU系统底层和编译器方向的关键角色。来源：浙江大学计算机学院科研团队介绍表。

总体而言，侯启明副教授的学术关系网络以浙大图形与并行系统实验室为核心，以MSRA经历为渊源，以产业合作（芯原、FaceUnity）为延伸，以国际合作为补充，形成了一个多圈层、跨领域的学术关系网络。他在GPU并行计算和编译器方向的独特技术能力，使其成为连接学术研究与产业应用的重要枢纽人物。

在周昆教授的带领下，图形与并行系统实验室已成为中国计算机图形学领域最具影响力的研究团队之一。周昆教授本人是ACM Fellow、IEEE Fellow、国家杰出青年基金获得者，获得过国家自然科学二等奖2项、MIT TR35 Award、ACM SIGGRAPH时间检验奖（2024年，亚洲团队首次获奖）等国内外重要奖项。侯启明作为该团队中GPU并行计算与编译器方向的唯一专家，在团队的技术版图中具有不可替代的独特定位——当团队其他成员分别在几何处理（周昆）、真实感渲染（任重）、外观建模（吴鸿智）、3D打印（陈翔）、数字化口腔（郑友怡）、3D内容生成（邵天甲）等方向深耕时，侯启明独自承担了从GPU底层编程语言到上层并行渲染系统的全栈技术工作，这种技术互补性是团队整体竞争力的重要来源。

展望未来，随着GPU在人工智能、科学计算和图形渲染领域的战略地位持续提升，侯启明在GPU编程语言和编译器方向的研究积累将具有更加突出的价值，其在芯原联合研究中心和FaceUnity联合实验室的产业布局也有望产生更深层次的技术转化成果。
