# 中国科学技术大学多媒体计算与通信教育部-微软重点实验室（MCC）学术关系网络报告
## （含周文罡组·3D视觉/深度展开网络 与 李厚强组·视频理解）

## 团队简介

多媒体计算与通信教育部-微软重点实验室（MCC，Ministry of Education-Microsoft Key Laboratory of Multimedia Computing and Communication）依托中国科学技术大学信息科学技术学院（现人工智能与数据科学学院）建设，是中国多媒体研究领域的旗舰平台之一。实验室早期由吴枫教授（高文院士在哈工大的博士生，IEEE Fellow，2025年当选中国工程院院士，现任中科大副校长）执掌，后由李厚强教授接任主任，汇聚了张勇东、陈志波、谢洪涛、周文罡、刘东、李力等骨干师资。

用户指定的"周文罡组（3D视觉/深度展开网络）"与"李厚强组（视频理解）"实为同一联合课题组——"李厚强、周文罡课题组"以双导师联合培养模式运行：李厚强深耕视频处理与通信、视频理解与多模态大模型，周文罡（李厚强指导的博士，UTSA博士后师从田奇）专注3D视觉、深度展开网络与视觉定位。课题组毕业生王宁（2021年博士，CSIG优博）、邓家俊（TransVG系列）、张宗萌（ICML 2024/2025一作）等分布学界与产业界，35名已毕业博士广泛进入华为（天才少年）、字节跳动、阿里通义、DeepSeek、OPPO等头部企业。

## 研究方向与圈层结构概述

实验室的学术谱系呈"高文—吴枫—中科大MCC"的跨校传承与"李厚强→周文罡"的校内师承双线结构。吴枫的哈工大博士导师高文院士（后任北大教授、鹏城实验室主任）将视频编码的学术血脉注入中科大；吴枫与李厚强、张勇东构成获奖共同体（两项国家级二等奖合作完成）；李厚强培养的周文罡成为教授级传承人后，二人以联合课题组形式运行。张勇东从天津大学博士→中科院计算所（2002-2017）→中科大的轨迹，则将MCC与中科院计算所的多媒体研究生态（VIPL体系）连接起来，其学生颜成钢现任杭州电子科技大学副校长。

校内同侪圈覆盖"合肥多媒体学派"——刘东（吴枫学生，视频编码方向教授）、李力、俞能海、李卫平、查正军、张燕咏，以及合肥工业大学的汪萌、洪日昌等。外部网络以华为（从视频编码委托项目到ICML 2025大模型可信性联合研究的二十年演进，对接人含赵洁、田奇）与微软亚洲研究院（实验室共建方）为核心，科大讯飞（手语识别）、OPPO研究院（欧阳万里，TransVG++合作）、海康威视等构成产业辐射圈。

## 产业转化亮点

实验室的技术转化贯穿中国视频产业史：AVS/JCTVC/MPEG标准化贡献支撑国产视频编解码体系；视频监控与智能分析技术（张勇东方向）落地安防产业；手语识别技术与科大讯飞合作服务听障人群；深度展开网络（周文罡）在图像处理与3D视觉的成果被广泛开源引用；近年大模型可信性研究（ICML 2024/2025）与华为形成新一代合作范式。毕业生网络（华为天才少年、DeepSeek、阿里通义等）持续将学术成果输送到中国AI产业最前沿。
