## 四、学术合作网络

### 4.1 核心合作圈层：李厚强教授（USTC）

李厚强教授是周文罡的**博士导师**，也是其职业生涯中最紧密的学术合作者。两人共同运行MCC实验室下属课题组，几乎所有周文罡指导的博士生论文中，李厚强均为共同通讯作者。两人联合发表的论文涵盖图像检索、手语识别、视觉定位、3D视觉、强化学习等多个方向，累计共同发表TPAMI论文10篇以上。

合作模式上，李厚强教授同时担任信息科学技术学院副院长和MCC实验室主任，侧重宏观方向把控与资源协调；周文罡教授则更深入参与具体课题指导与论文写作。课题组的日常管理（如考勤制度等）由两位教授共同负责。在专利方面，两人共同持有"行人重识别特征提取"、"手语视频翻译"、"连续手语识别"等多项发明专利。

两人合作发表的代表性论文包括：Collaborative Index Embedding for Image Retrieval（TPAMI 2018, 与孙剑、田奇合作）、SignBERT+（TPAMI 2023）、HandNeRF++（TPAMI 2025）等。

### 4.2 重要的师承与博士后合作网络

**田奇（Qi Tian）——博士后导师**
田奇是周文罡在美国UTSA做博士后期间的导师，也是其最重要的跨机构合作者。田奇现为华为云人工智能领域首席科学家、IEEE Fellow、国际欧亚科学院院士。周文罡多篇论文与田奇合作发表，包括TPAMI上的Collaborative Index Embedding（2018）、Towards Codebook-free Deep Probabilistic Quantization（2024），以及多篇TIP论文。田奇作为周文罡博士后导师，在其学术成长早期提供了国际视野与资源支持。两人的合作在田奇加入华为后仍在持续。

**孙剑（Jian Sun）——合作研究者**
孙剑（非中科大学者，曾任职微软亚洲研究院，后任旷视科技首席科学家/Megvii）是周文罡TPAMI论文"Collaborative Index Embedding for Image Retrieval"（2018年）的合作者。该论文是周文罡在图像检索领域的代表作，将SIFT特征与CNN特征在统一框架下融合用于大规模图像检索。孙剑的参与体现了周文罡在图像检索领域与国际顶尖研究者的学术联系。

**刘铁岩（Tie-Yan Liu）——微软亚洲研究院合作**
周文罡课题组与微软亚洲研究院首席研究员刘铁岩有论文合作，包括发表在TMLR上的"Direct Molecular Conformation Generation"（2022年），涉及分子构象生成这一跨学科方向。该合作通过MCC实验室这一平台实现，体现了微软联合实验室在跨学科合作中的桥梁作用。

## 五、业界合作关系深度分析

### 5.1 微软合作关系

周文罡与微软的关系需要从**机构平台**和**学术合作**两个层面理解。

**机构平台层面——MCC实验室**
周文罡所属的"多媒体计算与通信教育部-微软重点实验室"（MCC）是中国科学技术大学与微软亚洲研究院于2004年共建的5所"教育部-微软重点实验室"之一（前身为2003年成立的"科大-微软智能计算研究中心"）。该实验室隶属中科大电子工程与信息科学系，实验室主任为李厚强教授。微软亚洲研究院每年资助约10个项目，作为"种子基金"支持年轻教师开展前沿研究。周文罡作为MCC实验室核心教师，通过这一平台间接获得了微软的研究资源支持与学术交流渠道。

**学术合作层面——论文合作**
通过MCC实验室平台，周文罡课题组与微软亚洲研究院研究员有直接论文合作，包括：
- 与Jianmin Bao、Dongdong Chen、Dong Chen、Lu Yuan合作发表SinDiffusion（TPAMI 2025）
- 与Tie-Yan Liu（刘铁岩）、Tao Qin等MSRA研究员合作发表Direct Molecular Conformation Generation（TMLR 2022）
- 早期与孙剑（Jian Sun，时任MSRA研究员）合作发表TPAMI论文

这些合作主要体现为联合研究论文，而非企业项目或全职任职。

### 5.2 华为与其他企业合作

**华为**
周文罡课题组与华为的合作体现在多个层面：
1. **人才输送**：课题组多名毕业生加入华为，包括王宁（华为天才少年）、朱小天、欧阳剑波、魏龙辉等，至少4名博士毕业生进入华为。
2. **学术合作**：博士后导师田奇现为华为云人工智能领域首席科学家，双方保持学术合作关系。周文罡的优青项目（大规模图像检索）及手语视频分析重点项目等，亦与华为的产业需求存在关联。
3. **校级合作**：中科大EEIS系与华为上海研究所有"信息与通信卓越人才培养"合作计划。

**科大讯飞**
周文罡曾主持科大讯飞股份有限公司横向项目"基于多元图像信息的手语识别技术研发"（2014年1月—2016年12月，经费20万元），已结题。该项目是课题组手语识别研究方向的产业落地尝试，与后续在CVPR、AAAI、TPAMI等发表的一系列手语识别论文形成产学研闭环。

**其他企业**
课题组毕业生广泛分布于字节跳动（5人以上，含Seed团队和DeepSeek转岗）、阿里巴巴/通义千问（3人）、腾讯ARC Lab、百度、快手可灵AI、地平线、OPPO研究院、海康威视、云天励飞等企业。此外，课题组在第七届全国兵棋推演大赛"智能空中博弈算法挑战赛"中获冠军（2023年），体现了在多智能体强化学习与博弈方向的研究实力，该方向与国防智能应用密切相关。

周文罡教授的学术关系网络可划分为以下圈层：

**第一圈层——核心合作圈（日常科研共同体）**
- **李厚强**（USTC，博士导师，联合课题组负责人，MCC实验室主任）：周文罡最紧密的学术合作者，几乎所有论文的共同作者，共同指导大部分博士生。
- **MCC实验室课题组**：包括李力等实验室成员，以及课题组内在读博士生（约30余名在读），构成日常科研与论文产出的核心团队。

**第二圈层——师承与导师圈（学术成长脉络）**
- **田奇**（UTSA博士后导师，现为华为云首席科学家、IEEE Fellow）：周文罡博士后阶段的学术引路人，亦是长期论文合作者，连接学术界与华为产业界。
- **武汉大学本科**（2002-2006）：本科阶段的学术起点，但与后续研究网络的直接联系较少。

**第三圈层——MCC实验室同事圈（同机构平行团队）**
- **张勇东、吴枫、陈志波**等MCC实验室及EEIS系同事：同一机构内的平行研究团队，共享实验室资源与微软平台，但直接论文合作较少，更多体现为机构内的学术共同体关系。其中吴枫作为副校长在行政层面与课题组产生交集。

**第四圈层——微软合作圈（产业学术桥梁）**
- **微软亚洲研究院**：通过MCC联合实验室这一机构平台，与MSRA研究员（刘铁岩、Jianmin Bao、Dongdong Chen、Dong Chen、Lu Yuan等）形成论文合作关系，但不涉及全职任职。
- **孙剑**（原MSRA，后旷视）：早期TPAMI论文合作者，连接图像检索学术圈与产业界。

**第五圈层——学生辐射圈（人才网络扩散）**
- 35名已毕业博士构成的校友网络，广泛分布于华为（天才少年计划）、字节跳动、阿里巴巴、腾讯、百度、快手、DeepSeek、地平线、海康威视、OPPO等头部科技企业，以及中国科学技术大学（邓家俊，国家级青年人才）、合肥工业大学、杭州电子科技大学等高校。这一人才网络使得周文罡课题组的影响力从学术圈延伸至产业界前沿。

**总体特征**：周文罡的学术网络以中科大MCC实验室为锚点，向上通过师承关系连接田奇（华为）和微软亚洲研究院，向下通过学生培养辐射至国内主要科技企业。其最显著的合作特征是与导师李厚强教授的长期紧密联合——二人共同构建了一个兼具学术深度与产业辐射力的研究共同体，在图像检索、手语识别、视觉定位、3D视觉与具身智能等方向持续产出高水平成果。
