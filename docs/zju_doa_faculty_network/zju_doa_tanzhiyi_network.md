## 二、教育背景与职业履历

谈之奕是典型的浙大本土学者，其学术生涯的每一步都在浙江大学完成，履历连续且清晰：

- **1992年9月—1996年7月**：浙江大学应用数学系，本科；
- **1996年9月—2001年6月**：浙江大学数学系，硕士、博士（直攻博士学位）；
- **2001年7月—2003年7月**：浙江大学系统科学与工程学系，博士后；
- **2003年8月—2007年12月**：浙江大学数学系，副研究员；
- **2007年12月至今**：浙江大学数学系（数学科学学院）教授、博士生导师。

从本科入学算起，谈之奕在浙大已度过三十余年，其研究方向自博士阶段起即聚焦于排序理论与在线算法，此后逐步扩展至算法博弈论与机制设计，形成"组合优化—在线算法—博弈分析"三位一体的研究主线。这一演进轨迹也直接反映在其主持的国家自然科学基金项目序列中：

1. 平行机排序问题的新模型和新算法（2004-2006）；
2. 排序若干新问题的算法设计与分析（2007-2009）；
3. 排序问题的博弈分析和多目标排序（2010-2012）；
4. 分散决策模式下的排序问题研究（2013-2016）；
5. 平行机排序博弈的均衡分析与机制设计（2017-2020）。

此外，他还主持了浙江省自然科学基金项目《网络通信和信息传播中的离散优化问题》（2008-2010）以及浙江省杰出青年科学基金《若干组合优化问题的算法设计与分析》（2012-2014），表明其研究在国内省部层面亦获得持续认可。其论文主题覆盖半在线排序、装箱问题下界、机器覆盖博弈的无效率分析（Price of Anarchy）、带预测的非透视调度等方向，近期（2026年）仍在《Discrete Applied Mathematics》等期刊上发表排序博弈协调机制方面的新成果，学术产出持续而稳定。

谈之奕长期担任博士生导师，且在教学一线投入极深。其培养的学生呈现一个非常鲜明的特征：**大批弟子进入杭州及周边高校，形成了一个以"浙大数学—杭电—浙理工"为轴心的杭州离散优化学术圈**。根据公开论文署名与公开履历可辨识的代表性学生/合作弟子包括：

- **张安（An Zhang）**：与谈之奕合作论文11篇，为合作频次最高的学者之一，现为杭州电子科技大学教授，是杭电运筹优化方向的骨干力量，同时在浙大离散优化生态中与张国川研究组亦有交集；
- **陈永（Yong Chen）**：杭州电子科技大学教授，合作论文4篇，同样出身浙大数学系，与张安构成杭电"组合优化双子星"；
- **蒋义伟（Yiwei Jiang）**：浙江理工大学教授，合作论文5篇，主要研究方向为在线算法与近似算法；
- **陈倩倩（Qianqian Chen）**：合作论文3篇，杭电系统；
- **严玉杰（Yujie Yan）、林凌（Ling Lin）**：各合作5篇，其中林凌与谈之奕合著教材《组合优化与博弈论》，是其在教学建设上的重要伙伴；
- **何朝宇（Chaoyu He）、李榕奇、万龙、陈光廷、丁志豪**等：均以谈之奕（及合作导师）署名发表了多篇排序博弈方向论文，多人目前在杭州高校任教。

在本科生培养层面，谈之奕是国家精品资源共享课《数学建模》负责人、国家级教学团队《数学建模方法与实践》成员、浙江大学数学建模实践基地指导教师，指导的学生在全国大学生数学建模竞赛与美国大学生数学建模竞赛（MCM/ICM）中屡创佳绩。竺可桢学院荣誉课程《数学建模》《线性代数》也由他主讲，其教学影响覆盖了浙大理科拔尖人才的多个年级。

## 四、学术合作网络

### 4.1 浙大内部合作

谈之奕最重要的校内学术纽带包括：

- **何勇（Yong He，1969-2005）**：浙大数学系教授，谈之奕早期最核心的合作者，两人合作论文达12篇，主要集中于在线排序与半在线算法领域。何勇于2005年英年早逝，谈之奕曾参与撰写纪念社论（"In memoriam: Yong He"），这段合作深刻影响了谈之奕此后的研究方向选择；
- **张国川（Guochuan Zhang）**：计算机学院教授、浙大离散优化与算法研究组创始人。两人分属数学学院与计算机学院，但长期同属浙大组合优化生态的核心：研究方向高度互补（张侧重近似算法与在线算法的计算机科学视角，谈侧重运筹学与博弈论建模），两人及其学生经常在同一学术会议（如全国排序论会议、中国运筹学会学术年会）上共同出现，学生群体之间亦有大量合作论文；
- **张国川研究组成员**：百人计划研究员陈林（张国川学生）、讲师毛宇尘等，与谈之奕的学生群体（张安、陈永、蒋义伟等）在排序博弈、在线算法等课题上存在广泛的二度合作，构成浙大离散优化"跨院系联合体"的中坚层。

### 4.2 跨机构国内合作

在国内，谈之奕的合作网络以杭州为中心向外辐射：

- **杭州电子科技大学**（张安、陈永、陈倩倩等）：这是其学生网络的主要落点，双方形成了长期的师生型合作关系，近年大量排序博弈论文由"谈之奕 + 杭电团队"联合发表；

- **Guohui Lin（林国辉，阿尔伯塔大学，加拿大）**：合作3篇，华人组合优化学者中的重要合作对象；

可以看到，其国际合作呈现"匈牙利学派 + 以色列在线算法学派 + 北美华人学者 + 港校调度团队"的多元格局，与其研究主题（半在线排序、装箱、调度博弈）在国际上的主要力量分布高度吻合。

## 五、业界合作关系深度分析

与许多工程应用型团队不同，谈之奕的研究属于基础数学/理论运筹学范畴，其与业界的联系更多体现为**间接赋能型**而非直接项目合作型：

- **研究主题的应用出口**：其排序博弈、机制设计、在线调度研究天然对应云计算资源调度、物流配送路径优化、生产排程等产业场景，是运筹优化算法在工业界落地（如供应链优化、网约车派单、算力调度）背后的理论基石；
- **数学建模竞赛生态**：作为国家精品课程《数学建模》负责人，谈之奕长期处于"数学建模—产业问题求解"的桥梁位置，其指导的竞赛学生大量进入数据科学、运筹优化相关行业，形成人才层面的业界辐射；
- **教材影响力**：《组合优化与博弈论》被国内多所高校用作运筹学教材，其第九章博弈论部分为算法博弈论在国内运筹学教学中的普及提供了标准化材料。

综合判断，谈之奕的Connection图谱中**业界直接合作权重较低，学术共同体（师生网络 + 国际同方向学者）权重极高**，这是理论数学学者的典型网络形态。

## 七、Connection圈层总结

谈之奕的学术关系网络可以概括为**"一个本土、两层辐射、三重国际纽带"**的结构：

1. **核心圈（浙大离散优化生态）**：以浙大为原点，数学学院（谈之奕、已故的何勇）与计算机学院（张国川研究组：张国川、陈林、毛宇尘）构成双核驱动的组合优化联合体。谈之奕虽行政隶属数学学院，但与张国川研究组是紧密的学术同盟，两系学生高度互通，是浙大离散优化在国内占据一席之地的根本原因之一；
2. **学生辐射圈（杭州高校群）**：张安、陈永（杭电）、蒋义伟（浙理工）等弟子扎根杭州，将浙大排序论的学术传统扩散为区域性学术力量，"谈之奕—杭电"师生合作线是国内排序博弈方向最活跃的产线之一；
3. **国际纽带**：匈牙利装箱学派（Dósa、Tuza、Balogh）、以色列在线算法学派（Epstein）、加拿大/香港华人调度学者（林国辉、郑大昭），使其研究始终嵌于国际前沿对话之中。

对于希望通过Connection路径接触谈之奕的申请者或合作者而言，最自然的切入点是：排序论/算法博弈论方向的学术兴趣（尤其是调度博弈的无效率分析、半在线算法等其长期深耕的主题）、数学建模背景（其教学主线）、或经由杭电/浙理工离散优化群体的推荐。其网络特点是理论导向、师生纽带强、忠诚度高——一位在浙大持续工作三十余年、把教学与理论研究生涯完全融入同一所校园的学者，其网络的核心资产是人和信任，而非项目与资本。
