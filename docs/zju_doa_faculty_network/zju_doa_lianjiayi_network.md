### 4.3 国际网络：顶会论文与理论算法社群

连佳宜国际网络的最直接可见节点是STOC和FOCS所连接的全球理论计算机科学同行评议社群。三篇论文的技术贡献均置于国际算法复杂性研究的评价框架中：

- **《Approximating Partition in Near-Linear Time》（STOC 2024，arXiv:2402.11426）**：提出划分问题的 $\widetilde{O}(n+1/\varepsilon)$ 时间FPTAS，在强指数时间猜想（SETH）下近乎最优，使划分问题成为首个拥有几乎线性时间FPTAS的NP困难问题。
- **《A Nearly Quadratic-Time FPTAS for Knapsack》（STOC 2024，arXiv:2308.07821）**：改进背包问题近似方案的运行时间。
- **《An Improved Pseudopolynomial Time Algorithm for Subset Sum》（FOCS 2024）**：在子集和问题精确算法复杂度的核心开放问题上取得显著进展。

这些成果虽由浙江大学单一机构完成，却需要与既有国际工作（如Abboud, Bringmann, Hermein, Shabtay等人的下界结果，Deng, Jin, Mao及Wu, Chen的先前FPTAS）进行严格比较，也会通过会议报告、同行引用和后续研究建立间接国际连接。因此，连佳宜的国际网络目前更适宜描述为"以研究成果为媒介的学术传播网络"——通过论文进入国际同行视野，而非通过海外合作者署名建立的直接合作网络。
