# 浙江大学离散优化与算法团队 学术关系网络报告

## 团队简介

本报告集涵盖浙江大学离散优化与算法研究组的学术关系网络。该研究组由张国川教授于2009年1月在浙江大学计算机科学与技术学院建立，聚焦组合优化问题的算法分析与设计，是国内离散优化领域的重要研究力量。2024年，团队在STOC和FOCS上发表论文3篇（浙江大学为唯一完成单位），实现了浙大在该领域的历史性突破。

## 团队架构

团队以张国川教授为核心，其博士生陈林（现为百人计划研究员）为学术中坚，谈之奕教授（数学学院）为跨院紧密合作者，毛宇尘讲师和连佳宜博士后为青年骨干。团队2024年在背包问题、子集和问题、划分问题上的突破性成果（STOC×2 + FOCS×1）由四人共同完成。
