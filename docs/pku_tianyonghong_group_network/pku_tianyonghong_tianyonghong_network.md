## 三、学生培养情况

田永鸿自加入北京大学后开始独立指导研究生，课题组（PKU-ML）依托视频与视觉技术国家工程研究中心运行。根据课题组网站（pkuml.org）公布的信息及公开报道，以下列出已毕业博士及代表性学生。需说明的是，课题组网站显示的毕业生信息截至约2023年底，2024年及以后毕业的学生信息暂未公开。

### 1. 陈光耀（2023年博士毕业，田永鸿指导博士生）

陈光耀为北京大学计算机学院2018级博士研究生，计算机应用技术专业，师从田永鸿教授。2023年7月通过博士论文答辩，同年获北京大学优秀博士学位论文奖。博士论文题目为《开放视觉场景下未知类建模与学习方法研究》，聚焦开放场景下未知类检测与新类别发现，创新性地提出振幅相位重组优化、互惠点学习、可融合先验学习等方法。研究成果已在IEEE TPAMI、NeurIPS、ICCV等国际顶级期刊会议发表论文十余篇，并作为主要技术骨干参与编制全球首个人工智能模型表示与压缩技术的国际标准IEEE 2941和国内首个AI模型技术国家标准。成果已在百度、华为等企业产品中获得应用。曾获北京市优秀毕业生、石青云院士优秀论文、国家奖学金、IEEE标准突出贡献奖等荣誉。

## 五、业界合作关系深度分析

### 5.1 鹏城实验室与华为（鹏城云脑与昇腾生态）

田永鸿在鹏城实验室的角色是其业界合作网络中最核心的一环。作为鹏城云脑技术总师，他主导了超大规模国产智能算力系统的底层系统设计与技术创新。

**鹏城云脑项目概况**：该项目由鹏城实验室牵头，联合华为、北京大学、清华大学等单位协同攻关，建成国内首个全国产芯片（华为昇腾Ascend）超大规模AI智算集群。田永鸿与团队深耕底层系统设计，创新超大规模国产AI集群的高效互联架构，通过软硬件深度优化大幅提升大模型训练并行效率。平台连续斩获IO500、AIPerf500多项国际榜单全球第一（截至2026年6月已实现IO500十二连冠），支撑上千个国产大模型研发。

**产业化带动效应**：项目带动了华为昇腾大规模产业化，牵引科大讯飞、中国移动等互联网和运营商企业搭建10余个万卡昇腾智算集群，相关国产芯片累计出货超100万片。项目同步为讯飞星火、移动九天等国内超半数国产大模型的训练迭代及规模化应用提供全链条支撑。2025年度获国家科技进步一等奖。

**与华为的具体合作维度**：

| 维度 | 内容 |
|------|------|
| 芯片层面 | 基于华为昇腾AI芯片构建全国产智算集群 |
| 存储层面 | 鹏城云脑III采用华为OceanStor A800存储系统 |
| 软件层面 | 全栈软件系统协同优化，包括CANN、MindSpore等华为软件栈 |
| 生态层面 | 带动全国多地智算中心落地，形成可复制的国产智算建设方案 |

## 七、Connection圈层总结

田永鸿的学术关系网络呈现出以"高文-田永鸿"师承关系为轴线、以"北京大学-鹏城实验室-华为"为三角支撑的多层次结构。

**第一圈层（核心导师与合作者）**：高文院士是田永鸿整个职业生涯的核心人物。从博士阶段的师生关系（极可能），到北京大学的同事关系，再到鹏城实验室的正副职搭档关系，两人的合作贯穿视频编码（IEEE 1857标准）、数字视网膜概念提出（2018年）、鹏城云脑系统建设（2018年至今）和AI4S研究（2024年Nature Machine Intelligence）等全部关键节点。高文是鹏城实验室主任，田永鸿是网络智能部副主任兼云脑研究所所长，形成了"院士挂帅+杰青执行"的典型合作模式。

**第二圈层（校内学术搭档）**：黄铁军是田永鸿在神经形态视觉和脉冲相机方向最密切的合作者，两人在2017年国家技术发明二等奖中分列前两位（黄铁军第1、田永鸿第2），在多篇TPAMI论文中合作发表。马思伟在视频编码方向平行发展，在大项目中协同但各自独立。课题组层面，袁粒（信息工程学院助理教授）在视频生成方向合作，陈杰在AI4S方向合作。课题组毕业生彭沛翔等以研究团队成员身份留组继续合作。

**第三圈层（跨机构合作者）**：中科院自动化所李国齐是SpikingJelly框架的共同通讯作者，形成了"北大-中科院"脉冲神经网络合作联盟。厦门大学/北大的Rongrong Ji在NAS和模型量化方向有大量论文合作。广州国家实验室周鹏研究员在AI4S方向合作。

**第四圈层（产业合作网络）**：华为是田永鸿产业合作的最核心伙伴，鹏城云脑项目基于华为昇腾芯片构建，形成了深度的"学术-产业"绑定关系。海康威视、海信网络科技、云天励飞等企业在视频智能处理和数字视网膜产业化中参与合作。百度、华为等企业在IEEE 2941标准成果转化中受益。

**独特定位**：与VVT研究所其他教授相比，田永鸿的独特性在于他是唯一同时深度参与"底层算力系统建设"（鹏城云脑）、"前沿类脑计算研究"（脉冲神经网络、SpikingJelly）和"国际标准制定"（IEEE 2941）三个维度的学者。他既是IEEE Fellow和国家杰青，又是鹏城云脑技术总师和信息工程学院院长，在"学术研究-工程系统-行政管理"三重角色中保持了罕见的平衡。2025年度国家科技进步一等奖和2025年IEEE Hans Karlsson标准奖的双重认可，标志着他在工程系统和标准制定两个维度均达到了国际顶级水平。
