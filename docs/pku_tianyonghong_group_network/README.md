# 北京大学信息工程学院田永鸿课题组（PKU-ML）学术关系网络报告

## 团队简介

田永鸿课题组（PKU-ML，课题组网站 pkuml.org）是北京大学信息工程学院的核心机器学习研究团队，同时深度嵌入北京大学深圳研究生院与鹏城实验室的科研体系。田永鸿为北京大学博雅特聘教授、IEEE Fellow（2021年11月当选）、2018年国家杰青及2024年首届杰青延续资助获得者，现任北京大学信息工程学院院长（2022年6月起）、深研院副院长、科学智能学院执行院长，并兼任鹏城实验室网络智能部（现先进计算部）副主任兼云脑研究所所长、鹏城云脑技术总师。

课题组研究方向覆盖分布式机器学习、神经形态视觉/脉冲神经网络、视频大数据分析处理与 AI for Science，代表性工作包括"数字视网膜"智慧城市系统、脉冲相机视觉重建、大规模类脑神经网络理论等。2026年7月公布的2025年度国家科学技术进步奖评选中，高文院士与田永鸿牵头研发的"鹏城云脑"超大规模国产智能算力系统及产业化工程项目荣获一等奖，田永鸿作为技术总师是该项目的核心人物。

## 研究方向与圈层结构概述

田永鸿2005年获中国科学院计算技术研究所博士学位（博士导师公开信息不明，据多源推断与高文院士团队关系密切），其后进入北京大学（深研院/信息工程学院）任教，长期作为高文团队核心成员参与 AVS 与视频大数据研究。其学术网络呈四层结构：第一层是北大视频与视觉技术体系（高文、黄铁军、马思伟、王亦洲等），特别是与黄铁军在脉冲相机、类脑视觉方向的长期合作（学生朱林、李佳宁等由双方联合指导）；第二层是鹏城实验室体系，作为云脑研究所所长主导鹏城云脑 I/II/III 系统建设，与华为昇腾生态深度协同，鹏城云脑 III 于2026年6月在 ISC26 斩获 IO500 全球双榜第一、实现十二连冠；第三层是学生传承网络，培养出陈光耀（2023北大优博，开放视觉场景未知类建模）、翟云鹏、李马、李佳宁、朱林等已毕业博士，去向覆盖鹏城实验室、高校与产业界；第四层是标准与产业网络，担任 IEEE 数据压缩标准委员会副主席兼 IEEE 2941 标准工作组组长，推动神经网络表示与模型压缩国家标准（GB/T 42382.1-2023）制定，该标准由北大、鹏城实验室、华为、百度等16家单位共同编制。

## 产业转化亮点

鹏城云脑是本组最具代表性的产学研成果：作为技术总师，田永鸿主导设计的超大规模国产智能算力系统以华为昇腾芯片为底座，支撑开源大模型训练生态，获2025年度国家科技进步一等奖。数字视网膜理论与城市大脑系统在安防与智慧城市场景落地；神经网络模型压缩标准连接学术研究与产业落地；课题组与华为、字节跳动（学生获字节跳动奖学金）、商汤等企业保持密切合作。
