## 团队概况

金小刚课题组是CAD&CG全国重点实验室计算机动画与数字人方向的代表性团队。金小刚为浙大本硕博（1989学士—1995博士）本土培养的资深教授，1995年起留实验室工作至今，研究方向横跨布料动画与虚拟试衣、群组动画、表情动画、数字人脸重建、动捕解算与AIGC。近年代表性成果包括 AnimPortrait3D（SIGGRAPH 2025，文本生成可动画3D高斯泼溅虚拟人）、RoMo（SIGGRAPH Asia 2024，全身无标记光学动捕）、StyleTex（SIGGRAPH Asia 2024）等。

课题组产业属性突出：金小刚任浙江大学-腾讯游戏智能图形创新技术联合实验室主任，与腾讯天美J1&F1（实时运动间补，SIGGRAPH 2022）和NExT Studios（EyelashNet、宽松服装形变预测）均有联合论文；其国产数字化服装CAD工业软件成果获2022年浙大信息学部首届光谷成果转化奖。金小刚为2023年浙江省科技进步一等奖"智能化三维数字人制作关键技术及应用"第三完成人（周昆列第一，浙大/网易/相芯联合完成）。

## 学术谱系概览

金小刚的硕博阶段（应用数学系计算几何与图形学方向）正值彭群生等前辈主导实验室图形学研究的时期，其学科背景与梁友栋计算几何一脉高度重合（直接师承关系待核实）。课题组以博士生梯队为主，代表学生包括吴奕谦（AnimPortrait3D一作，ETH访学双导师）、潘晓宇（RoMo一作）等；在数字人产业网络中，金小刚与周昆组、网易、相芯科技通过2023年省奖等载体形成深度联结（秦昊系周昆学生、翁彦琳为控制系背景的合作完成人，均已严格区分，未冒领为金小刚学生）。
