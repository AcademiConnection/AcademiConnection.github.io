## 七、Connection圈层总结

基于以上分析，王亮的学术关系网络可划分为四个圈层：

**第一圈层（导师与核心团队）**：以谭铁牛院士为核心。谭铁牛是王亮的博士导师和回国后的合作导师，二者共同持有步态识别基础专利。谭铁牛创建的智能感知与计算研究中心是王亮团队的母体。在谭铁牛2015年调任中科院副院长后，王亮逐步独立承担研究中心常务副主任角色。黄岩是王亮亲自培养的博士、现为团队骨干，是第一圈层内的核心学生。

**第二圈层（博士生与校友网络）**：王亮团队已培养多届博士，其中黄永祯（2011年毕业）是最具产业影响力的校友，创办银河水滴科技。团队论文中青年作者（含研究人员及在读成员，身份未逐一核验）如张璋、宋依凡 (Yi-Fan Song)、黄林江 (Linjiang Huang)、陈春峰 (Chunfeng Song)、司晨阳 (Chenyang Si) 等持续出现在 TPAMI/CVPR/ECCV 等顶会论文中，反映出团队的稳定产出能力。

**第三圈层（同机构同事）**：胡卫明等自动化所模式识别方向资深研究员是早期论文合作者。赫然等同实验室研究员各自独立带领团队，属于"同实验室平行团队"关系而非密切合作关系。自动化所内从事NLP（宗成庆等）、脑科学（蒋田仔等）、机器人等方向的同事与王亮团队研究方向不重叠，不构成直接合作关系。

**第四圈层（海外合作者与产业伙伴）**：海外合作者（Leckie、Kotagiri、Suter、Smith-Miles 等）主要活跃于2010年前，回国后合作关系减弱。产业层面，银河水滴是核心技术转化载体，华为/腾讯/京东/高德/爱奇艺/美的等为团队层面的技术研发或应用合作方。
