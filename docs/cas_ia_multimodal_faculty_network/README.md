# 中科院自动化所多模态方向三团队 学术网络报告

本目录收录中国科学院自动化研究所五位学者的学术关系网络报告，覆盖依托多模态人工智能系统全国重点实验室（2022年由模式识别国家重点实验室与复杂系统管理与控制国家重点实验室实质性重组而成）及紫东太初大模型研究中心的三个研究方向：计算机视觉（王亮）、自然语言处理（宗成庆、张家俊）与机器人（乔红、王鹏）。

团队边界须特别澄清：自动化所内上述三个方向为相互独立的研究团队，不能相互混同。王亮领导的团队聚焦计算机视觉与智能感知（师承谭铁牛院士，隶属智能感知与计算研究中心），与赫然的生成模型团队为同实验室平行团队；宗成庆为NLP团队（中文信息处理组）学术带头人、张家俊为其团队核心研究员（现属紫东太初大模型研究中心），与赵军、刘康的知识工程/信息抽取团队为所内平级独立团队；乔红院士领导机器人"手—眼—脑"团队，王鹏为该体系"手"方向核心教师。三组之间不存在团队隶属或师生交叉，仅存在所级学术活动层面的交集。此外，王鹏与乔红的师生直系关系未获官方记载（王鹏博士阶段唯一导师未公开披露），按团队平台合作处理；宗成庆与张家俊的师生关系亦未经官方明示，按同团队核心同事与长期合著者记录。

## 研究方向与圈层结构概述

**CV团队（王亮）**：以谭铁牛—王亮师承为第一圈层（王亮为中国首位步态识别博士，与导师共同持有基础专利），黄岩（2017年博士、现研究员）为团队核心骨干，黄永祯（2011年博士）为最具产业影响力的校友；第二圈层为胡卫明等模式识别方向资深同事；第三、四圈层为英澳海外合作者（Leckie、Kotagiri、Suter等）与产业伙伴。团队从步态识别扩展至视觉-语言理解、时序建模，连续入选ESI高被引科学家。

**NLP团队（宗成庆—张家俊）**：宗成庆2025年出任国际计算语言学学会（ACL）主席，为该组织60余年来第三位华人主席；其主编《统计自然语言处理》是国内NLP影响最广的教材，因年龄原因自2025年起不再招生。张家俊主持科技创新2030重大项目（通用视觉对话模型，2000万元），学生陆金梁、金飞虎、王迁等以"学生一作+通讯作者"模式培养；周玉、赵阳、夏睿、朱军楠等构成实验室协作网络，形成"宗成庆—张家俊—学生"三代传承。

**机器人团队（乔红—王鹏）**：乔红院士（英国三校训练、曼彻斯特永久教职，2004年百人计划回国）以"环境吸引域"原创理论（国际称"乔的概念"）为学术内核，核心圈层含刘志勇、张波、徐杨、苏建华、王鹏、刘传凯等资深研究员与陈嘉浩（中科院优博）、郑恩昊、吴雅雄等新生代；第二圈层为北大王启宁团队（穿戴机器人联合研究）与北科大、中科大联培平台；第三圈层为IEEE学术治理网络（首位中国内地RAS管理委员会委员、世界机器人合作组织首任理事长）；第四圈层为广东产业化基地、Q系列人形机器人"大工厂"与中科硅纪孵化企业。

## 产业转化亮点

- **银河水滴科技（CV团队孵化）**：2016年由黄永祯创办，王亮、谭铁牛任重量级顾问，步态识别技术拥有世界最大户外步态数据库，2019年获WAIC最高奖SAIL，2020年刷新步态识别世界纪录并参与起草国家标准；王亮团队另与华为、腾讯、爱奇艺、京东金融、高德、美的等开展团队层面技术合作。
- **中科硅纪（机器人团队孵化）**：王鹏任创始人，2024年成立于南京，承接Casia Hand系列灵巧手产业化（M6量产款约六千元、G7工业50公斤负载款），2026年上半年订单破亿元，成果获2024年日内瓦国际发明展金奖与央视报道。
- **Q系列人形机器人**：乔红团队2024年发布谱系化Q1—Q5（Q5融入紫东太初多模态大模型），"人形机器人大工厂"获国家层面关注；广东两个机器人产业化基地落地精密装配与高速分拣。
- **NLP产业应用**：宗成庆团队多语言机器翻译与文本挖掘系统应用于国家重要领域和部门，曾承担863互联网语言翻译系统课题（906万元）；张家俊的多语言大模型研究延伸至视觉对话场景。
