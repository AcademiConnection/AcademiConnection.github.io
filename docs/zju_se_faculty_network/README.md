## 二、各位教师的角色定位

杨小虎是区块链研究中心的现任主任与软件所的建制核心。研究员、博导，兼任区块链与数据安全全国重点实验室副主任（该实验室主任为陈纯院士），研究程序设计语言、编译技术与区块链/智能合约安全。他自2001年起执掌浙大-道富技术中心，这一校企合作平台是浙大软件工程方向最重要的产学载体之一，也是多位创业者（如王新宇）的职业起点。

孙建伶与李善平是软件所的两代资深支柱。孙建伶1993年博士毕业留校，是浙大-道富技术中心联合创始人、阿里巴巴-浙大前沿技术联合研究中心"下一代数据库技术实验室"负责人，深耕数据库与中间件三十余年，道富中心/VLIS团队走出的产业人才（包括趣链科技CEO李伟，其具体指导关系待核实）多与其平台相关。李善平深耕嵌入式系统与物联网软件，曾任网新恒天高级副总裁/CIO（产业深度参与），现牵头国家重点研发计划"基于区块链的互联网信息服务监管关键技术"项目。

蔡亮是陈纯院士区块链路线在软件所的执行者。研究员、博导，区块链研究中心常务副主任，曾任趣链科技副董事长（曾长期担任法定代表人，2023年卸任；其"联合创始人"身份未见权威公开来源证实，以工商与公司披露为准），是区块链方向产学研转化的关键纽带。

王新宇是软件所谱系中"道富中心孵化创业"的典型样本。他是杨小虎在道富技术中心指导的第一批学生，后任浙大教授、博导，研究方向智能软件工程与大数据实时处理，获ICSE 2018与ASE 2018杰出论文奖，并创立实时风控企业邦盛科技（已进入IPO进程），是浙大"教授办企业"在软件工程方向的代表。

## 三、全实验室关系网络的整体观察

第一，"一个道富中心，半部创业史"。浙大-道富技术中心（杨小虎、孙建伶主持）孵化了以王新宇（邦盛科技）、李伟（趣链科技，与陈纯团队合作）为代表的产业人才集群，加上李善平在网新恒天的产业任职，软件所是浙大计算机学科中"产业基因"最浓重的建制之一。

第二，与陈纯院士体系的深度耦合。区块链研究中心（杨小虎主任、蔡亮常务副主任）与区块链与数据安全全国重点实验室（陈纯主任、任奎常务副主任、杨小虎副主任）形成"两块牌子、深度交叉"的人事网络，软件所由此接入趣链科技产学研闭环（陈纯-李伟-蔡亮轴线）。

第三，方向横跨"编译-数据库-嵌入式-区块链-软件工程"。软件所虽以"软件"为名，实际覆盖从底层系统（杨小虎的编译与合约安全、李善平的嵌入式OS）到数据系统（孙建伶的数据库与中间件）再到工程智能化（王新宇的智能软件工程）的完整软件栈，是浙大计算机学科中方向最分散、但产业出口最集中的研究所。

第四，师承谱系以内生+平台型为主。所内教师间的强连接多经由道富中心等平台项目而非师生传承形成；蔡亮与陈纯的师承关系、李伟与孙建伶的指导关系均待一手证据，报告均审慎标注。
