## 二、教育背景与职业履历

王新宇1998年进入浙江大学计算机科学与技术学院攻读本科，2002年获学士学位并被保送为硕博连读研究生。2001年（大三保送后），他作为第一批共15名学生之一加入何志均教授牵头、陈纯院士推动组建的浙江大学-道富技术中心，在杨小虎、孙建伶、周波、李善平等年轻教师带领下从事金融软件研发，由此进入浙大计算机学科"产学研"体系。2002年9月至2007年7月在浙大计算机学院攻读博士学位（计算机应用专业，研究方向为软件再工程；博士导师身份未见公开确证，待核实）。2007年7月博士毕业后留校从事博士后研究（2007.7-2009.10），随后历任讲师（2009.10-2011.12）、副教授（2011.12-2017.09）、博士生导师/副教授（2017.09-2019.01），2019年1月晋升教授并任博士生导师至今。

其学术研究的早期阶段聚焦分布式软件架构、金融信息工程与软件再工程：提出基于数据划分的软件分布式设计方法、可信驱动的遗留系统再造方法论等，与杨小虎、李善平等联合获得多项发明专利，项目合作单位包括美国道富银行、中国外汇交易中心、Cisco、IBM、浙大网新等。2010年起，其研究重心转向数据驱动的软件工程：在动态符号执行测试领域首次提出最优化策略，获 ICSE 2018 杰出论文奖；在提交日志（commit message）自动生成领域建立新基线，获 ASE 2018 杰出论文奖。近年其团队（智能软件工程方向）持续在 TSE、TOSEM、ICSE、ASE、ISSTA、FSE 等软件工程顶级刊物与会议产出成果，研究前沿延伸至基于大语言模型的缺陷检测（RLV）、公平性测试、LLM 语言学偏见评测（IJCAI 2025）与图学习（与其合作的浙大视觉智能团队联合发表 KDD、TKDE、VLDB 论文）。与此同时，他还是国家重点研发计划项目"基于编程现场大数据的软件智能开发方法和环境"（2018.5-2021.4）负责人，并曾主持国家科技支撑计划项目"基于云计算的物流信息服务关键技术与云平台研究与开发"（2014-2016）、国家自然科学基金及多项省部级课题，产业合作课题20余项。

## 五、业界合作关系深度分析

### 5.1 产业合作（邦盛科技等）

王新宇是"道富系"产学研模式中"教师创业"的代表性人物。2010年，他创立浙江邦盛科技（前身杭州邦盛金融信息技术有限公司），此后五年带领团队自研时序大数据实时智能处理平台"流立方"：核心性能指标超国外同类产品近百倍，峰值吞吐量达每秒300万笔、平均延迟毫秒级，在金融实时风控领域实现国产替代，大型银行实时风控市场占有率超过80%，服务500余家大中型单位（银联商务、近百家大中型商业银行、国泰君安、新华保险等）。邦盛科技股权结构分散，王新宇为实际控制人（合计控制约22.06%股份），长期担任董事长（早期董事长为陈纯院士，招股书认定王新宇与陈纯为共同实际控制人）；股东包括恒生电子、国投创业、君联资本、绿盟科技、浙大未来创投等。邦盛曾于2023年申报科创板IPO（拟募资约12.67亿元），后经历波折，2025年10月在浙江证监局重启IPO辅导（辅导机构银河证券、湘财证券；最新进展待核实）。此外，其早期项目合作单位还包括美国道富银行、中国外汇交易中心、Cisco、IBM、浙大网新等，产业合作课题累计20余项。

### 5.2 创业孵化与开源生态

王新宇自身是浙大计算机学科产学研体系孵化的创业者，而非孵化他人的投资型人物；其对生态的贡献更多体现在：（1）为道富技术中心/VLIS 体系培养了大批实时计算与金融风控工程人才，邦盛科技与其同源企业（趣链科技、谐云科技、网新恒天等）共享"浙大系"人才池；（2）其"实验室成果→自研平台→国产替代"路径成为浙大软件所创业范式的重要样本；（3）其团队在软件工程顶会的持续开源工具与数据集产出（如提交日志生成、缺陷定位工具链）构成智能软件工程研究的公共基础设施。中心层面亦与华为等企业建立联合实验室（2022年前后 ICSoft 平台披露，具体合作内容待核实）。

## 七、Connection圈层总结

**核心圈层（师生传承）**：王新宇的学术谱系呈"双线"结构。产业线：何志均（创系元老）→ 陈纯（产学研战略）→ 杨小虎、孙建伶、周波、李善平（道富中心带队教师）→ 王新宇（第一代学生、第二代创业者）。学术线：浙大软件所软件工程传统 → 其本人（ICSE/ASE 2018 双杰出论文）→ 邱方成、高志鹏、王浩野、张培鑫、董国梁等新生代学者，形成缺陷定位、漏洞检测、代码大模型等方向的人才梯队。

**中间圈层（校内协作）**：以智能计算与软件中心（杨小虎）为平台，与陈纯、蔡亮、李善平的区块链团队同平台共存；与宋明黎、冯尊磊等视觉智能团队在图学习方向深度交叉；与夏鑫（浙大校友）构成浙大软件工程的校内外双核。

**外围圈层（国际与产业）**：国际上以 Jun Sun、Jinsong Dong、Michael R. Lyu、David Lo、John Grundy、Xin Xia 等软件工程/形式化方法学者为稳定合作网；产业上以邦盛科技为轴心，连接银联商务、恒生电子、国投创业等金融科技资本与客户网络，并与趣链科技、谐云科技等同源"浙大系"企业共享人才生态。

总体而言，王新宇是浙大计算机软件研究所"产学研一脉"的枢纽型人物：他以学术身份（教授、软工顶会获奖者）与产业身份（独角兽级企业创始人/董事长）的双重角色，同时嵌入学术共同体（国际软工网络+浙大软工团队）与产业生态（道富系金融科技集群）。其学术关系网络的最大特色在于——学术研究（智能软件工程）与创业实践（实时大数据平台）两条线虽方向不同，却共用同一张源自道富技术中心的人际网络：杨小虎是其共同的起点，陈纯是其共同的背书，而邦盛科技与趣链科技则是这张网络在实时计算与区块链两个赛道上结出的并蒂果实。
