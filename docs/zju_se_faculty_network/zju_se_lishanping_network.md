## 二、教育背景与职业履历

李善平为计算机（应用）专业博士，毕业于浙江大学，1987 年起在浙江大学任教至今，是浙大计算机学院任教近四十年的资深教授。其履历可分为三个阶段：

**第一阶段（1987–2000 年代中期）：操作系统与嵌入式 Linux 时期。** 他长期主讲《操作系统》课程，在国内高校中率先开设 Linux 操作系统实验课，出版《边干边学——Linux 内核指导》（"十一五"国家级规划教材）、《Linux 与嵌入式系统》、《Linux 内核的代码分析》等多部 Linux 教材与专著，并出版《产品数据标准与PDM》。这一时期他承担了多项嵌入式 Linux、无线传感器网络方向的研究（如与刘文峰、李程远合作的嵌入式 Linux 操作系统研究），曾作为负责人完成 3 项国家自然科学基金项目和 4 项国家 863 计划项目。

**第二阶段（2000 年代中期–2010 年代）：普适计算与分布式系统时期。** 其团队承担国家自然科学基金项目"跨智能空间上下文共享研究"、"普适计算中的网格接入"等，DBLP 记录显示这一阶段其论文集中于上下文感知计算、移动 P2P、无线传感网与产品本体推理。

**第三阶段（2010 年代至今）：软件工程与区块链时期。** 李善平加入计算机软件研究所（智能计算与软件中心）建制，成为软件所软件工程方向（智能软件工程、缺陷定位、软件仓库挖掘、智能合约安全）的资深指导教师；2021 年 12 月起作为项目负责人承担国家重点研发计划项目"基于区块链的互联网信息服务监管关键技术"（2021.12–2024.11）。其学术身份在媒体中的最新呈现，是作为操作系统领域专家评论国产开源桌面操作系统"开放麒麟"及鸿蒙生态（2023 年杭州网采访）。此外，他曾任浙大网新恒天软件有限公司高级副总裁、CIO（2016 年公开活动资料），具有多年企业高管经历。

## 七、Connection圈层总结

**核心圈（教学与门生）**：李善平自 1987 年任教以来以《操作系统》课程和 Linux 教材为支点，培育了跨越嵌入式、普适计算、软件工程三代方向的学生群体：早年的林鑫、史伟、彭刚等（嵌入式/普适计算），近年的鲍凌峰、刘忠鑫、刘家坤、张俊伟等（智能软件工程与智能合约安全），以及博士后万志远。

**建制圈（软件所/区块链研究中心）**：他与杨小虎构成软件所"双资深"结构——杨小虎管平台与产业，李善平管教学与研究生论文生产线；两人共享专利、软著与合著论文，并共同嵌入陈纯—蔡亮的区块链全国重点实验室体系，其牵头的区块链监管国家重点研发项目与蔡亮的"以链治链"项目互为犄角。

**国际学术圈**：以 Xin Xia 为轴心、David Lo 为最紧密外部伙伴，辐射 Queen's、HKUST、NTU 等校的国际软件工程合作网络；近年产出集中于 LLM 辅助软件工程（如自动化单元测试生成、知识感知测试复用）等前沿主题。

**产业圈**：以网新恒天高级副总裁/CIO 的高管经历为标志，加上区块链监管国家项目与对国产操作系统生态的公共话语参与，形成"教学型学者+企业高管+政策专家"的复合身份。

总括而言，李善平代表了浙大软件所谱系中"教学与育人为体、系统软件为根、软件工程为用"的一脉：从 Linux 内核教学到嵌入式系统，从普适计算到智能软件工程与区块链监管，其方向四十年间数次迁移，但角色始终是团队中稳定的资深指导者与教学传承者。与杨小虎的"建制—产业"路线互补，他的"教学—论文"路线为软件所输出了持续不断的研究生产能，是理解浙大软件学科代际传承不可或缺的一环。
