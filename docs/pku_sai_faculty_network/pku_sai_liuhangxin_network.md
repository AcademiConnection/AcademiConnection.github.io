## 二、教育背景与职业履历

刘航欣本科就读于美国弗吉尼亚理工大学（Virginia Polytechnic Institute and State University），2012年8月入学、2016年5月毕业，获机械工程（机器人方向）与计算机科学（科学计算方向）**双学士学位**（辅修数学），以优等生（Magna Cum Laude）及荣誉学者（Honors Scholar）身份毕业；2014年5—8月曾以交换生身份赴上海交通大学（上海交大—密西根大学联合学院）学习机械工程课程（以上据其个人 CV）。本科后期（2015年1月—2016年9月）他在弗吉尼亚理工计算多物理系统实验室（CMS Lab）任本科/硕士研究助理，指导教授为 Tomonari Furukawa，从事非视距声/视觉目标贝叶斯估计、无人机对移动地面目标的定位跟踪等研究（参与 NSF EAGER 项目与 MBZIRC 2017 国际机器人挑战赛），此阶段产出了其最早的 IROS/FUSION/ASME 论文（2016—2017年）。

2016年9月他进入加州大学洛杉矶分校（UCLA），2018年3月获机械工程硕士学位（机器人方向），2021年6月获计算机科学博士学位（计算机视觉方向）。其研究生阶段全程在 UCLA 视觉、认知、学习与自主机器人中心（VCLA）度过，研究工作受 DARPA SIMPLEX、DARPA XAI、ONR MURI、ONR Cognitive Robot 等美国科研项目资助（据其个人主页与 CV 自述）。关于导师身份：北大官方教师页未披露；其个人 CV 在该段 VCLA 经历项下明确记载 "Advisor: Dr. Song-Chun Zhu"（朱松纯），属本人自述级证据；本库《朱松纯报告》因其官方页面未逐字标注而对该师承关系作降级处理（"属朱松纯学术体系骨干，此处审慎不作师承断言"），本报告维持该审慎口径并补充上述 CV 证据的来源与性质，供读者自行判断证据层级。

博士毕业后（2021年4月）刘航欣回国加入北京通用人工智能研究院（BIGAI）任研究员，领衔其机器人实验室（含博士、硕士层级人员，据其 CV）；牵头完成多项人形机器人在工业与特种场景中的应用交付，并主导研发全手掌视触觉灵巧手 F-TAC（教师页、百度百科口径一致）。2025年8月北京"具身智能"主题官方活动报道中，其身份为"北京通用人工智能研究院具身机器人中心副主任"（该中心时由黄思远任主任）；教师页与媒体则多用"机器人实验室主任"。两个头衔的时间对应关系公开资料未系统披露，本报告并列存录。2026年1月，他参与联合创立 BIGAI 孵化的具身智能公司德塔智能（Delta Intelligence）；2026年3月全职加入北京大学智能学院任助理教授，同时在 BIGAI 转任兼任研究科学家。2026年9月1日，他作为教师代表在智能学院2026年开学典礼上发言，结合学院发展历程与具身智能前沿趋势勉励新生"打牢学科基础、深耕真实场景、学会合作"（据学院官网报道）。

刘航欣的产业网络呈"研究院交付—创业公司—本体厂商联盟"三层递进结构，在北京大学智能学院青年教师中属罕见的"深度产业化"类型：

- **德塔智能（Delta Intelligence）联合创始人（2026年1月成立）**：据北京市科委官网转载及多家媒体报道，德塔智能为 BIGAI 孵化的具身智能公司（主体：北京德塔源创智能科技有限公司），专注研发原生人形机器人基础模型（HFMs），以自研原生3D世界引擎构建"3D场景理解—任务推理—全身控制—力位混合交互"的 Loco-manipulation 闭环，具备"数采—基模—端侧"全栈能力。创始团队为：创始人兼CEO马晓健（曾任职 Google Robotics、NVIDIA Research，亦列名智能学院"智能机器人"方向成员）、联合创始人刘航欣、联合创始人兼首席科学家黄思远（BIGAI 具身机器人中心主任，曾任职 DeepMind、Meta）。融资轨迹：成立半年内连续完成五轮——种子+轮（元禾控股、复星锐正）、天使轮（华映资本、华盖资本、联想创投联合领投，元禾控股、复星锐正超额追投）、天使+轮（珠海科技产业集团、海望资本、梅花创投，半导体产业方交源资产及某汽车产业方深度参与），BIGAI、乐聚机器人、智元机器人、星海图、高瓴创投参与两轮融资；媒体报道口径为"连续三轮融资超亿元"。落地验证包括一汽红旗产线协作、南方电网配电站巡检、SMT 料盘分拣等场景，模型同步适配宇树、智元、乐聚等多类人形本体。
- **机器人本体厂商共同体**：其学术合作与产业投资高度同构——乐聚机器人既是他双足控制研究的论文合作方（经孙立宁、冷晓琨一线），也是德塔智能的战略投资方；智元、星海图、宇树则经由德塔智能的模型适配进入其生态。这使其成为 BIGAI"通智大脑联盟"之外又一条联通国产人形机器人本体厂商的通道。
- **总体判断**：与纯学院派不同，刘航欣的产业资本是"内生技术股权型"（联合创始人身份）而非"横向项目型"；其学术成果（触觉传感、移动操作规划、人形测试床）与德塔智能的技术叙事（全身协同基础模型）之间存在清晰的转化连续性。这一"研究院孵化—青年教授创业"路径与本库朱松纯报告中"BIGAI 孵化体系"的产业布局判断一致。

## 七、Connection 圈层总结

刘航欣的学术关系网络呈"学派内核—建制矩阵—产业外溢—国际支点"四圈层结构，是北大智能学院"UCLA 体系回流"青年 PI 中产业化程度最高的一例：

- **第一圈：朱松纯学派内核（VCLA 同门圈）**。其网络的中心是 UCLA VCLA 时期的导师与同门：CV 自述的 Advisor 朱松纯、最高频合作者朱毅鑫、焦子元、苏垚、黄思远、郑子隆等。这一圈层的合作并未因回国而中断，反而通过"北大智能学院—BIGAI—全国重点实验室"三位一体平台制度化了——他几乎全部代表作（VKC、F-TAC、M2diffuser、Science Robotics 2026）都是该圈层的集体产出。其与朱松纯的师承关系：北大官方页未披露，个人 CV 自述 Advisor 为朱松纯，本库《朱松纯报告》按"体系骨干/论文合作者"降级记载，本报告维持同一口径并补充 CV 证据层级，三处表述完全一致、互不矛盾。
- **第二圈：学院建制矩阵（"智能机器人"方向与具身智能共同体）**。作为学科方向官方页列名的骨干成员，他与方向负责人罗定生（副院长）、资深教授刘宏、方向成员刘梦源/邓逸安及德塔智能 CEO 马晓健同列一个"1+7"梯队（见本库罗定生报告口径）；2024年4月具身智能与机器人国际研讨会（以 BIGAI 身份报告"机器人的场景理解与任务规划"）与2026年开学典礼教师代表发言，是其在学院共同体的两次完整公开亮相。北大校内的论文合作则延伸至工学院王启宁（具身智能—仿生步态交叉）。
- **第三圈：产业圈（德塔智能—本体厂商—场景方）**。以联合创始人身份嵌入 BIGAI 孵化的德塔智能（半年五轮融资，高瓴创投、联想创投等财务投资方与乐聚、智元、星海图三大本体厂商战略入局），落地一汽红旗、南方电网等场景，并与宇树等本体完成适配。该圈层的独特之处在于"教授—联合创始人—兼任研究院科学家"三重身份的合法并置（2026年3月起同时持北大教职与 BIGAI 兼任），为学院"有组织科研+产业转化"路线提供了青年 PI 层面的样本。
