## 二、教育背景与职业履历

朱松纯1969年出生于湖北鄂州梁子湖边的长岭镇，1986年从鄂州高中考入中国科学技术大学计算机科学技术系（五年制），1991年获学士学位。在中科大就读期间，他旁听人工智能导论课程、选修研究生神经网络课，并主动致信生物系认知科学实验室张达仁老师获得参与早期视觉注意机制研究的机会，其间读到马尔（David Marr）的《视觉》一书，确立"构建统一理论解释智能现象"的终身研究方向。1992年赴美国哈佛大学攻读计算机科学，1994年获硕士学位、1996年获博士学位，导师为数理大师、菲尔兹奖得主、美国国家科学奖章获得者戴维·芒福德（David Mumford）。其博士阶段工作首次以统计方法（最小最大熵原理）将困扰计算机视觉二十余年的基础问题"什么是纹理"刻画为统一的数学模型。1996—1997年在布朗大学应用数学系从事博士后研究，1997—1998年任斯坦福大学计算机系人工智能实验室讲师，1998—2002年任俄亥俄州立大学计算机系与认知科学中心助理教授。2002年入职加州大学洛杉矶分校（UCLA），历任统计系与计算机系副教授（终身教职）、正教授（2006年起），并于2002年在UCLA创建视觉、认知、学习与自主机器人中心（VCLA）并任主任，在此培养了大批博士生与博士后（据北大新闻网专访，其回国时名下在读博士生多达37名）。2010年起两次担任美国视觉、认知科学、AI领域跨学科合作项目MURI首席科学家。2020年8月，朱松纯放下海外实验室与团队举家归国；2020年11月同时受聘北京大学讲席教授、清华大学基础科学讲席教授，并在北京市人民政府、科技部、教育部支持下创建北京通用人工智能研究院（非营利性新型研发机构，2020年10月成立）并任院长。2021年12月北京大学正式成立智能学院（整合原智能科学系、王选计算机研究所和人工智能研究院力量），朱松纯出任首任院长；2022年10月，北京大学与北京通用人工智能研究院联合申报的"跨媒体通用人工智能全国重点实验室"获批（据北大新闻网及学校学科建设文章，该实验室由朱松纯牵头组建，常务副院长董乐任书记、副主任，王亦洲教授任副主任及学术委员会委员）。

## 三、学生培养情况

朱松纯在俄亥俄州立大学与UCLA的二十余年间培养博士、硕士、博士后数十人（仅UCLA末期在读博士即有37名），回国后又通过北大"通班"、BIGAI"有组织科研"体系成建制培养人才。以下按官方可核实口径列出代表性学生（凡官方页面未明确师承关系者，仅标注为长期论文合作者，不作师生推断）：

### 1. 朱毅鑫（Yixin Zhu，北京大学人工智能研究院/心理与认知科学学院，认知推理方向）

朱毅鑫为美国加州大学洛杉矶分校（UCLA）统计系博士，**师从朱松纯教授**（北京大学人工智能研究院官方页面原文）。其研究以高阶常识（功能性、可供性、物理性与因果）结合原始感官输入构建交互式AI。回国后任北京大学人工智能研究院院长助理、计算认知与常识推理研究中心执行主任，并任北京大学心理与认知科学学院助理教授、研究员、博雅青年学者，系北京市科技新星、北京大学元培学院21级"通班"班主任、2023年起兼任智能学院研究生班主任。代表性成果包括与朱松纯等合作的瑞文测试（IQ测试）归纳推理研究、机器人触觉感知（2025年发表于《自然·机器智能》）、以及通智测试（TongTest）体系（其所在的计算认知与常识推理研究中心提出以能力和价值为导向的AGI评测模型）。曾担任CVPR 2019组委会成员、CVPR 2021领域主席。

### 2. 张驰（Chi Zhang，北京大学智能学院助理教授，认知推理与神经符号方向）

据北京大学智能学院官方页面：张驰2017年于浙江大学获计算机科学与技术学士学位，2022年在UCLA获计算机科学博士学位，**师从朱松纯教授**。2025—2026年在字节跳动Seed大模型团队从事数学与代码推理模型研发（主导研发面向自动定理证明的深度推理系统Seed-Prover），2026年加入北京大学智能学院任助理教授。代表性工作包括基于极小极大熵学习的人类水平少样本概念归纳框架（Science Advances, 2024）与基于引导树搜索的奥林匹克几何题求解（Nature Machine Intelligence, 2026）。他是朱松纯UCLA晚期博士生"毕业即回流北大智能学院"的典型样本。（注意：与西湖大学工学院助理教授张驰、印第安纳大学医学院副教授张驰等重名学者无关。）

### 3. 刘航欣（Hangxin Liu，北京大学智能学院助理教授，机器人与具身智能方向）

据北京大学智能学院官方页面：刘航欣本科毕业于美国弗吉尼亚理工大学，于UCLA获机械工程硕士和计算机科学博士学位（**官方页面未标注其博士生导师**；从公开论文记录看，其在UCLA期间与朱松纯团队长期合作发表机器人学习系列工作，属朱松纯学术体系骨干，此处审慎不作师承断言）。回国后任北京通用人工智能研究院研究员、机器人实验室主任，牵头完成多项人形机器人工业与特种场景应用交付，主导研发全手掌视触觉灵巧手F-TAC，在Science Robotics与Nature Machine Intelligence发表论文3篇，曾获2019年ACM中国图灵大会最佳论文奖与2023年IROS移动操作方向最佳论文提名，现任北京大学智能学院助理教授（2026年该院开学典礼教师代表），兼任德塔智能联合创始人。

### 4. 王亦洲（Yizhou Wang，北京大学博雅特聘教授，UCLA 2005届博士）

王亦洲约1999—2005年在UCLA计算机科学系攻读博士并获博士学位，其与朱松纯的师生关系见于本库既有报告的审慎考证（两人长期密集的师生式合作谱系与公开履历互证；该报告同时提示未见官方逐字表述）。2005—2007年在美国施乐帕洛阿尔托研究中心（Xerox PARC）任研究员，2007年12月入职北京大学，现任博雅特聘教授、前沿计算研究中心（CFCS）副主任、计算机视觉与数字艺术实验室（CVDA）主任，2023年起任跨媒体通用人工智能全国重点实验室副主任及学术委员会委员。他与朱松纯近年共同提出AGI的(C, U, V)数理框架（Engineering 2026）、"通智测试"（Engineering 2024），并合著中英文专著（通智测试英文版The Tong Test由朱松纯、Yujia Peng、王亦洲等五人合著，人民邮电出版社2025年）。

## 五、业界合作关系深度分析

### 5.1 暗物智能科技（DMAI）：朱松纯亲自创办的强认知AI公司

暗物智能科技（广州）有限公司（Dark Matter AI，DMAI）于2018年在广州南沙成立（在美国另设研发主体），是朱松纯以"小数据、大任务"范式为技术路线创办的强认知AI平台公司。**角色核实结果：朱松纯为DMAI创始人**（2019年WAIC等公开活动均以"暗物智能创始人"称呼；据工商信息与市场分析，其通过关联持股平台为公司第一大股东，并保留董事长席位，2025年5月董事备案中仍保留其核心席位；用户背景中"首席科学家"的说法未见官方口径支持）。联合创始人董乐任首席运营官（COO）。DMAI提出"五层认知架构"，聚焦AI+教育等场景，融资轨迹为：2020年年中完成5亿元A轮（赛领资本、吉富创投领投，联想创投、广州基金、将门创投、花城创投跟投）；2022年7月完成5亿元B轮首期（广州产投、广州城投、广州工控、广州金控、南沙科金控联合战略投资，系《南沙方案》发布后南沙企业首笔融资）；此后累计完成十余亿元融资（投资方还包括科大讯飞、鼎晖、IDG、上海临港等），现处B+轮，入选广州拟上市高企百强榜单。DMAI生态中走出的人才（如曾在DMAI工作、后任中山大学副教授的王广润等）进一步扩散了朱松纯的产业网络。

### 5.2 北京通院（BIGAI）与产业界：从"通智大脑联盟"到具身智能落地

- **通智大脑联盟**：BIGAI联合宇树科技（Unitree）、乐聚机器人等企业成立"通智大脑联盟"，将"通智大脑"（TongBrain）具身智能框架与国产机器人本体结合。
- **人形机器人落地**：2025年8月，BIGAI-UNITREE双足人形机器人获世界人形机器人运动会单机舞蹈冠军（采用自研CLONE闭环全身遥操作系统与"通智大脑"框架）；2025年10月提出全球首个"力位混合控制算法的统一理论"；2025年11月，联合研发的5G-A具身智能机器人完成世界首例电力巡检应用示范并参与第十五届全运会火炬传递。
- **自主软件生态**：BIGAI推动开发自主可控的通用AI操作系统TongOS与编程语言TongPL（由常务副院长董乐牵头），并牵头研发国际评级标准AI-index；"通境"（TongVerse）仿真平台面向"AI+机器人"训练输出，与产业界共建八大领域产业智能体（见《为机器立心》）。
- **政企与数据生态**：2024年12月朱松纯受邀赴国家数据局"数据大讲堂"作《通用人工智能：构建数据生态，重塑产业体系，赋能社会治理》专题讲座（与百度首席技术官王海峰同场）；"通通"成果写入2025年北京市政府工作报告；北大武汉院的大型社会模拟器面向智能社会治理；重庆人工智能湾区（2026）提供"政用、商用、民用"完整场景。

### 5.3 产学研转化路径的总体特征

朱松纯的产业网络呈"双轨制"：其一是**亲自创办的DMAI**（市场化公司，广州南沙，认知AI+教育等场景，资本化路径清晰）；其二是**体制内的BIGAI**（非营利新型研发机构，承接国家战略任务，通过通智大脑联盟、TongOS/TongPL、全国重点实验室等通道与宇树、乐聚及地方国资体系绑定）。两轨在人员上高度互通（董乐由DMAI COO转任BIGAI常务副院长），形成"理论（北大/清华）—新型研发机构（BIGAI/武汉院/莲花山）—市场化公司（DMAI）—地方产业（重庆、鄂州、南沙）"的完整转化链条。这与一般学者的横向项目模式有本质区别，接近其自我定位的"有组织科研"体系。

## 七、Connection 圈层总结

朱松纯的学术关系网络是中国AI界罕见的"学派型+平台型+产业型"三位一体结构，可概括为"一脉、双核、三圈层"：

- **一脉（师承与谱系主线）**：上承哈佛David Mumford（菲尔兹奖得主）的数学传统，经布朗、斯坦福、俄亥俄州立的辗转积累，在UCLA VCLA形成"统计建模—视觉认知—通用人工智能"学派。谱系下第一代（Tu、Wu、Yuille、Barbu等）奠定了国际学术地位，第二代（王亦洲、朱毅鑫、张驰、刘航欣、Tianmin Shu、Yujia Peng等）构成当下中国AGI研究的中坚。其网络的国际节点（UCSD、JHU、MIT、UCLA）与中国节点（北大、清华、中山大学、西湖大学等）通过学生环流持续互锁。
- **双核（北大+通院）**：北京大学智能学院/人工智能研究院/全国重点实验室承担"教育—学科建制"功能（通班、智班、通计划），BIGAI及其衍生机构（武汉院、莲花山院、重庆院）承担"有组织科研—产业转化"功能。常务副院长董乐（DMAI联合创始人出身）是双核运营的关键执行者。
- **三圈层**：内圈是"通字系"成果共同体（通通、通脑、通境、通界、通智测试、TongOS/TongPL），由朱松纯学生与合作者集体产出；中圈是国内政策与学术网络（全国政协委员、全国劳模、国家数据局讲座、与高文等的北大学科协同、十余所"通计划"高校）；外圈是产业与资本网络（DMAI及其十余亿元融资与广州国资体系、通智大脑联盟的宇树/乐聚、字跳动Seed等企业人才出口）。
- **风格特征**：其一，"学者—建制的组织者"而非单纯的论文生产者——其网络资本大量沉淀为机构（学院、实验室、研究院、公司）而非个人荣誉；其二，鲜明的路线旗帜（"小数据、大任务"对"大数据、小任务"），使其网络具有强内聚性与论战性（2026年WAIC对大模型叙事的系统性批评是最新例证）；其三，人才培养的"回流闭环"——UCLA博士生毕业后成建制回国填充其中国平台，实现了学术谱系的跨国整体迁移。这一结构在当前中国AI学界几乎独一无二，可视为"学派建国"模式的代表样本。
