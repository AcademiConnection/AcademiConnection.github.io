# 中科院计算所处理器芯片团队 学术网络报告

本目录收录中国科学院计算技术研究所处理器芯片方向的五位学者学术关系网络报告，覆盖处理器芯片全国重点实验室的三条主线：胡伟武的龙芯路线、陈云霁的智能处理器路线、包云岗的开源RISC-V路线，以及孙凝晖院士的战略统筹与谭光明的高性能计算（HPC）主线。五份报告共同勾勒出从夏培肃院士开创的国产处理器学术血脉，到"龙芯中科""寒武纪""香山/一生一芯"三大标志性产业与生态出口的完整图谱。

团队边界须特别澄清：计算所处理器芯片方向的几支团队同属处理器芯片全国重点实验室平台，但研究方向与团队构成相互独立、并非同一团队。陈云霁领导的智能处理器研究中心聚焦深度学习加速器（寒武纪源头），包云岗领导的先进计算机系统研究中心聚焦开源RISC-V处理器与敏捷设计（香山），谭光明领导的高性能计算机研究中心主线是高性能计算与并行系统（曙光系列），其研究视角为"系统级HPC"而非"芯片级设计"，不宜与陈云霁/包云岗的处理器芯片设计团队混同。胡伟武的微处理器研究中心（龙芯）已演化出独立的龙芯中科公司。孙凝晖提出的"ABC体系"战略框架将上述不同路线整合：龙芯代表B体系（全自主）、寒武纪NPU与香山RISC-V代表C体系（全开放），但战略整合不等于团队合并。

## 研究方向与圈层结构概述

学术谱系上，第一圈层为"夏培肃—胡伟武—陈云霁"的国产处理器血脉：胡伟武师从夏培肃院士（1996年博士），陈云霁师从胡伟武（2008年博士，曾任8核龙芯3号主要架构师），张福新、章隆兵、汪文祥、苏孟豪等龙芯骨干均为胡伟武博士弟子。第二圈层为智能处理器团队：陈云霁与胞弟陈天石（兄弟合作而非师生）共同提出DianNao/DaDianNao体系结构，两获体系结构顶会最佳论文奖，涂志毅、王庚、郭崎、张珩等为团队成员。第三圈层为开源芯片生态：包云岗（博士导师为范建平、陈明宇）领导的团队产出HMTT、Labeled RISC-V、SERVE与香山处理器，并依托"一生一芯"计划、中国RISC-V联盟（秘书长）和北京开源芯片研究院（首席科学家）构建生态。第四圈层为HPC主线：孙凝晖（学术导师李国杰院士）主持研制曙光系列超算，谭光明（孙凝晖研讨班培养，特拉华大学高光荣实验室访学）率团队参与曙光4000—7000研制，与贾伟乐、王展等构成HPC与科学智能交叉核心。第五圈层为产业与政策网络，覆盖寒武纪、龙芯中科、中科曙光与国家战略咨询。

## 产业转化亮点

- **龙芯中科（"国产CPU第一股"）**：胡伟武任董事长，从2002年龙芯1号到自主LoongArch指令集，3A6000对标英特尔十代酷睿，2022年科创板上市，是产学研一体化最彻底的转化案例。
- **寒武纪科技**：陈云霁与陈天石2016年联合创立，国际首个深度学习处理器芯片（寒武纪1号）源自DianNao系列学术成果；陈天石负责公司运营，陈云霁以首席科学家角色参与、编制留在计算所，技术已应用上亿台智能终端。
- **香山RISC-V与"一生一芯"**：香山敏捷设计入选2022年IEEE MICRO Top Picks，成为国际最具影响力的开源高性能处理器之一；"一生一芯"从5名本科生起步发展为全国性芯片人才培养品牌，三步走开源芯片生态战略持续推进。
- **曙光超算与"信息高铁"**：孙凝晖主持的曙光系列打破国外HPC垄断，机群架构成为中国HPC主流路径，"算力如水电"理念对接"东数西算"工程；谭光明团队2025年推出DNA活字喷墨打印机"毕昇一号"，开辟HPC向生物产业交叉的新场景。
- **企业技术辐射**：包云岗团队HMTT访存监控成果入选华为2015年全球合作五个代表成果并写入年报，获阿里巴巴最佳合作项目奖；2024年全国人大常委会专题讲座进一步将团队研究接入国家AI政策议程。
