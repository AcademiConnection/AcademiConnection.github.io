## 团队概况

许威威组代表CAD&CG全国重点实验室几何处理与物理仿真方向（CAD/CAE）。许威威教授为河海大学本硕—浙大博士—立命馆大学博士后—微软亚洲研究院网络图形组研究员（7年）—2012年加盟浙大的复合路径学者，2014年优青、2022年长江学者，现任计算机学院副院长；其三维注册与重建技术在先临三维扫描仪、百度阿波罗自动驾驶仿真、华为河图大场景重建中落地。邹强研究员为UBC博士、启真青年学者，专注国产CAD/CAM工业软件，2026年获国际形状建模学会SMI Young Investigator Award（设立以来首位亚洲获奖者），主持工信部"揭榜挂帅"课题与国家科技重大专项课题，研究成果写入国家首个三维CAD软件测试标准。

二人于2025年共同组织SPM/SMI 2025国际会议（许威威任大会主席，邹强任组委会共同主席），是几何建模方向的核心组织搭档。组内人才网络连接zju3dv体系（许威威与鲍虎军共同指导NICE-SLAM一作朱紫涵等）。

## 学术谱系概览

许威威的谱系呈现"浙大博士+工业界回流"特征：浙大CAD&CG博士（导师待核实）→ MSRA七年 → 回归浙大任教授，与鲍虎军形成稳定的共同指导模式（朱紫涵、许佳敏等），其学生网络中王驰留校（软件学院特聘研究员）、许佳敏任教杭电、朱紫涵赴ETH Zurich深造。邹强为"海外博士+本土工业软件"路径（UBC博士），与Hsi-Yung (Steve) Feng教授有长期合作（导师关系待核实），下游为X-Studio平台团队与国产CAD生态。
