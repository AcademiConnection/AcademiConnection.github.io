## 二、团队背景与研究方向概述

北京大学计算语言学研究所是中国计算语言学与中文信息处理领域的奠基性机构，1986年由朱德熙、马希文联合创建，俞士汶教授长期主持工作，2008年在此基础上成立计算语言学教育部重点实验室（现任主任穗志方）。研究所三十年余年来最重要的基础性成果是"综合型语言知识库"（CLKB，含《现代汉语语法信息词典》等系列语言资源），获2011年国家科技进步二等奖（完成人共十人：俞士汶、穗志方、常宝宝、刘扬、段慧明、朱学锋、孙斌、吴云芳、李素建、陆俭明），累计对外签署转让协议超200份，使用者包括微软、IBM、百度、腾讯等头部企业。

研究方向上，本所在经典计算语言学（句法语义分析、语言知识库、中文信息处理——常宝宝、吴云芳、刘扬、胡俊峰）的基础上，形成了多条现代NLP主线：王厚峰的问答/对话系统与机器翻译、李素建的自动文摘与篇章分析、孙栩的深度学习与NLP融合（被引超2万次，COLING 2018与EMNLP 2023双最佳论文奖）、穗志方的知识工程与医疗NLP（中文医学知识图谱CMeKG），以及2025年新入职的潘亮铭带来的大模型推理与机理可解释性方向（PILLAR Group，博雅青年学者、国家级青年人才）。

## 三、关系网络与圈层结构概述

本所网络结构的核心特征是"俞士汶学术传承+DeepSeek人才输送通道"两条主线。俞士汶（1990-2004年主持所务）通过CLKB项目培养的穗志方（第二完成人）、常宝宝（第三完成人）、吴云芳（第八完成人）、李素建等构成了研究所的中生代骨干；这一谱系至今仍通过语言知识库的持续建设与转化（覆盖教育、医疗等领域）产生产业影响。

近年最引人注目的是本所与中国大模型产业的深度绑定。穗志方与常宝宝联合课题组培养的学生群体——罗福莉（硕士，阿里达摩院VECO→DeepSeek V2关键开发者→小米MiMo大模型负责人）、代达劢（2024届博士，EMNLP 2023最佳长论文奖、CIPS优博，现DeepSeek研究员）、许润昕（硕士，DeepSeek MoE/Math/Coder/V2/V3/R1全程参与者）、王培懿（直博生，Math-Shepherd核心作者）——构成了一条从BERT时代少样本事件分类研究到大模型reasoning时代的完整人才谱系，使PKU-ICL成为DeepSeek技术谱系的重要源头节点之一。孙栩（EMNLP 2023最佳论文通讯作者、代达劢的所内合作者）与学生王乐安等亦通过腾讯微信AI合作深度参与其中。

国际合作方面，本所与微软亚洲研究院（周明团队，多篇ACL/EMNLP联合论文）、京都大学（河原大辅）、东京大学（孙栩博士导师辻井潤一——前ACL主席）、新加坡国立大学（潘亮铭导师Min-Yen Kan、Tat-Seng Chua）、UCSB（潘亮铭博后导师William Yang Wang）等保持长期合作；潘亮铭的清华硕士导师为李涓子、唐杰（KEG实验室），使本所与清华KEG网络亦有联结。教学与评测方面，本所教师深度参与CCL（中国计算语言学大会）、NLPCC、SemEval等国内外评测体系，并在中文信息学会、CCF NLP专委会等学术组织中承担重要职务。
