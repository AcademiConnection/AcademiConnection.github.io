## 二、教育背景与职业履历

李素建是北京大学计算语言学研究所培养并在该所长期任教的本土学者。关于其博士学位的获取时间和博士导师，公开资料中存在不同说法，以下依据现有信息加以梳理。

**教育背景。** 李素建的本科及博士教育均在北京大学完成。根据北京大学计算机学院官方页面及百度百科等公开资料记载，其博士学位获自北京大学，专业方向为计算机科学与技术（计算语言学）。其博士阶段的研究工作应在北大计算语言学研究所完成，该所由俞士汶教授创立，是国内最早从事计算语言学研究的机构之一。关于其博士导师的具体身份，存在两种可能：一种是师从俞士汶教授（北大计算语言学研究所创始人），另一种是师从穗志方教授（现任计算语言学教育部重点实验室主任）。考虑到李素建早期论文（如2006年DUC会议论文）中已经作为独立研究者署名指导学生，推测其在2000年代初期已获得博士学位并留校任教。（博士毕业年份及导师身份待核实）

**职业履历。** 李素建自获得博士学位后即留在北京大学计算语言学研究所工作，历任讲师／副研究员、副教授。在北京大学信息科学技术学院时期（2022年及之前），其职称记载为"副教授"（属副高级职称）。随着北京大学计算机学院于2022年正式成立，其院系归属调整为计算机学院，职称升为"长聘副教授"。在其职业生涯中，李素建始终隶属于计算语言学研究所（ICL），未曾离开北大系统，是典型的"北大本土培养—留校任教"型学者。

**学术成长时间线。** 大致可归纳为以下阶段：2000年代初期获博士学位并留校任教；2005—2015年间逐步建立自己在自动文摘领域的研究特色，多次带队参加DUC（Document Understanding Conference）国际评测；2015年后拓展研究范围至深度学习驱动的NLP任务，包括篇章分析、文本生成、信息抽取等；2020年担任第十九届中国计算语言学大会（CCL 2020）程序委员会主席之一，同年其团队获CCL英文最佳论文奖；2023年后研究重心进一步延伸至大模型评测与Agent技术，并开始与小米等企业在GUI Agent方向展开合作。

## 三、学生培养情况

李素建作为博士生导师，长期指导研究生从事自然语言处理方向的研究。其指导的学生中已有多人在学术界和工业界取得突出成绩。以下列出代表性学生。

### 1. 沙磊（北京航空航天大学教授，博士毕业生）

沙磊是李素建指导的最具代表性的博士毕业生之一。2013年9月入读北京大学计算机科学与技术专业，2018年7月获理学博士学位。在读期间，其导师组包括穗志方教授、常宝宝教授和李素建副教授，三方联合指导。沙磊博士期间研究方向为信息抽取与文本生成，在ACL、EMNLP、NAACL、AAAI等顶级会议上发表多篇第一作者论文。博士毕业后，沙磊先在苹果公司（Apple Inc.）Siri NLP组担任研究科学家（2018.8—2020.4），负责Siri的领域分类和闲聊对话模块。随后赴牛津大学智能系统实验室担任副研究员（Research Associate，2020.3—2022.3），合作导师为Thomas Lukasiewicz教授。回国后，沙磊加入北京航空航天大学人工智能学院，任教授、博士生导师，并入选国家级青年人才计划（海外优青）。其研究成果成功落地苹果Siri项目和英国Serein公司的智能合同助手项目，曾获ACL杰出论文奖和EMNLP 2020杰出审稿人奖。2025年6月，沙磊被莲花控股提名为非独立董事候选人并任首席人工智能官，体现了其在产业界的影响力。

### 2. 朱大为（北京大学在读博士生，博三）

朱大为（Dawei Zhu）目前为北京大学计算机学院三年级博士生，导师为李素建教授。本科毕业于北京大学电子工程与计算机科学学院。研究方向聚焦于长上下文建模（Long Context Modeling），认为高效处理超长上下文是未来语言模型和多模态模型的关键能力，同时对智能体（Agent）、对齐（Alignment）及多模态模型的进展保持兴趣。朱大为曾作为小米MiMo团队成员受到关注——小米MiMo团队的核心成员几乎被北大学子"承包"，朱大为是其中的代表性人物之一。

## 四、学术合作网络

### 4.1 实验室内部合作

北京大学计算语言学研究所（ICL）是国内历史最悠久的计算语言学研究机构之一，由俞士汶教授创立。李素建作为该所核心成员，与所内多位教师形成了紧密的内部合作关系。

**与穗志方教授的合作。** 穗志方教授现为北京大学计算语言学教育部重点实验室主任、计算机学院教授，是NLP领域的资深学者。李素建与穗志方在学生联合指导方面合作密切——两人的共同博士生沙磊即由穗志方、常宝宝和李素建联合指导。二人在医疗领域非结构化文本语义化研究方面也有合作论文发表（与邱立坤等人合作）。穗志方教授同时也是北大NLP方向知名硕士毕业生罗福莉的导师，形成了"穗志方—李素建"的联合指导格局。

**与常宝宝教授的合作。** 常宝宝教授是计算语言学研究所的资深教师，在NLP领域有深厚的学术积累。常宝宝参与联合指导了沙磊的博士论文工作。李素建与常宝宝在研究所内长期共事，构成了ICL的核心教学科研团队。

**与冯岩松教授的合作。** 冯岩松教授（Yansong Feng）现为北京大学计算机学院副教授，研究方向同样为自然语言处理，是CCF NLP专委会副秘书长。冯岩松与李素建同属北大NLP团队，在学术活动和学院事务中有密切互动——2025年北大计算机学院校友羽毛球赛中，冯岩松担任王选所队领队，李素建参与指导组队，体现了两人在学院内部的协作关系。

**与王厚峰教授的合作。** 王厚峰教授曾任计算语言学研究所所长，主要研究方向为问答和对话系统。李素建与王厚峰同属ICL教师团队，在研究所的学科建设和人才培养方面有长期协作。

**与孙栩教授的合作。** 孙栩教授为计算机学院研究员，研究方向包括自然语言处理、深度学习和人工智能，与李素建同属ICL团队。

### 4.2 跨机构合作

**与京都大学河原大辅教授的合作。** 李素建与日本京都大学的Daisuke Kawahara（河原大辅）教授有直接的研究合作关系，二人联合发表了科学关键词抽取方向的论文（与刘倩莹合作）。这体现了其在东亚NLP学术圈的国际合作网络。

**与中国科技信息研究所邱立坤的合作。** 李素建与中国科学技术信息研究所的邱立坤（Likun Qiu）合作开展了医疗领域非结构化文本的语义化研究，论文中署名单位包括北京大学和该研究所。这反映了其研究在垂直领域（医疗NLP）的跨机构合作。

**与中科院自动化所等机构的合作。** 在CCL 2020上，李素建团队与中科院自动化所赵军团队分别获得英文最佳论文奖，表明两个团队在同一研究方向上有平行探索和学术对话关系。

**与小米AI团队的产业学术合作。** 2026年，李素建作为合作作者参与了小米AI团队发表在ICML 2026上的论文"Video2GUI: Synthesizing Large-Scale Interaction Trajectories for Generalized GUI Agent Pretraining"，论文作者包括熊伟民、谷舒豪、叶博文、岳子豪、李磊、宋非凡、李素建、田昊，合作单位标注为北京大学。这表明李素建已与小米AI团队建立了实质性的产学研合作关系，在GUI Agent方向开展前沿研究。

### 4.3 国际合作

**DUC国际评测参与。** 李素建在2006年和2007年连续带队参加DUC（Document Understanding Conference）国际自动文摘评测，论文以北京大学名义发表。DUC是NIST（美国国家标准技术研究院）组织的国际权威评测，李素建团队的参与标志着其研究在2000年代即已与国际学术评测体系接轨。

**与牛津大学的间接合作。** 李素建的博士毕业生沙磊在牛津大学智能系统实验室从事博士后研究，虽然这一合作以沙磊个人身份开展，但体现了李素建培养学生进入国际顶级研究机构的能力。

**国际学术服务。** 李素建担任ACL、AAAI、KDD、EMNLP等国际顶级会议的程序委员会委员（PC Member），以及ACL、COLING等会议的领域主席（Area Chair）。这些学术服务角色要求其与国际NLP社区保持持续的学术交流与合作。

## 五、业界合作关系深度分析

### 5.1 产业合作

李素建在产业合作方面展现了贯穿学术生涯的特点：从早期的企业委托项目，到近年与小米等科技企业的深度科研合作，其产学研融合持续推进。

**企业委托项目。** 根据北京大学官方师资页面记载，李素建"主持了多项企业项目"。虽然具体企业名称未在官方页面公开列出，但结合其研究方向（自动文摘、篇章分析、NLP），这些企业项目很可能涉及文本理解、信息抽取、自动摘要等技术在企业产品中的落地应用。在2000—2010年代，NLP技术的产业应用主要集中在搜索引擎、文本挖掘、智能客服等场景，李素建的研究成果具备直接转化为产业应用的潜力。

**与小米的GUI Agent合作。** 2026年，李素建参与小米AI团队ICML 2026论文"Video2GUI"，该研究构建了从5亿条互联网视频中提取420万条高质量教程的大规模流水线，利用Gemini-3-Pro将视频转换为结构化轨迹，最终产出WildGUI——目前规模最大的开源GUI预训练数据集（包含1270万条轨迹、1.245亿张截图，覆盖1500余个应用与网站、五大平台）。这是目前可公开确认的李素建与科技企业最具体的深度科研合作案例，体现了其研究已延伸至大模型时代的前沿Agent技术领域。

**与微软亚洲研究院（MSRA）的人才通道。** 李素建的博士生在读期间有在微软亚洲研究院实习的经历。其学生沙磊在博士期间曾在MSRA担任研究助理，与Chin-yew Lin、Lintao Zhang等MSRA研究员合作。当前TANGENT实验室的在读博士生也有在MSRA实习从事Agent研究的情况。这表明李素建与MSRA之间存在稳定的学生实习和人才输送通道。

**与华为诺亚方舟实验室的关联。** TANGENT实验室的学生有在华为诺亚方舟实验室实习的经历，这表明李素建研究组与华为的AI研究部门也存在人才层面的联系。

### 5.2 创业孵化与产业影响

**学生创业与技术落地。** 李素建培养的学生在产业界产生了实际影响。沙磊在苹果公司Siri NLP组的工作直接贡献于Siri的产品功能，其研究成果"成功落地苹果Siri项目"；在英国Serein公司的智能合同助手项目和OxTium多组学医学诊断大模型中也有实际应用。2025年6月，沙磊被莲花控股提名为非独立董事候选人并出任首席人工智能官（CAIO），进一步体现了李素建学生在产业界的高层影响力。

**NLP技术产业化。** 李素建的研究方向——自动文摘、篇章分析、文本生成——均具有高度的产业应用价值。自动文摘技术可应用于新闻聚合、文档摘要、会议记录等领域；篇章分析技术可用于信息抽取和知识图谱构建；文本生成技术则是大语言模型时代的核心能力。李素建团队在这些方向上的积累，为相关技术的产业转化提供了学术基础。

**大模型时代的产学合作趋势。** 随着大语言模型的兴起，李素建的研究重心逐步拓展至大模型评测和Agent技术。与小米在GUI Agent方向的ICML合作论文，以及学生在华为诺亚方舟实验室、MSRA等机构的实习，表明其研究组已深度融入大模型时代的产业创新生态。

## 七、Connection圈层总结

李素建的学术关系网络呈现出鲜明的"北大ICL内循环—全国NLP学术圈—国际NLP社区—产业界"四层结构，以下分圈层加以总结。

**第一圈层：北大计算语言学研究所核心圈。** 李素建的网络根基在北大ICL。她与穗志方（计算语言学教育部重点实验室主任）、常宝宝、冯岩松、王厚峰（所长）、孙栩等ICL同事构成了紧密的内部合作网络，在学生联合指导、课程教学、学术活动和学院事务中深度协作。这一圈层是其学术身份的核心：自北大博士毕业后留校至今，她始终是ICL教学科研团队的中坚力量。TANGENT实验室作为其领导的研究团队，是学生在读期间的主要科研平台。

**第二圈层：全国NLP学术圈。** 在全国NLP学术界，李素建通过CCF NLP专委会常务委员的身份以及CCL 2020程序委员会主席等学术服务角色，与国内NLP社区建立了广泛的联系。她的学生在毕业后进入北航、华为、苹果、MSRA等机构和企业，形成了以北大ICL为节点的学术人才辐射网络。与中科院自动化所赵军团队等国内顶尖NLP团队的平行获奖和学术对话，反映了其在全国NLP学术版图中的地位。

**第三圈层：国际NLP社区。** 李素建的国际网络通过三个渠道建立：一是DUC国际评测的早期参与（2006—2007年），二是与京都大学河原大辅教授的直接研究合作，三是长期担任ACL、EMNLP、AAAI、KDD、COLING等国际顶级会议的PC Member和Area Chair。其学生沙磊在牛津大学和苹果公司的经历，进一步延伸了这一国际网络。

**第四圈层：产业合作圈。** 李素建的产业网络正在持续扩展和深化。早期以企业委托项目为主；学生层面与微软亚洲研究院、华为诺亚方舟实验室等建立了稳定的人才实习通道；近年与小米AI团队在ICML 2026上的合作论文标志着其产业合作已进入大模型Agent时代的前沿领域。其学生沙磊从苹果Siri到北航教授再到企业CAIO的职业路径，是学术成果产业化的典型案例。

**网络结构特征。** 总体而言，李素建的学术网络具有以下特征：（1）以北大ICL为单一锚点，具有典型的"本土培养—留校深耕"特征，学缘关系集中于北大系统；（2）学生培养质量突出，已产出沙磊等国家级青年人才，学生去向覆盖学术界（北航教授）、国际企业（苹果、牛津）和国内科技公司（小米、华为、MSRA）；（3）产业合作正在从传统的企业委托项目模式向大模型时代的深度科研合作模式转型，ICML 2026论文是其标志性进展；（4）学术服务网络覆盖国内外主要NLP会议和学术组织，在CCF NLP专委会和CCL等平台中发挥组织作用。随着大模型时代的推进，其研究组在Agent、大模型评测等方向的研究活动预计将进一步拓展其学术和产业合作网络。
