## 五、业界合作关系深度分析

### 5.1 平台资产：知识工场与 CN-DBpedia 的规模化产业触达

作为知识工场平台技术负责人，梁家卿深度参与了国内最具规模的中文开放知识基础设施之一的建设与运维。据知识工场官网，该平台发布多个大型知识图谱与 20 余种知识图谱数据服务与认知服务 API，累计 500 余家公司及个人用户、超过 6500 个独立 IP 调用近 20 亿次；CN-DBpedia 累计下载量超两万次。这一平台资产构成其产业合作的技术底座——企业合作多以"知识服务+联合课题"的形式围绕平台展开。[知识工场简介](http://kw.fudan.edu.cn/about/)

### 5.2 华为、阿里等企业合作

- **华为**：据大数据学院师资页，梁家卿获"华为最佳论文复现奖"；其合作论文中出现华为海内外研究院研究人员署名（日志理解 KnowLog 等系统方向工作）；其所在团队的"大规模知识图谱知识更新方案"获 2023 年华为火花奖（团队级荣誉，见 fudan_kw 系列报告）。具体由其本人主持的企业项目名称公开资料未披露。

### 5.3 开源影响力与技术布道

2025 年 Simple-GRPO 项目是其在产业界影响最大的单项成果：以 200 余行代码、约 7 元单次实验成本复现 DeepSeek-R1-zero 的"Aha Moment"自发反思能力，并进一步开源大模型自主工具调用机制，被机器之心等广泛报道，成为低成本大模型强化学习训练的标杆性开源项目（GitHub: lsdefine/simple_GRPO）。此外，他活跃于产业技术社区：2024 年在 DataFun 分享《领域大模型的挑战与机遇：从构建到应用》，2025 年受邀出席全球机器学习技术大会（ML-Summit）大模型训练与推理专题，与阿里通义、新浪微博等企业技术负责人同台。这类布道活动使其成为知识工场面向产业界的"技术门面"之一。

- **第三圈层（国内跨校与研究机构）**：李直旭（人大，历史节点）、徐波（东华大学）、北京智源等，连接知识图谱与大模型学术共同体；经 2019 年语言与智能技术竞赛接入国内信息抽取评测圈。
- **第四圈层（产业生态）**：华为（最佳论文复现奖、KnowLog、团队火花奖）、阿里（联合署名、团队资助）、金融企业（BBT-Fin 类联合研究），叠加知识工场平台 500 余家企业用户的 API 调用网络与 Simple-GRPO 的开源社区影响力，形成"平台服务—联合研究—开源布道"三位一体的产业连接方式。

总体而言，梁家卿的网络结构呈"强内核、平台化外延"特征：内核是复旦知识图谱学派的双导师谱系与知识工场同事群，外延则主要通过公共知识基础设施（CN-DBpedia、知识工场 API）和开源项目（Simple-GRPO）触达产业界与开发者社区，而非依赖个人化的横向项目网络。与魏忠钰（DISC，偏社会计算与垂域大模型）同属复旦大数据学院 NLP/大模型生态，但分属不同实验室谱系，公开资料未见二人直接合作的显著记录。
