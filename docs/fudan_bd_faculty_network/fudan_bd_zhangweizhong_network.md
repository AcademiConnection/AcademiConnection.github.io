## 二、教育背景与职业履历

张卫忠的学术履历呈现典型的"浙大稀疏学习学派出身 + 美国联培拓宽 + 腾讯产业历练 + 港科大理论深造 + 复旦独立建队"五段式路径。据其个人主页自述，他于 2017 年在浙江大学获得计算机科学博士学位，导师为何晓飞教授与蔡登教授——二人是浙大机器学习/数据挖掘方向的核心组合，其博士工作（发表于 ICML 2017 会议版与 JMLR 2019 期刊版的《Scaling Up Sparse Support Vector Machine by Simultaneous Feature and Sample Reduction》为一作论文，合作者含联培导师叶杰平、王杰）奠定了其"稀疏学习 + 随机优化"的研究底色。博士期间他赴美国密歇根大学安娜堡分校联合培养，在叶杰平（Jieping Ye）与王杰（Jie Wang）指导下开展大规模机器学习研究，与二人合作发表了阿尔茨海默病基因风险因子多任务学习（IEEE TKDE 2018）等工作。

博士毕业后，他先进入腾讯 AI Lab 任研究员（学院官网称"高级研究员"，个人主页称 Research Scientist，2017 年毕业至 2020 年前后），期间与同在腾讯的张潼（Tong Zhang）教授建立起长期合作关系——二人在 ICML 2018 合作发表的《Safe Element Screening for Submodular Function Minimization》是其在产业界时期的代表作，合作者还包括腾讯 AI Lab 的洪斌、马林、刘威等。张潼于 2020 年前后转入香港科技大学任教后，张卫忠随之赴港科大，先后任博士后研究员与研究助理教授，合作导师即张潼。港科大阶段（2020–2022/2023）是其理论产出高峰期：NeurIPS 2020 过参数化卷积网络损失景观刻画、CVPR 2021 全局稀疏度约束神经网络稀疏化、NeurIPS 2021 前向/反向传播稀疏化加速训练、ICML 2022 双层核心集选择（Probabilistic Bilevel Coreset Selection）与稀疏不变风险最小化、AISTATS 2022 对抗中奖彩票等系列工作均在此期完成，署名机构为香港科技大学。约 2023 年，他加入复旦大学大数据学院任青年研究员（其个人主页教学记录自 2023 年春起出现复旦课程，且 2023 年起论文署名机构转为复旦大学；精确入职时间公开资料未披露），并在复旦组建独立课题组，同时与计算与智能创新学院金城教授建立联合团队。

## 五、业界合作关系深度分析

张卫忠的产业连接呈现"前雇主（腾讯）+ 横向项目（集成电路中心）+ 合作者外溢（金城—恺英网络）"三线结构：

- **腾讯 AI Lab（2017–2020 前后）**：其产业履历的起点，也是其与张潼结识的渠道。腾讯时期的代表性产出（ICML 2018 子模函数最小化安全元素筛选，与张潼、洪斌、马林、刘威合作）属于"大规模机器学习优化理论"，与腾讯当时的搜索/推荐业务需求同构。这段经历使其天然保有与腾讯系研究网络的连接，但目前未见其与腾讯的在建合作项目记录。
- **上海集成电路技术与产业促进中心横向项目（2024/09–2025/12，100 万元，主持）**：项目内容为"云平台资源智能调度和配置技术研发"，与其学术主线（计算预算约束下的数据选择、模型压缩与训练/推理效率）高度同构——NeurIPS 2025《Computational Budget Should Be Considered in Data Selection》等论文正是该横向项目的理论映射。这是其当前唯一公开披露的产业合作项目，属于典型的"效率算法研究对口算力资源调度需求"的产学研通道。
- **金城—恺英网络连接（间接业界接口）**：据公开报道（2026 年 8 月），其联合团队伙伴金城受聘恺英网络集团首席 AI 科学家，将主导 AI 原生 NPC、3D 世界模型等方向。考虑到二人团队的深度绑定（联合招生、共同通讯论文十余篇），这一任职为团队的大模型压缩/三维生成研究提供了潜在的游戏产业落点；但张卫忠本人与恺英网络的直接合作关系公开资料未披露，本报告不作断言。
- **技术方向本身的产业属性**：其当前研究主攻的模型压缩、混合精度量化与低秩适配器联合优化（ICML 2026 AutoQRA）、大模型全局秩-稀疏联合压缩（ICLR 2026）、少 API 调用黑盒调优（AAAI 2026）等，均为大模型推理降本与高效微调的产业刚需方向，与其"高校 PI + 横向项目"的路线一致。公开资料未见其持股企业、创业或技术入股记录，属于学院派产学研路线。

## 七、Connection 圈层总结

张卫忠的学术关系网络以"双师承、一中枢、一落点"为结构特征，整体处于快速扩张期的青年学者网络：

- **第一圈层（师承与职业导师）**：向上是浙大稀疏学习学派（何晓飞、蔡登）与密歇根联培谱系（叶杰平、王杰），赋予其"稀疏优化 + 大规模机器学习"的理论根基；职业轴心则是张潼——从腾讯同事到港科大指导教授再到持续十余篇的顶级合作者，张潼所在的"统计机器学习理论"谱系（其学生圈：皮仁杰、周晓、林雍等）构成了张卫忠最重要的学术人脉池。
- **第二圈层（复旦现职网络）**：以与金城的联合团队为核心（联合招生 + 共同通讯论文十余篇），辅以 Yifan Chen、高源、赵溯等院内合作者，以及上海创智学院的教学平台。其复旦网络的鲜明特点是"跨学院（大数据学院 × 计算与智能创新学院）+ 跨机构（上海创智学院）"的算法-视觉复合团队。
- **第三圈层（国内学术圈）**：浙大系（张利军-南京大学、金仲鸣-浙大等）、武大（杜博、夏桂松）、温大与浙工大等单点合作，以及密歇根系前辈（金榕）辐射的连接。该圈层尚未形成机构级战略绑定，以论文合作为主。
- **第四圈层（产业界）**：腾讯（前雇主，存量人脉）+ 上海集成电路技术与产业促进中心（在建横向）+ 金城—恺英网络（潜在外溢通道）。其产学研逻辑是"大模型效率算法"的刚需属性，而非专利转化或创业孵化。
- **潜在增长点**：其一，团队学生群体（2024–2026 年密集产出的学生作者）未来 3–5 年毕业去向将决定其学生谱系的辐射力；其二，其主持的国自然面上项目与引才计划项目若产出系统性稀疏大模型理论成果，有望建立其在"高效大模型训练理论"方向的全国性学术可见度；其三，国家级人才称号的进一步确认（目前仅能由引才计划项目间接推断）将直接影响其圈层的能级。

总体而言，张卫忠是复旦大数据学院近年引进的"产学研贯通型"青年机器学习学者：理论功底来自浙大—密歇根双谱系，学术声望积累于张潼主导的港科大—腾讯理论圈，而其当前的战略选择是与金城的视觉应用团队深度绑定，以大模型效率化为赛道，走"顶会论文 + 产业横向"并行的路线。
