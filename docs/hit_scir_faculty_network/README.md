## 二、各位教师的角色定位

刘挺是SCIR创始人，哈工大本硕博一脉相承（1998年博士），曾于1999-2000年在微软中国研究院（MSRA）任副研究员，2000年创立SCIR，2004年32岁晋升教授，2020-2023年任计算学部主任，2023年起任哈工大副校长。他主导研发的语言技术平台LTP免费共享600余家机构、被百度/腾讯/华为/讯飞付费使用，是CCF会士（2021年度）。其学生网络几乎构成SCIR全部师资：秦兵（早期合作者与学生辈）、车万翔、张宇、张伟男、丁效、冯骁骋等均在组内成长任教。

秦兵是SCIR现任主任，哈工大电气工程本科出身、计算机博士，与刘挺共同支撑起SCIR二十余年的发展。她深耕情感计算方向，情感计算专委会主任，Google Scholar引用超2.5万次。近年她带领团队研发"活字、本草、巧板、风筝、珠算"系列开源大模型（本草为国内首个开源医学大模型，获ACL 2024杰出论文奖），学生赵妍妍留校共同执掌情感计算方向。

车万翔是SCIR副主任、哈工大人工智能研究院副院长，2008年博士（导师刘挺），曾访学斯坦福大学NLP组。他是LTP平台的主要技术负责人之一，2015-2016年连续获Google Focused Research Award，2024年获吴文俊人工智能科技进步一等奖（排名第一），并担任ACL 2025程序委员会共同主席——中国内地NLP学者在ACL社区的最高级别任职之一。其学生李正华（苏州大学）、张梅山（天津大学）、覃立波（中南大学）等形成显著的学术输出。

丁效是SCIR副主任、国家级青年人才，博士师从刘挺。他主导事理图谱（Event Evolutionary Graph）研究，与刘挺合著国内该方向首部专著，构建了中文金融事理图谱，获ACL 2024、NLPCC 2024杰出论文奖及AI 2000最具影响力学者称号，是SCIR新一代教师中的领军者。

张伟男是SCIR对话系统方向的带头人，东北林业大学数学系本科、2014年哈工大博士（双导师刘挺/张宇），现任人工智能学院执行院长、国家级青年人才。他与科大讯飞合作研发的"笨笨"对话系统落地AIUI平台年均调用超7亿次，近年牵头工信部人形机器人"机器脑"揭榜挂帅项目并亮相2025年亚冬会，完成从对话AI到具身智能的拓展。

冯骁骋是SCIR文本生成组（TG）组长、人工智能学院副院长，2013级博士（导师刘挺），获中国中文信息学会优秀博士学位论文奖、中国科协青年人才托举工程。他深耕文本生成与代码生成，主导"活字""本草""风筝"等开源大模型研发（本草获GitHub 4.7K Star），学生冯夏冲现为香港大学博士后。

## 三、全实验室关系网络的整体观察

HIT-SCIR的师资网络呈现出几个较为清晰的结构性特征。

第一是"一家之姓、五代同心"的超级谱系结构。SCIR现任核心教师几乎全部出自刘挺一脉：车万翔（2008届）、张伟男（2014届）、丁效、冯骁骋（2013级）均为其博士弟子，秦兵为同期共同创业者，赵妍妍、张宇等亦由组内培养。相比复旦NLP、南大NLP的"单组传承"，SCIR将其转化为规模化组织——9个科研小组、13位教师、200余名师生的"母舰式"实验室，谱系深度与组织规模在国内独一无二。

第二是"平台型实验室"的技术输出模式。LTP（句法分析平台）、大词林（词汇知识库）、事理图谱、活字/本草系列大模型，SCIR坚持做"被行业付费使用的开源基础设施"，LTP获钱伟长一等奖（2010）、2016与2024年两度获黑龙江省科技进步一等奖、2024-2025年吴文俊人工智能科技进步一等奖，形成了以基础工具撬动产业影响力的独特路径。

第三是"校企联合实验室"的长期主义产学研模式。哈工大讯飞联合实验室（HFL，2014年成立）延续十余年，孵化出崔一鸣（科大讯飞首席科学家）等产业人才；与华为的鲲鹏昇腾科教创新孵化中心（2024）、腾讯AI Lab学术顾问关系、百度/搜狗的长期付费合作，构成多层级企业网络，这与多数实验室"项目制"合作形成鲜明对比。

第四是"国内学术输出+国际社区深耕"的双线布局。学生在国内高校形成密集分布（苏州大学李正华、中南大学覃立波、天津大学张梅山等），车万翔担任AACL执委兼秘书长、ACL 2025程序委员会共同主席，秦兵担任CIPS常务理事与多个国内会议General Chair，使SCIR成为国内NLP学术组织生态中话语权最重的团队之一。
