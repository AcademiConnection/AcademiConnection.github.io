# 中国科学技术大学 认知智能全国重点实验室教师学术关系网络报告

> 报告生成时间：2026年8月26日

## 团队简介

认知智能全国重点实验室（官网 https://cogskl.iflytek.com/ ）由中国科学技术大学与科大讯飞股份有限公司联合共建，2022 年 5 月入选科技部首批 20 家全国重点实验室，是"高校—企业"双主体共建的标杆性建制，亦是讯飞星火认知大模型的支撑研发平台。实验室主任为科大讯飞联合创始人胡国平，副主任为陈恩红（中国科大）与王士进（科大讯飞）。需要说明：该实验室与中科大—讯飞体系下另一机构"语音及语言信息处理国家工程研究中心"（前身为 2011 年批准的语音及语言信息处理国家工程实验室，2021 年底转建，语音方向，主任刘庆峰）相互独立，并非前身关系；语音方向的学术网络已由本站 ustc_speech_faculty_network 系列报告覆盖。

本报告系列聚焦实验室的**数据挖掘与知识计算主线**，即陈恩红教授领导的"大数据分析及应用"团队（科技部重点领域创新团队，对外称 BASE Group——Bigdata and Artificial intelligence for Science and Education）。该团队以情境大数据、智能教育（自适应学习、认知诊断、知识追踪）、推荐系统与大模型检索增强为三大主轴，获 2020 年度吴文俊人工智能科技进步奖一等奖（"面向智能教育的自适应学习关键技术与应用"，联合科大讯飞）、2018/2025 年度教育部自然科学一等奖、2023 年度 CCF 自然科学一等奖等标志性奖项，KDD 2018（XiaoIce Band，联合微软）与 KDD 2024（DR4SR，联合华为诺亚）两度摘得 KDD 最佳学生论文奖。团队最大的结构特色是近乎完全的"本土繁殖"——刘淇、连德富、徐童、黄振亚、王皓等核心师资几乎全部由团队自身培养并留校任教，与 LDS（海归整建制移植）、ADSL（非师承强绑定）形成鲜明对照。

## 研究方向与圈层结构概述

四份教师报告覆盖的学术网络呈"一主线、双支点、四圈层"结构。主线是陈恩红 1996 年留校以来在中科大计算机学院内部持续运转的数据挖掘学派：刘淇（2007 年入学，智能教育）、连德富（2005 年入学，推荐系统）、徐童（2010 年入学，社交媒体挖掘）、黄振亚与王皓（2015 年入学，智能教育与大模型推荐）五代学生接力，形成多级"老带新"联合指导机制——两代 KDD 最佳学生论文（2018 朱洪渊、2024 尹铭佳）即产自这一机制。国际支点有二：罗格斯大学熊辉（徐童、刘淇的联合培养导师，现港科大（广州））与微软亚洲研究院（谢幸、练建勋，2023 CCF 一等奖联合体；连德富的联培母校与铸星计划通道），辅以 UIUC（黄振亚、王皓两代访问）。

圈层结构上，核心圈是"1+5"本土师资梯队加校企两方实验室副主任（陈恩红—王士进）的制度化绑定；学术圈辐射 MSRA、华为诺亚（KDD 2024 联合体）、UIUC、罗格斯及国内推荐系统/数据挖掘共同体，校内与 LDS（何向南）、语音团队（戴礼荣、刘庆峰）构成同院系并行与同实验室交叉关系；产业圈以科大讯飞为绝对轴心——认知智能全国重点实验室共建（平台层）、吴文俊一等奖与智学网/AI 学习机（产品层，覆盖 32 个省级行政区 16000 余所学校、约 2500 万师生）、联合专利与安徽省科技奖（专利/奖项层）构成全国罕见的"三层深度绑定"校企关系，外围辅以阿里（刘淇 2019 青橙奖）、华为、OPPO（刘淇任联合实验室主任）、京东、腾讯优图（徐童 Video-MME）等横向合作；教育/建制圈则由陈恩红从计算机学院副院长（2009）到大数据学院创始执行院长（2018）再到人工智能与数据科学学院党总支书记（2024）的履历串联，是中科大人工智能学科建制化进程的关键人物。

## 产业转化亮点

团队产业转化的核心形态是"情境大数据理论—国家级平台—规模化民生应用"的转化链条而非创业孵化：与科大讯飞的智慧教育合作（智学网、AI 学习机）是主样板，刘淇等教师与讯飞研究院（王士进、苏喻、胡国平等）长期联合发表论文、持有"知识追踪方法"等专利并共同获奖；2024 年刘淇、陈恩红、黄振亚等通过学校职务科技成果赋权试点，以知识产权出资设立合肥中科迪曼智能科技有限公司（赋权金额 120 万元），是团队向成果转化公司形态的首次延伸；连德富团队与科大讯飞合作研发工具调用模型 ToolACE，与华为诺亚联合发表 KDD 2024 最佳学生论文并开源 Nexus 训推一体化系统、Rotlex 向量检索系统；徐童团队的 Video-MME、CRUD-RAG 等开源评测基准被大模型厂商广泛采用。技术落地覆盖教育（讯飞）、工业（华为盘古、腾讯工业广告）、招聘商务智能（百度人才智囊）等场景。
