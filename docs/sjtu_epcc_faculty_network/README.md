# 上海交通大学 EPCC 实验室教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

EPCC（Emerging Parallel Computing Center，新兴并行计算研究中心，官网 [epcc.sjtu.edu.cn](http://epcc.sjtu.edu.cn/)）是上海交通大学计算机学院面向并行与分布式系统、边缘计算、网络智能和 AI 系统的重要研究团队。团队由致远讲席教授过敏意领衔，现有陈全、冷静文、李超、朱弘恣等核心教师，形成从云边资源调度、异构计算、AI 编译优化到 AIoT 与移动网络的全栈研究布局。

团队的学术谱系兼具国际化与工程化特征：过敏意教授毕业于南京大学、获日本筑波大学博士学位，曾任会津大学教授，2009年加入上海交大；冷静文教授获得 UT Austin 博士学位，研究 AI 系统与处理器架构；李超教授拥有佛罗里达大学博士背景，聚焦边缘智能与分布式机器学习；朱弘恣教授师承李明禄，研究从车联网延展至 AIoT、可信边缘智能；陈全教授则在并行系统、云原生运行时与异构资源调度上形成特色。

## 网络结构与产业特色

EPCC 的内核是过敏意领导的跨方向协作共同体：陈全负责资源管理与运行时系统，冷静文承担 AI 编译和异构系统优化，李超连接边缘 AI 与体系结构，朱弘恣在网络、移动与 AIoT 方向拓展应用边界。团队成果发表在 OSDI、ASPLOS、ISCA、MICRO、HPCA、DAC、ATC 等顶级会议，并通过华为奥林帕斯奖、CCF 技术发明一等奖、国际会议最佳论文等体现系统研究的影响力。

产业合作覆盖华为、阿里、腾讯、字节跳动、魔形智能等企业，主要围绕昇腾与 AI 编译、边缘设备协同、云边资源编排与大模型推理展开。人才培养则形成“校内交叉指导—顶会论文—高校与产业输送”的闭环，学生进入高校、华为、腾讯、字节跳动等机构，持续扩展 EPCC 的学术与产业连接。
