## 二、团队背景与研究方向概述

网络与高能效计算研究所（NEEC）是北京大学计算机学院于学院实体化改革后组建的研究所之一，人员主体承接自原信息科学技术学院的计算机网络与信息系统研究所（天网搜索引擎、Maze P2P、中国网络信息博物馆等标志性成果的摇篮）及体系结构学科力量。研究所名称中的"高能效计算"体现了其与北京大学高能效计算与应用中心（CECA，主任为UCLA丛京生教授）的深度绑定——CECA的多位教师（罗国杰、王韬、陈翔、许辰人）行政上均隶属于NEEC。

研究方向上，本所覆盖三条主线：一是系统软件与虚拟化（罗英伟、汪小林、余华山、周迪宇），从KVM/Xen虚拟化优化到内存管理、操作系统内核，2025年SOSP最佳论文CortenMM（北大首篇）为标志性成果；二是网络与移动计算（许辰人、闫宏飞、陈翔），覆盖智能物联网、无线感知、搜索引擎与边缘智能，学生产出高度集中于SIGCOMM/NSDI/MobiCom；三是体系结构与智能计算硬件（罗国杰、陈翔，并联动CECA的梁云、孙广宇、林亦波），覆盖EDA、AI加速器与软硬件协同设计。此外，李文新（人工智能与生物特征识别）和王韬（具身智能机器人与情感计算）代表了研究所向AI应用与机器人方向的延伸。

## 三、关系网络与圈层结构概述

本所的网络结构呈"一老一新两大枢纽+CECA集群"的格局。"一老"是天网搜索引擎创始人李晓明教授所奠定的网络信息处理学术传统，经闫宏飞等传承至今；"一新"是罗英伟-汪小林-周迪宇的"三代合作"系统软件梯队——罗英伟与汪小林二十余年联合指导学生（含2026届博士李传东、杨泽华，SOSP 2025一作张骏扬），并与青年助理教授周迪宇（UCLA博士、EPFL博士后）合作斩获北大首篇SOSP最佳论文，产业端深度绑定蚂蚁集团（田洪亮、闫守孟团队）与中关村实验室（星绽OS开源）。

CECA集群方面，罗国杰（UCLA博士、SIGDA杰出博士论文奖）、陈翔（匹兹堡大学博士、陈怡然弟子、NSF CAREER得主、2023年回国）、王韬（Intel主任研究员出身、具身智能产业枢纽）三人加上许辰人（罗格斯WINLAB博士、国家优青、CCF技术发明一等奖）构成了国际化程度极高的青年学者群体，其学生和合作网络直通UCLA（丛京生、Yuval Tamir、吕松武）、杜克/匹兹堡（陈怡然学术圈）以及华为、蚂蚁、深开鸿等产业巨头。

学生去向上，本所毕业生呈现"顶会学术精英+头部产业工程"双轨：许辰人学生横扫SIGCOMM/NSDI/MobiCom后进入MIT、Stanford、UChicago、Yale及腾讯；TELOS学生进入字节跳动等企业；李文新培养的赵鑫（人大高瓴教授、优青）、毛先领（北理工教授）则成为学术界中坚；王韬、闫宏飞学生中亦出现创业系（一眸科技、AutoBizLine等）。
