## 二、教师的角色定位

**实验室核心与治理层：** 刘利刚教授是GCL实验室的创始负责人，2001年博士毕业于浙江大学（师从彭群生教授一脉），后在微软亚洲研究院工作、哈佛大学访问，2013年加入中科大并组建团队，是团队几何处理、计算机图形学方向的学术旗手。实验室治理呈"一主任四副主任"架构：刘利刚/张举勇（主任及联合负责）、陈仁杰、李新、吴超分别协助实验室不同方向的管理工作，吴超作为高级工程师承担系统工程化与平台建设职责。

**"GCL四代传承"数学谱系：** 团队中一支重要的学术血统源自中科大数学系常庚哲教授、冯玉瑜教授（第一代，计算数学/逼近论方向），传至陈发来教授、邓建松教授（第二代，均为二位先生的博士生，1990年代博士毕业后留校任教），再传至杨周旺教授（第三代，陈发来的博士生，杨本人曾在采访中明确表述"陈发来是我的导师，我属于第三代"），最终传至宋艳枝、翟晓雅、胡银雷等更年轻一代特任副研究员（第四代，多为杨周旺或陈发来的博士生）。邓建松教授在学术传承之外，现已进入学校行政管理序列，任中国科学技术大学党委常委、副校长（2025年3月起），是团队中职务级别最高的成员，但其学术根基与研究方向（计算机辅助几何设计、样条空间理论）仍与GCL团队深度绑定。

**微软亚洲研究院（MSRA）校友通道：** 陈雪锦教授（沈向洋/Harry Shum时代）与傅孝明副教授（郭百宁、刘洋指导）均出身MSRA体系，是团队中"MSRA—中科大"人才环流的两个典型代表，为团队带来了计算机视觉与前沿几何处理的国际化研究视野。

**跨机构引进的中生代骨干：** 陈仁杰教授（浙江大学博士，师从刘利刚，2021年博士毕业后即回中科大GCL任教，是刘利刚培养体系中"反哺母队"的代表性人物）与张举勇教授（南洋理工大学博士）均属团队近年从外部引进的中生代学术骨干，为团队补充了几何处理、三维重建方向的多元视角。

**"特任副研究员"青年培养梯队：** 方清、郭玉东、胡银雷、宋艳枝、吴天、翟晓雅六人均为特任副研究员序列，是团队重点培育的青年学者群体，普遍为团队内部教授（陈发来、杨周旺、麻希南等）亲自指导毕业的博士生留任或引进，其中翟晓雅已独立运行"USTC TopOpt Group"课题组，胡银雷则跨界深耕生物信息学方向，体现了团队在保持几何计算主线的同时向交叉学科拓展的趋势。

## 三、团队关系网络的整体观察

**1. 数学系血统与"四代传承"叙事是团队最鲜明的学术识别符号。** 常庚哲、冯玉瑜→陈发来、邓建松→杨周旺→宋艳枝/胡银雷/翟晓雅这条链条并非外部附会，而是有杨周旺本人公开采访原话为证的真实师承脉络，贯穿了从样条理论到增材制造几何、拓扑优化的方向演进，是理解团队内部学术权威结构的关键线索。需要注意的是，刘利刚（浙大博士）、张举勇（南洋理工博士）虽是团队现今的核心教授，但并非该谱系的本土培养产物，二者是团队"内生传承"与"外部引才"两种建队模式并存的直接体现。

**2. MSRA是团队仅次于本校培养体系的第二大人才来源地。** 陈雪锦、傅孝明两位骨干均出自MSRA，这与国内计算机图形学领域整体的人才流动格局一致——MSRA长期是国内图形学、视觉方向顶尖人才的孵化器，GCL团队较好地承接了这一溢出效应。

**3. 产业化转化能力突出，"九韶智能/AMCAX"是贯穿多名教师的共同产业纽带。** 合肥九韶智能科技有限公司（几何内核/CAD相关，2022年1月成立）由杨周旺任首席科学家、傅孝明任联合创始人，陈发来、宋艳枝等亦深度参与相关研发工作，是团队将样条理论、几何处理等基础研究成果产业化的代表性案例，也是团队区别于纯学术型实验室的一个重要特征。此外傅孝明还与团队外资源共同参与了"卢深视"三维人脸识别相关项目，显示团队成果在计算机视觉产业界也有渗透。

**4. "刘利刚培养体系反哺母队"是团队人才闭环的典型样本。** 陈仁杰作为刘利刚在浙江大学时期指导的博士生，2021年博士毕业后直接回到中科大GCL团队任教，与导师刘利刚形成长达16年（2010年师生关系建立至今）、跨越"学生—青年教师—同事"三重身份转变的持续合作关系，是团队内部"自主培养—人才回流"良性循环的缩影。

**5. 官网信息滞后、同名学者与团队内部关系被误传的风险需要持续警惔。** 本次研究与交叉验证过程中发现了多处需要澄清的问题：傅孝明的真实博士导师是MSRA的郭百宁和刘洋而非刘利刚（个别初稿曾误传）；童伟华并非某2020年ADMM相关论文的作者；胡银雷的真实研究方向是生物信息学（单细胞测序、空间转录组学）而非传统图形学；李新教授需要与美国路易斯安那州立大学的同名学者"Xin Li"仔细区分；此外交叉核查中还发现并修复了十余处人名拼写错误（如"董伟华"应为"童伟华"、"宋彦志"应为"宋艳枝"、"张金进"应为"黄章进"、"康宏梅"应为"康红梅"等）和机构名称、年份等细节错误。这些问题的产生根源多为官网信息更新滞后、同名同姓学者的检索混淆，以及跨报告独立撰写时对同一人物角色定位的不同猜测，提示在使用本报告集数据时，凡涉及具体导师关系认定，应优先以有直接第一手引语或官方档案支持的表述为准。
