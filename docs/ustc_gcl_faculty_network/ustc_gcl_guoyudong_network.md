## 二、教育背景与职业履历

郭玉东于2015年在中国科学技术大学获得统计学学士学位。GCL个人页明确记载其于2021年在中国科学技术大学获得博士学位，博士导师为张举勇教授；张举勇教授团队页还把他列为自2015年9月起的团队成员。这一时间链条表明，他在本科毕业后进入张举勇团队接受博士阶段训练，并在博士毕业后回到中科大GCL任教，是“GCL/中科大培养—产业实践—回流任教”的青年教师案例。公开材料未列出独立硕士学位、硕士就读院校或硕士导师；据此不宜将博士阶段前的教育经历表述为“硕士毕业”。

在博士训练期间，他曾于2016年秋至2017年春在南洋理工大学MultiMedia Lab担任研究助理，接受Jianfei Cai与Jianmin Zheng指导。这一短期海外研究经历不是学位教育，却在其后续三维人脸重建工作中留下了清晰的共同作者链：3DFaceNet论文共同作者正包括张举勇、Cai、Jianmin Zheng及Boyi Jiang。由此可见，其学术谱系的核心是张举勇的中科大三维视觉团队，同时经由南洋理工大学的合作网络连接到国际计算机视觉与多媒体研究圈。

2021年博士毕业后，郭玉东曾到杭州像衍科技公司担任研发总监。GCL公开报道指出，其在任期间研发的数字人相关产品已用于杭州文广电视台和中央广播电视总台多个栏目。随后，他以特任副研究员身份回到中科大数学科学学院/GCL；GCL于2024年发布的国家自然科学基金元宇宙专项新闻亦明确以“张举勇教授与郭玉东特任副研究员”并列项目申报人，证明其已在该阶段承担共同组织科研的角色。

其研究轨迹大致经历了三个相互衔接的阶段：早期从统计学和深度学习切入单目稠密三维人脸重建；中期将重建、表示、动作/语音驱动和编辑能力整合到数字人问题；近期延伸到神经辐射场、3D Gaussian Splatting（3DGS）、个性化头部表示、肖像视频生成和三维资产编辑。2024年暑期课程中，他讲授《三维数字人表示》与《多模态驱动与编辑》，具体讨论神经隐式场、3DGS、动作捕捉信号、语音/文本驱动和多模态编辑，较完整地呈现了当前技术布局。

### 代表性成果与发表脉络

其可明确核对的代表性早期工作为 **CNN-Based Real-Time Dense Face Reconstruction with Inverse-Rendered Photo-Realistic Face Images（3DFaceNet）**，作者为Yudong Guo、Juyong Zhang、Jianfei Cai、Boyi Jiang、Jianmin Zheng，发表于IEEE Transactions on Pattern Analysis and Machine Intelligence（TPAMI，2018）。该工作以逆渲染产生的逼真人脸图像辅助训练CNN，实现实时稠密人脸重建，是其“低成本采集—三维人脸建模—可用数字身份”的技术起点，也构成其与张举勇、Cai、Zheng、Boyi Jiang之间最明确的跨校合作证据。

截至报告日期，个人主页列出了 **ExpPortrait: Expressive Portrait Generation via Personalized Representation**（CVPR 2026）：Junyi Wang、郭玉东（共同通讯/共同指导标识）、Boyang Guo、Shengming Yang、张举勇。工作以个性化头部表示解耦表情与身份，用于高表现力且身份一致的肖像视频生成。同年度张举勇主页还列出 **Easy3E: Feed-Forward 3D Asset Editing via Rectified Voxel Flow**（CVPR 2026），作者包括Shimin Hu、Yuanyi Wei、Fei Zha、郭玉东、张举勇。两篇CVPR成果显示他不仅参与数字人肖像生成，也与团队学生共同推进通用三维生成/编辑方法。

应当区分“郭玉东个人署名论文”与“GCL整体成果”：GCL在SIGGRAPH/SIGGRAPH Asia、CVPR、ICCV等顶会持续有大量论文，但检索到的SIGGRAPH/SIGGRAPH Asia页面不能证明郭玉东本人在这些会议有署名论文。因此，本报告仅据公开可核记录确认其本人具有TPAMI及CVPR 2026发表；未将实验室其他教师和学生的SIGGRAPH、ICCV成果归入其个人发表清单。GCL报道称其近年来在相关领域顶级期刊与会议发表10余篇，作为数量级线索可以参考，但公开主页可直接逐篇核验的完整书目仍有限。

## 三、学生培养情况

公开可访问的个人主页、GCL个人页和网页检索结果未发现郭玉东独立列名的在读博士生、硕士生名册、毕业去向或招生指标。因此，目前不能据此确认其是否具有独立博士招生资格、具体指导人数及学生毕业去向。

但从论文作者与团队活动可观察到共同培养关系。CVPR 2026的ExpPortrait由Junyi Wang、Boyang Guo、Shengming Yang等青年作者完成，郭玉东与张举勇共同署名；Easy3E中也与Shimin Hu、Yuanyi Wei、Fei Zha等作者共同合作。这些材料足以支持其在张举勇团队的学生项目中承担联合指导或科研协作角色，但不能在没有学籍、导师署名或官方培养材料的情况下，将上述作者确定为其“独立指导学生”。其2024年面向暑期课程讲授数字人表示和多模态驱动与编辑，亦体现了课程教学和团队知识传承角色。

## 四、学术合作网络

郭玉东的合作网络可概括为“导师—GCL团队—南洋理工大学—产业与应用”四层。

**第一层：导师与核心学术枢纽。** 张举勇教授是其博士导师、当前最稳定的内部合作枢纽，也是其职业网络的中心节点。二人共同署名3DFaceNet；2024年共同获批国家自然科学基金“元宇宙理论与技术基础研究”专项第II期项目“结构化辐射场表达及其高效优化”；2026年又共同参与ExpPortrait、Easy3E等工作。合作主题从三维人脸重建推进到辐射场/高斯表示、数字人肖像动画及三维资产编辑，表明二人联系并非单一论文合作，而是覆盖人才培养、项目组织和持续的研究议程。

**第二层：GCL内部教师协同。** 与刘利刚教授的关系主要呈现为同一实验室与共同产业转化网络，而不是本次检索中有明确共同论文的直接作者关系。2024年CSIAM应用数学落地成果认证的“面向大规模产业应用的三维人脸识别关键技术与设备”项目，由中科大数学科学学院GCL与合肥的卢深视科技有限公司共同完成，署名成员包括张举勇、刘利刚、郭玉东、户磊、朱海涛。该项目将三维人脸技术贯通结构光深度感知、建模、识别、工程集成和大规模部署，说明郭玉东处于GCL以三维感知为核心的跨教师协同链条。与陈雪锦、方清等GCL教师，公开材料可确认其共同参与Chinagraph 2024技术论坛报告；但未检得可归因给郭玉东的共同署名论文，宜界定为实验室学术共同体和活动协同，而非强论文合作。

**第三层：跨机构学术合作。** 南洋理工大学MultiMedia Lab构成重要国际连接。Jianfei Cai与Jianmin Zheng既是其访问期指导者，也在3DFaceNet中共同署名；Boyi Jiang是该论文中的青年合作者。该链条说明其早期研究同时获得中科大和南洋理工大学两端的合作支持。2024年数字人课程讨论中，他还与微软亚洲研究院杨蛟龙、华为徐迪、北京师范大学张鸿文等学者/产业研究者同场交流，反映其所在团队在数字人方向的开放学术网络；这属于学术活动连接，不能等同于论文合作。

**第四层：项目与问题导向的合作。** 国家元宇宙专项把郭玉东和张举勇的合作推进到结构化辐射场、优化与隐私保护建模，目标包括普通终端部署和城市级大场景重建。相较于3DFaceNet时期以单人脸实时重建为主的研究，这一合作层连接了三维建模、数值优化、联邦学习与元宇宙应用，是其网络向更广泛三维数字化问题扩展的信号。

## 五、业界合作关系深度分析

郭玉东的业界关联具有较强的“研发—产品—场景验证—成果认证”闭环特征，而不只是企业联合署名。首先，杭州像衍科技公司的研发总监经历意味着其曾直接处于数字人产品研发和管理岗位。GCL报道指出，该阶段研发的数字人产品进入杭州文广电视台和中央广播电视总台多个栏目，显示其能力至少经过了广电内容生产场景的部署检验。由于公开资料未披露产品名称、合同规模、技术责任边界或后续商业化数据，不能进一步量化其个人贡献或经营效果。

其次，和合肥的卢深视科技有限公司共同完成的三维人脸识别项目提供了更强的产业化证据。中科大官方报道显示，该项目获2024年CSIAM应用数学落地成果认证，且当年仅四个项目获认证。项目在三维人脸识别关键算法、设备、专利、软著、标准和场景部署上形成系统成果：报道汇总为39项授权发明专利、1项实用新型专利、24项软件著作权、36篇论文，并称技术已用于多地公安、港珠澳大桥、广州/深圳/佛山地铁、微信支付设备、小米和TCL智能门锁。该统计归属于张举勇团队项目整体，不应全部等同于郭玉东个人专利或个人完成量；但其作为列名成员，表明他位于该项“高精度三维几何识别—结构光感知—产品化设备—公共与消费场景”的核心协作网络中。

再次，数字人方向的产业联系与研究议题高度一致：从三维人脸重建发展到高保真多模态三维数字人，再到神经表示、3DGS和语音/文本驱动，能够回应新闻播报、智能前台、数智教师、影视传媒和文旅等应用。中科大报道已明确团队数字孪生系统用于数字人新闻播报与智能前台；郭玉东自身的广电产品经历使其成为这一技术链中连接算法研发与传媒落地的节点。需要强调，公开材料并未显示他与腾讯、阿里、字节跳动等互联网企业存在可核验的直接合作，故不作推断。

## 六、重要奖项与学术兼职

公开材料明确记载郭玉东曾获“华人数学家联盟最佳论文奖（若琳奖）”。在项目/团队层面，他作为成员参与的三维人脸识别项目获得2024年CSIAM应用数学落地成果认证；这是一项项目荣誉，应与个人获奖严格区分。另据GCL报道，张举勇与郭玉东共同申报的“结构化辐射场表达及其高效优化”获国家自然科学基金元宇宙专项支持，属于重要竞争性科研项目资助。

学术服务方面，公开报道称其多次担任CVPR、ICCV、IEEE Transactions on Visualization and Computer Graphics（TVCG）、SIGGRAPH Asia、IEEE Transactions on Multimedia（TMM）等期刊/会议审稿人。现有材料支持“审稿服务”这一表述，但未见其担任编委、领域主席、会议主席或学会任职的可靠公开记录，因而不将其表述为相关职务。

## 七、Connection圈层总结

郭玉东的第一圈层是张举勇教授及其带领的中科大三维视觉/数字人团队。导师关系、共同论文、共同国家专项和共同学生项目共同构成了稳定而高强度的核心连接；这也是其从博士生到特任副研究员最清晰的学术传承路径。

第二圈层是GCL内部的跨方向协同网络，尤其是与刘利刚、户磊、朱海涛等通过三维人脸识别产业化项目建立的项目级合作。其特点是把计算机图形学、三维视觉、结构光感知、数值优化与设备工程化结合，服务于公共安全、交通、支付和智能家居等应用。

第三圈层是南洋理工大学MultiMedia Lab带来的国际学术合作链，以Jianfei Cai、Jianmin Zheng和Boyi Jiang为代表，已在TPAMI代表论文中形成可见的共同作者网络。这一圈层增强了其在三维人脸重建和视觉学习方向的国际连接度。

第四圈层是数字人产业与应用合作网络：杭州像衍科技的研发实践、合肥的卢深视的三维人脸产业化，以及广电、智能前台等落地场景。其突出特征是研究主题与产业问题匹配度高。综合而言，郭玉东是GCL中以“高保真人脸/数字人三维表示”为核心、同时具备海外研究协作和产品研发履历的青年研究者；目前公开资料对其独立学生名册、完整论文书目和个人级专利贡献仍不充分，后续若获得其官方招生页、完整CV或课题组年报，可进一步提升关系网络的量化精度。
