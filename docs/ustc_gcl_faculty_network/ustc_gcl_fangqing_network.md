## 二、教育背景与职业履历

方清是GCL实验室自主培养的青年学者，其学术生涯与中国科学技术大学深度绑定。他本科就读于中国科学技术大学数学科学学院，于2015年获得数学与应用数学学士学位。此后，方清继续留在中科大GCL实验室攻读博士学位，由刘利刚教授与傅孝明（时任特任副研究员，2021年4月起任副教授）共同指导。根据其个人主页早期版本的自我介绍，他在博士阶段自述为"第五年博士候选人"（fifth-year Ph.D. candidate），由此可推断其博士入学时间约为2016年前后；据傅孝明个人主页的校友名单，方清于2021年5月博士毕业（该主页标注的 2019.9 为傅孝明开始共同指导的时点，非方清入学时间）。

博士毕业后，方清以博士后身份留校工作，从事计算数学方向的博士后研究。在GAMES 301《曲面参数化》在线课程（2022年10月开课）的讲者简介中，方清的官方身份被描述为"中国科学技术大学计算数学方向博士后，博士毕业于数学科学学院中科大图形与几何计算实验室"。此后，他由博士后转为特任副研究员（Assistant Researcher），正式留任GCL实验室。在其GitHub个人主页（qingfang1208.github.io）上，他的头衔已更新为"Assistant Researcher @ USTC"，办公地址也从管理与科研楼1203室变更为1412室，表明其职位已发生正式转变。

方清的职业发展路径呈现出典型的"GCL实验室培养—博士后过渡—留校任教"模式，这一职业路径与GCL实验室的另一位核心教师傅孝明高度相似（傅孝明同样在中科大获得学士和博士学位后留校，先任特任副研究员后转为副教授）；但二人的学术出身不同——方清是GCL内部由刘利刚与傅孝明共同培养的博士，而傅孝明的博士导师则是微软亚洲研究院的郭百宁与刘洋。方清目前作为特任副研究员，已成为GCL实验室年轻教师梯队中的重要一员。

## 三、学生培养情况

根据现有公开信息，方清作为特任副研究员，已开始独立或合作指导学生。从其近年发表论文的作者列表中可以观察到一些学生合作者的身影。在2025年发表于CVM 2025并获得最佳论文提名奖的论文《Developable Approximation via Isomap on Gauss Image》中，第一作者为程元元同学，方清作为第二作者（对应作者之一）参与指导。在2026年发表的论文《Surface Multigrid via Global Parametric Domain Simplification》中，第一作者为赵安宇（Anyu Zhao）同学，方清同样位列第二作者。在《Efficient Computation of Integer-constrained Cones for Conformal Parameterizations》（IEEE TVCG, 2026）中，第一作者杜伟（Wei Du）同样是在方清指导下开展研究。此外，在《Probe-based Walk on Spheres for Efficient Path Reusing》（SIGGRAPH 2026）中，第一作者黄万超（Wanchao Huang）亦是在方清指导下完成的研究工作。

从这些合作模式来看，方清已逐步承担起指导研究生的职责，尤其在共形参数化、可展曲面逼近和几何处理算法等方向上形成了自己指导的学生群体。不过，由于方清目前仍为特任副研究员职称，其独立招收博士生的权限可能受限，推测其指导模式更多是与刘利刚教授或傅孝明副教授联合指导。公开信息中暂未找到方清已有独立指导毕业的博士生记录。

在教学方面，方清于2024年春季学期承担了中国科学技术大学《数字几何处理》（Digital Geometry Processing）课程的教学工作，这表明他已正式参与学院的本科或研究生教学工作。此外，他还作为授课讲者参与了GAMES 301《曲面参数化》在线课程的教学，与刘利刚、陈仁杰、傅孝明共同组成教师组，向全国学生和业界同仁系统讲授曲面参数化的理论、计算与实现方法。方清在该课程中负责的部分应与其在共形参数化和锥奇异点构造方面的深入研究密切相关。

## 四、学术合作网络

方清的学术合作网络以GCL实验室内部合作为绝对核心，同时延伸至少量国际合作伙伴。以下从几个层次进行分析。

**与刘利刚教授的合作。** 刘利刚教授是GCL实验室主任、国家杰出青年科学基金获得者，也是方清的博士导师。在方清目前公开的全部论文中，刘利刚的名字几乎出现在每一篇论文的作者列表中。无论是在共形参数化系列工作（2021年的Sparse Cones、2022年的Integer-Constrained Cones、2023年的Efficient Cone Singularity Construction）、可展曲面逼近系列工作（2022年的Developability-Driven、2023年的Evolutionary Developable、2025年的Isomap Developable），还是在点云处理（2024年的Stochastic Normal Orientation）和几何嵌入（2025年的Divide-and-Conquer Embedding）等方向，刘利刚均作为核心合作者参与。这反映了GCL实验室以刘利刚为学术核心的紧密合作模式。

**与傅孝明副教授的合作。** 傅孝明是方清博士阶段的另一位共同指导教师，也是其学术生涯中最为密切的合作者。傅孝明于2011年和2016年在中科大获得学士和博士学位（博士导师为微软亚洲研究院的郭百宁与刘洋，非刘利刚），2016年至2021年任特任副研究员，2021年4月起任副教授。在方清的绝大多数论文中，傅孝明均作为通讯作者或主要合作者出现。两人合作的研究方向高度一致，主要集中在共形参数化中的锥奇异点构造、可展曲面逼近、点云法向定向等问题。从论文署名模式来看，方清在许多论文中与傅孝明形成"一作—通讯"的搭配关系，表明两人之间形成了紧密的师生传承与科研伙伴关系。2025年9月，方清与傅孝明共同赴北京四中开展科普讲座，进一步体现了两人在学术之外的密切合作关系。

**与GCL实验室其他教师和学生的合作。** 方清与实验室内的多位教师和学生也有广泛合作。在可展曲面系列工作中，赵振宇（Zheng-Yu Zhao）是重要合作者，参与了从2022年到2023年的多篇SIGGRAPH论文。李默（Mo Li）在共形参数化锥奇异点系列工作中贡献突出。张正（Zheng Zhang）参与了从2023年到2026年的多篇论文，包括点云法向定向和锥奇异点构造方向。翟晓雅（Xiaoya Zhai）出现在微结构设计相关论文中。何颖（Ying He）参与了2024年的对称分片可展逼近工作。此外，程元元（Yuan-Yuan Cheng）作为学生合作者参与了2025年和2026年的多篇论文。这些合作者构成了方清学术网络的核心圈层。

**与国际学者的合作。** 方清的早期论文中有一项较为突出的国际合作：2018年发表于Computer-Aided Design的论文《Support-Free Hollowing for 3D Printing via Voronoi Diagram of Ellipses》，合作者包括韩国高丽大学的Mokwon Lee和Joonghyun Ryu，以及Deok-Soo Kim教授。这项合作围绕3D打印中的支撑结构优化展开，是方清在3D制造方向的代表性工作之一。不过，在其后续的研究中，国际合作相对较少，主要合作仍集中在GCL实验室内部。

## 五、学术成果概览

方清自2018年发表第一篇论文以来，截至2026年已有约18篇论文发表，其中以第一作者或通讯作者身份在ACM Transactions on Graphics（SIGGRAPH/SIGGRAPH Asia）上发表了多篇高水平论文。其代表性学术成果可以归纳为以下几条研究主线。

**共形参数化与锥奇异点构造系列。** 这是方清最为核心的研究方向，贯穿其整个学术生涯。2021年，他以第一作者身份在SIGGRAPH Asia上发表论文《Computing Sparse Cones with Bounded Distortion for Conformal Parameterizations》，提出了一种在有界畸变约束下计算稀疏锥奇异点的方法。此后，这一方向持续深化：2022年在SIGGRAPH上发表论文《Computing Sparse Integer-Constrained Cones for Conformal Parameterizations》，引入整数约束条件；2023年在SIGGRAPH Asia上发表论文《Efficient Cone Singularity Construction for Conformal Parameterizations》，提升了锥奇异点构造的效率；2023年在IEEE TVCG上发表论文《Practical Integer-Constrained Cone Construction for Conformal Parameterizations》；2026年在IEEE TVCG上发表论文《Efficient Computation of Integer-constrained Cones for Conformal Parameterizations》。这一系列工作构成了共形参数化领域中锥奇异点构造方向的系统性贡献。

**可展曲面逼近系列。** 这是方清的另一条重要研究主线。2022年，论文《Developability-Driven Piecewise Approximations for Triangular Meshes》发表于SIGGRAPH，提出了基于可展性驱动的分片逼近方法。2023年，论文《Evolutionary Piecewise Developable Approximations》发表于SIGGRAPH，进一步发展了进化式分片可展逼近策略。2024年，论文《Symmetric Piecewise Developable Approximations》发表于Pacific Graphics，引入了对称性约束。2025年，论文《Developable Approximation via Isomap on Gauss Image》发表于IEEE TVCG（此前在CVM 2025会议上获得最佳论文提名奖），创新性地采用非线性流形学习（Isomap）方法替代传统线性PCA降维来处理高斯映射退化问题，取得了更优的几何逼近效果。

**点云处理方向。** 2024年，方清参与的工作《Stochastic Normal Orientation for Point Clouds》发表于SIGGRAPH Asia（ACM Transactions on Graphics），提出了一种基于随机概率模型的点云法向定向方法，通过统计泊松曲面重建概率模型定义带符号不确定性函数来优化法线方向的全局一致性。2026年，后续工作《GPU-Accelerated Stochastic Normal Orientation》发表于Computer Aided Geometric Design，将该方法扩展至GPU加速场景。此外，2025年发表于Graphical Models的论文《Topology-Controlled Laplace-Beltrami Operator on Point Clouds Based on Persistent Homology》将拓扑控制引入点云上的拉普拉斯-贝尔特拉米算子计算。

**其他方向。** 方清还涉足了曲面参数化的其他问题，如2025年发表于SIGGRAPH的《Divide-and-Conquer Embedding》提出分治嵌入方法，2026年发表于SGP的《Surface Multigrid via Global Parametric Domain Simplification》将多重网格方法引入参数化领域，以及2026年发表于SIGGRAPH的《Probe-based Walk on Spheres for Efficient Path Reusing》探讨了球面游走方法在路径复用中的高效计算。此外，2024年发表于Computers & Graphics的论文《Differentiable Microstructures Design via Anisotropic Thermal Diffusion》将可微微结构设计与各向异性热扩散相结合，展示了方清在计算制造方向的拓展。2020年的早期工作《Metric First Reconstruction for Interactive Curvature-aware Modeling》发表于Computer-Aided Design（SPM会议），获得了最佳论文奖第三名。

## 六、业界合作关系深度分析

根据目前公开可查的信息，方清的学术合作主要局限于学术圈内部，尚未发现其与特定企业或产业界有深度的正式合作关系。不过，其研究方向中的多个课题具有显著的工业应用前景。共形参数化技术是纹理映射、UV展开等图形学应用的基础，在游戏、影视和工业设计领域有广泛需求。可展曲面逼近技术在钣金加工、船舶制造等工业领域具有直接应用价值——正如CVM 2025论文中所指出的，可展曲面可由平面材料通过弯曲或折叠而成，无需拉伸或撕裂，能够显著提高材料利用效率并简化制造流程。3D打印相关的支撑结构优化工作则直接面向增材制造场景。

在GCL实验室整体层面，实验室与产业界有着较为密切的联系，例如GCL实验室毕业生刘浩加入了九韶智能从事CAD行业工作。方清本人在2025年8月参加CAD/Graphics 2025和GDC 2025联合学术会议时，在"数字几何处理的范式跃迁：传统方法的坚守与数据智能的颠覆"专题技术论坛上做了报告，该论坛涉及传统方法与数据智能的对话，暗示了方清的研究可能对CAD/几何处理产业有所启示。但目前没有公开信息显示方清与特定企业有正式的合作项目或技术转让记录。

此外，方清参与的2024年论文《Inverse-designed 3D sequential metamaterials achieving extreme stiffness》（发表于Materials & Design）以及微结构设计相关研究，涉及超材料设计这一具有工业前景的交叉领域，但该工作更多是学术合作性质。总体而言，方清的业界合作尚处于起步阶段，其研究的主要价值目前更多体现在学术贡献层面。

在学术服务方面，方清作为授课讲者参与了GAMES 301《曲面参数化》在线课程（2022年10月开课），与刘利刚、陈仁杰、傅孝明共同组成教师组，面向全国学生和业界同仁系统讲授曲面参数化理论与方法。他还在2022年中科大《计算机图形学》暑期课程中担任授课讲者。2024年，方清在Chinagraph 2024和Pacific Graphics 2024联合会议的技术论坛上做了学术报告。2024年6月，在GCL实验室举办的"几何计算前沿"国际研讨会上，方清作为GCL实验室七位年轻教师之一进行了学术报告，与Denis Zorin（纽约大学）、Justin Solomon（MIT）、Eitan Grinspun（多伦多大学）等国际知名学者同台交流。2025年8月，方清在CAD/Graphics 2025和GDC 2025联合学术会议的"数字几何处理的范式跃迁"专题技术论坛上做了报告。

在科普活动方面，2025年9月25日，方清与傅孝明老师一同赴北京四中开展科普讲座，方清的报告题目为"分形世界，科学与艺术的融合"，向中学生介绍了分形的核心概念、自然界的分形现象（如雪花、树枝、闪电、河流形态），以及分形在工业和艺术领域的实际应用，包括利用分形散热器提高散热效率、利用分形控制音乐节拍和频率等，并探讨了3D打印技术对分形制造成本的影响。这一活动体现了方清在学术研究之外对科学传播和社会责任的积极承担。

## 八、Connection圈层总结

方清的学术关系网络呈现出清晰的圈层结构，以GCL实验室为绝对核心，呈现出"内生型"学术网络的特征。

**第一圈层（核心导师圈）：** 刘利刚教授和傅孝明副教授。刘利刚作为GCL实验室主任和方清的博士导师，是方清学术网络中最核心的节点，几乎覆盖其全部论文。傅孝明作为方清博士阶段的共同指导教师和最密切的科研伙伴，两人之间的合作关系深度和频率在方清的网络中居于首位，形成了典型的"师生传承—科研伙伴"双重关系。方清的职业发展路径（GCL博士—博士后—特任副研究员）完全在GCL实验室内部完成，是实验室自主培养并留用的青年学者代表。

**第二圈层（实验室合作圈）：** GCL实验室内部的其他教师和学生。包括赵振宇、李默、张正、翟晓雅、何颖、程元元、杜伟、黄万超、赵安宇等。这些合作者构成了方清日常科研活动的直接协作网络，覆盖了从资深博士生到青年教师的不同层次。GCL实验室目前拥有刘利刚、傅孝明、陈仁杰、张举勇、陈雪锦、李新、翟晓雅、郭玉东、方清等多位教师，方清在这一教师梯队中属于年轻一代，承担了共形参数化和可展曲面逼近等方向的科研主力角色。

**第三圈层（国内学术圈）：** 通过GAMES 301在线课程、中科大暑期课程、Chinagraph、Pacific Graphics、CAD/Graphics、GDC等学术会议和活动，方清已在国内计算机图形学和几何处理领域建立了初步的学术可见度。他在这些场合的学术报告和授课活动使其在国内同行中获得了一定的认知度。

**第四圈层（国际学术圈）：** 方清的国际合作相对有限，目前可确认的国际合作主要为2018年与韩国高丽大学Deok-Soo Kim课题组的合作（3D打印支撑结构优化）。尽管其论文发表于SIGGRAPH、SIGGRAPH Asia等顶级国际会议和期刊，但与其他国际学者的直接合作论文较少。这可能与GCL实验室以内生培养为主的模式有关。随着方清学术独立性的增强和研究方向的拓展，其国际合作的拓展空间值得期待。

总体而言，方清是一位由GCL实验室完整培养、已在共形参数化和可展曲面逼近方向做出系统性贡献的青年学者。他正处于从博士后向独立研究者的转型期，已开始指导学生并独立承担教学任务。以目前每年持续在SIGGRAPH/SIGGRAPH Asia等顶会发表论文的产出节奏来看，方清有望在未来几年内进一步巩固其在数字几何处理领域的学术地位，并逐步拓展其学术合作的广度与深度。
