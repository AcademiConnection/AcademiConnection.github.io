## 二、教育背景与职业履历

### 教育经历

吴天的学术生涯起步于中国科学技术大学少年班学院。2015年9月，他进入少年班学院攻读数学与应用数学专业，师从李平教授完成学士学位论文，于2019年6月获得理学学士学位。少年班学院是中科大独具特色的拔尖人才培养机构，聚集了全国优秀的年轻学子，吴天在此期间展现出卓越的数学天赋与综合素养，曾获国家奖学金（2017年）、郭永怀奖学金（2024年）等多项荣誉，并在第八届全国大学生数学竞赛决赛中获全国一等奖（2017年）。

本科毕业后，吴天留在中科大数学科学学院继续深造，于2019年9月以硕士身份入学，随后通过转博资格考试（分析第一名、几何第一名）转为博士研究生，师从麻希南教授攻读基础数学方向理学博士学位，于2024年6月获得博士学位。麻希南教授是中科大数学科学学院资深教授，长期从事椭圆偏微分方程、几何分析等领域的研究，在共形几何、Monge-Ampere方程等方向有深厚积累。吴天在麻希南教授指导下发展了"不变张量技术"，这一技术成为他博士阶段最核心的学术贡献，并在毕业后持续产出重要成果。

### 职业履历

吴天的职业路径完全根植于中国科学技术大学。2024年7月，他开始在中科大数学科学学院从事博士后研究，合作导师为刘利刚教授。刘利刚教授是GCL实验室主任、国家杰出青年科学基金获得者、中国计算机图形学领域的领军人物之一。这一博士后合作安排体现了吴天从纯基础数学研究向应用数学与计算机图形学交叉领域拓展的战略意图。他的博士后研究项目"偏微分方程解的分类问题以及在图像处理中的应用"获安徽省博士后科研项目资助（B档，10万元），将偏微分方程的理论工具引入图像处理与图形计算的应用场景。

2026年7月，吴天正式转聘为特任副研究员，留在数学科学学院与GCL实验室继续工作。从GCL实验室官网的组织架构来看，实验室主任为刘利刚，副主任包括张举勇（常务副主任）、李新、陈仁杰、吴超，秘书处秘书长为傅孝明和翟晓雅。吴天作为特任副研究员在GCL实验室教师页面上有独立著录，表明他已成为该实验室的正式成员，而非仅是短期访问或兼职合作。

作为一位2024年才开始博士后工作、2026年方正式入职的青年学者，吴天的学生培养工作尚处于起步阶段，但已有一定的积累。根据其教学主页信息，他已指导了多位本科生的毕业论文和研究项目。

在本科毕业论文指导方面，温家睿（2026届，获校优秀毕业论文）、李华滨（2026届）、朱浩然（2025届）和徐之栋（2025届）均在其指导下完成学士学位论文。其中温家睿的论文获评校级优秀毕业论文，体现了吴天在本科指导方面的用心与成效。此外，他还指导了大学生研究项目，包括周文硕（2026年）和李华滨（2025年），以及暑期研究项目学生马明昊（2025年）。

在教学方面，吴天长期承担科大本科数学通修课的教学工作。从2024年起，他先后教授或参与教授了数学分析（B1）、数学分析（B2）、代数I/II（口试与习题）、分析I（口试）、几何分析选讲（与王晓东合作）、物理与几何中的偏微分方程（与麻希南合作）等课程。他还长期担任中国科大大学生数学竞赛数学类辅导班的分析教练（2021-2023年），并在蜗壳学社（中科大学生学业互助平台）担任数学版块总版主（2021-2024年），在本科生学业支持方面贡献突出。2026年，他主持了一项校级教学研究项目"对抗与共生：AI时代数学通修课双轨教学模式的探索与实践"，探索人工智能时代数学教学模式的创新。他曾获校级教学奖一项。

## 四、学术合作网络

### （一）与博士导师麻希南教授的合作

吴天与麻希南教授的合作是其学术生涯中最核心、最深入的合作关系。麻希南教授是吴天的博士导师，也是他大部分论文的共同作者。从已发表和待发表的论文来看，吴天与麻希南合作了至少7篇论文，涵盖了不变张量技术的主要成果，包括发表在《中国科学：数学》上的综述性文章、发表在《Acta Math. Sci.》上的Heisenberg群上Jerison-Lee恒等式工作，以及多篇关于闭流形上四阶半线性方程、Onofri型不等式、Sobolev不等式的arXiv预印本（arXiv:2508.14494, arXiv:2508.14497等）。麻希南教授在多场学术报告中特别介绍了与吴天、吴汪哲、周晓合作的四阶椭圆方程向量场方法成果，表明吴天是麻希南研究团队中的核心成员。

### （二）与博士后合作导师刘利刚教授及GCL实验室的合作

吴天与刘利刚教授的合作始于2024年的博士后阶段。虽然吴天的研究背景是基础数学（偏微分方程与几何分析），而刘利刚的研究领域是计算机图形学与几何计算，两者的交叉点在于偏微分方程在图形学、拓扑优化等问题中的理论与数值应用。从论文来看，两人已合作了一篇待发表论文"Singular-aware kernel learning for walk on spheres on second-order linear PDEs"（与温家睿、王博治、方清合作），该论文将偏微分方程的球面行走数值方法与核学习技术相结合，体现了理论PDE与计算方法的交叉融合。

在GCL实验室内部，吴天的合作网络仍在构建之中。GCL实验室的核心教师团队包括刘利刚（图形学、几何处理）、张举勇（常务副主任，计算机视觉、三维感知）、陈仁杰（特任教授，几何处理）、傅孝明（副教授，几何建模与优化）、李新（计算几何）等。吴天作为偏微分方程理论方向的学者，在GCL实验室中扮演着独特的角色——他可以为图形学中的几何计算问题提供严格的PDE理论支撑，同时从图形学的应用需求中提炼新的数学问题。他参与的中科大-西南科技大学联合基金"面向复杂工程的微结构拓扑优化理论与算法"项目，以及作为骨干参与的国家重点研发计划"完全非线性椭圆方程及其应用"项目，正是这种交叉合作的具体体现。

### （三）与其他合作者的学术网络

除麻希南和刘利刚之外，吴天的合作者网络还包含多位学者。吴汪哲是吴天在麻希南团队中的密切合作者，两人共同参与了多项关于四阶椭圆方程、共形不变算子的研究工作。周晓（Xiao Zhou）也是重要合作者，参与了闭流形上四阶半线性方程与Sobolev不等式的研究。欧乾隆（Qianzhong Ou，广西师范大学）参与了Heisenberg群上Jerison-Lee恒等式的工作。此外，吴天还与窦静波（Jingbo Dou，陕西师范大学）、严金（Jin Yan）、陈露（Lu Chen）、梁维兆（Weizhao Liang）等多位学者有论文合作，合作方向涵盖各向异性Sobolev方程、p-Laplace方程的分类问题等。

在学术交流方面，吴天积极活跃于学术会议与报告平台。2025年9月，他应中科院数学与系统科学研究院邱国寰研究员的邀请，在思源楼做题为"不变张量技术在四阶半线性方程解的分类中的应用"的学术报告。2025年10月和2026年3月、7月，他分别在中科大做了英文和中文的学术报告，介绍不变张量技术与几何不等式的最新进展。他还组织了第一届中意椭圆方程与变分法会议（黄山），并长期维护麻希南教授讨论班的网页（从2022年春至2026年春共九个学期）。

吴天作为一位以基础数学理论研究为主的青年学者，其与业界的直接合作尚处于早期阶段，但已显现出向应用转化的明确趋势。

从研究方向来看，吴天关注的"偏微分方程在计算机图形学、拓扑优化等领域的渐进行为分析与数值求解"以及"机器证明、符号计算、人工智能在PDE理论与数值计算研究中的应用"，具有潜在的产业转化价值。特别是他与刘利刚教授合作的"球面行走方法的奇异感知核学习"工作，将PDE数值方法与机器学习相结合，可能对图形学中的物理模拟、渲染计算等应用场景产生贡献。此外，GCL实验室在2026年7月发布的"九重Eureka"数学研究AI平台新闻，与吴天"数学定理的机器证明"研究方向存在主题上的关联性，但目前没有公开证据表明吴天直接参与了该平台的开发。

吴天的学术关系网络呈现出清晰的圈层结构，可以概括为以下几个层次：

**核心圈层——中科大麻希南团队**。这是吴天学术成长的根基，麻希南教授是他的博士导师和最重要的学术合作者。两人合作的不变张量技术系列工作，解决了Jerison-Lee恒等式理论框架问题、CR流形上的刚性猜想、闭流形上的二阶Beckner不等式等多个公开问题，构成了吴天学术成果的主体。在这个团队中，吴汪哲和周晓是吴天最密切的同辈合作者，三人共同完成了四阶椭圆方程与几何不等式的系列工作。麻希南教授在多场公开学术报告中专门介绍与吴天等人的合作成果，表明吴天在团队中具有核心地位。

**拓展圈层——GCL实验室与刘利刚团队**。通过博士后阶段的合作，吴天进入了以刘利刚教授为首的GCL实验室网络。GCL实验室是安徽省图形计算与感知交互重点实验室，汇聚了张举勇、陈仁杰、傅孝明、李新等多位在计算机图形学、几何计算、计算机视觉等领域的优秀学者。吴天在GCL实验室中的定位是偏微分方程理论专家，他为团队提供严格的PDE理论支撑，同时从图形学应用中汲取新的数学问题。目前这一合作圈层已有初步成果（与刘利刚、方清等合作的PDE数值方法论文），但仍处于发展初期，合作深度和广度有待进一步拓展。

**外延圈层——国内PDE与几何分析学术社区**。吴天通过与欧乾隆（广西师范大学）、窦静波（陕西师范大学）、严金等学者的论文合作，以及在中科院数学与系统科学研究院、新疆师范大学等机构的学术报告，建立了与国内偏微分方程与几何分析学术社区的联系。他组织的第一届中意椭圆方程与变分法会议（黄山），表明他也在积极拓展国际学术交流网络。

**潜在圈层——产学研合作网络**。通过GCL实验室的产学研平台和国家重点研发计划项目，吴天处于中科大与西南科技大学、以及GCL实验室与"珂晶达""广联达"等企业的合作网络边缘。虽然他目前尚未有直接的产业合作成果，但其研究方向（PDE数值解、拓扑优化、机器证明）与工业应用的对接潜力值得关注。

从整体来看，吴天是一位具有扎实理论功底且正在向应用交叉领域拓展的青年学者。他的学术身份具有独特性：在GCL这个以计算机图形学为主导的实验室中，他是少有的以纯数学（偏微分方程与几何分析）为核心背景的教师成员，这使得他在实验室中扮演着"理论桥梁"的角色。他能否将不变张量技术等纯数学工具成功应用于图形学、拓扑优化等工程问题，并在GCL实验室的核心研究领域（如几何处理、物理模拟、三维重建）中产生独特贡献，将决定其在GCL实验室中的长期学术定位。从他目前的研究轨迹和合作态势来看，这一交叉融合的方向已经初步显现，但距离形成系统性的、有影响力的交叉成果仍有距离。
