## 二、教育背景与职业履历

胡银雷的学术生涯始于中国科学技术大学数学科学学院。根据2021年数学科学学院研究生学业奖学金公示，他以"2018博"（即2018级博士研究生）身份获得一等学业奖学金，表明其于2018年进入中国科学技术大学数学科学学院攻读博士学位。其博士培养阶段在陈发来教授指导下完成，于2022年获博士学位。公开材料未列示其本科和硕士阶段的具体院校与专业信息，亦未列示独立的硕士学位信息；据此，本报告不对博士前的教育经历做未经核实的描述。

博士毕业后，胡银雷以特任副研究员身份留校工作。根据中国科大教师主页的简介，其"现为中国科学技术大学数学院特任副研究员，合作导师为陈发来教授和瞿昆教授"。这一"双合作导师"安排是其职业身份的核心特征：陈发来教授隶属数学科学学院，是GCL实验室的核心教师之一，长期从事计算机辅助几何设计、稀疏优化在几何处理中的应用等方向研究；瞿昆教授隶属生命科学与医学部，是国家杰出青年基金获得者，长期致力于生物信息学、单细胞和空间组学测序技术与算法开发。胡银雷的研究正处在两位导师的学术交叉地带——将陈发来方向的数学工具（稀疏优化、低秩矩阵分解）应用于瞿昆方向的生物学问题（单细胞与空间组学数据分析）。

从职业发展的时间线看，胡银雷经历了"博士训练（2018–2022）—博士后/特任副研究员（2022至今）"的路径。其间他曾主持中国博士后科学基金面上项目、安徽省青年基金和中国科学技术大学青年创新基金项目，目前主持国家自然科学基金青年项目（C类）。他还获得了"小米青年学者"荣誉和中国科大墨子特资津贴，这些荣誉面向青年科研人员，通常要求在科研产出和发展潜力方面有突出表现。

在学术服务方面，2024年12月，胡银雷作为教师代表参加了数学科学学院组织的"图形与几何计算方向师生面对面"活动，与刘利刚、李新、童伟华、傅孝明、翟晓雅、郭玉东等GCL教师一同出席。在活动中，他建议学生"认真研读专业领域内近几年发表的最重要的几篇文章"，并强调"积极加入师兄师姐的项目中，通过'打杂'来了解这个领域"。这一公开露面进一步确认了他在GCL教学与学术共同体中的参与角色。

## 四、学术合作网络

胡银雷的学术合作网络呈现出以"双导师—双实验室—跨学科"为鲜明特征的交叉型结构，可划分为以下圈层。

**第一圈层：双合作导师。** 陈发来教授和瞿昆教授是胡银雷学术网络中最核心的两个节点。陈发来是其博士阶段的导师，也是其当前在数学科学学院的合作导师，在胡银雷全部四篇代表性论文中均作为通讯作者署名。瞿昆是其博士后阶段的合作导师，同样是全部代表性论文的通讯作者。两位教授的合作是胡银雷研究的学术基础：陈发来提供数学方法论支撑（稀疏优化、矩阵分解等），瞿昆提供生物学问题域和数据资源（单细胞测序、空间转录组等）。这种"数学+生物"的双导师模式在中国科大的交叉学科培养中具有典型性，也正是胡银雷能够以数学背景切入生物信息学研究的制度保障。

**第二圈层：陈发来课题组（GCL内部）。** 在陈发来课题组中，胡银雷与另一位特任副研究员翟晓雅是同级别的青年科研同事。课题组内的博士后黄炳儒、蔡颖以及多名研究生构成了日常学术研讨和项目协作的微观环境。在更广泛的GCL层面，胡银雷与刘利刚、李新、童伟华、张举勇、傅孝明、郭玉东等教师同属一个学术共同体。2024年12月的"师生面对面"活动是这一共同体最直接的公开体现。不过，从论文署名来看，胡银雷与GCL其他教师之间目前没有直接的合作论文——他的发表记录集中在生物信息学领域，合作者主要来自瞿昆实验室。他与GCL的连接更多体现为方法论同源（稀疏优化、矩阵分解等数学工具在GCL的几何处理研究中同样被广泛使用）和学术共同体归属，而非传统图形学方向的论文合作。陈发来教授本人的研究也包含稀疏优化在几何处理中的应用，这为胡银雷将相同数学工具迁移到生物数据分析提供了方法论根基。

**第三圈层：瞿昆实验室。** 瞿昆实验室是胡银雷研究产出的主要平台。该实验室的教职成员包括瞿昆（教授，PI）、林俊（副教授）、郭闯（副教授）、刘旭（特任副研究员）、胡银雷（特任副研究员）和李守振。实验室规模较大，拥有数十名在读研究生和博士后。胡银雷在实验室中的角色是将数学和计算方法引入生物学数据分析。从论文署名来看，他与实验室的多位成员有密切合作：黎斌（Bin Li，现北京生命科学研究所研究员）是其最重要的合作者之一，在四篇代表性论文中有三篇为共同第一作者；张文（Wen Zhang，现Insilico Medicine）也是多篇论文的合作者。这些合作关系构成了胡银雷在生物信息学领域的核心工作网络。

**第四圈层：跨机构与跨学科合作。** 2024年Nature Methods论文的合作者列表显示，该项目联合了中国科学技术大学生命科学与医学部（瞿昆课题组）、数学科学学院（陈发来课题组）和北京生命科学研究所（黎斌课题组）三个团队。论文作者还包括来自多个单位的研究人员，反映了单细胞多组学基准评估这一研究方向的全国性协作网络。此外，瞿昆实验室的校友网络遍布国际知名机构——包括斯坦福大学（刘年平）、宾夕法尼亚州立大学（广涛·徐）、牛津大学（金丽颖）、芝加哥大学（唐尔婷）等——这些校友虽非胡银雷的直接合作者，但通过实验室网络构成了潜在的学术连接。
