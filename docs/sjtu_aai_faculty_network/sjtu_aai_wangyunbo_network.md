## 二、教育背景与职业履历

王韫博2008年至2012年在西安交通大学完成电气工程与自动化专业本科学习；2012年至2015年在清华大学攻读集成电路工程专业硕士学位；2015年至2020年在清华大学攻读软件工程专业博士学位。

博士期间，他在清华大学软件学院机器学习课题组从事研究，与王建民教授、龙明盛教授合作最为密切——其成名作PredRNN（NeurIPS 2017）、PredRNN++（ICML 2018）、E3D-LSTM（ICLR 2019）、PredRNN-V2（TPAMI 2021）等时空序列预测系列工作均诞生于该团队，并与美国伊利诺伊大学芝加哥分校Philip S. Yu等学者联合署名。其博士学位论文导师的正式姓名公开资料未明确披露，本报告依据论文署名记录其与清华软件学院王建民—龙明盛课题组的紧密归属关系。

2020年，王韫博加入上海交通大学（时属电子信息与电气工程学院计算机系，2024年计算机学院成立后隶属先进人工智能研究所），任长聘教轨助理教授；2024年起晋升长聘教轨副教授。其研究主线为"世界模型"：一方面发展PredRNN系列视频预测与可交互动态场景生成技术（据交大教师页披露已应用于国家气象预报系统）；另一方面围绕有模型强化学习（Iso-Dream、LS-Imagine、VeoRL、CoWorld等）提升具身智能、自动驾驶与开放世界游戏环境中的智能体决策与Sim2Real泛化能力；此外以NeuroFluid为代表发展可微物理模拟与直觉物理推断技术。需要说明的是，公开资料中未见其在图像复原、去雨/去雾等低阶视觉方向上的署名成果，此类方向并非其研究内容。

## 五、业界合作关系深度分析

王韫博的产业关联呈现"成果落地+联合发表"两条线索：

1. **气象领域落地**：据交大教师页，PredRNN系列视频预测技术已应用于国家气象预报系统，提升气象预报精度与时效性。这是其科研成果在国家级行业系统中最明确的落地证据，具体承研项目与合作单位细节公开资料未披露。
2. **工业仿真场景**：NeuroFluid等可微物理模拟技术据官方表述"服务于复杂工业领域，支撑复杂多物理场的机器学习仿真"，具体合作企业公开资料未披露。
3. **联合发表网络**：LS-Imagine（ICLR 2025 Oral）与DisWM（ICCV 2025）论文的作者中包含Xin Jin、Yang Li、Wenjun Zeng等非交大署名作者，其中Wenjun Zeng长期在产业界研究院所与高校任职（曾长期任职微软亚洲研究院）。该类论文通常伴随企业研究团队参与，但相关合作者的具体任职单位在公开页面未逐一披露，本报告不作推定。
4. **具身智能方向**：VeoRL、CoWorld等世界模型迁移学习工作面向具身智能Sim2Real与跨任务泛化，与当前机器人产业的关注高度契合；课题组是否与具体机器人企业建立正式合作，公开资料未披露。
5. 与腾讯、字节跳动、华为等企业的正式横向合作或联合实验室，均未见公开披露。

## 七、Connection圈层总结

王韫博的学术网络以"清华软件学院机器学习组—上交先进人工智能研究所"为主轴：博士期间在王建民—龙明盛课题组完成PredRNN系列奠基性工作，并借E3D-LSTM与Philip S. Yu、李飞飞、Lu Jiang等国际学者建立合作；2020年加入上交后，杨小康成为其论文署名上最高频的资深合作者与所内依托，两人共同署名论文达数十篇。学生层面，Minting Pan、Jiajian Li、Qi Wang、Xiangming Zhu等构成Iso-Dream—LS-Imagine—DisWM一脉的世界模型研究梯队。产业层面，其PredRNN技术的气象预报系统落地是最确凿的应用证据，LS-Imagine等论文中的外部合作者暗示与产业研究力量的联合发表关系但细节未披露。在所内，他与马超、沈为、穆尧、张宇伦等同为同事，但公开合著集中于杨小康一线。总体而言，王韫博是先进人工智能研究所中"世界模型+有模型强化学习"方向的青年骨干，其圈层重心为"清华ML组学术母体+杨小康所内依托+气象/工业场景落地"，与用户预期中"图像复原去雨去雾、与马超合作较多"的画像存在明显出入。
