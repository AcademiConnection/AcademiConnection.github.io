## 二、教育背景与职业履历

高岳本科毕业于美国威斯康星大学麦迪逊分校，获计算机科学与数学双学位；其后曾在医疗软件公司Epic Systems担任软件工程师；随后进入美国康奈尔大学，先后获计算机科学硕士与博士学位（实验室主页about页）。在康奈尔期间，其研究横跨机器学习与认知计算：与计算机系Thorsten Joachims、Yisong Yue合作发表于SIGIR 2010的学习排序研究，与心理学系Shimon Edelman合作关于幸福感与语言表征（"happiness"语料的词嵌入分析）、与时任计算机系教授Michael Coen合作的博弈归纳偏置研究（CogSci等会议），构成其博士时期的学术底色。其确切博士导师公开资料未披露，但从合作网络看，其博士训练与康奈尔计算机系（Joachims组方向的机器学习研究）及心理学系认知科学群体均有密切关联。

约2020年前后，高岳加入上海交通大学，先后任职于自动化系与人工智能研究院（智能机器人教育部重点实验室），为长聘教轨副教授、博士生导师，2021年起招收博士研究生（faculty.sjtu.edu.cn教师页招生信息）；其成果亦见于中国自动化大会2020（CAC 2020）等国内会议。她创立并主持RL2-Lab，聚焦机器人学习与表征学习：早期（2017-2020）与上海交大机器人领域资深教授高峰等合作，将深度强化学习用于人形机器人舞蹈（ICRA 2020）、六足机器人运动（ASIAN MMS 2018）与四足机器人技能（DanceHAT, ICRA 2022），并作为合著者参与Science Robotics 2022年北京冬奥会机器人综述（合作者含杨广中、齐臣坤、李少远等）；中期（2021-2023）发展社交机器人与情感计算方向（节奏性拥抱交互、多层共情框架MHE, TAFFC 2024）；近年（2024-2026）重心转向具身智能与VLA大模型（G1-Bot人形机器人VLA系统、点云流可微采样FlowSF等，与杨小康、卢策吾团队合作），并跨界至AI for Industry（工业信息物理系统故障诊断，Nature Machine Intelligence 2024通讯作者）与认知科学×机器人交叉（发展心理表征启发的模仿学习）。现亦列入计算机学院先进人工智能研究所教师名录（cs.sjtu.edu.cn教师页）。

## 五、业界合作关系深度分析

与典型"学校→企业→学校"路径的学者相比，高岳的产业界面更多以应用导向科研的形式呈现：

1. **Epic Systems（美国医疗软件公司）**：博士前的软件工程师经历，是其唯一的正式企业任职记录（实验室about页）。
2. **机器人应用场景落地**：与高峰团队合作的服务机器人、养老陪护机器人（RA-L 2025老年陪护机器人论文）、物流巡检四足机器人（GATER等）均面向真实产业需求；G1-Bot人形机器人VLA系统对接具身智能产业化浪潮。
3. **工业智能与故障诊断**：Nature Machine Intelligence 2024的工业信息物理系统混合学习故障诊断研究面向智能制造场景，相关成果获WAIC SAIL Top30奖项（2021年）。
4. **产教融合平台**：深度参与上海创智学院建设（该校由上海市与头部AI企业共建的新型学院），并担任上海交大AI-MBA项目学术委员会主任，直接面向产业管理人才培养。
5. **学术团体**：担任上海人工智能技术协会专家委员会委员。

总体看，其业界合作以"科研课题+应用场景+人才培养平台"为主，未检索到与特定企业共建联合实验室或担任企业首席科学家等深度绑定关系；也未检索到IBM Research、微软亚洲研究院的任职记录。

## 七、Connection圈层总结

高岳是先进人工智能研究所中"具身智能+情感计算"双轨并进的青年学者，其关系网络呈三个层次：

**学术血统层**：康奈尔机器学习/认知计算谱系（Joachims、Yisong Yue、Shimon Edelman、Michael Coen），叠加威斯康星麦迪逊本科背景，属于典型的美国精英工科博士路径——但注意，这与提示中"上海交大博士、导师杨小康"的预设不符；杨小康与其为同事兼论文合作者关系，而非师生关系。

**校内平台层**：入交后迅速嵌入交大机器人学科网络——高峰（足式/六足机器人）、杨广中（医疗机器人）、卢策吾（具身智能）、杨小康（AI研究院）四大节点的合作使其成为交大具身智能矩阵中的活跃中间节点；先进人工智能研究所与自动化系的双重身份则横跨计算机与控制两个学科口径。

**应用与人才层**：通过上海创智学院、AI-MBA项目、SAIL奖及工业诊断成果，连接机器人产业与AI管理人才生态；RL2-Lab自主培养的硕士生群体与疑似博士生群体构成其梯队基底。

对建立Connection而言，高岳的最佳切入点是交大具身智能大团队（杨—卢—高—峰体系）中的"青年接口"角色：她同时联通计算机学院、电院自动化系、人工智能研究院与创智学院四个建制，且处于研究方向的快速上升期（2024-2026年密集产出Nature MI、RSS、AAAI等成果）。
