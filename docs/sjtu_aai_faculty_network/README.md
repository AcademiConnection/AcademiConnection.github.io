# 上海交通大学 先进人工智能研究所 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

先进人工智能研究所（Institute of Advanced Artificial Intelligence）是上海交通大学计算机学院下设研究所，所长为杨小康讲席研究员。研究所与上海交通大学人工智能研究院、人工智能教育部重点实验室深度融合：杨小康同时担任人工智能研究院常务副院长和教育部重点实验室主任，马超、沈为、金耀辉等多位教师均以人工智能研究院为主要办公地点（闵行校区软件大楼），形成了"计算机学院建制 + 研究院平台"的双层架构。研究所依托人工智能教育部重点实验室（2018年获批，依托计算机科学与技术国家重点学科建设），是上海交通大学人工智能基础研究与人才培养的核心阵地之一。

研究所教师名录（据计算机学院官网）包括杨小康、马超、沈为、王韫博、张宇伦、穆尧、晏轶超、袁肖赟、高岳、金耀辉、刘满华、董益宏、何黎明、许岩岩、张维夏、郑圣安等，研究方向覆盖计算机视觉与视觉智能、高效人工智能与模型压缩、具身智能与世界模型、数字人与三维视觉（3DGS/NeRF）、计算成像、AI for Science（白玉兰科学大模型、Chemma 化学合成大模型、冷冻电镜）等前沿方向。团队呈现"杨小康—马超"师生双核带动、多名国家优青与海外高层次青年人才汇聚的梯队结构：马超为杨小康指导的博士毕业生（留所任教并获国家优青），晏轶超亦为杨小康博士毕业生（IIAI 博士后后回所任教），王韫博、沈为、张宇伦、袁肖赟、穆尧等则为外引型青年人才，分别来自清华、华中科大、美国东北大学、香港科技大学、香港大学等不同学术血统。产学研触达联想（交大—联想 AI 联合实验室）、华为（AI for Science 布局、优秀技术成果奖）、上汽零束（联合研发中心）、vivo、京东、拙河科技等企业。

## 圈层结构概述

先进人工智能研究所的学术网络以杨小康（IEEE Fellow、国家杰青、长江学者特聘教授）为组织核心。谱系上，杨小康的博士导师未见官方披露，但其团队形成了两条内部传承线：一是马超（交大博士，联培导师 UC Merced 的 Ming-Hsuan Yang）代表的"视觉智能"主线，二是晏轶超（杨小康博士毕业生）代表的"数字人与三维视觉"主线，两人均在海外博士后历练后回所任教，构成"博士—海外博后—回所任教"的传承闭环。外引型教师带来多元学术血统：王韫博（清华软件学院 PredRNN 系列作者）、沈为（华中科大白翔/屠卓文一系、JHU Alan Yuille 团队）、张宇伦（美国东北大学、ETH 博士后）、袁肖赟（HKUST、清华方璐 Sigma Lab 博士后）、穆尧（香港大学罗平团队、EmbodiedGPT 一作）、高岳（康奈尔大学）、金耀辉（中科大物理硕士、交大博士、Bell Labs 研究员），使得研究所成为多个国际学术谱系在交大的汇流点。合作网络以杨小康为最高频合著枢纽（与王韫博数十篇合著、与沈为长期合著），并外联清华（梅宏院士团队 AI for Science、方璐/戴琼海系计算成像）、北大、华为系研究者（田奇、谢凌曦）、UC Merced、Caltech（Lihong V. Wang）等节点；产业层面通过联想、华为、上汽零束、vivo、京东、拙河科技、通达海（法律AI）等企业合作实现技术落地，并与校内 MVIG（卢策吾）、X-LANCE（俞凯）等团队在具身智能、语音语言方向形成互补。
