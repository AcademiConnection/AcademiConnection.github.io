## 二、教育背景与职业履历

张宇伦本科毕业于西安电子科技大学电子工程学院（2009年9月至2013年7月），随后在清华大学自动化系攻读硕士学位（2014年9月至2017年7月），硕士期间及前后在清华大学自动化系担任研究助理（2014年3月至2017年7月），并先后在中科院深圳先进技术研究院（2016年11月至2017年6月）、悉尼大学（2016年1月至2016年6月）、南洋理工大学（2015年11月至2016年1月）进行访问研究。

2017年9月，他赴美国东北大学（Northeastern University，波士顿）电气与计算机工程系攻读博士，2021年8月获博士学位，博士论文题目为《Deep Convolutional Neural Network for Image Restoration and Synthesis》。博士期间曾于哈佛大学担任研究实习员（2020年5月至2020年8月），并两次在Adobe Research实习（2018年、2019年）。需要说明的是，其官方页面未明确披露博士导师姓名；从公开合作署名看，他在东北大学期间与该校SMILE实验室的Yun Fu（傅彧）教授及Chenliang Xu长期持续合作发表多篇论文（如ICCV 2019的Attention Bridging Network、TNNLS及视频超分TDAN等），学界一般据此推断其博士训练在Yun Fu团队完成，但正式的导师关系属公开资料未明确披露范畴，本报告仅作合作谱系描述。

2021年10月至2024年2月，他在苏黎世联邦理工学院（ETH Zürich）计算机视觉实验室（CVL）从事博士后研究，合作者为Fisher Yu、Martin Danelljan等。2024年3月，他加入上海交通大学计算机学院先进人工智能研究所，任长聘教轨副教授、博士生导师至今。授课包括ISE3318计算机视觉（2025春）、CS0502（2025秋）、AI1003（2025秋）。

### 4.4 代表性研究成果与合作节点

- **RDN / RCAN图像超分辨率系列**：形成其早期图像复原代表作，是东北大学博士阶段深度卷积图像复原研究的主要成果脉络。
- **TDAN视频超分辨率**：与Yun Fu、Chenliang Xu等共同署名，直接对应东北大学阶段的核心合作网络。
- **CORUN（NeurIPS 2024）**：将深度展开思想用于去雾，与深圳大学何春明合作，体现其在可解释模型设计与生成复原间的结合。
- **HiT-SR（ECCV 2024 Oral）**：高效图像超分辨率代表工作，延续图像复原主线。
- **Reti-Diff（ICLR 2025）**：面向视网膜图像复原，连接深圳大学何春明与杜克大学Sina Farsiu团队。
- **FluxSR、PassionSR、OSDFace、OSDHuman（2025）**：围绕一步扩散与快速生成式复原，展示从传统复原到高效生成模型的转向。
- **Flexible Residual Binarization（ICML 2024）**：与秦浩通、刘祥龙等合作，是模型二值化方向的重要节点。
- **ARB-LLM（ICLR 2025）**：通过任意精度二值化面向大语言模型部署；闫相龙为共同第一作者，构成直接学生培养与论文合作交点。
- **PBS2P、PT²-LLM**：分别聚焦渐进二值化和大模型三值化，构成低比特LLM系列研究。
- **2DQuant、CondiQuant、AdaSVD、ReCalKV、DVD-Quant、QuantCache**：面向量化、KV缓存和推理效率的多条技术支线，合作成员涵盖上海交大、北航等机构。
- **BI-DiffSR（NeurIPS 2024）、BiMaCoSR（ICML 2025）**：将二值化/低比特思路延伸到扩散式超分辨率，连接其两条主要研究主线。

上述成果的论文题目、作者和发表信息以[个人主页论文列表](https://yulunzhang.com/)及各论文公开页为准。"BiLLM"系列工作未见张宇伦的署名记录，故未列入其代表作。

## 五、业界合作关系深度分析

张宇伦个人主页明确列出的研究资助方包括：**华为、vivo、联想、Adobe、芒果TV（MangoTV）、美团、传音、腾讯、荣耀、OPPO、小米**，以及国家自然科学基金（NSFC）。其产业合作呈现"手机/终端厂商密集+互联网大厂+海外研究机构"的特征，与其低比特量化、高效扩散模型研究方向高度契合——终端侧大模型部署是上述厂商的共同需求。

历史渊源方面，他博士期间曾两度在Adobe Research实习，为其保留了Adobe这一长期产业合作渠道。其量化压缩成果（如ARB-LLM、PT²-LLM等大语言模型二值化/三值化工作）对终端厂商的端侧LLM部署具有直接工程价值，这也是其获得多家手机厂商联合资助的主要原因。从合作强度看，公开信息以资助关系为主，未见其在校企联合实验室担任主任等更深度绑定角色的公开披露。

## 七、Connection圈层总结

张宇伦的学术网络可分为四层：第一圈层为**博士训练与合作核心**——东北大学Yun Fu团队（公开合作密集，正式导师关系未披露）与ETH Zürich博士后团队（Fisher Yu、Martin Danelljan等），这奠定了其图像复原与高效AI的双重研究底色；第二圈层为**现单位依托**——以杨小康为核心的上海交大先进人工智能研究所，以及孔令和、陈贵海等系统方向合作者，是其入职后（2024年3月起）论文产出的主要平台；第三圈层为**国内跨校固定合作**——北航刘祥龙/秦浩通（量化二值化）、深圳大学何春明（图像复原），均已形成多年持续合作；第四圈层为**产业圈**——以华为、OPPO、vivo、小米、腾讯、美团、Adobe等为代表的资助方网络。其学生培养刚起步，闫相龙（挑战杯特等奖、ICLR共同一作、国自然本科生项目）是公开信息中最亮眼的直接指导学生。
