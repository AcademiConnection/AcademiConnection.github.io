# 上海交通大学 先进网络研究所 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

先进网络研究所（Advanced Networking Research Institute）是上海交通大学计算机学院下设研究所，现任所长为陈贵海特聘教授（IEEE Fellow、CCF会士），副所长为孔令和教授（IEEE Fellow 2026届、长江特聘）。研究所现有教师17名（含国家级人才计划入选者3位、国家青年人才计划入选者7位），聚焦计算机网络、移动计算与边缘智能、数据科学与智能运维四大方向，产出了 MobiCom、SIGCOMM、INFOCOM 级别的持续成果，并与中国电信、阿里、华为、腾讯保持深度产学研合作（华为全国重点实验室、CCF-华为创新研究计划、CCF-腾讯犀牛鸟基金等）。

研究所的学术血脉呈现"南京大学网络学派南迁"的鲜明特征：陈贵海长期执教南京大学（LANDS 组），加盟交大后与高晓沨（UT Dallas 博士，与陈贵海十余年最紧密论文搭档）、吴帆（南大本科/布法罗博士，现计算机学院常务副院长、杰青）、孔令和（西电/法国国立电信/交大博士，长江特聘）、朱燕民（港科大博士，长聘教授、教务处副处长）、傅洛伊（本硕博交大、优青，王新兵团队核心）等共同构成两代协作网络。教师谱系中另有唐飞龙、郑臻哲等以名单级记录（郑臻哲为国家优青、CCF优博，与吴帆长期联合署名，见吴帆报告）；黄维然双重归属本所与清源研究院，另有独立报告（见 [sjtu_qingyuan_faculty_network](../sjtu_qingyuan_faculty_network/)）。所内与电院电子工程系的王新兵团队（傅洛伊、朱燕民的学术母体）、计算机学院其他研究所之间存在密切的跨建制合作。

## 圈层结构概述

研究所网络以陈贵海为组织与学术双枢纽：其"一纵一横"结构中，纵向是南京大学 LANDS 组谱系（戴海鹏等南大博士构成宁沪人才输送带，与高晓沨联合指导的陈涛、王斐等构成交大支线），横向是群智感知与数据中心网络的稳定合作集团（高晓沨、吴帆、Shaojie Tang、李向阳、中科大等）。吴帆（杰青、常务副院长）是所内行政权柄与科研产能的双料枢纽，其团队疑似培养出郑臻哲（优青、CCF优博）、李钦雅等两代研究者；孔令和的"博士—留校"路径（黄俊钦2024博士毕业留任助理研究员）则代表本土传承闭环。傅洛伊与朱燕民共同锚定王新兵（电院电子工程系、霍普克罗夫特中心首任执行主任）的无线网络理论母体团队——该团队还延伸出米哈游创始人刘伟等产业人物。国际网络方面，UT Dallas（Shaojie Tang）、TAMU（P. R. Kumar）、Cornell（John Hopcroft）、罗格斯（Yingying Chen）、中科大（李向阳）与 SUTD/麦吉尔/哥伦比亚（孔令和博后）等节点构成外环。需要澄清的边界：陈贵海非 ACM Fellow、非清华教授；吴帆非 ACM 班出身、非陈贵海博士生；高晓沨非陈贵海博士生、人才称号为青年长江（非优青）；本所历史上无"高晓峰"其人，相关记载均应统一为高晓沨。
