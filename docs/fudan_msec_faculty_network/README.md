# 复旦大学多媒体智能安全实验室学术关系网络报告

## 团队简介

复旦大学多媒体智能安全实验室（多媒体安全实验室）由张新鹏教授与钱振兴教授共同创建于2019年前后，是复旦计算与智能创新学院在多媒体安全、数字内容安全方向的代表团队。团队根植于上海大学信息隐藏学派：王朔中教授开创的上海大学信息隐藏研究传统，经张新鹏（2004年上海大学博士、2008年33岁破格晋升教授、2016年国家杰青）与钱振兴（中国科学技术大学博士、上海大学时期约十年）两代学者发展壮大，2019年钱振兴正式全职入职复旦、2020年前后张新鹏亦以复旦教授身份开展研究（2025年起兼任上海大学计算机工程与科学学院院长，呈上大院长+复旦教授双聘格局），团队整体在复旦落地。

团队研究覆盖信息隐藏（构造式隐写）、数字水印与版权保护（免疫图像、AIGC 潜空间水印 GenPTW）、图像与多媒体取证（AIGC 虚假内容检测）、密文域信号处理、神经网络模型安全等方向，直接对接《人工智能生成合成内容标识办法》施行后的 AIGC 内容治理国家需求。团队依托"数字文化保护与旅游数据智能计算"文化和旅游部重点实验室（张新鹏任主任，钱振兴任副主任），承担国家重点研发计划项目"数字文创资产权属管理及服务网络"（2023-2026）等重大任务。

本报告聚焦两位核心教师：张新鹏（团队学术带头人，国家杰青，爱思唯尔中国高被引学者连续十二年、2020全球高被引科学家）与钱振兴（实验室共建者，国家高层次人才计划入选者，文旅部重点实验室副主任、曾任原计算机学院院长助理，上海市自然科学奖一等奖获得者）。

## 研究方向与圈层结构

团队学术网络呈四层结构。第一圈层是上海大学信息隐藏谱系：王朔中（上海大学信息隐藏开创者）—张新鹏—钱振兴构成"开创者—两代传人"的师承与合作链条，张新鹏与钱振兴为平级共建关系而非师生关系；同代网络包括中国科学技术大学张卫明（信息隐藏与AI安全）、北京交通大学李晓龙（多媒体内容安全）、同济大学秦川等"多媒体安全共同体"学者。第二圈层是复旦校内网络：依托计算与智能创新学院（现任院长汪源源、执行院长杨珉、党委书记王新，详见 fudan_secsys、fudan_sonic 报告）与文旅部重点实验室（副主任颜波、孙云龙），与学院视觉与学习实验室（FVL）在 AIGC 内容治理方向形成呼应。第三圈层是国际网络：张新鹏长期担任 IEEE TIFS 编委/资深编委、ACM IH&MMSec 与 IEEE WIFS 等信息隐藏旗舰会议主席，与德国康斯坦茨大学（洪堡学者时期）、美国宾汉顿分校等保持联系。第四圈层是产业网络：与蚂蚁集团联合发表 AAAI 2026 GenPTW 潜空间水印；数字水印确权成果应用于国务院文旅部、凤凰传媒、新华传媒、上海文广等单位；数字文创资产平台成果对接江苏"国文数资"、中国文化传媒集团新文创 IP 平台；学生创业代表甘振良创办墨隐钤印（数字钤印/水印公司，获150万元种子轮融资）。

## 产业转化亮点

团队是"AIGC 内容安全国家治理"的典型学术供给方：张新鹏作为首席科学家的国家重点研发计划项目直接面向数字文创资产权属管理，其技术方案覆盖确权、溯源、篡改定位全链条；钱振兴的水印技术已在文旅与传媒产业规模化应用，获上海市自然科学奖一等奖与中国产学研合作创新成果奖；在《人工智能生成合成内容标识办法》2025年9月施行后，团队的 GenPTW、AIGC 检测综述等成果为行业提供了"谁生成、是否被篡改、篡改何处"的核心技术答案，是学术界回应国家 AIGC 治理需求的标杆样本。
