## 全团队关系网络的整体观察

PASA是南大大数据方向的"系统+落地"型实验室，其网络结构以黄宜华为恒星：与袁春风合作86次、与朱光辉43次、与顾荣52次，构成本科教学（袁春风长期承担系统基础课）—系统研究—学生扩散的三重纽带。实验室2009年创立以来经历了从HBase/Spark/MapReduce系统优化（2009-2016）到AutoML与图学习（2021-2023）、再到大模型微调与推理（2024-2026）的完整方向迭代；其"以赛促研"的产学研模式（NeurIPS 2019 AutoDL冠军、KDD Cup 2020 AutoGraph赛道亚军、PASA-AutoML平台获"互联网+"国赛金奖）与华为、Intel、奇虎360、中电科等企业的横向合作构成产业通道。黄宜华2019年创办的江苏鸿程研究院（2026年7月更名为江苏鸿程数据智能研究院）是学界-产业转化的直接载体。朱光辉作为2020届博士（导师黄宜华）留组接班，延续代际传承；顾荣毕业后转入LANDS（陈贵海组），使PASA与LANDS两个研究组之间形成师生桥接——这一记载与LANDS报告完全一致。

本目录的一个重要消歧成果：袁春风的DBLP档案（pid 47/2506）混入了中科院自动化所NLPR同名学者（与胡卫明合作的约104篇CV论文），两条线零重叠，报告已按机构严格拆分统计。
