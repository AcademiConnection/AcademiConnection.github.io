## 一、基本信息与学术履历

孟洛明，男，1955年5月生，北京邮电大学教授、博士生导师。网络与交换技术全国重点实验室网络管理研究中心学术带头人。北京邮电大学教师主页系统显示其当前在职状态为"离退休"。

### 1.1 学术荣誉

- 2000年：国家杰出青年科学基金获得者
- 入选百千万人才工程国家级人选
- 国家自然科学基金创新研究群体带头人
- 国家973计划项目首席科学家
- 国家级有突出贡献的中青年专家
- 2017年：中国工程院信息与电子工程学部院士增选有效候选人

### 1.2 主要学术成果概览

孟洛明自20世纪90年代初起率先在国内开展系统化的网络管理研究，作为项目负责人主持完成10余项国家级重大项目。主要成果包括：获国家科技进步奖二等奖2次、省部级科技进步一等奖5次；研究成果被完整采纳为7项国际标准；3次应邀在国际会议作大会特邀报告（Keynote Speech）。其研究领域为网络管理及通信软件，聚焦网络和数据管理、网络服务管理方向。

### 1.3 所属团队概况

网络管理研究中心是网络与交换技术全国重点实验室和链网融合技术教育部工程研究中心的主要承建单位之一。中心专业从事网络和数据管理研究，现有教师18人（教授6人、副教授11人、讲师1人），含博士生导师14人、硕士生导师18人。中心拥有杰青获得者1人、百千万人才工程国家级人选1人、优青获得者1人、跨世纪/新世纪人才计划获得者5人、973项目首席科学家1人。现有在读硕士、博士研究生210余人。

中心领导架构：

中心主要科研方向为网络智能管控与通信软件，聚焦于网络智能管控理论与关键技术、数据管理与服务技术、产业互联网应用技术三个层面。中心人员包括：孟洛明、亓峰、邱雪松、李文璟、高志鹏、陈兴渝、熊翱、芮兰兰、王颖、杨杨、王智立、刘会永、喻鹏、郭少勇、丰雷、邵苏杰、徐思雅等18位教师。

## 五、国家级项目与重要科研成果

### 5.1 国家973计划项目——"可测可控可管的IP网的基础研究"

孟洛明是国家973计划项目"可测可控可管的IP网的基础研究"的首席科学家。该项目是21世纪初中国网络基础研究领域的重要国家级项目，围绕IP网络的可测量性、可控制性和可管理性开展基础理论研究。

据公开报道，当时国家973计划有三个与网络体系结构相关的项目：清华大学吴建平教授主持的基于IPv6的演进性网络体系结构研究、另一项目（被描述为革命性体系结构研究），以及孟洛明主持的"可测可控可管的IP网的基础研究"。该项目体现了孟洛明在网络管理基础理论方面的学术定位——不追求网络体系结构本身的演进或革命，而是聚焦于网络的可测、可控、可管这一管理维度的基本科学问题。

此外，孟洛明还主持了包括国家自然科学基金创新研究群体项目和国防预研项目在内的一批重点课题，以及国家自然科学基金项目"通信网的网络理论和技术"（2012—2014）等。中心整体承担了包括973项目、863计划项目、国家科技攻关（科技支撑）项目、国家重点研发计划项目（课题）、国家自然科学基金重点项目等在内的百余项国家级重大重点项目。

### 5.2 国家科技进步奖与重大科研奖励

## 六、运营商与企业合作

### 6.1 北京市天元网络技术股份有限公司（天元网络）

北京市天元网络技术股份有限公司成立于1998年，是一家专注于通信网络运营支撑系统（OSS）软件平台及应用的研发、生产和销售的企业。该公司由北京邮电大学孵化，其网络管理研究中心与公司形成了产学研良性循环。孟洛明担任该公司董事长。

**技术与产品：** 公司提供覆盖技术攻关、标准制定、产品研发、工程实施等环节的网络运营支撑整体解决方案。基于自主掌握的核心技术，研发出100余种产品，25次入选国家级和省部级新产品计划。主导和主要参与了十余项ITU-T国际标准的制定工作。

**市场应用：** 公司网络管理与运营支撑系统产品在国内电信运营商中广泛应用。传输网综合网管系统市场占有率国内第一，移动网综合网管系统市场占有率国内第二。产品出口至马来西亚、香港、台湾等国家和地区。境内客户分布在中国联通、中国电信、中国移动等电信运营企业和电力、军队、政府、铁路、石油等行业。

**科研获奖：** 公司获省部级以上科技奖励近20项，其中2004年获国家科学技术进步奖二等奖，2007年获中国标准创新贡献奖一等奖。

**资本运作：** 2014年，神州泰岳以4.4亿元收购天元网络100%股权。

### 6.2 电信运营商合作

孟洛明及其团队的研究成果在中国运营商网络、各类专网和海外运营商网络中得到了广泛应用。中心承担了多项优质企事业委托项目，与国内三大运营商（中国移动、中国电信、中国联通）建立了长期合作关系。

在标准化领域，孟洛明担任中国通信标准化协会网络管理与运营支撑技术工作委员会主席，负责制定和参与起草了一系列通信行业标准和运营商企业标准。李文璟作为WG1工作组组长，负责制定和参与起草了一系列通信行业标准和国内各大运营商的企业标准。中心参与3GPP标准制定工作，主持制定了3GPP TS 32.742~32.745等四项3GPP标准。

### 6.3 产学研转化模式

孟洛明团队形成了"基础研究—技术攻关—标准制定—产品研发—工程实施"的完整产学研链条。天元网络作为产学研转化的核心载体，将北邮网络管理研究中心的基础理论和技术成果转化为商用OSS产品，服务于运营商和行业专网客户。第三代移动通信网管系统研究开发成果（主要完成人包括邱雪松、詹志强、孟洛明、李文璟、陈兴渝、芮兰兰、熊翱、亓峰、雷振、陈颖慧、刘星、王智立，合作单位为北京市天元网络技术有限公司）是这一转化模式的典型案例。

中心目前将研究范围拓展至产业互联网应用技术，涵盖能源电力、智能制造、文化计算、元宇宙等行业数字化技术，在能源电力、智能制造、文化数字化等行业开展了示范应用。
