## 二、教育背景与职业履历

李文璟的公开教师档案可确认其已获博士学位、毕业于北京邮电大学，现为教授并招收博士、硕士研究生。[1] 截至本报告检索时，学校公开主页未列出其本科、硕士、博士的起止年份、专业、博士论文题目或任职年表，因此不对这些细节作推断。

孟洛明与李文璟之间存在有文献直接支持的**导师—研究生阶段学术引导关系**：李文璟在中国通信标准化协会刊载的自述中写道，1996年她作为北邮网络管理研究方向研究生，在孟洛明安排和指导下参与接入网V5管理技术规范制定；该工作形成其首项标准化成果YD/T 1101—2001《用户接入网网络管理接口规范—V5管理与通用部分》。[4] 因此，可将孟洛明界定为其进入网络管理与信息通信标准化领域的导师/领路人。**但该报道并未逐字说明“孟洛明是其博士学位论文导师”，故本报告不将此作为已核实的博士导师事实。**

其可核验的职业轨迹主要体现为在北邮网络管理研究中心持续开展网络管理、无线网络管理和标准化工作，并承担中心主任职责。[1][2][3] 公开项目页登记了29项科研项目（含已结项条目），其中可辨识方向包括无线云网络资源协同管理、CDMA网络管理接口与网络优化、智能光网络资源调度等；项目页面缺乏完整的角色、经费及合作单位字段，故只作为研究活动线索使用。[6]

## 四、学术合作网络

### 4.1 导师与学术谱系：孟洛明

孟洛明是中心学术带头人，李文璟是中心主任，二者构成该中心公开可见的“学术带头人—组织负责人”核心结构。[2] 更强的关系证据来自李文璟本人关于1996年研究生阶段受孟洛明指导参与V5管理标准的回顾。[4] 因而，孟洛明应置于李文璟学术网络的第一圈层：其连接作用不仅是院内组织关系，更是网络管理标准化方法与议题的早期学术传承。

论文题录亦提供共同署名证据。2021年发表于 *Journal of Network and Computer Applications* 的“Smart network maintenance in edge cloud computing environment: An allocation mechanism based on comprehensive reputation and regional prediction model”署名包含李文璟与孟洛明，并同时包含邱雪松、芮兰兰、高志鹏等作者。[9] 这表明上述关系至少延续到网络智能运维/边缘云任务分配研究；不能仅凭单篇论文推导完整合作频次或项目主从关系。

### 4.2 中心内部协作：邱雪松、芮兰兰、亓峰、郭少勇

网络管理研究中心官网将孟洛明、亓峰、邱雪松、李文璟、芮兰兰、郭少勇等列为中心人员，并明确郭少勇担任中心党支部书记。[2][5] 这确认了五人与李文璟处于同一中心组织网络，但组织共属不等同于论文合著。

在可直接检索到的论文中，芮兰兰、邱雪松、李文璟、孟洛明共同署名2011年《北京邮电大学学报》论文《面向移动自组织网络的自主管理架构及应用》。论文围绕移动自组织网络的自主管理架构、负载均衡与管理节点协作展开，构成李文璟与邱雪松、芮兰兰在自主网络管理方向的明确合作证据。[10] 2021年边缘云网络维护论文再次同时出现李文璟、邱雪松、芮兰兰及孟洛明，显示该合作线索跨越传统自主管理与智能化运维场景。[9]

对亓峰和郭少勇，本次公开检索确认了其中心同事身份，但未获得足以稳妥引用的、由李文璟与二人共同署名的代表性论文或共同项目原始记录。因此将二人列为**组织近邻/潜在合作节点**，不标注为已核实的直接论文合作者。

### 4.3 研究主题、项目与标准化的跨界连接

李文璟的合作网络以“网络管理—移动通信—标准化”三条链路交织：

1. **国家科研链路。** 实验室简介确认其主持或完成国家重大科技专项、863课题、国家自然科学基金等国家级科研项目。[3] 可公开辨识的项目包括国家“十五”重大科技专项“第三代移动通信网关键技术标准研究”（2002BA906A05）、863项目“未来网络测量与管理技术”（2013AA013502）、自然科学基金“基于自主管理的LTE无线接入网节能机制和算法研究”（61271187），以及“基于毫米波空中基站的5G网络容量自主增强机制与算法”（61971053）。项目名称与编号来自聚合导师信息页，适合作为检索线索，具体主持身份、参与者及结题信息宜以科技主管部门原始库复核。[11]
2. **标准化链路。** 从V5管理标准起步，公开简介称其主持和参与编写多项ITU-T、3GPP国际标准及二十余项国家通信行业标准。[3] 协会报道确认其在CCSA平台叙述这一经历，体现其连接高校研究、运营商/设备商技术需求与国内外标准组织的枢纽角色。[4]
3. **研究共同体链路。** 共同论文展示的高志鹏、邱雪松、芮兰兰、孟洛明等节点，围绕自主管理、边缘云与智能维护形成主题交集。[9][10] 现有公开检索不足以严谨计算各节点合作篇数、通讯作者关系或完整共著图谱，故未给出虚假的量化排名。

## 五、业界合作关系深度分析

### 5.1 运营商、标准组织与行业标准接口

最具一手支持的产业连接是标准化工作，而非未经披露的企业合同。李文璟任CCSA网络管理与运营支撑技术工作委员会WG1工作组组长。[3] 她的协会自述表明，其早期V5管理标准经网络管理标准化工作组讨论、评审并发布为YD/T 1101—2001；此后长期参与信息通信标准化。[4] 因此可以谨慎判断：她通过CCSA、行业标准及ITU-T/3GPP标准工作，处在高校研究与通信运营、设备制造及行业治理之间的制度化接口。

公开简介还称其参与或主持国内各大运营商企业标准、并参与ITU-T和3GPP标准；但没有披露每家运营商名称、项目合同、实施时间和个人角色。[3] 本报告不将这些概述扩展成对中国移动、中国电信、中国联通任一具体合作项目的断言。

### 5.2 企业合作与成果转化：证据边界

中心官方页介绍其科研和标准化覆盖应用基础理论、共性技术、工程应用三个层次，但未按教师披露企业合作清单。[2] 其他公开的中心介绍材料提及中心与华为、中兴、国家电网等开展相关技术研发，也提到网络管理系统应用于天元网络MetaView系列产品；这属于**中心层面**信息，不能证明李文璟本人对某一合同、产品或企业项目的直接负责人/完成人身份。[12]

因此，李文璟的业界关系可稳妥描述为：以通信网络管理标准化和国家级项目为主轴，具有面向运营商企业标准和国际标准组织的公开工作记录；对于华为、中兴、国家电网、天元网络等具体企业，仅能作为其所在中心的合作生态背景，需待项目合同、专利实施、获奖证书或企业/学校联合公告交叉核验后，方可纳入个人直接合作网络。

## 七、Connection圈层总结

**第一圈层：学术传承与中心领导。** 孟洛明既是中心学术带头人，又在李文璟1996年研究生阶段引导其进入网络管理标准化；这一关系有本人回顾和组织信息双重支持。[2][4] 李文璟作为中心主任，将该传承延伸到网络智能管理、无线网络管理与标准化组织工作。

**第二圈层：可验证的同主题合著者。** 邱雪松、芮兰兰与孟洛明在2011年自主管理网络论文及2021年智能网络维护论文中均与李文璟共同署名，是当前检索中证据最明确的院内研究协作节点；高志鹏出现在2021年论文的协作集合中。[9][10]

**第三圈层：中心组织近邻。** 亓峰、郭少勇等与李文璟同列中心人员，郭少勇另任中心党支部书记。[2][5] 该层应理解为高概率的日常学术组织联系，而非已证明的直接论文或项目合作。

**第四圈层：行业与标准化生态。** CCSA WG1、ITU-T、3GPP、国家通信行业标准以及运营商企业标准构成其从科研到工程治理的外部连接通道。[3][4] 现阶段证据足以说明其标准化枢纽角色，但不足以对具体运营商或设备商建立个人合作强度排序。

总体而言，李文璟的关系网络呈现“孟洛明指导的网络管理学术谱系—北邮网络管理研究中心协同—移动通信与智能运维课题—国内外标准化平台”的递进结构。最可靠的网络边是导师引导、中心共属、两篇明确共同署名论文和CCSA标准化职务；未披露的博士论文导师、学生培养层次、企业合同及奖项排序均应保留待核状态。
