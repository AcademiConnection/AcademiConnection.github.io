# 北京邮电大学 网络与交换技术全国重点实验室 教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

网络与交换技术全国重点实验室（State Key Laboratory of Networking and Switching Technology，SKLNST，官网 [sklnst.bupt.edu.cn](https://sklnst.bupt.edu.cn/)）是北京邮电大学依托信息与通信工程、计算机科学与技术两个国家一级学科建设的国家级科研平台，前身为程控交换技术与通信网国家重点实验室。实验室以张平院士为主任，邱雪松教授、王尚广教授为副主任，下设网络管理研究中心、网络智能研究中心、网络信息安全研究中心等子机构，覆盖移动通信与无线网络、网络管理与业务智能、服务计算与交换技术、网络安全与密码学四大研究方向，形成"通信+网络+安全"全栈学科布局。

实验室的历史脉络可追溯至陈俊亮院士、周炯槃院士开创的北邮程控交换与智能网学派，由杨放春、廖建新、孟洛明等第二代学者在智能业务网络、网络管理标准化、服务计算等方向继承发展，第三代张平院士则将研究前沿拓展至 TDD 4G/5G/6G 移动通信系统并建成国家创新研究群体。实验室拥有杰青、优青、百千万人才工程国家级人选、973首席科学家等多层次人才队伍，教师80余人，在读硕博研究生数百人，是国家移动通信与网络交换技术领域最主要的人才培养与技术创新基地之一。

实验室在科研奖励方面成果卓著：张平院士获国家科学技术进步奖特等奖1项、一等奖1项、国家技术发明奖二等奖2项及国家科技进步二等奖2项；廖建新教授3次获国家科技进步二等奖；孟洛明教授获国家科技进步二等奖；邱雪松教授2次获国家科技进步二等奖。多项技术成果形成 ITU-T 国际标准（17项以上）和行业标准（18项以上），在中国运营商网络、各类专网和海外运营商网络中得到广泛应用。

## 研究方向与圈层结构概述

实验室呈现"三代传承、多中心并行"的学术谱系结构。第一代源头是陈俊亮院士（中科院院士）和周炯槃院士（工程院院士）开创的北邮程控交换与智能网学派。第二代学者沿三条主线分化：杨放春（2001年国家杰青）继承陈俊亮的智能网方向，延伸至车联网与融合网络，创建计算机通信国家级教学团队；廖建新师从李乐民和陈俊亮双院士，开辟智能业务网络系统方向，3次获国家科技进步二等奖；孟洛明在网络管理标准化方向深耕，作为973首席科学家建立了ITU-T国际标准体系，培养出邱雪松（实验室副主任）、李文璟（网络管理研究中心主任）等第三代学术力量。第三代张平院士则开辟了全新的移动通信主线，作为TDD 4G/5G技术路线的核心验证者获国家科技进步特等奖，带领国家创新研究群体并向6G前沿拓展；彭木根（副校长、IEEE Fellow、杰青）作为张平团队的核心成员，将研究延伸至5G异构网络与智能超表面（RIS），并进入校级管理层。

行政与组织层面，实验室现任领导层为张平（主任）、邱雪松（副主任、图书馆馆长）、王尚广（副主任、优青）。王尚广在服务计算与5G边缘计算方向开辟新线，任CCF服务计算专委会秘书长；其博士导师经报告交叉验证否定廖建新而推定为杨放春，体现了实验室内部跨中心的谱系交织。网络管理研究中心由孟洛明（学术带头人）—李文璟（主任）—邱雪松/亓峰/芮兰兰/郭少勇组成稳定的核心团队，拥有18名教师和210余名在读研究生。

## 产业转化亮点

实验室的产业转化以"国家标准战略+运营商规模部署+企业产品化"三位一体为特征。张平院士团队研制的TDD 4G试验系统验证了我国4G技术路线的可行性，相关成果在大唐电信、中国移动等企业产业化，为TD-LTE成为国际主流标准做出了基础性贡献，获国家科技进步特等奖。孟洛明—邱雪松团队的网络管理技术成果形成17项ITU-T国际标准和18项行业标准，在中国三大运营商网络、各类专网和海外运营商网络中得到广泛应用，孵化了天元网络MetaView系列产品。杨放春创立中国车联网产业技术创新联盟并任理事长，推动智能网与车联网技术在汽车产业落地。廖建新的智能业务网络关键技术形成3项国家科技进步二等奖成果，在东信北邮（产学研实体）等实现产业化。彭木根团队与华为、中兴在5G/6G方向持续合作。实验室整体构成了北邮信息通信学科与国家信息基础设施战略最紧密的接口。
