# 中国科学技术大学 MIRA Lab（王杰教授团队）学术关系网络报告

## 团队简介

MIRA Lab（Machine Intelligence Research and Applications）是中国科学技术大学信息学院电子工程与信息科学系王杰教授创立并领导的机器学习实验室，依托"脑启发智能感知与认知"教育部重点实验室。实验室"立足于严谨的理论研究，着眼于复杂场景下的落地应用"，研究方向覆盖三大板块：图机器学习（图基础模型、知识图谱、科学智能应用）、大语言模型（智能体、高效推理、复杂推理能力增强）、决策系统（AI辅助芯片设计AI4EDA、组合优化、自动驾驶）。

王杰教授现任中科大教授、博导，少年班学院副院长（挂职），"脑启发智能感知与认知"教育部重点实验室副主任，国家创新人才计划青年特聘专家（2017）、国家优青（2018）、IEEE Senior Member、CCF杰出会员，曾任美国密歇根大学研究助理教授。团队在 NeurIPS/ICML/ICLR 等顶会发文近百篇，近三年八次受邀作 Spotlight/Oral 报告；获斯坦福 OGB 大规模图学习挑战赛全球第一、连续两年 ACM KDD Cup 全球高校团队第一、中国电子学会自然科学一等奖，并三次获得华为火花奖。

## 研究方向与圈层结构概述

王杰的学术网络呈"美国训练—中科大建制—华为产研同盟"三段式结构。教育线：中科大电子科学与技术系学士（2005）→佛罗里达州立大学计算科学博士（2011）→亚利桑那州立大学博士后（与叶杰平等合作稀疏学习与大规模优化，2012-2015）→密歇根大学研究助理教授（2015-2017）；2017年通过国家人才计划回中科大创立 MIRA Lab。学术合作圈涵盖清华李建民/微软亚洲研究院等图学习共同体，以及 OGB/KDD Cup 国际竞赛社区。学生培养方面，实验室形成了从本科生（白寅岐，2023年国家自然科学基金青年学生项目——基于图机器学习的大规模逻辑电路高效综合）到博士生的完整梯队，毕业生进入华为等企业与高校任职。

## 产业转化亮点

MIRA Lab 与华为诺亚方舟实验室形成了罕见的深度产研同盟：ICLR 2025 联合提出基于神经符号函数挖掘的高效逻辑优化方法（EDA芯片设计效率提升最高2.5倍），TPAMI 2024 联合提出分层序列/集合模型使 MILP 数学规划求解器获得最高3倍无损提速（成果进入华为 MindSpore ModelZoo），三次获华为火花奖。研究成果在华为、阿里、滴滴等公司业务场景广泛应用，AI4EDA 方向直接回应芯片设计"卡脖子"难题，是国内"ML理论+工业落地"结合的标杆团队之一。
