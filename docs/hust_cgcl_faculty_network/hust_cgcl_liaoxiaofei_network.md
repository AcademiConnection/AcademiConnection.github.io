## 二、教育背景与职业履历

### 2.1 教育经历

廖小飞于1996年9月考入石油大学（华东），2000年7月获得工学学士学位。同年9月，他进入华中科技大学计算机科学与技术学院攻读计算机系统结构专业博士学位，师从金海教授，于2005年6月获得工学博士学位。其博士论文《大规模流媒体服务中媒体资源管理策略的研究》于2007年获得湖北省第八批优秀博士学位论文奖，标志着他在网络流媒体系统方向的早期开创性贡献。

### 2.2 职业履历

- **2005年**：博士毕业后留校任教，历任华中科技大学计算机学院计算机科学系副主任、服务计算技术与系统教育部重点实验室暨集群与网格计算湖北省重点实验室副主任。
- **2010年代中期**：先后担任华中科技大学国际交流处处长、港澳台事务办公室主任，负责学校国际学术交流事务。
- **2018年**：获国家杰出青年科学基金资助，同年入选中组部"万人计划"科技创新领军人才。
- **后续**：出任华中科技大学科学技术发展院院长、党总支书记，负责全校科研战略规划与重大科技项目管理。
- **现任**：华中科技大学计算机科学与技术学院教授、博士生导师、院长，湖北省计算机学会理事长。

从博士毕业留校到担任计算机学院院长，廖小飞的职业轨迹始终扎根于华中科技大学CGCL实验室体系，同时通过担任国际交流处处长和科技发展院院长等行政职务，积累了丰富的学术资源整合和产学研协同管理经验，成为金海教授学术团队中兼具学术深度与行政管理能力的核心人物。

## 五、业界合作关系深度分析

廖小飞在产业合作方面表现突出，其产学研协同模式具有鲜明的"从理论到规模化应用"特征：

**（1）华为合作**

廖小飞代表华中科技大学与华为签署了鲲鹏昇腾科教创新孵化中心合作协议。华为副总裁、ICT产品组合管理与解决方案部总裁马海旭等高层出席签约仪式，廖小飞作为科学技术发展院院长、计算机科学与技术学院院长代表校方签字。该合作聚焦鲲鹏和昇腾计算平台的科教创新与产业孵化，是华科-华为战略合作的标志性项目。

**（2）OPPO合作**

廖小飞参与了华中科技大学与OPPO的战略合作，双方建立了"华中科技大学-OPPO智慧系统联合研究中心"，由张瑞教授担任中心主任。OPPO副总裁兼软件工程系统总裁唐凯等出席签约仪式，廖小飞以计算机学院院长身份见证。该合作聚焦大模型、智慧终端系统等前沿方向。

**（3）国产服务器龙头企业合作**

廖小飞教授团队牵头完成的"高性能异构内存系统关键技术及应用"项目获2024年国家科技进步二等奖。该项目成果"广泛应用于服务器龙头企业，在云计算、大数据处理和人工智能等领域开展了规模化应用"。项目团队"坚持自主创新，成功打破国外垄断，实现了核心技术的国产化替代"，研发了高性能单机大内存服务器和分布式内存池系统。这项历时十余年的产学研协同攻关，体现了廖小飞在异构内存计算领域从基础研究到产业落地的全链条创新能力。

**（4）开源生态建设**

廖小飞团队研发的多个原型系统已在GitHub上开源（https://github.com/CGCL-codes/），包括多核/众核运行时系统、异构内存系统轻量级模拟器和核心系统软件、图计算异步迭代优化系统和专用加速器等。这一开源策略促进了学术成果的产业转化和社区传播。

**（5）国家重大项目支撑**

廖小飞主持了多项国家和产业重大科研项目，包括国家重点研发计划项目（担任首席）、国家863计划项目、霍英东青年教师基金等，这些项目为产学研合作提供了持续的资金和资源保障。

## 七、Connection圈层总结

廖小飞的学术关系网络可以划分为以下圈层结构：

**核心圈层（师生传承层）**：以金海教授为绝对核心。廖小飞是金海教授2000级博士生（2005年毕业），二人合作超过二十五年，共同署名论文和获奖项目数量庞大。金海-廖小飞的师生关系是CGCL实验室学术传承的主干，廖小飞已从学生角色成长为金海教授最重要的学术合作者和团队联合领导者。

**实验室同事圈层**：包括吴松、陈汉华、刘方明、石宣化、刘海坤、邵志远、张宇、郑龙、韩宗芬等教授，以及蒋文斌、张书豪、李钦宾等 younger 教授和郑然、黄禹、王庆刚等副教授。这些同事分布在CGCL实验室的系统软件与体系结构、分布式系统、大数据、网络空间安全等研究组中，形成了以金海教授为学术领袖、廖小飞为系统软件方向带头人的紧密合作网络。其中，刘海坤（内存计算方向）、张宇和郑龙（图计算方向）是廖小飞最密切的论文合著者和项目合作者。

**学生圈层**：廖小飞指导的博士生和硕士生构成了其学术传承的下一代力量。其中，赵文举、姚鹏程、王庆刚等在图计算加速器架构和系统软件方向形成了稳定的研究梯队，许绍显等年轻博士正在将研究拓展至图神经网络训练优化等前沿方向。郑龙教授指导的Graph Challenge竞赛团队和张宇教授指导的Graph 500竞赛团队的学生群体，也在廖小飞的学术辐射范围内。

**跨机构学术圈层**：包括之江实验室（图计算联合研究）、广东工业大学李小平教授（CCF DCSS会议合作）、国防科技大学李东升教授和郭得科教授、天津大学李克秋教授、南京大学叶保留教授、中国地质大学曾德泽教授、武汉大学吴黎兵教授等。这一圈层主要通过CCF分布式计算与系统专委的学术活动和国家重点研发计划项目建立，覆盖了国内分布式计算和系统软件领域的主要研究力量。

**产业合作圈层**：包括华为（鲲鹏昇腾科教创新孵化中心）、OPPO（智慧系统联合研究中心）、国产服务器龙头企业（异构内存系统规模化应用）、广州市南沙区（交叉科学创新研究院）等。廖小飞通过担任科技发展院院长和计算机学院院长的行政职务，将CGCL实验室的学术成果与产业需求深度对接，形成了"理论研究-原型开发-产业落地"的完整创新链条，其团队开源项目（GitHub CGCL-codes）进一步扩展了产业合作的技术影响力。

总体而言，廖小飞是华中科技大学CGCL实验室中承上启下的关键节点型学者：向上承接金海教授的学术传承，向下辐射一批青年教师和博士生群体；向内整合实验室多个研究组的协同力量，向外连接之江实验室、CCF专委和产业头部企业。他的学术关系网络以CGCL实验室为内核、以分布式计算与系统软件为学术主线、以产学研协同为特色，构成了一个层次分明、高度活跃的学术生态体系。
