# 华中科技大学金海CGCL实验室 学术关系网络报告

## 团队简介

本报告集涵盖华中科技大学计算机科学与技术学院金海教授创建的集群与网格计算湖北省重点实验室（CGCL）/服务计算技术与系统教育部重点实验室（SCTS）核心教师团队的学术关系网络。实验室成立于2002年（前身为2000年底金海教授回国后创建的互联网与集群计算研究中心），是中国集群计算、网格计算、云计算和大数据领域的核心研究力量，承建了中国教育科研网格ChinaGrid主结点和中国国家网格CNGrid武汉结点，发表学术论文1400余篇，获国家发明专利441项，获多项国家级科技奖励。

## 团队架构

CGCL以金海教授为核心，其直接培养的博士吴松（云计算）、廖小飞（分布式系统, 现计算机学院院长）、陈汉华（大数据, 全国百篇优博）构成中坚力量，刘方明（香港科技大学博士, 金海亲赴香港引进）为云计算方向重要成员，石宣化为内存计算和AI系统方向带头人。团队在2020年国家自然科学二等奖（云计算基础理论）和2015年国家科技进步二等奖（网络流媒体）等项目中展现了紧密的内部协作格局。

实验室与Intel、惠普、微软、IBM、华为、腾讯、阿里巴巴等国内外IT企业保持长期合作关系，研发的大数据流处理技术应用于华为系统并在Github开源。
