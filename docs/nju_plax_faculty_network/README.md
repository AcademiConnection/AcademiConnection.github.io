# 南京大学 PLaX（程序设计语言与系统）实验室 教师学术关系网络报告 · 总览索引

**报告生成时间：** 2026年

**覆盖范围：** 南京大学计算机学院 PLaX（Programming Language and Systems）实验室。该实验室由梁红瑾教授与冯新宇教授共同建设，聚焦程序设计语言理论、并发程序精化验证与形式化方法。首批收录梁红瑾（国家优青）；冯新宇为共建者，以合作网络形式在报告中交叉呈现。

**数据方法：** 以个人主页（hongjin-liang.github.io）、PLaX 实验室成员页（plax-lab.github.io）为核心数据源，结合计算机学院官网与中科大官方资料交叉确认。

**团队边界说明：** PLaX 是程序设计语言的**独立建制实验室**，与南京大学已有的软件工程/形式化方法团队（nju_sefm_faculty_network，计算机软件研究所）为不同建制，本目录不与 nju_sefm 合并。PLaX 依托计算机软件新技术全国重点实验室，与国际 PL（SIGPLAN）共同体及早期"中国科大—耶鲁高可信软件联合研究中心"（邵中等）保持脉络。
