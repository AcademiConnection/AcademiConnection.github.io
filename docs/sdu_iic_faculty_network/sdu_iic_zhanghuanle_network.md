### 4.1 IIC内部合作

IIC团队由成秀珍教授（IEEE Fellow、计算机科学与技术学院院长、国家"千人计划"特聘专家）创建并领衔，章宦乐作为团队成员，在论文产出和项目执行层面与团队核心成员保持学术协作。从IIC官网公开的论文列表看，章宦乐在"Model Poisoning Attack on Neural Network without Reference Data"（IEEE TC, 2023）一文中与团队多位成员形成共同署名关系，包括于东晓教授（国家优青）、胡鹏飞教授（国家优青、山东省海外优青）、成秀珍教授（IEEE Fellow）以及Guoming Zhang和Hong Li。这表明章宦乐在IIC内部的学术合作网络至少覆盖以下节点：

- **成秀珍教授**（IEEE Fellow，IIC创始人）：作为团队负责人，成秀珍在多篇IIC论文中担任共同作者，章宦乐的研究活动处于成秀珍领衔的团队框架之下。
- **于东晓教授**（国家优青）：IIC团队核心成员，研究方向包括边缘智能、分布式算法和图计算，与章宦乐在系统安全和区块链方向可能存在课题交叉。
- **胡鹏飞教授**（国家优青、山东省海外优青）：同为UC Davis校友，研究方向为网络安全和移动计算，与章宦乐的背景和方向高度相关，二人共同署名的论文已得到确认。

IIC团队与产业界的合作具有明确的制度化安排。根据IIC官网介绍，团队与浪潮集团共建"元计算研究院"，并参与国家区块链创新应用特色领域"区块链+教育"试点。浪潮集团（Inspur）是中国领先的服务器与云计算企业，总部位于山东济南，与山东大学的合作具有地缘和产业政策的双重驱动。

章宦乐作为IIC团队成员，在元计算研究院和数链融合技术创新中心的框架下，可能参与与浪潮集团相关的技术研发和项目合作。此外，IIC团队公开的产业合作伙伴还包括国家电网、华为、海信、天津诚泰、上海新时达、华电国际、北京睿企等企业，涵盖电力、制造、信息安全等多个行业。但公开资料未披露章宦乐本人在这些合作中的具体角色、负责项目或技术交付成果。

章宦乐于2025年起挂职青岛市海洋发展局副局长，这一安排可能与其在IIC从事的智能计算技术向海洋产业场景的应用转化相关。青岛市正在推进"4+4+2"现代海洋产业体系，山东大学青岛校区也位于蓝谷区域，近年来蓝谷区域内单位在涉海科技项目上表现突出。章宦乐的挂职角色为学术界与海洋产业管理的交叉节点，但具体的产业合作项目和技术转化成果尚待公开资料进一步披露。

### 5.2 技术转化与应用场景

从IIC团队公开的应用落地情况看，团队的研究成果已在华为智慧城市平台、上海新时达电梯制造供应链、城泰可信融资与租赁平台、中孚保密系统与日志管理平台等场景实现应用。章宦乐的研究方向涵盖边缘智能、区块链和系统安全，这些方向与上述应用场景具有直接对应关系：

- **区块链方向**：IIC团队在区块链基础理论、跨链技术、拜占庭共识和Web3.0领域取得多项成果，已开发工业级区块链平台并在智慧社区、融资租赁、供应链场景实现应用落地。章宦乐在该方向的论文产出包括与团队成员合作的模型安全相关研究。

- **系统安全方向**：团队在物联网安全、设备认证和隐私保护方面的成果发表于ACM CCS、INFOCOM、NDSS等顶级会议，章宦乐在该方向的研究与团队的系统安全布局形成互补。
