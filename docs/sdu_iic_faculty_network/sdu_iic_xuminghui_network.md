徐明辉是山东大学计算机科学与技术学院智能计算研究所（IIC）核心成员之一。他于2021年从乔治华盛顿大学获得计算机科学博士学位后加入山东大学，与IIC创始主任成秀珍教授共同领导区块链与分布式安全实验室。其个人主页、中国电子学会官方公众号报道及山东大学2024年关于CCS/NDSS论文的新闻报道均确认其已晋升为教授。他的研究聚焦区块链基础理论——包括拜占庭容错共识、跨链隐私、去中心化存储与应用密码学，在USENIX Security、NDSS、ACM CCS、IEEE INFOCOM等国际顶级会议和期刊发表论文20余篇。

**同名消歧：** 经检索，公开学术领域中存在多位名为"Xu Minghui"或"徐明辉"的学者，包括澳门大学统计学方向的Lihu Xu（许立虎）、上海国际问题研究院国际关系方向的徐明祺等，均与本报告研究对象无关。本报告所述徐明辉唯一指向山东大学IIC区块链与分布式安全实验室的徐明辉，其关键辨识特征为：乔治华盛顿大学计算机科学博士（2021年）、北京师范大学物理学学士（2018年）、研究方向为区块链与分布式安全。

## 二、教育背景与职业履历

徐明辉的学术道路以跨学科转变为显著特征。根据中国电子学会官方公众号对其"青年人才托举工程被托举人"的专题报道，其学术之旅始于高中时期对物理学的兴趣，高考志愿填报物理学专业。2014年进入北京师范大学物理学系，本科期间辅修计算机科学，并涉猎神经科学、系统科学等交叉学科。2017年5月，杨振宁先生做客北师大物理文化节，徐明辉当面提问"二十一世纪是物理学的春天还是冬天"，杨先生回答"肯定不是春天，大概是冬天"，这一回答坚定了他从物理跨界到计算机科学的决心。

**教育经历：**

- 2014年至2018年，在北京师范大学物理系获得学士学位（物理学专业），辅修计算机科学。
- 2018年至2021年，在乔治华盛顿大学（The George Washington University）计算机科学系获得博士学位。乔治华盛顿大学是IIC创始主任成秀珍教授此前任教15年（2002–2017年）的机构，这一校际关联是徐明辉与成秀珍学术渊源的重要背景。公开资料未明确标注其博士导师姓名，但从其博士期间研究方向（区块链）与成秀珍研究方向的高度重合、二人在SDU共同领导实验室的事实，以及大量论文中的共同署名关系来看，成秀珍极可能在其博士培养中扮演了核心指导角色，但本报告在缺乏显式官方表述的情况下不作定论。
- 2023年，访问苏黎世联邦理工大学（ETH Zurich），身份为academic guest（学术访问学者）。

**职业经历：**

- 2021年加入山东大学计算机科学与技术学院，任助理教授（Assistant Professor，2021–2023年）。
- 2023年晋升副教授（Associate Professor，2023–2024年）。
- 2024年获破格晋升教授（Full Professor）。其个人主页明确记载了这一快速晋升轨迹。但IIC官网及山东大学新闻网在2024年的报道中仍以"副教授"称谓，表明职称信息的更新在不同信息源间存在时间差。
- 加入SDU后，与成秀珍教授共同建立区块链与分布式安全实验室（Blockchain and Distributed Security Lab），并担任数链融合教育部工程研究中心副主任。

从研究方向的时间线看，徐明辉从物理学背景出发，在博士阶段转向计算机科学，专注于区块链与分布式安全。近年其研究进一步向应用密码学纵深拓展——包括可验证随机存取存储器（VDORAM，NDSS'26）、异步动态多方安全计算（AD-MPC，ACM CCS'25）、隐私保护范围查询（Trinity，IEEE TIFS'25）等，同时持续深耕拜占庭容错共识（如Koala，NDSS'26；OrbitBFT，ICDCS'26）和去中心化存储（如FileDES，INFOCOM 2024；PIR-DSN，INFOCOM 2026）等方向。这一研究脉络与IIC"区块链关键理论与技术"的研究方向高度契合。

他在个人主页上明确表示正在招收博士后、博士/硕士研究生及本科生，表明其科研团队处于活跃建设和扩张阶段。

## 三、学生培养情况

### 1. 国益豪（博士研究生，徐明辉指导）

国益豪为山东大学计算机学院2019级博士生，是徐明辉具有明确官方记载的指导学生。山东大学青岛校区官网报道，其论文"zkCross: A Novel Architecture for Cross-Chain Privacy-Preserving Auditing"发表于信息安全领域四大顶级会议之一USENIX Security 2024，国益豪为第一作者，徐明辉为通讯作者。该论文提出兼顾隐私保护与审计的跨链协议，针对跨链转移和跨链交换分别设计了隐私保护机制及高效审计机制。合作单位包括北京航空航天大学、马里兰大学以及浪潮云信息技术股份公司，受国家自然科学基金重点项目"基于模块化设计的异构跨链安全服务关键技术研究"资助。一名博士生以第一作者身份在USENIX Security发文，体现了徐明辉"面向安全顶会"的学生培养导向。

### 2. 于文轩（博士研究生，徐明辉、成秀珍与清华大学段斯斯共同指导）

于文轩为山东大学博士研究生。据山东大学官网报道，计算机学院三项最新研究成果被安全领域顶级会议ACM CCS和NDSS录用，其中于文轩为第一作者的研究由徐明辉教授、成秀珍教授和清华大学段斯斯研究员共同指导，中国科学院软件研究所路远副研究员和清华大学宋一凡助理教授亦给予重要指导。山东大学本科生吴兵（已获香港理工大学直博资格）对该研究亦有贡献。这一多导师联合指导模式表明徐明辉的学生培养网络已延伸至清华大学、中科院软件所等校外学术节点。

### 3. 吴兵（本科生，徐明辉参与指导）

吴兵为山东大学本科生，参与了于文轩主导的CCS/NDSS论文研究并作出贡献，已获香港理工大学直博资格。虽然其身份为本科生而非研究生，但这一案例说明徐明辉的指导范围已延伸至本科生科研训练，且其指导的本科生具备获得境外名校直博录取的竞争力。

## 五、业界合作关系深度分析

### 5.1 浪潮集团：从论文共著到产业生态绑定

浪潮集团是IIC团队整体层面最重要的产业合作伙伴，山东大学与浪潮于2023年7月共建元计算研究院（成秀珍任院长）。徐明辉在这一产业生态中具有直接的参与证据：其论文DataSafe（Springer会议论文）的共同作者中，明确标注有来自"Inspur Yunzhou Industrial Internet Co., Ltd."（浪潮云洲工业互联网有限公司）的企业研究人员——Shang Guangyong和Ma Zhen。此外，zkCross（USENIX Security 2024）的合作单位中亦包括"浪潮云信息技术股份公司"。这表明徐明辉的区块链研究并非纯学术活动，而是通过论文共著的形式与浪潮的工业互联网业务建立了直接的技术合作接口。

### 5.2 青岛地铁人工智能专题培训——数链融合报告

2024年5月17日至18日，山东大学举办青岛地铁人工智能专题培训班专家报告会，山东大学新闻网对此进行了报道。徐明辉副教授作题为"浅谈数据要素与数链融合"的报告，解析了数据要素与数字经济的紧密联系，以数据入表、数据交易等为切入点讲解了区块链技术在构建可信数据空间、实现数链融合目标等方面的重要作用。这一报告主题直接对应其作为数链融合教育部工程研究中心副主任的职能定位，也体现了其区块链研究向轨道交通行业输出技术知识的校企交流实践。

同场作报告的李峰教授的报告题为"异构智能算力"，另有中国科学院自动化研究所张家俊研究员、清华大学钱忱博士后、中科曙光刘玉海研究员、浪潮云李志华工程师、青岛地铁蓝天工程师等8位专家作专题报告，形成了学术界与产业界共同参与的技术交流格局。

### 5.3 贵州白山云科技：FileDES论文产业合作

FileDES（IEEE INFOCOM 2024）论文的合作单位包括"贵州白山云科技股份有限公司"，该公司是国内领先的边缘云服务提供商。这一合作表明徐明辉的去中心化存储网络研究与云服务产业需求直接对接，其技术成果具有面向Web3.0存储基础设施的应用导向。

### 5.4 区块链与数据要素融合产业生态

2023年软件创新发展大会期间，徐明辉以数链融合教育部工程研究中心副主任身份在"区块链与数据要素融合创新发展"专题论坛上作主旨演讲，与清华大学柴跃廷教授、中国信通院闫树主任、贵阳大数据交易所肖连春等行业专家同台。这一活动表明其在区块链与数据要素融合这一产业前沿话题上具有官方认可的学术话语权，且其产业网络已延伸至数据交易、大数据治理等领域。

### 5.5 IIC团队整体企业合作生态

IIC团队的产业合作覆盖面广泛，与浪潮、国家电网、华为、海信、天津诚泰、上海新时达、华电国际、北京睿企等企业建立了合作关系。IIC官网"研究项目"栏目展示了SandyChain区块链平台及融资租赁应用等已转化的产业应用项目。徐明辉作为IIC区块链方向的核心教师，在这一产业合作框架下参与相关项目，但其个人在具体项目中的角色分工和经费分配等信息在公开资料中未逐项披露。
