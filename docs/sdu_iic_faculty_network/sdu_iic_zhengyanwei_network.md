## 二、教育背景与职业履历

郑艳伟的公开履历具有从工程训练、软件理论到计算机应用技术研究的连续性。1995年9月至1999年7月，他在山东建筑工程学院学习机械电子工程，获工学学士学位；1999年7月至2001年8月在企业任职。2001年9月至2004年6月，他在山东大学攻读计算机软件与理论并获工学硕士学位。此后于2004年7月至2013年6月在济南大学信息学院先后任助教、讲师。

2013年9月至2019年1月，郑艳伟在北京航空航天大学计算机应用技术专业攻读工程博士专业学位。2019年4月进入山东大学计算机学院，教师主页记载其在2019年4月至2025年9月任副研究员，2025年9月至今任副教授。上述教育和工作时间线均以[山东大学教师主页](https://faculty.sdu.edu.cn/zhengyanwei/zh_CN/index.htm)为准；公开页面未披露其博士导师，故不基于论文署名推定导师关系。

### 4.2 跨机构与跨场景连接

郑艳伟的跨机构连接主要体现为项目和技术需求对接，而非可验证的国际合作者名单。其教师主页列有“5G赋能的端路云一体化智慧交管平台关键技术与应用”省部级项目，郑艳伟为负责人，立项于2022年10月；项目名称与其视觉目标导航、智能交通应用研究存在直接主题关联。
