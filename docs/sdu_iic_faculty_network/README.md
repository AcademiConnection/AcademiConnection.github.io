# 山东大学智能计算研究所（IIC）教师学术关系网络报告索引

## 一、IIC概况

山东大学智能计算研究所（Institute of Intelligent Computing, IIC）隶属于山东大学计算机科学与技术学院（青岛校区），由成秀珍教授（IEEE Fellow）于2018年创建并领衔。IIC在国内首次提出融合可信计算、精准计算、智能计算的"高置信计算"新范式，聚焦**边缘智能、区块链、系统安全**三大前沿研究方向。

研究所现有团队成员21人，其中国家优青1人、山东省海外优青6人、山东大学齐鲁青年学者4人、山东大学青年学者未来计划3人，博士及硕士研究生90余人。成立约五年间，IIC承担国家级和省部级科研项目30余项，发表论文300余篇，申请发明专利70余项，形成高置信信-物融合系统HiCon、区块链开发平台SandyChain等标志性成果。IIC依托数链融合技术教育部工程研究中心、山东省数链融合技术创新中心、山东省算网融合理论与技术重点实验室等科研平台开展工作，并与浪潮集团共建元计算研究院。

IIC官方网站列出的团队成员共21人，本报告系列已覆盖其中10位核心及重要教师。

## 四、主要研究方向

IIC团队围绕"高置信计算"新范式，形成三大核心研究方向：

- **边缘智能**：分布式学习理论与算法、联邦学习、边缘计算系统、异构智能算力、资源自适应计算。代表教师：于东晓、李峰、张啸。
- **区块链**：拜占庭容错共识、跨链隐私与审计、去中心化存储、应用密码学、智能合约安全。代表教师：成秀珍、徐明辉。
- **系统安全**：网络安全、侧信道攻击与防御、移动安全、人工智能安全、物联网安全。代表教师：胡鹏飞、章宦乐。

此外，张广辉（多媒体传输与计算机网络）和肖梦白（GPU加速与大数据系统）的研究为IIC提供了网络系统与计算基础设施方向的支撑；郑艳伟在计算机视觉与智能交通应用方向拓展了IIC的应用场景覆盖面。
