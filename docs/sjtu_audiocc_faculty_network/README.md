# 上海交通大学 AudioCC听觉认知与计算声学实验室（智能语音） 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

上海交通大学智能语音研究团队行政上隶属于计算机学院计算机应用研究所，实际由钱彦旻特聘研究员领导"智能语音技术实验室"与"听觉认知与计算声学实验室（AudioCC Lab）"，是国内最具国际影响力的语音处理团队之一。钱彦旻为 Kaldi 开源项目13位创始成员中唯一的亚洲学者，清华大学博士（与刘加教授团队长期合作）、剑桥大学机器智能实验室博士后，研究方向覆盖语音识别、说话人识别、语音增强与分离、多模态语音理解；2026年创立"宇生月伴"公司（同创伟业领投）。李晨达（助理研究员，2024年10月起）为团队青年骨干，深耕语音增强与分离（Interspeech 2020、ICASSP 2022/2023 等成果），曾访学 CMU WAVLab。团队与思必驰联合实验室、腾讯、蚂蚁、美团、荣耀等企业，以及清华刘加/张卫强团队、CMU、约翰霍普金斯大学（Shinji Watanabe）等保持紧密合作，开源项目 3D-Speaker 生态被阿里达摩院采纳。

需要说明的边界：钱彦旻、李晨达在学院名录中列于计算机应用研究所，但并非 APEX 实验室或 BCMI 实验室成员；他们与俞凯的 X-LANCE 实验室（见 [sjtu_xlance_faculty_network](../sjtu_xlance_faculty_network/)）、吕宝粮的 BCMI 实验室均为长期论文合作与联合培养关系。本目录系从"计算机应用研究所/APEX"调研项中按实际归属拆分而出。

## 圈层结构概述

团队网络以钱彦旻为双枢纽：学术谱系上溯清华大学电子系刘加团队（DCASE 2024 双冠军合作延续至今），经剑桥 MIL 博士后（Steve Renals 团队，需以报告内核实口径为准）接入国际语音学界，并作为 Kaldi 创始成员深度绑定 Daniel Povey—小米语音开源社区（新一代 K2/icefall/WeNet 生态与 3D-Speaker 开源）。李晨达作为团队培养的本土博士（与钱彦旻为论文合作与团队同侪关系，公开资料未披露正式导师关系），通过 ESPnet-SE 等开源工作连接国际语音工具链社区。产业网络以思必驰—上海交大智能语音联合实验室为轴心，延伸至腾讯（天籁行动）、蚂蚁、美团、荣耀等企业合作，2026年通过宇生月伴完成学术成果的商业化闭环。校内合作主要面向 X-LANCE（俞凯）与 BCMI（吕宝粮、吴梦玥）的语音语言与情感计算方向。
