## 二、教育背景与职业履历

肖俊，1979年9月出生于贵州省铜仁市，1998年从贵州铜仁一中考入浙江大学计算机学院。他在浙江大学完成了从本科到博士的全部学业，2002年获得浙江大学计算机科学与技术学院学士学位，2007年获得同校计算机科学与技术学院博士学位。其博士期间的导师体系与庄越挺教授密切相关——庄越挺教授是浙江大学人工智能研究所的奠基性人物，2006年至2015年担任该所所长，肖俊的博士研究正是在庄越挺领衔的跨媒体计算研究团队中完成。（博士导师为庄越挺教授这一信息有间接证据支持：肖俊与庄越挺长期保持密切合作，同属DCD实验室，且庄越挺系浙大AI所学术谱系的核心节点。但肖俊个人主页中未明确标注"师从庄越挺"，此为基于多重证据的合理推断，标注待核实。）

博士毕业后，肖俊留校任教，在浙江大学计算机科学与技术学院/人工智能研究所从事教学科研工作。其职业发展历程中的关键时间节点包括：

- **约2007年**：博士毕业后留校任教，担任讲师/助理研究员。
- **2015年**：入选浙江大学求是青年学者。
- **2018年**：获得浙江省自然科学基金杰出青年基金资助，入选浙江省151人才工程第二层次培养人员。
- **2019年**：入选浙江省"万人计划"科技创新领军人才。
- **此后**：晋升为教授、博士生导师，担任人工智能研究所副所长。
- **近期**：获聘教育部"长江学者奖励计划"特聘教授、浙江大学求是特聘教授。

肖俊目前担任浙江大学人工智能研究所副所长，兼任浙江大学数字法治研究院副院长。其办公地点位于浙江大学玉泉校区曹光彪主楼402室。他还担任之江实验室双聘教授，并作为导师组成员参与浙江大学"文科+X"多学科交叉人才培养项目。近年来，肖俊的研究方向从早期的跨媒体检索、图像描述（Image Caption）和视频问答（Video Question Answering），逐步拓展到广义多模态推理与生成（Generalized Multimodal Reasoning and Generation）以及面向开放世界的视觉关系理解等前沿问题。

虽然一知智能由陈哲乾创办，但其孵化自浙江大学人工智能研究所的实验室体系，属于庄越挺-肖俊团队的学术生态。一知智能目前已发展为估值超10亿元的准独角兽企业，聚焦AI数字人、智能外呼等技术，是浙大AI实验室创业孵化的代表性案例。陈哲乾带领"浙大博士团"正在升级"浙大先生"数字人项目，后续技术将与浙大联合开源。

**3. 联合实验室模式**
肖俊通过建立多个校企联合实验室（同盾、海康威视、拍拍贷、浙大网新、汇景等），形成了一套成熟的产学研合作模式。这种模式既为企业提供了AI技术支持，也为学生提供了产业实践机会和就业渠道。

**4. 智海平台**
2024年，肖俊代表浙江省计算机学会在宁波市计算机学会人工智能专业委员会成立大会上作《浙江大学人工智能学科发展及智海平台》主题报告。智海平台是浙江大学AI教育平台，体现了肖俊在AI教育推广方面的参与。

## 七、Connection圈层总结

肖俊的学术关系网络可按圈层结构分析如下：

**第一圈层：核心师生传承圈**

肖俊的学术根基深植于浙江大学人工智能研究所的"庄越挺学术谱系"。庄越挺教授是这一谱系的核心节点——国家杰青、长江学者、973首席科学家、曾任计算机学院院长和AI所所长。肖俊作为庄越挺的博士生（推断）和长期合作者，是这一谱系的核心传承人。两人及吴飞教授共同构成了DCD实验室的"铁三角"，长期在跨媒体智能、多媒体分析等方向并肩作战，共同获得多项省级和国家级奖项。这一圈层是肖俊学术身份的基础。

**第二圈层：实验室团队与学生圈**

DCD实验室培养的学生构成了肖俊网络的第二圈层。代表性人物包括：现任香港科技大学助理教授的陈隆（学术新星）、一知智能创始人陈哲乾（创业明星）、以及张凤达、游兆阳、沈弢等参与核心论文研究的学生。这些学生既是肖俊学术产出的主力，也延伸了他的学术影响力——陈隆在HKUST、哥伦比亚大学、NUS、NTU的国际联系，陈哲乾在产业界的商业网络，都从不同方向拓展了肖俊的影响半径。近五年来，肖俊指导学生发表CCF A/B类论文29篇，培养体系产出高效。

**第三圈层：浙大校内合作圈**

在浙江大学内部，肖俊与AI所的吴飞教授（AI所所长）、况琨副教授、张寅研究员等构成紧密合作关系。同时与上海高等研究院计算+AI团队有跨院系合作。庄越挺作为浙大学术委员会副主任，为这一合作圈提供了高层学术资源支撑。在CAD&CG全国重点实验室层面，肖俊与许威威、孙凌云、黄劲等图形学方向的教师同属实验室固定研究人员，但合作深度相对有限，其核心阵地仍在AI所体系。

**第四圈层：跨机构学术合作圈**

在国内层面，肖俊通过吴文俊奖合作者（何向南-中科大、汪萌-合工大、洪日昌-合工大、王翔-中科大）建立了跨校学术网络，主要集中在多媒体推荐与多模态学习领域。在国际层面，通过NUS传感器增强社交媒体中心PI身份和学生的访学渠道（Tat-Seng Chua、Hanwang Zhang、Shih-Fu Chang），与新加坡和美国的顶尖多媒体研究团队建立了联系。但相比第一、二圈层，这一圈层的合作深度有待进一步深化。

**第五圈层：产业生态圈**

肖俊的产业网络极为丰富，涵盖安防（海康威视）、金融科技（同盾科技、拍拍贷/信也科技）、软件（浙大网新）、互联网（华为、阿里）、动漫（中南卡通）等多个赛道。他通过联合实验室模式（至少8个校企联合实验室/研究中心职务）构建了系统化的产学研桥梁。同时，他亲自参与创业（量知数据联合创始人），并间接孵化了学生创业项目（一知智能）。这一产业圈层是肖俊区别于纯学术型教授的重要特征——他既是高水平研究者（ACM MM最佳论文、长江学者），也是活跃的产学研连接者。

**网络结构总结：**

肖俊的学术关系网络呈现"强核心、广外围"的结构特征。核心是庄越挺-肖俊-吴飞的DCD实验室三角，外围辐射至学生、国内合作者和产业伙伴。其网络的优势在于产学研融合度高，学术研究与产业落地形成正反馈；但在国际合作方面，相较于同领域的顶尖学者，直接的国际联合研究项目相对较少，主要通过学生访学和论文合作建立联系。随着近年来肖俊担任重大项目首席科学家、获长江学者特聘教授、其学生陈隆在HKUST和哥大等国际名校任职，其网络的国际化水平和影响力正在快速提升。
