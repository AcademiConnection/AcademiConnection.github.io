## 二、教育背景与职业履历

唐敏的学术生涯完全扎根于浙江大学。根据其个人主页（https://min-tang.github.io/）记载，他于1994年获浙江大学计算机软件专业学士学位，1996年获计算机应用专业硕士学位，1999年9月获计算机应用专业博士学位。其博士论文题为"Research and Implementation of Key Technology in Geometric Kernel Based on Sculptured Model"（基于曲面模型的几何内核关键技术研究与实现），导师为何志均（Zhijun He）教授与董金祥（Jinxiang Dong）教授。值得注意的是，唐敏的师承属于何志均—董金祥一脉（浙大CAD/智能CAD谱系），而非外界容易误传的"彭群生—鲍虎军"绘制谱系主轴；他后来通过科研合作与获奖项目（见第五章）与鲍虎军等图形学谱系学者建立了紧密联系。

职业履历方面，唐敏1999年博士毕业后留校任助教，2000年12月晋升副教授，2012年12月晋升教授，长期在浙江大学计算机学院与CAD&CG全国重点实验室（原国家重点实验室）工作，现任人工智能学院教授（具体转入时间待官方公告进一步确认）。访学经历方面：2003年6月至2004年5月，他获国家留学基金资助赴美国Wichita州立大学访问，师从几何约束求解专家周咸青（Shang-Ching Chou）教授；2007年4月至2008年4月，获浙江大学"新星计划"资助赴美国北卡罗来纳大学教堂山分校（UNC Chapel Hill）GAMMA研究组访问，合作导师为Dinesh Manocha与Ming C. Lin教授；2015年8月至9月，获欧盟AniNex项目资助访问瑞士日内瓦大学MIRALab（Nadia Magnenat-Thalmann教授实验室）；2016年9月至2017年5月，再次获国家自然科学基金资助重访UNC GAMMA组。这些访问经历奠定了他此后十余年与UNC及国际图形学界的深度合作。

科研项目方面，唐敏主持国家自然科学基金项目4项、国家支撑计划项目1项、博士点基金项目1项、浙江省自然科学基金面上及重点项目多项，并参与国家重点研发计划"云计算和大数据"重点专项（2017YFB1002700，复杂时变场景的物理仿真关键技术）及国家自然科学基金重点项目（61732015，服装电子商务中的真实感建模与体验，第三参与人）。

## 三、学生培养情况

唐敏与童若锋共同主持GIVE实验室（数字媒体处理与企业智能计算实验室），实验室官网列出了完整的历届毕业研究生去向，本节依据该名单及其合作论文整理代表性学生。

### 1. 林江（Jiang Lin）（已毕业博士，直接指导，与童若锋联合指导）

林江是唐敏早期培养的博士生，博士期间从事GPU加速的碰撞检测研究。其代表性工作包括发表于《计算机学报》2010年的"图形硬件加速的柔性物体连续碰撞检测"（唐敏、林江、童若锋合作），以及发表于I3D 2011的"Collision-Streams: Fast GPU-based Collision Detection for Deformable Models"（与Dinesh Manocha、童若锋合作）。该I3D论文是GPU碰撞检测方向的代表性成果，亦是唐敏与Manocha国际合作的起点之一。据实验室官网毕业生去向表，林江毕业后曾进入Google（美国）工作，现就职于中国工商银行杭州分行（去向以实验室官网为准）。

### 2. 王鑫磊（Xinlei Wang）（已毕业博士，直接指导）

王鑫磊的博士研究聚焦于物质点法（MPM）的GPU并行加速，是唐敏课题组计算物理仿真方向的代表学生。其作为第一作者的论文"A Massively Parallel and Scalable Multi-GPU Material Point Method"与"Hierarchical Optimization Time Integration for CFL-rate MPM Stepping"均被SIGGRAPH 2020接收（后者发表于ACM Transactions on Graphics），是大规模多GPU物理仿真的标志性工作。其毕业后的具体去向（待核实）。

### 3. 李澄（Cheng Li）（已毕业博士，直接指导）

李澄的代表性工作是作为第一作者发表于SIGGRAPH Asia 2020的"P-Cloth: Interactive Cloth Simulation on Multi-GPU Systems using Dynamic Matrix Assembly and Pipelined Implicit Integrators"，该工作提出了多GPU系统上的交互式布料仿真框架，延续了唐敏自I-Cloth以来的GPU布料仿真研究主线。其毕业后的具体去向（待核实）。

### 4. 李玉迪（Yudi Li）（已毕业博士，直接指导，与童若锋联合指导）

李玉迪从事数据驱动的布料变形预测研究，作为第一作者先后发表"N-Cloth: Predicting 3D Cloth Deformation with Mesh-Based Networks"（Eurographics 2022）、"D-Cloth: Skinning-based Cloth Dynamic Prediction with a Three-stage Network"（Pacific Graphics 2023）和"CTSN: Predicting cloth deformation for skeleton-based characters with a two-stream skinning network"（Computational Visual Media, 2024，与童若锋等合作），形成了从物理仿真到学习式仿真的完整研究脉络。其毕业后的具体去向（待核实）。

### 5. 樊鹏（Peng Fan）（在读/近期博士研究生，直接指导）

樊鹏是唐敏课题组近期培养的骨干学生，其作为第一作者的论文"gDist: Efficient Distance Computation between 3D Meshes on GPU"被SIGGRAPH Asia 2024接收，"gCDT: A Highly Parallel GPU Algorithm for Large-Scale Constrained Delaunay Triangulation"被SIGGRAPH 2026接收，均为大规模几何计算的GPU加速方向的前沿工作。

### 6. 叶力（Li Ye）（近期博士研究生，直接指导，与童若锋、杜鹏联合指导）

叶力的代表性工作包括作为第一作者发表于Computer-Aided Design期刊的"MidSurfer: Efficient Mid-Surface Abstraction from Variable Thin-walled Models"（2026），以及与周欣航、阳心宇、樊鹏等合作被CAD期刊录用的"gMidSurf: Hierarchical GPU-based Mid-surface Abstraction for Thin-walled CAD Models"，面向工业CAD中薄壁件中面抽取这一核心需求，是课题组近年向工业软件几何引擎方向拓展的代表。

### 7. 其他代表性学生（团队培养）

据GIVE实验室官网毕业生去向表：文晔、宓晓峰毕业后进入Google（美国），郑佳俊进入Google（上海），宋鹏进入微软（美国），张毅彬进入Qualcomm（美国），陈碧任教于宾夕法尼亚州立大学（Penn State），吕靖进入Google（美国）。此外，张良俊（Liangjun Zhang）曾在实验室学习，后在UNC Chapel Hill师从Dinesh Manocha获博士学位，现为斯坦福大学研究人员，曾与唐敏合作发表SIGGRAPH 2020多GPU MPM论文，属团队培养与国际联合培养的典型。

## 四、学术合作网络

### 4.1 实验室内部合作

唐敏学术网络的第一环是GIVE实验室的同事团队：童若锋（长期合作者，二人联名发表大量碰撞检测、布料仿真论文，并联合申请国家自然科学基金项目61572423/61572424、61972341/61972342）、董金祥（唐敏的博士导师之一，实验室资深教授）、林兰芬（医学影像与智能计算方向教授）以及杜鹏研究员（NTU/KAIST背景，近年CAD几何方向合作者）。在实验室层面，唐敏作为完成人之一与鲍虎军、王锐、黄劲、章国锋、华炜等共同获得2020年度浙江省技术发明一等奖（"虚拟环境的高效高保真建模和视觉呈现技术"），这一获奖团队构成浙大虚拟现实与图形学方向的骨干集群；他还与工业设计系的孙守迁教授团队合作完成探月工程虚拟仿真项目（见第五章）。

### 4.2 跨机构合作

唐敏最重要的国内跨机构合作是通过UNC GAMMA组与Dinesh Manocha（现马里兰大学）、Ming C. Lin（UNC，现耶鲁大学）建立的联合研究线，代表性成果包括I3D 2011的Collision-Streams、IEEE TVCG 2014的"Hierarchical and Controlled Advancement for Continuous Collision Detection of Rigid and Articulated Models"（与韩国梨花女子大学Young J. Kim合作）等。张良俊（斯坦福）等由该合作线培养的学生成为连接浙大与UNC/斯坦福的桥梁。此外，唐敏与日内瓦大学MIRALab的Nadia Magnenat-Thalmann在欧盟AniNex项目框架下开展虚拟人相关合作。

### 4.3 国际合作

唐敏的国际网络以美国为主轴：UNC Chapel Hill GAMMA组（Manocha/Lin，两次长期访问）、Wichita州立大学（周咸青，几何约束求解）、以及与Ewha Womans University的Young J. Kim的碰撞检测联合研究。欧洲方面有瑞士日内瓦大学MIRALab（AniNex 612627项目）。这一"以访学为种子、以联合论文与联合培养学生为纽带"的国际合作模式，使他成为中国图形学界与国际碰撞检测/物理模拟社区之间的重要节点。

## 五、业界合作关系深度分析

### 5.1 产业合作

唐敏的产业合作具有鲜明的"国家重大工程+头部企业"双线特征。国家工程方面，课题组研制的光学负载成像仿真系统于2014年成功应用于嫦娥三期再入返回试验，相关"面向探月工程航天任务的虚拟仿真支撑平台"成果获2021年度中国电子学会科技进步奖三等奖（完成人含孙守迁、唐敏、顾征等）。企业合作方面：他获得浙江大学—阿里巴巴前沿技术联合研究中心项目资助（基于CUDA加速的实时布料仿真，2017年）；早期研究获MOE-Intel专项科研基金（MOE-INTEL-09-05）及AMD中国支持；2017年其GPU加速布料仿真海报入选NVIDIA GTC China大会；其开发的开源布料仿真工具包I-Cloth（2018年发布）被业界广泛使用。

### 5.2 创业孵化与开源生态

唐敏长期坚持将GPU仿真研究成果开源化：I-Cloth布料仿真开发包（https://min-tang.github.io/gpuCloth/）及其在SIGGRAPH Asia 2018发表的配套论文"I-Cloth: Incremental Collision Handling for GPU-Based Interactive Cloth Simulation"（第一作者为其学生王彤彤）是这一路线的代表，降低了高质量布料仿真技术的产业应用门槛。其学生群体进入Google、微软、字节跳动、阿里巴巴、AMD、Qualcomm等企业及蚂蚁集团等金融机构，形成了GPU计算人才的产业辐射网络；部分学生（如宋晓峰、潘练武）选择创业。近年课题组与深圳泊松软件等国产几何引擎力量的产学研联动（经由GIVE实验室整体合作）亦在推进中（具体项目细节待核实）。

## 七、Connection圈层总结

唐敏学术关系网络的第一圈层是其GIVE实验室共同体：以博士导师董金祥及其同事童若锋为轴心，联合林兰芬、杜鹏形成浙大CAD&CG实验室内部稳定的核心合作组，其与童若锋近三十年的联名论文与联合项目是实验室内部合作的典范。

第二圈层是国际仿真与几何计算社区：以UNC GAMMA组（Dinesh Manocha、Ming C. Lin）为枢纽，辐射Young J. Kim（Ewha）、Nadia Magnenat-Thalmann（日内瓦）、周咸青（Wichita State）及斯坦福的张良俊等，形成了"碰撞检测—布料仿真—MPM物理模拟"方向的跨国研究网络。

第三圈层是产业与国家工程网络：上承嫦娥探月工程的虚拟仿真重大需求，下接阿里巴巴、Intel、AMD、NVIDIA等企业的GPU计算合作，并通过I-Cloth开源工具包向产业界输出技术。

第四圈层是学生辐射网络：其培养的学生广泛分布于Google、微软、斯坦福、Penn State等国际机构与国内头部科技企业，构成了GPU图形计算领域的人才扩散链。

总体而言，唐敏是一位以浙大为根、以GPU物理仿真与几何计算为轴、深度嵌入国际学术网络与国家重大工程需求的学者。其师承何志均—董金祥一脉而非彭群生—鲍虎军—周昆的绘制谱系主轴，但通过获奖合作、联合指导与国际合作与实验室主流谱系深度交织，是理解CAD&CG实验室"CAD内核—图形仿真"支线谱系与产业转化路径的关键节点人物。
