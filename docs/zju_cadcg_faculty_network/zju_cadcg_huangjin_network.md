## 二、教育背景与职业履历

黄劲的学术生涯与浙江大学CAD&CG实验室紧密相连。根据百度百科收录信息及浙大官方主页资料，其学术时间线可梳理如下：

**教育背景方面**，黄劲的博士毕业于浙江大学CAD&CG实验室，师从鲍虎军教授（其博士论文获2008年CCF优秀博士学位论文奖，属于鲍虎军所指导的获全国百篇优博/CCF优博的四篇博士论文之一；另有少量公开资料未明确标注其导师姓名，故师承关系以主流记载为准）。其博士论文研究聚焦于数字几何处理方向。早期职业经历中，黄劲曾于2003至2006年在微软亚洲研究院（Microsoft Research Asia）担任访问学生/研究员。

**职业履历方面**，由于其博士论文于2008年获CCF优秀博士论文奖，可推测其博士毕业时间约为2007年前后。2008年，黄劲曾访问香港中文大学，与韩秋孙（Hanqiu Sun）教授合作。2009年，黄劲晋升为浙江大学副研究员。2012至2014年间，黄劲赴美国加州理工学院（Caltech）进行学术访问，与国际著名几何处理学者Mathieu Desbrun开展合作研究。2015年，黄劲获国家自然科学基金优秀青年科学基金（优青）资助（项目编号61522209），并晋升为教授。此后至今，黄劲一直在浙江大学CAD&CG实验室任教，从事几何处理与物理仿真方向的科学研究与人才培养。

在其职业生涯中，黄劲主持或参与了多项国家级科研项目，包括国家重点研发计划（No. 2020AAA0108901, 2017YFB1002703）、国家自然科学基金重点项目（61732016）、973计划（2009CB320801）、863计划等，并获得了通用汽车（General Motors）、上海核工程研究设计院（SNERDI）、华为（Huawei）等产业界项目的资助。

## 三、学生培养情况

根据黄劲教授个人主页（http://www.cad.zju.edu.cn/home/hj）所列信息，其指导（含联合指导）的博士生名单如下（其中星号*标注的为已毕业学生）：Shuang Wu，Haoran Sun，*Xiaohu Zhang*，*Chongyao Zhao*，*Shiyi Wang*，*Jiong Chen*，*Zeyun Shi*，*Xianzhong Fang*，*Siwang Li*，*Yao Jin*，*Zherong Pan*，*Tengfei Jiang*，*Muyang Zhang*，*Lu Chen*，*Wei Feng*。以下选取代表性学生进行详细介绍。

### 1. 江腾飞（Tengfei Jiang）（已毕业博士，指导学生）

江腾飞是黄劲早期培养的博士生之一，其博士研究聚焦于四边形/六面体重网格化（quadrilateral/hexahedral remeshing）领域。江腾飞与黄劲合作发表了多篇高水平论文，其中最具代表性的工作是2015年发表于ACM Transactions on Graphics（TOG）的论文"Frame Field Generation through Metric Customization"，该论文由江腾飞、方显中、黄劲、鲍虎军、Yiying Tong（密歇根州立大学）和Mathieu Desbrun（Caltech）合作完成，是帧场引导网格生成方向的标志性工作。此外，二人还合作完成了六面体网格生成（Automatic Frame Field Guided Hexahedral Mesh Generation）的技术报告。江腾飞与黄劲还于2015年在《计算机辅助设计与图形学学报》上发表了四边形与六面体自动重网格化技术的综述论文。江腾飞毕业后的具体去向有待进一步核实（待核实）。

### 2. 方显中（Xianzhong Fang）（已毕业博士，指导学生）

方显中是黄劲指导下在几何处理领域取得突出成果的博士生。其代表性工作包括2016年发表于ACM TOG的"All-Hex Meshing using Closed-Form Induced Polycube"（与徐巍巍、鲍虎军、黄劲合作），以及2018年发表于ACM TOG的"Quadrangulation through Morse-Parameterization Hybridization"（与鲍虎军、Yiying Tong、Mathieu Desbrun、黄劲合作）。后者提出了一种将Morse理论与参数化方法相结合的混合四边形网格化方法，兼具理论保证与实际效率，是该领域的重要进展。方显中毕业后具体去向有待核实（待核实）。

### 3. 陈炯（Jiong Chen）（已毕业博士，指导学生）

陈炯的研究方向涵盖物理仿真与几何处理的多 个子领域。其代表性工作包括2018年发表于ACM TOG的"Numerical Coarsening using Discontinuous Shape Functions"（与鲍虎军、Tianyu Wang、Mathieu Desbrun、黄劲合作），提出了一种基于不连续形函数的数值粗化方法，在物理仿真领域具有重要应用价值。此外，陈炯还参与发表了布料压缩相关工作"Cloth Compression using Local Cylindrical Coordinates"（发表于The Visual Computer, 2017），该工作与香港中文大学韩秋孙教授合作完成。陈炯毕业后具体去向有待核实（待核实）。

### 4. 施泽云（Zeyun Shi）（已毕业博士，指导学生）

施泽云的博士研究聚焦于几何对称性检测与几何处理。其代表性工作是2016年发表于Eurographics Symposium on Geometry Processing（SGP）的论文"Symmetry and Orbit Detection via Lie-Algebra Voting"（与Pierre Alliez、Mathieu Desbrun、鲍虎军、黄劲合作），提出了一种基于李代数投票机制的对称性自动检测方法，该方法利用李群的数学结构实现鲁棒的几何变换检测，是几何处理领域的创新性工作。该论文的合作者包括法国INRIA的Pierre Alliez和当时在Caltech的Mathieu Desbrun，体现了黄劲课题组的国际学术合作网络。施泽云毕业后具体去向有待核实（待核实）。

### 5. 潘哲荣（Zherong Pan）（已毕业博士，联合指导学生）

潘哲荣是黄劲联合指导的博士生，其研究涉及物理仿真与机器人学交叉领域。潘哲荣参与了多项仿真方向的论文工作，包括与黄劲、鲍虎军等人合作发表的纹理合成与仿真相关论文。潘哲荣毕业后在机器人仿真领域继续发展（具体去向待核实）。

### 6. 孙浩然（Haoran Sun）（在读博士，指导学生）

孙浩然是黄劲当前指导的博士研究生。2024年，孙浩然作为第一作者、黄劲作为通讯作者的论文"GauWN: Gaussian-smoothed Winding Number and its Derivatives"被SIGGRAPH Asia 2024录用。该论文提出了高斯平滑卷绕数（高卷数）这一新型几何处理工具，能够将隐式与显式几何表达可微可导地耦合在统一优化框架中，应用于曲线自交解除、交互编辑与偏移等场景。该工作由鲍虎军和黄劲教授团队共同完成，体现了两位教授长期合作的科研模式。

### 7. 李思旺（Siwang Li）（已毕业博士，指导学生）

李思旺是黄劲指导的博士生，参与了弹性运动编辑等物理仿真方向的研究。其代表性工作包括发表于ACM TOG的"Space-Time Editing of Elastic Motion through Material Optimization and Reduction"（与黄劲、Fernando de Goes、Mathieu Desbrun、鲍虎军等人合作），该工作利用材料优化与约简方法实现弹性运动的时空编辑，是物理仿真与动画编辑领域的重要贡献。李思旺毕业后具体去向有待核实（待核实）。

### 8. 赵崇曜（Chongyao Zhao）（已毕业博士，指导学生）

赵崇曜是黄劲指导的已毕业博士生，其具体研究方向与毕业去向有待进一步核实（待核实）。根据黄劲主页信息，赵崇曜已在毕业学生名单中列出，表明其已完成博士学位论文答辩并毕业。

**学生培养总结**：黄劲教授至今已培养至少15名博士生（含联合指导），其中已毕业者至少10名。其学生研究方向覆盖几何处理（重网格化、四边形化、对称性检测）、物理仿真（数值粗化、弹性体编辑、布料仿真）等核心方向。多位学生以第一作者身份在ACM TOG（SIGGRAPH/SIGGRAPH Asia）等计算机图形学顶级期刊/会议发表论文，体现了黄劲课题组在高水平人才培养方面的卓越能力。

## 四、学术合作网络

### 4.1 实验室内部合作

黄劲在浙江大学CAD&CG实验室内部最重要的学术合作伙伴是**鲍虎军**教授。鲍虎军是国家杰出青年基金获得者、教育部长江学者特聘教授、国家"万人计划"入选者，曾任浙江大学CAD&CG国家重点实验室主任。黄劲与鲍虎军的合作关系贯穿其整个学术生涯，二人联合发表了大量ACM TOG论文，包括"All-Hex Meshing using Closed-Form Induced Polycube"（2016）、"Frame Field Generation through Metric Customization"（2015）、"Quadrangulation through Morse-Parameterization Hybridization"（2018）、"Numerical Coarsening using Discontinuous Shape Functions"（2018）等。鲍虎军团队曾荣获2013年国家自然科学奖二等奖，其所指导的四篇博士论文分别获全国百篇优秀博士论文和CCF优秀博士论文，黄劲即为其优秀毕业生之一。

实验室内部的其他合作者还包括**金小刚**（Xiaogang Jin）教授，金小刚是CAD&CG实验室的资深教授，研究方向涵盖计算机动画、群体行为仿真等，与黄劲同属实验室的核心教师团队。此外，**徐巍巍**（Weiwei Xu）研究员也是重要的论文合作者，参与了All-Hex Meshing等工作。

### 4.2 跨机构合作

在国内层面，黄劲与多家高校和研究机构保持着学术合作关系。2022年，黄劲参与了CCF CAD&CG专委会走进先临三维的学术活动，与**刘利刚**（中国科学技术大学教授）、**冯结青**（浙江大学教授，CCF CAD&CG专委会副主任）、**徐岗**（杭州电子科技大学教授）、**缪永伟**（杭州师范大学教授）等国内几何处理与图形学领域的学者共同进行产学研讨。黄劲还参与了CSIAM GDC（中国工业与应用数学学会几何设计与计算专业委员会）的学术活动，与该领域的国内学者网络有着广泛联系。

在跨学科合作方面，2022年黄劲团队与浙江大学地球科学学院**李卫军**研究员团队合作，在JGR: Atmospheres和Geophysical Research Letters上联合发表了关于大气黑碳气溶胶光吸收的研究。两个团队联合研发了全球首套仿真黑碳建模工具EMBS（Electron-Microscope-to-BC-Simulation），将透射电镜单颗粒分析与计算机三维仿真技术结合，突破了三维仿真模拟黑碳单颗粒光学特性的技术难题。这一合作展示了黄劲在跨学科研究方面的能力。

此外，黄劲还与**香港中文大学**韩秋孙（Hanqiu Sun）教授保持长期合作关系。2008年黄劲曾访问香港中文大学，此后陈炯等学生与韩秋孙合作发表了布料压缩相关论文（The Visual Computer, 2017）。

### 4.3 国际合作

黄劲最重要的国际学术合作伙伴是**Mathieu Desbrun**教授。Desbrun是国际著名几何处理学者，曾任加州理工学院（Caltech）教授，后转任法国INRIA/Ecole Polytechnique。2012至2014年间，黄劲在Caltech Desbrun课题组进行为期两年的学术访问。这次访问奠定了双方长期的深度合作关系，Desbrun作为合作者参与了黄劲团队的多项重要论文，包括"Frame Field Generation through Metric Customization"（TOG 2015）、"Quadrangulation through Morse-Parameterization Hybridization"（TOG 2018）、"Numerical Coarsening using Discontinuous Shape Functions"（TOG 2018）、"Symmetry and Orbit Detection via Lie-Algebra Voting"（SGP 2016）、"Space-Time Editing of Elastic Motion"（TOG）等。Desbrun的合作显著提升了黄劲课题组的国际学术影响力。

黄劲的另一重要国际合作伙伴是密歇根州立大学的**Yiying Tong**教授。Tong教授是几何处理与物理仿真领域的知名学者，参与了黄劲团队多项网格生成方向的论文工作。

此外，法国INRIA的**Pierre Alliez**教授（著名几何处理学者）也是黄劲的合作者之一，参与了上述对称性检测论文（SGP 2016）。**Fernando de Goes**（当时在Caltech/ Pixar）也参与了弹性运动编辑方向的论文合作。

## 五、业界合作关系深度分析

### 5.1 产业技术合作

黄劲教授的研究工作具有显著的产业应用属性，其几何处理与物理仿真技术在工业领域有广泛的应用场景。根据其个人主页信息，黄劲的研究获得了多家产业伙伴的资助：

- **通用汽车（General Motors）**：几何处理技术在汽车车身设计与曲面建模中有直接应用，黄劲获得了通用汽车的项目资助，开展几何计算相关研究。
- **上海核工程研究设计院（SNERDI）**：SNERDI是中国核工程领域的重要研究机构，黄劲与之合作的可能方向包括有限元网格生成（六面体网格化技术在工程仿真中的应用）等。
- **华为（Huawei）**：黄劲获得了华为的项目资助。华为在图形渲染、AR/VR、数字孪生等领域有大量技术需求，黄劲的几何处理与仿真技术可为其提供算法支持。2022年CSIAM GDC讲习班的资料中也提及华为技术有限公司参与了该学术活动。

此外，2022年黄劲参加了CCF CAD&CG专委会走进**先临三维科技股份有限公司**的产学研研讨会。先临三维是国内高精度三维视觉技术领域的领先企业，专注于三维数字化技术（3D扫描、3D打印），与黄劲的几何处理研究有着天然的契合点。黄劲参与此类学术产业交流活动，体现了其对产学研结合的重视。

黄劲团队还与**浙江大学科技成果转化**方面有实际案例。2016年浙江大学曾公示"计算机科学与技术学院14项科技成果普通实施许可"，黄劲的几何处理相关专利技术可能包含其中。

### 5.2 创业孵化与技术转化

目前未检索到黄劲教授直接参与创业或孵化企业的公开信息。但其研究领域的产业转化潜力显著：六面体网格生成技术在CAE（计算机辅助工程）仿真软件中具有核心地位，四边形/六面体重网格化技术被广泛用于Ansys、ABAQUS等工程仿真软件。黄劲在通用汽车、SNERDI等工业项目中积累的工程经验，为其研究成果的产业转化提供了基础。

黄劲团队与浙大地球科学学院合作的EMBS（黑碳建模工具）是全球首套此类仿真工具，具有潜在的工具软件化和产业转化价值。此外，黄劲团队的多项国家发明专利（约10项）在几何处理与仿真领域也具备技术许可与转化的可能。

需要指出的是，浙大CAD&CG实验室整体有着良好的产业转化传统。实验室与网易、阿里巴巴等杭州本地科技企业有着广泛的产学研合作，黄劲作为实验室核心教师，在这一生态中扮演着重要角色。

## 七、Connection圈层总结

黄劲教授的学术关系网络可从以下圈层进行总结：

**第一圈层——浙大CAD&CG实验室核心圈**：这是黄劲学术网络的中心，核心人物包括鲍虎军教授（长期合作导师/伙伴）、金小刚教授、徐巍巍研究员等。黄劲与鲍虎军的合作关系是其学术产出最重要的基础，二人联合署名的ACM TOG论文是其高产学术产出的主力。该圈层还包括黄劲指导的15名博士生群体，构成了黄劲课题组的研究主力。

**第二圈层——国内几何处理学术圈**：包括刘利刚（中国科学技术大学）、冯结青（浙江大学）、徐岗（杭州电子科技大学）、缪永伟（杭州师范大学）等通过CCF CAD&CG专委会和CSIAM GDC建立的国内学术合作网络。这一圈层使得黄劲在国内几何设计与计算领域具有广泛的学术影响力。

**第三圈层——国际合作圈**：以Mathieu Desbrun（Caltech/INRIA）为核心，延伸至Yiying Tong（密歇根州立大学）、Pierre Alliez（INRIA）、Fernando de Goes等国际几何处理领域的顶尖学者。2012-2014年Caltech的访问经历是这一圈层形成的关键节点。这一合作关系不仅带来了高质量的联合论文产出，也使黄劲课题组在国际几何处理社区中获得高度可见度。

**第四圈层——产业合作圈**：包括通用汽车、SNERDI、华为等技术资助方，以及先临三维等通过产学研活动建立联系的企业。这一圈层的合作驱动了黄劲研究在工程仿真、汽车设计、三维数字化等领域的实际应用。

**第五圈层——跨学科合作圈**：以与浙大地球科学学院李卫军研究员的合作为代表，展示了黄劲的几何处理技术在非计算机科学领域的应用拓展能力。

总体而言，黄劲教授的学术网络呈现"以浙大CAD&CG实验室为基座、以Caltech/Desbrun合作为国际桥梁、以NSFC优青为学术标签、以通用汽车/华为为产业支撑"的多层次结构。其在几何处理与物理仿真领域的影响力，既源于自身的学术原创性，也得益于与鲍虎军-Desbrun这一国内外双轨合作的独特优势。培养学生方面，黄劲已形成从重网格化、物理仿真到几何表达等方向的完整人才梯队，多名毕业生在ACM TOG等顶级期刊以第一作者身份发表论文，体现了其在学术传承上的卓越能力。
