## 二、教育背景与职业履历

刘新国的学术生涯扎根于浙江大学。根据其官方主页（https://person.zju.edu.cn/xgliu/ 及 http://www.cad.zju.edu.cn/home/xgliu ）的自述，他于1991年至2001年在浙江大学学习，分别于1995年和2001年获应用数学专业学士学位和博士学位，求学期间师从彭群生教授（其2000年发表于《软件学报》的论文《增量几何压缩》即与鲍虎军、彭群生联合署名，与这一师承背景一致）。其博士学位论文题为"几何压缩"（Geometry Compression），该论文入选2003年全国优秀博士学位论文，这是国内博士论文的最高荣誉之一。需要指出的是，网络上有少量资料将其博士背景误写为哈佛大学、本科误写为中国科大等，均无可靠来源支持——刘新国的本科与博士学位均在浙江大学取得，其专业为应用数学（而非计算机科学），方向为计算几何与计算机图形学。

在职业履历方面，刘新国于2001年至2006年在微软亚洲研究院（Microsoft Research Asia, MSRA）工作，先后任职副研究员（Associate Researcher）和研究员（Researcher）。他在MSRA期间隶属于Internet Graphics（IG）组和Visual Computing（VC）组，从事计算机图形学方向的基础研究，期间申请并取得授权4项美国发明专利。在微软亚洲研究院期间，他与沈向洋（Heung-Yeung Shum）、郭百宁（Baining Guo）、Peter-Pike Sloan、John Snyder等国际知名学者有密切合作，发表了多篇ACM SIGGRAPH论文，在预计算辐射度传输（Precomputed Radiance Transfer, PRT）、双向纹理函数（BTF）合成等方向做出了重要贡献。

2006年4月，刘新国离开微软亚洲研究院，正式加入浙江大学计算机科学与技术学院、CAD&CG国家重点实验室，任教授、博士生导师。同年入选教育部"新世纪优秀人才支持计划"。2007年，他在美国卡内基梅隆大学（Carnegie Mellon University, CMU）计算机学院进行访问研究。从2006年至今，刘新国一直在浙江大学CAD&CG实验室从事计算机图形学、视觉与人工智能相关的应用基础研究。

从时间线来看，刘新国的职业生涯可以分为三个阶段：（1）浙江大学求学阶段（1991-2001），在应用数学领域打下坚实的几何与计算基础；（2）微软亚洲研究院工业研究阶段（2001-2006），在图形学前沿研究与产业技术转化方面积累经验；（3）浙江大学学术研究阶段（2006年至今），作为教授和博士生导师持续培养人才并产出高水平研究成果。其个人主页最后一次更新时间为2018年9月14日，但2025年仍有以他为作者的研究论文发表（如JCST上的"Efficient and Structure-Aware Three-Dimensional Reconstruction via Differentiable Primitive Abstraction"），表明其仍在持续活跃于学术研究前沿。

## 四、学术合作网络

### 4.1 实验室内部合作

刘新国所在的浙江大学CAD&CG全国重点实验室是国内计算机图形学领域的顶尖研究机构，实验室历任主任包括石教英教授、彭群生教授和鲍虎军教授，现任主任为周昆教授。刘新国在实验室内部有紧密的合作网络：

**鲍虎军（Hujun Bao）**：长江学者、国务院政府特殊津贴专家，是刘新国最频繁的实验室内部合作者。在刘新国的论文列表中，鲍虎军出现在几乎所有重要论文中，包括ACM SIGGRAPH 2005的"Large mesh deformation using the volumetric graph Laplacian"、ACM SIGGRAPH 2006的"Subspace Gradient Domain Mesh Deformation"以及多篇Pacific Graphics和Computer & Graphics论文。鲍虎军与刘新国的合作跨越了网格变形、预计算辐射度传输、几何处理等多个方向。

**彭群生（Qunsheng Peng）**：CAD&CG实验室前任主任，资深教授，是刘新国在浙大求学期间的博士导师。彭群生出现在刘新国多篇早期论文中，包括2001年Computer Graphics Forum上的"Constrained Fairing for Meshes"和2002年Graphical Models上的"A Novel Volume Constrained Smoothing Method for Meshes"，以及2000年《软件学报》的《增量几何压缩》（与鲍虎军三人联合署名）。彭群生是中国计算机图形学领域的先驱学者之一。

**周昆（Kun Zhou）**：现任实验室主任，教授，是刘新国在MSRA时期和回归浙大后的重要合作者。周昆同样曾在微软亚洲研究院工作，两人合作的论文包括ACM SIGGRAPH 2005和2006的多篇论文。周昆于2024年获得ACM SIGGRAPH Test-of-Time Award，是亚洲团队首次获得该奖项。

**黄劲（Jin Huang）**：教授、博士生导师，CAD&CG实验室核心成员，师从鲍虎军教授。黄劲是刘新国论文列表中出现频率最高的合作者之一，担任多篇SIGGRAPH和Pacific Graphics论文的第一作者。黄劲于2008年获得CCF优秀博士学位论文奖，2009年晋升副研究员，2015年获国家优秀青年基金资助，研究方向为数字几何处理和物理模拟。黄劲与刘新国有极为密切的学术合作关系，二人在MSRA背景、几何处理方向上高度重叠，是实验室同代际的核心合作者。

**王锐（Rui Wang）**：CAD&CG实验室成员，与刘新国在预计算辐射度传输、球面调和指数软阴影等渲染方向有深入合作，共同发表了Euro Graphics 2007和ACM SIGGRAPH 2006等论文。

**许威威（Weiwei Xu）**：CAD&CG实验室长聘教授、教育部长江学者，同样有微软亚洲研究院工作经历（网络图形组研究员），与刘新国有共同的MSRA背景。许威威的研究方向为智能图形图像处理，其开发的三维注册和重建技术在先临三维扫描仪、百度阿波罗自动驾驶仿真、华为河图大场景重建中有产业应用。

## 五、业界合作关系深度分析

### 5.1 产业技术合作与专利

刘新国在产业技术合作方面有独特的优势，这主要得益于他在微软亚洲研究院五年的工业研究经历。

**微软亚洲研究院期间的产业化成果**：在MSRA工作期间（2001-2006），刘新国申请并取得授权4项美国发明专利，主要集中在预计算辐射度传输渲染（Precomputed Radiance Transfer for Rendering Objects，专利发明人包括John Snyder、Peter-Pike Sloan、Xinguo Liu、Heung-Yeung Shum）和双向纹理函数等方面。这些技术对微软产品的图形渲染管线有潜在贡献。他在MSRA的IG组和VC组从事的研究具有明确的产业应用导向，涉及实时渲染、纹理合成等工业级图形技术。

**CAD&CG实验室的产业生态**：刘新国所在的CAD&CG实验室整体上与产业界有密切联系。实验室同事许威威开发的三维注册和重建技术已应用于先临三维扫描仪、百度阿波罗自动驾驶仿真和华为河图大场景重建等产业项目。同事黄劲的研究受到通用汽车（General Motors）等企业的项目资助，涉及物理模拟在汽车工业中的应用。2022年，CCF CAD&CG专委会组织了"走进先临三维"活动，刘新国的多位实验室同事（冯结青、黄劲、李玺等）参与了与先临三维的高精度3D视觉技术交流，体现了实验室在3D扫描与3D打印方向的产业布局。

**3D打印与数字制造**：刘新国的研究方向包括几何建模和数字几何处理，这些是3D打印技术的核心基础。虽然其个人主页未明确列出3D打印的产业化项目，但CAD&CG实验室在几何处理、网格处理方面的技术积累与3D打印产业密切相关。实验室整体在先进制造、工业CAD等方向有深厚的产业联系。

**技术转化潜力**：刘新国在几何压缩（其博士论文方向）、网格变形（SIGGRAPH论文方向）和渲染技术（PRT系列论文）方面的研究成果均有明确的工业应用价值。几何压缩技术可应用于3D模型的网络传输和存储，网格变形技术可应用于动画制作和游戏开发，PRT技术可应用于实时渲染引擎。他在MSRA取得的4项美国发明专利也表明其研究具有直接的技术转化能力。

### 5.2 创业孵化与产学研网络

**学生创业与产业就业**：刘新国培养的学生在产业界有显著的就业分布。其博士生吴子朝在杭州电子科技大学任教的同时，担任杭电-网易游戏研发产教融合示范基地负责人，指导本科生已有30余人在网易游戏、腾讯游戏就业。这一产教融合模式将刘新国的学术谱系延伸到了游戏产业的人才培养中。

**微软校友网络**：刘新国作为微软亚洲研究院的校友，天然处于一个强大的产学研网络之中。MSRA校友在中国科技产业中占据重要位置，许多校友后来成为科技企业的高管或创业者。刘新国在MSRA期间的合作者沈向洋后来担任微软全球执行副总裁，郭百宁在微软继续从事图形学研究。这些MSRA校友关系为刘新国及其学生的产业合作提供了潜在的网络资源。

**区域产业生态**：刘新国所在的杭州地区是中国数字经济的重要中心，拥有阿里巴巴、网易等互联网企业以及先临三维等3D技术企业。CAD&CG实验室与杭州本地科技企业的地理 proximity 为产学研合作提供了便利。从实验室整体来看，与先临三维（3D扫描与打印）、百度（自动驾驶仿真）、华为（大场景重建）、网易（游戏）等企业均有技术合作或人才输送关系。

**学术-产业桥梁角色**：刘新国兼具学术研究（浙大教授）和工业研究（MSRA研究员）的双重背景，这使他在学术与产业之间扮演着桥梁角色。他的研究方向——几何处理、渲染、人脸建模等——既有深厚的理论基础，又有明确的产业应用场景（游戏、VR/AR、3D打印、数字人等）。在当前AIGC（AI生成内容）和数字人技术快速发展的背景下，刘新国的技术积累具有显著的产业转化潜力。

## 七、Connection圈层总结

刘新国的学术关系网络可以划分为以下几个圈层：

**第一圈层（核心学术圈）——浙江大学CAD&CG实验室内部**：鲍虎军（长江学者、最频繁合作者）、彭群生（实验室前主任、博士求学期间导师之一）、周昆（实验室现任主任、MSRA共同经历者）、黄劲（密切合作者、数字几何处理方向）、王锐（渲染方向合作者）、许威威（MSRA校友、同在实验室）。这一圈层构成了刘新国日常科研合作的核心网络，涵盖了从几何处理、物理模拟到渲染、三维视觉等图形学的核心子领域。

**第二圈层（微软亚洲研究院圈层）——MSRA校友与合作者**：沈向洋（前微软全球执行副总裁）、郭百宁（MSRA研究员）、Peter-Pike Sloan（PRT技术先驱）、John Snyder（几何与渲染专家）、任重（软阴影技术、后加入浙大）。这一圈层是刘新国在2001-2006年MSRA工作期间建立的学术人脉，这些合作关系产出了多篇ACM SIGGRAPH论文，在预计算辐射度传输、双向纹理函数等方向有重要的学术影响。MSRA校友网络也为产学研合作提供了资源。

**第三圈层（国内高校合作圈）——跨机构学术网络**：苗兰芳（浙江师范大学，ZJU CAD&CG博士）、秦绪佳（浙江工业大学，ZJU CAD&CG博士后）、曹卫群、王平安（香港中文大学）、黄田津（香港中文大学，后加入香港城市大学）。这一圈层主要通过学生培养和博士后流动形成，将刘新国的学术影响扩展到了浙江省内多所高校以及香港地区。

**第四圈层（学生培养圈）——学术谱系**：吴子朝（杭州电子科技大学副教授，产学研融合突出）、康菁菁、程轩、寿如阳、陈坤、蒋剑、郑家祥等。刘新国自2006年回浙大以来培养的硕博学生，其去向涵盖高校教职（吴子朝在杭电）、产业就业等多个方向。吴子朝在交互动作生成和游戏产业方向的拓展，将刘新国的学术谱系延伸到了更广泛的应用领域。

**第五圈层（产业合作圈）——产学研转化网络**：微软（4项美国专利、PRT渲染技术）、先临三维（3D扫描与打印，实验室整体合作）、通用汽车（黄劲的产业合作）、网易游戏（吴子朝的产教融合）、百度（实验室整体合作）、华为（实验室整体合作）。刘新国凭借其MSRA工业研究背景和浙大学术地位，在图形技术的产业化方面具有独特的桥梁优势。

**网络结构特征**：刘新国的学术关系网络呈现出"双重根脉"的鲜明特征——一方面扎根于浙江大学CAD&CG实验室的学术传统（从彭群生到鲍虎军到周昆的学术传承），另一方面深受微软亚洲研究院工业研究文化的影响（与沈向洋、郭百宁等的合作）。这种学术-产业双轨背景使他在中国计算机图形学界具有独特的定位：既能在SIGGRAPH等顶级学术会议上产出高水平论文，又具备将研究成果向产业转化的意识和能力。从圈层结构来看，其网络以浙大CAD&CG实验室为核心，向MSRA校友圈、国内高校圈和产业合作圈三个方向辐射，形成了一个覆盖学术研究、人才培养和产业转化的完整生态系统。
