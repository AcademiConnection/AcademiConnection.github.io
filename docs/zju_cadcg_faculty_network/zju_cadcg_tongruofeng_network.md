## 二、教育背景与职业履历

童若锋的学术起点在数学。他1991年毕业于复旦大学应用数学专业获学士学位，随后进入浙江大学攻读计算机辅助几何设计与计算机图形学方向的研究生，1996年在浙江大学应用数学专业获博士学位，师从汪国昭教授与金通洸教授——这一师承将其纳入浙大数学系CAGD（计算机辅助几何设计）谱系，与CAD&CG实验室"石教英—彭群生"创建的图形学主线并行交融，构成实验室几何造型支线的知识源头之一。

1996年博士毕业后，童若锋留浙江大学计算机系任教，1998年9月晋升副教授。1999年10月至2001年9月，他赴日本广岛大学（Hiroshima University）智能系统与造型实验室从事博士后研究。回国后长期在浙大工作，逐步晋升为教授、博士生导师，并曾担任浙江大学计算机科学与工程系系主任、CAD&CG国家重点实验室（2022年后重组为计算机辅助设计与图形系统全国重点实验室）副主任等职务。他长期主持与唐敏联合运行的GIVE实验室（数字媒体处理与企业智能计算实验室），研究方向覆盖几何处理、图像与视频处理和企业智能计算。

科研方面，童若锋作为负责人或主要人员承担了国家"八五"攻关、863计划、973计划、国家自然科学基金（含面上项目61572424"针对着装图像的参数化人体重建"、61972342"基于语义参数化模型的高质量人脸重建"）及浙江省重大科技攻关项目等多项课题。2024年7月，他在第十二届中国科大《计算机图形学前沿》暑期课程上作题为《几何引擎的关键技术和进展》的报告，系统论述了几何引擎作为CAD系统基石的技术体系（混合建模、NURBS曲面求交、曲面过渡、补洞、计算加速）及AIGC生成CAD模型的精度问题，反映其当前聚焦国产工业软件几何引擎的战略方向。

## 四、学术合作网络

### 4.1 实验室内部合作

童若锋是GIVE实验室的组织核心，与唐敏构成浙大CAD&CG实验室内部最稳定的长期合作对（二人联名论文贯穿碰撞检测、布料仿真、几何处理各方向，并连续同期获得国家自然科学基金项目资助61572424/61572423、61972342/61972341）；实验室资深教授董金祥（CAD专家）与林兰芬（医学影像方向）、杜鹏研究员（几何计算方向）构成完整的技术拼图。在实验室层面，他与陈为、周昆、许威威、邹强等不同方向学者的互动依托全国重点实验室平台展开（具体合作论文待核实）。

### 4.2 跨机构合作

童若锋的跨机构合作以医工交叉为突出特色：与浙江大学医学院附属邵逸夫医院（Sir Run Run Shaw Hospital）放射科胡红杰、王芳、陈青庆等医生建立长期合作，围绕肝脏局灶性病变分类、肺结节检测、RECIST标注弱监督分割等课题发表多篇论文（如Modality-Aware Graph Reasoning Network for Focal Liver Lesion Classification等，合作者含浙大计算机学院蔡铭、林兰芬及李宗耀所在的航空航天学院）。在国产工业软件方向，他作为浙江大学代表与深圳泊松软件技术有限公司（创始人张德强）共建联合研发中心，时任计算机学院院长陈刚出席签约，形成"高校—工业软件企业"的深度绑定。国内学术服务方面，他担任第五届"计图"（Jittor）人工智能算法挑战赛专家委员会委员（与白翔、程明明、严骏驰等同列），并参与腾讯犀牛鸟中学科学人才培养计划评审（与胡事民、郭延文等同列）。

### 4.3 国际合作

童若锋最重要的国际合作伙伴是日本立命馆大学（Ritsumeikan University）的陈延伟（Yen-Wei Chen）教授，双方围绕医学图像分析开展了持续二十余年、延续至今的联合研究（近至2025年EEISS会议的弱监督病灶分割、2026年ICASSP的联邦学习个性化全局原型等论文均由双方及林兰芬共同完成），并联合培养了莫少聪等立命馆大学与浙大之间的交流学生。其国际网络的另一源头是1999–2001年日本广岛大学智能系统与造型实验室的博士后经历，这段经历奠定了其与日本学界的长期联系。

## 五、业界合作关系深度分析

### 5.1 产业合作

童若锋的产业合作呈"国际芯片巨头—国产工业软件—医疗装备"三线布局。早期与Intel、Qualcomm等公司开展项目合作（百度百科记载），其学生中张毅彬、成可立等进入Qualcomm（美国）工作。国产工业软件方向是其当前产业合作的重心：2022年9月29日，深圳泊松软件技术有限公司与浙江大学签署合作协议成立工业软件联合研发中心，童若锋出任"浙江大学—深圳泊松工业软件联合研发中心"主任，致力于几何引擎等工业软件关键核心技术攻关——泊松软件是国产几何引擎新势力，其产品对标国外商用几何内核，该合作直接服务于工业软件国产化替代的国家战略。医疗方向通过毕业生进入联影医疗等路径实现成果转化。此外，他与腾讯（犀牛鸟计划评审、计图挑战赛专家委员会）保持学术公益性质的产业界联系。

### 5.2 创业孵化与开源生态

童若锋所在实验室的历届毕业生中形成了可观的创业与产业孵化网络：宋晓峰创办瑞导科技、潘练武创办非奇科技、张桂超等选择创业，更多毕业生进入网易、字节跳动、阿里巴巴、蚂蚁集团、海康威视、华为等企业研发一线；实验室的CAD课程体系（含《计算机图形学课程设计》教材及cgcourse在线课程）为开源教学生态作出贡献。在工业软件开源方面，其课题组近年与唐敏团队联合发布的GPU几何计算工具（gDist、gCDT、MidSurfer等，均附project page与开源代码）正在构建面向几何引擎的开放技术底座。

## 七、Connection圈层总结

童若锋学术关系网络的第一圈层是师承与实验室共同体：其博士导师汪国昭、金通洸将其接入浙大数学系CAGD谱系；在CAD&CG实验室内，他与唐敏近三十年的联合研究构成实验室"CAD几何—图像处理"支线的双核结构，联合运行GIVE实验室并共同培养学生。

第二圈层是医工交叉网络：以林兰芬（浙大计算机学院）为桥接，联结邵逸夫医院放射科临床团队（胡红杰等）与日本立命馆大学陈延伟实验室，形成横跨中日、贯通临床与算法的医学影像智能诊断研究网络，并向联影医疗等国产医疗装备企业输送人才。

第三圈层是国产工业软件网络：以浙大—深圳泊松工业软件联合研发中心主任身份为枢纽，联合计算机学院行政体系（时任院长陈刚）与国产几何引擎企业，对接工业软件自主可控的国家重大需求；在学术服务侧通过计图挑战赛、腾讯犀牛鸟评审等与国内AI学界及产业界保持广泛连接。

第四圈层是学生辐射网络：廖胜辉、董天阳、丁濛等进入高校任教，许莹莹进入之江实验室，彭俪颖进入联影医疗，大量毕业生分布于网易、字节跳动、阿里巴巴及Qualcomm等企业，形成几何引擎、图像处理与智能计算交叉领域的人才扩散链。

总体而言，童若锋是一位以浙大数学CAGD谱系为根、以CAD&CG实验室副主任身份承担组织职能、以"几何引擎国产化+医学影像智能化"为两翼的学者。他既非纯图形学谱系（彭群生—鲍虎军—周昆主轴）的直系传人，也非单纯的人工智能研究者，而是横跨CAGD、图形学、计算机视觉与医学图像的枢纽型人物；其学术网络的历史纵深（汪国昭—金通洸师承）与现实宽度（泊松软件、邵逸夫医院、立命馆大学）共同构成了理解浙大CAD&CG实验室产学研生态不可绕过的一环。
