# 天津大学智慧软件工程团队（TJU-WISE Lab）教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

智慧软件工程团队（TJU-WISE Lab）隶属于天津大学智能与计算学部软件工程系，聚焦软件测试与分析、程序调试与修复、可信人工智能及数据驱动软件工程等研究方向。本系列收录团队核心教师的学术关系网络报告。
