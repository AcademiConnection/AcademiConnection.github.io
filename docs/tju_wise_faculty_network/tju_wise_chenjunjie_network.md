## 二、教育背景与职业履历

陈俊洁的学术训练完成于北京大学，职业发展则全部在天津大学完成，是典型的"北大博士毕业即建团队"的青年学者路径。

**教育背景：**

陈俊洁于2019年7月在北京大学信息科学技术学院获得博士学位（博士期间由北京大学软件研究所团队指导，据公开论文合作记录，其博士阶段的主要指导教师与合作者包括郝丹、张路、熊英飞、谢冰等北京大学软件工程方向教授，其中与郝丹合作最为持久）。博士论文研究聚焦数据驱动的软件测试与调试。2019年，他同时获得CCF优秀博士学位论文奖和北京大学优秀博士学位论文奖，是当年国内软件工程领域最突出的博士毕业生之一。

**职业履历（时间线）：**

- 2019年：博士毕业后加入天津大学智能与计算学部，任软件工程系教师，初创天津大学软件工程团队（TJU-WISE Lab/智慧软件工程团队）并担任团队负责人；
- 入职初期任长聘副教授、特聘研究员，硕士生/博士生导师，主讲"编译原理""软件测试"两门课程；
- 2019—2020年：获ASE 2019、ISSTA 2019两项ACM SIGSOFT杰出论文奖，主持国家自然科学基金青年项目、重点项目课题及CCF-华为胡杨林基金等多个项目；
- 2020—2021年：入选中国科协青年人才托举工程；团队论文获FSE 2020、FSE 2021杰出论文奖及ISSRE 2021最佳研究论文奖（唯一Best Research Paper Award）；
- 2021—2022年：担任CCF-A类会议ASE 2021评审过程主席；获ASE 2022杰出论文奖，累计七项国际会议最佳/杰出论文奖；
- 此后晋升为教授，出任天津大学软件学院副院长；
- 近年：获国家优秀青年科学基金、国家重点研发计划青年科学家项目，研究方向从编译器测试、智能运维扩展至代码大模型效果增强与大模型安全，入选斯坦福大学全球前2%顶尖科学家榜单；与王赞、姜佳君共同领导华为仓颉编程语言编译器的质量保障研究。

## 三、学生培养情况

陈俊洁自2019年在天津大学独立建组以来培养了大批硕士/博士研究生，其学生以软件工程顶会（ICSE、FSE、ASE、ISSTA）一作论文见长，多人获得国际会议最佳论文奖和学生竞赛金牌。以下为核心学生情况：

### 1. 王维靖（硕士毕业生，陈俊洁直接指导的2019级硕士生）

王维靖是陈俊洁在天大最早指导的学生之一。作为第一作者完成的论文《How Long Will it Take to Mitigate this Incident for Online Service Systems?》（AIOps领域首个研究云服务系统异常恢复时间预测的工作，提出深度学习方法TTMPred，在微软20个在线服务系统上开展实证研究）荣获ISSRE 2021唯一最佳研究论文奖，陈俊洁为该文第二作者（指导教师）。该成果由天津大学与微软亚洲研究院合作完成，是天大软件工程团队具有标志性的国际获奖成果。其毕业后的去向公开信息有限。

### 2. 杨林（博士生，2021级，陈俊洁指导）

杨林为天津大学智能与计算学部2021级博士生，是上述ISSRE 2021最佳论文的第三作者，研究方向涉及在线服务系统智能运维与AIOps。作为陈俊洁早期核心博士生之一，他参与了团队与微软亚洲研究院的异常缓解时间预测等合作项目。其他详细培养信息公开有限。

### 3. 杨晨（博士生，本科阶段起由陈俊洁与姜佳君联合指导）

杨晨为天津大学智能与计算学部2018级本科生，本科期间即进入陈俊洁、姜佳君指导的软件工程团队开展研究，以参赛成果《Accelerating Redundancy-Based Program Repair via Code Representation Learning and Adaptive Patch Filtering》（基于代码表示学习与自适应补丁过滤的程序修复加速技术AccPR）荣获ESEC/FSE 2021学生科研竞赛（SRC）本科生组金牌。此后继续在团队攻读研究生，据DBLP合作记录，其近年（2023年起）与陈俊洁合作论文十余篇，研究方向为大模型辅助单元测试生成等智能化软件工程方向。

### 4. 沈庆超（博士生，2020级硕士生起步，陈俊洁指导）

沈庆超为学部2020级硕士生（后继续攻读博士学位），其作为第一作者的论文《A Comprehensive Study of Deep Learning Compiler Bugs》由陈俊洁指导完成并发表于FSE 2021（Research Track），是深度学习编译器（如TVM、MLIR等AI编译基础设施）缺陷研究的代表性工作。据DBLP统计，其与陈俊洁合作论文达17篇（2021—2026年），是团队在深度学习编译器测试方向的核心学生骨干。

### 5. 赵英全（博士毕业生，现任天津大学副研究员，陈俊洁与王赞共同指导）

赵英全为陈俊洁与王赞共同指导的博士生，据DBLP统计与陈俊洁合作论文12篇以上（2022—2026年），研究方向为Java虚拟机（HotSpot、OpenJ9）模糊测试与MLIR测试，博士毕业后留校任天津大学副研究员，实现了"学生—同事"的团队内部循环。他是华为仓颉编译器质量保障研究的第一线骨干，是仓颉测试工作中被官方点名的核心学生之一。

### 6. 闫明（博士生，2021级，陈俊洁与王赞共同指导）

闫明为学部2021级博士生，其作为第一作者的论文《Exposing Numerical Bugs in Deep Learning via Gradient Back-propagation》由陈俊洁、王赞共同指导，发表于FSE 2021（Research Track），提出通过梯度反向传播暴露深度学习数值缺陷的方法，是团队深度学习系统测试方向的代表性成果之一。

### 7. 尤含默（博士生，陈俊洁指导）

尤含默（Hanmo You）为团队博士研究生，据DBLP统计与陈俊洁合作论文13篇（2020—2026年），研究方向为深度学习系统测试与回归缺陷分析。其作为骨干学生参与了团队在深度学习框架与AI基础设施测试方向的系列顶会工作。

### 8. 王栋（博士生，陈俊洁指导）

王栋（Dong Wang）为团队较新的博士研究生，据DBLP统计与陈俊洁自2024年起合作论文已达16篇，是团队产出最迅速的青年学生之一，研究方向为强化学习与软件工程交叉方向，代表了团队向智能化软件工程方向扩展的新一代培养力量。

此外，在华为仓颉编译器质量保障研究中，官方通报明确点名付瑞丰、郭以勒、郑开、樊兴宇等十余名研究生在陈俊洁、王赞、姜佳君带领下参与仓颉编译器测试工作；团队另有田钊（Zhao Tian，变异测试与LLM辅助软件工程方向）等骨干学生。整体来看，陈俊洁的学生培养呈现"顶会一作+国际获奖+企业级项目实战"三位一体的鲜明特色，多名学生毕业后留校或进入学术界与头部企业。

## 五、业界合作关系深度分析

### 5.1 产业合作

陈俊洁团队的产业合作以"基础软件质量保障"为主线，深度嵌入国产基础软件与大型科技企业的核心工程流程：

- **华为（仓颉编程语言编译器质量保障）**：这是团队最具代表性的产业合作。自仓颉编程语言诞生五年以来，陈俊洁、王赞、姜佳君带领赵英全、付瑞丰、郭以勒、郑开、樊兴宇等十余名研究生，深度参与华为仓颉编译器的质量保障研究，提出数据驱动的仓颉编译器系统化测试框架，涵盖基于程序综合的测试程序生成、基于程序变异的测试预言构造、基于代码表示的测试过程加速等技术，成果发表于软件工程领域顶会，天津大学也因此成为深度参与华为仓颉编程语言生态的高校之一（另一深度参与高校为北京航空航天大学，负责仓颉语言其他方面）。此外，陈俊洁还主持CCF-华为胡杨林基金（系统软件专项）等华为合作项目，编译器测试成果在华为落地。
- **微软（亚洲研究院及产品团队）**：与微软亚洲研究院（智能运维方向）开展长期产学研合作，围绕在线服务系统异常缓解时间预测、坏变更识别等真实云运维问题联合发表ISSRE 2021最佳论文及FSE系列论文，合作对象覆盖Microsoft 365与Microsoft Azure产品团队，研究基于微软真实生产系统数据完成。
- **开源基础软件社区**：团队开发的测试方法在GCC、LLVM等开源编译器中发现数百个缺陷，直接回馈国际开源社区。
- **其他企业落地**：据公开介绍，其研究成果应用于华为、百度等多家知名企业；据用户方提供的背景信息，成果亦在华为、国家汽车技术研究中心、海信等企业/机构落地（涉及自动驾驶测试等方向，该部分细节公开信息有限）。

### 5.2 创业孵化与成果转化

就公开信息而言，尚未检索到陈俊洁本人或其学生基于团队技术（仓颉编译器测试、AIOps、代码大模型等）成立初创公司的公开记录，该方面公开信息有限。其成果转化路径目前主要体现为"技术嵌入企业研发流程"模式：测试框架直接进入华为仓颉编译器工具链、AIOps方法进入微软在线服务运维实践、缺陷发现成果回馈GCC/LLVM开源社区。学生培养层面，团队毕业生多进入华为、微软等头部企业及高校任职（如赵英全留校任副研究员），形成了"学界任职+企业核心技术岗位"的双通道输出。这一以工程实效为导向的转化模式，与其"基础软件测试"研究定位高度一致。

**第三圈层（学生梯队，团队内循环）**：沈庆超、赵英全、尤含默、王栋、田钊、杨晨、闫明、王维靖、杨林等骨干学生构成产出主力，其中赵英全已留校完成"学生—同事"转化；学生群体以FSE/ASE/ISSRE一作论文和SRC金牌为标志，是网络中最具活力的节点。

**第四圈层（国际与企业合作网络）**：Hongyu Zhang（纽卡斯尔/新南威尔士）、Lingming Zhang（UIUC）、Shing-Chi Cheung（港科大）、Jun Sun（新加坡管理大学）等国际学者覆盖测试与运维全方向；微软亚洲研究院（及Microsoft 365/Azure）是其最重要的国际企业合作节点；华为（仓颉编译器、胡杨林基金）是其最重要的国内企业合作节点，并延伸至国家汽车技术研究中心、海信、百度等应用场景。

**网络结构特征**：该网络以陈俊洁为绝对中心（DBLP显示其约175篇发表记录、300余位合作者），呈现"青年领军者+双核心团队+强企业绑定"的模式——与多数学院派实验室不同，其网络的产业侧权重极高（华为仓颉、微软AIOps均为深度嵌入式合作而非浅层资助），学术侧则以北大系人脉和国际测试领域顶会圈层为骨干。2023年以来团队产出显著加速，研究重心从编译器测试、智能运维向代码大模型与大模型安全演进，网络正在向AI基础设施质量保障领域扩展。
