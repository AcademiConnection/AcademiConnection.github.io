## 二、教育背景与职业履历

姜佳君的学术训练横跨西北工业大学与北京大学，职业发展则在天津大学完成，是典型的"西工大本科—北大博士—天大建组"的青年学者路径。

- 2011年9月至2015年7月：就读于[西北工业大学](http://www.nwpu.edu.cn/)计算机学院，获计算机科学与技术学士学位。
- 2015年9月至2020年7月：就读于[北京大学](http://www.pku.edu.cn/)软件研究所，获计算机软件与理论博士学位。据其个人主页明确记载，博士导师为熊英飞（Yingfei Xiong）教授、胡振江（Zhenjiang Hu）教授和陈向群（Xiangqun Chen）教授。其中熊英飞为北京大学新体制长聘副教授，研究方向为程序设计语言与软件工程（程序合成、修复与分析），与姜佳君的程序修复研究方向直接对应。

**博士期间海外访问与实习经历：**

- 2017年6月至12月：以访问博士生身份赴澳大利亚纽卡斯尔大学（The University of Newcastle, AU），在张宏禹（Hongyu Zhang）教授指导下开展合作研究。
- 2019年1月至5月：以访问研究学者身份赴美国德克萨斯大学达拉斯分校（The University of Texas at Dallas），在Lingming Zhang教授指导下开展合作研究。Lingming Zhang现为伊利诺伊大学香槟分校（UIUC）副教授，是软件测试与程序修复领域的国际活跃学者。
- 2019年7月至10月：在微软亚洲研究院（Microsoft Research Asia）DKI（Data, Knowledge, Intelligence）组任研究实习生，导师为林庆维（Qingwei Lin）。

**职业履历（时间线）：**

- 2020年7月至2023年12月：加入天津大学智能与计算学部，任预聘制副研究员（Tenure-track Associate Professor）、硕士生导师。
- 2024年1月至今：晋升为长聘副教授（Associate Professor with Tenure）、兼任研究员（Co-Appointed Research Professor）、博士生导师。

## 三、学生培养情况

姜佳君自2020年在天津大学独立培养研究生以来，以其程序修复与程序分析的研究方向为核心，指导和共同指导了多名学生。以下为公开来源可确认的核心学生情况：

### 1. 杨晨（2022级硕士生，姜佳君与陈俊洁共同指导）

杨晨是姜佳君与陈俊洁共同指导的标志性学生。杨晨为天津大学智能与计算学部2018级本科生，本科期间即进入软件工程团队，在姜佳君与陈俊洁的联合指导下开展程序修复方向研究。其参赛成果《Accelerating Redundancy-Based Program Repair via Code Representation Learning and Adaptive Patch Filtering》（基于代码表示学习与自适应补丁过滤的程序修复加速技术AccPR）荣获ESEC/FSE 2021学生科研竞赛（SRC）本科生组金牌。2022年6月，ACM发布2022年度SRC全球总决赛结果，杨晨获得全球季军（本科生组），这是天津大学学生首次获得该比赛荣誉奖项。杨晨此后继续在团队攻读硕士研究生（2022级），并在2024年以第一作者身份发表论文于程序设计语言领域顶级会议OOPSLA 2024（天津大学在程序设计语言领域顶级会议上的首篇论文），指导教师为陈俊洁（通讯作者）与姜佳君，研究面向代码自然性开展。杨晨的成长轨迹清晰呈现了"本科科研入门—SRC获奖—研究生阶段顶会论文"的培养链条，是姜佳君学生培养的代表性成果。

### 2. 李丰杰（硕士生，姜佳君指导）

李丰杰（Fengjie Li）为姜佳君指导的研究生，据姜佳君个人主页的发表论文记录，李丰杰作为第一作者或核心作者在多篇论文中出现，包括ICSME 2025论文《Boosting Redundancy-based Automated Program Repair by Fine-grained Pattern Mining》（获IEEE TCSE杰出论文奖，姜佳君为第一作者、李丰杰为第二作者）、TOSEM 2025论文《Hybrid Automated Program Repair by Combining Large Language Models and Program Analysis》（李丰杰为第一作者，姜佳君为通讯作者）以及ICSE 2025 NIER论文《Evaluating the Generalizability of LLMs in Automated Program Repair》（李丰杰为第一作者，姜佳君为通讯作者）。李丰杰的研究方向为大语言模型与程序分析结合的自动程序修复，是姜佳君在LLM辅助软件工程方向的核心学生骨干。

### 3. 韩佳晨（硕士生/博士生，姜佳君指导）

韩佳晨（Jiachen Han）为姜佳君指导的学生，据个人主页论文记录，其在TOSEM 2026论文《Intent-Aware Defect Pattern Extraction from Singular Examples》中担任第一作者，姜佳君为通讯作者，合作者包括熊英飞、陈俊洁等。该研究提出从单一样例中自动学习可复用缺陷检测模式的方法，提升了方法在实际应用中的可用性。韩佳晨的研究方向为缺陷检测模式提取与自动程序修复，是姜佳君在缺陷自动发现方向的学生骨干。

### 4. 李松睿（学生，姜佳君指导）

李松睿（Songrui Li）为姜佳君指导的学生，据个人主页论文记录，其在FORGE 2026论文《Jailbreaking Large Language Models via Multi-Task Embedding-based Prompt》中担任第一作者，姜佳君为通讯作者；在TOSEM 2026论文《Enhancing Code Model Robustness Against Identifier Renaming via Unified Code Normalization》中担任第二作者，姜佳君为第一作者兼通讯作者。李松睿的研究方向涉及大语言模型安全与代码模型鲁棒性，是姜佳君向AI安全方向扩展的新一代学生。

索晨遥（Chenyao Suo）和王永嘉（Yongjia Wang）出现在OOPSLA 2025论文《DESIL: Detecting Silent Bugs in MLIR Compiler Infrastructure》的作者列表中，该论文由陈俊洁担任通讯作者，姜佳君为共同作者。论文提出了一种创新的MLIR编译器基础设施静默缺陷检测方法。姜佳君个人主页特别提到"Congrats to Chenyao, Yongjia, and Qingchao"，表明这些学生在该工作中发挥核心作用。他们与沈庆超（Qingchao Shen，陈俊洁指导的博士生）共同构成了团队在编译器缺陷检测方向的协作网络。

## 五、业界合作关系深度分析

### 5.1 华为仓颉编译器质量保障（产业合作核心）

姜佳君与陈俊洁、王赞共同主导的华为仓颉编译器质量保障研究，是其最重要的产业合作关系。据天津大学智能与计算学部官方新闻报道，自仓颉编程语言诞生五年来，团队陈俊洁教授、王赞教授、姜佳君研究员带领赵英全、付瑞丰、郭以勒、郑开、樊兴宇等十余名研究生，围绕仓颉编译器测试工作开展深入研究，提出数据驱动的仓颉编译器系统化测试框架，涵盖基于程序综合的测试程序生成技术、基于程序变异的测试预言构造技术、基于代码表示的测试过程加速技术等多项先进技术。相关成果已部署到仓颉编译器的实际测试中。

这一产业合作的特点在于：三位教师明确分工带队十余名研究生，形成了"教师组—研究生群—企业需求"的多层级协作结构。姜佳君在其中的技术贡献与其研究方向高度吻合——程序变换（测试程序生成）、缺陷定位（测试预言构造）和代码表示学习（测试过程加速）恰好对应其三个核心研究方向。这一合作不仅是单次项目资助，而是持续五年的深度嵌入式协作。

### 5.2 CCF-华为胡杨林基金（项目负责人）

2024年，姜佳君作为申请人获得CCF-华为胡杨林基金软件工程专项产业挑战类项目资助，课题为"DSL检查规则自动生成技术"（项目编号A1）。该项目属于产业挑战类，要求申请者基于已有学术成果开发原型系统或工具并实际落地到系统中。这一项目表明姜佳君正将其在程序分析与缺陷检测方面的方法积累延伸至领域特定语言（DSL）检查规则的自动生成方向，进一步深化与华为的产业合作。

### 5.3 微软亚洲研究院（学术实习经历）

姜佳君于2019年在微软亚洲研究院DKI组任研究实习生，导师为林庆维（Qingwei Lin）。该经历虽为博士期间的短期实习，但为其提供了与微软AIOps研究团队连接的机会。CIKM 2021论文（个人主页编号issre23及icse23b附近时段的成果）体现了其在智能运维方向的早期积累。

## 七、Connection圈层总结

姜佳君的学术关系网络以"北大师承—天大团队—企业落地"为主线，呈同心圆结构：

**第一圈层（学术师承，北京大学）**：熊英飞、胡振江、陈向群三位北京大学教授构成其博士阶段联合导师团队，其中熊英飞是合作最持久的导师（从博士期间延续至2026年TOSEM论文合作），其程序修复与程序合成方向直接塑造了姜佳君的研究底色。这一师承关系使姜佳君天然接入北大软件工程学术网络。

**第二圈层（团队核心协作，天津大学TJU-WISE Lab）**：陈俊洁（同为北大出身的团队负责人）是姜佳君最密切的合作者，二人共同指导杨晨等学生，合作论文十余篇；王赞与姜佳君在仓颉编译器质量保障中形成三核心协作结构；刘爽为团队早期合作者。姜佳君在团队中承担程序修复、缺陷定位与程序变换方向的技术角色，与陈俊洁的测试调试方向、王赞的程序分析与DNN测试方向互补。

**第三圈层（学生梯队）**：杨晨（SRC金牌与OOPSLA 2024一作）是姜佳君共同指导下成长最快的标志性学生；李丰杰在LLM辅助程序修复方向作为第一作者发表TOSEM 2025论文；韩佳晨在缺陷检测模式提取方向发表TOSEM 2026论文；李松睿在LLM安全与代码模型鲁棒性方向发表FORGE 2026论文。仓颉编译器团队的赵英全、付瑞丰、郭以勒、郑开、樊兴宇等十余名研究生在三位教师共同带领下参与产业级测试研究。

**第四圈层（国际与企业合作网络）**：Hongyu Zhang（纽卡斯尔大学/现新南威尔士大学）是姜佳君博士阶段访问合作者，也是ICSME 2025杰出论文奖的共同作者，合作关系持续至今；Lingming Zhang（UIUC）是2019年访问合作者，在变异测试与程序修复方向提供学术影响；微软亚洲研究院（林庆维）为其博士阶段实习经历，连接AIOps研究网络；Xiaofei Xie（SUTD/CSIRO）在代码模型鲁棒性方向有最新合作。华为是姜佳君最重要的国内企业合作节点——仓颉编译器质量保障（与陈俊洁、王赞共同领导）和CCF-华为胡杨林基金（DSL检查规则自动生成技术，2024年产业挑战类）构成两条并行的产业合作线。

**网络结构特征**：姜佳君的学术网络以北大师承为根基、以天大团队为平台、以华为产业合作为出口，呈现"青年骨干+核心团队+强企业绑定"的模式。其与陈俊洁的北大同源关系是团队形成的天然纽带，二人在学生共同指导（杨晨）和论文合作上形成深度互补。相比陈俊洁的全局性网络中心角色，姜佳君的网络更加聚焦于程序修复与缺陷检测的技术纵深，同时在仓颉编译器、DSL检查规则等产业场景中实现技术落地。2023年以来，其研究重心从传统程序修复向大语言模型辅助修复、代码模型鲁棒性与LLM安全方向演进，网络正在向AI基础设施质量保障领域扩展。
