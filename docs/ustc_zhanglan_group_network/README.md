# 中科大计算机学院 张兰/LINKE实验室 团队学术关系网络报告

> 报告生成时间：2026年8月24日
> 报告组标识：USTC-ZHANGLAN

## 团队说明

本报告组对应第五批第5组"中科大 张兰组"。经调研核实，中科大具有较高学术影响力的"张兰"为**计算机科学与技术学院张兰教授**（计算机学院副院长，国家优青，首届阿里巴巴达摩院青橙奖获得者），其实际研究方向为**大数据理解、数据隐私保护、数据共享交易与联邦学习**，隶属**李向阳教授领衔的LINKE实验室**，而非用户原始标注的"图像处理/遥感"方向。公开资料中未发现中科大从事图像处理/遥感方向的同名"张兰"教师（武大遥感方向教师张荣、复旦/西南交大等同名学者均非中科大）。本报告以官方核实的真实研究方向为准，特此说明。

张兰本人为该团队的独立PI（拥有自己的博士生团队），同时是LINKE实验室核心成员。因单人团队规模较小，按惯例补充团队学术带头人李向阳教授（信息与智能学部执行部长、计算机学院执行院长，ACM/IEEE双料Fellow）的报告，共同构成LINKE实验室的核心画像。

## 团队核心脉络

**张兰**：清华大学软件学院学士（2007）、清华计算机系博士（2014，博士期间论文署名显示刘云浩/李向阳为资深合作者与推断指导者）、清华博后（2014-2016），2016年加入中科大，2019年特任教授，2022年12月起任教授，现任计算机学院副院长。研究方向为数据智能、隐私保护、联邦学习（代表成果：Kaleido/MobiCom 2015、PCAT/USENIX Security 2023等）。与腾讯、阿里、华为、OPPO等企业有深度合作。核心学生包括高鑫本、袁慕、王俊豪、韩锋、李子充等（据论文署名推断）。

**李向阳**：清华双学士（1995）、UIUC博士（2001，导师滕尚华/哥德尔奖得主），美国伊利诺伊理工大学（IIT）任教十余年（2000-2015），2016年全职加入中科大。IEEE Fellow（2015）、ACM Fellow（2019）、国家杰青、国家特聘专家。LINKE实验室入选首批"全国高校黄大年式教师团队"。主持中科大-蔚来/阿里联合实验室、华为鲲鹏昇腾中心。培养博士30余名，多人在中美高校任教（Yu Wang/UNCC、Wen-Zhan Song、ShaoJie Tang/UT Dallas等）。

**团队关系**：张兰清华博士时期即与李向阳长期合作（据论文署名推断为合作指导关系），2016年随李向阳团队建设中科大LINKE实验室，形成"刘云浩（清华）—李向阳/张兰（中科大）"的物联网与数据安全学术传承链条。LINKE实验室其他核心成员：张燕咏（IEEE Fellow）、杨盘隆、华蓓、张昱、周颢、谈海生、闫宇博、Nikolaos M. Freris等。
