## 二、教育背景与职业履历

张兰的学术生涯起步于清华大学，横跨软件学院与计算机系，之后在中国科学技术大学迅速成长为这一代青年学者中的佼佼者。

**教育阶段：**

- **2003/08–2007/07**：清华大学软件学院，获学士学位。本科期间曾获2007年微软创新杯软件设计大赛中国赛区第三名。
- **2007/08–2014/07**：清华大学计算机科学与技术系，攻读博士学位（硕博连读）。博士期间，2007/07–2009/07担任清华大学软件学院带班辅导员；2010/11–2011/11赴香港科技大学计算机系任研究助理，进行访学研究。博士期间连续四年在移动计算领域旗舰会议ACM MobiCom发表论文共4篇（该会议每年全球仅录用30余篇），并以博士论文成果获2015年CCF优秀博士学位论文奖和ACM中国优秀博士论文奖。
- **2014/07–2016/07**：清华大学软件学院博士后。

**职业阶段：**

- **2016/07–2018/12**：中国科学技术大学计算机科学与技术学院，特任研究员。
- **2019/01–2022/11**：中国科学技术大学计算机科学与技术学院，特任教授。
- **2019年**：获国家自然科学基金优秀青年科学基金（优青）资助。
- **2022/12至今**：中国科学技术大学计算机科学与技术学院，教授。
- **现任**：计算机科学与技术学院副院长（据中国科大新闻网官方报道确认，与连德富、李永坤同为副院长，李向阳任执行院长）。

张兰的职业轨迹体现了从清华到中科大的完美衔接：清华时期的研究奠定了其在隐私保护与移动计算领域的基础，中科大时期则在李向阳教授的LINKE实验室中进一步向物联网安全、联邦学习和跨域感知方向扩展，逐步成长为独立的研究团队负责人和学院管理者。

### 4.3 合作网络图谱分析

张兰的学术合作网络呈现鲜明的"双核驱动"特征：

- **清华内核**（2007–2016）：以刘云浩、李向阳、刘克彬为核心，产出大量MobiCom/INFOCOM/TMC论文，聚焦移动计算、隐私保护和物联网。这构成了张兰的研究根基。
- **中科大内核**（2016至今）：以李向阳为枢纽，连接张燕咏、杨盘隆、周颢、谈海生、华蓓、张昱等同团队教授，形成LINKE实验室的整体合力。张兰在此框架下逐步建立独立的学生团队，研究向联邦学习、安全AI和跨域计算扩展。

两个内核之间存在天然桥梁——李向阳既是清华早期合作者，又是中科大团队带头人，使张兰从清华到中科大的过渡极为顺滑。此外，香港科技大学的访学经历为张兰增加了国际化视野，但目前公开信息中与港科大的持续合作较少。

从合作者分布的时间线看，张兰的研究影响力在2019年（优青+达摩院青橙奖）后显著跃升，合作圈从清华系扩展到更广泛的学术界与工业界。

3. **华为**：据USTC先研院导师页面明确提及，张兰与华为在大数据和隐私保护领域开展了深入的项目合作。具体合作课题和产出待核实。

### 5.2 产学研合作模式

张兰的产学研合作呈现以下特点：

- **前沿技术导向**：与企业的合作项目多数聚焦于"前瞻技术"而非短期产品需求。如腾讯合作项目名为"计算广告前瞻技术研究"，体现了对长期技术趋势的关注。

- **隐私保护为核心切入点**：几乎所有企业合作都围绕数据隐私保护展开。在当前数据安全法规日趋严格的背景下，张兰的研究方向与企业需求高度匹配：腾讯的广告场景需要用户隐私保护，华为的物联网生态需要跨域安全，阿里的数据交易需要联邦学习方案。

- **从项目合作到人才输送**：据推断，张兰团队培养的具备隐私安全和联邦学习背景的学生，毕业后有望进入合作企业从事相关研发工作，形成人才与技术双向流动的良性循环。

- **区块链+物联网安全**：张兰主持的基金委重点项目"基于区块链的物联网安全"（2020–2024）具有明显的产业化指向，区块链技术在数据交易和物联网安全中的应用是企业高度关注的领域。

## 七、Connection圈层总结

张兰教授的学术关系网络可划分为四个圈层：

**第一圈层（核心师承与团队）**：李向阳教授和刘云浩教授构成张兰学术生涯的两大支柱。李向阳既是她清华时期的合作导师，又是中科大LINKE实验室的引进者和长期合作伙伴，贯穿其全部学术轨迹。刘云浩则是清华软件学院时期的指导力量，奠定了张兰在物联网与隐私保护领域的学术根基。两位均为ACM/IEEE Fellow，在国际学术界具有广泛影响力。

**第二圈层（同门与实验室同事）**：LINKE实验室的成员——张燕咏、杨盘隆、周颢、谈海生、华蓓、张昱等——构成张兰在中科大的日常学术生态。清华时期的刘克彬、杨铮等则是她的学术同门与长期合作者。这些人共同构成了中科大计算机学院在物联网与数据安全方向的研究合力。

**第三圈层（独立团队与学生）**：张兰已建立独立的学生培养体系。以高鑫本、袁慕、王俊豪、韩锋、李子充等为代表的博士生/硕士生已在USENIX Security、MobiCom、ICDE等顶级会议形成系统性的发表能力，标志着张兰团队从传统移动计算向AI安全与隐私计算的成功转型。

**第四圈层（业界与国际合作）**：腾讯、阿里巴巴、华为、OPPO、招商银行等企业合作为张兰的研究提供了落地场景和产业资源。阿里达摩院青橙奖不仅是荣誉，更是与阿里技术生态连接的桥梁。国际层面，与Taeho Jung等海外学者的合作、在AIST和微软亚洲研究院的特邀报告，以及在INFOCOM等顶级会议的持续学术服务，使张兰在国际学术社区中保持了良好的可见度。

总体而言，张兰是中国青年计算机学者中"产学研一体化"的典型代表：以清华名校背景和CCF/ACM双优博起步，以优青和青橙奖为加速器，在隐私保护与数据安全这一国家战略需求方向上建立了从基础研究到产业应用的完整链条，同时作为计算机学院副院长承担着学科建设与人才培养的管理职责。其学术网络的厚度和广度在中科大这一代青年教授中处于领先水平。
