## 二、教师角色定位

陈焰是浙江大学特聘教授、互联网安全实验室（LIST）主任，同时保持美国西北大学计算机科学系教授职位，为跨国双任职的网络安全学者。他是UC Berkeley博士（2003年12月，师从Randy H. Katz——云计算与数据中心网络奠基人），IEEE Fellow，研究方向互联网安全、移动安全、网络测量与协议逆向分析，代表工作发表于 IEEE S&P、CCS、NDSS 等安全四大会议及 SIGCOMM/NSDI。

在浙大，他负责计算机学院信息安全方向建设，LIST 实验室与网络空间安全学院（任奎团队等）在人事上交叉互补、建制上并行发展；其在西北大学培养的学生多任教于美国高校，形成横跨太平洋的学术网络。

---

## 三、实验室关系网络的整体观察

LIST 是浙大安全版图中"资深海归双聘"模式的代表：以一位 IEEE Fellow 级学者个人品牌带动方向建设，其学术网络（Berkeley—Randy Katz谱系、Northwesten师生链）与浙大本地安全建制（网安学院、区块链与数据安全全国重点实验室）形成互补而非隶属关系。实验室规模精干，以网络测量与系统安全的基础研究为主轴，产业合作相对学术合作为次要位置。该模式与任奎（全职回国）、杜文亮（全职加盟）的重才引进路线形成对照，是浙大安全学科国际化程度的另一注脚。
