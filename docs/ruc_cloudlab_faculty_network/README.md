# 中国人民大学 存储与数据中心系统组（云计算与大数据系统实验室 CloudLab）教师学术关系网络报告

> 报告生成时间：2026年8月20日

## 团队简介

中国人民大学"存储与数据中心系统组"以信息学院云计算与大数据系统实验室（CloudLab，官网 http://cloudlab.ruc.edu.cn/ ）为主体，由柴云鹏教授（中国人民大学"吴玉章"特聘教授、信息学院院长，清华大学计算机系本博）领衔。实验室依托数据工程与知识工程教育部重点实验室（DEKE）生态运行，是国内数据库系统与存储系统交叉方向最具活力的中坚团队之一。

实验室研究主线覆盖三个层面：一是存储与硬件系统（SSD 直通访问、NVM/闪存缓存、存内计算 PIM 硬件上的数据库与推理加速），代表成果有 R2B（DAC 2022）、PIMANN、MI-LLM 等；二是分布式与键值存储系统（LSM-tree、共识协议 Raft 优化），代表成果有 CruiseDB、vRaft（ICDE 2021 等）；三是云原生数据库与数据湖（Serverless 分析、学习索引、数据库调优），代表成果有 PixelsDB、SIGMOD 2024 学习索引工作等，并孵化了开源项目 Pixels。团队论文发表于 SIGMOD、VLDB、ICDE、ATC、DAC、SIGMOD 等顶会，承担国家重点研发计划课题、国家自然科学基金面上/青年项目等。

实验室与产业界联系紧密：与腾讯共建协同创新实验室（TDSQL 分布式数据库方向），合作成果获 CCF—腾讯犀牛鸟基金卓越项目奖（2021）、深圳市科技进步一等奖（2022），相关专利获中国专利金奖；与华为在数据库一体机、存储优化方向有长期合作。人才梯队上，柴云鹏—卞昊穹构成"存储系统 + 云原生数据系统"的代际传承组合，陈晋川（教授）等关联教师在分布式数据管理、区块链方向形成互补，博士生葛加可、孙殿森、梁俊凯、王洋洋等构成了持续产出顶会成果的学生梯队。

## 研究方向与圈层结构概述

团队的研究布局以柴云鹏为核心枢纽形成三环结构。内环是 CloudLab 师生共同体：柴云鹏与卞昊穹在 PixelsDB（ICDE'25）、Eunomia（DATE'26）、DBdoctor（ICDE'26）等成果上紧密联合署名，并与学生梯队（葛加可、孙殿森、梁俊凯、王洋洋、胡普蕴等）构成高产出内核。中环是人大校内生态：向北接入 DEKE 数据库体系（杜小勇、陈红、陈跃国、覃雄派、卢卫等，均已建有独立学术网络报告，见 [ruc_deke_faculty_network 总览](../ruc_deke_faculty_network/README.md)），形成"数据库内核 + 存储系统"的全谱系覆盖；陈晋川的分布式数据管理与区块链方向则通过腾讯协同创新实验室、苏州校区派驻等制度化纽带与 CloudLab 相连。外环是产业与国际网络：腾讯（TDSQL 协同创新实验室、犀牛鸟基金）、华为（数据库一体机、SSD 优化）构成产业圈双支柱；学术上则经柴云鹏的清华教育背景与国内数据库学术共同体（CCF 数据库专委会、信息存储专委会执行委员）嵌入全国性网络。

## 产业转化亮点

团队产业合作的标志性成果是"人大—腾讯协同创新实验室"模式：以 TDSQL 分布式数据库为共同试验田，合作成果先后获 2021 年 CCF—腾讯犀牛鸟基金卓越项目奖与 2022 年深圳市科技进步一等奖，卞昊穹为第一发明人的专利"数据库事务处理方法、装置及服务器"（应用于 TDSQL）获第二十五届中国专利金奖，实现了数据库领域专利金奖零的突破。开源方面，Pixels（云原生数据湖存储与查询加速框架）已在 GitHub 开源并进入 PolarDB 数据库大赛等教学竞赛生态，团队还建设了人大 OpenHarmony 技术俱乐部。人才培养出口上，毕业生进入腾讯、阿里、华为等企业数据库/存储团队，葛加可入选 2025 CCF 信息系统专委会优秀博士学位论文激励计划（全国 3 名），体现了"顶会论文 + 产业落地 + 开源生态"三位一体的培养成效。
