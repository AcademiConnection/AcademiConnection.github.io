## 二、教育背景与职业履历

卞昊穹的学术路径横跨中国、瑞士两国学术界与腾讯、微软两大工业界，是人大计算机系"本土培养—产业历练—海外深造—回校任教"的代表性样本。2008 年至 2012 年，他在河海大学计算机系完成本科学习，获工学学士学位；2012 年进入中国人民大学计算机系攻读博士学位，2018 年获工学博士学位。博士期间，他曾于 2014—2015 年在微软亚洲研究院（MSRA）系统与算法组任实习研究员，2015—2016 年赴美国俄亥俄州立大学（OSU）进行联合培养。2017 年，他以第一作者（学生身份）在数据库顶级会议 SIGMOD 2017 上发表论文《Wide Table Layout Optimization based on Column Ordering and Duplication》，成为人大历史上第一位以第一学生作者身份在 SIGMOD 发表论文的博士生，此后又在 ICDE 2018 发表该工作的系统演示论文 Rainbow。

关于其博士导师：公开资料未见官方明确记载。从其博士期间论文（SIGMOD'17、ICDE'18、APWeb'15、软件学报综述等）持续与陈跃国、杜小勇、覃雄派等教师联合署名，且陈跃国教授的教师页将卞昊穹的多篇论文收录于本人科研成果来看，学界一般认为其博士阶段主要在陈跃国教授（大数据存储与分析方向）指导下开展研究；背景资料中"师从陈红教授"的说法未获公开资料直接证实，仅供参考。

2018 年博士毕业后，他没有直接留在学术界，而是加入腾讯 TDSQL 团队担任数据库内核高级工程师（2018—2020），从事分布式数据库内核研发。正是在这段产业经历中，他作为第一发明人完成了后来获得中国专利金奖的"数据库事务处理方法、装置及服务器"专利（专利号 ZL202010520559.2，统一 MVCC 机制下的在线 Schema 变更技术），该专利已在腾讯 TDSQL 国产分布式数据库中作为核心技术落地。2020 年，他转入瑞士洛桑联邦理工学院（EPFL）DIAS Lab，在著名数据库学者 Anastasia Ailamaki 指导下从事博士后研究（2020—2023），负责云原生数据系统方向，并担任欧盟 Horizon 2020 重点研发课题 "Sustainable Data Lakes for Extreme-Scale Analytics" 存储引擎子课题负责人。其自 2017 年起主持研发的开源云数据湖仓引擎 Pixels（PixelsDB）正是在"博士期间奠基—腾讯历练—EPFL 深化—回校后扩展"的轨迹中持续演进的标志性系统。

2023 年，卞昊穹回到中国人民大学信息学院计算机系任教（讲师），获聘中国人民大学杰出青年学者；2025 年晋升副教授。回校后他主持多项企业课题与新教师启动金项目，讲授《计算机系统基础 II（ICS2）》《实用数据库开发》，并规划开设《开源软件实践》《开源大数据系统实践》等课程。

## 三、学生培养情况

卞昊穹 2023 年才正式独立建组，学生梯队尚在建设期，但其"教赛研融合"的培养模式已产出可见成果：指导本科生连续两届获全国大学生计算机系统能力大赛 PolarDB 赛道全国亚军，指导 2024 届本科生获北京市优秀本科毕业论文（全校理工科仅 4 人、信息学院 1 人）。据其个人主页，目前组内有博士生 3 人、硕士生 6 人、访问学生 1 人，另有已毕业（ Alumni ）成员 2 人。以下列举代表性学生（部分学生公开信息有限，描述以论文署名与获奖记录为据）。

### 1. 耿东杨（博士生，本人指导）

耿东杨是卞昊穹组内成果最突出的在读博士生，深度参与 Pixels/PixelsDB 系统研发。他是 ICDE'25 演示论文《PixelsDB: Serverless and NL-Aided Data Analytics with Flexible Service Levels and Prices》的第二作者（与 EPFL 的 Anastasia Ailamaki、柴云鹏共同署名），也是 arXiv 论文《Serverless Query Processing with Flexible Performance SLAs and Prices》的合作者；2026 年他以共同第一作者身份在 VLDB 论文《Transactional Data Change for Real-Time Analytics in Lakehouses》（湖仓实时分析事务数据变更）中与导师卞昊穹（共同一作兼通讯）并列署名，成为组内最早冲击 VLDB 正会的学生之一。他还参与了 SIGMOD'26 workshop 论文（湖表一致性与新鲜度研究）等组内多项工作，研究方向集中于云原生湖仓的事务与查询处理，是 PixelsDB 下一代技术的核心承担者。

郭云达是卞昊穹组已毕业成员，其经历集中体现了 CloudLab 体系内"柴云鹏—卞昊穹"两条线的联动培养。他作为共同作者参与了柴云鹏教授团队的 SIGMOD 2024 论文《SALI: A Scalable Adaptive Learned Index Framework based on Probability Models》（与葛加可、腾讯陈育兴、潘安群等合作），切入学习索引方向；毕业前后又以第一作者完成了 DATE'26 论文《Eunomia: Preemption-based and QoS-aware Core Allocation in Oversubscribed Cloud》（过订阅云环境下基于抢占的 QoS 感知核分配），卞昊穹为通讯作者，柴云鹏及多位疑似产业界合作者（Puqing Wu、Yao Shen 等）联合署名。该工作横跨云计算资源调度与数据库系统，正是柴云鹏（云资源管理）与卞昊穹（数据系统）两个方向交叉的典型产物。

## 四、学术合作网络

### 4.1 实验室内部合作（人大 CloudLab 及数据库团队）

卞昊穹处于人大计算机系两大体系的交汇点：一是以杜小勇、陈红、陈跃国等为代表的老牌数据库研究团队（数据工程与知识工程教育部重点实验室 / 数据库与智能信息检索实验室），二是以柴云鹏为核心的云计算与大数据系统实验室（CloudLab / 存储与数据中心系统组）。

**与柴云鹏（Yunpeng Chai）的合作**是目前其留校后最核心的内部合作。柴云鹏现任信息学院院长（曾任副院长主持工作、计算机科学与技术系主任），CloudLab 负责人。两人近年在多个顶级成果上联合署名：ICDE'25 论文《PixelsDB: Serverless and NL-Aided Data Analytics》（卞昊穹第一作者、柴云鹏合作者）、arXiv 论文《Serverless Query Processing with Flexible Performance SLAs and Prices》、DATE'26 论文《Eunomia》（通讯作者组合中含柴云鹏）、ICDE'26 论文《DBdoctor》（柴云鹏署名）。两人还共同活跃于中国人民大学—腾讯协同创新实验室框架（2025 年 3 月 20 日同席实验室年度会议），并在本科生竞赛指导上形成互补（柴云鹏主讲 ICS 课程体系，卞昊穹承担 ICS2 并主导 PolarDB 赛道指导，2025 年与谢旻晖联合指导队伍夺冠亚军）。可以说，在 CloudLab 体系内，柴云鹏主导云资源管理与新硬件存储方向，卞昊穹补上了云原生湖仓与数据库内核方向，二人构成"存储系统+数据系统"的互补型核心组合。

**与数据库元老团队的合作**集中于博士阶段及回校后：陈跃国、杜小勇、覃雄派是其博士期间论文（SIGMOD'17、ICDE'18、APWeb'15、软件学报 HDFS 综述）的持续合作者；靳国栋（Guodong Jin）与其在 EDBT'22 以共同一作发表数据湖列式存储优化与缓存论文；回校后，卢卫参与了 DBdoctor（ICDE'26）工作，杜小勇亦署名该论文。他与陈红教授同属人大—腾讯协同创新实验室出席阵容（2025 年度会议），但未见直接论文合作记录。

### 4.2 跨机构合作（国内）

其国内跨机构合作网络以两条线为主。其一是**微软亚洲研究院**：博士期间在 MSRA 系统与算法组实习，SIGMOD'17 论文的合作者 Ying Yan（颜映）、Wenbo Tao、Liang Jeff Chen 与 Thomas Moscibroda 均来自微软体系，该论文属于典型的 MSRA 联合研究；其多项发明专利亦被微软应用于实际数据库产品。其二是**清华大学**：据个人主页，SIGMOD'27（录用）论文《EASE: Resource-Aware Query Scheduling across Heterogeneous Cloud Compute Services》与清华大学李国良（Guoliang Li）共同通讯指导（李文博为第一作者），建立了与清华数据库团队的直接合作通道。此外，通过全国大学生计算机系统能力大赛 PolarDB 赛道（阿里云主办），人大作为合作高校参与赛事宣传、组织和技术方案制定，卞昊穹本人深度介入赛题技术方案制定并获大赛特殊贡献奖，与阿里云数据库生态形成教学与人才层面的合作关系。

### 4.3 国际合作

国际合作的核心是**瑞士洛桑联邦理工学院（EPFL）DIAS Lab 及其主任 Anastasia Ailamaki**（数据库系统领域国际著名学者）。2020—2023 年博士后期间，卞昊穹在该团队负责云原生数据系统研究，双方合作产出 ICDE'22《Pixels: An Efficient Column Store for Cloud Data Lakes》、SIGMOD'23《Using Cloud Functions as Accelerator for Elastic Data Analytics》、ICDE'25 PixelsDB 演示论文及 SIMPLIFY'21 workshop 论文（合作者还包括微软的 Bikash Chandra、慕尼黑工大的 Ioannis Mytilinis）。留校任教后，Ailamaki 仍在 PixelsDB 后续成果（ICDE'25）中保持署名，说明该国际合作在其独立建组后仍在延续。此外，其 2015—2016 年俄亥俄州立大学联合培养经历、MSRA 实习经历（Thomas Moscibroda 等国际学者）构成其早期国际化训练基础；欧盟 Horizon 2020 "Sustainable Data Lakes for Extreme-Scale Analytics" 课题的经历使其深度嵌入欧洲数据系统研究网络。

## 五、业界合作关系深度分析

### 5.1 腾讯：从 TDSQL 工程师到协同创新实验室核心成员

卞昊穹与腾讯的关系是"由内而外"的：他不是以外部学者的身份与腾讯合作，而是先作为腾讯 TDSQL 数据库内核高级工程师（2018—2020）在产业一线工作两年，再以校友学者身份回归产学研合作体系，这在国内青年数据库学者中相当罕见，也决定了其合作的深度。

**技术与专利层面**：其获得中国专利金奖的发明专利"数据库事务处理方法、装置及服务器"（第一发明人）即诞生于腾讯 TDSQL 工作期间，该专利提出对用户数据和元数据采用统一 MVCC 机制、在无状态计算节点上执行不阻塞事务的在线 Schema 变更（Online DDL），已在 TDSQL 国产分布式数据库中作为核心技术落地，是数据库领域首个中国专利金奖，也是人大教师首次获得该奖（注：人大信息学院新闻称其为第二十五届中国专利奖获奖项目，其个人主页与教师页记为第二十四届中国专利金奖，届次表述存在差异，以官方公示为准）。

**实验室层面**：中国人民大学—腾讯协同创新实验室建于 2019 年（主任为杜小勇），据人大信息学院披露，双方合作获得国内外授权专利 19 项、合作发表 SIGMOD/VLDB/ICDE/VLDB J/TKDE 等顶会顶刊论文 16 篇，合作成果获 2021 年 CCF—腾讯犀牛鸟基金卓越项目奖、2022 年深圳市科技进步一等奖；另据人大深圳研究院方面 2025 年披露，联合实验室近两年在 VLDB/ICDE/SIGMOD 三大顶会累计录用 7 篇论文，核心技术深度应用于 TDSQL 产线并在金融、政务领域规模化落地。卞昊穹作为曾在 TDSQL 内核团队任职的核心成员，2025 年 3 月与柴云鹏、陈红、陈晋川、卢卫、张峰、李彤等一同出席实验室年度会议，与腾讯技术管理委员会主任王巨宏、TDSQL 研发总经理潘安群等对接。其组内 DBdoctor 数据库性能诊断平台系列论文（SIGMOD'26 演示、ICDE'26 正会）的作者中包含多位疑似腾讯侧工程师（Jikuan Zhang、Xiang Zheng 等，DBdoctor 为腾讯云数据库诊断产品），显示其回校后与 TDSQL 的合作已从"个人经历"升级为"团队级联合研发"。其 2024—2025 年承担的"OLAP 数据库一体机新型存储系统研发"（重大企业课题，共同负责人）与 2025 年起主持的"OLTP 数据库一体机中基于事务重排序的高效多写优化技术研究"（企业课题，负责人）据公开信息推断亦属此类产研重点合作项目（委托方未见明示）。

**人才层面**：其每年推荐组内多名本硕博学生赴腾讯做 Research Intern，人大亦有多名研究生入选"腾讯犀牛鸟精英人才培养计划"并加入 TDSQL 实习、工作，形成稳定的人才输送管道。

### 5.2 产学研总体格局与标准化、开源影响力

除腾讯这一主轴外，卞昊穹的产业合作网络呈多极分布：**微软**（MSRA 实习出身，5 项发明专利被微软、腾讯等企业应用于实际数据库产品）；**阿里云**（PolarDB 国赛合作高校、赛题技术方案制定、学生实习推荐）；**字节跳动**等（学生 Research Intern 输出）；另有"主流云厂商"（据其主页表述未具名）采用 Pixels 查询执行关键技术与代码用于数据库产品原型研发。

其产学研影响力的两个独特支点是**国家标准**与**开源**。作为主要起草人，他参与立项和撰写了大数据领域国家标准《信息技术—大数据—面向分析的数据存储与检索技术要求》（GB/T 41818-2022），Pixels 的列式存储关键技术被编入其中——这将其实验室成果沉淀为行业规范。同时，他自 2017 年起主持研发开源云数据湖仓引擎 PixelsDB（GitHub: pixelsdb/pixels），涵盖列式存储格式、基于云函数的 Serverless 查询加速、自然语言辅助数据分析等能力，并以 CCF 开源发展委员会执行委员身份参与全国开源生态治理。整体来看，卞昊穹走的是"开源系统为体、标准专利为翼、企业课题与联合实验室为落地通道"的产学研路径，研究选题（湖仓一体、Serverless、AI 存储系统）均直接对接云厂商产品需求，属于典型的"问题来自产业、成果回到产业"型学者。

## 七、Connection圈层总结

**核心圈（师承与团队）**：卞昊穹的学术身份由三段师承/雇佣关系定义——人大数据库团队（博士阶段，据公开论文署名推断主要合作指导者为陈跃国，团队灵魂人物杜小勇）、腾讯 TDSQL（2018—2020 内核工程师）、EPFL DIAS Lab（Anastasia Ailamaki 博士后）。回校后，其最紧密的内部盟友是 CloudLab 负责人柴云鹏：二人以"云资源管理 + 云原生数据系统"的互补分工共同支撑人大—腾讯协同创新实验室的技术主线，近三年在 ICDE'25、DATE'26、ICDE'26 等成果上持续联合署名。

**合作圈（学术同行）**：人大内部包括卢卫（DBdoctor）、覃雄派、靳国栋、谢旻晖（联合竞赛指导）等；国内跨机构包括清华李国良团队（SIGMOD'27 EASE）、微软亚洲研究院（Thomas Moscibroda、Ying Yan 等，SIGMOD'17）；国际层面以 EPFL/Ailamaki 为轴心，延伸至欧洲 Horizon 2020 数据湖研究网络与俄亥俄州立大学联合培养网络。

**学生圈（梯队）**：以耿东杨（湖仓事务，VLDB'26 共同一作）、王正今（DBdoctor，SIGMOD'26/ICDE'26）、李子诺（湖表一致性，FORMATS'26）为代表的新生代，叠加郭云达等横跨柴云鹏—卞昊穹两线培养的毕业生，构成 CloudLab 数据系统方向的后备梯队；本科生层面通过 PolarDB 国赛两连亚军建立了高辨识度的选拔品牌。

**产业圈（产研网络）**：腾讯是最深的一极（个人任职经历 + 金奖专利 + 协同创新实验室 + DBdoctor 联合研发 + 犀牛鸟人才管道），微软（MSRA 出身、专利授权）次之，阿里（PolarDB 赛事生态）、字节（学生实习）为外围节点；通过 GB/T 41818-2022 国家标准、PixelsDB 开源项目和 CCF 开源发展委员会执行委员身份，其产业影响力进一步制度化、公共化。

**网络结构总评**：卞昊穹是典型的"双重嵌入"节点——向上嵌入人大数据库学派（杜小勇—陈红—陈跃国学术谱系）与柴云鹏 CloudLab 行政—学术双体系，向外嵌入腾讯 TDSQL 产业体系与 EPFL 国际学术体系。这四重网络的交汇使其在人大计算机系内部充当了连接"数据库理论团队"与"云系统实验室"的桥梁人物，在产学研层面则以开源系统 PixelsDB 为枢纽，把学界成果（顶会论文、国家标准）与产业需求（TDSQL、云厂商产品）双向转译。随着 2025 年晋升副教授并持续扩充学生梯队，其网络中心度预计将进一步上升。
