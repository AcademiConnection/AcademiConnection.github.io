# 中国人民大学 理论CS与软件工程方向教师学术关系网络报告

> 报告生成时间：2026年8月

## 团队简介

中国人民大学信息学院的理论计算机科学与软件工程方向由四位背景各异的教师构成。**何昆副教授**（中国人民大学杰出学者，2023年入职）是理论 CS 的中坚力量：武汉大学本科、中科院计算所硕博（导师孙晓明），以概率方法见长，在 STOC、FOCS、SODA 三大理论顶会上发表多篇论文，并曾解决哥德尔奖得主与莱布尼茨奖得主提出的开放问题，获中科院院长特别奖（2019）与 CCF 优博（2020）。**周春来副教授**是逻辑学与量子计算的跨界学者：印第安纳大学应用数学博士（导师 Lawrence S. Moss，延续 Church—Kleene—Moschovakis 计算逻辑谱系）、阿姆斯特丹大学硕士、清华博士后，2009年起任教人大，其研究方向横跨概率逻辑、知识推理与量子信息，曾在哈佛、ANU、悉尼科技大学量子计算研究中心等机构访问。**刘爽副教授**（2024年1月自天津大学加盟）代表 AI4SE 方向：人大本科、新加坡国立大学博士（2015），ESEC/FSE 2020 最佳论文奖得主，研究方向为智能软件工程（大模型代码生成与软件测试），入职后与卢卫、张心怡等 DEKE 数据库团队在 TXSQL 锁优化（SIGMOD 2025）、数据库测试、LLM 调优 Agent 等方向形成高频合作。**赵素云教授**（2024年8月晋升）则属机器学习安全方向：河北大学本硕、香港理工大学博士（2009），DWBI 实验室成员，长期深耕模糊粗糙集与弱监督学习，近年转向大模型安全（后门攻击与防御），是陈红—李翠平—张静团队之外的第四位核心合作者。

## 研究方向与圈层结构概述

该方向的学术网络高度异质，四位教师各自嵌入不同的谱系与传统。何昆的谱系经由孙晓明接入中科院计算所理论组与国内理论 CS 共同体（与南大尹一通保持长期合作），并上承概率方法国际学派（Krzysztof Onak、Xi Chen、 Rahul Santhanam 等）；周春来则通过 Moss 门下延续数理逻辑的 Church 谱系，同时与量子信息学界（如中科大、清华交叉信息院的相关学者）保持联系；刘爽的 NUS 软件工程背景（ESEC/FSE 最佳论文）使其成为人大连接国际软工共同体的桥梁，入职后与 DEKE 数据库团队的"AI4SE×DB"合作（卢卫16次、张心怡4次）是其人大网络的主轴；赵素云则深度嵌入人大 DWBI 实验室的"三导师+1"结构（与陈红、李翠平、张静的合作网络），同时与王熙照（河北大学/深圳大学）保持模糊机器学习谱系的长期联系。

## 与其他方向的交叉亮点

该方向最突出的网络特征是"跨界耦合"：刘爽与赵素云两人虽编制上属理论/软工方向，其实际学术产出分别与数据库系统（TXSQL、数据库测试、Chimera 云原生数据库）和机器学习安全×数据挖掘（DWBI 团队论文）深度绑定，2024—2026年与 DEKE 团队的联合署名持续攀升。何昆与周春来则代表了人大在纯理论与逻辑方向的稀缺储备——何昆的 STOC/FOCS 论文使人大在理论 CS 顶会版图上有了立足点，周春来的概率逻辑与量子计算交叉则呼应了全国性的"量子+CS"学科建设趋势。
