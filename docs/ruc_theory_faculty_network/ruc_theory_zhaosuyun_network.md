## 一、学者基本信息

赵素云，女，1979年9月出生，中国人民大学信息学院计算机科学与技术系教授（2024年8月起）、博士生导师，数据仓库与商务智能实验室（DWBI）成员。主要研究方向为机器学习、深度学习与计算机视觉，具体包括智能数据标注（主动学习、半监督学习、部分标签学习等弱监督范式）、多模态文本识别、安全可控生成与大模型安全风险控制、小样本与低成本学习、复杂环境机器学习理论与泛化性分析，以及模糊粗糙集理论。现为中国计算机学会数据库专委会执行委员、中国人工智能学会知识工程专委会委员。参与并主持国家自然科学基金项目多项（青年项目、面上项目各一项在案），作为主要参与人员参研国家自然科学基金重点项目、973项目和核高基项目等国家级重大科研项目。现已发表学术论文60余篇，代表性成果发表于 TPAMI、CVPR、AAAI、ICCV、ICML、ICDE、IJCAI、ECAI、TKDE、TFS、TCyberB 等人工智能领域顶级会议与期刊。担任 ICLR、ICML、CVPR、ECCV、ACMMM、ICMR、TKDE、TFS、TCyberB、INS、PR 等国际权威会议/期刊审稿人。讲授机器学习、机器学习入门、深度学习入门、概率论与数理统计等课程，并与王秋月、覃雄派、张静合著通识教材《人工智能与机器学习》（21世纪通识教育系列教材，中国人民大学出版社，2020）。

### 研究方向

- **机器学习安全**：大模型安全风险控制、安全可控生成、对抗环境下的鲁棒学习
- **弱监督/低成本学习**：智能数据标注、主动学习、半监督学习（尤其类别分布不匹配场景）、部分标签学习、小样本学习
- **模糊粗糙集**：属性约简、特征选择、不确定性建模及其加速算法
- **差分隐私与联邦学习**：本地化差分隐私下的频繁项集挖掘与重击者识别、个性化联邦学习的隐私放大
- **复杂环境机器学习理论与泛化性分析**：分布失配场景下的泛化误差理论

## 三、博士教育背景

### 博士阶段（香港理工大学，2006—2009年）

赵素云于2006年至2009年在香港理工大学攻读计算机应用技术专业博士学位。值得注意的是，其履历显示她在2005年6月至12月先以研究助理（Research Assistant）身份进入香港理工大学，2006年正式攻读博士；同时她2004年至2011年（或至2010年，两处履历记载略有出入）仍在河北大学数学与计算机学院任讲师，属于在 职/保留教职攻读博士学位的模式。官网仅表述"于2009年香港理工大学毕业"，未披露导师姓名及博士论文题目。

**博士导师推断：Eric C.C. Tsang（香港理工大学）。** 判断依据：

1. 2005年（正式攻博前一年）她进入港理工任研究助理，同年即在 ICMLC 发表与 Eric C.C. Tsang、Daniel S. Yeung、John W.T. Lee 合作的论文"Learning from an Incomplete Information System with Continuous-Valued Attributes"，这是其可追溯的第一篇国际论文，研究助理岗位与其后导师的课题组高度相关；
2. DBLP 记录显示她与 Tsang 合作多达 **17篇**（2005—2020年），是其在陈红、李翠平之外合作次数最多的学者，其中涵盖其整个博士阶段（2006—2009）；
3. 其博士期间所有第一作者论文均由 Tsang 署名第二作者或通讯位置，包括 Inf. Sci. 2008"On fuzzy approximation operators in attribute reduction with fuzzy rough sets"（两人独著）、TFS 2009"The Model of Fuzzy Variable Precision Rough Sets"（赵一作、Tsang 二作）——这种署名模式是典型的"学生一作+导师"结构；
4. Tsang 为港理工计算学系从事粗糙集/模糊集研究的教师，研究方向与赵素云博士阶段完全吻合；两人合作延续至2020年（Inf. Sci. 2020增量特征选择论文，Tsang 为末位作者），远超普通合作者的合作时长。

需要说明：香港理工大学学位论文库及人大官方页面均未公开披露其导师姓名，上述结论为基于一手署名证据的**高置信度推断**。此外，Daniel S. Yeung（港理工教授，IEEE Fellow）在其博士早期论文中频繁出现（3次，2005—2008年），可能是课题组共同指导者或实验室负责人。本项目此前的调研已核验否定"王熙照为其博士导师"的说法——王熙照的机构轨迹（河北大学→深圳大学）与港理工博士阶段不符，他是赵素云的早期合作者（详见第四节）。

与项目内张骁（华为/快手联合论文）、张静（智谱生态）等案例相比，赵素云的产学研合作公开披露信息明显较少，呈现"**项目资助为主、联合署名论文为辅**"的特征。

### 1. 企业横向项目（合作方未披露）

人大官网师资页科研项目栏明确记载：**"2023年3月—2025年3月，企业横向项目，150万元，主持"**。这是其名下唯一可查的企业横向项目，金额达150万元（高于其主持的两项国家自然科学基金面上项目之和），规模可观，但官网未披露合作企业名称，公开资料未披露。结合其官网研究方向中"大模型安全风险控制、安全可控生成"的表述及项目时间（2023年，正值大模型安全需求爆发期），该项目的合作方大概率与生成式AI安全评测或内容安全业务相关，但此为方向性推测，无直接证据。

### 2. 国家级重大工程项目的产业关联

- **国家科技重大专项（核高基）课题"国产数据库高性能高安全关键技术研究"（2010年1月—2012年6月，665万元，参与）**：该课题与国产数据库生态（人大系的人大金仓等）直接相关，属早期参与国家级数据库自主可控工程；
- **973项目、国家自然科学基金重点项目**（面向不确定的机器学习的不确定性建模及应用研究等）：属纵向项目，但其弱监督学习与差分隐私方向（本地化差分隐私重击者识别、联邦学习隐私放大）在工业界数据采集与隐私合规场景有直接落地价值。

### 3. 联合论文中的产业界线索

DBLP 记录中未发现明确标注企业机构隶属的合作者，是 DWBI 团队内产业署名论文最少的核心教师之一。ICML 2025 论文"Unsupervised Learning for Class Distribution Mismatch"的合作者 Kai Wang 0036 等来自尤洋（NUS）团队，属学术合作而非产业合作。

### 4. 产学研合作总结

赵素云的产学研模式可概括为"**理论输出型**"：其贡献集中在弱监督学习的泛化理论（TPAMI 两篇理论工作）与差分隐私机制设计，这些成果面向数据标注成本控制、隐私合规等产业痛点，但合作形式以纵向基金与企业横向项目资助为主，公开的联合署名产业论文极少。其名下150万元企业横向项目的存在（2023—2025年）表明其产业合作实质强度高于论文署名所显示的水平，但合作方身份为公开资料未披露状态。

## 七、Connection 圈层总结

**第一圈层（现单位核心同事）：** 陈红教授（49篇，2012—2025年）与李翠平教授（39篇，2013—2025年）构成赵素云学术网络的绝对重心——加入人大以来其约七成论文由 DWBI 团队三教师结构共同署名。与张骁-徐君、赵鑫-文继荣等"师承型双核"不同，这三人的关系是**平辈同事型合作**：陈红作为实验室负责人提供平台与课题（其主持的基金重点项目为赵素云参与），赵素云则以机器学习理论专长反哺团队的隐私计算与弱监督方向。杜小勇（DEKE主任）在2013—2015年有3次合作。

**第二圈层（博士师承与早期学术圈）：** Eric C.C. Tsang（港理工，17篇，2005—2020年，疑博士导师）与王熙照（河北大学/深圳大学，11篇，2007—2022年，疑硕士导师）是其学术血缘的两端。她的学术谱系横跨两个模糊集研究重镇：港理工（Tsang、Yeung）与河北大学（王熙照），并与陈德刚（渤海大学，11篇）等构成2005—2013年活跃的模糊粗糙集合作圈。值得注意的是，这两条师承线索的合作均延续到博士毕业十年之后（Tsang 至2020年、王熙照至2022年），显示其与早期学术圈的长期维系——但两者均以"疑导师"推断属性标注。

**第三圈层（自主培养学生）：** 以杜盼（TPAMI×2、ICCV×2、ICML，与陈红联合指导）为代表，倪鹏、赵丹、刘瑞轩（差分隐私线）、盛子森、甘泽宇（弱监督/视觉线）等学生梯队支撑其2019年后的产出高峰。其团队方向高度聚焦"标签缺失与分布失配"这一主线：半监督、主动学习、部分标签学习到无监督泛化理论，呈现清晰的理论纵深。

**第四圈层（外部学术合作与产业网络）：** 跨国学术合作包括美国埃默里大学 Li Xiong（联邦学习隐私，AAAI 2023）与新加坡国立大学尤洋团队（ICML 2025）；UIUC访问学者经历（2014—2015年）未对应可查的署名论文。产业合作以150万元企业横向项目（2023—2025年，合作方未披露）与核高基国产数据库课题参与为主，公开论文网络中产业界存在感低。

**产出规模与方向演进：** DBLP 收录75条记录（正式发表约68篇），2005—2016年为模糊粗糙集理论期，2017年后完成向弱监督学习与机器学习安全的转向，2021—2023年达到产出峰值（25篇，含 TPAMI×2、CVPR、ICCV×2、AAAI×2、ICDE、IJCAI）。2024年8月晋升教授。其职业生涯体现了一条"传统不确定性理论（模糊粗糙集）→现代弱监督学习理论（分布失配泛化分析）→大模型安全"的完整演进路径，是 DWBI 团队中唯一以机器学习理论为核心标识的教师。
