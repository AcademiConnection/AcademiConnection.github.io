# 上海交通大学 CMaCH认知机器与计算健康中心 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

认知机器与计算健康研究中心（Center for Cognitive Machines and Computing Health, CMaCH）由徐雷教授于2016年12月牵头组建（整合计算机、自动化、电子工程、微纳电子四个系的多支团队），2017年6月2日正式揭牌。徐雷（IEEE Fellow 2001、IAPR Fellow 2002、欧洲科学院院士 2003）是我国首个AI类专业"模式识别与智能控制"首位博士（清华，1987，导师常迵院士、阎平凡教授），此前为香港中文大学讲席教授（2002-2016），2016年以国家"千人计划"专家身份加入交大，任 CMaCH 主任与人工智能研究院首席科学家，2025年5月从致远讲席教授岗位荣休后为访问讲席教授。中心副主任包括连勇（微纳电子）、杨杰（自动化）、杨小康（电子）、张丽清（计算机），施鹏飞任特别顾问。

中心以徐雷的 BYY 和谐学习理论与 Lmser 双向学习框架为理论内核，向"认知机器"（图匹配、因果表示学习、神经启发搜索、草图生成）与"计算健康"（心电诊断、颅内动脉瘤风险、药物设计）双主线延伸，形成"徐雷（理论把关）+涂仕奎（方法执行）"双通讯的实验室传统。涂仕奎长聘副教授（港中文博士，导师徐雷；UMass 医学院博后，师从 Craig Mello 诺奖实验室）任中心主任助理，其深度报告见 [sjtu_agi_faculty_network](../sjtu_agi_faculty_network/)（涂同时挂靠通用人工智能研究所"AI赋能生化医药"团队）。

## 圈层结构概述

CMaCH 网络以徐雷的"三段学统"为纵轴：清华（常迵、阎平凡）—北大博后（程民德、石青云）—国际访学（Oja、Yuille、Jordan、Hinton 合作）构成其学术血缘；港中大时期培养了张晓明（现港浸会AI讲席教授）等学生并与 Michael Jordan、Hinton 合作混合专家模型；交大时期与涂仕奎形成"理论+执行"事业合伙人体制，在读学生梯队（郭文奇、李腾杰、钱浩、周靖远、杨宇培、曾必洋、张琳等）以 NeurIPS/ICML/ICLR/AAAI 第一作者成果和"涂仕奎*、徐雷*"双通讯署名为组织标识，早期毕业生臧思聪（东华大学讲师）为 Lmser 传人。连勇一脉则代表中心的医工交叉支线：其与王国兴共同领衔的 BiCASL（生物电路与系统实验室，8名教师、70余名学生）在心电诊断（IJCAI 2020 房颤 ECG 论文连接徐雷、涂仕奎、王国兴、连勇四名 CMaCH/BiCASL 学者）、脑电解码与可穿戴智能方向深耕，并与上海儿童医学中心、电子科大等医工节点合作。产业网络以商汤清源研究院（徐雷任首席科学家）为主要接口，延伸至 AI 药物设计与初创企业。需要注意的消歧：常被误归徐雷门下的港理工张磊（西北工大博士）与黄开竹（师承 King/Lyu）均非其学生；CMaCH 的连勇与 IEEE Fellow 连勇为同一人（无同名学者），其博士母校为新加坡国立大学。
