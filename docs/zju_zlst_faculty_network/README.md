## 二、教师角色定位

卜佳俊是 EAGLE-Lab 的负责人与中国信息无障碍研究的旗帜人物。浙江大学计算机学院教授、求是特聘教授、博导，现任浙江大学研究生院副院长、中国残疾人信息和无障碍技术研究中心副主任、全省无障碍感知与智能系统重点实验室主任，2022年当选CCF会士。其博士导师为中国工程院院士陈纯（据CCF专访自述），与陈纯团队的长期绑定是其实验室发展的核心资源。

需要澄清：调研中未在任何官方来源发现"ZLST"这一名称，实验室官方名称为 EAGLE-Lab（浙江大学创新软件研发中心）；本目录按原始调研清单保留 ZLST 别名以便检索，正文以 EAGLE-Lab 为准。其代表性工作涵盖信息无障碍（盲人辅助技术）、普适计算与大规模软件工程交付，实验室官网校友名录收录579人，是浙大规模最大的工程化人才培养基地之一。

## 三、实验室关系网络的整体观察

第一，"陈纯谱系"的工程化支脉。EAGLE-Lab 与陈纯院士团队同源，早期校友（1996-2001级）多为陈纯团队培养；实验室以大规模软件工程交付能力著称，走出了以拼多多创始人黄峥为代表的现象级产业人物（其为陈纯/卜佳俊所在大团队早期校友，与卜佳俊的直接指导关系需区分看待，报告已审慎处理）。

第二，无障碍事业的国家级平台。依托中国残疾人信息和无障碍技术研究中心与省级无障碍重点实验室，实验室是国内信息无障碍方向唯一的建制化国家级团队，社会影响独特。

第三，工程化育人范式。579人校友名录、数十年企业级项目交付，使 EAGLE-Lab 形成"论文+工程"双轨育人模式，学生广泛进入阿里、华为及创业公司，董玮的 EmNets 亦隶属 EAGLE 大平台，形成"一个中心、多个实验室"的伞形结构。
