# 复旦大学人工智能创新与产业研究院（AI³院）学术关系网络报告

## 团队简介

复旦大学人工智能创新与产业研究院（AI³院）成立于2021年11月，由漆远教授领衔创建并担任院长。漆远为美国MIT博士及博士后、国家高层次海外引进人才、复旦大学浩清特聘教授，曾任普渡大学计算机科学与统计系终身教职（副教授）、阿里巴巴副总裁、阿里iDST（达摩院前身）联合创始人、蚂蚁集团首席AI科学家，是横跨学界与业界的代表性人物。研究院以"原创科技+应用转化"为建院核心，聚焦AI for Science（科学智能）与人工智能技术创新，服务国家生命健康和经济发展重大战略需求。

研究院的建制特色可概括为"一平台、一联动、一体系"：其一，承担中国高校最大云上科研智算平台CFFF（Computing for the Future at Fudan）的建设与运行，累计服务53个校内外单位、550个课题组、5200名科研人员，支撑产出百余项创新成果，2025年5月26日发布的CFFF 2.0成为国内首个覆盖"教-学-研"全链条的人工智能基础设施；其二，作为初始动力支撑上海科学智能研究院（上智院）成立建设，通过"1+1"联动机制形成复旦—上智院双聘体系，并联合主办世界科学智能大赛（已举办四届，2026年于WAIC 2026收官）；其三，支撑复旦大学国家人工智能产教融合创新平台，已建成"感染性疾病数字医疗校企联合研究中心""人工智能大模型校企联合研究中心""云上智算校企联合实验室"等校企联合机构。研究院还深度参与国际人类表型组计划（二期），并与计算机学院、大数据学院、表型组研究院、大气研究院、中山/华山医院等兄弟院系交叉融合。旗舰科学成果包括"伏羲"气象大模型（入选2025年度"中国十大气象科技进展"）。

2025年，研究院迎来一批年轻PI密集入职，形成"漆远掌舵+青年PI军团"的梯队结构，本报告聚焦其中四位代表人物：姜若曦（芝加哥大学博士，表征学习与生成模型的AI4Science）、魏龙（浙江大学博士、西湖大学博后，物理引导扩散模型与生成式控制）、熊昊（上海交通大学博士，量子人工智能与图学习）、屈超（新加坡国立大学博士、无限光年大模型后训练负责人，RL/LLM后训练与科学智能）。

## 研究方向与圈层结构

研究院四份教师报告覆盖的学术网络呈五层结构。第一圈层是漆远核心体系：屈超直接来自漆远创立的无限光年大模型团队（2022-2025年任后训练负责人），与漆远联合发表NeurIPS/ICML/ICLR系列论文，是"漆远学术—产业双线"最直接的传承者；姜若曦、魏龙、屈超三人同时兼任上智院AI科学家，深度嵌入复旦—上智院"1+1"联动机制。第二圈层是外部师承网络：姜若曦出自芝加哥大学Rebecca Willett/Michael Maire表征学习学派；魏龙出自浙江大学何晓飞/蔡登学派，经阿里巴巴达摩院、西湖大学吴泰霖AI4S课题组两段历练；熊昊出自上海交通大学严骏驰ThinkLab；屈超出自新加坡国立大学Huan Xu（强化学习/优化）学派并有以色列理工学院Shie Mannor博后经历——四人分别接入美国顶校、浙大、上交、NUS四条不同谱系。第三圈层是校内交叉网络：依托计算与智能创新学院招生，与复旦计算机学院、大数据学院、大气科学研究院（伏羲气象模型）等保持合作，熊昊与复旦黄增峰教授已有合著论文。第四圈层是产业网络：屈超携蚂蚁集团、字节跳动、无限光年三段业界履历；魏龙有阿里达摩院城市大脑经历并担任世界科学智能大赛可控核聚变赛道出题人（联动新奥集团"玄龙-50U"聚变装置）；熊昊的图学习成果落地华为终端推荐系统；姜若曦有论文推动创业公司落地的记录。第五圈层是国际学术网络：斯坦福Jure Leskovec、MIT Yilun Du、剑桥/帝国理工合作者（屈超分子方向）、西湖大学吴泰霖课题组等。

## 产业转化亮点

AI³院的产业转化以CFFF智算平台为底座、以漆远的业界资源网络为纽带：屈超是"大模型后训练"从蚂蚁/无限光年到复旦学界的代表性回流人才，入职后即参与发布AI4S智能体CNS挑战赛（与金力、漆远等）；魏龙的可控核聚变AI控制方向直接对接新奥集团聚变装置，是"AI4S落地国家战略产业"的典型样本；熊昊与华为诺亚方舟实验室（唐业辉等）保持长期合作，量子启发LLM训练方法面向产业算力瓶颈；研究院层面已建成三个校企联合实验室，并通过世界科学智能大赛（阿里云、南方电网、复星医药等十余家产业机构协办）持续输出产学合作生态。
