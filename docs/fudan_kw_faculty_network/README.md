# 复旦大学知识工场实验室教师网络报告索引

复旦大学知识工场实验室（Knowledge Works，简称 KW@FUDAN）源自复旦大学图数据管理实验室，依托复旦大学计算机科学技术学院，面向大规模、高质量知识图谱的构建、管理、分析与应用开展研究。实验室由肖仰华教授负责，其研究主线贯穿知识抽取、清洗、推断、更新到行业应用，并延展至大模型的认知评测、能力增强与领域适配。团队已发布 CN-DBpedia、知识工场平台及多类知识图谱数据与认知服务，构成"公共知识基础设施—论文合作—产业应用"三者联动的技术底座。肖仰华同时担任上海市数据科学重点实验室主任、复旦—爱数认知智能联合研究中心主任等职务。

需要说明的是，本目录的教师报告目前仅收录肖仰华教授一人。知识工场历史上还有其他合作者（如曾于2021年7月至2024年9月在复旦大学计算机科学技术学院任研究员、博士生导师的李直旭，其已于2024年9月起任中国人民大学信息学院、智慧治理学院教授，应视为历史合作节点而非现任成员），其余合作者多以论文共同署名或团队论文作者身份出现，尚未形成单独的教师报告。

本 README 作为团队报告的索引入口，汇总现有教师报告文件、研究方向与圈层结构概述以及产业转化亮点。所有内容均以目录内已有报告及其中引用的官方公开材料为准，不作超出原始报告的信息延展。

## 研究方向与圈层结构概述

知识工场的核心研究方向包括：大规模知识图谱的构建、管理、分析与应用；大模型认知评测、能力增强与领域适配；以及社会科学启发下的人工智能。以肖仰华报告为例，其学术网络可概括为四个圈层：

- **第一圈层：复旦与知识工场的组织核心。** 连接复旦计算机科学技术学院、知识工场实验室、上海市数据科学重点实验室及复旦—爱数认知智能联合研究中心，决定研究议题、人才培养与项目组织的稳定性。
- **第二圈层：论文合作与培养网络。** 包括可确认的博士生刘井平（现为高校教师），以及以 Xiezhi、CELLO 等 AAAI 2024 团队论文作者身份出现的顾洲洪、朱晓萱、叶浩宁、何千羽等合作节点；李直旭为该层的历史合作节点，现已任职于中国人民大学。
- **第三圈层：跨机构学术共同体。** 通过国际会议（KDD、IJCAI、AAAI 等）与期刊服务（Applied Intelligence、JCST 等副主编或编委），以及在美国贝勒医学院、香港中文大学、微软亚洲研究院、阿里巴巴达摩院的访问交流，连接知识图谱、数据管理、自然语言处理与大模型评测等学术社群。
- **第四圈层：产业协作与应用生态。** 与美团、阿里、华为、百度等企业的持续合作，将知识工程能力迁移到真实数据、搜索与服务系统。

## 产业转化亮点

- **美团合作闭环：** 肖仰华团队凭"构建生活服务领域中的常识型知识图谱"项目获美团2020—2021年度科研合作创新奖，建立了同义词、隶属、功能、因果及元知识获取等技术能力，成果已转化为四项申请中专利及多篇高水平论文，并在美团生活服务多个应用场景中检验，取得搜索意图理解与商户标签化的显著落地效果。
- **持续企业资助与落地：** 知识工场官网记载团队连续多年获得包括阿里、华为、百度、美团等十多家企业资助，相关技术已落地于企业服务与产品；肖仰华个人曾获2017年阿里巴巴 Research Fellowship Award、2018年阿里巴巴学术合作最佳合作伙伴、2020年华为优秀合作伙伴、2023年华为火花奖等荣誉。
- **组织化转化接口：** 复旦—爱数认知智能联合研究中心为"实验室—企业—联合研究中心"的产学研协作提供组织化节点，承接知识图谱、认知智能和行业/领域大模型的长期议题。
