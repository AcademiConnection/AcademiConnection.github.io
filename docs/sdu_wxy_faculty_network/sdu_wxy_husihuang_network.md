## 三、学生培养情况

## 五、业界合作关系深度分析

胡思煌是编码理论领域"基础理论突破与产业应用并重"的典型代表，其产业合作格局以华为为核心，同时辐射航天、能源、通信等关键信息基础设施领域。

### 5.1 ABS极化码与华为5G标准极化码：竞争与互补关系

胡思煌团队提出的ABS（Adjacent-Bits-Swapped）极化码及改进版本ABS+极化码，在相同译码时间复杂度下，相较于华为5G标准中采用的极化码方案，性能提升了0.15–0.60 dB。这一成果具有鲜明的产业对标意义：华为的极化码是5G通信标准的核心编码方案（3GPP 5G NR控制信道采用Polar码），而胡思煌团队的ABS/ABS+方案在保持相同计算复杂度的前提下实现了可测量的性能增益，体现了编码理论基础研究对产业标准的直接改进能力。这一工作由其博士生李国栋主导（以第一作者发表于IEEE Trans. Inform. Theory），合作者包括Min Ye，形成了"学生–合作者–导师"的三方产出模式。

### 5.2 CCF-华为胡杨林基金理论计算机专项：A类项目

2023年8月，胡思煌教授申报的课题"最小存储再生码的设计与实现"获得CCF-华为胡杨林基金理论计算机专项A类项目资助。该年度全国仅2项A类项目获批（从25所高校与研究所的29份有效申请中遴选），竞争极为激烈。项目明确表述"将与华为公司合作研发设计最小存储再生码新型构造方案并落地实现"，是将分布式存储编码理论成果直接对接华为云存储系统可靠性与可用性需求的产学研通道。这也是山大网安学院系统性产学研合作布局的一部分——学院自2022年以来先后获得华为"难题揭榜火花奖"及多个CCF-华为胡杨林基金专项支持。

### 5.3 华为openHiTLS密码开源社区：学院层面的共建关系

山东大学网络空间安全学院是华为openHiTLS密码开源社区的初创会员单位之一。openHiTLS是由华为、西安电子科技大学、山东大学等15家产学研单位于2024年12月联合发布的业界首款面向全场景数智安全的开源密码套件，支持国际主流及中国商用密码算法（SM2/SM3/SM4），并集成了ML-KEM等后量子密码算法。在学院与openHiTLS共建的密码工程实践课程中，面向200余位本科生，由网安学院王美琴教授、王伟嘉教授、鞠雷教授及华为资深工程师联合授课。胡思煌作为学院副院长，在学院与华为openHiTLS合作的制度性安排中处于管理中枢位置。学院获评2024年第三季度"优秀推广单位"，2025年鞠雷、王伟嘉获评年度优秀布道师，魏普文、纪卓然获评年度优秀导师。

### 5.4 密码算法自动化测评平台：关键领域应用

密码与数字经济安全全国重点实验室构建的密码算法自动化测评平台已在航天、能源、通信等关键领域应用，服务于国家关键信息基础设施安全。胡思煌作为全国重点实验室核心骨干和学院副院长，在这一面向国家战略需求的成果转化链中承担管理与学术双重角色。实验室以"建设密码强国"为使命，主攻后量子密码标准化、密态隐私计算性能优化、数论难题、人工智能安全、密码数字货币及区块链等核心领域。

**小结**：胡思煌的产业合作格局呈现"一核心（华为）+ 多领域（航天/能源/通信）"的结构。与一般学者的"框架协议式"产业合作不同，其ABS极化码直接对标华为5G标准、CCF-华为胡杨林基金A类项目直接对接华为存储系统需求，均具有可验证的技术对标实体与经费支持载体，在编码理论学界属于极为罕见的产业渗透深度。

1. **强完美格新发现**：近20年来首次在24维以下欧式空间中发现新的强完美格，发表于J. London Math. Soc.等国际著名数学综合类期刊。这一成果在其亚琛工业大学期间孕育，与Gabriele Nebe教授的学术传统一脉相承。

4. **最小存储再生码最优构造**：构造了一类已知分包数最低的最小存储再生码（MSR码），在分布式存储编码领域两个重要公开问题上取得突破。该成果由李国栋在ISIT 2024上报告并获学生论文奖，被评价为"创造性地提出了从MDS性质到局部限制的归约方法，使得MSR码MDS性质的证明得到了根本的简化"。

## 七、Connection圈层总结

胡思煌的学术关系网络可以概括为**一个中心、四个圈层**：

1. **核心圈（山大密码学派）**：以王小云院士为塔尖的山东大学网络空间安全学院/密码与数字经济安全全国重点实验室，包括王美琴、许光午、魏普文、鞠雷、王伟嘉、陈宇、侯孟波、付仕辉等同事，以及方伟军、张一炜等紧密学术协同者，构成国内最强密码学科研高地之一的组织依托。胡思煌作为副院长和教工党支部书记，在学院管理层面与上述同仁形成制度化协同。

2. **学术血缘圈**：浙江大学（博士，导师葛根年教授）→ 亚琛工业大学（两次博士后/洪堡学者，导师Gabriele Nebe）→ 特拉维夫大学（博士后，导师Ofer Shayevitz），叠加九位列明的海外合作者（Alexander Barg、Tuvi Etzion、Arya Mazumdar、Itzhak Tamo、Lele Wang、Nir Weinberger、Eitan Yaakibi等）和跨机构合作者Min Ye，形成跨越中、德、以、美、加五国的编码理论与信息论国际学术共同体。其学术路径同时嵌入欧洲数学学派和以色列信息论学派，这一双重嵌入在编码理论学界极为罕见。

3. **学生梯队圈**：李国栋（ISIT学生论文奖、博新计划，ABS极化码与MSR码核心贡献者）、王宁宁（MSR码方向，日本筑波大学交流）、徐颜（Reed–Muller码与仿射不变码方向，多项荣誉）、汲长江（循环码方向，人民警察）、张梓豪（协作MSR码方向）、陶然（局部修复码方向）、王乐雯、王东等硕博生与博士后，正在将分布式存储编码和极化码方向推向国际引领地位。2024年ISIT学生论文奖（大陆高校第二次）是该梯队最具标志性的国际学术认可。

4. **产业生态圈**：华为是胡思煌产业合作的核心枢纽，形成三层合作结构——（a）技术竞争层：ABS极化码直接对标并超越华为5G标准极化码0.15–0.6 dB；（b）联合研发层：CCF-华为胡杨林基金A类项目"最小存储再生码的设计与实现"，与华为合作研发云存储编码方案并落地实现；（c）学科共建层：学院作为openHiTLS密码开源社区初创会员单位，共建密码工程实践课程，联合培养密码开源人才。此外，密码与数字经济安全全国重点实验室的密码算法自动化测评平台已在航天、能源、通信等关键领域应用，延伸至更广泛的国家关键信息基础设施服务网络。

综合来看，胡思煌是"数学根基深厚、编码理论前沿突破、产业标准直接对标"的稀缺型学者：在强完美格、图香农容量等纯数学方向产出国际同行认可的原创性结果，同时在ABS极化码和最小存储再生码方向实现了对5G通信标准和云存储系统可靠性需求的直接技术改进。对于寻求编码理论学术合作、5G/6G通信编码技术对接、分布式存储方案研发或密码工程人才培养的对接方而言，他是连接中国编码理论学界与通信/存储产业界的关键枢纽节点。
