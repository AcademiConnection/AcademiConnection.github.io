# 山东大学王小云团队 学术关系网络报告

## 团队简介

本报告集涵盖山东大学网络空间安全学院/密码与数字经济安全全国重点实验室核心教师团队的学术关系网络。团队以王小云院士为核心，依托密码技术与信息安全教育部重点实验室，是中国密码学研究的重要阵地。

## 团队架构

团队以王小云院士为学术领袖，王美琴教授（山东大学副校长）为行政核心，形成了从基础理论（许光午）、理论密码学（陈宇、付仕辉）、对称密码（王美琴、董晓阳）、后量子密码（魏普文）、编码理论（胡思煌）、密码工程与侧信道（王伟嘉）、安全多方计算（侯孟波、徐秋亮）到隐私计算体系结构（鞠雷）的完整研究布局。

董晓阳现为清华大学副教授，博士师从王小云院士（山东大学培养），是连接山大-清华密码学研究的桥梁人物。
