## 二、教育背景与职业履历

据计算机学院官方教师页：徐云 2002 年于中国科学技术大学计算机系获计算机软件与理论专业博士学位，1999 年起即在中国科学技术大学计算机学院、国家高性能计算中心（合肥）从事并行计算与应用相关的研究和教学工作。其本科与硕士阶段的就读院校、以及从讲师/副教授到教授的逐级晋升时间，在公开官方渠道未见明确记载；其博士学位导师亦未见官方文字记载。但从其博士期间及入职初期的论文看（2001年《计算机学报》SAT 随机算法、2002年《中国科学技术大学学报》SAT 问题的改进 DP 算法、2003年《软件学报》随机化算法异步并行化分析等），其早期成果均与**陈国良院士**合作完成，且职业起点即锚定于陈国良1995年创建的国家高性能计算中心（合肥），可保守地认定其学术共同体归属为陈国良开创的中科大并行计算学派（其博士导师归属在无官方记载的情况下不作断言）。

其研究脉络大致可分为四个阶段：

- **第一阶段（约1999–2008）：并行算法与组合优化的理论根基**。围绕 SAT 问题的随机化算法、装箱问题平均性能分析、单体型（Haplotype）组装算法等展开，与陈国良、许胤龙、张强峰（后为清华丘成桐数学科学中心教授）等合作，成果多发表于《计算机学报》《软件学报》《中国科学技术大学学报》及 BMC Bioinformatics 等期刊。
- **第二阶段（约2008–2015）：并行算法落地与生物信息学**。依托 GPU 与异构平台，将位向量计算、FM-index、流网络模型等算法工具应用于基因测序数据比对（BitMapper，BMC Bioinformatics 2015）、单体型快速分型（WinHAP/WinHAP2、FNphasing）与多序列最长公共子序列并行化（TPDS 2013、TKDE 2014）；同期与姜海涛等开展操作系统内核级二进制翻译（KBT）与虚拟机图形驱动跨平台翻译框架（UKCF）研究，是其在系统软件方向的主要工作。
- **第三阶段（约2015–2020）：大规模程序与代码分析**。以 ICSE 2018 的 CCAligner（基于 token 的大间隔代码克隆检测器，与萨斯喀彻温大学 Chanchal K. Roy 团队及校内薛吟兴合作）为代表，后续产出 CCSharp（APSEC 2017）、CCGraph（2020）、LVMapper（IEEE Access 2020）、CCStokener（JSS 2023）等系列工具。
- **第四阶段（约2020年至今）：RDMA 与分布式/分离式内存数据结构**。以博士生李玉婷、毕业生王鹏程等为主力，产出 iWriter（IPCCC 2023）、BT-Duper（ISPA 2023）、vBoost（CLUSTER Workshops 2024）、HiCHT（DASFAA 2025）、Lock-free RDMA-friendly Index（ACM TACO 2025）等成果；生物信息线延续至泛基因组图上的序列比对（2024）。

## 三、学生培养情况

据其个人主页披露的学生名录（自2005级至2021级，累计培养学生约80人，其中标注"博士毕业"者约10人），其学生去向呈现"地方高校教职 + 头部企业 + 海外深造"三通道。以下列出可确证或可较可靠追踪的代表性学生：

### 1. 杨矫云（合肥工业大学副教授，2014届博士毕业生）

杨矫云是徐云学术谱系中最具代表性的高校教职线学生。他2005—2009年就读中国科学技术大学计算机科学与技术专业（本科），2009—2014年师从徐云攻读计算机软件与理论博士学位（博士期间与徐云、尚伊、陈国良合作发表多篇高水平论文，包括 TKDE 2014 的多序列最长公共子序列 anytime 算法、TPDS 2013 的并行化算法等）。2014年起任教于合肥工业大学计算机与信息学院，2016年12月晋升副教授，现研究方向为大数据、机器学习与因果学习及其在医疗健康领域的应用，兼任中国计算机学会理论计算机科学专业委员会委员（与其导师徐云同届同委）、东芬兰大学福祉科技社会研究中心国际合作网络首任科学委员会委员。他主持国家自然科学基金面上/青年项目、国家重点研发计划子课题等9项，出版《统计因果推理入门》《因果论：模型、推理和推断》等译著及科普著作《因果漫步》。这一案例典型体现了徐云"算法功底 + 应用驱动"的培养风格——学生将中科大的算法训练带向不同应用领域（生物信息 → 因果学习/医疗大数据）落地生根。

### 2. 王鹏程（2019届博士毕业生，CCAligner 第一作者）

王鹏程是徐云软件工程方向的旗帜性学生，作为第一作者完成 ICSE 2018 论文 CCAligner: a token based large-gap clone detector（与萨斯喀彻温大学 Jeffrey Svajlenko、Yanzhao Wu 及 Chanchal K. - **安虹（教授）**：先进计算机系统结构实验室主任、时珍书院院长，同属国家高性能计算中心（合肥）并行计算团队。**经核验，DBLP 与双方论文列表中未见徐云与安虹的合著论文**；二人的合作关系体现为同一中心平台下的长期同事关系与共同活动（如2019年6月与德国斯图加特高性能计算中心 HLRS 签署合作备忘录时，安虹、徐云、郑启龙、孙广中共同出席座谈）。对其"长期合作"的表述应以"同平台同事、共同承担中心活动"为边界，不引申为论文级或项目级合作。

- **薛吟兴（特任研究员）**：2018年自微软亚太研发集团加入中科大计算机学院（苏州高等研究院），与徐云在代码克隆检测方向持续合作（CCGraph 2020、挑战机器学习克隆检测器的语义保持变换 2023、CCStokener JSS 2023），是徐云近年校内最重要的软件工程方向合作伙伴，为其代码分析线引入了程序分析与国际 SE 圈（NUS/NTU 背景）的连接。

### 4.2 跨机构合作（国内学术圈）

- **合肥工业大学**：通过2014届博士毕业生杨矫云（现为合工大副教授、CCF 理论计算机科学专委会委员）建立的"师生—同盟"式连接；杨矫云主持的国家重点研发计划子课题等延续了该谱系的应用落地。
- **上海交通大学**：王建平（FiWi 光纤-无线融合网络，JLT 2010）等早期合作者。
- **清华大学**：张强峰（丘成桐数学科学中心教授）为徐云早期（2006—2007年）生物信息合作者，后成为量子信息与密码理论方向的国家级人才，构成谱系向理论量子信息方向的意外延伸（注：此为张强峰个人学术轨迹，与徐云本人研究无关）。
- **安徽省计算机学会网络**：作为学会秘书长，徐云长期与安徽大学仲红（学会副理事长、信创委员会主任委员）、合肥师范学院郭玉堂（青少年信息学教育专委会主任）、合肥大学等省内高校互动，主持安徽省计算机大会（2023年第五届，铜陵学院）等区域性学术活动，是安徽计算机学术共同体的实际运营者。
- **地方竞赛与科普生态**：NOIP 安徽赛区（2024年与安徽省青少年科技活动中心共同视察）、安徽省青少年信息机器人科技素养实践活动（2023年致辞）、安徽省大学生网络与分布式系统创新设计大赛（2025年组委会委员，与顾乃杰、李京、蒋建国、罗斌等同列），形成覆盖中学—大学的区域人才培养网络。

### 4.3 国际合作

- **美国密苏里大学（Yi Shang 尚伊）**：徐云最稳定的国际合作伙伴，BitMapper（2015）、MLCS anytime 算法（TKDE 2014）、MLCS 并行化（TPDS 2013）、Planted Motif 搜索（Information Sciences 2013）等系列成果的共同通讯作者，合作横跨生物信息与并行算法两线。
- **加拿大萨斯喀彻温大学（Chanchal K. Roy、Jeffrey Svajlenko）**：CCAligner（ICSE 2018）及后续克隆检测评测工作的合作方，Roy 团队是国际代码克隆检测方向的权威评测（BigCloneBench）维护者，该合作为徐云的软件工程线提供了国际基准与影响力出口。
- **香港城市大学（Rynson W.H. Lau、Howard Leung）**：早期立体视频深度映射（IJCV 2013）与中文书写教学系统（PCM 2007 等）合作，是其与港澳学界的主要纽带；胡智慧、晏涛等学生经此获得境外联合培养式训练。
- **周丰丰（Fengfeng Zhou）**：WinHAP/WinHAP2（BMC Bioinformatics 2012/2014）合作者，其时在美国伊利诺伊大学芝加哥分校，后回国任教（吉林大学），构成生物信息方向的跨洋合作样本。
- **德国斯图加特高性能计算中心（HLRS）**：2019年6月作为学校超算中心代表团成员参与合作备忘录签署（员工交流、联合研究项目、国家与国际联合项目协作），是徐云以国家高性能计算中心（合肥）副主任身份参与的机构级国际合作。
- **顾钧**：早期 SAT 随机算法论文（2001年《计算机学报》，顾钧署名单位为清华大学）合作者，具有海外任教背景的算法学者，属其博士阶段的学术连接。

## 五、业界合作关系深度分析

### 5.1 产业合作主线：华为与中电14所

据计算机学院官方教师页明确记载，徐云"至今已主持国家重点自然科学基金子课题及面上课题、973子课题、863子课题多项，以及**华为、中电14所等横向合作项目**"；其个人主页资助方徽标亦含华为。结合其研究脉络可作如下有依据的解读：

- **华为**：横向合作与其多核并行编程模型与性能优化、GPU 加速等方向高度匹配；其近年 RDMA/分离式内存数据结构研究（TACO 2025 等）与华为数据中心网络与内存解耦技术议题同频（合作关系细节未见公开披露，不作引申）。
- **中国电子科技集团第十四研究所（中电14所）**：国内雷达与电子系统总体研究所，与其早期二进制翻译/异构平台加速类系统软件工作存在供需关系（具体项目内容未见公开披露）。
- **纵向项目体系**：国家自然科学基金重点项目子课题与面上项目、973/863 子课题，属陈国良学派承接国家高性能计算任务的传统通道。

### 5.2 产学研生态特点

- **人才输送为主、深度技术协同为辅**：与许胤龙—平凯星辰式的"深度绑定"战略合作不同，徐云的产业合作以横向项目与毕业生输送为主，未见以本人或学生为核心创始人的创业公司、专利许可大额转化或联合实验室的公开记录，属于典型的"项目制"学院派产学研路线。
- **开源工具影响力**：CCAligner、BitMapper 等成果以开源工具形式发布，其产业影响主要通过工具被业界广泛使用实现（如代码克隆检测工具被工业界与学术界大量引用复用），而非直接商业化。
- **教育与竞赛生态反哺**：以安徽省计算机学会秘书长身份运营的 NOIP 安徽赛区、省级大学生创新设计大赛等活动，构成其连接地方政府、中学与省内高校的"教育产业"网络，这与并行计算学派（陈国良"科教报国"传统）一脉相承。

## 七、Connection 圈层总结

徐云的学术关系网络以"一学派、一学会、三支线"为结构特征：

- **核心圈（陈国良学派 · 国家高性能计算中心合肥本部）**：以陈国良院士为共同源头，徐云与孙广中、郑启龙、安虹等同辈学者构成中心的教学科研中坚——徐云主"算法与并行应用"，孙广中主"高性能计算与算法优化"，安虹主"体系结构与芯片"，许胤龙主"存储系统"（早期曾与徐云直接合著，后分流）。该圈层的凝聚力来自国家高性能计算中心（合肥）平台、《并行计算》国家级教学团队与安徽省计算机学会（陈国良曾任理事长，徐云现任秘书长）三重制度纽带。徐云在其中扮演"教学传承者 + 区域学术共同体运营者"的独特角色。
- **学术圈（师生谱系 + 国际同行）**：向内是学生谱系——学术线以杨矫云（合工大副教授、因果学习方向）为代表，工程线以王鹏程（CCAligner 一作，毕业后仍持续回签合作至2025年）为代表，生物信息线以程昊宇（美国）、吴鸣（北京）为代表，在读骨干为李玉婷（RDMA 方向）；向外是国际同行网络——密苏里大学 Yi Shang（生物信息/算法）、萨斯喀彻温大学 Chanchal K. Roy（代码克隆检测）、香港城市大学 Rynson Lau/Howard Leung（早期多媒体与教育应用）以及校内薛吟兴（程序分析）。
- **产业与教育圈**：以华为与中电14所横向项目、CCAligner/BitMapper 开源工具影响、以及覆盖 NOIP 安徽赛区—省级大学生竞赛—安徽省计算机大会的教育竞赛网络为骨架；其产学研风格为"项目制合作 + 工具开源 + 人才输送"，无创业孵化记录。
- **研究版图的可迁移性**：徐云团队的独特方法论是"算法—新硬件—应用"三角：经典算法问题（比对、LCS、克隆检测）× 新硬件平台（GPU、龙芯、RDMA）× 应用数据（基因序列、程序代码）。这一公式使其网络能在不更换核心圈层的前提下，随硬件浪潮（从多核到 GPU 到 RDMA 分离式内存）持续切换前沿战场。

总体而言，徐云的网络结构呈现"学派内核深厚、区域网络发达、国际连接精准"的特征：其网络资本的独特性在于**国家级并行计算教学传承（教学成果奖排名第2、国家级教学团队排名第3）**与**算法落地多领域应用（生物信息/软件工程/分布式内存）**的叠加。他既是陈国良并行计算学派在合肥本部的教学旗手，也是安徽区域计算机学术共同体的实际组织者；其国际合作网络虽不如系统方向学者密集，但在生物信息与软件工程两个应用圈各有高质量的长期锚点。与同院许胤龙（ADSL）的"存储系统 + 深度产业绑定"路线相比，徐云走的是"并行算法 + 教育共同体"路线，二者同源分流，共同构成中科大计算机学院高性能计算大版图的两翼。
