# 中国科学技术大学 高性能计算与体系结构团队（ACSA / 国家高性能计算中心（合肥））教师学术关系网络报告

> 报告生成时间：2026年8月26日

## 团队简介

中国科学技术大学的高性能计算传统由陈国良院士开创——其创建的国家高性能计算中心（合肥）是我国第一家国家级高性能计算中心，"并行计算"教材—课程—教学体系（2009 年国家级教学团队与教学成果奖）培养了数代体系结构人才。本报告系列覆盖该谱系的两位当代骨干：安虹（讲席教授，先进计算机系统结构实验室 ACSA 主任，计算机系统结构专业学位点负责人，博士师从陈国良）与徐云（教授，国家高性能计算中心（合肥）副主任，安徽省计算机学会秘书长）。二者与许胤龙（ADSL 实验室，本站已有独立报告）共同构成计算机系统结构学科点的"三驾马车"：ACSA 主攻体系结构与国产超算软件生态，徐云团队深耕并行算法与软件分析，ADSL 专注存储系统，方向互补而非从属。

团队的标志性成果集中于国产神威超算平台上的软件生态：swFLOW 数据流运行时系统支撑的全体积托卡马克等离子体模拟（SC 2021，戈登·贝尔奖提名）、250 万原子第一性原理模拟（SC 2022 DGDFT，戈登·贝尔奖提名）、"瀚海星云"海洋环境大模型（2024 年，崂山实验室/青岛国实/科大讯飞联合发布，构建于神威·海洋之光）、台风轨迹预测（Science Bulletin 2025）等；安虹团队四次获戈登·贝尔奖提名（2021–2024）。历史脉络上，安虹曾在中科院计算所博士后期间参加龙芯 1 号/2 号研制（2004 年首届中科院杰出科技成就奖），延续"曙光—龙芯—神威"的国产算力谱系。需准确把握的边界：2021 年戈登·贝尔奖获奖成果 SWQSIM 属之江实验室/清华团队；安虹、陈俊仕在 2026 年"九章四号"Nature 论文中承担的是经典模拟与验证支撑，并非潘建伟量子团队原型机研制成员。

## 研究方向与圈层结构概述

两位教师的网络共同锚定在"陈国良—国家高性能计算中心（合肥）"学派，但路径分化明显。安虹走"国产平台工程带头人"路线：核心圈是 ACSA 的"本土连续培养 + 工程任务锻造"梯队（陈俊仕、石军、韩文廷、吴俊敏），最独特的一层是 2018 年组建的校内"高性能计算前沿交叉协同创新团队"——将杨金龙—胡伟（材料）、何力新（物理）、罗喜胜—黄生洪（工程）、赵纯（大气海洋）、庄革—肖建元（核物理）五个联合团队的计算需求聚合到神威平台，扮演"计算基础设施供给者"角色；学生出口以华为为第一去向（含林晗等首批"天才少年"，汤旭龙现为匹兹堡大学副教授）。徐云走"算法与应用多元化"路线：从 SAT 随机算法（与陈国良、许胤龙、顾钧合作的博士阶段起点）经生物信息（BitMapper/WinHAP）、代码克隆检测（CCAligner，ICSE 2018，与萨斯喀彻温大学 Chanchal K. Roy 合作）到 RDMA 数据结构，形成四阶段演进，并以国家高性能计算中心副主任与省计算机学会秘书长身份承担学派的组织性角色。

## 产业转化亮点

团队产业化的核心形态是"国产算力生态绑定"而非创业孵化：神威/申威平台上的软件栈（swFLOW、PWDFT-SW、SwFormer）与瀚海星云大模型直接服务国家超算体系；安虹团队承接华为（横向课题 + 天才少年输出）、蔚来、英特尔（RAMP 项目与奖学金）、讯飞等企业合作；徐云团队与华为、中电 14 所保持横向课题合作。2014 年教育部科技进步二等奖"基于自主龙芯 CPU 的个人高性能计算机"（陈国良、孙广中、徐云、郑启龙等 15 人）是团队国产化路线的历史性注脚；ACSA 毕业生去向（华为 11 人、腾讯 3 人、讯飞 2 人等，据实验室官网校友页）则体现其作为国产算力人才"蓄水池"的定位。2019 年与德国斯图加特高性能计算中心（HLRS）签署合作备忘录，是该学派少有的机构级国际连接。
