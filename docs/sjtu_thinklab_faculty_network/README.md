# 上海交通大学 ThinkLab/RethinkLab（严骏驰组）学术关系网络报告

## 团队简介

ThinkLab（思维工厂实验室）由严骏驰教授于2018年4月创立（时值其从IBM中国研究院首席研究员任上回归学术界），初期聚焦机器学习、数据挖掘与计算机视觉，现已扩展为RethinkLab研究体系，研究方向覆盖组合优化的机器学习求解（图匹配）、量子机器学习、神经架构搜索（NAS）、EDA电子设计自动化、智能决策、AI4Science与大模型新架构等前沿领域。严骏驰现任上海交通大学人工智能学院教授（2023年晋升正教授）兼人工智能学院创始副院长。

实验室最鲜明的特征是"学术治理话语权 + 产业落地能力"的双重稀缺性：严骏驰于2025年7月与北京大学林宙辰同时当选ICML董事会成员（首批中国大陆学者），长期担任ICML/NeurIPS/ICLR领域主席、IEEE TPAMI编委；同时其约10年工业界经历（IBM首席研究员、亚马逊AI实验室顾问）奠定了从基础研究到EDA/工业视觉商业化的完整链条——与华为诺亚方舟实验室联合提出的EasyRL刷新EPFL逻辑综合基准纪录，IBM期间主导的全球首个深度学习液晶屏缺陷检测商业项目是智能制造领域的里程碑。

学生培养是实验室的另一支柱：10名博士毕业生分获上海交大、复旦、中科大、南大教职，2人赴MIT从事博士后研究（含Broad Institute），指导学生获CCF优博或提名（2次）、CV新锐奖（3次）、交大学术之星或提名（3次）、挑战杯特等奖。本报告覆盖实验室创始人严骏驰及其培养的代表性青年学者杨学（2023年CCF优博、RethinkLab体系下VisionXLab负责人）。

## 研究方向与圈层结构

团队以"机器学习及交叉应用"为轴心，形成五层辐射网络：第一圈层为博士师承与嫡系（查宏远—严骏驰—杨学/王润中/贾萧松/刘畅/吴齐天等，出口覆盖交大、复旦、南大、MIT、NTU、Broad Institute）；第二圈层为RethinkLab—VisionXLab嵌套实验室结构（严骏驰与杨学共同指导新生代学生）；第三圈层为交大校内AI生态（俞勇ACM班、杨小康、人工智能学院、吴文俊博士班）；第四圈层为产学研网络（IBM旧部、华为诺亚EDA合作、亚马逊AWS AI Lab、DeepSeek/字节等学生就业通道）；第五圈层为国际学术社区（ICML董事会、林宙辰等同行、日本NII/MBZUAI客座教授网络）。

## 产业转化亮点

EDA与工业视觉是实验室产业转化的双引擎：与华为诺亚方舟实验室合作的EasyRL在EPFL Combinational Benchmark Suite 2023上刷新Rapid Silicon占榜的26个电路结果、取得12个单项第一（2024年再获10项第一）；IBM时期的液晶屏缺陷检测系统开创了深度学习大规模工业质检商业化的先例。新生代转化体现在杨学身上：2026年8月受聘酷哇科技（COOWA）首席科学家，牵头筹建"上交—酷哇通用具身智能联合实验室"，将其在目标检测（R3Det、MMRotate/AlphaRotate框架超7000 star）与多模态大模型（Mono-InternVL、PKINet）上的积累推向万台级机器人运营场景；VisionXLab学生亦获腾讯混元博士生专项、CCF博士生科研激励计划等产业界资助。
