## 七、Connection 圈层总结

**第一圈层：长期论文合作。** 梁彬是可见书目中合作最稳定的同校合作者之一，至少14次合作横跨2016—2026；Xiangyu Zhang 则是跨机构合作网络中的高频合作者，至少11次合作，研究主题集中于程序分析、二进制分析、模糊测试与强制执行。二者均为论文合作关系，公开资料未证明其为游伟博士导师。

**第二圈层：人大网络与信息安全团队。** 黄建军、石文昌、梁彬与游伟兼具同事关系和共同论文关系；李亚平、秦波可确认属学院信息安全团队同事，但本次材料不足以确认其与游伟的高频论文合作。

**第三圈层：直接指导与学生团队。** 官方新闻明确詹倚飞由游伟指导；个人主页公布了当前团队成员，并对林润、王宇杰明确标注了联合指导情形。应将“导师—学生”与“共同论文作者”分开：学生论文共署并不自动证明唯一导师关系。

**第四圈层：跨校博士后合作。** 印第安纳大学和普渡大学的博士后经历构成其国际学术流动节点；与 Xiangyu Zhang 等人的持续共同发表，显示出该阶段形成的跨机构研究联系仍在延续。

整体而言，游伟的公开学术网络以软件安全研究为主轴，围绕模糊测试、程序/二进制分析、漏洞挖掘、强制执行和内核安全展开；近年与人大安全团队共同覆盖 AI 安全、内核漏洞利用等议题。业界合作和博士导师信息尚无公开、可核验材料支撑。
