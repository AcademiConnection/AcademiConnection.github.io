# 中国人民大学 网络与信息安全团队教师学术关系网络报告

> 报告生成时间：2026年8月

## 团队简介

中国人民大学信息学院的网络与信息安全方向由两个互补的团队构成：一是**智能软件安全研究团队（信息安全实验室）**，以梁彬教授（中科院软件所博士、清华博士后）为核心，联合游伟副教授、黄建军副教授等，聚焦软件安全性分析与新型安全攻防对抗技术，在主流软件系统和商业人工智能系统中发现了数百个已确认漏洞/缺陷，长期在 IEEE S&P、CCS、USENIX Security、ICSE、FSE、ISSTA 等安全与软工顶会保持稳定产出；二是以**石文昌教授**（可信计算国内代表学者）为代表的系统安全与可信计算方向，覆盖安全操作系统、漏洞分析、电子取证，并延伸至区块链安全。

团队的学术谱系呈现"中科院软件所+普渡大学"双源头特征：梁彬、石文昌均出自中科院软件所（安全操作系统课题组），上游联系孙玉芳、贺也平等前辈；游伟、黄建军则先后毕业于人大与普渡大学（导师张翔宇教授），将普渡的程序分析传统带入团队。秦波副教授是西班牙加泰罗尼亚理工大学（URV，Domingo-Ferrer 领先的 CRISES 组）出身的密码学学者，与北航吴铫鸿构成"西电密码学—广播加密/群密钥—区块链共识"的独立研究主线，同时与石文昌团队及 DEKE 数据库团队（陈红、李翠平、赵素云）形成"安全×数据库"的密文查询交叉合作。

国际合作以美国普渡大学 Xiangyu Zhang 教授（游伟、黄建军的博后/博士导师）为枢纽；国内则与中科院软件所、北航、清华等机构保持长期合作。

## 研究方向与圈层结构概述

团队的圈层结构以梁彬—石文昌的二十年合作（DBLP 联合署名50次）为双核锚点。内环是"铁三角"：梁彬（软件安全与漏洞挖掘）、游伟（模糊测试与系统安全，26次合作）、黄建军（程序分析与智能合约安全，23次合作），三人在 2019 年后共同支撑起团队在 S&P、ICSE、CCS、FSE、ISSTA 的顶会产出，2025 年 S&P 录用两篇论文。中环是秦波—石文昌的密码学与区块链支线（30次合作），以及与 DEKE 数据库团队的密文查询交叉（陈红、李翠平、赵素云，IWQoS 2019/TKDE 2023）。外环是国际网络：普渡大学 Xiangyu Zhang（普渡-人大持续联合发表，涵盖梁彬、游伟、黄建军三代人）与中科院软件所旧部（吴彦俊等）。

## 产业合作与人才培养亮点

团队产业影响主要体现为"漏洞发现与安全工具"路径而非商业横向项目：在主流软件系统与商业 AI 系统中发现数百个已确认 CVE 漏洞。秦波支线则通过密码学应用接入产业（Nervos/Cryptape 生态、阿里/字节安全团队）。人才培养上，游伟已入选国家级青年人才，学生毕业去向覆盖高校教职与头部企业安全实验室，形成"中科院软件所—人大—普渡"三角环流中相对年轻的一支力量。
