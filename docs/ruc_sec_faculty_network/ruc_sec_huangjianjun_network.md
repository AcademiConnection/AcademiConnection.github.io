## 一、学者基本信息

黄建军，中国人民大学信息学院计算机科学与技术系副教授（2024年9月起），此前为该系讲师（2017年12月—2024年8月），智能软件安全研究团队成员。2017年于美国普渡大学计算机系获得博士学位，导师为张翔宇教授。其研究主线是通过自然语言处理与静态程序分析相结合进行软件安全性分析，涵盖 Android 应用分析、恶意行为发现与隐私泄露检测、Web 安全等；近年亦参与团队的人工智能安全（对抗补丁攻防）与漏洞检测方向。曾获 2016 年 ACM SIGSOFT 杰出论文奖（FSE 2016 第一作者论文），并作为团队成员获 2021 年度中国计算机学会自然科学一等奖（"高精度智能化的软件分析与测试方法"）。担任 IEEE TSE、Journal of Computer Security、《计算机学报》、SCIENCE CHINA Information Science 审稿人。

### 研究方向

- **软件安全性分析与程序分析**：自然语言处理与静态分析结合的敏感行为/隐私泄露检测（代表性成果 SUPOR、AsDroid、FSE 2016 杰出论文）

- **Web 安全与漏洞/缺陷检测**：钓鱼页面检测、模糊测试、缺陷检测（Raisin、SICode、Feature Slice Matching 等）

- **区块链/智能合约安全**：智能合约漏洞检测（TIFS 2021、TC 2022，近年产出减少）

## 三、博士教育背景

### 博士阶段（美国普渡大学，约2012—2017年）

黄建军在普渡大学计算机系攻读博士学位（个人主页称始于2012年秋，人大教师页记为2015.08—2017.12，2017年12月获学位），导师为**张翔宇教授**。其博士论文为《Static Analysis of Android Apps with Text Analysis and Bi-directional Propagation》（DBLP 收录，Purdue AAI10639233），主题即"文本分析与双向传播相结合的 Android 应用静态分析"——这一定调贯穿其整个学术生涯。

博士阶段的主要成果（均为第一作者或主要贡献者）：

- **ICSE 2014**："AsDroid: Detecting Stealthy Behaviors in Android Applications by User Interface and Program Behavior Contradiction"——UI 与程序行为矛盾检测隐蔽行为（合作者含梁彬、王鹏，为国内硕士期间合作的延续）
- **USENIX Security 2015**："SUPOR: Precise and Scalable Sensitive User Input Detection for Android Apps"——与 NEC Labs America 合作，敏感用户输入检测，并衍生美国专利 US 20160132679 A1
- **ESEC/FSE 2016**："Detecting Sensitive Data Disclosure via Bi-directional Text Correlation Analysis"——获 **2016 ACM SIGSOFT 杰出论文奖**
- **ICSE 2016**：从文档自动生成 Java API 函数模型（与翟佳、马世奇、谭琳等合作）
- **ASE 2017**："UI Driven Android Application Reduction"
- **CCS 2018 / NDSS 2018**：Android API 保护映射推理、AceDroid 访问控制一致性检测（与同门 Yousra Aafer、导师张翔宇、李宁辉等）

普渡期间所在的张翔宇研究组是程序分析与软件安全领域的顶级团队（张翔宇现为普渡 Samuel D. Conte 讲席教授，2006 年亚利桑那大学博士、ACM SIGPLAN 博士论文奖得主），同期成员包括 Yousra Aafer（现任康涅狄格大学教授）、Guanhong Tao、Zhuo Zhang 等，李宁辉、谭琳、XiaoFeng Wang（印第安纳大学）等亦为密切合作者。

### 硕士与本科阶段（中国人民大学，2005—2012年）

黄建军本科（2005—2009）与硕士（2009—2012）均就读于中国人民大学信息学院，硕士导师公开资料未披露；其 ICSE 2014 AsDroid 论文与梁彬、王鹏共同署名，显示人大硕士阶段即已与梁彬建立合作关系（该论文是否属硕士期间工作无法确证，但其后加入梁彬团队的事实佐证了这一早期纽带）。这一"人大本硕—普渡博士—回人大任教"的路径，与团队同事游伟（人大本硕博—普渡博士后—人大任教）形成了呼应。

其指导的本科生信息安全竞赛一等奖作品（VMKillers，虚拟机逃逸/恶意软件分析方向）后续在游伟团队发展为 CCS 2026 论文，体现了"教赛研融合"路径，但未见商业化转化披露。

### 5. 总结

黄建军的合作网络以**学术共同体为主、产业为辅**：企业合作仅博士阶段 NEC Labs 一项（含专利），回国后的"合作对象"主要是中科院软件所与普渡母门。其产学研属性弱于团队内游伟（企业横向合作亦少），团队整体的产业转化以漏洞发现（团队宣称在主流系统中发现数百个已确认漏洞/缺陷）而非产品化为主。

## 七、Connection 圈层总结

**第一圈层（博士导师与普渡师门）：** 张翔宇教授（普渡大学，11 次合作）是其学术根基的直接来源——自然语言处理+程序分析的技术路线、Android 安全的研究选题均成型于普渡，且回国后八年间合作不断线，是该团队对接国际顶级程序分析力量的核心通道。同门 Yousra Aafer、Zhuo Zhang、Yapeng Ye 及谭琳、李宁辉、汪晓峰（XiaoFeng Wang）等构成的普渡/印第安纳学术圈是其最重要的海外网络。

**第二圈层（现单位团队"铁三角"）：** 梁彬（17 次）、游伟（16 次）、石文昌（12 次）构成其回国后的核心合作网络。三者关系均为论文合作+同事关系（与梁彬的硕士阶段渊源无直接指导记载）；团队呈"梁彬掌舵—游伟/黄建军双主力"的格局，游伟与黄建军还共同指导硕士生。2021 年 CCF 自然科学一等奖为团队集体成果。

**第三圈层（跨机构稳定合作）：** 中科院软件所（张健、吴敬征、武延军、边攀，累计约 10 次合作）是其最主要的国内院外合作网络；NEC Labs America 是其唯一的产业合作经历（SUPOR 论文+美国专利，2015 年）。

**第四圈层（自主培养学生）：** 龚元君、李嘉纯、冯佳楠、聂江磊等学生团队正在成长，2024—2026 年 ICSE/ISSTA/FSE/S&P/CCS/TDSC 持续产出；其角色已从博士阶段的"第一作者"逐步转向"通讯作者/指导者"（Raisin ICSE 2024 第一作者兼通讯、FuzzInMem 通讯、Feature Slice Matching FSE 2026 通讯）。

**整体画像：** 黄建军是典型的"人大本硕—海外博士—回流母校"学者：技术上承袭普渡张翔宇组的程序分析路线，组织上嵌入梁彬领导的智能软件安全团队，产出节奏上经历了博士期高产（2014—2018 年 8 篇 CCF A 一作/主力）—回国调整期（2019—2022 年期刊化、合作化）—团队爆发期（2023 年至今年均 3—5 篇 CCF A）三个阶段。其学术网络的独特价值在于同时桥接了普渡顶级程序分析组和人大本土软件安全团队。
