## 二、教育背景与职业履历

孙士锋在上海交通大学完成博士学位，导师为讲席教授谷大武，研究方向为可搜索加密与公钥密码。其博士论文工作获得2019年中国密码学会优秀博士学位论文奖，这是国内密码学科博士培养的最高标志性荣誉之一，也印证其学术起点即处于谷大武所领导的LoCCS/IISeC体系核心。博士期间及毕业后，他与Monash大学应用密码学团队建立了密切联系，并在该校信息技术学院任助理教授（终身教职）。

在Monash期间，他的合作者圈层明显扩展：与Joseph K. Liu（莫纳什大学应用密码学方向代表学者）、Cong Zuo、Xingliang Yuan、Ron Steinfeld、Amin Sakzad、Tsz Hon Yuen，以及CSIRO的Dongxi Liu等共同发表可搜索加密、加密网络流量匹配、区块链认证等方向的论文。其中发表于IEEE TDSC的"Non-Interactive Multi-Client Searchable Encryption: Realization and Implementation"（孙士锋为第一作者、谷大武为通讯作者）即为上交—Monash—CSIRO—港大多机构合作的代表成果。

2021年前后，孙士锋选择回国加入上海交通大学网络空间安全学院，任长聘教轨副教授、博士生导师，并入选上海市高层次人才计划。2024年起出任网络空间安全学院副院长，同时作为青年教师骨干在谷大武（院长）领导下的学院管理架构中承担重要角色。这一履历使其成为IISeC中兼具国际视野、产业落地经验与行政管理能力的枢纽型青年学者。

## 三、学生培养情况

作为博士生导师，孙士锋已建立起围绕公钥加密、可搜索加密、零知识证明与隐私保护机器学习的研究生培养梯队。从公开论文署名可以观察到其学生网络的一些代表节点：

1. **袁博实**等（LoCCS博士生群体）：在USENIX Security 2024录用的隐私保护机器学习论文"MD-ML"（袁博实、杨士玄、张永翔、丁宁、谷大武、孙士锋）中，孙士锋与谷大武共同指导的学生团队完成了抗恶意敌手的安全多方计算机器学习协议，实现向量点乘在线通信量与维度无关的突破，体现了其学生在顶级安全会议上的独立产出能力。

2. **密码创新奖获奖团队**：2024年孙士锋牵头获中国密码学会密码创新奖二等奖，学院通报中特别强调其"以第一/通讯作者发表50余篇"的成果结构，说明其培养模式下学生成果多由其亲自把关与通讯署名，形成紧密的师生学术共同体。

3. 其在Monash及合作机构期间指导或合作培养的学生（如与Cong Zuo、Joseph K. Liu合作的DSSE方向研究生）也延续了可搜索加密方向的研究，构成跨国师承网络的延伸。

值得注意的是，其博士导师谷大武的公开招生信息中明确将"简洁非交互零知识证明、数据隐私保护、区块链安全交易协议"列为团队方向，这些正是孙士锋回国后承担的接力方向，显示出"谷大武—孙士锋"两代学者在课题布局上的传承与分工。

## 四、学术合作网络

### 4.1 内部：IISeC与LoCCS的协同网络

IISeC为孙士锋提供了最核心的组织化协作场域。研究所由邢朝平负责，资深教授层包括来学嘉（IACR Fellow、IDEA算法设计者）、谷大武（讲席教授、院长，孙士锋的博士导师）、刘胜利（国家杰青）与郁昱等，构成"理论—算法—工程—应用"的骨干结构。孙士锋与这些资深学者的合作关系有明确成果支撑：

- **谷大武**：既是导师也是长期合作者。两人在CCS 2022的VOProof（向量预言机编译器构造高效zkSNARK）、PKC 2023的"Functional Encryption against Probabilistic Queries"（与王更、汪哲东合作）等论文中持续合作，并在2024年度中国电子学会自然科学二等奖项目中同为完成人。
- **韩帅**：同为谷大武体系培养的青年教师，研究方向为公钥密码与区块链。两人同为"数据安全中的关键密码理论与方法"获奖项目完成人，是IISeC青年层最紧密的内部搭档。
- **刘胜利**：同为上述获奖项目完成人，其团队在公钥加密与密码理论方向的积累与孙士锋形成互补。
- **王更**：IISeC副教授，格密码分析方向，与孙士锋在PKC 2023论文中合作。
- **汪哲东、王浩洋**等青年教师分别在网络空间安全、对称密码方向延伸了研究所的覆盖面。

在LoCCS实验平台上，孙士锋参与谷大武领导的隐私保护机器学习（USENIX Security 2024）、零知识证明等课题，形成"理论构造—协议实现—系统验证"的团队协作模式。

### 4.2 跨机构：国内高校合作网络

孙士锋的国内跨机构合作以可搜索加密与数据安全为纽带，最突出的是与西安电子科技大学的长期合作：

- **王剑锋（西安电子科技大学）**：两人合作频繁，包括CCS 2022的"Practical Volume-Hiding Encrypted Multi-Maps"（与李天赐、齐赛玉、陈晓峰合作）、CCS 2024的"Practical Non-interactive Encrypted Conjunctive Search with Leakage Suppression"（与王云玲、陈晓峰、Joseph Liu、谷大武合作）等，形成"上交—西电"在加密数据库检索方向的稳定双中心。

## 五、业界合作关系深度分析

孙士锋的产业合作沿三条路径展开：

1. **密态数据库与加密检索**：其可搜索加密、保序/泄露抑制加密研究成果被表述为"成功应用于密态数据库"，该方向与蚂蚁集团（OceanBase等密态计算产品线）、华为等IISeC长期企业伙伴的业务场景直接相关。
2. **数字金融与隐私保护交易协议**：获奖项目覆盖"隐私保护交易协议"，与银联等金融支付机构的合作场景吻合；其担任上海市数据标准化技术委员会委员，进一步将其研究嵌入数据要素流通的地方标准制定进程。
3. **检测与合规生态**：谷大武创建的国家级商用密码检测（上海）中心与上海浦东密码研究院为IISeC青年教师提供了企业检测需求的接口，孙士锋作为学院副院长与大数据与人工智能安全专委会秘书，在这一"研究—检测—标准—产业"链条中承担转化枢纽角色。

需要注意的是，公开材料中对企业合作的表述多为团队层面的"深度合作"与成果"应用于"某领域，未逐一披露具体联合项目编号与合同细节，宜以方向性合作格局理解，而非逐项对应。
