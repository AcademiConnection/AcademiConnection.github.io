## 二、教育背景与职业履历

邢朝平于1990年在中国科学技术大学获得博士学位，随后留校工作。这一阶段奠定了其代数数论与编码理论的数学根基，也构成其后续研究中频繁使用代数几何、有限域及函数域方法的知识源头。1993年，他获德国洪堡奖学金赴德国Essen大学开展研究，之后在奥地利科学院从事研究工作。德语区的学术经历使其较早进入欧洲数学与编码研究网络，并通过洪堡学者身份形成稳定的国际学术连接。

1998年，邢朝平加入新加坡国立大学，先后担任助教、获得tenure的副教授及教授。NUS时期是其由独立研究者成长为国际合作枢纽的关键阶段：新加坡的区域性国际化环境有利于他连接东亚、欧洲与北美的编码、密码研究群体。2007年起，他任新加坡南洋理工大学教授，进一步扩大了在编码理论、密码学与理论计算机领域的合作半径。2019年加盟上海交通大学后，他将长期积累的国际网络和研究议题带入IISeC，推动交大在代数几何码、秩度量码、MPC和零知识证明等方向形成连续产出。

上述履历也说明其网络并非一次性、项目式拼接，而是由长期任职机构构成的多节点网络：中科大提供基础训练与国内学术源头，德国和奥地利带来数学研究传统，NUS和NTU形成东南亚国际合作平台，SJTU则成为近年组织团队、培养学生并承接国家级项目的核心节点。

## 三、学生培养情况

公开资料表明，邢朝平为博士生导师，其课题组面向信息安全、理论计算机、数学和人工智能等相邻领域开展培养，重点议题包括代数曲线理论与应用、代数几何码、安全多方计算和零知识证明。这样的培养结构强调从数学理论到密码协议与计算效率的完整链条：学生需要同时理解代数对象、编码构造、复杂性分析和安全证明，因此适合产出跨会议社群的工作。

从近年论文作者和学院新闻可观察到一批与其研究方向高度耦合的青年研究者与学生型合作者。李宋宋（Songsong Li）与邢朝平共同完成SODA 2024论文《Fast Fourier Transform via Automorphism Groups of Rational Function Fields》，体现代数函数域与算法设计结合的培养路径。林富春与姚逸洲共同参与CRYPTO 2024工作《More Efficient Zero-Knowledge Protocols over Z_{2^k} via Galois Rings》，呈现了从编码/环理论向零知识协议优化的迁移。刘弘庆、袁晨、邹涛旭与邢朝平合著2024年ASIACRYPT录用工作，研究矩阵环上的不诚实多数MPC。

需要区分的是，论文共著能够直接证明研究协作与学术指导环境，但公开网页未逐一公布上述作者与邢朝平之间的正式学位指导关系或入学、毕业信息。因此，本报告将其列为“课题组/论文协作网络中的青年研究者”，而不将全部作者未经证实地标注为其博士生。就培养影响而言，这些共同作者构成了邢朝平网络向下一代研究者扩散的可见接口：一端承接数学与编码传统，另一端进入零知识证明、MPC和隐私计算等前沿方向。

## 四、学术合作网络

### 4.1 内部：IISeC与上海交通大学协同网络

IISeC内部的合作基础是密码、计算机安全与可信数据技术的交叉布局。公开团队信息所列的核心师资包括讲席教授、院长谷大武，教授来学嘉（IACR Fellow）、刘胜利、郁昱，以及青年教师王浩洋、孙士锋、韩帅等。邢朝平作为研究所负责人，在组织层面连接编码理论、密码协议和安全应用议题；谷大武作为学院管理者与研究所重要负责人，则构成团队治理和学术资源协调的关键节点。来学嘉、刘胜利、郁昱及青年教师群体提供不同密码与安全方向的专业覆盖，使编码与密码的理论成果能够与公钥密码、协议安全、系统安全等问题形成交流。

从论文和新闻中可见更直接的内部合作链条。SODA 2024中，邢朝平与李宋宋以有理函数域自同构群为工具，构造包含加法和乘法的快速傅里叶变换统一框架；这条连接体现了数学科学与理论计算机方向之间的协同。2024年MPC论文由刘弘庆、邢朝平、袁晨、邹涛旭共同完成，针对矩阵环上的安全计算降低秘密共享和矩阵乘法开销，显示团队向隐私保护机器学习等应用场景延伸。林富春—邢朝平—姚逸洲的零知识证明工作，则将环上的代数结构转化为低通信量协议设计。

内部网络的特点不在于所有成员都共同署名，而在于共享研究基础设施和问题域：代数、编码与密码为共同语言，IISeC为人员与课题的组织平台，LoACPP等研究群体则为面向隐私保护和先进密码的专题节点。该结构有利于把基础理论课题转化为多方计算、零知识证明和数据安全中的可计算方案。

### 4.2 跨机构：国内外流动形成的合作走廊

邢朝平的跨机构联系首先来自其长期职业迁移。中国科学技术大学、德国Essen大学、奥地利科学院、NUS和NTU是其研究生涯中具有明确时间顺序的机构节点；这些节点分别对应中国数学教育、欧洲代数与数学研究传统、新加坡高等教育与国际化研究平台。2019年加入SJTU后，跨机构合作并未中断，而是以共同论文、学术访问、国际会议与项目组织等方式继续向上海汇聚。

在项目层面，他曾主持或承担中国国家自然科学基金重点项目、科技部重点研发项目、新加坡国家科学基金重点项目、新加坡国防部基金及新加坡教育部基金。项目来源横跨中国与新加坡，反映其科研组织网络兼具国内重大任务与国际任职积累。以国家重点研发计划“代数几何码的数学理论及应用”为例，邢朝平作为项目负责人承担总体方案介绍与课题组织，这使其成为数学理论、编码应用和国内协同研究之间的连接节点。

跨学院连接同样值得关注。交大数学科学学院的公开活动中，邢朝平与袁晨、李宋宋参与面向本科生的学术分享，议题覆盖数学、信息安全和理论计算。这类交流并非单纯宣传，而是为从数学背景进入密码与理论计算机方向的学生建立导师、课题与研究方法之间的通道；其长期价值在于扩大未来学生与合作者来源。

### 4.3 国际：以编码理论和密码学旗舰共同体为核心

国际合作网络中最具代表性的学者是Venkatesan Guruswami。Guruswami是编码理论与理论计算机科学领域的重要学者，曾任职于卡内基梅隆大学并与加州大学伯克利分校有学术关联。两人合作研究代数几何码的列表译码，成果包括《Optimal Rate List Decoding over Bounded Alphabets Using Algebraic-geometric Codes》（JACM，2022）以及有关窄射线类域的最优速率代数列表译码工作。该合作的意义在于：Guruswami侧重算法与复杂性、列表译码理论，邢朝平长期深耕代数函数域和编码构造；二者结合使代数几何码能够在接近容量的译码问题中获得更强结果。这是“数学结构供给—算法译码目标”互补型国际合作的典型案例。

密码学国际网络则由多篇共同论文反映。Ronald Cramer、Ivan Damgård、Daniel Escudero、Peter Scholl、Ignacio Cascudo等研究者与邢朝平在SPDZ2k、秘密共享、MPC摊销复杂度、零知识证明等议题上合作。比如CRYPTO 2018的SPDZ2k工作针对不诚实多数场景下模2^k的高效MPC；CRYPTO 2022的工作继续以Galois Rings改进此类安全计算。该合作群连接了欧洲密码学传统、MPC协议设计与邢朝平的编码/代数背景，使其网络从“编码理论国际合作”扩展为“现代密码协议国际合作”。

此外，FOCS 2024论文《Random Gabidulin Codes Achieve List Decoding Capacity in Rank Metric》由Z. Guo、邢朝平、C. Yuan、Z. Zhang合作；CRYPTO 2024、SODA 2024的成果又分别在零知识证明和算法理论方向形成高水平可见度。由此可见，国际网络不是围绕单一合作者建立，而是以旗舰会议为交汇场：编码理论通过FOCS/SODA/JACM连接理论计算机共同体，MPC和零知识证明通过CRYPTO、EUROCRYPT、ASIACRYPT、TCC、PKC连接国际密码共同体。

## 五、业界合作关系深度分析

就公开可检索材料而言，邢朝平的网络主体是高校、科学院、国际学术组织和国家科研项目，而非直接以企业联合实验室、公司任职或具名产业联合项目为中心。因此，不能仅凭其研究领域涉及“安全”“隐私保护”便推断其与某一家企业存在直接合作关系。本节所述“业界关系”应理解为技术外溢与应用接口，而非未经公开证实的商业合作名单。

第一，研究议题具有显著的产业相关性。安全多方计算面向多主体数据协作，矩阵环上的MPC直接关联隐私保护机器学习中的线性层计算；零知识证明可服务于低带宽、可验证计算和隐私认证；编码理论则与可靠传输、存储和抗错误计算有关。2024年关于矩阵环MPC的工作在秘密共享大小、矩阵乘法计算量和线上/线下性能方面给出具体优化，显示研究并不止步于抽象安全定义，而重视协议的资源消耗与可部署性。

第二，项目经历构成从基础研究到行业需求的制度化接口。中国科技部重点研发项目、国家自然科学基金重点项目以及新加坡国防部基金等，通常要求兼顾理论原创性、关键技术与任务场景。特别是国家重点研发计划中“代数几何码的数学理论及应用”的布局，说明其团队具备将数学理论组织为应用导向研究任务的能力。不过，公开资料未披露具体企业合作方、合同项目或技术转化主体，故不对合作深度作超出证据范围的判断。

第三，学术服务可形成间接产业影响。担任IEEE Transactions on Information Theory、Information and Computation、Finite Fields and Their Applications等期刊编委，以及参与Hamming奖评审专家委员会，使其处于编码和信息论成果评价的国际节点。这种影响不同于商业合作：它通过研究议程设置、学术标准与人才流动，影响密码、通信和数据安全产业可吸收的基础技术。整体看，邢朝平的业界连接属于“基础理论—国家项目—安全技术场景—人才输出”的深层间接模式；若需要形成企业合作图谱，仍应以公开项目公告、专利、联合实验室和企业署名论文作进一步补充。

## 六、重要奖项与学术兼职

邢朝平获得新加坡国家科学奖、荷兰Leiden大学Kloosterman讲席教授荣誉，并具有德国洪堡学者经历；同时入选国家海外高层次人才计划、上海市海外高层次人才计划和中科院百人计划。这些荣誉分别覆盖新加坡科研体系、欧洲数学传统、德国学术交流网络与中国高层次人才体系，说明其学术声誉具有跨区域认可度。

学术服务方面，他曾任国际编码界最高奖Hamming奖评审专家委员会成员，并曾作为斯坦福大学访问教授开展学术交流；现任IEEE Transactions on Information Theory、Information and Computation、Finite Fields and Their Applications等SCI期刊编委。编辑和评审角色使其不仅是论文合作网络中的节点，也在学术质量控制与研究方向传播中承担“把关人”角色。其专著《Coding Theory -- A First Course》由剑桥大学出版社出版并被多所大学采用为教材，则进一步扩大了网络的教育传播范围：教材使用者未必是直接合作者，却构成其学术思想影响的广义连接圈层。

## 七、Connection圈层总结

**第一圈层：课题组与IISeC内部协同。** 邢朝平以IISeC负责人和博士生导师身份，连接谷大武、来学嘉、刘胜利、郁昱及青年教师群体，并通过李宋宋、林富春、刘弘庆、袁晨、姚逸洲、邹涛旭等论文协作者，形成围绕代数、编码、MPC与零知识证明的高频研究网络。这一圈层最直接承担论文产出、学生培养和项目实施。

**第二圈层：跨学科与跨学院人才网络。** 数学科学学院与网络空间安全学院之间的交流，使代数曲线、函数域、FFT等数学主题能够与密码学、理论计算机问题对接。该圈层的核心价值是吸纳具有数学基础的学生和合作者，并为复杂密码问题提供严谨的结构工具。

**第三圈层：国际核心合作者与旗舰会议共同体。** Venkatesan Guruswami代表编码理论、列表译码和算法方向的关键合作节点；Cramer、Damgård、Escudero、Scholl、Cascudo等代表MPC、秘密共享和零知识证明网络。FOCS、SODA、JACM与CRYPTO、EUROCRYPT、ASIACRYPT、TCC、PKC共同构成这些连接被建立、展示与延续的国际平台。

**第四圈层：职业履历、项目与学术服务网络。** 中科大、Essen大学、奥地利科学院、NUS、NTU与SJTU构成时间跨度长的机构网络；中德欧新中的科研经历和中国、新加坡项目体系提供资源与议题接口；期刊编委、Hamming奖评审及教材传播则使其影响延伸至论文合作之外。

总体而言，邢朝平的学术关系网络是“以代数与编码为理论底座、以密码和安全计算为应用方向、以国际旗舰共同体为外部连接、以IISeC为国内组织枢纽”的多层结构。其网络优势在于跨越数学、信息论、理论计算机和密码协议四种学术语言；未来最具增长潜力的连接方向，则是将代数几何码和秩度量码的理论进展，与隐私计算、零知识证明和可信数据流通中的效率与安全需求进一步耦合。
