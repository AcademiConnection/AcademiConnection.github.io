## 二、教育背景与职业履历

刘胜利具有独特的"中西双重博士"培养路径，这使其学术网络同时连接中国密码学传统和欧洲离散数学与编码理论共同体。

**本科阶段（1991.9—1995.7）：** 就读于西安电子科技大学经济管理学院，获工学学士学位，专业方向为科技信息。该阶段为其奠定了信息管理与科技情报的基础素养。

**硕士阶段（1995.9—1998.2）：** 在西安电子科技大学计算机学院学习，获工学硕士学位，专业为计算机应用，导师为李伯成教授。此段经历使其从信息管理转向计算机科学，为后续密码学研究打下计算机系统基础。

**国内博士阶段（1997.3—2000.1）：** 在西安电子科技大学通信工程学院信息安全与保密实验室攻读博士，获密码学博士学位，导师为王育民教授。王育民是中国密码学领域的资深学者，长期从事信息论、编码与密码学研究，是西电密码学传统的重要代表人物之一。这一师承关系使刘胜利的学术源流可追溯至中国密码学的早期学科建设脉络。

**海外博士阶段（2000.3—2002.2）：** 赴荷兰爱因霍芬技术大学（Eindhoven University of Technology，TU/e）数学与计算机科学系离散数学组学习，于2002年2月获密码学博士学位，导师为Henk van Tilborg教授。TU/e的离散数学与编码理论在欧洲具有较高声誉，van Tilborg在编码理论与密码学领域有广泛学术影响。这段经历不仅为其补充了欧洲密码学及编码理论的训练，也使其与欧洲学术共同体建立了最初的国际连接。

**职业经历：** 2002年4月加入上海交通大学计算机科学与工程系，在陈克非教授领导的密码与信息安全实验室从事研究工作。2008年12月晋升教授。2007年9月至2008年2月赴美国路易斯安那州立大学拉法叶分校任访问学者，进一步拓展了其与北美学术界的联系。2019年获国家杰出青年科学基金建议资助，标志着其在国内密码学界的学术地位获得正式认可。2022年1月起担任电子信息与电气工程学院副院长，2024年起担任学生创新中心主任，2025年11月起担任教学发展中心主任，2026年1月起担任信息安全与密码研究所副所长。这一系列行政角色的扩展，使其连接范围从学术研究扩展到本科教学、创新创业教育和学科管理层面。

## 三、学生培养情况

刘胜利在博士生培养方面成果显著，其指导的博士生中已有多人获得中国密码学会优秀博士学位论文奖，形成了从基础密码理论到后量子密码应用的学术传承链条。以下为其代表性学生：

1. **韩帅**：2017届博士毕业生，师从刘胜利教授，现为IISeC助理教授。韩帅在读期间及毕业后持续与刘胜利保持紧密合作，是CRYPTO 2023论文"Almost Tight Multi-User Security under Adaptive Corruptions from LWE in the Standard Model"的第一作者。其研究成果发表于CRYPTO、ASIACRYPT、PKC等国际顶级会议和JoC、DCC、TCS等国际期刊。2019年获中国密码学会优秀博士学位论文奖，2020年入选上海市青年科技英才扬帆计划，2021年入选中国科协青年人才托举工程并荣获ACM中国新星奖。韩帅从博士生成长为同事和核心合作者，是刘胜利培养网络中"学生—同行—团队骨干"演化路径的典型代表。

2. **温云华**：2013级博士，2019年6月获博士学位，师从刘胜利教授。其学位论文围绕从噪声随机源中提取安全可靠的随机数这一研究课题，对模糊提取器进行了深入研究。主要成果包括首次提出鲁棒可重用模糊提取器的安全模型，构造了第一个既满足鲁棒性又满足可重用性的模糊提取器，以及第一个抗量子攻击的鲁棒可重用模糊提取器等。研究成果发表于ASIACRYPT、PKC、Designs Codes and Cryptography等会议和期刊。2021年获中国密码学会优秀博士学位论文奖。

3. **刘翔宇**：2019级博士，2023年3月获博士学位，师从刘胜利教授。其学位论文以紧致安全证明为切入点，设计构造了若干具有紧致安全性的密码算法与协议，成果包括首次提出显式认证且紧致安全的2轮AKE协议、首次提出UC模型下基于标准困难假设的紧致安全PAKE协议等。研究成果发表于ASIACRYPT、PKC、Theoretical Computer Science等会议和期刊。2023年获中国密码学会优秀博士学位论文奖。

4. **吕优**：2022级致远荣誉博士生，导师为刘胜利教授，研究方向为公钥密码学。目前已发表7篇论文，以第一作者身份在EUROCRYPT、ASIACRYPT等密码学顶级会议发表论文5篇。其设计的混合口令密钥协商协议框架被国际标准草案采用。曾获上海交通大学杨嘉墀奖学金，获国家自然科学基金青年学生基础研究项目资助，并入选2025年中国科协青年科技人才培育工程博士生专项计划。吕优的学术产出速度和质量表明刘胜利指导团队在后量子密钥协商与标准提案方向保持了高活跃度。

5. **吕林（Lin Lyu）**：作为刘胜利指导的博士生，吕林在公钥加密的选择打开安全（Selective-Opening Security）方向与刘胜利、韩帅合作发表了多篇高水平论文，包括PKC 2018发表的"Tightly SIM-SO-CCA Secure Public Key Encryption from Standard Assumptions"等。其研究覆盖了公钥加密的紧致安全证明这一前沿课题。

此外，刘胜利还指导了温云华等学生从事模糊提取器和LWE基础上的可重用提取器研究，将后量子困难假设与生物特征认证等应用场景结合。总体而言，其培养网络以公钥密码理论为核心，向后量子加密、数字签名、密钥协商和模糊提取器等方向辐射，形成了理论深度与应用广度兼备的传承链条。

## 四、学术合作网络

### 4.1 内部：IISeC核心协作圈

IISeC是刘胜利最核心的组织化协作场域。在这一研究所中，她以"双聘"身份同时属于计算机科学与工程系和网络空间安全学院，使其在跨系合作中具有天然的桥梁角色。

**与谷大武教授的深度协作。** 谷大武是网络空间安全学院院长、LoCCS实验室主任和中国密码学会副理事长，与刘胜利同为西电密码学传统的出身者（谷大武1995—1998年在西电攻读密码学博士）。二人的合作关系兼具学术和体制双重维度：在学术层面，他们共同发表多篇论文，包括CRYPTO 2023论文中谷大武为合作者之一，以及Tightly CCA-secure identity-based encryption等期刊论文；在体制层面，二人共同参与"数据安全中的关键密码理论与方法"项目并同获2024年中国电子学会自然科学二等奖。谷大武侧重密码工程、侧信道与检测，刘胜利侧重公钥密码理论与后量子算法设计，二人的互补关系使IISeC在理论密码与密码工程之间形成完整链条。

**与韩帅助理教授的长期合作。** 韩帅是刘胜利指导的博士生（2017年毕业），现为IISeC助理教授。二人合作极为密切，在刘胜利的个人主页公开论文列表中，韩帅几乎出现在每一篇代表性论文的合作者中。从2018年的DCC、Designs Codes and Cryptography、PKC论文，到2023年的CRYPTO论文，韩帅—刘胜利的合作模式已成为团队内最稳定的学术配对。韩帅获得ACM中国新星奖（2021）和中国密码学会优秀博士论文奖（2019），也反映了刘胜利培养模式的有效性。

**与汪哲东助理教授的合作。** 汪哲东现为IISeC助理教授，是CRYPTO 2023论文的合作者之一。其研究涉及公钥密码和后量子安全，与刘胜利在后量子加密与签名框架方向形成互补。

**与孙士锋副院长的协作。** 孙士锋现为网络空间安全学院副院长、IISeC助理教授，是2024年中国电子学会自然科学二等奖项目"数据安全中的关键密码理论与方法"的第一完成人。该项目由孙士锋牵头，谷大武、韩帅、刘胜利为共同完成人，反映了四人之间在公钥加密、可搜索加密和隐私保护交易协议方向已形成可获省部级奖项认可的稳定合作组合。

**与邢朝平、来学嘉、郁昱的学术共同体关系。** 邢朝平为IISeC负责人、讲席教授，在编码理论与代数数论方向提供理论支点；来学嘉为IACR Fellow、IDEA算法设计者，连接国际密码学共同体；郁昱为国家杰青、特聘教授，2025年起兼任华东师范大学密码学院院长，在后量子密码和侧信道方向有广泛积累。三者与刘胜利共同构成IISeC的资深骨干层，在学科建设、人才引进和项目组织方面形成支撑。

### 4.2 跨机构：高校与学术组织

**西安电子科技大学**是刘胜利的教育源头。其本硕博三段教育经历均在西电完成，导师王育民教授是西电密码学传统的代表人物。西电密码学共同体在国内密码学界具有广泛影响，刘胜利的师承关系使其自然连接到包括王新梅、肖国镇等前辈学者所代表的编码与密码学学术网络。这一源流也与谷大武的西电背景形成呼应，二人同出西电密码学门下又同在交大发展，形成了"西电—交大"的密码学传承链路。

**荷兰爱因霍芬技术大学（TU/e）**是刘胜利的海外博士培养单位。TU/e离散数学组在编码理论与密码学方向有深厚积累，Henk van Tilborg教授在该领域有广泛学术影响。这段经历使刘胜利的学术网络连接到欧洲离散数学与编码理论共同体，也为其后量子密码研究中的格理论基础提供了数学训练支撑。

**路易斯安那州立大学**是刘胜利2007—2008年的访问学者所在机构，该段经历进一步拓展了其与北美学术界的联系。

**中国密码学会**是刘胜利在学术组织层面的重要节点。她于2020年起担任中国密码学会理事，与谷大武（副理事长）、郁昱（理事）等共同参与学会治理。该角色使其参与全国密码学学术评价、学科建设和人才推荐工作，连接到更广泛的国内密码学共同体。

### 4.3 国际：学术会议与论文发表

刘胜利的国际学术网络主要通过高质量论文发表渠道建立。其团队研究成果被CRYPTO 2023、USENIX Security 2024等密码学与安全领域顶级会议录用，这一发表渠道本身就是最可持续的国际连接方式。

**CRYPTO 2023论文**是其国际学术可见度的标志性成果。该论文"Almost Tight Multi-User Security under Adaptive Corruptions from LWE in the Standard Model"提出了标准模型下第一个基于格的紧致安全的后量子公钥加密算法和数字签名算法，并引入"概率性准自适应哈希证明系统"（pr-QA-HPS）这一新工具。论文的第一作者为韩帅，通讯作者为刘胜利，合作者包括谷大武和汪哲东。此前此类紧致安全方案仅在数论假设或随机预言机模型下存在，因而对量子敌手脆弱；该工作首次在标准模型下基于LWE假设实现了紧致安全，是后量子密码基础理论的重要突破。

此外，刘胜利团队还在PKC（Public Key Cryptography）、ASIACRYPT、ACISP等IACR系列会议，以及Designs Codes and Cryptography、Theoretical Computer Science等国际期刊发表多篇论文。其指导的博士生吕优已在EUROCRYPT、ASIACRYPT等顶级会议以第一作者发表5篇论文，并将混合口令密钥协商协议框架推向国际标准草案，说明其团队的研究产出已具有持续的国际影响力。

在论文合作者层面，刘胜利还与**秦宝东（Baodong Qin）**等外部学者有合作记录，如共同发表"Tightly CCA-secure identity-based encryption with ciphertext pseudorandomness"等论文，表明其合作网络不限于校内。

## 五、业界合作关系深度分析

刘胜利的业界合作主要通过IISeC和LoCCS的集体平台实现，呈现出"基础密码理论—标准提案—产业安全需求"的传导链条。

**第一层：IISeC集体校企合作平台。** IISeC公开介绍将华为、蚂蚁金服（蚂蚁集团）、银联等列为深度合作企业。刘胜利作为IISeC骨干教授和双聘成员，通过研究所的集体合作框架与这些企业建立间接但实质的学术—产业连接。蚂蚁集团安全科技联合研究中心、华为安全创新联合实验室等平台将密码协议、数据安全和隐私计算研究连接到大规模互联网金融、终端安全和云计算场景。对于刘胜利团队的后量子密码和公钥加密研究而言，这些平台提供了从标准理论模型走向实际部署约束的反馈通道。

**第二层：国际标准提案。** 刘胜利指导的博士生吕优设计的混合口令密钥协商协议框架被国际标准草案采用，是其团队将理论研究推向产业标准化的直接证据。密钥协商协议是TLS、VPN、移动通信等场景的核心组件，后量子密钥协商的国际标准化工作与NIST后量子密码标准化进程密切相关。这一成果说明刘胜利团队的研究已具备从学术论文向国际标准提案的转化能力，也为其连接国际标准化组织和产业安全社区提供了通道。

**第三层：国家自然科学基金项目。** 刘胜利主持多项国家自然科学基金项目，包括"无证书公钥密码体制的研究"（2009—2011，批准号60873229）、"有损陷门函数与标准模型下CCA2安全的公钥密码体制"（2012—2015）、"不同环境下的公钥加密算法设计与可证安全研究"（2014—2017）等。这些项目聚焦公钥密码的可证明安全理论，虽非直接产业合作，但其研究产出为后量子密码迁移和密码标准更新提供了理论基础。

**第四层：教学创新与人才培养产业化。** 刘胜利自2024年起担任学生创新中心主任，围绕"课-赛-创-研-普"育人体系开展创新创业教育工作，并参与创建生成式人工智能AIGC微专业。该角色使其连接到中国国际大学生创新大赛等全国性赛事平台和产业学院建设网络，将密码学人才培养与创新实践教育结合，形成区别于纯学术研究的产业人才培养连接。

- **上海市青年科技启明星计划A类（2009年）**：上海市针对青年科技人才的资助计划。
- **SMC博文奖**：上海交通大学设立的青年学者奖励。

学术兼职方面，刘胜利担任中国密码学会理事（2020年起），参与全国密码学学术评价、学科建设和人才推荐工作。此外，其担任电子信息与电气工程学院副院长（2022年起）和学生创新中心主任（2024年起）等管理职务，使其在学院层面参与学科规划、人才引进和教学创新等组织工作，构成其关系网络中区别于纯论文合作者的"制度性连接"。

在教学层面，刘胜利长期开设"基础代数"（硕士生，2008—2012年秋）、"现代密码算法"（博士生，2015年至今春）、"应用代数"（硕士生，英文授课，2005年至今）等课程，通过教学活动连接到多届密码学研究生群体。

## 七、Connection圈层总结

刘胜利的学术关系网络可概括为五个相互支撑的圈层：

1. **学术源流圈**：以西安电子科技大学的三段教育经历和王育民教授的密码学师承为起点，连接中国密码学早期学科建设传统；以荷兰TU/e和Henk van Tilborg教授的海外博士训练为补充，连接欧洲离散数学与编码理论共同体。该圈层使其学术根基兼具中西密码学传统。

2. **核心团队圈**：以IISeC为中心，与谷大武（密码工程与检测）、韩帅（公钥密码与区块链）、汪哲东（后量子安全）、孙士锋（可搜索加密与数据安全）形成稳定的论文合作与项目协作组合；与邢朝平（编码理论）、来学嘉（对称密码与国际连接）、郁昱（后量子与侧信道）共同构成IISeC资深骨干层。其中韩帅—刘胜利的师生合作配对尤为紧密，从博士培养延续到CRYPTO等顶级会议的共同发表。

3. **学生传承圈**：以韩帅（2017届博士，ACM中国新星奖）、温云华（2019届博士，中国密码学会优博）、刘翔宇（2023届博士，中国密码学会优博）、吕优（2022级在读，EUROCRYPT发表）为代表，形成从基础密码理论到后量子密码应用的传承链条。多名学生获中国密码学会优秀博士论文奖，显示其培养模式的持续有效性。学生从受培养者成长为同事和合作者的路径，是其网络中知识传承与团队扩展的核心机制。

4. **学术发表与国际标准圈**：通过CRYPTO 2023、USENIX Security 2024、PKC、ASIACRYPT等顶级会议的论文发表渠道建立国际学术可见度；通过博士生吕优的混合口令密钥协商协议国际标准提案，将理论研究连接到国际标准化进程。该圈层以论文和标准提案为主要媒介，比人际访学更具可持续性。

5. **产业与制度连接圈**：通过IISeC集体平台与华为、蚂蚁集团、银联等企业建立间接但实质的学术—产业连接；通过中国密码学会理事角色参与全国密码学共同体治理；通过学生创新中心和教学发展中心等管理角色，将密码学人才培养与创新创业教育和学科建设结合，形成区别于纯学术研究的制度性连接。

总体而言，刘胜利并非仅以单一研究方向或单个合作者为中心构建网络，而是通过师承传统、团队协作、学生培养、国际发表和制度参与，将密码基础理论与后量子密码应用、标准提案和人才培养编织为复合型网络。其网络的突出优势在于后量子密码理论研究的国际可见度和高质量博士生培养的传承效应，未来在后量子密码标准化、后量子密钥协商协议和密码学教育创新等方向仍具有较强的协同扩展空间。
