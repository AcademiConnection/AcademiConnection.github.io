# 上海交通大学信息安全与密码研究所(IISeC) 学术关系网络报告

## 团队简介

本报告集涵盖上海交通大学信息安全与密码研究所（Institute of Information Security and Cryptology, IISeC）核心教师团队的学术关系网络。IISeC隶属于上海交通大学网络空间安全学院，由谷大武教授创建并发展壮大，拥有IACR Fellow、国家杰青、教育部长江学者等一批知名教授和青年学者。研究所下设密码与计算机安全实验室(LoCCS)、国家级商用密码上海检测机构等平台，与华为、蚂蚁集团、中国银联等企业深度合作。

## 团队架构

IISeC以谷大武教授为行政核心（院长/创始人），邢朝平教授为学术负责人（IISeC负责人），来学嘉教授（IACR Fellow）为学术名誉领袖。中坚力量包括国家杰青刘胜利教授和后量子密码专家郁昱教授，青年教师王浩洋（对称密码）、孙士锋（数据安全/副院长）、韩帅（区块链）构成研究梯队。

团队与山东大学密码学团队存在双向人才通道：王伟嘉（谷大武/郁昱博士生，现任山东大学教授）和王浩洋（山东大学本科，现上交助理教授）是两位关键桥梁人物。
