# 南京大学软件质量研究所（软件测试与软件质量方向）教师学术关系网络报告 · 总览索引

**报告生成时间：** 2026年

**覆盖范围：** 南京大学软件质量研究所（江苏省软件质量研究所）为核心的软件工程质量/软件测试方向。该网络以徐宝文教授（国家杰青、CCF会士）为学术带头人，团队聚焦软件测试、程序切片、软件度量与软件分析方法。本次首批收录核心学者徐宝文一人，其余所内成员（周毓明、陈林、徐磊、谢晓园、杨玉标等）在报告中以合作网络交织呈现。

**网络边界说明：** 该研究所与南京大学计算机软件研究所的软件工程组（SEG，nju_sefm_faculty_network，李宣东主持）以及软件学院（nju_softwareeng_faculty_network，软件学院南京本部）为**不同独立建制**。徐宝文2008年将原东南大学软件工程实验室整体迁入南大组建本所，学术根脉在武大/华科/北航一线，不属南大软件所徐家福体系。需注意：另有一位同名"徐宝文"现任武汉中非合作中心主任，属不同人。
