本目录当前收录 1 份报告，对应山东大学计算机科学与技术学院图数据管理方向的独立课题组。

**口径说明：** 罗琦 2026 年 2 月以教授身份入职，组建的是**独立课题组**，并非 IIC（智能计算研究所）建制内的 PI。IIC 官网团队页将其列在"博士"栏目，反映的是其培养来源，而非当前组织身份；其研究方向（图数据库、图基础模型、图智能体）也已超出 IIC"边缘智能—区块链—系统安全"三大方向的范围。本目录因此单独设目，不并入 `sdu_iic_faculty_network`。

## 三、学术网络结构

- **师承主轴极粗**：博士阶段由成秀珍、于东晓共同指导（于东晓为直接导师），与于东晓合著 28 篇、与成秀珍合著 17 篇，覆盖 2019 年至今全部年份，属"师承＋持续合作"的双重结构。
- **两条国际驻留线**：UNSW（合作导师 Wenjie Zhang）接入林学民—Wenjie Zhang 的澳洲图数据库学派；香港科技大学（合作导师 Song Guo）接入郭嵩的大模型／物理智能网络；另有香港人工智能金融科技实验室（AIFT，贾小华指导）的研究员经历。两站博士后的先后顺序在公开资料中不可考，报告中未作断定。
- **学生梯队刚起步**：官方招生节奏为每年 1 名博士、1—2 名硕士；已可见"学生一作＋罗琦通讯"的产出模式，并存在长春工业大学跨校联合培养、UNSW 跨国合作两条学生来源。
- **产业接口最薄**：目前无公开的横向项目、专利或企业联合实验室记录，是"论文型青年学者"的典型形态。
