## 二、教育背景与职业履历

**教育经历**（据光明日报2026年专访及北大官方介绍）：

- 1999年考研进入中国科学院计算技术研究所，师从高文研究员（后为中国工程院院士），开始接触视频编码领域；硕博连读，2005年获博士学位，博士论文获2007年全国百篇优秀博士学位论文奖；

**职业履历**：

- 2007年前后（一说2006年）加入北京大学，先后任职于信息科学技术学院数字媒体研究所、计算机学院视频与视觉技术研究所至今；

马思伟产业合作的巅峰是2025年度国家科技进步二等奖"**视觉感知编解码关键技术及超高清视频产业化应用**"（第一完成人，2026年7月8日公布），该项目完整呈现其产业合作版图：

- **主要完成人**：马思伟（北大）、郑萧桢（大疆创新）、智卫（中央广播电视总台）、王荣刚（北大深研院）、邵喜斌（京东方）、李琳（咪咕文化）、贾川民（北大）、王苫社（北大）、蒋文（朝歌数码）、张嘉琪（北大）；
- **主要完成单位**：北京大学（第一）、大疆创新、中央广播电视总台、北京大学深圳研究生院、京东方、咪咕文化、朝歌数码。

具体合作脉络：

- **咪咕文化（中国移动）**：AVS3 在冬奥移动端直播场景落地，李琳为对接专家。
- **大疆创新**：郑萧桢团队将 AVS/AVS3 应用于无人机航拍视频编码，为2025年度奖项第二完成人；北大团队与航拍场景的视觉感知编码合作由来已久。
- **京东方（BOE）**：显示端联动，邵喜斌为代表，打通"编码—传输—显示"全链路。
- **华为/海思（芯片端）**：2020年度国家技术发明一等奖"超高清视频多态基元编解码关键技术"（马思伟排名第二）的共同完成人包括华为周建同、上海海思王稷；华为专家周建同至今仍以参建单位代表身份出席 NERCVT 年度会议。
- **北大-朝歌数码**：机顶盒/接收终端方向的产业化落地。
- **衍生创业**：团队成员王苫社创办博雅睿视（北京）科技有限公司，2024年12月发布内置 AVS3/SVAC 编解码能力的 SPARK RE3200 智慧视觉芯片（NERCVT 为技术依托单位之一），形成"实验室—标准—芯片"的孵化闭环。
- **行业标准生态**：作为第一起草单位之一参与广电行业标准 GY/T 368-2023《先进高效视频编码》（AVS3 全景/高效视频编码）制定，联合当虹科技、海康威视、腾讯、OPPO、大华、数码视讯等数十家AVS产业联盟成员单位；AVS 产业联盟成立于2005年。需要说明：**未检索到马思伟与海信、当虹科技的直接（人员级）合作记录**，当虹科技等属于 AVS 标准生态内的间接联系。

## 七、Connection圈层总结

马思伟的关系网络以"**标准为纲、师门为干、产业为翼**"为鲜明特征，可分为五层：

1. **师承核心层**：高文院士（362篇合作）—马思伟构成的"师徒轴"是其全部网络的引力中心。中科院计算所视频编码一脉（吴枫、赵德斌、黄铁军、熊瑞勤、王苫社、张莉等）经由此轴汇聚于北大 NERCVT 平台，形成中国视频编码领域事实上的"国家队"。
2. **嫡系学生层**：以贾川民（北大王选所）、张嘉琪（北大计算机学院）为代表的留校梯队，与王诗淇（香港城大）、张新峰（国科大）、毛麒（中传）、王钊（阿里→回北大）为代表的分布式梯队，分别占据神经视频编码学术地图的国内外关键节点——其学生网络本身就是一张覆盖标准、学术前沿与产业研发的全球网。
3. **标准组织层**：AVS 工作组（视频组组长身份）+ JVET/IEEE 1857/MPAI/DVB 的多重标准任职，使其与国内外标准界人物（如大疆郑萧桢、华为周建同、海思王稷、字节刘鸿彬/李俊儒/张莉、JVET 同仁）保持制度化高频互动，这一层是其他学者难以复制的关系资产。
4. **产业应用层**：以两次国家级一等奖（2020技术发明一等奖排名第二、2025科技进步二等奖排名第一）为标志，绑定央视总台、咪咕、大疆、京东方、朝歌数码、华为海思、字节跳动等超高清全产业链；并通过博雅睿视（王苫社创业）实现标准—芯片孵化闭环。
5. **荣誉与管理层**：IEEE Fellow、国家杰青、科学探索奖、计算机学院党委副书记、NERCVT 副主任等身份使其进入更广泛的高校治理与科技界荣誉网络。

总体而言，马思伟是中国视频编码领域罕见的"**学术—标准—产业三栖枢纽型**"学者：在学术上由高文门下嫡系成长为学生遍布局海内外的高被引学者；在标准上从研究生时代的AVS参与者成长为三代AVS标准的实际技术组织者；在产业上以第一完成人身份摘得国家科技进步二等奖、直接支撑央视8K与北京冬奥等标志性应用。其网络结构的可复制性低、中心度高，是理解中国超高清视频产业与技术标准生态绕不开的关键节点。
