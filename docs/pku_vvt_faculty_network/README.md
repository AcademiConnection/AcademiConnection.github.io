# 北京大学计算机学院视频与视觉技术研究所学术关系网络报告

## 团队简介

北京大学计算机学院视频与视觉技术研究所依托视频与视觉技术国家工程研究中心、多媒体信息处理全国重点实验室等平台，面向国家超高清视频、人工智能与类脑智能战略开展研究。团队的核心历史脉络由高文院士在数字音视频编解码、模式识别与虚拟现实领域的长期工作奠定，并由黄铁军、马思伟、田永鸿、王亦洲等教师拓展至类脑视觉、智能视频编码、媒体大数据、计算机视觉与认知计算等方向。

研究所形成了“视频编码标准—视觉智能—类脑计算—智能体”交叉布局。高文院士及马思伟团队深度参与AVS、AVS3、IEEE 1857等标准与超高清视频产业化；黄铁军、陈国璋和施柏鑫等围绕视觉大模型、神经形态计算、计算摄像学展开探索；王亦洲、段凌宇、卢宗青等将视觉理解拓展至医学影像、媒体大数据、强化学习与通用智能体。团队同时与鹏城实验室、北京智源人工智能研究院、华为、上海海思、中央广播电视总台、大疆等形成协同网络。

## 研究方向与圈层结构概述

团队的核心学术传承以高文院士为枢纽。马思伟是高文指导的博士，王苫社为高文门下成员并与马思伟组成AVS标准和智能视频编码的高频合作节点；黄铁军在中科院计算所博士后阶段加入高文团队，后于2007年加入北大并在视觉信息处理、标准管理和智源人工智能研究院建设方面发挥关键作用。王亦洲从朱松纯教授的UCLA视觉计算谱系进入北大，形成统计视觉与认知计算支线；施柏鑫则由东京大学、MIT Media Lab的计算摄像学训练拓展了国际合作网络。

产业连接主要围绕标准和工程平台展开。AVS体系将北大研究与华为、上海海思、广电及芯片企业连接，超高清视频多态基元编解码关键技术获得2020年度国家技术发明一等奖；2025年度国家科技进步奖中，鹏城云脑超大规模国产智能算力系统及产业化工程获一等奖，视觉感知编解码关键技术及超高清视频产业化应用获二等奖。视频与视觉技术国家工程研究中心还通过北大—福州新基建视觉智能联合实验室、智平方等平台推进场景转化。
