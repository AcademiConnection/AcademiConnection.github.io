鄂金龙，中国人民大学信息学院计算机科学与技术系副教授（2024年起），中国人民大学"杰出学者"青年学者（2022），CCF高级会员（2024），中国人民大学玉兰青年学者（华为评选资助，2024）。博士毕业于清华大学计算机系（2018年，清华大学计算机系优秀博士毕业生，2017年博士研究生国家奖学金）。研究方向包括云边协同计算、智能物联网、移动流媒体、分布式机器学习等，研究成果发表在SIGCOMM、INFOCOM、ATC、ICDE、TON、TMC、TPDS等CCF A类国际会议和期刊。

## 三、博士教育背景

### 博士阶段（清华大学计算机系，2014—2018年）

鄂金龙于2014年至2018年在清华大学计算机系攻读博士学位，导师为**崔勇教授（Prof. Yong Cui）**，2018年获清华大学计算机系优秀博士毕业生称号，2017年获博士研究生国家奖学金。崔勇现为清华大学计算机系教授、博士生导师、网络技术研究所所长，教育部青年长江学者、国家优秀青年科学基金获得者，国际互联网标准化组织IETF IPv6过渡工作组（softwire）主席，曾获国家技术发明奖二等奖、国家科学技术进步奖二等奖，研究方向为互联网体系结构、数据驱动网络与低时延网络。

博士阶段鄂金龙的核心研究方向为**跨云协作与云存储系统**，代表性成果形成"CoCloud—HyCloud"谱系：

- **INFOCOM 2017 / IEEE TPDS 2018**："CoCloud: Enabling Efficient Cross-Cloud File Collaboration based on Inefficient Web APIs"——基于低效Web API实现高效的跨云文件协作
- **INFOCOM 2019 / IEEE/ACM TON 2020**："HyCloud: Tweaking Hybrid Cloud Storage Services for Cost-Efficient Filesystem Hosting"——混合云存储服务的成本高效文件系统托管
- **IEEE TPDS 2018**：参与"OpenStack Swift类云存储系统的同步瓶颈"研究（与阮明康、翟恩南等合作）
- **IWQoS 2016**：参与"Multi-Resource Partial-Ordered Task Scheduling in Cloud Computing"（与张朝昆、崔勇、吴建平等合作）

- **联合专利**：2023年专利"一种数据包调度方法和相关装置"的共同发明人包括陈共龙（Gonglong Chen）、陈炜（Wei Chen）、王巨宏、王亚晨——后四者为华为技术有限公司研究人员，对应论文即INFOCOM 2024"AggDeliv: Aggregating Multiple Wireless Links for Efficient Mobile Live Video Delivery"（多无线链路聚合的移动直播传输），该论文署名中的Zongyi Zhao（赵宗一，音）、Yachen Wang（王亚晨）等亦与专利名单吻合，属典型的人大-华为联合研究。
- **个人身份**：鄂金龙担任**华为开发者布道师**，并获评**中国人民大学玉兰青年学者（华为评选资助，2024）**——该奖项由华为出资设立，反映其与华为的机构级合作关系。
- 崔勇（其博士导师）长期与华为2012实验室有密切交流，其IPv6过渡技术曾被产业界采用，这一师承渠道很可能为鄂金龙的华为合作提供了历史延续性。

### 2. 腾讯（Tencent）

**合作深度：★★★☆☆（科研基金资助）**

据人大官网，鄂金龙主持**CCF-腾讯犀牛鸟基金科研基金项目 & 技术标准化研究项目**"智能边缘计算网络架构与关键技术研究"（2021.11—2022.11，主持）。该基金由CCF与腾讯联合设立，面向青年学者，通常包含经费资助与联合研究内容。此项目立项时鄂金龙尚在清华做博士后，说明其边缘计算方向的产业合作在入职人大之前已经启动。DBLP记录中未检索到明确标注腾讯机构隶属的联合论文。

### 3. 字节跳动（ByteDance）

**合作深度：★★★☆☆（学术合作项目）**

据人大官网，鄂金龙主持**字节跳动学术合作项目**"大模型驱动的智能直播质量调度系统"（2026.3—2027.5）。该项目与其学术研究方向（移动流媒体、AggDeliv移动直播传输）高度吻合，属"研究方向直接对接产业需求"型合作。2026年3月启动，为最新布局的合作渠道。

### 4. 其他产业界与政府项目线索

- **国家重点研发计划重点专项**"基层派出所智能化协同关键技术研究与应用示范"（2025—2028，项目骨干&课题联系人）——公安场景的智能协同应用，反映其物联网协同技术在政务领域的落地。
- **互联网体系结构国家重点实验室开放课题**"面向工业互联网的大模型部署与调度研究"（2025.12—2027.12，主持）——与清华网络研究体系一脉相承的合作渠道。
- **SIGCOMM 2025短视频省流论文**的合作者群（徐威、毕建飞、柴云鹏等）与字节跳动、快手等短视频平台的业务场景直接对接，专利"短视频智能省流方法及装置"（2025）已完成布局。
- **新加坡MOE Tier 1 Grant**"Data-Driven Sensing and Analysis for Smart Transportation"（2018—2020，主要参与人）——NTU李默团队项目，对应CrowdAtlas城市轨道交通客流估计研究。

### 5. 产学研合作总结

鄂金龙的产业合作模式可概括为"**场景驱动**"型——其云边协同与移动流媒体的学术方向天然对接短视频（字节跳动）、直播传输（华为）等产业场景，合作形式从基金资助（腾讯犀牛鸟）、横向项目（字节跳动）到联合论文与专利（华为）逐级深化。其华为合作具有身份层面的绑定（开发者布道师、玉兰青年学者），为其当前最深的产业合作关系。

## 七、Connection 圈层总结

**第一圈层（学术领路人与最高频合作者）：** 崔勇教授（清华计算机系，博士导师，~6次合作）奠定了其计算机网络与云计算的研究根基；刘云浩院士（清华软件学院，博士后合作导师，2次合作+多项专利）引导其转向智能物联网方向；李默教授（NTU，Research Fellow合作导师）提供了城市感知研究的国际化经历。李振华（清华软件学院THUCloud实验室，~7次合作，2016—2024年跨越三个职业阶段）是其学术生涯中最稳定的长期合作者。

**第二圈层（清华网络集群——当前最活跃的合作圈）：** 何林（~12次，全网络最高频）、刘莹（~8次）、杨家海（~4次）、徐明伟（~2次）、张朝昆（~7次）等构成的清华大学网络研究群体，是鄂金龙2023年以来产出加速的主要合作来源，集中于IPv6测量与网络系统方向。何林作为高频"桥梁型"合作者，连接了鄂金龙与清华杨家海/刘莹团队。这一圈层的存在使鄂金龙虽身在人大，研究网络重心仍深度嵌入清华体系。

**第三圈层（现单位同事）：** 柴云鹏（人大计算机系主任，SIGCOMM 2025共同作者+多项专利）是其在人大最重要的同事合作者，两者形成"网络（鄂金龙）+系统（柴云鹏）"的互补组合，联合指导徐威、毕建飞等学生；张骁（人大高瓴学院）通过专利合作构成跨院系弱连接。相对而言，其人大本地的合作网络仍处于建设早期，尚未形成大规模自主学生团队。

**第四圈层（产业合作网络）：** 华为（联合专利+论文+开发者布道师+玉兰青年学者，最深绑定）、腾讯（CCF-犀牛鸟基金）、字节跳动（2026年启动的直播质量调度项目）构成三大产业支点；国家重点研发计划（公安场景）与互联网体系结构国家重点实验室开放课题延伸了其政务与基础研究合作。

**产出规模与趋势：** DBLP收录27条记录（约22项独立成果），2025—2026年进入产出高峰（年均5篇），并在SIGCOMM、USENIX ATC等顶会实现第一作者突破。研究方向从博士阶段的跨云存储（2016—2020），经博士后阶段的智能物联网与边缘计算（2019—2022），演进至当前的"云边协同+移动流媒体+IPv6测量+大模型边缘部署"多元布局。其师承（崔勇—李默—刘云浩）横跨网络、无线感知与物联网三大领域，是典型的"学术网络型"学者——个人独立产量中等，但嵌入的合作网络（清华网络集群+人大CloudLab+华为产业线）极为密集。
