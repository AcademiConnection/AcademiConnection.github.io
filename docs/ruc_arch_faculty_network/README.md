# 中国人民大学 体系结构与网络方向教师学术关系网络报告

> 报告生成时间：2026年8月

## 团队简介

中国人民大学信息学院的体系结构与网络方向是数据库学科之外以"系统"为纽带的多方向集合，教师均依托 DEKE/DBIIR 生态运行。**张峰教授**（清华高性能所博士，导师陈文光、翟季冬联合指导）负责 DEKE"混合架构下的计算优化研究"方向，是少有的同时覆盖 SIGMOD/PVLDB/ICDE 数据库顶会与 SC/TPDS/ATC/ASPLOS 体系结构顶会的双栖学者，亦是腾讯 TDSQL 系统论文的稳定学术合作者。**王晶教授**（北大直博，2022年自首师大加盟）深耕 DB/AI 加速体系结构与 PIM 存内计算，与上海交大李超、过敏意（IPADS）团队保持长期合作，并通过 MI-LLM 等成果与柴云鹏 CloudLab 协同。**李彤副教授**（清华徐恪门下博士，华为主任工程师四年，2022年入职，个人主页称2026年破格晋升教授）代表"工业界回流"路径，研究方向为数据中心网络与算力网。**鄂金龙副教授**（南开本硕、清华崔勇门下博士、NTU 李默博士后、清华刘云浩院士组博士后）聚焦云边协同与物联网。**王永才教授**（清华自动化系本博，导师郑大钟、赵千川）则为 Spatial AI/SLAM/多智能体系统方向，与李德英教授构成人大智能体研究的双子星。

## 研究方向与圈层结构概述

该方向的学术网络呈现鲜明的"清华体系结构学派扩散"特征。五人中张峰（陈文光/翟季冬）、李彤（徐恪）、鄂金龙（崔勇）三位清华计算机系博士分别代表高性能所、网络所、网络所三条支线；王晶出自北大体系结构传统（程旭/管雪涛团队，推断）并经上交 IPADS 网络放大；王永才则出自清华自动化系的控制学派（郑大钟/赵千川）。这一"清华系密度"使该方向成为人大连接国内系统学术共同体的天然桥梁。

圈内结构上，张峰以杜小勇（73次合作）为制度性依托，与卢卫（11次）、柴云鹏（10次）、张孝（8次，含归属存疑条目）构成 DBIIR 中生代矩阵；王晶通过李超（36次）、过敏意（33次）接入上交系统圈；鄂金龙的清华-NTU-清华三段训练使其同时嵌入刘云浩（物联网）与李默（智能系统）两大谱系；王永才与李德英的129次合作是人大校内最强绑定之一，并经李德英接入高瓴 AI 学院生态。产业网络上，张峰—腾讯 TDSQL、李彤—华为、王永才—地平线（机器人实验室 VLN 方向合作）分别代表三条差异化产学路径。

## 产业转化与人才培养亮点

方向上的产业合作以"系统落地"为特色：张峰参与腾讯 TDSQL 的 PVLDB/SIGMOD 系统论文披露（TDSQL、TXSQL、TDSQL-Boundless 三部曲），是国产分布式数据库学术化的代表案例；李彤的华为主任工程师经历（数据中心网络，2017—2021）为其带来直接的工业界网络系统经验；王永才与地平线机器人实验室在视觉语言导航（VLN）方向的多年合作覆盖多篇顶会。人才培养上，张峰的自建梯队（Jiawei Guan、Zaifeng Pan、Ruofan Wu 等，TADOC/G-TADOC 文本压缩系列）与王永才的 SLAM/多智能体梯队是其各自的产出主力，毕业生流向华为、腾讯、阿里等企业系统团队与高校教职。
