## 一、学者基本信息

王晶，女，中国人民大学信息学院计算机科学与技术系教授、博士生导师，2022年5月加入人大。入选国家级高层次青年人才项目、北京市科技新星（2018）、北京市青年拔尖人才培育计划（2017）。据人大信息学院新闻，她于2025年入选教育部—华为"智能基座"优秀教师奖励计划（当年全国20位获奖者之一），并曾获中国产学研合作创新促进成果奖一等奖、首都前沿学术成果奖、北京市教学成果奖一等奖1项与二等奖1项。研究成果发表于计算机体系结构领域A类期刊TC、TPDS、TACO、TCAD及A类会议HPCA、MICRO等，其中TC 2020论文入选当期唯一"Featured Paper"，ICCD 2016论文获最佳论文奖。

### 研究方向

- **智能计算系统与领域专用加速架构**：面向人工智能和数据库/大数据应用的加速器设计，包括PIM（存内计算）硬件上的LLM推理（MI-LLM）、RRAM交叉杆加速器（STAR、ReRAM CNN训练、NAS-SE）、FPGA动态图更新（LiveGraph）
- **高能效与高可靠计算**：近阈值计算（NTC）、暗硅（Dark Silicon）、神经元级电压缩放、差错容忍的神经网络计算架构
- **计算机系统结构**：缓存可靠性与分区、DRAM/存力系统、分离式内存（Disaggregated Memory）、GPU图计算与随机游走（FlowWalker、Skywalker）
- **软硬件协同设计与容错加固**：SEU故障注入、RISC核多比特错误检测与快速恢复（航天级可靠性需求）

讲授课程：计算机系统基础、智能计算系统。

## 三、博士教育背景

### 博士阶段（北京大学，2005—2011年）

王晶2005年从哈尔滨工业大学计算机系本科毕业后，保送北京大学计算机科学与技术系直接攻读博士学位，2011年6月获理学博士学位，研究主题为**无线网卡的能量管理**（其2011/2012年发表于《电子学报》（英文版CJE）的论文"Wireless Network Interface Card Energy Management for Interactive Applications"、"Energy-Efficient Web Browsing for Wireless Network Interface Card"以及2010年《电子学报》中文论文"CBLA：多信道无线网状网络负载感知的分簇式信道分配"均属此脉络）。

**博士导师：公开资料未披露。** 从一手论文证据看，她博士期间及博士后初期的论文持续与**管雪涛**（Xuetao Guan，时任北京大学教师）和**程旭**（Xu Cheng，北京大学教授、北大计算机系统结构研究所/微处理器研究开发中心创始人）联合署名（CJE 2011、CJE 2012、电子学报2010、ISPA 2013），据此审慎推断其博士培养依托程旭教授领衔的北京大学系统结构研究团队（该团队以北大众志微处理器/嵌入式系统研究著称）。此推断未经官方页面证实，仅供参考。

### 博士后阶段（北京大学，2011—2013年）

2011—2013年在北京大学信息科学与技术学院从事博士后研究，合作导师公开资料未披露。此阶段代表性成果为VEE 2013论文"SPIRE: improving dynamic binary translation through SPC-indexed indirect branch redirecting"，合作者为贾宁（Ning Jia）、杨春（Chun Yang）、佟冬（Dong Tong）——均为北京大学系统结构/软件工程背景学者，显示其博士后阶段仍深耕北大系统研究圈。

值得注意的是，其研究方向在此后完成了从"无线网络节能"到"缓存可靠性/近阈值计算"再到"AI/DB加速体系结构"的两次跃迁，而北大阶段的系统结构训练为后续转向奠定了基础。

## 五、现单位团队与核心合作者

### 在人大的定位

王晶2022年5月以教授身份加入人大信息学院计算机科学与技术系，是学院**体系结构与智能计算系统方向的学术带头人**之一，也是该方向目前职称最高的教师（教授、博导，国家级高层次青年人才）。她与院长柴云鹏的CloudLab（存储与数据中心系统）在院系内构成"**加速器/存算一体硬件 × 存储与云系统**"的互补分工。

### 与柴云鹏/CloudLab的合作（同事关系+论文合作）

DBLP可见的直接合作是TC 2026论文**"MI-LLM: Multiplier-Free LLM Inference on Commodity Processing-in-Memory Hardware"**：胡普蕴（柴云鹏组博士生）为第一作者，柴云鹏为通讯作者，王晶与张晓（据论文主题推断为CloudLab新硬件方向教师）、Size Zheng（曾属上海交大李超合作圈）等联合署名。该工作延续CloudLab自PIMANN以来的"商用存内计算硬件加速神经网络推理"主线，与王晶长期深耕的PIM加速方向高度契合，标志着两支团队在人大内部的正式合流。此外，王晶与李超/过敏意团队在GPU图计算、LLM推理系统方向的系列成果（FlowWalker、VLDB 2024等）与CloudLab的数据库系统方向也存在天然的应用交叉。

### 上海交大IPADS"影子团队"（论文合作，非同事关系）

值得注意的是，王晶加入人大后，其论文产出的主力署名群体仍是上海交大李超/过敏意团队（IPADS）的师生：侯小凤（20次）、汪陶磊（11次）、徐诚（10次）、王鑫凯（8次）、郭进阳（7次）、梅君夷（6次）等。这一合作自2018年（其仍在首师大期间）启动，持续至今未断，构成了跨越其两次工作变动的稳定学术共同体。代表性联合成果包括：

- **HPCA 2026**（AUM，LLM服务加速单元）——第一作者王鑫凯（李超2026届博士）
- **ASPLOS 2026**（MoE-APEX，MoE推理系统）
- **SC 2024**（分离式内存多后端管理）——王晶为第一作者
- **VLDB 2024**（FlowWalker，GPU动态图随机游走）——梅君夷一作
- **CSUR 2026**（分离式内存综述）——王晶一作

### 首师大旧部的延续合作

与首师大张伟功团队（张伟功29次、高岚7次、邱柯妮9次）的合作持续至2024年（TC 2024"Enhancing Neural Network Reliability"），此后DBLP记录中新合作明显减少，反映其研究重心已随工作调动转移至人大—上交体系。其首师大时期指导的学生（如Dehui Qiu、Yuchen Zhao等，ICPADS 2023两篇）身份为推测，未经官方确认。
