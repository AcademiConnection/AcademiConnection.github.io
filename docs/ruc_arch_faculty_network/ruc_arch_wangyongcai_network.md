## 三、博士教育背景

### 博士阶段（清华大学自动化系，2001—2006年，直博）

王永才1997年进入清华大学自动化系本科学习，2001年本科毕业后直接攻读博士学位，2006年12月获工学博士学位，**导师为郑大钟教授和赵千川教授**（人大官方教师页面明确记载："本科、博士均毕业与清华大学自动化系，师从郑大钟和赵千川教授"）。注意：任务背景中提及的"博士可能毕业于香港科技大学或中科院自动化所"两种说法均不成立，一手来源（人大官网、个人主页、百度百科）一致确认为清华大学自动化系。

两位导师均为清华自动化系控制理论方向的代表性学者：

- **郑大钟教授**（1935—2019）：自动控制理论专家，我国控制理论与系统科学领域重要奠基者之一，长期从事线性系统理论、离散事件动态系统（DEDS）及电力系统安全控制研究，是国内最早在IEEE TAC发表系列成果的学者之一，所著《线性系统理论》为全国研究生教学经典教材。1959年毕业于清华大学并留校任教。
- **赵千川教授**：清华大学自动化系教授，1992年本科、1996年博士均毕业于清华自动化系，研究领域为网络化动态系统的建模、分析、控制与优化，与郑大钟合著《离散事件动态系统》《线性系统理论基本教程》。

王永才博士阶段的研究方向为**网络化系统的定位、传感与优化**——这一源自控制与DEDS理论的"网络+图论+优化"底色贯穿其学术生涯：从早期的无线传感器网络定位、超声波目标定位（JSAC 2015）、非侵入式负载监测（IJCAI 2015、TECS 2014），到后来的稀疏网络可定位性理论（TON/TMC/TOSN系列），再演进为基于图优化的Graph SLAM与Spatial AI。其代表性早期成果包括JSAC 2015（超声波多目标定位）、INFOCOM 2014（压缩感知交通监测）、MOBIHOC 2014（二值临近传感器多目标计数跟踪）、AAAI 2017（在线模型自适应）等。

## 七、Connection 圈层总结

**第一圈层（长期学术同盟）：** 李德英教授（人大计算机系，129次合作，占其DBLP论文约70%）是王永才学术网络中绝对的核心节点。两人自2013年起连续14年深度合作，构成人大计算机系"感知定位+图优化"方向的双核结构，联合指导了孙宏宇等大量学生。这一绑定强度在人大信息学院内部罕见（对比高瓴学院徐君—张骁的~25次），反映了传感网/图算法方向"师生共同体"式的传统产出模式。陈文萍（37次）、范肇心（12次，人大博士校友现北航助理教授）是这一圈层的延伸。

**第二圈层（师承与清华网络）：** 清华大学自动化系是其学术出身——师从郑大钟、赵千川两位控制理论名家，继承了DEDS/线性系统/图优化的理论功底。清华交叉信息研究院六年经历（2009—2015）使其进入姚期智体系下的学术网络（Yuexuan Wang等）。师承谱系解释了其研究风格的"控制味"：从网络定位的刚性图理论到Graph SLAM再到多智能体协同，图论与优化始终是方法论主轴。清华校友范肇心及清华自动化系贾庆山教授的合作是这一网络的当代延续。

**第三圈层（自主培养团队）：** 王永才2015年加入人大后逐步建组，核心学生包括王硕（27次，VLN/视觉里程计）、蔡旭东（24次，重定位/重建）、李婉婷（22次，协同SLAM）、黄哲、孙宏宇、王鹏、白雪薇、许晓佳、平浩迪、杨康、刘浩宇等，团队产出已覆盖CVPR/ICCV/NeurIPS/ICML/SIGMOD/ICDE/WWW/MM等主流顶会。2026年7月RIAS省级重点实验室获批，标志着团队完成从课题组到建制实验室的升级。

**第四圈层（产业合作网络）：** 地平线机器人实验室（苏治中团队，VLN/具身智能方向，多篇ICML/CVPR/NeurIPS/AAAI联合论文与联合开源项目）是当前最活跃的产业合作方；智能航运领域（无人船辅助驾驶决策系统+航海学会技术发明一等奖）是其产业落地的标杆案例；另有机场飞鸟检测、能源算法、无人集群数字孪生测试等横向项目。职业起点NEC中国研究院的经历塑造了其重视落地的合作风格。

**产出规模与趋势：** DBLP收录183条记录（2026年8月），2023年起年均产出20篇以上，研究方向经历了清晰的演进路径：传感网定位与优化（2004—2018）→ 网络可定位性理论与图算法（2019—2022）→ SLAM/协同感知/三维视觉（2023—2024）→ Spatial AI/具身智能/视觉语言导航（2025至今），每一步转型均保留了图论与优化的方法论内核。
