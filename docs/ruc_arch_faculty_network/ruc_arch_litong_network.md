## 一、学者基本信息

李彤，现任中国人民大学信息学院、数据工程与知识工程教育部重点实验室教授，中国人民大学杰出学者，个人主页称其于2026年破格晋升教授，并任数据科学与技术系副主任、信息技术中心副主任。人大信息学院教师页仍标为“副教授、数据科学与工程教研室副主任”，这是两处公开页面因更新节奏不同形成的职称表述差异；本报告按其个人主页的2026年最新自述使用“教授”。

其长期从事网络系统研究，研究主线为新型互联网体系结构，并覆盖高性能数据中心网络、确定性广域网、算力网络、面向大模型的通信优化、QUIC传输与跨域数据管理。人大元宇宙研究中心公开页面亦将其方向概括为“算力网络、智能无线网络、确定性低时延广域网和高性能数据中心网络”。

### 研究方向

- **高性能数据中心网络与拥塞控制：** 面向动态负载的RED参数调节、低时延高吞吐传输；NSDI 2025论文 *PRED* 是该方向代表作。
- **AI/算力网络与大模型通信：** Networking4LLM、跨数据中心/广域RDMA、大模型训练与推理通信瓶颈优化。
- **确定性广域网与网络系统：** 广域低时延传输、网络资源调度与算力网优化。
- **QUIC与应用传输：** 面向视频、内容分发和跨域数据库管理的QUIC传输优化。
- **分布式数据系统交叉：** 地理分布式数据库同步、共识协议和跨域事务中的网络性能问题。

## 三、博士教育背景

李彤于2012年8月至2017年6月在**清华大学计算机科学与技术系**攻读博士，获工学博士学位；这一学历与导师信息均由人大信息学院教师页直接披露。博士导师为**徐恪教授（Ke Xu）**。人大信息学院2024年关于其获ACM SIGCOMM China新星奖的新闻再次明确“2017年从清华大学计算机科学与技术系获得博士学位（导师徐恪，IEEE Fellow）”。

## 七、Connection 圈层总结

**第一圈层（直接学术师承与长期论文合作）：** 清华博士导师徐恪是最明确的核心节点。两人的关系同时具有“直接指导”和跨越博士毕业后的持续“论文合作”属性，合作主题由传输控制拓展至数据中心网络和可编程网络系统。英国埃塞克斯大学的Kun Yang属于访问阶段的学术指导/合作节点，不等同于博士导师。

**第二圈层（网络系统论文共同体）：** 郑凯、杜鑫乐、高翔雨、吴波等围绕传输控制、数据中心拥塞控制、可编程交换机、直播/CDN恢复等方向形成论文合作网络。公开论文可证实共同署名，但对其中学生、企业工程师或其他角色均应以官方名单为准，不能仅凭署名推定。

**第三圈层（人大DEKE/DB-IIR同事网络）：** 李彤负责“算力网优化研究”，与杜小勇、卢卫、柴云鹏、张孝等构成不同类型的校内协作。其间应严格区分：杜小勇团队归属及共同论文属于同事/团队关系；卢卫、柴云鹏的共同论文属于同事加论文合作；张孝、柴云鹏与李彤的课程论文属于教学合作。现有公开资料不支持将上述同事关系称为直接指导。

**第四圈层（产业合作网络）：** 华为是履历最清晰、关联最深的产业节点；腾讯、字节跳动则有官方列出的项目合作线索。该圈层连接高性能网络、系统软件、数据中心与算力网应用，但对具体项目成果、人员流动和商业部署的公开披露有限。
