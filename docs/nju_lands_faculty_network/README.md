## 二、八位教师的角色定位

陈贵海是LANDS研究组的创始人和负责人，IEEE Fellow、CCF会士、国家杰青，南京大学与上海交通大学双聘教授，研究方向覆盖分布式网络、物联网、数据中心和边缘智能等极为宽广的领域，是该组学术网络的绝对核心。

窦万春是组内另一位资深教授，国家重点研发计划项目首席科学家，研究方向偏向云-边-端智能协同计算与智能工业互联网，与陈贵海形成"网络基础设施"与"计算应用层"的互补分工。

王炜教授的研究方向为无线智能感知、软件无线电和移动蜂窝网络，曾在微软亚洲研究院（MSRA）和中兴通讯从事研究与标准化工作，是组内唯一具有通信产业标准制定经验的教师。

田臣教授是组内学术产出最为突出的青年教师之一，国家杰青获得者，独立领导NASA实验室，以南京大学历史上首篇SIGCOMM和首篇FAST论文奠定了在网络与系统领域的地位，2026年其团队荣获NSDI杰出论文奖（全球仅3篇），与华为、阿里、字节跳动等企业有深度合作。

戴海鹏教授是陈贵海亲自培养的博士生，IET Fellow、教育部青年长江学者，研究方向为物联网、边缘智能和无线充电，论文总量300余篇（含CCF A类130余篇），在华为、阿里、腾讯等企业有成果转化落地。

郑嘉琦助理教授同样是陈贵海培养的博士生，国家优青获得者，曾获ICNP 2015最佳论文奖（该会议32年来首篇完全由中国学者独立完成的获奖论文）和ACM SIGCOMM China Rising Star Award，研究重心正从数据中心网络向AI基础设施拓展。

顾荣助理教授的情况较为特殊，其博士导师为南京大学PASA大数据实验室的黄宜华教授（而非陈贵海），加入LANDS后成为组内大数据与流数据挖掘方向的核心力量，同时深度参与Fluid和Alluxio两个国际开源项目，产业合作覆盖阿里、腾讯、华为等十余家企业。

史书瑜副研究员是组内公开资料最少的一位教师，未配置独立个人主页，承担《计算机操作系统》课程教学，在DBLP和Google Scholar等学术数据库中未检索到明确的学者档案，可能更多承担教学与协作研究角色。

## 三、全研究组关系网络的整体观察

LANDS研究组的师资网络呈现出几个较为清晰的结构性特征。

第一是"老中青"梯队传承结构。陈贵海作为组长培养了戴海鹏和郑嘉琦两位博士生，二人现已晋升为教授/助理教授并留校任教，形成了清晰的"一代—二代—三代"学术传承链条。田臣虽非陈贵海直接指导的博士生（毕业于华中科技大学，耶鲁大学博士后），但加入LANDS后与陈贵海形成了密切的组内合作关系，独立领导NASA实验室。顾荣的博士导师为PASA实验室的黄宜华教授，跨实验室流动后加入LANDS，客观上构成了南京大学计算机系内大数据方向两个研究组之间的学术桥梁。

第二是"基础研究—产业标准—工程落地"的产学研贯通模式。王炜在中兴通讯的标准化工作、田臣与华为/阿里的系统部署合作、戴海鹏在多家企业的成果转化、顾荣在Fluid/Alluxio开源生态中的核心角色，共同构成了从底层网络协议到上层大数据系统的全栈产业合作图谱。这与LANDS研究组"先进网络与数据科学"的定位高度一致。

第三是"大导全覆盖"与"小导辅助"的指导分工。LANDS研究组8位教师中有7位具备博士生导师资格，仅史书瑜（副研究员，研究系列）不独立招收研究生，这在高校实验室中属于相当高的博导密度。已毕业学生去向涵盖国内外两条路径——海外深造路径覆盖MIT、Princeton、UIUC、CMU、密歇根大学等顶尖院校，产业就业路径覆盖华为、阿里、腾讯、字节跳动、微软等头部企业，还有部分学生进入南京大学、清华大学、国防科技大学等高校任教。

第四是"双聘"与跨机构辐射。陈贵海同时受聘于南京大学和上海交通大学，使得LANDS的研究网络自然延伸至上海交大。此外，陈贵海与明尼苏达大学何田教授、天普大学吴杰院士团队、韦恩州立大学等国际机构保持长期合作，赋予了LANDS国际化视野。田臣的NASA实验室也聚集了十余位跨机构合作教授。

第五是职称信息滞后的问题。LANDS团队页面（cs.nju.edu.cn/lands/people.html）对田臣和戴海鹏的职称标注仍为"副教授"，但南京大学计算机系官方教师页面已确认二人晋升为教授，本系列报告以官方页面为准。类似地，LANDS团队页面未为史书瑜配置独立个人主页链接，导致其公开学术信息极度有限，本系列报告中涉及史书瑜的部分内容基于团队结构推断，已明确标注。

## 数据来源与说明

各报告数据主要来源于LANDS研究组官网、南京大学计算机系官方教师页面、各教师个人主页、DBLP、Google Scholar，以及南京大学官方新闻报道（如NSDI获奖公告、IET Fellow入选公告、人才计划入选名单等）。由于LANDS团队页面未逐一标注学生的指导教师，报告中标注为"基于合著网络推断"的师生关系不代表官方确认的正式指导关系；博士导师、学生毕业去向等信息如缺乏权威来源直接确认，均已在对应报告中注明推断依据，如遇后续信息更新，请以学者本人或学校官方发布为准。
