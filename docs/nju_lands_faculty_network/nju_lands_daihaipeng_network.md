**教育背景关键节点：**

- **2003年免试入学**：戴海鹏于2003年5月因在高中全国物理奥林匹克竞赛中获奖，免试进入上海交通大学教改联读班（从全国选拔的拔尖学生荣誉班级）。
- **2007年免试读研**：本科毕业后免试进入上海交通大学研究生项目。
- **2010年转攻计算机博士**：硕士毕业后转入南京大学计算机科学与技术系攻读博士学位，导师为陈贵海教授。
- **973联合实验室经历**：2010年6月至8月，作为973 WSN联合实验室成员，在倪明选（Lionel Ni，IEEE Fellow）、刘云浩（Yunhao Liu，ACM/IEEE Fellow）、刘云淮（Yunhuai Liu）领导下从事无线传感网研究。
- **联合培养经历**：2013年2月至2014年2月，由何田（Tian He，ACM/IEEE Fellow，明尼苏达大学）联合指导（何田在中国休学术假期间）。

### 2.2 博士论文信息

- **研究方向**：该论文奠定了戴海鹏后续在无线充电、物联网领域的研究基础

## 七、Connection圈层总结

### 第一圈层：导师与核心学术传承

- **陈贵海（Guihai Chen）**：戴海鹏的博士生导师，也是其学术生涯中最核心的合作者。陈贵海是南京大学计算机软件新技术全国重点实验室的核心成员，IEEE Fellow、国家杰出青年基金获得者、CCF会士。戴海鹏从博士期间（2010-2014）到独立建组后的所有重大成果几乎都有陈贵海的深度参与，形成"导师-学生"到"平等合作者"的良性学术传承关系。
- **何田（Tian He）**：博士期间联合指导老师，ACM/IEEE Fellow，为戴海鹏引入了国际顶尖的传感网与物联网研究视角。

### 第二圈层：LANDS课题组内部网络

LANDS研究组8位教师形成紧密的内部合作网络：
- **同门师兄/资深教师**：窦万春、王炜、田臣与戴海鹏同为LANDS研究组成员，在分布式计算、网络优化等方向有交叉合作。
- **学术后辈/同期**：郑嘉琦（ACM SIGCOMM China博士论文奖获得者）、顾荣（近年与戴海鹏在SIGMOD、HPDC等顶会有合作）等青年教师与戴海鹏形成"同辈互助"的合作模式。
- **学生反哺**：李猛（戴海鹏的博士生，现留校任助理教授）成为戴海鹏的重要合作者，体现了学术血脉的延续。

### 第三圈层：国内跨机构合作

- **Alex X. Liu（密歇根州立大学）**：戴海鹏最重要的国际合作伙伴之一，两人在无线充电网络优化方向有长期稳定的合作，共同在INFOCOM、TMC等顶会顶刊发表多篇论文。
- **刘云淮、刘云浩、倪明选**：通过973 WSN联合实验室的早年经历建立的合作关系，持续影响其学术网络。
- **曹建农（香港理工大学）**：在边缘计算、移动计算方向有深度合作。

### 第四圈层：产业界合作

- **华为、阿里、腾讯、中兴**：ICT头部企业，戴海鹏的研究成果（尤其是边缘智能、物联网感知方向）已在这些企业实现转化。
- **能源与医疗行业**：国家电网、中石化、南京脑科医院等垂直行业机构，体现其研究从基础理论向实际应用的延伸。
- **国际产业联系**：通过学生王蔚峻在清华大学AIR的博士后工作，与华为移动服务（HMS）建立成果转化通道；通过学生孙珂在密歇根大学的教职，建立了中美学术合作桥梁。

### 网络特征总结

戴海鹏的学术关系网络呈现**"以导师为核心、课题组为根基、国际合作为两翼、产业转化为延伸"**的典型特征：

1. **强导师纽带**：与陈贵海的师生关系是其学术网络的基石，合作贯穿其整个学术生涯。
2. **课题组凝聚力**：LANDS研究组8位教师形成高密度的内部合作网络，资源共享、方向互补。
3. **人才培养成效显著**：培养的博士生中，李猛留校任教、孙珂任密歇根大学助理教授、王蔚峻进入清华大学AIR博士后，形成人才梯队的良性循环。
4. **产学研深度融合**：与华为、阿里、腾讯等头部企业的合作不仅停留在项目层面，更有实际成果落地，且通过学生培养持续向产业输送人才。
5. **学术影响力持续扩展**：从早期的无线充电、传感网，到近年来的边缘智能、大模型系统（如SMoE、V-LoRA等），研究方向的拓展带动合作网络的不断更新和扩大。
