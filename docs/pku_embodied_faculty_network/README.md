# 北京大学前沿计算研究中心具身感知与交互 / PKU-Agibot Lab 学术关系网络报告

## 团队简介

北京大学前沿计算研究中心（Center on Frontiers of Computing Studies, CFCS）围绕具身智能方向形成了两个紧密协作又相对独立的实验室：一是董豪长聘副教授负责的 PKU-Agibot Lab（北大—智元机器人联合实验室），聚焦具身智能、可泛化机械臂操作、机器人视觉与大模型机器人系统，代表性开源产出包括 TensorLayer、OpenMLsys 等万级 GitHub Star 项目；二是王鹤助理教授创立并领导的具身感知与交互实验室（EPIC Lab），依托斯坦福 Leonidas J. Guibas 教授的三维几何计算脉络，从类别级位姿估计与抓取扩展到合成数据、视觉—语言—动作模型与通用机器人系统。

两个实验室与北京大学计算机学院、前沿计算研究中心的王亦洲、卢宗青、邓小铁等学者共同构成北大具身智能方向的学术集群，活跃于智源大会等学术平台。产业侧，董豪通过北大—智元机器人联合实验室（任主任）和上纬启元首席科学家身份深度参与人形机器人产业化；王鹤创立银河通用机器人公司并任首席技术官，2026年8月银河通用牵头获批"具身智能大模型北京市重点实验室"（王鹤任主任），形成"高校 PI—联合实验室—创业公司"的并行产学研结构。

## 研究方向与圈层结构概述

董豪的学术网络以英国帝国理工学院为根基——导师郭毅可教授（现香港科技大学首席副校长）是其学术生涯奠基人，两人共同创办初创公司并合著 TensorLayer 相关著作。回国后，董豪以 PKU-Agibot Lab 为核心构建了"开源系统—国家重大项目—智元机器人生态"三位一体的网络：培养的博士生（吴天昊、吴铭东、张继耀、李晓琦等）在 6D 姿态估计（GenPose/Omni6DPose）、大模型机器人操作（ManipLLM）、柔性物体操作（GarmentLab）等方向持续产出顶会论文，毕业生直接进入智元机器人（AgiBot）等具身智能头部企业；同时以上纬启元首席科学家身份参与消费级人形机器人研发。

王鹤的网络则以清华本科—斯坦福博士（导师 Leonidas J. Guibas）—北大 EPIC Lab（2021年9月建立）为主线，与银河通用机器人形成深度绑定，走"合成数据+具身多模态大模型"路线，主持"具身智能大模型北京市重点实验室"。两人与王亦洲（CFCS副主任）、卢宗青（强化学习/智能体）共同构成北大具身智能的四核心集群，并通过智源大会、中关村学院等平台辐射更广泛的学术与产业生态。

## 产业转化亮点

具身智能是本轮 AI 浪潮中产学研融合最紧密的方向之一。董豪主导的 TensorLayer 获 ACM Multimedia 2017 最佳开源软件奖，OpenMLsys 获 2021-2022 年 OpenI 杰出项目奖，支撑 TensorFlow、MindSpire 及英伟达 GPU、华为昇腾等多平台；北大—智元机器人联合实验室提出 OmniManip 等架构，将视觉语言模型的推理能力转化为机器人高精度动作。王鹤创立的银河通用机器人聚焦通用机器人本体与场景部署，其牵头的"具身智能大模型北京市重点实验室"以北大为共建单位，学术委员会包括王亦洲等学者，是校企协同的标杆案例。课题组本科生大量输送至 Oxford、MIT、Berkeley 等顶级博士项目，形成国际化人才网络。
