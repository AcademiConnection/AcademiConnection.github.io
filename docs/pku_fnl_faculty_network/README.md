# 北京大学信息工程学院未来网络实验室学术关系网络报告

## 团队简介

北京大学信息工程学院未来网络实验室依托深圳市信息论与未来网络体系重点实验室和国家重大科技基础设施"未来网络"北大实验室（PKU Lab of CENI）两大平台，由李挥教授领导，研究方向覆盖未来网络体系与网络空间安全、高安全专网/车联网、区块链与分布式存储、AI 与网络安全分析等。

实验室最具标志性的成果是多边共管多标识网络体系（MIN，Co-Governed Multiple Identifier Network）。该体系在邬江兴院士的指导下研发，在全球率先提出支持身份、内容、服务、IP、北斗地空等多种标识的网络架构，顶层标识多边共管、下级标识自主管理，旨在打破 IP 网络单边垄断格局、推动全球互联网治理体系变革。MIN 体系完成了全球 150 个顶级节点的标识管理功能测试，入选第六届（2019年）世界互联网大会"世界互联网领先科技成果"；在"强网"拟态防御国际精英挑战赛等多次攻防竞赛中作为实战靶场经受千万次众测攻击保持不败。团队已授权数十项中美发明专利，衍生出 MIN-VPN 高安全专网系统并推动相关通信行业标准制定。

## 研究方向与圈层结构概述

李挥的学术网络以"清华—港中文—北大深研院—邬江兴院士体系"为主线：1986/1989 年获清华大学学士/硕士学位，2000 年获香港中文大学博士学位，2003 年 12 月加入北京大学深圳研究生院信息工程学院。其网络第一圈层是邬江兴院士及其信息工程大学/嵩山实验室体系——MIN 体系由邬江兴院士指导、李挥团队研发，拟态防御理论与多标识网络在架构安全理念上一脉相承；第二圈层是学生传承网络，培养出王菡（获 IEEE TEMS 优博奖，2025）、杨昕（中国石油大学（华东）讲师）等博士毕业生及王云敏、李文君、侯汉旭、朱冰、张寰宇、陈福兴等校友，以及王滨等在读骨干（ICSE 2026 两篇录用、与腾讯合作 A.S.E 框架）；第三圈层是产业与标准网络，通过 MIN-VPN、智能车联网（MIN-V2X）、金网工程等场景，与运营商、设备商及佛山赛思禅等关联企业形成转化通道。

## 产业转化亮点

MIN 体系的产业化路径颇具特色：以竞赛靶场验证安全性（三次实战靶场不败纪录），以行业标准固化技术主张（MIN-VPN 通信行业标准），以专利族构筑知识产权壁垒（数十项中美发明专利，含获英国发明展钻石奖的"主权网架构及应用"专利族）。2022 年相关联盟链 CAP 专利族获第二十五届全国发明展金奖；"高安全可信媒体主权互联网技术及应用"获深圳市科技进步奖二等奖（李挥为第一完成人）。据公开报道，李挥 2024 年前后亦受聘为福耀科技大学计算与人工智能学院教授，其网络主权理念正在更广泛的产教平台上延展。
