# 上海交通大学 MVIG 实验室（卢策吾组）学术关系网络报告

## 团队简介

MVIG（Machine Vision and Intelligence Group，机器视觉与智能实验室）由卢策吾教授于2016年回国后在上海交通大学创建，是国内具身智能领域最具影响力的学术团队之一。实验室围绕"具身智能"主线，形成了从人类活动理解（AlphaPose、HAKE）到机器人操作学习（GraspNet-1Billion、AnyGrasp、RH20T）的完整研究脉络。卢策吾作为通讯/共同作者在《Nature》正刊发表论文，是国内唯一受邀加入谷歌 DeepMind 牵头的 Open X-Embodiment 国际联合数据集项目的团队负责人。

实验室的核心特征是"学术—产业"双线并进：卢策吾联合王世全（非夕科技联合创始人兼CEO）创立穹彻智能（Noematrix），将 AnyGrasp 等学术成果产品化为"具身大脑"通用技能体系，累计融资超10亿元人民币，投资方包括 Prosperity7、红杉中国、阿里巴巴、无锡数据集团及上海交大AI未来基金等，形成"上海交大—上海创智学院—穹彻智能"的产学研闭环。

在人才培养上，卢策吾以"实验室 + 平台 + 班级"三层体系（MVIG、上海创智学院副院长、吴文俊人工智能荣誉博士班首届班主任、全国首个具身智能本科专业负责人）培养出一批具身智能新生代领军者。本报告覆盖实验室主任卢策吾及其培养的标杆性青年学者李永露（清源研究院长聘教轨副教授、吴文俊优博、ICRA 2025 HRI最佳论文独立通讯作者）。

## 研究方向与圈层结构

团队研究方向覆盖具身智能、机器人学习（操作/抓取/技能学习）、计算机视觉（人体姿态估计、人类活动理解）与实体世界大模型。学术网络呈五层辐射结构：

第一圈层为师承与嫡系（贾佳亚/CUHK、邓智强/HKUST、李飞飞与Guibas/斯坦福，Guibas谱系与王鹤、苏昊同门）；第二圈层为亲传学生网络（李永露、方浩树、刘浏、陈文迪、陈曦等，出口覆盖MIT、马里兰、合工大与国际大厂）；第三圈层为上海交大校内同事（王延峰、杨小康、马利庄团队等）；第四圈层为国际学术圈（Salk的Kay Tye、Open X-Embodiment联盟、康奈尔/哥伦比亚、MIT、NUS等）；第五圈层为产业网络（穹彻智能、非夕科技、华为、腾讯等）。

## 产业转化亮点

穹彻智能（Noematrix）是团队核心产业载体：2023年11月由非夕科技战略孵化成立，"王世全（本体/力控）+ 卢策吾（AI大脑/视觉）"构成国内具身智能领域罕见的"本体+大脑"完整组合。其 Noematrix Brain 具身大脑已迭代至2.0版本，AnyFold（柔性物体折叠）、AnyShave（表面刮削）等通用技能广受关注，首家智能药房已在沈阳常态化试运营。此外，实验室与腾讯合作的"健康码"项目获上海市科技进步特等奖（卢策吾为第三完成人），与华为共建全国首个具身智能本科专业。
