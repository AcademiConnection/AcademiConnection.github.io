# 上海交通大学 通用人工智能研究所 教师学术关系网络报告

> 报告生成时间：2026年8月25日

## 团队简介

通用人工智能研究所是上海交通大学计算机学院2025年学院实体化后设立的研究所，所长为赵海长聘教授，副所长为杨旸教授（官网名录列专任教师13人；本目录另将兼职教师许建峰纳入覆盖，见其个人报告），按"基础理论＋核心技术＋交叉应用"体系布局四大方向：基础大模型（赵海、王瑞）、计算机视觉与具身智能（卢宏涛、丁玥）、脑机接口与情感计算（吕宝粮、郑伟龙，产出世界首个脑电大模型）、交叉应用（含杨旸、涂仕奎、苏锐丹所在的"AI赋能生化医药"团队等）。研究所共建平台包括瑞金脑病中心—米哈游联合实验室、九识自动驾驶联合实验室，国际合作触达牛津、哈佛医学院、UNC、HKUST 等机构；2026年与太初元碁开展国产算力合作（BriLLM-MetaPred）。

本目录建立7位教师的深度报告。需要注意的是，涂仕奎同时挂靠 CMaCH 认知机器与计算健康研究中心（徐雷创建，涂任中心主任助理），其报告如实记录了双重归属；苏锐丹的研究活动亦紧密依托 CMaCH 体系。脑机接口方向的吕宝粮、郑伟龙等 BCMI 实验室成员已有独立目录覆盖（见 [sjtu_bcmi_faculty_network](../sjtu_bcmi_faculty_network/)）。

## 圈层结构概述

研究所网络呈现"所长谱系+CMaCH学脉"双结构。赵海一脉以师承链条见长：其联合指导的王瑞（与吕宝粮、CNRS 的 Sabine Ploux）现为所长骨干，直接指导的张倬胜2023年博士毕业后留校任 Tenure-Track 助理教授，形成"博士—留校—再指导"的传承闭环；NLP/大模型主线（赵海、王瑞、杨旸）产出 BatGPT-Chem、BriLLM 等成果。卢宏涛—丁玥构成 CV 与具身智能搭档（KDD 2024、CVPR 2024 等合作），产业端连接腾讯互娱（游戏部署）、九识（自动驾驶联合实验室）、上海航天、西门子。CMaCH 学脉方面，徐雷（欧洲科学院院士、IEEE Fellow）创建的认知机器与计算健康研究中心为涂仕奎（港中文博士、Science 2018 共同一作）与苏锐丹（Lmser 双向学习）提供主要研究平台，三人与杨旸共同构成"AI 赋能生化医药"交叉团队。跨机构网络包括日本 NICT（赵海长期通道）、CNRS（王瑞联合培养）、UMass 医学院（涂仕奎博后、Craig Mello）、中科院上海高研院（苏锐丹前东家）等国际节点。需要澄清的边界：赵海无新加坡长期任职经历（系香港城大 RF）；卢宏涛非神经形态/SNN 芯片方向（交大 SNN 芯片属王国兴团队）；苏锐丹与西电同名教授非同一人，非西安交大背景。
