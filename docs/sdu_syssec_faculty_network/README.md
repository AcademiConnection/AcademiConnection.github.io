## 三、三人的共同特征与差异

**共同特征：** 三人均为近两年从海外全职引进的青年学者，均在回国前已建立以第一/通讯作者为主体的高水平产出（安全四大顶会、CCS、NDSS、USENIX Security、S&P 等），且都被学院列入"国家级青年人才"梯队。三人的研究方向构成一条互补链：**二进制制品与供应链层（王怀瑾）— 运行时与移动/物联网层（张悦）— AI 与联邦学习层（胡琴）**。

**结构差异：**
- 张悦、胡琴的网络重心已部分"在地化"——与成秀珍、徐明辉、于东晓等 IIC 成员形成稳定共同署名，并通过 IIC 的平台资源（数链融合教育部工程研究中心、山东省算网融合理论与技术重点实验室）承接项目；
- 王怀瑾的网络仍高度依赖港科大 Shuai Wang 课题组，国内合作以南京大学（同门 Zhibo Liu）、腾讯安全科恩实验室为主，院内合作尚在形成中。

## 四、与学院既有团队的关系

- **IIC（智能计算研究所）**：学院系统安全方向最集中的建制平台，现有团队页 16 人（成秀珍、于东晓、李峰、肖梦白、张广辉、胡鹏飞、郑艳伟、章宦乐、潘润宇、张啸、徐明辉、Riccardo Spolaor、王芯蕊、杨燕妮、邹逸飞、张国明）。本轮三人的档案不并入 `sdu_iic_faculty_network`，以避免与既有 10 份报告重复建档或产生归属冲突。
- **IRC（交叉研究中心）**：以图形学、可视化、几何计算为主，与三位教师无方法交集。
- **网络空间安全学院**：刁文瑞教授（安卓应用安全、IoT 固件安全）与张悦有 RAID 2019 历史共著，是校内一条独立于 IIC 的连接线。
