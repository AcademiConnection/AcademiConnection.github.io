## 二、教育背景与职业履历

张悦的学术训练呈现出"国内博士 + 长期海外驻留 + 美国教职 + 回国任教"的完整闭环，是典型的"海外优青"回流路径。

**（1）博士阶段（2016.09—2020.09，暨南大学信息安全专业，工学博士）。** 其个人主页中英文版均写明"师从翁健教授和罗伟奇教授"（under the supervision of Jian Weng and Weiqi Luo），即两位导师共同署名指导。公开材料未披露二人具体的指导分工，仅能从成果分布作有限观察：与翁健的共同署名集中在密码学与区块链系统方向（NDSS 2023 "Fusion: Efficient and Secure Inference Resilient to Malicious Servers"、TDSC 2021 "Peripheral-free Device Pairing by Randomly Switching Power"、TDSC 2019 "DeepChain"、"Looking Back! Using Early Versions of Android Apps as Attack Vectors"、TPDS 2018 "CrowdBC"），与罗伟奇的共同署名则集中在多媒体取证与隐私保护方向（TDSC 2021 "DAMIA: Leveraging Domain Adaptation as a Defense against Membership Inference Attacks"、CMC 2020 重采样因子估计）。这种"一密一安"的双导师结构，为其后续"系统安全 + 密码学"的复合能力奠定了基础。博士学位于 2020 年 9 月获得。

**（2）博士期间海外访学（2018.04—2020.09）。** 2018 年 4 月至 2019 年 4 月在中佛罗里达大学（UCF），2019 年 4 月至 2020 年 9 月在马萨诸塞大学洛厄尔分校（UMass Lowell），合作导师均为付新文（Xinwen Fu）教授。这一段近两年半的访学经历是其 BLE（低功耗蓝牙）与 IoT 安全研究真正的成型期：USENIX Security 2020 "Breaking Secure Pairing of Bluetooth Low Energy Using Downgrade Attacks"、INFOCOM 2020 "BLESS: A BLE Application Security Scanning Framework"、INFOCOM 2022 "FUME: Fuzzing Message Queuing Telemetry Transport Brokers" 等代表作均出自这一合作脉络。

**（3）博士后阶段（2020.10—2023.09，美国俄亥俄州立大学）。** 合作导师为林志强（Zhiqiang Lin）教授，隶属 OSU Computer Security Laboratory（SecLab）。该实验室官网当时将其列为 Post-Doctoral Researcher，与左超顺（Chaoshun Zuo）并列。这一阶段是其"移动超级应用安全"研究的高产期：CCS 2022 "Cross Miniapp Request Forgery"、USENIX Security 2023 "One Size Does Not Fit All: Uncovering And Exploiting Cross Platform Discrepant APIs in Wechat"、CCS 2023 两篇（"Don't Leak Your Keys: AppSecret Leaks in Mini-Programs"、"Uncovering and Exploiting Hidden APIs in Mobile Super Apps"）、ICSE 2023 "TAINTMINI"、SIGMETRICS 2021 "A Measurement Study of Wechat Mini-Apps" 等构成了一条完整的微信小程序安全研究线。

**（4）教职阶段（2023.09—2025.03，美国德雷塞尔大学计算机科学系，终身轨助理教授）。** 任期起止存在两处口径：教师主页工作经历记为 2023.09—2025.03，个人主页中英文版均记为 2024—2025；本报告以教师主页为准，并保留该差异。 这是其独立建组的起点。此期间他一方面延续 OSU 时期的物联网与程序分析工作（CCS 2024 三篇、USENIX Security 2024），另一方面与同系的可信 AI 学者徐凯迪（Kaidi Xu）合作，将研究重心扩展到"LLM 安全与不确定性量化"，产出 IEEE S&P 2025、ACL 2025 两篇、EMNLP 2024 等成果。

**（5）回国阶段（2025.03 至今，山东大学计算机科学与技术学院教授）。** 以国家优青（海外）身份全职回国，入职即获教授职称与博导资格。归国后研究节奏明显加快：2025 年 3 月至 2026 年 10 月间，新增 IEEE S&P 2026、USENIX Security 2026、CCS 2025、CCS 2026、NDSS 2026、NDSS 2027、ICML 2026、NeurIPS 2026、ISSTA 2026、ASE 2025/2026、EMNLP 2026、TDSC 2026、T-IFS 2026 三篇等录用记录，并开始承担 NDSS 2027、ACM CCS 2027、USENIX Secure Agentic AI Systems 2027 等会议的程序委员会工作。

从研究方向演进看，其路径可概括为四段：BLE/IoT 协议与固件安全（2018—2022）→ 移动超级应用与小程序生态安全（2021—2024）→ 程序分析与模糊测试（2022—2024）→ LLM for Security 与 LLM Security 双轨（2023 至今）。回国后的最新布局则在此基础上叠加了"智能体（Agent）安全"这一新方向，代表性成果包括 ICDCS 2026 的 AgentDID（AI 智能体免信任身份认证）、DLS 2025 的 MCP 权限管理测量、以及 USENIX Secure Agentic AI Systems 2027 的会议服务。

**（1）东南大学——凌振、罗军舟、杨明团队（最密集的国内合作通道）。** 这是张悦除导师线之外产出最密集的一条合作链，覆盖 USENIX Security 2024（"A Friend's Eye is A Good Mirror"）、USENIX Security 2025a（"The Cost of Performance: Breaking ThreadX with Kernel Object Masquerading Attacks"）、USENIX Security 2025c（"TORCHLIGHT"）、CCS 2024a（"RIoTFuzzer"）、CCS 2024c（"Collapse Like A House of Cards: Hacking Building Automation System Through Fuzzing"）、CCS 2025（"Time Tells All: Deanonymization of Blockchain RPC Users"）、NDSS 2023c（"CONQUER" 攻击窃取密码）、NDSS 2026（BACnet 隐式保留字段安全）、NDSS 2027（"The SLIP Problem"）、IEEE S&P 2026（Tor 匿名性破坏）、INFOCOM 2024（以太坊 RPC 用户去匿名）、BlackHat Asia 2026（"Shedding LIGHT on Real-World Attacks on Cloudless IoT Devices"）等。该合作的实质是"东南大学（凌振、罗军舟）主导的 IoT/固件/匿名通信攻防体系"与"张悦的协议分析与程序分析能力"的深度耦合，其中多篇论文由张悦担任通讯或核心作者。

**（3）暨南大学/广州大学——翁健、罗伟奇（师承延伸）。** 与翁健的共同署名包括 NDSS 2023b（"Fusion: Efficient and Secure Inference Resilient to Malicious Servers"）、TDSC 2021b、TDSC 2019a/b、TPDS 2018（"CrowdBC"，高被引论文）、BlackHat Asia 2020（QEMU/KVM virtio 逃逸）等；与罗伟奇的共同署名包括 TDSC 2021a、CMC 2020 等。翁健为张悦博士导师、国家杰出青年科学基金获得者，2020 年 2 月至 2026 年 1 月任暨南大学党委常委、副校长，**2026 年 1 月起任广州大学校长（试用期一年）**。张悦 2021 年度广东省自然科学奖一等奖即来自翁健领衔的项目，这一师承关系为其连接了中国密码学与网络空间安全学科最具组织影响力的学者之一。

**（4）西安电子科技大学——李金库、马建峰团队。** 共同署名包括 ASE 2025（"Hit The Bullseye On The First Shot: Improving LLMs Using Multi-Sample Self-Reward Feedback for Vulnerability Repair"）与 ASE 2026（"LaMAR: Latent Multi-Agent Collaboration via KV-Cache Communication for Automated Program Repair"），第一作者焦锐（Rui Jiao）单位为西电综合业务网国家重点实验室。该合作聚焦"LLM 驱动的漏洞修复与自动程序修复"，是张悦把程序分析能力延伸至软件工程顶会的重要出口。

## 五、业界合作关系深度分析

张悦的产业接口在系统安全学者中属于较为扎实的一类：不只是横向项目，而是以"真实漏洞发现—厂商致谢—标准组织反馈"构成的完整链条。

### 5.1 漏洞披露与厂商致谢

据其教师主页与中文主页，张悦"曾多次发现 Bluetooth SIG、谷歌、Apple、德州仪器、MQTT、腾讯等组织、知名公司的高危严重漏洞，获得 Apple、德州仪器、谷歌等公司公开致谢，漏洞赏金或立项支持"，并"成果被中央电视台、新华社、新浪等媒体报道"。这一披露清单与其研究线高度对应：

- **Bluetooth SIG**：对应 BLE 降级攻击（USENIX Security 2020）与 BLE MAC 地址随机化破坏（CCS 2022a / TOPS 2025），后者获 ACM CCS 最佳论文荣誉提名，属于会直接冲击蓝牙核心规范配对流程的协议级缺陷。
- **德州仪器（TI）、MQTT**：对应 MCU/RTOS 固件与外设建模（USENIX Security 2024、2025a 的 ThreadX 内核对象伪装攻击）、MQTT broker 模糊测试（INFOCOM 2022 "FUME"）等 IoT 中间件与芯片级工作。
- **谷歌、Apple、腾讯**：对应安卓应用与移动超级应用生态（微信小程序、安卓年龄验证、无障碍 API 滥用等）。
- **以太坊**：对应区块链 RPC 用户去匿名（INFOCOM 2024、CCS 2025）与智能合约相关安全研究；其项目清单中的"以太坊基金会发展项目"（Ethereum Foundation Ecosystem Support Program 类项目）表明这一合作已从漏洞致谢升级为正式立项支持。

### 5.2 纵向与横向项目结构

其主持项目呈现"国家级人才项目 + 国家级面上 + 省市级攻关 + 国际基金会"的四层结构：

- **国家自然科学基金优秀青年科学基金项目（海外）**：人才引进型项目，是其 2025 年全职回国的核心支撑。
- **国家自然科学基金面上项目**：国家级常规资助，支撑 LLM 安全与程序分析主线。
- **山东省重大基础研究项目**：省级重大基础研究，与山东省"算网融合""数链融合"的地方学科布局衔接，也解释了其与成秀珍团队（数链融合技术教育部工程研究中心、山东省算网融合理论与技术重点实验室）的合作动因。
- **青岛市重点技术攻关项目**：市级技术攻关，指向可落地的 IoT/工业控制系统安全能力，与 CCS 2024c 的楼宇自动化系统（BACnet）模糊测试工作存在主题呼应。
- **以太坊基金会发展项目**：国际开源基金会资助，属国内安全学者中较少见的资助来源，反映其区块链安全工作的国际可见度。

需要说明的是，山东大学教师主页"科研项目"栏目前显示"共 0 条"，上述项目信息全部来自其个人主页中文版，学院与学校层面尚无逐项公开的立项公告，因此项目名称、编号与起止时间均未在公开材料中细化。

### 5.3 产业相关研究的落点

从技术—产业的对应关系看，张悦的产业价值集中在四个赛道的安全测评与攻防：

1. **短距无线与消费电子**：BLE 配对、MAC 随机化、设备身份去匿名，直接影响可穿戴、智能家居与车钥匙等产品线。
2. **工业与楼宇控制系统**：BACnet/BACnet-SC 协议模糊测试与隐式保留字段缺陷（CCS 2024c、NDSS 2026、USENIX Security 2026），面向楼宇自控与关键基础设施。
3. **MCU/RTOS 与 IoT 固件**：ThreadX 内核对象伪装攻击、MCU 外设模型自动合成、伴随 App 辅助远程模糊测试（RIoTFuzzer），面向嵌入式与芯片厂商。
4. **移动超级应用与小程序生态**：AppSecret 泄露、隐藏 API、跨小程序请求伪造、迷你程序恶意软件，面向平台型互联网企业。
5. **LLM 与智能体安全**：LLM 代码审计器致盲攻击（Flashboom）、MCP 权限管理测量、智能体身份认证（AgentDID），面向正在部署 AI 编码助手与智能体平台的厂商。

其产业化路径的突出特征是"以顶会论文为漏洞发现载体、以厂商致谢与赏金为验证、以标准组织（Bluetooth SIG）反馈为影响放大"，而非以专利许可或联合实验室为主要形式。这与同校 IIC 团队以"数链融合教育部工程研究中心 + 浪潮元计算研究院"为载体的平台化产业路径形成有趣互补：张悦更接近"个体 PI + 国际漏洞生态"，IIC 更接近"平台 + 地方龙头企业的组织化合作"。

## 七、Connection 圈层总结

张悦的学术关系网络可概括为五个嵌套圈层，由内向外依次为"团队—师承—同门合作—国际方法伙伴—漏洞与产业生态"。

1. **第一圈层：IIC 团队归属圈（校内组织锚点）。** 以成秀珍为核心，向外连接徐明辉、李琨、于东晓。这一圈层提供的是"高置信计算"框架下的区块链、分布式系统与密码学基础设施，以及数链融合教育部工程研究中心、山东省算网融合理论与技术重点实验室等平台资源。其关系性质是**论文共同署名 + 团队层面的学术关联**，而非共同指导，也非已获证实的建制成员身份（IIC 官网团队页未列入张悦）。此外，与刁文瑞（网络空间安全学院教授）的 RAID 2019 历史共著构成一条独立于 IIC 的校内连接线，是山东大学内部最值得关注的"潜在二次合作"节点。

2. **第二圈层：师承与学术谱系圈（方向决定权）。** 博士导师翁健（暨南大学→广州大学校长）与罗伟奇提供密码学与隐私保护根基；访学导师付新文（UMass Lowell）提供 BLE/IoT 系统安全入口；博士后合作导师林志强（OSU）提供移动生态安全与程序分析的方法体系。三位导师分别对应其三条主要研究线的"原点"，且均为长期共同作者，属"师承—合作"复合关系。这一圈层的独特价值在于：它同时连接了中国密码学界（翁健，国家杰青、中国密码学会副理事长）与北美系统安全学派（林志强、付新文），构成其学术合法性的双重来源。

3. **第三圈层：北美实验室同门与同事圈（产出主力）。** 包含 OSU SecLab 的 Yuqing Yang、Chao Wang、Christopher Ellis、Mohit Kumar Jangid、Shixuan Zhao、Melih Sirlanci、Ruoyu "Fish" Wang，以及 Drexel 时期的徐凯迪、Zhibo Eric Sun、Yuanfang Cai、Shawn McCollum。这一圈层承担了其论文产出的一半以上，并在其回国后继续保持合作惯性（NDSS 2025a/b、USENIX Security 2025b、ACL 2025、ICML 2026、NeurIPS 2026 等）。其中徐凯迪（现香港城市大学）是唯一实现"机构迁移后合作强度不减"的节点，说明二人关系已从"同事"演化为"方法互补型长期伙伴"。

4. **第四圈层：国内跨校合作圈（回国后的规模扩张来源）。** 以东南大学（凌振、罗军舟、杨明）为最密集通道，南京大学（徐峰远、仲盛、吴昊、李悦、李霄）为增长最快通道，西安电子科技大学（李金库、马建峰）为软件工程出口，暨南大学/广州大学（翁健、罗伟奇）为师承延伸，香港理工大学（曹建农）为国际化补充。这一圈层的共同特征是"对方提供场景与系统能力、张悦提供攻防视角与 LLM 方法"，且多篇论文由对方学生担任第一作者、张悦担任通讯或核心作者，体现其在合作中更多扮演"方法论供给者"而非"资源组织者"的角色。

5. **第五圈层：漏洞生态与产业圈（影响力放大器）。** 以 Bluetooth SIG、Google、Apple、Texas Instruments、MQTT、Tencent、以太坊基金会为节点，以 CVE/致谢/赏金/立项为交换介质，以中央电视台、新华社等媒体曝光为影响扩散渠道。这一圈层不产生论文，但产生"真实世界影响力"这一系统安全领域最硬的通货，也是其国家优青（海外）申请与山东省/青岛市项目立项的重要支撑材料。

**网络功能的整体判断：** 张悦处于"移动与物联网系统安全（方法内核）—LLM 安全（新增能力）—漏洞生态（影响力出口）"三者的交汇位置。其学术影响力不主要来自论文数量或单项奖励，而来自三点：一是把 BLE、楼宇自控、MCU/RTOS、移动超级应用四条相对冷门但产业价值极高的攻击面做成了连续的研究线；二是在 2023 年前后及时完成从"传统系统安全"到"LLM 安全"的能力迁移，且迁移路径依托既有合作者（徐凯迪、南京大学团队），成本较低、见效较快；三是回国后迅速与成秀珍、徐明辉等 IIC 成员形成稳定合作，借助其区块链与分布式系统资源，把"智能体身份与信任"这一新议题做成了团队级的共同方向（AgentDID、MCP 权限测量）。

**待观察的三个变量：** 第一，IIC 官网团队页何时同步更新，将决定其在学院组织架构中的正式身份表述；第二，其在山东大学的首批博士生（黄宇航）与硕士生（于婉莹、马建宇、李智豪）能否在 2027—2028 年形成以山东大学为第一单位的安全四大顶会产出，这将是判断其"本土建组能力"的关键指标；第三，与刁文瑞（网络空间安全学院）、王怀瑾（二进制分析与软件供应链安全）等校内互补方向是否形成新的共同署名，将决定其能否从"单点引进人才"成长为"校内系统安全集群的连接枢纽"。
