## 全团队关系网络的整体观察

陆桑璐与叶保留是南大计算机系"内生培养—长期搭档"的典型组合：两人DBLP合作66次，同属Dislab（分布式计算与并行处理实验室）体系，陆桑璐1997年、叶保留2004年先后在南大获得博士学位。陆桑璐的网络以群智感知与移动计算为主线，近年在MobiCom（2015/2018/2022/2024）持续产出，形成了"李文中—钱柱中—谢磊"的实验室骨干层与罗格斯大学Yingying Chen等国际通道；叶保留则以分布式容错与边缘计算为主线，与唐斌、瞿志豪、Song Guo等形成跨机构网络，并曾任CCF南京主席（2025年换届由谢磊接任）——这使两位教师既是学术搭档，又在CCF地方学会治理上形成代际交接。团队的国际连接（会津大学、NTU、罗格斯）与行业连接（国家电网科技项目）构成其业内外双通道。

需要说明的是，原缺失清单中叶保留"苏州校区职务"的线索经核实无官方依据（河海大学页面的相关职务系其河海兼职口径），已在报告中如实标注。
