## 二、五位教师的角色定位

唐杰是 KEG 实验室的学术领军人物与对外代表，兼任系副主任、智源研究院学术副院长，是智谱AI的联合创始人兼首席科学家，其学生网络横跨学术界与产业界，产出了以杨植麟（月之暗面创始人）、东昱晓（回流KEG任教）为代表的顶尖人才。

李涓子是 KEG 实验室主任，与唐杰构成实验室最核心的"双核心"合作搭档，二人共同建设 AMiner 学术搜索系统并联合创立智谱AI；其博士生侯磊已留校任教，形成清晰的学术传承链条。

许斌同样具备博导资格，是智谱AI的另一位联合创始人，研究方向从早期的语义 Web 服务计算逐步演进至知识图谱、教育知识工程，近年进一步扩展至大模型与智能体；他与李涓子在教育知识图谱、事件抽取方向合作尤为密切。

东昱晓是实验室中履历最为国际化的教师，本科受唐杰指导，博士毕业于圣母大学，历经微软研究院、Meta AI 的工业界研究员生涯后回流清华任教，是唯一将海外顶尖工业实验室经验直接带回 KEG 的教师，其指导的本科生大量进入 MIT、UCLA、Cornell、Stanford、CMU 等顶尖院校深造。

侯磊是李涓子的博士生，博士后出站后沿"助理研究员→副研究员"的研究系列晋升路径留校，是 KEG 中唯一未被标注"Ph.D Advisor"的教师，代表了实验室内"小导"（当前以硕士生合作指导为主）的角色定位，同时也是李涓子知识图谱研究线的核心执行者。

## 三、全实验室关系网络的整体观察

KEG 实验室的师资网络呈现出几个较为清晰的结构性特征。

第一是"学术—产业"高度融合的双栖结构。五位教师中有三位（唐杰、李涓子、许斌）直接是智谱AI的联合创始人，GLM/ChatGLM 系列大模型的核心技术出自 KEG，这使得实验室内部的师生关系、合作关系与智谱AI的产业组织结构高度重叠，形成了国内高校实验室中较为罕见的"实验室即公司技术底座"的产学研一体化模式。

第二是清晰的学术传承代际链条。唐杰的本科生东昱晓历经海外深造与工业界历练后回流任教，李涓子的博士生侯磊博士后出站后留校任教，两条传承线都完整体现了"实验室培养—对外深造/历练—回归任教"的人才闭环，这也是 KEG 能持续保持团队年轻化和国际化视野的重要机制。

第三是"大导"与"小导"的层级分工。唐杰、李涓子、许斌、东昱晓四人具备独立博士生导师资格，侯磊作为副研究员目前不具备这一资格，但在实际科研产出中，侯磊与李涓子的合作密度极高（在其代表作中占比超过九成），实质上承担着相当比例的学生指导与论文通讯作者职能，这种"正式导师资格"与"实际指导强度"之间的错位，是理解 KEG 内部人才培养体系的关键。

第四是学生去向的两极分化。一部分学生（如唐杰的本科生杨植麟、东昱晓指导的多名本科生和实习生）走向了 CMU、MIT、UCLA 等海外顶尖学术机构或自主创业，另一部分学生则直接进入智谱AI等 KEG 孵化或深度关联的产业机构，体现了 KEG 毕业生"学术精英输出"与"自我造血产业链条"并存的双轨去向格局。

第五是重名与身份消歧的挑战。本系列研究过程中最典型的案例是许斌研究员常被误记为"徐冰"，需要通过邮箱、机构、学位、研究主题的四重交叉验证才能准确定位；类似地，KEG 团队页面未逐一标注学生的指导教师，本系列报告中大量学生的师生归属是基于论文合著模式、通讯作者身份及公开新闻报道综合推断，标注为"推断关系"的内容不应视为官方确认信息。

## 数据来源与说明

各报告数据主要来源于 KEG 实验室官网、清华大学计算机系官方教师页面、各教师个人主页、DBLP、Google Scholar、AMiner，以及清华大学官方新闻报道（如"良师益友"奖、"挑战杯"获奖公示、SIGKDD/EMNLP等奖项报道）。由于 KEG 团队页面未逐一标注学生的指导教师，报告中标注为"基于合著网络推断"的师生关系不代表官方确认的正式指导关系；博士导师、学生毕业去向等信息如缺乏权威来源直接确认，均已在对应报告中注明推断依据，如遇后续信息更新，请以学者本人或学校官方发布为准。
