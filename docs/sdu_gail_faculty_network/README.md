# 山东大学通用智能实验室（GAI Lab）教师学术关系网络报告索引

## 一、团队概况

山东大学通用智能实验室（General Artificial Intelligence Lab, GAI Lab）隶属山东大学计算机科学与技术学院与人工智能学院，前身为 2004 年由马军教授创建的山东大学信息检索实验室（IR Lab），现主站为 gail.sdu.edu.cn（原 ir.sdu.edu.cn 站点目前仍在线并行维护）。

实验室的治理结构为"荣誉主任—主任—双副主任"：荣誉主任（创始主任）马军，主任陈竹敏，副主任任鹏杰、辛鑫。研究覆盖大模型（语言/多模态/检索增强/智能体）、信息检索、自然语言处理、推荐系统、医疗健康大数据、具身智能与三维视觉等方向，是山东大学在信息检索与大模型方向最集中的建制化团队。

## 四、团队关系网络的主要特征

- **一条主轴、六个方向**：陈竹敏占据"检索／大模型／医疗健康"中枢位，任鹏杰承担生成式检索与对话、辛鑫承担推荐系统与强化学习、张孟奇承担知识图谱与大模型编辑、任昭春承担国际化、刘千惠承担类脑与多模态前端、于邓／何科技／罗传琛承担具身智能与图形学。
- **学术谱系内生化**：陈竹敏（2008 届）、任鹏杰（2018 届）均为实验室培养的博士并留校任教，形成"马军→陈竹敏→任鹏杰"的世代交接链。
- **制度化产业平台**：青岛市可信智能重点实验室（筹，2025 年 12 月获批）、多个校企联合实验室（义远、联合永道、深辰凯动、潍坊卫健委—维克特、爱特云翔）与自研"大模型一体化平台"，构成"垂域微调＋系统集成"的落地形态；校级应用"山大智能助手"是其实质影响力载体。
