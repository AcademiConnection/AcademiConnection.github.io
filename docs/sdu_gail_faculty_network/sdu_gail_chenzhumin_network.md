陈竹敏是山东大学通用智能实验室的第二代学术带头人。他的网络结构具有鲜明的"单点深根＋多向外溢"特征：根系是2004年由马军创建的信息检索实验室（IR Lab）及其在2008年培养的博士群体；主干是在信息检索与自然语言处理主赛道上与任鹏杰、辛鑫、张孟奇、任昭春等构成的实验室教师共同体；外溢方向则有四条——一是与荷兰阿姆斯特丹大学／莱顿大学（Maarten de Rijke、任昭春）的长期国际合作，二是与百度、微软亚洲研究院等企业的论文与项目合作，三是与浪潮、海信、青岛地铁、义远科技、维克特等的垂域大模型产业化合作，四是与潍坊市卫健委等地方政府卫生系统的医疗健康大数据合作。他的特殊性在于：既是学术带头人，又是行政管理者（人工智能学院副院长，分管科研、人事人才、研究生培养、教育拓展、国际交流、产教融合），因此其网络同时具备"学术网络"和"治理网络"双重属性。

## 二、教育背景与职业履历

**博士阶段与学位。** 山东大学通用智能实验室的毕业生页面明确把陈竹敏列入"2008届博士"，同届博士还有刘慧（现山东财经大学），其去向标注为"山东大学"。这与他"由该实验室培养、留校任教"的路径一致。需要说明的是：实验室页面只按届公布毕业生与去向，**不标注每位毕业生的具体导师**。

**关于博士导师的核实与依据。** 综合三条公开线索，本报告判断其博士导师为马军教授，但标注为"高置信推断"而非"直接披露"：（1）GAI Lab 由马军于2004年创建，2008年前后实验室的博士生导师仅马军一人（马军为日本九州大学工学博士，现为实验室荣誉主任）；（2）实验室 2008 届博士仅陈竹敏、刘慧两人，均出自该学科组；（3）陈竹敏与马军至今保持长期共同署名关系（例如 SIGIR 2024 最佳论文提名论文 *Generative Retrieval as Multi-Vector Dense Retrieval* 的作者列表同时包含"陈竹敏、马军"）。实验室官方页面从未出现"师从马军"一类表述，故本条只能作为谱系推断，不宜写作确证的师徒关系。可确证的是：**二人同属该实验室的师生两代，构成"创建者—继任者"的谱系关系**。

**海外与机构访问经历（有明确起止时间）。** 
- 2012年2月至2012年8月：微软亚洲研究院（MSRA）访问学者。MSRA 是中文信息处理与信息检索研究的重要枢纽，实验室页面亦将 MSRA 前副院长、首席研究员周明列为"合作博士生导师"，说明这一访问不是一次性交流，而是嵌入了实验室的长期合作关系。
- 2014年12月至2015年12月：美国普渡大学（Purdue University）访问学者，为期一年。这是其唯一一段长周期海外驻留，也是其后续与 Purdue 系学者保持联系的基础。
- 未检索到其海外博士后经历。可检索到的博士后线索是"国家博士后基金—网络突发事件的感知方法及动力学演化模型研究（2010—2012）"，据此可推断其在博士毕业（2008）后于山东大学从事博士后研究，研究方向由"Web 图像检索／语义标注"转向"社会媒体与网络突发事件"，这也是其研究从纯检索向"社会媒体＋大数据"扩展的转折点。

**职业履历与角色演进。** 
- 2008年博士毕业后留校，经历讲师—副教授—教授的常规晋升路径；2022年计算机学院博士招生团队简介中，其头衔已是"教授、博导、副院长"，并任 CCF 自然语言处理专委会副秘书长、中文信息学会信息检索专委会委员。此后逐步晋升为 CCF NLP 专委会常委、中文信息学会信息检索专委会副主任。
- 2024年8月30日，山东大学浪潮人工智能学院（人工智能学院）成立，成为学校"大人工智能战略"的组织载体；陈竹敏任副院长，分管科研、人事人才、研究生培养、教育拓展、国际交流、产教融合。同期他继续以 GAI Lab 主任身份领导实验室。
- 2025年5月，被计算机科学与技术学院推荐为山东大学第十七届"我心目中的好导师"候选人，材料系统总结了其指导研究生58人、承担项目近30项、授权专利26项、获国际顶级会议最佳论文/提名5次的成绩。

**研究重心的三段式迁移。** 第一阶段（2005—2013）为 Web 信息检索与语义标注：国家自然科学基金"Web图像的语义表示及在聚类与排序中的应用"、"基于机器学习的多义性数据概念标注研究"、"基于多空间描述的Web图像检索"（教育部博士点基金）、"Web网页时效性评价及其在网页排序应用中的研究"（2012—2014）。第二阶段（2014—2019）转向社会媒体与医疗健康大数据：社会网络模型、社会媒体文本摘要与图像标注、基于社会媒体的用户移动模式发现，以及"基于互联网与本地数据融合的'互联网+医疗健康'信息检索研究"（NSFC，2017—2020）、"基于互联网与医院本地大数据融合的复杂疾病演化建模及预测研究"（山东省自然科学基金，2017—2019）。第三阶段（2020年至今）聚焦垂域大模型与生成式检索：SDU 系列大模型、大模型一体化平台、山大智能助手、知识产权行政执法智能辅助监督系统，以及"面向多专家辅助会诊的多方可控对话技术研究"（NSFC，2024年起）。

### 3.5 培养模式特征

其培养模式的三个可观察特征：其一，**顶会导向的学生第一作者制**——SIGIR、WSDM、EMNLP、RecSys 的获奖论文第一作者均为在读硕士或博士生，导师承担通讯或方向把握角色；其二，**本科生早期介入**——2021级泰山学堂本科生魏闻达参与 SIGIR 2024 最佳论文提名论文，韩晓晖、吴世广等案例显示本科生进入顶会作者列表是常态；其三，**"学生—青年教师—副主任"的内部晋升通道**——任鹏杰、赵玉琨、张佃磊三人分别以"博士毕业生—副教授—项目主任"的路径回到实验室体系中，形成人才内循环。

## 四、学术合作网络

### 4.1 实验室内部合作

**组织结构。** GAI Lab 的治理结构为"荣誉主任＋主任＋双副主任"：荣誉主任（创始主任）马军；主任陈竹敏；副主任任鹏杰、辛鑫。这一结构清晰标示了实验室的世代交替：马军（日本九州大学工学博士，2004年创建实验室）为创建者与精神源头，陈竹敏为2008届实验室博士、现任学术带头人，任鹏杰（2018届实验室博士）与辛鑫（英国格拉斯哥大学博士）为分管科研与人才培养的副主任。

**核心教师群。** 实验室现有教师与研究人员20余人，覆盖信息检索、自然语言处理、大模型、推荐系统、具身智能、多模态、计算机图形学与 VR/AR、强化学习与智能体等方向。与陈竹敏直接构成方法共同体的包括：

### 4.3 国际合作

陈竹敏的国际合作呈现"低密度、高深度、制度化"的特征：合作节点数量不多，但每个节点都有多篇顶会／顶刊支撑，且多以实验室"合作专家"或"合作博士生导师"的制度形式固定下来。

- **荷兰（核心）**：阿姆斯特丹大学 Maarten de Rijke（院士）、莱顿大学任昭春。这是唯一一条覆盖"论文—学生交换—博士后—教职流动"全链条的国际合作轴。
- **加拿大**：蒙特利尔大学 Jian-yun Nie，信息检索方向的早期方法来源。
- **美国**：普渡大学（其2014—2015年访问单位）、德州州立大学 Byron J. Gao、微软亚洲研究院（周明，兼具国内机构与国际企业研究院双重属性）。
- **英国／欧洲其他**：格拉斯哥大学（辛鑫的博士母校；Xuri Ge、Joemon Jose 的合作论文）、爱丁堡系研究者（信息检索与多模态）。
- **新加坡／香港**：刘千惠与李海洲（香港中文大学（深圳）／新加坡）的类脑计算合作，是实验室近年新增的国际方向。

与其 IRC 同侪（如曾琼）以"论文合作为主、缺乏长期海外驻留"相比，陈竹敏的国际合作更依赖"制度化的合作专家名单＋博士生联合培养＋人员在 UvA／Leiden 的往复流动"，稳定性更强，但地理集中度也更高（荷兰一极独大）。

## 五、业界合作关系深度分析

陈竹敏的产学研网络可拆为四层：**国家级纵向项目（打底）—省级重大工程（放大）—校企联合实验室（接口）—具体产品与系统（落地）**。

### 5.1 国家级纵向项目

- **国家重点研发计划课题"知识产权行政执法智能辅助监督关键技术研究"（2022—2025）**：聚焦权责清单知识图谱构建（覆盖率≥90%）、执法依据判定与裁量基准判定，产出"知识产权行政执法智能辅助监督系统"。
- **国家重点研发计划课题"行政执法全流程合法合规性风险预警和智能审查技术研究"**：是上一课题的延伸，从"监督"扩展到"全流程合规性预警"。
- **国家重点研发计划课题"人机协同的稿件质量评价体系"**：面向出版与学术传播场景，属"AI＋出版"的垂直应用。
- **国家自然科学基金"面向多专家辅助会诊的多方可控对话技术研究"（2024年起）**：这是他当前最核心的医疗健康大数据项目，把"多专家会诊"建模为"多方、可控、可追溯的对话"，直接对应医疗大模型的可信性难题。
- **国家自然科学基金"基于多源异构数据融合的可解释性医疗健康问答技术研究"（2020—2023）**：解决医疗问答的可解释性，是"医疗大模型"能否进入临床辅助决策的前置条件。
- **国家自然科学基金"基于互联网与本地数据融合的'互联网+医疗健康'信息检索研究"（2017—2020）**：这是他医疗方向的起点，把"互联网公开医学信息"与"医院本地电子病历数据"做融合检索。
- **国家自然科学基金"Web网页时效性评价及其在网页排序应用中的研究"（2012—2014）**：其早期检索研究的代表性项目，属"时效性感知的排序模型"。
- **山东省重大科技创新工程课题"垂直领域大模型技术研发与应用"**：省级层面对"垂域大模型"的总纲性支持，是 SDU 系列大模型与"大模型一体化平台"的直接经费来源。
- **山东省重大科技创新工程课题"面向公共安全的互联网中文文本语义分析关键技术研究"（2020—2022）**：把中文语义分析用于公共安全场景（舆情、风险识别）。
- **山东省自然科学基金"基于互联网与医院本地大数据融合的复杂疾病演化建模及预测研究"（2017—2019）**：医疗方向的省级配套。
- **济南市校融合项目"人工智能产教融合技术研发中心"**：市级平台，指向人才培养与产业对接。

### 5.3 具体产品与系统（落地层）

- **大模型一体化平台**：自主研制的科研—应用一体化平台，集成 vLLM 加速推理、数据标注、模型微调与部署，定位为"面向科研技术人员的研发需求与传统行业人员的实际应用"。
- **SDU 系列大模型与垂域大模型**：政务大模型（浪潮）、智能电视大模型（海信）、城轨大模型（青岛地铁）、建筑大模型（义远科技）、医疗大模型（维克特／潍坊卫健委）。获第二十五届高交会"优秀产品奖"、世界工业互联网产业大会"2023年度大模型优秀创新应用案例"、2025年中国高校远程与继续教育优秀案例奖。
- **山大智能助手**：面向全校师生上线，覆盖通用问答（校园数据微调的基座模型）、科研辅助（论文翻译、润色、总结、综述）、教学助手（教案生成）、法律与管理服务，是"高校治理场景＋大模型"的标志性案例。
- **夫子·明察司法大模型**：与浪潮云、中国政法大学联合研发，获高交会"优秀产品奖"，衍生出知识产权行政执法智能辅助监督系统。
- **模型研发平台**：面向多领域大数据与 AI 融合的工具库／算法库／模型库，提供数据分析与方案定制。

### 5.4 企业横向项目（历史层）

早期与中期的横向合作对象包括：腾讯（"基于知识库的回复生成研究"）、科大讯飞（"面向多种推荐场景的对话生成"）、海信（"自然语言生成技术研究"、"基于空调报障的智能客服系统"）、微软（"城市生活方式发现"，Windows Azure 城市计算，Co-PI）、以及"跨平台社会媒体大数据分析"（2017—2018）、"自然语言生成和对话技术研究"（2019—2020）、"不动产价格智能评估模型研发"（2023—2024）、"消防队站资源配置优化研究研判模型算法模块研发"（2024—2025）、"面向营销客户服务的大语言模型微调技术研究"、"表格高精度解析与结构化数据智能查询技术研究"、"智能仓储货物盘点与三维测绘系统开发"等。这批项目显示其产业化路径并非只押注"大模型"单一赛道，而是横跨推荐／对话／大数据分析／空间智能（测绘、仓储）多个应用面。

### 5.5 医疗健康大数据的产业合作纵深

医疗健康是其四大研究方向中产业化链条最完整的一条，可清晰划分为四段：
1. **数据层**：山东省自然科学基金"基于互联网与医院本地大数据融合的复杂疾病演化建模及预测研究"（2017—2019）确立"互联网数据＋医院本地数据"的融合范式；
2. **检索与问答层**：NSFC"互联网+医疗健康"信息检索（2017—2020）→ NSFC 可解释性医疗健康问答（2020—2023），从"找得到"推进到"答得准、可解释"；
3. **会诊决策层**：NSFC"面向多专家辅助会诊的多方可控对话技术研究"（2024—），把单轮问答升级为多专家、多轮、可控的会诊对话；
4. **区域落地层**：2025年2月，潍坊市卫健委与山东大学人工智能学院、山东维克特信息技术有限公司签署共建"卫生健康数字智能创新实验室"协议（潍坊市第三届卫生健康系统人才发展大会上签约），把研究转化为区域卫生系统的智能底座。
这一"基金→论文→联合实验室→地方卫生系统"的四段式，是其在医疗方向最值得关注的产业化结构；相较之下，与具体三甲医院的临床深度合作在公开资料中尚不显著，是其医疗网络当前的相对薄弱环节。

### 5.6 产业化能力评价

三个维度可以概括其产业合作的强度与边界：**平台化能力强**（同时运营5个校企联合实验室／研究中心，且有"大模型一体化平台"这样的自研底座）、**场景覆盖广**（政务、司法、广电／电视、轨道交通、建筑、医疗、教育、营销、仓储、消防、不动产），**但单点深度受制于"平台—场景"的耦合方式**——多数合作以"垂域微调＋系统集成"为技术形态，尚未出现类似"独家共建国家级平台"的深度绑定。其最不可替代的资产是"山大智能助手"：它是国内少有的、真实覆盖全校师生且持续运行的高校级大模型应用，兼具技术验证与治理示范价值。

## 七、Connection圈层总结

陈竹敏的学术关系网络可概括为六个由内向外、层层嵌套的圈层：

**第一圈层：实验室谱系与治理结构。** 以马军（创建者、荣誉主任、疑似博士导师）为谱系源头，以任鹏杰（副主任、2018届同门博士）、辛鑫（副主任）为治理支点，构成"荣誉主任—主任—双副主任"的四角结构。这一圈层提供的是"合法性"（实验室的创建历史与学术正统）与"执行力"（副主任分管的科研组织与人才培养）。陈竹敏在此圈层中的角色是"继任者与整合者"，而非"创始人"——这一身份决定了其网络风格偏重"组织与协调"，而非"个人英雄式突破"。

**第二圈层：学生与青年教师的内部循环。** 以58名研究生的培养体量为基础，以任鹏杰、赵玉琨、张佃磊"毕业—历练—回流"三人为标志性样本，形成"学生—青年教师—副主任／项目主任"的完整晋升通道。这一圈层的功能是"人才再生产"：既产出顶会论文的第一作者，也产出实验室未来的教师与管理者。其健康度可从两个指标观察：顶会最佳论文／提名奖的连续性（CIKM 2017 → EMNLP 2023 → WSDM/SIGIR 2024 → RecSys 2024），以及学术岗位毕业生的省域分布（山东财经大学、山东师范大学、山东建筑大学、济南大学、青岛科技大学、太原理工大学等）。

**第三圈层：荷兰轴与欧洲合作制度化。** 以 Maarten de Rijke（UvA，荷兰皇家艺术与科学院院士）为学术高点，以任昭春（UvA 博士 → SDU 教授 → Leiden 教授）为人员枢纽，形成"合作专家名单＋联合发表＋博士后／博士生流动"的三重制度化合作。这是其网络中唯一具备"全链条人员流动"的国际通道，也是其顶会成果最稳定的外部方法来源。

**第四圈层：产业合作的多平台结构。** 以浪潮（政务大模型、司法大模型）、海信（智能电视大模型、智能客服）、青岛地铁（城轨大模型）、义远科技（建筑大模型）、维克特＋潍坊卫健委（医疗大模型）、联合永道（数据资源）、深辰凯动（具身智能）、爱特云翔（算力＋行业大模型）为节点，形成"一企一垂域"的平台矩阵。与单一企业深度绑定的模式不同，其策略是"多点布点、统一底座"——所有垂域模型共享"大模型一体化平台"的技术底座，从而在保持合作广度的同时控制研发边际成本。这一策略的代价是单个合作的深度有限，收益是抗风险能力强、场景覆盖广。

**第五圈层：医疗健康大数据的纵向链条。** 这是其最具辨识度的"纵深型"网络：从山东省自然科学基金（2017）→ NSFC 面上（2017、2020、2024）→ 潍坊市卫健委联合实验室（2025），形成"省级—国家级—区域落地"的三级递进，研究问题也从"信息检索"演进到"可解释问答"再到"多专家可控会诊对话"。该链条的独特性在于它同时具备学术前沿性（多方对话、可控生成）与治理落地性（区域卫生系统），是"AI＋医疗"少见的完整闭环。相对短板是与顶级三甲医院的临床科研合作尚不显著。

**第六圈层：学术治理与政策影响。** 以 CIPS 信息检索专委会副主任、CCF NLP 专委会常委为核心的组织身份，叠加青岛市人工智能产业协会副会长、《High-Confidence Computing》编辑部主任、山东省／青岛市 AI 规划编制参与者、40余场政策与技术报告，构成"学术共同体—产业协会—政策制定"的三重影响力通道。这一圈层是其区别于纯学术型教授的关键：他的影响力不仅通过论文传播，也通过标准、规划、平台与产品传播。

**网络功能的总体判断。** 陈竹敏处于"信息检索方法—垂域大模型系统—区域产业与治理"三者之间的枢纽位置。其学术影响力并不主要来自单篇论文的引用量，而来自三种组织能力：其一，把实验室三代的教师（马军—自身—任鹏杰／辛鑫）组织成可持续的分工体系；其二，把 UvA／Leiden 的国际方法与 SDU 的学生产能组织成稳定的顶会产出流水线；其三，把山东省的产业场景与政策资源组织成"大模型一体化平台＋多垂域模型"的落地矩阵。若说其网络存在结构性风险，主要在两处：一是国际合作高度集中于荷兰一极，缺少北美与东亚的第二支柱；二是医疗方向的临床端合作尚浅，若能补齐与顶级医院的联合研究，其"医疗健康大数据"链条将从"区域卫生信息化"升级为"临床可验证的智能辅助决策"，这将是其网络下一个最值得期待的扩展方向。
