公开可检索材料没有给出商琳的本科、硕士、博士授予院校、各学位年份及博士导师。因此，不能据同组师生关系或论文作者顺序倒推出其教育背景；上述具体信息均为**待核实**。可确认的是，南京大学计算机学院公开师资页将其标为“商琳（博士）”，而其个人主页显示其已任南京大学计算机科学与技术系副教授，并依托计算机软件新技术国家重点实验室开展教学与研究。

其可由公开记录拼接出的职业时间线如下：

- **2007—2010年前后**：在粗糙集、粒计算、迁移学习与早期情感分析方向形成稳定合作。学生杨盛（Yangsheng Ji）的公开主页明确记载其受陈家骏、商琳共同指导，并列出双方与戴新宇、黄书剑、牛刚等人的论文，反映了她与南大 NLP/机器学习团队在该阶段的交叉合作。
- **2010年代至今**：持续在南京大学任教。其主页列明研究生“计算智能”、本科“数据结构”“程序设计基础”，以及曾开设的“人工智能”；页面所列毕业生从2008届前后延续至2025届，反映其长期承担研究生培养。
- **2023年6月10日—2024年6月9日**：受加拿大麦吉尔大学常晓文（Xiaowen Chang）教授邀请，以中国国家留学基金公派资助赴加进行人工智能方向访问交流。该记录可作为明确的国际学术访问履历，但不能据此推定共同论文或长期联合项目。

商琳在[NJU NLP 人员页](https://nlp.nju.edu.cn/people.html)与陈家骏、戴新宇、黄书剑共同列为教师，构成组织层面的近邻关系；其中陈家骏、戴新宇、黄书剑均为教授、博士生导师，商琳为副教授。需要区分“同团队”与“共同署名”：同属团队是公开可确认的事实，并不自动意味着每两人均有持续共同论文。

可直接确认的合作包括：杨盛个人主页明确写明其受**陈家骏与商琳共同指导**；其2010年论文 *Transfer Learning via Multi-View Principal Component Analysis* 署名杨盛、陈家骏、牛刚、商琳、戴新宇，建立了商琳—陈家骏—戴新宇在迁移学习方向的共同论文联系。该生主页还列出商琳与杨盛、戴新宇的依存句法分析论文，以及商琳与杨盛、邵悦、贾秀一的数值属性切分论文。黄书剑同样是 NJU NLP 的核心教师，且杨盛2008年情感分类论文署名陈家骏、戴新宇、黄书剑；但该篇并无商琳署名，故只能说明其处于共同的团队研究环境，商琳与黄书剑的直接共同署名关系仍待核实。

### 4.2 跨机构合作

跨机构合作中，最清晰的学术节点是牛刚：他由商琳指导完成硕士，后赴东京工业大学获博士，经历百度、东京大学并进入 RIKEN。商琳与牛刚、杨盛、博岱在 PAKDD 2010 共同发表论文，形成南京大学—日本机器学习研究网络的早期连接。该联系以共同作者和校友发展为依据，不应扩大解释为商琳与 RIKEN 的正式机构合作（待核实）。

另一条可明确说明的跨机构学术流动是徐苏萍博士毕业后赴阿尔伯塔大学从事博士后。这显示商琳组学生延伸至加拿大高校；但尚未找到共同发表、联合项目或联合培养协议的公开凭据。商琳在2023—2024年访问麦吉尔大学，也为其个人网络增加了加拿大节点。

### 4.3 国际合作

国际关系以“访问交流”和“学生海外发展”两类为主。南京大学计算机学院2023年正式公告确认：商琳受麦吉尔大学常晓文教授邀请，获得国家留学基金资助，赴该校进行一年人工智能访问交流。这是本报告所能确认的商琳个人国际合作/交流事实。

## 七、Connection圈层总结

**第一圈层：师生与共同研究节点。** 商琳的关系网络核心是长期研究生培养。可确认的代表节点包括博士生徐苏萍、硕士生牛刚、冯俊佳、林明倩、殷文彪、谢鹏飞、李维涛与王帅。杨盛是特殊的双重节点：公开资料明确其由陈家骏、商琳共同指导，且连接了早期迁移学习、情感分析和粗糙集研究合作。

**第二圈层：NJU NLP 内部协同。** 陈家骏、戴新宇、黄书剑与商琳共同构成 NJU NLP 教师圈层。陈家骏和戴新宇与商琳存在可见的共同指导/共同论文证据；黄书剑则是团队共同研究环境中的关键同事，直接共著关系尚待补充证据。这一圈层体现了从传统机器学习、粗糙集到情感分析与语言智能的交叉基础。

**第三圈层：跨校与国际延展。** 加拿大麦吉尔大学常晓文教授邀请访问构成商琳本人可核实的国际交流节点；阿尔伯塔大学博士后去向和 RIKEN 的牛刚构成学生发展带来的加拿大、日本连接。该圈层目前应定义为访问和人才流动网络，不宜未经证实升级为联合实验室或长期项目网络。

**第四圈层：产业与校友生态。** 阿里巴巴、华为、百度、腾讯微信、美团、字节跳动、携程、网易、蚂蚁集团、滴滴、搜狗等，是由学生就业/实习汇聚而成的广泛产业圈层。其特征是科技企业密集、跨届持续、兼有互联网与国企/金融机构去向。证据强度最高的是校友就业和实习；企业联合研发、创业孵化、成果转让及顾问关系在现有公开材料中仍属待核实。
