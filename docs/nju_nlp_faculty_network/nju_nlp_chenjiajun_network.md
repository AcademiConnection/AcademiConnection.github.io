## 二、教育背景与职业履历

陈家骏教授本科、硕士、博士均毕业于南京大学计算机软件专业，是土生土长的南大学者。据南京大学人工智能实验室官方介绍，陈家骏于1998年在南京大学获得博士学位。其博士阶段的研究方向为计算机软件，早期工作涉及结构化软件开发方法、CASE环境等软件工程领域，曾与郑国梁教授合作发表结构化软件开发过程平稳过渡方面的研究。其博士导师信息尚未从公开渠道确认（待核实）。

博士毕业后，陈家骏留校任教于南京大学计算机科学与技术系，长期从事教学与科研工作。他逐步将研究重心从软件工程转向自然语言处理，特别是机器翻译方向。在2000年代初期，他参与了六轮国家863计划资助项目"日汉机器翻译系统"的研制，并主持了其中863重点项目"Internet在线日汉机器翻译系统"和"基于多策略的日汉/汉日Internet机器翻译系统"，以及"面向奥运的多语言信息服务系统"中受限领域日汉机器翻译技术的研究工作，研究成果据称达到国际领先水平。

陈家骏现为南京大学计算机科学与技术系教授、博士生导师，同时担任南京大学人工智能实验室主任。他是计算机软件新技术国家重点实验室（现更名为计算机软件新技术全国重点实验室）成员，NJU NLP研究组的核心学术带头人之一。在教学方面，他长期承担"程序设计（用C++语言编程）"和"自然语言处理"两门课程的教学工作，编著的教材《程序设计教程——用C++语言编程》已出版至第4版（2022年8月，机械工业出版社）。

在科研方面，陈家骏带领NJU NLP研究组在机器翻译领域持续深耕，从早期的基于规则和统计的日汉机器翻译，逐步发展到神经机器翻译、翻译质量评估（QE）、大语言模型等前沿方向。研究组承担了多项国家级项目，包括国家863计划、国家重点研发计划等。近年来，研究组的论文频繁被ACL、EMNLP、NAACL、AAAI、NeurIPS等顶级会议录用，在WMT质量评估评测中多次获得第一名。

## 五、业界合作关系深度分析

### 5.1 产业合作

NJU NLP研究组在陈家骏带领下，与国内头部科技企业建立了深度产业合作关系，形成了"产学研"紧密结合的模式：

**字节跳动合作**

字节跳动是NJU NLP最紧密的产业合作伙伴。双方的合作体现在多个层面：

- **联合研究**：2021年，郑在翔（陈家骏博士生）、周浩（陈家骏博士毕业生）与字节跳动AI Lab火山翻译团队联合发表可逆神经机器翻译（REDER）论文于NeurIPS 2021，论文作者包括字节跳动的许晶晶、李磊。此后双方在机器翻译、大模型训练等方面持续合作。
- **人才输送**：字节跳动是吸收NJU NLP毕业生最多的企业，从2017届到2025届累计接收超过14名毕业生（含博士和硕士），分布在上海、北京等研发中心。
- **近期合作**：据公开报道，南京大学与字节跳动联合开展AI训练精度优化研究，提出CoRT方法（基于反事实重播的强化学习训练机制），在多个基准测试中显著提升模型性能。
- **企业合作导师**：NJU NLP官网师资列表中列有"何亮"作为"企业合作导师"，暗示实验室引入了企业界联合导师机制（待核实何亮具体所属企业）。

**阿里巴巴/通义实验室合作**

- **联合论文**：在ACL 2026上，NJU NLP与阿里通义实验室联合发表多语言大模型论文（DeltaMoE方法），作者包括通义实验室的杨宝嵩（Baosong Yang）等，合作机构标注为"南京大学、通义实验室、浙江大学"。杨宝嵩是机器翻译和多语言NLP领域的知名研究者，与NJU NLP的合作由来已久。
- **人才输送**：阿里巴巴及蚂蚁集团累计接收NJU NLP毕业生超过17名，是仅次于字节跳动的第二大就业去向。

## 七、Connection圈层总结

陈家骏教授的学术关系网络可划分为四个圈层：

**第一圈层：核心学术伙伴与传承者**

最核心的圈层由陈家骏直接培养或长期合作、并留校任教的学术传承者组成，包括黄书剑（教授，2012届博士）、戴新宇（教授，2005届博士）、张建兵（副教授，2009/2018届）和吴震（助理教授，2021届博士）。其中吴震的正式博士导师为戴新宇；其余师承关系的具体安排以公开资料为准。这些学者共同构成当前NJU NLP研究组的核心教学科研力量，形成了稳固的"师-生-同事"三代传承结构。黄书剑是其中最核心的合作者，两人几乎在所有研究方向上共同发力，联合指导博士生。

**第二圈层：毕业校友网络**

陈家骏及其团队自2001年以来培养的百余名毕业生构成了庞大的校友网络。这些校友分布在字节跳动（14+人）、阿里巴巴/蚂蚁集团（17+人）、腾讯（9+人）、华为、百度、美团、快手等头部科技企业，以及清华大学AIR、江南大学、南京理工大学、南京师范大学等学术机构。这一校友网络为NJU NLP的产学研合作提供了天然的渠道——企业合作往往通过校友牵线搭桥，联合论文的作者中频繁出现已毕业校友的身影。

**第三圈层：产业合作伙伴**

NJU NLP与字节跳动、阿里巴巴（通义实验室）、美团等企业建立了深度合作关系，形成了"联合培养-联合发表-人才输送"的闭环模式。字节跳动火山翻译团队与NJU NLP的合作（如REDER/NeurIPS 2021）是最典型的案例。美团合作（如ReNeLLM/NAACL 2024）体现了在大模型安全方向的新拓展。通义实验室的合作（如DeltaMoE/ACL 2026）则反映了在多语言大模型前沿的协同创新。实验室还引入了"企业合作导师"机制，进一步制度化产业合作。

**第四圈层：国内外学术网络**

在国际层面，NJU NLP通过黄书剑在CMU和MSRA的访问经历、参与WMT国际评测等方式，与卡内基梅隆大学（Stephan Vogel）、微软亚洲研究院（Mu Li等）等建立了联系。在国内层面，通过毕业生进入清华大学AIR、北京中关村实验室、IDEA等新型研发机构，以及与浙江大学等高校的联合论文，构建了跨机构的学术合作网络。陈家骏本人作为CIPSC委员和国家级项目评议专家，在学术共同体内发挥着服务与评审作用。

总体而言，陈家骏教授的学术网络以NJU NLP研究组为核心枢纽，通过"师生传承+产业合作+校友网络"三重机制，形成了在国内NLP领域具有显著影响力的学术生态圈。其最突出的特点是：培养的大量学生进入头部科技企业后反哺学术合作，形成了产学研良性循环的独特模式。
