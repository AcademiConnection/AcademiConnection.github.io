# Academic Connection Network

面向高校与研究实验室的学术关系网络资料库。内容按“机构 / 实验室 → 教师个人报告”组织，涵盖学术履历、师承谱系、合作网络、团队培养与产学研联系等公开信息。

网站使用 MkDocs Material 构建，并通过 GitHub Actions 发布到 GitHub Pages。站点源文件位于 [`docs/`](docs/)。

## 报告生成来源

本仓库收录的全部学术关系网络报告均由 [AcademiConnection](https://github.com/AcademiConnection/AcademiConnection) 工具生成，并基于公开可获取的信息整理。
