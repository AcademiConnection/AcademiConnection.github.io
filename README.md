# Academic Connection Network

面向高校与研究实验室的学术关系网络资料库。内容按“机构 / 实验室 → 教师个人报告”组织，涵盖学术履历、师承谱系、合作网络、团队培养与产学研联系等公开信息。

网站使用 MkDocs Material 构建，并通过 GitHub Actions 发布到 GitHub Pages。站点源文件位于 [`docs/`](docs/)，本地预览可执行：

```bash
python3 -m pip install mkdocs-material
mkdocs serve
```

发布前请在 GitHub 仓库的 **Settings → Pages** 中将发布源设为 **GitHub Actions**。

资料来自公开来源，可能随时间变化；如需更正，请以学者或所属机构的最新公开信息为准。
